# blog 콘텐츠 정리 — 2026-08-17

세운의 지시로 blog.oiyo.net에서 걷어낸 콘텐츠다. `git rm` 대신 이 폴더로 옮겼다.

## 커리어 성장 스네이크 (`career-growth-snake-game.{ko,en}.mdx`)

- **판정 근거**: 세운의 직접 지시 — "정말 억지 컨텐츠 같습니다. 삭제 요망."
  GSC 90일(2026-05-18~08-15) 실측도 **노출 0 · 클릭 0**으로 이를 뒷받침한다.
- **설계 의도**: 스네이크 게임 메커니즘(지식을 먹고 몸이 길어지되 자기 꼬리=번아웃을 피한다)을
  커리어 성장의 비유로 쓴 게임형 아티클이었다. 게임을 심리·커리어 개념의 은유로 재해석하는
  매거진 실험군의 하나.
- **왜 접었나**: 은유가 콘텐츠를 끌고 가는 구조라 검색 의도와 만나는 지점이 없었다. 스네이크를
  찾는 사람은 game.oiyo.net에서 게임을 하고 싶은 것이고, 커리어 성장을 찾는 사람은 게임 비유를
  찾지 않는다. 두 수요 어느 쪽도 이 URL에 도착하지 않았다.
- **같이 정리한 것**: 이 글로 향하던 내부 링크 4개를 제거했다
  (`{ko,en}/psychology-test-guide.mdx`, `{ko,en}/checkers-maneuver-strategy.mdx`).

## 함께 진행된 랜딩·카탈로그 정리 (파일 이동 없음)

같은 배치에서 코드만 바뀐 항목들이다. 되돌리려면 git 이력을 보면 된다.

- `src/components/IntentBundles.astro` — 랜딩 퀵액세스에서 **심리 테스트**와 **게임 & 퍼즐**
  번들 제거(8종 → 6종). 근거: 두 항목의 실행 화면은 각각 oiyo.net과 game.oiyo.net에 있고,
  푸터에 이미 링크가 있다. 랜딩에 남겨 두면 blog 자체 콘텐츠 대신 형제 사이트로 사람을 흘려보낸다.
- `src/pages/[...lang]/tools.astro` — `/tools`의 **mystic(운세·사주·타로) 카테고리** 제거.
  사주·타로·별자리·수비학의 정본 실행 화면은 oiyo.net이다. `EXCLUDED_CATEGORIES`로 명시적으로
  거른 이유는, 카테고리 매핑에서 그냥 빼면 `?? "learning"` 기본값 때문에 학습 버킷으로
  조용히 흘러들어가기 때문이다.
  - 영향 범위: Mysticism 카테고리의 interactive 글 12편(`tool-saju-calculator`,
    `tool-tarot-daily-card`, `tool-chinese-zodiac` 등)이 `/tools` 카탈로그에서 빠진다.
    **글 자체는 지우지 않았다** — URL과 카테고리 페이지로는 그대로 접근된다.
