# ロストアーク公略団分配器

軍団長レイドを複数ゲームにわたって行う際に、딜러・서포터の比率が各パーティーに均等に配分されるよう自動計算するツールです。

## 進行方式

**本1副1（2ゲーム）**：本キャラ1回、サブキャラ1回  
**本1副3（4ゲーム）**：本キャラ1回、サブキャラ3回

各ゲームごとにサポーターとDPSの比率が偏らないよう最適配分を計算します。

## 入力方式

```
D(M) D S ㄷ
```

| 記号 | 意味 |
|---|---|
| `D`、`ㄷ`、`d` | DPS（딜러） |
| `S`、`ㅍ`、`s` | サポーター |
| `(M)` サフィックス | 本キャラクター |

1行に1人、スペースでキャラクターを区切ります。

<Callout type="tip">
**サポーター不足の場合**：レイド人数に対してサポーターが不足すると警告が表示されます。サポーター不足時は一部のゲームのパーティー構成が不均衡になる可能性があります。
</Callout>

## 均等配分アルゴリズム

このツールはメインサポーター・サブサポーター・メインDPSのゲームごとの偏差を最小化するスワップアルゴリズムを使用します。各ゲーム間の最大・最小値の差が1以下になるまで最適化します。
