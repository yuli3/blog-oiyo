# 로스트아크 tool- 문서 6편 → game 도구로 301 (2026-08-19)

## 왜

같은 도구가 blog에는 **문서**로, game에는 **실물 도구**로 있었다. 우리 페이지
둘이 같은 질의를 나눠 먹고 있었다.

```
                                   URL  노출  클릭
blog 측 (tool- 문서)                 4    16     0
game 측 (실제 도구)                  5    63    15
```

**클릭은 전부 game에서 나온다.** `game/ko/lostark-raid-distribution` 은 5위·
11클릭으로 패밀리에서 두 번째로 잘 버는 페이지다. blog 문서는 그 옆에서 노출만
갉아먹고 클릭은 0이었다.

`blog/en/tool-lostark-auction-calc` 13노출 22위 ↔
`game/en/lostark-auction-calculator` 4노출 38위 — 한 질의에 우리 페이지 둘이
3~4페이지에 나란히 있었다.

## 규칙을 파일 맨 앞에 넣은 이유

**blog `_redirects`는 #306~#320 사이에서 규칙 적용을 멈춘다.** 2026-08-19에
페이지가 없는 소스로 라이브 프로브해서 확인했다 — #306은 작동하고 #320·#340·
#360·#380은 전부 죽어 있다.

⚠️ **이건 동적 100 한도가 아니다.** blog는 동적이 7개뿐이고 무효 줄도 중복도
0인데 그렇다. wiki가 같은 날 죽은 원인(동적 353개)과는 **다른 현상**이고 원인은
2026-08-12에 "반복 배포 비용 대비 무가치"로 규명하지 않기로 했다.

그래서 **끝에 붙이면 조용히 작동하지 않는다.** 새 규칙은 앞쪽에 넣는다.

## 일괄 적용하지 말 것

blog의 `tool-*` 문서 42편(12슬러그) 중 10슬러그가 실제 도구와 겹치는데,
**어느 쪽이 이기는지는 짝마다 다르다.**

```
tool-daily-horoscope        21노출 3클릭  ↔  blog/daily-horoscope   0/0   ← 문서가 이김
tool-lostark-auction-calc   13노출 0클릭  ↔  game/…-calculator      4/0
tool-pomodoro-timer          6노출 0클릭  ↔  blog/pomodoro          1/0
나머지 6쌍                     양쪽 다 0
```

합쳐서 80노출·9클릭이다. **자기잠식은 실재하지만 걸린 트래픽은 작고**, 운세처럼
문서가 이기는 짝도 있다. 짝마다 재고 이긴 쪽으로 모은다.
