## 진짜 관계 궁합을 높이는 요소

재미로 보는 이름 궁합과 달리, 연구가 밝힌 실제 관계 만족도를 높이는 요소들이 있습니다.

| 요소 | 설명 |
|---|---|
| **공통 가치관** | 돈·자녀·가정에 대한 기본 관점 일치 |
| **소통 방식** | 갈등 시 대화 vs 회피 패턴 |
| **애착 유형** | 불안형·회피형·안정형 조합 |
| **성장 마인드셋** | 관계를 노력으로 발전시킬 수 있다는 믿음 |
| **공감 능력** | 상대방 감정을 이해하려는 의지 |

## 사랑의 언어 (5 Love Languages)

게리 채프먼의 연구에 따르면 사람마다 사랑을 표현하고 받는 방식이 다릅니다.

| 사랑의 언어 | 특징 |
|---|---|
| 인정하는 말 | 칭찬, 감사, 격려의 말 |
| 함께하는 시간 | 집중된 시간과 관심 |
| 선물 | 작은 선물로 마음 표현 |
| 봉사 행위 | 도움과 행동으로 사랑 표현 |
| 신체 접촉 | 포옹, 스킨십으로 연결감 형성 |

사주 계산기 페이지에서 더 자세한 심리 분석을 확인할 수 있습니다.
