# 摩斯密碼轉換器

摩斯密碼由塞繆爾·莫爾斯和艾爾菲德·維爾於1830年代發明，是有史以來最經久耐用的通信系統之一。它將每個字母和數字轉換為點（短信號）和劃（長信號）的組合。
