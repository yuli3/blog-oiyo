## 환전 팁

<Callout type="tip">
**가장 유리한 환전 방법**: ① 토스·카카오페이 환전 (우대율 90–95%) → ② 은행 앱 환전 (우대율 70–90%) → ③ 공항 환전소는 최후 수단. 여행 1–2주 전 환율이 유리할 때 미리 환전하세요.
</Callout>

| 방법 | 우대율 | 특징 |
|---|---|---|
| 토스·카카오페이 | 90–95% | 앱 환전 후 공항 수령 |
| 은행 앱 | 70–90% | 가장 접근성 좋음 |
| 은행 창구 | 50–70% | 기본 환율 |
| 공항 환전소 | 0–30% | 비쌈, 급할 때만 |
| 해외 현지 ATM | 우대율 낮음 | 비상 시 활용 |

## 환전 계산 꿀팁

- **달러 빠른 암산**: 1달러 ≈ 1,350원 기준 → 100달러 = 13.5만원
- **엔화 빠른 암산**: 1만 엔 ≈ 9,000–10,000원 → 10만 엔 = 약 9–10만원
- **유로 빠른 암산**: 1유로 ≈ 1,500원 → 100유로 = 15만원
