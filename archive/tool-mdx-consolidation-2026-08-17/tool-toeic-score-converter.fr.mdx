# Convertisseur Score TOEIC

Le TOEIC (Test of English for International Communication) est la certification d'anglais professionnel la plus utilisée en France, avec plus de 7 millions de candidats par an dans le monde. Comprendre ce que signifie votre score aide à cibler vos efforts.

## Tableau de Correspondance TOEIC → CECRL

| Score TOEIC | Niveau CECRL | Description |
|---|---|---|
| 10–254 | A1 | Débutant |
| 255–399 | A2 | Élémentaire |
| 400–549 | B1 | Intermédiaire |
| 550–784 | B2 | Intermédiaire avancé |
| 785–899 | C1 | Avancé |
| 900–990 | C1+ | Maîtrise professionnelle |

## Exigences en France

| Contexte | Score TOEIC recommandé |
|---|---|
| Diplôme de grande école (exigé) | 785–850 |
| Poste en multinationale | 700+ |
| Expatriation / mobilité internationale | 800+ |
| Permis de travail Canada (Express Entry) | 781+ (IELTS 6.5 équivalent) |
| Certification B2 reconnue | 785 |

<Callout type="tip">
**Progrès TOEIC** : Passer de 550 à 700 prend en moyenne 150–200 heures de travail régulier. Au-delà de 800, les gains marginaux deviennent plus lents. Concentrez-vous sur les erreurs récurrentes plutôt que sur la quantité de révision.
</Callout>
