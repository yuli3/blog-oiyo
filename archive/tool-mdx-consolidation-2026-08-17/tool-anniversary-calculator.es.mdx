# Calculadora de Aniversarios

Calcular fechas de aniversario a mano es tedioso y propenso a errores — los meses tienen distinto número de días y los años bisiestos complican aún más el cálculo. Introduce simplemente **una fecha de referencia** y deja que la calculadora haga todo el trabajo.

**Fechas calculadas:**
- 22, 50, 100, 200, 300 días — hitos a corto plazo
- 500, 1.000 días — hitos intermedios
- 1, 2, 3, 5, 10 años — aniversarios anuales

## ¿Cuándo usar esta calculadora?

| Fecha de referencia | Ejemplo de uso |
|---|---|
| Inicio de una relación | Aniversarios de pareja (100 días, 1 año) |
| Fecha de contratación | Antigüedad laboral |
| Fecha de nacimiento | Celebraciones y hitos personales |
| Creación de empresa | Aniversarios empresariales |
| Adopción de mascota | Aniversario de tu compañero |
| Inicio de dieta / dejar de fumar | Seguimiento de motivación (100 días, etc.) |

<Callout type="tip">
**Cuenta atrás D-Day**: Cuando se acerca una fecha especial, la calculadora muestra **D−N** días restantes. Las fechas pasadas se mantienen visibles como historial.
</Callout>
