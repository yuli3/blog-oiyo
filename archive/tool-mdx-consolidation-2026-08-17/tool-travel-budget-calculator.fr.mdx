# Calculateur de Budget Voyage

Établir un budget voyage est la première étape indispensable de toute planification. Décomposer les dépenses par catégorie — plutôt que de se fier à une estimation vague — évite les mauvaises surprises financières à votre retour.

## Budget journalier moyen par destination (par personne, en €)

| Destination | Économique | Confort | Premium |
|---|---|---|---|
| Portugal / Espagne | 50–75 € | 100–150 € | 250 €+ |
| Italie / France (hors Paris) | 60–90 € | 120–180 € | 300 €+ |
| Paris | 100–140 € | 200–300 € | 500 €+ |
| Japon | 60–90 € | 110–160 € | 220 €+ |
| Thaïlande / Vietnam | 30–50 € | 60–100 € | 170 €+ |
| Amérique du Nord | 100–140 € | 200–320 € | 550 €+ |

*Hébergement, repas et transports locaux inclus — vols internationaux non compris*

## Conseils pour économiser

<Callout type="tip">
**Vols** : Réservez 6–10 semaines à l'avance. Les départs mardi et mercredi sont souvent moins chers. Utilisez Skyscanner ou Google Flights en vue "mois entier" pour trouver les meilleures dates.
</Callout>

| Catégorie | Comment économiser |
|---|---|
| Vols | Réserver tôt, utiliser les miles, voyager en milieu de semaine |
| Hébergement | Airbnb, auberges de jeunesse, légèrement hors centre-ville |
| Repas | Marchés locaux, menus du midi, supermarchés |
| Transports | Pass journalier, vélo en libre-service, marche |
| Devises | Applications fintech (Revolut, Wise) pour les meilleurs taux |

## Répartition recommandée du budget (% du total)

| Catégorie | % recommandé |
|---|---|
| Vols | 30–40 % |
| Hébergement | 20–30 % |
| Repas | 15–20 % |
| Transports locaux | 10–15 % |
| Visites / entrées | 5–10 % |
| Shopping / souvenirs | 5–10 % |
| Fonds d'urgence | 10 % (indispensable !) |

<Callout type="warning">
**L'assurance voyage est incontournable.** Elle couvre les urgences médicales, les bagages perdus et les annulations de vol — et coûte généralement seulement 15–40 € pour un voyage international standard.
</Callout>
