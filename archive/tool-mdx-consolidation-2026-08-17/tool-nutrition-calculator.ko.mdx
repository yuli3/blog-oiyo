# 영양성분 계산기

식단을 계획하거나 오늘 먹은 음식의 영양성분을 합산하고 싶을 때 활용하는 계산기입니다. 20가지 주요 식품의 100g당 영양성분 데이터를 내장하고 있으며, 섭취량(g)을 조절하면 실시간으로 합산됩니다.

**지원하는 영양성분:**
- 칼로리 (kcal)
- 단백질 (g)
- 지방 (g)
- 탄수화물 (g)
- 식이섬유 (g)
- 나트륨 (mg)

## 영양성분 읽는 법

<Callout type="tip">
**한국인 영양섭취기준(KDRIs)** 성인 기준 일일 권장량: 칼로리 2,000kcal, 단백질 55-65g, 지방 50-65g, 탄수화물 300g, 식이섬유 25g, 나트륨 2,000mg 이하.
</Callout>

### 다이어트 시 주의할 식품

| 식품 | 함정 | 이유 |
|---|---|---|
| 라면 | 나트륨 과다 | 100g당 1,160mg (일일 권장량의 58%) |
| 아몬드 | 칼로리 과다 | 100g당 579kcal (고칼로리 지방) |
| 치즈 | 포화지방 | 100g당 33g 지방 |

### 단백질 효율 높은 식품 TOP 5

1. 닭가슴살: 109kcal / 단백질 23.1g
2. 두부: 76kcal / 단백질 8.1g
3. 달걀: 155kcal / 단백질 12.6g
4. 연어: 208kcal / 단백질 20.0g
5. 소고기(등심): 247kcal / 단백질 18.0g

영양성분 데이터는 한국식품영양소 함량 데이터베이스 및 USDA 기준을 참조했습니다.
