# 연차 계산기

"내 연차가 몇 일이나 남았지?" 매번 헷갈리는 연차 계산. 입사일과 사용 일수만 입력하면 즉시 계산합니다.

## 근로기준법 연차 발생 기준

### 1년 미만 신입사원 (월 단위 발생)

| 근속 기간 | 연차 발생 | 누적 |
|---|---|---|
| 1개월 개근 | 1일 | 1일 |
| 2개월 개근 | 1일 | 2일 |
| … | … | … |
| 11개월 개근 | 1일 | **최대 11일** |

### 만 1년 이상 (매년 15일 기본)

| 근속 연수 | 연차 일수 |
|---|---|
| 1년 | 15일 |
| 2년 | 15일 |
| 3년 | 16일 |
| 4년 | 16일 |
| 5년 | 17일 |
| … (2년마다 1일 가산) | … |
| 21년 이상 | **최대 25일** |

<Callout type="tip">
**가산 공식**: 15일 + ⌊(근속연수 − 1) ÷ 2⌋일, 최대 25일 한도
</Callout>

## 연차 사용 촉진 제도

사용자는 연차 만료 6개월 전까지 근로자에게 연차 사용을 촉구해야 합니다. 촉구에도 사용하지 않으면 **미사용 연차수당 지급 의무가 면제**됩니다.

<Callout type="warning">
**연차수당**: 연차를 사용하지 않고 퇴직하면 잔여 연차 × 1일 통상임금이 수당으로 지급됩니다. 단, 연차 사용 촉진을 받은 경우는 제외될 수 있습니다.
</Callout>

## 자주 묻는 질문

**Q. 주 15시간 미만 단시간 근로자도 연차가 생기나요?**  
네, 주 15시간 이상이면 연차 규정이 동일하게 적용됩니다. 15시간 미만 초단시간 근로자는 연차법 적용 제외입니다.

**Q. 반차(반일 연차)는 어떻게 계산하나요?**  
반차 2회 = 연차 1일 소진으로 처리됩니다. 이 계산기는 반차 0.5일 단위도 지원합니다.
