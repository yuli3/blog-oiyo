# Calculateur d'Amour

Quel est votre score de compatibilité ? Ce calculateur transforme deux prénoms en un pourcentage d'affinité — pour le plaisir. C'est un outil de divertissement, pas un oracle de votre vie sentimentale.

<Callout type="note">
Ce calculateur utilise un algorithme basé sur les lettres des prénoms. Il n'a aucune valeur prédictive réelle. La vraie compatibilité se construit avec la communication, le respect mutuel et les valeurs partagées — pas avec un algorithme.
</Callout>

## Ce que la psychologie dit vraiment de la compatibilité

| Facteur | Importance réelle |
|---|---|
| **Valeurs partagées** | Très élevée — vision du futur, famille, finances |
| **Communication** | Très élevée — résolution des conflits |
| **Attirance physique** | Élevée au début, diminue avec le temps |
| **Groupe sanguin / MBTI** | Aucune base scientifique |
| **Signe astrologique** | Aucune base scientifique |
| **Prénom / numérologie** | Aucune base scientifique |

La psychologie moderne se concentre sur les **styles d'attachement** formés dans l'enfance :

| Style | Comportement en relation | Compatible avec |
|---|---|---|
| **Sécure** | Confiant, stable | Tous les styles |
| **Anxieux** | Besoin de réassurance | Sécure (idéal) |
| **Évitant** | Besoin d'espace | Sécure (idéal) |
| **Désorganisé** | Ambivalent | Thérapie conseillée |
