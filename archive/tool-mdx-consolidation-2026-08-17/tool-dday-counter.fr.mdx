# Compteur D-Day Multi-Événements

Lorsqu'on jongle entre plusieurs deadlines, un seul compte à rebours ne suffit pas. Ce compteur vous permet de surveiller plusieurs événements simultanément — et ils sont sauvegardés automatiquement dans votre navigateur.

## Exemples d'Utilisation Combinée

| Événements | D-Days à suivre |
|---|---|
| Étudiant | Partiels, mémoire, soutenance, rentrée |
| Professionnel | Deadline projet, réunion client, congés |
| Couple | Anniversaire, vacances planifiées, mariage |
| Parentalité | Date prévue d'accouchement, anniversaires des enfants |
| Sport | Marathon, compétition, reprise entraînement |

<Callout type="tip">
**Conseil d'organisation** : Classez vos D-Days par catégorie (Pro / Personnel / Famille) et attribuez des icônes différentes pour identifier rapidement les événements prioritaires.
</Callout>
