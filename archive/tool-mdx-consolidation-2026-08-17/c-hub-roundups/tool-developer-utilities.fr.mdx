## Hash : Comparatif des Algorithmes

| Algorithme | Longueur | Sécurité | Usage |
|---|---|---|---|
| MD5 | 128 bits (32 hex) | ❌ Vulnérable | Vérification d'intégrité (non sécurisé) |
| SHA-1 | 160 bits (40 hex) | ⚠️ Déprécié | Systèmes legacy |
| SHA-256 | 256 bits (64 hex) | ✅ Sécurisé | Signatures, API, hachage général |
| SHA-512 | 512 bits (128 hex) | ✅ Très sécurisé | Systèmes haute sécurité |

<Callout type="warning">
**N'utilisez jamais MD5 pour stocker des mots de passe** : MD5 est vulnérable aux attaques par rainbow table. Pour les mots de passe, utilisez toujours bcrypt, Argon2 ou PBKDF2.
</Callout>
