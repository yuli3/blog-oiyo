# 운세 도구 모음

동서양의 지혜가 담긴 세 가지 운세 도구를 한 페이지에서 탐색합니다. 타로, 꿈 해몽, 오늘의 행운은 각각 다른 방식으로 내면을 들여다보는 문을 제공합니다. 과학적 근거는 없지만, 심리학에서 이런 도구들은 **프로젝션(투사)** — 자신의 생각과 감정을 외부 상징에 비춰 인식하는 과정 — 을 돕는다는 점에서 자기 탐색의 도구로 활용됩니다.

## 타로 카드 리딩

타로는 14세기 유럽에서 시작된 78장의 카드 덱입니다. 과거·현재·미래 3장 스프레드로 현재 상황을 살펴봅니다.

## 타로 스프레드 해석 가이드

| 위치 | 의미 |
|---|---|
| 1번 카드 (과거) | 현재 상황을 만든 배경과 원인 |
| 2번 카드 (현재) | 지금 당신이 처한 상황과 에너지 |
| 3번 카드 (미래) | 현재 방향대로 갈 때의 가능성 |

## 꿈 해몽 주요 상징

| 꿈 소재 | 전통적 해석 |
|---|---|
| 하늘을 나는 꿈 | 자유를 향한 욕구, 새로운 가능성 |
| 이가 빠지는 꿈 | 걱정·불안, 변화에 대한 두려움 |
| 물(바다·강) 꿈 | 감정, 무의식, 변화의 흐름 |
| 쫓기는 꿈 | 현실의 압박, 회피하고 싶은 것 |
| 돼지 꿈 | 재물운, 풍요 (한국 전통) |
