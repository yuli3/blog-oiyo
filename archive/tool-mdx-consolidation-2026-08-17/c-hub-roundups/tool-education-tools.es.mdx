## Niveles del MCER

| Nivel | Denominación | Capacidades |
|---|---|---|
| **A1** | Iniciación | Frases simples, presentaciones básicas |
| **A2** | Elemental | Situaciones cotidianas |
| **B1** | Intermedio | Temas familiares, viajes |
| **B2** | Intermedio alto | Textos complejos, interacción espontánea |
| **C1** | Avanzado | Lengua fluida, profesional |
| **C2** | Maestría | Comprensión casi nativa |
