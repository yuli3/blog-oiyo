# 영어 학습 도구 모음

영어 실력 향상의 첫 단계는 현재 수준을 정확히 파악하는 것입니다. 레벨 테스트로 출발점을 확인하고, 플래시카드로 어휘를 쌓고, 타이핑 속도를 높여 업무 생산성을 높이세요. 세 도구는 독립적으로 사용하거나 함께 학습 루틴으로 구성할 수 있습니다.

## 영어 수준(CEFR) 기준

| 레벨 | 설명 | 토익 점수 |
|---|---|---|
| A1 | 기초: 간단한 표현 가능 | 120 이하 |
| A2 | 초급: 일상 표현 가능 | 225 이하 |
| B1 | 중급: 친숙한 주제 소통 | 550 이하 |
| B2 | 중상급: 복잡한 주제 이해 | 785 이하 |
| C1 | 고급: 유창하고 자연스러운 표현 | 905 이상 |

## 타이핑 속도 기준 (WPM)

| 수준 | 영문 WPM | 설명 |
|---|---|---|
| 초급 | 20–30 | 독수리 타법 |
| 중급 | 40–60 | 일반 사무직 수준 |
| 빠름 | 60–80 | 전문 사무직 |
| 매우 빠름 | 80–100+ | 타이피스트·개발자 |

<Callout type="tip">
**플래시카드 학습법 (간격 반복)**: 처음 배운 단어는 1일 → 3일 → 7일 → 14일 → 30일 간격으로 복습하면 장기 기억으로 전환됩니다. 이것이 Anki 같은 앱의 핵심 원리입니다.
