# 생활 도구 모음

음악 연습, 육아, 건강, 식사 결정까지 일상의 다양한 상황에서 바로 꺼내 쓸 수 있는 도구 다섯 가지입니다. 특히 메트로놈과 예방접종 스케줄러는 독립 앱을 설치하지 않고 브라우저에서 바로 사용할 수 있다는 것이 장점입니다.

## 메트로놈 BPM 가이드

| 빠르기말 | BPM | 곡 예시 |
|---|---|---|
| Largo (매우 느리게) | 40–60 | 느린 발라드 |
| Andante (걷는 속도) | 76–108 | 포크송 |
| Moderato (보통) | 108–120 | 팝송 평균 |
| Allegro (빠르게) | 120–156 | 댄스 음악 |
| Presto (매우 빠르게) | 168–200+ | 테크노·드럼앤베이스 |

<Callout type="tip">
**예방접종 팁**: 국가필수예방접종(NIP)은 보건소와 지정 의료기관에서 **무료**로 받을 수 있습니다. 예방접종 도우미(nip.cdc.go.kr)에서 일정을 관리하세요.
</Callout>
