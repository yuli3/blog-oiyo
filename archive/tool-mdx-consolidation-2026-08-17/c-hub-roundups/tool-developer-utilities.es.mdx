## Hash: Comparativa de Algoritmos

| Algoritmo | Longitud | Seguridad | Uso |
|---|---|---|---|
| MD5 | 128 bits (32 hex) | ❌ Vulnerable | Verificación de integridad (no seguro) |
| SHA-1 | 160 bits (40 hex) | ⚠️ Obsoleto | Sistemas legacy |
| SHA-256 | 256 bits (64 hex) | ✅ Seguro | Firmas, APIs, hash general |
| SHA-512 | 512 bits (128 hex) | ✅ Muy seguro | Sistemas de alta seguridad |
