# 有給休暇計算機（韓国労基法）

「有給が何日残っているか」——毎回迷う有給の計算。入社日と使用日数を入力するだけで即座に確認できます。

## 韓国の有給休暇発生基準

### 入社1年未満（月単位で発生）

| 勤続期間 | 発生日数 | 累計 |
|---|---|---|
| 1ヶ月皆勤 | 1日 | 1日 |
| 2ヶ月皆勤 | 1日 | 2日 |
| … | … | … |
| 11ヶ月皆勤 | 1日 | **最大11日** |

### 満1年以上（毎年15日が基本）

| 勤続年数 | 年次有給 |
|---|---|
| 1年 | 15日 |
| 2年 | 15日 |
| 3年 | 16日 |
| 4年 | 16日 |
| 5年 | 17日 |
| …（2年ごとに1日加算）| … |
| 21年以上 | **最大25日** |

<Callout type="tip">
**加算計算式**：15日 + ⌊(勤続年数 − 1) ÷ 2⌋日、上限25日
</Callout>

## 有給取得促進制度

使用者は有給消滅6ヶ月前までに労働者に取得を促す必要があります。促進を行っても取得しなかった場合、**未使用有給手当の支払い義務が免除**される場合があります。

<Callout type="warning">
**未使用有給手当**：退職時に未使用有給がある場合、残日数×1日分の通常賃金が支払われます。ただし取得促進が適切に行われた場合は除外される可能性があります。
</Callout>

## よくある質問

**Q. 週15時間未満のパートタイムにも有給は発生しますか？**  
週15時間以上勤務の場合は同じ規定が適用されます。週15時間未満の場合は有給制度の対象外です。

**Q. 半休（半日有休）の計算方法は？**  
半休2回 = 有給1日消化として処理されます。この計算機は0.5日単位に対応しています。
