# 별자리 성격 분석

황도 12궁은 태양이 1년 동안 지나는 12개 별자리로, 태어난 날의 태양 위치를 기반으로 성격 특성을 분석하는 서양 점성술의 핵심입니다.

별자리 성격론은 기원전 2세기 헬레니즘 시대부터 발전해 온 문화적 전통입니다. 현대 심리학자 칼 융(Carl Jung)은 점성술이 인간의 원형적 패턴을 상징하는 도구로 활용될 수 있다는 점에 주목했습니다. 오늘날 별자리는 단순한 미신이 아니라 **자기 탐색의 언어**로 폭넓게 사용됩니다.

**이 분석기로 알 수 있는 것:**
- 내 별자리의 핵심 성격 키워드 (강점·약점)
- 연애·직장에서의 행동 패턴
- 원소(불·흙·바람·물)별 그룹 특성
- 나와 잘 맞는 별자리 궁합

별자리를 선택하면 즉시 분석이 시작됩니다.
