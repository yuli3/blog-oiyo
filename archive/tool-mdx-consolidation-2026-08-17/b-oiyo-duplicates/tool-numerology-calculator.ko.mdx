# 수비학(Numerology) 계산기

수비학은 숫자에 특별한 의미와 에너지가 있다는 고대 철학으로, 피타고라스(기원전 570~495)가 체계화했습니다. 생년월일을 더해 나오는 숫자로 삶의 방향성과 성격을 탐구합니다.

## 운명수(Life Path Number) 계산법

생년월일의 모든 숫자를 한 자리가 될 때까지 더합니다.

**예시: 1990년 5월 23일**  
1+9+9+0 + 0+5 + 2+3 = 29 → 2+9 = **11** (마스터 넘버)  
또는 1+1 = **2**

<Callout type="tip">
**마스터 넘버 (11·22·33)**: 두 자리로 유지하는 특별한 숫자. 더 큰 잠재력과 도전을 상징합니다. 보통 해석 시 단일 숫자(2·4·6)와 마스터 넘버 두 가지를 함께 고려합니다.
</Callout>

## 운명수별 의미

| 숫자 | 키워드 | 성격 특징 |
|---|---|---|
| **1** | 선구자 | 독립심, 리더십, 창조력 |
| **2** | 조화로운 자 | 협력, 외교, 감수성 |
| **3** | 표현하는 자 | 창의성, 커뮤니케이션, 낙천성 |
| **4** | 건설자 | 성실함, 체계성, 안정 추구 |
| **5** | 자유로운 자 | 모험, 변화, 다재다능 |
| **6** | 양육자 | 책임감, 사랑, 가정 중심 |
| **7** | 탐구자 | 분석력, 영적 탐구, 내향성 |
| **8** | 성취자 | 야망, 권력, 물질적 성공 |
| **9** | 인도주의자 | 관대함, 이상주의, 봉사 |
| **11** | 영적 직관자 | 직관력, 영감, 고감수성 |
| **22** | 마스터 건설자 | 대규모 비전, 실천력 |
| **33** | 마스터 교사 | 이타주의, 치유, 영적 지도 |
