# 顏色代碼轉換器

每種顏色格式都有其適用場景：HEX用於網頁，RGB用於螢幕和程式設計，HSL用於直覺調色，HSV用於色輪選色。手動轉換容易出錯，本工具一秒搞定。

## 顏色格式說明

| 格式 | 範例 | 主要用途 |
|---|---|---|
| **HEX** | `#FF5733` | CSS、HTML、網頁設計 |
| **RGB** | `rgb(255, 87, 51)` | 螢幕顯示、Canvas、CSS |
| **RGBA** | `rgba(255, 87, 51, 0.8)` | 帶透明度的CSS |
| **HSL** | `hsl(14°, 100%, 60%)` | 色調/飽和度調整 |
| **HSV** | `hsv(14°, 80%, 100%)` | Adobe系列、圖形工具 |
| **CMYK** | `C0 M66 Y80 K0` | 印刷設計 |

<Callout type="tip">
**設計技巧**：使用HSL建立和諧配色方案。建立深淺變體時，保持色調（H）和飽和度（S）不變，只調整亮度（L）。例：`hsl(220°, 80%, 60%)` → 淺色版：`hsl(220°, 80%, 85%)`
</Callout>
