# Calculadora de Presupuesto de Viaje

Elaborar un presupuesto de viaje es el primer paso imprescindible de cualquier planificación. Desglosar los gastos por categoría —en lugar de hacer una estimación vaga— evita sorpresas financieras desagradables a tu vuelta.

## Presupuesto diario medio por destino (por persona, en €)

| Destino | Económico | Confort | Premium |
|---|---|---|---|
| Portugal / Marruecos | 30–50 € | 70–110 € | 200 €+ |
| Italia / Francia | 60–90 € | 120–180 € | 300 €+ |
| España (interior) | 50–75 € | 100–150 € | 250 €+ |
| Japón / Corea | 60–90 € | 110–160 € | 220 €+ |
| Sudeste Asiático | 30–45 € | 65–100 € | 170 €+ |
| Latinoamérica | 35–55 € | 75–120 € | 200 €+ |

*Incluye alojamiento, comidas y transporte local — vuelos internacionales no incluidos*

## Consejos para ahorrar

<Callout type="tip">
**Vuelos**: Reserva con 6–10 semanas de antelación. Los martes y miércoles suelen ser más baratos. Usa Skyscanner o Google Flights en vista "mes completo" para encontrar las mejores fechas.
</Callout>

| Categoría | Cómo ahorrar |
|---|---|
| Vuelos | Reservar con antelación, usar millas, volar entre semana |
| Alojamiento | Airbnb, hostales, ligeramente fuera del centro |
| Comidas | Mercados locales, menú del día, supermercados |
| Transporte | Bono de transporte diario, bicicleta, a pie |
| Divisas | Apps fintech (Revolut, Wise) para las mejores tasas |

## Distribución recomendada del presupuesto (% del total)

| Categoría | % recomendado |
|---|---|
| Vuelos | 30–40 % |
| Alojamiento | 20–30 % |
| Comidas | 15–20 % |
| Transporte local | 10–15 % |
| Visitas / entradas | 5–10 % |
| Compras / souvenirs | 5–10 % |
| Fondo de emergencia | 10 % (¡imprescindible!) |

<Callout type="warning">
**El seguro de viaje es imprescindible.** Cubre emergencias médicas, equipaje perdido y cancelaciones de vuelo — y suele costar solo 15–40 € para un viaje internacional estándar.
</Callout>
