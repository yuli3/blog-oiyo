# Convertisseur de Couleurs

Chaque format de couleur a son domaine d'application : HEX pour le web, RGB pour les écrans et la programmation, HSL pour les ajustements intuitifs, HSV pour les roues de couleurs. Convertir manuellement entre ces formats est source d'erreurs — cet outil le fait instantanément.

## Formats de couleurs expliqués

| Format | Syntaxe | Utilisation principale |
|---|---|---|
| **HEX** | `#FF5733` | CSS, HTML, design web |
| **RGB** | `rgb(255, 87, 51)` | Écrans, Canvas, CSS |
| **RGBA** | `rgba(255, 87, 51, 0.8)` | CSS avec transparence |
| **HSL** | `hsl(14°, 100%, 60%)` | Ajustements teinte/saturation |
| **HSV** | `hsv(14°, 80%, 100%)` | Adobe, outils graphiques |
| **CMJN** | `C0 M66 Y80 K0` | Impression offset |

<Callout type="tip">
**Conseil design** : Utilisez HSL pour créer des palettes harmonieuses. Pour créer une couleur plus claire ou plus foncée, gardez la teinte (H) et la saturation (S) et faites varier uniquement la luminosité (L). Ex. : `hsl(220°, 80%, 60%)` → version claire : `hsl(220°, 80%, 85%)`
</Callout>
