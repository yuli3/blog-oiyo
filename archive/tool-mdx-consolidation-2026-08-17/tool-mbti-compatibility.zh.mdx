# MBTI性格配對

MBTI（邁爾斯-布里格斯類型指標）將人格分為16種類型，基於四個維度：外向/內向、感覺/直覺、思考/情感、判斷/感知。儘管科學性存在爭議，它仍是全球最廣泛使用的自我認知工具之一。

## 16種MBTI人格類型

| 類別 | 類型 | 核心特徵 |
|---|---|---|
| **分析家** | INTJ、INTP、ENTJ、ENTP | 邏輯性、戰略性 |
| **外交家** | INFJ、INFP、ENFJ、ENFP | 共情、理想主義 |
| **守護者** | ISTJ、ISFJ、ESTJ、ESFJ | 可靠、負責任 |
| **探險家** | ISTP、ISFP、ESTP、ESFP | 自發、適應力強 |

## 配對核心維度

| 共同維度 | 對關係的影響 |
|---|---|
| **N/S相同** | 溝通更自然，有共同的世界觀 |
| **T/F相反** | 可能產生摩擦，但互補性強 |
| **J/P相反** | 一個計畫，一個隨機應變——摩擦或平衡 |
| **E/I混搭** | 若雙方理解彼此需求，往往相得益彰 |

<Callout type="tip">
**「對立」組合（如INTJ & ENFP）**往往是最持久的伴侶關係。雙方各自擁有對方天生缺乏的特質。關鍵不是相似，而是相互理解。
</Callout>
