# Calculateur d'Hydratation

Le corps humain est composé à **60–70 % d'eau**. Une déshydratation de seulement 2 % altère les performances cognitives. Pourtant, la plupart des gens boivent insuffisamment — non par manque de volonté, mais par manque de routine.

## Besoins en eau selon le profil

| Profil | Besoin quotidien estimé |
|---|---|
| Adulte sédentaire (70 kg) | ~2,0–2,5 L |
| Adulte actif (70 kg, sport 1h) | ~2,5–3,0 L |
| Femme enceinte | +0,3 L supplémentaires |
| Allaitement | +0,7 L supplémentaires |
| Environnement chaud / humide | +0,5–1,0 L supplémentaires |

<Callout type="tip">
**Règle pratique** : ~35 ml par kg de poids corporel. Pour 70 kg : 70 × 35 = 2 450 ml. Ajoutez 400–600 ml par heure d'exercice modéré.
</Callout>

## Programme d'hydratation recommandé

| Heure | Quantité | Pourquoi |
|---|---|---|
| Au réveil | 250–500 ml | Réhydrater après 7–8h sans boire |
| Avant les repas | 250 ml | Soutient la digestion |
| Après-midi (14–16h) | 300–500 ml | Période de creux naturel |
| Avant le sport | 500 ml | Prévention des crampes |
| Après le sport | 400–700 ml | Compensation des pertes |
| 1 heure avant le coucher | Max 150 ml | Éviter les réveils nocturnes |

## Signes de déshydratation

| Symptôme | Niveau de déshydratation |
|---|---|
| Légère soif, urine jaune foncé | –1 à 2 % |
| Maux de tête, fatigue | –2 à 3 % |
| Vertiges, crampes musculaires | –4 à 5 % |
| Confusion, accélération cardiaque | > –5 % |

<Callout type="note">
Boire plus de 500 ml d'un coup est contre-productif. **200 ml toutes les 1–2 heures** est bien plus efficace pour l'absorption. Un rappel sur téléphone toutes les 2 heures suffit à transformer l'habitude.
</Callout>
