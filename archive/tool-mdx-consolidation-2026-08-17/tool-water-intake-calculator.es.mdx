# Calculadora de Hidratación

El cuerpo humano está compuesto de un **60–70 % de agua**. Una deshidratación de solo el 2 % deteriora el rendimiento cognitivo. Sin embargo, la mayoría de las personas beben insuficientemente — no por falta de voluntad, sino por falta de rutina.

## Necesidades de agua según el perfil

| Perfil | Necesidad diaria estimada |
|---|---|
| Adulto sedentario (70 kg) | ~2,0–2,5 L |
| Adulto activo (70 kg, deporte 1h) | ~2,5–3,0 L |
| Mujer embarazada | +0,3 L adicionales |
| Lactancia | +0,7 L adicionales |
| Entorno caluroso / húmedo | +0,5–1,0 L adicionales |

<Callout type="tip">
**Regla práctica**: ~35 ml por kg de peso corporal. Para 70 kg: 70 × 35 = 2.450 ml. Añade 400–600 ml por hora de ejercicio moderado.
</Callout>

## Programa de hidratación recomendado

| Hora | Cantidad | Por qué |
|---|---|---|
| Al despertar | 250–500 ml | Rehidratarse tras 7–8h sin beber |
| Antes de las comidas | 250 ml | Favorece la digestión |
| Tarde (14–16h) | 300–500 ml | Periodo de caída natural de energía |
| Antes del ejercicio | 500 ml | Prevención de calambres |
| Después del ejercicio | 400–700 ml | Compensar las pérdidas |
| 1 hora antes de dormir | Máx. 150 ml | Evitar despertares nocturnos |

<Callout type="note">
Beber más de 500 ml de una vez es contraproducente. **200 ml cada 1–2 horas** es mucho más eficaz para la absorción. Un recordatorio en el teléfono cada 2 horas es suficiente para transformar el hábito.
</Callout>
