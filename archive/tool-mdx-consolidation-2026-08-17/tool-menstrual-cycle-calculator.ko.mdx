# 생리주기 계산기

생리주기를 파악하면 컨디션 관리, 여행·행사 계획, 임신 준비 등에 큰 도움이 됩니다. 마지막 생리 시작일과 평균 주기만 입력하면 됩니다.

## 생리주기 기본 개념

**평균 주기**: 21–35일 (평균 28일)  
**생리 기간**: 3–7일  
**배란일**: 다음 생리 예정일로부터 약 14일 전

| 단계 | 기간 (28일 기준) | 특징 |
|---|---|---|
| 생리기 | 1–5일 | 자궁내막 탈락, 호르몬 최저 |
| 여포기 | 6–13일 | 에스트로겐 상승, 활력 증가 |
| 배란기 | 14일 전후 | 가임기 최고점, LH 급상승 |
| 황체기 | 15–28일 | 프로게스테론 상승, PMS 시작 |

<Callout type="tip">
**가임기(임신 가능 기간)**: 배란일 전 5일 + 배란 당일 + 배란 후 1일, 총 약 7일. 정자는 체내 3–5일 생존하므로 배란 전부터 가임기가 시작됩니다.
</Callout>

## 생리불순 기준

| 상황 | 기준 |
|---|---|
| 정상 범위 | 주기 21–35일, 편차 ±7일 이내 |
| 빈발월경 | 주기 21일 미만 |
| 희발월경 | 주기 35일 이상 |
| 무월경 | 3개월 이상 없음 |
| 과다월경 | 생리량 과도 (패드 1시간마다 교체) |

<Callout type="warning">
이 계산기는 **평균 주기 기반 예측**입니다. 스트레스, 체중 변화, 호르몬 불균형 등으로 실제 배란일은 달라질 수 있습니다. 임신을 원하거나 피임이 필요한 경우 산부인과 상담 및 배란 테스트기를 병행하세요.
</Callout>

## PMS(월경전증후군) 관리

배란 후 황체기(15–28일)에 많은 분들이 PMS를 경험합니다.

- **신체 증상**: 유방 압통, 복부 팽만, 두통, 피로
- **심리 증상**: 예민함, 우울감, 집중력 저하
- **완화법**: 규칙적 유산소 운동, 카페인·나트륨 제한, 충분한 수면, 마그네슘 보충
