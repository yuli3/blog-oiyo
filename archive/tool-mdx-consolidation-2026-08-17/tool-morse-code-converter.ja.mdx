# モールス信号変換器

モールス信号（Morse Code）は1840年代にサミュエル・モースが発明した電気通信システムで、点（・）と線（−）の組み合わせで文字を表現します。SOS（···−−−···）のような遭難信号でもよく知られています。

<Callout type="tip">
**SOS**：···−−−··· （点3つ・線3つ・点3つ）。1906年に国際遭難信号として採択。緊急時には地面に書いたり懐中電灯でも送信できます。
</Callout>

## モールス信号の規則

- **点（·）**：1単位時間
- **線（−）**：3単位時間
- **文字内の間隔**：1単位時間
- **文字間の間隔**：3単位時間
- **単語間の間隔**：7単位時間
