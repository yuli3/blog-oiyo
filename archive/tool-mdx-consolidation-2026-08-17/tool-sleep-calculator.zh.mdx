# 睡眠計算器

明明睡了8小時，為什麼還是覺得很累？問題不總是睡眠時長——而是**時機**。每個睡眠週期約為90分鐘。在週期中途醒來會產生睡眠慣性（起床氣），而在週期末尾醒來則會感到神清氣爽。

## 睡眠階段

| 階段 | 大致時長 | 功能 |
|---|---|---|
| **N1（入睡）** | 5–10分鐘 | 清醒→睡眠過渡 |
| **N2（淺睡）** | 20–30分鐘 | 記憶鞏固、心率減慢 |
| **N3（深睡）** | 20–40分鐘 | 身體恢復、免疫增強 |
| **REM（快速動眼）** | 10–60分鐘 | 做夢、情緒整合 |

一個完整週期約**90分鐘**。7.5小時睡眠 = 5個完整週期。

<Callout type="tip">
**時間生物學小提示**：身體在N2（淺睡）階段自然準備醒來。將鬧鐘設置在週期末尾，在N2而非N3階段醒來，起床氣會大幅減少。
</Callout>

## 各年齡段建議睡眠時長

| 年齡段 | 建議時長 | 最少時長 |
|---|---|---|
| 嬰兒（0–3個月） | 14–17小時 | 11小時 |
| 兒童（6–12歲） | 9–12小時 | 8小時 |
| 青少年（13–18歲） | 8–10小時 | 7小時 |
| 成人（18–64歲） | **7–9小時** | 6小時 |
| 老年人（65歲+） | 7–8小時 | 5小時 |

## 睡眠負債

每晚少睡1小時，一週後就會累積**7小時睡眠債**。這相當於血液酒精濃度0.10%時的認知損傷程度。週末補眠並不能完全恢復。

<Callout type="warning">
本計算器不診斷睡眠障礙（睡眠呼吸中止症、失眠等）。如有持續問題，請諮詢醫師或睡眠專科醫師。
</Callout>
