# 生理週期計算器

了解自己的生理週期是重要的自我健康管理方式。本工具幫助您預測下次月經時間、找出排卵高峰期，更好地了解身體規律。

## 生理週期四個階段

| 階段 | 典型天數 | 身體變化 |
|---|---|---|
| **月經期** | 第1–5天 | 子宮內膜脫落出血 |
| **卵泡期** | 第1–13天 | 卵泡發育，雌激素上升 |
| **排卵期** | 約第14天（28天週期） | 卵子釋放——生育高峰 |
| **黃體期** | 第15–28天 | 黃體素上升，為受精卵著床做準備 |

## 易孕期計算

卵子在排卵後存活**12–24小時**，精子在體內可存活**3–5天**。因此每個週期的易孕窗口約為**5–6天**。

<Callout type="tip">
**排卵信號**：白帶變清澈拉絲（似生蛋清），基礎體溫微升（+0.2–0.5°C），下腹部輕微刺痛感（排卵痛）。這些信號因人而異。
</Callout>
