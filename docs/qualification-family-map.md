# Qualification Family Map

## 1. Purpose

This document groups qualifications into editorial families so they can be planned consistently across:

1. overview articles
2. lecture pathways
3. comparison pages
4. structured data records

## 2. Family Grouping Rule

Every qualification should belong to one primary family and may link to one or more secondary subject families.

## 4. Qualification Record Planning Rule

Each qualification should eventually support these content layers.

1. short overview
2. detailed roadmap
3. first-stage subjects
4. second-stage subjects
5. lecture links
6. preparation timeline
7. comparison page membership

## 5. Qualification-to-Lecture Link Rule

Examples:

1. 공인노무사 -> 노동법, 인사관리, 행정쟁송 관련 lecture pathway
2. 세무사 -> 세법학, 국가징수법, 종합부동산세, 양도소득세, 상속세, 증여세, 회계학, 재정학, 경제학
3. 감정평가사 -> 경제학, 회계학, 민법, 감정평가이론
4. 경영지도사 -> 경영학, 인사관리, 마케팅, 재무관리
5. 변리사 -> 민법, 산업재산권 관련 pathway
