# Content Style Examples

## 1. Purpose

This document gives concrete examples of how the standards should look in practice.

## 2. Academy Example

Title:

`Ch3. 인사관리`

Good structure:

1. 이 장이 중요한 이유
2. 핵심 용어
3. 개념 설명
4. 비교표
5. 사례
6. 시험 포인트
7. 요약

Good emphasis:

1. `**직무분석**은 채용, 배치, 평가의 출발점입니다.`
2. `<mark data-tone="yellow">암기 포인트</mark>`
3. `<mark data-tone="green">실무 적용 포인트</mark>`

Bad structure:

1. 긴 서론만 있고 핵심 개념이 늦게 등장함
2. 아무 이유 없이 여러 차트를 삽입함
3. 장 제목이 장황함

## 3. Magazine Example

Title:

`공부 잘하는 방법론`

Good structure:

1. 문제 제기
2. 핵심 원리
3. 압축 전략
4. 복습 전략
5. 실전 적용
6. 관련 강의 링크

Good style:

1. lecture처럼 딱딱하지 않음
2. 그래도 구조는 명확함
3. 필요한 경우만 표나 callout 사용

## 4. Interactive Example

Title:

`오목의 유래와 두는 법`

Good structure:

1. 오목이 왜 재밌는가
2. 기본 규칙
3. 초반 핵심 개념
4. `Gomoku` island 삽입
5. 실제로 두면서 이해할 포인트
6. 더 읽을 거리

Rule:

The page is still an article. The island strengthens the article, not the other way around.

## 5. Emphasis Examples

### Good

1. `**양도소득세**는 양도차익과 보유기간, 비과세 요건을 함께 봐야 합니다.`
2. `<mark data-tone="yellow">시험에 자주 나오는 함정</mark>`
3. `<mark data-tone="green">실무상 먼저 확인할 항목</mark>`

### Bad

1. 문단 전체를 전부 굵게 처리
2. 한 문단에 형광 표시를 여러 번 연속 사용
3. `<b>`를 남발해서 마크다운 규칙을 우회

## 6. Public Document Writing Example

Hierarchy example:

1. `1`
2. `가`
3. `1)`
4. `가)`
5. `(1)`
6. `(가)`

Use this when the content is formal, procedural, or lecture-outline oriented.
