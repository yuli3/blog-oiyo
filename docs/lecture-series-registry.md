# Lecture Series Registry

## 1. Purpose

This registry is the planning surface for `academy`.

A lecture series should be registered here before full drafting begins, so chapters, visuals, and internal links are designed deliberately.

## 2. Registry Fields

Each series should eventually define:

1. `series_id`
2. display title
3. category
4. target audience
5. qualification linkage
6. planned chapter count
7. prerequisite level
8. required data source
9. preferred visual types
10. rollout priority
