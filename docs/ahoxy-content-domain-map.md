# Ahoxy Content Domain Map

## 1. Purpose

This document groups Ahoxy’s wide slug inventory into migration-ready editorial families.

Ahoxy contains a large number of message namespaces and tool/game/test slugs. This map is the domain-level abstraction that allows full-inventory governance without manually improvising each case from scratch.

## 3. Mapping Rule

Each Ahoxy slug should eventually be assigned:

1. domain family
2. source type
3. target track
4. target editorial angle
5. migration priority

## 4. Full-Inventory Governance Principle

“Full inventory” does not mean every Ahoxy slug must become a blog article.

It means every slug must receive a decision:

1. migrate
2. cross-link
3. hold
4. archive

That decision must be documented.
