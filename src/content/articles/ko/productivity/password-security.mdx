# 복잡성보다 '길이'가 중요합니다

짧지만 특수문자가 섞인 비밀번호보다, 긴 문장형 비밀번호가 해킹(브루트 포스 공격)하기 훨씬 어렵습니다.
-   **약함**: `P@sw0rd!` (복잡해 보이지만 짧고 예측 가능)
-   **강함**: `coffee blue sky morning run` (길고 무작위)

# 보안 팁

1.  **비밀번호 관리자 사용**: 모든 사이트의 비밀번호를 다 외우지 마세요.
2.  **개인정보 피하기**: 이름, 생일, 반려동물 이름은 추측하기 쉽습니다.
3.  **비밀번호 재사용 금지**: 특히 이메일이나 금융 사이트의 비밀번호는 절대 다른 곳과 똑같이 쓰지 마세요.
4.  **2단계 인증(2FA) 설정**: 2단계 인증은 해킹을 막는 가장 강력한 방패입니다.
