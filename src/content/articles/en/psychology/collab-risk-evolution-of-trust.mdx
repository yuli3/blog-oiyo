# The Evolution of Trust

In 1980, political scientist Robert Axelrod held a tournament. He invited experts in game theory to submit computer programs to play the **Prisoner's Dilemma** against each other thousands of times.

## The Problem

- **Cooperate**: Both win (+3 points).
- **Defect**: You win big (+5), they lose big (0).
- **Both Defect**: Both lose (+1).

Logic dictates you should *always* defect. If they cooperate, you get +5. If they defect, you get +1 (better than 0). So, rational agents should never trust each other.

## The Solution: Tit-for-Tat

The winner was the simplest code submitted: **Tit-for-Tat** (4 lines of BASIC).
1.  START by Cooperating.
2.  THEN, copy whatever the opponent did last round.

### Why it Won
It embodied four properties of evolutionary success:
1.  **Nice**: Never defect first.
2.  **Retaliatory**: If betrayed, strike back immediately.
3.  **Forgiving**: If the opponent apologizes (cooperates), return to cooperation immediately.
4.  **Clear**: Its behavior was predictable, building trust.

## Daily Nash Equilibrium

We often think "Nice guys finish last." Math says otherwise. In a repeated game (life), **Reciprocal Altruism** is the only stable strategy. Trust is not a moral virtue; it is an evolutionary survival mechanism.
