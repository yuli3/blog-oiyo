# 第9章: 人事行政の基礎

人事行政は、政府の目標を達成するために優秀な公務員を採用し、管理し、士気を高める一連の過程です。「人がすなわち政策である」という言葉のように、人事は行政の核心です。

---

## 1. 開放型 vs 閉鎖型 任用体系

- **開放型 (Open System)**: 外部の専門家をいつでも採用できる体系。（競争を促進し専門性を向上させるが、公務員の士気低下の懸念がある）
- **閉鎖型 (Closed System)**: 最下位職としてのみ採用し、それ以上は内部昇進で埋める体系。（身分保障が強化され一体感が形成されるが、閉鎖性と官僚主義の懸念がある）

---

## 2. 階級制 vs 職位分類制

公務員組織をどのような基準で分けるかについての最も重要な分類です。

| 区分         | 階級制 (Rank-in-person)          | 職位分類制 (Rank-in-job)         |
| :----------- | :------------------------------- | :------------------------------- |
| **分類基準** | 人の資格、学歴、身分             | 職務の種類、困難度、責任         |
| **特徴**     | ジェネラリスト (Generalist) 志向 | スペシャリスト (Specialist) 志向 |
| **人事異動** | 広範な配置転換が可能             | 専門分野内に制限                 |
| **補償基準** | 人の身分と勤続                   | 職務の価値（同一労働・同一賃金） |
| **強み**     | 身分保障、柔軟な人力活用         | 専門性の確保、公正な補償         |

---

## 3. 職位分類制の樹立手順

1. **職務分析**: 職務を性質に応じて **職群、職列、職類** に分ける過程。
2. **職務評価**: 職務の困難度と責任に応じて **等級 (Grade)** と **職級 (Class)** に分ける過程。
