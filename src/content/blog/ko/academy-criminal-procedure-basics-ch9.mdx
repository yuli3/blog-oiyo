## 오답 유형 1 — 체포 종류 혼동

```
자주 틀리는 포인트:

현행범 체포:
"누구든" 가능 (사인 포함)
범죄 실행 중·직후

긴급체포:
"수사기관만" 가능 (사인 불가)
체포 후 즉시 영장 청구 필수

자주 나오는 함정:
"긴급체포는 누구든 가능" → 오답 (수사기관만)
"현행범 체포 후 영장 불필요" → 정답
"긴급체포 후 영장 불필요" → 오답 (즉시 청구 필요)
```

## 오답 유형 2 — 증거 법칙 혼동

```
자주 틀리는 포인트:

자백 보강 법칙:
자백만으로 유죄 불가 → 보강증거 필요
"자백+자백 = 유죄" → 오답 (자백끼리는 보강 안됨)

전문 법칙:
전문증거 = 원칙적 증거 능력 없음
예외: 피의자 신문조서 (내용 인정 필요)

위법수집증거:
영장 없이 압수한 물증 = 증거 능력 없음
독수독과: 위법 증거에서 파생된 것도 배제
```

## 오답 유형 3 — 불이익변경금지 적용 범위

```
자주 틀리는 포인트:

불이익변경금지 적용:
피고인만 항소(상고) 시 적용
원심보다 중한 형 선고 불가

적용 안되는 경우:
검사도 항소한 경우
항고 (결정·명령 불복)

함정:
"불이익변경금지는 항상 적용" → 오답 (검사도 항소 시 미적용)
"약식명령 정식재판 청구 후도 적용" → 정답 (피고인만 청구 시)
```

## 오답 유형 4 — 기소독점·재정신청

```
자주 틀리는 포인트:

기소독점주의:
검사만 공소 제기 가능
경찰은 불가

재정신청:
고소인이 불기소 처분에 불복
법원에 신청 → 법원이 기소 명령 가능

친고죄 고소 취소:
1심 판결 선고 전까지만 취소 가능
판결 선고 후 취소 불가

함정:
"재정신청은 누구든 가능" → 오답 (고소인만)
"친고죄 고소는 언제든 취소 가능" → 오답 (1심 판결 전만)
```

## 핵심 개념 카드

**긴급체포=수사기관만+즉시영장** ★★★★★
: 현행범(누구든)과 구별.
*암기 포인트: 긴급체포=수사기관+영장*

**불이익변경금지=피고인만항소시** ★★★★★
: 검사도 항소하면 적용 안됨.
*암기 포인트: 불이익금지=피고인만*

**친고죄고소취소=1심판결전** ★★★★☆
: 1심 판결 선고 후에는 고소 취소 효력 없음.
*암기 포인트: 친고죄취소=1심전*

## 실전 퀴즈

**Q. "고소 취소 후에도 검사가 기소할 수 있는가?" (친고죄 사건)**
> 원칙: 친고죄는 고소 없으면 공소 제기 불가. 이미 공소 제기된 경우: 1심 판결 전 고소 취소 → 공소 기각. 1심 판결 선고 후 고소 취소 → 효력 없음 (취소 불가). 공소 제기 전 고소 취소: 공소 제기 자체 불가. 결론: 1심 판결 전 취소 = 기소 불가·공소 기각. 판결 후 취소 시도 = 효력 없음.

**Q. 자백만으로 유죄 선고한 판결의 법적 문제는?**
> 자백 보강 법칙 위반 (형소법 제310조). 위반 시: 판결 위법, 상소 이유. 항소심에서 파기 사유. 자백만으로 유죄 = 헌법 위반 (자기부죄거부권 실질적 침해). 설령 피고인이 자백을 유지해도 보강증거 필요. 취지: 허위 자백·자백 강요 방지.
