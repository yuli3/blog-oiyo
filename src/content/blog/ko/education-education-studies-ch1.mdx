## 교육(Education)이란?

```
교육의 어원:
→ 라틴어 educatio (이끌어 내다)
→ 내재적 가능성을 끌어내는 과정

교육의 정의:
→ 인간의 잠재적 가능성을 최대한 실현하도록 돕는
  의도적·계획적 활동

교육의 3가지 측면:
1. 규범적 의미: 가치 있는 것을 전달
2. 인지적 의미: 지식·이해 형성
3. 과정적 의미: 도덕적으로 허용 가능한 방법 사용

교육의 유형:
→ 형식 교육 (Formal): 학교, 구조화된 교육과정
→ 비형식 교육 (Non-formal): 학교 밖 의도적 교육 (평생교육, 학원)
→ 무형식 교육 (Informal): 일상 속 우연한 학습

교육 vs 훈련 vs 교화:
→ 교육: 이해, 비판적 사고, 자율성 포함
→ 훈련: 특정 기술·행동 형성
→ 교화: 비판 없이 일방적 주입 (교육과 구별)
```

## 교육의 목적

```
교육 목적의 수준:
1. 교육 이념: 홍익인간, 민주시민 등 (가장 상위)
2. 교육 목적: 이념 구체화 (인격 완성 등)
3. 교육 목표: 구체적 행동 변화 (교과별, 학년별)

교육 목적의 분류:

내재적 목적 (교육 자체가 목적):
→ 지식 추구 자체의 가치
→ 피터스(Peters): 내재적 가치 강조
→ 인간 자체의 완성

외재적 목적 (수단으로서의 교육):
→ 국가 발전, 경제 성장
→ 취업, 사회 진출
→ 사회화·문화 전달

블룸(Bloom)의 교육 목표 분류:
→ 인지적 영역: 지식, 이해, 적용, 분석, 종합, 평가
→ 정의적 영역: 수용, 반응, 가치화, 조직화, 인격화
→ 심동적 영역: 신체 기능, 운동 능력
```

## 교육철학의 흐름

```
진보주의 (Progressivism, 듀이):
→ 아동 중심 교육, 경험 중심 학습
→ 민주적 학교 공동체
→ "교육은 삶이지 삶을 위한 준비가 아니다"
→ 문제해결, 탐구 학습 강조
→ 비판: 기초 학력 저하 우려

항존주의 (Perennialism, 허친스):
→ 불변하는 진리 강조 (고전 읽기)
→ 그레이트 북스(Great Books) 운동
→ 이성 계발이 교육의 핵심
→ 비판: 현실 적용성 부족

본질주의 (Essentialism):
→ 기본 지식·기술 전달 강조
→ 교사 주도, 학문 중심
→ 학업 성취, 훈련, 표준화 강조

재건주의 (Reconstructionism):
→ 교육을 통한 사회 개혁
→ 비판적 사고, 사회 문제 해결
→ 비고츠키적 사회문화 맥락 강조

실존주의 교육:
→ 개인의 자유·책임·선택 강조
→ 프레이리 (Freire): 의식화 교육
→ "은행 예금식 교육" 비판 → 대화식 교육
```

## 교육사회학

```
기능론 (Functionalism):
→ 사회는 유기체, 교육은 사회 통합 기능
→ 뒤르켐: 사회화 기관으로서의 학교
→ 파슨스: 학교는 사회 선발·배치 기능
→ 인적 자본론 (Human Capital Theory):
  교육 = 생산성·소득 증가 투자

갈등론 (Conflict Theory):
→ 교육은 불평등 재생산 도구
→ 부르디외: 문화 자본 (cultural capital)
  상류층 문화가 학교에서 유리
→ 보울스·긴티스: 대응 이론
  학교는 자본주의 노동자 길러내는 장치
→ 잠재적 교육과정: 학교에서 의도 없이 전달되는 내용

상징적 상호작용론:
→ 미시적 관점: 교실 안 상호작용 분석
→ 낙인 이론: 교사의 기대·낙인 → 학생 자아실현
→ 피그말리온 효과(로젠탈): 교사의 기대가 학생 성취에 영향
```

## 교육심리 기초

```
행동주의 학습 이론:
→ 스키너: 조작적 조건화
  행동 → 강화 → 반복 증가
→ 파블로프: 고전적 조건화 (자극-반응)
→ 정적 강화(보상), 부적 강화(불쾌 제거)
→ 벌 vs 강화: 벌은 단기적, 부작용 있음

인지주의 학습 이론:
→ 피아제: 인지발달 단계 (동화·조절·평형화)
→ 오수벨 (Ausubel): 유의미 수용 학습
  선행 조직자(advance organizer) 제공
→ 가네 (Gagne): 학습 조건 이론
  학습 위계: 단순 → 복잡

인본주의 학습:
→ 매슬로우: 욕구 위계 (결핍 욕구 → 성장 욕구)
→ 자기실현 추구가 학습의 동기
→ 로저스: 학습자 중심, 촉진자로서의 교사

동기 이론:
→ 내재적 동기: 흥미, 호기심, 도전
→ 외재적 동기: 성적, 보상, 처벌
→ 귀인 이론(와이너): 성공·실패 원인 귀인
  능력, 노력, 과제 난이도, 운
```

## 교육과정 이론

```
교육과정의 유형:

공식적 교육과정:
→ 국가·학교가 의도적으로 계획한 내용
→ 한국: 국가 교육과정 (교육부 고시)

잠재적 교육과정 (Hidden Curriculum):
→ 의도하지 않았지만 실제로 배우는 것
→ 규범, 가치, 태도, 권력 관계
→ 복도에서, 쉬는 시간에 습득

영 교육과정 (Null Curriculum):
→ 학교에서 가르치지 않는 것들
→ 무엇을 배우지 않는가도 중요

교육과정 설계 모형:
→ 타일러(Tyler) 모형: 목표 → 경험 선정 → 조직 → 평가
→ 위긴스·맥타이 (백워드 설계):
  목표 설정 → 평가 계획 → 수업 계획
```

## 자주 묻는 질문

**Q. 교육학과를 졸업하면 어떤 진로가 있나요?**
A. 교원 임용시험(초·중등 교사), 교육행정직 공무원, 교육연구원, 기업 HRD(인적자원개발) 담당자, 교육 NGO, 평생교육사 등 다양합니다. 특히 교직과정 이수 또는 교원대 진학 시 교사로, 대학원 진학 시 교육 연구자나 컨설턴트로 진출할 수 있습니다.

**Q. 잠재적 교육과정은 왜 중요한가요?**
A. 학생들은 교과서 내용만 배우는 것이 아니라 학교의 규칙, 교사의 태도, 또래 관계 속에서 많은 것을 배웁니다. 예를 들어 경쟁적 환경에서 협동보다 경쟁을 배우거나, 권위적 교사 아래서 순응을 배울 수 있습니다. 좋은 학교 문화를 만드는 것이 공식 교육과정 못지않게 중요한 이유입니다.
