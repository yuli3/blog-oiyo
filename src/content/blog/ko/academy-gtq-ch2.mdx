## 포토샵은 레이어를 다루는 프로그램이다

GTQ 준비에서 가장 먼저 익혀야 할 것은 화려한 효과가 아니라 레이어 구조입니다. 이미지, 문자, 도형, 보정 요소가 각각 다른 층에 쌓인다고 생각하면 됩니다. 시험에서는 결과물만 맞으면 되는 것이 아니라, 빠르게 수정할 수 있는 상태로 작업하는 습관이 점수 안정에 도움이 됩니다.

### 기본 도구 표

| 도구 | 쓰임 |
|---|---|
| 이동 도구 | 오브젝트 위치와 정렬을 조절합니다. |
| 선택 도구 | 사각형, 원형, 자유 형태의 범위를 만듭니다. |
| 브러시 | 색을 칠하거나 마스크를 보정합니다. |
| 문자 도구 | 제목, 본문, 자간, 행간을 조절합니다. |
| 도형 도구 | 버튼, 배경, 장식 요소를 만듭니다. |

## 레이어 습관

### 이름보다 순서가 먼저

초반에는 레이어 이름을 모두 예쁘게 붙이기보다 순서를 정확히 이해하세요. 배경은 아래, 사진은 중간, 문자와 강조 도형은 위에 놓는 식입니다. 잠금, 숨김, 불투명도, 혼합 모드도 자주 쓰이므로 실습 때마다 직접 만져 보아야 합니다.

## 핵심 요약

포토샵 기본기는 도구 암기보다 레이어 구조 이해에서 시작합니다. 이동, 선택, 문자, 도형, 브러시를 빠르게 전환하고 레이어 순서를 안정적으로 관리하세요. 다음 장에서는 선택, 마스크, 합성으로 이미지를 더 정교하게 다룹니다.
