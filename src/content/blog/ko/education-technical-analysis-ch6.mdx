## 피보나치 수열과 황금비율

레오나르도 피보나치의 수열(0, 1, 1, 2, 3, 5, 8, 13, 21...)에서 인접한 수의 비율은 황금비율 1.618에 수렴합니다.

```
핵심 피보나치 비율:
0.236 (23.6%)
0.382 (38.2%)
0.500 (50.0%)  ← 수학적으로 피보나치는 아니지만 실용적 사용
0.618 (61.8%)  ← 황금비율의 역수 ★★★
0.786 (78.6%)

확장 비율:
1.272, 1.618, 2.618
```

## 피보나치 되돌림 (Retracement)

추세 진행 후 어디까지 되돌아오는지 예측:

```
상승 추세 되돌림 적용법:
1. 저점(A)과 고점(B)을 선택
2. AB 구간에 피보나치 레벨 표시
3. 38.2%, 50%, 61.8% 지점 = 지지 후보

매수 전략:
38.2% 되돌림 → 얕은 되돌림 (강한 추세)
61.8% 되돌림 → 깊은 되돌림 (약한 추세)
→ 61.8% 이탈 시 추세 전환 신호
```

## 피보나치 확장 (Extension) — 목표가 설정

```
상승 목표가 계산:
A(저점) → B(고점) → C(되돌림 저점)
목표가 = C + (A→B 이동폭 × 1.618)

예시:
A = 10,000원, B = 15,000원, C = 12,500원
AB 이동폭 = 5,000원
목표가 = 12,500 + (5,000 × 1.618) = 20,590원
```

## 엘리엇 파동 이론 (Elliott Wave Theory)

랄프 엘리엇(Ralph Elliott, 1938)이 주장한 시장 패턴:

```
기본 구조:
상승 5파 + 하락 3파 = 완전한 사이클

상승파 (충격파):
1파: 첫 번째 상승 (소수만 인식)
2파: 되돌림 (1파의 최대 100%)
3파: 가장 강하고 긴 파 ★ (2파 저점 이탈 불가)
4파: 되돌림 (1파 고점 이탈 불가)
5파: 마지막 상승 (동력 감소)

하락파 (조정파):
A파: 첫 하락
B파: 반등 (함정)
C파: 강한 하락
```

## 파동 카운팅 규칙

```
절대 위반 불가 규칙:
1. 2파는 1파의 시작점보다 낮아지면 안 됨
2. 3파는 가장 짧은 충격파가 될 수 없음
3. 4파는 1파의 고점 영역에 진입 불가

가이드라인 (권고):
- 3파가 보통 가장 길고 강함
- 파동의 교대 원칙: 2파와 4파는 서로 다른 형태
```

## 피보나치 + 파동 이론 실전 결합

```
3파 타겟 예측:
→ 1파 저점 + (1파 이동폭 × 1.618)
→ 3파는 1파의 161.8% 확장이 일반적

매수 진입 전략:
→ 5파 완성 후 A·B·C 조정 진행
→ C파 종료 후 매수 (다음 상승 사이클 착수)
→ 피보나치 61.8% 지지 구간과 일치하면 강한 진입점
```

## 핵심 암기 포인트

*피보나치 핵심 레벨: 38.2% · 50% · 61.8% (되돌림 지지/저항)*
*61.8% 이탈 = 추세 전환 경고 신호*
*엘리엇 5파 규칙: 2파 &lt; 1파 시작, 3파 최단 불가, 4파와 1파 겹침 불가*
*3파 타겟 = 1파 저점 + (1파 폭 × 1.618)*
