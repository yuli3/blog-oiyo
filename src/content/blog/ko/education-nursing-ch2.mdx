# 제2장: 간호 과정 — ADPIE 프레임워크

간호 과정은 간호사가 개별화된 환자 중심 돌봄을 제공하기 위해 사용하는 체계적이고 근거 기반의 프레임워크입니다. 다섯 단계인 **사정(Assessment), 진단(Diagnosis), 계획(Planning), 수행(Implementation), 평가(Evaluation) — ADPIE**는 임상 의사결정을 이끄는 연속적인 순환 과정을 형성합니다.

## ADPIE의 다섯 단계

**사정(Assessment)**은 기초가 됩니다. 간호사는 주관적 자료(환자가 보고하는 것 — 증상, 통증, 병력)와 객관적 자료(측정 가능한 소견 — 활력 징후, 검사 수치, 신체 검진)를 수집합니다. 도구로는 두부에서 발끝까지의 사정, 기능 사정, 그리고 표준화된 선별 도구가 활용됩니다.

**진단(Diagnosis)**은 사정 자료를 분석하여 실제적 또는 잠재적 건강 문제를 확인하는 과정입니다. 간호 진단은 의학적 진단과 다릅니다. 간호 진단은 질병 자체가 아닌 질병에 대한 *인간 반응*에 초점을 맞춥니다. NANDA 인터내셔널(NANDA International)은 표준화된 간호 진단 분류 체계를 관리합니다.

**계획(Planning)**은 측정 가능한 환자 중심 목표를 설정하고 간호 중재를 선택하는 단계입니다. 목표는 SMART 원칙, 즉 구체적(Specific), 측정 가능(Measurable), 달성 가능(Achievable), 현실적(Realistic), 시간 제한적(Time-bound)이어야 합니다.

**수행(Implementation)**은 돌봄 계획의 실행 단계입니다. 약물 투여, 처치 수행, 환자 교육, 돌봄 조정이 이에 해당합니다.

**평가(Evaluation)**는 목표가 달성되었는지 측정합니다. 결과가 달성되지 않았다면 간호사는 재사정하고 계획을 수정합니다.

## NANDA 간호 진단

NANDA 진단은 세 부분으로 구성된 PES 형식을 따릅니다:
- **P**roblem(문제): 간호 진단 명칭
- **E**tiology(병인): 관련 요인 / 기여 요인
- **S**igns and Symptoms(징후와 증상): 정의적 특성 / 근거

| 유형 | 예시 |
|------|------|
| 실제적 진단 (Actual) | 폐포-모세혈관막 변화와 관련된 가스 교환 장애 — SpO₂ 89%로 입증 |
| 위험 진단 (Risk) | 보행 변화 및 기립성 저혈압과 관련된 낙상 위험 |
| 건강 증진 진단 (Health Promotion) | 영양 향상 준비도 (Readiness for Enhanced Nutrition) |
| 증후군 진단 (Syndrome) | 허약 노인 증후군 (Frail Elderly Syndrome) |

## 우선순위 설정

간호사는 **매슬로의 욕구 위계(Maslow's Hierarchy of Needs)**와 **ABC 프레임워크** (기도(Airway), 호흡(Breathing), 순환(Circulation))를 사용하여 진단의 우선순위를 정합니다. 생명을 위협하는 문제는 항상 심리사회적 요구보다 우선합니다.

| 우선순위 | 프레임워크 | 예시 |
|----------|-----------|------|
| 1순위 | 생리적 요구 (ABC) | 기도 폐쇄, 출혈 |
| 2순위 | 안전/보안 | 낙상 위험, 감염 위험 |
| 3순위 | 사랑/소속감 | 고립, 비탄 |
| 4순위 | 자기존중 | 신체상 장애 |
| 5순위 | 자아실현 | 영적 고통 |

## 핵심 체크리스트

- [ ] 폐렴 환자에서 SpO₂가 88%일 때 세 부분으로 구성된 NANDA 간호 진단을 올바른 형식으로 작성하세요
- [ ] 실제적 진단, 위험 진단, 건강 증진 진단을 각각 한 가지 예시를 들어 구별하세요
- [ ] ABC 우선순위 프레임워크를 적용하여 네 가지 간호 문제를 긴급도 순으로 정렬하세요
