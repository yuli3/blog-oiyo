## 세금을 제때 내지 못했다면

```
체납 발생 후 주요 진행:
→ 납부 기한 + 3개월: 가산세 누적
→ 압류 예고 통지
→ 압류 집행 (부동산, 예금, 급여 등)
→ 공매 처분 (압류 재산 매각)
→ 체납자 명단 공개 (2,000만원 이상)

→ 방치할수록 불이익 커짐
→ 즉시 대처가 핵심
```

---

## 체납 시 가산세

```
납부 기한 경과 후:
- 납부 지연 가산세: 미납 세액 × 0.022% × 경과 일수
- 연 약 8% 수준 누적
- 국세 최대 가산세: 75%

→ 빨리 해결할수록 가산세 누적 최소화
```

---

## 분납 신청

```
납부 능력이 부족할 때:
→ 세금을 여러 회에 나눠 납부하는 것

신청 방법:
- 국세: 홈택스(hometax.go.kr) → 신고/납부 → 분납 신청
       또는 세무서 방문
- 지방세: 위택스(wetax.go.kr) or 시군구청 방문

분납 기간: 최대 12~24개월 (세목별 상이)

주의:
→ 분납 중에도 가산세 일부 발생
→ 분납 약정 불이행 시 즉시 전액 납부 + 체납 처분
```

---

## 납부 유예 신청

```
일시적 자금 부족 or 재해 발생 시:

국세 납부 유예:
- 최대 9개월 유예 (1회 연장 가능)
- 신청: 세무서 방문 or 홈택스

지방세 납부 유예:
- 재해, 사업 부진, 심각한 손실 인정 시
- 최대 1년 유예

조건:
- 납세 담보 제공 필요 (부동산 등기 or 보증보험)
- 재정 어려움 입증 서류 제출
```

## 압류 순서와 절차

```
세금 체납 후 압류 진행 순서:

1. 납부 독촉 (안내문 발송)
2. 압류 예고 통지 (30~60일 전)
3. 압류 집행:
   - 예금 압류 (가장 먼저)
   - 급여 압류 (월급의 1/2까지)
   - 부동산 압류
   - 자동차 압류
4. 압류 재산 매각(공매)

→ 압류 예고 단계에서 반드시 대응해야 함
```

---

## 압류 방어 방법

### 압류 예고 수령 후

```
즉시:
1. 세무서·시군구 세금 담당 부서에 연락
2. 분납 or 유예 협의 신청
3. 분납 계획서 제출

→ 납부 의지를 보이면 압류 집행 보류 가능
```

### 생계형 체납자 특례

```
최저 생계 유지에 필요한 재산은 압류 면제:
- 생계형 차량 (생계 수단 입증 시)
- 체납 처분 유예 조건부 신청 가능

신청:
→ 세무서에 생계형 체납자 유예 신청서 제출
→ 재산 상황·수입 증빙 자료 제출
```

## 불복 청구 (세금이 잘못 부과된 경우)

```
절차:
1. 이의 신청: 처분을 한 세무서에 90일 이내 신청
2. 심사 청구: 국세청에 90일 이내
3. 심판 청구: 조세심판원에 90일 이내
4. 행정 소송: 법원

→ 체납세와 이의 신청을 동시에 진행 가능
→ 체납 상태에서도 불복 청구 권리 있음
```

## 지방세 체납 특이사항

```
지방세 체납:
- 자동차세 체납 → 번호판 영치 가능
- 재산세 체납 → 부동산 압류
- 주민세 체납 → 급여 압류

번호판 영치 시:
→ 지방세 전액 납부 후 즉시 영치 해제 신청 가능
→ 지방세 납부 후 구청 방문 or 전화로 해제 요청
```

---

## 체납 세금 소멸시효

```
국세 소멸시효: 5년 (5억 이상은 10년)
지방세 소멸시효: 5년

→ 소멸시효 기산일: 세금 납부 기한 다음 날
→ 압류 등 체납 처분으로 시효 중단
→ 소멸시효 완성 시 납부 의무 소멸 (단, 압류 없는 경우)
```

## 자주 묻는 질문

**Q. 세금이 너무 많아서 도저히 낼 수 없는데 어떻게 하나요?**
A. 분납·유예도 안 되는 경우 '체납 처분 유예'나 생계형 특례 신청을 검토하세요. 국세청 납세자 보호 담당관(126)에 상담을 요청하세요.

**Q. 세금 체납이 신용점수에 영향을 주나요?**
A. 일정 금액 이상 장기 체납은 신용정보에 등록될 수 있습니다. 또한 금융 기관 대출 심사에서 세금 체납 사실이 조회됩니다.

**Q. 이미 압류된 통장은 해제할 수 없나요?**
A. 세금 전액을 납부하거나 분납 계획이 승인되면 압류 해제 신청이 가능합니다. 세무서에 즉시 연락하세요.

**Q. 체납자 명단은 어디에 공개되나요?**
A. 2,000만원 이상 고액 체납자는 국세청 홈페이지에 공개됩니다. 명단 공개 전 6개월의 소명 기간이 주어집니다.
