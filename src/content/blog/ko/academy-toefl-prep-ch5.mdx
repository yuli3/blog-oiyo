## TOEFL 핵심 공식과 전략 최종 정리

### 섹션별 고득점 핵심

| 섹션 | 핵심 전략 | 흔한 실수 |
|------|---------|---------|
| Reading | 지문 구조 파악 후 질문 탐색 | 처음부터 끝까지 정독 |
| Listening | 노트테이킹, 첫 30초 주제 포착 | 세부사항만 집중 |
| Speaking | 템플릿+자연스러운 발화 | 암기한 답변처럼 들림 |
| Writing | 강의 중심 요약, 본인 의견 배제 (Task 1) | 지문 문장 그대로 복사 |

---

## 점수 향상 로드맵

### 70점대 → 80점대
- Reading: Inference 문제 유형 집중 연습
- Listening: 강의 첫 30초 주제 파악 훈련
- Speaking: 연결어 자동화
- Writing: Integrated Task 템플릿 숙달

### 80점대 → 90점대
- Reading: Summary 문제 (3점 문제) 완성도 높이기
- Listening: Function/Attitude 문제 정확도 향상
- Speaking: 발화 속도 조절 + 적절한 쉼표 활용
- Writing: Academic Discussion 200자 목표

### 90점대 → 100+
- 모든 섹션 균형 잡기
- 실전 모의시험 × 5회 이상
- 약점 섹션 집중 투자

## 시험 당일 완전 가이드

### 시험 전날
- 충분한 수면 (7~8시간)
- 신분증(여권), 등록 확인 메일 재확인
- 시험 센터 위치, 주차/교통 확인
- 새로운 연습 금지 — 마음 편히 쉬기

### 시험 당일 아침
- 시험 시작 30분 전 도착
- 가벼운 식사 (배고픔/졸음 방지)
- 귀마개 지참 가능 여부 확인

### 시험 중 섹션별 전략

**Reading**:
- 먼저 첫 문단 정독으로 주제 파악
- Vocabulary 모르면 문맥으로 추론
- Summary 문제는 가장 마지막에 (전체 이해 필요)

**Listening**:
- 강의 시작 직후 주제 반드시 노트
- 헷갈리면 이전 답변으로 돌아가지 말고 진행
- 오디오는 한 번만 재생됨

**Speaking**:
- Task 1: 직접적인 의견 먼저 제시, 이유 2개
- 마이크에 일정 거리 유지
- 시간이 남으면 추가 예시 제공

**Writing**:
- Task 1: 20분 내 3~4 단락 완성 목표
- Task 2: 150자 이상 목표, 자신의 독창적 관점 필수

## TOEFL 공식 모의시험 활용법

**ETS가 제공하는 공식 연습 도구**:
1. **TOEFL Practice Online (TPO)**: 실제 시험과 동일한 환경, 가장 정확한 점수 예측
2. **Free Practice Test**: ETS 사이트에서 무료 제공 (1회)
3. **Official TOEFL iBT Tests vol. 1, 2**: 실제 시험 문제 포함 유료 자료

**모의시험 활용 전략**:
- 최소 4~6주 전부터 시작
- 실제 시험과 동일한 환경에서 응시 (조용한 공간, 타이머 설정)
- 오답 분석에 응시 시간의 2배 투자

## 최종 체크리스트

**Reading**:
- [ ] Factual/Negative Factual 문제 정답률 85%+
- [ ] Vocabulary 문맥 추론 가능
- [ ] Summary 문제 주요 아이디어 선별 가능

**Listening**:
- [ ] 강의 노트테이킹 시스템 완성
- [ ] Function/Purpose 문제 전략 이해
- [ ] 대화에서 학생의 태도/문제 파악 가능

**Speaking**:
- [ ] 4과제 템플릿 자연스럽게 활용
- [ ] 분당 125~150단어 속도로 발화 가능
- [ ] 응답 녹음 후 자체 평가 완료

**Writing**:
- [ ] Integrated Task 200단어 내외 완성 능력
- [ ] Academic Discussion 150단어 이상 완성 능력
- [ ] 문법 오류 최소화
