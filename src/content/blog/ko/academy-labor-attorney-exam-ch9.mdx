## 근로기준법 오답 포인트

```
① 해고 예고 = 30일 전 (또는 30일분 임금)
   → 5인 미만 사업장은 해고예고 적용 안됨

② 부당해고 구제 신청 = 3개월 이내
   → 법원 소송 = 2년 (별도)

③ 연장근로 한도 = 주 12시간
   → 합의해도 초과 불가 (강행법규)

④ 통상임금 ≠ 평균임금
   → 통상=정기·일률·고정
   → 평균=직전 3개월 실제 지급 임금

⑤ 해고 서면 통지 = 사유+날짜 필수
   → 구두 해고 통지는 무효
```

## 노동조합법 오답 포인트

```
⑥ 단체협약 유효기간 = 2년
   → 2년 이상 약정 = 2년으로 단축

⑦ 파업 사전신고 = 10일 전
   → 공익사업 = 15일 전

⑧ 부당노동행위 = 3개월 이내 신청
   → 부당해고도 3개월 (기간 같음)

⑨ 직장폐쇄 = 파업 개시 후에만 가능
   → 선제적 직장폐쇄 = 불법

⑩ 단체교섭 거부 = 부당노동행위
    → 경영권 사항은 거부 정당
```

## 사회보험 오답 포인트

```
⑪ 산재보험 = 사용자 전액 (근로자 부담 없음)
⑫ 고용보험 실업급여 = 근로자+사용자 반반
⑬ 실업급여 = 18개월 내 180일 + 비자발 이직
⑭ 출퇴근 재해 = 2018년부터 산재 인정
⑮ 휴업급여 = 평균임금의 70% (100% 아님)
```

## 혼동 포인트 비교

```
부당해고 vs 부당노동행위:
둘 다 3개월 이내 노동위원회 신청
부당해고: 정당한 이유 없는 해고
부당노동행위: 노조 활동 방해·불이익

통상임금 vs 평균임금:
통상=고정·정기·일률 (연장 기준)
평균=3개월 실지급 (퇴직금 기준)

파업 vs 직장폐쇄:
파업=근로자 쟁의, 선제 가능
직장폐쇄=사용자, 파업 후에만 가능
```

## 핵심 개념 카드

**5인미만=해고예고 적용제외** ★★★★★
: 4인 이하는 해고 예고 의무 없음.
*암기 포인트: 5인미만=해고예고X*

**산재보험=사용자전액** ★★★★★
: 4대 보험 중 산재만 사용자 100% 부담.
*암기 포인트: 산재=사용자100%*

**구두해고=무효** ★★★★☆
: 해고는 서면 통지 필수, 미이행 시 무효.
*암기 포인트: 해고=서면*

## 실전 퀴즈

**Q. 5인 미만 사업장 근로자의 권리 차이는?**
> 적용 안됨: 해고예고·해고제한·부당해고 구제·연차유급휴가 일부. 적용됨: 최저임금·퇴직급여(1년 이상)·4대보험·주휴수당. 근로기준법은 5인 이상이 full 적용. 5인 미만은 부분 적용. 공인노무사 시험에서 자주 출제.

**Q. 노무사와 변호사가 노동 사건에서 경쟁하는 이유는?**
> 노동 사건: 부당해고·임금 체불·산재 등. 노무사=노동위원회 대리 강점, 행정 사건 특화. 변호사=법원 소송 독점. 노동위원회 → 법원 상소 경로에서 연계. 실무: 1심(노동위)=노무사, 2심(법원)=변호사 협업 많음.
