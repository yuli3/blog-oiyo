## 핵심 수치 총정리

```
근로시간:
법정 근로: 1일 8시간, 1주 40시간
연장 한도: 1주 12시간 → 합계 52시간
휴게: 4시간마다 30분, 8시간마다 1시간

가산수당:
연장·야간·휴일: 각 50% 가산

휴가:
주휴일: 주 1회 유급
연차: 1년 80% 출근=15일, 최대 25일
1년 미만: 월 1일 (최대 11일)

퇴직금:
1년 이상 + 주 15시간 이상
= 30일분 평균임금 × 근속 연수

해고 예고: 30일 전 또는 30일분 통상임금
부당해고 구제 신청: 3개월 이내
```

## 기간 및 기한 총정리

```
근로계약·임금:
임금 지급: 매월 1회 이상 정기일
퇴직금 지급: 퇴직 후 14일 이내
임금 채권 소멸시효: 3년

해고·불복:
부당해고 구제 신청: 3개월 이내
부당노동행위 구제: 3개월 이내
노동쟁의 조정 기간: 일반 10일, 공익 15일

휴가·휴직:
산전후 휴가: 90일 (다태아 120일)
육아휴직: 1년
배우자 출산휴가: 10일

보험:
실업급여 피보험 기간: 18개월 중 180일
실업급여 지급 기간: 120~270일
산재 요양급여: 치료 종료까지

기타:
단체협약 유효기간: 최대 2년
기간제 사용 한도: 2년
파견 기간 한도: 2년
```

## 비교표: 해고 vs 사직 vs 계약 만료

```
┌──────────────┬────────────┬────────────┬────────────┐
│ 구분         │ 해고       │ 사직       │ 계약 만료  │
├──────────────┼────────────┼────────────┼────────────┤
│ 의사         │ 사용자     │ 근로자     │ 쌍방       │
│ 퇴직금       │ 있음(1년+) │ 있음(1년+) │ 있음(1년+) │
│ 실업급여     │ 가능       │ 원칙불가   │ 가능       │
│ 해고예고     │ 필요       │ 불필요     │ 불필요     │
│ 정당 이유    │ 필요       │ 불필요     │ 불필요     │
└──────────────┴────────────┴────────────┴────────────┘
```

## 자주 틀리는 오답 포인트

```
① 근기법 5인 기준
   → 5인 이상=전면 적용, 5인 미만=해고예고+임금원칙만
   → 연장수당은 5인 미만 없음

② 해고 예고 불이행 효과
   → 해고 자체 무효 아님 → 수당 지급 의무만 발생

③ 통상임금 vs 평균임금
   → 통상임금=가산수당 기준 (고정·정기·일률)
   → 평균임금=퇴직금 기준 (3개월 임금 총액 평균)

④ 정리해고 4요건 모두 필수
   → 긴박한 필요+회피 노력+합리적 기준+사전 협의
   → 하나라도 빠지면 부당해고

⑤ 산재보험 = 사용자 전부담
   → 근로자 기여금 없음 (국민연금·건강·고용=근로자도 부담)

⑥ 기간제 2년 = 무기계약 간주
   → "2년 이상 사용 금지"가 아니라 "2년 초과 시 무기계약 간주"

⑦ 파견 = 허용 업무만
   → 포지티브 리스트 방식
   → 불법 파견 2년 초과=직접 고용 의무

⑧ 연차 발생 기준
   → 1년 80% 출근=15일 (입사 1년 후)
   → 1년 미만=월 1일 (입사 첫 해)

⑨ 부당노동행위 납세 의무자
   → 사용자만 부당노동행위 주체 (근로자 행위는 해당 없음)

⑩ 단체협약과 근로계약 관계
   → 유리 원칙: 근로계약이 더 유리하면 근로계약 적용
```

## 핵심 개념 카드

**노동법 핵심 3단어** ★★★★★
: 최저기준(근기법)·자주단결(노조법)·사회안전망(사회보험). 노동법 3대 축.
*암기 포인트: 최저기준+단결권+사회보험*

**퇴직금 14일·부당해고 3개월** ★★★★★
: 퇴직금 지급=14일. 부당해고 구제 신청=3개월 이내.
*암기 포인트: 퇴직금14일, 부당해고3개월*

**연차 최대 25일** ★★★★★
: 15일 기준, 3년 이상 2년마다 1일 가산, 최대 25일.
*암기 포인트: 연차=15일→최대25일*

## 실전 퀴즈 (종합)

**Q. 5인 이상 사업장에서 근무 3년 차 근로자의 법정 연차는 며칠인가?**
> 3년 차 = 2년 근속 후 가산 1일 적용. 15일 + 1일 = 16일. (3년 이상이 되는 시점에 2년마다 1일 가산)

**Q. 평균임금 일급 12만 원, 5년 근무 후 퇴직 시 퇴직금은?**
> 퇴직금 = 12만 × 30 × 5 = 1,800만 원.

**Q. 사용자가 근로자를 해고하려 할 때 서면 통보 의무와 예고 의무를 각각 설명하시오.**
> 서면 통보: 해고 사유와 시기를 서면으로 통지 의무. 구두 해고 무효(2007년 이후). 예고 의무: 해고 30일 전 예고 또는 30일분 통상임금 지급. 예고 없이 해고해도 해고 자체는 무효 아님 — 수당만 지급.
