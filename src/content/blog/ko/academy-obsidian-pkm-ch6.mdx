## 플러그인은 강력하지만 적게 시작해야 한다

Obsidian의 큰 장점은 플러그인 생태계입니다. 코어 플러그인과 커뮤니티 플러그인으로 일정, 템플릿, 데이터 쿼리, 캔버스, 동기화 보조 등 다양한 기능을 추가할 수 있습니다.

하지만 처음부터 플러그인을 많이 설치하면 노트 습관보다 설정 관리가 더 커집니다. 초보자는 기본 기능으로 기록 흐름을 만든 뒤 필요한 기능만 추가하는 편이 좋습니다.

## 먼저 익힐 기본 기능

| 기능 | 용도 |
|------|------|
| Daily Notes | 하루 단위 기록 |
| Templates | 반복 노트 양식 |
| Backlinks | 연결 확인 |
| Graph View | 전체 구조 확인 |
| Canvas | 아이디어 배치와 관계 정리 |

이 기능만으로도 개인 지식관리의 기본 흐름은 충분히 만들 수 있습니다.

## 커뮤니티 플러그인 접근법

커뮤니티 플러그인은 유용하지만 외부 코드입니다. 설치 전에는 업데이트 상태, 사용자 수, 권한, 문서, 백업 여부를 확인해야 합니다.

대표적으로 많이 언급되는 유형은 다음과 같습니다.

1. 일정과 태스크 관리 플러그인
2. 표와 데이터 질의 보조 플러그인
3. 독서·하이라이트 가져오기 플러그인
4. Git 백업 플러그인
5. 글쓰기와 발행 보조 플러그인

플러그인 이름보다 중요한 것은 내 워크플로에 필요한지입니다.

## 추천 워크플로 예시

```text
Daily Note에 빠르게 기록
-> Inbox 노트로 모음
-> 주 1회 정리
-> 영구 노트로 분리
-> MOC와 프로젝트에 연결
-> 필요하면 글이나 업무 산출물로 변환
```

이 흐름에서는 Daily Notes, Templates, Backlinks만 있어도 충분합니다. 이후 반복 작업이 생길 때 플러그인을 추가합니다.

## 핵심 요약

- Obsidian 플러그인은 강력하지만 초보자는 적게 시작해야 합니다.
- Daily Notes, Templates, Backlinks, Graph View, Canvas만으로도 기본 워크플로를 만들 수 있습니다.
- 커뮤니티 플러그인은 외부 코드이므로 업데이트 상태와 백업을 확인해야 합니다.
- 플러그인은 기능 수집이 아니라 반복 작업을 줄이기 위해 추가해야 합니다.
