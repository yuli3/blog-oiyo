## 왜 출력 형식이 중요한가

AI 답변은 사람이 읽는 문장으로만 받을 필요가 없습니다. 표, 목록, JSON, 체크리스트처럼 구조화하면 비교, 복사, 검토, 자동화가 쉬워집니다. 특히 업무에서는 멋진 문장보다 바로 옮겨 쓸 수 있는 형식이 더 중요할 때가 많습니다.

모델과 기능은 변할 수 있고, 어떤 도구는 구조화 출력 기능을 별도로 제공하기도 합니다. 그래도 “필드명과 형식을 명확히 지정한다”는 원리는 계속 사용할 수 있습니다.

## 표로 받기

표는 비교와 분류에 적합합니다. 기준이 여러 개일 때는 먼저 열 이름을 정하고, 각 열에 어떤 내용이 들어갈지 알려 줍니다.

```text
아래 아이디어 5개를 표로 정리해 줘.

열:
- 아이디어
- 대상 독자
- 기대 효과
- 실행 난이도(상/중/하)
- 주의할 점
```

| 형식 | 적합한 작업 |
|---|---|
| 표 | 비교, 분류, 우선순위 검토 |
| 번호 목록 | 절차, 순서, 학습 계획 |
| 체크리스트 | 검토, 준비물, 리스크 점검 |
| JSON | 시스템 연동, 자동화, 데이터 추출 |

## JSON으로 받기

JSON은 프로그램이나 자동화 도구가 읽기 쉬운 구조입니다. 다만 모델이 항상 완벽한 JSON을 출력한다고 단정하면 안 됩니다. 실제 시스템에 넣기 전에는 파싱 검증과 예외 처리가 필요합니다.

```text
아래 문장에서 할 일 정보를 추출해 JSON으로 출력해 줘.

문장: 다음 주 화요일까지 견적서 초안을 만들고 민수에게 검토 요청하기

형식:
{
  "task": "",
  "deadline": "",
  "owner": "",
  "next_action": ""
}

JSON 외의 설명은 쓰지 마.
```

## 구조화 출력의 흔한 문제

출력 형식을 지정해도 결과가 흔들릴 수 있습니다. 필드가 빠지거나 설명 문장이 섞이거나 값의 타입이 일관되지 않을 수 있습니다. 중요한 자동화에서는 모델 출력만 믿지 말고 후처리 검증을 붙여야 합니다.

| 문제 | 예방 방법 |
|---|---|
| 필드 누락 | 필수 필드 목록과 빈 값 처리 규칙을 명시 |
| 설명 섞임 | “지정한 형식 외 문장 금지”라고 지시 |
| 값 불일치 | 가능한 값 목록을 제한 |
| 긴 문장 | 글자 수 또는 문장 수 제한 |

## 핵심 요약

- 출력 형식을 정하면 AI 결과를 검토하고 재사용하기 쉬워진다.
- 표는 비교와 분류, JSON은 자동화와 데이터 추출에 적합하다.
- 필드명, 가능한 값, 금지할 출력까지 함께 지정하면 안정성이 높아진다.
- 구조화 출력도 검증이 필요하며 시스템 입력 전에는 예외 처리를 해야 한다.
