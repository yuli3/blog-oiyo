## 특허 명세서 구성

```
명세서 필수 기재:
발명의 명칭
기술분야·배경기술
발명의 내용 (해결과제·수단·효과)
도면의 간단한 설명
발명을 실시하기 위한 구체적 내용
청구범위

청구범위 (Claims):
특허권의 범위를 결정
독립청구항·종속청구항

독립청구항:
가장 넓은 권리 범위
핵심 구성요소만

종속청구항:
독립항에 추가 한정
더 좁은 권리, 보완적 보호
```

---

## 출원 절차

```
출원 서류:
명세서·청구범위·도면·요약서
대리인(변리사) 위임장

출원일:
서류 도달일 = 출원일
우선일 기산점

출원 공개:
출원일로부터 1년 6개월 후 자동 공개
조기 공개 신청 가능 (전략적)

심사청구:
출원 후 3년 이내 심사 청구 필수
미청구 시 취하 간주
출원과 별도 수수료
```

---

## 심사 과정

```
방식 심사:
출원 서류 형식 확인
결함 시 보정 명령

실체 심사:
신규성·진보성·명세서 기재 확인
선행기술 조사

거절이유 통지:
심사관이 거절 사유 통지
의견서 제출 기간: 2개월

의견서·보정서:
의견서: 심사관 논리에 반박
보정서: 청구범위·명세서 수정

등록 결정:
거절 없으면 등록결정 통지
등록료 납부 → 특허권 발생
```

## 보정 제한

```
보정 허용 범위:
최초 명세서·도면의 요지를 변경하지 않는 범위
신규 사항 추가 불가

보정 시기:
거절이유 통지 후: 보정 가능
특허 결정 후: 원칙 불가

분할 출원:
원출원 일부를 분리해 새로운 출원
청구범위 확장 방법
```

## 핵심 개념 카드

**청구범위=특허권범위결정** ★★★★★
: 독립청구항이 가장 넓은 권리.
*암기 포인트: 청구범위=권리범위*

**심사청구=3년이내** ★★★★★
: 출원 후 3년 이내 청구 안 하면 취하.
*암기 포인트: 심사청구=3년*

**공개=1년6개월** ★★★★☆
: 출원일로부터 1년 6개월 후 자동 공개.
*암기 포인트: 공개=1년6개월*

## 실전 퀴즈

**Q. 독립청구항을 넓게 쓰는 것이 왜 중요한가?**
> 특허권 범위 = 청구범위 기준. 넓은 독립항 = 넓은 독점권. 경쟁사가 청구항 범위 밖으로 설계 변경하면 침해 아님. 단, 너무 넓으면 선행기술 저촉 → 거절. 최적: 선행기술보다 넓지만 저촉 안 되는 범위. 변리사 명세서 작성 스킬의 핵심.

**Q. 출원 공개 전 경쟁사가 동일 기술을 사용하면?**
> 공개 전: 특허권 없음 (등록 전). 보상청구권: 출원 사실 알린 후 공개 후 경고→등록 후 소급 청구 가능. 출원 후 1년6개월 전 조기 공개 → 경쟁사 경고 효과. 출원 공개 = 선행기술로서 타인 출원 방지 효과.
