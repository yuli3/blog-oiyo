## FRM 전 범위 핵심 공식 최종 정리

### 시장위험
| 공식 | 의미 |
|------|------|
| VaR_n = VaR_1 × √n | n일 VaR 스케일링 |
| ES = μ − σ·φ(z)/(1−c) | 기대 부족분(정규분포) |
| GARCH(1,1): σ²ₜ = ω + αε²ₜ₋₁ + βσ²ₜ₋₁ | 조건부 분산 |
| EWMA: λ ≈ 0.94 | 일별 변동성, 리스크메트릭스 |

### 신용위험
| 공식 | 의미 |
|------|------|
| EL = PD × LGD × EAD | 기대손실 |
| LGD = 1 − Recovery Rate | 부도 시 손실률 |
| CDS 스프레드 ≈ PD × LGD | 신용디폴트스왑 가격 근사 |

### 유동성 & 규제
| 지표 | 공식 | 기준 |
|------|------|------|
| LCR | HQLA / 30일 순유출 | ≥ 100% |
| NSFR | ASF / RSF | ≥ 100% |
| CET1 비율 | CET1 / RWA | ≥ 4.5% (+ 2.5% 완충) |
| 레버리지 비율 | Tier 1 / 총익스포저 | ≥ 3% |

### 투자관리
| 지표 | 공식 |
|------|------|
| RAROC | (수익 − 비용 − EL) / 경제적 자본 |
| Duration Gap | D_A − (L/A) × D_L |
| 샤프비율 | (R_p − R_f) / σ_p |
| 정보비율 | α / 추적오차(TE) |

### 시장위험 (Q1–8)

**Q1.** 포트폴리오 1일 VaR(99%)가 \$50만이다. 10일 VaR는?

A) \$50만  B) \$158만  C) \$500만  D) \$1,000만

**Q2.** GARCH(1,1)의 α + β < 1이 의미하는 것은?

A) 변동성이 항상 증가한다  
B) 변동성이 장기 평균으로 평균회귀한다  
C) 변동성이 임의보행을 따른다  
D) 변동성이 감소하여 0에 수렴한다

**Q3.** FRTB에서 Expected Shortfall의 신뢰수준은?

A) 95%  B) 97.5%  C) 99%  D) 99.9%

**Q4.** 백테스팅에서 250일 동안 예외가 12개 발생했다. 바젤 신호등 판정은?

A) 녹색  B) 황색  C) 적색  D) 주황

**Q5.** 채권 수정듀레이션 8, 볼록성 100. 금리가 100bps 상승 시 가격 변화율은?

A) −7.5%  B) −8.0%  C) −8.5%  D) +7.5%

**Q6.** VaR 방법 중 정규분포 가정을 사용하지 않는 것은?

A) 분산-공분산법  B) GARCH 모형  C) 역사적 시뮬레이션  D) EWMA

**Q7.** EWMA에서 λ가 0.94에서 0.90으로 감소하면?

A) 최근 관측치에 더 낮은 가중치를 부여

D) 변동성 추정 반응 속도가 느려짐

**Q8.** 극단값 이론(EVT)에서 POT(임계초과) 방법에 사용하는 분포는?

A) 정규분포  B) 학생 t-분포  C) 일반화 파레토 분포(GPD)  D) 로그정규분포

## 정답 및 해설

| Q | 정답 | 해설 |
|---|------|------|
| 1 | B | \$50만 × √10 = \$50만 × 3.162 = **\$158만** |
| 2 | B | α + β < 1 → 분산이 장기 무조건 분산(ω/(1−α−β))으로 평균회귀 |
| 3 | B | FRTB ES는 97.5% 신뢰수준 (99% VaR와 동등한 수준의 자본) |
| 4 | C | 250일 중 12개 예외: 바젤 적색 구간(>10개 예외) |
| 5 | A | ΔP/P = −8×0.01 + ½×100×(0.01)² = −0.08 + 0.005 = **−7.5%** |
| 6 | C | 역사적 시뮬레이션: 실제 과거 데이터 사용, 분포 가정 없음 |
| 7 | B | λ 감소 → (1−λ) 증가 → 최근 관측치에 더 높은 가중치 |
| 8 | C | POT 방법: 임계 초과 손실에 GPD(일반화 파레토 분포) 적용 |
| 9 | B | EL = 0.03 × 0.40 × \$5,000만 = **\$60만** |
| 10 | C | 바젤 III IRB: 자본은 99.9% 신뢰수준의 UL을 커버 |
| 11 | B | CDS 보장매수자: 프리미엄 지급 → 신용이벤트 시 원금 수취 |
| 12 | A | CVA = 거래상대방 부도 위험으로 인한 공정가치 하향 조정 |
| 13 | C | 위험 조정 할인: P = 100 × e^(−(0.04+0.02)×1) = 100 × e^(−0.06) = **\$94.18** → A |
| 14 | B | 워터폴 구조: 에쿼티 → 메자닌 전부 소진 후 시니어 손실 시작 |
| 15 | D | A-IRB: PD/LGD/EAD 자체 추정; 자산상관계수(ρ)는 바젤 규정값 |
| 16 | B | ILM = (BIC/ILDC)^0.8; 내부 손실(ILDC)이 BIC보다 크면 ILM > 1 |
| 17 | B | 가우시안 코풀라: 꼬리 의존성 = 0 → 위기 동조화 과소평가 (2008년 CDO 실패 원인) |
| 18 | D | 장기 분산 = ω/(1−α−β) = 0.000002/(1−0.06−0.92) = 0.000002/0.02 = **0.0001** → A |
| 19 | B | 과잉첨도 < 0: 정규분포보다 얇은 꼬리 (드문 경우) |
| 20 | B | ARCH 효과: 변동성이 뭉치는 현상(클러스터링) 포착 |
| 21 | C | 직원 차별 소송 → "고용 관행 및 직장 안전" 범주 |
| 22 | C | 정규분포에서도 ES > VaR: ES는 꼬리 평균 손실 |
| 23 | B | Level 2A HQLA 헤어컷: **15%** |
| 24 | B | 만기 1년 이상 장기부채 → ASF **100%** |
| 25 | B | ΔE = −3 × \$2B × 0.005 = **−\$30M** |
| 26 | B | RAROC > WACC: 위험 조정 기준으로 주주 가치 창출 중 |
| 27 | A | IR = α/TE = 2%/8% = **0.25** |
| 28 | B | 생존편향 교정: 폐업 펀드(저성과) 포함 → 평균 수익률 **감소** |
| 29 | B | C_A > C_L: 볼록성 조건이 있으면 금리 변동 후 자산 > 부채 유지 |
| 30 | C | G-SIBs: 레버리지 비율 3% + 추가 완충(G-SIB 서차지) → **높다** |

## FRM 시험 당일 전략

### 시험 전날
- 공식 노트 통독 (새 내용 금지)
- HP 12C / BAII Plus 계산기 건전지 교체
- 신분증·수험표 확인

### 시험 당일 (Part I / Part II 각 4시간)
- 80문항 × 3분 = 240분 (여유 40분)
- 계산 문제: 공식 먼저 정리 후 대입
- 어려운 문제: 표시하고 넘긴 후 재도전

### 합격 후 자격 취득
1. Part I + Part II 합격
2. GARP 회원 유지
3. 금융위험 관련 업무 경력 **2년 이상** 인정
4. GARP 제출 → FRM Certification 수여
