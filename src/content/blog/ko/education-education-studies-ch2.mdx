## 교육과정의 개념과 유형

```
교육과정 (Curriculum)의 정의:
→ 학교 교육에서 학생들이 배워야 할 내용·경험의 계획
→ 어원: 라틴어 currere (달리는 코스·경주로)
→ 광의: 학교 안팎의 모든 교육적 경험
→ 협의: 공식 교과목·단원의 체계

교육과정의 유형:

공식적 교육과정 (Formal/Explicit):
→ 국가·교사가 공식적으로 계획한 교육 내용
→ 교육과정 문서·교과서·수업 계획서

잠재적 교육과정 (Hidden Curriculum):
→ 잭슨 (Jackson, 1968): 공식 교육과정 밖에서 학생이 습득하는 것
→ 학교 문화·규범·권력 관계·성별 역할 등 내면화
→ 교실의 군중 속 살기·표창·권력 구조
→ 긍정적 (공동체 의식) vs 부정적 (불평등 재생산)

영 교육과정 (Null Curriculum):
→ 아이스너 (Eisner): 학교에서 가르치지 않는 것
→ 의도적 배제: 배제된 지식·기술·관점 자체가 메시지
→ 예: 특정 역사적 사건 배제·비판적 사고 교육 부족

경험 교육과정:
→ 듀이 (Dewey): 학생이 실제로 경험한 것이 진짜 교육과정
→ 계획된 내용 ≠ 학생이 배운 것

한국 국가 교육과정:
→ 교육부가 고시·전국 학교에 적용
→ 2022 개정 교육과정: 역량 중심·학습자 주도성 강화
→ 핵심 역량: 자기관리·지식정보처리·창의적사고·심미적감성·협력·의사소통
```

## 교육과정 개발 모형

```
타일러 모형 (Tyler, 1949):
→ 교육목표 설정 → 학습 경험 선정 → 조직 → 평가
→ 목표 달성 모형 (Objectives Model)
→ 목표 원천: 학생·사회·교과 전문가
→ 필터: 교육철학·교육심리학

타바 모형 (Taba, 1962):
→ 타일러보다 귀납적: 교사가 단원 개발 → 일반화
→ 7단계: 욕구 진단→목표→내용→내용조직→학습경험→조직→평가

워커 모형 (Walker, 1971):
→ 자연주의적 모형: 실제 교육과정 개발 과정 기술
→ 강령(Platform) → 숙의(Deliberation) → 설계(Design)
→ 목표 먼저가 아닌 가치·신념에서 출발

역방향 설계 (Understanding by Design, UbD):
→ 위긴스·맥타이 (Wiggins & McTighe)
→ 1단계: 바라는 결과 확인 (무엇을 이해해야 하는가)
→ 2단계: 수용 가능한 증거 결정 (어떻게 평가할 것인가)
→ 3단계: 학습 경험·수업 계획
→ "끝을 먼저 생각하기" (Begin with the End in Mind)

재개념주의 (Reconceptualism):
→ 파이너 (Pinar): 교육과정을 정치·젠더·인종 비판 관점으로
→ 쿠레레 (Currere): 교육과정을 살아가는 개인 경험으로 재개념화
→ 국가 교육과정의 정치적 성격 비판

한국 교육과정 조직:
→ 교과 교육과정: 교과별 목표·내용·방법·평가
→ 창의적 체험활동: 자율·동아리·봉사·진로 활동
→ 교과 집중 이수: 소수 교과 집중 이수 제도
```

## 블룸의 교육 목표 분류

```
블룸 (Bloom) 교육 목표 분류 (1956·개정 2001):
→ 인지적·정의적·심동적 영역으로 구분

인지적 영역 (Cognitive Domain):

원 분류 (1956):
→ 지식 → 이해 → 적용 → 분석 → 종합 → 평가

개정 분류 (Anderson & Krathwohl, 2001):
→ 기억 (Remember): 기억하고 재현
→ 이해 (Understand): 의미 해석·설명
→ 적용 (Apply): 새 상황에 사용
→ 분석 (Analyze): 부분으로 나누기·관계 파악
→ 평가 (Evaluate): 기준에 따른 판단
→ 창안 (Create): 새로운 것 조합·생성

지식 차원 (개정판 추가):
→ 사실적 지식·개념적 지식·절차적 지식·메타인지적 지식

정의적 영역 (Affective Domain, 크라트월):
→ 수용·반응·가치화·조직화·인격화

심동적 영역 (Psychomotor Domain):
→ 지각·태세·유도 반응·기계화·복합 외현 반응·적응·창안

교육 목표 진술 방법:
→ ABCD: Audience(대상)·Behavior(행동)·Condition(조건)·Degree(기준)
→ 명세적 행동 목표: "학생은 3가지 예를 들어 설명할 수 있다"
→ 메이거 방식: 조건·행동·기준 포함

목표 분류 활용:
→ 수업 계획: 목표 수준에 맞는 수업 활동
→ 평가 문항: 각 수준의 인지 능력 측정
→ 고차원적 사고 강조: 암기 위주 교육 탈피
```

## 교육평가의 유형

```
교육평가 (Educational Assessment) 유형:

시기에 따른 분류:

진단평가 (Diagnostic Assessment):
→ 수업 전 학생의 선수 학습·흥미·능력 파악
→ 목적: 개인차 파악·수업 계획 조정
→ 예: 단원 시작 전 사전 검사·학습 준비도 조사

형성평가 (Formative Assessment):
→ 수업 중 학습 진행 상황 파악
→ 목적: 즉각적 피드백·수업 개선·오개념 교정
→ 블랙·윌리엄 (Black & Wiliam): 형성평가는 학력 향상에 가장 효과적
→ 예: 퀴즈·관찰·질문·출구 티켓

총괄평가 (Summative Assessment):
→ 수업 후 학습 성취 결과 평가
→ 목적: 성적 부여·프로그램 효과 판단
→ 예: 기말시험·자격시험·수능

준거 참조에 따른 분류:

규준 참조 평가 (Norm-Referenced):
→ 집단 내 상대적 위치로 평가 (상대평가)
→ 정규 분포 전제·석차·백분위
→ 선발·분류 목적에 적합
→ 단점: 학생 간 경쟁 조장·집단 의존

준거 참조 평가 (Criterion-Referenced):
→ 사전에 설정된 기준 달성 여부 (절대평가)
→ 목표 달성률·합격/불합격
→ 개인의 성장·목표 달성 중심
→ 예: 운전면허 시험·자격증 시험

성장 참조 평가:
→ 이전 수준 대비 변화량 측정 (개인 성장)
```

## 수행평가와 피드백

```
수행평가 (Performance Assessment):
→ 학생이 직접 수행하는 과정·산출물로 평가
→ 선택형 문항 한계 극복: 고차원적 사고·복합 능력 측정

수행평가 유형:
→ 포트폴리오: 학생이 선별·구성한 작품 모음
→ 프로젝트: 실제 문제 해결 과제 수행
→ 토론·발표: 구두 의사소통 능력
→ 실험·실기: 실제 기능 수행
→ 서술형·논술형 평가

루브릭 (Rubric):
→ 수행 수준의 기준 기술표
→ 분석적 루브릭: 각 차원별 채점 기준
→ 전체적 루브릭: 전체 수행 수준 통합 평가
→ 채점 일관성·공정성·투명성 확보

피드백의 원칙:
→ 즉시성: 가능한 빨리 제공
→ 구체성: 무엇을 어떻게 개선할지
→ 미래 지향: 과거 판단보다 앞으로의 행동
→ 형성적: 성적보다 학습 개선에 초점

학습 분석 (Learning Analytics):
→ 학습 데이터를 분석하여 맞춤형 피드백 제공
→ AI 튜터·적응형 학습 시스템
→ 학습자의 강점·약점 패턴 파악

한국 학교 평가 제도:
→ 2012년 수행평가 의무화
→ 고교학점제 (2025 도입): 학점 이수제·절대평가 확대
→ 과정 중심 평가: 결과보다 과정 중시
```

## 자주 묻는 질문

**Q. 잠재적 교육과정은 왜 중요하고, 교사는 어떻게 활용해야 하나요?**
A. 잠재적 교육과정은 학생이 학교에서 배우는 것이 교과서 내용만이 아님을 일깨워 줍니다. 교실의 좌석 배치, 교사가 어떤 학생을 더 자주 호명하는지, 규칙을 어겼을 때 누구를 더 엄하게 대하는지 같은 요소들이 학생에게 권위·불평등·성별 역할 등에 대한 메시지를 전달합니다. 교사가 잠재적 교육과정을 인식하는 것이 중요한 이유는, 의도치 않은 편견이나 차별이 교육 경험에 스며드는 것을 방지하기 위해서입니다. 교사는 자신의 언어·행동·교실 환경이 어떤 가치와 기대를 전달하는지 성찰하고, 다양성 존중·민주적 참여·학생 자율성을 촉진하는 방향으로 의도적인 교실 문화를 만들어가야 합니다.

**Q. 형성평가와 총괄평가는 서로 다른 도구가 필요한가요?**
A. 반드시 다른 도구가 필요한 것은 아닙니다. 동일한 평가 도구라도 어떤 목적으로 사용하느냐에 따라 형성평가 또는 총괄평가가 됩니다. 예를 들어 중간고사 결과를 성적으로만 반영하면 총괄평가이지만, 그 결과를 분석하여 학생의 오류 패턴을 파악하고 다음 수업에 반영한다면 형성적으로 활용한 것입니다. 다만 형성평가는 일반적으로 낮은 위험(low-stakes), 빈번하게, 즉각적 피드백을 제공하는 방식이 효과적입니다. 최근 연구(블랙&윌리엄)에 따르면, 질문하기·동료 평가·자기 평가·관찰 등 일상적인 수업 내 형성평가 실천이 학업 성취 향상에 가장 큰 효과를 보입니다.
