# 카운트다운 타이머

목표 날짜까지 남은 일·시간·분·초를 실시간으로 확인합니다. 수능, 자격증 시험, 생일, 여행 출발, 이벤트 오픈까지 어떤 순간이든 카운트다운하세요.

단순히 날짜를 아는 것과 초 단위로 시간이 줄어드는 것을 보는 것은 심리적으로 다른 효과를 냅니다. 연구에 따르면 시각적 카운트다운은 목표 달성 의지와 집중력을 높이는 것으로 알려져 있습니다. 특히 수험생들 사이에서 D-Day 화면을 배경으로 설정해 매일 긴장감을 유지하는 방법이 인기입니다.

날짜와 시간을 설정하면 바로 카운트다운이 시작됩니다.

## 활용 사례

| 용도 | 예시 |
|---|---|
| 수험 준비 | 수능·공무원 시험·자격증 시험일 |
| 기념일 | 생일·결혼기념일·입사일 |
| 여행 | 출발 전날까지 |
| 이벤트 | 신제품 출시·콘서트·경기 |
| 프로젝트 | 마감일까지 |

<Callout type="tip">
**카운트다운의 심리 효과**: 구체적인 숫자로 남은 시간을 보면 **파킨슨의 법칙**을 역이용할 수 있습니다. 마감이 눈에 보이면 뇌는 긴박감을 느끼고 집중력이 높아집니다.
</Callout>

## 타이머 vs 카운트다운 차이

| 도구 | 방향 | 용도 |
|---|---|---|
| 타이머 | 정해진 시간에서 → 0으로 | 집중 세션, 요리, 운동 |
| 카운트다운 | 현재 → 목표 날짜까지 | 이벤트 대기, D-day |
| 스톱워치 | 0에서 → 현재까지 | 기록 측정 |
