## 기관계의 통합적 이해

인체는 각 기관이 독립적으로 작동하는 것이 아니라 서로 긴밀히 연결되어 있습니다.

```
심혈관-호흡 연계:
폐에서 산소화 → 심장이 전신으로 펌프
→ 심부전 → 폐에 체액 저류 → 호흡 곤란

내분비-면역 연계:
스트레스 → 코르티솔 상승 → 면역 억제
당뇨 → 면역 기능 저하 → 감염 취약

신경-내분비 연계:
시상하부 → 뇌하수체 → 말초 내분비선
HPA 축: 스트레스 반응의 중추
```

## 예방의학의 3단계

```
1차 예방 (발병 전):
→ 백신 접종
→ 생활습관 개선 (운동, 식사, 금연)
→ 환경적 위험 제거

2차 예방 (조기 발견):
→ 건강검진 (암 조기 발견)
→ 선별검사 (혈압, 혈당, 콜레스테롤)
→ 고위험군 집중 관리

3차 예방 (합병증 방지):
→ 당뇨 환자 → 망막·신장 정기 검사
→ 심근경색 후 → 재발 방지 약물·재활
→ 삶의 질 유지
```

## 한국 국가건강검진 가이드

```
일반 건강검진 (2년마다):
→ 혈압, 혈당, 총콜레스테롤, 중성지방
→ 신장, 체중, 허리둘레 (복부비만)
→ AST/ALT (간기능), 크레아티닌 (신기능)

암 검진:
위암: 40세 이상 2년마다 위내시경
대장암: 50세 이상 1~2년마다 분변잠혈검사
간암: 40세 이상 고위험군 6개월마다 초음파+AFP
유방암: 40세 이상 여성 2년마다 유방촬영술
자궁경부암: 20세 이상 여성 2년마다 세포검사
폐암: 54~74세 흡연자 2년마다 저선량 CT
```

## 생활습관의학 — 가장 강력한 약

```
근거 기반 생활습관 처방:

신체 활동:
→ 중등도 유산소 주 150분 이상
→ 근력 운동 주 2회 이상
→ 효과: 심혈관 질환 30%, 당뇨 27%, 암 21% 위험 감소

식이:
→ 지중해식 식단: 올리브오일, 채소, 생선, 통곡물
→ 초가공식품 최소화
→ 나트륨 제한 (2,000mg/일 이하)

수면:
→ 7~9시간 (성인)
→ 만성 수면 부족 → 비만·당뇨·심혈관·면역 저하

스트레스 관리:
→ 만성 스트레스 = 만병의 근원 (염증, 면역 억제)
→ 마인드풀니스, 운동, 사회적 연결이 효과적

금연·절주:
→ 흡연: 폐암 위험 15~25배, 심혈관 위험 2~4배
→ 음주: 1표준잔/일 초과 = 여러 암 위험 증가
```

## 주요 만성 질환 예방 체크리스트

```
심혈관 질환 예방:
☐ 혈압 120/80mmHg 이하 유지
☐ LDL 콜레스테롤 100mg/dL 이하
☐ 금연 (1년 후 심혈관 위험 절반 감소)
☐ 규칙적 유산소 운동

당뇨 예방 (당뇨 전단계):
☐ 체중 5~7% 감량
☐ 주 150분 신체활동
☐ 정제 탄수화물 줄이기
→ 당뇨 발병 위험 58% 감소 (DPP 연구)

암 예방:
☐ 금연 (폐암·구강암·방광암·췌장암)
☐ 적정 체중 (비만 = 13개 암 위험 증가)
☐ 국가암검진 빠짐없이 수검
☐ B형간염 예방접종 (간암 예방)
☐ HPV 예방접종 (자궁경부암 예방)
```

## 의학 지식을 대하는 자세

```
의학 정보 리터러시:
→ 근거 수준 확인: 체계적 문헌고찰 > 무작위 대조 실험 > 코호트 연구 > 사례 보고
→ 상관관계 ≠ 인과관계
→ 통계적 유의미함 ≠ 임상적 의미

"N=1" 주의:
→ "이걸 먹었더니 나았다" = 개인 사례
→ 수천 명 연구 결과와는 다름

의사와의 파트너십:
→ 증상 정확히 기록 (언제부터, 어떤 상황, 동반 증상)
→ 복용 중인 약·보조식품 모두 알리기
→ 궁금한 것 망설이지 말고 질문하기
```
