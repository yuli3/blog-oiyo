## 배틀로얄, 한 판의 흐름부터

배틀로얄은 "여러 명이 한 맵에 떨어져 **마지막 1인(팀)이 남을 때까지** 싸우는" 장르다. 배그(PUBG)·포트나이트·에이펙스 등이 대표작이다. 핵심 규칙만 알면 첫 판부터 헤매지 않는다.

---

## 한 판의 기본 흐름

```
1. 대기/탑승: 비행기(또는 시작 지점)에서 출발
2. 낙하(드랍): 원하는 지점에 착지
3. 파밍(Looting): 건물에서 무기·방어구·아이템 수집
4. 생존·교전: 자기장에 맞춰 이동하며 적과 싸움
5. 최종 원: 좁아진 구역에서 마지막 승부 → 1인(팀) 생존 시 승리
```

승리 표현은 게임마다 다르다(예: 배그 "치킨").

---

## 가장 중요한 — 자기장(Zone)

<a id="zone"></a>

```
자기장: 시간이 지나면 안전 구역(원)이 점점 좁아짐.
- 원 밖에 있으면 지속 피해(데미지) → 결국 사망
- 시간이 갈수록 원 밖 피해가 커짐
→ "항상 다음 원 안으로 미리 이동"이 생존의 기본
```

자기장 관리가 배틀로얄 실력의 절반이다.

---

## 파밍 — 무엇을 챙기나

| 분류 | 예 | 우선순위 |
|------|-----|---------|
| **무기** | 주무기 2개(근·중거리 조합) | 최우선 |
| **방어구** | 헬멧·방탄조끼·가방 | 높음 |
| **회복** | 구급상자·붕대·에너지 | 높음 |
| **부착물** | 조준경·손잡이·탄창 | 중 |
| **탄약** | 무기 구경에 맞게 | 필수 |

```
착지 직후 1분: 무기 → 방어구 → 회복 순으로 빠르게.
"빈손 교전"이 가장 위험하다.
```

---

## 초보 생존 전략

```
1. 외곽 드랍: 처음엔 교전 적은 곳에 내려 파밍·적응
2. 엄폐 활용: 탁 트인 곳 이동 금지, 나무·바위·건물 끼고
3. 소리: 발소리·총성·차량음으로 적 위치 파악(헤드셋 권장)
4. 팀플(듀오/스쿼드): 핑(표시)으로 소통, 같이 움직이기
5. 무리한 교전 금지: '생존'이 목적 — 끝까지 살아남기
```

---

## 대표 모드

```
솔로: 혼자 / 듀오: 2인 / 스쿼드: 4인
TPP(3인칭) / FPP(1인칭): 시점 차이
```

---

## 핵심 요약

1. 마지막 1인(팀)이 남을 때까지 싸우는 장르.
2. 흐름: 낙하 → 파밍 → 자기장 따라 이동·교전 → 최종 원.
3. **자기장(좁아지는 안전 구역)** 관리가 생존의 핵심.
4. 착지 후 무기→방어구→회복 순으로 빠르게 파밍.
5. 초보는 외곽 드랍·엄폐·소리 활용·무리한 교전 자제로 생존부터.
