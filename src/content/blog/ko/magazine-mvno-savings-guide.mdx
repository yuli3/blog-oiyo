## 알뜰폰이란?

```
알뜰폰(MVNO: Mobile Virtual Network Operator):
→ SK텔레콤·KT·LG U+의 망을 빌려 저렴하게 서비스하는 통신사
→ 통신망 품질은 대형 통신사와 동일
→ 가격만 훨씬 저렴 (월정 요금의 50~80% 절약 가능)
```

---

## 알뜰폰 vs 대형 통신사 비교

```
대형 통신사 (5G, 데이터 무제한):
- KT·SKT·LGU+: 월 4.5~8만원

알뜰폰 (동일 속도 5G, 데이터 무제한):
- 헬로모바일, KT 알뜰폰 등: 월 1.5~3만원

→ 같은 통화·데이터 조건에서 연간 30~60만원 절약
```

---

## 주요 알뜰폰 통신사 종류

```
SKT 망 사용:
- SK7모바일, 유니버스 모바일, 이야기모바일, KB모바일 등

KT 망 사용:
- KT M모바일, 알뜰폰 허브, 헬로모바일, 케이티 스카이라이프 등

LGU+ 망 사용:
- U+알뜰모바일, 이지모바일 등

→ 어느 망을 쓰느냐에 따라 지역별 통신 품질 차이 있을 수 있음
```

## 추천 요금제 유형

### 데이터 소량 사용 (월 1~1.5만원)

```
- 음성 무제한 + 데이터 1~3GB
- 집 또는 직장에서 Wi-Fi 이용 가능한 분
- 카카오톡, SNS 위주 사용자

예시:
→ 스마텔 음성 데이터 소량 요금제: 월 9,900~14,900원
→ KT M모바일 기본 요금제: 월 11,000원대
```

### 데이터 중간 사용 (월 1.5~2.5만원)

```
- 음성 무제한 + 데이터 5~10GB
- 동영상·유튜브 보통 사용자

예시:
→ 월 15,000~25,000원대 요금제
→ 5G 속도 적용
```

### 데이터 무제한 (월 2~3만원)

```
- 영상·게임 헤비 유저
- 대형 통신사 무제한 대비 50~60% 저렴

예시:
→ 헬로모바일 LTE 무제한: 월 22,000원
→ 대형 통신사 동급: 월 50,000원 이상
```

## 가입 방법

### 온라인 가입

```
알뜰폰 허브 (mvno.kr):
→ 비교 검색 후 원하는 통신사·요금제 선택
→ 본인 인증 후 온라인 가입

각 알뜰폰 통신사 홈페이지:
→ 직접 요금제 확인 후 신청

KT/SKT/LGU+ 자사 알뜰폰:
→ 해당 통신사 MVNO 서비스 홈페이지
```

### 오프라인 가입

```
편의점 유심 구매:
→ CU, GS25, 세븐일레븐에서 알뜰폰 유심 구매 가능
→ 구매 후 번호 개통 (온라인 셀프 개통)

우체국:
→ 우체국 알뜰폰 서비스 창구 방문
→ 통신 취약계층 우대 요금제 있음
```

## 기존 번호 그대로 이동 (번호 이동)

```
절차:
1. 기존 통신사에서 명의확인 (온라인 또는 고객센터)
2. 새 알뜰폰 가입 신청 시 '번호 이동' 선택
3. 이동 완료까지 1~3영업일

주의:
→ 기존 통신사 위약금 확인 (약정 있으면 위약금 발생)
→ 약정 만료 후 이동이 유리
→ 위약금이 있어도 1~2년 절약액이 더 클 수 있음
```

## 알뜰폰의 단점

```
1. 고객 서비스 접근 불편:
→ 오프라인 매장 거의 없음
→ 문제 발생 시 전화 또는 채팅 상담만

2. 폰 구입 제한:
→ 최신 스마트폰 할부 구매 어려움 (자급제 폰 별도 구매)
→ 자급제 폰 + 알뜰폰 유심이 일반적

3. 통신 품질 미세한 차이:
→ 대형 통신사 전용 주파수 미사용
→ 혼잡 지역에서 속도 저하 가능 (LTE는 대부분 문제없음)

4. 해외 로밍 한계:
→ 해외 로밍 서비스가 제한적이거나 없음
→ 해외 여행 많은 분은 주의
```

## 저소득층 통신비 지원

```
정부 통신비 지원 제도:
→ 기초수급자·차상위계층 대상 통신비 감면

감면 내용 (2024년):
- 기초수급자: 월 최대 26,000원 감면
- 차상위계층: 월 최대 11,000원 감면

신청:
→ 해당 통신사 고객 센터에 복지 수급 증명서 제출
→ 알뜰폰도 동일 감면 적용

→ 알뜰폰 + 복지 감면 = 거의 무료에 가까운 요금 가능
```

## 자주 묻는 질문

**Q. 알뜰폰으로 바꾸면 카카오톡 등 앱 사용에 지장이 있나요?**
A. 없습니다. 통신망은 대형 통신사와 동일하게 사용하므로 데이터를 쓰는 모든 앱이 정상 작동합니다.

**Q. 기기는 어떻게 구매하나요?**
A. 자급제 스마트폰(공기계)을 삼성 딜라이트, 애플 스토어, 네이버 쇼핑 등에서 구매한 후 알뜰폰 유심을 삽입하면 됩니다.

**Q. 약정 없이 언제든 해지할 수 있나요?**
A. 대부분의 알뜰폰은 약정 없이 월 단위 해지가 가능합니다. 단, 일부 특가 요금제는 3~12개월 약정이 있을 수 있으니 가입 전 확인하세요.
