## 워드프로세서 1급 시험 구조 복습

워드프로세서 1급 필기는 워드프로세싱 일반, PC 운용 능력, 문서 관리 3개 과목으로 구성됩니다. 실기는 **한글(HWP)**을 이용한 문서 작성 능력을 평가합니다.

이번 챕터에서는 실기 시험에서 자주 출제되는 **메일머지**와 **문서 양식** 기능을 집중 정리합니다.

---

## 메일머지 (Mail Merge)

메일머지는 **하나의 본문 서식**에 **여러 개의 데이터**를 자동으로 삽입하여 개인화된 문서를 대량 생성하는 기능입니다.

### 활용 예시

- 같은 내용의 초청장을 100명에게 발송 — 이름과 주소만 다르게
- 성적표, 납부 안내서, 인증서 일괄 생성

### 메일머지의 3가지 구성 요소

| 구성 | 설명 | 예시 |
|------|------|------|
| **주 문서 (본문)** | 공통 내용이 담긴 서식 문서 | 초청장 본문 |
| **데이터 파일** | 개인별 데이터가 담긴 목록 | 이름·주소 목록 |
| **병합 필드** | 본문에서 데이터가 들어갈 위치 | `{{이름}}`, `{{주소}}` |

## 한글에서 메일머지 단계별 작업

### 1단계: 데이터 파일 작성

**방법 1: 한글 내 주소록 사용**
1. 도구 → 주소록 편집
2. 필드명 정의 (이름, 부서, 이메일 등)
3. 데이터 입력

**방법 2: 엑셀/CSV 파일 연결**
1. 첫 행을 필드명으로 구성
2. 이후 행에 데이터 입력
3. `파일 → 저장 → CSV 형식`

### 2단계: 주 문서(본문) 작성

```
[본문 예시]
{{이름}} 귀하

안녕하세요. 저희 회사 {{연도}}년 연간 총회에 초청합니다.
일시: {{일시}}
장소: {{장소}}

참석 부탁드립니다.
```

병합 필드 삽입 방법:
- 도구 → 메일 머지 → 메일 머지 표시 달기
- 또는 `{{` 직접 입력 후 필드명 입력

### 3단계: 메일머지 실행

1. **도구 → 메일 머지 → 메일 머지 만들기**
2. 데이터 파일 선택
3. 출력 방식 선택:
   - **새 문서로**: 각 레코드가 새 문서로 생성
   - **현재 문서에 추가**: 단일 파일에 모두 포함
   - **프린터 출력**: 바로 인쇄

### 메일머지 출력 결과

데이터가 3건이면 → 본문 서식 × 3 = 3개 완성 문서

## 양식 문서 작성

### 양식 문서란?

사용자가 특정 영역에만 입력할 수 있도록 **입력 필드를 미리 정의**해 놓은 문서입니다. 설문지, 신청서, 계약서 등에 활용됩니다.

### 양식 도구 종류

**1. 입력란 (텍스트 입력)**

```
삽입 → 양식 개체 → 입력란
- 사용자가 자유롭게 텍스트 입력 가능
- 최대 길이, 기본값 설정 가능
```

**2. 체크박스**

```
삽입 → 양식 개체 → 체크박스
- 체크/체크 해제 토글
- 활성화 값, 비활성화 값 설정 가능
```

**3. 목록 상자 (콤보박스)**

```
삽입 → 양식 개체 → 목록 상자
- 드롭다운으로 선택 항목 제공
- 항목 추가/삭제 가능
```

**4. 계산식**

특정 입력란의 값을 계산해 자동 표시할 수 있습니다.

### 양식 보호

작성이 완료된 양식 문서는 **도구 → 문서 보호 → 양식 보호**를 설정하면 지정된 입력란 외의 내용 수정이 불가능해집니다.

## 주석(Footnote)과 미주(Endnote)

### 차이점

| 구분 | 주석(Footnote) | 미주(Endnote) |
|------|---------------|--------------|
| 위치 | 같은 페이지 하단 | 문서 맨 마지막 |
| 번호 | 페이지별 또는 전체 일련번호 | 전체 일련번호 |
| 활용 | 단어 설명, 출처 표시 | 긴 참고문헌 목록 |

### 삽입 방법

```
커서 위치 → 삽입 → 주석 → 각주 (또는 미주)
→ 주석 번호 자동 삽입 → 하단에 내용 입력
```

## 덧말과 숨은설명

### 덧말 (Ruby Text)

한자나 어려운 단어 **위나 아래에 작게 발음·설명**을 표시하는 기능.

```
삽입 → 덧말
- 대상 텍스트 선택 → 덧말 내용 입력
- 위치: 위/아래 선택
```

활용: 한자 발음 표시, 외국어 번역, 약어 풀이

### 숨은설명 (Hidden Text)

문서에 **표시되지 않는 주석**을 삽입하는 기능.

```
서식 → 글자 모양 → 숨은설명 탭
- 화면에서 보이지 않음
- 인쇄 시 출력 여부 선택 가능
- 편집 모드에서는 표시됨
```

활용: 편집자 메모, 내부 지시사항, 초안 메모

## 실전 문제 유형

### 유형 1: 메일머지 설정

> 다음 중 메일머지에서 데이터 파일로 사용 가능한 형식은?

- ① HWP 파일만 가능
- ② DBF, CSV, XLS, HWP 가능
- ③ CSV 파일만 가능
- ④ TXT 파일만 가능

**정답**: ② (다양한 형식 지원)

- ① 입력란  ② 체크박스  ③ 목록 상자  ④ 계산식

**정답**: ③

### 유형 3: 각주와 미주

## 실전 퀴즈 5문항

**Q1.** 메일머지에서 병합 필드를 표시하는 기호는?
- ① `<<필드명>>`  ② `{필드명}`  ③ `{{필드명}}`  ④ `[필드명]`

**정답**: ③ *(한글에서는 이중 중괄호 사용)*

---

**Q2.** 메일머지 데이터 파일에서 첫 행의 역할은?

- ② 필드명 정의
- ③ 날짜 정보
- ④ 파일 형식 지정

**정답**: ②

---

**Q3.** 양식 문서에서 입력란과 체크박스의 차이로 옳은 것은?
- ① 입력란은 선택, 체크박스는 자유 입력
- ② 입력란은 자유 텍스트 입력, 체크박스는 체크/해제 선택
- ③ 두 기능은 동일하다
- ④ 체크박스는 숫자만 입력 가능

**정답**: ②

---

**Q4.** 각주(Footnote)의 위치는?
- ① 문서 맨 마지막  ② 같은 페이지 하단  ③ 섹션 끝  ④ 챕터 끝

**정답**: ②

**Q5.** 덧말 기능의 주요 활용 목적은?
- ① 텍스트를 숨기기 위해
- ② 한자 발음 표시 또는 어려운 단어 설명
- ③ 인쇄 미리보기 전용
- ④ 메일머지 데이터 연결
