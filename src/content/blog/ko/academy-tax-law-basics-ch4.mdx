## 부가가치세 개요

```
부가가치세 (VAT):
재화·서비스의 거래 단계마다 창출된 부가가치에 과세

특성:
- 세율: 10% (단일 세율)
- 납세자: 사업자 (최종 부담자: 소비자)
- 전단계 세액 공제법: 매출세액 - 매입세액

과세 사업자 vs 면세 사업자:
과세 사업자: VAT 부담, 매입세액 공제 가능
면세 사업자: VAT 없음, 매입세액 공제 불가
```

---

## 과세·면세·영세율 구분

```
과세:
- 일반 재화·서비스 (세율 10%)
- 사업자가 소비자에게 VAT 받아 국가에 납부

면세:
- 기초 생활품·의료·교육 등
- VAT 부과 안 함
- 면세 사업자: 매입세액 공제 불가 (영구 비용화)
- 예: 미가공 식품·의약품·교육 서비스·의료

영세율 (0%):
- 수출 재화·국외 제공 서비스
- VAT = 0 이지만 매입세액은 전액 환급
- 완전한 세금 부담 없음 (수출 경쟁력)
```

### 면세 vs 영세율 비교

```
┌────────────┬───────────────┬───────────────┐
│ 구분       │ 면세          │ 영세율(0%)    │
├────────────┼───────────────┼───────────────┤
│ 매출 VAT   │ 없음          │ 0% (영)       │
│ 매입세액   │ 공제 불가     │ 전액 공제     │
│ 실질 효과  │ 매입세액 비용 │ 완전 면제     │
│ 적용 대상  │ 기초생활·교육 │ 수출          │
└────────────┴───────────────┴───────────────┘
```

## 매입세액공제

```
납부할 VAT:
매출세액 - 매입세액 = 납부세액

매입세액 공제 불가 항목:
- 면세 사업 관련 매입
- 개인적 사용 (자가 소비)
- 비영업용 승용차 구입·유지
- 접대비 관련 매입
- 세금계산서 미수령 또는 불성실 기재

세금계산서:
- 공급자가 공급받는 자에게 발행
- 발행 의무: 과세 사업자
- 전자세금계산서 의무화 (일정 규모 이상)
```

## 과세 기간과 신고납부

```
과세 기간:
제1기: 1월 1일 ~ 6월 30일
  예정 신고: 4월 25일
  확정 신고: 7월 25일

제2기: 7월 1일 ~ 12월 31일
  예정 신고: 10월 25일
  확정 신고: 다음 해 1월 25일

간이과세자 (연 매출 1억 400만 미만):
- 단순화된 신고
- 세율: 업종별 부가가치율 × 10%
- 매입세액 공제 방식 다름
```

## 부동산 관련 VAT

```
토지: 면세 (토지는 부가가치 창출 없음)
건물: 과세
토지+건물 일괄 거래:
→ 실가 또는 안분 기준으로 건물분 VAT 부과

임대 사업:
주거용 임대: 면세
상업용 임대: 과세
→ 상가 임대인: 임대료의 10% VAT 징수
```

## 핵심 개념 카드

**면세 vs 영세율** ★★★★★
: 면세=매입세액공제불가(비용). 영세율=매입세액 전액 환급(완전면제). 수출=영세율.
*암기 포인트: 수출=영세율=매입세액 환급*

**매입세액 공제 불가** ★★★★★
: 비영업용 승용차·접대비·면세사업 관련·세금계산서 미수령. 4가지 암기.
*암기 포인트: 비승용+접대비+면세+세계산서없음=공제불가*

**부동산 VAT** ★★★★☆
: 토지=면세, 건물=과세. 주거용임대=면세, 상업용임대=과세.
*암기 포인트: 토지·주거=면세, 건물·상업=과세*

## 실전 퀴즈

**Q. 수출업체가 원재료 구입 시 납부한 VAT 1,000만 원. 수출 매출세액은 0원. 어떻게 처리되는가?**
> 영세율 적용 수출 → 매출세액 0원. 매입세액 1,000만 원 전액 환급 청구. 수출기업은 VAT 부담 없음.

**Q. 식료품점(미가공 식품 판매)이 냉장고를 구매할 때 VAT를 납부했다. 이를 매입세액 공제받을 수 있는가?**
> 불가. 면세 사업자(미가공 식품 판매)는 매입세액 공제 불가. 냉장고 VAT는 비용으로 처리.
