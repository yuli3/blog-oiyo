# 12장: 모성 간호 — 임신, 분만, 산후 관리

모성 간호는 수태부터 산후 기간까지 여성의 돌봄을 포괄합니다. 임신의 심오한 생리적 변화, 역동적인 분만 과정, 산후 기간의 신체적·정서적 회복을 이해하는 것이 필요합니다.

## 산전 관리(Antepartum Care)

### 임신 중 주요 생리적 변화

- **심혈관계**: 혈액량 40–50% 증가; 심박수 10–15 bpm 증가; 임신 2분기에 혈압이 저하될 수 있음
- **호흡계**: 횡격막 상승; 일회 호흡량(TV) 증가; 경미한 호흡성 알칼리증(정상)
- **신장계**: GFR 40–60% 증가; 병적 원인 없이 당뇨(glucosuria)가 나타날 수 있음
- **혈액계**: 생리적 빈혈(희석성); 백혈구 증가; 과응고 상태(hypercoagulable state)

**경고 징후** (HELLP/자간전증): 혈압 ≥ 140/90, 단백뇨, 부종, 두통, 시각 변화, 상복부 통증, 우상복부 통증 → 즉시 의료 제공자에게 보고하세요.

### 분만 예정일(Estimated Due Date, EDD) — 네겔레 법칙(Naegele's Rule)

마지막 월경 시작일(LMP) + 7일 − 3개월 + 1년 = 분만 예정일(EDD)

## 분만 단계

| 단계 | 설명 | 간호 돌봄 |
|-----|-----|---------|
| 1단계 — 잠재기(Latent) | 자궁경부 0–6 cm; 수축 5–30분 간격 | 보행, 체위 변경, 안위 도모 |
| 1단계 — 활성기(Active) | 자궁경부 6–10 cm; 수축 2–3분 간격 | 통증 관리, 지속적 모니터링, 지지 |
| 2단계 | 완전 개대부터 분만까지; 힘주기 | 힘주기 코칭; 태아심박수(FHR) 모니터링; 분만 준비 |
| 3단계 | 태반 만출(최대 30분) | 옥시토신 투여, 자궁 저부 마사지, 출혈 모니터링 |
| 4단계 | 산후 첫 1–2시간 | 15분마다 사정; 출혈 예방 |

**태아심박수 모니터링**: 정상 FHR 기저 110–160 bpm. 안심 징후: 가속(accelerations, 양호), 이른 감속(early decelerations, 두부 압박 — 양성). 비안심 징후: 후기 감속(late decelerations, 자궁태반 기능 부전), 변이 감속(variable decelerations, 제대 압박), 지연 감속, 변이성 소실.

## 산후 사정: BUBBLE-HE

| 구성 요소 | 사정 |
|---------|-----|
| **B**reasts(유방) | 울혈, 유두 압통, 모유 생성 |
| **U**terus(자궁) | 자궁 저부 높이, 단단함(단단함 = 수축), 중앙 vs. 편위 |
| **B**owel(장) | 첫 배변(보통 2–3일), 장음 |
| **B**ladder(방광) | 소변 배출량, 요정체 징후, 요로감염(UTI) |
| **L**ochia(오로) | 색(혈성 오로(rubra) → 장액성 오로(serosa) → 백색 오로(alba)), 양, 냄새(악취 = 감염) |
| **E**pisiotomy/절개(회음 절개/절개부) | REEDA: 발적(Redness), 부종(Edema), 반상출혈(Ecchymosis), 분비물(Discharge), 접합(Approximation) |
| **H**omans 징후(Homans Sign, 제한적 유용성) | 배측 굴곡 시 종아리 통증(심부정맥혈전증, DVT — 민감도 낮음; 온감/발적/부종 사정) |
| **E**motions(정서) | 산후 우울감(blues) vs. 산후 우울증(depression) vs. 산후 정신증(psychosis) |

## 산후 우울증(Postpartum Depression)

**산후 우울감(Baby blues)**: 일시적인 눈물, 기분 변화, 처음 2주 이내 — 정상적인 호르몬 조정.

**산후 우울증(Postpartum Depression, PPD)**: 지속적인 슬픔, 유대감 형성 어려움, 불면증, 무가치감, 2주 이상 지속. 신생아 어머니의 약 10–15%에 영향을 미칩니다. 선별: 에딘버러 산후 우울증 척도(Edinburgh Postnatal Depression Scale, EPDS). 치료: 심리 치료, 항우울제, 지지.

**산후 정신증(Postpartum psychosis)**: 드물지만 위험함; 환각, 망상, 급격한 발병 — 정신과적 응급 상황; 영아 살해/자살 위험.

## 모유 수유 지원(Breastfeeding Support)

젖 물기 사정: LATCH 점수(Latch 젖 물기, Audible swallowing 청각적 삼키기, Type of nipple 유두 유형, Comfort 편안함, Hold 자세). 올바른 젖 물기: 아기의 입이 유두와 대부분의 유륜(areola)을 덮어야 함; 수유 시 통증 없어야 함.

## 핵심 체크리스트

- [ ] 분만의 네 단계를 나열하고, 각 단계의 주요 간호 중재를 설명하세요.
- [ ] 각 구성 요소에서 정상 소견이 어떻게 보이는지 설명하며 산후 BUBBLE-HE 사정을 수행하세요.
- [ ] 산후 우울감, 산후 우울증, 산후 정신증을 발생 시기, 심각도, 간호/의학적 대응 측면에서 구분하세요.
