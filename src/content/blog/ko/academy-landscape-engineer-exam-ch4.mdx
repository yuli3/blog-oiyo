## 조경 시공의 기초

```
시공 과정:
- 부지 정지·토공 (절토·성토)
- 기반 조성 → 식재·시설물 설치 → 마감

토공:
- 절토(깎기) / 성토(쌓기)
- 법면(비탈면) 안정, 다짐
- 토량 환산계수(L값·C값) 계산
```

---

## 조경 구조와 재료

```
조경 재료:
- 목재 / 석재 / 콘크리트 / 벽돌·블록
- 점토·합성수지·금속

포장:
- 보도블록, 투수성 포장
- 마사토·자갈 포장

구조물:
- 옹벽(중력식·캔틸레버식)
- 데크·파고라·플랜터·계단
→ 안전·배수·내구성 고려
```

---

## 조경 적산(積算)

```
적산:
→ 공사에 필요한 수량·비용 산출

공사비 구성:
- 재료비 + 노무비 + 경비 = 직접공사비
- + 간접비(일반관리비·이윤) = 총공사비

수량 산출:
- 식재 수량(주, 본)
- 토공량(㎥), 포장 면적(㎡)
- 품셈(표준 단가) 적용

→ 실기 필답형에서 계산 출제
```

---

## 조경 관리론

```
관리의 3대 영역:
1. 운영관리: 예산·조직·이용 관리
2. 이용관리: 안전·서비스·프로그램
3. 유지관리: 식물·시설물 관리

식물 유지관리:
- 관수(물주기) / 시비(거름)
- 전정(가지치기) / 제초 / 멀칭
- 병해충 방제
```

### 전정과 병해충

```
전정(剪定) 목적:
- 수형 유지, 생장 조절, 통풍·채광
- 시기: 동계전정(휴면기)·하계전정

병해충 방제:
- 예방 중심(IPM, 종합적 방제)
- 흰불나방·솔잎혹파리 등 주요 해충
- 약제·천적·물리적 방제 병행
```

## 실기 대비 전략

```
실기 = 조경설계(작업형 도면 + 필답형)

작업형(도면):
- 평면도·단면도·상세도 시간 배분
- 수목 범례·규격 표기 정확히
- 제도 도구 숙달, 글씨·선 정리

필답형:
- 적산(수량·공사비) 계산 연습
- 시공·관리 단답 암기

→ 기출 대상지 반복 작도가 최선
```

## 핵심 암기 포인트

```
- 토공: 절토·성토, 토량환산(L·C값)
- 옹벽: 중력식·캔틸레버식
- 공사비: 직접비(재료+노무+경비)+간접비
- 관리 3영역: 운영·이용·유지관리
- 전정: 동계(휴면기)·하계전정
- 방제: IPM(종합적 병해충 관리)
```

## 자주 묻는 질문

**Q. 적산 계산이 어려운데 어떻게 대비하나요?**
A. 품셈을 이용한 표준 수량·단가 산출 패턴이 정해져 있어, 기출 유형(식재 수량·토공량·포장 면적)을 반복해 풀면 충분히 대비할 수 있습니다.

**Q. 전정 시기는 왜 중요한가요?**
A. 휴면기인 겨울에 하는 동계전정과 생장기의 하계전정은 목적이 다릅니다. 시기를 잘못 택하면 수목에 해가 되므로 출제 포인트로 자주 나옵니다.

**Q. 합격까지 얼마나 걸리나요?**
A. 필기는 2~3개월, 실기(도면)는 별도로 1~2개월 집중 작도 연습이 일반적입니다. 실기 도면 숙달이 전체 합격 기간을 좌우합니다.
