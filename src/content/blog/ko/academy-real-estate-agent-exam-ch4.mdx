## 공인중개사법 출제 분석

**2차 공인중개사법·중개실무 출제 비중**:

```
공인중개사 자격·등록: 약 15%
중개업자 의무: 약 25%
중개보수·실비: 약 15%
금지행위·행정처분: 약 20%
부동산 거래신고제도: 약 10%
중개계약·공제: 약 15%
```

---

## 중개업 등록 제도

### 등록 기준

| 구분 | 요건 |
|------|------|
| 사무소 | 건축물 대장 등재된 건물 |
| 인력 | 공인중개사 자격증 소지자 |
| 업무보증 | 개인 1억 이상, 법인 2억 이상 |
| 소속 공인중개사 | 사무소당 1인 이상 책임 |

**이중 등록 금지**: 2개 이상 사무소 등록 불가.  
**겸업 제한**: 중개업과 상충되는 업종 겸업 금지 (중개 공정성 훼손 우려).

---

## 결격 사유 (등록 거부·취소)

```
절대적 결격 (자격 취소 포함):
① 피성년후견인·피한정후견인
② 파산선고 받고 복권되지 않은 자
③ 금고 이상 실형 선고 후 집행 종료 3년 미경과
④ 공인중개사법 위반 징역 후 3년 미경과
⑤ 이중계약서 작성으로 등록 취소 후 3년 미경과
⑥ 업무정지 기간 중 중개 행위
```

## 중개대상물 확인·설명 의무

**공인중개사법 제25조**:

```
확인·설명 대상 (빈출 암기):
① 등기부 기재 사항
   - 소유권·지역권·전세권·저당권·지상권 등
② 토지이용계획 확인서
   - 용도지역·지역·지구
③ 건축물 현황
   - 건물 면적, 용도, 허가 여부
④ 시설 상태
   - 수도·전기·가스·난방 등
⑤ 임대차 확인
   - 선순위 담보·임차 관계
⑥ 실거래가
   - 공시가격, 개별공시지가
```

**중개대상물 확인·설명서**: 의무 작성, 서명·날인 후 당사자에게 교부. 3년 보관.

---

## 금지 행위 (공인중개사법 제33조)

```
절대 금지:
① 중개 대상물 직접 매매·교환·임대 (자기 거래)
② 법정 보수 이외 금품 수수
③ 허위·과장 광고 (사실과 다른 표시)
④ 이중계약서 작성 (업계약·다운계약)
⑤ 관계 법령 위반 거래 유도
⑥ 투기·부정 목적 단체 활동
```

**위반 시 처분**:
- 이중계약서 → 자격 취소 + 3년 이하 징역 또는 3,000만 원 이하 벌금
- 허위·과장 광고 → 500만 원 이하 과태료

## 중개보수 (수수료) 계산법

### 주택 매매 상한 요율

| 거래금액 | 상한 요율 | 한도액 |
|---------|---------|-------|
| 5,000만 미만 | 0.6% | 25만 원 |
| 5,000만~2억 미만 | 0.5% | 80만 원 |
| 2억~9억 미만 | 0.4% | — |
| 9억~12억 미만 | 0.5% | — |
| 12억~15억 미만 | 0.6% | — |
| 15억 이상 | 0.7% | — |

### 주택 임대차 상한 요율

| 거래금액 | 상한 요율 | 한도액 |
|---------|---------|-------|
| 5,000만 미만 | 0.5% | 20만 원 |
| 5,000만~1억 미만 | 0.4% | 30만 원 |
| 1억~6억 미만 | 0.3% | — |
| 6억~12억 미만 | 0.4% | — |
| 12억~15억 미만 | 0.5% | — |
| 15억 이상 | 0.6% | — |

```
계산 예시:
전세 3억 → 0.3% → 90만 원 (VAT 별도)
매매 6억 → 0.4% → 240만 원

주의: 상한이므로 협의로 낮출 수 있음
```

## 부동산 거래신고제도

**부동산 거래신고**: 계약 체결일로부터 **30일 이내** 신고.

**신고 의무자**: 거래 당사자 (공인중개사가 중개한 경우 중개업자가 대리 신고).

**허위신고 제재**:
- 다운계약: 취득세 추징 + 과태료
- 업계약: 양도세 추징 + 과태료 + 부동산 거래신고법 위반

---

## 행정 처분 체계

```
행정 처분 단계:
경고 → 업무정지 → 등록 취소

업무정지 최대: 6개월
등록 취소 사유: 이중계약, 결격 사유, 업무정지 기간 중 중개 등

자격 취소 사유:
공인중개사 자격 취소 → 자격시험 재응시 가능 여부?
→ 3년 경과 후 재응시 가능 (이중계약서 작성 등)
```

## 기출 핵심 문제

**Q1. 중개대상물 확인·설명서 보관 기간은?**
> 3년. 중개사무소에 보관 의무.

**Q2. 전세 5억 원 계약의 중개보수 상한액은?**
> 5억은 6억 미만 구간 → 0.4%. 5억 × 0.4% = 200만 원.

**Q3. 이중계약서 작성 시 행정 처분과 형사 처벌은?**
> 행정: 등록 취소 (이후 3년간 재등록 금지). 형사: 3년 이하 징역 또는 3,000만 원 이하 벌금.

**Q4. 업무보증이란 무엇이고 목적은?**
> 중개사고 발생 시 의뢰인의 손해를 배상하기 위한 보증. 보증보험·공제·공탁 중 선택.
