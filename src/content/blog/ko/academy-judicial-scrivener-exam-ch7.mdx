## 부동산 등기 신청

```
등기 신청 원칙:
당사자 신청 원칙 (매도인+매수인 공동)
법원 촉탁 (판결·경매)
관공서 촉탁 (수용 등)

단독 신청:
보존등기
판결에 의한 등기
상속 등기
가등기 가처분 후 본등기

신청 방법:
방문 신청 or 전자 신청 (법무사 전자)
등기신청서 + 첨부서류

등기소:
부동산 소재지 관할 등기소
```

---

## 등기 심사와 이의

```
형식적 심사주의:
등기관은 서류 형식만 심사
실체 진위 확인 안함
공신력 없는 이유

등기 이의:
등기관 결정에 불복
관할 지방법원에 이의
이의 기각 시 항고

등기 각하:
신청 흠결 시 (서류 미비 등)
등기관이 각하 결정

직권 말소:
등기관이 직권으로 말소
등기 후 무효 사유 발견 시
```

## 주요 등기 유형

```
소유권보존등기:
토지대장·건축물대장 소유자
신규 취득 부동산

소유권이전등기:
매매·증여·상속·경매
원인증서 필수

근저당권설정등기:
채무자·근저당권자 공동 신청
채권최고액 등기

가등기:
청구권 보전 가등기
순위 보전 가등기
본등기 시 소급 효력

말소등기:
등기 원인 소멸 시
공동 신청 or 단독 (판결)
```

## 상업 등기

```
회사 설립:
정관 작성·공증 → 출자 이행 → 설립 등기
등기 완료 = 법인격 취득

주요 등기 사항:
상호·목적·자본금
임원 (대표이사·이사·감사)
지점·본점 이전

변경 등기:
변경 사유 발생 2주 이내
주소 이전·임원 변경 등

해산 등기:
해산 결의·법원 해산 명령
청산 완료 후 청산 종결 등기
```

## 핵심 개념 카드

**등기=공동신청 원칙** ★★★★★
: 등기권리자+등기의무자 공동 신청.
*암기 포인트: 등기=공동*

**회사등기=설립 완료 후 법인격** ★★★★★
: 등기 완료 시점에 법인격 취득.
*암기 포인트: 법인격=등기완료*

**형식적 심사=공신력 없음** ★★★★☆
: 등기관이 실체 심사 안하므로 공신원칙 불인정.
*암기 포인트: 형식심사=공신X*

## 실전 퀴즈

**Q. 가등기의 효력과 본등기와의 관계는?**
> 가등기: 본등기 순위 보전. 가등기 이후 다른 등기가 있어도 본등기 경료 시 소급 효력. 가등기→본등기 사이의 중간 등기는 직권 말소 가능. 매매예약에 의한 가등기가 가장 일반적. 담보 목적 가등기는 가등기담보법 적용.

**Q. 법무사의 등기 대리 업무와 변호사의 차이는?**
> 법무사: 등기 신청 대리 전문. 부동산·상업 등기, 공탁, 집행, 비송. 변호사: 등기 포함 모든 법률 사무. 법무사가 소송 대리는 불가 (변호사 영역). 가격 경쟁력과 등기 전문성 면에서 법무사가 강점. 대법원 등기 처리의 상당 부분 법무사.
