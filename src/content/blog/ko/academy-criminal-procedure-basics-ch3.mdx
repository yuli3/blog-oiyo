## 체포의 종류

```
영장 체포:
검사 청구 → 법관 영장 발부
체포 후 48시간 내 구속 영장 청구 또는 석방

현행범 체포:
영장 없이 가능
누구든 체포 가능
즉시 수사기관 인도

긴급 체포:
긴급성·중범죄 요건
영장 없이 체포 가능
체포 후 즉시 영장 청구
영장 기각 시 즉시 석방

체포 후 권리:
변호인 선임권 고지
가족 등 통지 의무
```

---

## 구속의 요건

```
구속 요건:
죄를 범했다고 의심할 상당한 이유
도주·증거 인멸 우려

구속 대상:
피의자 (수사 단계)
피고인 (공판 단계)

구속 기간:
수사: 경찰 10일 + 검사 10일 (연장 포함 최대 30일)
공판: 2개월 (갱신 가능, 최대 6개월)

구속 장소:
구치소·교도소
미결 구금: 형 집행 시 산입
```

---

## 구속적부심사·보석

```
구속적부심사:
구속 적법성 법원 심사
피의자·변호인·가족이 청구
결정: 석방 명령 or 청구 기각

보석:
피고인이 보증금 납부 후 석방
보석 허가 사유: 도주 우려 없음 등
필요적 보석: 경미 범죄·고령·중병

구속취소:
구속 이유 소멸 시 취소
검사·법원 직권 가능

불구속 수사 원칙:
구속은 예외 → 불구속 수사가 원칙
구속 필요성 엄격 해석
```

## 핵심 개념 카드

**긴급체포=체포후즉시영장청구** ★★★★★
: 긴급체포 후 영장 없이 계속 구금 불가.
*암기 포인트: 긴급체포=즉시영장*

**구속기간=수사30일최대** ★★★★★
: 경찰 10일+검사 연장 포함 최대 30일.
*암기 포인트: 수사구속=30일*

**구속적부심=피의자청구가능** ★★★★☆
: 피의자·변호인·가족도 청구 가능.
*암기 포인트: 구속적부심=피의자도*

## 실전 퀴즈

**Q. 긴급체포와 현행범 체포의 차이점은?**
> 현행범: 범죄 실행 중·직후. 누구든 체포 가능. 시간적 현장성 요건. 긴급체포: 중범죄 + 긴급성 (영장 받을 시간 없음). 수사기관만 가능. 체포 후 즉시 영장 청구 필수. 공통점: 영장 없이 가능. 차이: 긴급체포는 반드시 사후 영장 청구, 미발부 시 즉시 석방.

**Q. 구속적부심과 보석의 차이점은?**
> 구속적부심: 구속 자체의 위법·부당 여부 다툼. 피의자 단계에서 가능. 석방되면 구속 자체 취소. 보석: 구속의 적법성은 인정, 보증금 납부 후 석방. 피고인 단계 (공소 제기 후). 조건부 석방 (도주 시 보증금 몰수). 핵심: 구속적부심=구속위법다툼, 보석=조건부석방.
