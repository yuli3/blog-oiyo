## 시스템으로 보는 통신

정보통신 시스템은 단순히 케이블과 장비의 모음이 아닙니다. 정보를 만드는 단말, 신호를 실어 나르는 전송로, 경로를 선택하는 교환·중계 장치, 장애를 감시하는 운용 체계가 하나로 맞물립니다. 이 구조를 알면 과목이 나뉘어 보여도 실제 시험에서는 같은 흐름으로 연결됩니다.

### 구성 요소

| 구성 | 역할 |
|---|---|
| 단말 | 사용자 데이터 생성과 수신 |
| 전송로 | 유선·무선 매체를 통한 신호 전달 |
| 교환 | 목적지까지 경로 선택과 접속 제어 |
| 중계 | 거리와 품질 보완 |
| 운용관리 | 장애, 성능, 보안, 구성 관리 |

단말은 데이터를 만들고, 전송로는 신호를 이동시키며, 교환 장치는 어느 방향으로 보낼지 결정합니다. 중계 장치는 약해진 신호나 멀어진 거리를 보완하고, 운용관리 체계는 서비스가 끊기지 않도록 상태를 감시합니다.

## 장애와 품질

통신 시스템 문제는 “장비 이름”보다 “품질을 떨어뜨리는 원인”을 묻는 경우가 많습니다. 감쇠, 지연, 혼선, 패킷 손실, 장애 복구 같은 용어를 원인과 결과로 연결하세요. 예를 들어 감쇠는 신호 세기가 줄어드는 현상이고, 지연은 응답 시간과 체감 품질에 영향을 줍니다. 실기 대비에서는 장애 상황을 보고 어느 계층과 장비를 먼저 확인할지 말할 수 있어야 합니다.

## 핵심 요약

- 통신 시스템은 단말, 전송로, 교환, 중계, 운용관리의 결합입니다.
- 품질 문제는 감쇠, 지연, 손실, 장애 복구 관점으로 정리합니다.
- 장비 암기보다 데이터 흐름을 먼저 그리는 것이 중요합니다.
