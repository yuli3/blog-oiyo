## 직장을 그만두면 국민연금은 어떻게 되나?

직장을 퇴직하거나 사업을 그만두면 국민연금 납부가 중단됩니다. 이때 선택지가 생깁니다.

```
선택 1: 반환일시금 — 지금까지 낸 보험료 이자 붙여 돌려받기
선택 2: 임의가입 — 계속 납부해 나중에 연금으로 받기
선택 3: 임의계속가입 — 60세 이후에도 계속 납부하기
선택 4: 그냥 납부 중단 (나중에 수령 또는 추납)
```

---

## 반환일시금이란?

```
수령 조건:
1. 국민연금 가입 기간이 10년 미만 (연금 수령 자격 미충족)
2. 만 60세가 되어도 가입 기간 부족
3. 국적 상실 or 해외 이주
4. 사망 (유족이 수령)

수령 금액:
납입 보험료 + 이자 (국민연금 이자율 적용)
→ 이자율이 낮아 실질 수익 적음
```

---

## 반환일시금 수령이 유리한 경우

```
1. 당장 목돈이 필요한 경우
2. 건강 악화로 수명이 짧을 것으로 예상되는 경우
3. 이미 다른 연금(공무원·사학 연금)이 충분한 경우
4. 해외 이민이 확정된 경우
```

---

## 반환일시금 수령이 불리한 경우

```
반환일시금 수령 후 재가입 불가:
→ 일시금을 받으면 그 기간은 삭제됨
→ 나중에 재직 시 처음부터 다시 가입

수명이 길면 연금이 훨씬 유리:
→ 70세까지 살면? 월 연금 × 10년 > 일시금
→ 80세까지 살면? 월 연금 × 20년 = 훨씬 유리

→ 특별한 이유 없으면 받지 않는 게 유리
```

---

## 임의가입 — 가입 의무가 없지만 계속 납부

```
대상:
- 27세 미만 학생, 군인
- 전업주부 (소득 없는 배우자)
- 퇴직 후 소득 없는 60세 미만

보험료:
- 지역가입자 보험료와 동일
- 최소 납부: 월 9만원대 (2024년 기준 최저 소득 기준)
- 최대 납부: 본인 희망 소득 수준

→ 납부 기간 쌓여 나중에 더 많은 연금 수령
```

---

## 임의계속가입 — 60세 이후도 계속 납부

```
일반 국민연금: 만 60세 납부 종료
→ 임의계속가입: 만 65세까지 계속 납부 가능

대상:
- 만 60세 이상 64세 이하
- 국민연금 가입 기간이 10년 이상인 자
- 또는 수급 연령(만 63~65세)까지 연장 원하는 자

효과:
→ 납부 기간 늘어남 → 연금 수령액 증가
→ 소득이 없어도 자진 납부로 연금 늘리기 가능

보험료:
→ 퇴직 전 마지막 보수월액 기준 or 최저 기준 선택
```

---

## 임의계속가입이 유리한 이유

```
예시:
만 60세, 지금까지 가입 기간 25년, 예상 월 연금 50만원

임의계속가입 5년 추가 납부:
→ 가입 기간 30년
→ 예상 월 연금 60만원으로 증가

손익 분기점 계산:
추가 납부 5년치: 월 9만원 × 60개월 = 540만원
연금 증가분: 월 10만원

→ 540만원 ÷ 10만원 = 54개월 = 4.5년
→ 65세에 연금 시작 → 약 69.5세에 본전
→ 이후는 순수 이익
```

## 추납 (추후 납부) 제도

```
과거에 납부 안 한 기간을 나중에 소급 납부:

대상 기간:
- 가입 기간 중 납부 예외(실직, 사업 중단 등)
- 군 복무 기간 일부
- 경력 단절 기간

방법:
→ 국민연금공단에 추납 신청
→ 과거 보험료 소급 납부 (현재 기준 이자 없이)

효과:
→ 가입 기간 복원 → 연금 수령액 증가
→ 일시납 or 분할납 선택 가능
```

## 국민연금 수령 연령

```
출생 연도별 수령 시작 연령:
- 1952년생 이전: 만 60세
- 1953~56년생: 만 61세
- 1957~60년생: 만 62세
- 1961~64년생: 만 63세
- 1965~68년생: 만 64세
- 1969년생 이후: 만 65세
```

---

## 조기 수령 vs 연기 수령

```
조기 수령 (최대 5년 앞당김):
→ 수령 시작 연도마다 6% 감액
→ 5년 앞당기면 30% 감액 → 평생 적게 받음

연기 수령 (최대 5년 미룸):
→ 수령 시작 연도마다 7.2% 증액
→ 5년 미루면 36% 증액 → 평생 많이 받음

→ 수명이 길수록 연기 수령 유리
→ 조기 수령은 당장 소득 필요할 때만 고려
```

## 자주 묻는 질문

**Q. 반환일시금 받고 나중에 다시 가입할 수 있나요?**
A. 다시 취업하면 재가입 가능하지만, 일시금을 받은 기간은 없어집니다. 반환일시금은 신중히 결정하세요.

**Q. 전업주부도 임의가입이 가능한가요?**
A. 가능합니다. 소득이 없어도 최소 보험료(월 9만원대)부터 임의가입이 가능합니다.

**Q. 임의계속가입 중 돈이 필요하면 해지할 수 있나요?**
A. 임의계속가입은 언제든지 중단할 수 있습니다. 이미 납부한 기간은 유효하게 반영됩니다.

**Q. 추납하면 연금 수령액에 바로 반영되나요?**
A. 추납 처리 완료 후 가입 기간에 반영됩니다. 연금 수령 전이라면 반영된 기간으로 수령액이 재계산됩니다.
