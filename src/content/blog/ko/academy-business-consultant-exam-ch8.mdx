## 인적자원관리 체계

```
인적자원 계획:
수요 예측 vs 공급 예측
과부족 시 채용·교육·배치 조정

채용:
내부 모집: 승진·전환 배치
외부 모집: 공개 채용·헤드헌팅

선발:
서류→시험→면접→신체검사
타당성·신뢰성 확보

교육훈련:
OJT: 직무 중 훈련 (현장)
Off-JT: 직무 외 집합 교육
```

## 동기부여 이론

```
내용 이론:
Maslow 욕구 5단계: 생안사존자
Herzberg 2요인: 위생(불만제거)·동기(만족)
McGregor XY이론: X=통제, Y=자율

과정 이론:
Vroom 기대이론: 기대×수단×유의성
Adams 공정성이론: 투입·산출 비율 비교
목표설정이론: 구체적·도전적 목표

강화이론:
긍정적 강화: 보상으로 행동 반복
부정적 강화: 불쾌 제거로 행동 반복
벌: 행동 억제
```

## 리더십 이론

```
특성 이론:
리더 고유 특성 (지능·카리스마)

행동 이론:
Ohio 연구: 구조 주도·배려 (2차원)
Blake·Mouton: 관리 그리드

상황 이론:
Fiedler: 상황 유리·불리·리더 스타일
Hersey·Blanchard: 부하 성숙도 따라 리더 변화

변혁적 리더십:
비전 제시·영감·개인 배려
vs 거래적 리더십 (조건부 보상)
```

## 핵심 개념 카드

**Maslow=생안사존자** ★★★★★
: 생리→안전→사회→존경→자아실현.
*암기 포인트: 생안사존자*

**Herzberg=위생·동기 2요인** ★★★★★
: 위생요인(불만 제거)≠동기요인(만족 증가).
*암기 포인트: 위생=불만, 동기=만족*

**OJT vs Off-JT** ★★★★☆
: OJT=현장, Off-JT=집합교육.
*암기 포인트: OJT=On=현장*

## 실전 퀴즈

**Q. Herzberg의 2요인 이론에서 연봉을 올려도 동기부여 안 될 수 있는 이유는?**
> 급여·작업 조건은 위생요인. 위생요인은 결핍 시 불만족, 충족 시 불만 해소에 불과. 동기요인(성취감·인정·성장)이 있어야 진정한 동기부여. 연봉 인상은 단기 효과. 장기 동기는 직무 자체에서 나옴.

**Q. 360도 평가의 장점과 단점은?**
> 장점: 다각도 피드백, 상사 단독 평가 편향 감소, 팀워크·협업 역량 평가 가능. 단점: 친분·보복 등 왜곡, 시간·비용 소요, 결과 해석 어려움. 개발 목적에는 효과적, 보상 연계 시 왜곡 위험.
