## GRE 전 범위 핵심 공식 정리

| 섹션 | 핵심 전략 |
|------|---------|
| Verbal TC/SE | 전체 문맥 → 빈칸 예측 → 선택지 확인 |
| Verbal RC | 구조 파악 → 질문 이동 → Must be true |
| Quant QC | 특수값 테스트 (0, 1, 분수, 음수) |
| Quant PS | 역방향 풀이, 추정, 단순화 |
| AW Issue | 입장 → 2~3 이유 + 예시 → 반론 → 결론 |
| AW Argument | 결함 분석 (인과 오류, 성급한 일반화 등) |

## 점수 향상 집중 전략

### Verbal 158+ 목표
- **플래시카드**: 최소 500~1000단어 GRE 전용 어휘 암기
- **Magoosh GRE Vocabulary**: 가장 효과적인 어휘 앱
- **RC 속도 향상**: 매일 2개 지문 + 질문 풀기

### Quantitative 160+ 목표
- **QC 특수값 테스트** 자동화
- **수식 암기**: 이차 공식, 특수 삼각형, 원뿔·구 공식
- **타임 어택**: 실전보다 25% 빠른 속도로 연습

### AWA 4.5+ 목표
- **에세이 2~3개 미리 작성**: 실제 ETS 과제 목록에서 연습
- **채점 기준 내재화**: ETS 공식 채점 루브릭 숙지

## GRE 대학원 지원서 완성 전략

### Statement of Purpose (SOP) 핵심 요소

SOP는 GRE 점수만큼 중요한 지원서의 핵심입니다.

```
단락 1 (훅 + 연구 관심):
왜 이 분야인지를 보여주는 구체적 순간 또는 경험

단락 2~3 (연구/경험 배경):
관련 프로젝트·인턴십·논문의 구체적 성과

단락 4 (박사/석사 연구 계획):
구체적 연구 질문 또는 방향

단락 5 (이 학교에서 하고 싶은 이유):
특정 교수 + 프로그램의 구체적 자원

단락 6 (결론):
연구가 해당 분야에 기여할 방향
```

## GRE 시험 당일 전략

### 섹션 순서 선택
- AW → Verbal → Quantitative 순서가 일반적
- 자신이 가장 약한 섹션을 마지막에 배치 (피로도 고려)

### 시간 관리
- Verbal: 문항당 약 1.5분
- Quant: 문항당 약 1.75분
- AW: 아이디어 5분 + 작성 22분 + 검토 3분

## ScoreSelect 제도 활용

GRE는 **ScoreSelect**를 통해 지원 학교에 보낼 점수를 선택할 수 있습니다:
- 가장 최근 시험 성적
- 모든 시험 성적
- 본인이 선택한 특정 날짜 성적

최대 5회 응시 가능 (12개월 내), 평생 최대 응시 제한 없음.
