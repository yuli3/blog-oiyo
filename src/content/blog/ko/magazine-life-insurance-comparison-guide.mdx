## 사망 보장이 필요한 이유

```
가족이 있는 경우:
→ 내가 사망하면 배우자·자녀의 소득이 사라짐
→ 자녀 교육비, 주택 대출, 생활비 지원 불가

사망 보험의 역할:
→ 내가 없어도 가족이 일정 기간 생활할 수 있는 자금 확보
```

---

## 종신보험이란?

```
사망 시기에 관계없이 언제 사망해도 보험금 지급

보장 기간: 사망 시까지 (평생)
보험료: 비쌈 (오래 보장하므로)
해지환급금: 있음 (시간이 지날수록 증가)

특징:
- 사망이 확정된 보험 → 보험금 지급 확실
- 해지환급금이 납입 보험료와 비슷해지는 시점 있음
- 노후 현금이 필요할 때 해지 가능 (단, 손실 있을 수 있음)
```

---

## 정기보험이란?

```
특정 기간 내에 사망한 경우에만 보험금 지급

보장 기간: 10년·20년·30년 or 60세까지 등 정해진 기간
보험료: 매우 저렴 (일반 비교 1/5~1/10 수준)
해지환급금: 없음 or 거의 없음

특징:
- 보장 기간이 지나면 계약 종료
- 보험 기간 내 사망 없으면 보험금 지급 없음
- 보험료가 저렴해 같은 금액에 더 많은 보장 가능
```

---

## 보험료 비교 예시

```
[40세 남성, 사망 보험금 1억원]

종신보험 (80세 납입 기준):
→ 월 약 10만~15만원

정기보험 (20년 정기):
→ 월 약 1.5만~2.5만원

→ 정기보험이 약 5~8배 저렴
→ 절약한 보험료로 다른 자산 형성 가능
```

---

## 어느 것이 유리한가

### 정기보험이 유리한 경우

```
1. 자녀가 어리거나 부양가족이 있는 30~40대
   → 자녀 독립 시까지만 보장하면 충분
   → 20~30년 정기로 충분한 보장 확보
   
2. 보험료 부담이 큰 경우
   → 같은 돈으로 훨씬 높은 사망 보험금 확보 가능
   
3. 투자를 별도로 할 수 있는 경우
   → 절약된 보험료를 ETF·연금 등 투자에 활용
```

### 종신보험이 유리한 경우

```
1. 상속·증여 설계가 필요한 고자산가
   → 사망 보험금 = 법적 상속 재원
   
2. 종신 보장이 심리적으로 중요한 경우
   → 언제 사망해도 가족이 보험금 받는다는 안도감

3. 사업자 키맨 보험 목적
   → 핵심 인력 사망 시 사업 리스크 대비
```

## 변액종신보험 주의사항

```
변액종신보험:
→ 종신 보장 + 보험료 일부를 투자 (펀드 연계)

단점:
- 투자 결과에 따라 해지환급금 손실 가능
- 수익률이 낮으면 일반 종신보험보다 불리
- 사업비가 높아 장기 수익률 낮음

→ 투자 목적은 IRP·연금저축으로 별도 운용이 효율적
```

---

## 최적 조합 전략

```
30~40대 가장 (부양가족 있음):

1. 정기보험 (20~30년, 1~2억원): 월 2~4만원
   → 자녀 독립 전까지 가족 생계 보장

2. 암보험 + 실손보험: 월 5~7만원
   → 큰 의료비 대비

총 보장성 보험료: 월 7~11만원
vs 종신보험 단독 1억원: 월 10~15만원

→ 정기 + 건강 조합이 더 경제적이고 실질적
```

---

## 보험 해약 전 체크리스트

```
기존 종신보험이 있는 경우:
□ 해지환급금 현재 얼마인가?
□ 보험금 규모가 현재 가족 상황에 적합한가?
□ 납입 기간이 얼마나 남았는가?
□ 해지 후 재가입 시 나이·건강 문제로 불이익은?

→ 무조건 해지보다는 감액, 납입 유예 등 중간 옵션 검토
→ 보험 설계사가 아닌 중립적 재무 상담사 조언 권장
```

## 자주 묻는 질문

**Q. 종신보험을 해지하면 납입 보험료를 돌려받을 수 있나요?**
A. 일부만 돌려받습니다. 초기 수년간은 해지환급금이 납입 보험료보다 훨씬 적습니다. 20~30년 이상 유지한 경우에야 납입 보험료와 비슷한 수준이 됩니다.

**Q. 30세에 정기보험 20년을 가입하면 50세에 보장이 끊기지 않나요?**
A. 네, 50세에 계약이 종료됩니다. 하지만 자녀가 독립하는 50대에는 사망 보험 필요성이 줄어드는 경우가 많습니다. 필요하다면 만기 후 재가입을 검토하세요.

**Q. 사망 보험금은 세금이 붙나요?**
A. 수익자가 배우자나 자녀이면 상속세 과세 대상이 될 수 있습니다. 단, 피상속인이 계약자이고 수익자가 상속인이면 상속 재산에 포함되어 상속세 한도 내에서 비과세 가능합니다.
