# 금융투자소득세 계산기

주식·펀드·ETF 투자로 수익을 냈다면 금융투자소득세 납부 여부를 확인하세요.

## 금융투자소득세 구조

| 항목 | 내용 |
|---|---|
| 과세 대상 | 국내 주식·펀드·ETF·채권 등 |
| 기본 공제 | **연 5,000만원** |
| 세율 (공제 후 3억 이하) | **20%** |
| 세율 (공제 후 3억 초과) | **25%** |
| 지방소득세 포함 | ×1.1 (22% / 27.5%) |
| 신고 방법 | 다음 해 5월 종합소득세 신고 |

<Callout type="tip">
**기본 공제 5,000만원**: 1년 동안 모든 금융투자 손익을 합산해 순이익 5,000만원까지는 비과세입니다. 5,100만원 수익이면 100만원에만 세금이 부과됩니다.
</Callout>

## 손익 통산 예시

| 항목 | 금액 |
|---|---|
| A주식 수익 | +8,000만원 |
| B펀드 손실 | −1,000만원 |
| 순이익 합계 | 7,000만원 |
| 기본 공제 | −5,000만원 |
| **과세 대상** | **2,000만원** |
| **세금 (20%)** | **400만원** |

## 기존 과세와 비교

| 구분 | 기존 (대주주만) | 금투세 (전체) |
|---|---|---|
| 과세 기준 | 종목당 10억+ 보유 | 전체 투자자 |
| 기본 공제 | 없음 | 5,000만원 |
| 세율 | 20–30% | 20–25% |
| 손익 통산 | 불가 | 가능 |

<Callout type="note">
금융투자소득세는 도입 시기와 세부 규정이 정치적 논의에 따라 변경될 수 있습니다. 최신 세법을 확인하거나 세무사에게 문의하세요.
</Callout>
