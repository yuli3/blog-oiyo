## 직무분석

```
직무분석 정의:
직무의 내용·요건·특성을 체계적으로 조사

직무분석 목적:
채용·선발 기준 설정
교육훈련 내용 결정
성과평가 기준 개발
보상 체계 설계

직무분석 방법:
관찰법: 직접 관찰
면접법: 직무담당자·상사 인터뷰
설문지법: 표준화된 설문
중요사건기록법: 효과적·비효과적 행동 기록
```

---

## 직무기술서와 직무명세서

```
직무기술서 (Job Description):
직무 자체를 기술
직무 내용·책임·권한·환경
What → What is done

직무명세서 (Job Specification):
직무 수행에 필요한 인적 요건
학력·경험·기술·능력
Who → Who can do it

직위 vs 직무 vs 직군:
직위: 개인이 차지하는 위치
직무: 유사 과업의 묶음
직군: 유사 직무의 집합
```

---

## 직무설계 이론

```
과학적 관리론 (Taylor):
직무 단순화·표준화
효율 극대화
→ 단조로움·이직 증가 부작용

직무 확대 (Job Enlargement):
수평적 확대: 유사 과업 추가
단조로움 감소

직무 충실화 (Job Enrichment):
수직적 확대: 자율성·책임 증가
Herzberg 2요인 기반

직무 특성 이론 (Hackman·Oldham):
기술 다양성·과업 정체성·과업 중요성
자율성·피드백
→ MPS(동기 잠재력 점수)
```

## 직무평가

```
직무평가 목적:
직무 간 상대적 가치 결정
임금 체계 설계 기반

직무평가 방법:
서열법: 전체 직무 순서 정렬 (간단)
분류법: 등급 기준에 직무 분류
요소비교법: 핵심 요소별 직무 비교
점수법: 요소별 점수 합산 (가장 정확)
```

## 핵심 개념 카드

**직무기술서=직무내용, 직무명세서=인적요건** ★★★★★
: 기술서=What, 명세서=Who.
*암기 포인트: 기술서=직무, 명세서=사람*

**직무충실화=수직확대** ★★★★★
: 자율성·책임 증가 (확대=수평, 충실화=수직).
*암기 포인트: 충실화=수직*

**점수법=가장정확한직무평가** ★★★★☆
: 요소별 점수 합산, 객관성 높음.
*암기 포인트: 점수법=정확*

## 실전 퀴즈

**Q. 직무 충실화와 직무 확대의 차이는?**
> 직무 확대(수평): 동일 수준의 과업 추가. 단조로움 감소. 예: 조립 2단계 → 4단계 담당. 직무 충실화(수직): 계획·통제 권한 추가. 동기부여 효과 큼. 예: 직원이 작업 계획·품질 확인도 담당. Herzberg에 따르면 충실화만이 진정한 동기부여.

**Q. 직무평가가 임금 체계 설계에 중요한 이유는?**
> 직무 간 가치 차이를 객관적으로 산정. 같은 직급이라도 직무 난이도·책임 다름. 내부 공정성 확보: 더 어려운 직무 = 더 높은 임금. 외부 공정성: 시장 임금과 비교. 직무급(직무 가치 기반 임금)의 기초. 점수법이 가장 공정하나 시간·비용 많이 소요.
