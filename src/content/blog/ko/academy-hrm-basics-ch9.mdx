## 노사관계 기초

```
노사관계 당사자:
근로자·노동조합 ↔ 사용자·사용자단체
정부 (제3당사자)

노사관계 접근법:
unitarist: 경영자와 직원 이해 일치
pluralist: 이해 충돌 인정, 협상 필요
radical: 구조적 갈등 (마르크스)

단체교섭:
교섭 의무 사항: 임금·근로시간·안전
교섭 가능 사항: 경영 참여
교섭 불가 사항: 순수 경영권
```

## 숍 제도 — 조합 가입과 고용의 관계

노동조합 가입이 고용 조건과 얼마나 묶여 있는지에 따라 나뉜다. 조합의
교섭력이 왼쪽에서 오른쪽으로 갈수록 약해진다.

```
클로즈드 숍 (Closed Shop):
채용 전부터 조합원이어야 한다
조합이 사실상 채용을 통제한다 — 가장 강한 형태
한국에서는 허용되지 않는다

유니온 숍 (Union Shop):
채용은 자유롭지만 입사 후 일정 기간 내 가입해야 한다
탈퇴하면 해고 대상이 된다
한국에서 제한적으로 허용 (조직 대상 근로자 2/3 이상 대표 조합일 때)

에이전시 숍 (Agency Shop):
가입은 자유지만 비조합원도 조합비(대리비)를 낸다
"무임승차 방지"가 논리 — 교섭 성과는 비조합원도 누리기 때문
가입 강제는 없다

프리퍼렌셜 숍 (Preferential Shop):
채용·승진에서 조합원을 우대한다
비조합원도 고용될 수 있다 — 우대일 뿐 강제가 아니다

메인터넌스 숍 (Maintenance of Membership Shop):
가입은 자유지만, 일단 가입하면 협약 기간 중 탈퇴할 수 없다
조합원 수를 "유지"하는 데 목적이 있다

오픈 숍 (Open Shop):
가입 여부가 고용과 무관하다
조합의 교섭력이 가장 약한 형태
```

강도 순으로 한 줄

```
클로즈드 > 유니온 > 메인터넌스 > 에이전시 > 프리퍼렌셜 > 오픈
```

**핵심 구분**: 클로즈드는 **채용 전**, 유니온은 **채용 후** 가입 강제다.
에이전시는 **돈만** 걷고 가입은 강제하지 않는다.

## 인사관리 오답 포인트

```
① HRM 5기능 = 확개활유방 (채용만 아님)
② OJT = 현장, Off-JT = 집합 (혼동 금지)
③ Kirkpatrick = 반학행결 (4단계)
④ 직무기술서 = 직무 내용, 명세서 = 인적 요건
⑤ 타당성 없으면 신뢰성도 의미 없음
   (신뢰성은 타당성 필요조건)
⑥ 후광효과 = 하나가 전체에 영향
⑦ Maslow = 생안사존자 (사회→존경 순서)
⑧ Herzberg 급여 = 위생요인 (동기요인 아님)
⑨ 직무 충실화 = 수직 확대 (수평 아님)
⑩ 변혁적 리더십 = 비전·지적자극·개별배려·이상적영향
```

## 조직 행동 오답 포인트

```
⑪ Adams 공정성 = 투입/산출 비율 비교
⑫ Vroom = 기대×수단×유의성 (하나라도 0=동기0)
⑬ 목표설정 = 구체적+도전적 목표 (어렵지만 가능)
⑭ 변동비율 강화 = 가장 강력·소거에 강함
⑮ Lewin = 해빙→변화→재동결 (3단계)
```

## 핵심 개념 카드

**직무충실화=수직, 확대=수평** ★★★★★
: 충실화=권한·책임 추가, 확대=과업 수평 추가.
*암기 포인트: 충실=수직·확대=수평*

**Vroom 하나라도0=동기0** ★★★★★
: 기대·수단·유의성 모두 0 이상이어야.
*암기 포인트: Vroom=곱셈*

**노사관계=3당사자** ★★★★☆
: 근로자·사용자·정부.
*암기 포인트: 노사관계=3자*

## 실전 퀴즈

**Q. 직무분석이 인사관리의 기초인 이유는?**
> 직무분석 결과물(직무기술서·명세서)이 모든 HR 기능의 출발점. 채용: 직무명세서 → 선발 기준. 교육: 직무기술서 → 필요 훈련 내용. 평가: 직무 내용 → 평가 기준. 보상: 직무평가 → 임금 수준. 직무분석 없으면 HR 기능이 일관성 없게 됨.

**Q. 단체교섭과 단체협약의 차이는?**
> 단체교섭: 과정 (교섭 행위). 단체협약: 결과물 (서면 합의서). 협약의 규범적 효력: 근로조건은 협약이 최저 기준 → 개별 계약으로 불리하게 변경 불가. 협약의 채무적 효력: 당사자 간 의무 발생. 유효기간: 최장 2년.
