## 실용신안법

```
실용신안 대상:
물품의 형상·구조·조합에 관한 고안
특허보다 낮은 기술 수준

특허와 비교:
실용신안: 물품만 (방법·화합물 불가)
특허: 방법·물질·장치 모두 포함
존속기간: 실용신안=10년, 특허=20년

무심사 등록:
방식 심사 후 등록 (실체심사 없음)
후에 이의신청·무효심판으로 다툼
권리 불안정

이중 출원:
특허+실용신안 동시 출원 불가
하나 선택 후 조기 권리화 전략
```

## 상표법 — 기본 개념

```
상표 정의:
자기 상품·서비스를 타인 것과 구별하는 표장
기호·문자·도형·색채·소리·냄새·홀로그램

기능:
출처 표시 기능
품질 보증 기능
광고 기능

등록주의:
한국·일본 등 대부분 국가
먼저 등록한 자가 권리 취득

상표 출원:
특허청에 지정상품·서비스 표시
국제분류(니스분류) 45개 류
```

## 상표 등록 요건

```
절대적 거절 이유:
식별력 없는 표장 (기술적·보통명칭·관용)
공익 관련 표장 (국가명·국기·훈장)
공서양속 위반

상대적 거절 이유:
선등록·선출원 상표와 동일·유사
타인의 주지·저명 상표 (등록 여부 불문)
원산지 오인 우려

식별력 취득:
처음에 식별력 없어도 사용으로 취득 가능
(사용에 의한 식별력)
```

## 상표권 효력

```
존속기간:
출원일로부터 10년
갱신 무제한 → 영구 보호 가능

불사용 취소:
3년 이상 연속 불사용 → 취소 심판 가능
사용 입증 의무: 상표권자

사용의 정의:
지정상품에 상표 사용
포장·광고에 표시
```

## 핵심 개념 카드

**실용신안=물품10년, 특허=20년** ★★★★★
: 대상과 존속기간 구별 필수.
*암기 포인트: 실용신안=물품+10년*

**상표=10년+갱신무제한** ★★★★★
: 갱신하면 영구 보호 가능.
*암기 포인트: 상표=10년갱신*

**상표불사용취소=3년** ★★★★☆
: 3년 미사용 시 취소 심판 청구 가능.
*암기 포인트: 불사용=3년*

## 실전 퀴즈

**Q. 실용신안이 무심사 등록임에도 출원하는 전략적 이유는?**
> 빠른 권리화: 심사 생략으로 빨리 등록. 경쟁사 사전 차단. 단, 무효 위험 있음. 전략: 핵심 기술은 특허, 주변 기술은 실용신안. 등록 후 이의나 무효 청구 없으면 10년 유지. 특허 심사 대기 중 임시 보호 목적.

**Q. 상표 불사용 취소 심판에서 상표권자의 방어 방법은?**
> 사용 증거 제출: 지정상품 포장·광고·판매 기록. 사용 시기: 취소 심판 청구 전 3년 내 사용 입증. 광고만으로는 불충분 → 실제 상거래 사용 필요. 유사 상표 사용은 인정 안됨. 경쟁사 브랜드 잠식을 방어하는 핵심 수단.
