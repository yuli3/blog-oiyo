# 타로 오늘의 카드

타로카드는 14세기 유럽에서 기원한 78장짜리 카드 덱입니다. 그 중 **메이저 아르카나(Major Arcana) 22장**은 삶의 큰 흐름과 원형적 에너지를 상징합니다. 오늘 하루의 에너지를 한 장의 카드로 살펴보세요.

## 메이저 아르카나 22장

| 번호 | 카드 | 핵심 의미 |
|---|---|---|
| 0 | 바보 (The Fool) | 새로운 시작, 자유, 모험 |
| I | 마법사 (The Magician) | 의지, 창조력, 기술 |
| II | 여사제 (The High Priestess) | 직관, 내면의 지혜, 신비 |
| III | 여황제 (The Empress) | 풍요, 창조, 자연 |
| IV | 황제 (The Emperor) | 권위, 안정, 구조 |
| V | 교황 (The Hierophant) | 전통, 교육, 신념 |
| VI | 연인 (The Lovers) | 선택, 사랑, 가치관 |
| VII | 전차 (The Chariot) | 승리, 의지, 통제 |
| VIII | 힘 (Strength) | 용기, 인내, 내면의 힘 |
| IX | 은둔자 (The Hermit) | 성찰, 내면 탐구, 고독 |
| X | 운명의 수레바퀴 (Wheel of Fortune) | 변화, 순환, 운명 |
| XI | 정의 (Justice) | 공정, 진실, 균형 |
| XII | 매달린 사람 (The Hanged Man) | 관점 전환, 희생, 기다림 |
| XIII | 죽음 (Death) | 변환, 끝과 시작, 전환점 |
| XIV | 절제 (Temperance) | 균형, 조화, 인내 |
| XV | 악마 (The Devil) | 집착, 물질주의, 제약 |
| XVI | 탑 (The Tower) | 갑작스러운 변화, 붕괴, 계시 |
| XVII | 별 (The Star) | 희망, 영감, 치유 |
| XVIII | 달 (The Moon) | 환상, 불안, 무의식 |
| XIX | 태양 (The Sun) | 기쁨, 성공, 활력 |
| XX | 심판 (Judgement) | 부활, 각성, 새로운 부름 |
| XXI | 세계 (The World) | 완성, 통합, 성취 |

<Callout type="note">
타로는 신성하거나 예언적인 도구가 아닙니다. 심리학적 관점에서 타로는 **투사(Projection)** 도구로, 카드 이미지를 통해 내면의 생각과 감정을 탐색하는 데 활용됩니다. 결정에 타로를 맹목적으로 따르지 마세요.
</Callout>
