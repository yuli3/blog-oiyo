## 오행(五行)이란?

**오행(五行)**은 우주를 구성하는 다섯 가지 에너지 흐름입니다. 사주명리학에서 오행은 단순한 자연 현상이 아니라 **인간의 성격, 욕구, 행동 패턴**을 설명하는 심리적 언어입니다.

| 오행 | 상징 | 방향 | 계절 | 색상 |
|---|---|---|---|---|
| 목(木) | 나무, 성장 | 동 | 봄 | 청(靑) |
| 화(火) | 불, 열정 | 남 | 여름 | 적(赤) |
| 토(土) | 흙, 안정 | 중앙 | 환절기 | 황(黃) |
| 금(金) | 금속, 결단 | 서 | 가을 | 백(白) |
| 수(水) | 물, 지혜 | 북 | 겨울 | 흑(黑) |

## 오행별 심리 특성 완전 분석

### 🌱 목(木) 에너지 — 성장과 창의의 사람

목의 에너지는 **봄의 새싹처럼 위를 향해 뻗어나가는 힘**입니다.

**심리 특성:**
- 미래 지향적이고 성장을 추구
- 새로운 것을 시작하는 에너지가 넘침
- 이상주의적이고 원칙을 중요시
- 직선적이고 솔직한 표현

**목 에너지가 강한 사람의 특징:**
```
강점: 추진력, 리더십, 창의성, 정의감
약점: 고집, 융통성 부족, 때로 충동적
직업: 교육, 의료, 법조, 기획, 창업
```

**목 에너지 과다:**
- 지나친 완고함과 경직성
- 자신의 원칙에 맞지 않으면 쉽게 분노
- 타인의 도움을 받기 어려워함

**목 에너지 부족:**
- 추진력과 자신감 부족
- 시작은 잘 못 하지만 유연함이 강점
- 타인의 방향을 따르는 경향

---

### 🔥 화(火) 에너지 — 열정과 표현의 사람

화의 에너지는 **불꽃처럼 밝고 뜨거운 표현의 힘**입니다.

**심리 특성:**
- 감정이 풍부하고 표현력이 강함
- 사교적이고 사람을 끌어당기는 매력
- 현재를 중요시하고 즉흥적
- 인정받고 싶은 욕구가 강함

**화 에너지가 강한 사람의 특징:**
```
강점: 열정, 카리스마, 창의성, 낙천성
약점: 충동성, 산만함, 지속성 부족
직업: 연예, 교육, 마케팅, 리더십
```

**화 에너지 과다:**
- 쉽게 흥분하고 감정 기복이 큼
- 과도한 표현으로 타인을 지치게 함
- 번아웃에 취약

**화 에너지 부족:**
- 열정을 드러내기 어려움
- 차가운 인상을 줄 수 있음
- 내면의 따뜻함이 표현되지 않는 경우

---

### 🌍 토(土) 에너지 — 안정과 포용의 사람

토의 에너지는 **대지처럼 모든 것을 받아들이고 안정을 주는 힘**입니다.

**심리 특성:**
- 안정과 신뢰를 중요시
- 포용력과 인내심이 강함
- 현실적이고 실용적인 판단력
- 다른 사람의 중재자·연결자 역할

**토 에너지가 강한 사람의 특징:**
```
강점: 신뢰성, 포용력, 현실감, 인내
약점: 변화 저항, 과중한 책임감
직업: 경영, 부동산, 교육, 의료, 사회복지
```

**토 에너지 과다:**
- 지나친 안정 추구로 성장이 정체
- 변화에 극도로 저항
- 책임감이 지나쳐 스스로를 지치게 함

**토 에너지 부족:**
- 현실 감각이 부족
- 변화에는 유연하지만 안정감이 없어 보임
- 루틴을 만드는 데 어려움

---

### ⚔️ 금(金) 에너지 — 결단과 원칙의 사람

금의 에너지는 **쇠처럼 단단하고 날카로운 결단의 힘**입니다.

**심리 특성:**
- 원칙과 기준을 중요시
- 명확하고 직접적인 소통 스타일
- 불필요한 것을 잘라내는 결단력
- 완벽주의적이고 높은 기준 유지

**금 에너지가 강한 사람의 특징:**
```
강점: 결단력, 논리성, 정확성, 용기
약점: 냉정함, 타협 거부, 감정 표현 어려움
직업: 법조, 군인, 금융, 의료, 엔지니어
```

**금 에너지 과다:**
- 지나친 비판과 냉정함
- 타협을 거부하는 완고함
- 감정을 너무 억압

**금 에너지 부족:**
- 결단력과 추진력 부족
- 부드럽고 유연하지만 강하게 주장 못 함
- 중요한 순간에 우유부단

---

### 💧 수(水) 에너지 — 지혜와 적응의 사람

수의 에너지는 **물처럼 자유롭게 흐르며 모든 공간에 스며드는 지혜의 힘**입니다.

**심리 특성:**
- 지략이 뛰어나고 상황 파악이 빠름
- 자유와 변화를 선호
- 깊은 직관과 통찰력
- 적응력이 매우 강함

**수 에너지가 강한 사람의 특징:**
```
강점: 지혜, 적응력, 직관, 창의적 사고
약점: 방향 부재, 충동적, 무책임
직업: 전략, 연구, IT, 금융, 외교
```

**수 에너지 과다:**
- 지나친 자유 추구로 책임 회피
- 방향을 잡지 못하고 흩어짐
- 변화가 너무 많아 주변을 불안하게 함

**수 에너지 부족:**
- 지략보다 원칙에 의존
- 유연성 부족
- 새로운 상황에 적응이 느림

## 오행의 상생(相生)과 상극(相剋)

### 상생(相生): 서로 도와주는 관계

```
목 → 화: 목이 화를 키움 (나무가 불을 만듦)
화 → 토: 화가 토를 만듦 (재가 흙이 됨)
토 → 금: 토가 금을 품음 (땅이 금속을 품음)
금 → 수: 금이 수를 만듦 (금속에 물이 맺힘)
수 → 목: 수가 목을 키움 (물이 나무를 키움)
```

**인간 관계에서의 상생**: 내가 부족한 오행을 가진 사람이 나를 보완해줍니다.

### 상극(相剋): 서로 제어하는 관계

```
목 → 토: 목이 토를 극함 (뿌리가 흙을 파고듦)
토 → 수: 토가 수를 극함 (흙이 물을 막음)
수 → 화: 수가 화를 극함 (물이 불을 끔)
화 → 금: 화가 금을 극함 (불이 금속을 녹임)
금 → 목: 금이 목을 극함 (도끼가 나무를 자름)
```

## 나의 오행 균형 파악하기

사주 8글자(천간 4개 + 지지 4개)에서 각 오행이 몇 개인지 세어봅니다.

**이상적인 균형**: 5개 오행이 각각 1~2개씩 존재
**과다**: 특정 오행이 3개 이상
**부족**: 특정 오행이 0개

### 내 오행 불균형이 삶에 미치는 영향

| 상황 | 삶의 패턴 | 해결 방향 |
|---|---|---|
| 목 과다 | 지나친 원칙주의, 갈등 많음 | 유연성 기르기, 금 에너지 환경 |
| 화 과다 | 감정 기복, 번아웃 | 안정 루틴, 수 에너지 환경 |
| 토 과다 | 변화 저항, 고집 | 새로운 경험, 목 에너지 자극 |
| 금 과다 | 냉정함, 관계 갈등 | 공감 연습, 화 에너지 환경 |
| 수 과다 | 방향 없음, 불안정 | 목표 설정, 토 에너지 환경 |

<Callout type="tip">
**오행 균형 TIP**: 부족한 오행은 그 오행과 관련된 색상, 방향, 음식, 직업, 인간 관계로 보완할 수 있습니다. 완벽한 균형이 목표가 아니라, 자신의 에너지 패턴을 이해하는 것이 핵심입니다.
</Callout>
