## 2강 개요: 계약서 검토의 핵심 포인트

계약서는 분쟁이 생겼을 때 유일한 근거다. 그러나 법률 전문 용어가 가득한 계약서를 혼자 읽기는 쉽지 않다. AI는 계약서 검토에서 **비용 없는 1차 법무 검토자** 역할을 할 수 있다.

<Callout type="info">
**이 강의의 목표**: AI를 활용해 계약서의 핵심 위험 조항을 빠르게 파악하고, 협상 가능한 수정 포인트를 찾는 실전 역량을 갖춘다.
</Callout>

<Callout type="warning">
AI 계약서 검토는 **1차 스크리닝** 용도다. 고액 계약, 분쟁 소지가 있는 조항, 복잡한 법적 쟁점은 반드시 변호사 검토가 필요하다.
</Callout>

## 1. AI 계약서 검토의 강점과 한계

| 강점 | 한계 |
|---|---|
| 독소 조항 1차 식별 | 최신 판례·법령 반영 불완전 |
| 법률 용어 해설 | 개인 상황별 법적 판단 불가 |
| 표준 조항과 비교 | 계약 전략·협상 전술의 한계 |
| 24시간 즉시 검토 | 전문 법률 의견서 대체 불가 |

## 2. 독소 조항 찾기: 프롬프트 공식

### 기본 검토 프롬프트

```
프롬프트 예시:
"아래 프리랜서 용역 계약서를 검토해주세요.
다음 사항을 중점적으로 확인해 주세요:
1. 불리한 조항 또는 독소 조항
2. 모호하거나 해석이 분분할 수 있는 조항
3. 누락된 필수 조항
4. 수정을 요청할 수 있는 조항

[계약서 내용 붙여넣기]"
```

### 업종별 주의 조항

**IT·디자인 프리랜서**

| 주의 조항 | 위험 내용 | 요청할 수정 방향 |
|---|---|---|
| 저작권 양도 조항 | "결과물 일체의 저작권 갑에게 귀속" | 2차 저작물 사용 제한 명시 |
| 비경쟁 조항 | "계약 종료 후 2년간 동종 업계 취업 금지" | 기간 단축 또는 삭제 요청 |
| 하자 보수 조항 | "납품 후 1년간 무상 수정 의무" | 무상 수정 범위·횟수 명시 |
| 지연 배상 조항 | "지연 1일당 계약금의 1% 배상" | 상한선 설정 요청 |

**콘텐츠·강의 분야**

| 주의 조항 | 위험 내용 |
|---|---|
| 독점 제공 조항 | 동일·유사 콘텐츠 타사 제공 금지 |
| 영구 사용권 | 계약 종료 후에도 콘텐츠 사용 허용 |
| 수정 권한 조항 | 갑이 콘텐츠 내용을 임의 수정 가능 |

## 3. 계약서 초안 작성 AI 활용법

### 3-1. 표준 프리랜서 계약서 초안 요청

```
프롬프트 예시:
"웹 개발 프리랜서가 사용할 수 있는 
표준 용역 계약서 초안을 작성해주세요.
포함 항목:
- 용역 범위 및 산출물 명세
- 대금 지급 일정 (계약금 30%, 중도금 30%, 잔금 40%)
- 저작권 귀속 (개발자 귀속, 사용권 양도)
- 하자 담보 책임 (납품 후 30일, 명백한 결함에 한정)
- 계약 해지 조건
- 비밀유지 조항"
```

### 3-2. 불리한 조항 수정 요청 문구 생성

계약서의 불리한 조항을 발견했을 때, AI에게 **협상 문구**를 생성해달라고 할 수 있다.

```
프롬프트 예시:
"계약서에 '납품 후 1년간 무상 수정 의무' 조항이 있습니다.
이를 '납품 후 30일 이내, 계약 명세서에 명시된 기능 범위 내 
결함에 한해 무상 수정'으로 수정을 요청하는 
정중하고 전문적인 이메일 문구를 작성해주세요."
```

## 4. 주요 계약 조항 용어 해설

| 용어 | 의미 | 주의 사항 |
|---|---|---|
| **손해배상의 예정** | 손해 발생 시 미리 정한 금액 배상 | 과도한 금액은 법원에서 감액 가능 |
| **면책 조항** | 특정 상황에서 책임 면제 | "일체의 책임을 지지 않는다"는 과도한 면책 주의 |
| **일방적 계약 해지권** | 갑이 조건 없이 계약 해지 가능 | 사전 통보 기간·위약금 명시 필수 |
| **포괄적 저작권 양도** | 현재·미래 모든 저작권 이전 | "2차 저작물 작성권"까지 양도인지 확인 |
| **비경쟁·비유사 조항** | 동종 업계 활동 제한 | 기간·지역·범위 명확히 제한해야 유효 |

## 5. 계약서 검토 체크리스트

계약서에 서명하기 전 AI와 함께 다음 항목을 확인하자.

**필수 포함 여부 확인:**
- [ ] 계약 당사자 정보 (사업자등록번호 포함)
- [ ] 용역 범위 및 산출물 명세 (구체적)
- [ ] 대금 지급 일정 및 방법
- [ ] 저작권 귀속 조항
- [ ] 계약 해지 조건 및 절차
- [ ] 분쟁 해결 방법 (관할 법원)
- [ ] 비밀유지 조항

**독소 조항 점검:**
- [ ] 일방적으로 불리한 손해배상 조항
- [ ] 과도한 비경쟁 조항
- [ ] 포괄적 저작권 양도
- [ ] 무제한 수정 의무
