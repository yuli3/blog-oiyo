## 후보정이 필요한 이유

디지털 사진에서 후보정은 **선택이 아닌 필수**입니다. 카메라가 기록하는 이미지는 실제 눈으로 본 것과 다릅니다 — 특히 하이라이트와 섀도우 사이의 넓은 다이나믹 레인지를 디스플레이에 맞게 최적화하는 작업이 필요합니다.

후보정 = "현상실에서 인화하는 과정"의 디지털 버전

---

## RAW vs JPEG

가장 중요한 기초 선택입니다.

| 구분 | RAW | JPEG |
|------|-----|------|
| **파일 크기** | 20~50MB | 3~10MB |
| **화질** | 최고 (무손실) | 손실 압축 |
| **편집 여지** | 매우 넓음 | 제한적 |
| **화이트밸런스** | 자유롭게 수정 가능 | 제한적 |
| **노출 복구** | ±3~5 스톱 | ±1~2 스톱 |
| **카메라 처리** | 없음 (날 것 그대로) | 카메라가 자동 처리 |
| **즉시 사용** | 편집 소프트웨어 필요 | 바로 공유 가능 |

**결론**: 진지한 사진이라면 **RAW**, 빠른 공유가 목적이라면 **JPEG** (또는 RAW+JPEG 동시 촬영).

## Lightroom 기본 편집 워크플로우

### 작업 순서

```
1. 가져오기 (Import)
2. 선별 (Culling) — 별점·플래그로 좋은 사진 선택
3. 기본 보정 (Develop)
4. 색 보정 (Color Grading)
5. 세부 조정 (Detail)
6. 내보내기 (Export)
```

---

## 기본 패널 완전 정리

### 노출 관련 슬라이더

```
Exposure (노출): 전체 밝기 조절 (-5 ~ +5 스톱)
Highlights: 밝은 영역만 조절 (하늘, 흰 부분)
Shadows: 어두운 영역만 조절 (그늘, 어두운 피부)
Whites: 가장 밝은 부분 (클리핑 방지)
Blacks: 가장 어두운 부분 (깊은 검정 설정)
```

**기본 보정 전략**:
1. **Highlights 낮추기** → 날아간 하늘 복구
2. **Shadows 올리기** → 어두운 부분 디테일 살리기
3. **Blacks 낮추기** → 깊은 검정 만들기 (사진 입체감)
4. **Whites 올리기** → 전체 밝기 미세 조정

### Presence (질감과 명료도)

```
Texture: 중간 톤의 질감 강조 (피부 모공, 직물 결)
Clarity: 중간 톤 콘트라스트 강조 (또렷함)
Dehaze: 안개·헤이즈 제거 (풍경 사진에 효과적)
Vibrance: 채도 낮은 색을 선택적으로 강화 (자연스러운 채도)
Saturation: 전체 채도 조절 (주의해서 사용)
```

## 색 보정 (Color Correction)

### 화이트밸런스 수정

RAW 파일은 촬영 후에도 화이트밸런스를 **자유롭게 변경**할 수 있습니다.

```
Temp(온도) 슬라이더:
  왼쪽(낮음) → 파란빛 (차가운)
  오른쪽(높음) → 노란빛 (따뜻한)

Tint(틴트) 슬라이더:
  왼쪽(낮음) → 초록빛
  오른쪽(높음) → 마젠타빛
```

### HSL/Color 패널 (색상별 조정)

특정 색상만 선택해서 조정할 수 있는 강력한 도구입니다.

| 활용 예 | 방법 |
|---------|------|
| 하늘을 더 파랗게 | Blue Hue 조정, Blue Saturation 올리기 |
| 피부 톤 개선 | Orange Hue/Saturation/Luminance 미세 조정 |
| 초록 잔디 생동감 | Green Saturation 올리기 |
| 노을 강조 | Orange/Red Saturation 올리기 |

### 색조 곡선 (Tone Curve)

S자 곡선 적용으로 **콘트라스트와 색감**을 세밀하게 조정합니다.

```
기본 S자 커브:
  - 밝은 부분(상단) 올리기 → 하이라이트 밝게
  - 어두운 부분(하단) 낮추기 → 섀도우 어둡게
  결과: 콘트라스트 증가, 생동감 향상
```

**필름 룩**: 하단을 완전한 0(검정)이 아닌 약간 올려두면 밝은 검정 → 필름 느낌

## 세부 조정 (Detail)

### 노이즈 제거

```
Noise Reduction:
  Luminance: 밝기 노이즈 제거 (주로 이 설정)
  → 30~50 정도 적용
  → 너무 높으면 디테일 손실 (뭉개짐)
  
  Color: 색 노이즈 제거 (컬러 얼룩)
  → 25~40 정도 적용
```

### 선명도 (Sharpening)

```
Sharpening:
  Amount: 선명도 강도 (60~80 권장)
  Radius: 선명화 적용 반경
  Detail: 세부 디테일 보호
  Masking: 특정 영역만 선명화 (엣지 감지)
  → Alt 키 누르며 Masking 조정: 흰 부분만 선명화됨
```

> **원칙**: 노이즈 제거와 선명화는 서로 반대 효과 — 균형 조절이 중요합니다.

## 크롭과 수평 조정

### 크롭(자르기)

```
일반 크롭: R 키 → 원하는 비율로 크롭
  - 자유: 자유로운 비율
  - 1:1: 정사각형 (인스타그램)
  - 4:3, 16:9: 화면 비율
  - 2:3: 35mm 필름 비율 (기본)
```

### 수평 조정

수평이 맞지 않는 사진은 자동 수평 조정 또는 수동으로 회전합니다.

```
Level 도구로 수평선이나 수직선을 드래그 → 자동 수정
Angle 슬라이더로 미세 조정
```

## 내보내기 (Export)

| 목적 | 권장 설정 |
|------|----------|
| 인쇄 | JPEG, 300dpi, sRGB 또는 AdobeRGB |
| 웹·SNS | JPEG, 72dpi, sRGB, 장변 2400px |
| 아카이브 | TIFF 또는 DNG (원본 보존) |

## 편집 전후 비교 워크플로우 예시

**풍경 사진 1분 보정 레시피**:

```
1. Highlights -60 (하늘 복구)
2. Shadows +50 (전경 살리기)
3. Blacks -30 (깊이감)
4. Clarity +15 (선명도)
5. Dehaze +10 (안개 제거)
6. Blue Saturation +20 (하늘 강화)
7. Green Hue 약간 조정 (잔디 자연스럽게)
```

## 실전 퀴즈 5문항

**Q1.** RAW 파일의 가장 큰 장점은?
- ① 파일 크기가 작다
- ② 화이트밸런스와 노출을 촬영 후 자유롭게 수정 가능
- ③ 즉시 SNS에 공유 가능
- ④ 카메라가 자동으로 최적화한다

**정답**: ②

---

**Q2.** Highlights 슬라이더를 낮추면 주로 어떤 효과가 있는가?
- ① 어두운 부분이 밝아진다
- ② 날아간 하늘·흰 부분을 복구한다
- ③ 전체 밝기가 낮아진다
- ④ 색 채도가 감소한다

**정답**: ②

---

**Q3.** 고ISO로 촬영한 사진에서 색깔 얼룩이 생겼다면 어떤 슬라이더로 해결하는가?
- ① Clarity
- ② Luminance Noise Reduction
- ③ Color Noise Reduction
- ④ Sharpening

**정답**: ③

---

**Q4.** 곡선(Tone Curve)에서 S자 커브를 적용하면?
- ① 사진이 전체적으로 어두워진다
- ② 콘트라스트가 증가한다
- ③ 채도가 올라간다
- ④ 노이즈가 제거된다

**정답**: ②

---

**Q5.** 웹/SNS용 내보내기 시 가장 적합한 해상도(dpi)는?
- ① 72dpi  ② 150dpi  ③ 300dpi  ④ 600dpi

**정답**: ① *(웹은 72dpi, 인쇄는 300dpi)*
