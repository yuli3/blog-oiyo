앨버트 메라비안(Albert Mehrabian)의 연구에 따르면 감정과 태도를 전달할 때, 말의 내용은 7%, 목소리 톤은 38%, **비언어적 신호(바디랭귀지)**는 55%를 차지합니다. 우리는 말보다 훨씬 더 많은 것을 몸으로 표현하고 있습니다. 이 가이드에서는 일상에서 마주치는 주요 바디랭귀지 신호들을 분석합니다.

<Callout type="info">
**중요한 주의사항**: 바디랭귀지는 맥락(Context)이 중요합니다. 팔짱을 끼는 것이 "방어적"일 수도 있지만, 단순히 춥거나 편해서일 수도 있습니다. 하나의 신호만으로 판단하지 말고 전체적인 패턴을 봐야 합니다.
</Callout>

## 눈과 시선

### 눈 맞춤

| 신호 | 의미 |
|------|------|
| **자연스러운 눈 맞춤** (60~70%) | 자신감, 진정성, 관심 |
| **과도한 응시** (100%) | 위협, 지배, 집착 |
| **눈 맞춤 회피** | 불안, 거짓말, 복종, 또는 문화적 존중 |
| **자주 깜빡임** | 불안, 긴장 |
| **천천히 깜빡임** | 이완, 침착 |

### 동공

- **확장된 동공**: 관심, 각성, 또는 어두운 환경
- **수축된 동공**: 불쾌, 긴장, 또는 밝은 환경

### 시선 방향 (주의: 과학적 근거 제한적)

| 시선 방향 | 일부 주장 |
|---------|--------|
| 위 왼쪽 | 기억 구성 (시각적) |
| 위 오른쪽 | 새로운 이미지 창조 |
| 아래 왼쪽 | 내적 대화 |
| 아래 오른쪽 | 감정 |

## 표정 (Facial Expressions)

폴 에크먼의 연구: 7가지 기본 감정은 문화를 초월하여 동일한 표정으로 나타납니다.

### 7가지 보편적 표정

| 감정 | 주요 근육 신호 |
|------|-------------|
| 행복 | 눈꼬리 올라감, 눈 주름, 입꼬리 상승 |
| 슬픔 | 눈썹 안쪽 모임, 입꼬리 내려감 |
| 분노 | 눈썹 내려옴, 눈 좁아짐, 이 물림 |
| 두려움 | 눈썹 올라가고 모임, 눈 크게 열림 |
| 놀람 | 눈썹 크게 올라감, 입 벌어짐 |
| 혐오 | 코 주름, 윗입술 올라감 |
| 경멸 | 한쪽 입꼬리만 올라감 |

### 미세 표정 (Microexpressions)

1/25초 미만으로 나타나는 무의식적 표정. 숨기려는 진짜 감정을 드러냅니다. 전문적인 훈련으로 인식 가능합니다.

## 자세와 몸 방향

### 열린 자세 vs 닫힌 자세

**열린 자세** (자신감, 개방성):
- 팔은 양옆으로 이완
- 몸을 상대방 쪽으로 기울임
- 손바닥 보임
- 가슴을 펴고 등을 세움

**닫힌 자세** (방어, 불안):
- 팔짱
- 몸을 뒤로 물러남
- 다리를 꼬거나 붙임
- 어깨 움츠림

### 파워 포즈 (Power Pose)

에이미 커디의 연구(일부 논란 있음): 2분간 파워 포즈를 취하면 자신감이 높아집니다.

**파워 포즈**: 두 다리를 벌리고 손은 허리에, 상체를 펴는 자세

### 위치 관계

- **상대와 같은 높이**: 동등한 관계
- **상대보다 높음**: 권위, 지배
- **상대보다 낮음**: 복종, 겸손
- **상대 옆에 앉기**: 협력적
- **상대 맞은편에 앉기**: 경쟁적 또는 공식적

## 팔과 손 제스처

### 팔짱

| 상황 | 해석 |
|------|------|
| 대화 중 갑자기 팔짱 | 방어적으로 변함 |
| 처음부터 팔짱 | 추울 수도, 습관일 수도 |
| 팔짱 + 주먹 쥠 | 적대적 방어 |
| 팔짱 + 미소 | 단순한 편안한 자세 |

### 손 위치

| 제스처 | 의미 |
|--------|------|
| **손바닥 위로** | 개방성, 진실성 |
| **손바닥 아래로** | 권위, 억제 |
| **뾰족 손가락** | 지시, 강조 (종종 공격적) |
| **손 감추기** | 긴장, 숨김 |
| **목 만지기** | 불안, 불편함 |

### 악수

| 악수 방식 | 의미 |
|---------|------|
| **손바닥 아래로** | 지배적 |
| **손바닥 위로** | 복종적 |
| **양손 악수** | 따뜻함, 진정성 |
| **너무 강한 악수** | 지배력 과시 |
| **너무 약한 악수** | 자신감 부족 |

## 다리와 발

다리와 발은 가장 덜 통제되는 신체 부위입니다. 진실된 감정이 드러나는 경우가 많습니다.

| 신호 | 의미 |
|------|------|
| **발이 문을 향함** | 나가고 싶음 |
| **발이 상대를 향함** | 관심, 호감 |
| **다리를 심하게 흔들기** | 불안, 긴장 |
| **다리를 꼬고 상대 쪽으로** | 관심 |
| **다리를 꼬고 반대쪽으로** | 차단, 불편함 |

## 미러링 (Mirroring)

상대방의 바디랭귀지를 무의식적으로 따라 하는 현상입니다.

**의미**: 미러링은 긍정적 관계와 공감의 신호입니다. 대화 중 상대방이 당신의 자세를 따라 한다면, 그들이 당신과 연결되어 있다는 신호입니다.

**활용**: 좋은 관계를 구축하고 싶다면 자연스럽게 상대의 속도, 톤, 자세를 따라가 보세요.

## 첫인상 관리 전략

첫인상은 0.1초 만에 결정되며, 이것이 이후 모든 판단에 영향을 미칩니다.

**긍정적 첫인상을 만드는 바디랭귀지**:
1. **자신감 있는 자세**: 어깨를 펴고 등을 세우기
2. **적절한 미소**: 눈꼬리까지 올라가는 진짜 미소
3. **눈 맞춤**: 60~70%의 자연스러운 눈 맞춤
4. **안정된 악수**: 적당한 힘과 2~3초
5. **몸 방향**: 상대를 향해 몸을 기울이기

<Callout type="tip">
**취업 면접 팁**: 면접관과의 미러링을 자연스럽게 활용하세요. 면접관이 앞으로 기울이면 당신도 기울이고, 속도를 맞추면 "우리는 잘 맞는다"는 무의식적 인상을 줄 수 있습니다.
</Callout>
