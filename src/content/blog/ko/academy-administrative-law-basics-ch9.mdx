## 공무원 제도의 의의

**공무원**: 국가 또는 지방자치단체와 공법상 근무 관계에 있는 자.

```
공무원법 체계:
국가공무원법 (국가 공무원)
지방공무원법 (지방 공무원)
특별법: 교육공무원법, 경찰공무원법, 군인사법 등
```

---

## 공무원의 분류

### 경력직 vs 특수경력직

```
경력직 공무원 (직업 공무원):
- 일반직: 행정·기술·관리운영직
- 특정직: 법관·검사·경찰·군인·교원 등

특수경력직 공무원:
- 정무직: 선거·국무총리·장관 등
- 별정직: 특수 업무
```

**직업공무원제 원칙**: 신분 보장, 정치적 중립.

---

## 공무원의 의무

### 주요 의무

```
성실 의무: 법령 준수, 맡은 직무에 최선 (가장 기본적)
복종 의무: 직무상 상관의 명령 복종
           위법 명령 → 복종 거부 가능 (취소·무효 명령)
친절·공정 의무: 국민에게 친절하고 공정하게
비밀 엄수 의무: 재직 중·퇴직 후에도 직무상 비밀 유지
청렴 의무: 직무 관련 부당 이익 수수 금지
정치적 중립: 특정 정당·정치단체 가입·활동 금지
품위 유지 의무: 직위 품위에 맞는 행동
```

### 영리 행위 금지

```
겸직 금지:
- 직무와 관련 있는 영리 기업 임직원 겸직 불가
- 허가 없이 다른 직무 겸직 불가

주식 보유 제한 (공직자 윤리법):
- 고위공직자: 3,000만 원 초과 주식 보유 시 매각 또는 백지신탁 의무
```

## 징계

### 징계의 종류

```
국가공무원법 징계 6종류:
파면 | 해임 | 강등 | 정직 | 감봉 | 견책

중한 순서: 파면 > 해임 > 강등 > 정직 > 감봉 > 견책
```

| 징계 | 내용 | 특이사항 |
|------|------|---------|
| 파면 | 공무원 신분 박탈 | 5년 재임용 금지, 퇴직금 감액 |
| 해임 | 공무원 신분 박탈 | 3년 재임용 금지 |
| 강등 | 직급 1단계 하락, 3개월 정직 | |
| 정직 | 1~3개월 직무 정지, 보수 전액 삭감 | |
| 감봉 | 1~3개월 보수 1/3 삭감 | |
| 견책 | 경고 성격 | 가장 가벼운 징계 |

### 징계 절차

```
징계 절차:
징계 사유 발생 → 징계의결 요구 (임용권자)
            → 징계위원회 심의·의결
            → 징계 처분
            → 당사자에게 통보
```

### 징계 불복

```
징계 처분에 불복:
소청심사위원회 청구 (처분 안 날로부터 30일 내)
  ↓
소청 기각 → 행정 법원 소송 (3개월 내)
```

## 공무원의 신분 보장

**신분 보장의 원칙**: 직업공무원제 → 의사에 반한 불이익 처분 금지.

```
불이익 처분 사유:
- 징계 (위원회 의결 필요)
- 직권 면직 (법정 사유 있을 때만)

직권 면직 사유:
- 잉여 인원 (직제·정원 개편)
- 휴직·직위해제 후 복귀 불가
- 직무 불성실
```

## 핵심 개념 카드

**징계 6종류 순서** ★★★★★
: 파면>해임>강등>정직>감봉>견책. 파면·해임은 공무원 신분 박탈.
*암기 포인트: 파해강정감견 (파해강정감견)*

**파면 vs 해임 차이** ★★★★★
: 파면 5년 재임용 금지+퇴직금 감액. 해임 3년 금지. 둘 다 공무원 신분 박탈.
*암기 포인트: 파면 5년, 해임 3년 재임용 금지*

**비밀 엄수 의무** ★★★★☆
: 재직 중뿐 아니라 퇴직 후에도 의무 존속. 직무상 알게 된 비밀 누설 금지.
*암기 포인트: 비밀 엄수 = 퇴직 후에도 계속*

## 실전 퀴즈

**Q. 공무원이 상관의 위법한 명령을 받았을 때 어떻게 해야 하는가?**
> 위법·무효인 명령은 따를 의무 없음 (복종 의무의 한계). 명백한 위법 명령 거부 가능. 단, 적법성 판단이 어려운 경우 이의를 제기하되 일단 복종.

**Q. 정직과 직위해제의 차이는?**
> 정직: 징계 처분 (1~3개월, 보수 전액 삭감). 직위해제: 직무 배제 (징계 아님, 징계 절차 진행 중 직무 배제 수단, 보수는 일부 지급).
