## 심리학의 핵심 원칙 재확인

```
원칙 1: 행동에는 원인이 있다
→ 충동적으로 보이는 행동도 생물·심리·사회적 요인의 산물

원칙 2: 유전과 환경은 모두 중요하다
→ Nature vs Nurture → 이제는 Nature AND Nurture
→ 유전자는 가능성이고, 환경이 그 가능성을 현실화

원칙 3: 과학적 방법만이 미신을 구별한다
→ 무작위 대조 실험 > 개인 사례 > 직관

원칙 4: 인간은 인지 편향에 취약하다
→ 시스템 1의 빠른 판단을 의심하는 습관이 필요
```

## 관계에서의 심리학

### 호감과 매력

```
근접 효과: 가까이 있을수록 호감 증가
단순 노출 효과: 자주 볼수록 좋아진다
유사성: 비슷한 사람에게 끌린다
상호성: 좋아해 주면 좋아하게 된다

스턴버그의 사랑의 삼각형:
→ 열정 + 친밀감 + 헌신 = 완전한 사랑
→ 세 요소의 균형이 관계의 질 결정
```

### 갈등 해결

```
고트만의 연구 — 이혼을 예측하는 4개의 기수:
1. 비판: 성격·인격 공격
2. 경멸: 냉소, 비아냥
3. 방어: 자기변명, 반격
4. 담쌓기: 감정적 철수

→ 경멸이 가장 독성 강함
→ 비판 대신 "나" 메시지 사용
```

## 직장에서의 심리학

### 동기 부여

```
내재적 동기 vs 외재적 동기:
→ 과도한 외적 보상은 내재적 동기 감소 (과잉 정당화 효과)

심리적 안전감 (에이미 에드먼슨):
→ 팀 내에서 실수해도 안전하다는 느낌
→ 혁신과 학습의 전제 조건
→ 구글 프로젝트 아리스토텔레스: 팀 성과 1위 요인

몰입 (Csikszentmihalyi):
→ 도전 = 능력 수준일 때 최고 생산성
→ 명확한 목표 + 즉각적 피드백 필요
```

### 의사결정

```
집단 사고 방지:
→ 악마의 변호인 지정
→ 다양한 관점 의도적 수집
→ 익명 투표 활용

확증 편향 극복:
→ 반증 가설 설정 ("내 아이디어가 틀렸다면?")
→ 사전 부검 (Premortem): 실패를 미리 상상
```

## 건강과 심리학

```
스트레스와 건강:
셀리에의 GAS (일반 적응 증후군):
경보 → 저항 → 소진

코르티솔 만성 상승 → 면역 저하, 기억 손상

심리신경면역학:
→ 마음 상태가 면역 기능에 직접 영향
→ 긍정 정서 → NK세포 활성화

회복탄력성 강화:
→ 사회적 지지 망 구축
→ 의미 찾기 (로고테라피)
→ 마인드풀니스 실천
```

## 심리학 공부를 마치며

심리학은 인간을 이해하는 도구입니다.

```
심리학이 줄 수 있는 것:

자기 이해:
→ 내 감정·행동 패턴의 원인을 이해
→ 변화 가능성을 인식

타인 이해:
→ 판단 줄이기
→ 행동 뒤에 숨은 맥락 보기

더 나은 결정:
→ 인지 편향 인식 → 더 이성적 판단
→ 집단 역학 이해 → 더 좋은 팀원

회복탄력성:
→ 스트레스·역경을 성장의 기회로
→ 과학적으로 증명된 행복 전략 실천
```

*인간을 이해한다는 것은 곧 자신을 이해하는 여정입니다.*
