## 재정정책

```
재정정책: 정부 지출·세금으로 경제 조절

확장적 재정정책:
정부 지출 증가 or 감세
→ 총수요 증가 → GDP 증가 → 고용 증가
→ 경기침체 시 사용

긴축 재정정책:
정부 지출 감소 or 증세
→ 총수요 감소 → 물가 억제
→ 과열 경기 시 사용
```

### 승수 효과 (Multiplier Effect)

```
케인즈 승수:
정부 지출 1원 → GDP 1/MPS 원 증가
MPS = 한계저축성향 = 1 - MPC

예) MPC = 0.8 → MPS = 0.2
승수 = 1/0.2 = 5
정부 지출 100조 → GDP 500조 증가

조세 승수:
감세 1원 → GDP MPC/MPS원 증가 = 4원 (MPC=0.8)
→ 정부 지출보다 효과 작음
```

이 승수는 정액세, 물가·이자율 불변, 유휴 생산능력, 해외부문 부재를 둔 단순 케인즈 모형의 값입니다. 현실에서는 조세·수입 누출, 물가와 금리 반응, 정책 시차 때문에 실제 GDP 변화가 이 산식과 다를 수 있습니다.

### 구축 효과 (Crowding Out)

```
구축 효과:
정부 지출 증가 → 국채 발행 → 금리 상승
→ 민간 투자 감소 → 재정정책 효과 반감

통화정책과 조합:
확장 재정 + 금리 유지 → 구축 효과 최소화
```

## 환율

```
환율: 두 나라 통화의 교환 비율

원/달러 환율 표시:
1달러 = 1,200원

환율 상승 (원화 절하/달러 강세):
→ 외화표시 수출가격 하락·원화표시 수입가격 상승 압력
→ 수출입 물량 반응은 가격탄력성·계약통화·생산능력 등에 따라 달라짐
→ 무역수지 개선에는 마셜-러너 조건과 조정시간을 확인

환율 하락 (원화 절상/달러 약세):
→ 위 경로의 반대 압력이 생기지만 수출입 물량과 경상수지가 반드시 같은 방향으로 변하는 것은 아님

환율 결정 요인:
- 수요공급 (외화 수급)
- 금리 차이 (고금리국 통화 강세)
- 물가 (구매력 평가설)
- 국제수지
- 기대·투기
```

## 비교우위와 무역

```
절대우위: 동일 재화를 더 적은 자원으로 생산
비교우위: 기회비용이 상대적으로 낮은 재화 생산

비교우위 원리 (리카도):
양국이 비교우위 있는 재화에 특화·무역
→ 양국 모두 이익

예시:
      TV(시간) 의류(시간)  의류/TV 기회비용
한국     2        1         0.5
미국     4        3         0.75

한국: 의류 기회비용 0.5 < 미국 0.75 → 의류 비교우위
미국: TV 기회비용 4/3 < 한국 2 → TV 비교우위

한국=의류 특화 수출, 미국=TV 특화 수출 → 양국 이익
```

## 국제수지

```
국제수지 구성:
경상수지:
  - 상품수지 (수출 - 수입)
  - 서비스수지 (관광·운수·금융)
  - 본원소득수지 (임금·배당)
  - 이전소득수지 (원조·송금)

자본수지:
  - 자본이전
  - 비생산·비금융자산의 취득·처분

금융계정:
  - 직접투자·증권투자·파생금융상품·기타투자
  - 준비자산

경상수지 흑자:
수출 > 수입 → 외화 유입 → 원화 절상 압력
```

## 핵심 개념 카드

**케인즈 승수** ★★★★★
: 승수=1/MPS=1/(1-MPC). MPC=0.8이면 승수=5. 정부지출×승수=GDP 증가.
*암기 포인트: 승수=1÷(1-MPC)*

**비교우위=기회비용 낮은 것** ★★★★★
: 절대우위 없어도 기회비용 낮은 재화에 특화하면 무역 이익. 리카도 이론.
*암기 포인트: 비교우위=기회비용 낮은 곳 특화*

**환율 상승=원화 절하 압력** ★★★★☆
: 원/달러 환율 상승은 원화 가치 하락을 뜻합니다. 수출입 물량과 무역수지는 탄력성·계약·시차 조건을 함께 봅니다.
*암기 포인트: 환율 방향과 무역수지 결과를 분리*

## 실전 퀴즈

**Q. MPC = 0.75인 경제에서 정부가 60조 원 지출 증가 시 GDP는 얼마나 늘어나는가?**
> 승수 = 1/(1-0.75) = 1/0.25 = 4. GDP 증가 = 60조 × 4 = 240조 원.

**Q. 원/달러 환율이 1,200원 → 1,400원으로 상승했다. 이것이 의미하는 바는?**
> 원화 가치 절하 (달러 강세). 한국 수출품 가격 하락 → 수출 경쟁력 향상. 수입품 가격 상승 → 수입 감소. 단기적으로 J커브 효과로 경상수지 즉각 개선 안 될 수 있음.
