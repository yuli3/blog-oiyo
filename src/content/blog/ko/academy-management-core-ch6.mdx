## 생산관리란

**생산관리(Operations Management)**는 제품이나 서비스를 효율적으로 창출하기 위해 자원과 프로세스를 계획·조직·통제하는 활동입니다.

제조업만의 이야기가 아닙니다. 병원의 환자 처리, 콜센터의 상담 처리, 식당의 주문-조리-서빙 — 모두 운영 관리의 영역입니다.

**생산관리의 핵심 목표**:
- **품질(Quality)**: 고객 기대를 충족하는 제품·서비스
- **비용(Cost)**: 경쟁력 있는 원가 구조
- **속도(Speed)**: 빠른 납기와 대응력
- **유연성(Flexibility)**: 수요 변화에 적응하는 능력

---

## 생산 시스템 유형

| 유형 | 특징 | 예시 |
|------|------|------|
| **프로젝트형** | 단일 품목, 일회성 | 건물 시공, 영화 제작 |
| **잡샵(Job Shop)** | 소량 다품종, 주문 생산 | 맞춤 제작 공장 |
| **배치(Batch)** | 중간 규모, 반복 생산 | 인쇄소, 제과점 |
| **연속(Continuous)** | 대량 표준화, 흐름 생산 | 자동차 조립 라인 |
| **연속 공정** | 24시간 중단 없음 | 정유소, 철강 |

## 품질 관리

### TQM (Total Quality Management)

전사적 품질 관리. 품질을 "검사 단계"에서 잡는 것이 아니라 **전체 프로세스에 내재**시킵니다.

**에드워즈 데밍(W. Edwards Deming)**의 14가지 원칙 중 핵심:
- 품질은 경영진의 책임
- 공포를 제거하고, 아이디어를 자유롭게
- 지속적 개선 (PDCA 사이클)

**PDCA 사이클**:
1. **Plan**: 문제 정의, 목표 설정
2. **Do**: 소규모 파일럿 실행
3. **Check**: 결과 측정 및 분석
4. **Act**: 성공 시 표준화, 실패 시 재계획

### 6시그마 (Six Sigma)

불량률을 100만 개당 3.4개 이하(6σ)로 줄이는 품질 혁신 방법론. GE의 잭 웰치가 도입하여 세계적으로 보급.

**DMAIC 프로세스**:
- Define (정의): 문제와 목표 정의
- Measure (측정): 현재 성과 측정
- Analyze (분석): 원인 분석
- Improve (개선): 해결책 실행
- Control (통제): 개선 효과 유지

### 린 생산(Lean Production)

도요타 생산 시스템(TPS)에서 발전. **낭비 제거**에 집중합니다.

**7대 낭비(TIMWOOD)**:
- T: 과잉 운반(Transportation)
- I: 재고 과다(Inventory)
- M: 불필요한 이동(Motion)
- W: 대기(Waiting)
- O: 과잉 생산(Overproduction)
- O: 과잉 처리(Over-processing)
- D: 불량(Defects)

## 재고 관리

### EOQ (Economic Order Quantity)

주문 비용과 보관 비용의 합이 최소화되는 최적 주문량.

**EOQ = √(2DS/H)**
- D: 연간 수요량
- S: 1회 주문 비용
- H: 단위당 연간 보관 비용

EOQ 이상 주문하면 보관 비용이 과다, EOQ 이하로 주문하면 주문 횟수가 증가하여 주문 비용이 과다.

### JIT (Just-In-Time)

필요한 것을, 필요한 때, 필요한 양만큼 생산·공급. 재고를 최소화합니다.

**장점**: 재고 비용 절감, 불량 조기 발견, 공간 절약
**단점**: 공급망 중단에 취약 (COVID-19가 JIT 의존도의 위험성을 드러냄)

## 공급망 관리 (SCM)

**SCM(Supply Chain Management)**은 원자재 조달에서 최종 고객 배달까지의 전체 가치 흐름을 관리합니다.

### 공급망의 구조

```
공급업체 → 제조업체 → 유통업체 → 소매업체 → 최종 고객
```

각 단계에서 재고, 정보, 현금, 물리적 흐름이 발생합니다.

### 채찍효과 (Bullwhip Effect)

최종 소비자의 작은 수요 변동이 공급망을 거슬러 올라갈수록 점점 크게 증폭되는 현상.

원인:
- 각 단계의 수요 예측 오류 누적
- 리드타임에 대비한 과도한 안전재고
- 대량 주문 관행

해결: 실시간 정보 공유, 수요 신호 투명화

### SCM의 전략적 의미

애플, 아마존, 월마트의 경쟁 우위 상당 부분이 **우수한 공급망**에서 옵니다.

- 애플: 부품 독점 계약으로 경쟁사 배제
- 아마존: FBA(Fulfilled by Amazon)로 물류 통합
- 월마트: EDI로 공급업체와 실시간 재고 공유

## 핵심 개념 카드

**화폐의 시간가치 (TVM)** ★★★★★
: 현재가치(PV) = 미래가치(FV) / (1+r)^n. 미래가치(FV) = PV × (1+r)^n. 순현재가치(NPV): 현금유입의 PV - 현금유출의 PV. NPV > 0 → 투자 타당. 내부수익률(IRR): NPV = 0이 되는 할인율.

**자본구조와 레버리지** ★★★★
: 부채비율 = 부채/자기자본. 재무레버리지: 부채 사용 → ROE 증폭 (EBIT 변동 시 EPS 더 크게 변동). MM정리: 완전자본시장에서 자본구조는 기업가치에 무관. 현실: 세금효과(부채 이자 세금공제)·재무곤란비용 고려.

**재무제표 분석: 주요 비율** ★★★★★
: 유동성: 유동비율=유동자산/유동부채(>200% 양호), 당좌비율. 수익성: ROE=당기순이익/자기자본, ROA=당기순이익/총자산. 레버리지: 부채비율=부채/자기자본. 활동성: 재고자산회전율=매출/재고. 시장가치: PER=주가/EPS, PBR=주가/BPS.

## 실전 퀴즈

**Q. NPV법과 IRR법 중 어느 것이 더 신뢰할 만한가? 이유는?**
> NPV법이 더 신뢰성 높음. IRR법은 복수 해 문제·재투자가정(내부수익률로 재투자 가정=비현실적) 문제 존재. NPV는 기업가치 증가분을 직접 측정.
