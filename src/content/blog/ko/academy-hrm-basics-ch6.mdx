## 보상 체계의 구성

```
총보상 (Total Compensation):
직접 보상: 기본급 + 성과급
간접 보상: 복리후생

보상의 공정성:
내부 공정성: 조직 내 직무 간 형평
외부 공정성: 노동 시장과 비교
개인 공정성: 동일 직무 내 개인 차이

보상 목적:
우수 인재 유인·유지
동기부여
비용 효율
```

---

## 임금 체계 유형

```
연공급 (Seniority-Based):
근속 연수·나이 기준
한국 전통 방식
장점: 안정·충성도
단점: 성과 연계 약함

직무급 (Job-Based):
직무 가치(직무평가) 기준
서구 방식
장점: 내부 공정성
단점: 직무 이동 경직

역량급 (Competency-Based):
보유 역량·스킬 기준
지식 근로자에 적합
장점: 자기 개발 동기
단점: 역량 측정 어려움

성과급 (Performance-Based):
개인·팀·조직 성과 연계
인센티브·보너스
장점: 직접 동기부여
```

---

## 복리후생

```
법정 복리후생:
4대 보험: 건강·국민연금·고용·산재
퇴직급여

비법정 복리후생:
주거: 사택·주택자금 대출
교육: 학비 지원·어린이집
건강: 의료비·건강검진
레저: 휴양시설·문화비

유연 복리후생 (카페테리아):
직원이 원하는 항목 선택
다양한 니즈 충족
비용 효율
```

## 임금 관리 이슈

```
임금 구조:
기본급 비중 vs 변동급 비중
고정비 부담 vs 동기부여

최저임금:
법적 최소 기준
매년 고용노동부 고시

임금 피크제:
정년 전 일정 연령부터 임금 감소
고령 인력 유지·정년 연장 연계

통상임금·평균임금:
통상임금: 정기·일률·고정 (연장 기준)
평균임금: 직전 3개월 (퇴직금 기준)
```

## 실전 퀴즈

**Q. 한국 기업이 연공급에서 직무급으로 전환하기 어려운 이유는?**
> 장기 근속 기대 훼손: 고연령 직원 불이익. 직무 측정 어려움: 화이트칼라 직무 평가 복잡. 노조 반대: 기득권 보호. 문화적 거부감: 연차·나이 무시 인식. 실무: 혼합형(연공+직무) 많음. 글로벌 경쟁력 위해 직무·성과 요소 강화 추세.

**Q. 성과급 비중이 너무 높을 때의 부작용은?**
> 단기 성과 집중 → 장기 투자 소홀. 협업 약화: 개인 성과 극대화. 부정 행위: 성과 왜곡·쇼핑. 위험 회피: 도전적 목표 기피. 스트레스·소진: 심리적 압박. 불확실한 수입 → 우수 인재 이탈. 성과급은 적정 비중이 중요.
