## 이 시리즈에서 배운 것들

법학 기초 시리즈는 일상생활과 사업 현장에서 만나는 핵심 법률을 체계적으로 다루었습니다.

## 법적 사고의 기본 틀

법률 문제를 만났을 때 적용하는 3단계 분석법:

```
STEP 1: 사실관계 파악
→ 무엇이 언제 어떻게 일어났는가?
→ 당사자는 누구인가?

STEP 2: 적용 법률 찾기
→ 계약 문제? → 민법 계약 편
→ 회사 문제? → 상법 회사 편
→ 소비자 문제? → 소비자기본법, 전자상거래법
→ 근로 문제? → 근로기준법
→ 부동산? → 민법 물권 편 + 공인중개사법

STEP 3: 법 효과 확인
→ 어떤 구제가 가능한가?
→ 기간 제한이 있는가? (소멸시효, 청약 철회 기간)
→ 증거는 무엇이 필요한가?
```

## 핵심 개념 비교 총정리

### 물권 vs 채권

```
물권: 물건 지배 → 모든 사람에게 주장 가능 (대세권)
채권: 특정인에 청구 → 그 사람에게만 주장 가능 (대인권)

예: 부동산 등기 = 물권 / 임대차 계약 = 채권
(등기된 전세권 vs 미등기 임차권 — 전자가 훨씬 강력)
```

### 해제 vs 해지

```
해제: 소급효 있음 → 처음부터 없었던 것처럼
→ 대상: 매매, 도급 등 1회성 계약

해지: 소급효 없음 → 장래만 효력 소멸
→ 대상: 임대차, 고용, 위임 등 계속적 계약
```

### 무효 vs 취소

```
무효: 처음부터 효력 없음, 누구나 주장 가능, 기간 제한 없음
→ 불공정 계약, 강행법규 위반, 사회질서 위반

취소: 일단 유효, 취소권자만 주장, 3년(또는 10년) 제한
→ 착오, 사기, 강박, 제한능력자 행위
```

### 특허 vs 저작권

```
특허: 기술 아이디어 보호 / 등록 필요 / 20년
저작권: 창작 표현 보호 / 등록 불필요(자동) / 사후 70년

핵심 차이: 특허는 "아이디어 자체"도 보호
         저작권은 "표현"만 보호 (아이디어 보호 안 함)
```

## 생활 속 법률 체크리스트

### 취업·근로 시

- [ ] 근로계약서 서면 교부 받았는가?
- [ ] 최저임금 이상인가? (2025년: 10,030원/시간)
- [ ] 수습 기간 명시되어 있는가? (3개월 이내, 감액 한도 있음)
- [ ] 경업금지·비밀유지 약정의 범위가 합리적인가?
- [ ] 퇴직금 조항 확인했는가? (1년 이상 근무 시 의무)

### 부동산 거래 시

- [ ] 등기부 갑구(소유권)·을구(담보) 확인했는가?
- [ ] 근저당권 금액이 매매가 대비 과도하지 않은가?
- [ ] 임차 시 전입신고 + 확정일자 받았는가?
- [ ] 계약금·중도금·잔금 일정 명확한가?
- [ ] 공인중개사 등록증 확인했는가?

### 온라인 쇼핑 시

- [ ] 청약 철회 기간(7일) 내 반품 가능한가?
- [ ] 사업자 정보(상호, 대표자, 주소)가 명시되어 있는가?
- [ ] 개인정보 수집 항목이 서비스에 필요한 최소한인가?
- [ ] 필수 동의와 선택 동의가 구분되어 있는가?

### 창업·계약 시

- [ ] 계약서 작성 전 약관 불공정 조항 검토했는가?
- [ ] 지식재산권 귀속 조항 확인했는가? (업무상 발명)
- [ ] 손해배상 상한 조항이 불합리하게 낮지 않은가?
- [ ] 계약 기간·갱신·해지 조건이 명확한가?

## 법률 구제 기관 총정리

```
민사 분쟁:
- 법원 (소액사건: 3,000만 원 이하 간이 절차)
- 대한법률구조공단 (무료 법률 지원)
- 한국소비자원 (소비자 분쟁)

노동 분쟁:
- 고용노동부·지방노동청
- 노동위원회 (부당해고, 임금 체불)

개인정보 침해:
- 개인정보보호위원회
- KISA(한국인터넷진흥원) 신고센터

지식재산권:
- 특허청 (특허·상표·디자인)
- 저작권위원회 (저작권 분쟁)
```

## 시험 대비 최빈출 핵심

**민법 물권:**
- 부동산 물권 변동 → 등기가 성립요건
- 저당권 → 부종성·수반성·불가분성·물상대위성

**민법 채권:**
- 채무불이행 3유형 → 이행지체·이행불능·불완전이행
- 소멸시효 → 일반채권 10년, 상사채권 5년

**회사법:**
- 보통결의: 출석과반수 + 발행주식 1/4
- 특별결의: 출석 2/3 + 발행주식 1/3

**지식재산권:**
- 저작권 → 등록 불필요, 창작시 자동 발생
- 특허 → 진보성이 핵심 요건, 20년

**소비자법:**
- 통신판매 청약 철회 → 7일
- 방문판매 청약 철회 → 14일

## 마치며

법은 생활의 규칙입니다. 계약서 한 줄, 등기부 을구의 근저당권 금액, 온라인 쇼핑몰의 환불 정책 — 이 모든 것이 법의 언어로 쓰여 있습니다.

법학 기초를 익힌 당신은 이제 일상의 법률 문제를 두려워하지 않아도 됩니다. 더 깊은 공부가 필요하다면 민법·상법·각종 특별법 시리즈로 이어가세요.

*"법을 아는 자는 권리를 지킨다."*
