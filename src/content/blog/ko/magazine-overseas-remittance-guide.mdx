## 해외송금, 수수료 차이가 수십만 원

100만 원을 해외로 보낼 때 수수료가 5,000원이냐 3만 원이냐는 작아 보이지만, 매달 보내면 연 30만 원 차이가 납니다. 방법만 알면 대부분의 수수료를 0원에 가깝게 줄일 수 있습니다.

---

## 해외송금 방법 종류 한눈에 보기

| 방법 | 대표 서비스 | 수수료 수준 | 속도 |
|------|-----------|-----------|------|
| **시중은행 창구** | 국민·신한·우리 | 높음 (건당 5~10만원) | 1~3 영업일 |
| **시중은행 앱** | 국민·신한·우리 | 중간 (건당 5,000~3만원) | 1~2 영업일 |
| **인터넷은행** | 카카오뱅크, 케이뱅크 | 낮음 | 당일~1영업일 |
| **핀테크 앱** | 토스, 트랜스퍼와이즈(Wise) | 매우 낮음 | 수분~1영업일 |
| **편의점 송금** | 세븐일레븐 등 | 중간 | 1~3 영업일 |

## 주요 서비스 수수료 상세 비교

### 시중은행 (100만원 기준)

| 은행 | 인터넷 수수료 | 창구 수수료 | 환율 우대 |
|------|------------|-----------|---------|
| 국민은행 | 5,000~10,000원 | 20,000~50,000원 | 앱 50~70% |
| 신한은행 | 5,000원 | 20,000~50,000원 | 앱 50~70% |
| 우리은행 | 5,000원 | 20,000~50,000원 | 앱 50~90% |
| 하나은행 | 5,000원 | 20,000~50,000원 | 앱 70~90% |

> **환율 우대 꼭 확인**: 송금 수수료 외에 **환전 환율 차이(스프레드)**가 실제 비용의 대부분입니다.

### 카카오뱅크 해외송금

```
수수료: 건당 5,000원
환율 우대: 최대 90%
한도: 1회 최대 3,000달러 / 연간 50,000달러
지원 국가: 약 15개국 (미국·일본·중국·유럽 주요국)
속도: 보통 당일~1 영업일
```

### 토스 (비바리퍼블리카)

```
수수료: 건당 0~5,000원 (이벤트 기간 0원)
환율 우대: 미드레이트(mid-rate) 기준 적용 (최대 우대)
지원 국가: 약 70개국 이상
한도: 1회 5,000달러 / 연간 50,000달러
속도: 즉시~1 영업일
```

> **토스가 유리한 이유**: 환율을 은행 매매기준율이 아닌 **실제 시장 중간 환율**에 가깝게 적용. 실질 비용이 가장 낮은 경우가 많음.

### Wise (트랜스퍼와이즈)

```
수수료: 송금액의 0.4~1.5% (국가별 상이)
환율: 실제 시장 중간환율 적용 (가장 투명)
지원 국가: 80개국 이상
한도: 국가별 상이 (한국 출금 시 연 50,000달러)
속도: 수분~1 영업일
```

**Wise 장점**: 수수료 구조가 투명하게 공개됨, 다중 통화 계좌 지원

## 실제 비용 계산: 100만원을 미국에 보낼 때

```
[ 환율 가정: 1달러 = 1,350원 기준 ]

방법별 실수령 달러:

1. 은행 창구 (환율 우대 0%):
   수수료: 30,000원 → 실제 환전 970,000원
   환율 스프레드 2%: 970,000원 ÷ 1,377원 = $704.4

2. 은행 앱 (환율 우대 70%):
   수수료: 5,000원 → 실제 환전 995,000원
   환율 스프레드 0.6%: 995,000원 ÷ 1,358원 = $732.7

3. 토스 (미드레이트 적용):
   수수료: 0~5,000원 → 실제 환전 995,000원~1,000,000원
   환율 스프레드 ~0%: 1,000,000원 ÷ 1,350원 = $740.7

→ 은행 창구 vs 토스 차이: $36 = 약 48,600원
```

## 환율 우대 받는 방법

### 은행 앱에서 환율 우대 신청

```
국민은행: 앱 → 환전·송금 → 환율우대 신청
  - 우리은행: 우리WON뱅킹 → 외환 → 환율우대쿠폰
  - 하나은행: 하나원큐 → 환전 → 환율우대 최대 90%
```

### 주거래 실적으로 우대율 높이기

```
급여이체, 카드 실적, 공과금 자동이체 등록
→ VIP 고객 등급 상승 → 환율 우대율 90~100% 가능
```

### 핀테크 앱의 우대 이벤트 활용

```
토스: 첫 해외송금 수수료 무료 이벤트 상시
카카오페이: 월별 수수료 프로모션
→ 앱 알림 설정으로 놓치지 않기
```

## 해외송금 한도와 세금 신고

### 외환거래 신고 기준

| 금액 | 조건 | 신고 여부 |
|------|------|---------|
| 연간 5만 달러 이하 | 개인 송금 | 신고 불필요 (은행 자체 처리) |
| 연간 5만 달러 초과 | 개인 송금 | 한국은행 신고 필요 |
| 연간 1만 달러 이하 | 해외 직접투자 | 간이 신고 |
| 연간 1만 달러 초과 | 해외 직접투자 | 사전 신고 필요 |

> **유학생 생활비**: 연 5만 달러 이내 부모의 생활비 지원은 신고 불필요. 초과 시 외국환거래법에 따른 신고 필요.

### 증여세와 해외송금

```
부모 → 자녀 해외 송금 시:
- 성인 자녀 10년간 5,000만원 초과 → 증여세 대상
- 유학 생활비·학비 명목은 증명 가능하면 비과세
→ 은행에서 "유학생 해외송금" 목적으로 이체 시 기록 남김
```

## 유학생·해외취업자를 위한 절약 전략

### 월별 고정 송금: 자동이체 활용

```
매월 정기 송금 시:
1. 토스 앱 → 정기 해외송금 설정
2. 은행 앱 → 외화 예금 → 환율 좋을 때 미리 환전 후 이체
3. 카카오뱅크 → 해외송금 예약 기능 활용
```

### 환율 타이밍 전략

```
원화 강세(환율 낮을 때) → 많이 보내기 유리
원화 약세(환율 높을 때) → 최소한만 보내기

환율 알림 설정:
- 하나은행 앱 → 환율 알림 설정
- 토스 → 환율 도달 시 알림
- 네이버 금융 → 환율 모니터링
```

### 현지 ATM vs 해외송금 비교

```
현지 ATM 인출:
- 해외 원화 인출 수수료: 건당 3,000~5,000원 + 해외 ATM 수수료
- 환율: 비자/마스터 네트워크 환율 적용 (보통 불리)

해외송금 후 현지 계좌 입금:
- 환율 우대 + 수수료 절감 가능
→ 큰 금액은 해외송금이 유리
```

## 해외에서 한국으로 송금받을 때

### 외화 수취 계좌 개설

```
해외에서 달러/유로 받기:
1. 시중은행 외화통장 개설
2. Wise 다중통화 계좌 (달러·유로·파운드 계좌 무료 개설)
   → 해외 급여, 프리랜서 수익을 외화로 받아 환율 유리할 때 환전
```

### 해외 수익 수취 세금

```
해외 프리랜서 수입, 투자 수익:
- 국내 거주자: 전 세계 소득 → 종합소득세 신고 대상
- 해외 원천징수 후 수령 시 → 외국납부세액공제 적용 가능
```

## 해외송금 체크리스트

**송금 전:**
- [ ] 수취인 계좌번호 (IBAN 또는 SWIFT/ROUTING 번호) 정확한지 확인
- [ ] 수취 은행 SWIFT 코드 확인
- [ ] 수취인 이름 영문 정확 입력 (은행 명의와 일치)
- [ ] 환율 비교 (토스 vs 은행 앱)
- [ ] 수수료 비교

**주의사항:**
- 잘못 송금된 해외 이체는 **회수가 매우 어렵고 수수료 발생**
- 처음 보내는 계좌라면 소액(1만원) 테스트 이체 권장
- 사기 문자로 유도된 계좌에 송금 금지 (로맨스 스캠, 투자 사기 주의)
