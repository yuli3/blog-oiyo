## 코드는 실행 흐름으로 읽습니다

프로그래밍 언어 활용은 문법 암기보다 실행 순서를 따라가는 힘이 중요합니다. 변수, 조건문, 반복문, 함수, 배열, 포인터나 참조 개념이 문제 안에서 함께 움직입니다. 구체적으로 어떤 언어와 문항 유형이 강조되는지는 회차별 출제 기준을 [Q-net](https://www.q-net.or.kr)과 시행처 공식 홈페이지에서 확인하세요. 확인일: 2026-06.

### 자주 보는 요소

| 요소 | 읽는 방법 |
|---|---|
| 조건문 | 참과 거짓의 분기 추적 |
| 반복문 | 초기값, 조건, 증감식 확인 |
| 배열 | 인덱스 범위와 저장 값 확인 |
| 함수 | 매개변수, 반환값, 호출 순서 |
| 알고리즘 | 입력, 처리, 출력 단계 분리 |

코드 문제는 머릿속으로만 풀면 실수가 늘어납니다. 표를 그려 변수 값을 한 줄씩 바꾸어 보세요. 특히 반복문은 첫 회와 마지막 회를 따로 확인하면 오답이 줄어듭니다. 자료구조는 스택, 큐, 트리, 그래프의 동작 방식을 그림으로 연결하면 기억이 오래갑니다.

## 핵심 요약

- 프로그래밍 문제는 문법보다 실행 흐름 추적이 중요합니다.
- 변수 값 표와 반복문 경계 확인이 실수를 줄입니다.
- 언어별 세부 범위는 공식 공고에서 확인해야 합니다.
