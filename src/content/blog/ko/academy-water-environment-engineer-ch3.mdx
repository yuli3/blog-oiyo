## 상하수도 계획의 위치

상하수도 계획은 물을 공급하고 사용한 뒤 다시 처리하는 시스템을 다루는 과목입니다. 정수장과 하수처리장을 따로 외우기보다, 취수 -> 도수 -> 정수 -> 송수 -> 배수, 그리고 배수 -> 차집 -> 처리 -> 방류의 흐름으로 정리하세요.

응시자격·일정·합격기준·과목 개편은 변동될 수 있습니다. 한국산업인력공단 Q-net(https://www.q-net.or.kr) 공고 기준 확인. 확인일: 2026-06.

## 계획 요소

| 영역 | 주요 학습 포인트 |
|---|---|
| 수량 산정 | 계획급수량, 시간·일 변화, 유량 단위 |
| 상수도 | 취수, 정수, 송배수, 수압 관리 |
| 하수도 | 우수·오수, 관거, 펌프장, 처리장 |
| 시설 계획 | 여유율, 체류시간, 유지관리성 |

계산 문제에서는 단위가 자주 함정이 됩니다. 인구, 원단위, 유량, 체류시간을 한 번에 다루기 때문에 L, m3, day, second 단위를 문제 옆에 바로 표시해야 합니다.

## 처리공정과의 연결

상하수도 계획은 다음 장의 방지기술과 이어집니다. 하수처리장에 어떤 유입수가 들어오는지 알아야 침전, 생물학적 처리, 고도처리의 의미가 선명해집니다. 계획 수량이 틀리면 시설 규모와 처리 효율 판단도 흔들립니다.

## 핵심 요약

- 상하수도 계획은 물의 공급과 처리 시스템을 보는 과목입니다.
- 수량 산정, 관로, 정수·하수처리 흐름을 함께 정리해야 합니다.
- 계산 문제는 단위 변환과 시간 기준 확인이 중요합니다.
- 공식 출제기준과 시험 구성은 Q-net 공고 기준으로 확인해야 합니다.
