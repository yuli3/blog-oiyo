## 실기는 손으로 익히는 개념입니다

실기 준비는 명령어 목록을 외우는 것만으로는 부족합니다. 케이블을 만들 때는 핀 배열과 용도를 이해해야 하고, 라우터 명령을 입력할 때는 인터페이스, IP 주소, 라우팅, 저장의 의미를 알아야 합니다. 실제 시험 환경과 도구는 시행 안내에 따라 달라질 수 있으므로 공식 공지를 확인해야 합니다.

### 실기 학습 표

| 영역 | 연습 포인트 |
|---|---|
| 케이블 | 다이렉트·크로스 용도, 색상 배열, 테스터 확인 |
| IP 설정 | 인터페이스 주소, 서브넷 마스크, 게이트웨이 |
| 라우팅 | 정적 경로, 기본 경로의 의미 |
| 장비 확인 | 설정 조회, 인터페이스 상태 확인 |
| 저장 | 설정 저장과 재부팅 후 유지 여부 |

명령어는 "왜 치는지"를 붙여서 외우세요. 예를 들어 인터페이스에 IP를 넣는 것은 그 포트가 네트워크에 참여하게 만드는 일이고, `show` 계열 명령은 설정과 상태를 검증하는 과정입니다.

연습할 때는 입력 화면만 보지 말고 예상 결과와 실제 조회 결과가 같은지도 확인해야 합니다.

## 실수 줄이는 루틴

케이블은 배열 확인, 압착, 테스터 확인 순서로 루틴화하고, 장비 설정은 입력 후 조회 명령으로 검증하세요. 시험 방식·합격 기준·준비물은 변경될 수 있으므로 시행처 공식 홈페이지와 해당 시 Q-net(https://www.q-net.or.kr)을 확인하세요. 확인일: 2026-06.

## 핵심 요약

실기는 케이블 작업과 장비 설정을 절차로 몸에 익히는 파트입니다. 입력보다 검증이 중요하며, 명령어마다 목적을 설명할 수 있어야 합니다. 다음 장에서는 최종 시험전략을 정리합니다.
