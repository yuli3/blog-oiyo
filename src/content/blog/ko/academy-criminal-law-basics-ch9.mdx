## 수사

```
수사의 개시:
고소: 피해자(제3자 포함) 수사 요청
고발: 고소권자 외 제3자가 수사 요청
진정: 수사 의뢰 (법적 의무 없음)
인지: 수사 기관이 스스로 범죄 인지

고소 기간:
범죄 안 날로부터 6개월 이내 (친고죄)
친고죄: 피해자 고소 없으면 공소 불가

임의 수사 vs 강제 수사:
임의: 상대방 동의에 의한 수사
강제: 영장에 의한 강제 처분
→ 강제 수사=영장주의 적용
```

## 체포·구속과 영장

```
체포:
48시간 이내 단기 신체 자유 제한

일반 체포: 체포 영장 필요
현행범 체포: 영장 없이 가능 (누구든)
긴급 체포: 48시간 이내 영장 청구 의무

구속:
장기 신체 자유 제한 + 구속 영장 필요
구속 기간: 수사 단계 30일, 공판 단계 별도

구속 적부 심사:
구속된 피의자가 법원에 구속 적법성 심사 요청
법원이 불법 구속 판단 시 즉시 석방

불구속 수사 원칙:
구속은 예외 (도주·증거 인멸 우려 있을 때)
원칙: 불구속 수사
```

## 압수·수색과 증거

```
압수·수색:
물건 점유·장소 수색
원칙: 영장 필요
예외: 현행범 체포 시·긴급 체포 시

전자정보 압수수색:
디지털 증거 압수 시 피의자 참여권 보장
관련 정보만 압수 (선별 원칙)

위법 수집 증거 배제:
위법하게 수집한 증거는 증거능력 없음
(위법 수집 증거 배제 원칙)

자백 보강 법칙:
자백만으로 유죄 판결 불가
자백+보강 증거 필요
```

## 공소와 재판

```
공소 제기:
검사가 법원에 재판 요청 (기소)
불기소: 혐의 없음·기소유예·기소중지 등

공소시효:
사형: 25년
무기: 15년
단기 3년 이상: 10년
단기 3년 미만: 5년
일부 중대 범죄: 공소시효 없음

재판 절차:
기소 → 공판 준비 → 공판 → 판결

심급 제도:
3심 제도 (지방법원→고등법원→대법원)
항소: 1심 → 2심
상고: 2심 → 3심 (대법원)

무죄 추정의 원칙:
확정 판결 전까지 무죄로 추정
```

## 핵심 개념 카드

**현행범 체포=영장 없음** ★★★★★
: 현행범은 누구든 영장 없이 체포 가능. 48시간 내 석방 또는 영장 청구.
*암기 포인트: 현행범=영장불요*

**자백 보강 법칙** ★★★★★
: 자백만으로 유죄 선고 불가. 반드시 보강 증거 필요.
*암기 포인트: 자백+보강증거=유죄*

**공소시효 사형=25년** ★★★★☆
: 사형25년·무기15년·3년이상10년·3년미만5년.
*암기 포인트: 사25무15단10기5*

## 실전 퀴즈

**Q. 위법 수집 증거 배제 원칙의 목적은?**
> 수사 기관이 불법 방법으로 수집한 증거를 법정에서 사용 불가. 목적: 수사 기관 위법 행위 억제, 피의자 기본권 보호. 진실 발견보다 적법 절차 보장이 더 중요한 경우 증거 배제.

**Q. 구속 적부 심사와 보석의 차이는?**
> 구속 적부 심사: 구속 자체의 적법성·타당성 심사. 불법 구속이면 즉시 석방. 보석: 적법한 구속이지만 일정 조건(보증금 등)으로 석방. 구속 자체는 유효하지만 집행을 유예.
