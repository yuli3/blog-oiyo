## 특허 대상 — 발명

```
발명의 성립 요건:
자연법칙을 이용
기술적 사상의 창작
고도한 것 (실용신안보다 높은 수준)

특허 대상:
물건 발명: 제품·화합물·조성물
방법 발명: 제조방법·사용방법
용도 발명: 새로운 용도 발견

특허 제외:
자연법칙 자체 (E=mc²)
순수 수학 공식
게임 규칙 (아이디어만)
의료 방법 (일부 국가)
```

## 신규성

```
신규성 정의:
출원 전에 공지·공용·반포된 발명이 아닐 것

선행기술:
특허 출원 전 세계 어디서나 공개된 기술
특허 문헌·학술지·제품 등

신규성 상실 사유:
공개 발표·전시·판매
타인의 특허 출원(공개 후)

공지 예외:
출원 전 12개월 내 공개 → 신규성 의제 신청
학술 발표·박람회·시험 공개 등
신청 필수 (자동 아님)
```

## 진보성

```
진보성 정의:
그 발명이 속하는 기술분야에서
통상의 지식을 가진 사람이
선행기술로부터 쉽게 발명할 수 없을 것

통상의 기술자:
해당 기술분야 평균적 지식·기술 보유
최신 기술 인지, 창의력 없음

진보성 판단:
선행기술 결합 → 쉽게 도출 가능? → 진보성 없음
예측 불가능한 효과 → 진보성 있음

가장 많이 다퉈지는 요건:
심사·심판·소송에서 진보성 분쟁 최다
```

## 산업상 이용가능성

```
정의:
산업에 이용 가능한 발명
공업적 생산·반복 실시 가능

예외 (이용불가):
의료 행위 방법 (일부 국가)
인체 처치 방법
순수 학술적·이론적 발명

인정 범위:
농업·광업·수산업 포함
미래 기술도 잠재 가능성 있으면 인정
```

## 실전 퀴즈

**Q. 신규성과 진보성을 동시에 판단해야 하는 이유는?**
> 신규성: 이미 알려진 것인가? (절대적 기준). 진보성: 알려진 것에서 쉽게 도출 가능한가? (상대적 기준). 선행기술 A가 없으면 신규성 O, 있으면 신규성 X. 선행기술 A, B 있어도 조합이 어려우면 진보성 O. 신규성 없으면 진보성도 없음.

**Q. 논문 발표 후 특허 출원이 가능한가?**
> 공지 예외 제도 활용 가능. 요건: 발표 후 12개월 이내 출원 + 공지 예외 주장 신청. 주의: 해외 출원 시 각국 공지 예외 확인 필요. 일부 국가는 공지 예외 없음. 최선: 논문 발표 전에 먼저 출원. 변리사 상담 후 전략 결정 권장.
