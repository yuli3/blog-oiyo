## 필기와 실기를 함께 묶습니다

네트워크관리사 준비의 마지막 단계에서는 필기 개념과 실기 작업을 따로 보지 않는 것이 중요합니다. 서브넷을 공부했다면 장비 IP 설정으로 연결하고, 라우팅을 공부했다면 기본 게이트웨이와 경로 설정으로 연결하세요. 시험 일정, 응시 자격, 합격 기준은 시행처 공식 홈페이지와 해당 시 Q-net(https://www.q-net.or.kr)에서 최종 확인해야 합니다. 확인일: 2026-06.

### 마무리 계획

| 구간 | 할 일 |
|---|---|
| D-14~D-10 | TCP/IP, OSI, 서브넷 기본 개념 재정리 |
| D-9~D-6 | 장비 역할, 보안, NOS 오답 정리 |
| D-5~D-3 | 실기 케이블 배열과 라우터 명령 반복 |
| D-2~D-1 | 공식 안내 확인, 준비물과 시간표 점검 |
| 시험 당일 | 문제의 계층, 주소, 장비 역할부터 표시 |

오답노트는 "틀린 답"보다 "왜 그 장비나 프로토콜이 아닌지"를 적어야 효과가 큽니다. 예를 들어 DNS 문제를 DHCP로 헷갈렸다면 이름 해석과 주소 할당의 차이를 다시 적어 두세요.

필기 오답과 실기 실수를 같은 노트에 연결하면 시험 직전 점검 시간이 줄어듭니다.

## 실전 감각 만들기

실기는 시간 압박이 생기기 쉬우므로 정해진 순서로 연습해야 합니다. 케이블은 배열 확인 후 압착, 장비 설정은 입력 후 조회, 최종 저장 순서를 반복하세요.

## 핵심 요약

시험전략의 핵심은 계층, 주소, 장비, 명령어를 하나의 문제 해결 흐름으로 묶는 것입니다. 공식 시행 정보는 항상 최신 공지를 기준으로 확인하고, 마지막에는 실기 검증 루틴을 반복하세요.
