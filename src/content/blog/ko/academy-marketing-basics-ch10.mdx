## 1. 마케팅 전략 프레임워크

**① 환경 분석**

- 거시: PEST 분석
- 산업: Porter 5 Forces
- 기업: SWOT 분석

**② 시장 전략**

- STP: 세분화→표적→포지셔닝

**③ 실행 전략**

- 마케팅 믹스: 4P (제품·가격·유통·촉진)
- 서비스: 7P (4P + 사람·프로세스·물리증거)

**④ 평가·피드백**

- KPI 측정
- CLV·ROI 분석

## 3. 핵심 수치 총정리

```
고객 유지율 5% 증가 = 이익 25~95% 증가
서비스 품질 5차원 = SERVQUAL (유신반확공)
PLC 4단계 = 도성숙쇠
마케팅 발전 3단계 = 생판마
촉진 믹스 5요소 = 광인판PR직
글로벌 진입 방식 = 수출→계약→직접투자
```

## 4. 빈출 오답 10선

```
① STP = 세분→표적→포지셔닝 (순서)
② PLC 성숙기 = 매출정점 but 이익 감소
③ 스키밍=고가도입, 침투=저가도입
④ 서비스 4특성 = 무비이소
⑤ SERVQUAL = 유신반확공 (5차원)
⑥ PUSH=유통대상, PULL=소비자대상
⑦ PR = 통제력 낮음·신뢰도 높음
⑧ 집약적 유통 = 최대한 많은 중간상
⑨ 라이선싱≠프랜차이징 (범위 다름)
⑩ CLV = 고객 생애 전체 수익 현재가치
```

## 5. 핵심 개념 카드

**마케팅 핵심=STP+4P** ★★★★★
: 전략(STP) 수립 후 전술(4P) 실행.
*암기 포인트: STP→4P*

**서비스 7P=4P+인프물** ★★★★★
: People·Process·Physical Evidence 추가.
*암기 포인트: 7P=4P+3P*

**고관여=광범위·저관여=제한적** ★★★★☆
: 구매 의사결정 과정 깊이 차이.
*암기 포인트: 고관여=광범위*

## 6. 실전 퀴즈 (종합)

**Q. 신규 스타트업이 마케팅 전략을 수립하는 순서는?**
> 1. 환경 분석 (PEST·경쟁·SWOT). 2. 시장 세분화 및 표적 선정. 3. 포지셔닝 결정 (경쟁자 대비 차별점). 4. 마케팅 믹스 4P 설계. 5. 예산 배분 및 실행. 6. KPI 설정·측정·피드백. 자원 제한 시 집중 전략 + 디지털 채널 활용이 효율적.

**Q. 전통 마케팅과 디지털 마케팅의 핵심 차이는?**
> 전통: 단방향 소통(TV·신문), 대량 노출, 측정 어려움. 디지털: 양방향·개인화, 타겟 정밀, ROI 즉시 측정. 데이터 기반 실시간 최적화. 소비자가 콘텐츠 생산(UGC). 경계 소멸: 옴니채널이 표준. 두 방식 통합이 현대 마케팅.
