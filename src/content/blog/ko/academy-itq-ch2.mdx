## ITQ 엑셀·한셀 시험 구성

```
시험 구성:
→ 실기 시험 60분, 500점 만점
→ A등급 400점 이상 / B등급 300점 이상

출제 영역:
→ 기본 작업 (100점): 데이터 입력·편집·서식
→ 계산 작업 (80점): 함수 수식 작성
→ 분석 작업 (100점): 조건부 서식·정렬·필터·부분합
→ 기타 작업 (100점): 차트·이름 정의·매크로

주요 함수 카테고리:
→ 통계 함수: SUM·AVERAGE·COUNT·MAX·MIN·LARGE·SMALL
→ 논리 함수: IF·AND·OR·NOT·IFS·SWITCH
→ 텍스트 함수: LEFT·RIGHT·MID·LEN·TRIM·UPPER·LOWER
→ 날짜 함수: TODAY·NOW·YEAR·MONTH·DAY·EDATE·DATEDIF
→ 찾기 함수: VLOOKUP·HLOOKUP·INDEX·MATCH·XLOOKUP
→ 수학 함수: ROUND·ROUNDUP·ROUNDDOWN·INT·MOD·SUMIF·SUMIFS
→ 데이터베이스 함수: DSUM·DAVERAGE·DCOUNT

합격 전략:
→ 함수 인수 순서 정확히 암기
→ 조건부 서식 조건 범위 정확히 설정
→ 차트 제목·축·범례 위치 지시 사항 준수
→ 저장: 파일명·형식 지시대로 저장 (미저장 0점)
```

## 주요 함수 완전 정복

```
조건 함수:

IF:
→ =IF(조건, 참 값, 거짓 값)
→ =IF(B2>=90, "A", IF(B2>=80, "B", "C"))
→ 중첩 IF: 최대 7단계 (IFS 함수로 대체 권장)

IFS (엑셀 2019/365):
→ =IFS(조건1, 값1, 조건2, 값2, ...)
→ =IFS(B2>=90,"A", B2>=80,"B", B2>=70,"C", TRUE,"F")

AND·OR:
→ =AND(조건1, 조건2): 모두 참일 때 TRUE
→ =OR(조건1, 조건2): 하나만 참이어도 TRUE
→ =IF(AND(B2>=60, C2>=60), "합격", "불합격")

집계 함수:

SUMIF / SUMIFS:
→ =SUMIF(범위, 조건, 합계범위)
→ =SUMIF(A2:A10, "서울", C2:C10)
→ =SUMIFS(합계범위, 범위1, 조건1, 범위2, 조건2)

COUNTIF / COUNTIFS:
→ =COUNTIF(범위, 조건)
→ =COUNTIF(B2:B10, ">=80")
→ =COUNTIFS(범위1, 조건1, 범위2, 조건2)

AVERAGEIF:
→ =AVERAGEIF(범위, 조건, 평균범위)

RANK / RANK.EQ:
→ =RANK(값, 참조범위, [순서])
→ 순서 0 또는 생략: 내림차순 / 1: 오름차순
→ =RANK.EQ(B2, $B$2:$B$10, 0)
→ 동점 처리: RANK.EQ는 동점 동일 순위 부여
```

## VLOOKUP·INDEX·MATCH

```
VLOOKUP:
→ =VLOOKUP(찾을값, 표범위, 열번호, [일치방법])
→ 일치 방법: 0(FALSE) = 정확히 일치
→ =VLOOKUP(A2, $F$2:$H$10, 2, 0)
→ 제한: 왼쪽 열 기준, 오른쪽으로만 검색

HLOOKUP:
→ =HLOOKUP(찾을값, 표범위, 행번호, [일치방법])
→ 가로 방향 검색

INDEX·MATCH (VLOOKUP 대안):
→ =INDEX(반환범위, MATCH(찾을값, 검색범위, 0))
→ 방향 제한 없음·더 유연
→ =INDEX($H$2:$H$10, MATCH(A2, $F$2:$F$10, 0))

XLOOKUP (엑셀 365):
→ =XLOOKUP(찾을값, 검색범위, 반환범위)
→ 좌우·상하 방향 자유
→ 기본값 인수: 미찾으면 반환값 지정 가능

TEXT 함수:
→ =TEXT(값, 형식코드)
→ =TEXT(TODAY(), "yyyy-mm-dd") → 날짜 문자열
→ 형식 코드: 0 (자릿수 유지), # (유효 숫자만), "원" (단위)

DATEDIF (날짜 차이):
→ =DATEDIF(시작일, 종료일, 단위)
→ 단위: "Y" 연 차이, "M" 월 차이, "D" 일 차이
→ =DATEDIF(A2, TODAY(), "Y") → 현재 나이 계산
```

## 차트 작성

```
차트 삽입:
→ 데이터 선택 → 삽입 → 차트 종류 선택
→ 차트 유형: 묶은 세로 막대·꺾은선·원형·분산형·가로막대

차트 구성 요소:
→ 차트 영역: 전체 차트 공간
→ 그림 영역: 실제 데이터 표시 공간
→ 범례: 데이터 계열 구별 표시
→ 데이터 레이블: 각 항목 값 표시
→ 제목: 차트 제목·축 제목

ITQ 차트 작성 주요 체크:
→ 차트 종류 정확히 선택 (묶은·누적 막대 구분)
→ 데이터 범위 정확히 지정 (행·열 방향 확인)
→ 제목 내용·글꼴·크기 지시 사항대로
→ 범례 위치: 아래·오른쪽·위·왼쪽
→ 데이터 레이블: 표시·위치(안쪽 끝·바깥쪽 끝)
→ 차트 색상: 채우기 색 지정 시 정확히

2축 차트 (혼합 차트):
→ 일부 계열: 보조 축 사용
→ 계열 선택 → 데이터 계열 서식 → 보조 축
→ 꺾은선 + 막대 혼합 시 자주 사용

원형 차트:
→ 데이터 레이블에 백분율 표시
→ 특정 조각 분리: 조각 선택 → 드래그
```

## 데이터베이스 기능

```
정렬 (Sort):
→ 데이터 탭 → 정렬
→ 기준 여러 개: 1차·2차·3차 정렬 기준
→ 오름차순·내림차순·사용자 지정 목록 순서

필터 (AutoFilter):
→ 자동 필터: 데이터 탭 → 필터 → 필터 아이콘 클릭
→ 숫자 필터: 조건 범위 지정 (≥, ≤, 사이)
→ 텍스트 필터: 포함·시작·끝나는 문자 조건
→ 고급 필터: 별도 조건 범위 지정·다른 위치 복사

부분합 (Subtotal):
→ 반드시 정렬 후 사용
→ 데이터 탭 → 부분합 → 그룹화할 항목·사용 함수 선택
→ 합계·평균·최대·최소·개수 선택
→ 중첩 부분합: 기존 부분합 삭제 체크 해제

조건부 서식:
→ 홈 탭 → 조건부 서식
→ 셀 강조 규칙: 특정 값보다 크거나 작을 때 색 변경
→ 상위/하위 규칙: 상위 10개·상위 10%
→ 데이터 막대·색조·아이콘 집합: 시각화
→ 수식 사용: =AND(A2>0, B2="완료") → 행 전체 서식

피벗 테이블:
→ 삽입 → 피벗 테이블
→ 행·열·값·필터 영역 필드 배치
→ 값 필드 설정: 합계·평균·개수·최대·최소
→ 그룹화: 날짜 → 년·월·분기로 그룹
→ 슬라이서: 필터를 시각적 버튼으로 표시
```

## 자주 묻는 질문

**Q. VLOOKUP에서 정확히 일치(0)와 근사 일치(1)는 언제 구분해 사용하나요?**
A. 정확히 일치(0 또는 FALSE)는 검색값과 완전히 같은 값을 찾을 때 사용합니다. 제품 코드로 가격을 찾거나, 학번으로 성적을 찾는 경우입니다. 근사 일치(1 또는 TRUE·생략)는 검색 범위가 오름차순으로 정렬되어 있고, 범위 내 값 미만의 가장 큰 값을 찾을 때 사용합니다. 성적 구간(0~59=F, 60~69=D...)을 표에서 등급으로 변환하거나, 요금제 구간을 찾는 경우에 적합합니다. 시험에서는 대부분 정확히 일치(0)가 요구됩니다.

**Q. ITQ 시험에서 저장을 잘못하면 0점인가요?**
A. ITQ는 실기 시험이므로 저장된 파일이 채점 대상입니다. 파일명을 잘못 지정하거나 저장 형식을 다르게(xlsx 대신 csv 등) 저장하면 채점 파일을 찾을 수 없어 0점 처리될 수 있습니다. 반드시 지시 사항의 파일명(예: 수험번호.xlsx)과 저장 위치를 확인하고 시험 종료 전 저장합니다. 중간에도 Ctrl+S로 수시로 저장하는 습관이 중요하며, 시험 종료 신호가 나면 즉시 저장 여부를 재확인해야 합니다.
