## 민법의 구조

**민법(民法)**: 사인(私人) 간의 법률 관계를 규율하는 기본법입니다.

```
민법 체계:
제1편 총칙   - 민법 전체에 공통되는 기초 문법
제2편 물권   - 물건을 직접 지배하는 권리
제3편 채권   - 특정인에게 특정 급부를 요구하는 권리
제4편 친족   - 혼인, 부모·자녀, 후견, 부양
제5편 상속   - 사망 후 재산 승계와 유언, 유류분
```

**민법의 3대 원칙**:
- 사적 자치(계약 자유)의 원칙
- 소유권 절대의 원칙
- 과실 책임의 원칙

---

## 제1편 총칙의 전체 지도

민법 총칙은 단순히 `법률행위`만 배우는 파트가 아닙니다. 민법 전체를 읽는 문법서에 가깝습니다.

| 장 | 핵심 내용 | 시험·실무 포인트 |
|---|---|---|
| 제1장 통칙 | 법원, 신의성실, 권리남용금지 | 민법 해석의 출발점 |
| 제2장 인 | 권리능력, 행위능력, 주소, 부재·실종 | 미성년자, 실종선고 문제 |
| 제3장 법인 | 설립, 기관, 해산, 청산 | 비영리법인 기본 구조 |
| 제4장 물건 | 부동산·동산, 주물·종물, 과실 | 물권 파트의 전제 |
| 제5장 법률행위 | 의사표시, 대리, 무효·취소, 조건·기한 | 민법 빈출 핵심 |
| 제6장 기간 | 초일불산입, 월·연 계산 | 기간 계산형 문제 |
| 제7장 소멸시효 | 권리 불행사에 따른 소멸 | 기간 암기와 기산점 |

이 장에서는 위 표를 따라 `통칙 -> 인 -> 법인 -> 물건 -> 법률행위 -> 기간 -> 소멸시효` 순으로 민법의 공통 언어를 정리합니다.

## 제1장 통칙

### 민법의 법원과 해석 기준

**법원(法源)**: 재판의 기준이 되는 법 형식입니다. 민법은 성문법 국가이므로 법률이 중심이지만, 관습법과 조리도 해석에 작동합니다.

```
민법 해석의 층위:
헌법 -> 민법 조문 -> 특별법 -> 관습법 -> 조리
```

### 신의성실의 원칙과 권리남용금지

- **신의성실의 원칙**: 권리 행사와 의무 이행은 신의에 좇아 성실히 해야 합니다.
- **권리남용금지**: 형식상 권리 행사라도 사회적으로 정당성을 잃으면 허용되지 않습니다.

```
암기 포인트:
신의칙 = 민법 전체를 관통하는 일반 조항
권리남용금지 = 권리 행사에도 한계가 있다는 선언
```

---

## 제2장 인

### 능력

- **권리능력**: 사람이 권리·의무의 주체가 될 수 있는 자격
- **행위능력**: 단독으로 유효한 법률행위를 할 수 있는 자격

| 구분 | 의미 | 대표 쟁점 |
|---|---|---|
| 미성년자 | 원칙적으로 법정대리인 동의 필요 | 취소 가능 |
| 피성년후견인 | 지속적 의사결정 지원 필요 | 법정대리 보호 |
| 피한정후견인 | 일부 법률행위에 동의 필요 | 제한적 보호 |

### 주소, 부재와 실종

- **주소**: 생활의 근거가 되는 곳
- **부재자 재산관리**: 장기간 소재 불명자의 재산 보호
- **실종선고**: 일정 기간 생사 불명 시 사망 간주

```
실종선고:
보통실종 5년
특별실종 1년
```

---

## 제3장 법인

법인은 자연인이 아닌 권리의 주체입니다. 특히 비영리법인의 설립과 기관 구조는 민법 총칙의 중요한 축입니다.

### 법인의 흐름

```
설립허가 -> 설립등기 -> 권리능력 취득
운영 -> 기관 활동
해산 -> 청산 -> 소멸
```

### 법인 기관

- **이사**: 법인의 업무 집행
- **감사**: 감독과 검사
- **사원총회**: 중요한 의사결정

---

## 제4장 물건

물권법을 공부하기 전에 민법이 말하는 `물건`이 무엇인지 먼저 정리해야 합니다.

| 구분 | 내용 | 예시 |
|---|---|---|
| 부동산 | 토지와 그 정착물 | 토지, 건물 |
| 동산 | 부동산 이외의 물건 | 자동차, 기계 |
| 주물 | 독립된 경제적 효용을 가진 중심 물건 | 건물 |
| 종물 | 주물의 상용에 이바지하는 부속 물건 | 건물 열쇠, 부속 설비 |
| 천연과실 | 물건이 자연적으로 산출 | 과수의 열매 |
| 법정과실 | 물건 사용 대가 | 임료, 이자 |

## 법률요건과 법률효과

**법률요건**: 법률 효과를 발생시키는 사실의 조합입니다.  
**법률효과**: 법률요건에 의해 발생하는 권리·의무의 변동입니다.

```
예시:
법률요건: 매매 계약 체결
법률효과: 소유권 이전 의무 + 대금 지급 의무
```

**법률사실의 종류**:
- **법률행위**: 의사표시를 요소로 하는 법률요건 (계약, 유언)
- **법률행위 아닌 사실**: 불법행위, 사무관리, 부당이득

---

## 제5장 법률행위

### 법률행위의 요소

```
법률행위 = 의사표시 + (때로 급부 이행)

단독행위: 의사표시 1개 (취소, 해제, 유언)
계약: 청약 + 승낙 (의사표시 합치)
합동행위: 다수인의 의사표시 (사단법인 설립)
```

### 법률행위의 목적 (유효 요건)

```
법률행위 유효 요건:
① 확정성: 목적이 확정되거나 확정 가능해야
② 가능성: 원시적 불능 -> 무효 (후발적 불능 -> 채무불이행)
③ 적법성: 강행법규 위반 -> 무효
④ 사회적 타당성: 반사회질서 -> 무효 (민법 제103조)
```

### 의사표시의 하자

| 하자 유형 | 내용 | 효과 |
|---|---|---|
| 비진의 표시 | 진의 아닌 줄 알면서 한 표시 | 원칙 유효, 상대방이 알았으면 무효 |
| 허위 표시 | 당사자가 짜고 한 가장행위 | 무효, 선의 제3자 보호 |
| 착오 | 내용의 중요 부분 착오 | 취소 가능 |
| 사기·강박 | 기망·협박에 따른 의사형성 | 취소 가능 |

**무효 vs 취소**:

| 구분 | 무효 | 취소 |
|---|---|---|
| 효력 | 처음부터 없음 | 소급해서 없어짐 |
| 주장 | 누구든지 | 취소권자만 |
| 기간 제한 | 없음 | 3년(안 날) / 10년(행위 시) |

### 대리

**대리**: 대리인의 의사표시 효과가 본인에게 귀속되는 제도입니다.

```
대리 구조:
본인 -> 수권행위 -> 대리인
대리인 -> 대리행위 -> 상대방
효과 -> 본인에게 귀속
```

| 구분 | 내용 |
|---|---|
| 임의대리 | 본인의 수권에 의해 성립 |
| 법정대리 | 법률에 의해 성립 |

```
무권대리: 권한 없이 대리 -> 원칙 본인에게 효력 없음
표현대리: 외관상 권한 있는 것처럼 보이면 상대방 보호
```

### 조건과 기한

| 구분 | 의미 | 효과 |
|---|---|---|
| 조건 | 장래 불확실한 사실에 효력 의존 | 정지조건, 해제조건 |
| 기한 | 장래 확실한 사실에 효력 의존 | 시기, 종기 |

```
정지조건: 조건 성취 시 효력 발생
해제조건: 조건 성취 시 효력 소멸
시기: 도래 시 효력 발생
종기: 도래 시 효력 소멸
```

## 제6장 기간

민법은 기간 계산에도 통일된 규칙을 둡니다.

```
초일불산입:
일·주·월·년으로 정한 기간은 첫날을 산입하지 않음

예외:
오전 0시부터 바로 시작하면 초일 산입 가능
```

---

## 제7장 소멸시효

소멸시효는 `권리를 행사할 수 있는데도 오래 행사하지 않으면 법이 더 이상 보호하지 않는다`는 정책입니다.

```
소멸시효:
- 일반채권: 10년
- 상사채권: 5년
- 단기소멸시효(의사·약사·숙박업 등): 3년

제척기간:
- 취소권: 추인 가능 시부터 3년, 행위 시부터 10년
- 채권자취소권: 안 날로부터 1년, 행위 날로부터 5년
```

## 핵심 개념 카드

**신의성실의 원칙** ★★★★★
: 민법 전반의 일반조항. 계약, 권리 행사, 의무 이행 전부를 통제하는 해석 기준입니다.
*암기 포인트: 신의칙은 민법 전체의 브레이크이자 방향키*

**반사회질서 법률행위** ★★★★★
: 민법 제103조 — 선량한 풍속 기타 사회질서 위반 법률행위는 무효입니다. 추인으로도 유효화되지 않습니다.
*암기 포인트: 반사회질서 = 절대 무효*

**허위표시의 제3자 보호** ★★★★★
: 당사자 간 무효이지만 이를 모르는 선의의 제3자에게는 무효를 주장할 수 없습니다.
*암기 포인트: 허위표시 -> 선의 제3자 보호*

**표현대리** ★★★★☆
: 대리권이 없어도 대리권 있는 외관이 있을 때 본인이 책임을 집니다.
*암기 포인트: 외관 신뢰 -> 본인 책임*

## 실전 퀴즈

**Q. 甲이 乙에게 토지를 담보 목적으로 매도하기로 합의하고 소유권을 이전했다. 이 계약의 효력은?**
> 통정허위표시(민법 제108조)로 당사자 간 무효입니다. 담보 목적이므로 실제 매매 의사가 없습니다.

**Q. 대리인이 권한 없이 계약을 체결했을 때 상대방의 권리는?**
> 본인에게 추인 촉구를 할 수 있고, 본인이 추인을 거절하면 무권대리인에게 이행 또는 손해배상을 청구할 수 있습니다.

**Q. 미성년자가 법정대리인 동의 없이 고가 물품을 구입하면 언제나 무효인가?**
> 무효가 아니라 원칙적으로 취소 가능합니다. 민법은 미성년자 보호를 위해 취소권을 부여합니다.
