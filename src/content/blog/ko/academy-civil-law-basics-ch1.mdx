## 민법의 구조

**민법(民法)**: 사인(私人) 간의 법률 관계를 규율하는 기본법.

```
민법 체계:
제1편 총칙 (법률행위·대리·시효)
제2편 물권 (소유권·담보물권)
제3편 채권 (계약·불법행위)
제4편 친족
제5편 상속
```

**민법의 3대 원칙**:
- 사적 자치(계약 자유)의 원칙
- 소유권 절대의 원칙
- 과실 책임의 원칙

## 법률요건과 법률효과

**법률요건**: 법률 효과를 발생시키는 사실의 조합.  
**법률효과**: 법률요건에 의해 발생하는 권리·의무의 변동.

```
예시:
법률요건: 매매 계약 체결
법률효과: 소유권 이전 의무 + 대금 지급 의무
```

**법률사실의 종류**:
- **법률행위**: 의사표시를 요소로 하는 법률요건 (계약, 유언)
- **법률행위 아닌 사실**: 불법행위, 사무관리, 부당이득

## 법률행위

### 법률행위의 요소

```
법률행위 = 의사표시 + (때로 급부 이행)

단독행위: 의사표시 1개 (취소, 해제, 유언)
계약: 청약 + 승낙 (의사표시 합치)
합동행위: 다수인의 의사표시 (사단법인 설립)
```

### 법률행위의 목적 (유효 요건)

```
법률행위 유효 요건:
① 확정성: 목적이 확정되거나 확정 가능해야
② 가능성: 원시적 불능 → 무효 (후발적 불능 → 채무불이행)
③ 적법성: 강행법규 위반 → 무효
④ 사회적 타당성: 반사회질서 → 무효 (민법 제103조)
```

## 의사표시

**의사표시**: 일정한 법률효과 발생을 원하는 의사를 외부에 표시하는 행위.

### 의사표시의 하자

| 하자 유형 | 내용 | 효과 |
|---------|------|------|
| 비진의 표시 | 진의 아닌 줄 알면서 | 원칙 유효, 상대방이 알았으면 무효 |
| 허위 표시 | 당사자 합의한 가장행위 | 무효 (선의 제3자 보호) |
| 착오 | 내용의 중요 부분 착오 | 취소 가능 (중과실 없을 것) |
| 사기·강박 | 기망·협박으로 의사 형성 | 취소 가능 |

**무효 vs 취소**:

| | 무효 | 취소 |
|--|------|------|
| 효력 | 처음부터 없음 | 소급해서 없어짐 |
| 주장 | 누구든지 | 취소권자만 |
| 기간 제한 | 없음 | 3년(안 날)/10년(행위 시) |

## 대리

**대리**: 대리인의 의사표시 효과가 본인에게 귀속되는 제도.

```
대리 구조:
본인 ──── 수권행위 ────→ 대리인
                            ↓ 대리 행위
                         상대방
본인 ←──── 효과 귀속 ────────
```

### 대리의 종류

| 구분 | 내용 |
|------|------|
| **임의대리** | 본인의 수권에 의해 성립 |
| **법정대리** | 법률에 의해 성립 (미성년자 법정대리인) |

### 무권대리 vs 표현대리

```
무권대리: 권한 없이 대리 → 원칙 본인에게 효력 없음
         → 본인이 추인하면 소급하여 유효

표현대리: 외관상 대리권 있는 것처럼 → 상대방 보호
         → 본인이 책임 (민법 제125·126·129조)
```

## 민법 총칙 주요 기간

```
소멸시효:
- 일반채권: 10년
- 상사채권: 5년
- 단기소멸시효(의사·약사·숙박업 등): 3년

제척기간:
- 취소권: 추인 가능 시부터 3년, 행위 시부터 10년
- 해제권: 법정해제권은 원칙 계약에 따라
```

## 핵심 개념 카드

**반사회질서 법률행위** ★★★★★
: 민법 제103조 — 선량한 풍속 기타 사회질서 위반 법률행위는 무효. 추인으로도 유효화 불가.
*암기 포인트: 반사회질서 = 절대 무효*

**허위표시의 제3자 보호** ★★★★★
: 당사자 간 무효이지만 이를 모르는(선의의) 제3자에게는 무효 주장 불가.
*암기 포인트: 허위표시 → 선의 제3자 보호*

**표현대리** ★★★★☆
: 대리권이 없어도 대리권 있는 외관이 있을 때 본인이 책임. 상대방 신뢰 보호.
*암기 포인트: 외관 신뢰 → 본인 책임*

## 실전 퀴즈

**Q. 甲이 乙에게 토지를 담보 목적으로 매도하기로 합의하고 소유권을 이전했다. 이 계약의 효력은?**
> 통정허위표시(민법 제108조) — 당사자 간 무효. 담보 목적이므로 실제 매매 의사 없음.

**Q. 대리인이 권한 없이 계약을 체결했을 때 상대방의 권리는?**
> ① 본인에게 추인 촉구 (최고권). ② 본인이 추인 거절 시 무권대리인에게 계약 이행 또는 손해배상 청구.
