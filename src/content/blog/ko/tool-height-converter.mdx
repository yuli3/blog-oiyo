# 키 단위 변환기

미국 드라마나 SNS에서 "I'm 5'11"" 같은 표현을 보면 헷갈리기 마련입니다. cm와 피트·인치를 즉시 변환하고, 반대로 미국 기준 신발·의류 사이즈도 확인하세요.

## 주요 키 변환 참조표

| cm | 피트·인치 | 표기 |
|---|---|---|
| 150cm | 4피트 11인치 | 4'11" |
| 160cm | 5피트 3인치 | 5'3" |
| 165cm | 5피트 5인치 | 5'5" |
| 170cm | 5피트 7인치 | 5'7" |
| 175cm | 5피트 9인치 | 5'9" |
| 180cm | 5피트 11인치 | 5'11" |
| 185cm | 6피트 1인치 | 6'1" |
| 190cm | 6피트 3인치 | 6'3" |

## 단위 변환 공식

| 변환 | 공식 |
|---|---|
| cm → 인치 | cm ÷ 2.54 |
| 인치 → cm | 인치 × 2.54 |
| 피트 → cm | 피트 × 30.48 |
| cm → 피트 | cm ÷ 30.48 |
| 1피트 | = 12인치 = 30.48cm |

<Callout type="tip">
**빠른 암산**: 170cm ≈ 5피트 7인치. cm에서 100을 빼면 대략 인치 수(170 − 100 = 70인치)가 되는 건 아니고, 피트는 170 ÷ 30.48 ≈ 5.57 → 5피트 + 0.57 × 12 ≈ 6.8인치 ≈ 5'7" 입니다.
</Callout>
