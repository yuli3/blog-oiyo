# 로스트아크 공대 분배기

군단장 레이드를 여러 게임에 걸쳐 진행할 때, 딜러·서포터 비율이 각 파티에 균등하게 배분되도록 자동으로 계산하는 도구입니다.

## 진행 방식

**본1부1 (2게임)**: 본캐 1회, 부캐 1회
**본1부3 (4게임)**: 본캐 1회, 부캐 3회

각 게임마다 서포터와 딜러의 비율이 편향되지 않도록 최적 분배를 계산합니다.

## 입력 방식

```
D(M) D ㄷ ㅍ
```

| 기호 | 의미 |
|---|---|
| `D`, `ㄷ`, `d` | 딜러 |
| `S`, `ㅍ`, `s` | 서포터 |
| `(M)` 접미사 | 본캐릭터 |

한 줄에 한 명, 공백으로 캐릭터 구분.

</Callout>

## 균등 분배 알고리즘

이 도구는 메인 서포터, 서브 서포터, 메인 딜러의 게임별 편차를 최소화하는 교환 알고리즘을 사용합니다. 각 게임 간 최대-최솟값 차이가 1 이하가 될 때까지 최적화합니다.
