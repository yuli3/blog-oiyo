## 일본어, 한국인에게 얼마나 쉬운가

좋은 소식: 한국인에게 일본어는 상대적으로 쉬운 외국어.

**장점**:
- 문장 구조 거의 동일 (SOV 어순)
- 한자 기반 단어 상당수 공유
- 발음이 비교적 쉬움 (영어보다)

**어려운 점**:
- 히라가나·가타카나·한자 3개 문자 체계
- 경어·정중체·반말 등 다양한 표현 체계
- 한자 읽기 (훈독·음독 구분)

**현실적 목표 기간**:
- 기본 회화 (N4 수준): 6개월~1년
- 자유 대화 (N2 수준): 2~3년

---

## 일본어 문자 체계

### 히라가나 (3~4주)

일본어의 기본 음절 문자. 46개.

**학습법**:
- 앱 활용: Duolingo, AnkiApp
- 노래로 외우기 (유튜브 히라가나 노래)
- 쓰면서 외우기 (3회 쓰기 → 암기 강화)

하루 20~30분씩 2~3주면 완성 가능.

### 가타카나 (2~3주)

주로 외래어·의성어에 사용. 46개.

히라가나와 발음은 동일, 모양만 다름.
히라가나 완성 후 학습 시 더 빠름.

### 한자 (장기 학습)

JLPT 급수별 필요 한자:
- N5: 100자
- N4: 300자
- N3: 650자
- N2: 1,000자
- N1: 2,000자

## JLPT 급수별 목표 설정

| 급수 | 수준 | 목표 기간 (독학) |
|-----|-----|--------------|
| N5 | 기초 (기본 히라가나, 간단한 회화) | 3~4개월 |
| N4 | 초급 (간단한 일상 회화) | 6~8개월 |
| N3 | 중급 (자연스러운 일상 대화) | 12~18개월 |
| N2 | 중상급 (취업, 대학 입학 수준) | 24~36개월 |
| N1 | 상급 (거의 원어민 수준) | 5년+ |

**취업·유학 목적**: N2 이상 목표
**여행·취미 목적**: N4~N3으로 충분

## 단계별 학습 로드맵

### 단계 1: 문자 + 기초 (3개월)

**우선순위**:
1. 히라가나 완성 (3주)
2. 가타카나 완성 (3주)
3. 기초 문법 + N5 어휘 (2개월)

**추천 교재**:
- 「다이스키 일본어」 시리즈
- 「JPT 실전 모의고사」 (문제 유형 파악)

**앱**:
- **Duolingo**: 히라가나, 기초 문장
- **ひらがな**: 히라가나 전용 앱

### 단계 2: 초급 (N4 수준, 3~6개월)

**학습 내용**:
- 기본 동사 활용 (ます형, て형, た형)
- 기초 표현 (시간, 장소, 감정)
- 어휘 800~1,500개

**추천 교재**:
- 「みんなの日本語 初級」 1·2권 (글로벌 표준 교재)
- 「JLPT N4 한자·단어 출제 예상」

### 단계 3: 중급 (N3 수준, 6~12개월)

**학습 내용**:
- 복잡한 문형 (~ たり~たりする, ~ ようになる 등)
- 경어 기초
- 어휘 3,000개+

**전략**:
- 일본 드라마·애니 보기 시작 (자막 활용)
- Anki로 어휘 SRS 관리

## 어휘 암기 전략

### 간격 반복 시스템 (SRS)

**Anki** 활용:
- 플래시카드 + 알고리즘이 복습 시점 최적화
- 매일 새 단어 20~30개 + 복습
- 1년이면 2,000~3,000 단어 장기 기억화

**어휘 순서**:
- JLPT 빈출 단어 덱 다운로드 (Anki 공유 덱)
- 급수별로 진행

### 단어 문맥 암기

단독 단어보다 문장 안에서 암기.

나쁜 방법: "食べる = 먹다"만 외우기
좋은 방법: "朝ごはんを食べる (아침밥을 먹다)" 문장으로 외우기

## 듣기·말하기 향상

### 섀도잉

원어민 발음 듣고 즉시 따라 말하기.

1. 짧은 문장 선택 (드라마 1~2줄)
2. 듣기 → 듣기 + 따라 말하기 → 혼자 말하기
3. 자연스러운 억양·속도 습득

**소재**:
- NHK 뉴스 (명료한 발음)
- 일본 유튜브 (자연스러운 구어)
- 드라마 (실제 회화)

### 언어 교환

- **HelloTalk**: 한국어 배우는 일본인 매칭
- **Tandem**: 언어 교환 앱
- 서로의 언어 교환 → 실전 회화 + 무료

### 일본어 콘텐츠 소비

| 수준 | 추천 콘텐츠 |
|-----|---------|
| 입문 | 폴리랏 유튜브, NHK やさしい日本語 |
| 초급 | 아기상어 일본어 버전, 쉬운 유튜브 |
| 중급 | 일본 예능 (テレビ), 어린이 애니 |
| 중상급 | 일반 드라마, 뉴스, 팟캐스트 |

## 한자 공부법

### 학습 순서

**뜻 먼저, 읽기 나중**:
한자의 의미 → 음독(중국식 발음) → 훈독(일본식 발음) 순서.

**쉬운 한자부터**:
수 (一二三四), 기본 명사 (山水火木) → 점차 확장

### RTK vs 전통 방식

**RTK (Remembering the Kanji)**:
한자를 그림/스토리로 의미와 연결해 외우는 방법.
영어권 학습자에게 인기, 한국어 화자에게도 효과적.
