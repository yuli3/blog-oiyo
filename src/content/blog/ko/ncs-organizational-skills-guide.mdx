NCS 필기에서 조직이해능력은 **8%** 비중입니다. 50문항 기준 약 4문항. 기업 및 공공기관의 조직 구조, 경영 원리, 업무 프로세스를 이해하는 개념을 묻는 문제들입니다. 경영학 배경이 없어도 핵심 개념만 이해하면 충분히 대비 가능합니다.

## NCS 조직이해능력 구성

| 하위 능력 | 내용 | 출제 빈도 |
|----------|------|---------|
| 경영이해능력 | 조직의 목적, 경영 원리 이해 | ★★★★ |
| 체제이해능력 | 조직구조와 기능 파악 | ★★★★ |
| 업무이해능력 | 자신의 직무와 타 부서 업무 연관성 | ★★★ |
| 국제감각능력 | 국제화 환경 이해 | ★★ |

## 1. 경영 이해

### 경영의 구성요소 (5M)

| 요소 | 내용 |
|------|------|
| Man (사람) | 인적자원, 조직 구성원 |
| Material (물자) | 원자재, 물품 |
| Machine (기계) | 설비, 기술 |
| Money (자금) | 재무자원 |
| Method (방법) | 업무 방식, 프로세스 |

### 경영의 기능 (PODC)

1. **계획(Planning)**: 목표 설정, 전략 수립
2. **조직(Organizing)**: 업무 분배, 권한 위임
3. **지휘(Directing)**: 구성원 동기부여, 리더십
4. **통제(Controlling)**: 성과 측정, 편차 수정

### 경영 이념과 목표

**경영 이념**: 기업이 추구하는 핵심 가치와 철학 (예: "고객 만족을 통한 사회 기여")

**경영 목표 체계**:
- 비전(Vision): 장기적 미래상
- 미션(Mission): 존재 목적, 핵심 사업
- 전략 목표: 비전 달성을 위한 중기 목표
- 운영 목표: 부서별 단기 실행 목표

## 2. 조직 구조 이해

### 조직의 유형

**공식 조직 vs 비공식 조직**
- 공식 조직: 계획적으로 구성된 공식적 관계 (예: 회사 조직도)
- 비공식 조직: 자연스럽게 형성된 관계 (예: 동호회, 친목 모임)

### 조직 구조 유형

**기능별 조직 (Functional Structure)**
업무 기능에 따라 부서 구분 (인사부, 재무부, 마케팅부)

장점: 전문성 깊이, 규모의 경제
단점: 부서 간 소통 어려움, 의사결정 지연

**사업부별 조직 (Divisional Structure)**
제품·지역·고객별로 독립 사업부 구성

장점: 빠른 의사결정, 시장 대응력
단점: 자원 중복, 부서 이기주의

**매트릭스 조직 (Matrix Structure)**
기능별 + 프로젝트별 이중 구조

장점: 전문성과 유연성 결합
단점: 이중 지휘로 혼선 가능

**프로젝트 조직**
특정 프로젝트를 위한 임시 조직, 완료 후 해산

### 조직 구조 설계 원칙

**계층화(Hierarchy)**: 상하 명령 체계 수립

**분업화(Division of Labor)**: 업무를 역할별로 나눔

**부문화(Departmentalization)**: 유사 업무를 그룹화

**통제 범위(Span of Control)**: 한 관리자가 직접 감독하는 부하 수

**집권화 vs 분권화(Centralization vs Decentralization)**:
- 집권화: 의사결정이 상위에 집중
- 분권화: 의사결정 권한을 하위에 위임

## 3. 경영 전략

### SWOT 분석 (재확인)
조직이해능력에서도 SWOT가 출제됩니다:
- S: 내부 강점 → 경쟁 우위 확인
- W: 내부 약점 → 개선 필요 사항
- O: 외부 기회 → 활용 가능 환경 변화
- T: 외부 위협 → 대비 필요 위험 요소

### BCG 매트릭스 (시장 성장률-시장점유율)

|  | 높은 시장점유율 | 낮은 시장점유율 |
|--|-------------|-------------|
| **높은 성장률** | ⭐ 스타(Star) — 투자 유지 | ❓ 물음표(Question Mark) — 투자 확대 or 철수 |
| **낮은 성장률** | 🐄 현금젖소(Cash Cow) — 수익 수확 | 🐕 개(Dog) — 철수 검토 |

### 포터의 경쟁우위 전략

**원가우위 전략**: 경쟁사보다 낮은 원가로 가격 경쟁력 확보

**차별화 전략**: 독특한 제품·서비스로 프리미엄 실현

**집중화 전략**: 특정 시장·고객층에 집중

## 4. 기업 문화와 조직 문화

### 기업 문화의 기능

**순기능**: 구성원 통합, 행동 방향 제시, 조직 정체성 형성

**역기능**: 변화 저항, 다양성 억압, 외부 환경 적응 방해

### 조직 문화 유형 (Quinn의 경쟁가치모형)

| 유형 | 특징 | 중시 가치 |
|------|------|---------|
| 집단문화(Clan) | 가족적, 공동체 | 협력, 사기, 신뢰 |
| 발전문화(Adhocracy) | 혁신 지향, 창의 | 성장, 새로운 자원 획득 |
| 위계문화(Hierarchy) | 안정, 규칙 | 효율, 통제, 정보 관리 |
| 합리문화(Market) | 성과 지향, 경쟁 | 생산성, 목표 달성 |

## 5. 업무 이해

### 부서별 주요 기능

| 부서 | 핵심 역할 |
|------|---------|
| 인사(HR) | 채용, 교육, 평가, 급여, 복리후생 |
| 재무/회계 | 예산 관리, 결산, 세무, 원가 분석 |
| 영업/마케팅 | 시장 조사, 판매, 고객 관리, 브랜딩 |
| 생산/운영 | 제조, 품질 관리, 공급망 관리 |
| R&D | 신제품 개발, 기술 연구 |
| 법무 | 계약 검토, 분쟁 해결, 컴플라이언스 |

### 직급 체계 이해

일반적인 공기업·대기업 직급 체계:
사원 → 대리 → 과장 → 차장 → 부장 → 팀장/임원

### 업무 협조 공문서

부서 간 업무 협조 시 "협조 공문" 사용:
- 수신부서에서 처리를 요청
- 협조 이유와 필요 사항 명확히 기술
- 기한, 담당자, 연락처 포함

## 6. 국제감각능력

### 기업의 국제화 단계

1. **수출**: 본국에서 생산 → 해외 판매
2. **직접투자**: 해외에 생산·판매 법인 설립
3. **전략적 제휴**: 현지 기업과 파트너십
4. **다국적 기업화**: 여러 국가에서 통합 경영

### 국제 비즈니스 주요 개념

**FTA (자유무역협정)**: 국가 간 관세 철폐·무역 장벽 감소 협정

**환율**: 통화 간 교환 비율. 원화 강세(환율 하락) → 수출 불리, 수입 유리

**문화적 다양성**: 국제 업무에서 각국의 문화적 차이 이해와 존중
