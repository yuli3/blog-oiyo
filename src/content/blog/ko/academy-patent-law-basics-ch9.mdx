## 오답 유형 1 — 존속기간 혼동

```
자주 틀리는 포인트:
특허: 출원일로부터 20년 (등록일 아님!)
실용신안: 출원일로부터 10년
상표: 등록일로부터 10년 (갱신 무제한)
디자인: 등록일로부터 20년

핵심 구별:
특허·실용신안: 출원일 기산
상표·디자인: 등록일 기산

자주 나오는 함정:
"특허권은 등록일로부터 20년" → 오답
"상표권은 출원일로부터 10년" → 오답
```

## 오답 유형 2 — 전용·통상실시권

```
자주 틀리는 포인트:
전용실시권: 등록 필수 (물권적)
통상실시권: 등록 없어도 유효 (채권적)

전용실시권 설정 시:
특허권자도 실시 못함 (약정 없으면 가능)
→ "특허권자는 항상 실시 가능" → 오답

통상실시권:
여러 명에게 부여 가능
→ "통상실시권도 등록 필수" → 오답

법정 실시권:
당연 발생 (계약 불요)
선사용권이 대표적 예
```

## 오답 유형 3 — 공지 예외·우선권 기간

```
공지 예외:
출원 전 12개월 내 공개 → 신청 필수 (자동 아님!)
"공지 예외는 자동 적용" → 오답

파리조약 우선권:
특허·실용신안: 12개월
상표·디자인: 6개월
"상표도 우선권 기간 12개월" → 오답

PCT 국내 단계:
30개월 이내 진입
"PCT 국내 단계는 12개월" → 오답

심사 청구:
출원 후 3년 이내 (미청구 시 취하 간주)
```

## 오답 유형 4 — 무효 심판·심결

```
무효 심판:
누구든 청구 가능 (이해관계 불요)
확정 시 소급 효력

무효 심결 확정:
처음부터 없었던 것
→ 기납부 로열티 반환 원칙 없음

특허법원 관할:
심결취소소송 전속 관할
침해 소송은 일반 법원

무효와 권리범위확인:
권리범위확인: 이해관계인만 가능
무효심판: 누구든 가능
```

## 핵심 개념 카드

**특허=출원일기산, 상표=등록일기산** ★★★★★
: 기산점 혼동 최다 오답.
*암기 포인트: 특허출원일↔상표등록일*

**전용=등록필수, 통상=등록불요** ★★★★★
: 물권적·채권적 구별.
*암기 포인트: 전용=등록, 통상=불요*

**공지예외=신청필수** ★★★★☆
: 자동 적용 아님 — 신청해야 효력 발생.
*암기 포인트: 공지예외=신청*

## 실전 퀴즈

**Q. "특허권자가 전용실시권을 설정해도 자신은 실시할 수 있다"는 맞는가?**
> 원칙적으로 틀림. 전용실시권 설정 시 특허권자의 실시 여부는 계약 내용에 따름. 계약에 "특허권자도 실시 가능" 명시하면 가능. 명시 없으면 통상 특허권자도 실시 불가 해석. 이 점이 전용실시권이 물권적 성격을 갖는 이유. 시험에서 "항상 실시 가능"이면 오답, "약정 시 가능"이면 정답.

**Q. PCT 출원 후 국내 단계 미진입 시 어떻게 되는가?**
> 30개월 내 국내 단계 미진입 시 해당 국가에서 포기된 것으로 간주. 국제 출원 자체는 유지되나 해당 국가 권리 소멸. 일부 국가는 시한 연장 가능 (추가 수수료). 국내 단계 진입 결정이 전략적 핵심: 사업성·경쟁 상황 고려. 미진입 국가에서는 누구나 자유롭게 실시 가능.
