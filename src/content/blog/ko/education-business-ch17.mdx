## 1. MIS 개요

**MIS (Management Information System)**: 경영 의사결정을 지원하기 위해 데이터를 수집·처리·저장·배포하는 시스템.

### 정보시스템 발전 단계

| 세대 | 시스템 | 초점 |
|------|--------|------|
| 1세대 | TPS (거래처리시스템) | 일상 거래 자동화 |
| 2세대 | MIS (경영정보시스템) | 관리 보고서 |
| 3세대 | DSS (의사결정지원시스템) | 반구조적 의사결정 |
| 4세대 | EIS (중역정보시스템) | 경영자 전략 지원 |
| 5세대 | AI/지식기반시스템 | 전문가 시스템, AI |

### 의사결정 유형별 시스템

| 유형 | 특징 | 시스템 |
|------|------|--------|
| 구조적 | 반복적, 규칙 명확 | TPS, MIS |
| 반구조적 | 일부 규칙 존재 | DSS |
| 비구조적 | 창의적, 불확실 | EIS, AI |

## 2. 통합 기업 시스템

### ERP (전사적 자원관리)

기업의 모든 자원(생산·구매·회계·인사·물류)을 실시간 통합 관리하는 시스템.

**특징**: 단일 데이터베이스 / 실시간 정보 공유 / 모듈화 구조

**ERP 모듈 예**: 재무회계 / 관리회계 / 인사 / 생산계획 / 구매 / 영업 / 물류

**ERP 도입 효과**: 업무 중복 제거, 데이터 일관성, 의사결정 속도 향상.
**ERP 도입 리스크**: 도입 비용, 사용자 저항, 맞춤화 한계.

### SCM (공급망관리)

원자재 공급자 → 제조업자 → 유통업자 → 최종 고객까지 전체 공급망을 통합 최적화.

**SCM 목표**: 총 공급망 비용 최소화 + 고객 서비스 수준 최대화.

**VMI (공급자 재고관리)**: 공급자가 고객사 재고를 직접 관리 → 채찍 효과 완화.

### CRM (고객관계관리)

고객 정보를 통합·분석하여 맞춤형 서비스 제공, 고객 충성도 향상.

**CRM 유형**
- 운영적 CRM: 판매·마케팅·서비스 자동화
- 분석적 CRM: 고객 데이터 분석, 세분화
- 협업적 CRM: 채널 간 통합 커뮤니케이션

### KMS (지식관리시스템)

조직 내 암묵지·형식지를 수집·저장·공유·활용하는 시스템.

**Nonaka의 SECI 모형**: 암묵지 ↔ 형식지 변환
- 사회화(S) → 표출화(E) → 결합화(C) → 내면화(I)

## 3. 빅데이터와 분석

### 빅데이터 3V (Gartner)

| V | 내용 |
|---|------|
| Volume (크기) | TB·PB 단위 대용량 |
| Velocity (속도) | 실시간 또는 고속 처리 |
| Variety (다양성) | 정형·반정형·비정형 데이터 |

**추가 V**: Veracity(정확성), Value(가치)

### 데이터 분석 유형

| 유형 | 내용 | 가치 |
|------|------|------|
| 기술 분석 | 과거 데이터 요약 | 낮음 |
| 진단 분석 | 원인 파악 | 중간 |
| 예측 분석 | 미래 예측 | 높음 |
| 처방 분석 | 최적 행동 제안 | 최고 |

## 4. 클라우드 컴퓨팅

인터넷을 통해 컴퓨팅 자원(서버, 저장장치, 소프트웨어)을 서비스로 제공.

| 서비스 모델 | 내용 | 예시 |
|------------|------|------|
| IaaS | 인프라 제공 | AWS EC2, Azure |
| PaaS | 플랫폼 제공 | Google App Engine |
| SaaS | 소프트웨어 제공 | Office 365, Salesforce |

**배포 모델**: 퍼블릭 / 프라이빗 / 하이브리드

## 5. 디지털 전환 기술

### AI (인공지능)
- **머신러닝**: 데이터에서 패턴 학습
- **딥러닝**: 신경망 기반 비정형 데이터 처리
- **NLP**: 자연어 처리 (챗봇, 번역)

### RPA (로봇 프로세스 자동화)
반복적 규칙 기반 업무를 소프트웨어 로봇이 자동 처리.
**장점**: 빠른 도입, 인력 비용 절감, 오류 감소.

### IoT (사물인터넷)
물리적 사물에 센서·네트워크 연결 → 데이터 수집·제어.
**스마트 공장 (Smart Factory)**: IoT + AI + 빅데이터로 생산 최적화.

### 블록체인
분산 원장 기술 — 거래 기록을 복수 노드에 분산 저장, 변조 불가.
**활용**: 스마트 계약, 공급망 추적, 디지털 자산.
