## JLPT(일본어능력시험)란?

```
JLPT (Japanese Language Proficiency Test):
→ 일본국제교류기금과 일본국제교육지원협회 주관
→ 전 세계 일본어 학습자 대상 공인 시험
→ 한국: 연 2회 시행 (7월, 12월)

등급 체계:
N5 (입문) → N4 (기초) → N3 (중급) → N2 (상급) → N1 (최고급)

합격 기준:
→ 각 과목 기준점 이상 + 총점 기준 이상 동시 충족
```

## 등급별 능력 기준

```
N5 (입문):
→ 기초 히라가나·가타카나 읽기
→ 기초적인 일본어 표현 이해
→ 어휘 약 800단어, 한자 약 100자

N4 (기초):
→ 일상 장면에서 기초 회화 가능
→ 어휘 약 1,500단어, 한자 약 300자

N3 (중급):
→ 일상 장면의 일본어를 어느 정도 이해
→ 어휘 약 3,750단어, 한자 약 650자

N2 (상급):
→ 일상 장면·사회 장면의 일본어 이해
→ 어휘 약 6,000단어, 한자 약 1,000자

N1 (최고급):
→ 폭넓은 상황에서 자연스러운 일본어 이해
→ 어휘 약 10,000단어, 한자 약 2,000자
```

## 합격 기준 (등급별)

```
점수 체계: 각 과목 0~60점, 총점 0~180점

N5 합격 기준:
→ 총점 80점 이상
→ 각 과목 기준점: 문자·어휘 38점, 청해 19점

N4 합격 기준:
→ 총점 90점 이상
→ 각 과목 기준점: 문자·어휘·문법 38점, 청해 19점

N3 합격 기준:
→ 총점 95점 이상
→ 각 과목 기준점: 문자·어휘·문법 19점, 독해 19점, 청해 19점

N2 합격 기준:
→ 총점 90점 이상
→ 각 과목 기준점: 문자·어휘·문법 19점, 독해 19점, 청해 19점

N1 합격 기준:
→ 총점 100점 이상
→ 각 과목 기준점: 문자·어휘·문법 19점, 독해 19점, 청해 19점
```

## JLPT 활용처

```
취업·진학:
→ N2 이상: 일본계 기업 취업 서류 우대
→ N1: 일본 대학원 입학, 일본 기업 정규직 지원 유리
→ 통역·번역 직종 필수 수준: N1

자격·면허:
→ 외국인 일본 내 의사·간호사 시험 응시: N2 이상 권장
→ 일부 직종 자격 취득 시 일본어 요건 충족

관광·문화:
→ N3: 일본 여행 시 독립 소통 가능
→ N2: 일본어 콘텐츠(드라마, 소설) 자막 없이 이해 가능
```

## N5 핵심 문법

```
기초 조사:
→ は (wa): 주제 표시 (저는...)
→ が (ga): 주어 표시 (제가 갑니다)
→ を (o): 목적어 표시 (밥을 먹다)
→ に (ni): 시간·장소·방향 (3시에, 학교에)
→ で (de): 수단·장소 (버스로, 카페에서)
→ の (no): 소유·수식 (제 책)
→ も (mo): 도 (나도)
→ と (to): 와/과 (친구와)

기초 동사 활용:
→ 일반형 (사전형): たべる (먹다), のむ (마시다)
→ ます형 (정중형): たべます, のみます
→ ない형 (부정형): たべない, のまない
→ て형 (연결): たべて, のんで

기초 표현:
→ ~です/~ます: 정중형 어미
→ ~ではありません: 부정 (~이 아닙니다)
→ ~たい: ~하고 싶다
→ ~てください: ~해 주세요
→ ~てもいいですか: ~해도 됩니까?
```

## N4 핵심 문법

```
사역·수동·수동사역:
→ 사역: ~させる (하게 하다)
→ 수동: ~られる (당하다, 되다)
→ 사역수동: ~させられる (억지로 하게 되다)

형식 명사:
→ こと: 추상적 사실 (泳ぐことができる: 수영할 수 있다)
→ もの: 물건, 일반적 사실
→ の: 설명·강조 (行くのは難しい: 가는 것은 어렵다)

추측·전문:
→ ~そうだ: ~할 것 같다 (외관 추측)
→ ~らしい: ~인 것 같다 (간접 정보)
→ ~ようだ: ~인 듯하다 (근거 있는 추측)
→ ~そうだ: ~라고 한다 (전문)

가정·조건:
→ ~たら: ~하면 (가정)
→ ~ば: ~하면 (조건)
→ ~なら: ~라면 (화제 제시)
→ ~と: ~하면 (자연스러운 결과)
```

## 자주 묻는 질문

**Q. JLPT N2와 N1은 얼마나 차이가 나나요?**
A. N2는 일상 및 사회적 상황을 이해하는 수준이고, N1은 복잡한 주제의 자연스러운 일본어를 이해하는 수준입니다. 어휘량이 N2 약 6,000단어 → N1 약 10,000단어로 대폭 늘어나고, 독해 지문도 훨씬 어렵습니다.

**Q. JLPT는 말하기·쓰기 시험이 없나요?**
A. 네, JLPT는 읽기·듣기·어휘·문법 위주로 말하기와 쓰기는 평가하지 않습니다. 말하기 능력이 필요하면 JLPT와 별도로 OPI(회화 능력 시험) 등을 고려할 수 있습니다.
