## 산업재산권 4종 핵심 비교

```
구분     특허      실용신안   상표        디자인
대상     발명      물품고안   표장        물품외관
기산     출원일    출원일     등록일      등록일
기간     20년      10년       10년+갱신   20년
심사     실체심사  무심사     실체심사    실체심사
갱신     불가      불가       무제한가능  불가

핵심 암기:
특허·실용신안 = 출원일 기산
상표·디자인 = 등록일 기산
상표만 갱신 무제한 (영구 보호 가능)
```

## 특허 요건 및 절차 핵심

```
특허 3요건:
신규성 + 진보성 + 산업상이용가능성 (신진산)

중요 기간:
공지예외 신청: 12개월 이내 + 신청 필수
출원 공개: 출원일로부터 1년 6개월
심사청구: 출원 후 3년 이내
거절이유 의견서: 2개월

실시권:
전용실시권: 물권적·독점·등록 필수
통상실시권: 채권적·비독점·등록 불요
법정실시권: 선사용권 (당연 발생)
```

## 침해·심판·소송 핵심

```
특허 침해:
문언 침해 → 균등론 침해 → 간접 침해

무효심판:
누구든 청구 가능
확정 시 소급 효력

특허법원:
심결취소소송 전속 관할

손해배상:
실시료 상당액 (최소 기준)
침해자 이익액 추정

형사:
7년/1억 이하, 친고죄
```

## 국제 출원 핵심

```
파리조약 우선권:
특허·실용신안: 12개월
상표·디자인: 6개월

PCT:
하나의 출원 → 전 세계 우선일
국내 단계 진입: 30개월 이내

디자인 존속: 20년 (등록일 기산)
상표 불사용 취소: 3년 연속 불사용
실용신안 무심사: 방식심사만
```

## 핵심 개념 카드

**산업재산권=특실상디(특20·실10·상10갱·디20)** ★★★★★
: 4종 존속기간과 기산점 완전 암기.
*암기 포인트: 특실=출원일, 상디=등록일*

**국제출원=파리12·PCT30** ★★★★★
: 파리조약 12개월, PCT 국내단계 30개월.
*암기 포인트: 파리=12, PCT=30*

**전용=등록물권, 통상=채권불요** ★★★★★
: 실시권 2종 완전 구별.
*암기 포인트: 전용=등록, 통상=불요*

## 실전 퀴즈

**Q. 특허법 기초에서 가장 자주 출제되는 3가지 주제는?**
> ① 존속기간 기산점: 특허·실용신안=출원일, 상표·디자인=등록일. ② 실시권 구별: 전용=물권·등록필수 vs 통상=채권·등록불요. ③ 무효심판 효력: 소급효 (처음부터 없었던 것). 추가: 파리조약 우선권 기간 (특허12, 상표6), PCT 국내단계 30개월. 진보성 판단 기준도 자주 출제.

**Q. 특허 포트폴리오 전략에서 특허·실용신안·디자인을 어떻게 조합하는가?**
> 핵심 기술: 특허 (20년, 방법·물질 포함). 파생 기술: 실용신안 (빠른 권리화, 10년). 외관 보호: 디자인 (20년, 미감 보호). 브랜드: 상표 (갱신 무제한). 중복 보호: 동일 제품에 특허+디자인+상표 동시 출원. 경쟁사 진입 장벽 형성이 전략 목표.
