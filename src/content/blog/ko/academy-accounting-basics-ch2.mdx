## 재무상태표란

**재무상태표(Statement of Financial Position)** — 구 명칭: 대차대조표(Balance Sheet)  
특정 시점에서 기업의 **자산, 부채, 자본** 현황을 보여주는 재무제표.

```
자산 = 부채 + 자본
(기업이 가진 것) = (빌린 것) + (내 것)
```

---

## 자산 (Assets)

기업이 보유하고 있는 경제적 자원으로, 미래에 경제적 효익을 가져다 줄 것이 예상되는 항목.

### 유동자산 (Current Assets)
1년 이내에 현금화가 가능한 자산.

| 항목 | 내용 |
|------|------|
| 현금 및 현금성자산 | 즉시 현금 전환 가능 |
| 단기금융상품 | 만기 1년 이내 예금·채권 |
| 매출채권 | 외상 판매 미수금 |
| 재고자산 | 판매용 상품·제품·원재료 |
| 선급비용 | 미리 지급한 비용 |

### 비유동자산 (Non-Current Assets)
1년 이후에 효익이 실현되는 장기 자산.

| 항목 | 내용 |
|------|------|
| 유형자산 | 토지, 건물, 기계장치 (감가상각 대상) |
| 무형자산 | 특허권, 영업권, 소프트웨어 |
| 투자자산 | 장기금융상품, 관계기업 투자 |
| 이연법인세자산 | 세무 차이로 발생 |

---

## 부채 (Liabilities)

기업이 타인에게 갚아야 할 의무. 미래의 경제적 자원 유출이 예상되는 항목.

### 유동부채 (Current Liabilities)
1년 이내에 상환해야 하는 부채.

| 항목 | 내용 |
|------|------|
| 매입채무 | 외상 구매 미지급금 |
| 단기차입금 | 만기 1년 이내 차입 |
| 미지급비용 | 발생했으나 미지급 비용 |
| 선수수익 | 미리 받은 수익 |

### 비유동부채 (Non-Current Liabilities)
1년 이후에 상환되는 장기 부채.

- 사채 (회사채)
- 장기차입금
- 퇴직급여부채
- 이연법인세부채

---

## 자본 (Equity / Stockholders' Equity)

자산에서 부채를 차감한 순자산. 주주의 청구권.

```
자본 = 자산 - 부채 = 순자산
```

| 구성 요소 | 내용 |
|---------|------|
| **자본금** | 발행 주식 액면 총액 |
| **자본잉여금** | 주식 발행 초과금 등 |
| **이익잉여금** | 누적 당기순이익 중 미배당 부분 |
| **기타포괄손익누계액** | 자산·부채 재평가 등 |
| **자기주식** | 매입 소각용 자사주 (차감 항목) |

## 재무상태표 분석 지표

**유동성 분석**:
```
유동비율 = 유동자산 / 유동부채 × 100%
(200% 이상: 양호)

당좌비율 = (유동자산 - 재고자산) / 유동부채 × 100%
(100% 이상: 양호)
```

**안정성 분석**:
```
부채비율 = 부채 / 자본 × 100%
(100% 이하: 안정적)

자기자본비율 = 자본 / 자산 × 100%
(50% 이상: 건전)
```

## 핵심 개념 카드

**유동자산 vs 비유동자산 기준** ★★★★★
: 1년이 기준. 1년 이내 현금화 = 유동자산, 1년 초과 = 비유동자산.
*암기 포인트: 유동 = 1년 이내*

**부채비율** ★★★★★
: 타인자본 의존도 측정. 부채 ÷ 자본 × 100%. 높을수록 재무 위험 증가.
*암기 포인트: 부채비율 100% = 부채와 자본이 동일*

**이익잉여금** ★★★★☆
: 과거부터 현재까지 쌓인 당기순이익 중 배당 지급 후 남은 금액. 기업의 내부 유보.
*암기 포인트: 이익잉여금 = 역대 순이익 - 역대 배당금*

## 실전 퀴즈

**Q. 기업의 매입채무와 매출채권은 각각 어디에 분류되는가?**
> 매출채권(물건 팔고 아직 못 받은 돈) → 유동자산. 매입채무(물건 사고 아직 못 준 돈) → 유동부채.

**Q. 부채비율이 300%인 기업과 50%인 기업을 비교하면?**
> 300%는 부채가 자본의 3배 → 재무 레버리지 높음, 경기 악화 시 부도 위험 큼. 50%는 부채가 자본의 절반 → 안정적, 하지만 투자 활용이 낮을 수 있음.
