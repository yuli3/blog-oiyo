## 재무회계 오답 포인트

```
① 충당부채 vs 우발부채
   → 충당부채=현재의무+가능+추정가능 (계상)
   → 우발부채=주석 공시만

② 유형자산 손상차손
   → 회수가능액 = MAX(순공정가치, 사용가치)
   → 순공정가치 아닌 둘 중 큰 값

③ 금융자산 분류 (IFRS 9)
   → AC·FVOCI·FVPL 3분류
   → FVOCI 평가손익=기타포괄손익

④ 재평가모형 재평가잉여금
   → 기타포괄손익 (당기손익 아님)

⑤ 리스 회계처리 (IFRS 16)
   → 운용리스도 사용권자산·부채 인식
   → 단기·소액 리스만 예외
```

## 원가·관리회계 오답 포인트

```
⑥ 공헌이익 = 매출 - 변동원가 (고정원가 아님)
⑦ BEP = 고정원가 / 단위공헌이익
⑧ 표준원가 차이: 가격차이·수량차이 구분
⑨ 전부원가 vs 변동원가
   → 생산량>판매량: 전부원가 이익 더 높음
⑩ ABC: 활동별 원가동인으로 간접비 배부
```

## 세무회계 오답 포인트

```
⑪ 익금산입 vs 손금불산입
   → 익금산입: 회계상 수익 아니나 과세
   → 손금불산입: 회계상 비용이나 불인정

⑫ 부가세 = 매출세액 - 매입세액
   → 매입세액 환급 = 납부세액 음수 시

⑬ 영세율 vs 면세
   → 영세율: 매입세액 환급 가능
   → 면세: 환급 불가

⑭ 종합소득 vs 분류과세
   → 퇴직·양도소득 = 분류과세 (합산 안함)

⑮ 소득세 세율 = 6~45% (8단계 누진)
```

## 감사·회계기준 오답 포인트

```
⑯ 감사의견 4종류
   → 적정·한정·부적정·의견거절
   → 의견거절≠부적정 (범위 제한 vs 중요 왜곡)

⑰ 감사인 독립성
   → 정신적·외관적 독립성 모두 필요

⑱ 중요성
   → 재무제표 왜곡 허용 기준
   → 금액·성격·상황에 따라 판단

⑲ 내부통제
   → 통제환경·위험평가·통제활동·정보·모니터링

⑳ 연결재무제표
    → 지배·종속회사 일체 작성
    → 내부거래 제거
```

## 핵심 개념 카드

**충당부채 3요건=현유신** ★★★★★
: 현재의무+유출가능+신뢰성추정.
*암기 포인트: 현유신*

**감사의견=적한부의** ★★★★★
: 적정·한정·부적정·의견거절.
*암기 포인트: 적한부의*

**영세율=매입환급, 면세=환급불가** ★★★★☆
: 핵심 구별 포인트.
*암기 포인트: 영세율=환급O, 면세=환급X*

## 실전 퀴즈

**Q. 감사의견 중 부적정과 의견거절의 차이는?**
> 부적정: 재무제표가 중요하게 왜곡 → 전체적으로 신뢰 불가. 의견거절: 감사 범위가 제한되어 의견 표명 불가. 기업이 자료를 안 주거나 감사 방해 시 의견거절. 부적정은 봤더니 틀렸다, 의견거절은 못 봤다.

**Q. 연결재무제표에서 내부거래를 제거하는 이유는?**
> 지배·종속 간 거래는 경제적 실질 관점에서 외부 거래가 아님. 제거 안 하면 매출·비용·자산 부풀려짐. 예: 모회사가 자회사에 판매 → 그룹 전체로는 아직 외부 미판매. 내부이익·내부채권채무 모두 제거.
