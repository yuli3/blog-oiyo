## 노인 일자리 사업이란?

만 60세 이상 (일부 사업 65세 이상) 어르신께 사회 참여 기회와 소득을 제공하는 국가 지원 사업입니다. 전국적으로 연간 약 100만 명 이상이 참여합니다.

---

## 일자리 유형 3가지

### 공공형 (사회활동형)

```
대상: 만 65세 이상
내용: 교통 정리, 학교 급식 지원, 환경 정화, 복지시설 지원 등
활동 시간: 월 30시간 (하루 3시간 × 주 3회 기준)
활동비: 월 29만원 (2024년 기준)
특징:
- 고용 형태가 아닌 '사회공헌 활동'
- 전국 읍·면·동 단위 배정
- 지원자 많으면 추첨 or 대기
```

### 사회서비스형

```
대상: 만 65세 이상
내용: 노인 돌봄, 아동 안전 지킴이, 장애인 지원 등
활동 시간: 월 60시간 (하루 4~5시간, 주 4일)
활동비: 월 59만 4,000원 (2024년 기준)
특징:
- 공공형보다 더 전문적인 역할
- 경력이나 전문성 있는 분 우대 배정
```

### 민간형 (시장형·취업 알선형)

```
시장형 (소규모 사업단):
- 공동 작업장 운영 (택배 보조, 세탁, 공예 판매 등)
- 수익 일부를 활동비로 지급
- 수입: 최저임금 기준 이상 가능

취업 알선형:
- 기업 취업 연계 (시니어 인턴십 등)
- 근로 계약 후 최저임금 적용
- 만 60세 이상 가능
```

## 신청 자격

```
공공형·사회서비스형:
- 만 65세 이상 (일부 사업 만 60세 이상)
- 기초연금 수급 여부 무관
- 건강 상태 일상 활동 가능

민간형 취업 알선:
- 만 60세 이상
- 근로 능력 있는 어르신

중복 제한:
- 다른 정부 급여(일부 제외)와 중복 가능 여부 확인 필요
```

---

## 신청 방법

### 절차

```
1단계: 1월~2월 신청 기간 (지역마다 상이)
       → 반드시 해당 기간에 신청

2단계: 주민센터(행정복지센터) or 노인복지관 방문
       → 신청서 작성 + 서류 제출

3단계: 배정 결과 통보 (2~3월)

4단계: 참여 교육 후 3월경 활동 시작
```

### 신청 장소

```
- 거주 지역 읍·면·동 주민센터
- 가까운 노인복지관 (시·군·구 지정)
- 시니어클럽 (취업 알선형)
- 대한노인회 지회
```

## 활동비 정리

| 유형 | 월 활동비 | 월 시간 |
|------|---------|--------|
| 공공형 | 29만원 | 30시간 |
| 사회서비스형 | 59만 4,000원 | 60시간 |
| 시장형 | 수익 기반 | 개별 계약 |
| 취업 알선형 | 최저임금 기준 | 근로 계약 |

---

## 기초연금과의 관계

```
공공형·사회서비스형 활동비:
→ 소득으로 인정되어 기초연금 소득인정액에 포함될 수 있음
→ 단, 월 29만원의 활동비는 공제 후 계산되므로
   대부분 기초연금 수급 자격에 큰 영향 없음

→ 정확한 영향은 거주 관할 주민센터에 문의 권장
```

---

## 신청 시 주의사항

```
1. 1월 신청 놓치면 1년 기다려야 함:
   → 대부분 연 1회 모집, 1~2월이 핵심 신청 기간
   
2. 조기 신청 권장:
   → 인기 사업단은 접수 시작 직후 마감
   
3. 같은 사업에 배정 보장 없음:
   → 매년 재신청, 사업 유형이 바뀔 수 있음
   
4. 건강 상태 확인:
   → 활동 불가한 질환 있으면 참여 제한
```

## 지역별 사업 예시

```
도시 지역:
- 교통 안전 지킴이 (학교 앞 어린이 교통 지도)
- 복지시설 지원 (어린이집, 경로당 보조)
- 환경 정화 활동 (공원, 거리 청소)

농어촌 지역:
- 영농 보조 활동
- 어촌 환경 정비
- 취약 노인 안부 확인
```

## 더 많은 수입을 원한다면

```
노인 일자리 사업 외 추가 소득 방법:

1. 요양보호사 취업:
   → 자격증 취득 후 재가 요양으로 월 100~260만원
   → 가족 요양보호사로 월 50~60만원

2. 시니어 인턴십:
   → 기업 연계 인턴, 최저임금 적용
   → 고용센터에서 신청

3. 고용 가능 연령 상한 없는 직종:
   → 경비, 주차 관리, 택배 분류, 제조업 단순 작업
```

## 자주 묻는 질문

**Q. 부부 모두 신청할 수 있나요?**
A. 각각 개인 자격으로 신청 가능합니다. 부부가 같은 사업단에 배정될 수도 있고 다른 곳에 배정될 수도 있습니다.

**Q. 신청했는데 탈락하면 어떻게 되나요?**
A. 대기자로 등록되어 결원 발생 시 순차 배정됩니다. 다음 연도에 재신청할 수 있습니다.

**Q. 활동 중 건강 문제로 중단해야 하면?**
A. 중도 탈퇴 시 활동한 기간만큼의 활동비가 지급됩니다. 다음 연도 재신청에는 일반적으로 불이익 없습니다.

**Q. 65세가 아직 안 됐는데 신청할 수 있나요?**
A. 민간형 취업 알선은 만 60세 이상부터 가능합니다. 공공형과 사회서비스형은 만 65세부터입니다.
