## 볼린저 밴드 (Bollinger Bands)

존 볼린저(John Bollinger)가 1980년대 개발. 이동평균을 중심으로 표준편차를 활용한 동적 밴드입니다.

```
구성:
중심선: 20일 단순이동평균 (SMA)
상단 밴드: 중심선 + (2 × 표준편차)
하단 밴드: 중심선 - (2 × 표준편차)

통계적 의미:
→ 가격의 약 95%가 밴드 내에 존재
→ 밴드 폭 = 현재 변동성 척도
```

## 볼린저 밴드 해석

### 밴드 폭 (Bandwidth)

```
밴드 스퀴즈 (Squeeze):
→ 밴드 폭 좁아짐 = 변동성 수축 = 폭발적 움직임 준비 중
→ 방향은 알 수 없음 → 돌파 방향 확인 후 진입

밴드 확장:
→ 변동성 급증 = 강한 추세 확인
→ 상단 밴드 타고 올라가면 강한 상승 추세
```

### 가격과 밴드의 관계

```
밴드 워크 (Band Walk):
→ 강한 추세에서 가격이 밴드를 따라 이동
→ 상단 밴드 워크 = 강한 상승 (매도 신호 아님!)

반전 신호:
→ W 바닥: 하단 밴드 터치 → 반등 → 재차 하단 근접 but 밴드 터치 못함 → 매수
→ M 천장: 상단 밴드 터치 → 하락 → 재차 상단 근접 but 밴드 터치 못함 → 매도
```

## ATR (평균 실제 범위, Average True Range)

웰스 와일더(J. Welles Wilder) 개발. 변동성을 절대값으로 측정:

```
TR (True Range) = MAX of:
1. 현재 고가 - 현재 저가
2. |현재 고가 - 전일 종가|
3. |현재 저가 - 전일 종가|

ATR = 14일 TR의 지수이동평균
```

### ATR 활용 — 손절 설정

```
ATR 기반 손절:
매수 진입 시: 진입가 - (2 × ATR) = 손절가
매도 진입 시: 진입가 + (2 × ATR) = 손절가

예시:
삼성전자 진입가 70,000원, ATR = 1,500원
손절가 = 70,000 - (2 × 1,500) = 67,000원

장점:
→ 변동성에 맞는 논리적 손절 (단순 % 손절보다 정교)
→ 변동성 크면 여유 있는 손절 / 작으면 타이트한 손절
```

### ATR 기반 포지션 크기 계산

```
위험 금액 = 계좌의 1~2%
포지션 크기 = 위험 금액 ÷ (2 × ATR)

예시:
계좌 1,000만 원, 리스크 1% = 10만 원
ATR = 1,500원
포지션 크기 = 100,000 ÷ (2 × 1,500) = 33주
```

## 볼린저 밴드 + 켈트너 채널 스퀴즈

TTM 스퀴즈(존 카터 전략):

```
켈트너 채널:
중심선: 20일 EMA
상단: 20일 EMA + (1.5 × ATR)
하단: 20일 EMA - (1.5 × ATR)

스퀴즈 조건:
볼린저 밴드 &lt; 켈트너 채널 내부 → 스퀴즈 발생
= 변동성 극도로 수축 = 폭발적 움직임 임박

방향 판단:
스퀴즈 해제 시 모멘텀 방향 확인 → 매매 진입
```

## 핵심 암기 포인트

*볼린저 밴드 스퀴즈 = 변동성 수축 = 폭발 준비 (방향은 모름)*
*밴드 워크 ≠ 과매수/과매도 (강한 추세는 밴드 따라 이동)*
*ATR 손절: 진입가 ± 2×ATR (변동성 맞춤 논리적 손절)*
*포지션 크기 = 계좌 리스크 금액 ÷ (2×ATR)*
