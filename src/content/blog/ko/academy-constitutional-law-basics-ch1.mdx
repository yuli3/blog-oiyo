## 헌법의 의의

**헌법(憲法)**: 국가의 최고 규범. 국가 구조·통치 조직·국민의 기본권을 규정.

```
헌법의 특성:
① 최고 규범성: 모든 법령은 헌법에 위배될 수 없음
② 기본권 보장 규범: 국가에 대한 개인의 권리 보장
③ 권력 제한 규범: 국가 권력의 범위와 한계 설정
④ 조직 수권 규범: 국가 기관 설치·권한 부여

헌법 ↔ 법률 구별:
- 헌법: 국민 투표 또는 특별 절차로 개정
- 법률: 국회 의결
- 헌법 위반 법률 → 위헌 → 효력 없음
```

## 헌법의 기본 원리

### 국민 주권의 원리

```
헌법 제1조:
① 대한민국은 민주공화국이다.
② 대한민국의 주권은 국민에게 있고, 모든 권력은 국민으로부터 나온다.

국민 주권:
- 선거: 대표 선출
- 국민 투표: 헌법 개정·중요 정책 (헌법 제72조)
- 국민 소환: 헌법상 명문 규정 없음
```

### 자유민주주의 원리

```
자유민주주의 = 자유주의 + 민주주의

자유주의:
- 개인의 자유·권리 존중
- 국가 권력으로부터의 자유 (소극적 자유)
- 법치주의: 법률에 의한 지배

민주주의:
- 국민 자치
- 대의민주주의 (간접 민주주의)
- 복수 정당제·정치적 다원주의
```

### 법치주의의 원리

```
형식적 법치주의:
- 법률에 의한 지배 (형식적 합법성)
- 법률만 있으면 기본권 제한 가능

실질적 법치주의 (현대 헌법):
- 법률의 내용도 정의로워야 함
- 과잉 금지 원칙 (비례의 원칙)
- 기본권의 본질적 내용 침해 금지

비례의 원칙 (헌법 제37조 제2항):
목적의 정당성 → 수단의 적합성 → 피해의 최소성 → 법익의 균형성
```

### 사회국가(복지국가)의 원리

```
사회국가 원리:
- 실질적 평등 추구
- 사회적 약자 보호
- 국가의 적극적 역할

관련 조항:
- 제34조: 인간다운 생활을 할 권리
- 제31조: 교육 기회 균등
- 제32조: 근로 기회 제공
- 제119조 제2항: 경제 민주화
```

## 헌법 개정

### 헌법 개정 절차

```
헌법 개정 발의:
① 국회 재적의원 과반수 발의
② 대통령 발의

국회 의결:
- 재적의원 2/3 이상 찬성

국민 투표:
- 국회 의결 후 30일 이내 실시
- 국회의원 선거권자 과반수 투표 + 투표자 과반수 찬성

공포:
- 대통령 공포

주의: 대통령 임기 연장·중임 변경 개정은
헌법 개정 당시 대통령에게 적용 불가 (헌법 제128조)
```

```
헌법 전문 주요 내용:
- 3·1 운동 정신 계승
- 임시정부 법통 계승
- 4·19 민주 이념 계승
- 평화 통일 지향
- 기회 균등

헌법 전문의 법적 성격:
- 헌법의 일부 → 법적 효력 있음
- 재판 규범으로서의 효력 인정
- 국가의 기본 가치·목적 선언
```

## 핵심 개념 카드

**헌법 개정 정족수** ★★★★★
: 발의=국회 재적의원 과반수, 의결=재적 2/3, 국민투표=투표자 과반수 찬성.
*암기 포인트: 과반수 발의 → 2/3 의결 → 국민투표*

**비례의 원칙 4단계** ★★★★★
: 목적 정당성 → 수단 적합성 → 피해 최소성 → 법익 균형성. 기본권 제한 한계.
*암기 포인트: 목적·수단·최소·균형*

**실질적 법치주의** ★★★★☆
: 법률의 형식만이 아닌 내용의 정의성도 요구. 위헌 법률은 무효.
*암기 포인트: 형식+내용 모두 정의로워야 = 실질 법치*

## 실전 퀴즈

**Q. 헌법 개정 시 국회 의결 정족수는?**
> 재적의원 2/3 이상 찬성. (일반 법률은 재적 과반수 출석 + 출석 과반수.)

**Q. 비례의 원칙(과잉 금지 원칙) 4단계를 순서대로 쓰시오.**
> ① 목적의 정당성 ② 수단의 적합성 ③ 피해의 최소성 ④ 법익의 균형성.
