# 연봉 협상 계산기

연봉 협상 시즌이 되면 "얼마나 올려달라고 해야 할까?" 막막하기 쉽습니다. 현재 연봉과 목표를 숫자로 명확히 보면 협상이 훨씬 수월해집니다.

## 연봉 인상률 벤치마크 (2024 기준)

| 구분 | 평균 인상률 |
|---|---|
| 국내 대기업 | 4–7% |
| 중견기업 | 3–5% |
| 스타트업 (성과 좋은 경우) | 10–20%+ |
| 이직 시 연봉 협상 | **현재 연봉 +15–30%** 가능 |
| 물가상승률 (2024) | 약 2.3% |

<Callout type="tip">
**이직이 최고의 연봉 협상**: 통계적으로 이직 시 연봉 인상폭(평균 20%)이 재직 중 협상(평균 3–5%)보다 훨씬 큽니다. 커리어 계획에 이직을 전략적 도구로 활용하세요.
</Callout>

## 협상 전략 체크리스트

| 준비 항목 | 내용 |
|---|---|
| 시장 시세 조사 | 잡코리아·사람인·링크드인 연봉 데이터 |
| 성과 문서화 | 수치로 증명 가능한 기여 목록 |
| BATNA 확보 | 다른 오퍼 또는 이직 의지 준비 |
| 목표 범위 설정 | 최저선·목표선·이상선 3단계 |
| 타이밍 | 성과 평가 직후, 프로젝트 완료 후 |

## 연봉 협상 대화 예시

**잘못된 접근**  
"저 연봉 좀 올려주세요. 생활비가 부족해서요."

**좋은 접근**  
"지난 분기 담당 프로젝트에서 매출 15% 기여, 고객 유지율 8% 향상을 달성했습니다. 시장 시세를 조사한 결과, 제 직급·경력 대비 OO만원 수준이 적정하다고 생각합니다. 현재 연봉에서 OO% 인상을 요청드립니다."

<Callout type="note">
실수령액은 4대 보험료(건강보험·국민연금·고용보험·산재보험)와 근로소득세가 공제됩니다. 연봉 5,000만원 기준 실수령액은 약 3,750–3,900만원 수준입니다.
</Callout>
