## 1. 노출이란?

사진의 밝기를 결정하는 것이 **노출(Exposure)**입니다. 사진이 너무 밝으면 **과노출(Overexposure)**, 너무 어두우면 **부족노출(Underexposure)**이라고 합니다.

올바른 노출을 얻기 위한 세 가지 요소를 **노출 삼각형**이라고 부릅니다.

| 설정 | 직접 바뀌는 것 |
| --- | --- |
| 조리개 | 입사광의 양·피사계 심도 |
| 노출 시간 | 빛을 모으는 시간·움직임 표현 |
| ISO | 신호 증폭·출력 밝기, 입사광 자체는 아님 |

이 세 요소가 서로 균형을 이루어야 원하는 밝기의 사진을 얻을 수 있습니다.

## 2. 셔터속도 (Shutter Speed)

셔터가 열려 있는 시간으로, **빛이 센서에 닿는 시간**을 결정합니다.

### 가. 표기 방법

| 노출 시간 변화 | 다른 설정이 같을 때 |
| --- | --- |
| 1/1000초 → 1/500초 | 시간·입사광이 두 배, 움직임 번짐 가능성 증가 |
| 1/500초 → 1/250초 | 한 스톱 더 많은 빛 |
| 1초 → 2초 | 시간·입사광이 두 배, 장노출에서 움직임 누적 |

### 나. 셔터속도의 두 가지 역할

**1. 밝기 조절**: 느릴수록 더 많은 빛 → 밝은 사진

**2. 움직임 표현**:

| 셔터속도 | 효과 | 적합한 피사체 |
|----------|------|--------------|
| 1/1000s 이상 | 순간 포착 (피사체 선명) | 스포츠, 새, 물방울 |
| 1/250s | 일반 움직임 정지 | 걷는 사람, 자동차 |
| 1/60s | 약간의 흔들림 | 초상 (핸드헬드 한계) |
| 1/30s 이하 | 움직임 블러 | 폭포, 빛의 궤적 |
| 수 초 이상 | 완전한 빛의 궤적 | 별 궤적, 야경 |

> **핸드블러 방지**: 보통 `1/(초점거리)s` 이상이 필요합니다. 50mm 렌즈라면 1/50s 이상 확보.

## 3. 조리개 (Aperture)

렌즈 내부의 빛 통과 구멍 크기를 **f값(f-stop)**으로 표현합니다.

### 가. f값의 역설적 관계

대표적인 한 스톱 계열은 f/1.4, f/2, f/2.8, f/4, f/5.6, f/8, f/11, f/16이다. 숫자가 한 단계 커질 때 입사광은 대략 절반이 된다. f값은 초점거리와 입사동공 지름의 비이며, 정확한 한 스톱 비는 $\sqrt{2}$다.

> **주의**: f값이 **작을수록** 구멍이 **큰** 것입니다 (역수 관계).

### 나. 심도(Depth of Field)

조리개의 두 번째 역할은 **초점이 맞는 범위(심도)**를 결정하는 일입니다.

| 조리개 | 내용·조건 |
| --- | --- |
| f/1.4~f/2.8 | 심도: **얕은 심도**; 배경: 크게 흐려짐(보케); 용도: 인물, 제품 사진 |
| f/4~f/5.6 | 심도: 중간 심도; 배경: 적당히 흐려짐; 용도: 일상 스냅 |
| f/8~f/11 | 심도: 깊은 심도에 유리; 배경: 선명한 범위를 넓히는 경향; 용도: 풍경, 건축 |
| f/16 이상 | 심도: 깊은 심도에 유리; 배경: 회절로 미세 선명도 저하 가능; 용도: 스타버스트 효과 |

이 표는 같은 초점거리와 촬영 거리에서의 경향이다. 심도는 f값만으로 결정되지 않으며, 조리개를 조인다고 배경 전체가 선명해지는 것은 아니다.

## 4. ISO (감도)

디지털 카메라에서 ISO는 신호 증폭과 출력 밝기에 관련된 설정이다. 조리개·셔터·조명이 같다면 ISO만 올려도 센서가 받는 광자 수는 늘지 않는다.

ISO 100, 200, 400, 800, 1600, 3200, 6400은 한 스톱 간격의 표시값이다. 같은 밝기로 보정한 결과의 노이즈는 입사광과 읽기 노이즈, 증폭·처리 방식에도 영향을 받는다. 높은 ISO 자체가 언제나 새 노이즈를 만들어 낸다고 단정하지 않는다.

### 가. ISO 선택 기준

| 상황 | 권장 ISO |
|------|----------|
| 맑은 야외 | ISO 100~200 |
| 흐린 날/그늘 | ISO 400 |
| 실내 (밝은 조명) | ISO 800~1600 |
| 실내 (어두운 조명) | ISO 3200~6400 |
| 야간/콘서트 | ISO 6400 이상 |

> **원칙**: 가능하면 ISO는 낮게 유지하고, 셔터속도와 조리개로 먼저 노출을 맞춥니다.

## 5. 노출 삼각형의 상호 관계

세 요소는 서로 **연동**된다. 하나를 바꾸면 나머지 중 하나 이상으로 밝기를 보완할 수 있다. 같은 입사광을 유지하는 것과 ISO로 출력 밝기를 맞추는 것은 구별한다.

### 가. 1스톱(Stop) 개념

셔터·조리개의 광학 노출에서 한 스톱은 입사광을 두 배 또는 절반으로 바꾸는 간격이다. ISO 한 스톱은 출력 설정의 변화이며 입사광 증가와 구별한다.

- **셔터**: 1/500 → 1/250 (1스톱 느려짐) → 빛 2배
- **조리개**: f/5.6 → f/4 (1스톱 열림) → 빛 2배
- **ISO**: ISO 200 → ISO 400 (1스톱 증가) → 출력 밝기 약 두 배, 입사광 증가 아님

### 나. 상황별 최적 설정 예시

**인물 사진 (야외 맑은 날)**
- **셔터**: 1/250s (자연스러운 움직임 정지)
- **조리개**: f/2.8 (배경 흐리기)
- **ISO**: 100~200 (노이즈 최소화)

**풍경 사진 (삼각대 사용)**
- **셔터**: 1/30s~수 초 (삼각대 필수)
- **조리개**: f/8~f/11 (전체 선명)
- **ISO**: 100 (최저 노이즈)

**스포츠/동물 사진**
- **셔터**: 1/1000s 이상 (움직임 정지)
- **조리개**: f/4~f/5.6 (적당한 배경 분리)
- **ISO**: 상황에 따라 800~3200

**야간 도시 사진 (삼각대)**
- **셔터**: 5~30초 (빛의 궤적)
- **조리개**: f/8 (전체 선명 + 스타버스트)
- **ISO**: 100~400 (노이즈 최소화)

## 6. 히스토그램 읽기

히스토그램은 사진의 **밝기 분포**를 그래프로 보여줍니다.

가로축은 어두움에서 밝음으로, 세로축은 해당 밝기의 픽셀 수를 나타낸다. 0~255는 8비트 출력값의 예이며 RAW 센서값의 보편적 경계가 아니다.

| 히스토그램 모양 | 의미 |
|----------------|------|
| 왼쪽에 치우침 | 어두운 피사체·로우키 의도일 수 있음 |
| 오른쪽에 치우침 | 밝은 피사체·하이키 의도일 수 있음 |
| 고르게 분포 | 밝기 범위가 넓음; 적정 노출의 보증은 아님 |
| 오른쪽 끝이 잘림 | 표시된 출력의 하이라이트 클리핑; RAW 데이터 확인 필요 |
| 왼쪽 끝이 잘림 | 섀도우 클리핑 |

> **목표**: 중요한 영역의 디테일을 확인한다. 광원이나 의도적인 실루엣은 클리핑을 허용할 수도 있다. RAW에 일부 정보가 남아 있다면 보정 여지가 있지만, 기록되지 않은 디테일은 복구할 수 없다.

## 실전 퀴즈 5문항

**Q1.** 같은 조명과 조리개에서 1/250초·ISO 400을 1/500초·ISO 800으로 바꾸면 무엇이 달라지는가?
- ① 입사광과 출력 밝기가 모두 두 배가 된다
- ② 입사광은 절반, 출력 밝기는 대략 비슷하다
- ③ 입사광과 출력 밝기가 모두 변하지 않는다
- ④ ISO가 새 광자를 추가한다

**정답**: ②. 노출 시간이 절반이므로 입사광도 절반이다. ISO로 밝기는 보완할 수 있지만 광자 부족을 없앨 수는 없다.

---

**Q2.** 같은 초점거리·피사체와 배경 거리에서 f/1.8과 f/11 중 배경이 더 흐려지는 것은?
- ① f/1.8  ② f/11  ③ 동일  ④ 알 수 없음

**정답**: ① *(f값이 작을수록 얕은 심도 → 배경 흐려짐)*

---

**Q3.** 낮은 입사광에서 ISO로 출력 밝기를 높일 때 유의할 점은?
- ① 사진이 어두워짐
- ② 색이 바랜다
- ③ 입사광 부족에 따른 노이즈가 눈에 띌 수 있으며 ISO만으로 해결되지 않는다
- ④ 초점이 흐려진다

**정답**: ③. 노이즈는 읽기 노이즈와 증폭·처리에도 영향을 받으므로 ISO 하나만의 보편적 인과관계로 단정하지 않는다.

---

**Q4.** 셔터·조리개의 광학 노출에서 1스톱 변화의 의미로 옳은 것은?
- ① 셔터속도를 10배 증가
- ② 빛의 양을 2배 또는 1/2로 변화
- ③ ISO를 100 증가
- ④ 조리개를 0.5 증가

**정답**: ②

---

**Q5.** 히스토그램이 오른쪽 끝에서 잘렸을 때 가장 먼저 확인할 것은?
- ① 사진이 너무 어둡다
- ② 노이즈가 많다
- ③ 중요한 영역의 클리핑과 RAW에 남은 데이터
- ④ 셔터속도가 너무 빠르다

**정답**: ③. 표시된 출력의 클리핑만으로 RAW의 모든 정보가 소실됐다고 단정하지 않는다. 실제로 기록되지 않은 정보는 복구되지 않는다.
