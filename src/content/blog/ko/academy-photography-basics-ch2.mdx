## 노출이란?

사진의 밝기를 결정하는 것이 **노출(Exposure)**입니다. 사진이 너무 밝으면 **과노출(Overexposure)**, 너무 어두우면 **부족노출(Underexposure)**이라고 합니다.

올바른 노출을 얻기 위한 세 가지 요소를 **노출 삼각형**이라고 부릅니다.

```
       노출 삼각형
         ISO
        /     \
  셔터속도 ─── 조리개
```

이 세 요소가 서로 균형을 이루어야 원하는 밝기의 사진을 얻을 수 있습니다.

---

## 셔터속도 (Shutter Speed)

셔터가 열려 있는 시간으로, **빛이 센서에 닿는 시간**을 결정합니다.

### 표기 방법

```
1/4000s → 1/2000s → 1/1000s → 1/500s → 1/250s → 1/125s
빠름 ←←←←←←←←←←←←←←←←←←←←←←←←←←←→→→→ 느림
어두움 ←←←←←←←←←←←←←←←←←←←←←←←←←←←→→→ 밝음
```

### 셔터속도의 두 가지 역할

**1. 밝기 조절**: 느릴수록 더 많은 빛 → 밝은 사진

**2. 움직임 표현**:

| 셔터속도 | 효과 | 적합한 피사체 |
|----------|------|--------------|
| 1/1000s 이상 | 순간 포착 (피사체 선명) | 스포츠, 새, 물방울 |
| 1/250s | 일반 움직임 정지 | 걷는 사람, 자동차 |
| 1/60s | 약간의 흔들림 | 초상 (핸드헬드 한계) |
| 1/30s 이하 | 움직임 블러 | 폭포, 빛의 궤적 |
| 수 초 이상 | 완전한 빛의 궤적 | 별 궤적, 야경 |

> **핸드블러 방지**: 보통 `1/(초점거리)s` 이상이 필요합니다. 50mm 렌즈라면 1/50s 이상 확보.

## 조리개 (Aperture)

렌즈 내부의 빛 통과 구멍 크기를 **f값(f-stop)**으로 표현합니다.

### f값의 역설적 관계

```
f/1.4  f/2  f/2.8  f/4  f/5.6  f/8  f/11  f/16
←── 구멍 큼 ───────────────────────── 구멍 작음 ──→
←── 밝음 ─────────────────────────────── 어두움 ──→
```

> **주의**: f값이 **작을수록** 구멍이 **큰** 것입니다 (역수 관계).

### 심도(Depth of Field)

조리개의 두 번째 역할은 **초점이 맞는 범위(심도)**를 결정하는 것입니다.

| f값 | 심도 | 배경 | 용도 |
|-----|------|------|------|
| f/1.4~f/2.8 | **얕은 심도** | 크게 흐려짐(보케) | 인물, 제품 사진 |
| f/4~f/5.6 | 중간 심도 | 적당히 흐려짐 | 일상 스냅 |
| f/8~f/11 | **깊은 심도** | 전체 선명 | 풍경, 건축 |
| f/16 이상 | 매우 깊은 심도 | 매우 선명 | 스타버스트 효과 |

## ISO (감도)

카메라 센서가 빛에 반응하는 민감도입니다.

```
ISO 100 → ISO 200 → ISO 400 → ISO 800 → ISO 1600 → ISO 3200 → ISO 6400
낮은 감도                                                        높은 감도
어두움                                                          밝음
노이즈 적음                                                     노이즈 많음
```

### ISO 선택 기준

| 상황 | 권장 ISO |
|------|----------|
| 맑은 야외 | ISO 100~200 |
| 흐린 날/그늘 | ISO 400 |
| 실내 (밝은 조명) | ISO 800~1600 |
| 실내 (어두운 조명) | ISO 3200~6400 |
| 야간/콘서트 | ISO 6400 이상 |

> **원칙**: 가능하면 ISO는 낮게 유지하고, 셔터속도와 조리개로 먼저 노출을 맞춥니다.

## 노출 삼각형의 상호 관계

세 요소는 서로 **연동**됩니다. 하나를 바꾸면 다른 두 요소를 조정해야 같은 밝기를 유지할 수 있습니다.

### 1스톱(Stop) 개념

1스톱은 **빛의 양을 2배 또는 1/2로** 변화시킵니다.

```
셔터: 1/500 → 1/250 (1스톱 느려짐) → 빛 2배
조리개: f/5.6 → f/4 (1스톱 열림) → 빛 2배
ISO: ISO 200 → ISO 400 (1스톱 증가) → 감도 2배
```

### 상황별 최적 설정 예시

**인물 사진 (야외 맑은 날)**
```
셔터: 1/250s (자연스러운 움직임 정지)
조리개: f/2.8 (배경 흐리기)
ISO: 100~200 (노이즈 최소화)
```

**풍경 사진 (삼각대 사용)**
```
셔터: 1/30s~수 초 (삼각대 필수)
조리개: f/8~f/11 (전체 선명)
ISO: 100 (최저 노이즈)
```

**스포츠/동물 사진**
```
셔터: 1/1000s 이상 (움직임 정지)
조리개: f/4~f/5.6 (적당한 배경 분리)
ISO: 상황에 따라 800~3200
```

**야간 도시 사진 (삼각대)**
```
셔터: 5~30초 (빛의 궤적)
조리개: f/8 (전체 선명 + 스타버스트)
ISO: 100~400 (노이즈 최소화)
```

## 히스토그램 읽기

히스토그램은 사진의 **밝기 분포**를 그래프로 보여줍니다.

```
         ▓▓▓
      ▓▓▓▓▓▓▓▓
   ▓▓▓▓▓▓▓▓▓▓▓▓▓
 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
──────────────────────
어두움   중간    밝음
 0              255
```

| 히스토그램 모양 | 의미 |
|----------------|------|
| 왼쪽에 치우침 | 부족노출 (사진이 어두움) |
| 오른쪽에 치우침 | 과노출 (사진이 밝음) |
| 고르게 분포 | 적정 노출 |
| 오른쪽 끝이 잘림 | 하이라이트 클리핑 (복구 불가) |
| 왼쪽 끝이 잘림 | 섀도우 클리핑 |

> **목표**: 히스토그램이 좌우 끝에서 잘리지 않도록 유지합니다.

## 실전 퀴즈 5문항

**Q1.** 움직이는 물체를 선명하게 담으려면 어떤 설정이 필요한가?
- ① 느린 셔터속도 + 낮은 ISO
- ② 빠른 셔터속도 + 높은 ISO
- ③ 낮은 f값 + 느린 셔터속도
- ④ 높은 f값 + 빠른 셔터속도

**정답**: ② *(빠른 셔터로 움직임 정지, 어두워진 만큼 ISO로 보완)*

---

**Q2.** f/1.8과 f/11 중 배경이 더 흐려지는 것은?
- ① f/1.8  ② f/11  ③ 동일  ④ 알 수 없음

**정답**: ① *(f값이 작을수록 얕은 심도 → 배경 흐려짐)*

---

**Q3.** ISO를 높였을 때 나타나는 부작용은?
- ① 사진이 어두워짐
- ② 색이 바랜다
- ③ 노이즈(입자감)가 증가한다
- ④ 초점이 흐려진다

**정답**: ③

---

**Q4.** 1스톱의 의미로 옳은 것은?
- ① 셔터속도를 10배 증가
- ② 빛의 양을 2배 또는 1/2로 변화
- ③ ISO를 100 증가
- ④ 조리개를 0.5 증가

**정답**: ②

---

**Q5.** 히스토그램이 오른쪽 끝에서 잘렸다는 것은 무엇을 의미하는가?
- ① 사진이 너무 어둡다
- ② 노이즈가 많다
- ③ 하이라이트 영역이 날아가 복구 불가
- ④ 셔터속도가 너무 빠르다

**정답**: ③
