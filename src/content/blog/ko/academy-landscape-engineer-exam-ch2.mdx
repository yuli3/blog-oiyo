## 조경계획의 과정

```
조경계획 단계:
1. 목표 설정
2. 자료 조사·분석 (자연·인문·경관)
3. 종합·평가 (적지 분석)
4. 기본구상 → 기본계획
5. 기본설계 → 실시설계

→ 계획은 '분석', 설계는 '구체화'
```

---

## 분석 기법

```
경관 분석:
- 메쉬(Mesh) 분석, 중첩법(맥하그)
- 시각회랑·조망점 분석

토지 적합성 분석:
- 맥하그(McHarg)의 도면 중첩법
  (생태적 인자를 층층이 겹쳐 적지 도출)

이용자·행태 분석:
- 행태(behavior) 관찰, 설문
- 동선·이용 패턴 분석
```

---

## 환경 심리·행태 이론

```
주요 개념:
- 개인적 공간(Personal Space)
- 영역성(Territoriality)
- 혼잡(Crowding)
- 프로스펙트-리퓨지 이론
  (조망 prospect + 은신 refuge 욕구)

→ 공간 설계 시 인간 행태 반영의 근거
```

## 동양 조경사

```
한국:
- 삼국·통일신라: 안압지(임해전지) — 신라 정원
- 고려: 격구장, 화원
- 조선: 별서정원(소쇄원), 궁궐(창덕궁 후원),
  서원·향교 조경
  · 자연 순응적, 차경(借景) 기법

중국:
- 자연 산수 모방, 축경(縮景)
- 졸정원·이화원 등 강남 정원

일본:
- 고산수(枯山水) 정원 — 돌·모래로 산수 표현
- 다정(茶庭)·회유식 정원
```

## 서양 조경사

```
고대~중세:
- 이집트·메소포타미아(공중정원)
- 로마 빌라정원
- 중세 수도원 정원(약초원)

이탈리아 르네상스:
- 노단건축식(테라스) 정원 — 경사지 단(段)

프랑스:
- 평면기하학식(정형식) — 베르사유 궁원
  (보 르 비콩트, 르노트르)

영국:
- 자연풍경식(Landscape Garden)
  · 브라운, 렙턴 — 곡선·자연 지형

근대:
- 옴스테드(Olmsted): 뉴욕 센트럴파크
  → 근대 도시공원의 출발
```

## 도시공원·녹지 체계

```
공원 분류(도시공원):
- 생활권공원: 소공원·어린이공원·근린공원
- 주제공원: 역사·문화·수변·체육공원 등

녹지:
- 완충녹지·경관녹지·연결녹지

녹지 체계 이론:
- 그린벨트(개발제한구역)
- 그린 네트워크(녹지축 연결)
```

## 핵심 암기 포인트

```
- 계획 과정: 목표→조사분석→종합평가→구상·계획→설계
- 맥하그: 도면 중첩법(생태적 적지 분석)
- 한국: 안압지·소쇄원·창덕궁 후원, 차경
- 일본: 고산수(돌·모래), 회유식
- 이탈리아 노단식 / 프랑스 평면기하학식 / 영국 자연풍경식
- 옴스테드: 센트럴파크(근대 도시공원)
```

## 자주 묻는 질문

**Q. 조경사(史)는 어떻게 공부해야 하나요?**
A. 나라별 대표 정원과 양식을 '키워드+사례'로 묶어 외우는 것이 효율적입니다. 예: 프랑스=평면기하학식=베르사유=르노트르 식으로 연결해 암기하면 출제에 강합니다.

**Q. 맥하그의 중첩법이 왜 중요한가요?**
A. 생태적 인자(경사·토양·식생·수계 등)를 도면으로 겹쳐 개발 적지를 찾는 방법으로, 생태계획의 고전이자 빈출 이론입니다.

**Q. 차경(借景)이란?**
A. 담장 밖 산·자연 경관을 정원 안으로 끌어들여 빌려 쓰는 한국·동양 조경의 기법으로, 자연 순응적 공간 구성의 대표 개념입니다.
