## 이 강의의 목적

이론을 알아도 실제 문장을 고치는 연습이 없으면 공문서 작성 능력은 늘지 않습니다. 이번 강의는 **실제 공공기관 문서에서 수집된 패턴**을 바탕으로, 나쁜 문장 → 좋은 문장으로 고치는 연습을 집중적으로 다룹니다.

각 예시는 단순 수정이 아니라, **왜 나쁘고 왜 좋은지**를 설명합니다.

---

## 첨삭 패턴 1: 모호한 주어

### 나쁜 예
```
추진 일정이 검토되어야 할 것으로 판단됩니다.
```

**문제점**: 누가 검토하는가? 언제까지? '판단됩니다'는 누구의 판단인가?

### 좋은 예
```
○○과는 추진 일정을 2025년 8월 31일까지 검토하여 결과를 보고합니다.
```

**고친 이유**:
- 주어 명시 (○○과)
- 기한 명시 (8월 31일)
- 능동태로 전환
- '~할 것으로 판단됩니다' 제거

---

## 첨삭 패턴 2: 중복 표현 제거

### 나쁜 예
```
본 사업의 사업 목적은 청소년들의 청소년 문화 활동을 지원하기 위한 목적으로 추진됩니다.
```

**문제점**:
- '사업' 3회 반복
- '목적' 2회 반복
- '위한 목적으로' — '위해'와 동의어 중복

### 좋은 예
```
이 사업은 청소년 문화 활동을 지원합니다.
```

**고친 이유**: 의미를 유지하면서 불필요한 반복과 명사형 종결을 제거.

---

## 첨삭 패턴 3: 피동태 → 능동태

### 나쁜 예
```
교육 신청서가 접수되었으며, 대상자 선정이 이루어질 예정입니다.
```

### 좋은 예
```
교육 신청서를 접수하였으며, 대상자를 선정할 예정입니다.
```

**고친 이유**: 행위 주체가 담당 부서임을 문맥에서 알 수 있으므로 능동태가 자연스럽습니다. 피동태는 주체를 숨기거나 책임을 회피하는 인상을 줍니다.

---

## 첨삭 패턴 4: 관용어 제거

### 나쁜 예
```
귀 기관의 무궁한 발전을 기원하오며, 항상 적극적인 협조에 감사드립니다.
아울러 우리 기관의 업무와 관련하여 아래와 같이 협조를 요청하오니 적극적인 협조를 부탁드립니다.
```

**문제점**: '귀 기관 무궁한 발전 기원', '아울러', '적극적인 협조' 반복 — 모두 의미 없는 형식 표현입니다.

### 좋은 예
```
아래와 같이 협조를 요청합니다.
```

**고친 이유**: 공문서는 요청 사항이 핵심입니다. 서두의 인사말 없이도 충분하며, 전자결재 시대에는 더욱 불필요합니다.

---

## 첨삭 패턴 5: 명사화 남용

### 나쁜 예
```
회의 결과에 대한 검토 및 분석의 실시와 보완책 수립이 필요합니다.
```

**문제점**: '검토', '분석', '실시', '수립'이 연쇄 명사화. 문장 구조가 불명확합니다.

### 좋은 예
```
회의 결과를 검토·분석하여 보완책을 수립합니다.
```

**고친 이유**: 동사 중심 문장이 더 명확하고 읽기 쉽습니다.

---

## 첨삭 패턴 6: 날짜·숫자 표기 오류

### 나쁜 예
```
2025년 7월 1일부터 7월 15일까지 15일간 신청을 받을 예정이며, 정원은 30명이고 선발은 25명을 대상으로 합니다.
```

**문제점**:
- '15일간' — '2025. 7. 1. ~ 7. 15.(15일간)' 형식 사용
- '30명이고', '25명을' — 단위와 숫자를 아라비아 숫자로 바르게 썼지만 문장이 장황

### 좋은 예
```
신청 기간: 2025. 7. 1. ~ 7. 15.(15일간)
정원: 30명(선발 25명)
```

**고친 이유**: 표로 정리하거나 항목화하면 더 명확합니다. 날짜는 공문서 형식(마침표 구분)을 사용합니다.

---

## 첨삭 패턴 7: 불명확한 기준 표현

### 나쁜 예
```
대상자는 일정한 요건을 갖춘 자로 합니다.
```

**문제점**: '일정한 요건'이 무엇인지 알 수 없습니다. 수신자가 행동할 수 없는 문장입니다.

### 좋은 예
```
대상자는 다음 요건을 모두 충족한 자로 합니다.
가. 만 19세 이상 39세 이하
나. 지원 공고일 기준 주민등록상 ○○시 거주자
다. 최근 2년 이내 직업 훈련 미이수자
```

**고친 이유**: 구체적 기준을 항목으로 제시합니다.

---

## 첨삭 패턴 8: 연결어 오용

### 나쁜 예
```
사업 예산은 삭감되었습니다. 그러므로 사업 내용을 변경하고자 합니다.
```

**문제점**: '그러므로'는 논리적 결론을 제시할 때 사용하지만, 여기서는 인과관계가 자연스럽지 않습니다.

### 좋은 예
```
예산 삭감으로 사업 내용을 변경합니다.
```

**고친 이유**: 연결어 없이 하나의 문장으로 통합하는 것이 더 간결합니다. 공문서에서 '따라서'·'그러므로'보다 '~으로 인해', '~에 따라' 형태가 더 자연스럽습니다.

---

## 종합 첨삭 연습

다음 문단 전체를 첨삭해봅니다.

### 원문
```
당 기관에서는 우리 지역의 균형발전과 관련하여 지역 주민들의 삶의 질 향상을
위한 목적으로 문화 복지 프로그램을 운영하고 있으며, 이번에 하기 기재된 바와
같이 프로그램 참가자를 모집하오니 지역 내 해당 주민들의 적극적인 참여와
협조를 바라는 바입니다.
```

**문제점 분석**:
1. '당 기관에서는' — 불필요한 서두
2. '우리 지역의 균형발전과 관련하여' — 막연한 배경
3. '삶의 질 향상을 위한 목적으로' — '~위해'로 충분
4. '하기 기재된 바와 같이' — '아래와 같이'로 대체
5. '적극적인 참여와 협조를 바라는 바입니다' — 관용적 종결

### 첨삭 후
```
문화 복지 프로그램 참가자를 아래와 같이 모집합니다.
```

원문 77자 → 첨삭 후 25자. 의미는 100% 유지됩니다.

## 자주 쓰는 잘못된 표현 교체 목록

| 잘못된 표현 | 올바른 표현 |
|-----------|-----------|
| 시행하고자 합니다 | 시행합니다 |
| ~하여 주시기 바랍니다 | ~해 주십시오 |
| ~와 관련하여 | ~에 대해 / 삭제 |
| ~의 경우에는 | ~이면 |
| 제출하여 주실 것을 요청드립니다 | 제출해 주십시오 |
| 검토 후 처리하여 주시기 바랍니다 | 검토 후 처리해 주십시오 |
| 위와 같이 알려드립니다 | 위와 같습니다 |
| ~를 위한 목적으로 | ~를 위해 |
| 아울러 | 또한 / 삭제 |
| ~될 것으로 기대됩니다 | ~를 기대합니다 / ~됩니다 |

## 시리즈 최종 체크리스트

공문서 작성법 5강을 마치며, 전체 시리즈의 핵심을 정리합니다.

**구조 (1강)**
- [ ] 두문: 기관명, 수신처, 제목 완비
- [ ] 항목 체계: 가→1)→가)→(1)→(가) 순서 준수
- [ ] 날짜: 2025. 5. 5. 형식

**내용 (2·3강)**
- [ ] BLUF: 핵심 먼저, 배경 나중
- [ ] 능동태 중심 문장
- [ ] 관용어·형식 표현 제거
- [ ] 각 문장: 하나의 의미

**형식 (4강)**
- [ ] 표: 제목 표기, 정렬 원칙
- [ ] 붙임: 순번·제목·부수·"끝."
- [ ] 보존 기간 확인

**첨삭 (5강)**
- [ ] 모호한 주어 제거
- [ ] 중복 표현 제거
- [ ] 날짜·숫자 공문서 형식
- [ ] 전체 문단 읽고 불필요한 문장 삭제
