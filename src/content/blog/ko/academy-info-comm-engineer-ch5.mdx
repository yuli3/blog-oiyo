## 무선 통신의 핵심

무선 통신은 케이블 대신 전파를 매체로 쓰기 때문에 거리, 장애물, 간섭, 주파수 자원이 중요해집니다. 같은 데이터 통신이라도 유선보다 채널 환경이 더 자주 변하고, 여러 사용자가 한정된 주파수를 나누어 써야 합니다. 그래서 무선·이동통신은 전파 특성과 자원 배분을 함께 이해해야 합니다.

### 주요 개념

| 개념 | 공부 포인트 |
|---|---|
| 전파 | 주파수, 파장, 전파 손실 |
| 안테나 | 지향성, 이득, 송수신 특성 |
| 셀 | 서비스 영역 분할과 주파수 재사용 |
| 다중접속 | 여러 사용자의 채널 공유 방식 |
| 핸드오버 | 이동 중 접속 유지 |

셀 구조는 넓은 지역을 작은 서비스 영역으로 나누어 주파수를 효율적으로 쓰는 방법입니다. 핸드오버는 사용자가 이동해도 통화나 데이터 연결을 유지하도록 접속 지점을 바꾸는 절차입니다. 다중접속은 여러 사용자가 같은 무선 자원을 나누는 원리로, 방식별 차이를 표로 비교해 두면 좋습니다.

## 이동통신을 읽는 법

세대별 이동통신을 외울 때는 숫자보다 목표를 보세요. 음성 중심에서 데이터 중심으로, 다시 초고속·초저지연·대규모 접속으로 요구가 바뀌었습니다. 시험에서는 세대 이름보다 대역폭, 지연, 셀 설계, 기지국, 코어망 역할을 함께 묻는 흐름이 중요합니다.

## 핵심 요약

- 무선 통신은 전파 손실, 간섭, 주파수 자원 제약을 고려해야 합니다.
- 셀 구조와 핸드오버는 이동통신을 이해하는 핵심입니다.
- 세대별 기술은 “무엇을 개선하려 했는가”로 정리하세요.
