## 유통 물류의 이해

```
유통 물류의 정의:
→ 상품이 생산자에서 소비자까지 이동하는 과정의 관리
→ 수송·보관·하역·포장·정보 활동

물류의 목표 (7R):
→ Right Product: 정확한 상품
→ Right Quantity: 정확한 수량
→ Right Condition: 올바른 상태
→ Right Place: 정확한 장소
→ Right Time: 정확한 시간
→ Right Customer: 정확한 고객
→ Right Price: 적정 가격

유통 물류의 구성:

수·배송:
→ 수송: 거점 간 대량 이동 (간선 수송)
→ 배송: 거점에서 고객까지 소량 이동
→ 라스트마일: 최종 소비자 배달 (비용 높음)

보관·창고:
→ 거점 창고 (DC, Distribution Center): 중간 보관
→ 풀필먼트 센터: 포장·발송까지 일괄 처리
→ 3PL 창고: 외부 물류 업체 위탁

하역:
→ 상품의 입·출하, 분류, 적재
→ 자동화: 컨베이어·소터(분류기)·로봇
```

## 재고 관리

```
재고의 유형:
→ 순환 재고: 정기 주문에 의한 일상 재고
→ 안전 재고: 수요 불확실성 대비 여분
→ 파이프라인 재고: 이동 중인 재고 (운송 중)
→ 투기 재고: 가격 상승 예상 시 미리 구매

재고 관리의 핵심 지표:

재고 회전율:
→ 연간 매출 원가 / 평균 재고액
→ 높을수록 좋음 (재고가 빠르게 팔림)
→ 편의점: 매우 높음 / 명품 매장: 낮음

재고 일수:
→ 365일 / 재고 회전율
→ 평균 상품이 재고에 머무는 기간

ABC 재고 관리:
→ A 품목: 매출의 80% (20% 상품) → 철저 관리
→ B 품목: 매출의 15% → 중간 관리
→ C 품목: 매출의 5% → 단순 모니터링

적정 재고 수준 (EOQ 개념):
→ 주문 비용: 주문 횟수 많을수록 증가
→ 보관 비용: 재고량 많을수록 증가
→ EOQ: 두 비용의 합이 최소인 주문량

서비스율 (Service Level):
→ 고객 수요 충족 가능한 비율
→ 높은 서비스율 = 높은 안전 재고 필요
```

## 소매 업태와 전략

```
소매 업태 유형:

백화점:
→ 다양한 상품 구색, 고가 전략
→ 서비스 강조, 쾌적한 쇼핑 환경
→ 대형 도심 입지

할인점·대형마트:
→ 저가·대량 판매 (EDLP: Every Day Low Price)
→ 셀프 서비스, 넓은 매장
→ 예: 이마트, 롯데마트, 홈플러스

편의점 (CVS):
→ 24시간, 소량·다품종
→ 근접 입지, 높은 회전율
→ 예: CU, GS25, 세븐일레븐

전문점:
→ 특정 카테고리 전문화
→ 깊은 상품 구색
→ 예: 다이소, 올리브영, 이케아

아울렛:
→ 재고·이월 상품 할인 판매
→ 교외 대형 단지

소매 수레바퀴 이론 (Wheel of Retailing):
→ 새 업태 등장: 낮은 가격·서비스로 시작
→ 성장하면서 서비스 확충, 가격 상승
→ 다시 저가 업태 등장으로 대체
```

## VMD (비주얼 머천다이징)

```
VMD의 정의:
→ 상품을 시각적으로 효과적으로 진열하여 판매 촉진

VMD의 구성:

VP (Visual Presentation):
→ 점포 전체 이미지 연출
→ 쇼윈도, 입구 연출

PP (Point of Point):
→ 매장 내 주목 포인트 연출
→ 마네킹, 특별 진열

IP (Item Presentation):
→ 개별 상품 진열·정리

진열 방법:
→ 정면 진열: 상품 앞면 정렬
→ 적층 진열: 쌓아 올림 (저가 대량)
→ 걸기 진열: 훅에 걸기 (의류, 소품)
→ 엔드 진열: 판매대 끝 (주목도 높음)

매대 배치 전략:
→ 황금 매대: 눈높이(1.2~1.5m) → 구매율 최고
→ 동선 설계: 고객이 많이 보는 상품 매장 안쪽 배치
→ 크로스 머천다이징: 연관 상품 함께 진열
  (맥주 옆에 안주, 라면 옆에 계란)

색채 전략:
→ 따뜻한 색(빨강·주황): 구매 충동, 빠른 결정
→ 차가운 색(파랑·초록): 신뢰감, 신중한 구매
→ 흰색: 청결감, 의료·위생 제품
```

## 점포 입지 선정

```
입지의 중요성:
→ 소매업의 3요소: 입지, 입지, 입지
→ 입지 선정은 취소 어렵고 장기 영향

입지 분석 절차:
1. 상권 범위 설정 (1차·2차·3차 상권)
2. 상권 내 인구·소득 분석
3. 경쟁 현황 파악
4. 입지 후보지 평가

주요 입지 유형:

독립 입지:
→ 단독 건물, 대형 주차장
→ 대형마트, 창고형 할인점 (교외)

쇼핑 센터 내 입지:
→ 집객력 공유, 테넌트 믹스 중요
→ 앵커 스토어: 대형 핵심 점포
→ 기획 구성 매장이 유리

도심 상업 지구:
→ 높은 유동 인구, 높은 임대료
→ 접근성 좋음

레일리의 소매 인력 법칙:
→ 두 도시가 중간 지역 고객을 끄는 힘은
  인구에 비례, 거리 제곱에 반비례
→ B_a / B_b = (P_a/P_b) × (D_b/D_a)²

허프(Huff) 모형:
→ 특정 점포 선택 확률 = 규모/거리^λ 지수
→ 경쟁 점포 포함 실제 선택 확률 계산

상권 분석 도구:
→ 체크리스트법: 항목별 점수화
→ 유추법: 유사 점포 성과 참고
→ 회귀 분석: 매출 예측 모형
```

## 자주 묻는 질문

**Q. 유통관리사 시험에서 물류 파트는 어떻게 공부해야 하나요?**
A. 물류 파트는 유통관리사 시험의 비중 있는 부분입니다. EOQ, ABC 분석, 재고 회전율 계산 문제가 자주 나오므로 공식을 이해하고 직접 계산 연습이 필요합니다. SCM(공급망관리), JIT, VMI, CPFR 등 최신 물류 기법의 특징과 차이점을 명확히 구분해야 합니다. 용어 암기보다 개념의 맥락 이해가 응용 문제 대응에 도움이 됩니다.

**Q. VMD는 오프라인 매장에만 해당하는 개념인가요?**
A. 아닙니다. 온라인 쇼핑몰에도 디지털 VMD가 적용됩니다. 웹사이트의 메인 배너 구성, 상품 추천 위치, 썸네일 이미지 설계, 카테고리 구성 등이 온라인 VMD입니다. 오프라인의 황금 매대에 해당하는 것이 온라인의 메인 화면 상단 노출이고, 엔드 진열에 해당하는 것이 검색 결과 상단이나 추천 섹션입니다.
