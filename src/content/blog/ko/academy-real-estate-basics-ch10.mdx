## 공인중개사 제도 개요

**공인중개사법**: 공인중개사 자격, 중개업 등록, 중개 업무에 관한 기본법.

**중개**: 중개의뢰인의 의뢰를 받아 부동산 거래 쌍방 사이에서 계약이 성립하도록 알선하는 행위.

```
중개 행위:
매도인(임대인) ─── 중개의뢰 ───→ 공인중개사
매수인(임차인) ─── 중개의뢰 ───→ 공인중개사
                          ↓
                     계약 체결 알선
```

## 공인중개사 자격과 등록

### 자격 취득

- 공인중개사 자격시험 합격 (국가자격시험, 2차 시험)
- 1차: 부동산학개론, 민법·민사특별법
- 2차: 공인중개사법·중개실무, 부동산공법, 부동산공시법·세법

### 중개업 등록

**중개사무소 등록**: 자격 취득 후 관할 시·군·구청에 등록

**등록 기준**:
- 건축물 대장에 등록된 실제 사무소
- 등록증·중개보조원 명부 비치
- 업무보증 설정 (보증보험·공제)

**업무보증 금액**:
- 법인 중개업자: 2억 원 이상
- 개인 중개업자: 1억 원 이상

## 공인중개사의 의무

### 확인·설명 의무

**공인중개사법 제25조**: 중개 대상물의 중요 사항을 중개의뢰인에게 확인·설명.

```
설명 의무 대상:
① 등기부 기재 사항 (소유권·담보 현황)
② 공법상 이용 제한 (용도지역·건축제한)
③ 실제 거래가격 (고·저가 왜곡 금지)
④ 시설물 상태 (수도·전기·가스 등)
⑤ 토지이용계획 확인서 내용
```

**중개대상물 확인·설명서**: 거래 전 의무적으로 작성·교부.

### 비밀 유지 의무

업무상 알게 된 거래 당사자의 정보를 누설 금지.

### 공정 중개 의무

쌍방으로부터 중개를 의뢰받더라도 어느 일방에 유리한 행위 금지.

## 중개보수 (수수료)

**중개보수**: 거래 성사 시 받을 수 있는 보수. 상한 요율 이내로 협의.

### 주택 중개보수 상한 요율

| 거래 유형 | 거래금액 | 상한 요율 |
|---------|---------|---------|
| 매매·교환 | 5,000만 미만 | 0.6% |
| 매매·교환 | 5,000만~2억 미만 | 0.5% |
| 매매·교환 | 2억~9억 미만 | 0.4% |
| 매매·교환 | 9억~12억 미만 | 0.5% |
| 매매·교환 | 12억~15억 미만 | 0.6% |
| 매매·교환 | 15억 이상 | 0.7% |
| 임대차 | 5,000만 미만 | 0.5% |
| 임대차 | 5,000만~1억 미만 | 0.4% |
| 임대차 | 1억~6억 미만 | 0.3% |
| 임대차 | 6억~12억 미만 | 0.4% |
| 임대차 | 12억~15억 미만 | 0.5% |
| 임대차 | 15억 이상 | 0.6% |

**한도액**: 거래금액 × 상한 요율 (VAT 별도)

## 금지 행위

**공인중개사법 제33조** 금지 행위:
- 중개 대상물의 매매·교환·임대차를 직접 행위 (자기 거래)
- 거래 당사자로부터 법정 이외의 금품 수수
- 사실과 다른 광고 (허위·과장)
- 이중 계약서 작성 (다운계약·업계약)
- 사무소 내 음란·도박 행위

**이중계약서 작성**: 실거래가 신고 위반 + 중개사 등록 취소 사유.

다음에 해당하면 공인중개사 자격 취소 또는 등록 취소:
- 피성년후견인·피한정후견인
- 공인중개사법 위반으로 징역형 이상
- 업무정지 기간 중 중개 행위
- 이중계약서 작성

## 핵심 개념 카드

**확인·설명 의무** ★★★★★
: 등기부·공법 이용제한·시설물 상태 등 중요 사항 설명 + 확인·설명서 교부 의무.
*암기 포인트: 중개 전 확인·설명서 의무 작성·교부*

**중개보수 상한 요율** ★★★★★
: 매매 2억~9억 = 0.4%, 임대 1억~6억 = 0.3%. 법정 상한 이내 협의.
*암기 포인트: 매매 일반 0.4%, 임대 일반 0.3%*

**업무보증 금액** ★★★★☆
: 개인 중개업자 1억 원 이상, 법인 2억 원 이상의 보증보험·공제 설정.
*암기 포인트: 개인 1억, 법인 2억*

## 실전 퀴즈

**Q. 매매가 5억 원 주택의 중개보수 상한액은? (상한 요율 0.4%)**
> 5억 × 0.4% = 200만 원. (VAT 별도)

**Q. 공인중개사가 매도인·매수인 양쪽으로부터 중개를 의뢰받은 경우 수수료 처리는?**
> 각 당사자로부터 각각 상한 요율 이내의 중개보수를 받을 수 있음. 합산 상한 규정 없음.
