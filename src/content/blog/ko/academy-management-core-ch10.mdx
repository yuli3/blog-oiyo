## 이 강의의 목적

경영학 핵심 시리즈 9강을 학습했다면, 이 마지막 강의는 **취업 시험에 직접 활용**하기 위한 총정리입니다. 공기업·공공기관 경영학 필기 + 면접에서 실제로 묻는 유형과 답변 전략을 다룹니다.

## 시리즈 핵심 개념 압축 정리

### 경영 4기능 (Ch1)

| 기능 | 핵심 내용 |
|------|---------|
| 계획(Planning) | 목표 설정, SMART 기준 |
| 조직화(Organizing) | 분업·전문화, 지휘 범위, 라인-스태프 |
| 지휘(Leading) | 동기부여, 리더십 스타일 |
| 통제(Controlling) | 성과 측정, 피드백, 수정 |

### 경영전략 핵심 (Ch2)

- **SWOT**: 내부(강점·약점) + 외부(기회·위협) → SO/ST/WO/WT 전략
- **포터의 본원적 전략**: 원가 우위 / 차별화 / 집중화
- **BCG 매트릭스**: 스타(고성장·고점유) / 캐시카우(저성장·고점유) / 물음표 / 개

### 동기부여 이론 (Ch3)

- **매슬로우**: 생리→안전→사회→존경→자아실현 (계층적)
- **허즈버그**: 위생요인(만족 제거)·동기요인(동기 유발)
- **맥그리거**: X이론(강제)·Y이론(자율)
- **브룸 기대이론**: MV = 기대감×수단성×유의성

### 인사관리 (Ch4)

직무분석 → 채용(구조화 면접) → 교육훈련(OJT/Off-JT) → 성과평가(MBO, 360도) → 보상

### 재무비율 (Ch5)

| 비율군 | 대표 비율 |
|-------|---------|
| 수익성 | ROE, ROA, 영업이익률 |
| 안전성 | 부채비율, 유동비율, 이자보상배율 |
| 활동성 | 재고회전율, 매출채권회전율 |
| 성장성 | 매출증가율, 영업이익증가율 |

### 생산·품질 (Ch6)

- PDCA: Plan → Do → Check → Act
- 6시그마 DMAIC: Define → Measure → Analyze → Improve → Control
- 린(Lean) 7대 낭비: TIMWOOD (이동·재고·모션·대기·과잉생산·과잉처리·불량)

### 공기업 (Ch7)

- 시장형/준시장형/기금관리형/위탁집행형 구분
- 경영실적평가: S~E 등급, 사회적 가치 항목 강화
- ESG: E(환경)·S(사회)·G(지배구조)

### 회계 (Ch8)

- BEP = 고정비 ÷ (단가 – 변동비)
- ROE = 순이익률 × 총자산회전율 × 재무레버리지 (DuPont)
- 재무회계 vs 관리회계: 외부 보고 vs 내부 의사결정

### 경영과학 (Ch9)

- EMV = Σ(결과×확률)
- LP: 제약 하에서 목적 함수 최적화
- PERT/CPM: 주공정(Critical Path), 여유시간(Slack)

## 자주 출제되는 유형 분석

### 유형 1: 개념 매칭

"다음 중 포터의 본원적 전략에 해당하지 않는 것은?"
→ 원가 우위·차별화·집중화를 외우고, 함정 선택지(혁신 전략, 성장 전략) 구분

### 유형 2: 상황에서 이론 찾기

"김 과장은 팀원들이 어려운 과제를 자발적으로 해결할 것을 믿고 자율권을 부여한다. 이에 해당하는 이론은?"
→ 맥그리거 Y이론, 허즈버그 동기요인과 연결 (자율성)

### 유형 3: 계산 문제

"고정비 200만 원, 판매 단가 5만 원, 변동비 3만 원. 손익분기점 수량은?"
→ 200만 ÷ (5만 – 3만) = 100개

### 유형 4: 사례 → 기법 매칭

"○○공사는 제품 생산의 8단계 공정을 분석해 불필요한 대기 시간 2단계를 제거했다. 이 기법은?"
→ 린(Lean) 생산 / 7대 낭비 제거

### 유형 5: 공기업 특성 이해

"공기업이 민간기업보다 낮은 서비스 요금을 유지하는 이유는?"
→ 공익성 목표, 자연독점 규제, 사회적 약자 배려

## 면접 답변 구조: 경영학 개념 활용

공기업 면접에서 경영학 지식은 **직접 답** 혹은 **논거**로 활용됩니다.

### 면접 질문 유형과 활용 개념

**"이 기관의 경쟁력 강화를 위해 어떻게 하겠습니까?"**
→ Porter의 차별화 전략 또는 RBV(핵심역량) 활용
→ "기관의 강점인 ○○역량을 VRIN 기준으로 볼 때 희귀하고 모방하기 어렵기 때문에..."

**"팀원과 갈등이 생기면 어떻게 처리하겠습니까?"**
→ Thomas-Kilmann 갈등 해결 모델: 통합(Collaborate) 전략
→ "양측의 이해관계를 파악하고 원칙 중심 협상으로..."

**"업무 개선 경험이 있으신가요?"**
→ PDCA 또는 6시그마 DMAIC 구조로 답변
→ "문제를 정의(D)하고, 현황 측정(M), 원인 분석(A), 개선안 도출(I), 표준화(C) 단계로 진행했습니다."

**"공기업에 지원한 이유는?"**
→ 공익성·사회적 가치 + ESG 맥락
→ "민간기업이 시장 실패로 충분히 공급하지 못하는 영역에서..."

## 함께 공부하면 좋은 시리즈

경영학과 함께 학습하면 시너지가 나는 시리즈:

- **NCS 핵심**: 공기업 필기의 직업기초능력 영역 (의사소통·수리·문제해결 등)
- **경제학 핵심**: 거시경제 지표 해석, 재정·통화 정책 이해
- **공문서 작성법**: 보고서·기안문 작성, 실무 문서 능력
- **노동법 기초**: 근로기준법·취업규칙·직장 내 권리

## 핵심 개념 카드

**ERP (전사적 자원관리)** ★★★★
: 기업의 전 기능(생산·영업·재무·인사)을 하나의 통합 DB로 연결하는 시스템. 실시간 정보 공유로 의사결정 지원. 대표 제품: SAP, Oracle. 장점: 부서 간 정보 사일로 제거. 단점: 도입비용·커스터마이징 어려움.

**CRM (고객관계관리)** ★★★
: 고객 데이터 수집·분석으로 관계 강화·수익 극대화. 고객생애가치(CLV) 극대화 목적. 운영적 CRM (자동화·서비스) + 분석적 CRM (데이터마이닝) + 협업적 CRM (채널 통합).

## 실전 퀴즈

**Q. ERP·SCM·CRM의 관리 대상 차이를 구분하라.**
> ERP: 기업 내부 전 자원(생산·재무·인사 통합). SCM: 기업 간 공급망 전체(원자재~최종소비자). CRM: 고객 관계(마케팅·영업·서비스).
