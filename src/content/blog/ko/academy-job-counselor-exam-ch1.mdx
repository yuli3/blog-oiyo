## 직업상담사 자격증이란?

```
주관: 한국산업인력공단
등급: 1급 / 2급
자격 유형: 국가기술자격

직업상담사의 역할:
→ 구직자·재직자·실직자의 취업, 진로, 직업 적응 상담
→ 직업 정보 제공 및 취업 활동 지원
→ 취업 지원 기관, 고용센터, 직업훈련기관 등 취업

2급 취득 후 1급 응시 가능 (실무 경력 요건 충족 시)
```

## 시험 과목 (2급 필기)

```
총 5과목 (각 20문제, 객관식 5지선다):

1과목: 직업상담학
→ 직업상담 이론, 상담 기법, 집단상담

2과목: 직업심리학
→ 직업 심리 이론, 직업 발달 이론, 직업 흥미·적성 이론

3과목: 직업정보론
→ 직업 정보 수집·분석, 한국직업사전, 직업·진로 정보

4과목: 노동시장론
→ 노동 수요·공급, 임금 이론, 실업 이론

5과목: 노동관계법규
→ 근로기준법, 직업안정법, 고용보험법

시험 시간: 과목당 25분 (125분 총)
합격 기준: 각 과목 40점 이상 + 평균 60점 이상

실기 (작업형):
→ 직업상담 실무 (4시간, 주관식)
→ 상담 일지 작성, 직업 정보 분석 등
```

## 직업상담의 개념과 목적

```
직업상담의 정의:
→ 내담자가 직업 선택, 직업 적응, 진로 개발 과정에서
  직면하는 문제를 전문가의 도움으로 해결하는 과정

직업상담의 목적:
1. 올바른 직업 선택 지원
2. 직업 생활 적응 지원
3. 직업 능력 개발
4. 재취업 지원
5. 진로 탐색 지원

내담자 유형:
→ 구직자 (첫 취업, 이직, 재취업)
→ 실직자 (고용보험 급여 수혜자 등)
→ 재직자 (전직, 승진, 직무 갈등)
→ 학생·청소년 (진로 탐색)
→ 경력 단절 여성
```

## 직업상담의 기본 원칙

```
직업상담 6대 원칙:

1. 공감적 이해 (Empathy):
→ 내담자의 입장에서 감정·상황 이해
→ "이렇게 힘드셨군요"

2. 무조건적 긍정적 수용:
→ 판단·비판 없이 내담자를 있는 그대로 수용

3. 진실성·일치성 (Congruence):
→ 상담사의 내면과 외면 일치
→ 가식 없는 진심 어린 태도

4. 비밀보장:
→ 상담 내용의 외부 유출 금지
→ 예외: 생명 위협, 법적 요구

5. 자기결정권 존중:
→ 내담자 스스로 선택·결정하도록 지원
→ 상담사가 대신 결정하지 않음

6. 개별화:
→ 내담자를 개인으로 인식
→ 획일적 접근이 아닌 맞춤형 상담
```

## 직업상담의 이론적 접근

```
1. 특성-요인 이론 (Trait-Factor Theory):
→ 대표학자: 파슨스 (Parsons), 윌리암슨
→ '어울림(Matching)': 개인의 특성과 직업의 요인 매칭
→ 직업 선택 = 자신 이해 × 직업 이해 × 합리적 선택
→ 주로 직업 정보 제공, 검사 활용 상담에 적용

2. 정신분석적 접근:
→ 무의식적 동기, 방어기제가 직업 선택에 영향
→ 초기 경험과 부모-자녀 관계 탐색
→ 내담자의 내면 갈등 해결에 초점

3. 인간중심 상담 (Rogers):
→ 내담자의 자기 성장 가능성 신뢰
→ 상담자의 3요소: 공감, 무조건적 수용, 진실성
→ 지시보다는 반영·수용 중심

4. 인지행동 접근:
→ 직업 선택에 영향 주는 부정적 사고 수정
→ "나는 취업할 자격이 없다" → 합리적 사고로 교체
→ 목표 설정, 행동 계획 수립 병행
```

## 직업 발달 이론

```
슈퍼(Super)의 발달 이론:
→ 직업 발달은 전 생애에 걸친 과정

생애 발달 단계:
1. 성장기 (0~14세): 자아개념 형성, 직업 탐색
2. 탐색기 (15~24세): 직업 탐색·시도, 잠정적 선택
3. 확립기 (25~44세): 직업 정착, 능력 개발
4. 유지기 (45~64세): 직업 안정, 은퇴 준비
5. 쇠퇴기 (65세 이후): 직업 역할 감소, 은퇴

직업자아개념 (Career Self-Concept):
→ 직업에 관한 자신의 능력·특성에 대한 인식
→ 직업 선택의 핵심 요소

홀랜드(Holland)의 유형론:
R (현실형): 기계·도구 조작, 외향적
I (탐구형): 분석·연구, 내향적
A (예술형): 창의·표현, 독립적
S (사회형): 사람 돕기, 협조적
E (진취형): 리더십·설득, 외향적
C (관습형): 자료 정리·체계화, 꼼꼼함

직업 유형 일치도:
→ RIASEC: 개인 유형과 직업 환경 일치도 높을수록 만족도 높음
```

## 직업상담 면접 기법

```
비지시적 기법 (내담자 중심):
→ 개방형 질문: "직업에 대해 어떻게 생각하세요?"
→ 반영: 내담자 말을 다른 표현으로 돌려줌
→ 요약: 핵심 내용 정리·확인
→ 명료화: 모호한 내용 구체화 요청

지시적 기법 (상담사 주도):
→ 정보 제공: 직업 시장, 훈련 프로그램 안내
→ 직접적 조언: 구체적 행동 제안
→ 해석: 내담자 경험·행동의 의미 부여
→ 직면: 모순·불일치 지적

구조화된 직업상담 과정:
1. 관계 형성 (Rapport): 신뢰 관계 구축
2. 문제 명료화: 내담자 욕구·문제 파악
3. 목표 설정: 구체적·현실적 목표
4. 개입: 검사 활용, 정보 제공, 기술 훈련
5. 평가·종결: 목표 달성 여부, 추후 계획
```

## 직업심리 검사

```
표준화 검사 도구:

흥미 검사:
→ 스트롱 직업흥미검사 (Strong Interest Inventory)
→ 홀랜드 직업선호도 검사 (SDS)
→ 워크넷 직업선호도 검사 (무료, 국내)

적성 검사:
→ GATB (일반직업적성검사): 언어, 수리, 공간 등 11개 요인
→ 직업기초능력 평가 (NCS)

가치관 검사:
→ 직업 가치관 검사: 워라밸, 성취, 안정 등 가치 우선순위

성격 검사:
→ MBTI: 16가지 성격 유형 (취업 상담에 자주 활용)
→ DISC: 행동 유형 (주도형, 사교형, 안정형, 신중형)

주의:
→ 검사 결과는 참고 자료이며, 최종 결정은 내담자 자율
→ 검사 결과 해석 시 전문적 피드백 필수
```

## 자주 묻는 질문

**Q. 직업상담사와 취업지원관의 차이는 무엇인가요?**
A. 직업상담사는 국가기술자격으로, 취업·진로 상담의 전문성을 검증합니다. 취업지원관은 고용센터 등 기관에서 채용하는 직위로, 직업상담사 자격증 소지자가 우대받는 경우가 많습니다.

**Q. 실기 시험이 어렵다고 하던데 어떻게 준비해야 하나요?**
A. 직업상담사 2급 실기는 직업 상담 사례 분석, 직업 정보 활용, 상담 일지 작성 등 주관식 문제입니다. 이론 학습 후 모의 사례 연습과 워크넷, 직업사전 활용 능력을 기르는 것이 중요합니다.
