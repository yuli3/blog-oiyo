## 행정 책임의 의의

```
행정 책임:
공무원이 자신의 행위에 대해 지는 책임

책임의 유형:
정치적 책임: 국회에 대한 책임
법적 책임: 법률 위반에 대한 책임
도덕적 책임: 윤리 기준에 따른 책임
직무 책임: 상관·조직에 대한 책임

Finer vs Friedrich:
Finer: 외부 통제 강조 (외재적 책임)
Friedrich: 내부 윤리·전문성 강조 (내재적 책임)
```

## 행정통제의 유형

```
내부통제:
행정 조직 내부에서 자체 통제

① 계층제적 통제: 상관이 부하 감독
② 감사원 감사: 회계·직무 감사
③ 직무 규정: 규정에 따른 행동 제한
④ 교육훈련: 윤리·전문성 함양
⑤ 고충 처리: 내부 불만 처리

외부통제:
행정 조직 외부에서 통제

① 입법부 통제: 국정감사, 예산 심의, 법률
② 사법부 통제: 행정소송, 위헌심사
③ 시민 통제: 민원, 정보공개, 참여
④ 언론 통제: 취재, 보도
⑤ 이익집단: 로비, 압력
```

## 옴부즈만 제도

```
옴부즈만 (Ombudsman):
행정 불만을 독립적으로 조사·처리하는 기관
스웨덴 기원 (1809년)

특성:
독립성: 정부로부터 독립
중립성: 특정 이익 편향 없음
비공식성: 소송 없이 분쟁 해결
접근 용이: 일반 시민도 쉽게 접근

권한:
조사권, 권고권 (강제력 없음)
단, 도덕적 권위로 실질적 영향력

한국 제도:
국민권익위원회 (옴부즈만 역할)
행정 심판
국민 신문고
```

## 행정 윤리

```
행정 윤리의 필요성:
공무원의 권한 남용 방지
공익 우선 행동 보장

이해충돌:
공무원 개인 이익과 직무 충돌
→ 이해충돌 방지법 (2022년 시행)
직무 관련 이해충돌 회피·신고 의무

부패:
직권 남용, 뇌물, 횡령, 배임
부패방지법, 청탁금지법(김영란법)

공익신고:
내부 고발자 보호 (공익신고자보호법)
부패 행위 신고 시 신분 보호

청탁금지법 (2016년~):
금품 수수·부정 청탁 금지
식사 3만 원, 선물 5만 원 기준 (농수산물 10만 원)
```

## 핵심 개념 카드

**내부통제 vs 외부통제** ★★★★★
: 내부=계층제·감사원·규정. 외부=국회·법원·시민·언론.
*암기 포인트: 내부=자체감시, 외부=외부감시*

**옴부즈만 특성** ★★★★★
: 독립성·중립성·비공식성·접근용이. 강제력 없지만 도덕적 권위.
*암기 포인트: 옴부즈만=독립+중립+권고*

**청탁금지법 기준** ★★★★☆
: 식사 3만 원, 선물 5만 원 (농수산물 10만 원).
*암기 포인트: 식3만·선5만·농10만*

## 실전 퀴즈

**Q. 옴부즈만이 강제력 없이도 효과적인 이유는?**
> 독립적·중립적 조사로 도덕적 권위 보유. 옴부즈만의 권고는 법적 강제력이 없지만 무시하면 언론 노출, 정치적 압박, 여론 악화로 실질적 압박. 비공식 해결로 빠른 구제 가능.

**Q. 이해충돌 방지의 필요성은?**
> 공무원이 개인 이익과 직무가 충돌하면 공익보다 사익 우선 결정 가능. 예: 규제 대상 기업 주식 보유한 규제 공무원. 이해충돌 방지법은 이런 상황 신고·회피 의무화해 공익 결정 보장.
