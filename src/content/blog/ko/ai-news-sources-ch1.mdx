## 2026년에 따로 봐야 할 흐름

- **AI 에이전트**: 단순 채팅보다 "파일을 읽고, 코드를 고치고, 브라우저로 검증하는" 작업형 도구가 중요해졌습니다. OpenCode, GitHub Copilot agent, Codex, Claude Code 같은 도구는 릴리즈 노트를 자주 확인하세요.
- **UI 생성과 vibe design**: v0, Stitch, Opal처럼 말로 화면·앱·워크플로를 만드는 도구가 늘고 있습니다. 디자이너에게는 초안 생성, 개발자에게는 구현 전 제품 검증 도구입니다.
- **오픈 모델 생태계**: Hugging Face의 모델·데이터셋·Spaces와 LMArena의 공개 평가는 모델 선택의 기준점입니다.
- **AI SaaS 수익화**: Polar, Vercel, Stripe, usage billing 도구처럼 토큰 사용량과 매출을 함께 보는 운영 도구도 중요해졌습니다.
