## 승자의 저주 (Winner's Curse)

<Callout type="important" title="승자의 저주 — 이기면 손해?">
  공통 가치 경매(예: 유전 개발권, M&A)에서 낙찰자는 종종 과도하게 지불합니다. 왜? 낙찰자는 가치를 **가장 높게 평가한 사람**이고, 그 평가가 과대추정일 가능성이 높기 때문입니다. 이것이 **승자의 저주**입니다.
</Callout>

```
승자의 저주 방어 전략:
→ 공통 가치 경매에서 입찰가를 낮춰 조정
→ "내가 낙찰되면 내 추정이 가장 낙관적일 것" 인지
→ 독립적 전문가 평가 활용
→ 최악 시나리오 기준으로 입찰가 설정
```

## 게임이론으로 보는 주파수 경매

실제 정부 주파수 경매는 경매 이론의 가장 큰 실전 무대입니다.

```
주파수 경매의 복잡성:
→ 보완재: A 주파수와 B 주파수는 함께 가져야 가치 있음
→ 패키지 입찰 허용: 개별 vs 묶음 선택 전략
→ 전략적 입찰: 경쟁자 약화를 위한 입찰 (shill bidding)
→ 결합 가치 경매 (Combinatorial Auction): 최신 해결책

한국 5G 주파수 경매 (2018):
→ 3.5GHz, 28GHz 대역 경매
→ SK텔레콤, KT, LG유플러스 참여
→ 총 3조 6,183억 원 낙찰
```

## 핵심 암기 포인트

*비크리 경매: 진짜 가치 그대로 써라 — 솔직함이 우월 전략*
*1가격 봉인: 가치보다 낮게 — 낙찰 마진 확보*
*승자의 저주: 낙찰 = 가장 낙관적 추정자 → 공통 가치에서 할인 입찰*
*최강 무기: 정보 — 경쟁자보다 더 잘 알면 정확한 가치 평가 가능*
