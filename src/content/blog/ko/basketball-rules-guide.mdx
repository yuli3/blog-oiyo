## 농구, 시간과 득점만 알면 끝

농구는 빠르지만 규칙은 단순하다. **득점 방식·시간 제한·반칙** 세 가지만 잡으면 경기가 한눈에 들어온다.

---

## 기본 — 인원·시간

```
인원: 한 팀 5명(코트). 교체 자유.
시간: FIBA 10분 × 4쿼터 / NBA 12분 × 4쿼터.
      동점 시 연장 5분.
승부: 시간 종료 시 점수 많은 팀 승(무승부 없음).
```

---

## 득점 — 2점·3점·자유투

<a id="scoring"></a>

```
2점: 3점 라인 안에서 넣은 야투
3점: 3점 라인 밖에서 넣은 야투
1점: 자유투(프리스로) — 슛 동작 중 파울 등으로 주어짐
```

---

## 시간 규칙(바이얼레이션)

농구의 묘미는 촘촘한 시간 제한이다.

| 규칙 | 내용 |
|------|------|
| **24초** | 공격은 24초 안에 슛(림 맞아야) — 안 하면 공격권 상실 |
| **8초** | 백코트에서 8초 안에 하프라인 넘어야 |
| **5초** | 가까이 수비당하며 5초 이상 공 못 가짐 |
| **3초** | 공격수가 상대 페인트존(제한구역)에 3초 이상 머물기 금지 |

---

## 주요 반칙

```
바이얼레이션(가벼운 위반 → 공격권 전환):
- 트래블링(공 들고 3걸음 이상)
- 더블드리블(드리블 멈췄다 다시)
- 백코트 바이얼레이션 등

파울(신체 접촉 반칙):
- 개인 파울 누적(FIBA 5개·NBA 6개) 시 퇴장
- 슛 동작 중 파울 → 자유투
- 팀 파울 누적 시 자유투 부여(보너스)
- 테크니컬/플래그런트 파울 → 자유투 + 공격권
```

---

## 포지션

```
1 포인트가드(PG): 경기 조율·패스
2 슈팅가드(SG): 외곽 슛
3 스몰포워드(SF): 공수 만능
4 파워포워드(PF): 골밑·리바운드
5 센터(C): 골밑 수비·득점
```

---

## 알아두면 좋은 용어

```
리바운드: 슛 실패한 공 잡기  ·  어시스트: 득점 연결 패스
스틸: 공 가로채기  ·  블록: 슛 막기
속공(패스트브레이크): 수비→공격 빠른 전환
```

---

## 핵심 요약

1. 5명·4쿼터, 시간 종료 시 점수 많은 팀 승(무승부 없음).
2. 득점은 2점·3점·자유투(1점).
3. 24·8·5·3초 시간 규칙이 경기 템포를 만든다.
4. 트래블링·더블드리블은 공격권 전환, 신체 접촉은 파울.
5. 개인 파울 누적(5~6개)이면 퇴장.

> 세부 규칙은 FIBA와 NBA가 일부 다르다(쿼터 시간·파울 한도 등).
