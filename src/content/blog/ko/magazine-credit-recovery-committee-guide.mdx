## 신용회복위원회(신복위)란?

금융기관 간 협약으로 설립된 기구로, 빚 상환이 어려운 사람의 채무를 조정해주는 기관입니다. 법원이 아닌 **행정적 절차**로 진행되어 빠르고 간편합니다.

---

## 개인회생 vs 신복위 채무조정 비교

| 항목 | 신복위 채무조정 | 개인회생 |
|------|-------------|--------|
| **절차** | 행정 (신복위) | 법원 |
| **속도** | 1~3개월 | 6~12개월 |
| **비용** | 무료 | 법원 비용 있음 |
| **원금 감면** | 제한적 (연체 이자 위주) | 최대 70~90% 감면 |
| **조건** | 협약 금융기관 부채 | 모든 부채 |
| **신용점수 영향** | 부정적 (단기) | 매우 부정적 (장기) |

---

## 신복위 채무조정 종류

### 개인워크아웃

```
대상: 연체 기간 3개월 이상 (90일 이상)
조건: 최저 생계비 이상 소득 있는 자

내용:
- 연체 이자 감면 (최대 전액 감면)
- 원금 최대 30~50% 감면 (일부 조건 충족 시)
- 남은 원금 분할 상환 (최대 10년)
- 총 갚아야 할 금액 대폭 감소

신청:
→ 신용회복위원회 상담 센터 (1600-5500)
→ 전국 지부 방문
```

### 프리워크아웃

```
대상: 연체 직전 (1~2개월 이내) 상환 위기
→ 아직 장기 연체가 되기 전 선제 조정

내용:
- 이자 일부 감면
- 원금 분할 상환 기간 연장 (최대 3~5년)
- 상환 유예 기간 부여 가능

특징:
→ 신용점수 타격이 개인워크아웃보다 적음
→ 조기에 신청할수록 유리
```

### 신속채무조정

```
대상: 코로나·경기침체 등으로 일시 어려움
→ 단기 유동성 부족 케이스

내용:
- 이자 감면 + 상환 유예
- 6~12개월 상환 유예 후 분할 상환

특징:
→ 정부 정책에 따라 시행 여부 달라짐
```

---

## 채무조정 신청 조건

```
원칙:
- 신복위 협약 금융기관(은행, 카드사, 저축은행 등) 부채
- 비협약 사채·불법 대출은 대상 외

소득 기준:
- 최저 생계비 이상의 소득 필요 (상환 능력 증명)
- 소득이 너무 낮으면 개인회생이나 파산 검토

부채 규모:
- 개인워크아웃: 15억원 이하 (무담보)
- 담보 부채 별도 협의
```

---

## 신청 절차

```
1단계: 신복위 상담 신청
       → 전화 1600-5500
       → 전국 지부 방문 (서울·경기·지방 전국 30여 곳)
       → 온라인 사전 상담

2단계: 채무 내역 조사
       → 금융기관별 부채 현황 파악
       → 소득·재산 자료 제출

3단계: 채무조정안 제시
       → 신복위에서 금융기관 동의 조율
       → 원금·이자 감면 및 상환 일정 확정

4단계: 채무조정 계약 체결 및 상환 시작
       → 약정한 날짜에 분할 상환
```

---

## 채무조정 후 신용점수 영향

```
채무조정 이력:
→ 신용점수에 부정적 영향 (단기)
→ 개인워크아웃 완료 후 5년 경과 시 신용 정보 삭제 가능

장기적으로:
→ 채무조정 완료 후 성실 상환 이력 쌓이면 신용 회복
→ 새 대출은 채무조정 기간 중 어려움
→ 채무 해소 후 신용 재건에 집중
```

---

## 신복위 채무조정이 안 맞는 경우

```
다음이면 개인회생·파산 검토:
- 소득이 거의 없어 상환 자체가 불가능
- 사채 등 비협약 채무 비중이 큰 경우
- 부채가 매우 많아 원금 감면이 더 필요한 경우

→ 신복위 상담 후 개인회생 안내를 받을 수도 있음
```

## 자주 묻는 질문

**Q. 신복위 신청 후 추심 전화가 멈추나요?**
A. 채무조정 신청 후 협약 금융기관의 추심 행위는 원칙적으로 중지됩니다. 불법 사채는 별도 대응이 필요합니다.

**Q. 신복위 채무조정과 개인회생을 동시에 할 수 있나요?**
A. 동시 진행은 어렵습니다. 신복위 조정 중 개인회생 신청 시 조정이 중단됩니다.

**Q. 보증인도 영향을 받나요?**
A. 채무조정은 주채무자와 금융기관 간 협약입니다. 보증인에 대한 청구는 별도 협의가 필요합니다.

**Q. 신청 비용이 있나요?**
A. 신복위 채무조정 신청 및 상담은 무료입니다.
