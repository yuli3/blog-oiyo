## 행정 강제의 체계

**행정 강제**: 행정 목적 실현을 위해 물리적 수단으로 실력을 행사하거나 의무 이행을 간접적으로 강제하는 작용.

```
행정 강제 체계:
┌── 행정 강제 집행
│   ├── 대집행
│   ├── 이행강제금
│   ├── 직접 강제
│   └── 강제 징수
└── 즉시 강제 (의무 부과 없이)
```

---

## 행정 대집행

**행정 대집행**: 의무자가 의무를 이행하지 않을 때 행정청이 대신 이행하고 비용을 의무자에게 징수.

### 요건 (행정 대집행법 제2조)

```
대집행 요건:
① 법령에 의한 의무 (작위 의무)
② 다른 수단으로 의무 이행 곤란
③ 불이행 방치가 심히 공익에 반할 것
④ 대체적 의무여야 (타인이 대신할 수 있는 것)
```

**대체 불가 의무**: 대집행 불가 (예: 직접 출석 의무, 진술 의무).

### 절차

```
대집행 절차:
계고 (상당한 이행 기간 + 불이행 시 대집행 경고)
   ↓ 불이행
대집행 영장 통지 (대집행 시기, 비용 등)
   ↓
대집행 실행
   ↓
비용 징수 (납부명령 → 강제 징수)
```

## 이행강제금 (집행벌)

**이행강제금**: 의무 이행을 촉구하기 위해 일정 금액을 부과하는 간접 강제 수단.

```
대집행과 이행강제금 비교:
대집행: 대체적 의무 + 행정청이 직접 이행
이행강제금: 비대체적 의무 포함 + 반복 부과 가능

건축법 위반 사례:
불법 건축물 철거 → 이행강제금 + 대집행 가능
직접 거주 의무 미이행 → 이행강제금만 가능
```

**반복 부과**: 의무 이행 시까지 1년 2회 한도로 반복 부과 가능.

## 즉시 강제

**즉시 강제**: 미리 의무를 부과할 여유 없이 즉시 실력으로 행정 목적 달성.

```
즉시 강제 요건:
- 긴급 필요성 (사전 의무 부과 불가)
- 법적 근거 필요 (법령 수권)

예시:
- 감염병 환자 강제 격리
- 위험한 물건 즉시 압류
- 경찰의 위험 방지 조치

한계:
- 비례 원칙 적용 (필요 최소한)
- 법원 사후 통제 (영장 등)
```

## 행정 조사

**행정 조사**: 행정 기관이 행정 목적 달성을 위해 자료·정보를 수집하는 활동.

```
행정 조사 유형:
- 실지 조사: 현장 직접 방문 (세무 조사)
- 장부·서류 제출 명령
- 출석 요구
- 진술 청취
```

### 행정 조사 기본 원칙

```
행정 조사 기본법:
① 최소 침해의 원칙: 목적 달성에 필요한 최소한
② 사전 통지: 조사 목적·대상·기간 사전 알림
③ 조사원증 제시 의무
④ 자발적 협조 원칙 (강제 조사는 법적 근거 필요)
⑤ 중복 조사 금지
```

## 강제 징수

**강제 징수**: 금전 납부 의무를 이행하지 않을 때 강제로 징수.

```
강제 징수 절차 (국세징수법 준용):
납부 통지 → 독촉 → 재산 압류 → 공매 → 배분
```

## 핵심 개념 카드

**대집행 요건 4가지** ★★★★★
: ① 법령상 작위 의무 ② 다른 수단 곤란 ③ 공익에 심히 반함 ④ 대체적 의무.
*암기 포인트: 작위·불가·공익·대체 = 대집행 4요건*

**이행강제금 vs 대집행** ★★★★★
: 대집행 = 대체적 의무만. 이행강제금 = 비대체적 의무도 가능. 반복 부과 가능(연 2회).
*암기 포인트: 이행강제금 = 비대체 포함, 반복*

**즉시 강제 한계** ★★★★☆
: 사전 의무 부과 없이 실력 행사. 긴급성과 법적 근거 모두 필요. 비례 원칙 엄격 적용.
*암기 포인트: 즉시강제 = 긴급+법적근거+비례*

## 실전 퀴즈

**Q. 불법 건축물 소유자가 철거 명령을 이행하지 않을 때 행정청이 취할 수 있는 조치는?**
> 이행강제금 부과 (반복 가능) + 대집행 (행정청이 직접 철거 후 비용 징수). 양자 선택 또는 병행 가능.

**Q. 행정 조사에서 세무 공무원이 사업장에 출입할 때 지켜야 할 절차는?**
> 사전 통지 (조사 목적·기간·대상 등). 현장 도착 시 조사원증 제시. 자료 제출 강제 시 별도 법적 근거 필요.
