## 정책의 의의

```
정책:
정부가 공공 문제 해결을 위해 결정한 행동 방침

정책의 유형:
배분 정책: 서비스·혜택 배분 (보조금, 복지)
규제 정책: 행위 제한 (환경, 안전 규제)
재분배 정책: 부·소득 재분배 (누진세, 사회보험)
구성 정책: 정부 구조·절차 변경 (선거법, 조직 개편)

Lowi의 정책 유형:
배분→공급자 수혜
규제→피규제자 부담
재분배→계층 간 자원 이동
```

## 정책 과정

```
① 정책 의제 설정:
사회 문제 → 정부 의제로 전환
외부 주도: 시민→정치→정부
내부 접근: 정부 내부에서 발원
동원 모형: 정부→국민 지지 획득

② 정책 결정:
목표 설정 + 대안 탐색 + 최선안 선택

③ 정책 집행:
결정된 정책을 구체적 행동으로 실행
상향식: 일선 공무원 재량 중시
하향식: 중앙의 지시에 따른 집행

④ 정책 평가:
집행 결과 평가
효과성·효율성·형평성 기준
환류 → 정책 수정·폐지
```

## 정책 결정 모형

```
합리 모형:
완전한 정보, 모든 대안 검토
최적해 선택
현실적으로 불가능

만족 모형 (Simon):
제한된 합리성 (인지 한계, 정보 부족)
만족할 만한 수준의 대안 선택

점증 모형 (Lindblom):
현재 정책에서 조금씩 수정
정치적 합의 가능한 범위 내 변화
보수적, 안정적

혼합 주사 모형 (Etzioni):
합리+점증 혼합
중요 결정=합리, 세부=점증

쓰레기통 모형 (Cohen):
문제·해결책·참여자·선택 기회가
우연히 결합
복잡한 조직 의사결정 설명
```

## 정책 집행의 변수

```
집행 성공 요인:
명확한 목표, 충분한 자원
지지적 정치 환경
집행 기관 역량

집행 저항:
관료 재량 남용, 이해관계 충돌
민간 행위자 비협조

일선 관료제 (Lipsky):
일선 공무원(교사·경찰·사회복지사)이
실질적 정책 결정자
재량권 행사로 정책 변형

정책 순응:
대상 집단이 정책에 따르는 행동
순응 제고: 교육·홍보·유인·강제
```

## 핵심 개념 카드

**정책 과정 4단계** ★★★★★
: 의제설정→결정→집행→평가(환류).
*암기 포인트: 의결집평*

**점증 모형** ★★★★★
: 현재 정책에서 소폭 수정. 합리적 탐색 불가능 시 현실적 대안.
*암기 포인트: 점증=현상유지+소폭변화*

**쓰레기통 모형** ★★★★☆
: 문제·해결책·참여자·선택기회의 우연한 결합으로 결정.
*암기 포인트: 쓰레기통=우연+혼란*

## 실전 퀴즈

**Q. 합리 모형이 현실에서 실현되기 어려운 이유는?**
> 완전한 정보 수집 불가능(정보 비용·부재). 인간 인지 능력 제한(Simon의 제한된 합리성). 모든 대안 탐색 불가능. 비용·시간 제약. 현실은 만족 모형이나 점증 모형에 가까움.

**Q. 일선 관료제 이론의 핵심 주장은?**
> 정책 집행의 실질적 주체는 일선에서 시민과 접촉하는 공무원. 이들은 상당한 재량권을 가지고 있어 정책 내용을 변형할 수 있음. 교사·경찰·복지사 등이 실질적 정책 결정자 역할.
