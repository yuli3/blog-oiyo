## 문서 편집 고급 기능

```
찾기와 바꾸기:
→ 찾기 (Ctrl+F): 특정 문자열 검색
→ 바꾸기 (Ctrl+H): 찾아서 일괄 대체
→ 고급 옵션:
  대소문자 구분·전체 단어·정규식
  서식까지 포함한 검색·바꾸기
  방향 (위/아래)·범위 (전체/선택)
→ 한글에서 찾기·바꾸기:
  자모 분리 검색 (초성 검색)
  속성으로 찾기: 글꼴·문단 속성 기준

맞춤법·문법 검사:
→ 맞춤법 (F8 / 도구 메뉴):
  빨간 밑줄: 맞춤법 오류
  파란 밑줄: 문법·표현 제안
→ 사전 추가: 전문 용어·고유 명사 등록
→ 자동 고침:
  오탈자 자동 수정
  날짜·시간 자동 입력
  영문 첫 자 대문자 자동화

스타일 (Style):
→ 제목 1·2·3·본문·목록 등 미리 정의된 서식
→ 일관된 문서 서식 유지·빠른 수정
→ 스타일 수정: 스타일 기반 일괄 변경
→ 목차 생성: 제목 스타일 기준 자동 목차

매크로 (Macro):
→ 반복 작업 자동화: 여러 단계 명령 기록·실행
→ 기록 방법: 도구 → 매크로 → 기록 시작
→ VBA (Visual Basic for Applications): 프로그래밍으로 자동화
→ 단축키 지정: 매크로에 키 조합 배정

개요 보기 (Outline View):
→ 제목 수준에 따라 계층 구조 편집
→ 단락 승격·강등: Alt+Shift+좌/우 화살표
→ 문단 이동: Alt+Shift+위/아래 화살표
→ 목차 자동 생성과 연동
```

## 단락·글꼴 서식

```
글꼴 서식:
→ 글꼴 이름: 굴림·바탕·맑은 고딕·HY 계열 등
→ 글꼴 크기: 포인트 (pt) 단위
→ 글꼴 스타일: 굵게(B)·기울임(I)·밑줄(U)·취소선
→ 색상: 글자 색·강조 색(형광펜)
→ 효과: 그림자·외곽선·엠보싱·양각·음각
→ 자간: 글자 간격 조절 (비율·포인트)
→ 장평: 글자 너비 비율 (%)

단락 서식:
→ 맞춤: 왼쪽·오른쪽·가운데·양쪽 (Ctrl+L/R/E/J)
→ 들여쓰기:
  첫 줄 들여쓰기·내어쓰기 (한 수준: Tab/Shift+Tab)
  눈금자로 설정
→ 줄 간격:
  고정·배수·최소·정확히
  1줄·1.5줄·2줄 등
→ 단락 앞뒤 간격: 단락과 다음 단락 사이 여백
→ 탭 정렬: 왼쪽·오른쪽·가운데·소수점 탭

목록:
→ 글머리 기호 (Bullet): 원·사각형·특수문자
→ 번호 매기기: 1·2·3 / 가·나·다 / 로마자
→ 다단계 목록: 수준별 중첩 목록
→ 목록 수준 변경: Tab (내려가기) / Shift+Tab (올라가기)

테두리·음영:
→ 단락 테두리: 상하좌우·박스·그림자
→ 단락 음영 색: 배경색 지정
→ 페이지 테두리: 전체 페이지 테두리
```

## 표와 그림

```
표 삽입과 편집:
→ 삽입: 삽입 메뉴 → 표·행·열 수 지정
→ 표 선택:
  셀 선택: 셀 왼쪽 클릭
  행 선택: 행 왼쪽 여백 클릭
  열 선택: 열 위쪽 경계 클릭
  전체 표: 표 왼쪽 위 이동 핸들 클릭
→ 셀 병합: 선택 후 레이아웃 → 셀 병합
→ 셀 나누기: 열/행 수 지정
→ 자동 맞춤: 내용·창·고정 너비 기준

표 서식:
→ 셀 크기: 행 높이·열 너비 지정
→ 셀 여백: 셀 안 상하좌우 여백
→ 텍스트 방향: 가로·세로 270도 회전
→ 셀 정렬: 상·중·하 + 왼·가운데·오른쪽 (9가지)
→ 테두리 스타일: 실선·점선·이중선·굵기·색
→ 표 스타일: 미리 정의된 색상·테두리 조합

그림·도형 삽입:
→ 그림 삽입: 삽입 → 그림 → 파일에서
→ 그림 서식:
  크기 조절: 모서리 핸들 드래그 (비율 유지: Shift)
  자르기: 불필요한 부분 제거
  텍스트 배치: 문자열 위·아래·사각형·빽빽이·뒤·앞
→ 도형: 직선·화살표·사각형·원·말풍선·순서도
→ 개체 위치 고정: 단락·페이지·열 기준

그림 효과·조정:
→ 밝기·대비·선명도 조정
→ 예술 효과: 흐림·연필 스케치·수채화
→ 배경 제거: 배경색 투명화
→ SmartArt: 계층 구조·순환·관계 다이어그램
```

## 인쇄와 페이지 설정

```
페이지 설정:
→ 용지:
  A4 (210×297mm): 기본 공문서
  B5 (176×250mm): 소형 문서
  Letter (215.9×279.4mm): 미국 표준
→ 용지 방향:
  세로: 기본 설정
  가로: 표·이미지 많은 문서
→ 여백: 위·아래·왼쪽·오른쪽·제본 여백
→ 머리글·바닥글:
  페이지 번호·날짜·파일 이름
  짝수·홀수 페이지 다른 머리글

단 나누기:
→ 1단~3단: 신문·잡지 레이아웃
→ 단 너비·간격 조절
→ 단 나누기 구분선 표시
→ 텍스트 흐름 방향: 왼쪽→오른쪽

섹션과 구역 나누기:
→ 섹션 나누기: 문서 내 다른 페이지 설정 적용
→ 나누기 종류:
  다음 페이지·연속·홀수/짝수 페이지
→ 섹션별 페이지 번호 시작·머리글 독립 설정

인쇄:
→ 인쇄 미리 보기 (Ctrl+P → 미리 보기):
  확대·축소·여러 페이지 동시 보기
→ 인쇄 옵션:
  페이지 범위: 전체·현재·특정 페이지
  인쇄 매수·한 면·양면·소책자
  인쇄 순서: 정순·역순
  인쇄 품질: 초안·표준·고품질
→ 용지 1장에 여러 페이지 인쇄 (N-up)
→ 축소 인쇄·확대 인쇄
```

## 파일 관리와 시험 단축키

```
파일 저장 형식:
→ .hwp: 한글 기본 형식
→ .hwpx: 한글 XML 기반 형식 (최신)
→ .docx: Microsoft Word 호환
→ .doc: 구형 Word 형식
→ .pdf: 인쇄·배포 전용
→ .txt: 텍스트만 저장 (서식 없음)
→ .rtf: Rich Text Format (호환성)
→ .odt: 오픈오피스 형식

파일 보안:
→ 암호 설정:
  열기 암호: 파일 열 때 비밀번호 필요
  편집 암호: 내용 변경 제한
→ 읽기 전용: 수정 불가·저장만 다른 이름으로
→ 배포용 문서: 편집 완전 제한

버전 관리:
→ 자동 저장: 일정 간격 임시 저장
→ 임시 파일 복구: 비정상 종료 시 복구
→ 변경 내용 추적:
  수정·삽입·삭제 표시 (빨간색 등)
  작성자·날짜 기록
→ 문서 비교: 두 버전 차이점 표시

시험 빈출 단축키:
→ 파일: Ctrl+N (새 문서)·Ctrl+O (열기)·Ctrl+S (저장)·Ctrl+P (인쇄)
→ 편집: Ctrl+Z (실행 취소)·Ctrl+Y (재실행)
         Ctrl+X (잘라내기)·Ctrl+C (복사)·Ctrl+V (붙여넣기)
         Ctrl+A (전체 선택)·Ctrl+F (찾기)·Ctrl+H (바꾸기)
→ 서식: Ctrl+B (굵게)·Ctrl+I (기울임)·Ctrl+U (밑줄)
         Ctrl+L/E/R/J (정렬: 왼쪽/가운데/오른쪽/양쪽)
→ 이동: Home/End (줄 처음/끝)
         Ctrl+Home/End (문서 처음/끝)
         Ctrl+방향키 (단어 단위 이동)
→ 선택: Shift+방향키 (한 글자씩)
         Ctrl+Shift+방향키 (단어 단위)
         Shift+Ctrl+Home/End (문서 처음/끝까지 선택)
→ 보기: Ctrl+= (확대)·Ctrl+- (축소)·Ctrl+0 (쪽 맞춤)
```

## 자주 묻는 질문

**Q. 워드프로세서 시험에서 기능키 문제가 자주 나오는 이유는 무엇인가요?**
A. 워드프로세서 실기 및 필기 시험에서 기능키(단축키) 문제가 많이 출제되는 이유는 실무 활용 능력을 직접 확인할 수 있기 때문입니다. 단순히 메뉴를 외우는 것보다 Ctrl+F(찾기)·Ctrl+H(바꾸기)·F8(맞춤법 검사 - 한글) 같은 기능키를 알아야 빠른 문서 작업이 가능합니다. 시험 준비 전략으로는 주요 단축키를 그룹(파일·편집·서식·이동·선택)으로 분류해 외우는 것이 효율적입니다. 특히 Ctrl+Z(실행 취소), Ctrl+S(저장), Ctrl+P(인쇄) 같은 공통 단축키와 한글 전용 기능키(F3 블록 설정, F8 맞춤법 등)를 구분해서 숙지해야 합니다. 실기에서는 단축키보다 실제 기능 수행 결과물이 중요하므로 자주 연습해 손에 익히는 것이 최선입니다.

**Q. 한글(HWP)과 Microsoft Word의 차이점 중 시험에 자주 나오는 항목은 무엇인가요?**
A. 시험 단골 비교 항목입니다. 파일 형식: 한글은 .hwp/.hwpx, Word는 .docx/.doc입니다. 단 나누기: 한글은 F6키(또는 서식 메뉴), Word는 레이아웃 탭에서 설정합니다. 맞춤법 단축키: 한글 F8, Word는 F7입니다. 스타일: 한글은 '스타일'이라고 부르고, Word는 '스타일'로 동일하지만 인터페이스 차이가 있습니다. 표 계산: 한글은 F5(셀 계산), Word는 레이아웃 탭에서 수식을 사용합니다. 차트: 한글은 '차트 만들기', Word는 '차트 삽입'으로 기능명이 다릅니다. 시험에서는 두 프로그램의 기능명·단축키 차이를 구분하는 문제가 자주 출제됩니다. 어떤 프로그램 기준 문제인지 먼저 확인하는 습관이 중요합니다.
