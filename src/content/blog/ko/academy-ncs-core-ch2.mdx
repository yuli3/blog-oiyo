## 수리능력 개요

**NCS 수리능력**은 직장 생활에서 수학적으로 사고하고 계산하는 능력입니다.

공기업 시험에서 수리능력은 수학 고수들을 위한 영역이 아닙니다. 기초 계산과 도표 분석이 핵심입니다.

**4가지 하위 능력**:

| 하위 능력 | 설명 |
|---------|------|
| **기초연산능력** | 사칙연산, 비율, 단위 환산 |
| **기초통계능력** | 평균, 중앙값, 최빈값, 분산, 표준편차 |
| **도표분석능력** | 표, 그래프의 수치를 읽고 해석 |
| **도표작성능력** | 데이터를 도표로 변환 |

## 기초연산: 자주 쓰이는 패턴

### 백분율과 비율

**비율 = 부분 / 전체 × 100**

**증가율 = (비교 연도 - 기준 연도) / 기준 연도 × 100**

예: 2023년 매출 1,000억 → 2024년 매출 1,250억
증가율 = (1,250 - 1,000) / 1,000 × 100 = **25%**

**증가폭 vs 증가율 구분**: 시험에서 자주 함정이 됩니다.
- 증가폭: 250억 (절대 차이)
- 증가율: 25% (상대 변화)

### 속도·거리·시간

**거리 = 속도 × 시간**

**시간 = 거리 / 속도**

실무 응용: 처리량 = 처리율 × 시간

### 농도 계산

**농도(%) = 용질의 양 / 용액의 양 × 100**

혼합 문제: 가중평균으로 해결

예: 20% 소금물 100g + 10% 소금물 200g 혼합 농도?
→ (20×100 + 10×200) / (100+200) = (2000+2000)/300 = **13.3%**

## 기초 통계 개념

### 대표값

| 개념 | 계산법 | 특징 |
|------|--------|------|
| **평균(Mean)** | 총합 / 개수 | 극단값에 민감 |
| **중앙값(Median)** | 크기순 배열 후 가운데 값 | 극단값에 둔감 |
| **최빈값(Mode)** | 가장 자주 나타나는 값 | 범주형 자료에 유용 |

**왜 평균만으로 부족한가?**

예: [1, 2, 3, 4, 100]의 평균 = 22, 중앙값 = 3

평균 22는 대부분의 값과 동떨어집니다. 소득 분포처럼 극단값이 있을 때 중앙값이 더 현실적입니다.

### 산포도

**분산(Variance)**: 각 값이 평균으로부터 얼마나 떨어져 있는지의 평균.

**표준편차(Standard Deviation)** = √분산

표준편차가 클수록 값들이 평균 주위에 고르게 분포하지 않고 흩어져 있습니다.

실무 응용: 품질 관리, 성과 분포, 리스크 평가

## 도표 분석 전략

### 자주 나오는 도표 유형

**막대 그래프**: 항목 간 크기 비교

**꺾은선 그래프**: 시계열 변화 추이 (언제 증가·감소)

**원 그래프 (파이차트)**: 구성 비율

**표**: 다차원 데이터 (연도 × 항목)

### 도표 분석 5단계 전략

**Step 1. 제목 확인**: 이 도표가 무엇을 보여주는가? (대상, 기간, 단위)

**Step 2. 축 확인**: 세로축·가로축의 의미와 단위 (백만 원인지, 억 원인지)

**Step 3. 전체 트렌드**: 전반적으로 증가 추세인가, 감소인가, 혼재인가?

**Step 4. 특이점 확인**: 급등·급락, 역전 현상, 이상치

**Step 5. 선택지와 대조**: 선택지의 주장이 도표에서 실제로 확인되는가?

## 빈출 도표 함정 유형

### 함정 1: 절대값 vs 비율 혼동

도표는 절대값을 보여주는데, 선택지는 "비율이 가장 높다"라고 주장하는 경우.

예: A가 B보다 절대 수치는 크지만, 전체 대비 비율은 B가 더 높을 수 있습니다.

### 함정 2: 증가폭 vs 증가율

연도별 절대 수치 차이(증가폭)와 전년 대비 성장률(증가율)을 구분해야 합니다.

### 함정 3: 기준 연도 혼동

"2020년 대비"와 "전년 대비"는 다릅니다. 어느 해를 기준으로 비교하는지 확인해야 합니다.

### 함정 4: 단위 착각

10,000원 단위 vs 백만 원 단위 — 계산 전에 반드시 단위 확인!

## 계산 실수 줄이는 습관

**1. 어림셈 먼저**: 정확한 계산 전에 대략적인 답을 추정. 선택지가 크게 다른 경우 빠른 소거 가능.

예: 1,234 × 198 ≈ 1,200 × 200 = 240,000 (정확한 답: 244,332)

**2. 단위 통일**: 계산 중 단위를 일치시키고 최종 결과의 단위 확인

**3. 검산 습관**: 역산 또는 다른 방법으로 한 번 더 확인

**4. 소거법 활용**: 선택지에서 명백히 불가능한 것부터 제거

**5. 극단값 의심**: 나온 답이 상식적으로 너무 크거나 작으면 재계산

## 자주 나오는 계산 유형

### 일률 문제 (Work Rate)

A가 혼자 하면 x일, B가 혼자 하면 y일 걸리는 일을 함께 하면?

**1일 작업량**: A = 1/x, B = 1/y, 함께 = 1/x + 1/y

→ 완료까지 걸리는 날 = 1 / (1/x + 1/y) = xy / (x+y)

### 평균 속도

A→B 구간을 속도 60으로, B→A를 속도 40으로 왕복할 때 평균 속도?

**평균 속도 = 2 / (1/60 + 1/40) = 2 / (5/120) = 48**

(단순 평균 50이 아닙니다! 시간가중 평균)

### 비례배분

전체 120을 A:B = 3:5로 나눌 때?
- A = 120 × 3/(3+5) = 120 × 3/8 = **45**
- B = 120 × 5/8 = **75**
