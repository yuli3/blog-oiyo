# 제12편. 경제성장의 문제

## 제33장. 경제성장 이론

### 1. 솔로우 성장 모형 (외생적 성장)

신고전학파 솔로우(Solow)는 노동과 자본을 투입 생산 요소로 가정합니다.

- **자본의 한계생산 체감**: 자본이 지속 투입될수록 1단위 추가 자본이 창출하는 생산량은 점차 감소.
- **균제 상태 (Steady State)**: 신규 투자액이 감가상각 + 인구 증가분을 정확히 상쇄하는 정지 상태. 이 상태에서는 1인당 국민소득 성장률 = 0.
- **기술 진보의 역할**: 균제 상태의 한계를 타파하는 힘. 모형 외부(외생)에서 떨어지는 것으로 가정 → 지속 성장의 원천.

### 2. 내생적 성장 이론 (루카스, 로머)

왜 선진국은 개도국과의 격차를 더 벌릴 수 있는가?

- **지식·인적 자본의 수확 체증**: R&D·교육 투자는 외부 효과를 창출하여 지속 성장 가능.
- **정부 개입 논리**: 지식은 공공재 성격 → 민간은 과소 투자(시장실패) → 국가의 교육·R&D 보조 타당성 증명.

### 3. 무역 발전 전략 비교

| 전략            | 내용                            | 장점                             | 단점              |
| --------------- | ------------------------------- | -------------------------------- | ----------------- |
| **수출 주도형** | 수출 중심의 성장 (한국 모델)    | 규모의 경제 확보, 기술 이전 빠름 | 대외 의존도 과도  |
| **수입 대체형** | 내수 보호·외세 탈피 우선 (남미) | 자국 산업 보호                   | 규모 한계, 폐쇄적 |

# 제13편. 국제경제

## 제34~35장. 국제 무역 체제

### 1. 비교우위론 (리카도)

어떤 나라든 **기회 비용이 상대적으로 낮은 상품에 특화하여 무역**하면, 양국 모두의 부가 증가한다(무역 이익).

### 2. 관세 vs 수입할당제 비교

| 구분           | 관세 (Tariff)        | 수입할당제 (Quota)                         |
| -------------- | -------------------- | ------------------------------------------ |
| 개념           | 수입품에 세금 부과   | 수입 물량 자체에 법적 한도 설정            |
| 국내 가격      | 국제가보다 인위 상승 | 국제가보다 인위 상승                       |
| 초과 수익 귀속 | 정부의 관세수입      | 면허 배분·경매·수출자 협정에 따라 국내 면허보유자·정부·외국 수출자 등에 할당지대 귀속 |
| 정책 투명성    | 높음                 | 낮음 (부패·지대추구 위험)                  |

## 제36장. 환율 구조와 통화제도

### 1. 환율 변동 방향과 결정 요인

**환율(원/달러) 상승 = 원화 가치 하락 = 달러 강세**

| 거시 지표           | 환율에 미치는 영향                   |
| ------------------- | ------------------------------------ |
| 경상수지 흑자       | 외화 공급↑ → 환율↓                   |
| 경상수지 적자       | 외화 수요↑ → 환율↑                   |
| 국내금리 > 해외금리 | 해외 자본 유입↑ → 외화 공급↑ → 환율↓ |
| 국내물가 상승       | 수출↓, 수입↑ → 외화 수요↑ → 환율↑    |

### 2. 변동환율제 vs 고정환율제: 통화·재정정책 효과 (먼델-플레밍)

단기 고정물가, 소규모 개방경제, 완전자본이동, 국내외 자산의 완전대체와 주어진 세계이자율을 둔 극단적 먼델–플레밍 기준입니다. 자본이동성·위험프리미엄·불완전 가격조정이 달라지면 아래 효과도 약해지거나 달라집니다.

| 정책          | 변동환율제                                                                  | 고정환율제                                                                                     |
| ------------- | --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **통화 정책** | 위 가정에서 환율 절하·순수출 경로로 상대적으로 강함 | 환율 방어 개입으로 통화량이 되돌아가 상대적으로 약함 |
| **재정 정책** | 환율 절상·순수출 감소로 상대적으로 약함 | 환율 방어에 따른 통화공급이 재정확대를 뒷받침해 상대적으로 강함 |

## 제37장. 마셜-러너 조건과 J-커브 효과

- **마셜-러너 조건**: 환율 상승이 순수출 증가로 이어지려면, 수출품의 가격탄력성 + 수입품의 가격탄력성 합 > 1이어야 함.
- **J-커브 효과**: 환율 상승 직후에는 단기 계약 등으로 인해 순수출이 오히려 감소하다가, 상당한 시간이 지난 후에야 증가. 그래프 형태가 J자 모양.

### 2. 양적 완화 (QE: Quantitative Easing)

단기 정책금리가 실효하한에 가까워 전통적 금리 인하 여력이 작을 때 사용할 수 있는 비전통적 통화정책입니다.

- 중앙은행이 직접 중장기 국채·자산담보증권을 대량 매입 → 시중에 유동성 직접 공급.
- **전달 경로**: 기간프리미엄·중장기 금리, 포트폴리오 재조정, 기대와 금융여건을 통해 수요에 영향을 줄 수 있습니다. 대출·자산가격·소비의 반응은 금융상태에 따라 다릅니다.
- **위험과 논쟁**: 자산가격·분배·환율·출구전략·인플레이션 영향은 시기와 정책 조합에 따라 달라져 자동 결과로 단정하지 않습니다.

### 3. 케인즈의 유동성 함정과 양적 완화의 관계

<Callout type="note" title="유동성 함정 (Liquidity Trap)">
  이자율이 0%에 근접하면 채권 가격이 너무 높아 모두가 가격 하락을 예상.
  전통적 IS–LM의 극단에서는 화폐수요의 이자율 탄력성이 매우 커져 통화량 확대의
  단기금리·소득 효과가 작아집니다. 이는 전통적 금리경로의 한계이며 모든 통화정책이
  완전히 무력하거나 재정정책만 유일하다는 뜻은 아닙니다. 양적완화는 장기자산 매입과
  기대·포트폴리오 경로를 사용합니다.
</Callout>
