## 법정 근로 시간

```
소정 근로 시간:
1일 8시간, 1주 40시간 (휴게시간 제외)

연장 근로:
당사자 합의 → 1주 12시간 한도
→ 총 주 52시간 (40+12)

5인 미만:
연장근로 가산수당 없음 (12시간 한도도 적용됨)

탄력적 근로시간제:
- 2주 이내: 특정 주 48시간까지
- 3개월 이내: 특정 주 52시간까지
- 단위 기간 평균 40시간 초과 불가
```

---

## 연장·야간·휴일 근로 가산수당

```
가산수당 (5인 이상 사업장):
연장 근로: 통상임금의 50% 가산
야간 근로 (22시~06시): 통상임금의 50% 가산
휴일 근로: 통상임금의 50% 가산

중복 가산:
야간 + 연장: 각각 50%씩 가산 = 200%
휴일 + 8시간 이내: 50% 가산
휴일 + 8시간 초과: 100% 가산

계산 예시:
통상임금 시간급 = 15,000원
연장 2시간 근무:
= 15,000 × 2 × 150% = 45,000원
```

## 휴게 시간

```
휴게 시간 기준:
4시간 근무 시: 30분 이상
8시간 근무 시: 1시간 이상

특성:
- 근로자가 자유롭게 이용
- 임금 지급 불필요
- 근로 시간에 미포함

대기 시간:
사용자 지휘·감독 받는 대기 = 근로 시간
자유로운 대기 = 휴게 시간
```

## 연차 유급 휴가

```
연차 발생 기준:
1년 80% 이상 출근: 15일
계속 근로 1년 미만 또는 80% 미만:
→ 1개월 개근 시 1일 발생 (월차)

가산 휴가:
3년 이상 계속 근로: 2년마다 1일 가산
최대 25일 한도

연차 사용 촉진 제도:
사용자가 사용 시기 지정 통지 → 미사용 시
→ 사용자 연차수당 지급 면제

연차수당:
미사용 연차 × 1일 통상임금
소멸시효: 3년
```

## 주요 법정 휴일

```
법정 공휴일 (근로자의 날 포함):
근로자의 날: 5월 1일 (유급 휴일)
관공서 공휴일: 2022년부터 민간기업도 적용

주휴일:
주 1회 유급 휴일
1주 소정 근로일 개근 시 부여

유급 vs 무급:
주휴일·법정공휴일: 유급
약정 휴일: 노사 합의에 따라 결정
```

## 핵심 개념 카드

**주 52시간** ★★★★★
: 소정근로 40시간+연장 12시간=52시간. 5인 이상 사업장 적용.
*암기 포인트: 40+12=52시간*

**연장·야간·휴일 가산 50%** ★★★★★
: 각각 통상임금 50% 가산. 야간+연장 겹치면 각각 가산(200%).
*암기 포인트: 연장·야간·휴일=각 50% 가산*

**연차 15일 발생 요건** ★★★★★
: 1년간 80% 이상 출근. 3년이상 2년마다 1일 가산, 최대 25일.
*암기 포인트: 1년80%=15일, 최대 25일*

## 실전 퀴즈

**Q. 야간에 4시간 연장 근무한 경우 가산수당은 통상임금의 몇 %인가?**
> 야간수당 50% + 연장수당 50% = 각각 가산 → 총 통상임금의 200%. 시간급 × 4시간 × 200% = 실제 지급액.

**Q. 입사 후 8개월 만에 퇴직한 근로자의 연차는?**
> 1년 미만이므로 매월 개근 시 1일씩 발생 → 최대 8일 연차. 소진하지 못한 연차는 연차수당으로 지급.
