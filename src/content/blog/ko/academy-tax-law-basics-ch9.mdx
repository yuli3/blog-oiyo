## 절세의 원칙

```
절세 (Tax Saving): 세법이 허용하는 범위 내에서 합법적으로 납세액 최소화
탈세 (Tax Evasion): 불법적 납세 회피 → 가산세·형사처벌
조세 회피 (Tax Avoidance): 합법이나 과세 취지에 벗어난 거래 이용
→ 실질과세 원칙으로 부인 가능

합리적 절세 원칙:
① 소득 분산: 소득을 여러 사람·기간에 분산
② 공제 활용: 세법상 모든 공제·감면 활용
③ 타이밍 조절: 소득·비용의 귀속 연도 최적화
```

## 개인 절세 수단

### 연금 관련 세액공제

```
연금저축펀드:
- 연 600만 원 한도 세액공제
- 공제율: 15% (총급여 5,500만 이하) / 12%

IRP (개인형 퇴직연금):
- 연금저축과 합산 900만 원 한도
- 연금저축 600만 + IRP 300만 (합산 900만)
- 세액공제: 동일

예시:
연봉 5,000만, 연금저축+IRP 900만 납입
세액공제 = 900만 × 15% = 135만 원 절세
```

### ISA (개인종합자산관리계좌)

```
ISA:
- 국내 주식·펀드·예금 한 계좌로 통합
- 순이익 200만 원 비과세 (서민형 400만)
- 초과분: 9.9% 분리과세

장점:
손익 통산 → 수익과 손실 합산 후 과세
예금·주식·펀드 한 계좌에서 운용
```

### 주택 관련 공제

```
주택담보대출 이자 공제:
- 장기주택저당차입금 이자상환액 공제
- 연 최대 2,000만 원 (상환 방식에 따라)

월세 세액공제:
- 총급여 8,000만 이하 무주택 근로자
- 공제율: 15~17%
- 연 1,000만 원 한도
```

## 부동산 절세 포인트

```
양도세 절세:
① 장기 보유: 장기보유특별공제 최대 80% (1주택)
② 1세대 1주택 비과세 요건 충족
③ 필요경비 최대 입증 (리모델링·자본지출 증빙)

취득세 절세:
④ 생애최초 주택구입: 취득세 감면 (200만 한도)
⑤ 1주택 유지: 다주택 중과(8·12%) 방지

증여 절세:
⑥ 증여는 10년 단위 분산 (공제 반복 사용)
⑦ 미성년 자녀: 2,000만 → 성년 후 5,000만 추가
⑧ 증여 후 상승분 = 수증자 것 → 증여 타이밍

임대소득 절세:
⑨ 주택 임대소득 분리과세 vs 종합과세 선택
⑩ 등록임대주택: 세액감면 (요건 충족 시)
```

## 법인 절세 포인트

```
법인 설립:
- 개인사업자 → 법인 전환: 세율 차이 이용
  개인 소득세 최대 45% vs 법인세 최대 24%

법인 비용 처리:
- 대표이사 급여 (적정 수준)
- 차량 감가상각·유지비 (법인 명의)
- 교육훈련비·복리후생비

배당 전략:
- 이익잉여금 → 배당 vs 급여 선택
- 배당소득 2,000만 이하: 분리과세 14%

퇴직금 설정:
- 임원 퇴직금: 소득세 분류과세 유리
```

## 핵심 개념 카드

**연금저축+IRP 한도** ★★★★★
: 연금저축 600만+IRP 합산 900만. 세액공제율 15%(총급여 5,500만이하)/12%.
*암기 포인트: 연금저축600만, IRP합산900만*

**ISA 비과세 한도** ★★★★★
: 일반형 200만, 서민·농어민형 400만. 초과분 9.9% 분리과세.
*암기 포인트: ISA=200만 비과세+손익통산*

**증여세 10년 분산** ★★★★☆
: 증여재산공제는 10년 합산. 10년마다 공제 리셋 → 반복 사용 가능.
*암기 포인트: 10년마다 증여 공제 재사용*

## 실전 퀴즈

**Q. 총급여 4,500만인 근로자가 연금저축 600만+IRP 300만을 납입했을 때 세액공제액은?**
> (600만+300만)×15% = 900만×15% = 135만 원 세액공제.

**Q. 자녀 증여 시 10년 단위 분산이 절세에 유리한 이유는?**
> 증여재산공제(직계비속 5,000만)는 10년 합산이 기준. 10년 지나면 공제 초기화 → 다시 5,000만 공제 가능. 분산 증여로 세율 낮추고 공제 반복 활용.
