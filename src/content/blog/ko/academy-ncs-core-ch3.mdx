## 문제해결능력이란

**NCS 문제해결능력**은 업무에서 발생하는 문제를 인식하고, 원인을 분석하며, 최적의 해결책을 찾아 실행하는 능력입니다.

**2가지 하위 능력**:
- **사고력**: 창의적·논리적·비판적으로 생각하는 능력
- **문제처리능력**: 문제를 정의하고 해결책을 도출해 실행하는 능력

---

## 문제의 유형

직장에서 마주치는 문제를 유형별로 이해하면 접근 방법이 달라집니다.

| 유형 | 특징 | 접근법 |
|------|------|--------|
| **발생형 문제** | 현재 기준과 현실의 차이 → "이미 발생한 문제" | 원인 분석 → 복구 |
| **탐색형 문제** | 현재 기준은 충족하지만 더 잘할 수 있는 기회 | 개선 아이디어 탐색 |
| **설정형 문제** | 미래 목표와 현재의 차이 → "아직 발생하지 않은 문제" | 목표 설정 → 계획 |

---

## 문제 해결의 5단계

**1단계: 문제 인식**

무엇이 문제인가를 명확히 정의합니다. 증상(Symptom)과 문제(Problem)를 구분해야 합니다.

예: "매출이 줄었다"는 증상 → 문제는 "신규 고객 획득률이 전년 대비 30% 감소했다"

**2단계: 문제 정의**

문제를 측정 가능한 용어로 표현합니다. 좋은 문제 정의는:
- 구체적 (수치 포함)
- 현재 상태와 목표 상태의 차이 명시
- 비난이 아닌 상황 중심

**3단계: 원인 분석**

표면적 원인이 아닌 근본 원인을 찾습니다.

**4단계: 해결책 개발**

여러 대안을 생성하고 최적 방안을 선택합니다.

**5단계: 실행 및 평가**

해결책을 실행하고 효과를 측정합니다.

## 원인 분석 도구

### 5Why 분석

"왜?"를 5번 반복해 근본 원인에 도달하는 방법. 도요타 생산 시스템에서 유래.

**예시**: 생산 라인이 멈췄다.

1. 왜? → 기계가 과부하 상태였다
2. 왜? → 윤활유가 충분하지 않았다
3. 왜? → 오일 펌프가 제대로 작동하지 않았다
4. 왜? → 펌프 필터가 막혔다
5. 왜? → 필터를 교체하는 주기적 점검이 없었다

**근본 원인**: 예방적 유지관리 시스템 부재

### 로직 트리 (Logic Tree)

문제를 계층적으로 분해하는 방법. MECE(Mutually Exclusive, Collectively Exhaustive — 상호 배타적이고 전체를 포괄하는) 원칙을 적용합니다.

```
매출 감소
├── 기존 고객 이탈
│   ├── 가격 경쟁력 약화
│   └── 서비스 품질 저하
└── 신규 고객 획득 실패
    ├── 마케팅 부족
    └── 브랜드 인지도 낮음
```

### 피시본 다이어그램 (Fishbone / Ishikawa)

결과(물고기 머리)에서 원인(뼈대)을 역으로 추적하는 도구.

일반적으로 6M 카테고리로 원인을 분류합니다:
- Man (사람)
- Machine (기계)
- Method (방법)
- Material (재료)
- Measurement (측정)
- Mother Nature (환경)

## 논리적 사고

### 연역적 추론 vs 귀납적 추론

**연역적 추론**: 일반 원칙 → 특정 결론

- 전제 1: 모든 사람은 죽는다
- 전제 2: 소크라테스는 사람이다
- 결론: 소크라테스는 죽는다

시험 응용: 전제가 참이라고 가정하고, 결론이 논리적으로 타당한지 판단.

**귀납적 추론**: 특정 사례 → 일반 원칙

- 사례: A, B, C 기업 모두 원가 절감 후 수익성이 개선됨
- 결론: 원가 절감은 수익성을 높인다

주의: 귀납적 결론은 "강한 주장"이 아닌 "개연성 있는 결론"

### 논리적 오류 유형

| 오류 | 설명 | 예시 |
|------|------|------|
| 성급한 일반화 | 소수 사례로 전체를 결론 | "내가 아는 의사들이 다 바쁘니 모든 의사는 바쁘다" |
| 허수아비 공격 | 상대 주장을 왜곡해 반박 | 원래 주장과 다른 쉬운 버전을 공격 |
| 순환 논리 | 결론을 전제로 사용 | "이 약이 좋은 건 효과가 있기 때문이고, 효과가 있는 건 좋은 약이기 때문이다" |
| 권위에 호소 | 전문가 말이라 무조건 옳다 | 관련 없는 분야의 전문가 인용 |

## 창의적 사고 기법

### 브레인스토밍 (Brainstorming)

**규칙**:
1. 비판 금지 (모든 아이디어 수용)
2. 양 우선 (질보다 양)
3. 타인 아이디어에 편승 가능
4. 자유롭고 비현실적 아이디어도 환영

**변형**: 브레인라이팅 — 말 대신 글로 쓰는 방식. 내성적인 사람이 더 활발히 참여할 수 있음.

### SCAMPER 기법

기존 아이디어를 변형해 새 아이디어 도출.

| 글자 | 의미 | 질문 |
|------|------|------|
| S | Substitute (대체) | 다른 재료/방법으로 대체하면? |
| C | Combine (결합) | 두 가지를 합치면? |
| A | Adapt (적용) | 다른 분야 아이디어를 가져오면? |
| M | Modify (변형) | 크기·형태·색을 바꾸면? |
| P | Put to other uses (다른 용도) | 다른 용도로 쓰면? |
| E | Eliminate (제거) | 없애면 어떻게 될까? |
| R | Reverse/Rearrange (역발상) | 거꾸로 생각하면? |

## NCS 시험 문제해결 문제 유형

**1. 상황판단형**: 직장 상황이 주어지고, 가장 적절한 행동을 고르는 문제
→ 실제 업무 맥락을 이해하고 "합리적이고 협력적인 행동"을 선택

**2. 자료 해석 + 판단형**: 데이터·도표가 주어지고 적절한 결론이나 조치를 선택
→ 5단계 문제 해결 프로세스 적용

**3. 논리 추론형**: 조건이 주어지고 참/거짓을 판단하거나 순서를 결정
→ 연역적 추론, MECE 체계로 정리

**핵심 전략**: 감정보다 프로세스. "직관적으로 좋아 보이는 것"이 아니라 "단계적으로 분석했을 때 가장 합리적인 것"을 선택.
