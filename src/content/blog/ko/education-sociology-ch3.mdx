## 성(Sex)과 젠더(Gender)

```
생물학적 성(Sex):
→ 생물학적·해부학적 차이 (염색체, 호르몬, 생식기)
→ XX (여성), XY (남성) → 사실 스펙트럼 존재

사회적 성(Gender):
→ 사회·문화적으로 구성된 여성성·남성성
→ 역할, 기대, 행동 규범
→ 시대·사회마다 다름 → 사회적 구성물

젠더 vs 섹스 구분의 중요성:
→ 생물학적 특성 ≠ 사회적 역할·능력 차이
→ "여성은 감성적, 남성은 이성적" → 사회화의 결과

젠더 정체성:
→ 자신이 어떤 젠더라고 느끼는가
→ 젠더 표현: 외모·행동으로 드러나는 젠더

인터섹스(Intersex):
→ 성별 특성이 전형적 남/녀 구분에 맞지 않는 경우
→ 세계 인구의 약 1.7% 추정

트랜스젠더:
→ 생물학적 성과 젠더 정체성이 불일치
```

## 성별 불평등의 원인

```
생물학적 결정론:
→ 성별 차이가 선천적 생물학적 요인에서 비롯
→ 현대 사회학·페미니즘의 비판 대상
→ 비판: 성별 역할은 문화마다 다름 → 사회화의 산물

사회화 이론:
→ 가정, 학교, 미디어가 성 역할 내면화
→ 남아: 강인함·경쟁 강조 / 여아: 돌봄·순종 강조
→ 성별 스테레오타입의 재생산

가부장제 (Patriarchy):
→ 남성이 권력·자원을 지배하는 사회 구조
→ 공사 영역 분리: 남성=공적, 여성=사적
→ 번지 (Walby): 가부장제의 6가지 구조
  (유급 노동, 가사, 문화, 섹슈얼리티, 폭력, 국가)

교차성 (Intersectionality, 크렌쇼):
→ 성별+인종+계급+장애 등 복합적 억압
→ 흑인 여성: 성차별+인종차별 동시 경험
→ 단일 범주로는 복합 차별 설명 불가

유리 천장 (Glass Ceiling):
→ 여성의 고위직 진출을 막는 보이지 않는 장벽
→ 유리 에스컬레이터: 남성이 여성 지배 직종에서 빠르게 승진
```

## 페미니즘의 흐름

```
1물결 페미니즘 (19세기~1920년대):
→ 참정권 운동 중심
→ 투표권, 재산권, 교육권 획득
→ 수전 B. 앤서니, 에멀린 팽크허스트

2물결 페미니즘 (1960~80년대):
→ 성별 역할·가부장제 근본 비판
→ "개인적인 것이 정치적이다"
→ 낙태권, 동일 임금, 성폭력 이슈
→ 자유주의 페미니즘, 급진적 페미니즘, 사회주의 페미니즘

3물결 페미니즘 (1990년대~):
→ 다양성·교차성 강조
→ 단일한 여성 경험 부정
→ 젠더 수행성 (버틀러: 젠더는 반복된 행위로 구성)

4물결 페미니즘 (2010년대~):
→ 온라인·소셜 미디어 기반
→ 미투(#MeToo) 운동
→ 디지털 페미니즘

주요 이론가:
→ 시몬 드 보부아르: "여성은 태어나는 것이 아니라 만들어진다"
→ 베티 프리단: 여성성의 신화
→ 주디스 버틀러: 젠더 트러블, 수행성
→ 벨 훅스: 교차성 페미니즘
```

## 가족사회학

```
가족의 정의:
→ 혼인·혈연·입양으로 결합된 1차 집단
→ 비판: 현대에는 동거 커플, 동성 커플 등 다양화

가족의 기능 (기능주의):
→ 성적 욕구 통제 및 규제
→ 자녀 출산·양육
→ 사회화: 문화·가치 전달
→ 경제적 협력
→ 정서적 지지

가족의 유형:
→ 핵가족 (Nuclear Family): 부부+자녀
→ 확대 가족 (Extended Family): 3세대 이상
→ 한부모 가족
→ 재혼 가족 (Blended Family)
→ 독신 가구: 증가 추세
→ 동성 커플 가족

한국 가족 변화:
→ 핵가족화, 가구 수 증가
→ 초저출산: 합계출산율 0.7 (2023년)
→ 만혼·비혼 증가
→ 독신 가구 비율 급증 (전체 가구의 30%+)

갈등론 관점:
→ 가족 내 권력 관계, 가사 노동의 불균형
→ 가정 폭력·아동 학대
→ 정서적 노동(Emotional Labor): 여성에 집중
```

## 사회화 (Socialization)

```
사회화의 정의:
→ 사회 구성원으로서 살아가는 데 필요한
  규범·가치·기술·지식을 습득하는 과정

1차 사회화:
→ 유아기·아동기, 주로 가족
→ 언어, 기본 가치, 자아 형성

2차 사회화:
→ 성인기까지, 학교·또래·미디어·직장
→ 더 넓은 사회 규범·역할

재사회화:
→ 기존 사회화 대체 (군대, 교도소, 종교 회심)

사회화 이론:

미드(Mead)의 자아 발달:
→ 'I' (충동적 자아): 본능적 반응
→ 'Me' (사회적 자아): 타인의 기대 내면화
→ 일반화된 타자: 사회 전체 규범·기대

쿨리의 거울 자아 (Looking-Glass Self):
→ 타인이 나를 어떻게 보는지 상상
→ 그 인식이 자아 개념 형성에 영향

사회화 기관:
→ 가족: 1차적, 가장 강력
→ 학교: 공식 교육 + 잠재적 교육과정
→ 또래 집단: 청소년기 강력한 영향
→ 미디어: 현대사회 점점 강화
→ 종교, 직장
```

## 자주 묻는 질문

**Q. 페미니즘은 남성에 반대하는 이념인가요?**
A. 아닙니다. 페미니즘은 성별에 따른 불평등을 없애고 모든 성별이 동등한 권리와 기회를 갖는 사회를 지향합니다. 남성도 성별 고정관념(강인해야 한다, 감정 표현 금지 등)의 피해자입니다. 벨 훅스는 "페미니즘은 성차별주의와 성차별에 근거한 착취와 억압을 끝내기 위한 운동"이라고 정의합니다.

**Q. 한국의 초저출산 문제는 사회학적으로 어떻게 분석하나요?**
A. 출산율 하락은 여성의 교육·취업 기회 확대와 가사·육아 부담의 불평등한 분배 사이의 모순에서 옵니다. 출산과 경력의 양자택일을 강요받는 구조, 높은 주거비·교육비, 불안정한 고용이 복합적으로 작용합니다. 해법으로는 젠더 평등한 가사 분담, 공보육 확충, 주거·교육 비용 감소가 필요합니다.
