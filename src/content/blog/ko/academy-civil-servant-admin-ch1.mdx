## 9급 공무원 행정직 시험 개요

```
시험 시행: 인사혁신처 주관 (국가직), 각 시·도 (지방직)
응시 자격: 만 18세 이상, 결격 사유 없는 자

시험 과목 (5과목):
→ 필수: 국어, 영어, 한국사
→ 선택: 행정학개론, 행정법총론 (행정직 기준)

출제 경향:
→ 객관식 4지선다, 과목당 20문항
→ 행정학개론: 이론 40% + 제도·정책 60%
→ 행정법: 법 조문·판례 중심

합격 전략:
→ 한국사: 한국사능력검정시험 3급 이상 대체 가능
→ 영어: TOEIC 등 공인어학성적 대체
→ 행정학·행정법: 최신 판례·법령 변화 주목
→ 최근 경쟁률: 국가직 행정직 30~50:1
```

## 행정(Administration)의 이해

```
행정의 정의:
→ 공익을 실현하기 위한 정부의 조직적·합리적 활동
→ 입법·사법과 구별되는 집행적 국가 작용

행정의 특성:
→ 공공성: 사익 아닌 공익 추구
→ 강제성: 공권력 행사 가능
→ 합법성: 법령에 근거한 활동
→ 지속성: 일관된 정책 집행

행정의 기능:
1. 정책 결정: 공공 문제 해결 방향 결정
2. 정책 집행: 결정된 정책 실행
3. 정책 평가: 효과 측정, 피드백
4. 규제: 사회 질서 유지

행정 vs 경영:
→ 공통점: 목표 달성, 조직 관리
→ 차이점:
  - 행정: 공익, 독점성, 정치적 영향
  - 경영: 이윤, 경쟁, 시장 원리
```

## 행정학 이론의 발달

```
과학적 관리론 (Taylor, 1900s):
→ 시간·동작 연구로 최적 작업 방법 도출
→ 능률 극대화, 기계적 인간관
→ 행정에 적용: 능률주의, 과업 분석

인간관계론 (Mayo, Hawthorne 실험, 1930s):
→ 비공식 집단, 사회적 요인이 생산성에 영향
→ 인간적 욕구·감정 중시
→ 민주적 리더십, 집단 역동성

행태주의 (Behavioral):
→ 관찰 가능한 행동만 연구
→ 사이먼 (Simon): 제한된 합리성 (bounded rationality)
→ 행정인은 "만족스러운" 결정을 함

체제론 (Systems Theory):
→ 행정을 환경과 상호작용하는 열린 체제로 봄
→ 투입 → 전환 → 산출 → 피드백

신공공관리론 (New Public Management, 1980s~):
→ 시장 원리 도입: 성과급, 경쟁, 민영화
→ 대처리즘(영국), 레이거노믹스(미국)
→ 작은 정부, 민간 위탁
→ 비판: 공공성 훼손 우려
```

## 관료제 (Bureaucracy)

```
베버(Weber)의 근대 관료제:
→ 합법적-합리적 지배의 산물
→ 관료제의 특징:
  1. 법·규정에 의한 지배
  2. 직무의 전문화·분업
  3. 계층제 (위계 질서)
  4. 문서주의 (공식 기록)
  5. 비개인성 (개인 아닌 직위 중심)
  6. 기술 자격에 의한 임용

관료제의 장단점:
→ 장점: 예측 가능성, 일관성, 전문성
→ 단점: 형식주의(Red Tape), 경직성, 무사안일
→ 목표 대치: 수단이 목표로 전환

대표 관료제:
→ 사회 구성과 인종·성별·지역 비율을 
  관료 구성에 반영
→ 목적: 다양한 집단 이익 대변
→ 한국: 균형 인사 정책, 여성 채용 목표제

엽관제 vs 실적제:
→ 엽관제(Spoils System): 정치적 충성에 따른 임용 → 부패 위험
→ 실적제(Merit System): 시험·능력에 따른 임용 → 전문성
→ 한국: 실적제 기반 (공무원 임용시험)
```

## 행정 조직론

```
조직 구조의 유형:

계층제 (Hierarchy):
→ 수직적 명령·복종 관계
→ 책임·권한의 명확성
→ 기계적 관료제에서 강함

부서화 (Departmentalization):
→ 기능별: 재무부, 인사부 등
→ 지역별: 서울청, 부산청
→ 고객별: 노인복지과, 아동과
→ 사업별(매트릭스): 기능부와 프로젝트팀 교차

조직 설계 원칙:
→ 계층의 수 최소화 (Flat Organization)
→ 통솔 범위 (Span of Control): 한 관리자가 관할하는 부하 수
→ 분권화 vs 집권화

공식 조직 vs 비공식 조직:
→ 공식 조직: 규정된 구조, 공식 권한
→ 비공식 조직: 자연발생적 인간관계
→ 비공식 조직이 조직 성과에 영향
```

## 정부 예산

```
예산의 정의:
→ 1회계연도의 세입·세출 예정 계획
→ 국회 의결로 효력 발생

예산의 원칙:
→ 공개의 원칙
→ 명확성의 원칙
→ 사전의결의 원칙
→ 한계성의 원칙 (목적·금액·기간)
→ 완전성의 원칙

예산 제도:
→ 품목별 예산 (Line-item): 지출 품목 중심, 통제에 강점
→ 성과주의 예산 (PB): 성과 측정 중심
→ 계획 예산 (PPBS): 장기 계획 연계
→ 영기준 예산 (ZBB): 매년 제로에서 재검토
→ 프로그램 예산 (현행): 목적·사업 중심

재정 민주주의:
→ 국회의 예산 심의·의결권
→ 국민의 납세에 기반, 국민을 위한 지출
```

## 자주 묻는 질문

**Q. 9급 행정직 시험에서 행정학 점수를 올리려면 어떻게 해야 하나요?**
A. 행정학개론은 암기량이 많아 보이지만 개념의 맥락을 이해하면 효율적입니다. 핵심 이론(과학적 관리론, 인간관계론, 체제론, 신공공관리론)의 흐름을 시대순으로 이해하고, 최신 행정 제도·법령 변화(정부 조직 개편, 예산 제도 등)를 꾸준히 체크해야 합니다.

**Q. 엽관제와 실적제는 왜 공존하나요?**
A. 실적제가 원칙이지만 정무직(장·차관, 청장)은 대통령이 임명하는 정치적 임명이 필요합니다. 선출된 권력이 국정 방향을 책임지려면 정치적 신뢰를 받는 인사를 고위직에 두어야 하기 때문입니다. 따라서 고위직(엽관적 요소)과 하위직(실적 중심)의 이원 구조가 형성됩니다.
