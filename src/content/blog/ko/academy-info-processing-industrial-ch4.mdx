## 데이터베이스는 구조와 질의가 함께 나옵니다

데이터베이스 구축 단원은 데이터를 어떻게 모델링하고, SQL로 어떻게 다루며, 무결성을 어떻게 지키는지 묻습니다. ERD, 키, 정규화, 트랜잭션, 인덱스가 서로 떨어진 개념처럼 보이지만 실제로는 저장 구조의 품질을 높이는 장치입니다. 시험 범위는 [Q-net](https://www.q-net.or.kr)과 시행처 공식 홈페이지 공고로 확인하세요. 확인일: 2026-06.

### DB 핵심 개념

| 주제 | 학습 포인트 |
|---|---|
| 모델링 | 엔터티, 속성, 관계 |
| 키 | 기본키, 외래키, 후보키 |
| 정규화 | 중복 제거와 이상 현상 방지 |
| SQL | SELECT, JOIN, DML, DDL |
| 트랜잭션 | 원자성, 일관성, 고립성, 지속성 |

SQL은 손으로 써보는 연습이 필요합니다. 특히 JOIN 조건과 WHERE 조건의 차이를 놓치면 결과가 달라집니다. 정규화는 “몇 정규형인가”보다 중복과 삽입·삭제·갱신 이상을 줄이는 목적을 먼저 이해하세요.

## 핵심 요약

- 데이터베이스는 모델링, SQL, 무결성을 함께 공부해야 합니다.
- 정규화는 중복과 이상 현상을 줄이기 위한 설계 절차입니다.
- 출제 범위와 기준은 공식 공고에서 확인합니다.
