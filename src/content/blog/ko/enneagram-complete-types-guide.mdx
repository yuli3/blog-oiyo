에니어그램(Enneagram)은 **9가지 기본 성격 유형**으로 인간을 이해하는 심리 시스템입니다. 그리스어로 9를 뜻하는 "ennea"와 도형을 뜻하는 "gramma"의 합성어로, 수천 년의 지혜와 현대 심리학이 결합된 강력한 자기 이해 도구입니다.

<Callout type="info">
**에니어그램의 핵심**: MBTI가 "어떻게 행동하는가"를 보여준다면, 에니어그램은 "왜 그렇게 행동하는가"—즉 내면의 동기와 두려움을 보여줍니다.
</Callout>

## 에니어그램 9가지 유형 개요

| 유형 | 이름 | 핵심 동기 | 핵심 두려움 | 센터 |
|------|------|----------|------------|------|
| **1번** | 개혁가 | 옳음, 완벽 | 나쁜 사람이 됨 | 장(본능) |
| **2번** | 조력자 | 사랑받음 | 필요 없는 존재 | 가슴(감정) |
| **3번** | 성취자 | 성공, 인정 | 실패, 무가치 | 가슴(감정) |
| **4번** | 개인주의자 | 정체성, 깊이 | 정체성 없음 | 가슴(감정) |
| **5번** | 탐구자 | 지식, 자립 | 무능, 압도 | 머리(사고) |
| **6번** | 충성가 | 안전, 지지 | 고립, 위험 | 머리(사고) |
| **7번** | 열정가 | 만족, 경험 | 고통, 박탈 | 머리(사고) |
| **8번** | 도전자 | 통제, 보호 | 취약, 통제당함 | 장(본능) |
| **9번** | 평화주의자 | 평화, 조화 | 분리, 갈등 | 장(본능) |

## 3가지 센터 (Intelligence Centers)

에니어그램의 9유형은 **3개의 센터**로 나뉩니다. 같은 센터의 유형들은 비슷한 핵심 감정을 공유합니다.

### 장(본능) 센터 — 1, 8, 9번
**핵심 감정**: 분노(Anger)

| 유형 | 분노와의 관계 |
|------|-------------|
| 1번 | 분노를 억압하고 도덕적 분개로 표현 |
| 8번 | 분노를 즉각적으로 표현하고 행동 |
| 9번 | 분노를 부정하고 무기력으로 표현 |

### 가슴(감정) 센터 — 2, 3, 4번
**핵심 감정**: 수치심(Shame)

| 유형 | 수치심과의 관계 |
|------|--------------|
| 2번 | 도움으로 수치심 회피 ("나는 좋은 사람이다") |
| 3번 | 성공으로 수치심 회피 ("나는 가치 있다") |
| 4번 | 수치심을 내면화하고 탐구 ("나는 결핍되어 있다") |

### 머리(사고) 센터 — 5, 6, 7번
**핵심 감정**: 두려움(Fear)

| 유형 | 두려움과의 관계 |
|------|--------------|
| 5번 | 지식으로 두려움 관리 |
| 6번 | 안전 시스템으로 두려움 관리 |
| 7번 | 즐거움으로 두려움 회피 |

## 유형별 간단 특징 비교

### 업무 스타일

| 유형 | 업무 스타일 | 최고 환경 |
|------|----------|---------|
| 1번 | 원칙적, 체계적 | 명확한 기준이 있는 곳 |
| 2번 | 협력적, 지원적 | 팀과 함께하는 환경 |
| 3번 | 목표지향, 효율적 | 성과가 인정받는 곳 |
| 4번 | 창의적, 독창적 | 개성이 존중되는 환경 |
| 5번 | 분석적, 독립적 | 집중할 수 있는 공간 |
| 6번 | 충실, 신중 | 명확한 역할과 신뢰 시스템 |
| 7번 | 자발적, 다재다능 | 다양하고 자유로운 환경 |
| 8번 | 직접적, 주도적 | 리더십을 발휘할 수 있는 곳 |
| 9번 | 조화롭고 유연 | 평화로운 팀 환경 |

### 스트레스 반응

| 유형 | 스트레스 시 방향 | 증상 |
|------|--------------|------|
| 1번 | → 4번 | 우울, 감정적 불안정 |
| 2번 | → 8번 | 공격적, 통제적 |
| 3번 | → 9번 | 무기력, 회피 |
| 4번 | → 2번 | 집착적 도움 요청 |
| 5번 | → 7번 | 산만, 과잉 자극 추구 |
| 6번 | → 3번 | 경쟁적, 이미지 집착 |
| 7번 | → 1번 | 완벽주의적, 비판적 |
| 8번 | → 5번 | 고립, 분석마비 |
| 9번 | → 6번 | 불안, 외부 의존 |

## 유형별 연애 궁합

에니어그램 연애 궁합에서 중요한 것은 **같은 센터 내의 이해**와 **다른 센터 간의 보완**입니다.

### 상호 보완 궁합 (다른 센터 간)

| 조합 | 이유 |
|------|------|
| 1번 + 7번 | 원칙 + 자발성의 균형 |
| 2번 + 8번 | 돌봄 + 보호의 완벽한 조합 |
| 3번 + 9번 | 성취 + 평화의 조화 |
| 4번 + 5번 | 감성 + 지성의 깊은 연결 |
| 6번 + 9번 | 안전 + 평화의 안정적 관계 |

### 주의가 필요한 궁합

| 조합 | 이유 |
|------|------|
| 1번 + 4번 | 비판 + 감수성 충돌 |
| 3번 + 4번 | 이미지 + 진정성 충돌 |
| 7번 + 6번 | 자유 + 안전 욕구 충돌 |

<Callout type="warning">
**에니어그램 궁합의 한계**: 어떤 유형 조합도 좋은 관계가 될 수 있고 나쁜 관계가 될 수 있습니다. 유형 자체보다 각 개인의 건강 수준이 더 중요합니다.
</Callout>

## 나의 유형 찾기

### 가장 빠른 방법: 핵심 두려움으로 찾기

자신에게 가장 깊이 공명하는 두려움을 고르세요:

- "나쁜 사람이 되는 것이 두렵다" → **1번**
- "사랑받지 못하는 것이 두렵다" → **2번**
- "실패하고 가치 없는 것이 두렵다" → **3번**
- "정체성이 없는 것이 두렵다" → **4번**
- "무능하고 압도당하는 것이 두렵다" → **5번**
- "지지받지 못하고 혼자인 것이 두렵다" → **6번**
- "박탈당하고 고통스럽게 되는 것이 두렵다" → **7번**
- "통제당하고 취약해지는 것이 두렵다" → **8번**
- "분리되고 갈등이 생기는 것이 두렵다" → **9번**

<Callout type="tip">
**정확한 타입 찾기**: 두려움보다 핵심 동기와 어린 시절의 상처를 함께 살펴보면 더 정확합니다. 공식 에니어그램 인스티튜트 검사(RHETI)나 저희 무료 테스트를 이용하세요.
</Callout>
