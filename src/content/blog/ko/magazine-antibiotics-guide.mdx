## 항생제, 잘못 먹으면 오히려 해가 된다

항생제는 세균 감염에 효과적이지만, 잘못 사용하면 **항생제 내성균**을 만들거나 심각한 부작용을 일으킬 수 있습니다. 올바른 사용법을 꼭 알아야 합니다.

---

## 항생제 기본 원리

### 항생제란?

```
세균(박테리아)을 죽이거나 성장을 억제하는 약물
→ 바이러스에는 효과 없음

바이러스 질환 예시 (항생제 불필요):
- 감기 (대부분 바이러스)
- 독감 (인플루엔자 바이러스)
- COVID-19
- 단순 위장염 (대부분 바이러스)
```

### 항생제가 필요한 세균 감염

```
항생제 필요한 상황:
- 세균성 폐렴
- 요로감염 (방광염·신우신염)
- 세균성 편도염·중이염
- 피부 연조직염
- 결핵
- 성병 (임질·매독)
→ 반드시 의사 처방 후 복용
```

## 주요 항생제 종류

| 계열 | 대표 약품 | 주요 적응증 |
|------|---------|-----------|
| **페니실린계** | 아목시실린 | 편도염, 중이염, 요로감염 |
| **세팔로스포린계** | 세파클러, 세파드록실 | 피부감염, 요로감염 |
| **마크롤라이드계** | 아지트로마이신(지스로맥스) | 폐렴, 성병, 피부감염 |
| **플루오로퀴놀론계** | 시프로플록사신 | 심한 요로감염, 폐렴 |
| **테트라사이클린계** | 독시사이클린 | 여드름, 말라리아 예방, 성병 |
| **메트로니다졸** | 플라질 | 혐기성 균, 질 감염 |

## 항생제 올바른 복용법

### 규칙 1: 처방된 기간 끝까지 복용

```
항생제는 증상이 나아도 처방 기간 완료까지 복용
이유:
- 증상 호전 ≠ 균 완전 제거
- 일찍 중단 → 살아남은 세균 증식 → 재발 + 내성 발생

예시:
편도염 처방: 7일치
3일 후 증상 개선 → 중단하고 싶은 충동
→ 절대 안 됨 → 7일 완료 필수
```

### 규칙 2: 정해진 시간 간격 유지

```
1일 2회 처방: 12시간 간격
1일 3회 처방: 8시간 간격

→ 혈중 약물 농도 일정하게 유지
→ 약효가 끊기면 세균 재성장 가능
```

### 규칙 3: 음식과의 상호작용

```
빈속에 먹어야 하는 항생제: 암피실린, 일부 플루오로퀴놀론
음식과 함께 먹어야 하는 항생제: 아목시실린, 세파드록실

주의 음식:
- 유제품: 테트라사이클린·플루오로퀴놀론과 동시 복용 금지 (흡수 방해)
- 알코올: 메트로니다졸과 절대 금지 (심한 두통, 구토 유발)
- 자몽 주스: 일부 항생제 혈중 농도 이상 변화
```

## 항생제 부작용 종류와 대처

### 흔한 부작용

```
1. 위장 장애 (가장 흔함):
   증상: 구역, 구토, 설사, 복통
   대처: 식사와 함께 복용, 프로바이오틱스 병용

2. 항생제 관련 설사 (AAD):
   원인: 장내 정상 세균총 파괴
   대처: 유산균 보충제 복용 (항생제 복용 2시간 후)

3. 여성 질염·구강 칸디다:
   원인: 항생제로 정상 세균 감소 → 곰팡이(칸디다) 증식
   대처: 의사에게 항진균제 추가 처방 요청
```

### 심각한 알레르기 반응 (즉시 의료기관 방문)

```
위험 신호:
- 전신 두드러기 + 호흡 곤란 → 아나필락시스 (응급)
- 전신에 퍼지는 발진
- 입·눈 주위 붓기
- 발열 + 발진 동반

응급 대처:
→ 119 호출 또는 응급실 즉시 방문
→ 복용 중단
→ 처방 받은 항생제 포장지 지참
```

## 항생제 내성: 왜 심각한가

### 내성 발생 원리

```
항생제 사용
→ 세균 중 약에 견디는 변이체 생존
→ 내성 세균 증식
→ 같은 항생제 효과 없음
→ 더 강한 항생제 필요 → 반복 → 슈퍼박테리아 탄생
```

### 내성 예방 행동 수칙

```
해야 할 것:
- 처방대로 완료 복용
- 의사 지시 없이 임의 복용 금지
- 남은 항생제 다음에 사용하지 않기

하지 말아야 할 것:
- 친구·가족의 항생제 빌려 복용
- 감기에 항생제 요구
- 항생제 인터넷 구매 (처방전 없이)
```

## 어린이 항생제 주의사항

```
체중 기준 용량 중요:
→ 임의로 성인 약 반 알 자르는 것 금지
→ 반드시 어린이용 액상 제제 사용 or 소아과 처방

항생제 복용 후 발진:
→ 즉시 의사에게 연락 (알레르기 vs 약진 구분 필요)

불필요한 항생제 요구 금지:
→ 감기에 "혹시 몰라서" 항생제 처방 요구 → 오히려 해
```

## 임산부 항생제 사용

```
임신 중 사용 가능한 항생제 (Category B):
- 아목시실린
- 세팔로스포린 대부분
- 에리트로마이신 (일부)

임신 중 금지 항생제:
- 테트라사이클린: 태아 뼈·치아 발달 영향
- 플루오로퀴놀론: 태아 관절 발달 영향
- 메트로니다졸: 임신 초기 금기 (2기·3기는 의사 판단)

→ 항상 의사에게 임신 사실 고지 후 처방
```

## 자주 묻는 질문

**Q. 감기에 항생제를 처방해 달라고 해도 되나요?**
A. 일반 감기는 바이러스성이라 항생제가 효과 없습니다. 오히려 내성균 위험과 부작용을 초래합니다. 의사의 판단을 따르세요.

**Q. 항생제 복용 중 술을 마시면 어떻게 되나요?**
A. 메트로니다졸은 알코올과 반응해 심한 두통·구토를 유발합니다. 다른 항생제도 음주는 면역력·회복력을 떨어뜨려 피하는 게 원칙입니다.

**Q. 남은 항생제를 다음에 써도 되나요?**
A. 안 됩니다. 항생제 처방은 감염의 종류·균의 종류에 따라 다릅니다. 과거 처방된 항생제가 다른 감염에 맞지 않을 수 있고, 내성 발생 위험도 큽니다.
