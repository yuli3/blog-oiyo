## 시험 과목 구성

```
1차 시험 (객관식):
재정학
세법학개론
회계학개론
상법 (or 민법)
영어

2차 시험 (주관식):
세법학 1부 (국세기본법·법인세·소득세)
세법학 2부 (부가세·상속증여세·지방세)
회계학 1부 (재무회계)
회계학 2부 (원가관리회계)
세무회계

합격 기준:
1차: 각 40점 이상·평균 60점
2차: 각 40점 이상·평균 60점
```

```

증여세 신고: 증여일 말로부터 3개월
이월결손금: 10년 (중소=100%, 일반=60%)
조세 소멸시효: 5년 (부정=10년)
```

## 빈출 오답 10선

```
① 법인세율=9·19·21·24% (구간 암기)
② 금융소득 종합과세=2천만원 초과
③ 퇴직·양도소득=분류과세 (합산X)
④ 부가세 영세율=환급O, 면세=환급X
⑤ 접대비 한도=기본3600만+수입금액비율
⑥ 상속 일괄공제=5억
⑦ 증여 성년=5천만, 미성년=2천만 (10년)
⑧ 사전증여=10년 내 합산 (초과=합산X)
⑨ 조세불복=전치주의 (심판→소송)
⑩ 세액공제>소득공제 절세 효과
```

## 실전 퀴즈 (종합)

**Q. 세무사와 공인회계사의 업무 영역 차이는?**
> 세무사: 세무 신고·조사 대리·불복 청구 독점. 세무 전문가. 공인회계사: 재무제표 감사 독점. 세무도 가능 (세무사 등록 시). 세무사가 재무제표 감사 불가. CPA가 세무사 등록 후 세무업무 가능. 두 자격 상호 보완적. 대형 법인은 CPA+세무사 혼재.

**Q. 법인세와 소득세의 연결 고리는?**
> 법인: 법인세 납부 후 배당 시 주주에게 배당소득세. 이중과세 조정: 배당세액공제 (Gross-up). 개인사업자: 법인 없이 소득세만. 법인 전환: 절세 목적으로 소득세→법인세. 세율 비교: 소득세 최고45% vs 법인세 최고24%. 고소득 자영업자는 법인화가 유리.
