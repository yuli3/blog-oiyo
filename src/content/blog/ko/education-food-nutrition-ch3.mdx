## 에너지 단위와 식품 에너지

```
에너지 단위:
→ kcal (킬로칼로리): 물 1kg을 1°C 올리는 열량
→ kJ (킬로줄): 1 kcal = 4.184 kJ
→ 식품 표시: kcal 사용 (한국·미국), kJ (유럽·호주)

에너지 영양소 열량:
→ 탄수화물: 4 kcal/g
→ 단백질: 4 kcal/g
→ 지방: 9 kcal/g
→ 알코올: 7 kcal/g (영양소 아님)
→ 수분: 0 kcal/g

식품 에너지 측정:
→ 봄브 열량계: 완전 연소 열량 측정
→ 아트워터 계수(Atwater Factor): 소화율 반영
  탄수화물 97%, 단백질 92%, 지방 95%

에너지 밀도 (Energy Density):
→ 단위 중량당 에너지 (kcal/g)
→ 고에너지 밀도: 지방 많은 식품 (버터 7~9 kcal/g)
→ 저에너지 밀도: 수분 많은 채소·과일 (0.1~0.5 kcal/g)
→ 저에너지 밀도 식품 → 포만감·체중 관리 유리

식품군별 1회 제공량 에너지:
→ 곡류: 약 300 kcal
→ 고기·생선·달걀·콩류: 약 100~150 kcal
→ 채소류: 약 15~30 kcal
→ 과일류: 약 50 kcal
→ 유지·당류: 약 45 kcal
→ 유제품: 약 125 kcal
```

## 에너지 소비량 구성

```
총 에너지 소비량 (TEE, Total Energy Expenditure):
→ TEE = BMR + AEE + TEF

기초대사량 (BMR, Basal Metabolic Rate):
→ 생명 유지에 필요한 최소 에너지 (안정·공복·중립 온도)
→ 전체 에너지 소비의 60~75%
→ 영향 요인:
  - 체구성: 근육량 많을수록 BMR 증가
  - 성별: 남성 > 여성 (근육량 차이)
  - 연령: 나이 증가 → 근육량 감소 → BMR 감소
  - 갑상선 호르몬: 대사율 조절
  - 체표면적: 클수록 BMR 증가

안정 시 대사량 (RMR):
→ BMR보다 약간 높음 (수면·앉기 등 포함)

활동 대사량 (AEE):
→ 신체 활동으로 소비하는 에너지
→ 전체의 15~30% (운동 습관에 따라 큰 변동)
→ PAL (Physical Activity Level): TEE/BMR
  좌식 생활: PAL 1.2~1.4 / 활동적: PAL 1.6~1.9

식품 열효과 (TEF, Thermic Effect of Food):
→ 소화·흡수·대사에 사용하는 에너지
→ 전체의 5~10%
→ 단백질 TEF 가장 높음 (20~30%)
  지방 TEF 가장 낮음 (0~3%)

BMR 예측 공식:

해리스-베네딕트 (Harris-Benedict):
→ 남성: 88.4 + 13.4×체중(kg) + 4.8×키(cm) - 5.68×나이
→ 여성: 447.6 + 9.25×체중(kg) + 3.10×키(cm) - 4.33×나이

간편 추정:
→ 성인 남성: 약 1.0 kcal/kg/시간 × 체중
→ 성인 여성: 약 0.9 kcal/kg/시간 × 체중
```

## 체중 관리 원리

```
에너지 균형 방정식:
→ 체중 변화 = 에너지 섭취 - 에너지 소비
→ 에너지 잉여 → 체중 증가 (지방 저장)
→ 에너지 부족 → 체중 감소 (지방 분해)
→ 1kg 체지방 ≈ 7,700 kcal

체지방 측정:
→ BMI (Body Mass Index): 체중(kg) / 키(m)²
  저체중: <18.5 / 정상: 18.5~24.9 / 과체중: 25~29.9 / 비만: ≥30
  (한국: 과체중 23~24.9, 비만 25 이상으로 낮게 적용)
→ 허리 둘레: 복부 지방 지표
  남성 ≥90cm, 여성 ≥80cm → 복부 비만 (한국 기준)
→ 체지방률: 생체전기저항(BIA) · DEXA · 수중 체중법

비만의 원인:
→ 에너지 과잉 + 신체 활동 부족
→ 유전적 소인 (FTO 유전자, 렙틴 신호)
→ 장내 미생물: 비만과 연관성
→ 수면 부족: 식욕 조절 호르몬 불균형
→ 스트레스: 코티솔 상승 → 지방 축적

체중 감량 원칙:
→ 하루 500 kcal 결손 → 주당 0.5 kg 감량 목표
→ 급격한 감량 금지: 근육 손실·기초대사량 저하
→ 유산소+저항 운동 병행: 체지방 감소 + 근육 유지
→ 단백질 충분 섭취: 근육 보호 (1.2~1.6 g/kg/일)
→ 지속 가능성: 극단적 식이 제한보다 장기 생활 습관 변화

요요 현상:
→ 급격한 감량 후 체중 회복
→ 원인: 적응성 열생성 감소 (BMR 저하), 식이 제한 포기
→ 예방: 점진적 감량, 운동 병행, 유지기 전략
```

## 영양 상태 평가

```
영양 평가 방법 (ABCDE):

A - 인체계측 (Anthropometric):
→ 키, 체중, BMI, 허리 둘레
→ 상완 근육 둘레, 삼두근 피부 두겹
→ 성장 곡선 (소아)

B - 생화학적 검사 (Biochemical):
→ 혈청 단백질: 알부민·프리알부민 (영양 상태)
→ 헤모글로빈·헤마토크릿: 철 결핍 빈혈
→ 혈청 비타민 D·B12·엽산
→ 지질 검사: 총 콜레스테롤·LDL·HDL·중성지방
→ 혈당·HbA1c: 당뇨 평가

C - 임상 증상 (Clinical):
→ 결핍 증상 관찰 (구각염·탈모·부종 등)
→ 의료 기록·병력

D - 식이 섭취 조사 (Dietary):
→ 24시간 회상법: 전날 섭취 내용 회상
→ 식품 섭취 빈도 조사 (FFQ): 반정량적
→ 식품 기록법: 수일간 직접 기록 (가장 정확)
→ 영양 조사: 국민건강영양조사 (KNHANES)

E - 환경 및 기타 (Environmental):
→ 사회·경제적 여건
→ 교육·문화·식품 접근성

한국인 영양 섭취 기준 (KDRIs):
→ 평균 필요량 (EAR): 50% 충족 수준
→ 권장 섭취량 (RNI): 97.5% 충족 (EAR × 1.2)
→ 충분 섭취량 (AI): 충분한 근거 없을 때
→ 상한 섭취량 (UL): 건강 위해 없는 최대 섭취량
→ 에너지 적정 비율 (AMDR):
  탄수화물: 55~65% / 단백질: 7~20% / 지방: 15~30%
```

## 식단 계획

```
균형 식단의 원칙:
→ 다양성: 여러 식품군 섭취
→ 충분성: 필수 영양소 충족
→ 적절성: 권장량에 맞는 섭취
→ 적정 칼로리: 에너지 균형 유지
→ 절제: 포화지방·나트륨·당 제한

식품구성 자전거 (한국):
→ 곡류: 6~12단위 (에너지의 50~65%)
→ 고기·생선·달걀·콩류: 3~4단위 (단백질)
→ 채소류: 7~8단위 (비타민·무기질·식이섬유)
→ 과일류: 2~3단위 (비타민·항산화)
→ 우유·유제품: 2단위 (칼슘)
→ 유지·당류: 4~5단위 (소량)

나트륨 줄이기 (WHO 목표 2,000 mg/일):
→ 한국 평균: 약 3,200 mg/일 (과다)
→ 국물류·젓갈·가공식품 주의
→ 신선 식품 중심, 저나트륨 제품 선택

식이섬유:
→ 권장량: 하루 25~30 g
→ 수용성: 귀리·보리·콩·과일 → 혈당·콜레스테롤 완화
→ 불용성: 통곡물·채소·밀기울 → 배변 촉진

지중해식 식단 (건강 식단 근거):
→ 채소·과일·통곡물·올리브 오일·콩류 중심
→ 어류: 주 2회 이상
→ 적색 고기·가공육 최소화
→ 심혈관 질환·당뇨·인지 기능 저하 예방 근거
```

## 자주 묻는 질문

**Q. 기초대사량을 높이려면 어떻게 해야 하나요?**
A. 기초대사량(BMR)을 높이는 가장 효과적인 방법은 근육량을 늘리는 것입니다. 근육은 지방보다 안정 시에도 더 많은 에너지를 소비합니다(근육 1kg = 약 13 kcal/일). 저항 운동(근력 운동)을 통해 근육량을 유지·증가시키고, 단백질을 충분히 섭취해 근육 합성을 지원합니다. 또한 급격한 식이 제한을 피하는 것이 중요한데, 칼로리 섭취를 갑자기 크게 줄이면 신체가 에너지 절약 모드로 들어가 BMR이 감소합니다.

**Q. BMI가 정상이어도 건강에 문제가 있을 수 있나요?**
A. 네, BMI는 체구성(근육 vs 지방 비율)을 구분하지 못합니다. 근육이 많은 운동선수는 BMI가 높아도 건강하고, 반대로 BMI가 정상 범위지만 체지방률이 높고 근육이 적은 '정상 체중 비만(Normal Weight Obesity)'은 대사 위험이 있습니다. 특히 한국인을 포함한 아시아인은 같은 BMI에서 서양인보다 체지방률이 높고 복부 지방이 많은 경향이 있어, 허리 둘레나 체지방률을 함께 평가하는 것이 중요합니다.
