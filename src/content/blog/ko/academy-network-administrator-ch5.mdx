## 장비는 계층으로 구분합니다

네트워크 장비를 외울 때는 이름보다 어느 계층에서 어떤 정보를 보고 판단하는지를 먼저 보세요. 허브는 단순 전달, 스위치는 MAC 주소 기반 전달, 라우터는 IP 주소와 경로 기반 전달, 방화벽은 정책에 따른 허용·차단을 담당한다고 정리하면 됩니다.

### 장비별 역할

| 장비 | 핵심 역할 |
|---|---|
| 허브 | 들어온 신호를 여러 포트로 전달 |
| 스위치 | MAC 주소를 학습해 프레임 전달 |
| 라우터 | 서로 다른 네트워크 간 패킷 전달 |
| 방화벽 | 보안 정책에 따라 트래픽 제어 |
| 무선 AP | 무선 단말을 유선 네트워크와 연결 |

시험에서는 장비 역할뿐 아니라 장애 상황도 함께 묻습니다. 같은 네트워크 안에서 통신이 안 되면 케이블, 포트, VLAN, MAC 학습을 볼 수 있고, 다른 네트워크로 나가지 못하면 게이트웨이와 라우팅을 의심할 수 있습니다.

장비를 고를 때는 속도보다 어느 주소 정보를 보고 판단하는 장비인지 먼저 구분하는 습관이 필요합니다.

## 설정의 의미 이해하기

실기에서 명령어를 다룰 때도 결국 장비 역할을 설정하는 것입니다. IP 주소를 넣는 이유, 기본 게이트웨이를 지정하는 이유, 인터페이스를 켜는 이유를 말로 설명할 수 있어야 합니다. 시험 범위와 장비 환경은 시행처 공식 홈페이지 및 해당 시 Q-net(https://www.q-net.or.kr)을 확인하세요. 확인일: 2026-06.

## 핵심 요약

네트워크 운용기기는 허브, 스위치, 라우터, 방화벽, 무선 AP의 역할 차이를 계층과 주소 기준으로 구분하면 됩니다. 다음 장에서는 네트워크 보안 기초를 다룹니다.
