## 1. 운전 자본의 의의

**운전 자본(Working Capital)**: 단기 영업 활동에 필요한 자금.

```
순운전자본(Net Working Capital) = 유동자산 - 유동부채

유동자산: 현금, 단기투자자산, 매출채권, 재고자산
유동부채: 매입채무, 단기차입금, 미지급 비용
```

**운전 자본 관리 목표**: 충분한 유동성 확보 + 과잉 투자 방지.

---

## 2. 현금 전환 주기 (CCC)

**CCC(Cash Conversion Cycle)**: 현금을 투입하고 회수할 때까지 걸리는 기간.

```
CCC = 재고자산 보유 기간 + 매출채권 회수 기간 - 매입채무 지급 기간

재고자산 보유 기간 = 365 / 재고자산 회전율
                  = 평균 재고 / 매출원가 × 365

매출채권 회수 기간 (DSO) = 365 / 매출채권 회전율
                        = 평균 매출채권 / 매출액 × 365

매입채무 지급 기간 = 365 / 매입채무 회전율
                  = 평균 매입채무 / 매입액 × 365
```

**CCC가 짧을수록**: 자금 묶이는 기간 짧음 → 운전 자본 효율적 사용.

## 3. 현금 관리

### (1) 최적 현금 잔액 모형

**Baumol 모형**: 거래 비용과 기회비용 균형점.

```
최적 현금 잔액:
C* = √(2 × F × T / r)

F: 현금 전환 비용
T: 기간 중 현금 수요
r: 투자 기회비용 (이자율)

총 비용 = 거래 비용 + 기회비용
       = (T/C) × F + (C/2) × r
```

**Miller-Orr 모형**: 현금 흐름이 불규칙적일 때 상·하한선 설정.

## 4. 매출채권 관리

**① 매출채권 투자 결정**

- 비용: 자금 기회비용 + 대손 비용 + 관리 비용
- 편익: 매출 증가로 인한 이익

**② 신용 정책 완화**

- 매출 증가 → 이익 증가
- 매출채권 증가 → 기회비용 증가
- 대손 증가 → 비용 증가

**신용 분석 5C**:

```
Character: 신용 이력, 지급 의지
Capacity: 상환 능력 (현금흐름)
Capital: 자본 (재무 건전성)
Collateral: 담보
Conditions: 경기 상황
```

## 5. 재고자산 관리

**EOQ (Economic Order Quantity, 경제적 주문량)**:

```
EOQ = √(2 × D × O / H)

D: 연간 수요량
O: 1회 주문 비용
H: 단위당 보유 비용 (연간)

총 재고 비용 = 주문 비용 + 보유 비용
             = (D/Q) × O + (Q/2) × H

Q = EOQ에서 두 비용 같아짐 (총 비용 최소)
```

## 6. 단기 자금 조달

```
단기 자금 조달 수단:
① 상업어음 할인 (매출채권 담보)
② 팩토링: 매출채권 매각
③ 단기 차입금: 은행 당좌대출
④ 기업어음 (CP): 무담보 단기 사채 발행
⑤ 매입채무 활용: 외상 기간 최대 활용

자발적 자금 조달: 매입채무, 미지급 비용 (이자 없음)
협상형 자금 조달: 은행 단기대출 (이자 있음)
```

## 7. 핵심 개념 카드

**현금 전환 주기(CCC)** ★★★★★
: 재고 보유 기간 + 매출채권 회수 기간 - 매입채무 지급 기간. 짧을수록 현금 효율적.
*암기 포인트: CCC = 재고 + 매출채권 - 매입채무*

**EOQ** ★★★★★
: √(2DO/H). 주문 비용과 보유 비용이 같아지는 최적 주문량.
*암기 포인트: EOQ = √(2DO/H)*

**신용 분석 5C** ★★★★☆
: Character(의지)·Capacity(능력)·Capital(자본)·Collateral(담보)·Conditions(환경).
*암기 포인트: 5C = 의지·능력·자본·담보·환경*

## 8. 실전 퀴즈

**Q. 연간 수요 1,200개, 1회 주문 비용 5만 원, 단위당 연간 보유 비용 2,000원일 때 EOQ는?**
> EOQ = √(2 × 1,200 × 50,000 / 2,000) = √(60,000) ≈ 245개.

**Q. 재고 보유 기간 30일, 매출채권 회수 기간 45일, 매입채무 지급 기간 50일일 때 CCC는?**
> CCC = 30 + 45 - 50 = 25일.
