## 자기개발능력

**NCS 자기개발능력**은 자신의 능력·적성·특성을 이해하고, 목표 성취를 위해 지속적으로 역량을 개발하는 능력입니다.

**3가지 하위 능력**:
1. **자아인식능력**: 자신의 가치·관심·능력·특성을 이해
2. **자기관리능력**: 목표 달성을 위해 자신의 행동과 감정을 관리
3. **경력개발능력**: 중·장기 직업 목표를 설정하고 개발 계획 수립

---

## 자아인식: 나는 누구인가

### SWOT 자기분석

자기 자신을 외부 환경과 내부 특성으로 분석합니다.

- **강점(S)**: 내가 잘하는 것, 남보다 뛰어난 능력
- **약점(W)**: 개선이 필요한 영역
- **기회(O)**: 외부 환경에서 나에게 유리한 요소 (산업 성장, 학습 기회)
- **위협(T)**: 외부 환경에서 나에게 불리한 요소 (경쟁 심화, 기술 변화)

### 요하리 창 (Johari Window)

자기 인식과 타인 인식의 관계를 4사분면으로 나타냅니다.

| | 내가 아는 것 | 내가 모르는 것 |
|--|------------|-------------|
| **타인이 아는 것** | 공개 영역 (Open) | 맹점 영역 (Blind Spot) |
| **타인이 모르는 것** | 비밀 영역 (Hidden) | 미지 영역 (Unknown) |

**활용**:
- 공개 영역 넓히기: 자기 개방, 진솔한 소통
- 맹점 줄이기: 피드백 적극 수용
- 비밀 영역 줄이기: 자기 표현, 신뢰 형성

## 자기관리: 목표와 실행

### SMART 목표 설정

- **S (Specific)**: 구체적 ("체력 키우기" ✗ → "주 3회 30분 조깅" ✓)
- **M (Measurable)**: 측정 가능 ("성과 개선" ✗ → "고객 만족도 10% 향상" ✓)
- **A (Achievable)**: 달성 가능 (너무 높거나 낮지 않게)
- **R (Relevant)**: 전체 목표와 연관성
- **T (Time-bound)**: 명확한 기한

### 시간 우선순위: 아이젠하워 매트릭스

| | 중요함 | 중요하지 않음 |
|--|-------|------------|
| **긴급함** | 즉시 실행 (위기, 마감) | 위임 (일부 회의, 전화) |
| **긴급하지 않음** | 계획 실행 (성장, 관계, 개발) | 제거 (낭비, 불필요한 업무) |

핵심 통찰: 진정으로 중요한 업무(2사분면 — 중요하나 긴급하지 않음)가 항상 긴급한 일에 밀립니다. 의식적으로 이 영역에 시간을 확보해야 합니다.

### 습관 형성: 원자적 습관

**제임스 클리어(James Clear)**의 원자적 습관 원칙:

1. **명백하게**: 실행 계획을 구체적으로 (언제, 어디서, 어떻게)
2. **매력적으로**: 원하는 보상과 연결
3. **쉽게**: 마찰을 최소화 (2분 규칙: 새 습관은 2분이면 시작 가능해야)
4. **만족스럽게**: 즉각적인 보상 설계

## 경력개발: 장기 전략

### 경력 개발 4단계

| 단계 | 시기 | 특징 |
|------|------|------|
| 탐색기 | 10~20대 | 직업 세계 탐색, 자신 이해 |
| 확립기 | 20~30대 | 역할 안착, 전문성 개발 |
| 유지기 | 40~50대 | 성취 유지, 후진 양성 |
| 쇠퇴기 | 60대~ | 전환, 은퇴 준비 |

### T자형 인재

**깊이**: 특정 분야의 깊은 전문성 (세로 막대)
**너비**: 인접 영역의 기본 이해와 협업 능력 (가로 막대)

디지털 전환 시대에는 T자형보다 ∏(파이)자형 — 두 분야 이상의 깊이 + 넓은 연결 능력 — 을 갖춘 인재가 더 유리합니다.

## 자원관리능력

**NCS 자원관리능력**은 업무에 필요한 자원(시간·돈·재료·인적 자원)을 파악하고 계획·조직·활용하는 능력입니다.

**4가지 하위 능력**:
1. **시간관리능력**: 업무 우선순위 설정, 계획 수립
2. **예산관리능력**: 비용 예측, 예산 집행 관리
3. **물적자원관리능력**: 시설·장비·재료 효율적 활용
4. **인적자원관리능력**: 팀 구성, 역할 배분, 인력 활용

---

## 시간 관리 실전

### 시간 낭비 요인 진단

직장에서 흔한 시간 낭비 요인:
- 명확하지 않은 목표
- 잦은 방해와 끼어드는 업무
- 불필요한 회의
- 완벽주의 (충분한 결과보다 완벽한 결과 추구)
- 우선순위 없이 이것저것 시작하기
- 위임하지 않고 혼자 다 하기

### 포모도로 기법

25분 집중 → 5분 휴식을 반복하는 시간 관리 기법. 집중력을 유지하고 장시간 작업의 피로를 줄입니다.

4회 반복 후 15~30분 긴 휴식.

## 예산 관리 기초

**예산(Budget)**: 특정 기간 동안 예상 수입과 지출을 계획하는 재무 계획.

### 예산 관리 3단계

1. **편성**: 목표와 자원을 바탕으로 예산 계획 수립
2. **집행**: 계획에 따라 자원 배분 및 사용
3. **통제·평가**: 실제 지출과 계획의 차이 분석, 조정

**분산 분석 (Variance Analysis)**:

실제 비용 - 예산 비용 = 분산

- 양(+) 분산: 예산 초과 (원인 분석 필요)
- 음(-) 분산: 예산 미달 (효율화 또는 사업 지연)

## NCS 시험 자기개발·자원관리 문제 유형

**1. 상황 판단형**: 주어진 상황에서 가장 효율적인 자원 관리 방법 선택
→ 우선순위가 높고, 긴급도가 높은 업무부터 처리

**2. 시간 계산형**: 업무별 소요 시간, 우선순위를 고려해 최적 일정 배열
→ 중요도와 긴급도를 2×2 매트릭스로 분류 후 순서 결정

**3. 예산 배분형**: 한정된 예산으로 최대 효과를 내는 배분 방식 선택
→ 각 항목의 우선순위와 필요도를 비교
