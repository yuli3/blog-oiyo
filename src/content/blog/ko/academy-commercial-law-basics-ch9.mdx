## 보험계약의 의의

```
보험계약:
당사자 일방(보험계약자)이 보험료를 납부하고
상대방(보험자)이 보험사고 시 보험금을 지급하는 계약

당사자:
보험자: 보험회사 (보험금 지급 의무)
보험계약자: 보험료 납부자
피보험자: 보험 대상 (손해보험=피보험 이익 주체)
보험수익자: 보험금 수령자 (생명보험)

보험계약 특성:
① 유상계약: 보험료 ↔ 보험금
② 쌍무계약: 양방 의무
③ 사행계약: 불확실한 사고 조건
④ 부합계약: 보험자가 작성한 약관
⑤ 선의계약: 최대 선의 원칙
```

## 손해보험

```
손해보험:
재산상 손해를 보상하는 보험

종류:
화재보험·해상보험·자동차보험·배상책임보험 등

실손보상 원칙:
실제 손해액만 보상 (이익 취득 방지)
→ 초과보험: 보험가액 초과 보험금 지급 불가

중복보험:
동일 피보험 이익에 복수 보험 가입
→ 보험자들이 보험금액 비율로 분담 (비례 보상)

대위:
보험자가 보험금 지급 후 보험계약자의 제3자에 대한
손해배상청구권 대신 취득
→ 이중 이득 방지

잔존물대위:
전손 시 보험자가 잔존물 소유권 취득
```

## 생명보험

```
생명보험:
사람의 생사에 관한 보험

종류:
사망보험: 사망 시 보험금
생존보험: 생존 시 보험금 (연금)
혼합보험: 사망+생존

정액 지급:
손해액 관계 없이 약정 금액 지급
실손보상 원칙 미적용

피보험자 동의:
타인 생명 보험: 피보험자 서면 동의 필요
동의 없으면 보험계약 무효

보험수익자 지정:
계약자가 보험수익자 지정·변경 가능
사망보험금 수령자를 지정
```

## 고지의무

```
고지의무 (알릴 의무):
보험계약 체결 전 중요한 사항을 보험자에게 알릴 의무
보험계약자·피보험자가 부담

중요 사항:
보험자가 보험료 결정이나 계약 여부에 영향 줄 사항

고지의무 위반 효과:
보험자: 계약 해지권 발생
해지 시: 보험금 지급 불요 (사고 후에도)

제척 기간:
사실 안 날로부터 1개월 이내 해지 가능
계약 체결일로부터 3년 경과 시 해지권 소멸
```

## 보험자 면책

```
면책 사유:
① 보험계약자·피보험자 고의 사고
② 보험계약자·피보험자 중대한 과실 (손해보험)
③ 전쟁·내란 등 면책약관 사유

자살:
사망보험 원칙적 면책 (고의 자살)
단, 보험가입 2년 후 자살: 약관에 따라 지급 가능

음주운전 사고:
자동차보험: 약관에 따라 일부 면책

통지의무:
보험사고 발생 시 보험자에게 즉시 통지 의무
위반 시 보험자 면책 또는 감액
```

## 핵심 개념 카드

**손해보험=실손보상** ★★★★★
: 손해보험은 실제 손해만 보상. 초과 이득 금지. 생명보험은 정액 지급.
*암기 포인트: 손해=실손, 생명=정액*

**고지의무 위반=해지권** ★★★★★
: 고지 안 했거나 허위 고지 → 보험자 해지권. 1개월 내 행사, 3년 경과 소멸.
*암기 포인트: 고지위반=해지권 1개월*

**타인 생명 보험=피보험자 동의** ★★★★☆
: 타인 생명 보험 계약 시 피보험자 서면 동의 필수. 없으면 무효.
*암기 포인트: 타인생명=서면동의*

## 실전 퀴즈

**Q. 중복보험 가입 시 보험금은 어떻게 지급되는가?**
> 중복보험은 동일 피보험 이익에 여러 보험 가입. 실손보상 원칙에 따라 실제 손해액 한도 내에서 각 보험자가 보험금액 비율로 분담 지급. 합산 보험금이 실제 손해를 초과할 수 없음.

**Q. 보험계약자가 중요 사항을 고지하지 않은 경우 언제까지 해지할 수 있는가?**
> 보험자가 사실을 안 날로부터 1개월 이내, 또는 계약 체결일로부터 3년 이내. 3년이 경과하면 해지권 소멸. 사고 발생 후라도 해지 가능하며 보험금 지급 불요.
