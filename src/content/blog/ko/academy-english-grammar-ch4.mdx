## 4강 개요

가정법(Conditional/Subjunctive Mood)은 한국어와 다른 영어만의 독특한 문법입니다. 한국어는 "만약 ~라면"으로 모두 표현하지만, 영어는 **현실 가능성이 있는지 없는지**에 따라 동사 형태가 달라집니다. 이 차이를 이해하면 영어 가정법이 논리적으로 보입니다.

---

## 가정법 4종류 비교

| 종류 | 의미 | If절 | 주절 |
|---|---|---|---|
| 0형 (사실·과학) | 항상 사실 | `if + 현재` | `현재` |
| 1형 (실현 가능) | 미래에 가능 | `if + 현재` | `will + V` |
| 2형 (현재 비현실) | 지금 사실과 반대 | `if + 과거` | `would + V` |
| 3형 (과거 비현실) | 과거 사실과 반대 | `if + 과거완료` | `would have + p.p.` |

---

## 0형 조건문 (Zero Conditional)

사실, 과학적 법칙, 일반적 진리에 사용합니다.

```
If you heat water to 100°C, it boils.
If you mix red and blue, you get purple.
If it rains, the ground gets wet.
```

---

## 1형 조건문 (First Conditional)

미래에 실현 가능한 조건을 나타냅니다.

```
If I finish early, I will call you.
If it rains tomorrow, we will cancel the trip.
If you study hard, you will pass the exam.
```

<Callout type="note">
1형 if절에는 `will`을 쓰지 않습니다.
❌ If I will have time, I'll help. → ✅ If I have time, I'll help.
</Callout>

---

## 2형 조건문 (Second Conditional)

**현재 또는 미래의 비현실적 상황**을 가정합니다. 실제로 그렇지 않음을 전제합니다.

```
If I were rich, I would travel the world.
(부자가 아니지만, 만약 부자라면)

If she spoke English, she could work here.
(영어를 못하지만, 만약 할 수 있다면)

If I were you, I would apologize.
(조언할 때 자주 씀 — If I were you 관용구)
```

<Callout type="note">
2형 가정법에서 be동사는 주어에 관계없이 `were`를 씁니다(공식적·격식적).
`If I was`도 구어에서는 허용되지만 시험에서는 `were`가 정답입니다.
</Callout>

---

## 3형 조건문 (Third Conditional)

**과거의 비현실적 상황** — 이미 일어난 일을 반대로 가정합니다. 후회, 아쉬움, 비난을 표현할 때 자주 씁니다.

```
If I had studied harder, I would have passed.
(더 열심히 공부했더라면 합격했을 텐데 — 후회)

If you had told me, I would have helped you.
(말해줬다면 도왔을 텐데 — 아쉬움)

If they had left earlier, they wouldn't have missed the flight.
(일찍 출발했더라면 비행기를 놓치지 않았을 텐데)
```

---

## 혼합 가정법

과거의 조건이 현재에 영향을 미칠 때 사용합니다.

```
If I had listened to my parents, I would be a doctor now.
(과거 if절) + (현재 주절)

If she had taken the job, she would be earning more money.
(과거에 그 일자리를 받아들였더라면, 지금 더 많이 벌고 있을 텐데)
```

---

## unless, provided, as long as

`if not` = `unless`:

```
I won't go unless you come with me.
(= I won't go if you don't come with me.)
```

강한 조건 표현:

```
You can use my car provided (that) you fill up the tank.
We will succeed as long as everyone cooperates.
```

---

## 도치 가정법 (Inversion)

격식체 글쓰기에서 if를 생략하고 도치로 표현합니다.

```
Were I in your position, I would accept the offer.
(= If I were in your position)

Had I known earlier, I would have acted differently.
(= If I had known)

Should you need assistance, please contact us.
(= If you should need)
```

## 자주 묻는 질문

**Q: 가정법 과거에서 왜 과거 시제를 쓰는데 현재를 의미하나요?**
A: 영어에서 과거 시제는 '과거의 시간'뿐 아니라 '현실로부터의 거리'도 나타냅니다. 가정법에서 과거 형태는 "지금 현실과 멀다(비현실)"는 신호입니다.

**Q: TOEIC에서 가정법 문제를 빠르게 푸는 방법은?**
A: if절의 동사를 먼저 확인하세요. `had + p.p.` → 주절은 `would have + p.p.`. `과거 동사(were/knew 등)` → 주절은 `would + 원형`. 공식을 외우되, 혼합가정법은 주절의 시간 부사(now, today)로 구분합니다.
