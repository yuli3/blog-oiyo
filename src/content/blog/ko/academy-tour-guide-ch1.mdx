## 관광통역안내사 시험 개요

```
자격 개요:
→ 문화체육관광부 소관 국가자격
→ 외국인 관광객에게 한국어·외국어로 안내 서비스 제공
→ 어학별 시험: 영어·일어·중어·불어·독어·스페인어·러시아어·아랍어·태국어 등

시험 구성:
→ 1차 필기 (4과목):
  관광국사 (한국사 중심)
  관광자원해설
  관광법규 (관광기본법·관광진흥법 중심)
  관광학개론

→ 2차 면접: 외국어 구술·자질 평가

합격 기준:
→ 필기: 과목당 40점 이상, 평균 60점 이상
→ 면접: 외국어 능력·태도·한국 관광 지식

합격 전략:
→ 관광법규: 여행업·호텔업 등록 기준·등급 암기
→ 관광국사: 3국 시대 ~ 현대까지 핵심 사건
→ 관광자원해설: 세계·유네스코 유산, 한국 관광지
→ 관광학개론: 관광의 정의·개념·관광객 유형
```

## 관광기본법 핵심

```
관광기본법 목적:
→ 관광 진흥을 위한 국가·지방자치단체의 책무 규정
→ 관광 진흥 계획, 국제 관광 육성, 국민 관광 편의 증진

관광 진흥 계획:
→ 문화체육관광부 장관: 5년마다 관광 진흥 계획 수립
→ 시·도지사: 지역 관광 진흥 계획 수립
→ 연도별 시행 계획 포함

국민 관광:
→ 국민의 건강하고 여유 있는 여가 활동 지원
→ 관광 진흥 기금 조성
→ 저소득층·장애인·노인·아동 관광 지원

국제 관광:
→ 외국 관광객 유치 정책
→ 한국관광공사: 국가 관광 기관, 외국인 관광 진흥

관광 주간:
→ 문화체육관광부 장관이 매년 지정
→ 봄·가을 관광 주간 (국민 관광 활성화)

관광 진흥 개발 기금:
→ 출국납부금·카지노 납부금 등으로 재원 조성
→ 관광 시설 개발·외국인 관광객 유치·관광 인재 양성에 사용
```

## 관광진흥법 — 관광사업 종류

```
여행업 (Travel Agency):
→ 여행자에게 운송·숙박·관광시설 이용 알선 서비스

여행업 종류:
→ 종합여행업: 국내·국외 여행업 모두 포함
→ 국외여행업: 국내 거주자의 해외 여행 알선
→ 국내여행업: 국내 여행 알선

등록 기준 (종합여행업):
→ 자본금 3억 원 이상
→ 사무실 보유
→ 보증보험 또는 영업 보증금 가입

관광숙박업:
→ 호텔업 (관광호텔·수상관광호텔·한국전통호텔·가족호텔·호스텔·의료관광호텔)
→ 휴양콘도미니엄업
→ 등급: 5성~1성 (한국관광공사 등급 결정)

관광객 이용 시설업:
→ 전문휴양업: 민박·야영장·오토캠핑장
→ 종합휴양업: 숙박 + 놀이·오락
→ 자동차 야영장·관광 유람선업

국제회의업:
→ 국제회의 기획·운영·지원
→ MICE 산업 (Meetings·Incentives·Conferences·Exhibitions)

카지노업:
→ 허가제 (등록 아님)
→ 외국인 전용이 원칙 (강원랜드 예외)
→ 문화체육관광부 장관 허가
```

## 관광통역안내사 자격·의무

```
관광통역안내사 자격 취득:
→ 문화체육관광부 소관 국가자격
→ 1차 필기 합격 → 2차 면접 → 자격증 교부

자격 유효 기간:
→ 자격증은 취소되기 전까지 유효
→ 자격 취소 사유: 거짓 취득·등록 미이행·정지 중 활동

자격증 등록·갱신:
→ 자격 취득 후 광역 시·도에 등록
→ 등록 유효 기간 3년 → 갱신 시 보수 교육 이수 필요

관광통역안내사 의무:
→ 관광객에게 성실하고 정확한 안내
→ 수수료 외 사례금 불수령
→ 의무 안내 언어: 취득 시험 언어 사용
→ 불법 쇼핑 등 부당 이익 취득 금지

안내 활동 범위:
→ 외국인 관광객 입국 ~ 출국까지 안내
→ 관광지 해설·교통 안내·숙박 알선
→ 현지 문화·역사 정보 제공

무자격 안내 금지:
→ 자격 없는 자가 관광 안내 업무 수행 시 처벌
→ 관광진흥법 위반: 과태료 부과

허가·등록·신고 구분 (출제 핵심):
→ 허가: 카지노업
→ 등록: 여행업·관광숙박업·국제회의업
→ 신고: 관광편의시설업 일부
```

## 한국 관광 현황

```
외래 관광객 유치 현황:
→ 2019년: 약 1,750만 명 (역대 최다)
→ 2020~2022년: 코로나로 급감 (91% 감소)
→ 2023년 이후: 회복 추세
→ 주요 방문국: 중국·일본·미국·동남아

관광 수입과 관광 수지:
→ 관광 수입: 외국인이 국내 소비한 금액
→ 관광 수지: 관광 수입 - 관광 지출
→ 관광 수지 적자 원인: 해외여행 증가

주요 관광 정책:
→ 의료 관광: 외국인 환자 유치 (의료법·관광법 연계)
→ K-관광: 한류 연계 콘텐츠 관광
→ 스마트 관광: 디지털 여행 정보·언택트 서비스

유네스코 세계유산 (한국):
→ 세계 문화유산: 석굴암·불국사, 해인사 장경판전, 종묘, 창덕궁,
  수원 화성, 경주 역사 지구, 고창·화순·강화 고인돌, 조선 왕릉,
  한국의 역사 마을(하회·양동), 남한산성, 백제 역사 유적 지구,
  산사(한국의 산지 승원), 한국의 서원, 가야 고분군 (2023년 등재)
→ 세계 자연유산: 제주 화산섬과 용암 동굴
→ 세계 기록유산: 훈민정음·조선왕조실록·승정원일기 등
→ 인류 무형문화유산: 판소리·종묘 제례악·강강술래·아리랑 등
```

## 자주 묻는 질문

**Q. 관광통역안내사와 문화관광해설사의 차이는 무엇인가요?**
A. 관광통역안내사는 외국인 관광객을 대상으로 외국어로 안내하는 국가자격사입니다. 반면 문화관광해설사는 주로 내국인을 대상으로 관광지에서 역사·문화를 해설하는 직책으로, 각 지방자치단체나 문화재청 등에서 선발·운영합니다. 문화관광해설사는 국가자격은 아니지만 해당 지역의 문화·역사에 대한 전문 교육을 이수해야 합니다. 관광통역안내사는 국가자격 시험 합격이 필수이고 외국어 능력이 핵심 요건입니다.

**Q. 여행업 등록 시 보증보험이나 영업 보증금을 내야 하는 이유는 무엇인가요?**
A. 여행사가 파산하거나 서비스를 이행하지 못했을 때 여행자를 보호하기 위한 제도입니다. 소비자가 여행 상품 대금을 선납했으나 여행사가 영업을 중단하면 환불받기 어렵습니다. 이를 방지하기 위해 여행업자는 사전에 보증보험에 가입하거나 영업 보증금을 예치해야 합니다. 이 금액은 피해 발생 시 여행자에게 우선 보상하는 재원이 됩니다. 자본금과 관련 보증 기준은 시험에서 자주 출제됩니다.
