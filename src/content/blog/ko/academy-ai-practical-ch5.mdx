## 5강 개요: 보고서·기획서, AI로 속도와 품질 동시에

직장인이 가장 많은 시간을 쓰는 업무 중 하나가 **문서 작성**이다. AI를 활용하면 초안 작성 시간을 70% 줄이고, 구조적으로 완성도 높은 문서를 만들 수 있다.

<Callout type="info">
**이 강의의 목표**: 보고서와 기획서의 구조를 AI와 함께 빠르게 잡고, 설득력 있는 문서로 완성하는 실전 방법을 배운다.
</Callout>

## 1. 보고서 작성 — 5분 초안 만들기

### 현황 보고서 프롬프트

```
프롬프트:
"아래 정보를 바탕으로 임원 보고 수준의 현황 보고서를
작성해주세요.

보고 목적: [목적]
핵심 지표: [수치들]
문제점: [현재 이슈]
제안 방향: [아이디어]

형식: 요약(3줄) → 현황 분석 → 문제 원인 → 제안 → 기대효과"
```

**좋은 보고서의 PREP 구조:**

| 구성 | 내용 | 분량 |
|---|---|---|
| **P** (Point) | 핵심 결론 먼저 | 1~2문장 |
| **R** (Reason) | 근거와 데이터 | 3~5개 포인트 |
| **E** (Example) | 구체적 사례 | 1~2개 |
| **P** (Point) | 결론 재강조 + 요청사항 | 1~2문장 |

## 2. 기획서 작성 — 상사를 설득하는 구조

### 신규 프로젝트 기획서

```
프롬프트:
"아래 아이디어를 경영진을 설득하는 기획서로 작성해주세요.

아이디어: [핵심 아이디어]
배경: [문제 상황]
예산: [예상 비용]
기간: [실행 기간]

포함 항목:
1. 제안 배경 및 문제 정의
2. 솔루션 개요
3. 기대 효과 (정량/정성)
4. 실행 계획 (타임라인)
5. 필요 자원 및 리스크"
```

## 3. AI 문서 작성 5단계 워크플로우

```
1단계: 구조 요청
"[주제]에 대한 보고서 목차를 5개 섹션으로 짜줘"

2단계: 각 섹션 내용 생성
"1번 섹션 '현황 분석'을 [데이터]를 포함해서 300자로 써줘"

3단계: 전체 연결 & 흐름 점검
"전체 보고서를 읽고 논리 흐름이 자연스러운지 체크해줘"

4단계: 임원 눈높이 편집
"이 내용을 CEO가 30초 안에 파악할 수 있게 요약해줘"

5단계: 최종 교정
"이 보고서에서 애매한 표현, 중복, 불필요한 내용을 찾아서 수정해줘"
```

## 4. 업종별 보고서 템플릿 요청

| 보고서 유형 | AI 요청 방법 |
|---|---|
| 주간 업무 보고 | "주간 업무 보고서 양식을 만들어줘. 핵심 성과·이슈·다음 주 계획 포함" |
| 마케팅 성과 보고 | "광고 캠페인 성과 보고서. KPI 달성률, 인사이트, 다음 액션 포함" |
| 프로젝트 완료 보고 | "프로젝트 사후 보고서. 목표 대비 결과, 교훈, 재활용 가능 방법론 포함" |
| 리스크 분석 보고 | "리스크 매트릭스 포함한 리스크 분석 보고서 양식" |
