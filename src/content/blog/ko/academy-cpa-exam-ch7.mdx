## 원가 분류와 계산

원가 분류는 목적과 기준을 먼저 고정해야 합니다. 고정·변동 구분은 **관련 범위와 기간** 안에서의 원가행태이고, 직접·간접 구분은 정한 **원가대상에 경제적으로 추적 가능한지**에 달려 있습니다. 제품원가·기간원가 구분도 외부 재무보고인지 내부 의사결정인지에 따라 쓰임이 다릅니다. 아래는 제조기업의 외부보고와 기본 관리회계 문제에서 채택하는 분류입니다.

```
원가 분류:
제조원가: 직접재료비·직접노무비·제조간접비
기간원가: 판관비 (제품원가 아님)

원가 행태:
고정원가: 관련 범위·기간 안에서 총액 일정
변동원가: 관련 범위 안에서 조업도에 따라 총액 변동
혼합원가: 기준비+변동 부분

원가계산 방법:
개별원가계산: 주문별·제품별 원가 집계
종합원가계산: 공정별 대량 생산
활동기준원가(ABC): 활동 중심 간접비 배부
```

## 표준원가와 차이분석

```
표준원가:
미리 설정한 예정 원가
실제원가와 비교 → 차이 분석

직접재료비 차이:
가격차이: (실제가격-표준가격) × 실제수량
수량차이: (실제수량-표준수량) × 표준가격

직접노무비 차이:
임률차이: (실제임률-표준임률) × 실제시간
능률차이: (실제시간-표준시간) × 표준임률

제조간접비 차이:
예산차이·조업도차이·능률차이
```

## CVP 분석

```
CVP (Cost-Volume-Profit):
원가·조업도·이익 관계 분석

공헌이익:
매출액 - 변동원가 = 공헌이익
공헌이익률 = 공헌이익 / 매출액

손익분기점 (BEP):
BEP 판매량 = 고정원가 / 단위공헌이익
BEP 매출액 = 고정원가 / 공헌이익률

목표이익:
목표 판매량 = (고정원가+목표이익) / 단위공헌이익

안전한계:
실제매출 - BEP매출 = 안전한계
```

## 예산 관리

```
종합예산:
판매예산 → 생산예산 → 원가예산 → 재무예산

영업예산:
판매예산이 출발점
판매계획에서 생산계획 도출

자본예산:
장기 투자 의사결정
NPV·IRR 적용

유연예산:
실제 조업도 기준으로 허용 원가 설정
정적예산과 달리 조업도 차이 반영
```

## 실전 퀴즈

**Q. 변동원가계산과 전부원가계산의 이익 차이는?**
> 전부원가: 제조간접비 고정비도 제품원가에 포함. 생산량 > 판매량 시 이익 더 높음 (고정비 일부 재고에 남음). 변동원가: 고정제조간접비를 기간비용. 생산량과 무관. CVP 분석은 변동원가 기준이 더 적합. 외부 보고는 전부원가.

**Q. ABC 원가계산의 장점과 한계는?**
> 장점: 간접비 배부 정확도 향상. 원가 왜곡 감소. 비효율 활동 파악. 한계: 활동 분류·원가동인 파악에 시간·비용 소요. 소규모 기업에는 과도. 전통 원가계산 대비 복잡. 특히 다품종 소량 생산 환경에서 유용.
