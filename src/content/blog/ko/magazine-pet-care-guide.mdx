## 반려동물 입양 전 — 현실 점검

한국 반려동물 포기 이유 1위: **생각보다 많은 비용과 시간**.

입양 전 반드시 확인:

| 확인 항목 | 질문 |
|---------|-----|
| 비용 | 월 20~30만 원 이상 감당 가능한가? |
| 시간 | 강아지: 하루 2~3시간 상호작용 가능한가? |
| 공간 | 충분한 활동 공간이 있는가? |
| 알레르기 | 동거인 포함 모두 동물 알레르기 없는가? |
| 장기 계획 | 15년 이상 함께할 수 있는 상황인가? |
| 여행·출장 | 부재 시 돌봄 계획이 있는가? |

## 강아지 vs 고양이

| 특성 | 강아지 | 고양이 |
|-----|------|------|
| 독립성 | 낮음 (지속적 관심 필요) | 높음 (혼자서도 잘 지냄) |
| 산책 | 매일 필수 | 불필요 (실내 활동) |
| 훈련 | 기본 훈련 필요 | 상대적으로 쉬움 |
| 소음 | 짖음 | 대체로 조용 |
| 털 빠짐 | 종류별 차이 | 많음 (정기 브러싱 필요) |

**1인 가구 직장인**: 고양이가 현실적 선택.
**가족·주택 거주자**: 강아지도 가능.

---

## 입양 vs 구매

### 입양 (유기동물 입양)

- **유기동물 보호소**: 전국 동물보호관리시스템 (animal.go.kr)
- **입양 비용**: 무료~10만 원 (중성화·기본 검진 포함)
- **장점**: 구조한 생명에 새 가정 제공, 비용 절약

### 구매 (펫샵·브리더)

- **비용**: 30만~수백만 원
- **주의**: 펫샵은 강아지 공장 출신 가능성 높음 → 건강 문제 리스크
- **신뢰할 수 있는 브리더**: 부모 개 직접 확인 가능, 건강검진서 제공

## 기본 의료 비용 현실

### 강아지 연간 의료비 (중형견 기준)

| 항목 | 비용 |
|-----|-----|
| 예방접종 (매년) | 10~20만 원 |
| 심장사상충·진드기 예방약 | 연 12~20만 원 |
| 정기 건강검진 | 5~15만 원 |
| 치과 스케일링 | 20~40만 원 |
| 소계 | 약 50~100만 원/년 |

질병·사고 발생 시 추가 (수술비 50~500만 원 가능).

### 고양이 연간 의료비

| 항목 | 비용 |
|-----|-----|
| 예방접종 (매년) | 5~15만 원 |
| 내부·외부 기생충 예방 | 연 6~12만 원 |
| 정기 건강검진 | 5~10만 원 |
| 소계 | 약 20~40만 원/년 |

## 예방접종 스케줄

### 강아지 기본 접종

| 시기 | 접종 종류 |
|-----|---------|
| 생후 6~8주 | DHPP (홍역·파보·간염 등 복합) 1차 |
| 생후 10~12주 | DHPP 2차 + 코로나 |
| 생후 14~16주 | DHPP 3차 + 광견병 |
| 이후 매년 | DHPP + 광견병 추가접종 |

**심장사상충**: 매월 예방약 (3월~11월, 또는 연중)

### 고양이 기본 접종

| 시기 | 접종 종류 |
|-----|---------|
| 생후 8~9주 | FVRCP (허피스·칼리시·범백) 1차 |
| 생후 12주 | FVRCP 2차 + 광견병 |
| 이후 매년 또는 3년 | FVRCP 추가접종 |

## 일상 건강관리

### 강아지

**식사**:
- 나이별 맞춤 사료 (퍼피·어덜트·시니어)
- 인분 계산: 체중별 권장량 준수 (과체중 문제 많음)
- 초콜릿, 포도, 양파, 자일리톨 절대 금지

**운동**:
- 소형견: 하루 30~60분 산책
- 중·대형견: 하루 1~2시간 이상
- 운동 부족 → 문제 행동 (파괴, 과도한 짖음)

**그루밍**:
- 장모종: 주 2~3회 브러싱
- 단모종: 주 1회
- 목욕: 월 1~2회 (너무 잦으면 피부 건조)

### 고양이

**화장실**:
- 고양이 수 + 1개 (2마리면 화장실 3개)
- 매일 모래 정리, 주 1회 세척

**스크래처**:
- 발톱 갈기는 본능 — 스크래처 충분히 제공해야 소파 피해 예방

**장난감·놀이**:
- 하루 15~30분 상호작용 (사냥 본능 충족)

## 반려동물 보험

**반려동물 의료비는 예측 불가**. 보험이 유용.

### 보험 선택 기준

| 항목 | 확인 내용 |
|-----|---------|
| 보장 항목 | 입원·수술·통원 포함 여부 |
| 보상 한도 | 연간 한도, 1회 한도 |
| 자기 부담 | 본인 부담금 비율 |
| 나이 제한 | 가입 가능 연령 (보통 8~10세 이하) |
| 기존 질환 | 가입 전 질환 면책 여부 |

### 주요 보험사

- DB손해보험 펫보험
- 현대해상 하이펫보험
- KB손해보험 KB금쪽 같은 반려동물보험
- 삼성화재 펫보험

**추천**: 어릴 때 가입이 보험료 낮고 면책 적음. 3~5세 이전 가입 권장.

## 노령 반려동물 돌봄

강아지·고양이 평균 수명: 12~15년.

### 노령 징후 (7세 이상부터 주의)

- 활동량 감소
- 식욕·음수 변화
- 체중 변화
- 관절 통증 (계단 오르내리기 어려워함)
- 치매 증상 (밤에 이유 없이 울기)

### 노령 반려동물 관리

- 6개월마다 건강검진
- 관절 보조제 (글루코사민)
- 높이 있는 식기대 (목 편하게)
- 쿠션 침대

### 작별 준비

반려동물의 마지막을 준비하는 것은 어렵지만 필요한 일.

**안락사 결정**: 고통이 지속되고 삶의 질이 없을 때, 수의사와 상담.
**반려동물 장례**: 화장 (화장장), 자연장 (허가된 경우)

## 반려동물 비용 총정리 (월별)

| 항목 | 강아지 | 고양이 |
|-----|------|------|
| 사료 | 5~15만 | 5~10만 |
| 간식·용품 | 2~5만 | 2~3만 |
| 예방약 | 1~2만 | 0.5~1만 |
| 의료비 (평균) | 5~10만 | 3~5만 |
| 미용 (강아지) | 3~8만 | - |
| **월 합계** | **16~40만** | **10~19만** |

반려동물은 15년 이상의 헌신입니다. 충분히 생각하고 준비한 후 입양하세요. 그 사랑은 돌려받는 것 이상을 줍니다.
