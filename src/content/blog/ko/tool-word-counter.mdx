# 글자수 계산기

자기소개서, SNS 포스팅, 기사 원고 — 글자수 제한이 있는 글을 쓸 때 매번 일일이 세는 것은 번거롭습니다. 텍스트를 붙여넣기만 하면 즉시 계산합니다.

이 계산기는 공백 포함·제외 글자수를 동시에 표시하며, 영단어 수와 문장 수도 함께 집계합니다. 한국 자기소개서는 보통 **공백 포함** 기준을 사용하고, 영문 에세이나 해외 투고는 **단어(word) 수** 기준을 사용하기 때문에 두 가지 모두 즉시 확인할 수 있습니다.

**이런 상황에 바로 활용하세요:**
- 대기업 자소서 (항목당 500·800·1,000자 제한)
- 인스타그램 캡션 (2,200자), X(트위터) (140자)
- 네이버 블로그 제목 (60자)
- 학술 논문 초록 (영문 200–250 words)

## 플랫폼별 글자수 제한

| 플랫폼 | 제한 |
|---|---|
| 트위터(X) | 280자 (영문), 140자 (CJK) |
| 인스타그램 캡션 | 2,200자 |
| 인스타그램 바이오 | 150자 |
| 페이스북 포스팅 | 63,206자 |
| 유튜브 제목 | 100자 |
| 유튜브 설명 | 5,000자 |
| 카카오톡 메시지 | 10,000자 |
| 네이버 블로그 제목 | 60자 |

## 자기소개서 글자수 가이드

| 항목 | 일반 기업 | 공기업 |
|---|---|---|
| 성장 과정 | 500–800자 | 500자 내외 |
| 지원 동기 | 500–700자 | 500자 내외 |
| 직무 역량 | 700–1,000자 | 700자 내외 |
| 입사 후 포부 | 400–600자 | 500자 내외 |

<Callout type="tip">
**공백 포함 vs 제외**: 한국 자기소개서는 보통 **공백 포함** 글자수 기준입니다. 영문 글쓰기는 **단어(word) 수** 기준이 일반적입니다.
</Callout>

## 원고료 계산 기준
