## 매매 전 최종 체크리스트

### 추세 확인

```
☐ 상위 시간대(주봉) 추세 방향 확인
☐ 이동평균선 배열 상태 (정배열/역배열/혼조)
☐ 주요 지지·저항 레벨 표시
☐ 지금 추세 초기/중기/말기 어느 단계?
```

### 진입 신호 확인

```
☐ 최소 2개 이상 독립적 신호 일치
  예: 이동평균 지지 + RSI 과매도 + 거래량 증가
☐ 다이버전스 여부 확인 (반전 신호 유무)
☐ 캔들스틱 반전 패턴 존재 여부
☐ 피보나치 지지 구간과 일치 여부
```

### 리스크 관리

```
☐ 손절가 사전 결정 (기술적 레벨 기반)
☐ R:R 비율 계산 (최소 1:2)
☐ 포지션 크기 계산 (계좌의 1~2% 리스크)
☐ 최악의 경우 손실 금액 수용 가능 여부
```

## 통합 분석 프레임워크

```
시장 상태 판별:
상승 추세 → 눌림목 매수 전략
하락 추세 → 반등 매도 전략 or 관망
횡보 → 밴드 하단 매수/상단 매도 or 관망

상승 추세 눌림목 매수 시나리오:
1. 주봉: 상승 추세 확인
2. 일봉: 20일 MA까지 눌림목
3. 4시간봉: RSI 40~50 + 볼린저 중심선 지지
4. 1시간봉: 반전 캔들 + 거래량 증가
→ 진입, 직전 저점 - ATR 손절
→ 피보나치 161.8% 목표
```

## 흔한 기술적 분석 실수

```
실수 1: "신호가 예쁘면 무조건 진입"
→ 큰 그림(상위 시간대) 확인 없이 매매
→ 방지: 반드시 3단계 시간대 분석

실수 2: "손절 없이 장기 보유"
→ "언젠가 올라오겠지" 심리 = 계좌 폭발 지름길
→ 방지: 진입 전 손절가 결정, 실행은 기계적으로

실수 3: "RSI 70 = 즉시 매도"
→ 강한 추세에서 RSI는 장기간 70 이상 유지
→ 방지: 추세 확인 후 오실레이터 해석

실수 4: "지표 많을수록 좋다"
→ 지표 10개가 모두 같은 데이터를 다르게 표시
→ 방지: 각 카테고리(추세·오실레이터·변동성)에서 1~2개만

실수 5: "과거 백테스트 = 미래 수익"
→ 과최적화(Overfitting) = 과거에만 맞는 전략
→ 방지: 충분한 샘플(200회 이상), 다른 기간 검증
```

## 기술적 분석의 한계

```
기술적 분석이 작동하는 이유:
→ 수많은 시장 참여자가 같은 차트를 보고
   비슷한 결정을 내림 = 자기실현적 예언

기술적 분석이 실패하는 이유:
→ 뉴스·이벤트 → 패턴 무력화
→ 알고리즘 트레이딩 → 패턴 변형
→ 유동성 낮은 종목 → 패턴 왜곡

결론:
→ 기술적 분석 = 확률 게임
→ 완벽한 예측 불가능
→ 시스템 + 리스크 관리 = 장기 생존
```

## 나만의 매매 시스템 완성

```
단계 1: 전략 선택
→ 추세 추종 or 반전 매매 or 혼합 결정

단계 2: 규칙 문서화
→ 진입 조건 (명확한 수치로)
→ 손절 기준
→ 목표가 설정 방법

단계 3: 백테스트
→ 최소 200회 이상 과거 데이터 검증

단계 4: 소액 실거래
→ 계획대로 실행하는 심리 훈련

단계 5: 일지 기록 → 월별 검토 → 개선
```

*기술적 분석은 시장의 언어를 배우는 여정입니다. 완벽한 방법은 없지만, 일관된 시스템과 철저한 리스크 관리로 장기 생존이 가능합니다.*
