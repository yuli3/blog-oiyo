## 디자인보호법 개요

```
디자인 정의:
물품의 형상·모양·색채 또는 이들의 결합
시각을 통해 미감을 일으키는 것

보호 대상:
물품 디자인 (독립 거래 물품)
부분 디자인 (물품 일부)
글자체 디자인
화상 디자인 (UI·아이콘)

보호 제외:
물품으로 보기 어려운 것
기능에만 의해 결정된 형상
공공 질서·선량한 풍속 위반
```

---

## 디자인 등록 요건

```
신규성:
출원 전 국내외 공지·공용·반포된 것 아닐 것

창작성:
쉽게 창작할 수 없을 것
(특허 진보성보다 낮은 기준)

공업상 이용가능성:
공업적으로 양산 가능한 것

유사 디자인 제외:
선등록·선출원 디자인과 동일·유사하지 않을 것

디자인 무심사 등록:
물품 지정 분야 (패션·잡화 등) 심사 없이 등록
```

---

## 디자인 등록 절차

```
출원:
물품의 도면·사진 제출
정면·배면·양측면·평면·저면 6면도
사시도 포함

심사:
방식 심사 + 실체 심사
거절이유 통지 → 의견서·보정서

복수 디자인 출원:
1출원으로 100 이내 디자인 일괄 출원

비밀 디자인:
출원일로부터 3년 이내 비밀 유지 가능
제품 출시 전 보호 전략
```

---

## 디자인권 효력

```
존속기간:
등록일로부터 20년

유사 디자인 등록:
기본 디자인에 유사한 디자인 별도 등록 가능
기본 디자인과 운명 함께함

침해 판단:
미감 유사 여부 기준 (육안 대비)
전체적인 심미감 비교

효력 제한:
연구·시험 목적
자기 실시 전부터 실시 (선사용권)
```

## 핵심 개념 카드

**디자인=물품미감20년** ★★★★★
: 물품의 미감을 주는 외관, 존속 20년.
*암기 포인트: 디자인=물품+미감+20년*

**디자인창작성=낮은기준** ★★★★☆
: 특허 진보성보다 낮은 수준.
*암기 포인트: 디자인창작성&lt;특허진보성*

**비밀디자인=3년** ★★★★☆
: 출원 후 3년 이내 비밀 유지 신청 가능.
*암기 포인트: 비밀디자인=3년*

## 실전 퀴즈

**Q. 패션 업계에서 디자인 무심사 등록을 선호하는 이유는?**
> 트렌드 사이클이 빠름: 심사 대기 없이 빠른 등록. 권리화 속도가 핵심. 무심사라도 등록되면 경쟁사 경고 가능. 무효 위험은 있지만 시즌 내 보호 효과. 유행 지난 후 무효 돼도 손해 없음. 비밀 디자인과 결합하면 출시 전 보호 강화.

**Q. 디자인 침해 판단에서 특허 침해 판단과의 차이점은?**
> 특허: 청구범위 구성요소 대비 (기술적 분석). 디자인: 육안으로 전체 심미감 비교 (미적 판단). 디자인은 전문가보다 일반 소비자 기준. 디자인은 유사 범위가 주관적 → 분쟁 많음. 특허는 문언+균등론, 디자인은 전체적 유사 기준. 동일 제품도 기술특허·디자인권 중복 보호 가능.
