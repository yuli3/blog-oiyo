## 경영이란 무엇인가

**경영(Management)**은 조직의 목표를 달성하기 위해 인적·물적·재무적 자원을 계획하고 조직하고 지휘하고 통제하는 일련의 활동입니다.

핵심은 두 가지입니다:

1. **목표 달성**: 경영은 방향이 있는 활동입니다. 방향 없이 자원만 움직이는 것은 경영이 아닙니다.
2. **자원 활용**: 사람, 돈, 시간, 정보 — 제한된 자원을 가장 효과적으로 배합합니다.

경영학의 아버지로 불리는 **피터 드러커(Peter Drucker)**는 경영을 "사람을 통해 일을 이루는 것(Getting things done through people)"으로 정의했습니다. 기계가 아닌 사람이 중심이라는 철학이 담겨 있습니다.

## 경영의 4가지 기능

전통적으로 경영은 네 가지 핵심 기능으로 나뉩니다.

### 1. 계획(Planning)

목표를 설정하고, 그 목표를 달성하기 위한 전략과 행동 계획을 수립합니다.

- 무엇을 달성할 것인가?
- 어떤 경로로 달성할 것인가?
- 어떤 자원이 필요한가?

좋은 계획은 **SMART 원칙**을 따릅니다: Specific(구체적), Measurable(측정 가능), Achievable(달성 가능), Relevant(연관성), Time-bound(기한 명확).

### 2. 조직(Organizing)

계획을 실행하기 위해 역할을 분배하고 구조를 설계합니다.

- 누가 무엇을 담당하는가?
- 어떤 부서를 만들고 어떻게 연결하는가?
- 권한과 책임은 어떻게 배분하는가?

조직 설계는 기능별(영업부/개발부) 구조, 사업부제, 매트릭스 구조 등 다양한 형태가 있습니다.

### 3. 지휘(Leading)

사람들이 계획에 따라 행동하도록 동기를 부여하고 방향을 제시합니다.

- 리더십과 커뮤니케이션
- 동기 부여와 팀 문화
- 갈등 관리와 협업 촉진

지휘는 경영 기능 중 가장 인간적인 요소입니다. 기술보다 관계와 신뢰가 핵심입니다.

### 4. 통제(Controlling)

실제 성과를 계획과 비교하고 편차를 수정합니다.

- 성과를 어떻게 측정하는가?
- 목표와 실제 간 차이를 어떻게 줄이는가?
- 필요 시 계획을 어떻게 수정하는가?

통제는 감시가 아닙니다. 조직이 올바른 방향으로 가고 있는지 확인하는 피드백 루프입니다.

## 경영자의 역할

헨리 민츠버그(Henry Mintzberg)는 경영자의 실제 역할을 10가지로 정리했습니다.

### 대인 관계 역할 (Interpersonal Roles)
| 역할 | 설명 |
|------|------|
| 대표자 (Figurehead) | 조직을 대표해 의식적 기능 수행 |
| 리더 (Leader) | 팀을 동기부여하고 방향 제시 |
| 연락자 (Liaison) | 외부 이해관계자와 관계 유지 |

### 정보 역할 (Informational Roles)
| 역할 | 설명 |
|------|------|
| 모니터 (Monitor) | 환경 변화와 정보 수집 |
| 전파자 (Disseminator) | 내부 구성원에 정보 전달 |
| 대변자 (Spokesperson) | 외부에 조직 입장 전달 |

### 의사결정 역할 (Decisional Roles)
| 역할 | 설명 |
|------|------|
| 기업가 (Entrepreneur) | 새 기회 발굴과 변화 주도 |
| 문제해결자 (Disturbance Handler) | 위기와 갈등 해결 |
| 자원배분자 (Resource Allocator) | 자원 우선순위 결정 |
| 협상자 (Negotiator) | 내외부 협상 수행 |

## 경영자의 역량: 카츠 모델

로버트 카츠(Robert Katz)는 경영자에게 필요한 역량을 세 가지로 구분합니다.

**기술적 역량 (Technical Skills)**
- 업무에 필요한 전문 지식과 기술
- 실무자와 하위 관리자에게 특히 중요
- 예: 회계사의 회계 지식, 엔지니어의 기술 이해

**대인 역량 (Human Skills)**
- 사람들과 효과적으로 소통하고 협력하는 능력
- 모든 레벨의 경영자에게 동등하게 중요
- 예: 적극적 경청, 갈등 중재, 동기부여

**개념화 역량 (Conceptual Skills)**
- 복잡한 상황을 전체적으로 이해하고 전략적으로 사고하는 능력
- 고위 경영자일수록 더 중요
- 예: 산업 트렌드 분석, 시나리오 계획, 큰 그림 이해

> **계층별 역량 비중**: 하위 관리자는 기술적 역량이 크고, 최고경영자는 개념화 역량이 커집니다.

## 기업의 목표와 이해관계자

전통적으로 기업의 목표는 **이윤 극대화**였습니다. 그러나 현대 경영학은 이해관계자(Stakeholder) 관점을 강조합니다.

**이해관계자 유형**:

| 이해관계자 | 주요 관심사 |
|----------|-----------|
| 주주 | 투자 수익, 배당, 주가 |
| 직원 | 급여, 고용 안정, 성장 기회 |
| 고객 | 품질, 가격, 서비스 |
| 공급업체 | 공정한 거래, 결제 신뢰성 |
| 지역사회 | 고용, 환경, 사회적 책임 |
| 정부 | 납세, 법규 준수 |

에드 프리먼(Ed Freeman)의 **이해관계자 이론**은 기업이 주주만이 아닌 모든 이해관계자의 이익을 균형 있게 고려해야 한다고 주장합니다. 오늘날 ESG(환경·사회·지배구조) 경영의 철학적 토대입니다.

## 경영 환경: PEST 분석

조직은 진공 속에 존재하지 않습니다. 외부 환경이 경영 결정에 끊임없이 영향을 미칩니다.

**PEST 분석**은 거시 환경을 4가지 차원으로 분석합니다:

- **P (Political)**: 정치·법적 환경 — 규제, 세법, 정치 안정성
- **E (Economic)**: 경제 환경 — 경기 사이클, 금리, 환율, 인플레이션
- **S (Social)**: 사회·문화 환경 — 인구구조, 소비 트렌드, 가치관 변화
- **T (Technological)**: 기술 환경 — 기술 혁신, 자동화, 디지털 전환

좋은 경영자는 이 네 가지 환경 요인을 지속적으로 모니터링하며 전략을 조정합니다.

## 핵심 개념 카드

**경영(Management)의 정의** ★★★★
: 조직의 목표를 효과적·효율적으로 달성하기 위해 인적·물적·재무 자원을 계획·조직·지휘·통제하는 과정. 효과성(Effectiveness): 목표 달성. 효율성(Efficiency): 자원의 최소 투입.

**경영의 기능 POLC** ★★★★
: Planning(계획) → Organizing(조직) → Leading(지휘·리더십) → Controlling(통제·평가). 파욜(Henri Fayol)의 5기능: 계획·조직·지휘·조정·통제.
*암기 포인트: POLC = 폴씨 (Plan-Organize-Lead-Control)*

**경영자의 역할: 민츠버그** ★★★★
: 대인관계 역할(Interpersonal): 대표자·리더·연결자. 정보 역할(Informational): 모니터·전파자·대변인. 의사결정 역할(Decisional): 기업가·위기관리자·자원배분자·협상가.
