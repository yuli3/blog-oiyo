## 교육과정 이론

```
교육과정의 정의:
→ 좁은 의미: 교수·학습의 계획된 내용 (교과서)
→ 넓은 의미: 학교에서 학생이 갖는 모든 경험
→ 교육과정 구성 요소:
  목표·내용·방법·평가의 네 요소

타일러 (Ralph Tyler)의 합리적 교육과정:
→ 4가지 기본 질문 (Tyler's Rationale, 1949):
  1. 어떤 교육 목표를 달성해야 하는가?
  2. 어떤 교육 경험을 제공할 것인가?
  3. 어떻게 교육 경험을 조직할 것인가?
  4. 어떻게 목표 달성 여부를 평가할 것인가?
→ 목표 설정 원천: 학습자·사회·교과 전문가
  철학적·심리학적 여과 적용
→ 학습 경험 조직 원리: 계속성·계열성·통합성

아이즈너 (Elliot Eisner)의 예술적 교육과정:
→ 행동 목표의 한계 비판
→ 표현적 결과 (Expressive Outcomes): 예측 불가 성과
→ 교육 상상력: 교사의 전문적 예술성
→ 교육 감식안 (Educational Connoisseurship)
  교육 비평 (Educational Criticism): 질적 평가

잠재적 교육과정 (Hidden Curriculum):
→ 공식 교육과정 외에 학교 생활에서 암묵적으로 학습
→ 잭슨 (P.W. Jackson): "Life in Classrooms"
  군집·평가·권력: 학교의 비가시적 학습
→ 사례: 순종·경쟁·성별 역할·시간 통제 내면화
→ 영교육과정 (Null Curriculum):
  아이즈너: 의도적으로 가르치지 않는 내용
  제외된 교육과정도 메시지를 전달

구성주의 교육과정:
→ 지식은 능동적으로 구성 (주어지는 것이 아님)
→ 인지적 구성주의: 피아제 발달 단계·개인적 구성
→ 사회적 구성주의: 비고츠키·근접발달영역·비계
→ 구성주의 교육 방법:
  프로젝트 학습·문제 기반 학습·탐구 학습
```

## 수업 설계 모형

```
ADDIE 모형:
→ 체계적 수업 설계의 기본 틀
→ 분석 (Analysis):
  학습자 분석·과제 분석·맥락 분석·요구 분석
→ 설계 (Design):
  학습 목표 진술·평가 설계·내용 조직
  수업 전략·매체 선정
→ 개발 (Development):
  교수 자료 제작·파일럿 테스트
→ 실행 (Implementation):
  수업 진행·학습자 지원
→ 평가 (Evaluation):
  형성 평가 (과정)·총괄 평가 (결과)

딕과 캐리 모형 (Dick & Carey):
→ 수업 목표 확인→수업 분석→학습자 분석
  성취 목표 진술→준거 평가 개발
  수업 전략 개발→수업 자료 개발
  형성 평가→수업 개정→총괄 평가
→ 선형적·체계적 과정
→ 기업 연수·군 훈련·직업 교육 적합

켈러의 ARCS 모형:
→ 학습 동기 설계 이론
→ Attention (주의):
  지각적 각성·탐구적 각성·변화성
  "눈길을 끄는 질문·역설·새로운 접근"
→ Relevance (관련성):
  목표 지향성·모티브 매칭·친숙성
  "이 학습이 학생의 목표와 어떻게 연결되나"
→ Confidence (자신감):
  학습 요구·성공 기회·개인 통제
  "성취 가능하고 내 노력에 달려 있음"
→ Satisfaction (만족감):
  내재적 강화·외재적 보상·공정성
  "학습 결과를 활용하고 인정받음"

가네의 9가지 수업 사태:
→ 주의 획득 → 목표 제시 → 선수 학습 자극
  자극 제시 → 학습 안내 → 수행 유발
  피드백 제공 → 성취 평가 → 파지와 전이
→ 학습 조건 이론: 학습 유형별 다른 조건 필요
```

## 교육평가

```
블룸의 교육 목표 분류학:
→ 인지적 영역 (Bloom, 1956):
  지식→이해→적용→분석→종합→평가
→ 개정 분류학 (Anderson & Krathwohl, 2001):
  기억→이해→적용→분석→평가→창조
  지식 차원: 사실적·개념적·절차적·메타인지적
→ 정의적 영역 (Krathwohl):
  수용→반응→가치화→조직화→인격화
→ 심동적 영역 (Harrow·Dave):
  운동 기술 발달 단계

평가의 유형:
→ 형성 평가 (Formative Assessment):
  학습 과정 중 피드백 목적
  오류 진단·수업 개선
  수업 중 퀴즈·과제·구두 확인
→ 총괄 평가 (Summative Assessment):
  학습 결과 판단·등급·자격 결정
  기말 고사·졸업 시험
→ 진단 평가 (Diagnostic Assessment):
  학습 시작 전 선수 학습·오개념 파악
→ 동료 평가 (Peer Assessment):
  학습자 상호 피드백·메타인지 촉진

수행 평가 (Performance Assessment):
→ 실제 과제·맥락에서 능력 직접 측정
→ 유형: 포트폴리오·프로젝트·실험·실기·토론
→ 루브릭 (Rubric): 평가 기준 명시
  총체적 루브릭: 전체 수준 판단
  분석적 루브릭: 요소별 기준

준거 참조 평가 vs 규준 참조 평가:
→ 준거 참조 (Criterion-Referenced):
  절대 기준과 비교 (80점이면 합격)
  학습 목표 달성 여부 판단
→ 규준 참조 (Norm-Referenced):
  집단 내 상대적 위치 (상대 등급·석차)
  선발·경쟁 상황에 사용
→ 한국 수능: 규준 참조 (등급제)
```

## 역량 기반 교육과정

```
역량 기반 교육 (Competency-Based Education):
→ 지식 주입에서 역량 함양으로 전환
→ 역량 (Competency): 지식·기능·태도의 통합적 능력
  실제 생활 문제 해결에 적용

OECD DeSeCo 프로젝트:
→ 세 가지 핵심 역량:
  자율적 행동 (Self-Direction)
  이질적 집단과의 상호작용
  도구 활용 능력 (언어·지식·기술 포함)
→ 21세기 핵심 역량 (4C):
  비판적 사고 (Critical Thinking)
  창의성 (Creativity)
  의사소통 (Communication)
  협업 (Collaboration)

역방향 설계 (Backward Design):
→ 위긴스·맥타이 (Wiggins & McTighe): "Understanding by Design"
→ 3단계:
  1. 기대하는 결과 확인 (목표·핵심 이해)
  2. 수용 가능한 증거 결정 (평가 설계)
  3. 학습 경험·수업 계획 (교수 활동)
→ 전통 설계와 차이:
  전통: 교과서 내용→활동 계획→최종 시험
  역방향: 목표→평가→교수 활동
→ 이해의 6가지 측면:
  설명·해석·적용·관점·공감·자기지식

한국 2022 개정 교육과정:
→ 역량 강화: 자기관리·지식정보처리·창의적 사고
  심미적 감성·협력적 소통·공동체 역량
→ 고교학점제: 학생 과목 선택권 확대
  2025년 전면 도입
→ 디지털 소양·생태 전환 교육 강조
→ 학생 맞춤형 교육 지원 강화
```

## 자주 묻는 질문

**Q. 형성평가와 총괄평가의 차이는 무엇이고 어떻게 활용해야 하나요?**
A. 두 평가는 목적과 활용 방법이 완전히 다릅니다. 형성평가는 학습이 진행되는 동안 학습자의 이해 수준을 확인하고 피드백을 제공해 학습 방향을 수정하는 것이 목적입니다. 성적 산정보다는 학습 개선에 초점을 둡니다. 예를 들어 수업 중 질문·투표·짧은 퀴즈·출구 티켓(수업 끝에 핵심 내용 한 줄 쓰기) 등이 있습니다. 총괄평가는 학습 종료 후 학생이 얼마나 학습 목표를 달성했는지 판단하는 것으로 성적·자격·선발에 활용됩니다. 효과적 교사는 두 가지를 균형 있게 활용합니다. 잦은 형성평가로 학습자의 약점을 조기에 발견하고, 총괄평가는 단원 종료나 학기말에 집중합니다. 최근에는 '학습을 위한 평가(Assessment for Learning)'라는 개념 아래 형성평가의 피드백 기능이 더욱 강조되고 있으며, 특히 이분법적인 맞고 틀림보다 다음 학습 단계를 안내하는 서술형 피드백이 학습 효과를 높인다는 연구가 많습니다.

**Q. 잠재적 교육과정은 의도한 것이 아닌데 왜 중요하게 다루나요?**
A. 잠재적 교육과정이 중요한 이유는 명시적 교육과정 못지않게 학생에게 강력하고 지속적인 영향을 미치기 때문입니다. 학생들은 수업 내용만큼 학교 생활의 패턴과 관계에서 많은 것을 배웁니다. 구체적 사례로는 점수 경쟁이 지속되면 협력보다 경쟁을 내면화하게 되고, 교사-학생의 권력 관계는 권위에 대한 순응·복종을 학습시킬 수 있습니다. 성별에 따른 기대(남학생은 과학·여학생은 문학)가 무의식적으로 전달되기도 합니다. 교육 연구자들이 잠재적 교육과정을 중요시하는 것은 두 가지 이유에서입니다. 첫째, 숨겨진 불평등을 드러내기 위해서입니다. 잠재적 교육과정이 특정 집단(여성·소수자·저소득층)에게 불리하게 작동할 수 있음을 인식하고 개선해야 합니다. 둘째, 의도적으로 설계하기 위해서입니다. 협력·민주적 토론·다양성 존중 같은 가치는 명시적 교육 내용이 아닌 학교 문화와 수업 분위기를 통해 더 잘 전달됩니다.
