## 전략 경영(Strategic Management)이란?

```
전략 경영의 정의:
→ 기업이 장기적으로 경쟁 우위를 확보하고 유지하기 위해
  목표를 설정하고 자원을 배분하는 과정

전략 vs 전술:
→ 전략 (Strategy): 장기적 방향과 목표 설정
→ 전술 (Tactics): 전략을 실행하기 위한 구체적 행동

전략 경영의 중요성:
→ 불확실한 환경에서 방향 설정
→ 자원의 효율적 배분
→ 지속적 경쟁 우위 확보
→ 이해관계자 가치 창출
```

## 전략 경영 프로세스

```
5단계 전략 경영 프로세스:

1단계: 미션·비전·가치 수립
→ 미션 (Mission): 기업 존재 이유 "우리는 무엇을 하는가?"
→ 비전 (Vision): 미래 모습 "우리는 어디로 가는가?"
→ 핵심 가치: 기업 행동 원칙

2단계: 외부 환경 분석 (기회·위협)
→ 산업 구조, 경쟁 환경, 거시 환경 분석

3단계: 내부 역량 분석 (강점·약점)
→ 자원, 핵심 역량, 가치 사슬 분석

4단계: 전략 수립
→ SWOT 분석, 전략 대안 도출, 전략 선택

5단계: 전략 실행 및 평가
→ 조직 구조, 시스템, 리더십으로 실행
→ BSC (균형 성과표) 등으로 성과 평가
```

## PESTEL 분석 (거시 환경)

```
PESTEL: 거시 환경의 6개 요소

P - Political (정치적):
→ 정부 정책, 규제, 정치 안정성
→ 예: 최저임금 인상, 환경 규제

E - Economic (경제적):
→ 경제 성장률, 금리, 환율, 인플레이션
→ 예: 경기 침체 → 소비 감소

S - Social (사회·문화적):
→ 인구 변화, 가치관, 라이프스타일
→ 예: 고령화, 1인 가구 증가

T - Technological (기술적):
→ 기술 혁신, 디지털화, R&D
→ 예: AI, 플랫폼 비즈니스

E - Environmental (환경적):
→ 기후변화, 탄소 규제, 친환경 요구
→ 예: 탄소 중립 법제화

L - Legal (법적):
→ 고용법, 소비자 보호법, 공정거래법
→ 예: 개인정보보호법 강화
```

## 포터의 5대 경쟁력 모델 (Porter's Five Forces)

```
마이클 포터 (Michael Porter) 제안
→ 산업의 매력도와 수익성 결정 요인

5가지 경쟁력:

1. 기존 경쟁자 간 경쟁 강도 (Rivalry Among Competitors):
→ 경쟁사 수, 시장 성장률, 제품 차별화 정도
→ 강할수록 수익성 하락

2. 신규 진입자의 위협 (Threat of New Entrants):
→ 진입 장벽: 규모의 경제, 브랜드, 특허, 규제
→ 낮을수록 수익성 하락 위협

3. 대체재의 위협 (Threat of Substitutes):
→ 다른 방식으로 같은 욕구 충족 가능한 제품
→ 예: 커피 → 에너지 드링크, 택시 → 카카오택시

4. 구매자의 교섭력 (Bargaining Power of Buyers):
→ 대형 고객, 전환 비용, 가격 민감도
→ 높을수록 이익 마진 축소

5. 공급자의 교섭력 (Bargaining Power of Suppliers):
→ 독점 공급자, 차별화된 원재료
→ 높을수록 비용 증가

분석 활용:
→ 5힘 모두 약할수록 매력적인 산업
→ 방어 전략 또는 시장 선택에 활용
```

## SWOT 분석

```
SWOT = 강점(S) + 약점(W) + 기회(O) + 위협(T)

강점 (Strengths, 내부):
→ 경쟁사 대비 우위 요소
→ 특허, 브랜드, 핵심 기술, 우수 인재

약점 (Weaknesses, 내부):
→ 경쟁사 대비 열위 요소
→ 자금 부족, 기술 격차, 인지도 낮음

기회 (Opportunities, 외부):
→ 유리한 환경 요소
→ 시장 성장, 경쟁사 약화, 기술 트렌드

위협 (Threats, 외부):
→ 불리한 환경 요소
→ 경쟁 심화, 규제 강화, 경기 침체

SWOT 전략 매트릭스:
S + O → 공격 전략: 강점으로 기회 활용
W + O → 방어 전략: 약점 보완하여 기회 포착
S + T → 다각화 전략: 강점으로 위협 대응
W + T → 위기 관리: 약점 최소화, 위협 회피
```

## 경쟁 우위 (Competitive Advantage)

```
경쟁 우위의 의미:
→ 경쟁사 대비 탁월한 성과를 지속적으로 달성하는 능력

경쟁 우위의 두 원천 (포터):

1. 비용 우위 (Cost Leadership):
→ 산업 내 최저 비용으로 생산
→ 규모의 경제, 공정 혁신, 원가 절감
→ 예: 월마트, 쿠팡, 라이언에어

2. 차별화 (Differentiation):
→ 고객이 더 높은 가격을 지불할 만큼 독특한 가치 제공
→ 브랜드, 품질, 기술, 서비스, 디자인
→ 예: 애플, 루이비통, 스타벅스

3. 집중화 (Focus):
→ 특정 세분 시장에 집중
→ 비용 집중 or 차별화 집중

진퇴양난 (Stuck in the Middle):
→ 비용 우위도, 차별화도 아닌 어중간한 위치
→ 수익성 가장 낮음
```

## 자원 기반 관점 (Resource-Based View)

```
RBV (Resource-Based View):
→ 경쟁 우위는 기업의 내부 자원·역량에서 비롯

VRIN 기준 (지속적 경쟁 우위 자원):
V - Valuable (가치 있음): 기회 활용, 위협 방어
R - Rare (희귀함): 경쟁사가 갖고 있지 않음
I - Inimitable (모방 불가): 복제 어려움
N - Non-substitutable (대체 불가): 다른 자원으로 대체 불가

핵심 역량 (Core Competence, 프라할라드·해멀):
→ 경쟁사가 쉽게 따라할 수 없는 기업 고유 능력
→ 다양한 시장에 적용 가능
→ 예: 소니의 소형화 기술, 3M의 접착제 기술

지식 경영 (Knowledge Management):
→ 조직 내 지식을 체계적으로 창출·공유·활용
→ 암묵지(Tacit Knowledge) vs 형식지(Explicit Knowledge)
```

## 자주 묻는 질문

**Q. SWOT 분석은 실제로 얼마나 유용한가요?**
A. SWOT는 단순하지만 전략적 사고의 출발점으로 유용합니다. 그러나 각 요소 간 우선순위를 설정하거나 구체적인 실행 방안을 도출하는 데 한계가 있습니다. SWOT 후에 구체적인 전략 대안을 도출하는 SWOT 전략 매트릭스나 포터의 모델과 결합해 사용하는 것이 더 효과적입니다.

**Q. 포터의 5대 경쟁력 모델의 한계는 무엇인가요?**
A. 정적인 산업 구조 분석에 집중하여 기술 혁신으로 산업 경계가 허물어지는 현상을 잘 설명하지 못합니다. 또한 빠르게 변화하는 디지털 경제에서 플랫폼 기업처럼 여러 산업을 동시에 재편하는 경우에는 적용이 어렵습니다.
