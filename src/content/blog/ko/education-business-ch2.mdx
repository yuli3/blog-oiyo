## 4. 각 이론의 상세 핵심 내용

### (1) 테일러 (F.W. Taylor) — 과학적 관리법

| 핵심 원칙 | 내용                                                         |
| --------- | ------------------------------------------------------------ |
| 목표      | **높은 임금, 낮은 노무비 (High Wage, Low Labor Cost)**       |
| 방법      | 시간 연구 + 동작 연구 = **One Best Way 도출**                |
| 제도 ①    | 과학적 근로자 선발                                           |
| 제도 ②    | **차별적 성과급**: 표준과업 달성 시 고임금, 미달성 시 저임금 |
| 제도 ③    | **기획부 제도**: 계획과 실행을 분리하는 기능부서             |
| 제도 ④    | **기능식 직장 제도**: 한 작업자에게 여러 기능 전문가가 지도  |
| 한계      | 인간의 기계화, 비공식 조직 무시                              |

**길브레스(Gilbreth)**: 동작연구 — 벽돌 쌓기 18동작 → 5동작. **서블릭(Therblig)** 기호 제작.
**간트(Gantt)**: 과업 선후관계를 시각화한 **간트차트** 제작 (프로젝트 관리 원조).

☐ 명령 통일 vs 기능식 직장제도의 충돌 관계 이해  
☐ VRIN = **가·희·모·대**
