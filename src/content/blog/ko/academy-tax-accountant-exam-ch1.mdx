## 1차 합격의 공식

세무사 1차 시험은 **평균 60점 이상, 각 과목 40점 이상(과락 없음)** 이 두 조건을 동시에 충족해야 합격입니다. 단순해 보이지만, 과목 간 난이도 편차가 크기 때문에 전략적 배분이 핵심입니다.

<Callout>
**합격 공식 요약**

- 전 과목 평균 60점 이상 (240점/400점)
- 각 과목 40점 미만 시 과락 → 불합격
- 영어 과목은 공인어학성적으로 대체 (별도 응시 불필요)
</Callout>

1차는 객관식 5지선다형으로, 실력 편차보다 **시간 관리와 과목 간 균형**이 당락을 가릅니다. 잘하는 과목에서 80점을 받더라도 취약 과목에서 40점 이하가 나오면 탈락입니다.

## 재정학: 핵심 테마 5선

재정학은 경제학 배경이 없는 수험생에게 낯설지만, 출제 테마가 비교적 고정되어 있어 **집중 공략 시 단기 고득점**이 가능한 과목입니다.

### 테마 1 — 공공재 이론

- 비배제성·비경합성의 개념 및 시장실패 논거
- 린달 균형(Lindahl Equilibrium): 개인별 수요곡선 수직합 = 사회 최적
- 무임승차 문제(Free-rider problem)와 정부 개입 정당성
- 사무엘슨 조건: 공공재 최적 공급 조건 `ΣMRSi = MRT`

### 테마 2 — 조세 귀착(Tax Incidence)

- 법적 귀착 vs 경제적 귀착의 구분
- 수요·공급 탄력성에 따른 귀착 비율 계산
- 생산자 부담 비율 공식: `Ed / (Ed + Es)`
- 소비자 부담 비율 공식: `Es / (Ed + Es)`

### 테마 3 — 최적조세 이론

- 램지 규칙(Ramsey Rule): 역탄력성 원칙 — 탄력성이 낮은 재화에 높은 세율
- 수평적 공평성 vs 수직적 공평성
- 사회후생함수와 소득재분배의 상충관계

### 테마 4 — 재정 적자와 국가채무

- 기능적 재정론 vs 건전재정론
- 리카도 동등성 정리(Ricardian Equivalence): 부채=미래 증세 → 소비 불변
- 재정 승수 효과와 구축효과(Crowding-out effect)

### 테마 5 — 공채론

- 공채의 종류: 내국채·외국채, 강제공채·임의공채
- 공채의 전가론 쟁점: 현 세대 vs 미래 세대 부담
- 중앙은행 인수 방식의 위험성(인플레이션 재원조달)

## 세법학개론: 1차 범위 집중 정리

세법학개론 1차는 **기본 구조와 개념 위주**로 출제됩니다. 계산 문제도 나오지만 2차처럼 복잡하지 않습니다.

### 국세기본법 절차

| 절차 | 핵심 내용 |
|------|-----------|
| 납세의무 성립 | 과세요건 충족 시 자동 성립 |
| 납세의무 확정 | 신고납부(소득세·법인세·부가세) vs 부과납부(상속세·증여세) |
| 납세의무 소멸 | 납부·충당·부과제척기간 경과·소멸시효 |
| 부과제척기간 | 일반 5년, 무신고 7년, 사기 10년, 역외탈세 15년 |
| 국세우선권 | 원칙적으로 일반 채권보다 우선; 당해세 우선의 예외 |

### 소득세 1차 과세구조

```
총수입금액
  - 필요경비 (사업소득·기타소득)
= 각 소득금액
→ 종합합산 (이자·배당·사업·근로·연금·기타)
  - 종합소득공제
= 종합소득 과세표준
  × 세율 (6%~45%, 8단계)
= 산출세액
  - 세액공제·세액감면
= 결정세액
```

### 법인세 1차 과세구조

법인세 1차에서는 세무조정 개념과 소득처분의 종류를 정확히 이해하는 것이 핵심입니다.

- **익금산입**: 결산에서 수익으로 인식하지 않았으나 세법상 익금에 해당하는 항목
- **손금불산입**: 결산에서 비용으로 계상했으나 세법상 손금으로 인정하지 않는 항목
- **소득처분**: 유보(사내 유보), 배당, 상여, 기타사외유출, 기타

### 부가가치세 기본 구조

- 사업자 등록, 과세기간(1기: 1~6월, 2기: 7~12월)
- 과세표준 = 공급가액 합계 (부가세 미포함)
- 세액 계산: 매출세액 - 매입세액 = 납부세액
- 영세율(0%) vs 면세(부가세 미과세) 차이

## 회계학개론: 3대 영역 집중 전략

### 재무제표 5종과 상호 연계

| 재무제표 | 핵심 정보 | 시점 |
|---------|-----------|------|
| 재무상태표 | 자산·부채·자본 잔액 | 기말 시점 |
| 포괄손익계산서 | 수익·비용·당기순이익 | 기간 |
| 자본변동표 | 자본 항목의 변동 내역 | 기간 |
| 현금흐름표 | 영업·투자·재무 현금흐름 | 기간 |
| 주석 | 재무제표 본문 보완 설명 | 기말 |

### 재무회계 기초 분개 7유형

1. 자산 취득: (차) 자산 ↑ / (대) 현금 ↓ 또는 부채 ↑
2. 부채 발생: (차) 비용 ↑ / (대) 미지급금 ↑
3. 수익 인식: (차) 현금·매출채권 ↑ / (대) 수익 ↑
4. 감가상각: (차) 감가상각비 ↑ / (대) 감가상각누계액 ↑
5. 대손 인식: (차) 대손상각비 ↑ / (대) 대손충당금 ↑
6. 재고 인식: (차) 매출원가 ↑ / (대) 재고자산 ↓
7. 자본 거래: (차) 현금 ↑ / (대) 자본금·주식발행초과금 ↑

### 원가계산 기초: 세무사 1차 출제 포인트

- 제조원가 3요소: 직접재료비, 직접노무비, 제조간접비
- 기본 원가계산 흐름: 재료비 → 재공품 → 제품 → 매출원가
- 전부원가계산 vs 변동원가계산의 영업이익 차이

## 상법: 회사법 집중 공략

상법은 전체 범위가 넓지만, **회사법(특히 주식회사) 파트가 약 70~80%**를 차지합니다. 나머지 어음·수표법은 기본 개념만 확인하면 됩니다.

### 주식회사 4대 핵심 쟁점

**① 설립**
- 발기설립 vs 모집설립
- 설립 시 현물출자: 검사인 조사 또는 감정인 감정
- 이사·감사 선임 절차

**② 자본**
- 자본금 = 액면가 × 발행주식총수 (원칙)
- 자본충실 원칙: 실질 납입 없는 주식 발행 금지
- 준비금(이익준비금·자본준비금) 적립 의무

**③ 이사회**
- 이사의 선관주의의무·충실의무
- 이사회 결의사항 vs 주주총회 결의사항 구분
- 이사의 자기거래 제한: 이사회 승인 필요

**④ 합병**
- 흡수합병 vs 신설합병
- 합병 절차: 이사회 결의 → 합병계약 → 공고 → 주주총회 특별결의 → 등기
- 반대주주 주식매수청구권

## 민법: 총칙 + 채권법 선택과 집중

민법은 방대하지만 세무사 1차에서는 **민법총칙과 채권법 총론**에 집중하는 것이 정석입니다. 물권법·가족법은 출제 비중이 낮습니다.

### 민법총칙 핵심 5테마

1. **법률행위**: 의사표시의 성립요건, 진의 아닌 의사표시(심리유보), 통정허위표시
2. **대리**: 유권대리·무권대리·표현대리의 구분과 효과
3. **법률행위의 무효·취소**: 무효의 절대성 vs 취소의 소급효
4. **소멸시효**: 일반채권 10년, 상사채권 5년, 단기소멸시효 3년·1년 항목
5. **기간 계산**: 초일불산입 원칙, 말일이 공휴일인 경우 처리

### 채권총론 핵심 테마

- **채무불이행 3종**: 이행지체, 이행불능, 불완전이행
- **손해배상**: 통상손해 + 특별손해(예견가능성 있는 경우)
- **채권자 보호 수단**: 채권자대위권, 채권자취소권(사해행위 취소)
