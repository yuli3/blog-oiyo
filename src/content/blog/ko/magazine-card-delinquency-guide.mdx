## 카드 연체가 시작되면

```
연체 즉시 영향:
- 1일~: 연체 사실 신용정보회사에 등록 (KCB, NICE)
- 5일 이상: 카드사에서 독촉 연락 시작
- 30일 이상: 신용점수 급락
- 90일 이상: 금융 거래 기록에 장기 연체로 등록
```

---

## 연체 직후 해야 할 일

```
1순위: 소액이라도 즉시 일부 납부
→ 연체 기간을 최소화하는 것이 핵심
→ 전액 납부가 어려우면 최소 납입금이라도

2순위: 카드사 고객 센터 연락
→ 분할 납부 협의, 유예 기간 요청
→ 카드사는 돌려받는 것이 목적이므로 협의 가능

3순위: 다른 카드 신규 대출 막기
→ 연체 상태에서 새 대출은 불리한 조건 or 불가
```

---

## 연체 기간별 신용점수 영향

```
1~29일 연체:
→ 소폭 신용점수 하락 (20~50점)
→ 완납 후 단기 회복 가능

30~89일 연체:
→ 신용점수 100~200점 하락
→ 신규 대출 어려워짐

90일 이상 연체:
→ 연체 정보 신용정보원에 등록 (장기 연체)
→ 신규 대출 사실상 불가
→ 채권 추심 기관으로 채권 양도

5년 내 완납 후:
→ 연체 이력 신용 정보에서 삭제
→ 삭제 후 신용점수 회복 가능
```

## 카드사 채무 재조정 신청

```
방법 1: 카드사 직접 협의
→ 고객 센터 전화 → 채무 조정 상담 요청
→ 분할 상환 계획 협의 (이자 감면 포함)

방법 2: 신용회복위원회 (신복위)
→ 1600-5500
→ 여러 금융 기관 채무 통합 조정 가능
→ 이자 전액 감면 + 원금 분할 상환

방법 3: 개인회생 (법원)
→ 채무 규모가 크고 소득 있으면 원금 최대 90% 감면
```

## 불법 채무 추심 대처

```
불법 추심 행위 (금지 사항):
- 야간 (22시~6시) 전화, 방문
- 직장이나 가족에게 알리는 행위
- 폭언, 협박, 공포감 조성
- 반복적인 문자·전화로 괴롭히기

대처:
→ 증거 확보 (녹취, 문자 캡처)
→ 금융감독원 신고: 1332
→ 경찰 신고: 112

합법적 추심은 거부 불가:
→ 변제 의무가 있으면 추심 자체는 합법
→ 방법이 불법인 경우만 신고 대상
```

## 카드 론 vs 리볼빙 연체 차이

```
일시불 카드 연체:
→ 결제일에 전액 미납

리볼빙(분할 결제) 연체:
→ 최소 결제금액도 미납 시 연체

카드 론(대출) 연체:
→ 대출 이자 + 원금 미납

→ 세 가지 모두 연체이지만
   카드 론 연체가 이자율 높아 피해 더 큼
```

## 신용점수 회복 로드맵

```
0단계: 모든 연체 완납
→ 연체 정보가 즉시 삭제되지는 않지만
   추가 하락 막기

1단계: 소액 신용카드 사용 + 전액 납부
→ 신용 건전성 회복 신호 만들기

2단계: 통신비, 공과금 자동이체 등록
→ 비금융 납부 이력도 신용점수에 반영

3단계: 연체 이력 삭제 시점 확인
→ 완납 후 최대 5년 내 삭제
→ KCB·NICE 각각 삭제 시점 다를 수 있음

4단계: 신용점수 꾸준한 모니터링
→ 토스, 카카오페이, 뱅크샐러드에서 무료 조회
```

## 장기 연체 기록 삭제 요청

```
조건:
- 완납 후 1년 이상 경과
- 또는 파산 면책 결정 후

신청:
→ KCB (한국신용평가) 1588-2580
→ NICE 평가정보 1600-1522
→ 각 금융기관 신용정보 삭제 요청

주의:
→ 삭제 조건 충족 전 요청은 불가
→ 미완납 상태에서는 삭제 불가
```

## 자주 묻는 질문

**Q. 카드 연체 중에 새 카드 발급이 안 되나요?**
A. 연체 중에는 대부분의 카드사에서 신규 발급을 거절합니다. 완납 후 신용점수가 회복되면 발급 가능합니다.

**Q. 가족이나 직장에 연락이 와도 막을 수 있나요?**
A. 법적으로 정당한 채무자 확인 목적 외에 제3자(가족·직장)에게 채무를 알리는 행위는 금지되어 있습니다. 위반 시 금융감독원 1332에 신고하세요.

**Q. 연체 이력이 신용등급에 얼마나 오래 남나요?**
A. 완납 후 최대 5년까지 기록이 남을 수 있습니다. 단, 미납액 규모와 연체 기간에 따라 삭제 시점이 달라집니다.

**Q. 신복위로 채무조정하면 카드 연체 기록이 사라지나요?**
A. 채무조정 이력 자체는 기록에 남지만, 정상 상환 후 신용 회복이 가능합니다. 즉시 삭제는 아닙니다.
