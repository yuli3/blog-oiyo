## 형벌의 종류

```
사형:
생명 박탈. 사형제 존폐 논란.
한국: 법정형으로 존재, 집행은 1997년 이후 없음

징역:
자유 박탈 + 노역 강제
유기(1개월~30년), 무기

금고:
자유 박탈 (노역 없음)
정치범 등에 주로 적용

구류:
1일~30일 자유 박탈
경미한 범죄

벌금:
5만 원 이상 재산 박탈
미납 시 노역장 유치

과료:
2천 원~5만 원 미만

몰수:
범죄 관련 물건 박탈 (부가형)

자격상실·정지:
공민권·직업 자격 박탈·정지
```

## 집행유예

```
집행유예:
유죄 선고 + 형 집행 잠시 유예
일정 기간 재범 없으면 형 면제

요건:
① 3년 이하 징역·금고 또는 500만 원 이하 벌금
② 정상 참작 여지
③ 집행유예 결격 사유 없음
   (집행유예 기간 중 범죄, 3년 내 금고 이상 실형 등)

유예 기간:
1년 이상 5년 이하

결격 사유:
금고 이상의 형을 선고받아 집행 종료 후 3년 미경과
집행유예 기간 중 또 금고 이상 선고

취소:
유예 기간 중 재범 → 집행유예 취소
→ 원래 형 집행
```

## 가석방

```
가석방:
수형자 선행·개전 인정 시 형기 전 석방

요건:
징역·금고형 수형자
형기의 1/3 경과 (무기=10년)
행형 성적 양호

가석방 기간:
석방일부터 잔여 형기 동안 (무기=10년)

가석방 취소:
가석방 기간 중 범죄 또는 조건 위반
→ 가석방 취소 + 잔여 형기 집행
```

## 보안처분

```
보안처분:
형벌 보충/대체 수단
장래 재범 위험 방지

치료감호:
정신질환·마약 중독 범죄자
치료 목적 구금

보호관찰:
준수 사항 부과 + 사회 내 처우
집행유예·가석방 시 병과 가능

사회봉사명령·수강명령:
사회 내 처우
주로 집행유예와 함께

전자감독 (전자발찌):
위치 추적
성범죄자·가정폭력 등

수강명령:
교육 이수 명령
음주운전, 가정폭력 등
```

## 핵심 개념 카드

**집행유예 요건** ★★★★★
: 3년 이하 징역·금고 or 500만 원 이하 벌금 + 정상 참작.
*암기 포인트: 집행유예=3년이하+정상참작*

**가석방 기준** ★★★★★
: 형기 1/3 경과 (무기=10년). 선행+개전.
*암기 포인트: 가석방=1/3경과*

**보안처분 종류** ★★★★☆
: 치료감호·보호관찰·사회봉사·수강명령·전자발찌.
*암기 포인트: 치보사수전*

## 실전 퀴즈

**Q. 집행유예와 가석방의 차이는?**
> 집행유예: 판결 시 형 선고+집행 미룸. 유예 기간 무사 통과 시 형 면제. 재범 시 원래 형 집행. 가석방: 이미 수용 중인 상태에서 조기 석방. 잔여 기간은 사회 내 집행 간주. 재범 시 잔여 형기 집행.

**Q. 보호관찰이 형벌이 아닌 이유는?**
> 보호관찰은 보안처분(형사 정책적 조치). 형벌(응보·억제 목적)이 아닌 재사회화·위험 방지 목적. 형사미성년자·가석방자·집행유예자에게도 부과 가능. 형법상 형벌 목록에 없음.
