## 테니스, 점수만 알면 끝

테니스에서 가장 헷갈리는 건 독특한 점수 체계다. 그 구조만 잡으면 경기가 한눈에 들어온다.

---

## 점수 체계 — 포인트 → 게임 → 세트 → 매치

```
포인트(한 점): 0(러브) → 15 → 30 → 40 → 게임 획득
게임: 4포인트를 먼저, 단 2점 차로 이겨야 게임 획득
세트: 6게임을 먼저, 2게임 차로 → 세트 획득(6-4 등)
매치: 3세트 중 2세트(또는 5세트 중 3세트) 먼저 이기면 승리
```

| 포인트 수 | 콜 |
|---------|-----|
| 0 | 러브(Love) |
| 1 | 15 |
| 2 | 30 |
| 3 | 40 |
| 동점 40-40 | 듀스(Deuce) |

---

## 듀스와 어드밴티지

```
40-40(듀스): 2점을 연속 더 내야 게임 승
- 듀스 후 1점 = 어드밴티지(Ad)
- 어드밴티지에서 1점 더 = 게임 / 상대가 따면 = 다시 듀스
```

---

## 서브 규칙

```
- 대각선 방향 서비스박스로 넣어야 유효
- 1차 폴트 → 2차 서브 기회 / 2차도 실패 = 더블폴트(상대 득점)
- 풋폴트: 서브 시 베이스라인을 밟으면 폴트
- 네트 맞고 들어가면(서브) = 렛(Let), 다시 서브
```

---

## 타이브레이크

```
세트에서 6-6이 되면 타이브레이크:
- 7포인트를 먼저, 2점 차로 이긴 쪽이 세트 획득(7-6)
- 점수는 1, 2, 3…으로 셈
```

---

## 코트와 인/아웃

```
단식: 좁은 사이드라인 안 / 복식: 넓은 더블라인까지
- 라인 위(터치)는 '인'
- 공이 코트 밖에 떨어지면 '아웃'
- 한 번만 바운드 허용(투바운드 전에 쳐야)
```

---

## 핵심 요약

1. 점수: 0→15→30→40→게임, 2점 차로 이겨야 게임.
2. 6게임(2게임 차)으로 세트, 보통 2/3세트로 매치 승부.
3. 40-40 듀스에선 연속 2점이 필요(어드밴티지).
4. 서브는 대각선 박스로, 더블폴트는 상대 득점.
5. 6-6이면 타이브레이크(7점, 2점 차).

> 세부 규칙은 국제테니스연맹(ITF) 규정을 기준으로 하며, 대회별로 세트 수 등이 다를 수 있다.
