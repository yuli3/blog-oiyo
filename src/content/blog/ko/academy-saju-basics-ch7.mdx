## 육친론이란?

**육친론(六親論)**은 십신(十神)의 각 성분이 실제 인물관계에서 **부모·형제·배우자·자녀** 등 어떤 가족을 상징하는지를 분석하는 이론입니다.

사주에서 특정 십신이 강하거나 약하면, 그에 해당하는 가족 관계에서 특정 패턴이 나타납니다.

---

## 십신과 육친 대응표

### 남성 사주의 육친

| 십신 | 남성에게 상징하는 대상 |
|---|---|
| 비견·겁재 | 형제·동료·경쟁자 |
| 식신·상관 | 자녀·창작물·제자 |
| 편재 | 아버지·애인·이성 |
| 정재 | 아내·재물 |
| 편관 | 자녀(아들)·압박·상사 |
| 정관 | 자녀(딸)·명예·직장 |
| 편인 | 계모·이모·특별한 어른 |
| 정인 | 어머니·학문·은사 |

### 여성 사주의 육친

| 십신 | 여성에게 상징하는 대상 |
|---|---|
| 비견·겁재 | 자매·동료·경쟁자 |
| 식신·상관 | 자녀·창작물 |
| 편재 | 아버지·시어머니 |
| 정재 | 아버지·재물 |
| 편관 | 남편후보·애인 |
| 정관 | 남편·직장·명예 |
| 편인 | 계모·특별한 어른 |
| 정인 | 어머니·학문 |

<Callout type="note">
**유의사항**: 육친 대응은 전통 명리학의 관점이며, 현대적 가족 구조에 그대로 적용하기보다 심리적 패턴으로 이해하는 것이 더 유용합니다.
</Callout>

## 부모와의 관계 분석

### 어머니 — 정인(正印)

**정인이 강하면**: 어머니의 사랑과 보살핌이 풍부. 학문적 지원을 받는 환경. 안정된 가정에서 성장.

**정인이 약하거나 없으면**: 어머니와의 거리감, 일찍 독립하는 경우가 많음. 혼자 배움을 개척해야 하는 상황.

**정인이 충극을 받으면**: 어머니의 건강 문제 또는 관계에서 갈등이 있을 수 있음.

**정인 과다**: 지나친 의존성, 어머니에게서 독립하기 어려운 경우.

### 아버지 — 편재(偏財) 또는 정재(正財)

아버지는 남녀 모두 **재성(財星)**으로 봅니다.

**재성이 강하면**: 아버지가 사회적으로 활발하고 사업적 기질. 경제적 지원이 풍부.

**재성이 약하거나 없으면**: 아버지와의 거리감, 아버지의 부재 또는 경제적 어려움.

---

## 배우자와의 관계 분석

### 남성의 배우자 — 정재(正財)

**정재가 강하고 좋으면**: 안정적인 배우자, 경제적으로 도움이 되는 결혼, 현실적인 파트너.

**정재가 약하면**: 결혼이 늦어지거나 배우자와 재물 관련 갈등.

**정재가 충극을 받으면**: 결혼 생활에서 갈등, 이혼 가능성 주의.

**정재가 여러 개**: 여러 관계를 동시에 진행하는 성향 or 배우자가 바뀔 수 있음.

### 여성의 배우자 — 정관(正官) 또는 편관(偏官)

**정관이 있고 강하면**: 사회적으로 성공한 안정적인 배우자. 명예 있는 결혼.

**편관만 있으면**: 강하고 카리스마 있는 남성에게 끌리는 성향.

**관성이 없으면**: 결혼에 무관심하거나 독립적인 삶을 선호.

**관성 과다**: 남성 관계가 복잡하거나 결혼 생활에서 압박을 많이 느낌.

<Callout type="tip">
**현대적 해석**: 여성의 관성이 없다고 결혼을 못 하는 것이 아닙니다. 현대 명리학에서는 독립적이고 자기주도적인 삶의 패턴으로 해석합니다.
</Callout>

## 자녀와의 관계 분석

### 자녀 — 식신·상관 (남성은 관성도 포함)

**식상이 강하면**: 자녀와의 관계가 풍성하고 창의적. 자녀를 잘 키우는 능력.

**식상이 없거나 약하면**: 자녀 관계에서 거리감, 자녀 양육에 어려움을 느끼는 경우.

**식상이 충극을 받으면**: 자녀의 건강이나 관계에서 어려움이 있을 수 있음.

### 형제·동료 — 비견·겁재

**비겁이 많으면**: 형제자매가 많거나, 경쟁자가 많은 환경. 독립심이 강하고 자기 영역을 지키려 함.

**비겁이 없으면**: 외동이거나 형제와 거리가 있는 경우. 독립적이지만 고독할 수 있음.

## 결혼 시기 판단

결혼 적기는 다음 조건이 겹칠 때입니다:

**남성의 경우**:
- 재성(財星) 대운 or 세운
- 관성·인성 대운 (안정적 환경)
- 재성 지지와 합(合)이 이루어지는 해

**여성의 경우**:
- 관성(官星) 대운 or 세운
- 관성 지지와 합이 이루어지는 해
- 비겁이 억제되고 관성이 활성화되는 시기

<Callout type="note">
**중요**: 사주는 결혼의 *방향성*을 제시하지, *반드시 그렇게 된다*는 것을 의미하지 않습니다. 개인의 의지와 노력이 운명을 바꿉니다.
</Callout>

## 일주(日柱)로 보는 배우자 특성

일주는 '나 자신'을 나타내지만, 일지(日支)는 **배우자가 앉은 자리**이기도 합니다.

| 일지 | 배우자 특성 |
|---|---|
| 자(子) | 영리하고 적응력 강한 배우자 |
| 축(丑) | 성실하고 인내심 강한 배우자 |
| 인(寅) | 리더십 있고 독립적인 배우자 |
| 묘(卯) | 예술적 감성이 풍부한 배우자 |
| 진(辰) | 카리스마 있고 독특한 배우자 |
| 사(巳) | 지혜롭고 계획적인 배우자 |
| 오(午) | 열정적이고 자유로운 배우자 |
| 미(未) | 예술가 기질, 섬세한 배우자 |
| 신(申) | 지략이 뛰어나고 다재다능한 배우자 |
| 유(酉) | 세련되고 완벽주의적인 배우자 |
| 술(戌) | 의리 있고 독립적인 배우자 |
| 해(亥) | 자유롭고 너그러운 배우자 |

## 궁합(宮合) 기초

사주 궁합은 두 사람의 사주를 종합적으로 비교합니다.

**기본 궁합 체크리스트**:

1. **오행 보완 관계**: 두 사람의 용신이 서로 희신 관계이면 최고
2. **일간 합(合)**: 갑기합, 을경합 등 일간이 합이 되는 조합 유리
3. **충(沖) 관계**: 일지끼리 충이 되면 관계 갈등이 잦을 수 있음
4. **오행 조화**: 한쪽에 부족한 오행을 다른 쪽이 채워주는 관계

<Callout type="tip">
**궁합의 진실**: 오행이나 사주가 잘 맞지 않아도 서로 이해하고 노력하면 좋은 관계를 만들 수 있습니다. 궁합은 참고 도구이지 절대 기준이 아닙니다.
</Callout>
