## SQLP의 위치

SQLP는 SQL 작성 수준을 넘어 데이터 모델, 옵티마이저, 실행계획, 튜닝 사고를 묻는 전문가형 자격입니다. SQLD가 SQL 기본기를 확인한다면, SQLP는 성능 문제 진단까지 봅니다.

시험 일정, 응시자격, 합격 기준, 과목 구성은 바뀔 수 있으므로 단정하지 않습니다. 최신 정보는 [DATAQ 공식 홈페이지](https://www.dataq.or.kr) 등 시행처 공식 홈페이지에서 확인하세요. 확인일: 2026-06.

### SQLD와 SQLP 비교

| 구분 | 중심 역량 | 학습 난도 |
|------|-----------|-----------|
| SQLD | SQL 기본·활용 | 입문~중급 |
| SQLP | 모델링·튜닝·전문 SQL | 중급~심화 |
| 공통 | 관계형 DB 이해 | 기초 필수 |

## 핵심 요약

SQLP는 SQL 문법보다 데이터 구조와 실행 원리를 함께 설명하는 시험으로 접근합니다.
