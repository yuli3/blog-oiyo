## 국민내일배움카드란?

취업·창업·직무 역량 강화를 위해 직업 훈련비를 국가가 지원하는 카드형 바우처입니다. 실업자, 재직자, 자영업자 모두 신청할 수 있습니다.

---

## 지원 금액

```
기본 지원 한도:
- 1인당 300만원 (5년 유효)
- 일부 대상 500만원:
  실업자, 영세 자영업자, 기간제·파견·단시간 근로자,
  육아휴직자, 50세 이상 근로자, 이직 예정자 등

자부담 비율:
- 일반 재직자: 훈련비의 15~55% 본인 부담
- 우대 대상 (실업자·기초수급자·차상위 등): 자부담 0~10%
```

---

## 신청 자격

### 가능한 대상

```
1. 실업자 (취업 준비 중)
2. 재직자 (기업 규모와 무관)
3. 자영업자
4. 특수 형태 근로자 (프리랜서, 학습지 교사, 배달원 등)
5. 농업인
6. 군 전역 예정자
7. 육아휴직자
```

### 신청 불가 대상

```
- 현재 대학교 재학생 (졸업 예정자 가능)
- 고등학교 재학생
- 연 매출 1억5천만원 초과 자영업자
- 월 임금 300만원 이상 대기업 재직자 (일부 훈련 제외)
```

## 발급 신청 방법

### 온라인 신청

```
고용24 홈페이지: www.work24.go.kr
→ 회원가입 → 국민내일배움카드 신청
→ 심사 후 카드 발급 (약 5~7 영업일)

HRD-Net: www.hrd.go.kr
→ 훈련 정보 검색 + 카드 신청 가능
```

### 오프라인 신청

```
가까운 고용센터(고용복지플러스센터) 방문
→ 상담사 면담 후 카드 발급 신청
→ 실업자의 경우 현장 상담 권장
```

## 훈련 과정 선택 방법

### 과정 검색

```
HRD-Net (www.hrd.go.kr):
→ 지역·직종·기간·비용 필터 검색
→ 훈련 기관 평가 등급 확인 (A~E 등급)
→ 수강 후기, 취업률 확인
```

### 인기 훈련 분야

```
IT·개발:
- 자바(Java), 파이썬, 클라우드 (AWS, Azure)
- 데이터 분석, 인공지능

자격증:
- 요양보호사, 사회복지사
- 전기기사, 산업안전기사
- 지게차, 굴삭기 (건설 기계)
- 조리기능사 (한식·양식·중식)

사무:
- 전산회계, ERP, SAP
- 사무 자동화, 컴퓨터 활용 능력

뷰티·인테리어:
- 헤어, 피부미용
- 인테리어 CAD
```

## 자부담 비율 상세

```
훈련비 자부담 = 훈련비 × 자부담 비율

실업자 (취업 준비):
- 0~20% (우선지원 대상 기업 피보험자 이직 후 등)

재직자:
- 대기업 재직자: 55%
- 중소기업 재직자: 15~25%
- 기간제·파견 등: 0%

기초수급자·차상위:
- 0% (전액 지원)
→ 문화누리카드와 함께 '소득 취약계층 지원' 범주
```

## 훈련 중 수당

### 실업자 훈련 수당

```
훈련수당 (구직급여 미수령 실업자):
- 훈련 참여일 기준 일정액 지급
- 식비 지원: 약 5,760원/일

구직급여(실업급여) 수급 중:
- 훈련 참여 시 구직급여 연장 가능
→ 수급 기간 종료 후에도 훈련 완료 시까지 연장
```

## 카드 사용 흐름

```
1. 고용24에서 훈련 과정 선택 및 수강 신청
2. 훈련 기관에 카드 번호 제출 (온·오프라인)
3. 자부담 금액만 본인 결제
4. 훈련 수료 후 지원금 자동 처리
```

> 카드로 직접 결제하는 것이 아니라 훈련비 지원이 기관에 직접 지급되는 구조입니다.

---

## 유효 기간 및 잔액 관리

```
카드 유효 기간: 발급일로부터 5년
지원 한도: 300만원 or 500만원 (5년 내 사용)
→ 5년 내 미사용 잔액은 소멸
→ 훈련 완료 후 다시 수강 신청 가능 (한도 소진 전까지)
```

## 내일배움카드 vs 국가기간전략훈련

```
내일배움카드:
- 다양한 분야, 수강생이 자유롭게 선택
- 자부담 있음 (실업자는 낮음)

국가기간전략직종훈련:
- 국가 필요 인력 양성 과정 (용접, 전기, IT 등)
- 자부담 0% (전액 무료)
- 조건: 실업자·이직 예정자 중심

→ 두 제도를 구분해 더 유리한 쪽 선택
```

## 자주 묻는 질문

**Q. 직장을 다니면서도 신청할 수 있나요?**
A. 재직자도 신청 가능합니다. 다만 대기업 재직자(월 300만원 이상)는 일부 훈련 과정이 제한될 수 있고 자부담 비율이 높습니다.

**Q. 요양보호사 교육도 내일배움카드로 들을 수 있나요?**
A. HRD-Net에서 요양보호사 훈련 과정을 검색하면 지원되는 기관을 찾을 수 있습니다. 기초수급자·차상위는 자부담 없이 무료로 수강 가능합니다.

**Q. 카드 발급 후 바로 사용할 수 있나요?**
A. 발급 후 고용24에서 원하는 훈련 과정을 선택해 신청해야 합니다. 카드 자체가 결제 수단이 아닌 바우처 식별 수단입니다.

**Q. 훈련을 중도 포기하면 어떻게 되나요?**
A. 지원금이 회수될 수 있고, 이후 동일 과정 재수강이 제한될 수 있습니다. 출석률(80% 이상) 미달 시에도 수료 인정이 안 됩니다.
