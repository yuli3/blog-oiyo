# 풀 MBTI 테스트 (Likert 척도 버전)

시중의 많은 MBTI 테스트는 "A와 B 중 하나를 선택하세요"라는 강제 이분법 방식입니다. 하지만 현실에서 사람은 완전한 E도, 완전한 I도 아닙니다. E 60%, I 40%처럼 연속적인 스펙트럼 위에 있습니다.

이 테스트는 **5점 Likert 척도** (전혀 아님 → 매우 그렇다)를 사용해 각 문항에 대한 자신의 동의 정도를 표현합니다. 결과는 단순한 4글자 유형이 아닌 각 차원의 비율(%)로 표시됩니다.

## MBTI의 4가지 차원

| 차원 | 의미 | 극단 예시 |
|---|---|---|
| **E / I** | 에너지의 방향 | E: 파티에서 충전 ↔ I: 혼자서 충전 |
| **S / N** | 정보 처리 방식 | S: 사실과 경험 ↔ N: 패턴과 가능성 |
| **T / F** | 의사결정 기준 | T: 논리와 원칙 ↔ F: 가치와 감정 |
| **J / P** | 생활 방식 | J: 계획과 마감 ↔ P: 유연성과 즉흥 |

MBTI는 Isabel Briggs Myers와 Katherine Cook Briggs가 Carl Jung의 심리 유형론(1921)을 바탕으로 개발한 성격 도구입니다. 1962년 첫 출판 이후 전 세계에서 연간 약 1.5-2백만 명이 직업 상담, 팀 빌딩, 자기 개발에 활용하고 있습니다.

## 결과 해석 가이드

### 비율로 읽는 MBTI

예를 들어 E 70% / I 30%라면 뚜렷한 외향형이지만, E 52% / I 48%라면 양향형(Ambivert)에 가깝습니다. 이 미묘한 차이가 실제 삶에서 크게 다르게 나타납니다.

### 16가지 유형 특성 요약

| 유형 | 핵심 키워드 |
|---|---|
| INTJ | 전략적 독립 / 비전 |
| INTP | 논리적 탐구 / 이론 |
| INFJ | 통찰 / 의미 추구 |
| INFP | 이상주의 / 진정성 |
| ENTJ | 지휘 / 결단력 |
| ENTP | 아이디어 / 논쟁 |
| ENFJ | 영향력 / 성장 지원 |
| ENFP | 열정 / 가능성 |
| ISTJ | 체계 / 책임감 |
| ISFJ | 돌봄 / 헌신 |
| ISTP | 실용 / 분석 |
| ISFP | 감성 / 현재 |
| ESTJ | 실행 / 조직 |
| ESFJ | 조화 / 소속감 |
| ESTP | 현장 / 즉각 |
| ESFP | 활력 / 표현 |

<Callout type="tip">
**MBTI는 도구입니다, 정체성이 아닙니다.** 유형이 나의 가능성을 제한하지 않습니다. "나는 INTJ니까 감정 표현을 못 해"가 아니라, "INTJ 성향이 강하지만 감정 표현을 연습하고 있다"가 더 건강한 활용법입니다.
</Callout>

이 테스트는 Myers-Briggs Type Indicator의 개념에 기반한 자기 이해 도구입니다. 공식 MBTI 인증 도구가 아니며, 임상적 진단 목적이 아닙니다.
