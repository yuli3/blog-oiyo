## 실기는 손으로 설명할 수 있어야 합니다

실기 대비는 필기 개념을 짧은 답안으로 바꾸는 훈련입니다. SQL 결과를 계산하고, 코드 실행 값을 추적하고, 개발·DB·시스템 관리 개념을 정확한 용어로 설명해야 합니다. 실기 형식, 배점, 합격기준은 회차별 공고에 따라 달라질 수 있으므로 [Q-net](https://www.q-net.or.kr)과 시행처 공식 홈페이지에서 확인하세요. 확인일: 2026-06.

### 실기 연습표

| 유형 | 연습 방법 |
|---|---|
| SQL | 테이블을 직접 그려 결과 확인 |
| 코드 | 변수 값을 줄 단위로 추적 |
| 개념 | 키워드와 정의를 한 문장으로 정리 |
| 절차 | 원인, 조치, 결과 순서로 답안 작성 |

실기에서는 “대충 아는 개념”이 점수로 이어지기 어렵습니다. 정규화라면 목적과 이상 현상을 말하고, 트랜잭션이라면 ACID를 설명하며, 코드라면 마지막 출력값까지 확인해야 합니다. 오답노트는 틀린 이유를 문법, 계산, 용어, 문제 해석으로 나누어 적으세요.

## 핵심 요약

- 실기는 필기 지식을 짧고 정확한 답안으로 바꾸는 시험입니다.
- SQL과 코드는 손으로 추적하는 연습이 필요합니다.
- 형식·배점·합격기준은 공식 공고에서 최종 확인합니다.
