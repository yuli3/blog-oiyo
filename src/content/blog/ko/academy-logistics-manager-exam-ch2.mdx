## 운송의 역할과 중요성

```
운송(Transportation)이란:
→ 화물을 출발지에서 목적지까지 이동시키는 물류 활동
→ 물류 비용 중 가장 큰 비중 차지 (40~50%)

운송의 효용:
- 장소 효용 창출: 저렴한 곳에서 생산 → 비싼 곳에 공급
- 시간 효용 보완: 운송 시간 단축으로 재고 감소

운송 선택 기준:
1. 비용 (운임)
2. 속도 (운송 시간)
3. 신뢰성 (정시 도착률)
4. 안전성 (화물 손상률)
5. 접근성 (서비스 지역)
```

## 5대 운송 수단 비교

```
1. 도로 운송 (Road):
장점: 접근성 최고, door-to-door 가능, 소량 배송 유리
단점: 대량 운송 한계, 교통 체증, 환경 오염
적합: 중단거리, 소량, 혼재 화물

2. 철도 운송 (Rail):
장점: 대량·장거리 저렴, 정시성 우수, 에너지 효율
단점: 노선 고정, 터미널 간 운송만 가능 (단거리 비효율)
적합: 중·장거리 대량 화물

3. 해상 운송 (Sea):
장점: 대량·장거리 최저 운임, 중량화물 운반 가능
단점: 속도 느림, 항구 접근 필요, 날씨 영향
적합: 국제 무역, 대량 원자재·컨테이너

4. 항공 운송 (Air):
장점: 속도 최고, 장거리에도 신속
단점: 운임 최고, 무게·부피 제한
적합: 고가품, 긴급화물, 신선 식품

5. 파이프라인 운송 (Pipeline):
장점: 대량 연속 운송, 운영비 저렴, 안전성 높음
단점: 초기 설비비 高, 특정 품목만 가능
적합: 원유, 가스, 화학물질
```

## 운송 수단 선택 기준 매트릭스

```
수단 비교표:

항목     | 도로 | 철도 | 해운 | 항공 | 파이프
--------|------|------|------|------|------
비용     | 중   | 저   | 최저 | 최고 | 저
속도     | 중   | 중   | 저   | 최고 | 저
접근성   | 최고 | 중   | 저   | 중   | 저
신뢰성   | 중   | 고   | 중   | 고   | 최고
대량운송 | 중   | 고   | 최고 | 저   | 고
```

## 운임 (Freight) 체계

```
운임의 종류:

1. 중량 운임 (Weight Rate):
→ 화물 무게 기준 운임 부과

2. 용적 운임 (Measurement Rate):
→ 화물 부피(체적) 기준 운임 부과

3. 종가 운임 (Ad Valorem Rate):
→ 화물 가격 기준 운임 부과 (고가품)

4. 품목별 운임 (Commodity Rate):
→ 특정 품목에 적용하는 특별 운임

중량 vs 용적 계산:
→ 운임 톤 = max(실제 중량, 용적 중량)
→ 용적 중량 = 부피(cm³) / 6000 (kg)
→ 더 큰 값으로 운임 적용 (운임 부과 기준)
```

## 복합 운송 (Multimodal Transport)

```
복합 운송의 정의:
→ 두 가지 이상의 운송 수단을 결합하여
  단일 운송 계약으로 화물 운반

특징:
→ 단일 운송인 책임 (복합 운송인)
→ 단일 운임 청구
→ 서류 단일화 (복합 운송 증권)

주요 복합 운송 형태:
1. 피기백 (Piggyback): 도로 + 철도 (트레일러를 열차에 탑재)
2. 피시백 (Fishyback): 도로 + 해운 (트레일러를 선박에 탑재)
3. 버디백 (Birdiback): 도로 + 항공 (트레일러를 항공기에 탑재)
4. 랜드브리지 (Land Bridge): 해상 + 육상 + 해상 (대륙 횡단)
```

## 컨테이너 운송

```
컨테이너의 종류:
- Dry Container: 일반 화물용 (20ft, 40ft)
- Reefer Container: 냉동·냉장 화물
- Open Top Container: 높이 초과 화물
- Tank Container: 액체·가스 화물
- Flat Rack Container: 초중량 화물

20피트 컨테이너: 1 TEU (Twenty-foot Equivalent Unit)
40피트 컨테이너: 2 TEU

운임 단위: TEU 당 운임
→ 해운 물동량 측정 단위도 TEU 사용

컨테이너 관련 비용:
- Demurrage: 컨테이너 반납 지연 비용
- Detention: 컨테이너 장기 사용 비용
```

## 운송 계약과 운송인 책임

```
운송 계약 유형:
1. 개품 운송 계약: 화물 단위로 계약
2. 용선 계약: 선박 전체 또는 일부 용선 (해운)
   - 항해 용선: 특정 항해 단위 계약
   - 기간 용선: 기간 단위 계약

운송인의 책임:
- 과실책임주의: 운송인의 주의 의무 위반 시 책임
- 무과실책임주의: 과실 여부 무관 배상

면책 사유:
- 불가항력 (천재지변)
- 화물 고유의 하자
- 포장 불량 (화주 귀책)
- 전쟁, 공공 적의 행위
```

## 핵심 암기 포인트

```
시험 빈출:

- 운송 비용 순서: 도로 > 철도 > 해운 (국내 비교)
- 운임 톤: max(중량, 용적 중량) 적용
- 피기백: 도로 + 철도
- TEU: 20피트 컨테이너 1개 단위
- Demurrage: 컨테이너 반납 지연 비용
- 복합 운송: 단일 운송인 책임 + 단일 운임
```

## 자주 묻는 질문

**Q. 도로와 철도 운임 비교가 시험에 자주 나오나요?**
A. 네, 운송 수단별 특성 비교는 물류관리사 단골 출제 유형입니다. 속도·비용·접근성·신뢰성을 각 수단별로 비교 정리해두세요.

**Q. 컨테이너 관련 용어는 얼마나 알아야 하나요?**
A. TEU, Demurrage, Detention, 컨테이너 종류는 기본 암기 필수입니다. 국제물류론 과목에서도 연계 출제됩니다.
