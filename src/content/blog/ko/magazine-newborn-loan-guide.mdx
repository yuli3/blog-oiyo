## 신생아 특례 대출이란?

2024년 출산 가구의 주거 부담을 낮추기 위해 신설된 저금리 정책 대출입니다. 구입 자금 대출과 전세 자금 대출 두 가지로 운영됩니다.

---

## 핵심 특징

```
- 출산 후 2년 이내 신청 가능
- 시중 금리 대비 훨씬 낮은 특례 금리 적용
- 기존 대출도 대환(전환) 신청 가능
- 추가 출산 시 금리 추가 인하 혜택
```

---

## 신생아 특례 구입 자금 대출

### 자격 조건

```
대출 신청일 기준:
- 2023년 1월 1일 이후 출생한 자녀 보유
- 자녀 출생일로부터 2년 이내 신청
- 무주택자 (1주택자도 대환 목적 가능)
- 부부 합산 연 소득: 1억3천만원 이하
- 순자산 5억600만원 이하
```

### 대출 한도·금리

```
대출 한도: 최대 5억원
주택 가격: 9억원 이하 주택

금리 (2024년 기준):
- 소득 8,500만원 이하: 연 1.6~2.7%
- 소득 8,500만원~1억3천만원: 연 2.7~3.3%

추가 혜택:
- 추가 출산 1명당 0.2% 금리 인하
- 금리 유지 기간: 기본 5년 (추가 출산 시 연장)
```

## 신생아 특례 전세 자금 대출

### 자격 조건

```
- 2023년 1월 1일 이후 출생 자녀 보유
- 자녀 출생일로부터 2년 이내 신청
- 무주택 세대구성원
- 부부 합산 연 소득: 1억3천만원 이하
- 순자산 3억4천500만원 이하
```

### 대출 한도·금리

```
대출 한도: 최대 3억원
전세 보증금: 수도권 5억원, 지방 4억원 이하

금리 (2024년 기준):
- 소득 7,500만원 이하: 연 1.1~2.3%
- 소득 7,500만원~1억3천만원: 연 2.3~3.0%

추가 출산 시:
- 1명당 0.2% 금리 인하
- 유지 기간 연장
```

---

## 기존 대출 대환 신청

```
2024년부터 기존 주택 대출도 신생아 특례 대출로 대환 가능:

조건:
- 기존 주택 구입 자금 대출 보유
- 신생아 특례 자격 충족
- 주택 가격 9억원 이하

→ 기존에 높은 금리 대출을 보유한 출산 가구에 큰 혜택
→ 중도 상환 수수료 면제 여부 확인 필요
```

---

## 신청 방법

### 신청 기관

```
- 기금e든든 홈페이지: enhuf.molit.go.kr
- 은행 창구: 우리은행, 신한은행, KB국민은행, 하나은행, NH농협은행
  (주택도시기금 취급 은행)

신청 흐름:
1단계: 기금e든든에서 사전 자격 확인
2단계: 은행 방문 상담 예약
3단계: 서류 제출 (소득·자산 증빙)
4단계: 심사 후 대출 실행
```

### 주요 서류

```
- 주민등록등본 (세대원 포함)
- 가족관계증명서 (출생 자녀 확인)
- 소득 증빙 (근로소득원천징수영수증, 사업소득 확인서 등)
- 건강보험료 납부 확인서
- 매매 계약서 or 전세 계약서
- 등기사항전부증명서
```

## 구입 vs 전세 대출 비교

| 항목 | 구입 자금 대출 | 전세 자금 대출 |
|------|-------------|-------------|
| **최대 한도** | 5억원 | 3억원 |
| **주택 조건** | 9억원 이하 | 수도권 5억 이하 |
| **금리 시작** | 연 1.6% | 연 1.1% |
| **소득 한도** | 1억3천만원 | 1억3천만원 |
| **자산 한도** | 5억600만원 | 3억4,500만원 |

## 다른 출산 혜택과 조합

```
신생아 특례 대출 + 다른 출산 혜택 동시 활용 가능:

1. 부모급여: 0~1세 월 100만원 (아이와 무관, 별개 급여)
2. 출산장려금: 지자체별 100~500만원
3. 첫만남이용권: 출생 시 200만원 (바우처)
4. 아동수당: 8세까지 월 10만원

→ 출산 시 여러 혜택을 조합해 최대한 활용
```

## 주의사항

```
1. 소득 계산 기준:
   → 전년도 소득 기준 적용 (대출 신청 연도 직전 연도)
   → 배우자 소득 합산

2. 금리 유지 기간 이후:
   → 특례 금리 종료 후 시장 금리로 전환될 수 있음
   → 금리 변동 위험 대비 필요

3. 자녀 기준:
   → 입양 자녀도 해당
   → 쌍둥이는 1회 출산이지만 추가 출산 금리 인하 혜택에 포함

4. 주택 매각 시:
   → 대출 조기 상환 조건 확인 (잔여 기간 패널티 여부)
```

## 자주 묻는 질문

**Q. 이미 집이 있는데 신청할 수 있나요?**
A. 기존 1주택자도 신생아 특례 대출로 '대환' 목적으로는 신청 가능합니다. 새 주택 구입 목적이라면 무주택자이어야 합니다.

**Q. 임신 중에도 신청할 수 있나요?**
A. 대출 신청 당시 출생한 자녀가 있어야 합니다. 출생 전 임신 중에는 신청이 어렵습니다.

**Q. 소득이 1억3천만원을 조금 넘으면 아예 안 되나요?**
A. 신생아 특례 대출은 소득 1억3천만원 이하가 기준입니다. 초과 시 일반 정책 모기지(디딤돌 대출 등)나 시중 은행 대출을 검토해야 합니다.

**Q. 쌍둥이를 낳으면 금리가 두 번 인하되나요?**
A. 쌍둥이는 1회 출산이지만 일반적으로 추가 출산 혜택이 2자녀 기준으로 적용될 수 있습니다. 은행 담당자에게 확인하시기 바랍니다.
