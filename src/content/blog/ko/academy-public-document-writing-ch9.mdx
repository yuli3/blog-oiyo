## 공문서 문체의 원칙

```
공문서 문체 3원칙:
① 간결성: 불필요한 수식어·중복 표현 제거
② 정확성: 모호한 표현 배제, 수치·사실 근거 제시
③ 객관성: 주관적 판단·감정 표현 자제
```

---

## 주어-서술어 호응

### 호응 불일치 유형

```
1. 주어와 서술어 불일치:
나쁜 예:
"이번 사업의 목적은 지역 경제 활성화를 위하여..."
→ "목적은 ~이다" 호응 불일치

올바른 표현:
"이번 사업의 목적은 지역 경제 활성화입니다."
또는
"이번 사업은 지역 경제 활성화를 위하여 추진합니다."

2. 복수 주어-단수 서술어:
나쁜 예:
"○○과장과 ○○팀장이 참석하여 보고하였습니다."
→ 주어 복수, 서술어는 자연스러우나 모호

올바른 표현:
"○○과장과 ○○팀장이 각각 보고하였습니다."
```

### 이중 주어 구조

```
나쁜 예:
"이 사업은 성과가 기대됩니다."
→ "사업은 ~ 성과가" = 이중 주어

올바른 표현:
"이 사업에서 성과가 기대됩니다."
또는
"이 사업의 성과가 기대됩니다."
```

## 피동·사동 표현 정리

```
과도한 피동 표현:
나쁜 예: "검토가 이루어졌습니다"
좋은 예: "검토하였습니다"

나쁜 예: "추진이 될 예정입니다"
좋은 예: "추진할 예정입니다"

이중 피동 (절대 금지):
나쁜 예: "되어지다", "보여지다"
좋은 예: "되다", "보이다"

사동 표현 주의:
나쁜 예: "보고토록 하겠습니다"
→ 책임 회피 느낌
좋은 예: "보고하겠습니다"
```

## 접속사와 연결어

```
공문서에서 접속사 사용 원칙:
① 불필요한 접속사 제거
② 단락 전환 시 명확한 접속어 사용

지양해야 할 접속사:
- "그리고", "또한" 과도 반복 → 항목 나열로 대체
- "그런데", "사실은" → 비공식적 문투

권장 연결어:
- 이에 따라 (결과·연결)
- 이에 (다음과 같이 조치하겠습니다)
- 아울러 (추가 사항)
- 다만 (단서·예외)
- 한편 (전환)
```

## 단락 구성 원칙

```
단락 구성:
① 한 단락 = 하나의 주제
② 두괄식: 핵심 문장 → 근거·설명
③ 항목 번호로 구조화

나쁜 단락 구성:
"이번 사업은 A, B, C 세 가지 목표를 달성하기 위해 추진되며,
예산은 5억 원이 소요되고, 기간은 6개월이며, 담당자는 홍길동이고,
추진 방법은 외부 용역을 통하며..."
→ 한 문장에 정보 과부하

좋은 단락 구성:
"이번 사업의 개요는 다음과 같습니다.
1. 목표: A, B, C
2. 예산: 5억 원
3. 기간: 2026. 6. 1. ~ 11. 30.
4. 담당: 홍길동(내선 1234)
5. 방법: 외부 용역"
```

## 불필요한 표현 제거

```
군더더기 표현:
"현재 현재 진행 중에 있습니다" → "진행 중입니다"
"그 결과로 인하여" → "그 결과"
"이와 같은 이유로 인하여" → "이러한 이유로"
"~하는 방향으로 검토해 보겠습니다" → "검토하겠습니다"

모호한 표현:
"적극적으로 추진하겠습니다" → "○월까지 완료하겠습니다"
"관계 기관과 협의하겠습니다" → "○○기관과 ○일 이내 협의하겠습니다"
"조속한 시일 내에" → "2026. 6. 30.까지"
```

## 핵심 개념 카드

**피동 표현 금지** ★★★★★
: "되어지다·보여지다" = 이중 피동 절대 금지. "검토가 이루어졌습니다" → "검토하였습니다".
*암기 포인트: 이중피동=되어지다/보여지다 금지*

**두괄식 단락 구성** ★★★★★
: 핵심 → 근거 → 세부. 상위 결재권자가 첫 줄만 읽어도 내용 파악.
*암기 포인트: 결론 먼저 → 이유 나중*

**모호한 기간 표현 금지** ★★★★☆
: "조속히·적극적으로·가능한 빨리" → 구체적 날짜·수치로 대체.
*암기 포인트: 기간=반드시 날짜, 수량=반드시 숫자*

## 실전 퀴즈

**Q. "적극적으로 추진하겠습니다"의 문제점과 개선 표현은?**
> 모호한 의지 표현. "2026. 7. 31.까지 완료하겠습니다" 또는 "○○ 방법으로 추진하겠습니다"로 구체화.

**Q. "이번 사업의 목적은 지역 경제 활성화를 위하여"의 호응 오류를 수정하시오.**
> "이번 사업의 목적은 지역 경제 활성화입니다." (목적은 ~이다 호응) 또는 "이번 사업은 지역 경제 활성화를 위하여 추진합니다."
