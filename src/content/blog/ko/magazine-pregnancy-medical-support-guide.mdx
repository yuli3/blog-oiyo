## 고운맘카드(국민행복카드)란?

임신·출산한 산모에게 의료비를 지원하는 국가 바우처입니다. 산부인과, 한방 병원, 약국 등에서 사용할 수 있습니다.

---

## 지원 금액

```
단태아 (1명): 100만원
다태아 (쌍둥이 이상): 140만원

사용 기간: 임신 확인일부터 출산 후 2년까지
```

---

## 신청 자격

```
- 임신 확인서를 발급받은 임산부
- 국내 거주 건강보험 가입자 (또는 피부양자)
- 의료급여 수급자도 별도 신청 가능
```

---

## 신청 방법

### 신청 절차

```
1단계: 산부인과에서 임신 확인서 발급
2단계: 국민건강보험공단 앱(The건강보험) or 홈페이지에서 신청
        또는 가까운 건강보험공단 지사 방문
3단계: 카드사 선택 (BC, 롯데, 삼성, KB국민, NH농협 등)
4단계: 국민행복카드 수령 (우편 or 은행 수령)
```

> 국민행복카드는 고운맘카드 기능이 포함된 다기능 카드입니다. 이미 국민행복카드가 있다면 바우처만 추가 신청하면 됩니다.

---

## 사용 가능한 곳

### 사용 가능

```
- 산부인과 (진료비, 초음파, 검사비)
- 한방 병의원 (임신 관련 진료)
- 의원·병원·종합병원 (임신 관련 진료)
- 약국 (임신 관련 처방약)
- 산전 검사 의원
```

### 사용 불가

```
- 산후조리원 (별도 바우처 제도 있음 - 아래 참고)
- 미용·성형 목적 시술
- 분만 보험 적용 외 의료비 일부
```

---

## 산후조리 지원 — 별도 바우처

```
산후조리원 지원은 고운맘카드와 별개:

첫째 출산: 200만원 (산후조리원 바우처)
※ 지자체별로 추가 지원 있음

신청:
→ 행복출산 원스톱 서비스 (정부24, 주민센터)
→ 출생신고 후 신청 가능
```

---

## 임신 의료비 절감 체계

```
임신 확인 후 이용 가능한 의료비 지원 체계:

1. 고운맘카드: 산전 검사·진료 100만원
2. 임산부 국가필수 예방접종: 무료 (인플루엔자, 파상풍 등)
3. 산전 건강검진: 일부 무료 (건강보험 공단 검진)
4. 기형아 검사: 일부 급여화
5. 분만 입원: 건강보험 급여 적용
```

---

## 잔액 소멸 주의

```
카드 사용 기한: 출산 후 2년 이내
→ 2년 이후 잔액 자동 소멸
→ 출산 초기에 잔액 확인 후 사용 권장

잔액 확인:
→ The건강보험 앱 → 바우처 잔액 조회
→ 고객센터: 1577-1000
```

---

## 의료급여 수급자 별도 지원

```
의료급여 1종·2종 수급자:
→ 건강보험 비가입자이므로 별도 신청 경로
→ 주민센터(행정복지센터) 방문 신청
→ 동일한 100만원(단태아)/140만원(다태아) 지원
```

## 자주 묻는 질문

**Q. 유산되면 바우처를 반환해야 하나요?**
A. 유산 전까지 사용한 금액은 환수되지 않습니다. 이미 사용한 산전 진료비는 정상 인정됩니다.

**Q. 국민행복카드가 이미 있는데 고운맘 바우처도 따로 신청해야 하나요?**
A. 국민행복카드가 있어도 임신 후 건강보험공단에 '임신·출산 진료비 신청'을 별도로 해야 바우처가 적재됩니다. 카드가 있다고 자동으로 지급되지 않습니다.

**Q. 쌍둥이는 얼마를 받나요?**
A. 쌍둥이(다태아) 임신 시 140만원이 지급됩니다. 세쌍둥이 이상도 동일하게 140만원입니다.

**Q. 외국인 배우자도 신청할 수 있나요?**
A. 건강보험 가입 또는 피부양자 등록이 된 외국인 배우자는 신청 가능합니다.
