## 청소년도 근로기준법 보호를 받는다

```
만 15세 이상이면 아르바이트 가능 (연소근로자)
만 18세 미만: 연소 근로자 보호 조항 추가 적용
→ 성인과 동일한 최저임금 보장
→ 위반 시 사업주 처벌
```

---

## 일할 수 있는 나이

```
만 15세 이상:
→ 단, 만 15~17세는 부모(또는 후견인) 동의서 필요
→ 취직 인허증 필요한 경우: 학교 수업 중이면 추가 절차

만 18세 이상:
→ 보호자 동의 없이 자유롭게 근로 가능

만 15세 미만:
→ 원칙적으로 근로 금지 (교육부 장관 발급 취직 인허증 있는 경우만 예외)
```

---

## 반드시 받아야 하는 근로계약서

```
근로계약서 작성 의무:
→ 하루짜리 단기 알바도 반드시 작성
→ 서면 계약서 1부씩 교부

계약서에 반드시 포함되어야 할 사항:
□ 임금 (시급 또는 월급)
□ 근무 일수, 근무 시간
□ 휴게 시간
□ 휴일
□ 업무 장소 및 업종

근로계약서 미작성 시:
→ 사업주 과태료 500만원 이하
→ 근로자는 언제든 신고 가능
```

## 최저임금

```
2024년 최저임금: 시간당 9,860원
2025년 최저임금: 시간당 10,030원 (예정)

→ 청소년도 동일하게 최저임금 적용
→ '시범 기간', '수습 기간'이라도 최저임금 미만 지급은 불법

최저임금 계산:
시급 × 실제 근무 시간 = 최소 받아야 할 금액
```

---

## 주휴수당

```
조건: 주 15시간 이상 근무 + 개근
→ 1주일에 하루치 임금 추가 지급

주휴수당 계산:
(주간 총 근무 시간 ÷ 5일) × 시급

예시:
주 20시간 근무, 시급 9,860원:
(20 ÷ 5) × 9,860 = 39,440원/주 추가
→ 월 약 157,760원 주휴수당 발생
```

## 야간·연장 근무 추가수당

```
야간 근무 (22시~06시):
→ 시급의 50% 추가 (최저 야간 수당)

연장 근무 (1일 8시간, 1주 40시간 초과):
→ 50% 추가 (연장 근무 수당)

휴일 근무:
→ 50% 추가 (또는 100% - 사업장 규모 따라)

연소 근로자 (만 18세 미만) 특별 보호:
→ 1일 7시간, 1주 35시간 초과 근무 금지
→ 본인 동의 + 근로감독관 인가 시 초과 가능 (각 1시간 이내)
→ 야간·휴일 근무: 본인 동의 + 근로감독관 인가 필수
```

## 청소년이 특별히 일할 수 없는 곳

```
만 18세 미만 청소년 취업 금지 업종:
- 술 파는 주점 (유흥 주점, 단란 주점)
- 성인 오락 시설 (성인 전용 오락실 등)
- 담배·유해 약품 판매
- 유해 화학물질 취급
- 야간(22시 이후) 숙박·목욕 시설
→ 위반 시 사업주 2년 이하 징역 or 1,000만원 이하 벌금
```

## 부당 대우 종류와 신고 방법

### 흔한 부당 대우

```
1. 최저임금 미만 지급
2. 주휴수당 미지급
3. 근로계약서 미작성
4. 야간·연장 수당 미지급
5. 급여 지급 지연
6. 허위 계약서 작성 강요
7. 부당 해고 (예고 없이)
```

### 신고 방법

```
고용노동부 신고:
→ 전화: 1350
→ 홈페이지: moel.go.kr → 민원 신청 → 진정 접수
→ 전국 지방 노동청 방문

청소년 전용 상담:
→ 청소년 근로 권익 센터: 1644-3119
→ 상담, 신고 대리, 법률 지원 제공

신고 전 준비:
→ 근로계약서 사본 (없어도 신고 가능)
→ 급여 미지급 내역, 근무 기록
→ 문자·카카오톡 대화 내용 (증거)
```

## 청소년 보호자가 알아야 할 것

```
부모 동의서 작성 시 주의:
→ 동의서 작성이 착취적 근로에 대한 동의가 아님
→ 최저임금 이하, 야간 강제 근무 등은 동의서 있어도 불법

자녀 급여 착취 금지:
→ 법적으로 근로자가 임금을 직접 받을 권리 있음
→ 부모가 자녀 급여를 강제로 빼앗으면 위법
```

## 자주 묻는 질문

**Q. 사장님이 수습 기간이라 최저임금을 안 줘도 된다고 하는데 맞나요?**
A. 수습 기간에도 최저임금의 90% 이상을 지급해야 합니다. 단, 이 규정은 1년 이상 근로계약을 맺은 경우에만 적용되므로, 단기 알바는 수습 기간 예외가 없습니다. 항상 최저임금 100%를 요구하세요.

**Q. 이미 그만뒀는데 임금을 못 받은 게 있으면 어떻게 하나요?**
A. 퇴직 후에도 3년 이내라면 신고 가능합니다. 고용노동부 1350에 전화하거나 청소년 근로권익센터에 상담하세요.

**Q. 사장이 주휴수당을 시급에 포함했다는데 맞나요?**
A. 주휴수당 포함 시급제는 조건이 있습니다. 주휴수당을 포함한다고 명시되어 있어도 실질 시급이 최저임금 이상이고, 총 수령액이 법정 주휴수당을 초과해야 합니다.
