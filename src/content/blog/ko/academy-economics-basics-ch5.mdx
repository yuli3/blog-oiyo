## 완전경쟁 시장

```
특성:
- 다수 구매자·판매자
- 동질적 제품
- 완전 정보
- 자유로운 진입·퇴출

가격 수용자 (Price Taker):
P = MR (수평 수요곡선)
이윤 극대화: P = MC

장기 균형:
P = MC = ATC (경제적 이윤 = 0)
→ 진입·퇴출로 정상이윤만 남음
```

## 독점 시장

```
독점 기업:
- 시장 전체 공급 → 우하향 수요곡선 직면
- MR < P (가격 인하 시 모든 단위에 적용)

MR과 수요곡선:
MR = P(1 - 1/|ε|)
|ε| > 1 (탄력적) → MR > 0
|ε| = 1 → MR = 0
|ε| < 1 (비탄력적) → MR < 0

독점 이윤 극대화:
MR = MC에서 생산량 결정 → 수요곡선에서 가격 결정
→ P > MC (사회적 비효율 = 자중손실)

독점의 비효율:
- 완전경쟁 대비 과소 생산·고가격
- 자중손실(Deadweight Loss) 발생
```

### 독점의 가격차별

```
1급 가격차별: 각 단위의 최대지불의사를 알고 그에 맞춘 가격 부과 (완전 가격차별)
→ 정보·재판매 통제가 완전하고 거래비용이 없는 표준 모형에서는 경쟁수량까지 거래하며 소비자잉여가 독점자에게 이전

2급 가격차별: 구매량에 따라 다른 가격 (누진·체감 요금)
→ 전기·수도 누진제

3급 가격차별: 소비자 집단별 다른 가격
→ 조건: 시장 분리 가능, 재판매 불가, 탄력성 차이
→ 탄력적 시장에 낮은 가격, 비탄력적 시장에 높은 가격
→ 예: 성인·학생 요금, 국내·해외 가격 차별
```

## 과점 시장

```
과점 특성:
- 소수 기업 → 상호의존성 높음
- 한 기업 행동 → 타 기업 영향

굴절 수요곡선 이론 (Kinked Demand):
- 가격 인상 → 경쟁자 미추종 → 큰 수요 감소
- 가격 인하 → 경쟁자 추종 → 소폭 수요 증가
→ 가격 경직성 설명

담합 (Cartel):
- 기업 간 가격·생산량 협정
- 독점처럼 행동 → 공동 이익 극대
- 불안정: 이탈 유인 (죄수의 딜레마)

게임이론 (Nash Equilibrium):
- 상대방 전략 주어졌을 때 최선 전략
- 내쉬균형: 양방이 이탈 유인 없는 전략 조합
- 죄수의 딜레마: 개별 합리성 → 집단 비최적
```

### 과점시장: 수량경쟁·가격경쟁·선도자 모형

과점시장의 핵심은 기업 수 자체보다 **전략적 상호의존성**입니다. 한 기업의 가격·수량 결정에 대한 경쟁자의 반응을 예상해야 하므로 하나의 공통 가격·생산량 공식으로 설명되지 않습니다.

| 모형 | 전략변수·순서 | 동질재의 대표 결론 |
| --- | --- | --- |
| 쿠르노 | 기업이 수량을 동시에 선택 | 동질재·동일한 양의 한계비용 등 표준 복점 가정에서 독점보다 생산량이 많고 완전경쟁보다 적음 |
| 베르트랑 | 기업이 가격을 동시에 선택 | 동일 원가·동질재 등 강한 가정 아래 가격이 한계비용까지 하락 |
| 슈타켈버그 | 선도기업이 수량을 먼저, 추종기업이 반응 | 선도자 우위가 생길 수 있음 |
| 카르텔 | 공동이윤을 위해 가격·수량 협의 | 독점 결과를 지향하지만 개별 기업에 증산 이탈 유인 |

내쉬균형은 각자가 상대 전략을 주어진 것으로 볼 때 일방적으로 바꿔 이득을 얻지 못하는 조합입니다. 모두에게 가장 좋은 결과나 담합을 뜻하지 않습니다. 굴절수요곡선은 경쟁자가 가격 인하는 따라가고 가격 인상은 따라가지 않는다고 보아 가격경직성을 설명하지만, 최초 가격이 어떻게 정해지는지는 설명하지 못합니다.

**시험 함정:** “기업이 둘이면 항상 베르트랑 결과”, “내쉬균형이면 공동이윤 최대”, “담합은 이탈 유인이 없어 안정적”이라는 단정을 피하고 제품 동질성·생산능력·게임 순서·반복 여부를 확인합니다.

## 핵심 개념 카드

**독점 MR < P** ★★★★★
: 독점은 판매량 늘리기 위해 가격 내림 → MR = P - 가격 인하 손실 < P.
*암기 포인트: 독점 MR < P, 완전경쟁 MR = P*

**3급 가격차별 조건** ★★★★★
: 시장 분리 가능 + 재판매 불가 + 탄력성 차이. 탄력적 시장=낮은 가격.
*암기 포인트: 탄력적=싸게, 비탄력적=비싸게*

**내쉬균형** ★★★★☆
: 상대방 전략 고정 시 자신의 최적 전략. 이탈 유인 없는 안정 상태.
*암기 포인트: 내쉬=서로 이탈 유인 없음*

## 실전 퀴즈

**Q. 독점 기업의 이윤 극대화 산출량에서 P > MC인 이유는?**
> MR = MC에서 생산하되 MR < P이므로 P > MC. 완전경쟁(P = MC)에 비해 과소 생산·고가격 → 사회적 자중손실 발생.

**Q. 항공사가 동일 노선을 학생에게 싸게, 비즈니스 고객에게 비싸게 파는 것은 몇 급 가격차별인가?**
> 3급 가격차별. 소비자 집단(학생 vs 비즈니스)의 가격 탄력성 차이 활용. 학생=탄력적(저가), 비즈니스=비탄력적(고가).
