## 미시경제 핵심 공식 총정리

```
수요·공급:
수요 탄력성 = 수요량변화율% / 가격변화율%
공급 탄력성 = 공급량변화율% / 가격변화율%

소비자 이론:
효용 극대화: MUx/Px = MUy/Py
MRS = MUx/MUy = Px/Py (소비자 균형)

생산자 이론:
이윤 극대화: MR = MC
총비용: TC = TFC + TVC
한계비용: MC = ΔTC/ΔQ
평균총비용: ATC = TC/Q = AFC + AVC

시장 구조:
완전경쟁: P = MR = MC (장기 P = ATC)
독점: MR = MC, P > MC (자중손실)
```

## 거시경제 핵심 공식 총정리

```
국민소득:
GDP = C + I + G + (X - M)
GNP = GDP + 국외순수취요소소득
실질GDP = 명목GDP / GDP디플레이터 × 100
경제성장률 = (실질GDP₁ - 실질GDP₀) / 실질GDP₀ × 100

통화·금융:
통화승수 = 1 / 지급준비율
MV = PQ (화폐수량설)

재정정책:
케인즈 승수 = 1 / MPS = 1 / (1-MPC)
GDP 증가 = 정부지출 × 승수
조세 승수 = -MPC / MPS

환율·무역:
경상수지 흑자 → 원화 절상 압력
환율 상승 → 수출 증가·수입 감소
비교우위: 기회비용 낮은 재화에 특화
```

## 자주 틀리는 오답 포인트

```
① 기회비용 = 포기한 최선의 대안 (단 하나)
   → 여러 포기 대안 중 최고 하나만

② 매몰비용 포함하면 오류
   → 의사결정 시 미래 비용·편익만 비교

③ 수요 변화 vs 수요량 변화 구분
   → 가격 변화: 수요량 변화 (점이동)
   → 다른 요인: 수요 변화 (곡선 이동)

④ GDP에 중간재 포함 금지
   → 최종재만. 밀(중간재) vs 빵(최종재)

⑤ 독점 MR = P 아님
   → 독점 MR < P. 완전경쟁만 MR = P

⑥ 금리와 채권 가격 역관계
   → 금리↑=채권가격↓ (반드시 역관계)

⑦ 환율 상승 = 원화 절하 = 수출 유리
   → 원/달러 환율 오름 = 원화 약세

⑧ 비교우위 = 절대우위 아님
   → 비교우위 = 기회비용 낮은 것
   → 절대우위 없어도 비교우위 있을 수 있음

⑨ 긍정 외부효과 = 과소 생산
   → 보조금으로 생산 늘려야

⑩ 케인즈 승수: 정부지출 > 감세 효과
   → 정부지출 승수 = 1/MPS
   → 감세 승수 = MPC/MPS (더 작음)
```

## 시장 구조 최종 비교

```
완전경쟁:
P = MC = MR = ATC (장기 균형)
경제적 이윤 = 0 (장기)
사회적 효율 최대

독점:
P > MC = MR
경제적 이윤 > 0 (장기도)
자중손실 발생

독점적 경쟁:
P > MC (단기 이윤 가능)
P = ATC (장기, 진입으로 소멸)
제품 차별로 브랜드 충성도

과점:
가격 경직성 (굴절수요곡선)
담합 유인 → 불안정
게임이론으로 분석
```

## 핵심 개념 카드

**GDP 지출 접근** ★★★★★
: C+I+G+(X-M). 수입(M)은 차감. 투자(I)=기업설비+건설+재고변동.
*암기 포인트: GDP=소비+투자+정부+순수출*

**승수 공식** ★★★★★
: 승수=1/(1-MPC). MPC=0.8→승수=5. 정부지출 1→GDP 5 증가.
*암기 포인트: 승수=1÷MPS=1÷(1-MPC)*

**자중손실(DWL) 발생 조건** ★★★★☆
: 독점·과세·최고가격제·최저가격제 → P≠MC → 효율적 거래량 미달 → 자중손실.
*암기 포인트: P≠MC=비효율=자중손실*

## 실전 퀴즈 (종합)

**Q. MPC = 0.6인 경제에서 정부 지출 50조 증가와 세금 50조 감소 중 GDP 증가 효과가 더 큰 것은?**
> 정부 지출이 더 큼. 승수=1/(1-0.6)=2.5 → GDP 증가=125조. 감세 승수=0.6/0.4=1.5 → GDP 증가=75조.

**Q. 독점 기업이 MR=MC에서 생산 시 P>MC가 되는 이유는?**
> 독점은 수요 전체를 담당 → 추가 판매를 위해 기존 단위 가격도 낮춰야 함 → MR < P. MR=MC이므로 P > MC. 자중손실 발생.

**Q. 한 나라가 두 재화 모두에서 절대우위를 가져도 무역에서 이익을 볼 수 있는 이유는?**
> 비교우위 원리. 상대적으로 기회비용이 낮은 재화에 특화하면 양국 생산량의 합이 증가. 절대우위와 관계없이 비교우위에 따른 특화·무역으로 상호 이익.
