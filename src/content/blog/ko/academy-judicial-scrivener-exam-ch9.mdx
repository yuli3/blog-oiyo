## 민법 오답 포인트

```
① 계약 해제 vs 해지
   → 해제=소급효+원상회복
   → 해지=장래효만 (임대차·고용 등)

② 상속 포기 기간 = 3개월
   → 안 날 3개월 이내 가정법원

③ 유류분 = 법정상속분 × 1/2 (직계비속·배우자)
   → 형제자매 = × 1/3

④ 불법행위 소멸시효 = 3년 + 10년
   → 채권 소멸시효(10년)와 혼동 주의

⑤ 사용자 책임 = 업무집행 중 불법행위
   → 개인 활동은 해당 없음
```

## 등기법 오답 포인트

```
⑥ 등기 = 공동 신청 원칙
   → 단독 가능: 보존·판결·상속

⑦ 공신원칙 불인정
   → 형식적 심사만 하므로 등기 믿어도 보호 안됨

⑧ 가등기 = 순위 보전 (본등기 소급 효력)
   → 가등기 후 중간 등기 = 직권 말소 가능

⑨ 법인격 취득 = 설립 등기 완료 시
   → 정관 작성 시 아님

⑩ 변경 등기 = 2주 이내
    → 상호·대표이사 변경 사유 발생 후 2주
```

## 소송·절차법 오답 포인트

```
⑪ 기판력 = 주문에만 (이유 불포함)
⑫ 항소 = 2주, 상고 = 2주 (기간 같음)
⑬ 집행권원 = 판화인공지
   → 판결·화해·인낙·공정증서·지급명령
⑭ 가압류=금전, 가처분=비금전
⑮ 변제공탁 = 채권자 수령 거부·불능·불명
```

## 상법 오답 포인트

```
⑯ 회사 설립 = 등기 완료 시 법인격 취득
⑰ 주주총회 특별결의 = 출석 2/3 + 발행 1/3
⑱ 이사 임기 = 3년 (정관으로 단축 가능)
⑲ 대표소송 = 1% 이상 (상장사 0.01%)
⑳ 흡수합병 = 존속회사가 소멸회사 포괄승계
```

## 핵심 개념 카드

**해제=소급·해지=장래** ★★★★★
: 해제는 처음부터 없었던 것, 해지는 앞으로만.
*암기 포인트: 해제=소급·해지=장래*

**집행권원=판화인공지** ★★★★★
: 5가지 집행권원 암기.
*암기 포인트: 판화인공지*

**법인격=설립등기완료** ★★★★☆
: 정관 아닌 등기 시점.
*암기 포인트: 법인격=등기완료*

## 실전 퀴즈

**Q. 판결의 기판력이 주문에만 미치는 실질적 의미는?**
> 기판력: 동일 사항을 다시 소송으로 다툴 수 없는 효력. 주문에만 → 판결 이유(사실 인정·법리)는 기판력 없음. 따라서 기각 판결 이유에서 인정된 채권도 별도 소송으로 다툴 수 있음. 실무에서 소송 전략상 중요.

**Q. 법무사와 변호사가 경쟁하는 업무 영역은?**
> 부동산 등기: 법무사가 압도적. 상업 등기: 법무사 강점. 소송 서류 작성 보조: 경쟁 영역. 독점 영역: 법무사=등기·공탁, 변호사=소송 대리. 가격 경쟁력: 법무사 우위. 법무법인도 등기 업무 취급해 일부 경쟁.
