## 행정의 의의

```
행정 (Public Administration):
국가 목적 달성을 위해 정부가 수행하는 공적 활동

행정의 특성:
① 공익성: 사익이 아닌 공공 이익 추구
② 권력성: 국가 강제력 수반 가능
③ 공공성: 사회 전체를 위한 활동
④ 정치성: 정치적 결정 집행
⑤ 복잡성: 다양한 이해관계 조정

행정학 발달:
행정관리설(Wilson) → 통치기능설 → 행정행태론
→ 신행정론(형평·참여) → 신공공관리론(NPM) → 뉴거버넌스
```

## 행정 이념

```
민주성:
국민 주권, 시민 참여, 책임 행정
행정이 국민 의사에 따라 운영

능률성 (Efficiency):
투입 대비 산출 비율 최대화
경제적 자원 낭비 최소화

효과성 (Effectiveness):
목표 달성 정도
산출보다 결과·영향 중시

합법성 (Legality):
법률에 따른 행정 수행
법치주의, 법 앞의 평등

형평성 (Equity):
결과의 공정한 배분
사회적 약자 보호, 기회 균등
```

## 공익

```
공익:
사회 전체의 이익, 공공의 이익

공익의 접근법:
과정설: 이익집단 간 타협·조정 결과가 공익
실체설: 사회 전체 이익, 객관적으로 존재

공익과 사익:
공익≠사익의 단순 합산
공익: 사익을 초월한 사회적 가치

공익 기준:
헌법적 가치·인권·평등·공동선
단순 다수결=공익 아님

신공공관리론 비판:
능률성·효과성 강조 → 공익·형평·민주성 약화
→ 뉴거버넌스: 정부·시민·기업 협력
```

## 행정 환경 변화

```
행정 패러다임 변화:
전통 행정 → 신공공관리론 → 뉴거버넌스

신공공관리론 (NPM):
시장 메커니즘 도입
성과 중심 관리
민간 위탁, 규제 완화
"고객"으로서 시민

뉴거버넌스:
정부·시민사회·시장 네트워크
참여와 협력
파트너십
서비스 공동 생산

전자정부:
ICT 활용 행정 서비스 향상
민원 온라인화, 데이터 기반 행정
```

## 핵심 개념 카드

**행정 이념 5가지** ★★★★★
: 민주성·능률성·효과성·합법성·형평성. 상호 긴장 관계.
*암기 포인트: 민능효합형*

**능률성 vs 효과성** ★★★★★
: 능률=투입/산출 비율. 효과=목표 달성 정도.
*암기 포인트: 능률=경제적, 효과=목표달성*

**신공공관리론(NPM)** ★★★★☆
: 시장 원리 도입, 성과 중심, 민간 위탁. 공익·형평 약화 비판.
*암기 포인트: NPM=민간경영기법 도입*

## 실전 퀴즈

**Q. 능률성과 효과성이 동시에 높을 수 없는 상황의 예는?**
> 의료 서비스: 효과적 치료(목표 달성)를 위해 고비용이 필요할 수 있어 능률성 낮아짐. 반대로 비용 절감(능률)하면 서비스 질 하락으로 효과성 감소 가능. 두 이념 간 긴장 관계 존재.

**Q. 신공공관리론의 한계는 무엇인가?**
> 시장 논리 강조로 공공성·형평성 약화. 성과 측정 어려운 공공서비스에 부적합. 시민을 '고객'으로만 봐 민주적 참여 경시. 민간 위탁 확대로 책임 소재 불명확.
