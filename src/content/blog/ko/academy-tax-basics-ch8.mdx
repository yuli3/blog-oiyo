## 법인세란 무엇인가

**법인세(法人稅)**는 법인(주식회사, 유한회사 등)이 벌어들인 소득에 부과하는 세금입니다. 개인에게 소득세가 있다면, 법인에게는 법인세가 있습니다.

```
법인세 납세 의무자:
- 내국법인: 국내에 본점·주사무소를 둔 법인
- 외국법인: 국내에 사업장을 둔 외국 법인 (국내 원천소득만 과세)
```

법인세는 **법인세법**에 규정된 국세이자 직접세입니다.

---

## 법인세 과세 소득의 종류

법인에 과세되는 소득은 다음과 같습니다.

| 소득 유형 | 내용 |
|-----------|------|
| 각 사업연도 소득 | 영업 활동에서 발생한 이익 |
| 청산소득 | 법인 해산 시 잔여재산 |
| 토지 등 양도소득 | 토지·건물 양도차익 (별도 추가 과세) |

일반적으로 **각 사업연도 소득**이 핵심입니다.

---

## 각 사업연도 소득 계산

### 기본 구조

```
각 사업연도 소득 = 익금 - 손금

익금(益金): 법인의 순자산을 증가시키는 거래 금액
손금(損金): 법인의 순자산을 감소시키는 거래 금액 (비용)
```

회계상 이익(당기순이익)을 출발점으로, 세법 규정에 따라 가감 조정합니다.

```
세무조정:
당기순이익
+ 익금산입 (세법상 수익이지만 회계상 미반영)
+ 손금불산입 (회계상 비용이지만 세법상 불인정)
- 손금산입 (세법상 비용이지만 회계상 미반영)
- 익금불산입 (회계상 수익이지만 세법상 제외)
= 각 사업연도 소득
```

### 주요 손금불산입 항목

세법에서 비용으로 인정하지 않는 항목들입니다.

- **접대비**: 한도 초과분 (중소기업 3,600만 원 등)
- **임원 상여금**: 정관·주주총회 결의 없는 과도한 지급
- **업무 무관 비용**: 사주의 개인적 지출
- **감가상각비 초과**: 법정 한도를 초과한 감가상각
- **과다 이자비용**: 특수관계인 간 고율 이자

## 법인세율

```
과세표준              세율
2억 원 이하          9%
2억~200억 원        19%
200억~3,000억 원    21%
3,000억 원 초과     24%
```

소규모 법인일수록 낮은 세율이 적용됩니다.

### 지방소득세 포함 실효세율

법인세 외에 **지방소득세** 10%가 추가됩니다.

```
실효 세율 = 법인세율 × 1.1

예) 9% → 9.9%, 19% → 20.9%, 24% → 26.4%
```

---

## 주요 세액공제와 감면

### 연구개발(R&D) 세액공제

중소기업이 R&D 비용을 지출하면 **최대 25%** 세액공제를 받을 수 있습니다.

```
R&D 세액공제 = R&D 비용 × 공제율 (중소기업 25%)
```

### 고용 증대 세액공제

전년 대비 상시 근로자가 증가하면 **1인당 최대 1,300만 원** 공제.

### 중소기업 특별세액감면

업종·규모에 따라 산출세액의 **5~30%** 감면.

### 외국납부세액공제

해외에서 법인세를 납부한 경우 국내 법인세에서 공제하여 이중과세를 방지합니다.

---

## 결손금 이월공제

사업 손실이 발생하면 최대 **15년** 이월하여 미래 이익에서 공제합니다.

```
예시:
2024년 손실: 1억 원
2025년 이익: 3억 원
→ 2025년 과세표준: 3억 - 1억 = 2억 원 (단, 이월공제 한도 60% 적용)
```

---

## 개인사업자 vs 법인사업자 비교

사업을 시작하거나 전환할 때 반드시 비교해야 합니다.

| 구분 | 개인사업자 | 법인사업자 |
|------|-----------|-----------|
| 납세 주체 | 사업주 개인 | 법인 |
| 세금 종류 | 소득세 (6~45%) | 법인세 (9~24%) |
| 최고 세율 | 45% (지방세 포함 49.5%) | 24% (지방세 포함 26.4%) |
| 대표자 급여 | 비용 불인정 | 비용 인정 |
| 손실 처리 | 개인 소득에서 공제 | 15년 이월 |
| 설립 비용 | 없음 | 등기 비용 발생 |
| 책임 범위 | 무한책임 | 출자 한도 유한책임 |
| 사회보험 | 지역가입자 | 직장가입자 |

**법인 전환 검토 시점**: 연 매출 1억~2억, 순이익 5,000만 원 이상이면 법인이 유리한 경우가 많습니다.

## 법인세 신고 및 납부

### 신고 기한

사업연도 종료일로부터 **3개월 이내** 신고·납부

```
12월 결산 법인: 다음 해 3월 31일까지
6월 결산 법인: 같은 해 9월 30일까지
```

### 중간예납

사업연도 중간에 법인세를 미리 납부하는 제도입니다.

```
중간예납 = 전년도 법인세의 50%
또는 당해 연도 상반기 실적으로 계산한 법인세
```

- 납부 기한: 사업연도 개시 후 6개월이 지난 날부터 2개월 이내

### 분납 제도

납부할 법인세가 1,000만 원 초과 시, **1개월 이내** 분납 가능.

---

## 법인 설립과 세금 계획

### 법인 설립 절차

1. 발기인 구성 및 정관 작성
2. 법인 설립 등기 (법원 등기소)
3. 사업자등록 (세무서)
4. 4대보험 가입

### 가족 법인 절세 전략

대표자 급여를 법인 비용으로 처리하고, 배우자나 자녀를 임원·직원으로 등재하면 소득이 분산되어 절세 효과가 있습니다.

```
주의: 실제 근무하지 않는 가족에게 지급하는 급여는
손금불산입 처리되고 탈세로 이어질 수 있습니다.
```

## 핵심 정리

| 구분 | 핵심 내용 |
|------|-----------|
| 법인세율 | 9~24% (지방소득세 포함 시 9.9~26.4%) |
| 과세 소득 | 각 사업연도 소득 = 익금 - 손금 |
| 신고 기한 | 사업연도 종료 후 3개월 이내 |
| 절세 핵심 | R&D 공제, 고용 공제, 결손금 이월 |
| 개인 vs 법인 | 고소득일수록 법인이 유리 |

법인세는 복잡하지만, **정확한 세무조정과 공제 활용**이 기업의 세금 부담을 크게 줄여줍니다. 전문 세무사와 협력하는 것이 중요합니다.
