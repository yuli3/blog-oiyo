## 성조숙증이란?

성조숙증은 사춘기 발달이 **정상보다 2년 이상 일찍** 시작되는 상태입니다.

| 기준 | 여아 | 남아 |
|------|------|------|
| 정상 사춘기 시작 | 만 8~13세 | 만 9~14세 |
| 성조숙증 기준 | **만 8세 이전** 유방 발달 | **만 9세 이전** 고환 발달 |

성조숙증은 방치하면 **최종 키가 작아질 수 있습니다.** 조기 발견과 치료가 중요합니다.

---

## 성조숙증 증상

### 여아 증상 (만 8세 이전)

```
- 유방 발달 (한쪽 또는 양쪽)
- 음모·액모 발생
- 질 분비물
- 생리 시작
- 키가 또래보다 갑자기 많이 큼
- 여드름
```

### 남아 증상 (만 9세 이전)

```
- 고환·음경 커짐
- 음모·겨드랑이털 발생
- 변성기 (목소리 굵어짐)
- 근육량 증가
- 여드름
- 키가 갑자기 많이 큼
```

> **주의**: 키가 빨리 크는 것이 좋아 보이지만, 성장판이 일찍 닫혀 **최종 신장이 작아질 수 있습니다.**

## 성조숙증의 주요 원인

### 진성 성조숙증 (GnRH 의존성)

뇌(시상하부-뇌하수체) 축이 조기 활성화되는 경우.

```
원인:
- 특발성 (원인 불명) - 가장 많음 (여아 90% 이상)
- 중추신경계 종양 or 병변 (남아에서 비율 높음)
- 방사선 치료 후 유발
```

### 가성 성조숙증 (GnRH 비의존성)

성호르몬이 뇌 통제 없이 분비되는 경우.

```
원인:
- 난소 낭종, 부신 종양
- 갑상선 기능 저하
- 외부 호르몬 노출 (환경호르몬)
```

### 성조숙증과 관련된 환경 요인

```
- 비만: 지방세포에서 에스트로겐 분비 → 성조숙증 위험 증가
- 환경호르몬: 플라스틱(BPA), 농약, 일부 화장품·샴푸
- 스트레스: 가족 갈등, 과도한 학업 스트레스
- 수면 부족: 멜라토닌 분비 감소 → 성호르몬 자극
- 식이 패턴: 가공식품, 탄산음료, 육류 과다
```

## 병원 검사 종류와 비용

### 1단계: 소아청소년과 진료

```
증상 발견 시 소아청소년과 전문의 진료
→ 성장 차트, 신체 검사, 문진
→ 추가 검사 필요 여부 결정
```

### 뼈나이 검사 (골연령 검사, X-ray)

```
검사 방법: 왼쪽 손목 X-ray 1장
비용: 3~5만원 (급여 적용 시 1~2만원)
결과: 실제 나이 vs 뼈 나이 비교
→ 뼈 나이가 2년 이상 앞서면 성조숙증 의심
```

### 혈액 검사 (기저 성호르몬 측정)

```
검사 항목: LH, FSH, 에스트라디올, 테스토스테론
비용: 3~7만원
결과 해석: 전문의가 나이·성별 기준치와 비교
```

### GnRH 자극 검사 (확진 검사)

```
방법: GnRH 주사 후 30분·60분·90분 간격으로 채혈
비용: 30~70만원 (병원별 상이)
소요 시간: 약 3~4시간 (당일)
목적: 진성/가성 성조숙증 구분, 치료 필요 여부 확정
```

### 뇌 MRI (필요 시)

```
대상: 남아·어린 여아에서 원인 병변 확인
비용: 40~80만원 (비급여 기준)
보험 급여: 성조숙증 확진 시 일부 급여 가능
```

## 치료: 성선자극호르몬 억제제

### 주사 치료 (루프린·트립토렐린 등)

```
치료 방법: 4주 or 3개월에 1회 주사
치료 기간: 보통 2~4년 (여아 만 10~11세, 남아 11~12세까지)
목적: 사춘기 진행 억제 → 성장판 조기 폐쇄 방지
```

### 비용과 건강보험 적용

```
비급여 시: 1회 20~40만원 → 3개월에 1회 = 연 80~160만원
건강보험 급여 조건:
  - 진성 성조숙증 확진
  - 여아: 만 9세 이하
  - 남아: 만 10세 이하
  - 뼈 나이 기준 충족

급여 적용 시: 비용의 20~30% 본인 부담
→ 1회 비용 4~8만원으로 감소
```

### 성장호르몬 치료 (별도)

```
성조숙증 치료와 함께 성장호르몬 주사를 병행하는 경우:
→ 최종 키 증가 목적
→ 비용: 월 30~70만원 (대부분 비급여)
→ 보험 급여: 성장 장애 기준 충족 시 일부 가능
```

## 치료 병원 찾기

### 1차: 소아청소년과

- 동네 소아청소년과 전문의 진료 → 초기 평가

### 2차: 소아내분비 전문 병원

```
규모 있는 병원 소아내분비클리닉 방문 권장
- 국립대 부속병원 소아과
- 종합병원 소아내분비과
→ GnRH 자극 검사, 확진 및 치료 처방
```

## 성조숙증 예방을 위한 생활 습관

### 식이 관리

```
- 가공식품·탄산음료 줄이기
- 유기농 채소·과일 늘리기
- 인스턴트 식품 자제
- 적정 체중 유지 (비만 예방)
```

### 환경호르몬 줄이기

```
- 플라스틱 용기 전자레인지 사용 금지
- 영수증 종이(BPA) 직접 만지지 않기
- 어린이 장난감: BPA-free 인증 제품
- 샴푸·로션: 파라벤 없는 제품 선택
```

### 수면·운동

```
- 규칙적인 수면 (9~10시간 이상)
- 스크린 타임 제한 (취침 전 1시간)
- 규칙적인 유산소 운동 → 체중 조절 + 스트레스 해소
```

## 자주 묻는 질문

**Q. 딸아이 만 7세인데 유방에 몽우리가 잡혔어요. 바로 병원 가야 하나요?**
A. 네, 만 8세 이전 유방 발달은 성조숙증 기준. 소아청소년과에서 뼈나이 검사를 먼저 받아보세요.

**Q. 뼈 나이가 1년 정도 앞서면 치료를 해야 하나요?**
A. 뼈 나이가 2년 이상 앞서거나 진행 속도가 빠른 경우 치료 대상. 1년 정도는 경과 관찰을 권고하는 경우가 많습니다. 전문의 판단이 중요합니다.

**Q. 치료를 하면 키가 더 크나요?**
A. 성조숙증 치료(억제제)는 성장판 조기 폐쇄를 막아 **최종 키를 지키는** 치료입니다. 키를 더 크게 하려면 성장호르몬 치료를 별도로 받아야 합니다.

**Q. 남자아이도 성조숙증이 있나요?**
A. 있습니다. 남아는 여아보다 드물지만, 뇌 종양 등 원인 질환이 있는 경우가 상대적으로 많아 정밀 검사가 중요합니다.
