## 전략·분석 오답 포인트

```
① STP 순서 = 세분→표적→포지셔닝
   → 포지셔닝부터 한다는 오답 주의

② SWOT SO전략 = 강점으로 기회 활용
   → ST=강점·위협, WO=약점·기회, WT=약점·위협

③ Porter 경쟁 전략 = 원가우위·차별화·집중
   → 집중은 원가 or 차별화 집중 (2가지)

④ PLC 성숙기 = 매출 정점 but 이익 감소
   → 매출과 이익이 동시에 최고가 아님

⑤ 고관여 구매 = 광범위 의사결정
   → 저관여 = 제한적 (비교 적게)
```

## 믹스·전술 오답 포인트

```
⑥ 가격 결정 = 원가기반·경쟁기반·가치기반
   → 원가기반이 유일한 방법 아님

⑦ 스키밍 vs 침투
   → 스키밍=도입기 고가, 침투=도입기 저가

⑧ 집약적·선택적·전속적 = 유통 너비 (길이 아님)
⑨ PR = 비용 대비 신뢰도 높음 (통제력 낮음)
⑩ PUSH = 유통업자 대상, PULL = 소비자 대상
```

## 서비스·B2B 오답 포인트

```
⑪ 서비스 4대 특성 = 무비이소
   → 무형성·비분리성·이질성·소멸성

⑫ SERVQUAL = 유신반확공 (5차원)
   → 5차원 순서 혼동 주의

⑬ 서비스 7P = 4P + 사람·프로세스·물리증거
⑭ B2B 구매센터 역할 = 사용자·영향자·구매자·의사결정자·문지기
⑮ 문지기(Gatekeeper) = 정보 통제 (실구매자 아님)
```

## 글로벌·관계 마케팅 오답 포인트

```
⑯ 라이선싱 ≠ 프랜차이징
   → 라이선싱=지재권만, 프랜차이징=비즈니스 모델

⑰ 글로컬 = 표준화+현지화 균형
⑱ CLV = 고객 생애 전체 수익 현재가치
⑲ 고객 유지율 5% 증가 = 이익 25~95% 증가
⑳ 5A 고객 여정 = Aware·Appeal·Ask·Act·Advocate
```

## 핵심 개념 카드

**PLC성숙기=매출↑이익↓** ★★★★★
: 매출 최대지만 경쟁 심화로 이익 압박.
*암기 포인트: 성숙=매출최대이익감소*

**서비스 무비이소** ★★★★★
: 무형성·비분리성·이질성·소멸성.
*암기 포인트: 무비이소*

**PUSH·PULL 방향** ★★★★☆
: PUSH=밀어내기(유통), PULL=당기기(소비자).
*암기 포인트: PUSH=밀기, PULL=당기기*

## 실전 퀴즈

**Q. 마케팅에서 가장 자주 혼동되는 PLC 단계의 특징은?**
> 성장기: 매출·이익 동시 증가 (가장 좋은 시기). 성숙기: 매출은 최고지만 이익 감소 (경쟁 심화). 혼동 포인트: 성숙기 매출 최고 = 이익도 최고라고 오해. 실제로는 가격 경쟁·마케팅비 증가로 이익 줄어듦. 성숙기 전략: 차별화·원가절감·세분 시장 집중.

**Q. 서비스 이질성이 품질 관리를 어렵게 하는 이유는?**
> 사람이 서비스 제공 → 매번 다름. 직원 기분·컨디션·고객에 따라 편차. 표준화 노력에도 한계. 해결책: 서비스 스크립트·표준 절차. 기술로 대체(챗봇·키오스크). 직원 교육·동기부여. 제조업과 달리 품질 검수 후 전달 불가.
