## 글로벌 마케팅의 기초

```
글로벌 마케팅:
→ 여러 국가에서 마케팅 활동을 조정·통합하는 전략
→ 목표: 글로벌 효율성 + 현지 반응성 균형

표준화 vs 현지화 딜레마:

표준화 전략 (Standardization):
→ 동일 제품·브랜드·광고를 전 세계에 사용
→ 장점: 규모의 경제·일관된 브랜드 이미지·비용 절감
→ 리빗 (Levitt, 1983): 기술이 취향을 동질화 → 글로벌 제품
→ 예: 코카콜라·애플 아이폰 (글로벌 일관성)

현지화 전략 (Adaptation/Localization):
→ 국가별 문화·선호·법규에 맞게 마케팅 믹스 조정
→ 장점: 현지 요구 충족·수용성 높음
→ 예: 맥도날드 메뉴 현지화 (인도 채식 버거·한국 불고기 버거)

글로컬화 (Glocalization):
→ 글로벌 + 로컬 = Think globally, act locally
→ 글로벌 브랜드 정체성 유지 + 현지 취향·관행 반영
→ 음식업·소매업·미디어에서 성공 사례 많음

현지화 압력 요인:
→ 소비자 취향 차이·문화적 선호
→ 정부 규제·현지 콘텐츠 요건
→ 유통 구조 차이·경쟁 환경

표준화 압력 요인:
→ 글로벌 고객의 수렴하는 취향
→ 규모의 경제·범위의 경제
→ 기술 표준화 (OS·소프트웨어)
→ 글로벌 경쟁사 대응
```

## 글로벌 시장 세분화와 포지셔닝

```
글로벌 세분화 (Global Segmentation):
→ 국가 간 경계를 넘어 유사한 필요와 행동 가진 고객 집단 파악
→ 초국가적 세분화 (Transnational Segmentation):
  "세계적 십대"·"글로벌 엘리트"·"글로벌 기업인"

세분화 기준:
→ 지리적 기준: 국가·지역·기후
→ 인구통계: 소득·연령·교육·가족 구성
→ 심리도: 가치관·라이프스타일 (Hofstede 문화 차원 활용)
→ 행동: 사용 행동·브랜드 충성도

지역별 접근 (Regional Approach):
→ EU·ASEAN·NAFTA 등 지역 경제 블록 기반
→ 유사한 규제·문화를 가진 지역을 하나의 시장으로

글로벌 포지셔닝 전략:
→ 공통 포지셔닝: 동일 가치 명제 전 세계 (나이키: 성취감)
→ 수정 포지셔닝: 핵심은 같되 현지 표현 다름
→ 이중 적응 포지셔닝: 포지셔닝과 실행 모두 현지화

브랜드 관리 전략:
→ 글로벌 브랜드: 코카콜라·삼성·소니
→ 다중 브랜드: 지역별 다른 브랜드 (P&G 다수 브랜드)
→ 로컬 브랜드 인수: 현지 시장 침투 (유니레버 지역 브랜드 전략)
→ 원산지 효과 (Country-of-Origin Effect):
  "Made in Germany" = 품질·정밀
  한국 브랜드: 전자·K-뷰티 긍정 이미지 강화 중
```

## 국제 제품·가격·유통 전략

```
국제 제품 전략:

제품 확장 (Product Extension):
→ 동일 제품을 기존 방식으로 해외 판매 (가장 단순)
→ 고객 선호 차이 무시 위험

제품 적응 (Product Adaptation):
→ 현지 시호에 맞게 제품 변경
→ 전압·플러그·언어·재료·크기·포장 조정

신제품 개발 (Product Innovation):
→ 현지 시장을 위해 새로운 제품 개발
→ 역방향 혁신 (Reverse Innovation): 신흥국 → 선진국 확산
  예: GE의 저가 심장 초음파 기기 (인도 개발 → 글로벌 판매)

국제 가격 전략:

가격 결정 방식:
→ 표준화 가격 (Standard Pricing): 전 세계 동일 가격
  환율 위험·가격 차익 거래 문제
→ 현지 시장 가격 (Local Market Pricing): 각국 시장 개별 가격
→ 이중 가격 구조: 현지 기업·수출 기업 다른 가격 (덤핑 우려)

가격 상승 요인 (Price Escalation):
→ 해외 운송·관세·중간상 마진으로 해외 소비자가 높은 가격 지불
→ 완화: 현지 생산·관세 면제(FTA)·채널 단축

국제 유통 전략:
→ 직접 채널: 기업 직접 수출·자사 온라인 판매
→ 간접 채널: 수출 중개인·현지 유통업체
→ 전략적 파트너십: 프랜차이즈·라이선싱·합작 투자
→ 전자상거래 (Cross-border E-commerce):
  아마존·알리바바·쿠팡 등 플랫폼 활용
  물류·통관·결제 현지화 중요
```

## 국제 커뮤니케이션·문화 마케팅

```
국제 광고 전략:
→ 표준화 광고: 동일 광고 전 세계 (주로 글로벌 브랜드)
→ 현지화 광고: 현지 모델·언어·문화 코드 사용

문화적 차이와 광고:
→ 고맥락(HC) 문화 (일본·중국·한국): 간접적·암묵적 메시지
→ 저맥락(LC) 문화 (미국·독일): 직접적·명시적 메시지
→ 집단주의 문화: 가족·공동체·조화 강조 광고
→ 개인주의 문화: 개인 성취·독립 강조 광고

색상·이미지의 문화적 의미:
→ 흰색: 서양(순수)·동아시아(죽음·애도)
→ 녹색: 이슬람(신성)·서양(환경·신선)
→ 빨강: 중국(행운)·서양(위험·정지)
→ 숫자: 4(한국·중국·일본-忌), 13(서양-不吉)

현지화 오류 사례:
→ 쉐보레 노바: 스페인어권 "가지 않는 차"
→ 펩시 "더 젊어져요": 중국어 직역 "조상을 무덤에서 깨움"
→ 코닥 배터리: 중동 문화 설명서에 왼쪽에서 오른쪽 사용(오류)

디지털 글로벌 마케팅:
→ 소셜미디어 현지화: 각국 주요 플랫폼 활용
  한국: 카카오·네이버 / 중국: 위챗·웨이보 / 러시아: VK
→ SEO 현지화: 현지어 키워드·검색 엔진 최적화
→ 인플루언서 마케팅: 현지 인플루언서 협업
→ 현지 결제 방법: 신용카드·페이팔·알리페이·카카오페이
```

## 한국 기업의 글로벌 마케팅

```
삼성전자 글로벌 마케팅:
→ 1990년대: 저가 OEM → 2000년대: 글로벌 프리미엄 전략
→ 표준화: 갤럭시 시리즈·글로벌 통일 브랜드
→ 현지화: 현지 특화 기능 (인도 힌디어 음성 입력·갤럭시 파 포함)
→ 스포츠 마케팅: 올림픽·FIFA 월드컵 글로벌 스폰서

현대·기아자동차 현지화:
→ 미국: 대형 SUV 비중 확대·10년 보증 전략
→ 인도: 소형차 특화·현지 생산·현지 R&D
→ 중국 합작 투자: 현지 법인 베이징현대

K-뷰티 글로벌화:
→ 아모레퍼시픽·LG생활건강 등
→ 한류 드라마·K-pop으로 한국 뷰티 인지도 상승
→ 중국·동남아·북미 시장 확대
→ 클린 뷰티·K-스킨케어 루틴 글로벌 트렌드화

K-콘텐츠 글로벌 마케팅:
→ BTS: 유튜브·스포티파이·SNS 직접 팬 소통
  ARMY 팬덤 = 브랜드 앰배서더
→ 넷플릭스 K-드라마: 오징어게임·더 글로리 글로벌 흥행
  자막 전략·문화적 공감 요소

글로벌 마케팅 역량 강화:
→ 현지 인재 채용·문화 이해
→ 데이터 기반 현지화: 시장조사·A/B 테스트
→ 현지 파트너십: 유통·PR·미디어
→ 민첩한 글로벌 팀: 본사-현지법인 긴밀 협업
```

## 자주 묻는 질문

**Q. 글로벌 기업이 현지화 실패로 큰 손해를 본 사례와 교훈은 무엇인가요?**
A. 현지화 실패 사례는 많습니다. 월마트의 독일·한국 철수가 대표적입니다. 월마트는 미국에서 성공한 저가 대형 마트 모델을 그대로 적용했지만, 독일에서는 이미 강력한 알디·리들 등 할인 마트가 있었고 독일 노동법과 충돌이 발생했습니다. 한국에서는 한국 소비자의 신선식품 선호, 온라인 쇼핑 문화, 고객 서비스 기대치 차이를 무시했습니다. 스타벅스는 오스트레일리아에서 현지 커피 문화(강한 에스프레소 기반)를 미국 스타일로 바꾸려다 실패했습니다. 교훈은 세 가지입니다. 첫째, 자국에서의 성공이 해외 성공을 보장하지 않습니다. 둘째, 진출 전 깊이 있는 시장 조사와 현지화가 필수입니다. 셋째, 현지 경쟁자와 차별화된 가치 제안이 있어야 합니다.

**Q. 소규모 기업도 글로벌 마케팅이 가능한가요?**
A. 디지털 환경이 소규모 기업의 글로벌 마케팅 장벽을 크게 낮췄습니다. 전자상거래 플랫폼(아마존·이베이·에세이)을 통해 물리적 해외 법인 없이도 글로벌 고객에게 판매할 수 있습니다. SNS와 콘텐츠 마케팅으로 광고 비용 없이도 글로벌 인지도를 쌓을 수 있습니다. 닉스 코스메틱(지금은 로레알 소유)처럼 유튜버 협업으로 미국 중소 뷰티 브랜드가 글로벌 인지도를 얻은 사례도 있습니다. K-뷰티 분야에서도 중소기업이 무신사·올리브영의 해외 판로를 통해 글로벌 시장에 진출하고 있습니다. 핵심은 차별화된 가치(독특한 제품·스토리·문화적 가치)를 디지털로 효과적으로 전달하는 능력입니다.
