손금(手相)은 수천 년의 역사를 가진 인류 공통의 지혜입니다. 서양에서는 **파몬드(Palmistry)** 또는 **카이로맨시(Chiromancy)**라 불리며, 동양에서는 **수상학(手相學)**으로 발전했습니다. 손금은 단순한 점술을 넘어, 손의 선과 형태를 통해 사람의 성향과 에너지를 읽는 학문입니다.

<Callout type="info">
**어느 손을 봐야 할까?**: 전통적으로 **오른손잡이는 왼손이 태어날 때의 잠재력, 오른손이 현재의 상태**를 나타냅니다. 두 손을 비교하면 더 풍부한 해석이 가능합니다.
</Callout>

## 4대 주요 선

### 1. 생명선(生命線, Life Line)

손목에서 엄지와 검지 사이로 이어지는 곡선입니다.

<Callout type="warning">
**오해**: 생명선이 짧다고 단명하는 것이 아닙니다. 생명선은 수명보다 **생명력, 활력, 삶의 질**을 나타냅니다.
</Callout>

| 생명선 특징 | 의미 |
|-----------|------|
| **길고 깊은 선** | 강한 생명력, 건강함, 지구력 |
| **짧고 얕은 선** | 섬세한 건강, 에너지 관리 필요 |
| **손목까지 크게 곡선** | 활동적, 여행을 사랑함 |
| **손바닥 중심으로 직선** | 조심스럽고 현실적 |
| **중간에 끊긴 선** | 삶의 큰 변화나 건강 변화 |
| **이중 생명선** | 강한 보호력, 회복력 |

### 2. 감정선(感情線, Heart Line)

새끼손가락 아래에서 시작하여 검지나 중지 방향으로 이어지는 선입니다.

| 감정선 특징 | 의미 |
|-----------|------|
| **검지 아래까지 올라가는 선** | 이상주의적, 높은 기대 |
| **중지 아래에서 끝나는 선** | 물질적, 현실적 |
| **곡선형** | 감성적, 표현력 풍부 |
| **직선형** | 이성적, 논리적 |
| **짧고 직선형** | 자기 중심적 경향 |
| **길고 깊은 선** | 감정이 풍부하고 헌신적 |

### 3. 두뇌선(頭腦線, Head Line)

엄지와 검지 사이에서 시작하여 새끼손가락 방향으로 이어지는 선입니다.

| 두뇌선 특징 | 의미 |
|-----------|------|
| **길고 직선** | 논리적, 분석적 사고 |
| **곡선으로 내려감** | 창의적, 상상력 풍부 |
| **짧고 직선** | 실용적, 현실적 |
| **생명선과 붙어 시작** | 신중함, 조심성 |
| **생명선과 분리 시작** | 독립심, 모험심 |
| **끝이 두 갈래** | 다재다능, 다양한 관심사 |

### 4. 운명선(運命線, Fate Line)

손목 중앙에서 시작하여 중지 방향으로 이어지는 세로 선입니다.

<Callout type="info">
**운명선이 없는 경우**: 운명선이 없다고 나쁜 운명이 아닙니다. 오히려 자유로운 삶, 자신이 선택하는 삶을 산다는 의미로 해석됩니다.
</Callout>

| 운명선 특징 | 의미 |
|-----------|------|
| **손목에서 시작하는 선** | 어린 시절부터 방향이 정해진 삶 |
| **손 중간에서 시작** | 30대 이후 방향이 잡힘 |
| **생명선에서 시작** | 가족이나 전통이 중요한 삶 |
| **감정선에서 시작** | 50대 이후 새로운 시작 |
| **깊고 긴 선** | 강한 목표의식, 성공 |

## 손 모양으로 보는 성격

### 손의 4가지 기본 유형

| 손 유형 | 특징 | 성격 |
|--------|------|------|
| **불의 손** (긴 손바닥, 짧은 손가락) | 열정적, 직관적 | 에너지 넘침, 충동적 |
| **흙의 손** (정사각형 손바닥, 짧은 손가락) | 현실적, 실용적 | 성실, 안정 추구 |
| **공기의 손** (정사각형 손바닥, 긴 손가락) | 분석적, 소통 능력 | 지적, 사교적 |
| **물의 손** (긴 손바닥, 긴 손가락) | 감성적, 직관적 | 감수성 풍부, 예술적 |

## 손가락으로 보는 성격

### 엄지손가락

| 특징 | 의미 |
|------|------|
| **길고 강한 엄지** | 의지력, 리더십, 자기 통제력 |
| **짧고 약한 엄지** | 의존적, 감정에 따라 행동 |
| **첫 번째 마디가 두꺼움** | 논리적, 판단력 |
| **두 번째 마디가 두꺼움** | 감성적, 직관적 |

### 검지(집게손가락) — 목성의 손가락

지배력, 야망, 자존감을 나타냅니다.

- **길고 강한 검지**: 리더십, 자신감
- **짧은 검지**: 낮은 자존감, 내향성

### 중지 — 토성의 손가락

책임감, 균형, 운명을 나타냅니다.

### 약지 — 태양의 손가락

예술성, 창의성, 자기 표현을 나타냅니다.

### 새끼손가락 — 수성의 손가락

소통 능력, 지능, 비즈니스 감각을 나타냅니다.

- **길고 강한 새끼손가락**: 뛰어난 소통 능력, 설득력
- **짧은 새끼손가락**: 자기 표현에 어려움

## 손바닥의 특별한 표시들

### 별표(★)

- **감정선에서 별**: 강렬한 사랑 경험
- **두뇌선에서 별**: 창의적 성취
- **운명선에서 별**: 특별한 성공

### 섬(○)

선 위의 섬 모양은 일반적으로 어려움이나 장애물을 나타내지만, 반드시 나쁜 것은 아닙니다.

### 십자(+)

- 손 중앙의 십자(신비로운 십자, Mystic Cross): 직관력, 영적 능력
- 감정선과 두뇌선 사이의 십자: 사랑에 관한 시련

## 손금의 현대적 이해

손금은 예언이 아닌 **경향성**입니다. 손금은 나이에 따라, 생활 방식에 따라, 마음가짐에 따라 변합니다. 이것은 손금 이론 자체가 "운명은 고정되지 않았다"는 것을 암시합니다.

**손금을 보는 바른 마음가짐**:
1. 자기 이해의 도구로 활용하세요
2. 약점을 발견했다면 성장의 기회로 삼으세요
3. 강점을 발견했다면 더 발전시키세요
4. 운명보다 선택이 더 중요합니다
