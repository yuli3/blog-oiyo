## 주식회사 주주총회 결의 정족수

```
보통결의 (일반 사항):
출석 주주 의결권 과반수 + 발행주식 1/4 이상

특별결의 (중요 사항):
출석 주주 의결권 2/3 + 발행주식 1/3 이상
→ 정관 변경, 합병, 해산, 자본 감소 등

특수 결의:
발행주식 총수 3/4 이상 동의 (주식병합 등 특수 사항)

감사 선임 특칙:
3% 초과 의결권 행사 제한 (감사의 독립성 보장)
```

## 소수주주권 지분 요건 총정리

```
1% 이상:
위법행위 유지청구권 (이사·감사)

3% 이상:
주주총회 소집청구권
장부열람권
이사·감사 해임청구권

6개월 보유 + 0.01% (상장) 또는 비상장 1%:
대표소송 (주주 대위소송)

비공개회사 (비상장):
지분율 요건 완화 (보유 기간 요건 없음 경우도)
```

## 자주 틀리는 오답 포인트

```
① 합자회사 무한책임사원 최소 인원
   → 1인 이상 (2인 이상 아님)
   → 합자=무한 1인 이상 + 유한 1인 이상 = 최소 2인

② 법인격 부인 = 주주에게도 책임
   → "법인격 부인"=주주 무한책임 아님
   → 특정 경우에만 배후 주주 추궁

③ 감사 선임 = 이사회 아님
   → 감사는 주주총회에서 선임 (이사회 X)
   → 독립성 보장 위해 3% 초과 의결권 제한

④ 배서의 담보 효력
   → 배서인도 지급 책임 (단순 권리 이전 아님)
   → 배서 연속 끊기면 권리자 자격 없음

⑤ 수표 지급인 = 반드시 은행
   → 어음은 누구든 지급인 가능
   → 수표는 은행만 지급인

⑥ 고지의무 위반 = 해지권, 무효 아님
   → 계약 자체는 유효
   → 위반 사실 안 날 1개월, 계약 3년 내 해지권 행사

⑦ 중복보험 = 이중 지급 아님
   → 실손 원칙으로 보험자들이 비례 분담
   → 실제 손해액 초과 지급 불가

⑧ 주식회사 최소 자본금
   → 없음 (2009년 폐지)
   → 최소 주주 수도 1인 가능

⑨ 이사 해임 = 주주총회 보통결의
   → 특별결의 아님 (이사 선임·해임=보통결의)
   → 단, 정당한 이유 없이 임기 중 해임 시 손해배상

⑩ 무상증자 = 실질 재산 증가 없음
   → 준비금→자본금 계정 이동만
   → 주주 실질 재산 변화 없음 (주가 하락 + 주식 수 증가)
```

## 핵심 개념 카드

**상법 적용 순서** ★★★★★
: 상법(특별법)→민법(일반법)→상관습법→민사관습법.
*암기 포인트: 상→민 순서*

**주주 유한책임** ★★★★★
: 주주는 출자액(납입 주식 대금) 한도만 책임. 개인 재산 책임 없음.
*암기 포인트: 주주=출자액 한도*

**어음 항변 절단** ★★★★★
: 선의 소지인에게 인적 항변 불가. 유통성 보호.
*암기 포인트: 선의=항변불가*

## 실전 퀴즈 (종합)

**Q. 주식회사 합병 시 주주총회 결의 요건과 채권자 보호 방법은?**
> 주주총회 특별결의(출석2/3+발행1/3 이상). 채권자 보호: 1개월 이상 이의 기간 부여, 이의 채권자에게 변제 또는 담보 제공.

**Q. 발행인이 수표를 발행하고 은행 계좌에 자금이 없는 경우 효과는?**
> 수표 부도. 소지인의 소구권 발생(배서인 등 소급 청구). 부정수표단속법 적용 시 형사 처벌 가능. 제시 기간(10일) 이내 제시하지 않으면 소구권 소멸.

**Q. 보험계약에서 최대 선의 원칙이란 무엇인가?**
> 보험계약자·피보험자는 보험자에게 중요 사항을 성실하게 고지해야 함. 선의 기반 계약이기 때문에 고지의무 위반 시 계약 해지권 발생. 일반 매매계약보다 더 높은 수준의 선의 요구.
