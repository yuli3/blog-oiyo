## 조경설계의 기초 — 제도

```
도면의 종류:
- 평면도 / 입면도 / 단면도
- 상세도 / 투시도 / 조감도

선의 종류:
- 실선(외형), 파선(숨은선),
  일점쇄선(중심선), 이점쇄선(가상선)

척도(Scale):
- 축척 1/100, 1/200 등
- 실기 도면 작성의 기본
```

---

## 디자인 원리

```
조경 디자인 원리:
- 통일(Unity)과 변화(Variety)
- 균형(Balance): 대칭·비대칭
- 강조(Emphasis): 초점(Focal Point)
- 율동(Rhythm): 반복·점층
- 척도(Scale)와 비례(Proportion)

조경 구성 요소:
- 점·선·면·형태·질감·색채
```

## 조경 수목의 분류

```
형태별:
- 교목(키 큰 나무) / 관목(키 작은 나무)
- 상록수 / 낙엽수
- 침엽수 / 활엽수

기능별:
- 녹음수(그늘): 느티나무, 플라타너스
- 가로수: 은행나무, 양버즘나무
- 화목류(꽃): 벚나무, 배롱나무
- 생울타리: 쥐똥나무, 사철나무
- 지피식물: 잔디, 맥문동
```

---

## 수목 규격 표기

```
규격 표기법:
- H: 수고(수목 높이, m)
- B: 흉고직경(가슴높이 줄기 지름, cm)
- R: 근원직경(지표면 줄기 지름, cm)
- W: 수관폭(가지 퍼진 너비, m)

표기 예:
- H3.0 × B8 : 수고 3m, 흉고직경 8cm (교목)
- H1.5 × W0.8 : 수고 1.5m, 수관폭 0.8m (관목)

→ B는 곧은 줄기, R은 분지·과수류에 주로 사용
```

## 식재 기법

```
식재 양식:
- 정형식 식재: 단식·대식·열식·교호식재
- 자연식 식재: 부등변삼각형 식재, 군식

기능 식재:
- 차폐식재(가림), 경관식재
- 녹음식재, 방풍·방화·방음 식재
- 생태복원 식재

→ 목적에 맞는 수종·배치 선택이 핵심
```

---

## 이식과 식재 시기

```
이식(移植):
- 뿌리분(根鉢) 떠서 옮김
- 분의 크기: 근원직경의 4~5배 정도

식재 적기:
- 낙엽수: 봄(해빙 후)·가을(낙엽 후)
- 상록수: 봄·장마기·초가을
- 이식 어려운 수목: 사전 단근(뿌리돌림)

활착 관리:
- 지주목 설치, 관수, 멀칭, 전정
```

---

## 핵심 암기 포인트

```
- 선: 실선·파선·일점쇄선·이점쇄선
- 디자인 원리: 통일·균형·강조·율동·비례
- 교목/관목, 상록/낙엽, 침엽/활엽
- 규격: H(수고)·B(흉고직경)·R(근원직경)·W(수관폭)
- 식재: 정형식(열식·교호) / 자연식(부등변삼각형)
- 뿌리분 = 근원직경의 4~5배
```

## 자주 묻는 질문

**Q. B와 R 규격은 어떻게 구분하나요?**
A. B(흉고직경)는 가슴 높이(약 1.2m)에서 잰 줄기 지름으로 곧은 교목에, R(근원직경)은 지표면 줄기 지름으로 밑동에서 가지가 갈라지는 수목·과수류에 주로 씁니다.

**Q. 식재 적기가 시험에 자주 나오나요?**
A. 네. 낙엽수(봄·가을)와 상록수(봄·장마기·초가을)의 시기 차이, 뿌리돌림 같은 활착 기법은 필기·실기 모두에서 빈출입니다.

**Q. 실기 도면은 어떻게 연습하나요?**
A. 기출 대상지를 반복해 평면도→단면도→식재 배치 순으로 시간을 재며 손도면으로 그려보는 것이 가장 효과적입니다. 수목 규격 표기와 범례 작성도 함께 익혀야 합니다.
