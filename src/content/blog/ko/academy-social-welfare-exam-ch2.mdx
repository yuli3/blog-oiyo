## 인간행동과 사회환경 과목 개요

출제 비중: 사회복지사 2급 핵심 과목 중 하나
시험 출제 유형: 이론가별 개념, 발달 단계 구분, 적용 사례

학습 핵심:

## 인간 발달의 기본 원리

```
1. 일정한 순서로 진행 (방향성):
→ 머리→발끝 (두미 방향)
→ 중심→말초 (근원 방향)
→ 전체→부분 (일반→특수)

2. 연속적이나 속도는 일정하지 않음

3. 개인차 존재

4. 발달의 결정적 시기 (Critical Period):
→ 특정 능력 발달에 최적인 시기
→ 이 시기를 놓치면 후에 발달이 어려움
```

## 프로이트 (Freud) 심리성적 발달이론

```
핵심 개념: 무의식, 리비도(성 에너지), 방어기제

인성 구조:
- 원초아 (Id): 쾌락 원리, 무의식
- 자아 (Ego): 현실 원리, 의식
- 초자아 (Super Ego): 도덕 원리

발달 5단계:
1단계 구강기 (0~1세): 입·수유
2단계 항문기 (1~3세): 배변 훈련
3단계 남근기 (3~6세): 성기에 관심, 오이디푸스 콤플렉스
4단계 잠복기 (6~12세): 성적 관심 잠복, 사회화
5단계 생식기 (12세 이후): 이성에 관심, 성숙

핵심 방어기제:
- 억압: 의식에서 무의식으로 밀어냄
- 부정: 현실 거부
- 합리화: 그럴듯한 이유 대기
- 투사: 자신의 감정을 타인에게 귀인
- 승화: 충동을 사회적으로 허용된 방식으로 표출
```

## 에릭슨 (Erikson) 심리사회적 발달이론

```
특징: 전 생애 발달 (영아~노인), 사회적 관계 강조

8단계 발달 과업:

1단계 (0~1세): 신뢰 vs 불신 → 희망
2단계 (1~3세): 자율 vs 수치심 → 의지
3단계 (3~6세): 주도 vs 죄의식 → 목적
4단계 (6~12세): 근면 vs 열등감 → 유능감
5단계 (12~20세): 정체감 vs 역할혼란 → 충성
6단계 (20~40세): 친밀감 vs 고립 → 사랑
7단계 (40~65세): 생산성 vs 침체 → 배려
8단계 (65세 이후): 자아통합 vs 절망 → 지혜

→ 각 단계를 성공적으로 해결하면 긍정적 자아 발달
→ 실패 시 다음 단계에서 갈등 지속
```

## 피아제 (Piaget) 인지발달이론

```
핵심 개념:
- 도식 (Schema): 사물 이해 틀
- 동화 (Assimilation): 새 정보를 기존 도식에 통합
- 조절 (Accommodation): 도식 자체를 변경
- 평형 (Equilibration): 동화·조절 균형 상태

4단계 인지 발달:

1단계 감각운동기 (0~2세):
→ 감각과 운동으로 세상 탐색
→ 대상 영속성 발달 (18개월 전후)

2단계 전조작기 (2~7세):
→ 언어 발달, 상징 사용
→ 자아중심성 (타인 관점 이해 어려움)
→ 보존 개념 부재

3단계 구체적 조작기 (7~12세):
→ 논리적 사고 가능 (구체적 대상)
→ 보존 개념 획득
→ 탈중심화 (타인 관점 이해)

4단계 형식적 조작기 (12세 이후):
→ 추상적·가설적 사고 가능
→ 연역 추론 가능
```

## 매슬로우 (Maslow) 욕구 위계 이론

```
5단계 욕구 (아래에서 위로 충족):

5단계 자아실현 욕구 (Self-Actualization)
   ↑
4단계 존경 욕구 (Esteem): 인정, 지위
   ↑
3단계 사회적 욕구 (Belonging): 소속감, 사랑
   ↑
2단계 안전 욕구 (Safety): 신체 안전, 안정
   ↑
1단계 생리적 욕구 (Physiological): 식욕, 수면, 성욕

핵심 원칙:
→ 하위 욕구가 충족되어야 상위 욕구로 진행
→ 결핍 욕구 (1~4단계) vs 성장 욕구 (5단계)
→ 사회복지 실천: 기본 생리·안전 욕구부터 충족 지원
```

## 행동주의 이론 (파블로프·스키너)

```
파블로프 (Pavlov) - 고전적 조건화:
→ 자극과 반응의 연합 학습
→ 무조건 자극(US) + 조건 자극(CS) → 조건 반응(CR)

스키너 (Skinner) - 조작적 조건화:
→ 행동의 결과(보상/처벌)로 행동 강화·약화

강화 유형:
- 정적 강화: 바람직한 자극 제공 (보상)
- 부적 강화: 불쾌한 자극 제거 (고통 제거)
- 정적 처벌: 불쾌한 자극 제공
- 부적 처벌: 바람직한 자극 제거

사회복지 적용:
→ 강화 원리를 활용한 클라이언트 행동 변화 개입
```

## 체계이론과 생태체계이론

```
체계이론 핵심 개념:
- 경계 (Boundary): 체계와 환경 구분
- 투입 (Input): 환경에서 체계로 에너지 유입
- 산출 (Output): 체계에서 환경으로 에너지 방출
- 피드백 (Feedback): 산출이 체계에 영향
- 항상성 (Homeostasis): 균형 유지 경향

브론펜브레너 (Bronfenbrenner) 생태체계이론:
- 미시체계: 개인과 직접 접촉 (가족, 학교)
- 중간체계: 미시체계 간 관계 (가족-학교 관계)
- 외체계: 개인에 간접 영향 (부모 직장 등)
- 거시체계: 문화, 법, 이념
- 시간체계: 시간에 따른 변화

→ 인간을 환경과의 상호작용으로 이해
```

## 핵심 암기 정리

```
이론가별 핵심 키워드:

프로이트: 리비도, 구강기→항문기→남근기→잠복기→생식기
에릭슨: 8단계, 심리사회적, 신뢰vs불신(영아)~자아통합(노년)
피아제: 도식·동화·조절, 4단계 인지발달, 대상영속성
매슬로우: 5단계 욕구 위계, 자아실현 최상위
스키너: 조작적 조건화, 정적강화·부적강화
브론펜브레너: 미시-중간-외-거시-시간 체계
```

## 자주 묻는 질문

**Q. 이론가가 너무 많아 헷갈리는데 어떻게 공부하나요?**
A. 이론가 이름과 핵심 키워드를 짝지어 암기하는 것이 효과적입니다. 예: 피아제=인지발달, 에릭슨=심리사회적, 프로이트=심리성적으로 정리하세요.

**Q. 발달 단계 숫자(나이)를 다 외워야 하나요?**
A. 정확한 나이보다 단계의 순서와 각 단계 특징이 더 중요합니다. 특히 에릭슨 8단계, 피아제 4단계의 핵심 개념을 먼저 익히세요.
