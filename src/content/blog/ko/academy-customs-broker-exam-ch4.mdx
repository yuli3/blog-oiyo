## 무역실무란?

```
무역실무:
→ 수출입 계약부터 운송·보험·결제·통관까지
  무역 거래의 전 과정에 대한 실무 지식

관세사에게 왜 필수인가:
- 통관 대리의 전제가 무역 거래 이해
- 인코텀즈 → 과세가격(운임 포함 여부) 판단
- 무역서류 → 신고·심사의 근거
```

---

## 인코텀즈(Incoterms) 2020

```
인코텀즈:
→ 국제상업회의소(ICC)가 제정한 무역 거래조건
→ 매도인·매수인의 비용·위험 분기점을 규정
→ 2020년판 11개 조건

[모든 운송수단용] 7개
- EXW (공장인도)
- FCA (운송인인도)
- CPT (운송비지급인도)
- CIP (운송비·보험료지급인도)
- DAP (도착지인도)
- DPU (도착지양하인도)
- DDP (관세지급인도)

[해상·내수로 전용] 4개
- FAS (선측인도)
- FOB (본선인도)
- CFR (운임포함인도)
- CIF (운임·보험료포함인도)
```

---

## 핵심 조건 비교 — 위험·비용 분기점

```
EXW: 매도인 공장에서 인도 (매수인 부담 최대)
FOB: 본선 적재 시 위험 이전 (해상)
CIF: 매도인이 운임·보험까지 부담, 위험은 본선 적재 시 이전
DDP: 매도인이 수입통관·관세까지 부담 (매도인 부담 최대)

주의:
- CIF·CFR: 비용 분기점(도착항)과 위험 분기점(선적항)이 다름!
- 보험 부보 의무: CIF·CIP만 매도인에게 있음
  · CIF는 최소담보(C), CIP는 최대담보(A) 권장
```

---

## 대금 결제 방식

```
1. 신용장 (L/C, Letter of Credit)
→ 은행이 대금 지급 보증 → 가장 안전
→ 서류 일치(엄격일치 원칙)가 핵심

2. 추심 (Collection)
- D/P(지급인도): 대금 지급해야 서류 인도
- D/A(인수인도): 환어음 인수하면 서류 인도(외상)

3. 송금 (T/T)
- 사전송금 / 사후송금 / 분할

4. 기타: 청산계정, 국제팩토링, 포페이팅
```

## 주요 무역서류

```
상업서류:
- 상업송장(Commercial Invoice): 대금청구·과세가격 근거
- 포장명세서(Packing List)
- 원산지증명서(C/O): FTA 특혜관세 근거

운송서류:
- 선하증권(B/L, Bill of Lading): 해상, 권리증권성
- 항공화물운송장(AWB): 항공, 권리증권성 없음
- 복합운송증권

보험서류:
- 적하보험증권 (해상보험)

금융서류:
- 환어음(Bill of Exchange)
```

## 무역영어 빈출 표현

```
- Shipment / Delivery: 선적·인도
- Consignee: 수하인 / Shipper: 송하인
- Letter of Credit (L/C): 신용장
- Bill of Lading (B/L): 선하증권
- Demurrage: 체선료 / Detention: 지체료
- Partial shipment: 분할선적
- Transshipment: 환적
- Force Majeure: 불가항력
```

## 핵심 암기 포인트

```
- 인코텀즈 2020: 11개 (전운송 7 + 해상 4)
- 보험 의무: CIF(최소담보)·CIP(최대담보)만
- CIF·CFR: 비용·위험 분기점 불일치
- L/C: 은행 지급보증, 엄격일치 원칙
- D/P(지급)·D/A(인수)
- B/L: 권리증권 / AWB: 권리증권 아님
```

## 자주 묻는 질문

**Q. FOB와 CIF의 가장 큰 차이는 무엇인가요?**
A. FOB는 본선 적재까지만 매도인이 부담하고, CIF는 목적항까지의 운임·보험료를 매도인이 부담합니다. 단 위험 이전 시점은 둘 다 '본선 적재 시'로 같습니다 — 이 비용·위험 분기점의 차이가 핵심입니다.

**Q. 신용장 거래에서 '엄격일치 원칙'이란?**
A. 제출 서류가 신용장 조건과 문면상 엄격히 일치해야 은행이 대금을 지급한다는 원칙입니다. 사소한 불일치(하자)도 지급 거절 사유가 될 수 있습니다.

**Q. 인코텀즈는 관세평가와 어떻게 연결되나요?**
A. 한국은 CIF 기준 과세이므로, 거래조건이 FOB면 운임·보험료를 가산해 과세가격을 산출해야 합니다. 인코텀즈 이해가 곧 정확한 과세가격 산정의 전제입니다.
