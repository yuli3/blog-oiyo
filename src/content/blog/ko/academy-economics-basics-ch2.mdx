## 수요의 법칙

```
수요 법칙:
가격 ↑ → 수요량 ↓ (역의 관계)
가격 ↓ → 수요량 ↑

수요곡선: 우하향

수요량 변화 vs 수요 변화:
- 수요량 변화: 가격 변화 → 곡선 위 이동
- 수요 변화: 가격 외 요인 → 곡선 자체 이동 (shift)
```

### 수요 이동 요인

```
수요 증가 (오른쪽 이동):
- 소득 증가 (정상재)
- 대체재 가격 상승
- 보완재 가격 하락
- 소비자 선호 증가
- 미래 가격 상승 기대

수요 감소 (왼쪽 이동):
위 요인의 반대

열등재 (Inferior Good):
- 소득 증가 → 수요 감소
- 예: 저가 라면, 대중교통
```

## 공급의 법칙

```
공급 법칙:
가격 ↑ → 공급량 ↑ (정의 관계)

공급곡선: 우상향

공급 이동 요인:
공급 증가 (오른쪽 이동):
- 생산비 하락 (임금·원자재 가격 하락)
- 기술 진보
- 공급자 수 증가
- 세금 감소·보조금 증가

공급 감소 (왼쪽 이동): 위 반대
```

## 균형가격과 균형거래량

```
균형: 수요량 = 공급량

초과 수요 (수요 > 공급):
→ 가격 상승 압력 → 균형 회복

초과 공급 (공급 > 수요):
→ 가격 하락 압력 → 균형 회복

균형 변화 예시:
수요 증가 → 균형가격↑, 균형거래량↑
공급 감소 → 균형가격↑, 균형거래량↓
수요·공급 동시 증가 → 균형거래량↑, 가격은 상대 변화에 따라
```

## 가격 탄력성

### 수요의 가격 탄력성 (PED)

```
PED = 수요량 변화율(%) / 가격 변화율(%)
    = (ΔQ/Q) / (ΔP/P)

탄력성 구분:
- |PED| > 1: 탄력적 (사치재·대체재 많은 상품)
- |PED| < 1: 비탄력적 (필수재·대체재 없는 상품)
- |PED| = 1: 단위 탄력적
- |PED| = 0: 완전 비탄력적 (수직 수요곡선)
- |PED| = ∞: 완전 탄력적 (수평 수요곡선)

탄력성 결정 요인:
- 대체재 수: 많을수록 탄력적
- 필수재 여부: 필수재일수록 비탄력적
- 지출 비중: 높을수록 탄력적
- 기간: 길수록 탄력적
```

### 탄력성과 총수입

```
총수입 (TR) = P × Q

탄력적 수요:
가격 ↑ → 수요량 대폭 감소 → TR 감소
가격 ↓ → 수요량 대폭 증가 → TR 증가

비탄력적 수요:
가격 ↑ → 수요량 소폭 감소 → TR 증가
가격 ↓ → 수요량 소폭 증가 → TR 감소

단위 탄력적:
가격 변화 → TR 변화 없음
```

## 소비자잉여와 생산자잉여

```
소비자잉여: 지불 용의 금액 - 실제 지불 금액
생산자잉여: 실제 수취 금액 - 최소 수취 용의 금액

사회적 총잉여 = 소비자잉여 + 생산자잉여
→ 자유 시장 균형에서 최대화 (효율적 배분)

가격 통제 → 총잉여 감소 (자중손실 발생)
```

## 핵심 개념 카드

**수요·공급 이동 vs 이동** ★★★★★
: 가격 변화=수요량·공급량 변화(곡선 위 이동). 다른 요인=수요·공급 변화(곡선 shift).
*암기 포인트: 가격=점이동, 비가격=곡선이동*

**탄력성과 총수입** ★★★★★
: 탄력적=가격 내리면 TR 증가. 비탄력적=가격 올리면 TR 증가.
*암기 포인트: 탄력적=할인 효과 큼, 비탄력적=가격 인상 효과 큼*

**수요 탄력성 결정 요인** ★★★★☆
: 대체재 多·사치재·지출비중 高·장기 → 탄력적. 필수재·단기 → 비탄력적.
*암기 포인트: 대체재 많을수록 탄력적*

## 실전 퀴즈

**Q. 쌀 가격이 올라도 수요량이 별로 줄지 않는 이유를 탄력성으로 설명하시오.**
> 쌀은 필수재이고 대체재가 제한적. 수요의 가격 탄력성이 비탄력적(|PED|&lt;1). 가격 상승 시 수요량 감소폭 작음.

**Q. 수요 탄력성이 2인 상품의 가격을 10% 내리면 수요량은?**
> 수요량 변화율 = PED × 가격 변화율 = 2 × 10% = 20% 증가.
