# 비밀번호 생성기

"123456", "password", "qwerty" — 세계에서 가장 많이 쓰이는 비밀번호들입니다. 이런 비밀번호는 해커가 1초도 안 걸려 뚫을 수 있습니다. 진짜 강력한 비밀번호를 지금 바로 만들어 보세요.

## 비밀번호 강도 기준

| 강도 | 길이 | 구성 | 해독 시간 (브루트포스 기준) |
|---|---|---|---|
| 매우 약함 | 6자 이하 | 숫자만 | 즉시 |
| 약함 | 8자 | 소문자만 | 수분 |
| 보통 | 10자 | 대+소+숫자 | 수개월 |
| 강함 | 12자 | 대+소+숫자+특수 | 수년 |
| 매우 강함 | 16자+ | 모든 문자 + 랜덤 | 수백년+ |

<Callout type="tip">
**패스프레이즈(Passphrase)**: "CoffeeBlue!Mountain2024" 같이 기억하기 쉬운 단어 조합도 강력한 비밀번호가 됩니다. 길이가 복잡성보다 중요합니다.
</Callout>

## 비밀번호 보안 원칙

| 원칙 | 설명 |
|---|---|
| **사이트마다 다르게** | 한 곳이 유출되면 전부 위험 |
| **12자 이상** | 최소 12자, 중요 계정은 16자+ |
| **정기 변경** | 중요 계정은 6개월마다 변경 |
| **비밀번호 관리자 사용** | 1Password, Bitwarden, KeePass 등 |
| **2단계 인증 병행** | SMS보다 인증 앱(Google Authenticator) 권장 |

## 절대 사용하지 말 것

- 이름, 생년월일, 전화번호
- 연속 숫자/문자: 1234, abcd
- 키보드 패턴: qwerty, asdf
- 단순 단어 + 숫자: password123
- 이전 비밀번호 재사용

<Callout type="warning">
이 생성기는 **브라우저 내에서만 동작**하며 생성된 비밀번호를 서버에 저장하거나 전송하지 않습니다. 생성 후 즉시 복사해 안전한 곳에 보관하세요.
</Callout>
