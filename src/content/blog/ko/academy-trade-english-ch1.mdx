## 무역영어 시험 개요

```
자격 개요:
→ 대한상공회의소 시행 국가자격
→ 무역 실무·무역 관련 영문서 처리 능력 평가
→ 1급 (고급), 2급 (중급), 3급 (초급)

1급 시험 구성:
→ 필기: 무역 영어 (영문 독해·영작·무역 실무)
→ 실기: 영문 서신 작성, 수출입 서류 처리

주요 출제 영역:
→ 무역 계약: 청약·승낙·인코텀즈·분쟁 해결
→ 결제: 신용장·추심·전신 송금
→ 운송·보험: 선하증권·적하보험·해상 사고
→ 세관·통관: 수출입 신고·원산지 규정
→ 클레임: 하자 통보·중재·배상

합격 전략:
→ 무역 용어 영어 정의 암기 필수
→ 신용장 조항 해석 연습
→ 인코텀즈 2020 조건별 위험·비용 이전 시점 완전 숙지
→ 무역 서신 형식과 관용 표현 암기
```

## 무역 계약 성립

```
국제 물품 매매 계약 (CISG):
→ UN 국제 물품 매매 계약에 관한 협약
→ 94개국 이상 가입 (한국 2005년 발효)
→ 당사자 간 별도 합의로 배제 가능

계약 성립 절차:

청약 (Offer):
→ 특정 조건으로 계약을 체결하겠다는 의사 표시
→ 확정성: 품목·수량·가격 명시
→ 청약의 효력: 상대방에게 도달 시 발생
→ 청약 철회: 승낙 발송 전까지 가능 (CISG)

승낙 (Acceptance):
→ 청약 내용 전부 동의 → 계약 성립
→ 조건부 승낙 = 반청약 (Counter-offer)
→ 승낙의 효력: CISG — 도달주의 (상대방 도달 시)
  영미법 — 발신주의 (발송 시)
→ 기간 내 승낙 원칙

계약 필수 조건 (3P):
→ Price (가격): 단가·통화·가격 조건 (인코텀즈)
→ Payment (결제): 방법·기간 (L/C·T/T)
→ Packing & Delivery (포장·인도): 조건·시기

계약서 주요 조항:
→ Arbitration Clause: 중재 조항 (분쟁 해결)
→ Force Majeure: 불가항력 (전쟁·천재지변)
→ Governing Law: 준거법 (어느 나라 법 적용)
→ Warranty: 하자 보증 기간·조건
```

## 인코텀즈 2020 (Incoterms 2020)

```
인코텀즈의 역할:
→ ICC 발행 국제 무역 조건 해석 통일 규칙
→ 매도인·매수인 간 위험·비용·서류 의무 명확화
→ 11개 조건 (2020 개정판)

해상 전용 조건 (4개):
→ FAS (Free Alongside Ship):
  매도인: 선측까지 인도, 수출 통관 부담
  매수인: 선측부터 모든 비용·위험
→ FOB (Free On Board):
  매도인: 본선 적재까지 / 수출 통관
  매수인: 본선 적재 후 모든 비용·위험
  가장 많이 사용
→ CFR (Cost and Freight):
  매도인: 목적항까지 운임 부담
  위험: 선적항 본선 적재 후 매수인
→ CIF (Cost, Insurance and Freight):
  매도인: 운임 + 해상 보험료 부담
  위험: 선적항 본선 적재 후 매수인

복합 운송 포함 조건 (7개):
→ EXW (Ex Works): 공장 인도 — 매도인 최소 의무
→ FCA (Free Carrier): 운송인 인도 — FOB 대체 권장
→ CPT (Carriage Paid To): CFR의 복합 운송 버전
→ CIP (Carriage and Insurance Paid To):
  CIF 복합 운송 버전 — 보험 최고 조건(110%)
→ DAP (Delivered at Place): 목적지 관세 미지급 인도
→ DPU (Delivered at Place Unloaded): 양하 후 인도
→ DDP (Delivered Duty Paid): 매도인 최대 의무

핵심 비교:
→ E 조건: 매도인 최소 의무 (EXW)
→ F 조건: 주 운임 매수인 부담
→ C 조건: 주 운임 매도인 부담 (위험은 선적지 이전)
→ D 조건: 목적지 인도 (매도인 최대 의무)
```

## 신용장 (Letter of Credit)

```
신용장의 의의:
→ 은행이 수입업자 대신 수출업자에게 지급 보증
→ 위험 감소: 수출업자 — 미결제 위험 / 수입업자 — 상품 미인도 위험
→ UCP 600: 신용장 통일 규칙 (ICC)

신용장 당사자:
→ 개설의뢰인 (Applicant): 수입업자
→ 개설은행 (Issuing Bank): 수입국 은행 — 지급 보증
→ 수익자 (Beneficiary): 수출업자
→ 통지은행 (Advising Bank): 수출국 은행 — 신용장 전달
→ 매입은행 (Negotiating Bank): 서류 매입·대금 지급

신용장 결제 과정:
① 매매 계약 체결
② 수입업자 → 개설은행: 신용장 개설 의뢰
③ 개설은행 → 수출업자: 신용장 통지
④ 수출업자: 선적 → 서류 준비
⑤ 수출업자 → 매입은행: 서류 제시·네고(매입)
⑥ 매입은행 → 개설은행: 서류 송부·대금 청구
⑦ 개설은행 → 수입업자: 서류 인도·대금 수령
⑧ 수입업자: 서류로 화물 수령

신용장 종류:
→ 취소불능 신용장: 당사자 합의 없이 취소 불가 (원칙)
→ 일람불 (Sight) L/C: 서류 제시 즉시 지급
→ 기한부 (Usance) L/C: 만기 후 지급 (60일·90일)
→ 확인 신용장: 제2은행의 추가 보증
→ 양도가능 신용장: 수익자가 제3자에게 양도 가능
→ 내국 신용장 (Local L/C): 국내 거래 신용장

하자 서류 (Discrepancy):
→ 선하증권·상업 송장·포장 명세서 내용 불일치
→ 개설은행 → 서류 거절 권리
→ 주요 하자: 선적 기일 초과, 금액 불일치, 서명 미비
```

## 무역 영문 서신

```
무역 서신의 구성:
→ Letterhead (회사명·주소)
→ Date (날짜)
→ Reference Number (참조 번호)
→ Recipient's Address (수신인 주소)
→ Salutation (인사: Dear Mr./Ms. Smith,)
→ Body (본문)
→ Complimentary Close (맺음말: Yours sincerely,)
→ Signature (서명·직함)

주요 서신 유형별 표현:

거래 조회 (Inquiry):
→ "We have learned of your company through..."
→ "We are interested in your products and would like to..."
→ "Please send us your latest catalogue and price list."

오퍼 (Offer):
→ "We are pleased to offer you the following:"
→ "This offer is subject to our final confirmation."
→ "The offer is valid until [날짜]."

주문 (Order):
→ "We would like to place the following order:"
→ "Please confirm receipt of this order at your earliest convenience."

클레임 (Claim):
→ "We regret to inform you that the goods arrived in a damaged condition."
→ "Upon inspection, we found a shortage of 50 units."
→ "We request you to compensate us for the damage caused."

클레임 답변:
→ "We apologize for the inconvenience caused."
→ "We are investigating the matter and will revert shortly."
→ "We are prepared to offer a replacement/credit note."
```

## 자주 묻는 질문

**Q. FOB와 CIF의 차이를 간단히 설명해 주세요.**
A. FOB(본선 인도)는 매도인이 수출국 항구에서 본선에 화물을 싣는 순간까지만 책임을 집니다. 이후 운임과 해상 보험료는 매수인(수입업자)이 직접 계약하고 부담합니다. CIF(운임·보험료 포함 인도)는 매도인이 목적항까지의 운임과 해상 보험료를 부담합니다. 단, 위험의 이전 시점은 FOB와 마찬가지로 선적항의 본선 적재 시점입니다. 수출업자 입장에서는 CIF가 더 많은 비용을 부담하지만, 선적·보험 계약을 자기가 통제할 수 있는 장점이 있습니다.

**Q. 신용장에서 하자 서류란 무엇이고 어떻게 처리되나요?**
A. 하자 서류(Discrepant Documents)란 신용장 조건과 일치하지 않는 서류입니다. 예를 들어 신용장에 지정된 선적 기일을 넘겼거나, 상업 송장의 금액이 신용장 금액을 초과하거나, 서류 간 화물 설명이 불일치하는 경우입니다. 개설은행은 서류를 검토해 하자를 발견하면 5영업일 이내에 거절 통지를 할 수 있습니다. 이 경우 수출업자는 수정 서류를 재제시하거나, 개설의뢰인(수입업자)의 하자 수리(Waiver) 승인을 요청해야 합니다.
