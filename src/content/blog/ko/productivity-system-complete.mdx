뇌는 아이디어를 저장하기 위한 것이 아니라 **아이디어를 만들기 위한** 것입니다. 정보와 할 일을 모두 머릿속에 저장하려고 할 때, 뇌는 과부하가 걸립니다. 최고의 생산성 시스템들은 공통적으로 한 가지를 추구합니다: **뇌를 자유롭게 하는 것**.

## GTD (Getting Things Done) — 데이비드 앨런

### 5단계 GTD 시스템

**1단계: 수집 (Capture)**
머릿속에 있는 모든 것을 외부 시스템에 담아냅니다. "열린 루프"(미결 사항)가 인지 부하를 만들기 때문입니다.

- 받은 편지함(인박스) 설정: 노트, 이메일, 물리적 트레이
- 떠오르는 모든 것을 즉시 수집

**2단계: 명확화 (Clarify)**
수집된 것들을 처리합니다. 각 항목에 대해 묻습니다: "이것은 실행 가능한가?"

- 실행 가능 → 다음 행동이 무엇인가?
- 실행 불가 → 삭제, 참고, 언젠가/아마도 목록

**2분 규칙**: 2분 안에 할 수 있으면 즉시 합니다.

**3단계: 정리 (Organize)**
명확화된 항목을 올바른 위치에 배치합니다.

| 범주 | 설명 |
|------|------|
| 다음 행동 | 즉시 할 수 있는 구체적 행동 |
| 프로젝트 | 2개 이상의 행동이 필요한 것 |
| 기다리는 것 | 다른 사람을 기다리는 것 |
| 언젠가/아마도 | 지금은 아니지만 나중에 할 수도 |
| 참고 자료 | 실행 불필요, 정보만 |
| 달력 | 특정 날짜/시간에 할 것 |

**4단계: 검토 (Reflect)**
시스템을 신뢰하려면 정기적으로 업데이트해야 합니다.

- **일간 검토**: 오늘의 할 일과 달력 확인
- **주간 검토** (가장 중요): 매주 1시간, 전체 시스템 검토 및 업데이트

**5단계: 실행 (Engage)**
4가지 기준으로 다음 행동 선택: 맥락, 가용 시간, 가용 에너지, 우선순위

## 제텔카스텐 (Zettelkasten) — 니클라스 루만

독일 사회학자 루만이 30권의 책을 쓴 비결. "메모 상자"라는 뜻의 지식 관리 시스템입니다.

### 핵심 원칙

**원자적 메모 (Atomic Notes)**: 메모 하나에 아이디어 하나. 짧고 집중적으로.

**자신의 말로**: 그대로 인용하지 말고 자신의 이해로 다시 씁니다.

**링크하기**: 관련 메모들을 서로 연결합니다. 시간이 지남에 따라 지식의 그물망이 형성됩니다.

**맥락 기록**: 왜 이것이 중요한지, 다른 것과 어떻게 연결되는지 씁니다.

### 3가지 메모 유형

| 유형 | 설명 |
|------|------|
| **Fleeting Notes** | 즉흥적 아이디어 포착. 나중에 처리 |
| **Literature Notes** | 읽은 것에서 배운 것. 자신의 말로 |
| **Permanent Notes** | 정제된 최종 아이디어. 영구 보관 |

### 추천 도구

- **Obsidian**: 무료, 로컬 마크다운 기반, 링크 기능 탁월
- **Roam Research**: 양방향 링크 선구자
- **Notion**: 데이터베이스와 통합, 팀 협업
- **Bear**: 맥/아이폰, 심플한 메모

## 세컨드 브레인 (Building a Second Brain) — 티아고 포르테

디지털 노트를 활용하여 "두 번째 뇌"를 구축하는 방법론입니다.

### CODE 방법

**C — Capture (포착)**: 가치 있는 정보 저장

**O — Organize (정리)**: 실행 가능성 기준으로 정리

**D — Distill (정제)**: 핵심만 남기기. "점진적 요약" — 처음에는 형광펜, 두 번째는 굵게, 세 번째는 요약 노트

**E — Express (표현)**: 저장이 아닌 창조를 위해 활용

### PARA 폴더 시스템

| 폴더 | 내용 | 예시 |
|------|------|------|
| **P** rojects | 현재 진행 중인 프로젝트 | "6월 프레젠테이션 준비" |
| **A** reas | 지속적으로 관리하는 영역 | "건강", "재무", "학습" |
| **R** esources | 관심 주제의 참고 자료 | "심리학", "투자" |
| **A** rchive | 완료/비활성화된 것들 | 이전 프로젝트 |

## 3가지 시스템 통합

| 시스템 | 최적 용도 |
|--------|---------|
| GTD | 할 일 관리, 실행 추적 |
| 제텔카스텐 | 지식 구축, 창의적 사고 |
| 세컨드 브레인 | 콘텐츠 수집, 프로젝트 관리 |

**추천 통합 방법**:
- 할 일: GTD (Todoist, Things, OmniFocus)
- 지식/메모: 제텔카스텐 방식의 Obsidian
- 프로젝트 문서: Notion (PARA 구조)

<Callout type="tip">
**시작 조언**: 완벽한 시스템 구축에 집착하지 마세요. 가장 간단한 인박스 하나로 시작하세요. 메모 앱에 떠오르는 것을 적는 것부터, 그것이 모든 생산성 시스템의 시작입니다.
