## 중개계약 유형

```
일반 중개계약:
여러 개업공인중개사에게 동시 의뢰 가능
계약 기간 자유
가장 일반적

전속 중개계약:
1개 중개사에게만 의뢰
계약 기간: 3개월 이내
2주 1회 이상 업무처리 상황 통보

독점 중개계약:
전속과 유사하나 더 강한 독점권
의뢰인도 직접 거래 불가
```

---

## 중개대상물 확인·설명서

```
작성 의무:
중개 완성 전 확인·설명서 작성
의뢰인에게 교부

포함 내용:
등기부 기재 사항 (소유권·저당권 등)
실제 권리 관계
입지·환경 조건
공법상 이용 제한
관리비·공과금

주택 임대차:
임대차 계약 존재 여부
선순위 임차인 여부
확정일자 여부

보관:
5년간 보존 의무
```

---

## 중개보수

```
중개보수율:
국토교통부령으로 정한 범위 내
시·도 조례로 결정

주택:
매매: 거래금액별 0.4~0.9%
임대차: 0.3~0.8%

주택 외:
매매·교환: 0.9% 이내
임대차: 0.8% 이내

한도:
매매 5억 = 최대 250만원 (0.5%)

납부 시기:
계약 체결 후 (거래 완성 시)
중도해제 → 소정 보수 청구 가능

이중계약:
쌍방 중개 시 각각 받음 (합산 한도 초과 불가)
```

## 손해배상 및 보증

```
손해배상:
중개사 고의·과실로 손해 발생 시 책임

공제 가입 의무:
개인: 1억원 이상
법인: 2억원 이상

계약 해제:
중도 해제 시 중개사의 보수 청구 권리
발생한 비용 한도에서 청구

비밀 유지:
의뢰인 비밀 누설 금지
```

## 핵심 개념 카드

**전속중개계약=3개월+2주1회보고** ★★★★★
: 3개월 이내 기간, 2주 1회 업무처리 통보.
*암기 포인트: 전속=3개월·2주1회*

**중개보수=시도조례** ★★★★★
: 국토부령 범위 내에서 시·도 조례로 결정.
*암기 포인트: 보수=시도조례*

**확인설명서 보존=5년** ★★★★☆
: 작성·교부 후 5년 보존.
*암기 포인트: 확인설명서=5년*

## 실전 퀴즈

**Q. 전속중개계약에서 의뢰인이 직접 매수인을 찾아 계약한 경우 중개보수는?**
> 전속중개계약에서는 의뢰인이 직접 상대방을 찾아 거래해도 중개사에게 소정 보수 지급. 전속 계약의 핵심은 의뢰인의 직접 거래도 제한하는 것. 단, 개인 간 직거래는 예외 규정 있음.

**Q. 중개보수 한도 초과를 약정한 경우 효력은?**
> 법정 한도 초과 약정은 무효. 공인중개사법에서 상한을 규정한 강행법규. 초과 지급 시 반환 청구 가능. 법정 최고 요율 이내의 협의는 유효.
