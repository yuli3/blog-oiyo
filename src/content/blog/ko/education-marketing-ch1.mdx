## 마케팅(Marketing)이란?

```
마케팅의 정의 (AMA):
→ 고객, 의뢰인, 파트너, 사회 전반에 가치 있는
  제공물을 창조·소통·전달·교환하는 활동·제도·과정

핵심 개념:
→ 욕구 (Needs): 결핍에서 오는 기본 필요 (배고픔)
→ 원츠 (Wants): 구체화된 욕구 (피자가 먹고 싶다)
→ 수요 (Demand): 구매 능력 갖춘 원츠
→ 가치 (Value): 제품이 주는 혜택 - 비용
→ 교환 (Exchange): 가치 있는 것을 대가로 얻는 행위

마케팅 지향성의 발전:
→ 생산 지향 (1900s): 많이 만들면 팔린다
→ 제품 지향: 품질 좋은 제품이 팔린다
→ 판매 지향 (1950s): 적극 판매해야 팔린다
→ 마케팅 지향 (1960s~): 고객 욕구 파악·충족이 핵심
→ 사회 마케팅 지향 (현재): 고객 + 사회 복지 균형
```

## STP 전략

```
STP = 시장 세분화 → 표적 시장 → 포지셔닝

1. 시장 세분화 (Segmentation):
→ 전체 시장을 동질적 하위 그룹으로 분할

세분화 기준:
→ 인구통계적: 연령, 성별, 소득, 직업, 학력
→ 지리적: 국가, 지역, 도시/농촌, 기후
→ 심리적: 라이프스타일, 성격, 가치관
→ 행동적: 구매 빈도, 충성도, 사용 상황

유효한 세분화 조건:
→ 측정 가능성, 접근 가능성, 충분한 규모, 차별성

2. 표적 시장 선정 (Targeting):
→ 비차별적 마케팅: 전체 시장 단일 전략 (코카콜라 초기)
→ 차별적 마케팅: 여러 세그먼트별 다른 전략
→ 집중적 마케팅: 특정 세그먼트에 집중 (틈새시장)
→ 개인화 마케팅: 1:1 맞춤 (아마존 추천)

3. 포지셔닝 (Positioning):
→ 표적 고객 마음속에 경쟁사 대비 독특한 위치 차지
→ 포지셔닝 맵: 2개 축(예: 가격-품질)으로 시각화
→ 재포지셔닝: 이미지 변경 전략
```

## 소비자 구매 행동 모델

```
구매 의사결정 5단계:
1. 문제 인식: 욕구 또는 결핍 인식
2. 정보 탐색: 내부(기억) + 외부(광고, 구전)
3. 대안 평가: 기준별 비교 (가격, 품질, 브랜드)
4. 구매 결정: 선택, 구매 방법, 시기 결정
5. 구매 후 행동: 만족/불만족, 구전, 재구매

구매 결정에 영향하는 요인:
→ 문화적: 문화, 하위문화, 사회 계층
→ 사회적: 준거 집단, 가족, 역할
→ 개인적: 나이, 직업, 라이프스타일, 성격
→ 심리적: 동기, 지각, 학습, 신념·태도

구매 관여도:
→ 고관여 구매: 비싸고, 위험하고, 복잡 (자동차, 주택)
  → 정보 많이 탐색, 신중한 비교
→ 저관여 구매: 저렴하고 반복적 (생필품)
  → 습관적 구매, 충동 구매
```

## 4P 마케팅 믹스

```
제품 (Product):
→ 핵심 제품: 기본 혜택 (스마트폰: 통신)
→ 실제 제품: 기능, 품질, 디자인, 브랜드, 포장
→ 확장 제품: AS, 보증, 배달, 설치

제품 수명 주기 (PLC):
→ 도입기: 인지도 구축, 높은 광고비
→ 성장기: 매출 급증, 경쟁자 진입
→ 성숙기: 성장 정체, 점유율 경쟁
→ 쇠퇴기: 매출 감소, 철수 검토

가격 (Price):
→ 원가 기반: 원가 + 이윤 마진
→ 경쟁 기반: 경쟁사 가격 참고
→ 가치 기반: 고객 지각 가치에 맞게 설정
→ 심리적 가격: 9,900원 (9숫자 효과)
→ 침투 가격: 저가로 시장 점유율 확보
→ 스키밍 가격: 고가로 진입, 이후 인하

유통 (Place):
→ 직접 채널: 제조사 → 소비자
→ 간접 채널: 제조사 → 도매 → 소매 → 소비자
→ 집약적 유통: 최대한 많은 점포 (생필품)
→ 선택적 유통: 선별된 소수 점포 (가전)
→ 전속 유통: 특정 소매점 독점 (명품)

촉진 (Promotion):
→ 광고 (Advertising): 유료 매체 활용
→ PR: 비구매 커뮤니케이션
→ 판매 촉진: 쿠폰, 샘플, 리베이트
→ 인적 판매: 영업사원 직접 판매
→ 다이렉트 마케팅: DM, 이메일, 텔레마케팅
```

## 브랜드 관리

```
브랜드(Brand)의 정의:
→ 판매자의 제품을 경쟁사와 구별하는 이름, 기호, 디자인

브랜드 자산 (Brand Equity):
→ 브랜드가 창출하는 추가적 가치
→ 구성 요소: 브랜드 인지도, 브랜드 연상, 지각된 품질, 충성도

브랜드 전략:
→ 기업 브랜드: 회사명이 곧 브랜드 (삼성, LG)
→ 개별 브랜드: 제품별 독립 브랜드 (P&G: 팸퍼스, 타이드)
→ 라인 확장: 기존 브랜드명으로 동일 카테고리 신제품
→ 브랜드 확장: 기존 브랜드명으로 다른 카테고리 진출

브랜드 포지셔닝 요소:
→ 기능적 혜택: 제품 성능, 품질
→ 감성적 혜택: 사용 시 느낌, 이미지
→ 자아 표현적 혜택: 브랜드를 통한 자아 표현
```

## 디지털 마케팅

```
디지털 마케팅의 특성:
→ 개인화: 데이터 기반 타깃 광고
→ 상호작용: 소비자 참여, 피드백
→ 측정 가능성: 클릭률, 전환율 실시간 측정
→ 비용 효율: 기존 미디어 대비 낮은 단가

주요 채널:
→ SEO (검색엔진 최적화): 검색 결과 상위 노출
→ SEM (검색엔진 마케팅): 유료 검색 광고
→ SNS 마케팅: 인스타그램, 틱톡, 유튜브
→ 콘텐츠 마케팅: 유용한 콘텐츠로 신뢰 구축
→ 이메일 마케팅: 리텐션, 재구매 유도
→ 인플루언서 마케팅: 팔로워 영향력 활용

PESO 모델:
→ Paid: 유료 광고
→ Earned: 보도·구전·바이럴 (무료)
→ Shared: SNS 공유
→ Owned: 자사 홈페이지·블로그

마케팅 퍼널:
→ 인지(Awareness) → 관심(Interest) → 욕구(Desire) → 행동(Action)
→ AIDA 모델
```

## 자주 묻는 질문

**Q. 4P와 4C의 차이는 무엇인가요?**
A. 4P(Product, Price, Place, Promotion)는 기업 관점의 마케팅 믹스입니다. 4C(Customer solution, Cost, Convenience, Communication)는 이를 소비자 관점으로 재해석한 것입니다. 제품 → 고객 솔루션, 가격 → 고객 비용, 유통 → 편의성, 촉진 → 커뮤니케이션으로 봅니다. 현대 마케팅은 점점 소비자 중심으로 이동하고 있습니다.

**Q. 포지셔닝은 어떻게 결정하나요?**
A. 포지셔닝은 두 단계로 결정합니다. 먼저 고객이 중요하게 생각하는 속성(가격, 품질, 디자인 등)을 파악하고, 그 속성을 축으로 하는 포지셔닝 맵에 경쟁사를 배치합니다. 그 다음 경쟁이 덜하거나 자사 강점이 있는 위치를 선택하여 그 위치에 대한 명확한 메시지를 만듭니다.
