## 정치(Politics)란 무엇인가?

```
정치의 다양한 정의:

아리스토텔레스: "인간은 정치적 동물(Zoon Politikon)"
→ 인간은 본성적으로 공동체 생활을 하는 존재

데이비드 이스턴: "가치의 권위적 배분"
→ 희소 자원과 가치를 누가 얼마나 갖느냐의 결정 과정

해럴드 라스웰: "누가, 무엇을, 언제, 어떻게 갖는가"
→ 사회적 자원 배분의 과정

정치의 핵심:
→ 권력(Power)을 둘러싼 경쟁과 협력
→ 집단 결정의 구속력 있는 집행
→ 갈등의 평화적 해결
```

## 권력(Power)의 개념

```
막스 베버의 권력 정의:
→ "다른 사람의 저항에도 불구하고 자신의 의지를 실현하는 능력"

권력의 3유형 (베버):
1. 전통적 권위: 관습과 전통에 기반 (왕권 세습)
2. 카리스마적 권위: 지도자의 특별한 자질에 기반
3. 합법적·합리적 권위: 법과 절차에 기반 (현대 국가)

권력 자원:
- 강제력: 물리적 힘, 군사·경찰
- 부(Wealth): 경제적 자원
- 정보: 지식과 전문성
- 정당성: 권력 행사에 대한 동의
- 네트워크: 사회적 연결망

연성 권력 (Soft Power, 나이):
→ 강제나 보상이 아닌 매력으로 상대방의 행동 변화
→ 문화, 가치, 외교 정책의 호소력
```

## 국가(State)의 이론

```
국가의 구성 요소 (국제법상):
1. 영토 (Territory)
2. 국민 (Population)
3. 주권 (Sovereignty)
4. 정부 (Government)

국가의 기원 이론:

1. 사회계약론:
- 홉스: 만인의 만인에 대한 투쟁 → 계약으로 절대 군주 탄생
- 로크: 자연 상태는 비교적 평화 → 재산 보호 위해 정부 구성
- 루소: 자연 상태는 순수 → 일반 의지에 기반한 국가

2. 역사적 발전론:
→ 국가는 인류의 역사적 발전 과정에서 형성

3. 마르크스주의:
→ 국가는 지배계급의 이익을 대변하는 도구

국가의 기능:
- 안보 기능: 외부 위협으로부터 국민 보호
- 질서 유지: 내부 갈등 해결, 법 집행
- 공공 서비스: 교육, 의료, 인프라
- 경제 규제: 시장 실패 교정
```

## 민주주의(Democracy)

```
민주주의의 어원:
→ 그리스어 demos(인민) + kratos(지배) = 인민의 지배

고대 그리스 민주주의:
→ 직접 민주주의 (아테네)
→ 시민이 직접 광장에서 투표
→ 노예·여성·외국인 제외

현대 민주주의 유형:

1. 직접 민주주의:
→ 시민이 직접 의사 결정 참여
→ 현대: 국민투표, 주민투표로 부분 실현

2. 대의 민주주의 (간접 민주주의):
→ 시민이 대표자를 선출하여 간접 통치
→ 현대 민주주의의 주류 형태

3. 참여 민주주의:
→ 선거 외 시민의 정책 과정 참여 강조
→ 시민 단체, 공청회, 참여 예산제

4. 숙의 민주주의 (Deliberative Democracy):
→ 이성적 토론과 공론화를 통한 의사 결정 강조
→ 공론화위원회 사례
```

## 선거와 선거 제도

```
선거의 기능:
→ 대표자 선출
→ 정치적 참여 보장
→ 정치 엘리트 교체
→ 정권의 정당성 부여

주요 선거 제도:

1. 다수 대표제 (Majoritarian):
- 단순 다수제: 가장 많은 표를 얻은 1명 당선
  → 영국, 미국 하원
  → 장점: 강한 정부 구성
  → 단점: 사표(死票) 발생, 소수 의견 배제

2. 비례 대표제 (Proportional Representation):
- 정당 득표율에 비례하여 의석 배분
  → 독일, 네덜란드
  → 장점: 다양한 의견 반영
  → 단점: 연립 정부 구성, 정치 불안정

3. 혼합제:
- 다수제 + 비례대표 혼합
  → 독일 연방의회: 지역구 + 정당 명부

한국 선거 제도:
→ 국회의원: 소선거구제 + 비례대표
→ 대통령: 단순 다수 직선제
```

## 정치 이데올로기

```
보수주의 (Conservatism):
→ 전통, 질서, 안정, 점진적 변화 강조
→ 시장 자유주의, 강한 안보

자유주의 (Liberalism):
→ 개인의 자유와 권리 강조
→ 법 앞의 평등, 제한적 정부

사회주의 (Socialism):
→ 경제적 평등, 집합적 소유 강조
→ 복지 국가, 재분배 정책

공산주의 (Communism):
→ 계급 없는 사회, 공동 소유
→ 마르크스-레닌주의

파시즘 (Fascism):
→ 극단적 민족주의, 권위주의
→ 20세기 전체주의 체제 (나치즘 포함)

페미니즘 (Feminism):
→ 젠더 평등, 여성의 권리 확대 추구

녹색 정치 (Green Politics):
→ 환경 보호, 지속 가능성 중심
```

## 정치 체제 분류

```
민주주의 vs 권위주의 vs 전체주의:

민주주의:
→ 주기적 선거, 정치 자유, 권력 분립
→ 다당제, 시민 자유 보장

권위주의 (Authoritarianism):
→ 선거 없거나 형식적, 정치 다원주의 제한
→ 일정 범위 사적 자유는 허용
→ 예: 군부 독재, 일당 체제

전체주의 (Totalitarianism):
→ 국가가 개인의 모든 영역 통제
→ 단일 이념, 자유 없음
→ 예: 나치 독일, 스탈린 소련, 북한

민주주의 지수:
→ EIU (이코노미스트) 민주주의 지수
→ Full Democracy / Flawed Democracy / Hybrid / Authoritarian 4단계
```

## 자주 묻는 질문

**Q. 권력과 권위는 어떻게 다른가요?**
A. 권력(Power)은 강제적 능력을 포함하는 광의의 개념이고, 권위(Authority)는 정당성에 기반한 권력입니다. 권력이 정당성을 확보할 때 권위가 됩니다. 독재자는 권력은 있지만 민주적 권위는 없습니다.

**Q. 민주주의가 항상 좋은 결과를 내는 것은 아닌데, 왜 여전히 최선의 제도로 여겨지나요?**
A. 처칠의 말처럼 "민주주의는 최악의 정치 체제다, 다른 모든 체제를 제외하고는"라는 역설적 표현처럼 민주주의는 권력 남용을 제어하고 평화적 권력 이양을 가능하게 하는 점에서 현재까지 가장 덜 나쁜 체제로 평가받습니다.
