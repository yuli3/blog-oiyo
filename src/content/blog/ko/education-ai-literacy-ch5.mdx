1강에서 프롬프트 기초를 배웠습니다. 이제 고급 기법으로 AI를 진짜 도구로 만듭니다.

```
실전 CoT 프롬프트 예시:

나쁜 프롬프트:
"이 사업 계획이 성공할까요?"

좋은 CoT 프롬프트:
"다음 사업 계획을 평가해주세요. 
단계별로 생각하세요:
1단계: 시장 규모와 성장성 분석
2단계: 경쟁 환경 평가
3단계: 수익 모델 타당성 검토
4단계: 핵심 위험 요인 식별
5단계: 종합 판단과 개선 제안

[사업 계획 내용]..."

→ 각 단계에서 근거 있는 분석 유도
```

<Callout type="tip" title="AI 시대에 불필요해지지 않는 역량">
  (1) **AI를 효과적으로 사용하는 능력** — 프롬프트 공학, AI 도구 통합, (2) **AI 결과물의 비판적 검토 능력** — 환각 탐지, 편향 식별, (3) **AI가 못하는 역량** — 인간적 신뢰, 맥락 판단, 책임감, (4) **도메인 전문성** — AI에게 올바른 질문을 할 수 있는 깊은 지식.

## 실전 AI 활용 워크플로우

```
업무 자동화 3단계:

1단계: 반복 작업 목록 작성
→ 매주 하는 일 중 "템플릿화 가능한 것" 식별
→ 이메일 답변, 보고서 초안, 데이터 요약

2단계: 프롬프트 라이브러리 구축
→ 효과 있는 프롬프트를 문서화하여 재사용
→ 역할 + 맥락 + 형식의 템플릿 만들기

3단계: AI-인간 검토 루프 설계
→ AI 초안 → 사실 확인 → 개인화 → 승인
→ 어느 단계에서 인간 검토가 필요한지 명확히

황금 원칙:
"AI는 당신을 대체하지 않는다.
AI를 사용하는 사람이 당신을 대체한다."
```

## 핵심 암기 포인트 종합

*CoT 프롬프트: '단계별로' 요청 → AI 추론 품질 대폭 향상*
*역할 분담: 초안·속도는 AI, 판단·책임·윤리는 인간*
*커리어 전략: AI 대체 대상이 아닌 AI 활용자가 경쟁력*
*황금 원칙: AI를 사용하는 사람이 AI를 모르는 사람을 대체한다*
