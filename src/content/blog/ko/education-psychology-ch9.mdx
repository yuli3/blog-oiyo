## 이상심리학이란 — '정상'과 '이상'의 경계

```
이상 행동의 4D 기준:
Deviance (이탈): 사회 문화적 규범에서 벗어남
Distress (고통): 본인이 고통을 느낌
Dysfunction (기능 손상): 일상생활·관계 방해
Danger (위험): 자신·타인에 위협

→ 네 가지 모두 갖출 필요 없음
→ 문화적 맥락이 중요
```

## 주요 정신장애

### 우울증 (Major Depressive Disorder)

```
증상 (2주 이상, 5가지 이상):
- 거의 매일 우울한 기분
- 흥미·즐거움 감소 (무쾌감증)
- 수면 변화 (과수면 or 불면)
- 식욕 변화
- 피로, 에너지 감소
- 자책감, 무가치감
- 집중 어려움
- 죽음에 대한 생각

평생 유병률: 약 15%
여성이 남성의 약 2배
```

### 불안장애

```
범불안장애 (GAD):
→ 6개월 이상 다양한 일에 대한 과도한 걱정

공황장애:
→ 갑작스러운 극도의 공포 (심박 증가, 숨 막힘, 죽을 것 같은 느낌)
→ 예상치 못하게 반복 발생

사회불안장애:
→ 사회적 상황에서 수치당할까 봐 극도의 두려움
→ 발표, 대화, 관찰에 대한 회피

공포증:
→ 특정 대상·상황에 대한 비합리적 공포
→ 고소공포증, 거미공포증 등
```

### PTSD (외상 후 스트레스 장애)

```
외상 사건 이후 발생:
- 침습 증상: 플래시백, 악몽
- 회피: 외상 관련 사람·장소·생각 피하기
- 부정적 인지·감정: 죄책감, 소외감
- 과각성: 놀람 반응 과장, 수면 장애

치료: EMDR, 지속 노출 치료 효과적
```

## 심리치료의 주요 접근법

### 인지행동치료 (CBT)

현재 가장 널리 사용되고 증거 기반이 강한 치료법:

```
핵심 원리:
생각(인지) → 감정 → 행동의 연결을 변화

인지 재구조화:
→ 자동적 부정적 사고 파악
→ 증거 검토 → 더 균형 잡힌 생각으로 교체

행동 활성화:
→ 우울할 때 즐거운 활동 증가
→ 회피 행동 점진적 도전

노출 치료:
→ 공포 자극에 점진적으로 노출
→ 불안의 소거 학습
```

### 정신분석 / 정신역동 치료

```
프로이트 기반:
→ 무의식의 갈등이 증상의 원인
→ 자유 연상, 꿈 분석으로 무의식 탐색
→ 전이(transference) 분석

현대 정신역동:
→ 초기 애착 경험과 현재 관계 패턴 연결
→ 장기 치료 (수개월~수년)
```

### 인본주의 치료 — 로저스의 내담자 중심 치료

```
핵심 조건:
무조건적 긍정적 존중: 판단 없는 수용
공감적 이해: 내담자 입장에서 이해
진솔성: 치료자의 진정성

인간은 자기실현을 향한 내적 성장 동력을 가짐
→ 치료자는 그 성장을 돕는 촉진자

→ 단기 치료에도 효과, 모든 치료의 기본
```

## 생물학적 치료

```
항우울제:
SSRI (선택적 세로토닌 재흡수 억제제): 플루옥세틴(프로작)
→ 세로토닌 재흡수 막아 시냅스 농도 증가
→ 2~4주 후 효과 나타남

항불안제:
벤조디아제핀: 빠른 효과, 의존성 위험
→ 단기 사용만 권장

전기경련치료 (ECT):
→ 심각한 우울증, 다른 치료 실패 시 사용
→ 효과적이나 기억 문제 부작용
```

---

## 치료 선택 가이드

```
우울증: CBT + 항우울제 (병행이 단독보다 효과적)
불안장애: CBT + 노출 치료 (1차 선택)
PTSD: EMDR, 지속 노출 치료
성격장애: 변증법적 행동치료(DBT), 장기 정신역동
조현병: 항정신병 약물 + 심리사회적 지원
```

## 핵심 암기 포인트

*이상행동 4D: Deviance·Distress·Dysfunction·Danger*
*CBT: 생각→감정→행동 연결 변화 — 가장 증거 기반 강한 치료*
*SSRI: 세로토닌 재흡수 억제 → 우울증·불안장애 1차 약물*
*로저스 3요건: 무조건적 긍정·공감·진솔성*
