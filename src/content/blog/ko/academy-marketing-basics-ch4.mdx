## 1. 제품의 분류

```
소비재:
편의품: 저관여·저가 (식품·생필품)
선매품: 비교 후 구매 (의류·가전)
전문품: 고관여·특정 브랜드 고집 (명품·자동차)
비탐색품: 필요성 인식 못하는 제품 (보험·묘지)

제품 3수준:
핵심 편익: 고객이 정말 사는 것
실제 제품: 브랜드·포장·특성
확장 제품: AS·보증·배달 등 부가 서비스
```

## 2. 제품 수명주기 (PLC)

```
도입기:
낮은 매출, 높은 비용
선도자 이익·인지도 구축
스키밍 or 침투 가격

성장기:
매출·이익 급증
경쟁자 진입
시장 점유율 확보 집중

성숙기:
매출 정점·이익 감소
치열한 경쟁·가격 하락
차별화·세분 시장 집중

쇠퇴기:
매출·이익 감소
수확 or 철수 전략
비용 절감
```

## 3. 브랜드 전략

```
브랜드 자산:
브랜드 인지도
브랜드 연상
지각된 품질
브랜드 충성도

브랜드 전략 유형:
개별 브랜드: 제품별 다른 이름 (P&G)
패밀리 브랜드: 모든 제품에 동일 이름 (삼성)
라인 확장: 기존 브랜드로 신제품
브랜드 확장: 기존 브랜드로 신범주

공동 브랜딩:
두 브랜드 결합 (Intel Inside)
성분 브랜딩
```

## 4. 신제품 개발 과정

```
아이디어 창출:
내부 R&D·고객 제안·경쟁사 분석

아이디어 선별:
실현 가능성·수익성·전략 적합성

개념 개발·테스트:
소비자에게 제품 컨셉 제시
반응 조사

마케팅 전략 개발:
목표 시장·포지셔닝·가격·유통 계획

사업성 분석:
수요·비용·수익 예측

제품 개발·시장 테스트:
시제품 제작 → 테스트 마켓

상업화:
본격 출시·전국 출시
```

## 5. 핵심 개념 카드

**PLC=도성숙쇠** ★★★★★
: 도입→성장→성숙→쇠퇴.
*암기 포인트: 도성숙쇠*

**성숙기=매출정점이익감소** ★★★★★
: 매출은 최대지만 경쟁 심화로 이익 감소.
*암기 포인트: 성숙=매출↑이익↓*

**브랜드 자산=인연지충** ★★★★☆
: 인지도·연상·지각품질·충성도.
*암기 포인트: 인연지충*

## 6. 실전 퀴즈

**Q. 제품 수명주기 도입기에 스키밍 vs 침투 가격을 선택하는 기준은?**
> 스키밍(고가): 혁신적·차별화 제품, 가격 비민감 소비자, 경쟁 진입 느릴 때. 침투(저가): 가격 민감 대중 시장, 빠른 시장 확보 필요, 규모의 경제 가능할 때. 스마트폰 신제품=스키밍, 넷플릭스 초기=침투.

**Q. 브랜드 확장의 장점과 위험은?**
> 장점: 신제품 인지도 빠른 구축, 마케팅 비용 절감, 기존 브랜드 이미지 활용. 위험: 브랜드 희석 — 기존 이미지 훼손. 부정적 연상 전이. 예: 명품 브랜드가 저가 제품 출시 시 프리미엄 이미지 손상.
