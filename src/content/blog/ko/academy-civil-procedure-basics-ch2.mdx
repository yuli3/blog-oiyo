## 소 제기

```
소 제기:
원고가 법원에 소장을 제출하는 행위
민사소송 절차의 시작

소 제기 효과:
소송 계속: 법원에 사건이 계속됨
시효 중단: 소멸시효 중단
중복소송 금지: 같은 사건 다시 제기 불가

소장 제출:
관할 법원에 소장 제출 + 수수료(인지) 납부
인지: 소송 금액 기준 비례 납부

전자 소송:
인터넷 전자 소송 시스템 이용 가능
(대법원 전자소송 홈페이지)
```

## 소장 기재 사항

```
필수 기재 사항:
① 당사자 (원고·피고): 이름, 주소
② 법정대리인: 있는 경우 기재
③ 청구취지: 원하는 판결 내용
④ 청구원인: 청구를 뒷받침하는 사실관계

청구취지:
판결 주문에 해당하는 부분
구체적·명확하게 기재
예: "피고는 원고에게 금 1,000만 원 및 이에 대한 지연손해금을 지급하라"

청구원인:
청구취지를 뒷받침하는 법적·사실적 근거
계약 내용, 채무 불이행 사실 등
```

## 소장 심사와 보정

```
소장 심사:
법원이 소장 제출 받아 형식 요건 심사

흠결 발견:
보정 명령: 기간 내 보정 요구
보정 불이행 → 소장 각하 명령

소장 각하 사유:
필수 기재 사항 흠결
인지 미납
관할 없음 등

이송:
관할 없는 법원에 소 제기
→ 관할 법원으로 이송 (이송 결정)

소장 송달:
소장 요건 갖추면 → 피고에게 소장 부본 송달
→ 피고 답변서 제출 기회 부여
```

## 소의 변경

```
청구의 변경:
소제기 후 청구취지·청구원인 변경

요건:
사실심 변론 종결 전
청구 기초 동일성 유지
피고에게 현저히 불이익하지 않을 것

종류:
교환적 변경: 구 청구 취하 + 신 청구로 교체
추가적 변경: 구 청구 유지 + 신 청구 추가

반소:
피고가 같은 소송에서 원고를 상대로 새로운 소 제기
관련성 있는 청구만 가능
```

## 핵심 개념 카드

**소장 필수 기재 사항** ★★★★★
: 당사자·법정대리인·청구취지·청구원인.
*암기 포인트: 당법취원*

**청구취지 vs 청구원인** ★★★★★
: 청구취지=원하는 판결내용. 청구원인=뒷받침 사실관계.
*암기 포인트: 취지=결론, 원인=사실*

**소 제기 효과** ★★★★☆
: 소송계속+시효중단+중복소송금지.
*암기 포인트: 계속·중단·금지*

## 실전 퀴즈

**Q. 소장에서 청구취지와 청구원인의 관계는?**
> 청구취지: 원고가 원하는 판결의 결론 부분. 청구원인: 그 결론을 도출하는 법적·사실적 이유. 둘이 논리적으로 일치해야 함. 청구원인이 청구취지를 지지해야 판결 가능.

**Q. 소장 보정 명령 불이행 시 어떻게 되는가?**
> 법원이 지정한 기간 내 보정하지 않으면 소장 각하 명령. 소장 각하는 본안 심리 없이 소 자체를 종결. 각하 후 재소 가능하지만 인지 다시 납부해야 함.
