## 부동산학개론 출제 패턴

**연평균 출제 비중**:

```
부동산 특성·시장: 약 15%
부동산 가격 원칙: 약 15%
감정평가 3방식: 약 25%
투자 분석: 약 20%
부동산 정책: 약 10%
기타: 약 15%
```

**전략**: 감정평가 3방식과 투자 분석에서 절반 가까운 점수 결정.

## 최빈출 1: 토지의 특성

| 특성 | 경제적 영향 | 빈출 포인트 |
|------|-----------|-----------|
| **부동성** | 지역시장 형성, 입지 중요 | "부동성 → 지역별 분리" |
| **부증성** | 공급 비탄력, 지가 상승 | "공급 비탄력 원인" |
| **영속성** | 장기 투자 대상 | "감가상각 없음" |
| **개별성** | 완전경쟁 불성립 | "표준화 불가" |
| **인접성** | 외부효과, 공법 규제 근거 | "외부효과 관련" |

**인문적 특성**: 용도 다양성, 병합·분할 가능성, 위치 가변성

## 최빈출 2: 부동산 가격 원칙

```
핵심 암기 8원칙:
① 수요공급의 원칙
② 변동의 원칙 — 시간에 따라 변동
③ 예측의 원칙 — 장래 기대수익이 현가에 반영
④ 대체의 원칙 — 대체재 가격이 상한선
⑤ 균형의 원칙 — 최유효이용 시 최고 가격
⑥ 기여의 원칙 — 각 부분의 기여도
⑦ 수익체증·체감의 원칙
⑧ 경쟁의 원칙 — 초과이윤 소멸
```

**최유효이용(Highest and Best Use)**:
합법적·물리적·경제적으로 가능하며 최고 가치를 창출하는 이용.

## 최빈출 3: 감정평가 3방식

### 원가방식 (비용접근법) — 공식 암기 필수

```
적산가액 = 재조달원가 × (1 - 감가수정률)
감가수정률 = 경과연수 / 내용연수

예: 재조달원가 5억, 경과 10년, 내용연수 50년
→ 감가수정률 = 10/50 = 20%
→ 적산가액 = 5억 × 0.8 = 4억
```

**적용 대상**: 신축·특수 목적 건물, 시장자료 부족 시

### 비교방식 (시장접근법)

```
비준가액 = 사례 가격 × 사정보정 × 시점수정 × 지역요인 × 개별요인

사정보정: 정상 거래가 아닌 경우 수정
시점수정: 과거 거래 → 현재 시점 수정
```

**적용 대상**: 주거용·상업용 (거래 사례 풍부한 경우)

### 수익방식 (소득접근법) — 공식 암기 필수

```
수익가액 = 순수익(NOI) / 환원율

DCF법: PV = Σ NOI_t / (1+r)^t + 잔존가치 / (1+r)^n

예: NOI 연 2,000만, 환원율 4%
→ 수익가액 = 2,000만 / 0.04 = 5억
```

**적용 대상**: 임대수익 목적 부동산 (오피스, 상가)

## 최빈출 4: 지가 이론

### 리카르도의 차액지대론
```
차액지대 = 우량지 수익 - 한계지(최열등지) 수익
→ 지대는 비용 차이로 발생
```

### 알론소의 입찰지대론
```
입찰지대 = 총수입 - 생산비 - 이윤 - 교통비
→ 도심 근접: 교통비 ↓ → 지불 가능 지대 ↑
```

## 최빈출 5: 투자 분석 지표

```
임대수익률 = 연임대료 / 매입가격 × 100%
자본수익률 = (매도가 - 매입가) / 매입가 × 100%
총수익률 = 임대수익률 + 자본수익률

NOI = 유효총소득(EGI) - 운영경비(OE)
BTCF = NOI - 부채서비스(DS)

NPV = Σ CF_t/(1+r)^t - 초기투자
IRR = NPV = 0이 되는 할인율
PI = PV(현금흐름) / 초기투자
```

## 최빈출 6: 부동산 시장의 특징

| 특징 | 원인 | 효과 |
|------|------|------|
| 완전경쟁 불성립 | 개별성 | 표준가 없음 |
| 지역성(국지성) | 부동성 | 지역별 분리 시장 |
| 정보 비대칭 | 복잡성 | 중개업 필요 |
| 거래 비용 높음 | 등기·세금 | 유동성 낮음 |
| 장기 시장 | 내구성 | 공급 조정 느림 |

## 기출 유형 문제

**Q1. 부동산 시장이 일반 상품 시장과 다른 이유 중 틀린 것은?**
> 정답 형태: "정보 완전성이 높다" — 부동산은 정보 비대칭이 높음.

**Q2. NOI 산정 시 제외되는 항목은?**
> 부채서비스(원리금 상환액) — NOI는 부채 차감 전 순수익.

**Q3. 원가방식에서 감가수정의 의미는?**
> 시간 경과·기능 저하·경제적 감가를 반영해 재조달원가를 현재 가치로 조정.

**Q4. 양(+)의 레버리지 조건은?**
> 부동산 수익률 > 차입금리. 이 경우 차입으로 자기자본수익률이 향상됨.
