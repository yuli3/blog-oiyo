## IELTS 전 섹션 핵심 전략 정리

| 섹션 | 핵심 전략 | 빈출 실수 |
|------|---------|---------|
| Listening | 오디오 전 질문 읽기·예측 | 비슷한 발음 단어 혼동 |
| Reading | 스캐닝 → 질문 이동 | True/False/NG 혼동 |
| Writing Task 1 | 전체 트렌드 먼저, 세부 데이터 나중 | 개인 의견 삽입 |
| Writing Task 2 | 명확한 입장 + 2 본론 단락 | 너무 짧은 답변 |
| Speaking | IERI 구조, 자연스러운 대화 | Yes/No 짧은 답변 |

## 밴드 점수 향상 로드맵

### 5.5 → 6.5 목표
- Listening: Part 1~2 완성도 높이기 (상대적으로 쉬운 구간)
- Reading: T/F/NG 문제 전략 집중
- Writing: 최소 단어 수 달성 + 구조 잡기
- Speaking: Part 1 유창성 향상

### 6.5 → 7.5 목표
- Listening: Part 3~4 학술 어휘 이해
- Reading: 헤딩 매칭·요약 문제 정확도
- Writing: 다양한 어휘와 문법 구조 활용
- Speaking: Part 3 분석적 의견 제시

---

## IELTS One Skill Retake 활용

2023년 도입된 **One Skill Retake** 제도:
- 한 번 시험을 본 후 4개 섹션 중 **1개만** 재응시 가능
- 원래 시험 후 60일 이내 신청
- 재응시 점수와 원래 3개 섹션 점수를 합산해 성적표 발급

활용 전략: Writing 또는 Speaking 한 섹션이 목표에 못 미쳤을 때 매우 유용.

## 시험 당일 완전 가이드

### 준비물
- 여권 (국제 시험) 또는 공식 신분증
- 귀마개 (허용 여부 센터별 확인)
- 연필 (Listening·Reading 답안지 연필 사용 가능)

### Listening 당일 전략
- 이어폰/헤드폰 불량 여부 사전 확인
- 답안지에 옮겨 적는 10분 최대 활용

### Reading 당일 전략
- 어려운 문제에서 5분 이상 소비 금지
- 확실한 것부터 먼저 답 작성

### Writing 당일 전략
- Task 2 먼저 (배점 비중 높음)
- 단어 수 항상 확인 (150/250 최소)

### Speaking 당일 전략
- 긴장 완화: Speaking은 일상 대화이므로 편안하게
- 이해 못 했을 때: "Could you please repeat the question?" 자연스럽게 활용

## 체크리스트: 시험 1주일 전

**Listening**:
- [ ] Part 4 학술 어휘 복습
- [ ] 숫자/날짜 빠른 기록 연습

**Reading**:
- [ ] True/False/Not Given 전략 복습
- [ ] Matching Headings 실전 연습

**Writing**:
- [ ] Task 1 그래프 서술 표현 10개 암기
- [ ] Task 2 에세이 구조 확인

**Speaking**:
- [ ] Part 2 카드 주제 10개 1분 발화 연습
- [ ] 고급 어휘 20개 자연스럽게 활용
