## 워드프로세서 1급 자격증 개요

**워드프로세서 1급**은 대한상공회의소(KCCI)가 주관하는 국가공인 자격증으로, 컴퓨터를 이용한 문서 작성 능력을 평가합니다. 사무직 취업, 공무원 가산점, 대학 학점 인정 등 활용 범위가 넓어 매년 수십만 명이 응시하는 인기 자격증입니다.

### 자격증 주관 기관

- **주관**: 대한상공회의소(Korea Chamber of Commerce and Industry)
- **등급**: 1급 · 2급 · 3급
- **시험 주기**: 연 3~4회 정기 시험 + 상시 시험
- **응시 자격**: 제한 없음(누구나 응시 가능)

### 시험 구조

| 구분 | 과목 | 시간 | 합격 기준 |
|------|------|------|-----------|
| 필기 | 워드프로세싱 용어 및 기능, PC 운영체제, 컴퓨터 통신 | 60분 | 60점 이상 |
| 실기 | 문서 편집 실무(한글 워드) | 30분 | 80점 이상 |

필기 합격 후 2년 이내에 실기에 합격해야 최종 자격을 취득할 수 있습니다. 실기 시험은 **한글(HWP)** 또는 **MS Word** 중 하나를 선택하여 응시합니다.

## 문서 편집 기초

### 문서 입력과 편집

워드프로세서에서 문서를 작성할 때는 다음 세 가지 기본 작업이 핵심입니다.

**1. 문자 입력**
- 삽입 모드(Insert): 커서 위치에 문자 추가
- 수정 모드(Overtype): 기존 문자를 덮어씌우며 입력
- 한글 입력 시 자음·모음 조합 방식 이해 필요

**2. 선택과 편집**
- 드래그: 연속 텍스트 선택
- Shift + 방향키: 키보드로 선택 범위 확장
- Ctrl + A: 전체 선택
- Ctrl + C / V / X: 복사 / 붙여넣기 / 잘라내기

**3. 교정 기능**
- **찾기(Ctrl+F)**: 특정 문자열 검색
- **바꾸기(Ctrl+H)**: 문자열 일괄 교체
- **맞춤법 검사**: F7 키 또는 메뉴에서 실행
- **자동 고침**: 자주 틀리는 표현 자동 수정 등록

### 커서 이동 단축키

```
Home         → 줄의 처음으로 이동
End          → 줄의 끝으로 이동
Ctrl + Home  → 문서 처음으로 이동
Ctrl + End   → 문서 끝으로 이동
Ctrl + ←/→  → 단어 단위로 이동
Page Up/Dn   → 한 화면 위/아래로 이동
```

## 서식 설정

서식(Formatting)은 문서의 외관을 결정하는 모든 설정입니다. 크게 **문자 서식**과 **단락 서식**으로 나뉩니다.

### 글꼴(Font) 설정

글꼴 서식은 개별 문자 또는 선택한 텍스트에 적용됩니다.

| 속성 | 설명 | 단축키 |
|------|------|--------|
| 글꼴 종류 | 한글/영문 글꼴 선택 | — |
| 글자 크기 | pt 단위로 설정 | Ctrl+Shift+P |
| 굵게 | Bold 처리 | Ctrl+B |
| 기울임 | Italic 처리 | Ctrl+I |
| 밑줄 | Underline | Ctrl+U |
| 취소선 | 텍스트에 가로선 | — |
| 글자 색 | 폰트 컬러 변경 | — |
| 음영 | 텍스트 배경색 | — |

**글꼴 선택 원칙**
- 제목: 굵은 고딕 계열(예: 나눔고딕Bold, HY헤드라인M)
- 본문: 가독성 좋은 명조 또는 고딕(예: 바탕, 맑은 고딕)
- 영문 혼용 시 한글·영문 글꼴을 별도 지정

### 단락(Paragraph) 서식

단락 서식은 문단 전체에 적용됩니다.

**정렬 방식**
```
왼쪽 정렬  → Ctrl+L  : 기본값, 본문에 사용
가운데 정렬 → Ctrl+E  : 제목, 표 제목
오른쪽 정렬 → Ctrl+R  : 날짜, 서명란
양쪽 정렬  → Ctrl+J  : 공식 문서, 보고서 본문
```

**줄 간격(Line Spacing)**
- 단 줄: 줄 간격 100%
- 1.5배: 가독성 향상, 검토 용도
- 2배(Double): 초안·수정 여백 확보
- 고정값: 정확한 px/pt 지정

**들여쓰기(Indentation)**
- 첫 줄 들여쓰기: 단락 첫 줄만 오른쪽으로 밀기
- 내어쓰기(Hanging Indent): 첫 줄을 제외한 나머지 줄 들여쓰기
- 왼쪽/오른쪽 들여쓰기: 단락 전체의 좌우 여백 조정

### 탭(Tab) 설정

탭 정지점(Tab Stop)을 이용하면 표 없이도 정렬된 목록을 만들 수 있습니다.

| 탭 종류 | 기능 |
|---------|------|
| 왼쪽 탭 | 탭 정지점에서 텍스트 왼쪽 정렬 |
| 오른쪽 탭 | 탭 정지점에서 텍스트 오른쪽 정렬 |
| 가운데 탭 | 탭 정지점 기준 가운데 정렬 |
| 소수점 탭 | 소수점 기준 정렬(숫자 표 유용) |
| 채움선 탭 | 탭 앞에 점선/실선 채움 |

## 스타일 활용

### 스타일(Style)의 개념

스타일은 글꼴·단락·탭 등 여러 서식을 묶어 이름을 붙인 **서식 묶음**입니다. 한 번 정의하면 클릭 한 번으로 적용할 수 있어 대형 문서 작업의 효율을 크게 높입니다.

**스타일 사용의 장점**
1. **일관성**: 같은 수준의 제목이 전 문서에서 동일한 서식 유지
2. **효율성**: 서식 변경 시 스타일만 수정하면 전체 적용
3. **목차 자동 생성**: 제목 스타일 적용 시 목차 자동 연동
4. **내비게이션**: 탐색 창에서 제목 구조로 이동 가능

### 기본 제공 스타일

```
제목 1 (Heading 1) → 장 제목
제목 2 (Heading 2) → 절 제목
제목 3 (Heading 3) → 항 제목
본문 (Normal)      → 일반 텍스트
인용문 (Quote)     → 인용·주석
```

### 스타일 만들기와 수정

1. 서식을 적용할 텍스트를 선택
2. [홈] → [스타일] 창 → [새 스타일] 클릭
3. 이름 입력, 기반 스타일·다음 단락 스타일 설정
4. 서식 변경 후 확인

기존 스타일 수정: 스타일 이름 우클릭 → [수정] → 서식 변경 → 자동으로 전체 문서 반영

## 목차 자동 생성

### 목차 생성 원리

워드프로세서의 자동 목차는 **제목 스타일(Heading 1~3)**이 적용된 단락을 수집하여 페이지 번호와 함께 목록으로 만듭니다.

**목차 삽입 순서**
1. 각 제목에 [제목 1], [제목 2], [제목 3] 스타일 적용
2. 목차를 삽입할 위치에 커서 이동
3. [참조] → [목차] → 자동 목차 형식 선택
4. 문서 내용 수정 후 [목차 업데이트] 클릭

### 목차 서식 옵션

- **탭 채움선**: 제목과 페이지 번호 사이 점선/실선 선택
- **페이지 번호 표시**: 오른쪽 정렬 여부
- **수준**: 목차에 포함할 제목 단계 수 지정(1~9)
- **형식**: 클래식, 고급, 서식 있음 등 내장 디자인

## 표 작성 및 서식

### 표 삽입

표는 **행(Row)**과 **열(Column)**의 교차점인 **셀(Cell)**로 구성됩니다.

```
삽입 방법:
[삽입] → [표] → 행/열 수 지정
또는 격자를 드래그하여 빠른 삽입
```

### 표 편집 기능

| 기능 | 방법 |
|------|------|
| 행/열 추가 | 마지막 셀에서 Tab 키 / 우클릭 → 삽입 |
| 행/열 삭제 | 행/열 선택 후 우클릭 → 삭제 |
| 셀 병합 | 여러 셀 선택 → 우클릭 → 셀 병합 |
| 셀 분할 | 셀 선택 → 우클릭 → 셀 분할 |
| 열 너비 조정 | 경계선 드래그 또는 [표 속성] 에서 수치 입력 |
| 행 높이 조정 | 경계선 드래그 또는 [표 속성] 에서 수치 입력 |

### 표 서식 설정

**셀 안쪽 여백**: 내용과 셀 경계선 사이의 간격 → 가독성 향상
**테두리**: 선 종류(실선/점선/이중선), 굵기, 색상 설정
**배경색**: 헤더 행에 음영 처리하여 강조
**텍스트 방향**: 세로 텍스트 설정 가능(열 제목 등)
**정렬**: 수평(좌/중/우) + 수직(위/중/아래) 조합

### 표 계산 기능

한글 워드와 MS Word 모두 기본적인 계산식을 지원합니다.

```
합계: =SUM(ABOVE) 또는 =SUM(LEFT)
평균: =AVERAGE(ABOVE)
특정 셀 참조: =SUM(B2:B5)
```

## 다단 설정

### 다단(Columns)이란

다단은 페이지를 세로로 분할하여 신문이나 잡지처럼 여러 단으로 텍스트를 배치하는 기능입니다.

**설정 방법**
1. 다단을 적용할 텍스트 선택(또는 전체 문서)
2. [레이아웃] → [단] → 단 수 선택(2단, 3단 등)
3. 단 너비, 단 간격, 구분선 옵션 조정

**다단 관련 옵션**
- **단 너비 같게**: 모든 단의 너비를 동일하게
- **단 사이 간격**: 기본값 1.27cm
- **구분선**: 단 사이에 세로 실선 표시
- **단 나누기**: 특정 위치에서 강제로 다음 단으로 이동

## 실전 출제 유형 분석

### 필기 시험 출제 포인트

워드프로세서 필기 시험에서 자주 출제되는 유형입니다.

**1. 용어 정의 문제**
- 워드랩(Word Wrap): 한 줄 끝에서 자동으로 다음 줄로 넘어가는 기능
- WYSIWYG: 화면에 보이는 대로 인쇄되는 방식
- OLE: 다른 프로그램 개체를 문서에 삽입·연결하는 기술
- 매크로: 반복 작업을 자동화하는 명령 집합

**2. 단축키 문제**
```
Ctrl+S   → 저장
Ctrl+Z   → 실행 취소
Ctrl+Y   → 다시 실행
Ctrl+P   → 인쇄
Ctrl+N   → 새 문서
Ctrl+O   → 열기
F12      → 다른 이름으로 저장
```

**3. 파일 형식 문제**
- .hwp / .hwpx: 한글 고유 형식
- .docx: MS Word 형식
- .rtf: 서식 있는 텍스트(호환성 높음)
- .txt: 순수 텍스트(서식 없음)
- .pdf: 편집 불가 배포 형식

### 실기 시험 주요 작업

실기 시험 30분 안에 완성해야 하는 주요 작업 유형입니다.

1. **제목 서식**: 글꼴·크기·정렬·테두리 적용
2. **스타일 적용**: 지정된 스타일 이름으로 제목 스타일 설정
3. **표 작성**: 지정 행/열 표 생성, 셀 병합, 서식 적용
4. **다단 설정**: 지정 단 수·간격으로 본문 다단 처리
5. **머리말/꼬리말**: 문서 전체 또는 섹션별 설정
6. **쪽 번호**: 위치·형식·시작 번호 지정
7. **그림 삽입**: 위치·크기·텍스트 배치 설정
8. **인쇄 설정**: 용지 크기(A4), 여백, 방향 지정

## 실전 퀴즈

**Q1. 워드프로세서에서 자동 목차를 생성하려면 무엇을 먼저 해야 합니까?**

A1. 목차에 포함할 각 제목 단락에 **제목 스타일(Heading 1, Heading 2 등)**을 적용해야 합니다. 자동 목차 기능은 제목 스타일이 적용된 단락을 자동으로 수집하여 페이지 번호와 함께 목록을 생성하기 때문입니다. 스타일 없이 단순히 글자 크기를 키우거나 굵게 처리한 경우에는 목차에 포함되지 않습니다.

---

**Q2. 워드프로세서 실기 시험에서 표의 특정 열 너비를 정확히 3cm로 맞추는 가장 정확한 방법은?**

A2. 경계선 드래그는 정확한 수치 조절이 어렵습니다. 가장 정확한 방법은 해당 열의 셀을 선택한 후 **[표 속성] 대화상자를 열어 '열' 탭에서 너비를 직접 수치(3cm)로 입력**하는 것입니다. 한글에서는 표를 선택 후 P 단축키, MS Word에서는 [레이아웃] → [표 속성]으로 접근합니다.

**Q3. 같은 문서 안에서 일부 페이지는 2단, 나머지는 1단으로 설정하려면 어떻게 해야 합니까?**

A3. **구역(Section) 나누기**를 활용해야 합니다. 다단 설정을 바꾸려는 위치에 [레이아웃] → [나누기] → [구역 나누기(다음 페이지 또는 연속)]를 삽입하면 구역별로 독립적인 다단 설정이 가능합니다. 구역 나누기 없이 다단을 설정하면 문서 전체 또는 선택 영역에만 적용됩니다.
