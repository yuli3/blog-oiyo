## 주택도시기금 대출이란?

정부가 운영하는 **주택도시기금**을 재원으로 시중 금리보다 낮은 이율로 제공하는 정책 대출입니다. 전세 자금은 **버팀목**, 주택 구입 자금은 **디딤돌**이 대표적입니다.

---

## 버팀목 전세 자금 대출

### 개요

```
목적: 전세 보증금 마련 지원
대상: 무주택 세대구성원
금리: 시중 금리 대비 저렴
신청: 기금e든든 (enhuf.molit.go.kr) or 협약 은행
```

### 일반형 자격 및 조건

```
소득 요건:
- 부부 합산 연 소득 5,000만원 이하
- 단독 세대주 2,500만원 이하

자산 요건:
- 총 자산 3억400만원 이하

주택 조건:
- 전세 보증금 수도권 3억원 이하 / 지방 2억원 이하
- 전용 면적 85m² 이하

대출 한도:
- 최대 1억2,000만원 (수도권) / 8,000만원 (지방)
```

### 신혼부부 우대형

```
조건: 혼인 7년 이내 or 3개월 이내 혼인 예정
소득: 부부 합산 6,000만원 이하

금리 우대:
- 자녀 1명: 0.2% 인하
- 자녀 2명: 0.3% 인하
- 자녀 3명 이상: 0.5% 인하

한도: 최대 2억원 (수도권 기준)
주택: 전세 보증금 수도권 4억원 이하
```

### 청년 전세 대출 (청년 전용 버팀목)

```
대상: 만 19~34세 무주택 단독 세대주
소득: 연 5,000만원 이하

금리: 연 2.1~2.9% (소득 구간별)
한도: 2억원
주택: 보증금 3억원 이하, 85m² 이하
```

## 디딤돌 주택 구입 자금 대출

### 개요

```
목적: 주택 매매 구입 자금 지원
대상: 무주택 세대구성원
담보: 취득 주택 (저당)
신청: 기금e든든 or 협약 은행
```

### 일반형 자격 및 조건

```
소득 요건:
- 부부 합산 연 6,000만원 이하

자산 요건:
- 총 자산 4억6,900만원 이하

주택 조건:
- 주택 가격 5억원 이하 (기준 시가)
- 전용 면적 85m² 이하

대출 한도:
- 최대 2억5,000만원
- LTV(담보인정비율): 70%
- DTI(총부채상환비율): 60%
```

### 신혼부부 우대형

```
조건: 혼인 7년 이내 or 3개월 이내 혼인 예정
소득: 부부 합산 7,000만원 이하 (단태아) / 8,500만원 이하 (다태아)

주택:
- 가격 6억원 이하
- 85m² 이하

대출 한도: 최대 4억원

금리 우대:
- 자녀 1명: 0.1% 추가 인하
- 자녀 2명: 0.2% 추가 인하
- 자녀 3명 이상: 0.3% 추가 인하
```

| 일반 (소득 4천~6천만원) | 연 2.65~3.3% |

## 버팀목 vs 디딤돌 비교 정리

| 항목 | 버팀목 (전세) | 디딤돌 (구입) |
|------|------------|------------|
| **용도** | 전세 보증금 | 주택 매매 대금 |
| **최대 한도** | 2억원 (신혼) | 4억원 (신혼) |
| **주택 가격 기준** | 전세 4억원 이하 | 매매 6억원 이하 |
| **소득 기준** | 6,000만원 이하 | 7,000만원 이하 |
| **기간** | 2년 (4회 연장) | 10~30년 |

## 신청 방법

```
1. 기금e든든 (enhuf.molit.go.kr) 접속
   → 상품 안내 → 사전 자격 확인

2. 협약 은행 방문 상담:
   우리은행, 신한은행, KB국민은행, NH농협은행, KEB하나은행

3. 필요 서류 제출:
   - 주민등록등본 (세대원 포함)
   - 소득 증빙 (근로소득원천징수영수증 등)
   - 건강보험료 납부 확인서
   - 전세 계약서 or 매매 계약서
   - 무주택 확인서
   
4. 심사 후 대출 실행
```

---

## 주의사항

```
1. 동일 주택에 버팀목 + 보증보험 동시 가입 필요
   → 전세사기 방지를 위해 전세 대출 시 보증 필수

2. 대출 기간 중 주택 취득 시 즉시 상환 의무
   → 대출 중 주택 구입하면 버팀목 대출 유지 불가

3. 소득 기준 계산:
   → 전년도 소득 기준 (신청 연도 직전 연도)
   → 부부 합산

4. 연장 신청:
   → 버팀목 2년 만기 시 요건 충족하면 4회 (최대 8년) 연장 가능
```

## 자주 묻는 질문

**Q. 전세 계약을 이미 체결했는데 신청 가능한가요?**
A. 계약 후 잔금 지급 전이라면 신청 가능합니다. 잔금일 전에 대출이 실행되어야 하므로 서류 준비를 서두르세요.

**Q. 디딤돌 대출 중에 집을 팔 수 있나요?**
A. 매각 시 대출을 즉시 상환해야 합니다. 다른 주택을 다시 취득하는 경우 새로 신청해야 합니다.

**Q. 소득이 없는 배우자도 합산해야 하나요?**
A. 네, 부부 소득 합산이 기준입니다. 소득이 없으면 0원으로 합산하므로 유리합니다.

**Q. 이미 한 번 받은 사람도 다시 받을 수 있나요?**
A. 자격 요건을 충족하면 재신청 가능합니다. 단, 이전 대출 잔액이 남아있으면 제한될 수 있습니다.
