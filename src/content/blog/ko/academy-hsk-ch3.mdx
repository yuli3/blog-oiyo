## HSK 5급 레벨 이해

```
HSK 5급 기준:
→ 중국어 신문·잡지를 읽고 영화·TV를 이해할 수 있는 수준
→ 어휘: 2,500단어
→ 활용: 대학원 입학, 전문직 취업, 통·번역 진입
→ 합격 기준: 180점 (총 300점)

HSK 5급 시험 구성:
→ 듣기 (听力): 45문항 30분 (100점)
→ 독해 (阅读): 45문항 45분 (100점)
→ 쓰기 (书写): 10문항 40분 (100점)
→ 총 100문항 115분

HSK 5급 독해 유형:
→ 제1부분: 문장 완성 (빈칸 채우기) 15문
→ 제2부분: 긴 지문·단락 이해 15문
→ 제3부분: 장문 독해 (3지문 각 5문) 15문

HSK 5급 쓰기 유형:
→ 제1부분: 어순 배열 8문 (단어 → 문장)
→ 제2부분: 그림 보고 80자 작문 2문
```

## HSK 5급 핵심 문법: 복합문 구조

```
인과 복합문:
→ 因为A, 所以B: A이기 때문에 B이다
→ 由于A, B: A로 인해 B
→ 既然A, 就B: 이미 A인 이상 B
→ A, 因此B: A이다, 그래서 B (문어체)

조건 복합문:
→ 只有A, 才B: A해야만 B (필요조건)
→ 只要A, 就B: A하기만 하면 B (충분조건)
→ 即使A, 也B: 설령 A이더라도 B
→ 除非A, 否则B: A하지 않으면 B

전환 복합문:
→ 虽然A, 但是B: 비록 A이지만 B
→ 尽管A, 还是B: A임에도 불구하고 B
→ A, 然而B: A이다, 그러나 B (격식)
→ 固然A, 但B: 물론 A이지만 B

가정 복합문:
→ 如果A, 就B: 만약 A라면 B
→ 要是A, 那B: 만약 A라면 그러면 B
→ 万一A, 就B: 만일(최악의 경우) A라면 B

점진 복합문:
→ 不但A, 而且B: A일 뿐만 아니라 B도
→ 不仅A, 还B: A뿐 아니라 또 B
→ 既A, 又B: A이기도 하고 B이기도 하다
→ 何况B: 하물며 B이다 (A는 이미 명시)
```

## HSK 5급 핵심 문법: 강조·특수 구문

```
강조 구문:
→ 是...的 (시태 강조):
  他是去年来的。(그가 온 것은 작년이다)
  → 이미 완료된 동작의 시간·장소·방식 강조

→ 连...都/也 (포함 강조):
  连我都知道。(나조차도 안다)
  → 극단적 예를 들어 강조

→ 就是...也 (양보 강조):
  就是再难也要做。(아무리 어려워도 해야 한다)

→ 非...不可 (~하지 않으면 안 된다):
  这件事非你做不可。(이 일은 네가 꼭 해야 한다)

처치문 (把 구문) 심화:
→ 把 목적어를 동사 앞으로 이동
→ 把 + 목적어 + 동사 + 결과 (처치 결과 필수)
→ 把他的话忘了 (그의 말을 잊었다)
→ 부정: 不要 / 没(有) 는 把 앞에 위치

피동문 (被 구문) 심화:
→ 被 + 행위자 + 동사 (피해·불리한 상황 多)
→ 书被他借走了。(책은 그에게 빌려 갔다)
→ 受到·遭到·得到: 결과 유형별 피동 표현
  受到批评: 비판받다
  遭到失败: 실패를 당하다
  得到帮助: 도움을 받다

兼语句 (겸어문):
→ 동사 + 목적어(=兼语) + 동사
→ 让·请·叫·使·命令·禁止 등
→ 老师让我回答问题。(선생님이 나에게 답하게 했다)
```

## HSK 5급 핵심 어휘 패턴

```
고빈도 동사 조합:
→ 发挥 (fāhuī): 발휘하다 — 发挥作用/潜力/优势
→ 体现 (tǐxiàn): 구현하다, 반영하다 — 体现价值/精神
→ 维护 (wéihù): 유지하다, 보호하다 — 维护权益/秩序
→ 促进 (cùjìn): 촉진하다 — 促进发展/交流/合作
→ 承担 (chéngdān): 담당하다, 부담하다 — 承担责任/义务
→ 实现 (shíxiàn): 실현하다 — 实现目标/理想/梦想
→ 保障 (bǎozhàng): 보장하다 — 保障权利/安全/利益

고빈도 형용사:
→ 积极 (jījí): 적극적인 (반: 消极)
→ 显著 (xiǎnzhù): 현저한, 뚜렷한
→ 严格 (yángé): 엄격한 — 严格要求/管理
→ 合理 (hélǐ): 합리적인 — 合理安排/分配
→ 可靠 (kěkào): 믿을 수 있는, 신뢰할 수 있는

고빈도 명사 조합:
→ 机制 (jīzhì): 메커니즘, 체제
→ 规模 (guīmó): 규모 — 大规模
→ 途径 (tújìng): 경로, 방법
→ 意义 (yìyì): 의의, 의미
→ 措施 (cuòshī): 조치 — 采取措施

전치사 용법 정리:
→ 对于: ~에 대해서 (평가·태도)
→ 关于: ~에 관해서 (주제)
→ 针对: ~에 대해 (대상·겨냥)
→ 根据: ~에 근거하여
→ 通过: ~을 통하여 (수단)
→ 随着: ~에 따라 (변화 수반)
```

## HSK 6급 개요와 전략

```
HSK 6급 기준:
→ 어휘: 5,000단어 이상
→ 중국어로 자유롭게 표현하고 교류할 수 있는 수준
→ 활용: 고급 통·번역, 학술 연구, 외교·언론직
→ 합격 기준: 180점 (총 300점)

HSK 6급 시험 구성:
→ 듣기 (听力): 50문항 35분 (100점)
  - 단문 듣기, 장문 듣기, 인터뷰·강연
→ 독해 (阅读): 50문항 50분 (100점)
  - 빈칸 채우기, 단락 배열, 장문 이해
→ 쓰기 (书写): 1문항 45분 (100점)
  - 1,000자 지문 → 400자 요약 (缩写)

缩写(요약 쓰기) 전략:
→ 핵심 정보 유지: 주인공, 사건, 결말
→ 직접 인용 피하기: 간접화법으로 전환
→ 원문 표현 다양화: 그대로 베끼지 않기
→ 분량: 약 400자 (±20자 허용)
→ 구조: 도입 → 전개 → 결말

오류 수정 유형 (HSK 5·6급 공통):
→ 어순 오류: 부사·보어 위치
  × 他已经走了没有。
  ○ 他已经走了。/ 他走了没有？
→ 중복 오류: 의미 중복 사용
  × 大约大概有100人 → ○ 大约有100人
→ 전치사 오류: 介词 잘못 사용
  × 我对这个问题很熟悉关于
  ○ 我对这个问题很熟悉
→ 양사 오류: 量词 불일치
  × 一张桌椅 → ○ 一套桌椅
```

## 자주 묻는 질문

**Q. HSK 5급과 6급의 실질적 난이도 차이는 얼마나 되나요?**
A. 어휘 수 기준으로 5급은 2,500단어, 6급은 5,000단어로 두 배 차이입니다. 5급이 읽기·듣기 이해 능력 중심이라면 6급은 400자 요약 작문이 핵심입니다. 요약 쓰기는 단순 이해를 넘어 논리 구조 파악과 중국어 표현력을 요구합니다. 일반적으로 5급 합격 후 최소 6~12개월의 추가 학습이 필요합니다. 중국어 전공자나 유학 경험자는 더 빠르게 준비할 수 있습니다.

**Q. HSK 5·6급 독해 지문에서 모르는 단어가 너무 많은데 어떻게 해야 하나요?**
A. 고급 시험에서 모르는 단어를 만나는 것은 정상입니다. 전략적으로 접근하면 문맥으로 의미를 추론할 수 있습니다. 한자 구성 요소(部首·词素)에서 의미를 유추하고, 문장의 앞뒤 맥락과 논리적 흐름을 활용합니다. 특히 복합문의 접속어(虽然…但是, 只要…就 등)를 파악하면 각 절의 내용 관계를 이해하는 데 도움이 됩니다. 어휘 학습보다 구조와 논리 이해 능력을 키우는 것이 고급 단계의 핵심입니다.
