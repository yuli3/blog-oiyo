## 표와 목록의 활용 원칙

### 표(Table)를 써야 할 때

표는 다음 상황에서 문장보다 효과적입니다:

- **비교**: 2개 이상의 항목을 여러 속성으로 비교
- **다차원 데이터**: 행(항목)과 열(속성)이 교차하는 정보
- **일정·절차**: 날짜·담당·내용을 동시에 보여야 할 때

**나쁜 사용 예**: 항목이 하나이거나, 단순히 나열할 정보인데 표로 만드는 경우. 표는 복잡성을 해소할 때 씁니다.

### 표 작성 원칙

```
┌──────────┬────────────────┬──────────┐
│ 교육 과목  │ 교육 일시        │ 교육 장소  │
├──────────┼────────────────┼──────────┤
│ 직무역량   │ 2025. 9. 1.(월) │ 대강당 3층  │
│ 조직문화   │ 2025. 9. 2.(화) │ 대강당 3층  │
└──────────┴────────────────┴──────────┘
```

- 표 위에 번호와 제목: `<표 1> 교육 일정`
- 표 안 숫자는 우측 정렬
- 표 안 문자는 좌측 또는 가운데 정렬
- 단위는 열 제목에 표시 (개별 셀 반복 불필요)

## 붙임(첨부) 자료 작성

### 붙임 표기 방법

본문 끝에 "끝." 다음 줄에 붙임을 표기합니다.

```
끝.

붙임  1. 2025년 교육 계획서 1부.
      2. 참가 신청서 1부.  끝.
```

**원칙**:
- "붙임" 표기는 한 줄 들여 씀
- 각 붙임에 순번과 제목, 부수를 표기
- 마지막 붙임 뒤에 "끝." 표시
- 붙임이 하나이면: `붙임  2025년 교육 계획서 1부.  끝.`

### 붙임 자료의 품질

붙임 자료도 공문서의 일부입니다.

- 파일명: 날짜-제목-버전 형식 (예: `20250901_교육계획서_v1.pdf`)
- 페이지 번호 표시 (긴 자료)
- 가독성: 폰트 크기, 여백, 표 정렬
- 불필요한 내용 제거

## 공문서의 결재 후 처리

### 기안문 → 시행문 변환

결재가 완료된 기안문은 시행 단계에서 다음과 같이 처리됩니다:

1. **결재일 확인**: 최종 결재자가 결재한 날짜
2. **문서 번호 부여**: 기관 코드-부서-연도-일련번호
3. **수신자 주소 추가**: 외부 발송 기관명, 담당자
4. **시행일 표시**: 결재일과 같거나 이후로 설정
5. **공문서 형식 완성**: 기관 직인 또는 전자서명 부착

### 공문서 보관과 이관

공문서는 **공공기록물 관리에 관한 법률**에 따라 보존·관리합니다.

| 보존 기간 | 해당 문서 유형 |
|---------|-------------|
| 영구 | 법령, 주요 정책 결정, 기관 설립 문서 |
| 30년 | 주요 사업 결정, 예산 편성 관련 |
| 10년 | 일반 정책 문서, 감사 관련 |
| 5년 | 일상 업무 처리 문서 |
| 3년 | 단순 민원 처리 |
| 1년 | 일상적 연락 문서 |

## 전자문서 시스템

### e-나라도움과 정부 문서 시스템

현대 공공기관은 대부분 **전자문서 시스템**으로 공문서를 작성·결재·발송합니다.

주요 시스템:
- **온나라 2.0**: 중앙부처 업무 포털
- **지방행정종합정보시스템(새올)**: 지방자치단체
- **e-나라도움**: 보조금 관리 시스템

### 전자결재의 특징

- 종이 문서 없이 온라인에서 결재 진행
- 결재선이 전산으로 관리
- 결재 상황 실시간 확인
- 공문서 발송도 시스템 내에서 처리

**전자서명**: 결재권자의 전자서명이 날인을 대체. 법적 효력 있음.

## 공문서에서 흔한 형식 오류

### 오류 1: 항목 체계 혼용

```
가. 교육 개요
   1) 목적: ~ (올바름)
   ⓐ 대상: ~ (혼용 — 잘못됨)
```

→ 정해진 항목 체계를 순서대로 사용해야 합니다.

### 오류 2: 붙임 없이 "첨부"라고 쓰기

"첨부 파일 참조" ✗ → "붙임 1. ○○○ 1부.  끝." ✓

공문서에서는 "붙임"을 사용합니다. "첨부"는 이메일 용어입니다.

### 오류 3: 쪽 번호 없는 긴 자료

10쪽 이상의 붙임 자료에 쪽 번호가 없으면 독자가 혼란스럽습니다.

### 오류 4: 마침표 위치 실수

```
붙임  1. 교육 계획서 1부  끝.  (잘못됨 — 1부 뒤에 마침표 없음)
붙임  1. 교육 계획서 1부.  끝.  (올바름)
```

## 공문서 작성 최종 체크리스트

모든 공문서를 발송 전에 다음을 확인합니다:

**두문**
- [ ] 기관명 정확
- [ ] 수신처 완전 기재
- [ ] 제목: 20자 내외, 명확한 내용

**본문**
- [ ] 항목 체계 순서 정확 (가→1)→가)→(1)→(가))
- [ ] 날짜: 2025. 5. 5. 형식
- [ ] 숫자: 아라비아 숫자 + 단위

**결문**
- [ ] "끝." 정확한 위치
- [ ] 붙임 목록 완전 기재

**전체**
- [ ] 피동 표현 최소화
- [ ] 관습적 표현 제거
- [ ] 오탈자 없음
