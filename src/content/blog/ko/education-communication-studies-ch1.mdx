## 커뮤니케이션(Communication)이란?

```
커뮤니케이션의 어원:
→ 라틴어 'communis' (공통의, 공유된)
→ 의미를 공유하는 과정

커뮤니케이션의 정의:
→ 송신자가 기호를 통해 수신자에게 의미를 전달하는 과정

커뮤니케이션의 수준:
1. 자기 커뮤니케이션: 내적 대화, 자기 성찰
2. 대인 커뮤니케이션: 소수 개인 간 (1:1, 소그룹)
3. 조직 커뮤니케이션: 기관·조직 내부
4. 공중 커뮤니케이션: 연설, 강연
5. 매스 커뮤니케이션: 미디어를 통한 대중 커뮤니케이션
```

## 커뮤니케이션 모델

```
라스웰 (Lasswell) 모델 (1948):
Who(송신자) + Says What(메시지) + In Which Channel(채널)
+ To Whom(수신자) + With What Effect(효과)

선형 모델로 한계:
→ 피드백, 소음, 맥락 무시

섀넌-위버 (Shannon-Weaver) 모델:
→ 정보원 → 송신기 → 채널 → 수신기 → 목적지
→ 소음(Noise) 개념 도입
→ 정보이론에 기반, 의미 전달보다 신호 전달 강조

슈람 (Schramm) 쌍방향 모델:
→ 피드백 루프 포함
→ 인코딩·디코딩: 공유된 경험 필요
→ 경험의 장(Field of Experience): 겹칠수록 소통 효과적

모델 발전:
→ 선형 → 쌍방향 → 트랜잭션 모델
→ 트랜잭션 모델: 동시에 송신·수신, 지속적 상호작용
```

## 비언어 커뮤니케이션

```
비언어 커뮤니케이션의 범위:
→ 언어 이외 모든 전달 방식
→ 전체 의사소통의 65~93% 차지 (연구마다 상이)

유형:
1. 신체 언어 (Kinesics):
→ 표정, 몸짓, 자세, 시선
→ 표정은 문화 보편적 (에크만: 기본 감정 6가지)

2. 근접학 (Proxemics, Hall):
→ 공간과 거리의 의미
→ 친밀 공간 (0~45cm): 연인, 가족
→ 개인 공간 (45~120cm): 친구, 지인
→ 사회 공간 (120~360cm): 직업적 관계
→ 공중 공간 (360cm+): 강의, 연설

3. 시간학 (Chronemics):
→ 시간 사용이 전달하는 의미
→ 늦게 도착 = 상대 무시 or 권력 표시

4. 준언어 (Paralanguage):
→ 목소리 톤, 속도, 높낮이, 침묵
→ "네"를 어떻게 말하느냐에 따라 의미 달라짐
```

## 매스 미디어와 사회

```
매스 미디어의 기능 (라스웰):
1. 환경 감시: 뉴스, 정보 제공
2. 상관 조정: 사회 부분들을 연결, 해석 제공
3. 사회 유산 전달: 문화·가치 계승

라이트의 추가 기능:
4. 오락·휴식 제공

미디어의 역기능:
→ 사회적 지위 부여: 미디어가 언급 = 중요하게 인식
→ 사회 규범 강화: 일탈 행위를 가시화하여 통제
→ 마취 기능 (Narcotization): 정보 과부하 → 수동적 시민화
```

## 주요 미디어 이론

```
1. 의제 설정 이론 (Agenda-Setting Theory, McCombs & Shaw):
→ 미디어가 '무엇을 생각할지'는 아니지만
  '무엇에 대해 생각할지'를 결정
→ 미디어의 이슈 선택이 공중의 중요도 인식에 영향

예시:
→ 언론이 특정 범죄를 집중 보도 → 사람들이 범죄를 가장 중요한 문제로 인식

2. 침묵의 나선 이론 (Spiral of Silence, Noelle-Neumann):
→ 개인은 자신의 의견이 소수라고 생각하면 침묵
→ 미디어가 '다수 의견'처럼 묘사하는 것이 실제 여론 형성
→ 고립 공포 (Fear of Isolation)가 침묵 유발

3. 문화 계발 이론 (Cultivation Theory, Gerbner):
→ TV를 많이 볼수록 TV 속 현실을 실제 세계로 착각
→ 중시청자: TV의 왜곡된 현실 인식 (범죄율 과대 추정 등)
→ 평균화 효과: 다양한 집단이 TV의 주류 가치로 동질화

4. 이용과 충족 이론 (Uses and Gratifications):
→ 수용자는 능동적으로 미디어를 선택·이용
→ "미디어가 사람들에게 무엇을 하는가?" → "사람들이 미디어로 무엇을 하는가?"
→ 이용 동기: 정보 추구, 오락, 사회적 상호작용, 개인 정체성
```

## 뉴미디어와 디지털 커뮤니케이션

```
뉴미디어의 특성 (올드 vs 뉴):
일방향 → 쌍방향
대중 → 개인화
동일 콘텐츠 → 맞춤형 콘텐츠
고정 시간 → 언제든지 접근
수동 수용 → 능동 참여

인터넷과 소셜 미디어의 영향:
→ 게이트키퍼 약화: 누구나 콘텐츠 생산·배포
→ 필터 버블 (Filter Bubble): 알고리즘이 비슷한 정보만 노출
→ 에코 챔버 (Echo Chamber): 동질적 의견만 들리는 환경
→ 정보 과부하와 가짜뉴스

유투브·틱톡 등 플랫폼 경제:
→ 알고리즘이 새로운 게이트키퍼
→ 크리에이터 이코노미: 개인이 미디어 사업자
→ 인플루언서 마케팅
```

## PR과 광고 커뮤니케이션

```
PR (Public Relations) vs 광고 차이:
→ 광고: 유료 공간 구매, 통제된 메시지
→ PR: 비구매 커뮤니케이션, 제3자 신뢰성

PR의 4가지 모델 (그루닉):
1. 언론 대행 모델: 일방적 홍보, 진실 비중요
2. 공중 정보 모델: 일방적, 정확한 정보 전달
3. 쌍방향 불균형 모델: 피드백 있지만 설득 목적
4. 쌍방향 균형 모델: 상호 이해·이익 추구 (이상적)

프레이밍 (Framing):
→ 이슈를 어떤 틀로 제시하느냐에 따라 인식 달라짐
→ "세금 감면 폐지" vs "세금 인상" (같은 내용, 다른 프레임)
→ 미디어와 PR의 핵심 전략
```

## 자주 묻는 질문

**Q. 커뮤니케이션학을 공부하면 어떤 진로가 있나요?**
A. 언론·방송 분야(기자, PD, 아나운서), 광고·홍보(카피라이터, PR 담당), 디지털 미디어(SNS 마케터, 유튜브 기획), 정치 커뮤니케이션, 기업 홍보, 미디어 연구자 등 다양합니다.

**Q. 소셜 미디어가 정치에 미치는 영향은 어떻게 평가할 수 있나요?**
A. 긍정적으로는 시민 참여 확대, 권력 감시, 다양한 목소리 표출이 가능해졌습니다. 부정적으로는 가짜뉴스 확산, 에코챔버로 인한 극단화, 알고리즘에 의한 여론 조작 가능성이 우려됩니다. 민주주의와 미디어의 관계는 현재 가장 중요한 커뮤니케이션 연구 주제 중 하나입니다.
