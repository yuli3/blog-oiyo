## TCP/IP는 네트워크의 문법입니다

TCP/IP를 공부할 때는 프로토콜 이름을 많이 외우는 것보다 각 계층이 맡는 역할을 먼저 잡아야 합니다. 응용 계층은 사용자가 만나는 서비스, 전송 계층은 통신의 신뢰성과 포트, 인터넷 계층은 IP 주소와 경로, 네트워크 접근 계층은 실제 매체와 프레임 처리를 담당한다고 보면 됩니다.

### 계층별 핵심

| 계층 | 대표 개념 |
|---|---|
| 응용 | HTTP, DNS, FTP, SMTP 같은 서비스 프로토콜 |
| 전송 | TCP, UDP, 포트 번호, 흐름 제어 |
| 인터넷 | IP, ICMP, 라우팅, 서브넷 |
| 접근 | Ethernet, MAC 주소, 스위칭 |

TCP와 UDP의 차이는 단골입니다. TCP는 연결 지향, 순서 보장, 재전송 같은 신뢰성을 강조하고, UDP는 가볍고 빠른 전송에 적합합니다. DNS는 이름을 IP 주소로 바꾸고, DHCP는 주소 설정을 자동화하며, ICMP는 연결 상태 진단에 자주 등장합니다.

## 주소와 포트 연결하기

IP 주소는 어느 네트워크의 어느 장비인지 가리키고, 포트는 그 장비 안의 어떤 서비스와 통신하는지 알려줍니다. 시험 정보와 출제 범위는 바뀔 수 있으므로 시행처 공식 홈페이지와 해당 시 Q-net(https://www.q-net.or.kr)을 확인하세요. 확인일: 2026-06.

## 핵심 요약

TCP/IP는 계층별 역할, 주소, 포트, 대표 프로토콜을 연결해서 이해해야 합니다. TCP/UDP, DNS, DHCP, ICMP, HTTP의 쓰임을 상황별로 정리하세요. 다음 장에서는 네트워크 일반 개념을 다룹니다.
