## 주임법의 존재 이유

**주택임대차보호법(주임법)**: 경제적 약자인 임차인을 보호하기 위한 **강행법규**.

```
강행법규: 당사자 합의로 변경 불가
임차인에게 불리한 특약 → 무효
```

---

## 대항력 (抗力)

### 대항력의 의미

임차주택이 매도·경매되어 소유자가 바뀌어도 임차인이 새 소유자에게 자신의 임차권을 주장할 수 있는 힘.

### 대항력 취득 요건

```
요건: 주택 점유(입주) + 전입신고 완료
효력 발생: 전입신고 다음날 0시 (00:00)

⚠️ 주의: 당일이 아닌 다음날 0시
```

### 대항력의 효과

```
경매로 소유자 변경 시:
대항력 있는 임차인 → 새 소유자에게 보증금 반환 청구 가능
대항력 없는 임차인 → 소멸 위험 (보증금 잃을 수 있음)
```

**선후관계**:
```
근저당 설정일 vs 대항력 취득일 비교:
근저당이 먼저 → 경매 시 임차인 보증금 위험
대항력이 먼저 → 경매 후 임차권 유지 (선순위 임차인)
```

## 우선변제권

### 우선변제권의 의미

경매 시 다른 채권자보다 **먼저** 보증금을 배당받을 수 있는 권리.

### 우선변제권 취득 요건

```
요건: 대항요건(점유+전입) + 확정일자 취득
```

**확정일자 취득처**:
- 주민센터
- 공증인 사무소
- 법원·등기소
- 임대차 신고 시 자동 부여 (현재)

### 배당 순서

```
경매 배당 순서 예시:
1순위: 경매 비용
2순위: 최우선변제 임차인 (소액)
3순위: 국세·지방세 (일부)
4순위: 확정일자 기준 저당권·임차권 순서
```

---

## 최우선변제권 (소액보증금 보호)

### 의미

소액의 보증금에 대해 다른 담보권자보다 **최우선으로** 일정 금액을 배당받는 권리.

### 요건

```
요건:
① 임차주택을 경매 신청 등기 전에 대항요건(점유+전입) 갖출 것
② 배당 요구 종기까지 계속 대항요건 유지

서울 기준 (2023~):
보증금 1억 6,500만 원 이하 → 5,500만 원 우선 배당
```

**지역별 기준 상이**: 서울 > 수도권 > 지방 순서로 기준액 다름.

## 임대 기간 보호

```
최단 임대 기간: 2년
(임차인이 2년 미만으로 원하면 가능, 임대인은 2년 미만 주장 불가)

묵시적 갱신:
만기 전 임대인: 6개월~1개월 전 통보 없으면 자동 갱신
만기 전 임차인: 1개월 전 통보 없으면 자동 갱신
갱신 후 해지: 언제든 가능 (임대인은 3개월 후 효력)

계약갱신청구권:
임차인 1회 행사 → 2년 연장
임대료 인상 5% 이내
```

## 실전 사례 분석

### 사례 1: 경매와 보증금 보호

```
시나리오:
2023.01.01: A가 보증금 2억에 전세 계약 체결
2023.01.05: 전입신고 완료 → 대항력 1월 6일 0시 취득
2023.01.05: 확정일자 취득 → 우선변제권 취득
2023.03.01: 채권자가 근저당 설정 (1억 채권최고액)

→ A의 우선변제권이 근저당보다 선순위
→ 경매 시 A의 보증금 2억 먼저 배당
```

### 사례 2: 선순위 근저당과 위험

```
시나리오:
2022.06.01: 근저당 3억 설정
2023.01.01: B가 보증금 1억 5천만에 전세 계약 + 전입

→ 근저당이 선순위 → 경매 시 근저당 먼저 배당
→ 집값이 4억이면: 근저당 3억 배당 후 B에게 1억만 남음
→ 소액기준 이하라면 최우선변제로 일부 보호
```

## 핵심 개념 카드

**대항력 효력 발생 시점** ★★★★★
: 전입신고 다음날 0시. 당일 설정된 근저당과 동일일 경우 근저당이 우선.
*암기 포인트: 전입신고 다음날 0시 (당일 아님!)*

**우선변제권 = 대항요건 + 확정일자** ★★★★★
: 점유+전입+확정일자 모두 갖추어야 경매 배당에서 우선순위 인정.
*암기 포인트: 우선변제 = 대항 + 확정일자*

**최우선변제 경매 신청 등기 전 요건** ★★★★★
: 경매 개시 결정 등기 이전에 대항요건을 갖추어야 최우선변제권 인정.
*암기 포인트: 경매 등기 전에 이미 전입+점유 완료해야*

## 실전 퀴즈

**Q. 임차인이 확정일자 없이 전입신고만 한 경우 받을 수 있는 보호는?**
> 대항력만 취득. 경매 시 임차권은 유지되지만 보증금 우선 배당 받지 못함.

**Q. 임대인이 계약갱신청구권 행사를 거절할 수 있는 경우 3가지는?**
> ① 임대인 직접 거주 목적. ② 임차인이 차임 2개월 이상 연체. ③ 임차인이 임차물을 현저히 훼손.
