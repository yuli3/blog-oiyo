# 5장: 신경계 — 중추신경계, 말초신경계, 그리고 뉴런

신경계는 감각 정보를 통합하고, 정보를 처리하며, 운동 출력을 생성하는 신체의 최상위 조절 시스템입니다. 이 모든 과정이 수 밀리초 안에 이루어집니다.

## 뉴런의 구조와 기능

**뉴런(neuron)**은 신경계의 기본 기능 단위입니다.

- **수상돌기(dendrites)**: 들어오는 신호를 받아들이는 분지 구조
- **세포체(soma)**: 핵과 세포소기관을 포함하는 대사의 중심부
- **축삭(axon)**: 세포체에서 신호를 전달하는 하나의 긴 돌기
- **수초(myelin sheath)**: 슈반 세포(말초신경계)나 희소돌기아교세포(중추신경계)가 형성하는 지질 절연체; 도약 전도(saltatory conduction)를 가능하게 하여 활동 전위가 랑비에 결절 사이를 "도약"
- **축삭 말단 / 시냅스 소체(axon terminal / synaptic bouton)**: 시냅스로 신경전달물질을 방출

**활동 전위(action potential):** 역치(약 -55 mV)에 도달하는 등급 탈분극이 전부 아니면 전무(all-or-none) 반응을 촉발합니다. 전압 개폐 Na⁺ 채널 개방 → 빠른 탈분극 (+40 mV) → 불활성화 → K⁺ 채널 개방 → 재분극 → 과분극 (불응기).

## 중추신경계(CNS)와 말초신경계(PNS) 비교

| 특징 | 중추신경계 (CNS) | 말초신경계 (PNS) |
|---|---|---|
| 구성 요소 | 뇌와 척수 | 뇌신경, 척수신경, 신경절 |
| 지지 세포 | 성상교세포, 희소돌기아교세포, 미세아교세포 | 슈반 세포, 위성 세포 |
| 재생 능력 | 매우 제한적 | 비교적 양호 (슈반 세포가 재성장을 안내) |
| 보호 구조 | 혈뇌 장벽, 수막, 뇌척수액 | 신경외막 (epineurium) |

## 자율신경계: 교감신경과 부교감신경 비교

| 특징 | 교감신경 ("싸움 또는 도주") | 부교감신경 ("휴식 및 소화") |
|---|---|---|
| 절전 신경전달물질 | 아세틸콜린 | 아세틸콜린 |
| 절후 신경전달물질 | 노르에피네프린 | 아세틸콜린 |
| 심박수 | 증가 ↑ | 감소 ↓ |
| 동공 크기 | 산대 (mydriasis) | 축소 (miosis) |
| 위장관 운동 | 감소 ↓ | 증가 ↑ |
| 방광 | 배뇨근 이완 | 배뇨근 수축 |

## 주요 신경전달물질

| 신경전달물질 | 기능 | 임상적 연관성 |
|---|---|---|
| 아세틸콜린 (Acetylcholine) | 신경근 접합부, 부교감신경 | 중증 근무력증, 알츠하이머병 |
| 도파민 (Dopamine) | 보상, 운동 조절 | 파킨슨병, 조현병 |
| 세로토닌 (Serotonin) | 기분, 수면, 식욕 | 우울증, 불안 (SSRI의 표적) |
| 노르에피네프린 (Norepinephrine) | 각성, 교감 긴장도 | PTSD, ADHD |
| GABA | 주요 억제성 신경전달물질 | 뇌전증, 불안 (벤조디아제핀) |
| 글루타메이트 (Glutamate) | 주요 흥분성 신경전달물질 | 뇌졸중/외상성 뇌손상에서 흥분 독성 |

## 뇌졸중: 허혈성 vs 출혈성

**뇌졸중(stroke)**은 뇌로 가는 혈류의 갑작스러운 차단(또는 혈관 파열)입니다.

| 특징 | 허혈성 뇌졸중 (87%) | 출혈성 뇌졸중 (13%) |
|---|---|---|
| 원인 | 혈전증 또는 색전증 | 혈관 파열 (고혈압, 동맥류) |
| CT 소견 | 초기에는 정상; 이후 저밀도 음영 | 즉시 고밀도 (밝게) 나타남 |
| 치료 | 4.5시간 이내 정맥 내 tPA 투여; 혈전 제거술 | 혈압 조절, 외과적 혈종 제거 |
| 항응고제 | 가능 (출혈 배제 후) | 금기 |

**FAST** 약어: **F**acial drooping (얼굴 처짐), **A**rm weakness (팔 힘 빠짐), **S**peech difficulty (언어 장애), **T**ime to call emergency services (즉시 응급 서비스 연락).

### 핵심 체크리스트

- [ ] 뉴런 해부 구조를 설명하고, 수초화된 신경섬유에서의 도약 전도를 설명할 수 있다
- [ ] 주요 장기 계통에 대한 교감신경과 부교감신경의 효과를 비교할 수 있다
- [ ] 허혈성과 출혈성 뇌졸중을 감별하고, 급성기 치료를 설명할 수 있다
