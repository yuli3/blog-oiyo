## NOS는 운영체제 관점의 네트워크입니다

NOS는 Network Operating System의 흐름으로 이해하면 됩니다. 네트워크 서비스를 제공하는 서버가 계정, 권한, 파일, 프로세스, 서비스, 로그를 어떻게 관리하는지를 묻는 영역입니다. Windows Server와 Linux 계열의 기본 명령, 서비스 구조가 함께 등장할 수 있으므로 운영 개념을 먼저 잡으세요.

### 서버 운영 체크 포인트

| 항목 | 학습 포인트 |
|---|---|
| 계정 | 사용자 생성, 권한, 그룹 관리 |
| 파일 권한 | 읽기, 쓰기, 실행 권한과 소유자 |
| 서비스 | DNS, DHCP, Web, FTP 등 시작과 중지 |
| 로그 | 접속 기록, 오류 기록, 보안 이벤트 |
| 백업 | 장애 복구를 위한 주기와 보관 |

실기나 실무형 문제에서는 "명령어를 안다"와 "상황에 맞게 쓴다"가 다릅니다. 사용자가 접속하지 못한다면 계정 상태, 암호, 권한, 서비스 동작, 방화벽 순서로 좁혀 보는 식의 점검 습관이 필요합니다.

## 보안과 함께 공부하기

서버 운영은 보안과 바로 연결됩니다. 불필요한 계정과 서비스를 줄이고, 패치를 적용하며, 로그를 확인하는 것이 기본입니다. 시험 방식과 세부 범위는 달라질 수 있으므로 시행처 공식 홈페이지와 해당 시 Q-net(https://www.q-net.or.kr)을 확인하세요. 확인일: 2026-06.

## 핵심 요약

NOS는 서버가 네트워크 서비스를 안정적으로 제공하도록 관리하는 영역입니다. 계정, 권한, 서비스, 로그, 백업을 하나의 점검 흐름으로 익히세요. 다음 장에서는 네트워크 운용기기를 다룹니다.
