## 왜 지금 금 투자인가

주식·채권이 흔들릴 때 금은 반대로 오르는 경향이 있습니다. 포트폴리오의 **5~15% 금 배분**은 변동성을 낮추고 구매력을 보존하는 고전적 전략입니다. 2024년 기준 금 가격은 역대 최고치를 경신 중입니다.

---

## 금 투자 방법 4가지 비교

| 방법 | 최소 투자 | 세금 | 수수료 | 특징 |
|------|---------|------|--------|------|
| **금현물 (실물)** | 3.75g (1돈) | 부가세 10% | 판매 마진 | 직접 보유 |
| **KRX 금시장** | 1g 단위 | **비과세** | 0.3~0.5% | 한국거래소 상장 |
| **금통장 (골드뱅킹)** | 0.01g | 배당소득세 15.4% | 1~1.5% | 은행 계좌 방식 |
| **금 ETF** | 1주(1만원~) | 배당소득세 15.4% | 0.3~0.5% | 주식처럼 매매 |

---

## 방법 1: 금현물 (실물 금)

### 구매 방법

```
구매처:
- 한국금거래소 (온·오프라인)
- 골드바 취급 은행 (국민·신한·우리 등)
- 귀금속 상가 (을지로, 종로 등)
```

### 비용 구조

```
금 1돈(3.75g) 기준:
- 금 가격 (국제가 기준): 약 350,000원 (시세 변동)
- 부가가치세 10%: 35,000원
- 판매 마진: 5,000~15,000원
→ 실제 구입가: 약 390,000~400,000원

판매 시:
- 매도 시 부가세 환급 없음
- 매매차익 비과세
```

### 언제 유리한가?

```
장점: 세금 없는 시세차익, 실물 보유 심리적 안정
단점: 부가세 10% 즉시 손실, 보관 비용, 도난 위험
→ 장기 보유(5년+)로 부가세를 초과하는 차익 발생 시 유리
```

## 방법 2: KRX 금시장 (가장 추천)

### 개요

한국거래소(KRX)가 운영하는 금 현물 거래 시장. 주식처럼 HTS/MTS에서 거래.

```
거래 단위: 1g 이상 (약 10만원 이상)
거래 시간: 주식 시장과 동일 (09:00~15:30)
수수료: 증권사별 0.3~0.5%
세금: 매매차익 비과세 (!!!)
```

### 세금 비과세의 의미

```
일반 주식 매매차익: 비과세 (대주주 제외)
금 ETF 수익: 배당소득세 15.4% 부과
KRX 금시장: **매매차익 비과세**

1,000만원 투자 → 200만원 수익:
- 금 ETF: 200만원 × 15.4% = 308,000원 세금
- KRX 금시장: 세금 0원
```

### 이용 방법

```
1. 증권사 계좌 개설 (미래에셋·한국투자·키움 등)
2. HTS/MTS에서 'KRX 금시장' 메뉴 접근
3. 금 종목 (KRX금현물): 국내금시장에서 거래
4. 실물 인출 가능 (100g 단위 이상, 수수료 별도)
```

## 방법 3: 금통장 (골드뱅킹)

### 개요

은행에서 개설하는 금 연동 계좌. 금을 0.01g 단위로 구입.

```
취급 은행: 국민·신한·우리·하나·농협
최소 가입: 은행마다 상이 (1만원~)
수수료: 매수·매도 시 각 1~1.5%
```

### 세금 구조

```
매매차익 → 배당소득세 15.4%
→ 연 금융소득 2,000만원 초과 시 종합과세 대상

예시: 1,000만원 투자 → 200만원 수익
→ 세금: 200만원 × 15.4% = 308,000원
```

### 금통장 특이사항

```
예금자 보호 대상 아님 (은행 파산 시 보호 안 됨)
금 가격 기준 외 환율 리스크도 있음 (국제 금 가격 = 달러 기준)
→ 원-달러 환율 하락 시 손실 가능
```

## 방법 4: 금 ETF

### 국내 상장 금 ETF 목록

| ETF명 | 운용사 | 추종 지수 | 총보수 |
|-------|--------|---------|-------|
| **KODEX 골드선물** | 삼성자산운용 | 금 선물 (달러) | 0.68% |
| **TIGER 골드선물** | 미래에셋 | 금 선물 (달러) | 0.39% |
| **ACE KRX금현물** | 한국투자신탁 | KRX 금현물 | 0.30% |

### 금 ETF 주의사항

```
1. 선물 ETF vs 현물 ETF: 
   - 선물 ETF: 롤오버 비용 발생 (장기 보유 시 수익 누수)
   - 현물 ETF: 실제 금 가격 추종 (더 안정적)

2. 환 노출 여부:
   - 대부분 금 ETF는 달러 기준 → 원화 강세 시 손실
   - 환 헤지 ETF: 수수료 높지만 환율 영향 제거

3. 세금:
   - 금 ETF 분배금: 배당소득세 15.4%
   - ISA 계좌에 담으면 비과세 or 분리과세 적용
```

### ISA 계좌에서 금 ETF 활용

```
ISA 계좌 내 금 ETF 매수:
→ 수익 200만원(서민형 400만원)까지 비과세
→ 초과분도 9.9% 분리과세 (배당소득세 15.4%보다 유리)
→ KRX 금시장과 함께 가장 세금 효율적
```

## 금 투자 비중 가이드

### 포트폴리오 내 금 비중

```
보수적 투자자: 10~15%
중립 투자자: 5~10%
공격적 투자자: 0~5%

금을 늘려야 할 때:
- 인플레이션 상승 우려
- 주식 시장 과열
- 지정학적 리스크 증가
- 달러 약세 예상

금을 줄여야 할 때:
- 실질금리 상승 (금 보유 기회비용 증가)
- 주식 시장 저평가
- 달러 강세 예상
```

## 금 vs 다른 안전자산 비교

| 자산 | 수익 | 인플레 헤지 | 유동성 | 세금 |
|------|------|-----------|-------|------|
| **금** | 없음 (시세차익) | 우수 | 높음 | KRX 비과세 |
| **채권** | 이자 | 약함 | 높음 | 이자소득세 |
| **예금** | 이자 | 없음 | 높음 | 이자소득세 |
| **부동산** | 임대수익+시세 | 우수 | 낮음 | 양도세 등 |

## 실전 금 투자 시작 가이드

### 초보자 추천 순서

```
1단계: KRX 금시장에서 소액(10만원) 시작
   → 증권사 앱에서 주식처럼 매수
   → 비과세 혜택 확인

2단계: ISA 계좌 개설 후 금 ETF 편입
   → 주식·ETF·채권과 함께 분산 투자

3단계: 포트폴리오 5~10% 금 배분 유지
   → 리밸런싱 연 1~2회
```

### 월적립 전략

```
매월 일정 금액을 KRX 금시장 or 금 ETF에 분할 매수
→ 가격 평균화 효과 (Cost Averaging)
→ 금 가격 타이밍 리스크 제거
```
