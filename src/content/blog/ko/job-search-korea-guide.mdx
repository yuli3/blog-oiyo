## 어디서 찾고, 무엇을 준비하나

취업 정보는 흩어져 있다. 공식 채널부터 알면 헛걸음을 줄인다. 공공·민간을 나눠 정리하고, 직무·자격증까지 준비 흐름을 짚는다.

> 사이트·제도는 바뀔 수 있으니 각 **공식 사이트**에서 최신 정보를 확인하세요.

## 취업 지원 제도 (공식)

```
- 국민내일배움카드: 직업훈련비 지원(고용24 신청)
- 국민취업지원제도: 저소득·청년 구직자 수당+취업지원(고용24)
- 청년 지원: 청년도약계좌·청년내일채움공제 등(수시 변동)
- 고용센터 상담: 거주지 고용센터(국번없이 1350)
```

## 직무·직렬·섹터 이해

지원 전 '무엇을 하는 자리인가'를 아는 것이 핵심이다.

```
산업 섹터: IT·제조·금융·유통·바이오 등(→ 주식 섹터 가이드 참고)
직무(Job): 영업·마케팅·인사·재무·개발·생산·연구 등
공공 직렬: 행정·기술·전산·세무 등(공무원·공공기관)
→ 같은 회사라도 직무에 따라 요구 역량이 전혀 다르다
```

## NCS — 공공·공기업 필수 개념

```
NCS(국가직무능력표준): 직무 수행에 필요한 능력을 국가가 표준화.
- 공공기관 'NCS 기반 채용'의 토대(필기·자소서·면접)
- NCS 코드: 대분류→중분류→소분류→세분류 체계
→ 공기업 준비라면 NCS 직업기초능력(의사소통·수리·문제해결 등) 학습 필수
```

자세한 학습은 [NCS 핵심 강의](/ko/academy-ncs-core-ch1/)에서 다룬다.

## 추천 자격증 (분야별 예)

```
사무·공통: 컴퓨터활용능력·워드·한국사·토익
회계·금융: 전산회계·재경관리사·투자자산운용사
IT: 정보처리기사·SQLD·ADsP
무역·물류: 무역영어·물류관리사·유통관리사
부동산·법무: 공인중개사 등
```

자격증 로드맵은 [자격증 가이드](/ko/cert-guide-exam-schedule/) 참고.

## 준비 흐름 체크리스트

```
1. 방향: 공공 vs 민간, 산업·직무 좁히기
2. 정보: 위 공식 사이트 + 기업 채용 페이지 즐겨찾기
3. 역량: 직무 요구 역량 매칭(자격증·경험)
4. 서류: 직무 중심 자소서(NCS형이면 능력 기반)
5. 면접: 상황·경험 면접 준비(→ 공공기관 면접 가이드)
```

## 핵심 요약

1. 공공은 **워크넷·고용24·나라일터·잡알리오·인재채움뱅크**, 민간은 포털+기업 공식 페이지.
2. 국민내일배움카드·국민취업지원제도 등 공적 지원을 활용한다.
3. 산업 섹터·직무·직렬을 좁혀 '무엇을 하는 자리'인지 파악한다.
4. 공공·공기업은 **NCS 기반 채용**이 핵심이다.
5. 분야별 추천 자격증으로 직무 역량을 증명한다.
