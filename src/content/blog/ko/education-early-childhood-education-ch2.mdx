## 유아 교육과정의 이해

```
교육과정의 정의 (유아교육):
→ 유아에게 제공되는 모든 계획된·비계획된 경험
→ 영·유아 발달을 지원하는 교육 내용·방법·환경

유아교육 교육과정 원리:
→ 발달적 적합성: 연령과 개인 차이 고려
→ 통합성: 발달 영역 간, 교과 간 통합
→ 개별화: 유아 개인 특성 존중
→ 가족 중심: 부모·가족 참여
→ 놀이 중심: 놀이가 최고의 학습

역사적 접근:

행동주의 교육과정:
→ 구체적 행동 목표, 직접 교수
→ 문자·수 학습 중심

발달적 상호작용 접근:
→ 전인 발달, 아동 선택·탐구 강조
→ Bank Street 모델

하이스코프 교육과정:
→ 능동적 학습 (Active Learning)
→ 계획-실행-회상 (Plan-Do-Review)
→ 핵심 경험 58가지
```

## 2019 개정 누리과정

```
누리과정의 개요:
→ 만 3~5세 공통 국가 교육과정
→ 유치원·어린이집 공통 적용
→ 2019년 개정: 놀이 중심, 유아 주도 강화

2019 개정의 핵심 변화:
→ 교사 주도 → 유아 주도 놀이
→ 세부 내용 축소 (내용 수 대폭 감소)
→ 교사의 자율성·전문성 확대
→ "유아가 충분히 놀이할 권리" 명시

5개 영역:

신체운동·건강:
→ 신체 활동, 건강, 안전

의사소통:
→ 듣기·말하기, 읽기·쓰기 기초 경험

사회관계:
→ 자신 이해, 더불어 생활, 사회에 관심

예술경험:
→ 아름다움 탐색, 예술 감상·창의적 표현

자연탐구:
→ 탐구 과정 즐기기, 생활 속 탐구, 자연과 더불어 생활

교육과정 운영:
→ 하루 일과: 자유놀이 + 바깥놀이 충분히
→ 바깥 놀이: 1일 1시간 이상 권장
→ 평가: 유아 관찰·기록 중심
```

## 대안적 유아 교육 접근

```
몬테소리 교육 (Maria Montessori):
→ 준비된 환경: 유아 자율 탐색 지원
→ 자기 교육 원리: 내재적 동기 강조
→ 감각 교구: 구체적 조작 경험
→ 혼합 연령: 3세 연령 혼합
→ 교사 역할: 관찰자·환경 조성자 (지식 전달자 아님)

레지오 에밀리아 접근 (Reggio Emilia):
→ 이탈리아 레지오 에밀리아 시 프로그램
→ "100가지 언어": 다양한 표현 방식 존중
→ 프로젝트 학습: 유아의 흥미에서 출발
→ 문서화 (Documentation): 학습 과정 기록·전시
→ 환경을 제3의 교사로
→ 교사·유아·부모의 공동 구성자 역할

프로젝트 접근법 (Katz & Chard):
→ 주제 중심의 심층 탐구 프로젝트
→ 3단계: 시작 → 전개 → 마무리
→ 유아의 질문·관심에서 출발
→ 지역사회와 연결, 실생활 문제 탐구

발도르프 교육:
→ 루돌프 슈타이너 철학 기반
→ 예술·자연·상상력 강조
→ 전자 기기 최소화
→ 7세 이전: 인지 학습 강제 지양
```

## 장애 유아 통합 교육

```
통합 교육의 의의:
→ 장애 유아와 비장애 유아가 함께 생활·교육
→ 정상화 원리: 가능한 한 일반 환경에서 교육
→ 모든 유아의 학습·사회성 발달에 이점

통합 유형:
→ 완전 통합: 일반 학급 완전 참여
→ 부분 통합: 일부 시간 일반 학급
→ 역통합: 특수 학급에 비장애 유아 참여

특수 교육 지원:
→ 개별화 교육 프로그램 (IEP):
  연간 목표, 교육 방법, 평가 명시
→ 보조 인력: 특수 교육 보조원 배치
→ 관련 서비스: 언어치료·작업치료·물리치료

발달 지연 유아 지원:
→ 조기 개입: 0~6세 발달 지연 조기 발견·개입
→ 영유아발달지원센터
→ 부모 교육·상담 연계

협력적 팀 접근:
→ 교사·특수교사·치료사·부모 협력
→ 통합 설정에서 자연적 지원 제공
```

## 보육 정책

```
한국 보육 정책의 발전:

주요 제도:
→ 국공립어린이집 확충: 국공립 이용률 목표 40%
→ 무상보육: 0~5세 보육료 전액 지원
→ 아이행복카드: 보육료·유아학비 바우처

보육료 지원:
→ 어린이집 0~2세: 전액 지원
→ 3~5세 누리과정: 어린이집·유치원 공통 지원

육아휴직:
→ 부·모 각각 1년 사용 가능
→ 육아휴직 급여: 통상 임금 80%(상한 150만원)
→ 아빠 육아휴직 보너스제 (3번째 달 급여 100%)
→ 배우자 출산 휴가: 10일

유치원·어린이집 관리:
→ 유치원: 교육부 관할, 유아교육법
→ 어린이집: 복지부 관할, 영유아보육법
→ 누리과정 공통 운영 (3~5세)

초저출산 대응:
→ 출산율 0.7 (2023년): 세계 최저
→ 육아 비용 부담, 일·가정 양립 어려움이 주요 원인
→ 보육 지원 확충, 남성 육아 참여 촉진 정책 추진
```

## 자주 묻는 질문

**Q. 몬테소리와 일반 유치원 교육의 실질적 차이는 무엇인가요?**
A. 가장 큰 차이는 교사의 역할과 활동 구조입니다. 일반 유치원에서는 교사가 활동을 주도하고 시간표가 구조화되어 있습니다. 몬테소리에서는 유아가 교구를 자유롭게 선택하고 교사는 관찰하며 필요할 때 개입합니다. 또한 혼합 연령 구성과 반복적 실습을 강조합니다. 어느 접근이 더 좋다고 단정하기는 어렵고, 개별 유아의 기질과 학습 스타일에 따라 맞는 환경이 다릅니다.

**Q. 누리과정은 왜 2019년에 개정되었나요?**
A. 2019년 개정의 핵심 배경은 지나치게 학습 지향적이었던 이전 교육과정에 대한 반성입니다. 놀이 감소, 선행 학습 경쟁, 교사의 자율성 제한이 문제였습니다. 개정 누리과정은 "놀이 중심"을 최우선 원칙으로 삼고, 세부 학습 내용을 대폭 줄이며 교사의 자율성을 높였습니다. 이는 유아기 놀이가 단순한 여가가 아닌 필수적 학습 활동이라는 연구들을 반영한 것입니다.
