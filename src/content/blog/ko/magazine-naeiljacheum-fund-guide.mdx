## 재직자 내일채움공제란?

중소·중견기업 재직 근로자의 **장기 근속과 목돈 마련**을 돕기 위해 정부가 운영하는 공제 제도입니다. 근로자, 기업, 정부가 함께 납입해 만기 시 목돈을 지급합니다.

---

## 가입 조건

### 근로자 조건

```
- 중소·중견기업 재직 중
- 정규직 근로자 (계약직·파견직 제외)
- 가입일 기준 재직 6개월 이상 경과
- 고용보험 가입 사업장 (사실상 대부분)
```

### 기업 조건

```
- 중소기업기본법상 중소기업
- 또는 중견기업 (일부 적용)
- 사업주가 공제 참여에 동의해야 함
→ 기업 참여 의사 확인 후 가입 진행
```

---

## 납입 구조 (5년형 기준)

```
근로자: 월 12만원 × 60개월 = 720만원
기업:   월 20만원 × 60개월 = 1,200만원
정부:   납입 지원 (기업 부담분 일부 보전)

합계 적립액: 약 1,920만원 + 이자
만기 수령: 약 2,000만원 이상 (이자 포함)
```

> 기업이 납입금의 약 2.5배를 부담하므로 근로자 입장에서 수익률이 매우 높은 구조입니다.

---

## 수령액 계산 예시

### 5년 만기

```
[근로자 월 12만원 납입 기준]

- 근로자 납입: 12만원 × 60 = 720만원
- 기업 납입:  20만원 × 60 = 1,200만원
- 이자 (연 복리 2% 수준): 약 80~100만원

예상 만기 수령액: 약 2,000~2,100만원
→ 근로자 실납입 대비 약 3배 수령
```

---

## 세금 혜택

```
소득공제 혜택:
- 근로자 납입금: 연 240만원 한도 소득공제
- 과세표준 4,600만원 이하: 15% 세율 → 연 36만원 절세
- 과세표준 8,800만원 이하: 24% 세율 → 연 57.6만원 절세

만기 수령 시:
- 기타소득 과세 (이자 부분)
- 근로자 납입분: 비과세 or 소득공제 후 환급 구조
```

## 신청 방법

### 절차

```
1단계: 중소기업진흥공단 또는 IBK기업은행 방문/온라인 상담
       → 내일채움공제 홈페이지: sbcplan.or.kr
       
2단계: 사업주(기업) 동의 확인
       → 기업이 참여 의사가 없으면 가입 불가
       
3단계: 가입 신청서 작성
       → 근로자·기업 공동 신청
       
4단계: 공제 계약 체결 및 납입 시작
       → 첫 달부터 근로자 자동이체, 기업 납입
```

### 주요 운영 기관

```
- 중소기업진흥공단 (주관)
- IBK기업은행 (운영)
- 신한은행, 하나은행 등 협약 은행
```

## 중도 해지 시 불이익

```
근로자 귀책 사유로 중도 퇴직:
- 근로자 납입분: 전액 환급
- 기업 납입분: 기업에 귀속 (근로자 수령 불가)
- 정부 지원분: 환수

기업 귀책 사유 (폐업·권고사직 등):
- 근로자 납입분 + 기업 납입분 일부 환급
- 세부 조건 확인 필요

→ 중도 해지는 손실이 크므로 장기 재직 의지가 있을 때 가입
```

## 청년재직자 내일채움공제 (별도 제도)

```
대상: 만 15~34세 중소·중견기업 재직자
기간: 3년
납입:
- 근로자: 월 12만원
- 기업:   월 20만원
- 정부:   월 3만원

만기 수령: 약 1,200만원+
→ 정부 지원이 추가로 들어오는 청년 특화 상품
```

## 자주 묻는 질문

**Q. 회사가 참여를 거부하면 어떻게 하나요?**
A. 내일채움공제는 기업 동의가 필수입니다. 기업이 거부하면 가입이 불가능합니다. 채용 시 복리후생으로 내일채움공제 제공 여부를 확인하는 것이 좋습니다.

**Q. 이직하면 어떻게 되나요?**
A. 근로자 자발적 퇴직은 중도 해지로 처리됩니다. 근로자 납입분은 돌려받지만 기업 납입분은 받지 못합니다. 이직 전 충분히 고려하세요.

**Q. 대기업·공기업도 가입할 수 있나요?**
A. 중소기업기본법상 중소기업 또는 중견기업만 해당됩니다. 대기업이나 공기업은 가입 대상이 아닙니다.

**Q. 5년 만기 후 재가입이 가능한가요?**
A. 만기 후 재가입 가능 여부는 당시 정책에 따라 다를 수 있으므로 중소기업진흥공단에 확인하시기 바랍니다.
