## 특허법 오답 포인트

```
① 신규성 vs 진보성 구별
   → 신규성: 알려진 것 아닌가? (절대적 기준)
   → 진보성: 통상의 기술자가 쉽게 도출 못하는가?

② 공지 예외 = 12개월 이내
   → 공개 후 12개월 내 출원 시 신규성 의제

③ 심사청구 = 출원 후 3년 이내
   → 기간 내 미청구 = 취하 간주

④ 특허 존속기간 = 출원일로부터 20년
   → 등록일이 아닌 출원일 기산

⑤ 특허 무효 = 소급 효력
   → 처음부터 없었던 것
```

## 상표·디자인 오답 포인트

```
⑥ 상표 존속 = 10년 (갱신 가능)
   → 특허·디자인 20년과 구별

⑦ 상표 불사용 취소 = 3년
   → 3년 연속 불사용 시 취소 심판

⑧ 디자인 존속 = 출원일 20년
   → 상표와 다름 (20년=특허·디자인)

⑨ 등록주의 = 먼저 등록한 자
   → 먼저 사용해도 미등록이면 권리 없음

⑩ 디자인 비밀 제도 = 최대 3년
    → 공개 유예로 출시 전 보호
```

## 실용신안·PCT 오답 포인트

```
⑪ 실용신안 = 물품 한정 (방법 불가)
   → 특허는 방법·물질도 가능

⑫ 실용신안 존속 = 10년 (특허=20년)
⑬ PCT 국내단계 진입 = 30개월 이내
   → 파리조약 우선권(12개월)과 구별

⑭ 파리조약 우선권 = 12개월
   → 최초 출원일 기산

⑮ 저작권 = 등록 불요 (창작 시 자동 발생)
   → 특허·상표·디자인은 등록 필수
```

---

## 혼동 포인트 정리

```
특허 vs 실용신안:
특허=20년·방법포함, 실용신안=10년·물품만

상표 vs 디자인:
상표=10년+갱신, 디자인=20년

PCT vs 파리조약:
PCT=하나로 다수국 출원
파리조약=우선권 12개월

저작권 vs 산업재산권:
저작권=자동발생, 산업재산권=등록 필요
```

: 존속기간 혼동 가장 많음.
*암기 포인트: 특허=20, 상표=10+갱신*

**공지예외=12개월** ★★★★☆
: 논문 발표 후 12개월 내 출원 가능.
*암기 포인트: 공지예외=12개월*

## 실전 퀴즈

**Q. 특허와 영업비밀 보호 중 어느 것이 유리한가?**
> 특허: 공개 → 권리 독점 20년. 영업비밀: 비공개 → 영구 보호 가능. 코카콜라 레시피 = 영업비밀 전략. 특허 만료 후 공개 기술이 경쟁사 사용 가능. 기술 역공학 어려울수록 영업비밀 유리. 공개 불가피하거나 독점권 필요 시 특허.

**Q. 변리사의 핵심 업무가 특허 출원 대리인 이유는?**
> 특허 명세서: 청구범위가 권리 범위 결정. 넓게 쓰면 선행기술 저촉, 좁게 쓰면 보호 부족. 전문 기술+법률 양쪽 지식 필요. 변리사=이공계 출신+법률 전문가 조합. 심사 단계 의견서·보정도 전략적. 분쟁 시 청구범위 해석이 승패 결정.
