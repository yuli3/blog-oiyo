## 사회조사분석사 시험 개요

```
자격 개요:
→ 국가기술자격 (한국산업인력공단)
→ 통계 자료 수집·분석·활용 전문가
→ 마케팅·여론조사·사회과학 연구·공공기관 활용

시험 구성 (2급):
→ 1차 필기: 조사방법론 + 사회통계
→ 2차 실기: 사회조사 실무

조사방법론 출제 영역:
→ 사회조사 기초 이론: 20%
→ 조사 설계: 25%
→ 설문지 작성: 25%
→ 표본 추출: 20%
→ 측정·척도: 10%

사회통계 출제 영역:
→ 기술통계: 30%
→ 추론통계: 30%
→ 상관·회귀분석: 20%
→ 비모수 통계: 20%

합격 전략:
→ 개념 이해 후 기출 문제 반복
→ 용어 정의 암기: 내적 타당도·외적 타당도 혼동 주의
→ 표본 추출 방법 유형 도표로 정리
→ 통계 공식 암기 + 계산 연습
```

## 사회조사의 이해

```
과학적 조사의 특징:
→ 경험성: 관찰·측정 가능
→ 반복성: 동일 조건 재현 가능
→ 간주관성: 다른 연구자도 같은 결론
→ 체계성: 논리적·절차적

연구 목적에 따른 분류:

탐색적 조사 (Exploratory Research):
→ 새로운 현상 발견·가설 생성
→ 방법: 문헌 조사·전문가 의견·집단 심층 면접
→ 비용 적고 유연함

기술적 조사 (Descriptive Research):
→ 현상의 특성·분포 기술
→ 방법: 대규모 설문·관찰
→ 누가·무엇·언제·어디서 질문에 답

인과 조사 (Causal Research):
→ 원인-결과 관계 규명
→ 방법: 실험 설계 (인과 추론의 강력한 방법)
→ 독립 변수 → 종속 변수 인과 검증

변수의 종류:
→ 독립 변수: 원인 (X)
→ 종속 변수: 결과 (Y)
→ 매개 변수: X와 Y 사이에서 전달 경로
→ 조절 변수: X→Y 관계의 강도·방향 조절
→ 통제 변수: 외생 변수 제거 목적

가설 (Hypothesis):
→ 연구 질문에 대한 잠정적·검증 가능한 진술
→ 귀무가설(H₀) vs 대립가설(H₁)
→ 연구 가설: 이론적 예측
```

## 조사 설계

```
조사 설계의 유형:

단면 조사 (Cross-Sectional):
→ 한 시점에서 다수의 표본 조사
→ 빠르고 저렴
→ 인과 관계 추론 어려움

종단 조사 (Longitudinal):
→ 동일 표본을 시간에 따라 반복 조사
→ 변화·추이 파악 가능

패널 조사:
→ 동일 집단 반복 조사 (탈락 문제)

추세 조사 (Trend Study):
→ 동일 질문을 여러 시점에 다른 표본에게
→ 집단 변화 파악 (OECD PISA 등)

코호트 조사:
→ 공통 경험을 가진 집단 추적
→ 예: 1990년대생 성인 후 삶의 변화

실험 설계 (Experimental Design):
→ 무작위 배정: 실험군·통제군
→ 이중맹검 (Double Blind): 가장 강력한 인과 설계
→ 외생 변수 통제 → 내적 타당도 높음

내적 타당도 위협:
→ 역사 효과: 외부 사건 영향
→ 성숙 효과: 시간 경과 자연 변화
→ 회귀 효과: 극단값 → 평균으로 회귀
→ 검사 효과: 사전 검사 경험이 사후 검사에 영향
→ 선발 편향: 집단 배정 차이

외적 타당도:
→ 연구 결과를 다른 집단·상황에 일반화 가능 여부
→ 모집단 대표성과 관련
```

## 설문지 작성

```
설문지 설계 원칙:

문항 언어:
→ 명확성: 중의적 해석 없도록
→ 단순성: 어려운 용어 피하기
→ 단일성: 한 문항 = 하나의 내용
→ 중립성: 유도·암시 표현 금지

피해야 할 문항 유형:
→ 이중 질문: "가격과 품질에 만족하십니까?"
→ 유도 질문: "대부분의 사람들은 X를 지지합니다. 당신은?"
→ 모호한 답변: "가끔", "자주"의 기준 불명확
→ 부정 질문: 이중 부정 혼동
→ 민감 질문: 직접 질문 대신 간접·투사 기법

응답 척도 유형:

리커트 척도 (Likert Scale):
→ 5점 또는 7점 척도
→ 예: 전혀 아니다(1) ~ 매우 그렇다(5)
→ 태도·의견 측정의 표준

의미분별 척도 (Semantic Differential):
→ 양극단 형용사 쌍 사이 평가
→ 예: 나쁜 [1-2-3-4-5-6-7] 좋은

서스톤 척도:
→ 전문가 판단으로 문항 가중치 결정

구텐만 척도 (Guttman):
→ 누적 척도 (쉬운 → 어려운 순)

설문지 구성 순서:
① 인사말·목적 안내
② 쉬운 문항부터 (흥미 유발)
③ 주요 관심 문항 (중간 배치)
④ 민감한 인구통계 문항 (후반부)
⑤ 감사 인사
```

## 표본 추출

```
모집단과 표본:
→ 모집단: 연구 관심 전체 집단
→ 표본: 모집단에서 추출된 일부
→ 표본 오차: 표본 통계량과 모수의 차이

확률 표본 추출 (Probability Sampling):
→ 무작위 원리 — 모든 구성원에게 알려진 확률
→ 표본 오차 계산 가능 → 일반화 가능

단순 무작위 표본:
→ 모집단에서 무작위 추출 (추첨·난수표)
→ 모집단이 균질할 때 효과적

계통 표본 (Systematic):
→ k번째 요소마다 추출 (k = 모집단/표본 크기)
→ 편리하지만 주기적 패턴 위험

층화 표본 (Stratified):
→ 모집단을 층(Stratum)으로 나누고 각 층에서 무작위
→ 층별 특성 반영 → 정확도 높음
→ 비례 층화: 층 크기에 비례해 추출

군집 표본 (Cluster):
→ 집단(군집) 단위 무작위 선정 후 군집 내 전수
→ 지역 조사에 편리 (비용 절감)
→ 단계별 군집: 1단계·2단계·다단계

비확률 표본 추출:
→ 주관·편의에 따른 추출 → 일반화 어려움

편의 표본: 접근 용이한 대상 선정
판단 표본: 연구자 판단으로 선정
할당 표본: 인구통계 비율 맞추어 비무작위 추출
눈덩이 표본: 대상자 소개로 확장 (숨겨진 집단)

표본 크기 결정:
→ 신뢰 수준·허용 오차·모집단 분산 고려
→ n = Z² × p(1-p) / E² (비율 추정)
→ 일반적 사회조사: 1,000명 내외 (신뢰 수준 95%, ±3%)
```

## 자주 묻는 질문

**Q. 내적 타당도와 외적 타당도를 동시에 높이기 어려운 이유는 무엇인가요?**
A. 내적 타당도를 높이려면 실험 조건을 엄격히 통제해야 합니다. 그러나 통제된 인공적 실험 환경은 현실과 달라 결과를 일반화하기 어렵습니다(외적 타당도 저하). 반대로 자연스러운 현장 조사는 외적 타당도가 높지만 외생 변수를 통제하기 어려워 인과 관계를 명확히 규명하기 힘듭니다(내적 타당도 저하). 연구 목적에 따라 어느 타당도를 우선할지 결정하거나, 다양한 방법론을 조합해 두 타당도를 모두 높이려 합니다.

**Q. 인터넷 설문이 전통 설문보다 불리한 점이 있나요?**
A. 인터넷 설문의 주요 한계는 표본 편향입니다. 인터넷 사용자 중심으로 편향되어 고령층·저소득층·농촌 거주자가 과소 대표됩니다. 또한 설문 완료율이 낮고 응답의 진지성을 확인하기 어렵습니다. 같은 사람이 여러 번 응답하거나 보상을 위해 불성실하게 응답할 수 있습니다. 반면 비용·속도·지리적 제약 없음의 장점이 크기 때문에, 대표성이 중요한 조사에서는 가중치 보정이나 혼합 방식(온·오프라인 조합)을 씁니다.
