## 마케팅 믹스 4P

```
마케팅 믹스:
→ 기업이 목표 시장에서 원하는 반응을 얻기 위해
  통제 가능한 마케팅 도구의 집합

4P 구성:
Product  (제품)   → 무엇을 팔 것인가
Price    (가격)   → 얼마에 팔 것인가
Place    (유통)   → 어디서 팔 것인가
Promotion(촉진)  → 어떻게 알릴 것인가

→ 4P는 판매자(기업) 관점
→ 소비자 관점: 4C (Consumer Value, Cost, Convenience, Communication)
```

## 제품(Product) 전략

```
제품의 3수준:
1. 핵심 제품 (Core): 기본 편익 (기능)
2. 유형 제품 (Actual): 브랜드, 포장, 디자인, 품질
3. 확장 제품 (Augmented): AS, 보증, 배달, 설치

제품 믹스 (Product Mix):
- 폭(Width): 제품 라인 수 (카테고리 다양성)
- 깊이(Depth): 한 라인 내 품목 수

제품 수명 주기 (PLC):
도입기 → 성장기 → 성숙기 → 쇠퇴기

각 단계 특징:
- 도입기: 낮은 판매, 고비용, 인지도 구축 집중
- 성장기: 급성장, 경쟁자 진입, 시장 점유율 경쟁
- 성숙기: 최대 판매, 경쟁 치열, 차별화 전략
- 쇠퇴기: 판매 감소, 단계적 철수 or 리포지셔닝
```

## 소비자 구매 의사결정 과정

```
5단계 구매 의사결정:

1단계 문제 인식:
→ 현재 상태와 원하는 상태 간 불일치 인식

2단계 정보 탐색:
→ 내부 탐색 (기억, 경험)
→ 외부 탐색 (광고, 추천, 인터넷)

3단계 대안 평가:
→ 평가 기준 설정 (가격, 품질, 브랜드)
→ 기억된 상표군 (Evoked Set) 비교

4단계 구매 결정:
→ 브랜드, 구매처, 시기, 수량, 결제 방법 결정

5단계 구매 후 행동:
→ 만족 → 재구매, 구전 마케팅
→ 불만족 → 반품, 부정적 구전
→ 인지 부조화 (Cognitive Dissonance): 구매 후 후회
```

## 가격(Price) 전략

```
원가 기반 가격:
- 원가 가산법: 원가 + 마진 = 가격
- 목표 수익률법: 목표 이익을 포함한 가격 설정

경쟁 기반 가격:
- 시가법: 경쟁사와 유사한 수준
- 입찰 가격: 입찰 시 경쟁사 예상 가격 대비 설정

소비자 기반 가격:
- 지각 가치 가격: 소비자가 느끼는 가치 기준
- 심리적 가격: 9,900원 (홀수 가격, 단수 가격)

신제품 가격 전략:
1. 스키밍 (Skimming, 초고가): 
   → 초기 고가 → 점진적 인하
   → 특허 기술, 얼리어답터 시장
   
2. 침투 (Penetration, 저가):
   → 초기 저가 → 시장 점유율 확보
   → 규모의 경제 달성 후 이익
```

## 촉진(Promotion) 믹스

```
4가지 촉진 도구:

1. 광고 (Advertising):
→ 유료 비인적 커뮤니케이션
→ TV, 신문, 인터넷, 옥외 광고
→ 대중에게 넓게 도달, 반복 가능

2. 판매 촉진 (Sales Promotion):
→ 즉각적 구매 유도 단기 인센티브
→ 쿠폰, 할인, 샘플, 경품, 포인트
→ 단기 효과 강함

3. 인적 판매 (Personal Selling):
→ 판매원이 직접 고객과 1:1 대화
→ 설득력 높음, 즉각 피드백
→ 비용 높음, 대규모 전달 어려움

4. PR (Public Relations):
→ 기업 이미지 관리, 비구매 커뮤니케이션
→ 언론 보도, 이벤트, 후원
→ 신뢰도 높음, 통제 어려움

추가: 직접 마케팅 (Direct Marketing)
→ 우편, 이메일, 텔레마케팅
→ 개인화, 측정 가능
```

## 유통 채널 전략

```
유통 강도 전략:

1. 집중적 유통 (Intensive Distribution):
→ 가능한 모든 유통 채널 이용
→ 편의품 (음료, 과자, 생필품)

2. 선택적 유통 (Selective Distribution):
→ 일부 중간상만 선택
→ 가전제품, 의류

3. 전속적 유통 (Exclusive Distribution):
→ 특정 지역에 단 하나의 유통상 지정
→ 명품, 자동차 딜러

Pull vs Push 전략:
- Pull: 소비자를 대상으로 광고 → 소비자가 유통상에 요구
- Push: 유통상 대상 인센티브 제공 → 유통상이 소비자에게 판매
```

## 브랜드 전략

```
브랜드의 기능:
→ 출처 표시, 품질 보증, 광고 기능

브랜드 확장 전략:
1. 라인 확장: 기존 브랜드 + 새 제품 (같은 카테고리)
   예: 신라면 → 신라면 블랙
   
2. 브랜드 확장: 기존 브랜드 + 신규 카테고리
   예: 빠삐코 → 아이스크림에서 과자로
   
3. 멀티브랜드: 같은 카테고리에 다수 브랜드
   예: P&G (팬틴, 헤드앤숄더, H&S)

4. 신규 브랜드: 신제품에 완전 새 브랜드
```

## 핵심 암기 정리

```
시험 빈출:

4P: Product, Price, Place, Promotion
PLC 4단계: 도입→성장→성숙→쇠퇴
구매 의사결정 5단계: 문제인식→탐색→대안평가→구매→구매후
촉진 믹스 4가지: 광고, 판매촉진, 인적판매, PR
가격 전략: 스키밍(초고가) vs 침투(저가)
유통 강도: 집중적 > 선택적 > 전속적
```

## 자주 묻는 질문

**Q. 4P와 4C의 차이는 무엇인가요?**
A. 4P는 기업(판매자) 관점의 마케팅 도구이고, 4C는 소비자 관점입니다. Product→Consumer Value, Price→Cost, Place→Convenience, Promotion→Communication으로 대응됩니다.

**Q. 판매 촉진과 광고의 차이가 시험에 자주 나오나요?**
A. 네, 두 개념 구분은 단골 출제 유형입니다. 광고는 장기적 브랜드 구축, 판매 촉진은 단기적 즉각 구매 유도가 핵심 차이입니다.
