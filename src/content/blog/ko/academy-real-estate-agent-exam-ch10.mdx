## 과목별 핵심 요약

```
1차 과목:
부동산학개론: 토지·건물 특성, 시장이론, 투자분석
민법·민사특별법: 물권변동, 임대차, 특별법

2차 과목:
공인중개사법: 자격·개업·업무·처벌
부동산공법: 용도지역, 건축법, 개발행위
부동산공시법: 등기, 지적, 공시가격, 임대차
부동산세법: 취득세, 재산세, 종부세
```

## 물권 vs 채권 비교표

```
┌──────────┬──────────────────┬─────────────────┐
│ 구분     │ 물권             │ 채권            │
├──────────┼──────────────────┼─────────────────┤
│ 성질     │ 절대권·대세권    │ 상대권          │
│ 대상     │ 물건             │ 사람(채무자)    │
│ 예시     │ 소유권·전세권    │ 임차권·매매대금 │
│ 우선순위 │ 등기 순서        │ 원칙 없음       │
└──────────┴──────────────────┴─────────────────┘
```

## 주요 기간·수치 총정리

```
취득시효: 부동산20년·동산10년
취득세 신고: 60일 (상속6개월)
재산세 과세기준일: 6월 1일
공인중개사 등록 결격: 3년
전속중개계약: 3개월 이내
중개보수 확인설명서 보존: 5년
건축허가기준: 연면적 100㎡ 초과
용도지역: 도관농자 (4구분)
공부서류 열람: 누구든 가능
임차인 대항력: 전입+점유 다음날 0시
```

## 빈출 오답 10선

```
① 전세권=물권, 임차권=채권 (혼동 금지)
② 공신원칙 불인정 = 등기 믿어도 보호 없음
③ 상공판경 = 등기 없이 물권 변동
④ 점유취득시효 = 20년 (자주점유+평온공연)
⑤ 취득세 신고기한 = 60일 (상속=6개월)
⑥ 전용주거지역 = 상업시설 불허
⑦ 가등기 = 본등기 순위 소급
⑧ 종부세 주택 기준 = 9억 (1주택=12억)
⑨ 중개보수 초과 약정 = 무효 (강행법규)
⑩ 토지거래허가 = 허가 없으면 계약 무효
```

## 핵심 개념 카드

**공인중개사 시험 1차 2과목** ★★★★★
: 부동산학개론 + 민법·민사특별법.
*암기 포인트: 1차=학개론+민법*

**2차 3과목** ★★★★★
: 공인중개사법·공법·공시법·세법 (총 4분야).
*암기 포인트: 2차=법공공세*

**대항력 발생=익일 0시** ★★★★★
: 전입신고+점유 완료 다음날 자정부터 대항력.
*암기 포인트: 대항력=다음날0시*

## 실전 퀴즈 (종합)

**Q. 임차인이 대항력을 갖추기 위한 요건과 효력은?**
> 주택임대차: 전입신고 + 주택 인도(점유). 두 요건 충족 다음날 0시부터 대항력 발생. 대항력 = 집이 팔려도 새 주인에게 임차 관계 주장 가능. 상가는 사업자등록 + 점유.

**Q. 용도지역이 부동산 거래에 미치는 영향은?**
> 용도지역에 따라 건축 가능 용도와 건폐율·용적률 제한. 예: 전용주거지역 상가 불허. 용도지역 변경은 가치에 큰 영향. 개발 행위 전 반드시 확인 필수. 토지이용계획확인서 발급으로 확인 가능.
