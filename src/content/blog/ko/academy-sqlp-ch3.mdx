## SQL은 결과 집합을 설계하는 언어입니다

심화 SQL은 문법 암기보다 결과 집합을 어떻게 만들 것인지가 중요합니다. 조인은 테이블을 결합하고, 집계는 여러 행을 요약하며, 윈도우 함수는 행을 유지한 채 순위·누적 값을 계산합니다.

### 주요 패턴

| 패턴 | 쓰는 상황 | 주의점 |
|------|-----------|--------|
| 조인 | 여러 테이블 결합 | 조건 누락 주의 |
| 서브쿼리 | 중간 결과 활용 | 상관 여부 확인 |
| 집계 | 그룹별 요약 | GROUP BY 기준 |
| 윈도우 함수 | 행 유지 계산 | PARTITION 범위 |

SQLP에서는 “돌아가는 SQL”보다 “설명 가능한 SQL”이 중요합니다. WHERE, GROUP BY, HAVING, ORDER BY의 논리 처리 순서를 말로 설명해 보세요.
