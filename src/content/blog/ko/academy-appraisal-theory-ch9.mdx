## 특수 부동산 평가 개요

일반 부동산과 다른 특수성이 있어 표준 방법을 변형하여 적용.

```
특수 부동산 분류:
① 산업 시설: 공장·창고·물류센터
② 농지: 전·답·과수원·목장용지
③ 임야: 산지·목장
④ 광업 시설: 광산·채석장
⑤ 레저 시설: 골프장·리조트
⑥ 공공 시설: 도로·철도·항만

공통 특성:
- 거래 사례 희소 → 비교방식 한계
- 특수 목적 → 최유효이용 판단 어려움
- 기계·설비 일체 평가 필요한 경우 多
```

## 공장 감정평가

### 공장의 구성 요소

```
공장 부동산:
① 토지 (공장 부지)
② 건물 (공장동·사무동·창고)
③ 구축물 (배관·기계 기초·담장)
④ 기계·기구 (생산 설비)
⑤ 부대 시설 (전기·통신·소방)

평가 접근:
- 원칙: 각 구성 요소 분리 평가 후 합산
- 일괄: 영업 일체로 평가 (수익 창출형 공장)
```

### 기계·기구 평가

```
기계·기구 재조달원가:
- 동일 기계 신규 취득 가격 (수입 포함)
- 설치비·시운전비 포함

감가:
- 물리적: 사용에 따른 마모 (내용연수 10–15년)
- 기능적: 구형 기계 (생산성 열위)
- 경제적: 생산 중단·수요 감소

주의: 생산 시설과 분리 불가한 설비 → 부동산으로 취급 가능
```

### 공장 평가 방법

```
원가방식 우선:
적산가액 = 토지가액 + 건물 적산가액 + 기계기구 적산가액

수익방식 보완:
- 임대 가능 공장 → NOI 환원
- 현황 이용 수익성 분석

비교방식:
- 동종 공장 매매 사례 (자료 희소)
- 공업지역 내 공장 단가 비교
```

## 농지 감정평가

### 농지의 특성

```
농지 이용:
- 전: 밭 (채소·과수류)
- 답: 논 (벼·수도작)
- 과수원: 과일나무 재배

농지 감정평가 특수성:
① 농업 생산성 중요 (토질·일조·배수)
② 농지 전용 가능성 → 전용 후 가치 반영
③ 농업 진흥 구역: 전용 제한 → 감가 요인
④ 절대 농지 (농업 진흥 지역): 전용 거의 불가
```

### 농지 평가 방법

```
비교방식 우선:
- 인근 농지 매매 사례 수집
- 지가변동률로 시점수정
- 토질·배수·도로 접면 개별요인 비교

수익방식 보완 (경작 소득):
- 연간 순경작 수익 / 환원율
- 쌀 가격·수확량·경작비 등 자료 필요

농지 가격 구성:
① 순 농경 가치: 경작 수익 현가
② 개발 기대 가치: 전용 가능성
③ 지가 형성 요인: 위치·교통
```

### 농지 전용 평가

```
전용 가능 농지:
전용 후 예상 지가 × 전용 가능성 확률
- 또는 인근 전용 완료 토지 가격 기준 할인

전용 불가 농지 (농업 진흥 지역):
- 경작 수익 기반 평가
- 인근 전용 가능 농지 대비 대폭 할인
```

## 임야 감정평가

### 임야의 구성

```
임야 구성 요소:
① 임지 (산지 토지 자체)
② 입목 (나무): 벌채 가능 목재 가치
③ 기타 부가 가치 (광물·수자원)

평가 대상 구분:
- 임지만: 나지 상태 토지
- 입목 포함: 임지 + 입목 일괄 또는 분리
```

### 입목 평가

```
입목 가치 평가 방법:
① 비용 방식: 조림비 기준 (식재·육림 비용)
② 비교 방식: 유사 입목 매매 사례
③ 수익 방식: 벌채 시 예상 수익 현가

입목 시장가:
= 단위당 목재 가격 × 재적(m³) × 시장 형성계수

입목도: 단위 면적당 수목 밀도
- 입목도 높음 → 수확 가치 높음
```

### 임야 평가 방법

```
비교방식 우선:
- 인근 산지 거래 사례 비교
- 경사도·접근성·수종 개별요인

원가방식 보완:
- 개발 조성 임야: 조림 원가 기준

수익방식 (임목 수익):
- 벌채 주기 고려한 순 현재가치
- 할인율 적용 (장기 투자)

개발 기대 가치:
- 리조트·산지 전용 가능 임야 → 개발 후 가치 현가
```

## 핵심 개념 카드

**공장 평가 순서** ★★★★★
: 토지 + 건물 + 구축물 + 기계기구 각각 적산가액 산정 후 합산. 원가방식 중심.
*암기 포인트: 공장 = 토지+건물+기계 합산*

**농지 전용 가능성** ★★★★★
: 농업 진흥 지역 = 전용 제한 → 감가. 전용 가능 농지는 전용 후 가치 일부 반영.
*암기 포인트: 진흥구역=전용불가=감가*

**입목 평가 3방식** ★★★★☆
: 비용방식(조림비), 비교방식(사례), 수익방식(벌채수익현가). 실무는 비교방식 우선.
*암기 포인트: 입목 = 비용·비교·수익 중 적합 방식*

## 실전 퀴즈

**Q. 공장 감정평가 시 생산 기계가 기초에 고정되어 있는 경우 부동산으로 보는가?**
> 원칙적으로 분리 가능하면 동산(기계기구)으로 별도 평가. 단, 구조물과 일체화되어 분리 불가한 경우 부동산 구성 요소로 취급 가능.

**Q. 농업 진흥 지역 내 답(논)과 인근 전용 가능 농지의 가격 차이 원인은?**
> 농업 진흥 지역은 타 용도 전용이 극히 제한되어 개발 기대 가치가 없음. 전용 가능 농지는 개발 후 가치 일부 반영되므로 진흥 지역 내 농지보다 높게 형성.
