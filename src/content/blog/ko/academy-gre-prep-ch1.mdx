## GRE란?

**GRE(Graduate Record Examinations)**는 ETS(Educational Testing Service)가 관리하는 대학원 입학 표준 시험입니다. MBA, 법학대학원(Law School) 일부를 포함해 이공계·인문사회계 대부분의 석·박사 프로그램에서 활용됩니다.

---

## GRE 시험 구조 (2024 개편 후)

| 섹션 | 문항 수 | 시간 | 점수 |
|------|--------|------|------|
| Verbal Reasoning | 27문항 (2세션) | 41분 | 130~170 |
| Quantitative Reasoning | 27문항 (2세션) | 47분 | 130~170 |
| Analytical Writing | 1과제 | 30분 | 0~6 |
| **총계** | | **약 1시간 58분** | |

2024년 개편으로 시험 시간이 약 절반으로 단축되었습니다 (기존 3시간 45분 → 약 2시간).

---

## 섹션별 특성

### Verbal Reasoning
- **Reading Comprehension**: 단락 이해·추론
- **Text Completion**: 1~3개 빈칸 채우기 (어휘 중심)
- **Sentence Equivalence**: 두 가지 동의어로 문장 완성

**핵심**: GRE Verbal은 고급 어휘력이 GMAT보다 훨씬 중요합니다.

### Quantitative Reasoning
- Quantitative Comparison (두 수량 비교)
- Problem Solving
- Data Interpretation (그래프·표 분석)

**핵심**: 고등학교 수준의 수학 + 논리적 적용. GMAT보다 난이도 낮지만 어휘 대신 계산기(내장) 활용 가능.

### Analytical Writing
- 하나의 에세이: Issue 또는 Argument 과제
- 논리적 글쓰기 능력 평가

---

## GRE 점수 체계

**총점**: Verbal + Quantitative 각 130~170점

| 점수 | 백분위 |
|------|--------|
| 170 | 99% |
| 163~169 | 90%+ |
| 155~162 | 75%+ |
| 148~154 | 50~74% |

**비교**: GRE와 GMAT 점수 변환 도구는 ETS와 GMAC 공식 사이트에서 제공.

## GRE를 선택해야 할 때

| 상황 | 추천 시험 |
|------|---------|
| 이공계 석박사 진학 | GRE |
| 인문사회계 석박사 | GRE |
| 특정 MBA 프로그램 (GRE 수락) | GRE 또는 GMAT |
| Top MBA (M7) 최강 준비 | GMAT |
| 어휘·독해가 강점 | GRE |
| 수리·논리가 강점 | GMAT |
