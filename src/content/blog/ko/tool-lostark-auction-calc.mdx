# 로스트아크 경매 계산기

로스트아크 군단장 레이드나 어비스 던전에서 경매 아이템이 등장할 때, 얼마에 입찰해야 파티원들에게 공평한지 빠르게 계산하는 도구입니다.

## 계산 방식

**균등 분배 입찰가 공식:**
```
입찰가 = 수수료 제외 시장가 × (인원 - 1) ÷ 인원
```

**최대 이득 입찰가 공식:**
```
입찰가 = 균등 분배 입찰가 ÷ 1.1
```

거래소 수수료(5%)는 시장 가격에서 자동으로 차감됩니다.

## 용어 설명

<Callout type="note">
**균등 분배 입찰가**: 낙찰자와 낙찰받지 못한 파티원이 모두 같은 이득을 얻는 입찰가입니다. 파티 내 공평함을 최우선으로 할 때 사용합니다.
</Callout>

<Callout type="tip">
**최대 이득 입찰가**: 낙찰자가 최대한의 이득을 가져가는 입찰가입니다. 파티원과 합의가 되어 있을 때 사용합니다. 균등 분배 입찰가보다 낮은 금액입니다.
</Callout>

### 실제 예시

시장 가격 100,000골드, 4인 파티일 경우:
- 수수료 (5%): 5,000골드
- 분배될 금액: 95,000골드
- **균등 분배 입찰가: 71,250골드** (낙찰자 포함 4명 모두 약 23,750골드 이득)
- **최대 이득 입찰가: 64,772골드** (낙찰자 최대 이득)
