## 개인회생이란?

과도한 부채로 정상적인 변제가 어려운 개인이 **법원의 감독 하에 채무를 조정**받고, 일정 기간 변제 후 잔여 채무를 면제받는 제도입니다. 파산과 달리 **재산과 소득을 유지**하면서 채무를 해결합니다.

---

## 개인회생 vs 개인파산 vs 신용회복 비교

| 항목 | 개인회생 | 개인파산 | 신용회복위원회 |
|------|---------|---------|------------|
| **대상** | 소득 있는 채무자 | 소득 없는 채무자 | 연체 채무자 |
| **채무 감면** | 최대 90%+ 감면 | 전액 면제 (면책) | 감면 없음 |
| **변제 기간** | 3~5년 | 없음 | 채무 전액 |
| **재산 처분** | 불필요 | 필요 | 불필요 |
| **직업 제한** | 없음 | 일부 제한 | 없음 |
| **신용 회복** | 면제 후 가능 | 면책 후 가능 | 상환 후 가능 |

## 개인회생 신청 자격

### 기본 요건

```
1. 채무 한도:
   - 담보 채무: 10억원 이하
   - 무담보 채무: 5억원 이하

2. 소득 조건:
   - 계속적·반복적 소득이 있는 자
   - 급여, 사업소득, 임대소득, 연금 등

3. 변제 가능성:
   - 채무를 일부라도 변제할 능력 있을 것
   - (완전한 지급 불능이면 파산 대상)
```

### 신청 가능한 채무 유형

```
무담보 채무: 신용대출, 카드빚, 사채, 보증채무
담보 채무: 주택담보대출 (담보 재산 포함 10억원 이하)
→ 세금 체납, 벌금, 양육비는 면제 제외 (특별 채권)
```

## 개인회생 절차 단계별 정리

### 1단계: 신청 전 준비 (1~2개월)

```
서류 준비:
- 채권자 목록 (모든 채권자 및 채무액 정리)
- 재산 목록 (부동산, 예금, 자동차, 보험 등)
- 소득 증빙 (최근 3개월 급여명세서, 통장 내역)
- 생활비 내역 (월 지출 항목별)
- 신분증, 주민등록등본, 가족관계증명서
```

### 2단계: 법원에 신청서 제출

```
신청 법원: 주소지 관할 지방법원 (파산부)
신청 방법: 직접 방문 or 법무사·변호사 대리

신청 수수료:
- 법원 납부금: 약 10만원
- 예납금: 약 3~5만원 (관리인 보수)
```

### 3단계: 보전처분·중지명령

```
신청 접수 후 1~2주 이내:
→ 법원이 '중지명령' 발령
→ 효과: 모든 채권자의 추심·압류 중지
   (전화 추심, 계좌 압류, 임금 압류 전부 중단)

→ 채무자가 바로 숨 쉴 수 있는 단계
```

### 4단계: 개시 결정

```
신청 후 보통 1~2개월:
→ 법원이 개인회생 절차 '개시 결정'
→ '회생위원' (관리인) 선임
→ 채권자 목록 확정

채권자 이의 기간: 1개월 (채권자가 채무 내용에 이의 가능)
```

### 5단계: 변제계획 제출

```
개시 결정 후 1개월 이내:
→ 변제계획안 제출

변제계획에 포함되는 내용:
- 월 변제액 (가처분 소득 기반)
- 변제 기간 (3~5년)
- 각 채권자 배당 순서
```

### 6단계: 인가 결정

```
변제계획 제출 후 1~3개월:
→ 채권자 집회 + 법원 심사
→ 인가 결정 (= 변제계획 공식 승인)

인가 기준:
- 청산가치 보장 (파산하면 받을 금액 이상)
- 가처분 소득 전액 변제
- 채권자 동의 or 법원 강제 인가
```

### 7단계: 변제 기간 (3~5년)

```
매월 정해진 변제액을 회생위원에게 납부
→ 회생위원이 채권자들에게 분배

변제 기간 중 주의:
- 새로운 채무 금지 (부득이한 경우 법원 허가)
- 소득 증가 시 변제액 증가 가능
- 재산 취득 시 신고 의무
```

### 8단계: 면제 결정 (채무 소멸)

```
변제 기간 완료 후:
→ 법원에 면제 신청
→ 면제 결정 → 나머지 채무 전액 소멸
```

## 변제 금액 계산 방법

### 핵심: 가처분 소득

```
가처분 소득 = 소득 - 최저 생계비

예시: 월 소득 200만원, 1인 가구
최저 생계비(2024): 약 120만원
→ 가처분 소득: 80만원/월
→ 변제 금액: 80만원/월

5년 변제 시 총 변제액: 80만원 × 60개월 = 4,800만원
→ 총 채무 1억원이라면 → 4,800만원 변제 후 5,200만원 면제
```

### 청산가치 보장 원칙

```
개인회생 변제액 ≥ 파산 시 배당액 (청산가치)

재산이 많은 채무자: 재산의 청산가치도 변제에 포함
→ 예금, 자동차, 보험 해약환급금 등 고려
```

## 개인회생 비용

| 항목 | 금액 |
|------|------|
| 법원 수수료 | 10만원 |
| 예납금 | 3~10만원 |
| **법무사 의뢰 시** | 150~300만원 |
| **변호사 의뢰 시** | 300~600만원 |
| 총 자비 신청 | 약 15~20만원 |

> **혼자 신청도 가능**: 법원에서 양식을 제공합니다. 단, 서류가 복잡하므로 법무사 도움을 받으면 훨씬 수월합니다.

## 인가 후 주의사항

### 해서는 안 되는 행동

```
- 새로운 대출 (법원 허가 없이 500만원 이상)
- 재산 처분 (부동산·자동차 매각 시 법원 허가 필요)
- 소득 은닉 (소득 증가 신고 의무)
- 채권자 일부에게만 별도 변제 (차별 금지)
```

### 변제 중 소득이 늘면?

```
소득 증가 → 가처분 소득 증가 → 변제액 증가 가능
법원에 변경 신청 또는 자동 조정
→ 단, 소득 증가가 확정되면 숨기지 말고 신고
```

## 개인회생 중 자주 묻는 질문

**Q. 개인회생 중에 직장을 잃으면 어떻게 되나요?**
A. 소득이 사라지면 변제 능력 소멸 → 절차 폐지 가능. 즉시 법원에 신고하고, 실업급여·재취업 기간을 고려해 변제계획 변경 신청을 해야 합니다.

**Q. 개인회생 중에 주택 임대차 계약이 가능한가요?**
A. 기존 거주 목적 임차는 가능. 단, 새 임대차 보증금이 일정 금액 이상이면 법원 허가 필요.

**Q. 개인회생 후 신용 회복은 얼마나 걸리나요?**
A. 개인회생 기록은 완료 후 금융 신용정보에서 약 5년간 남습니다. 이후 카드 발급, 소액 대출부터 신용 재구축 가능.

**Q. 채권자가 개인회생에 동의하지 않으면 어떻게 되나요?**
A. 채권자 1/2 이상(금액 기준)의 동의 또는 법원의 강제 인가로 진행됩니다. 단 채권자 전원 반대에도 청산가치 기준이 충족되면 법원이 인가할 수 있습니다.
