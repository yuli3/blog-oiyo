## 1차 과목 오답 포인트

```
부동산학개론:
① 부동산 = 토지 + 정착물 (준부동산 제외 주의)
② 거미집 이론 = 시간차 공급 반응
③ 헤도닉가격법 = 속성 가격 분리
④ 순소득환원법 = NOI / 환원이율

민법·민사특별법:
⑤ 점유취득시효 = 20년 (자주점유 + 평온공연)
⑥ 등기 없이도 물권 변동 = 상속·공판·경매·수용(상공판경)
⑦ 가등기 = 순위 보전 (본등기 효력 소급)
⑧ 전세권 = 물권 (임차권은 채권)
⑨ 근저당 = 채권최고액 (일반 저당과 구별)
⑩ 법정지상권 = 요건 충족 시 자동 발생
```

## 2차 과목 오답 포인트

```
공인중개사법:
⑪ 결격사유 = 3년이 지나지 않은 자
⑫ 개업 = 등록 + 실무교육 이수
⑬ 전속중개 = 3개월 이내
⑭ 손해배상 = 개인1억·법인2억 이상 공제

부동산공법:
⑮ 용도지역 4구분 = 도시·관리·농림·자연환경보전
⑯ 전용주거지역 = 단독·공동주택만 허용
⑰ 건축허가 기준 = 연면적 100㎡ 초과
⑱ 개발행위허가 = 허가 후 착공 (선허가)

부동산공시법:
⑲ 공신원칙 불인정 = 등기 믿어도 보호 안됨
⑳ 토지거래허가 = 허가 없으면 계약 무효
```

## 혼동 포인트 비교

```
취득세 vs 등록면허세:
취득세 = 취득 행위에 부과
등록면허세 = 등기·등록 행위에 부과
(주택은 취득세로 통합)

재산세 vs 종합부동산세:
재산세 = 지방세, 모든 부동산
종합부동산세 = 국세, 기준 초과분

가등기 vs 예고등기:
가등기 = 순위 보전, 당사자 신청
예고등기 = 분쟁 경보, 법원 촉탁

임차권 vs 전세권:
임차권 = 채권 (등기 없이도 대항력)
전세권 = 물권 (등기 필수)
```

## 실전 퀴즈

**Q. 등기를 믿고 부동산을 매수했는데 진짜 주인이 따로 있다면?**
> 한국은 공신원칙 불인정. 등기를 믿어도 법적 보호 없음. 진정한 소유자가 말소 등기 청구 가능. 선의취득은 동산에만 적용 (부동산 불가). 따라서 등기 전 실체 조사 필수.

**Q. 상속으로 취득한 부동산은 등기 없이도 소유권 취득이 되는가?**
> 상속은 등기 없이도 법률 규정에 의해 물권 이전 (상공판경). 단, 등기를 해야 제3자에게 대항 가능. 상속인은 등기 전이라도 소유자이지만 처분은 등기 후 가능.
