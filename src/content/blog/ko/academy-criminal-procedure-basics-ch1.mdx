## 형사소송법의 목적

```
형사소송법 목적:
실체적 진실 발견
적법 절차 보장
신속한 재판

이중 목적:
범죄자 처벌 (형사법 실현)
피고인 기본권 보호 (인권 보장)

형사소송과 민사소송 비교:
형사: 국가 vs 피고인, 유·무죄 판단
민사: 당사자 간, 권리·의무 판단
형사: 검사가 공소 제기
민사: 원고가 소 제기
```

## 기본 원칙

```
무죄추정원칙:
유죄 확정 전까지 무죄로 추정
의심스러울 때는 피고인 유리 (in dubio pro reo)

불이익변경금지:
피고인만 상소 시 원심보다 불리한 판결 불가

일사부재리:
확정 판결 있는 사건 재소 불가

자백배제법칙:
임의성 없는 자백 = 증거 능력 없음
고문·협박·유인·약속에 의한 자백 배제

위법수집증거배제:
위법하게 수집된 증거 = 증거 능력 없음
```

## 소송 구조

```
당사자주의 (현행):
검사 vs 피고인 대립 구조
판사는 중립적 심판
당사자가 증거 제출·주장

직권주의 요소 혼재:
재판장 직권 증거 조사 가능
피고인 이익 위한 직권 발동

소송 관계인:
법원: 심판 기관
검사: 수사·공소 기관
피고인: 피소추자
변호인: 피고인 보조

3심제:
1심 → 항소심 → 상고심(대법원)
```

## 핵심 개념 카드

**무죄추정=유죄확정전** ★★★★★
: 확정 판결 전까지 무죄로 추정.
*암기 포인트: 무죄추정=확정전*

**in dubio pro reo=피고인유리** ★★★★★
: 의심스러울 때 피고인에게 유리하게.
*암기 포인트: 의심=피고인유리*

**위법수집증거=증거능력없음** ★★★★☆
: 위법하게 수집한 증거는 사용 불가.
*암기 포인트: 위법수집=능력없음*

## 실전 퀴즈

**Q. 형사소송의 이중 목적이 충돌할 때 어떻게 해결하는가?**
> 실체진실 발견과 적법절차 보장 간 긴장 관계. 원칙: 적법절차 우선 → 위법수집증거 배제. 이유: 국가가 불법 행위로 증거 수집하면 법치주의 훼손. 예외: 독수독과 이론의 예외 (필연적 발견, 선의의 예외). 결론: 절차적 공정성이 실체진실보다 우선하는 것이 현대 형사법 원칙.

**Q. 민사소송에는 있고 형사소송에는 없는 원칙은?**
> 처분권주의: 민사는 당사자 청구 범위 내에서만 판결. 형사: 검사 공소장 범위 내이지만 법원이 더 가벼운 죄로 판결 가능. 조정·화해: 민사에서 가능, 형사는 원칙적 불가. 변론주의: 민사는 당사자 제출 자료만, 형사는 직권 조사 가능. 형사는 피고인 보호를 위한 직권 요소가 더 강함.
