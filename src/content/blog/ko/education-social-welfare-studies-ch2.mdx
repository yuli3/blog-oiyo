## 사회보장의 이해

```
사회보장(Social Security)의 정의:
→ 질병, 노령, 장애, 실업, 사망 등 사회적 위험으로부터
  국민을 보호하고 삶의 질을 향상시키는 제도

사회보장의 원칙 (베버리지 원칙):
→ 보편성: 모든 국민에게 적용
→ 포괄성: 모든 위험 포괄
→ 균일성: 동일한 급여
→ 책임성: 국가 책임

사회보장의 구성:
→ 사회보험: 기여 기반, 사전 예방
→ 공공부조: 자산 조사, 사후 구제
→ 사회서비스: 현금 외 서비스 급여
→ 사회 수당: 보편적 현금 급여 (아동수당)

한국 사회보장기본법:
→ 사회보험·공공부조·사회서비스를 사회보장으로 정의
→ 국가·지방자치단체의 책임 명시
```

## 사회보험

```
사회보험의 특성:
→ 강제 가입 (임의 가입 아님)
→ 기여 기반 (보험료 납부)
→ 위험 분산 (구성원 간)
→ 급여 수급: 기여 이력 기반

4대 사회보험 (한국):

국민연금:
→ 목적: 노령·장애·사망 시 소득 보장
→ 적용: 18~60세 모든 국민 (일부 제외)
→ 보험료: 기준 소득의 9% (근로자 4.5% + 사용자 4.5%)
→ 급여: 노령 연금, 장애 연금, 유족 연금
→ 재정 방식: 부분 적립 방식 (현세대 기여+적립)

건강보험:
→ 목적: 질병·부상에 따른 의료비 지원
→ 보험료: 소득·재산 기반 (직장·지역 가입자)
→ 급여: 요양급여, 건강검진, 의약품

고용보험:
→ 목적: 실업 급여, 취업 촉진, 직업 훈련
→ 실업 급여: 이직 전 임금의 60%, 최대 270일
→ 고용유지 지원금: 기업의 고용 유지 지원

산재보험:
→ 목적: 업무상 재해·질병 보상
→ 사용자 전액 부담
→ 요양급여·휴업급여·장해급여
```

## 공공부조

```
공공부조(Public Assistance)의 특성:
→ 자산 조사 (Means Test): 소득·재산 기준 충족 시만
→ 국가 전액 재정 (보험료 없음)
→ 최후 안전망 역할
→ 낙인 효과 우려

국민기초생활보장제도:
→ 1999년 제정 (생활보호법 폐지·대체)
→ 수급권자의 권리 명시 (최초)
→ 맞춤형 복지: 급여 종류별 수급자 선정 (2015년~)

급여 유형:
→ 생계급여: 현금 (기준 중위소득 30% 이하)
→ 의료급여: 의료비 지원 (중위소득 40% 이하)
→ 주거급여: 임대료·주택 수선 (중위소득 48% 이하)
→ 교육급여: 교육비 지원 (중위소득 50% 이하)

기준 중위소득:
→ 전 국민 소득을 순서대로 줄 세울 때 중앙 값
→ 급여 선정 기준 (매년 중앙생활보장위원회 결정)

근로 빈곤층 문제:
→ 일을 해도 빈곤에서 벗어나지 못하는 계층
→ 근로장려세제 (EITC): 저소득 근로자 세액 환급
→ 자활 지원: 자활근로, 자활 기업 지원
```

## 사회서비스

```
사회서비스의 정의:
→ 개인이나 사회 전체의 복지 향상을 위한
  현금 외 급여(서비스·현물)

돌봄 서비스:
→ 노인 돌봄: 재가 서비스, 노인 장기요양보험
→ 장애인 돌봄: 활동지원서비스
→ 아동 돌봄: 어린이집, 아이돌봄서비스

노인 장기요양보험:
→ 2008년 도입 (노인 의료비·돌봄 특화)
→ 1~5등급 판정 → 재가·시설 서비스
→ 재정: 장기요양 보험료 + 국가

지역사회 통합 돌봄 (커뮤니티케어):
→ 시설 입소 줄이고 지역에서 살면서 서비스 받기
→ 의료·복지·주거 연계
→ 탈시설화 정책 방향

바우처 제도:
→ 서비스 이용권 형태 지원
→ 소비자 선택권 강화
→ 사회서비스 바우처, 문화 바우처

사회투자 관점:
→ 복지 지출을 비용이 아닌 투자로 인식
→ 아동·교육·직업훈련에 집중
→ 미래 노동력과 사회적 자본 형성
```

## 복지국가 유형론

```
에스핑앤더슨(Esping-Andersen)의 3가지 복지국가 유형:

탈상품화 (De-commodification) 개념:
→ 시장에 의존하지 않아도 생활할 수 있는 정도
→ 높은 탈상품화 = 강한 복지국가

1. 자유주의적 복지국가:
→ 예: 미국, 영국(과거), 캐나다, 호주
→ 잔여적 복지, 시장 의존
→ 자산 조사 강조, 낮은 급여
→ 탈상품화 낮음, 계층화 높음

2. 보수주의/조합주의적 복지국가:
→ 예: 독일, 프랑스, 오스트리아, 이탈리아
→ 직업·지위 기반 복지 (직업별 보험)
→ 가족주의: 전통 가족 역할 강조
→ 중간 수준 탈상품화

3. 사회민주주의적 복지국가:
→ 예: 스웨덴, 덴마크, 노르웨이
→ 보편주의: 시민권 기반
→ 높은 탈상품화, 낮은 계층화
→ 일·가정 양립, 여성 노동 참여 지원

한국의 복지 유형:
→ 동아시아 발전주의 복지국가 (4번째 유형 제안)
→ 경제 성장 우선, 복지는 선별적
→ 최근: 보편주의 확대 (아동수당, 기초연금)
```

## 자주 묻는 질문

**Q. 사회보험과 공공부조 중 어느 것이 더 중요한가요?**
A. 두 제도가 상호 보완적으로 사회 안전망을 구성합니다. 사회보험은 사전 예방적이고 더 많은 사람을 포괄하는 기본 안전망입니다. 공공부조는 사회보험의 사각지대에 놓인 사람들에게 최후의 안전망 역할을 합니다. 베버리지 모델은 사회보험을 주축으로 공공부조를 보완적으로 설계했습니다.

**Q. 한국 복지국가는 발전이 느린 이유가 있나요?**
A. 여러 요인이 복합적으로 작용합니다. 1960~90년대 개발주의 체제에서 복지보다 성장을 우선했고, 재벌 중심 경제 성장 전략에서 기업 복지가 공공 복지를 대체했습니다. 또한 유교적 가족주의 전통이 국가 복지 의존을 억제했습니다. 1997년 IMF 외환위기 이후 급격히 복지가 확대되었고, 현재는 OECD 평균에 근접 중입니다.
