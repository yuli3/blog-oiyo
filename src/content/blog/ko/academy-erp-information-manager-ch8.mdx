## 시험전략은 최신 공지 확인에서 시작한다

ERP정보관리사 마무리 단계에서는 먼저 시행처 공식 홈페이지에서 시험일정, 접수 방식, 합격기준, 응시자격, 과목 운영을 확인해야 합니다. 이 정보는 변경될 수 있으므로 이 글에서는 단정하지 않습니다. 공식 출처: 시행처 공식 홈페이지. 확인일: 2026-06. 공식 정보를 확인한 뒤에는 회계·인사·물류·생산을 따로 외우지 말고 데이터 흐름으로 묶어야 합니다.

### 4회독 전략

| 회독 | 목표 |
|---|---|
| 1회독 | ERP 개념과 모듈 역할 파악 |
| 2회독 | 회계·인사 기준정보와 입력 항목 정리 |
| 3회독 | 실무 입력 후 보고서 확인 연습 |
| 4회독 | 오답을 오류 유형별로 재분류 |

오답노트는 과목명보다 실패 원인으로 나누는 편이 좋습니다. "계정과목 착오", "거래처 누락", "부가세 구분 착오", "근태 자료 미반영", "조회 기간 오류"처럼 쓰면 같은 실수를 줄일 수 있습니다. 특히 실무형 문제는 화면 위치를 외우기보다 거래가 어떤 보고서에 남아야 하는지 먼저 생각해야 합니다.

### 직전 점검

마지막에는 새 자료를 늘리지 말고 기준정보, 전표 입력, 급여 계산, 재고 수불, 주요 보고서의 연결을 짧게 말해보세요. 설명할 수 있는 흐름은 실전에서 흔들릴 가능성이 낮습니다.

시간 배분도 화면 조작, 이론 확인, 오답 복습으로 나누어 관리하세요. 특정 모듈에만 오래 머무르면 통합 흐름을 놓치기 쉽습니다.

## 핵심 요약

ERP정보관리사 시험 준비는 공식 정보 확인, 모듈별 흐름 이해, 실무 입력 검증으로 마무리해야 합니다. 오답은 화면 암기가 아니라 데이터 연결 실패 원인으로 정리하세요.
