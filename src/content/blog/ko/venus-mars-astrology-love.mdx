"태양 별자리가 당신이 누구인지를 말한다면, 금성은 당신이 어떻게 사랑하는지를, 화성은 당신이 무엇을 원하는지를 말한다."

많은 사람들이 연애 궁합을 볼 때 태양 별자리만 봅니다. 그러나 점성술에서 사랑과 관계에 가장 직접적인 영향을 미치는 행성은 **금성(Venus)**과 **화성(Mars)**입니다.

## 금성 (Venus) — 사랑의 행성

금성은 **어떻게 사랑하는지, 무엇에 아름다움을 느끼는지, 어떤 관계를 원하는지**를 나타냅니다.

금성이 위치한 별자리를 확인하려면 출생 차트가 필요합니다. (Astro.com에서 무료로 확인 가능)

### 금성 별자리별 사랑 스타일

| 금성 별자리 | 사랑 표현 방식 | 이상적 관계 |
|-----------|------------|---------|
| **양자리** | 열정적, 직접적, 충동적 | 스릴 있고 역동적인 연애 |
| **황소자리** | 감각적, 안정적, 신뢰 추구 | 편안하고 안정된 관계 |
| **쌍둥이자리** | 지적, 유머러스, 변동적 | 재미있고 자극적인 소통 |
| **게자리** | 보살핌, 모성/부성적, 충성 | 깊은 감정적 안전감 |
| **사자자리** | 드라마틱, 관대, 헌신적 | 로맨틱한 이벤트와 표현 |
| **처녀자리** | 실용적, 세심한, 서비스 | 일상의 작은 배려 |
| **천칭자리** | 우아한, 조화 추구, 파트너십 | 균형 잡힌 동반자 관계 |
| **전갈자리** | 강렬한, 독점적, 깊이 추구 | 영혼을 울리는 깊은 연결 |
| **사수자리** | 자유롭고, 모험적, 솔직한 | 성장과 모험을 함께하는 관계 |
| **염소자리** | 신중한, 헌신적, 장기 지향 | 미래를 함께 구축하는 관계 |
| **물병자리** | 독립적, 비전통적, 우정 기반 | 지적 파트너십, 자유 존중 |
| **물고기자리** | 낭만적, 공감적, 영적 연결 | 영적이고 깊은 사랑 |

## 화성 (Mars) — 욕망의 행성

화성은 **무엇에 끌리는지, 어떻게 욕망을 표현하는지, 어떤 자극이 필요한지**를 나타냅니다.

### 화성 별자리별 욕망 스타일

| 화성 별자리 | 욕망 표현 방식 | 끌리는 것 |
|-----------|------------|---------|
| **양자리** | 즉각적, 충동적, 공격적 | 자신감 있고 도전적인 파트너 |
| **황소자리** | 느리고 감각적, 인내 | 신뢰할 수 있고 따뜻한 파트너 |
| **쌍둥이자리** | 지적 끌림 우선 | 재치 있고 다재다능한 파트너 |
| **게자리** | 감정적 연결이 먼저 | 보살피고 돌보는 파트너 |
| **사자자리** | 화려하고 자신감 있게 표현 | 특별하고 주목받는 파트너 |
| **처녀자리** | 서비스와 현실적 도움으로 | 성실하고 신뢰할 수 있는 파트너 |
| **천칭자리** | 우아하고 간접적 | 균형 잡히고 매력적인 파트너 |
| **전갈자리** | 강렬하고 깊이 원함 | 신비롭고 심층적인 파트너 |
| **사수자리** | 자유롭고 직접적 | 모험적이고 철학적인 파트너 |
| **염소자리** | 목표 지향적, 인내심 있게 | 야망 있고 성숙한 파트너 |
| **물병자리** | 독특하고 비전통적 | 독립적이고 혁신적인 파트너 |
| **물고기자리** | 낭만적, 영적 에너지 | 감성적이고 영적인 파트너 |

## 금성과 화성 궁합

### 기본 원칙

**금성-화성 상호작용**: 상대방의 화성이 내 금성 별자리와 잘 맞으면 끌림이 강하고, 내 화성이 상대방의 금성 별자리와 맞으면 서로에게 매력적입니다.

**예시**:
- A의 금성 = 사수자리 + B의 화성 = 양자리 → 불(火) 원소 공명, 강한 끌림
- A의 금성 = 황소자리 + B의 화성 = 전갈자리 → 맞은편(충돌) → 강렬한 끌림과 갈등 공존

### 원소별 금성-화성 궁합

| 금성 원소 | 화성 원소 | 궁합 |
|---------|---------|------|
| 불(양자리·사자·사수) | 불 | 열정적이나 자아 충돌 가능 |
| 불 | 공기(쌍둥이·천칭·물병) | 불을 키우는 공기, 자연스러운 조화 |
| 흙(황소·처녀·염소) | 흙 | 안정적이나 변화 없을 수 있음 |
| 흙 | 물(게·전갈·물고기) | 물이 땅을 기름지게, 감성적 안정 |
| 공기 | 공기 | 지적 연결이나 감정 부족 가능 |
| 공기 | 불 | 아이디어와 에너지의 생동감 있는 결합 |
| 물 | 물 | 깊은 감정적 연결이나 현실감 부족 |
| 물 | 흙 | 감성에 현실이 더해져 안정적 |

## 사례 분석

**A (금성: 전갈자리, 화성: 양자리) + B (금성: 양자리, 화성: 전갈자리)**

→ A의 화성(양자리)이 B의 금성(양자리)에 끌림: 강한 초기 매력
→ B의 화성(전갈자리)이 A의 금성(전갈자리)에 끌림: 깊이 있는 연결 욕구
→ 전체적으로 강렬한 끌림이지만 권력 다툼 가능성

이런 조합은 "좋아하지만 싸우는" 커플의 전형적인 패턴.
