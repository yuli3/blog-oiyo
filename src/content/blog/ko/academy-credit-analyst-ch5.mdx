## 신용분석사 시험 전략 개요

신용분석사는 한국금융연수원이 주관하는 자격증으로, 은행·캐피탈·카드사 등 금융기관 취업과 승진에 광범위하게 활용됩니다. 시험은 **필기시험(100문항)**으로만 구성되며, 70점 이상이면 합격입니다.

시험 과목 구성은 다음과 같습니다.

| 과목 | 문항 수 | 비중 |
|------|---------|------|
| 신용분석 이론 | 30문항 | 30% |
| 기업신용분석 | 35문항 | 35% |
| 개인신용분석 | 20문항 | 20% |
| 여신규정 및 법규 | 15문항 | 15% |

---

## 과목별 핵심 정리

### 1. 신용분석 이론

**신용 3C (전통적 신용 분석 기준)**

| 요소 | 내용 | 평가 방법 |
|------|------|----------|
| **Character (성격·의지)** | 채무 이행 의지 | 신용이력, 도덕성, 경영진 평판 |
| **Capacity (상환 능력)** | 채무 상환 현금흐름 | 재무비율, 현금흐름 분석 |
| **Capital (자본)** | 순자산 규모 | 부채비율, 자본적정성 |

> **추가 요소**: Collateral(담보), Condition(경기 조건)을 포함해 5C로 확장하기도 합니다.

**기대손실 공식**

```
기대손실(EL) = PD × LGD × EAD
- PD (Probability of Default): 부도 확률
- LGD (Loss Given Default): 부도 시 손실률
- EAD (Exposure at Default): 부도 시 익스포저
```

**신용등급 체계 비교**

| S&P / Fitch | Moody's | 의미 |
|-------------|---------|------|
| AAA | Aaa | 최고 신용등급 |
| AA | Aa | 매우 우수 |
| A | A | 우수 |
| BBB | Baa | 투자적격 최저 |
| BB | Ba | 투기적 등급 시작 |
| B | B | 투기적 |
| CCC | Caa | 매우 위험 |
| D | C | 부도 |

> **투자적격(Investment Grade)**: BBB- 이상 / **투기등급(Speculative Grade)**: BB+ 이하

### 2. 기업신용분석 핵심

**재무비율 완전 정리표**

| 구분 | 비율명 | 공식 | 의미 |
|------|--------|------|------|
| **수익성** | ROA | 당기순이익 ÷ 총자산 | 자산 활용 효율 |
| | ROE | 당기순이익 ÷ 자기자본 | 주주 수익률 |
| | 영업이익률 | 영업이익 ÷ 매출액 | 본업 수익성 |
| **안정성** | 부채비율 | 부채 ÷ 자기자본 | 재무 레버리지 |
| | 유동비율 | 유동자산 ÷ 유동부채 | 단기 지급능력 |
| | 이자보상배율 | EBIT ÷ 이자비용 | 이자 지급능력 |
| **활동성** | 총자산 회전율 | 매출액 ÷ 총자산 | 자산 활용도 |
| | 재고자산 회전율 | 매출원가 ÷ 재고자산 | 재고 순환 속도 |
| **성장성** | 매출증가율 | (당기매출-전기매출) ÷ 전기매출 | 외형 성장 |

**EBITDA와 현금흐름 분석**

```
EBITDA = 영업이익 + 감가상각비 + 무형자산상각비
순차입금 = 이자부채(단기차입금+사채+장기차입금) - 현금성자산
순차입금/EBITDA = 채무상환 능력 지표 (3배 이하 양호)
```

**도산 예측 모형 — 알트만 Z-Score**

```
Z = 1.2×X1 + 1.4×X2 + 3.3×X3 + 0.6×X4 + 1.0×X5
X1: 운전자본/총자산
X2: 이익잉여금/총자산
X3: EBIT/총자산
X4: 자기자본 시장가치/총부채 장부가치
X5: 매출액/총자산

Z > 2.99: 안전권 / 1.81~2.99: 회색지대 / Z < 1.81: 위험권
```

### 3. 개인신용분석 핵심

**CSS(Credit Scoring System) 변수 가중치**

| 평가 항목 | 가중치 | 세부 내용 |
|----------|--------|----------|
| 상환 이력 | 35% | 연체 여부, 연체 기간, 연체 금액 |
| 부채 수준 | 30% | 신용한도 대비 사용률, 총부채 규모 |
| 신용거래 기간 | 15% | 최초 신용거래 시점, 평균 계좌 연령 |
| 신규 신용 | 10% | 최근 신규 신용 조회 횟수 |
| 신용 유형 | 10% | 신용카드·할부·대출 등 다양성 |

**DSR (총부채원리금상환비율)**

```
DSR = 연간 원리금 상환액 합계 ÷ 연간 소득
규제 기준: 총 DSR 40% 초과 대출 제한 (2023년 기준)
```

### 4. 여신규정 및 법규 핵심

- **금융실명제법**: 실명 확인 의무, 비밀보호, 위반 시 징역 5년 이하
- **신용정보법**: 신용정보 수집·이용·제공 규제, 신용조회사(CB) 규정
- **상호저축은행법**: 저축은행 대출 한도·자산운용 규제
- **여신전문금융업법**: 카드·리스·할부금융 규제
- **대부업법**: 최고이자율(현행 연 20%), 등록 의무

## 자주 출제되는 공식 모음

> **이자율 관련**
```
단리: FV = PV × (1 + r × n)
복리: FV = PV × (1 + r)^n
실효이자율: (1 + r/m)^m - 1  (m: 이자 지급 횟수)
```

> **현재가치/채권**
```
채권 PV = C/(1+r) + C/(1+r)^2 + ... + (C+F)/(1+r)^n
듀레이션(D) = Σ[t × PVt] / 채권가격
수정 듀레이션 = D / (1 + r)
```

## 합격 후 활용

신용분석사 취득 후 진출할 수 있는 분야:

**금융기관**
- 시중은행 여신 심사팀 — 기업·개인 대출 심사
- 캐피탈·리스사 — 기업여신 분석
- 저축은행 — 소호·개인사업자 대출 심사

**비금융권**
- 신용평가사(NICE/KCB) — 개인·기업 신용모형 개발
- 증권사 — 채권·CP 신용분석
- 공기업 — 신용보증기금, 기술보증기금, 주택금융공사

**연계 자격증 로드맵**
```
신용분석사 → CFA Level I → CAIA(대안투자분석사)
신용분석사 → 재무위험관리사(FRM) → 금융리스크 전문가
신용분석사 → 투자자산운용사 → 펀드매니저
```
