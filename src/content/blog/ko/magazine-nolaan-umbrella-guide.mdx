## 노란우산공제란?

소기업·소상공인이 폐업·사망·노령 등의 위험에 대비하도록 중소기업중앙회가 운영하는 공제 제도입니다. 쉽게 말해 **자영업자용 퇴직금 + 절세 통장**입니다.

---

## 노란우산공제 핵심 요약

| 항목 | 내용 |
|------|------|
| **가입 대상** | 소기업·소상공인 대표자 (개인·법인 모두) |
| **월 납입액** | 5만원~100만원 (1만원 단위) |
| **소득공제** | 연 최대 500만원 |
| **공제 수령** | 폐업·사망·질병·노령(60세+) 시 |
| **운용 이자** | 연 3.3~3.5% (복리) |
| **압류 금지** | 예, 채권자 압류 불가 |

## 가입 자격 조건

### 개인사업자

```
업종별 매출 기준 이하:
- 제조·건설·광업: 120억원 이하
- 도소매: 50억원 이하
- 서비스업: 10억원 이하
```

### 법인 대표자

```
법인 대표이사도 가입 가능
단, 법인 소득이 아닌 '대표자 개인 소득'에 대해 공제 적용
→ 대표자 보수가 있어야 실질 절세 효과
```

### 가입 불가 업종

```
금융·보험업, 부동산업 중 일부, 무도장·유흥주점 등
→ 가입 전 중소기업중앙회(1566-7050) 확인 권장
```

## 소득공제 절세 효과

### 공제 한도

| 사업(종합)소득 | 공제 한도 |
|-------------|---------|
| 4,000만원 이하 | **연 500만원** |
| 4,000만원~1억원 | **연 300만원** |
| 1억원 초과 | **연 200만원** |

### 실제 절세액 계산

```
[ 사업소득 3,000만원 기준 ]
→ 과세표준 구간: 1,400만~5,000만원 → 세율 15%

연 500만원 납입 시:
→ 절세액: 500만원 × 15% = 750,000원
→ 지방소득세(10%) 포함: 825,000원 절세

[ 사업소득 7,000만원 기준 ]
→ 과세표준 구간: 5,000만~8,800만원 → 세율 24%
→ 연 300만원 × 24% × 1.1 = 792,000원 절세
```

> **5년 납입 시 절세액 합계**: 500만원 × 15% × 1.1 × 5년 = **4,125,000원** 절세

## 공제금 수령 조건

### 정상 수령 (목돈 + 이자)

| 수령 사유 | 조건 |
|---------|------|
| **폐업** | 사업 중단 후 공제금 신청 |
| **사망** | 수익자(상속인)에게 지급 |
| **노령** | 만 60세 이상 + 가입 10년 이상 |
| **질병·부상** | 6개월 이상 요양 필요 시 |
| **배우자 사망** | 가입자 생계 곤란 인정 시 |

### 임의 해지 (중도 해지)

```
정상 수령 사유 없이 해지 시:
→ 원금 + 이자 수령 가능 (손해 없음)
BUT:
- 납입 기간 1년 미만: 이자 없음
- 공제금 수령 시 기타소득세 부과 (세율 16.5%)
- 이미 받은 소득공제 환급 없음 (소득공제 혜택은 유지)
```

### 공제금 과세 정리

```
정상 수령 (폐업·노령 등): 퇴직소득세 적용 (일반 소득세보다 유리)
임의 해지: 기타소득세 16.5% 원천징수
→ 장기 유지할수록 세금 면에서 유리
```

## 납입 전략

### 얼마를 납입해야 할까?

```
목표: 소득공제 한도 최대 활용
→ 소득 4,000만원 이하: 월 41,667원 이상 (연 500만원)
→ 소득 7,000만원: 월 25,000원 이상 (연 300만원)

납입 여력에 따른 선택:
- 최소: 월 5만원 (연 60만원) → 복리 누적에 의미 있음
- 권장: 월 40만원 이상 → 소득공제 최대화
- 최대: 월 100만원 (연 1,200만원 가능, 공제는 한도까지만)
```

### 납입 방법

```
자동이체: 매월 지정일 출금 (납입 누락 방지)
수동 납입: 일시납 가능 (연말 몰아서 납입 시 공제 적용)
→ 연말에 여유 자금 있으면 12월에 6개월치 몰아 납입도 가능
```

## 노란우산공제 vs 유사 제도 비교

| 항목 | 노란우산공제 | IRP (개인형퇴직연금) | 연금저축펀드 |
|------|-----------|-------------------|-----------|
| 대상 | 자영업자·사업주 | 누구나 | 누구나 |
| 소득공제 | 연 200~500만원 | 세액공제 | 세액공제 |
| 세금 혜택 방식 | 소득공제 (세율 × 한도) | 세액공제 16.5%/13.2% | 세액공제 16.5%/13.2% |
| 수령 세금 | 퇴직소득세 (유리) | 연금소득세 | 연금소득세 |
| 압류 보호 | **있음** | 없음 | 없음 |
| 수익 방식 | 확정 이자 (안전) | 투자 수익 (변동) | 투자 수익 (변동) |

> **결론**: 소득이 높은 자영업자는 노란우산(소득공제 효과 큼) + IRP(세액공제)를 함께 활용하는 게 최적.

## 압류 보호의 중요성

```
사업 실패 → 채권자 추심 → 통장 압류
노란우산공제 납입금: 법적으로 압류 금지
→ 최악의 상황에서도 공제금 보호
```

이 점이 단순 예금·적금과 가장 다른 점입니다. 사업 리스크가 있는 자영업자에게는 **위기 대비 자산**으로서 특별한 의미를 가집니다.

```
1. 중소기업중앙회 홈페이지(nosaa.or.kr)

```

## 자주 묻는 질문

**Q. 창업 직후 바로 가입할 수 있나요?**
A. 네. 사업자등록 후 바로 가입 가능합니다. 창업 초기부터 가입할수록 복리 효과가 커집니다.

**Q. 소득이 거의 없어도 가입하는 의미가 있나요?**
A. 소득이 없으면 소득공제 혜택이 줄지만, 복리 적립과 압류 보호 효과는 여전히 유효합니다. 최소 월 5만원으로 시작해도 됩니다.

**Q. 폐업 후 재창업하면 기존 공제금은?**
A. 폐업 시 공제금 수령 후 재창업하면 다시 가입 가능. 또는 폐업하지 않고 사업 전환하면 기존 계약 유지 가능.

**Q. 법인 전환 시 공제는 어떻게 되나요?**
A. 개인 → 법인 전환 시 기존 공제 계약을 법인 대표자 자격으로 계속 유지하거나, 해지 후 재가입. 법인 전환 전 중소기업중앙회에 확인 권장.
