## 행정사법 — 자격과 결격사유

```
행정사 자격:
행정사 시험 합격
대통령령으로 정한 자격 소지자 (공무원 경력 등)

결격사유:
미성년자
파산선고 복권 안 된 자
금고 이상 형 선고 후 3년 미경과
행정사 자격 취소 후 3년 미경과
공무원 재직 중

업무 범위:
행정기관 제출 서류 작성
행정심판 청구서 작성·제출 대리
인허가 신청 보조
```

## 행정사 업무와 의무

```
업무 수행:
수임 사건 성실 처리 의무
비밀 유지 의무

보수:
의뢰인과 협의
과도한 보수 금지

등록:
사무소 소재지 시·도 행정사협회 등록
개업 신고

금지 행위:
소송 대리 불가 (변호사 영역)
법률 사무 대리 불가
허위 서류 작성
```

## 민법 — 계약 총론

```
계약 성립:
청약 + 승낙 = 계약 성립
청약의 구속력: 철회 불가 원칙

계약의 효력:
채권채무 발생
동시이행 항변권
위험부담

계약 해제:
법정해제: 이행불능·이행지체+상당기간
약정해제: 계약에서 정한 경우

해제 효과:
소급 효력 (원상회복)
손해배상 가능
```

## 민법 — 불법행위

```
일반 불법행위:
고의·과실로 타인 손해
손해배상 의무

특수 불법행위:
사용자 책임: 피용자의 불법행위
공작물 점유자 책임
동물 점유자 책임

손해배상:
재산적 손해 + 비재산적(위자료)
과실상계: 피해자 과실 시 감액

소멸시효:
불법행위: 안 날 3년 + 10년
```

## 핵심 개념 카드

**행정사 결격=3년** ★★★★★
: 취소 후 3년, 금고 이상 형 후 3년 결격.
*암기 포인트: 행정사결격=3년*

**불법행위 시효=3년+10년** ★★★★★
: 안 날 3년, 행위일 10년 소멸시효.
*암기 포인트: 불법행위=3+10*

**계약 해제=소급효** ★★★★☆
: 해제 시 처음부터 없었던 것처럼 원상회복.
*암기 포인트: 해제=소급*

## 실전 퀴즈

**Q. 행정사가 소송 대리를 하면 어떻게 되는가?**
> 행정사는 소송 대리 불가. 변호사법 위반. 행정사법 위반으로 자격 정지·취소 가능. 행정심판 청구서 작성은 가능하나 심판 대리는 변호사·행정사 가능. 소송은 변호사만 대리.

**Q. 사용자 책임이 성립하려면?**
> 피용자가 업무 집행 중 불법행위. 사용자와 피용자의 사용관계. 피해자는 사용자에게 직접 청구 가능. 사용자는 피용자에게 구상. 선임·감독 주의 다하면 면책 (사실상 어렵).
