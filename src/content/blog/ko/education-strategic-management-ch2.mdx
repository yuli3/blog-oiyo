## 포터의 본원적 전략

```
마이클 포터의 경쟁 우위 원천:
→ 원가 우위 (Cost Leadership)
→ 차별화 (Differentiation)
→ 집중화 (Focus)

원가 우위 전략:
→ 업계에서 가장 낮은 원가로 생산
→ 경험 곡선 효과: 누적 생산량 증가 → 단위 비용 감소
→ 규모의 경제: 생산량 증가 → 고정비 분산
→ 활용 기업: 코스트코, 이케아, 라이언에어, 이마트

차별화 전략:
→ 독특한 가치로 프리미엄 가격 부과 가능
→ 차별화 원천: 품질, 디자인, 브랜드, 기술, 서비스, 속도
→ 활용 기업: 애플, 루이비통, 독일 메르세데스벤츠

집중화 전략:
→ 특정 세그먼트에 집중 (틈새시장)
→ 원가 집중 또는 차별화 집중
→ 활용 기업: 롤스로이스 (고급차 집중), 전문 법률 회사

중간에 낀 전략 (Stuck in the Middle):
→ 어느 전략도 명확히 선택하지 않음
→ 경쟁력 없는 상황 → 피해야 함
```

## 블루오션 전략

```
레드오션 vs 블루오션 (킴·모보르뉴):

레드오션:
→ 기존 시장 공간, 치열한 경쟁
→ 파이를 나누는 경쟁
→ 가치-비용 트레이드오프를 당연시

블루오션:
→ 미개척 시장 공간 창조
→ 경쟁 무의미한 새 시장
→ 가치 혁신: 차별화 + 원가 절감 동시 추구
→ 예: 서커스 드 솔레이(Cirque du Soleil)

가치 혁신 (Value Innovation):
→ 전략 캔버스 (Strategy Canvas): 현 경쟁 요소 시각화
→ 4가지 행동 프레임워크:
  - 제거 (Eliminate): 불필요한 요소 제거
  - 감소 (Reduce): 기준 이하로 줄일 요소
  - 증가 (Raise): 기준 이상으로 높일 요소
  - 창조 (Create): 새롭게 만들 요소

블루오션 예시:
→ 닌텐도 Wii: 노인·여성 시장 개척 (조작 단순화)
→ 카카오택시: 불편한 택시 호출 문제 해결
→ 에어비앤비: 숙박 공유 시장 창조
```

## 앤소프 성장 매트릭스

```
앤소프(Ansoff) 매트릭스:
→ 기존/신 제품 × 기존/신 시장 = 4가지 성장 전략

1. 시장 침투 (Market Penetration):
→ 기존 시장 + 기존 제품
→ 시장 점유율 확대 전략
→ 가격 인하, 마케팅 강화, 사용 빈도 증가
→ 위험: 낮음, 성장 한계: 있음

2. 제품 개발 (Product Development):
→ 기존 시장 + 신 제품
→ 기존 고객에게 새 제품 판매
→ R&D 투자, 신제품 출시
→ 예: 애플이 아이폰 사용자에게 애플워치 판매

3. 시장 개발 (Market Development):
→ 신 시장 + 기존 제품
→ 새 지역/세그먼트 진출
→ 지리적 확장, 새 고객층 발굴
→ 예: 국내 브랜드 해외 진출

4. 다각화 (Diversification):
→ 신 시장 + 신 제품
→ 가장 위험하지만 잠재 수익 큼
→ 관련 다각화: 시너지 있는 산업
→ 비관련 다각화: 완전히 다른 산업
```

## BCG 매트릭스

```
BCG(Boston Consulting Group) 매트릭스:
→ 사업 포트폴리오 관리 도구
→ 두 축: 시장 성장률 × 상대적 시장 점유율

별 (Star):
→ 고성장·고점유 사업
→ 많은 투자 필요하지만 높은 수익
→ 미래 주력 사업으로 성장 기대

현금젖소 (Cash Cow):
→ 저성장·고점유 사업
→ 적은 투자로 많은 현금 창출
→ 다른 사업 자금원 역할

물음표 (Question Mark, Problem Child):
→ 고성장·저점유 사업
→ 많은 투자 필요, 불확실한 미래
→ 투자 확대(별로) vs 철수 결정 필요

개 (Dog):
→ 저성장·저점유 사업
→ 현금 창출·투자 필요 모두 낮음
→ 유지(틈새)·매각·정리 검토

활용:
→ 현금젖소에서 얻은 현금 → 별·물음표에 투자
→ 개 사업은 정리 검토
→ 한계: 두 가지 기준만 고려
```

## 기업 성장 전략

```
수직 통합 (Vertical Integration):
→ 공급망에서 더 많은 단계 통제
→ 후방 통합: 공급업체 역할 내부화 (부품 직접 생산)
→ 전방 통합: 유통·판매 내부화
→ 장점: 비용 절감, 품질 통제, 진입 장벽
→ 단점: 유연성 감소, 집중 위험

수평 통합:
→ 같은 산업 내 경쟁사 합병
→ 시장 점유율 확대, 규모의 경제

M&A (인수·합병):
→ 인수 (Acquisition): 한 기업이 다른 기업 주식·자산 취득
→ 합병 (Merger): 두 기업이 하나로 결합
→ 인수 동기: 시장 진입, 기술·역량 획득, 시너지, 경쟁 제거
→ 실패 요인: 과도한 프리미엄, 통합 실패, 문화 충돌

전략적 제휴 (Strategic Alliance):
→ 독립성 유지하며 협력
→ 합작투자(Joint Venture), 라이선싱, 공동 마케팅
→ 장점: 위험·비용 분담, 상호 보완 역량
→ 단점: 목표 불일치, 기술 유출 위험

다각화 전략:
→ 관련 다각화: 현재 사업과 연관 (기술·시장 공유)
  예: 삼성전자 → 삼성생명
→ 비관련 다각화 (복합기업, Conglomerate):
  완전히 다른 산업 (포트폴리오 위험 분산)
  예: GE, SK그룹
```

## 자주 묻는 질문

**Q. 블루오션 전략은 실제로 지속 가능한가요?**
A. 블루오션이 형성되면 경쟁사들이 모방을 시도하여 결국 레드오션이 될 수 있습니다. 따라서 지속적인 가치 혁신이 필요합니다. 실제로 Cirque du Soleil도 모방 경쟁사들이 등장했고, 닌텐도 Wii는 결국 소니·마이크로소프트의 모방 전략에 시장 점유율을 빼앗겼습니다. 블루오션 전략의 핵심은 일회성이 아닌 지속적 혁신을 통해 앞서 나가는 것입니다.

**Q. BCG 매트릭스의 '개' 사업은 무조건 철수해야 하나요?**
A. 아닙니다. '개' 사업도 틈새시장에서 수익을 낼 수 있거나, 다른 사업과 시너지가 있으면 유지가 정당화될 수 있습니다. 또한 BCG 매트릭스는 두 가지 기준(성장률·점유율)만 보기 때문에 전략적 중요성, 경쟁사 대응, 미래 가능성 등 다른 요소를 무시합니다. 매트릭스는 출발점이지 최종 답이 아닙니다.
