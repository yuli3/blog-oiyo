## Quantitative Comparison (QC) 전략

QC는 GRE 고유의 문제 유형입니다.

**4가지 선택지**:
- (A) Quantity A가 더 크다
- (B) Quantity B가 더 크다
- (C) 두 수량이 같다
- (D) 정보 부족으로 판단 불가

### QC 황금 규칙

1. **두 수량을 단순화한 후 비교**
2. **특수값 테스트**: 0, 1, −1, 분수 등 극단적 값으로 검증
3. **대수 조작**: 양변에 같은 수를 더하거나 같은 양수를 곱해도 관계 유지
4. **함정**: 음수 곱셈 시 부등호 방향 반전!

## 핵심 수학 개념 빠른 정리

### 수와 연산
- 소수: 2, 3, 5, 7, 11... (2는 유일한 짝수 소수)
- 절댓값: |x| ≥ 0
- 지수: aᵐ × aⁿ = aᵐ⁺ⁿ

### 대수
- 이차방정식 근의 합: −b/a
- 이차방정식 근의 곱: c/a

### 기하
- 피타고라스: a² + b² = c²
- 원 넓이: πr², 둘레: 2πr
- 삼각형 합동 조건: SAS, ASA, SSS

### 통계
- 평균 = 합계/개수
- 범위 = 최댓값 − 최솟값

### 확률
- P(A 또는 B) = P(A) + P(B) − P(A∩B)
- 독립사건: P(A∩B) = P(A) × P(B)

## Data Interpretation 전략

그래프·표 세트에서 여러 문제를 풉니다.

**필수 기술**:
- **비율 계산**: 전체 대비 특정 값의 비율
- **변화율**: (New − Old) / Old × 100
- **추정**: 정확한 계산보다 근사값으로 빠르게 대답

**함정 주의**:
- Y축 단위 (천, 백만, %)
- 복수 그래프 간의 정보 연결
- "Approximately" — 정확한 답 요구하는 게 아님

## 실전 연습 문제

**Q1 (QC).** x > 0  
Column A: x + 1/x  
Column B: 2

A) A > B  B) B > A  C) A = B  D) 불확실

**정답**: C (AM-GM 부등식: x + 1/x ≥ 2, 등호는 x=1일 때)
→ A ≥ B이지만 등호 가능 → **D (불확실)**

**Q2.** 6명이 원형 테이블에 앉는 경우의 수는?

정답: (6−1)! = 5! = 120
