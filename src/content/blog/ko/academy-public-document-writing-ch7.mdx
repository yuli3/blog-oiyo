## 숫자 표기 원칙

행정 업무 처리 규정과 한글 맞춤법에 근거.

```
기본 원칙:
- 수량·금액은 아라비아 숫자 사용
- 법령 조문 번호: 아라비아 숫자
- 서술문 속 수사: 한글 또는 아라비아 숫자 (문맥에 따라)

규칙:
① 수량·수치: 아라비아 숫자
   바람직: 3명, 50건, 12월 31일
   지양: 세 명, 쉰 건 (공문서 내 수치)

② 만 단위 구분:
   10,000 → "1만" (서술 시)
   정확한 수치 필요 시: "10,000원"
   서술: "1만 원" 또는 "10,000원"

③ 억·만 혼합:
   125,300,000 → "1억 2,530만 원"
   → 한글로 단위 구분하여 읽기 쉽게
```

## 금액 표기

```
금액 표기 방법:
① 정확 표기: "금 3,500,000원" 또는 "금 3,500,000원정"
   → 계약서·예산 문서 등 공식 금액

② 서술 표기: "3,500만 원"
   → 보고서·기안문 서술부

③ 한글 병기 (중요 계약):
   "금 사백오십만 원(₩4,500,000)"
   → 위변조 방지용

주의:
- 원 단위 생략하지 말 것: "3,500만" (X) → "3,500만 원" (O)
- 외국 통화: "$3,500" 또는 "미화 3,500달러"
```

## 날짜 표기

```
공문서 날짜 표기 원칙 (행정 업무 처리 규정):
- 연·월·일 순 아라비아 숫자
- 마침표로 구분

올바른 표기:
2026. 5. 13.
→ 연도: 4자리, 월: 2자리 불요, 일: 마지막에도 마침표

나쁜 예:
- 2026년 5월 13일 (X, 공문서 형식 아님)
- 26. 5. 13. (X, 연도 줄임 금지)
- 2026.5.13 (X, 마지막 마침표 누락)

기간 표기:
2026. 1. 1. ~ 2026. 12. 31.
→ 물결표(~)로 기간 연결

회계연도:
2026년도 (연도 + 도(度))
→ "2026년 예산" (X) → "2026년도 예산" (O)
```

## 시간 표기

```
24시간제 원칙:
14:00, 09:30, 18:00

12시간제는 혼동 우려 시 피함:
오후 2시 → 14:00 (O)

일과 시간 외 업무:
"22:00 이후" 또는 "22시 이후"
```

## 단위 표기

```
면적:
- ㎡ (제곱미터) 사용
- 평 사용 지양 (공식 문서)
  → "100평" (X) → "330.58㎡" (O)

거리·무게:
- SI 단위 사용 (m, km, kg, t)
- "100m" (O), "100메터" (X)

통화:
- 원화: 원 (₩)
- 달러: 미화 ○달러 또는 USD ○

퍼센트:
- % 사용
- "10퍼센트" (X) → "10%" (O)
  단, 문장 처음 시작은 숫자 불가
  → "10%를 넘었습니다" (O)
  → "10%는 ~" (X) → "전체의 10%는 ~" (O)
```

## 로마자 및 부호

```
외국어·외래어:
- 원칙: 한글로 표기
- 전문 용어·고유명사: 한글(원어) 병기
  예: "인공지능(AI)", "국내총생산(GDP)"

숫자와 단어 연결:
- 제1조, 제2항 → 한자어와 아라비아 숫자 병용
- "제일조" (X) → "제1조" (O)

줄임표:
- "…" (3점 줄임표) 또는 "……" (6점)
  → 공문서에서 가급적 사용 자제
```

## 핵심 개념 카드

**공문서 날짜 표기** ★★★★★
: 2026. 5. 13. 형식. 마지막 마침표 필수. 연도 4자리. 한글 표기 금지.
*암기 포인트: 2026. 5. 13. (마지막 마침표 포함)*

**금액 한글 단위 구분** ★★★★★
: 125,300,000 → "1억 2,530만 원". 서술 시 단위 구분 가독성.
*암기 포인트: 억·만 단위 구분 후 "원" 붙이기*

**면적 단위 변환** ★★★★☆
: 1평 ≈ 3.3058㎡. 공문서는 ㎡ 사용. 100평 = 약 330.58㎡.
*암기 포인트: 공문서 면적=㎡, 평 사용 금지*

## 실전 퀴즈

**Q. "2026년 5월 13일"을 공문서 양식으로 올바르게 표기하면?**
> 2026. 5. 13. (마지막 마침표 포함. 연도 4자리, 한글 월일 표기 사용 안 함.)

**Q. "3,500,000원"을 서술 방식으로 자연스럽게 표기하면?**
> "350만 원" 또는 "3,500,000원(삼백오십만 원)". 계약서 등 위변조 방지 문서는 한글 병기.
