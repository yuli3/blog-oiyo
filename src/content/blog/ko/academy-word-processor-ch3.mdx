## 매크로(Macro) 개요

매크로는 **반복적인 작업을 자동화**하는 기능입니다. 복잡한 서식 설정, 반복되는 편집 작업을 기록해 두고 필요할 때 단축키 하나로 실행할 수 있습니다.

**활용 예시**:
- 특정 서식(글꼴·크기·색상·정렬)을 한 번에 적용
- 머리말/꼬리말 자동 삽입
- 표 작성·형식 지정 자동화

---

## 매크로 기록 (Recording)

### 기록 방법

1. **도구 → 매크로 → 매크로 기록 시작**
2. 또는 Alt+Shift+F8

### 기록 설정 창 항목

| 항목 | 설명 |
|------|------|
| **매크로 이름** | 영문·숫자 조합 권장 (공백 불가) |
| **단축키** | 매크로 실행 단축키 지정 (예: Ctrl+Shift+M) |
| **저장 위치** | 현재 문서 / 공유 매크로 파일 |
| **설명** | 매크로 용도 메모 |

### 기록 진행

1. 기록 시작 → 마우스 포인터에 녹화 표시 나타남
2. 원하는 작업 순서대로 실행 (글꼴 변경, 크기 조정, 색상 변경 등)
3. **도구 → 매크로 → 기록 중지** 또는 Alt+Shift+F8

> **주의**: 매크로 기록 중에는 키보드·메뉴 조작만 기록됩니다. 마우스 이동은 기록되지 않습니다.

## 매크로 실행

### 방법 1: 단축키

지정한 단축키(예: Ctrl+Shift+M)를 누르면 즉시 실행됩니다.

### 방법 2: 메뉴

도구 → 매크로 → 매크로 실행 → 목록에서 선택 → 실행

### 방법 3: 도구 상자 버튼

매크로를 도구 상자 버튼에 연결하면 버튼 클릭으로 실행 가능합니다.

## 스크립트 매크로 편집

기록된 매크로는 **스크립트 편집기**로 수정할 수 있습니다.

### 스크립트 편집기 열기

도구 → 매크로 → 스크립트 편집기

### 한글 스크립트 기본 구조

```
Sub MyMacro()
    // 글꼴 변경
    HFont = "바탕"
    HFontSize = 12
    
    // 텍스트 선택 후 서식 적용
    HAction.SetMessageBoxMode(1)
    HAction.Run("CharShape")
    HParameterSet.HCharShape.FontName = "바탕"
    HAction.Execute("CharShape")
End Sub
```

### 자주 쓰는 매크로 예시 5가지

**1. 제목 서식 자동 적용**
```
Sub ApplyTitle()
    // 선택 텍스트에 제목 서식 (HY헤드라인M, 18pt, 가운데 정렬, 굵게)
    With HAction
        .SetMessageBoxMode(1)
        ...
    End With
End Sub
```

**2. 본문 서식 초기화**
```
// 글꼴: 함초롬바탕, 10pt, 보통, 왼쪽 정렬
```

**3. 페이지 번호 삽입**
```
// 머리말에 페이지 번호 자동 삽입
```

**4. 표 자동 생성**
```
// 3행 4열 표를 자동으로 생성하고 크기 조정
```

**5. 인쇄 미리보기**
```
// 인쇄 미리보기 실행 단축키화
```

## 워드프로세서 1급 필기 핵심 정리

### 타이핑

| 항목 | 내용 |
|------|------|
| **타이핑 속도** | 1급: 분당 300타 이상 |
| **오류 처리** | 규정에 따라 감점 |
| **시간 제한** | 10분 |

### 교정 부호

시험에서 자주 출제되는 교정 부호:

| 기호 | 의미 |
|------|------|
| ∧ | 삽입 |
| × | 삭제 |
| ○ | 붙여쓰기 |
| ↪ | 줄 바꿈 |
| ⟳ | 행 바꿈 (단락 변경) |
| □ | 1칸 띄우기 |
| = | 동일하게 (본래대로) |
| / | 소문자로 |
| ≡ | 대문자로 |
| ▽ | 들여쓰기 |

## 워드프로세서 1급 합격 후 활용

| 진로 | 활용 |
|------|------|
| 사무직 취업 | 문서 작성 능력 증명 |
| 공무원 시험 | 필기 우대 (일부 직종) |
| 컴퓨터활용능력 1급 준비 | 스프레드시트·DB 추가 |
| 비서자격증 연계 | 사무 자동화 역량 강화 |

워드프로세서 1급은 **사무 자동화 능력의 기본기**를 보여주는 자격증입니다. 컴퓨터활용능력 1급, 정보처리기사와 함께 취득하면 IT 사무 역량 풀패키지가 완성됩니다.
