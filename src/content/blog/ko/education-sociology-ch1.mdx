## 사회학(Sociology)이란?

사회학은 인간의 사회적 행동, 집단, 제도, 사회 구조를 과학적으로 연구하는 학문입니다. 개인의 행동이 사회적 맥락에서 어떻게 형성되고, 사회 구조가 어떻게 유지·변화하는지를 탐구합니다.

```
사회학의 핵심 질문:
→ 사회는 어떻게 유지되고 변화하는가?
→ 불평등은 왜 발생하며 어떻게 지속되는가?
→ 개인은 사회에 의해 어떻게 형성되는가?
→ 사회 제도는 어떻게 작동하는가?

사회학의 상상력 (Sociological Imagination, C. W. Mills):
→ 개인적 문제를 사회 구조적 맥락에서 이해하는 능력
→ 예: 실업은 개인의 게으름이 아니라 경제 구조의 문제일 수 있음
```

## 사회학의 3대 이론 관점

### 1. 기능주의 (Functionalism)

```
핵심 명제:
→ 사회는 각 부분이 기능을 수행하는 유기체와 같음
→ 각 제도는 사회 전체의 안정·유지에 기여

주요 학자:
- 에밀 뒤르켐 (Durkheim): 사회 분업, 집합 의식
- 탈콧 파슨스 (Parsons): AGIL 기능 체계
- 로버트 머튼 (Merton): 순기능·역기능 구분

머튼의 순기능·역기능:
- 순기능 (Manifest Function): 의도된 명시적 기능
  예: 교육의 지식 전달 기능
- 역기능 (Latent Function): 의도치 않은 잠재적 기능
  예: 교육이 사회 불평등 재생산

비판:
→ 현상 유지 편향, 갈등과 변화 설명 미흡
```

### 2. 갈등론 (Conflict Theory)

```
핵심 명제:
→ 사회는 자원과 권력을 둘러싼 집단 간 갈등의 장
→ 지배 집단이 현 체제를 정당화하여 권력 유지

주요 학자:
- 카를 마르크스 (Marx): 계급 갈등, 자본주의 비판
- 막스 베버 (Weber): 계급·지위·권력 3차원 불평등
- 랄프 다렌도르프 (Dahrendorf): 현대 갈등론 발전

마르크스의 핵심 개념:
- 상부구조: 법, 정치, 이데올로기 (하부구조에 의해 결정)
- 하부구조 (토대): 생산 관계, 경제 구조
- 소외 (Alienation): 노동자가 자신의 노동 결과물로부터 분리됨
- 이데올로기: 지배계급의 생각이 사회 지배적 생각이 됨

비판:
→ 사회 통합·협력 측면 경시
→ 경제 결정론적 경향
```

### 3. 상징적 상호작용론 (Symbolic Interactionism)

```
핵심 명제:
→ 사회는 인간들이 상징(언어, 몸짓)을 통해 상호작용하며 의미를 만들어가는 과정

주요 학자:
- 조지 허버트 미드 (G.H. Mead): 자아의 사회적 형성
- 허버트 블루머 (Blumer): 상징적 상호작용론 정립
- 어빙 고프만 (Goffman): 연극론적 접근

미드의 자아 이론:
- I (주체적 자아): 자발적, 충동적 자아
- Me (객체적 자아): 사회화된, 타인의 기대에 반응하는 자아
- 일반화된 타자: 특정인이 아닌 사회 전체의 기대

고프만의 연극론:
→ 일상생활은 연극 무대와 같음
→ 전면 무대: 타인에게 보이는 공식 행동
→ 후면 무대: 긴장을 푸는 사적 공간

비판:
→ 거시 구조 설명 부족
→ 권력·불평등 분석 약함
```

## 사회화 (Socialization)

```
사회화란:
→ 개인이 사회의 문화, 규범, 가치를 내면화하는 과정

1차 사회화 (Primary Socialization):
→ 가족을 통한 초기 사회화
→ 언어, 기본 규범, 가치관 습득

2차 사회화 (Secondary Socialization):
→ 학교, 또래, 대중매체, 직장을 통한 사회화
→ 특정 역할·직업 문화 학습

사회화의 주체 (사회화 기관):
1. 가족: 최초·가장 영향력 큰 사회화 기관
2. 학교: 공식적 지식·규범 전달
3. 또래 집단: 비공식 사회화 (특히 청소년기)
4. 대중매체: 광범위한 문화 전달
5. 직장: 성인기 사회화

재사회화 (Resocialization):
→ 이전 사회화 내용을 버리고 새로운 가치·규범 학습
→ 예: 군대, 교도소, 종교 개종
```

## 사회 구조와 사회 제도

```
사회 구조:
→ 사회 내 상호 작용의 반복적인 패턴
→ 개인의 행동에 영향을 주는 제약과 기회의 틀

사회 제도 (Social Institution):
→ 사회 주요 욕구를 충족하기 위해 발전한 안정적 체계

5대 사회 제도:
1. 가족: 생식, 사회화, 경제 협력
2. 교육: 지식 전달, 사회화, 사회 이동
3. 경제: 재화·서비스 생산·분배
4. 정치: 권력 배분, 사회 통제
5. 종교: 의미 제공, 사회 통합
```

## 사회적 불평등

```
불평등의 차원:
1. 계급 (Class): 경제적 자원에 따른 위계
2. 지위 (Status): 사회적 명예·위신
3. 권력 (Power): 타인의 행동에 영향을 미치는 능력

사회 이동 (Social Mobility):
- 수평 이동: 같은 계층 내 이동 (직업 변경)
- 수직 이동: 계층 간 이동
  - 상향 이동: 더 높은 계층으로
  - 하향 이동: 더 낮은 계층으로
- 세대 내 이동: 한 세대 내 계층 변화
- 세대 간 이동: 부모세대 vs 자녀세대 계층 비교

불평등 이론:
- 기능주의: 불평등은 재능 있는 자를 중요한 위치에 배치하는 기능적 보상
- 갈등론: 불평등은 지배계급이 권력을 유지하는 구조적 산물
```

## 문화(Culture)의 개념

```
문화란:
→ 한 사회의 구성원들이 공유하는 신념, 가치, 규범, 행동 양식, 상징의 총체

문화의 구성 요소:
- 상징 (Symbols): 의미를 담은 기호 (언어, 제스처)
- 가치 (Values): 바람직한 것에 대한 공유된 믿음
- 규범 (Norms): 행동 기대·규칙
  - 관습 (Folkways): 일상적 관행 (악수, 식사 예절)
  - 도덕 (Mores): 강력한 도덕 규범
  - 법 (Laws): 공식화된 규범

문화 다양성:
- 에스노센트리즘 (자문화 중심주의): 자국 문화를 기준으로 타문화 판단
- 문화 상대주의: 각 문화를 그 맥락에서 이해

하위문화 (Subculture):
→ 전체 사회와 구분되는 가치·규범을 가진 집단 문화
반문화 (Counterculture):
→ 지배 문화에 적극 반대하는 하위문화
```

## 자주 묻는 질문

**Q. 기능주의와 갈등론 중 어느 것이 더 옳은가요?**
A. 두 이론 모두 사회 현상의 일면을 설명합니다. 기능주의는 사회 통합과 안정을, 갈등론은 권력 불평등과 변화를 잘 설명합니다. 현대 사회학은 두 관점을 상호 보완적으로 활용합니다.

**Q. 사회학적 상상력은 일상생활에서 어떻게 활용되나요?**
A. 예를 들어 '왜 어떤 지역에는 취업자가 적을까?'를 개인의 능력 부족이 아니라 산업 구조, 교육 기회, 지역 개발 정책 등 사회적 맥락에서 바라보는 것이 사회학적 상상력의 적용입니다.
