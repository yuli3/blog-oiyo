## 조사 보고서 작성

```
보고서 구성 요소:
→ 표지: 제목·날짜·작성자·기관
→ 목차·초록 (요약문)
→ 서론: 연구 배경·목적·필요성·연구 문제
→ 이론적 배경: 선행 연구·이론 검토
→ 연구 방법: 연구 설계·표본·측정도구·분석 방법
→ 결과: 기술통계·가설 검정·분석 결과
→ 논의: 결과 해석·선행 연구 비교·의미
→ 결론: 요약·한계·후속 연구 제언
→ 참고문헌·부록 (설문지·SPSS 출력)

APA 형식 (American Psychological Association):
→ 인용 방법: 저자(연도) 또는 (저자, 연도)
  단독 저자: (김철수, 2023)
  2 저자: (김철수, 이영희, 2023)
  3명 이상: (김철수 외, 2023)
→ 참고문헌 형식:
  단행본: 저자 (연도). 제목. 출판사.
  학술지: 저자 (연도). 논문 제목. 학술지, 권(호), 쪽-쪽.
→ 표와 그림 형식:
  표 제목: 표 위에
  그림 제목: 그림 아래
  출처 명시·단위·통계 설명

결과 시각화:
→ 기술통계 표: 평균·표준편차·왜도·첨도
→ 상관 행렬: 변수 간 상관계수 표
→ 그래프 선택:
  빈도·비율: 막대·원형
  분포: 히스토그램·상자 그림
  관계: 산점도·선 그래프
  비교: 다중 막대 그래프
→ 시각화 원칙: 단순·명확·정확·비왜곡

통계 결과 보고:
→ t검정 보고: t(df) = 값, p = 값
  예: t(98) = 2.45, p = .016
→ ANOVA 보고: F(df1, df2) = 값, p = 값
  효과크기 eta2 = 값 보고
→ 상관 보고: r(n-2) = 값, p = 값
→ 회귀 보고: F(df1, df2) = 값, p = 값, R2 = 값
  각 계수: B = 값, beta = 값, t = 값, p = 값
```

## 연구 윤리

```
연구 윤리 원칙:
→ 벨몬트 보고서 (Belmont Report, 1979):
  인격 존중: 자율성·동의
  선행: 이익 극대화·위험 최소화
  정의: 대상자 공정한 선택

IRB (기관생명윤리위원회):
→ 인간 대상 연구의 윤리 심사 기관
→ 심사 유형:
  면제 심사: 위험 없는 단순 설문
  신속 심사: 최소 위험 연구
  정식 심사: 위험 있는 연구
→ IRB 검토 항목:
  위험·이익 균형
  동의 과정·정보 제공
  대상자 선정의 공정성

연구 참여 동의:
→ 자발적 동의: 강제 없는 자유로운 결정
→ 정보에 기반한 동의 (Informed Consent):
  연구 목적·절차·위험·이익
  개인정보 처리 방법·철회 권리
→ 동의서 필수 포함 항목:
  연구자 정보·참여 내용·자유로운 철회
  개인정보 비밀 보호 방법
→ 취약 대상자 특별 보호:
  아동: 부모 동의 + 아동 동의
  인지 장애: 대리 동의
  수감자: 자발성 보장 어려움

연구 부정 행위:
→ 위조 (Fabrication): 없는 데이터 만들어냄
→ 변조 (Falsification): 데이터 조작
→ 표절 (Plagiarism): 타인 아이디어·글 무단 사용
→ 중복 게재: 같은 내용 여러 학술지 투고
→ 저자 문제:
  허위 저자 (Ghost Authorship)
  선물 저자 (Gift Authorship)
→ 이해 충돌: 연구 결과에 영향 미칠 이익 관계

개인정보 보호:
→ 익명화 (Anonymization): 식별 정보 완전 제거
→ 가명화 (Pseudonymization): 식별 정보 대체
→ 개인정보 보호법: 수집 동의·목적 외 사용 금지
→ 데이터 보관: 최소 기간·안전한 저장
  연구 원자료: 보통 3~5년 보관 권장
```

## 구조방정식 모형

```
구조방정식 모형 (SEM, Structural Equation Modeling):
→ 잠재 변수 포함 가설 모형 검증
→ 측정 모형 (CFA) + 구조 모형 통합
→ 경로 분석·다중회귀·요인분석 통합 접근

측정 모형 (Confirmatory Factor Analysis, CFA):
→ 잠재 변수와 관측 변수 관계 명시적 가설
→ 요인 부하량·오차 분산 추정
→ 수렴 타당도·판별 타당도 검증

구조 모형:
→ 잠재 변수 간 인과 경로 설정
→ 직접 효과·간접 효과·총 효과

모형 적합도 지수:
→ 절대 적합도:
  Chi-Square: 작을수록 좋음 (표본 크기 민감)
  RMSEA: 0.05 이하 좋음·0.08 이하 수용
  SRMR: 0.08 이하 수용
→ 증분 적합도:
  CFI: 0.90 이상 수용·0.95 이상 좋음
  TLI (NNFI): 0.90 이상 수용
→ 간명도:
  AIC·BIC: 모형 비교 기준 (낮을수록 좋음)

AMOS·R lavaan 활용:
→ AMOS: 그래픽 인터페이스·SPSS 연동
→ lavaan (R): 코드 기반·무료
  모형 명세: ~· =~· ~~
  예: A =~ x1 + x2 + x3 (잠재 변수)
      B ~ A (경로)
```

## 매개·조절 분석

```
매개 분석 (Mediation Analysis):
→ X → M → Y (M이 X와 Y 사이 경로 설명)
→ 완전 매개: X→Y 직접 효과 사라짐
→ 부분 매개: 직접 효과 감소되지만 유의

매개 검증 방법:
→ 바론-케니 4단계 (Baron & Kenny):
  1단계: X → Y 유의
  2단계: X → M 유의
  3단계: M → Y 유의 (X 통제)
  4단계: X → Y 비유의 (완전 매개)
  비판: 검증력 낮음·직접·간접 효과 분리 불충분
→ Sobel 검정: 간접 효과의 표준 오차 추정
  간접 효과 = a * b / SE (a*b)
  비판: 정규성 가정·소표본 부적합
→ 부트스트래핑 (Bootstrapping):
  현재 가장 권장되는 방법
  재표집으로 간접 효과 신뢰구간 추정
  95% CI가 0 포함 안 하면 유의
  SPSS PROCESS macro 활용 (Hayes)

조절 분석 (Moderation Analysis):
→ X와 Y의 관계가 Z에 따라 달라짐
→ 상호작용 항: X * Z
  Y = b0 + b1*X + b2*Z + b3*(X*Z)
  b3 유의하면 조절 효과 있음
→ 단순 기울기 분석:
  Z의 상·중·하 수준에서 X→Y 기울기
  플롯: 조절 효과 시각화
→ 중심화 (Centering): 주효과 해석·다중공선성 감소

조절 매개 분석 (Moderated Mediation):
→ 매개 효과가 조절 변수에 따라 달라짐
→ 조건부 간접 효과: Z 수준별 간접 효과
→ PROCESS macro Model 7·14 활용
→ 지수 of 조절된 매개 (Index of Moderated Mediation)

종단 연구 분석:
→ 반복 측정 분산분석: 시점 내·시점 간 변화
→ 잠재 성장 모형 (Latent Growth Model):
  절편 (초기값)·기울기 (변화율) 잠재 변수
  개인 간 차이 성장 패턴
→ 교차 지연 패널 모형 (CLPM):
  두 변수의 상호 인과 관계
```

## 자주 묻는 질문

**Q. 사회조사분석사 시험에서 구조방정식 모형까지 출제되나요?**
A. 1급(사회조사분석사 1급)에서는 구조방정식 관련 개념이 출제되지만, 2급(더 일반적인 자격증 수준)에서는 기초 통계와 SPSS 분석이 주를 이룹니다. 구조방정식의 경우 모형 적합도 지수(CFI·RMSEA·SRMR)의 기준값과 잠재 변수·관측 변수의 개념을 이해하면 충분합니다. 매개·조절 분석은 1급 필기와 실기 모두에서 중요하게 다뤄집니다. 특히 바론-케니 4단계 절차와 부트스트래핑의 차이, 조절 분석에서의 상호작용 항 해석이 자주 출제됩니다. 6강의 내용은 시험 범위 전체를 포괄하는 것이며, 실제 시험 준비는 공식 출제 기준을 확인하고 기출 문제 중심으로 접근하는 것이 효율적입니다. SPSS를 직접 다루는 실기는 매개·조절 분석을 실제로 수행할 수 있어야 하므로 PROCESS macro 사용법을 익혀두는 것이 도움이 됩니다.

**Q. 연구 윤리에서 '면제 심사'와 '신속 심사'는 어떻게 결정되나요?**
A. IRB 심사 유형 분류는 연구의 위험 수준을 기준으로 합니다. 면제 심사(Exempt Review)는 위험이 최소한이어서 IRB 전체 심의 없이 면제되는 경우입니다. 해당 조건: 익명화된 설문 조사, 관찰 연구로 개인 식별 불가, 공개된 자료 분석 등입니다. 그러나 "면제"라도 연구자 임의 결정이 아니라 IRB가 면제 여부를 확인해야 합니다. 신속 심사(Expedited Review)는 최소 위험 연구로, 전체 위원회 대신 지정 위원 1~2명이 심사합니다. 해당 조건: 건강한 성인 대상 표준 절차 연구, 기존 자료·문서·기록 활용, 피부·구강 비침습적 표본 수집 등입니다. 정식 심사(Full Board Review)는 취약 대상자 포함, 신체적·심리적 위험이 있는 연구, 기만 사용 연구에 적용됩니다. 실무에서는 '이 연구가 참여자에게 정상적 생활에서 겪는 것 이상의 위험을 주는가?'가 핵심 판단 기준입니다.
