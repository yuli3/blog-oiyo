## 2. 조직 변화와 학습 조직

### (1) ★ 레윈(Lewin)의 변화의 3단계

<FlowChart
  title="레윈의 변화 3단계"
  steps={[
    {
      title: "해빙 (Unfreezing)",
      description:
        "현상 유지에 대한 동기 부여. 변화의 필요성 인식시키기. 기존 행동의 힘을 약화시킴.",
    },
    {
      title: "변화 (Changing/Moving)",
      description: "실제 행동 변화가 일어나는 단계. 새로운 태도·행동 학습.",
    },
    {
      title: "재동결 (Refreezing)",
      description:
        "새로운 행동을 안정화하고 강화하는 단계. 변화를 지속적으로 유지.",
    },
  ]}
/>

**변화 수용 3가지 방식:**

1. **순응화**: 우호적 반응 회피를 위해 영향력 수용 (ex. 군대)
2. **동일화**: 좋아하는 사람·집단의 태도를 받아들임 (ex. 연예인 따라 하기)
3. **내면화**: 타인의 주장이 자신의 가치 체계에 부합하여 수용 (ex. 교수 강의)

### (2) 학습 조직 (Learning Organization)

| 개념          | 내용                                                  |
| ------------- | ----------------------------------------------------- |
| 단일고리 학습 | 잘못이 검출되면 수정만 함 (현재 시스템 내에서 수정)   |
| 이중고리 학습 | 잘못 시 목적·정책·절차 자체를 수정. 근본 가정에 도전. |

### (3) 기술과 조직구조 — 우드워드 (Woodward) & 페로 (Perrow)

**우드워드의 기술복잡성 3분류:**

| 생산 기술     | 특징                             | 적합 조직구조 |
| ------------- | -------------------------------- | ------------- |
| 단위·소량생산 | 고객별 맞춤 생산 (비반복적)      | 유기적        |
| 대량생산      | 표준화된 조립 공정 (반복적)      | 기계적        |
| 연속생산      | 화학·정유처럼 연속 변환 (자동화) | 유기적        |

**페로의 기술 2차원 매트릭스:**

|                      | 과업 다양성 낮음                   | 과업 다양성 높음                |
| -------------------- | ---------------------------------- | ------------------------------- |
| 문제 분석가능성 높음 | **일상적 기술** (기계적 조직 적합) | **공학적 기술** (다소 기계적)   |
| 문제 분석가능성 낮음 | **장인 기술** (다소 유기적)        | **비일상적 기술** (유기적 적합) |
