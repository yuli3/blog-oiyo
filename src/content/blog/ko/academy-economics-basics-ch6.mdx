## 시장 실패의 개념

```
시장 실패 (Market Failure):
- 자유 시장이 자원을 효율적으로 배분하지 못하는 상황
- 정부 개입의 근거

시장 실패 유형:
① 외부효과 (Externality)
② 공공재 (Public Good)
③ 공유 자원 (Commons)
④ 독점·시장지배력
⑤ 정보비대칭 (Information Asymmetry)
```

---

## 외부효과

```
외부효과: 시장 거래와 무관한 제3자에게 미치는 영향

긍정적 외부효과 (외부경제):
- 예: 교육, 예방 접종, 과수원 + 양봉
- 사회적 편익 > 사적 편익
- 시장 균형: 과소 생산
- 정부 해결: 보조금, 의무화

부정적 외부효과 (외부불경제):
- 예: 공장 매연, 환경 오염
- 사회적 비용 > 사적 비용
- 시장 균형: 과다 생산
- 정부 해결: 세금(피구세), 규제, 배출권 거래제

코즈 정리 (Coase Theorem):
- 재산권 명확히 규정 + 거래 비용 없으면
- 당사자 간 협상으로 외부효과 내부화 가능
- 정부 개입 불필요
- 한계: 거래 비용 없는 현실 드묾
```

## 공공재

```
공공재 특성:
① 비배제성: 가격 내지 않아도 소비 배제 불가
② 비경합성: 한 사람 소비가 타인 소비 감소시키지 않음

무임승차 문제 (Free Rider):
- 공공재 비배제성 → 돈 안 내고 소비
- 사적 공급 불가 → 시장 실패
- 정부가 공급 (국방·소방·가로등)

재화 분류:
┌──────────────┬──────────────┬──────────────┐
│              │ 배제 가능    │ 배제 불가    │
├──────────────┼──────────────┼──────────────┤
│ 경합적       │ 사적재       │ 공유 자원    │
│ 비경합적     │ 클럽재       │ 공공재       │
└──────────────┴──────────────┴──────────────┘
```

## 공유 자원과 코먼즈 문제

```
공유 자원 (Common Resource):
- 비배제성 + 경합성
- 예: 공해 어업, 지하수, 공중파 방송

코먼즈의 비극 (Tragedy of the Commons):
- 공유 자원 → 개인의 과다 이용
- 사회적 최적보다 남획
- 해결: 사유화·정부 규제·커뮤니티 관리
```

## 정보비대칭

```
역선택 (Adverse Selection):
- 계약 전 정보 비대칭
- 예: 중고차 시장 (레몬 시장)
  판매자: 품질 알고 있음
  구매자: 모름 → 평균 가격 제시
  → 좋은 차 빠지고 불량차만 거래
- 해결: 신호 발송(보증), 심사·인증

도덕적 해이 (Moral Hazard):
- 계약 후 정보 비대칭·감시 어려움
- 예: 건강보험 가입 후 건강관리 소홀
- 해결: 성과 연동 보상, 공동 부담(코페이)

주인-대리인 문제:
- 주주(주인) vs 경영자(대리인)
- 대리인이 주인 이익보다 자신 이익 추구
- 해결: 스톡옵션, 감독 강화
```

## 핵심 개념 카드

**외부효과 방향** ★★★★★
: 긍정 외부효과=과소 생산(보조금), 부정 외부효과=과다 생산(세금·규제).
*암기 포인트: 긍정=보조금 증산, 부정=세금 감산*

**공공재 2요건** ★★★★★
: 비배제성+비경합성. 무임승차 → 시장 공급 불가 → 정부 공급.
*암기 포인트: 공공재=비배제+비경합*

**역선택 vs 도덕적 해이** ★★★★★
: 역선택=계약 전 숨겨진 정보. 도덕적 해이=계약 후 숨겨진 행동.
*암기 포인트: 역선택=사전, 도덕적해이=사후*

## 실전 퀴즈

**Q. 공장 매연 오염에 대해 피구세를 부과할 때 세금액은 어떻게 결정하는가?**
> 사회적 한계비용(SMC)과 사적 한계비용(PMC)의 차이(외부한계비용) = 피구세. 사회적 최적 생산량에서의 외부 비용 상당액.

**Q. 중고차 시장에서 역선택을 줄이기 위한 방법은?**
> ① 제조사·딜러의 품질 보증(warranty) ② 인증 중고차 제도 ③ 차량 이력 조회 서비스(카히스토리 등) — 정보 비대칭 해소.
