## 축구, 규칙만 알면 10배 재밌다

축구의 공식 규칙은 **국제축구평의회(IFAB)** 가 정한 '경기 규칙(Laws of the Game)' 17개 조항이다. 핵심만 알면 경기가 완전히 다르게 보인다.

---

## 기본 — 인원·시간·승부

```
인원: 한 팀 11명(골키퍼 1 포함). 최소 7명 미만이면 경기 불가.
시간: 전·후반 각 45분(총 90분) + 추가시간(injury time).
      하프타임 15분. 동점 시 리그는 무승부,
      토너먼트는 연장 전·후반 15분 → 승부차기.
승부: 공이 골라인을 완전히 넘으면 1골. 더 많이 넣으면 승리.
교체: 공식 경기 보통 5명까지(대회별 상이).
```

---

## 가장 헷갈리는 — 오프사이드

<a id="offside"></a>

오프사이드는 "골대 앞에 미리 숨어 기다리는 것"을 막는 규칙이다.

```
오프사이드 위치 조건(공을 받는 순간):
- 상대 진영에 있고,
- 공보다 앞에 있으며,
- 자신을 제외한 상대 선수 중 끝에서 2번째보다 앞에 있을 때
  (보통 마지막 수비수보다 앞)

→ 단, '위치'만으로는 반칙 아님.
  그 위치에서 플레이에 '관여'할 때 오프사이드 반칙.
```

<small>※ 자기 진영, 스로인·골킥·코너킥 상황에서는 오프사이드가 없다.</small>

---

## 반칙과 재개 방법

| 상황 | 재개 |
|------|------|
| 일반 반칙 | 상대 팀 **프리킥**(직접/간접) |
| 페널티 박스 안 수비 반칙 | **페널티킥(PK)** |
| 공이 옆선 아웃 | **스로인**(손으로 던지기) |
| 공격수가 골라인 아웃시킴 | **골킥** |
| 수비수가 골라인 아웃시킴 | **코너킥** |

---

## 경고와 퇴장 — 카드

```
옐로카드(경고): 거친 반칙·지연·항의 등. 누적 2장 = 레드.
레드카드(퇴장): 심각한 반칙·폭력·결정적 기회 고의 저지(DOGSO).
→ 퇴장당하면 교체 없이 그 팀은 한 명 적게 싸운다.
```

---

## VAR — 비디오 판독

VAR(Video Assistant Referee)는 4가지 '명백한 오심'만 재검토한다.

```
1. 득점 상황(오프사이드·반칙 여부)
2. 페널티킥 선언/취소
3. 직접 레드카드
4. 선수 착오(잘못된 선수 징계)
```

---

## 포지션 기본

```
GK(골키퍼): 페널티 박스 안에서만 손 사용 가능
DF(수비수): 실점 방어
MF(미드필더): 공격·수비 연결, 경기 조율
FW(공격수): 득점 담당
```

---

## 핵심 요약

1. 11명·90분, 공이 골라인을 완전히 넘어야 득점.
2. 오프사이드는 '위치 + 플레이 관여'가 모두 충족돼야 반칙.
3. 반칙은 프리킥/PK, 아웃은 스로인·골킥·코너킥으로 재개.
4. 옐로 2장 또는 레드 1장이면 퇴장.
5. VAR은 득점·PK·레드·선수착오 4가지만 판독한다.

> 공식 규칙은 IFAB 'Laws of the Game'을 기준으로 하며, 대회별 세부 규정은 다를 수 있다.
