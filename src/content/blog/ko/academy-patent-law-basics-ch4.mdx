## 특허권 효력

```
특허권 내용:
실시 독점권
금지청구권: 침해 금지·예방 청구
손해배상청구권

존속기간:
출원일로부터 20년
(등록일 아닌 출원일 기산)

효력 제한:
시험·연구 목적 실시
특허 전 국내 실시 (선사용권)
권리 소진: 적법 판매 제품 재판매 가능
```

---

## 특허 침해

```
직접 침해:
청구범위 모든 구성요소 포함
문언 침해 (literal infringement)

균등론 침해:
문언상 벗어나나 실질적으로 동일
교체 가능·동일 방법·실질적으로 동일한 결과

간접 침해:
특허 제품 전용 부품·원재료 제조·판매
직접 침해 가능성 제공

구제 수단:
금지청구·손해배상·폐기청구
형사고소 (7년/1억 이하)
```

## 실시권

```
전용실시권 (물권적):
독점 실시권
특허권자도 실시 불가 (약정 시)
등록 필수

통상실시권 (채권적):
비독점 실시권
여러 명에게 부여 가능
등록 아니어도 유효

법정 실시권:
법률 규정으로 당연 발생
선사용권·통상실시권허락 심판

강제 실시권:
공공 필요 시 특허청장 허락
특허 불실시 시 청구 가능
```

## 특허 무효

```
무효 사유:
신규성·진보성 흠결
명세서 기재 불비
특허 요건 미충족

무효 심판:
특허 등록 후에도 청구 가능
확정 시 소급 효력 (처음부터 없었던 것)

권리 범위 확인 심판:
실시 제품이 특허권 범위 내인지 확인
적극적 확인·소극적 확인

정정 심판:
특허 등록 후 명세서 정정 가능
청구범위 감축·오기 정정·불명료 해소
```

## 핵심 개념 카드

**특허존속=출원일20년** ★★★★★
: 등록일 아닌 출원일 기산.
*암기 포인트: 특허=출원일+20년*

**전용=독점등록, 통상=비독점** ★★★★★
: 전용실시권은 물권적·등록 필수.
*암기 포인트: 전용=독점+등록*

**특허무효=소급효** ★★★★☆
: 확정 시 처음부터 없었던 것.
*암기 포인트: 무효=소급*

## 실전 퀴즈

**Q. 균등론이 적용되는 요건은?**
> 3요소 테스트: ① 대체 가능: 교체된 구성이 동일 기능. ② 동일 방법: 같은 원리로 작동. ③ 동일 결과: 실질적으로 동일한 효과. 추가 요건: 예측 가능하고 출원 당시 알 수 있었어야. 균등론 목적: 문언만으로 회피 설계 방지, 특허권 실질적 보호.

**Q. 특허 무효 심판에서 이기면 라이선스 비용을 돌려받을 수 있는가?**
> 원칙: 무효 전 지급한 로열티 반환 불요. 무효 확정 = 소급 효력이지만 기납부 로열티는 예외. 예외: 계약에 무효 시 반환 조항 있으면 가능. 불법행위 손해배상은 별도 판단. 전략: 특허 소송에서 무효 항변은 매우 중요한 방어 수단.
