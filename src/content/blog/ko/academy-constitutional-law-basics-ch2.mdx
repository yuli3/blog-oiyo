## 기본권의 법적 성격

```
기본권의 이중적 성격:
① 주관적 공권: 개인이 국가에 대해 갖는 주관적 권리
② 객관적 법질서: 국가 전체의 법질서를 구성하는 가치 체계

기본권의 성격 분류:
- 자유권: 국가로부터의 자유 (소극적 지위)
- 청구권: 국가에 대한 급부 요구 (적극적 지위)
- 참정권: 국가 의사 형성 참여 (능동적 지위)
- 사회권: 국가에 인간다운 생활 보장 요구 (적극적 지위)
```

---

## 기본권 주체

```
자연인:
- 국민: 모든 기본권 향유
- 외국인: 일부 기본권만 (평등권·신체의 자유·종교의 자유 등)
  → 입국 자유·선거권·공무담임권 등은 원칙적 제외

태아:
- 생명권 주체 여부 논쟁
- 헌재: 태아도 헌법상 생명권 보호 대상

법인:
- 성질상 가능한 기본권 향유
- 가능: 평등권·재산권·표현의 자유·영업의 자유
- 불가: 신체의 자유·양심의 자유 (인격권적 기본권)
```

## 기본권 제한의 요건

### 헌법 제37조 제2항

```
조문:
국민의 모든 자유와 권리는 국가 안전 보장·질서 유지 또는
공공복리를 위하여 필요한 경우에 한하여 법률로써 제한할 수 있으며,
제한하는 경우에도 자유와 권리의 본질적인 내용을 침해할 수 없다.

요건:
① 목적의 정당성: 국가 안보·질서 유지·공공복리
② 법률에 의한 제한 (법률 유보)
③ 과잉 금지 원칙 준수 (비례의 원칙)
④ 본질적 내용 침해 금지
```

### 과잉 금지 원칙 (비례의 원칙)

```
1단계: 목적의 정당성
- 공익 목적의 정당성 필요

2단계: 수단의 적합성
- 목적 달성에 기여하는 수단

3단계: 피해의 최소성
- 목적 달성 수단 중 가장 기본권 침해 적은 것

4단계: 법익의 균형성
- 제한되는 사익 < 달성되는 공익

모두 충족 → 합헌 / 하나라도 위반 → 위헌
```

## 기본권 제한의 형태

```
일반적 법률 유보:
- 헌법 제37조 제2항에 의한 법률로 제한

특별 제한:
- 비상계엄 시 기본권 특별 제한 (헌법 제77조)
- 일부 기본권에만 적용

기본권 제한 불가 영역:
- 헌법에 명시적으로 기본권을 보장한 경우
- 본질적 내용 침해 금지

위헌 심사 기준:
- 자유권: 엄격한 심사 (과잉 금지 원칙)
- 사회권: 완화된 심사 (입법 재량 광범위)
```

## 기본권의 효력

### 대국가적 효력

```
기본권 원래 기능:
- 국가 권력의 침해로부터 개인 보호
- 모든 국가 기관 구속
  → 입법부·행정부·사법부 모두 기본권 기속
```

### 대사인적 효력 (제3자 효력)

```
문제: 사인(私人) 간 관계에서 기본권 적용 여부?

학설:
① 직접 효력설: 기본권 규정이 사인 간에도 직접 적용
② 간접 효력설 (다수설·판례):
   민사법의 일반 조항 (신의칙·불법행위 등)을 통해
   기본권 가치가 간접적으로 반영

판례 태도:
- 근로 기본권, 양성 평등 → 간접 적용
- 표현의 자유 vs 명예 훼손 → 이익 형량
```

## 핵심 개념 카드

**기본권 제한 4요건** ★★★★★
: 목적 정당성·법률 유보·과잉 금지·본질 침해 금지. 헌법 제37조 제2항 핵심.
*암기 포인트: 목적+법률+과잉금지+본질*

**외국인의 기본권** ★★★★★
: 인간의 권리(인간으로서 당연한 권리)는 외국인도 향유. 국민의 권리(참정권 등)는 제외.
*암기 포인트: 인간의 권리=O, 국민의 권리=X*

**간접 효력설** ★★★★☆
: 사인 간 기본권은 민사법 일반 조항으로 간접 적용. 직접 적용 아님.
*암기 포인트: 사인 간=간접효력=민사법 매개*

## 실전 퀴즈

**Q. 법인에게 인정되지 않는 기본권은?**
> 신체의 자유, 양심의 자유, 혼인·가족에 관한 권리 등 인격권적·신분적 기본권. 법인의 성질상 누릴 수 없는 것.

**Q. 기본권 제한 시 본질적 내용 침해 금지란?**
> 기본권을 제한하더라도 그 기본권이 유명무실해질 정도로 제한할 수 없음. 예: 재산권 제한이 실질적으로 재산권 자체를 부정하는 수준이면 위헌.
