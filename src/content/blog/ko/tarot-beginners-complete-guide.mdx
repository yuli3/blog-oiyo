## 타로란?

타로(Tarot)는 **78장의 카드**로 구성된 상징 체계입니다. 점술 도구이기도 하지만, 현대에는 **자기 성찰과 의사결정을 돕는 심리적 도구**로 더 많이 활용됩니다.

타로를 처음 접하는 분께: 타로는 미래를 정확히 예언하는 도구가 아닙니다. 오히려 **현재 상황을 다른 각도로 보고, 숨겨진 가능성을 탐구하는 도구**입니다.

## 타로 78장의 구조

```
타로 78장
├── 메이저 아르카나 (Major Arcana): 22장
│   └── 삶의 큰 주제, 영적 교훈
└── 마이너 아르카나 (Minor Arcana): 56장
    ├── 완드 (Wands): 14장 — 불, 열정, 창의성
    ├── 컵 (Cups): 14장 — 물, 감정, 관계
    ├── 소드 (Swords): 14장 — 바람, 사고, 갈등
    └── 펜타클 (Pentacles): 14장 — 흙, 물질, 현실
```

## 역방향(Reversed) 카드 해석

카드가 거꾸로 나오는 역방향은 정방향 의미의 **방해, 내면화, 과잉 또는 부족**을 나타냅니다.

| 카드 | 정방향 | 역방향 |
|---|---|---|
| 태양 | 기쁨, 성공 | 일시적 좌절, 흐린 날 |
| 달 | 직관, 무의식 | 혼란, 두려움 직면 필요 |
| 별 | 희망, 치유 | 희망 잃음, 회복 필요 |
| 힘 | 내면의 힘 | 자신감 부족, 회복 필요 |

## 3카드 스프레드 실전

가장 기본적인 스프레드. 세 장의 카드로 상황을 다각도로 봅니다.

### 과거-현재-미래 스프레드

```
[1번 카드] — [2번 카드] — [3번 카드]
  과 거         현 재         미 래
```

**해석 방법:**
1. 각 카드의 기본 의미 파악
2. 세 카드가 어떤 스토리를 연결하는지 보기
3. 미래 카드는 예언이 아니라 현재 흐름의 방향성

### 상황-행동-결과 스프레드

```
[1번] 현재 상황 / [2번] 취할 행동 / [3번] 예상 결과
```

**활용 예시**: 이직 고민 중일 때
- 1번: 소드 9 (불안, 걱정) → 현재 직장에 대한 걱정
- 2번: 완드 에이스 (새로운 시작) → 용기 있게 도전하라는 메시지
- 3번: 컵 9 (소원 성취) → 만족스러운 결과

## 타로 리딩 시작하는 법

### 1. 덱 선택
초보자에게 추천: **라이더-웨이트 덱(Rider-Waite Tarot)** — 가장 기본적이고 많은 책에서 다루는 덱

### 2. 카드와 친해지기
- 매일 아침 한 장씩 뽑아 그날의 에너지 확인
- 저녁에 그날이 어떻게 연결됐는지 기록

### 3. 질문 만들기
좋은 질문: "이 상황에서 내가 알아야 할 것은?"
나쁜 질문: "그 사람은 나를 사랑하는가?" (타인의 마음을 묻는 것)

### 4. 직관 따르기
카드 의미를 외우기 전에 카드의 그림에서 먼저 느낌을 받으세요. 직관이 먼저입니다.
