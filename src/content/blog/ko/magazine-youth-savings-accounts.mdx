## 청년이라면 꼭 챙겨야 할 정부 금융상품

이자율이 낮은 일반 적금과 달리, 청년 전용 금융상품은 **정부 기여금 + 비과세 혜택**이 더해져 일반 적금 대비 2~3배 이상의 실질 수익을 제공합니다.

---

## 청년도약계좌 (2023년 출시)

### 기본 개요

| 항목 | 내용 |
|------|------|
| **대상** | 만 19~34세, 개인소득 7,500만원 이하 |
| **가입 기간** | 5년 (60개월) |
| **월 납입** | 최대 70만원 |
| **정부 기여금** | 소득에 따라 월 최대 24,000원 |
| **이자** | 가입 3년은 고정금리, 이후 변동금리 |
| **비과세** | 이자소득세 면제 |

### 정부 기여금 지급 기준

| 개인소득 | 기여금 매칭 비율 | 월 최대 기여금 |
|---------|-------------|------------|
| **2,400만원 이하** | 납입액의 6% | 24,000원 |
| **3,600만원 이하** | 납입액의 4.6% | 23,000원 |
| **4,800만원 이하** | 납입액의 3.7% | 22,000원 |
| **6,000만원 이하** | 납입액의 3.0% | 21,000원 |
| **7,500만원 이하** | 기여금 없음 | 0원 |

> **소득 2,400만원 이하**: 월 40만원 납입 시 기여금 24,000원 → 사실상 6% 추가 수익.

### 실제 수익 시뮬레이션

```
[ 소득 2,400만원 이하, 월 40만원 납입, 5년 기준 ]

본인 납입 원금: 40만원 × 60개월 = 2,400만원
정부 기여금:   24,000원 × 60개월 = 144만원
이자 (연 6%):  약 380만원 (복리 가정)
비과세 효과:   이자세 약 76,000원 절약

→ 만기 수령: 약 2,938만원
→ 총 수익: 538만원 (수익률 22.4%)
```

### 청년도약계좌 가입 조건 상세

**나이 조건:**
```
만 19~34세 (병역 이행자 최대 6년 추가 인정)
→ 군 2년 복무 시: 만 36세까지 가입 가능
```

**소득 조건:**
```
개인소득: 연 7,500만원 이하 (총급여 or 종합소득)
가구소득: 중위소득 250% 이하 (4인 기준 약 1,397만원/월)
→ 둘 다 충족해야 가입 가능
```

**기타 조건:**
```
직전 3개년 금융소득 종합과세 대상자 제외
비과세 종합저축 가입자 중 일부 중복 제한
```

### 가입 방법

```
1. 매월 가입 신청 기간 확인 (보통 월 초~중순)
2. 은행 앱 (국민·신한·하나·우리·농협·기업·부산은행 등)
3. 소득 확인: 건강보험 납부 확인 or 소득확인증명서 제출
4. 승인 후 자동이체 설정
```

## 청년희망적금 (2022년 출시, 만기 완료)

2022년 출시된 청년희망적금은 2024년 대부분 만기 도래. 만기자는 **청년도약계좌로 연계 전환** 가능.

### 만기 후 청년도약계좌 연계 전략

```
청년희망적금 만기 수령 → 청년도약계좌 일시납 허용

혜택:
- 만기 수령액 전액 청년도약계좌 납입 가능 (최대 200만원 일시납)
- 일시납 금액에 비례해 정부 기여금 지급
→ 이어서 복리 효과 극대화
```

## 청년 전용 금융상품 한눈에 비교

| 상품 | 대상 | 월 한도 | 혜택 | 기간 |
|------|------|--------|------|------|
| **청년도약계좌** | 19~34세 | 70만원 | 기여금+비과세 | 5년 |
| **청년형 ISA** | 19~34세 | 제한없음 | 비과세 400만원 | 3년 이상 |
| **청년내일저축계좌** | 저소득층 | 10만원 | 정부 3배 매칭 | 3년 |
| **청년우대형 주택청약** | 19~34세 | 50만원 | 이자 우대+비과세 | 무기한 |

### 청년 ISA (개인종합자산관리계좌)

```
일반 ISA 비과세 한도: 200만원
청년형 ISA (만 15~29세): 비과세 한도 400만원

활용법: 청년도약계좌 외 여유 자금을 청년 ISA에 넣어
주식·ETF·채권 투자 → 수익 400만원까지 비과세
```

### 청년 우대형 주택청약종합저축

```
일반 청약통장 금리: 연 2.0~2.8%
청년 우대형: 연 4.0~5.0% (최초 2년, 무주택 조건)
비과세: 이자 500만원까지 비과세

가입 조건:
- 만 19~34세
- 무주택 세대주 (또는 세대원)
- 소득: 직전연도 3,600만원 이하
```

## 청년도약계좌 중도 해지 시 주의사항

```
3년 미만 해지: 정부 기여금 전액 반환 + 비과세 혜택 소급 취소
3년 이후 해지: 기여금 비율적 반환 + 비과세 일부 유지

예외 허용 (기여금 유지):
- 가입자 사망, 해외 이주
- 천재지변
- 장기 입원
- 폐업·실직 (3개월 이상)
```

## 이런 분에게 청년도약계좌 강력 추천

- 사회초년생으로 목돈 만들고 싶은 경우
- 청약통장 외 여유 자금이 있는 경우
- 저소득(2,400만원 이하)으로 정부 기여금이 큰 경우
- 5년간 안정적으로 저축할 수 있는 경우

## 청년도약계좌가 맞지 않는 경우

- 5년 내 목돈이 필요한 경우 (중도 해지 시 불이익)
- 이미 고수익 투자를 적극적으로 하는 경우 (ISA + 투자가 더 유리할 수 있음)
- 소득 7,500만원 초과로 정부 기여금 없는 경우 (비과세 효과만 고려)
