## 집합건물

```
집합건물:
1동의 건물 내 구분된 여러 부분이 각각 소유권 대상
예: 아파트, 오피스텔, 상가

집합건물법 (집합건물의 소유 및 관리에 관한 법률):
구분소유자의 권리·의무 규정

구분소유권:
각 전유 부분에 대한 소유권

전유 부분:
구분소유자가 단독 소유·이용하는 부분
예: 아파트 각 호실 내부

공용 부분:
전유 부분 외 공동 사용 부분
복도, 계단, 엘리베이터, 외벽
→ 구분소유자 전원 공유 (지분 비율)
```

---

## 집합건물 등기부 구조

```
1동 건물 표제부:
건물 소재, 구조, 면적

전유 부분 표제부:
각 호실 면적, 층, 호수

갑구:
각 호실 소유권 (누가 몇 호 소유)

을구:
각 호실 저당권·전세권 등

대지권:
전유 부분 소유자가 대지를 이용하는 권리
토지 등기부에도 대지권 표시
→ 전유 부분 처분 시 대지권도 함께 처분
```

---

## 대지권

```
대지권:
집합건물 전유 부분 소유자의 토지 이용권
소유권 대지권: 토지 소유권 비율
전세권 대지권: 토지 전세권

대지권 등기:
1동 건물 표제부에 대지권 비율 표시
토지 등기부에도 대지권 등재

대지권과 전유 부분:
분리 처분 금지 (원칙)
→ 아파트 사면 토지 지분도 자동 취득

미등기 대지권:
토지 소유자와 건물 소유자 다른 경우 문제 발생
법정지상권 또는 대지권 미등기 상태
```

## 구분소유자 관계

```
관리단:
구분소유자 전원이 당연 구성원
→ 건물 관리를 위한 법인격 없는 단체

관리인:
관리단을 대표하는 자
구분소유자 중 선임 (또는 외부 전문 관리인)

규약:
구분소유자 집회 결의로 제정
건물 사용·관리에 관한 규칙

집회:
구분소유자 전원 참여 가능
의결: 의결권 과반수 (일반 사항)
특별 결의: 구분소유자 3/4 이상
```

## 핵심 개념 카드

**전유 부분 vs 공용 부분** ★★★★★
: 전유=단독소유(각 호실). 공용=공동소유(복도·계단·엘리베이터).
*암기 포인트: 전유=단독, 공용=공동*

**대지권=전유부분과 함께 처분** ★★★★★
: 대지권은 분리 처분 금지. 전유 부분 처분 시 자동 이전.
*암기 포인트: 대지권=전유부분 일체*

**집합건물 특별결의=3/4** ★★★★☆
: 구분소유자 3/4 이상 동의로 특별결의.
*암기 포인트: 집합건물 특별=3/4*

## 실전 퀴즈

**Q. 아파트를 매수할 때 토지 지분을 별도로 계약하지 않아도 되는 이유는?**
> 집합건물에서 전유 부분과 대지권은 일체로 취급. 전유 부분(아파트 호실)을 취득하면 대지권(토지 지분)도 자동 이전. 대지권은 전유 부분에서 분리 처분 금지.

**Q. 공용 부분을 1인 구분소유자가 단독으로 변경하지 못하는 이유는?**
> 공용 부분은 구분소유자 전원 공유 재산. 1인이 단독으로 구조 변경·용도 변경 불가. 집회 결의를 거쳐야 함. 공용 부분 분리 양도도 금지.
