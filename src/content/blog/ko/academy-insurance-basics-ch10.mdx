## 보험 기본 원리 종합

```
위험관리 4방법:
회피·감소·보유·전가 (회감보전)
보험 = 위험 전가 수단

보험 성립 원칙:
대수의 법칙: 다수 관찰 → 손실 예측 가능
수지상등: 보험료 총액 = 보험금 총액
급부반대급부: 보험료 = 위험도 비례

보험계약 특성:
최대선의계약: 상호 신뢰
쌍무·부합·사행계약

고지의무:
계약 전 중요 사항 고지 (위반 시 해지·지급거절)
인과관계 없으면 지급 의무 있음
```

## 보험 종류 핵심 비교

```
생명보험:
정액 지급, 실손원칙 미적용
중복 가입 시 각 전액 지급
종신(평생)·정기(기간)·연금(노후)

손해보험:
실손보상원칙 적용
중복 가입 시 실손 이내 분담
화재·자동차·해상·책임

제3보험:
상해·건강·간병 (제3보험=상건간)
상해 = 외래·급격·우연 3요소
```

## 사회보험·규제 핵심

```
4대 사회보험 (건연산고):
건강·연금·산재·고용
강제 가입, 소득 재분배

산재보험:
사용자 100% 부담 (근로자 부담 없음)

고용보험 실업급여:
피보험 단위기간 180일 이상

청약 철회:
15일 (통신판매 30일)

리베이트:
특별 이익 제공 금지
```

## 역선택·도덕적 해이·재보험

```
역선택:
계약 전, 고위험자 집중 가입
대응: 언더라이팅·차등 보험료

도덕적 해이:
계약 후, 위험 예방 노력 감소
대응: 자기부담금·공동보험

재보험:
보험사가 재보험사에 위험 전가
비례(비율 분담) vs 비비례(초과분 분담)

RBC 지급여력비율:
보험사 건전성 = 100% 이상 유지
```

## 핵심 개념 카드

**보험4원칙=대수수지급부** ★★★★★
: 대수의법칙·수지상등·급부반대급부.
*암기 포인트: 대수+수지+급부*

**생명=정액·손해=실손** ★★★★★
: 중복보험 처리 차이의 근본.
*암기 포인트: 생=정액, 손=실손*

**4대사회보험=건연산고·산재사용자100%** ★★★★★
: 부담 주체 완전 암기.
*암기 포인트: 산재=사용자전액*

## 실전 퀴즈

**Q. 보험학에서 가장 자주 출제되는 3가지 원칙을 설명하라.**
> ① 실손보상원칙: 손해보험의 기본. 실제 손해 이내 보상. 이중이득 방지. ② 최대선의원칙: 계약 양당사자 완전 고지 의무. 고지의무 위반 효과. ③ 대수의 법칙: 보험료 산정 기초. 다수 계약으로 손실 예측 가능. 이 3원칙이 충돌하는 문제가 자주 출제.

**Q. 보험 포트폴리오를 설계할 때 고려해야 할 우선순위는?**
> 1순위: 사회보험 최대 활용 (건연산고 강제 가입). 2순위: 실손의료보험 (의료비 리스크 커버). 3순위: 생명보험 (소득 대체 필요 시). 종신 vs 정기: 부채·가족 부양 기간은 정기. 4순위: 자동차보험 의무 가입 + 대인II 무한. 기타: 암·상해·치아는 필요에 따라. 원칙: 큰 위험부터 작은 위험 순으로 우선 가입.
