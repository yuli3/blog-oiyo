```

행정기관이 공무상 작성하거나 접수하는 문서

작성 원칙:
간결·명확하게 작성
표준어·한글 원칙
아라비아 숫자 사용
날짜: 연월일 표기

문서 구성:
두문: 수신처·참조
본문: 제목·내용
결문: 발신 기관명·날짜·서명
```

```
청구서 필수 기재사항:
청구인: 성명·주소
피청구인: 행정청명
심판 대상: 처분 특정
청구 취지: 무엇을 구하는가
청구 이유: 처분이 왜 위법·부당한가

첨부서류:
처분서 사본

제출처:
처분 행정청 또는 행정심판위원회

청구 기간:
처분 안 날 90일·처분일 180일 이내
```

## 실전 퀴즈

**Q. 행정심판 청구서에 청구 취지와 청구 이유를 구별하는 기준은?**
> 청구 취지: 인용 시 원하는 결론 (예: "○○처분을 취소한다"). 청구 이유: 처분이 위법·부당한 구체적 근거. 취지는 간결히, 이유는 법적 근거와 사실관계 상세히. 법원 소장의 청구취지·청구원인과 유사.

**Q. 민원 서류에 근거 법령을 반드시 명시해야 하는 이유는?**
> 행정청은 법률에 근거해서만 행위. 신청서에 근거 법령 없으면 수리 거부 가능. 정확한 조항 명시해야 심사 가능. 행정사는 의뢰인 대신 정확한 법령 파악이 핵심 업무.
