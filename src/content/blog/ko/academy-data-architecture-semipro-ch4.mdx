## 표준화는 같은 말을 쓰는 일입니다

데이터 표준화는 조직 안에서 같은 의미의 데이터를 같은 이름과 형식으로 관리하도록 정하는 활동입니다. “고객번호”, “회원ID”, “사용자코드”가 같은 의미인지 다른 의미인지 정리하지 않으면 통합과 분석 단계에서 혼란이 커집니다. DAsP에서는 표준 용어, 도메인, 코드, 명명 규칙을 함께 봐야 합니다.

### 표준화 요소

| 요소 | 역할 |
|---|---|
| 표준 용어 | 업무에서 쓰는 명칭과 정의 통일 |
| 단어 사전 | 용어를 구성하는 기본 단어 관리 |
| 도메인 | 값의 형식, 길이, 허용 범위 관리 |
| 코드 | 분류 값과 의미를 통일 |
| 명명 규칙 | 테이블과 컬럼 이름의 일관성 확보 |

도메인은 단순한 데이터 타입이 아닙니다. 예를 들어 금액, 날짜, 전화번호, 상태코드는 각각 허용 값과 표현 방식이 다릅니다. 도메인을 정하면 새 컬럼을 만들 때도 같은 기준을 적용할 수 있습니다.

## 표준화의 효과

표준화가 잘 되면 모델 검토가 쉬워지고, 데이터 품질 문제가 줄어들며, 시스템 간 연계도 안정됩니다. 반대로 표준이 없으면 같은 고객을 여러 방식으로 저장하고, 코드값의 의미가 부서마다 달라질 수 있습니다. 시험에서는 표준화 절차와 산출물, 표준 준수 관리의 목적을 연결해서 이해하세요.

## 핵심 요약

- 데이터 표준화는 용어와 형식을 조직 전체에서 일관되게 만드는 활동입니다.
- 표준 용어, 단어 사전, 도메인, 코드, 명명 규칙을 구분해야 합니다.
- 표준화는 모델링과 데이터 품질 관리의 기초가 됩니다.
