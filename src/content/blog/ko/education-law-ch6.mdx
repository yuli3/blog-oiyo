## 채권이란 무엇인가

**채권(債權)**은 특정인(채권자)이 다른 특정인(채무자)에게 일정한 행위(급부)를 청구할 수 있는 권리입니다.

```
채권 관계 기본 구조:

채권자 ──────────────► 채무자
(청구권)           (이행의무)

급부의 종류:
- 물건 인도 (매매, 임대차)
- 금전 지급 (대여, 손해배상)
- 행위 (노무 제공, 건물 건축)
- 부작위 (경쟁 금지, 소음 방지)
```

## 채권의 발생 원인

### 1. 계약

가장 중요한 채권 발생 원인. 청약 + 승낙으로 성립.

**계약의 종류:**

| 유형 | 설명 | 예시 |
|------|------|------|
| 쌍무계약 | 쌍방 대가적 채무 | 매매, 임대차, 고용 |
| 편무계약 | 일방만 채무 | 증여, 사용대차 |
| 유상계약 | 대가 있음 | 매매, 임대차 |
| 무상계약 | 대가 없음 | 증여, 무상임치 |

### 2. 불법행위

고의·과실로 타인에게 손해를 가한 경우 손해배상 채무 발생.

```
불법행위 요건 (민법 제750조):
1. 고의 또는 과실
2. 가해행위의 위법성
3. 손해 발생
4. 인과관계

손해배상 범위:
- 재산적 손해: 적극적 손해(지출) + 소극적 손해(일실이익)
- 정신적 손해: 위자료
```

**특수 불법행위:**
- **사용자책임**: 사용자는 피용자의 불법행위에 대해 책임
- **공작물책임**: 토지 공작물 점유자·소유자 책임
- **동물점유자 책임**: 동물이 타인 손해 가하면 점유자 책임

### 3. 부당이득

법률상 원인 없이 타인 손해로 이익 얻은 경우 반환 의무.

```
부당이득 요건:
1. 이득 발생
2. 손해 발생
3. 이득·손해 간 인과관계
4. 법률상 원인 없음

반환 범위: 이익이 현존하는 한도
악의 수익자: 이자 붙여서 반환 + 손해 있으면 배상
```

## 채무불이행

### 유형

```
이행지체: 이행 가능하나 정당한 이유 없이 제때 이행 않음
이행불능: 채무의 이행이 불가능해진 경우
불완전이행: 이행하기는 했으나 불완전 (하자있는 이행)
```

### 채무불이행의 효과

**1. 손해배상 청구**

```
배상 원칙: 통상손해 (예견 가능 손해)
특별손해: 채무자가 알았거나 알 수 있었을 때만
```

**2. 계약 해제**

- 이행지체: 상당한 기간 정하여 최고 후 해제 가능
- 이행불능: 최고 없이 즉시 해제 가능
- 해제 효과: 원상회복 의무 (이미 이행한 것 돌려줘야)

**3. 강제이행**

법원을 통해 강제로 이행하게 하는 방법 (직접강제, 대체집행, 간접강제).

---

## 계약의 해제 vs 해지

```
해제 (解除): 소급효 있음 — 처음부터 없었던 것처럼
→ 대상: 1회성 계약 (매매, 도급 등)
→ 효과: 원상회복 + 손해배상

해지 (解止): 소급효 없음 — 장래에 대해서만 효력 소멸
→ 대상: 계속적 계약 (임대차, 고용, 위임 등)
→ 효과: 장래 채무 소멸 + 경우에 따라 손해배상
```

## 채권의 소멸

### 변제

채무자가 채무 내용에 따라 이행하여 채권 소멸. 가장 정상적인 소멸 방법.

```
변제 충당 순서:
1. 당사자 합의
2. 변제자 지정
3. 비용 먼저 → 이자 → 원금 순
```

### 상계

쌍방이 서로 동종 채권 보유 시 대등액에서 소멸시키는 의사표시.

```
상계 요건:
1. 동종 채권 (보통 금전)
2. 상계적상: 양쪽 채권 모두 변제기 도래
3. 상계금지 아닐 것

상계금지 사유: 불법행위 채권(고의), 금지 약정, 압류 후 취득
```

### 시효 소멸

채권은 행사하지 않으면 소멸시효로 소멸.

```
소멸시효 기간:
일반 채권: 10년
상사 채권: 5년
단기소멸시효 (3년): 의사·약사 진료비, 숙박·음식점 채권
단기소멸시효 (1년): 여관·음식점 숙박료, 음료 대금
```

## 보증채무

타인(주채무자)의 채무를 이행할 것을 약속하는 보증인의 채무.

```
보증의 특성:
부종성: 주채무 소멸 → 보증채무 소멸
보충성: 보증인은 주채무자에 대한 최고·검색 항변권 가짐

연대보증: 보충성 없음, 보증인에게 바로 청구 가능
→ 보증보험·은행 대출 보증 대부분 연대보증
```

## 실전 응용: 계약 위반 대응법

**상황**: 중고차를 250만 원에 구매했는데, 인도받고 보니 주행거리가 허위 기재되어 있었습니다.

```
법적 대응:

1단계: 하자 확인 (불완전이행)
   → 불완전이행으로 인한 채무불이행

2단계: 선택지
   ① 완전이행 청구 (차량 교환)
   ② 손해배상 청구 (가격 차액)
   ③ 계약 해제 + 원상회복 (대금 반환)

3단계: 담보책임 (민법 제580조 매도인 하자담보책임)
   → 하자 안 날로부터 6개월 내 해제 또는 손해배상 청구
   → 허위 고지는 사기에 해당할 수 있음 (형사 + 민사)
```

## 핵심 암기 포인트

*채권 발생 3원인: 계약·불법행위·부당이득*
*채무불이행 3유형: 이행지체·이행불능·불완전이행*
*해제(소급효) vs 해지(장래효) — 1회성 vs 계속적 계약*
*소멸시효: 일반 10년, 상사 5년, 단기 1~3년*
