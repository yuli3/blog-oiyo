## 조직·인사·예산 핵심 비교

```
조직:
관료제 역기능=목동할무비 (목표전치·동조과잉·할거주의·무사안일·비밀주의)
통솔 범위↑=계층↓(수평). 집권=통일, 분권=자율.

인사:
엽관=정치보은. 실적=시험·능력.
직위분류=직무중심. 계급=사람중심.
징계: 파해강정감견 (무거운→가벼운)

예산:
편심집결 (편성→심의→집행→결산)
ZBB=제로베이스. 품목별=통제중심.
국고보조금=조건부. 지방교부세=무조건.
```

## 정책 결정 모형 비교

```
합리 모형: 완전정보+최적해 → 비현실적
만족 모형: 제한된 합리성+만족 수준 선택
점증 모형: 현재+소폭 수정 → 보수적·안정적
혼합주사: 합리(중요)+점증(세부) 혼합
쓰레기통: 우연한 결합 → 혼란스러운 조직

핵심 비교:
현실적 모형: 만족 모형, 점증 모형
규범적(이상적) 모형: 합리 모형
복잡·무질서 조직: 쓰레기통
```

## 자주 틀리는 오답 포인트

```
① 능률성 vs 효과성
   → 능률=투입/산출 비율. 효과=목표 달성.
   → 둘 다 높기 어려운 긴장 관계

② 단체자치 vs 주민자치
   → 단체자치=법적 독립(대륙). 주민자치=직접 참여(영미).
   → 한국=혼합형

③ 옴부즈만=강제력 없음
   → 권고만 가능. 도덕적 권위로 실질 효과.

④ 직위분류제=직무, 계급제=사람
   → 직위분류: 동일직무=동일보수. 전문가.
   → 계급제: 신분 보장+순환 보직. 일반가.

⑤ ZBB vs 점증 예산
   → ZBB=전년 무시+모두 재정당화. 시간·비용 과다.
   → 점증=전년 기반. 현실적.

⑥ 국고보조금 vs 지방교부세
   → 보조금=특정목적+조건. 교부세=재정균형+무조건.

⑦ 정책의 상향식 vs 하향식 집행
   → 하향=중앙 지시 준수. 상향=일선 재량 강조.
   → 일선 관료제=상향식 접근

⑧ 포지티브 규제 = 원칙 금지
   → 허용 목록에 있는 것만 가능. 혁신 저해 가능.
   → 네거티브 = 원칙 허용, 금지만 열거.

⑨ 예산 편성 기한
   → 회계연도 90일 전 = 9월 3일 국회 제출
   → 12월 2일까지 국회 의결

⑩ 합명회사 무한책임 vs 주식회사 유한책임
   → 행정학 아닌 상법 개념
   → 행정학에서 공공기관=정부 투자·출연·위탁 구분
```

## 핵심 개념 카드

**행정 이념 긴장 관계** ★★★★★
: 능률성↑→형평성↓ 가능. 합법성↑→능률성↓ 가능. 이념 간 트레이드오프.
*암기 포인트: 이념=상충 가능*

**예산 과정** ★★★★★
: 편성(행정부)→심의(국회)→집행→결산(감사원+국회).
*암기 포인트: 행정부편성, 국회심의*

**점증 모형의 의미** ★★★★★
: 완전한 합리적 탐색 불가 → 현실에서 전년 기반 소폭 변화. 정치적 합의 용이.
*암기 포인트: 점증=현실타협*

## 실전 퀴즈 (종합)

**Q. 행정 이념들이 서로 충돌하는 예를 들어보시오.**
> 능률성 vs 민주성: 신속 결정(능률)을 위해 주민 참여(민주) 생략. 합법성 vs 효과성: 법 절차 준수(합법)로 긴급 대응(효과) 지연. 형평성 vs 능률성: 취약계층 지원(형평) 비용 증가(능률 감소).

**Q. 한국 행정이 신공공관리론 도입 후 나타난 문제는?**
> 성과 측정 가능한 업무 집중, 측정 어려운 공공서비스 소홀. 민간 위탁 확대로 공공성·책임 약화. 성과급 경쟁으로 협력 저하, 공직 안정성 우려. 시민을 고객으로만 취급해 민주적 주인의식 경시.
