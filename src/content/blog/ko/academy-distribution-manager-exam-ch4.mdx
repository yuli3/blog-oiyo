## POS 시스템 (Point of Sale)

```
POS (판매시점 정보관리 시스템):
→ 판매 시점에 상품 정보와 판매 데이터를 실시간 수집

POS의 기능:
→ 판매 데이터 수집 (상품별, 시간대별, 점포별)
→ 재고 자동 관리 (판매 시 자동 차감)
→ 고객 구매 행동 분석
→ 단품 관리 (SKU: 개별 상품 단위 관리)

POS에서 수집되는 데이터:
→ 판매 시간, 상품 코드, 수량, 가격
→ 결제 수단, 점원 ID, 계산대 번호

POS 데이터 활용:
→ 인기 상품 파악 → 재주문 최적화
→ 시간대별 수요 패턴 → 직원 스케줄링
→ 시즌별 판매 추이 → 구매 전략
→ 장바구니 분석 (Market Basket Analysis)
```

## SCM (공급망 관리)

```
SCM (Supply Chain Management):
→ 원자재 조달부터 최종 소비자까지
  공급망 전체를 통합·최적화하는 경영 기법

공급망 구성:
공급업체 → 제조업체 → 물류센터 → 소매점 → 소비자

SCM의 목표:
→ 재고 최소화 (재고 비용 절감)
→ 리드타임 단축 (빠른 공급)
→ 비용 절감
→ 서비스 수준 향상

채찍 효과 (Bullwhip Effect):
→ 소비자 수요 변동이 공급망 상위로 갈수록 증폭되는 현상
→ 소매상의 작은 수요 변화 → 제조업체의 과잉 생산
→ 정보 공유(VMI, CPFR)로 완화 가능

VMI (Vendor Managed Inventory):
→ 공급업체가 직접 소매업체 재고 관리
→ 실시간 재고 정보 공유 → 채찍 효과 감소

CPFR (Collaborative Planning, Forecasting, Replenishment):
→ 제조업체·소매업체 공동 수요 예측 및 보충
```

## CRM (고객 관계 관리)

```
CRM (Customer Relationship Management):
→ 고객 정보를 수집·분석하여 개인화된 관계 유지

CRM의 목적:
→ 고객 유지율 향상 (이탈 방지)
→ 고객 생애 가치 (CLV: Customer Lifetime Value) 극대화
→ 맞춤 마케팅

고객 세분화:
→ RFM 분석:
  R (Recency): 최근 구매일 (얼마 전에 샀나)
  F (Frequency): 구매 빈도 (얼마나 자주 샀나)
  M (Monetary): 구매 금액 (얼마나 많이 샀나)

고객 등급 관리:
VIP 고객 → 골드 → 일반 → 이탈 위험 고객
→ 등급별 차별화된 서비스·혜택 제공

CRM 데이터 활용:
→ 크로스 셀링: 연관 상품 추천 ("이것도 함께")
→ 업셀링: 고급 상품 권유 ("이 상품은 어떨까요?")
→ 개인화 프로모션: 구매 이력 기반 쿠폰
```

## 전자상거래 (e-Commerce)

```
전자상거래의 유형:

B2C (Business-to-Consumer):
→ 기업이 일반 소비자에게 직접 판매
→ 쿠팡, 네이버 쇼핑, 11번가

B2B (Business-to-Business):
→ 기업 간 거래 (제조업체-도매업체 등)
→ 대규모 거래, 장기 계약

C2C (Consumer-to-Consumer):
→ 소비자 간 거래 (개인 판매)
→ 중고나라, 당근마켓, 번개장터

B2G (Business-to-Government):
→ 기업이 정부에 납품 (나라장터)

전자상거래 성공 요소:
→ 사용자 경험 (UX): 쉽고 편리한 쇼핑 프로세스
→ 신뢰: 안전한 결제, 반품 정책
→ 물류 경쟁력: 빠른 배송 (새벽배송, 당일배송)
→ 가격 경쟁력: 비교 쇼핑 환경에서 가격 우위
```

## EDI와 유통 표준

```
EDI (Electronic Data Interchange):
→ 기업 간 표준 형식으로 전자 문서 교환
→ 주문서, 인보이스, 납품 확인서 등
→ 종이 서류 없이 자동 처리

EDI 장점:
→ 처리 속도 향상 (수일 → 즉시)
→ 오류 감소 (수작업 입력 배제)
→ 비용 절감 (인건비, 종이)

바코드 표준:
→ EAN-13: 13자리, 전 세계 소비재
→ EAN-8: 소형 포장용
→ QR 코드: 2차원 바코드, 더 많은 정보 저장

GS1 표준:
→ 전 세계 유통 표준 기구
→ 바코드, GTIN (글로벌 상품 번호) 표준 관리

RFID:
→ 전파로 태그 정보 비접촉 읽기
→ 동시 다수 인식, 이동 중 인식 가능
→ 고비용으로 고가 상품, 물류 팔레트에 주로 사용
```

## 빅데이터와 유통

```
빅데이터의 3V (라메쉬):
Volume (크기): 방대한 데이터 양
Velocity (속도): 실시간 생성·처리
Variety (다양성): 정형·비정형 데이터

유통 빅데이터 활용:

1. 수요 예측:
→ 구매 이력 + 날씨 + 이벤트 데이터 → 상품별 수요 예측
→ 적정 재고 유지

2. 가격 최적화 (Dynamic Pricing):
→ 실시간 수요·경쟁가에 따라 가격 조정
→ 쿠팡, 항공권 등에서 활발히 적용

3. 개인화 추천:
→ 협업 필터링: "이 상품을 산 사람들은 이것도 샀습니다"
→ 콘텐츠 기반 필터링: 상품 특성 기반 추천

4. 재고 최적화:
→ 지역·시기별 수요 패턴 분석
→ 점포별 맞춤 상품 구성

옴니채널 전략:
→ 온라인·오프라인·모바일 채널 통합
→ 어느 채널에서든 일관된 고객 경험
→ 예: 온라인 주문 → 매장 픽업 (Click & Collect)
```

## 자주 묻는 질문

**Q. POS와 ERP의 차이는 무엇인가요?**
A. POS는 판매 현장에서 거래 데이터를 수집하는 시스템이고, ERP는 기업 전체(회계, 재고, 인사, 구매)를 통합 관리하는 시스템입니다. POS 데이터가 ERP와 연계되어 재고, 회계에 자동 반영됩니다.

**Q. 전자상거래에서 물류의 중요성은 왜 커졌나요?**
A. 쿠팡의 로켓배송, 새벽배송 서비스 성공에서 알 수 있듯이, 빠른 배송은 전자상거래의 핵심 경쟁력이 되었습니다. 상품은 비슷해도 배송 속도와 편의성이 쇼핑몰 선택의 결정적 요인이 되었기 때문에 라스트마일 물류에 대한 투자가 크게 증가했습니다.
