## 보안은 정상 흐름을 알아야 보입니다

네트워크 보안은 공격 이름을 외우는 과목처럼 보이지만, 실제로는 정상 통신 흐름을 이해해야 풀립니다. 누가 접속했고, 어떤 포트로, 어떤 장비를 지나, 어떤 권한으로 접근했는지를 알면 이상 트래픽과 설정 오류를 구분할 수 있습니다.

### 보안 기본 요소

| 요소 | 의미 |
|---|---|
| 인증 | 사용자가 누구인지 확인 |
| 인가 | 어떤 자원에 접근할 수 있는지 결정 |
| 암호화 | 데이터 내용을 제3자가 읽기 어렵게 보호 |
| 무결성 | 전송 중 변조 여부 확인 |
| 감사 | 로그를 남겨 추적 가능하게 함 |

대표 공격은 ARP 스푸핑, DoS/DDoS, 포트 스캔, 스니핑, 악성코드 감염처럼 분류해 두면 좋습니다. 대응도 방화벽 정책, 접근통제, 패치, 백신, 로그 분석, 네트워크 분리처럼 묶어서 기억하세요.

보안 문제는 원인과 대응을 짝으로 적어 두면 보기에서 비슷한 용어가 나와도 덜 흔들립니다.

## 장비 설정과 연결하기

보안 문제는 실기 설정과도 연결됩니다. 불필요한 포트를 막고, 관리자 계정을 보호하고, 원격 접속을 제한하는 일은 모두 기본 보안 조치입니다. 시험 세부 기준과 시행 정보는 바뀔 수 있으므로 시행처 공식 홈페이지와 해당 시 Q-net(https://www.q-net.or.kr)을 확인하세요. 확인일: 2026-06.

## 핵심 요약

네트워크 보안은 인증, 인가, 암호화, 무결성, 감사의 기본 틀로 정리하세요. 공격 이름보다 흐름과 대응 조치를 연결하는 것이 중요합니다. 다음 장에서는 실기 케이블과 라우터 명령을 다룹니다.
