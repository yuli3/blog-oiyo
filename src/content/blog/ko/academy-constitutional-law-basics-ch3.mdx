## 자유권 개요

**자유권**: 국가 권력의 간섭·침해 없이 개인의 자유로운 영역을 보장받는 권리.

```
자유권 분류:
① 인신의 자유: 신체의 자유
② 사생활의 자유: 주거·통신·사생활
③ 정신적 자유: 양심·종교·표현·학문·예술
④ 경제적 자유: 직업 선택·재산권·소비자 보호
```

## 신체의 자유

### 실체적 보장

```
죄형법정주의 (헌법 제12조, 제13조):
- 법률 없으면 범죄 없고, 형벌 없음
- 소급 처벌 금지: 행위 당시 법률로만 처벌
- 연좌제 금지: 자신의 행위만 책임
- 이중처벌 금지 (일사부재리)
```

### 절차적 보장

```
적법 절차의 원칙 (헌법 제12조 제1항):
- 법률에 의하지 않으면 체포·구속·압수·수색·심문·처벌 불가
- 적법한 절차에 의해야 함

영장 주의 (헌법 제12조 제3항):
- 체포·구속·압수·수색: 법관이 발부한 영장 필요
- 현행범: 영장 없이 체포 가능
- 긴급 체포: 48시간 이내 영장 청구

불법 체포·구속 구제:
- 구속 적부 심사제 (헌법 제12조 제6항)
- 인신 보호 영장 (habeas corpus 유사)
```

### 형사 피의자·피고인의 권리

```
묵비권 (진술 거부권):
- 불리한 진술 강요 불가

고문 금지:
- 어떤 상황에서도 고문 금지

변호인의 조력을 받을 권리:
- 국선 변호인 제도

무죄 추정의 원칙:
- 유죄 확정 전 무죄로 추정
```

## 사생활의 자유

```
주거의 자유 (헌법 제16조):
- 주거 침입·수색 금지 (영장 필요)

통신의 자유 (헌법 제18조):
- 통신 비밀 침해 금지
- 통신 비밀 보호법으로 구체화

사생활의 비밀과 자유 (헌법 제17조):
- 개인 정보 자기 결정권
- 사생활 침해·공개 금지
```

## 정신적 자유

```
양심의 자유 (헌법 제19조):
- 내심의 자유: 양심 형성·유지의 자유 → 절대적 보장
- 양심 실현의 자유: 제한 가능

종교의 자유 (헌법 제20조):
- 신앙의 자유·종교 행사의 자유
- 국교 부인, 정교 분리

표현의 자유 (헌법 제21조):
- 언론·출판의 자유
- 집회·결사의 자유
- 사전 검열 금지 (절대적 금지)
- 언론·출판의 책임: 타인 명예·권리 침해 시 손해배상

사전 검열 금지의 의미:
- 행정 기관에 의한 사전 허가제 방식의 검열 금지
- 영화등급위원회·방송위원회 등: 사전 심의 → 검열 아님 (헌재)
```

## 재산권

```
재산권 보장 (헌법 제23조):
① 모든 국민의 재산권은 보장됨
② 재산권의 내용과 한계는 법률로 정함
③ 재산권의 행사는 공공복리에 적합하게

재산권 제한:
- 공공 수용·사용·제한: 정당한 보상 지급
- 보상 기준: 시장 가치 = 완전 보상 원칙

공용 수용 요건:
① 공공 필요성
② 법률에 근거
③ 정당한 보상

사회적 구속성 vs 수용:
- 재산권의 사회적 구속: 보상 불요 (내재적 한계)
- 특별 희생이 되는 제한: 손실 보상 필요
```

## 핵심 개념 카드

**영장주의 예외** ★★★★★
: 현행범 체포·긴급 체포(48시간 내 영장 청구). 이 두 가지만 영장 없이 가능.
*암기 포인트: 예외=현행범+긴급체포*

**표현의 자유 vs 사전 검열 금지** ★★★★★
: 행정 기관의 사전 검열은 절대적 금지. 영화등급 심의·방송 심의는 검열 아님(헌재).
*암기 포인트: 사전검열=행정기관에 의한 것=절대금지*

**재산권 공용 수용 3요건** ★★★★☆
: 공공 필요성·법률 근거·정당 보상. 완전 보상 원칙.
*암기 포인트: 공공+법률+완전보상*

## 실전 퀴즈

**Q. 긴급 체포의 경우 영장 없이 체포 가능하지만 어떤 조치를 해야 하는가?**
> 48시간 이내에 구속 영장을 청구해야 함. 청구하지 않으면 즉시 석방.

**Q. 재산권의 사회적 구속성과 손실 보상이 필요한 특별 희생의 구분 기준은?**
> 수인 한도를 넘는 특별한 희생 여부. 사회적 구속 = 보상 불요. 특별 희생(재산권 실질적 박탈) = 손실 보상 필요.
