## 노인 장기요양보험이란?

고령이나 노인성 질병으로 일상 활동이 어려운 어르신에게 요양 서비스를 제공하는 사회보험입니다. 건강보험과 별개로 운영되며 전 국민이 장기요양보험료를 납부합니다.

---

## 신청 자격

```
신청 가능 대상:
- 만 65세 이상 노인
- 만 65세 미만이라도 노인성 질병 (치매, 파킨슨병, 뇌졸중 등) 있는 경우

→ 연령 요건이나 질병 요건 중 하나만 충족하면 신청 가능
```

## 장기요양 등급 종류

### 1~5등급 + 인지지원 등급

```
1등급 (최중증):
→ 95점 이상 / 일상생활 수행 능력 완전 상실
→ 24시간 돌봄 필요

2등급 (중증):
→ 75~95점 미만 / 일상생활 대부분 도움 필요

3등급 (중등):
→ 60~75점 미만 / 일상생활 상당 도움 필요

4등급 (경증):
→ 51~60점 미만 / 일상생활 일부 도움 필요

5등급 (치매 특별):
→ 45~51점 미만, 치매 진단 있는 경우
→ 치매 어르신 특화

인지지원 등급:
→ 45점 미만이나 치매 진단 있는 경우
→ 주간 보호, 치매 예방 프로그램 제한 이용
```

---

## 신청 방법

### 절차

```
1단계: 장기요양 인정 신청
       → 국민건강보험공단 지사 방문 or 전화 1577-1000
       → 장기요양 인정 신청서 + 의사 소견서 제출

2단계: 방문 조사 (공단 직원 가정 방문)
       → 신청 후 약 30일 이내
       → 장기요양 인정 조사 표 기준 항목 조사
       → 약 90분 소요

3단계: 등급 판정 위원회 심의
       → 조사 결과 + 의사 소견서 종합
       → 1~5등급 or 인지지원 등급 or 등급 외 결정

4단계: 결과 통보
       → 신청 후 약 30일 이내 결과 통보
       → 등급 인정서·표준 장기요양이용 계획서 수령
```

---

## 방문 조사 항목 (인정 조사 표)

```
조사 영역 (52개 항목):
1. 신체 기능 (12개): 옷 입기, 세면, 식사, 이동 등
2. 인지 기능 (7개): 날짜 인식, 장소 인식 등
3. 행동 변화 (14개): 폭언, 배회, 우울 증상 등
4. 간호 처치 (8개): 투약, 주사, 상처 처치 등
5. 재활 (10개): 관절 운동, 균형 훈련 등

→ 52개 항목 점수화 → 등급 판정 점수 산정
```

## 의사 소견서 발급

```
누가 발급?
→ 주치의 or 가까운 의원·병원 의사

비용: 건강보험 적용 (본인 부담 소액)

내용:
→ 노인성 질병 진단, 기능 상태, 돌봄 필요성 기술
→ 방문 조사 결과와 함께 등급 판정에 활용

주의:
→ 의사 소견서가 없거나 부실하면 등급 낮게 나올 수 있음
→ 어르신 상태를 의사에게 충분히 설명하고 소견서 발급
```

## 등급별 이용 가능 서비스

### 재가 서비스 (집에서 받는 서비스)

```
방문 요양:
→ 요양보호사가 가정 방문해 신체 활동·가사 지원
→ 1~5등급 모두 가능 (시간 상이)

방문 목욕:
→ 욕조 탑재 차량으로 가정 방문 목욕

방문 간호:
→ 간호사가 방문해 의료 처치

주야간 보호:
→ 낮 시간 요양 시설에서 돌봄 후 귀가

단기 보호:
→ 단기간(1개월 이내) 시설 입소
```

### 시설 서비스 (입소)

```
노인 요양 시설 (요양원):
→ 1~2등급 원칙 (3~5등급 예외 인정 시 가능)
→ 24시간 상주 케어

노인 요양 공동 생활 가정 (그룹홈):
→ 치매 어르신 소규모 공동 생활
```

## 등급 판정 결과에 불만족 시

```
이의 신청:
→ 결과 통보일로부터 90일 이내
→ 국민건강보험공단에 이의 신청서 제출
→ 재조사 후 재판정

이의 신청 사유:
- 실제 상태보다 낮은 등급 판정
- 방문 조사 당일 컨디션 좋아 실제보다 좋게 평가된 경우

팁:
→ 조사일에 어르신이 평소 어려운 동작을 더 힘들게 하려는 경향이 있어도 실제 일상을 설명하는 것이 중요
→ 조사관에게 평소 어려운 상황을 구체적으로 설명
```

## 자주 묻는 질문

**Q. 치매 초기인데 신청할 수 있나요?**
A. 치매 진단이 있으면 5등급이나 인지지원 등급으로 신청 가능합니다. 점수가 낮더라도 치매 진단이 있으면 별도 등급이 있습니다.

**Q. 등급 받으면 바로 서비스를 이용할 수 있나요?**
A. 등급 인정서와 이용 계획서를 받은 후 장기요양 기관(방문요양 업체, 요양원 등)과 계약을 맺어야 서비스를 이용할 수 있습니다.

**Q. 요양원 비용은 얼마인가요?**
A. 등급과 시설에 따라 다르지만, 월 60~100만원 이상이 일반적입니다. 장기요양보험에서 상당 부분 지원하고 나머지 15~20%가 본인 부담입니다.

**Q. 신청을 거부할 경우 서비스를 받을 방법이 없나요?**
A. 등급 외 판정을 받아도 지역별 노인 돌봄 사업, 노인 복지관 서비스 등 별도 지원을 받을 수 있습니다. 주민센터에서 안내받으세요.
