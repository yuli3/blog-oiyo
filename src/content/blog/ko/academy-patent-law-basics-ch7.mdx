## 특허 심판 종류

```
결정계 심판 (특허청 내부):
거절결정불복심판
정정심판
보정각하결정불복심판

당사자계 심판 (이해관계인):
무효심판: 등록된 특허 취소
권리범위확인심판: 실시 범위 확인
통상실시권허락심판: 강제 실시 허락

심판 청구인:
무효심판: 누구든 청구 가능
권리범위확인: 이해관계인
```

---

## 무효심판 절차

```
청구:
특허심판원에 청구서 제출
무효 사유: 신규성·진보성 흠결

심리:
서면 심리 원칙
구술 심리 신청 가능
특허권자 답변서 제출

심결:
무효 심결 or 청구 기각
확정 시 소급 효력

불복:
특허법원 → 대법원
```

## 특허 소송 체계

```
민사 소송:
침해금지·손해배상청구
서울중앙지방법원 (전속 관할 일부)

특허법원:
심결취소소송 전속 관할
특허심판원 심결 불복

손해배상 산정:
실시료 상당액 (최소 기준)
침해자 이익액 (추정)
특허권자 손해액

형사 소송:
7년 이하 징역 또는 1억 원 이하 벌금
친고죄 (피해자 고소 필요)
```

## 분쟁 전략

```
피침해자 전략:
침해 증거 수집 (제품·광고·판매)
특허 권리 범위 확인
경고장 발송
협상·라이선스 제안

피의 침해자 방어:
무효 자료 탐색 (선행기술)
비침해 설계변경
무효심판 청구
권리범위확인심판 (소극적)

특허 괴물(NPE) 대응:
선제적 무효심판
크로스 라이선스 협상
방어적 특허 포트폴리오
```

## 핵심 개념 카드

**무효심판=소급효확정** ★★★★★
: 무효 확정 시 처음부터 없었던 것으로 소급.
*암기 포인트: 무효=소급효*

**특허법원=심결취소전속** ★★★★★
: 특허심판원 심결 불복은 특허법원 전속.
*암기 포인트: 특허법원=심결취소*

**손해배상=실시료최소** ★★★★☆
: 실시료 상당액이 손해배상 최소 기준.
*암기 포인트: 손해배상≥실시료*

## 실전 퀴즈

**Q. 특허 침해 소송에서 피고가 주로 사용하는 방어 전략은?**
> 비침해 주장: 청구범위 구성요소 미충족. 무효 항변: 심판과 별도로 소송에서도 무효 주장 가능. 설계변경: 소송 중 청구범위 벗어나도록 제품 수정. 라이선스 협상: 실시료 합의로 소송 종결. 실시 기간 만료 항변. 가장 강력한 방어: 선행기술로 무효 입증.

**Q. 권리범위확인심판의 적극적·소극적 확인 차이는?**
> 적극적 확인: 특허권자가 청구 → 상대방 실시가 내 권리 범위 내에 있다. 소극적 확인: 실시자가 청구 → 내 실시가 특허권 범위 밖에 있다. 소극적 확인 심판: 침해 소송 전 선제적 방어 수단. 심결은 확인적 효력만 → 별도 소송에서 법원 구속 않음. 전략: 소극적 확인 청구로 침해 소송 방어 포지션 확보.
