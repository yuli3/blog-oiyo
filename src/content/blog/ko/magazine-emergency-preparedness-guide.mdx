## 왜 재난을 준비해야 하는가

우리는 대부분 "나는 괜찮을 것"이라고 생각합니다. 이것이 재난 피해를 키우는 심리 편향입니다.

**낙관주의 편향**: 나쁜 일이 나에게는 발생하지 않을 것이라는 믿음.

**현실**:
- 한반도는 완전한 지진 안전지대가 아님 (2016년 경주 5.8, 2017년 포항 5.4)
- 화재는 연간 4만 건 이상 발생
- 기후 변화 → 홍수·태풍 강도 증가

준비는 공포가 아닌 **안심**입니다.

---

## 재난 행동 요령

### 지진

**지진 발생 순간 (강한 흔들림)**:

1. **책상·테이블 아래로** — 머리와 목 보호 (방석, 가방으로 덮기)
2. 창문·가구·가전제품에서 멀리
3. 촛불·가스 불 끄기
4. 흔들림 멈출 때까지 움직이지 않기

**흔들림 멈춘 후**:
1. 가스 밸브 잠그기
2. 출구 확인 (문 뒤틀림 전에)
3. 엘리베이터 금지 — 계단으로 대피
4. 해안가 → 지진해일 주의, 즉시 고지대로

**건물 밖에 있을 때**: 가방으로 머리 보호, 건물·담장에서 멀리 이동, 넓은 공터로.

### 화재

**화재 발생 확인**:

1. **즉시 대피** — 귀중품 챙기러 돌아가지 않기
2. 문 손잡이 열기 전 손등으로 온도 확인 (뜨거우면 열지 않기)
3. 연기 → 낮은 자세로 이동 (연기는 위에 있음)
4. 문 틈 옷·수건으로 막기 (탈출 불가 시)
5. 엘리베이터 금지

**화재 발생 시 행동**: 불이야 외치기 → 화재경보기 누르기 → 119 신고 → 대피.

**화재 신고 정보**: 위치 (건물명, 층, 호수), 불이 난 곳.

### 홍수·침수

**홍수 예보 시**:
- 라디오·TV 재난 방송 청취
- 이동 자동차는 저지대 주차 피하기
- 지하 주차장·지하방 이동 금지

**홍수 발생 시**:
- 하천 둑·개울 접근 금지
- 이미 물이 들어왔다면 즉시 위층으로
- 흐르는 물 15cm → 성인 넘어짐, 30cm → 차량 이동 불가

**지하실·반지하 거주자**: 집중 호우 예보 시 사전 이동.

### 폭풍·태풍

- 창문·외부 문 닫고 잠금
- 지하실 or 실내 중앙부 이동
- 유리창 테이프 붙이기 (비산 방지)
- 야외 간판·화분 미리 치우기
- 정전 대비 손전등·배터리 준비

## 72시간 비상 키트

재난 후 **72시간**은 구조 지원이 도달하기 전의 골든타임.

### 비상식량·물

| 품목 | 용량 |
|-----|-----|
| 생수 | 1인당 3L/일 × 3일 = 9L |
| 즉석밥·레토르트 | 9끼 × 가족 수 |
| 에너지바·비스킷 | 3일치 |
| 소금·설탕 | 소량 |
| 분유 (영아) | 해당 시 |

**보관**: 서늘하고 어두운 곳, 유효기간 연 1회 확인.

### 비상 의약품

- 소독약, 거즈, 반창고
- 진통제 (타이레놀)
- 소화제, 설사약
- 항히스타민제 (알레르기)
- 상비 처방약 (개인 질환)
- 마스크, 일회용 장갑

### 비상 도구

- 손전등 + 여분 건전지 (또는 크랭크 손전등)
- 호루라기 (구조 신호)
- 보조 배터리 (핸드폰 충전)
- 라디오 (재난 방송 수신)
- 현금 소량 (정전 시 카드 불가)
- 지도 (종이, 정전·인터넷 불통 대비)
- 다기능 칼

### 중요 문서 사본

- 신분증, 보험 증서, 통장 사본
- 밀폐 비닐봉지에 보관

## 가족 재난 연락 계획

**직접 연락이 안 될 때 계획**:

1. **집결 장소**: 집 근처 + 집에서 멀리 떨어진 곳 2곳 결정
2. **연락 중계인**: 지역 밖 친척 or 친구 한 명 (시내 전화망 마비 시 장거리는 통화 가능한 경우 있음)
3. **어린이 학교 계획 확인**: 학교의 재난 대피 절차·연락 방법
4. **번호 암기**: 스마트폰 없이도 기억할 번호 2~3개

## 생존 배낭 (Go-Bag)

즉시 대피가 필요할 때 들고 나갈 가방.

**72시간 기준, 1인 배낭**:

| 항목 | 비고 |
|-----|-----|
| 물 1.5L | 더 많으면 무거움 |
| 에너지바·레토르트 | 3일치 |
| 구급 키트 | 소형 |
| 손전등 + 건전지 | |
| 보조 배터리 | |
| 호루라기 + 멀티 툴 | |
| 여벌 의류 + 비옷 | |
| 현금 | 5~10만 원 |
| 중요 문서 사본 | |
| 상비약 | |
| 핸드폰 + 충전기 | |

**배낭 무게**: 성인 15~20kg 이하.

## 응급 처치 기초

**심폐소생술 (CPR)**: 심장 정지 → 4~6분 내 뇌 손상.

1. 반응 확인 (어깨 두드리기)
2. 119 신고
3. 가슴 압박 30회 (깊이 5cm, 분당 100~120회)
4. 인공호흡 2회 (훈련받은 경우)
5. AED 도착까지 반복

**AED 위치**: 공공장소 의무 설치. 지도 앱에서 'AED' 검색.

## 정전·단수 대응

**정전 시**:
- 손전등 사용 (양초는 화재 위험)
- 냉장고 문 최소화 (4~6시간 온도 유지)
- 의약품 (인슐린 등) 냉장 필요한 것 확인
- 핸드폰 절전 모드

**단수 시**:
- 욕조에 물 받아두기 (목욕용)
- 식수는 비상 생수 활용
- 음식 조리 최소화

재난 준비는 하루면 됩니다. 오늘 생수 9L와 즉석밥 9개를 사두는 것으로 시작하세요.
