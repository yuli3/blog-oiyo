## 지리학의 학문 체계

```
지리학의 정의:
→ 지표상의 자연 및 인간 현상의 공간적 분포·관계·변화 연구
→ 핵심 질문: Where? Why there? What patterns? What consequences?
→ 공간 과학 (Spatial Science): 위치·분포·패턴·과정

지리학의 분류:
→ 자연지리학 (Physical Geography):
  지형학·기후학·생물지리학·수문학·토양지리학
→ 인문지리학 (Human Geography):
  인구·도시·경제·문화·정치 지리학
→ 지역지리학 (Regional Geography):
  특정 지역의 자연·인문 특성 통합 연구
→ 환경지리학: 인간-환경 상호작용

지리학의 주요 개념:
→ 입지 (Location): 절대 위치 (좌표)·상대 위치 (관계)
→ 장소 (Place): 의미와 정체성이 부여된 공간
→ 지역 (Region): 공통 특성으로 구분된 공간 단위
→ 이동 (Movement): 사람·물자·아이디어의 이동
→ 인간-환경 상호작용: 적응·개조·의존

지리적 사고:
→ 공간 사고 (Spatial Thinking): 위치·거리·방향·패턴
→ 스케일 (Scale): 분석 규모 (지역·국가·세계)
→ 지리적 상상: 장소와 공간의 사회적 구성
→ GIS와 원격 탐사: 공간 데이터 수집·분석·시각화
```

## 지형학

```
지형 형성 작용:
→ 내인적 작용 (Endogenic):
  화산·지진·조산 운동 (판구조 관련)
  융기·침강
→ 외인적 작용 (Exogenic):
  풍화·침식·운반·퇴적

풍화 (Weathering):
→ 물리적 풍화:
  열팽창·수분 동결 팽창·식물 뿌리 압력
  박리 (Exfoliation): 압력 감소→층상 박리
→ 화학적 풍화:
  용해 (석회암)·가수분해 (장석)·산화 (철)
  온난 습윤 기후에서 활발
→ 생물 풍화: 식물 뿌리·토양 미생물 산 분비

하천 지형:
→ 상류: V자 계곡·폭포·급류 (침식 우세)
→ 중류: 사행 (Meander)·우각호 형성
→ 하류: 범람원·자연제방·배후습지
  삼각주: 퇴적물 하구 퇴적 (한강 삼각주는 없음)
→ 선상지: 산기슭 급경사→완경사 전환점 퇴적

해안 지형:
→ 침식 해안: 해식애·파식대·해식동
→ 퇴적 해안: 사빈(모래 해변)·사구·사취·석호
→ 리아스식 해안: 하천 침식 계곡이 해수 침수
  서해안·남해안·에스파냐 갈리시아
→ 피오르드: 빙하 침식 계곡 침수
  노르웨이·뉴질랜드

카르스트 지형 (Karst):
→ 석회암 화학 풍화로 형성
  CO2 + H2O = H2CO3 → 석회암 용해
→ 지표: 돌리네·우발레·폴예·종유석·석순
→ 지하: 동굴(종유동)·지하 하천
→ 한국: 충북 단양·강원 삼척 (고수동굴·환선굴)

빙하 지형:
→ 침식: 빙식곡 (U자 계곡)·권곡 (Cirque)·호른 (피라미드 봉우리)
→ 퇴적: 모레인 (측퇴석·단퇴석)·드럼린·에스커
→ 주빙하 지형: 구조토·솔리플럭션
→ 스칸디나비아·알프스·안데스 빙하 지형
  한국 빙하 지형: 한라산 백록담 (화구호)·강원 고원
```

## 기후 지역

```
열대 기후 지역:
→ 연중 고온 (최한월 18도 이상)
→ 열대우림 (Af):
  연중 고온 다우·계절 없음
  아마존·콩고·동남아시아
  생물 다양성 최고
→ 열대 몬순 (Am):
  건기 1~2개월·건기에도 최저 60mm 이상
  방글라데시·서인도
→ 사바나 (Aw):
  뚜렷한 건기·우기
  아프리카 중부·브라질 세라도·오스트레일리아 북부

건조 기후:
→ 강수량 < 잠재 증발산량
→ 사막 (BW): 연강수량 250mm 미만
  열 사막 (사하라)·냉 사막 (고비)·해안 사막 (아타카마)
→ 스텝 (BS): 250~500mm
  반건조 초원·목축·밀 농업
→ 건조화 요인:
  아열대 고기압대 (23.5도 부근)
  내륙성·비 그늘·한류 지역

온대 기후:
→ 서안 해양성 (Cfb):
  편서풍·난류 영향·연중 온난 습윤
  영국·프랑스·뉴질랜드 남섬
  포도주·낙농·유채
→ 지중해성 (Cs):
  여름 건조·겨울 습윤
  포도·올리브·오렌지 재배
  캘리포니아·지중해 연안·칠레
→ 습윤 아열대 (Cfa):
  여름 고온 습윤·겨울 온난
  미국 남동부·중국 양쯔강·한국 남부
→ 한국 기후:
  냉대 습윤 (Dfa/Dfb): 북부
  온대 습윤 아열대 (Cfa): 남부
  계절풍 기후·여름 강수 집중

냉대·한대 기후:
→ 냉대 (D): 시베리아·캐나다·스칸디나비아
  침엽수림 (타이가) 발달
  냉대 습윤 (Df)·냉대 건조 (Dw)
→ 툰드라 (ET): 최온월 10도 미만
  나무 없는 지의류·이끼·관목
  영구동토 (Permafrost)
→ 빙설 기후 (EF): 연중 빙설 덮음
  남극·그린란드 내부
```

## 생물지리학과 GIS

```
생물 군계 (Biome):
→ 기후·식생·동물이 특징적인 대규모 생태계
→ 주요 생물 군계:
  열대우림: 높은 생물 다양성·층상 구조
  사바나: 분산된 나무·초원·대형 동물
  사막: 내건성 식물·야행성 동물
  지중해: 경엽 관목·여름 건조 적응
  온대 낙엽수림: 계절성·토양 비옥
  침엽수림 (타이가): 침엽수 우점·산성 토양
  툰드라: 짧은 성장기·영구동토

생물 지리학 이론:
→ 섬 생물지리학 (MacArthur & Wilson):
  섬의 종 수 = 이주율 - 멸종률 균형
  크기 큰 섬·대륙 가까운 섬 → 종 많음
  서식지 파편화에 응용 (보전 생물학)
→ 생물 다양성 핫스팟 (Biodiversity Hotspot):
  고유종 많고 서식지 위협 받는 지역
  마다가스카르·열대 안데스·필리핀

GIS (지리 정보 시스템):
→ 지리 데이터 수집·저장·분석·시각화 시스템
→ 공간 데이터 유형:
  벡터: 점·선·면 (도시·도로·행정 경계)
  래스터: 픽셀 격자 (위성 영상·DEM)
→ 원격 탐사 (Remote Sensing):
  위성 영상: Landsat·MODIS·Sentinel
  드론: 고해상도·실시간 데이터
  활용: 토지이용·삼림 변화·재해 모니터링
→ GPS: 위치 정보 수집
→ 공간 분석:
  중첩 분석 (Overlay): 여러 레이어 결합
  버퍼 분석: 특정 지점 주변 구역
  최적 경로 분석: 교통 계획·물류
→ 한국 GIS: 국토정보공사 (LX)·브이월드 (V-World)
```

## 자주 묻는 질문

**Q. 카르스트 지형은 왜 석회암 지대에서만 발생하나요?**
A. 카르스트 지형의 핵심은 석회암(탄산칼슘, CaCO3)의 화학적 용해성입니다. 비가 내리면 대기와 토양의 CO2가 물에 녹아 탄산(H2CO3)이 형성되는데, 이 약산이 석회암을 용해합니다(CaCO3 + H2CO3 → Ca2+ + 2HCO3-). 이 반응이 수천~수만 년에 걸쳐 반복되면 지표와 지하에 독특한 지형이 만들어집니다. 지표에는 오목한 함몰 지형(돌리네), 지하에는 동굴과 지하 하천이 형성됩니다. 다른 암석(화강암·편마암·현무암)은 이런 방식으로 쉽게 용해되지 않아 카르스트 지형이 발달하지 않습니다. 한국에서는 충북 단양과 강원 삼척 일대가 고생대 석회암 지대로 고수동굴·환선굴·노동동굴 같은 석회동굴이 발달해 있습니다. 온난 습윤 기후에서 화학 풍화가 활발하므로, 동남아시아의 열대 카르스트(베트남 하롱베이 등)는 장관을 이룹니다.

**Q. 한국의 기후가 온대인지 냉대인지 어떻게 구분하나요?**
A. 쾨펜 기후 구분에서 C(온대)와 D(냉대)는 최한월 기온 -3도를 경계로 나눕니다. 최한월 평균 기온이 -3도 이상이면 온대(C), 이하면 냉대(D)입니다. 한국은 지역마다 다릅니다. 서울의 1월 평균 기온이 약 -2~-3도로 C와 D의 경계에 걸쳐 있어 연구자마다 분류가 다릅니다. 남해안·제주도는 1월 기온 3~5도로 온대 습윤 아열대(Cfa)에 해당합니다. 중부 내륙과 북한 지역은 최한월 -10도 이하로 냉대(Dfa/Dfb)가 명확합니다. 한국 기후의 특징은 계절풍(몬순)의 영향으로 여름 강수 집중(전체 강수의 약 60% 이상이 6~9월)과 대륙성 특징이 강한 점입니다. 기후 변화로 한반도 남부 지역이 점차 온대화되는 경향이 관측되고 있으며, 제주도의 경우 아열대 식물 재배가 늘고 있습니다.
