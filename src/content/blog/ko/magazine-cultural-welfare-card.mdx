## 문화누리카드란?

기초생활수급자 및 차상위계층의 **문화생활을 지원**하기 위해 정부가 지급하는 연간 바우처(선불카드)입니다. 공연, 영화, 도서, 여행, 스포츠 관람 등에 사용할 수 있습니다.

---

## 2024년 지원 금액

```
지원 금액: 1인당 연간 13만원
→ 2023년 11만원에서 인상
→ 가구 인원과 무관하게 개인별 지급 (가족 4명 = 52만원)
```

---

## 신청 자격

### 지원 대상

```
1. 기초생활수급자 (생계·의료·주거·교육급여 모두 해당)
2. 차상위계층:
   - 차상위 본인부담경감 대상자
   - 자활근로 참여자
   - 장애인 연금 부가급여 수급자
   - 차상위 계층 확인서 발급자
3. 6세 이상 (만 6세 이상부터 개인 카드 발급)
```

> 매년 새롭게 신청해야 합니다 (자동 갱신 안 됨).

---

## 발급 신청 방법

### 온라인 신청

```
문화누리카드 홈페이지: www.mnuri.kr
→ 로그인 → 카드 신청
→ 배송 주소 입력 → 약 5~7일 내 카드 배송
```

### 오프라인 신청

```
주민센터(행정복지센터) 방문:
→ 신분증 지참
→ 신청서 작성 후 현장 발급 or 우편 수령

전화 신청: 문화누리카드 고객센터 1544-3412
```

### 신청 시기

```
매년 2월부터 신청 시작
연말까지 신청 가능하지만 잔액 소멸 주의
→ 2월~3월에 신청 후 연간 사용이 최적
```

## 사용 가능한 곳 (2024년)

### 문화 분야

| 분야 | 이용 가능 시설 |
|------|-------------|
| **공연·전시** | 국공립·민간 공연장, 박물관, 미술관 |
| **영화** | CGV, 롯데시네마, 메가박스 등 |
| **도서** | 교보문고, 영풍문고, 알라딘, YES24 온라인 |
| **음악** | 스트리밍 서비스 (멜론, 지니 등 일부) |

### 여행 분야

```
국내 여행:
- 한국관광공사 지정 숙박 시설
- 유명 관광지 입장료
- 국가유산(문화재) 입장료
- KTX 할인 (코레일)
```

### 스포츠 분야

```
- 프로야구, 프로축구 관람
- 국공립 체육 시설 (수영장, 헬스장 등)
```

## 사용 방법

```
카드형: 신용카드처럼 단말기에 삽입 or 터치 결제
온라인: 문화누리카드 번호 + 유효기간 입력

주의:
- 카드 뒷면의 초기 비밀번호: 생년월일 앞 4자리
- 분실 신고: 1544-3412 즉시 신고
- 잔액 확인: 앱 or 홈페이지 or 전화 ARS
```

---

## 잔액 및 소멸 주의사항

### 연말 소멸

```
문화누리카드 잔액은 해당 연도 12월 31일에 소멸
→ 연말까지 사용하지 않으면 0원이 됨
→ 이월 불가

팁:
12월에 잔액 확인 후 남은 금액은 도서 구입 등으로 소진
→ YES24, 알라딘 온라인 도서 구매로 간편하게 사용
```

### 잔액 확인 방법

```
1. 문화누리카드 앱 (안드로이드·iOS)
2. 홈페이지(mnuri.kr) → 로그인 → 잔액 조회
3. 전화: 1544-3412 → ARS → 잔액 조회
4. 카드 단말기: 사용 시 영수증에 잔액 표시
```

## 혜택 극대화 팁

### 팁 1: 공연·전시 최대 활용

```
일반 공연 티켓: 3~10만원
→ 13만원으로 공연 1~2회 관람 가능
CGV 주말 영화: 약 15,000원
→ 8~9회 관람 가능
```

### 팁 2: 여행 활용

```
KTX 할인:
→ 코레일 홈페이지에서 문화누리카드로 결제 가능
→ 교통비 절감

숙박:
→ 한국관광공사 지정 숙소에서 사용
→ 저렴한 펜션·게스트하우스도 포함 가능
```

### 팁 3: 도서 구입으로 마무리

```
연말 잔액이 남았다면:
→ 알라딘, YES24, 교보문고 온라인 도서 구매
→ 소액이라도 책으로 전환
→ 책은 교육 가치 + 소장 가치
```

## 자주 묻는 질문

**Q. 가족 카드인가요, 개인 카드인가요?**
A. 개인 카드입니다. 가족이 4명이라면 각각 신청해야 하며 각자 13만원을 받습니다.

**Q. 편의점이나 마트에서 쓸 수 있나요?**
A. 지정된 문화·여행·스포츠 관련 업종만 사용 가능합니다. 편의점·마트·음식점에서는 사용할 수 없습니다.

**Q. 전년도 미사용 잔액이 있는데 올해로 이월 가능한가요?**
A. 불가능합니다. 매년 12월 31일 잔액 소멸. 꼭 사용하세요.

**Q. 신청을 안 했는데 작년 것도 소급해서 받을 수 있나요?**
A. 불가능합니다. 신청 연도 기준으로만 지급됩니다.
