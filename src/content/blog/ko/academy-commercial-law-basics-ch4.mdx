## 주식의 의의와 종류

```
주식:
자본금을 균등하게 세분한 단위
주주의 회사에 대한 지분

주식의 종류:
┌────────────┬──────────────────────────────────────┐
│ 보통주     │ 기본적 권리 (의결권+배당권)           │
├────────────┼──────────────────────────────────────┤
│ 우선주     │ 배당·잔여재산에서 우선 지위           │
│            │ 의결권 없거나 제한 (무의결권 우선주)  │
├────────────┼──────────────────────────────────────┤
│ 후배주     │ 배당 등에서 후순위                    │
├────────────┼──────────────────────────────────────┤
│ 혼합주     │ 우선+후배 성격 혼합                   │
└────────────┴──────────────────────────────────────┘

기명주 vs 무기명주:
기명주: 주주명부에 이름 등재 (현재 상법=기명주 원칙)
무기명주: 2014년 상법 개정으로 폐지
```

## 자기주식

```
자기주식:
회사가 자신이 발행한 주식을 취득·보유

취득 요건:
배당 가능한 이익 범위 내 취득 (재원 규제)
이사회 결의 또는 주주총회 승인

자기주식 효과:
의결권 없음 (자기주식은 의결권 행사 불가)
배당 없음 (회사 자신에게 배당 불가)
소각 가능 (자본금 감소 효과)

취득 제한:
특정 목적 外 취득 규제 (이익 소각, 주가 안정 등)
```

## 자본금 증감

```
증자 (자본금 증가):
유상증자: 신주 발행 + 실제 납입 → 자본금+자산 증가
무상증자: 준비금→자본금 전환 → 자본금만 증가 (자산 변화 없음)

신주 인수권:
기존 주주: 지분 비율에 따른 신주 인수 우선권
정관이나 이사회 결의로 제3자 배정 가능

감자 (자본금 감소):
유상감자: 주주에게 환급 → 자본금+자산 감소
무상감자: 결손 보전 목적 → 자본금 감소 (자산 변화 없음)

감자 절차:
주주총회 특별결의 + 채권자 이의 절차
```

## 배당

```
이익배당:
회사 이익을 주주에게 분배
배당 기준일 주주에게 지급

배당 결정:
정기 주주총회에서 결의 (원칙)
이사회 결의 배당: 정관 규정 있는 경우 가능

현금배당 vs 주식배당:
현금배당: 현금 지급
주식배당: 신주 교부 (주주 수령액=이익잉여금→자본금 전환)

배당 한도:
배당 가능 이익 범위 내
= 대차대조표상 순자산 - 자본금 - 법정준비금 - 임의준비금

중간배당:
영업연도 중 1회 한해 이사회 결의로 가능
정관에 근거 필요
```

## 핵심 개념 카드

**무상증자 vs 유상증자** ★★★★★
: 유상=신주+납입→자본금+자산 모두 증가. 무상=준비금→자본금 전환→자본금만 증가.
*암기 포인트: 무상증자=회계상 이동만*

**자기주식 의결권 없음** ★★★★★
: 회사가 자기 주식 보유해도 의결권 없음. 배당도 없음.
*암기 포인트: 자기주식=권리 없음*

**배당 가능 이익** ★★★★☆
: 순자산-자본금-법정준비금-임의준비금 이내.
*암기 포인트: 배당=초과 이익만 지급*

## 실전 퀴즈

**Q. 우선주 주주가 의결권을 행사하지 못하는 이유는?**
> 우선주는 배당이나 잔여재산 분배에서 우선 지위를 얻는 대신 의결권이 없거나 제한됨. 상법상 무의결권 우선주 발행 가능. 경영 참여보다 재무적 이익을 원하는 투자자용.

**Q. 무상증자와 유상증자의 주주 입장 차이는?**
> 유상증자: 주주가 돈 내고 신주 인수 → 실질적 지분 유지. 무상증자: 돈 안 내고 신주 교부 → 주가 하락하지만 주식 수 증가. 실질 재산가치는 동일 (자산 변화 없음).
