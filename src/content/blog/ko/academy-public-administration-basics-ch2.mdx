## 관료제

```
Weber의 관료제:
근대 국가의 합리적·법적 지배 구현
계층적·규칙 기반·비개인적 조직

관료제 특성:
① 계층제: 상하 명령·복종
② 전문화: 업무 분업화
③ 규칙·규정: 문서화된 절차
④ 비개인성: 감정 배제, 규칙에 따른 처리
⑤ 경력 시스템: 시험·승진에 의한 임용

관료제 역기능:
목표 전치: 수단(규칙)이 목적화
→ 절차에 집착, 실질 목표 무시

동조 과잉: 규정에 지나치게 복종
할거주의: 부서 이기주의
무사안일: 창의성·혁신 저하
비밀주의: 정보 독점
```

## 계층제와 통솔 범위

```
계층제:
상하 권위의 연쇄
명령 통일의 원칙 (한 명의 상관)

통솔 범위 (Span of Control):
한 관리자가 직접 통솔하는 부하 수
좁은 통솔 → 계층 많음 (고층 조직)
넓은 통솔 → 계층 적음 (저층 조직, 수평 조직)

집권화 vs 분권화:
집권화: 의사결정 권한 상위 집중
→ 통일성·조정 용이, 혁신 어려움

분권화: 의사결정 권한 하위 위임
→ 신속 결정·자율성, 조정 어려움

위임:
상급자→하급자로 업무 권한 이전
단, 책임은 위임 불가 (위임해도 상급자 책임 잔류)
```

## 조직 유형

```
계선 조직 (Line):
명령·집행 담당, 직접 목표 수행
상하 명령 계층

참모 조직 (Staff):
계선 조직 지원·자문
직접 명령권 없음

계선-참모 조직:
계선+참모 혼합 (현대 대규모 조직)

위원회 조직:
다수 위원으로 구성된 합의체
장점: 다양한 관점, 신중한 결정
단점: 결정 지연, 책임 불명확

매트릭스 조직:
기능별 조직 + 프로젝트별 조직 혼합
이중 명령 구조 (기능 부서장 + 프로젝트 팀장)
장점: 유연성, 단점: 갈등 발생
```

## 공식 조직·비공식 조직

```
공식 조직:
법령·규정으로 명시된 공식 구조
명확한 역할·책임

비공식 조직:
자생적으로 형성된 인간관계
공식 조직 내에서 자연 발생
(동창회·혈연·취미 모임)

비공식 조직의 기능:
긍정: 구성원 심리적 안정, 소통 원활화
부정: 파벌 형성, 공식 질서 저해

동조 과잉 vs 역할 갈등:
동조: 규범에 과도히 복종
역할 갈등: 여러 역할 기대가 충돌
```

## 핵심 개념 카드

**관료제 역기능** ★★★★★
: 목표전치·동조과잉·할거주의·무사안일·비밀주의.
*암기 포인트: 목동할무비*

**집권화 vs 분권화** ★★★★★
: 집권=통일성+통제, 분권=자율+신속. 대규모 복잡 조직→분권화 경향.
*암기 포인트: 집권=조정, 분권=자율*

**위임 시 책임 잔류** ★★★★☆
: 권한은 위임해도 최종 책임은 상급자에 잔류.
*암기 포인트: 위임=권한만, 책임은 남음*

## 실전 퀴즈

**Q. 관료제의 목표 전치 현상이란 무엇인가?**
> 조직 목표(예: 주민 서비스)를 위한 수단(규칙·절차)이 그 자체 목적이 되는 현상. 예: 서류 형식이 맞지 않아 정당한 민원 거절. 수단이 목적을 대체하는 역기능.

**Q. 통솔 범위와 조직 층수의 관계는?**
> 반비례 관계. 통솔 범위 좁으면(1인이 적은 부하 관리) 계층 많이 필요 → 고층 조직. 통솔 범위 넓으면(1인이 많은 부하 관리) 계층 적음 → 수평 조직. 현대는 수평 조직 선호.
