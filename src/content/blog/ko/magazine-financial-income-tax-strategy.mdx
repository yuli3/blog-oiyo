## 금융소득 2,000만원 기준이 왜 중요한가

이자·배당소득이 연 2,000만원을 넘으면 **종합과세**로 전환됩니다. 세율이 15.4%에서 최대 49.5%까지 올라갈 수 있습니다. 투자 금액이 커질수록 반드시 알아야 할 세금 구조입니다.

---

## 금융소득 종합과세 기본 원리

### 일반 구조

```
금융소득(이자 + 배당) ≤ 2,000만원:
→ 원천징수 세율 15.4%로 분리과세 종결

금융소득(이자 + 배당) > 2,000만원:
→ 초과분을 다른 소득(근로·사업소득 등)과 합산
→ 종합소득세율(6~45%) 적용
→ 5월에 종합소득세 신고·납부 의무 발생
```

### 세금 계산 예시

```
[ 직장인, 연 급여 5,000만원 + 이자·배당 3,000만원 ]

2,000만원까지: 15.4% 원천징수 = 308만원
초과분 1,000만원: 종합과세 대상

종합과세 계산:
합산 소득 = 5,000만원 + 1,000만원 = 6,000만원
과세표준 기준 세율: 24%

원천징수 세금과 비교 후 추가 납부:
→ 기납부 308만원 중 2,000만원분 공제 후 정산
→ 실질 추가 납부세액 발생
```

## 금융소득 합산 대상 vs 비합산 대상

### 합산되는 소득

```
- 은행 예금·적금 이자
- 국내 주식 배당
- 채권 이자 (일부 제외)
- 펀드 분배금
- 해외 주식 배당 (일부)
- P2P 이자
- 저축성 보험 이자 일부
```

### 합산되지 않는 소득 (비과세·분리과세)

```
- ISA 계좌 이익 (비과세 한도 or 9.9% 분리과세)
- 장기 저축성 보험 비과세 요건 충족 시
- 비과세 채권 이자
- 국내 주식 매매차익 (비과세, 대주주 제외)
- 국민저축 이자 일부
```

## 금융소득 2,000만원 달성되는 자산 규모

```
예금 금리 4% 기준:
→ 2,000만원 = 원금 5억원 × 4%
→ 5억원 이상 예금이면 주의 필요

배당수익률 3% ETF:
→ 2,000만원 = 원금 약 6.7억원 × 3%
→ 주식·ETF 투자 금액이 클수록 주의

→ 예금+주식 혼합 포트폴리오에서도 합산
```

## 절세 전략 6가지

### 전략 1: ISA 계좌 최대 활용

```
ISA 내 수익은 금융소득 합산 제외:
- 일반형: 비과세 200만원 + 초과분 9.9% 분리과세
- 서민형·농어민형: 비과세 400만원 + 초과분 9.9%

→ 연 200~400만원 수익까지 금융소득 합산 불포함
→ 3년 이상 유지 후 만기 수령

실전 활용:
ISA에 배당주·채권 ETF 담기 → 배당·이자 비합산
```

### 전략 2: 비과세 금융 상품 활용

```
비과세 대상:
- 청년도약계좌: 이자 비과세
- 청년 우대형 주택청약: 이자 비과세 (500만원 한도)
- 장기 저축성 보험: 10년+ 유지 시 이자 비과세

→ 이 계좌의 이자·배당은 금융소득 합산 미포함
```

### 전략 3: 가족 간 분산

```
배우자에게 증여 후 배우자 명의 금융소득:
- 배우자 증여 공제: 6억원 (10년간)
- 배우자에게 금융자산 6억원 이전 → 배우자 금융소득 발생
→ 부부 각각 2,000만원 기준 적용 가능

주의: 증여세 신고 필요 (6억 초과분)
```

### 전략 4: 비과세·분리과세 채권 선택

```
분리과세 채권:
- 재형채권, 비과세 채권 (일부)
→ 이자가 금융소득 합산 제외

주식 매매차익:
- 국내 상장 주식 매매차익 = 비과세 (대주주 아닌 경우)
→ 배당 대신 가치 상승으로 수익 추구 시 합산 회피 가능
```

### 전략 5: 배당 시기 분산

```
연말 배당 집중 시:
→ 당해 연도 금융소득 급증
→ 이듬해 1월 배당 기업으로 분산
→ 연도별 2,000만원 균분 전략
```

### 전략 6: 해외 주식 ETF 활용

```
국내 ETF 배당: 배당소득세 15.4% + 합산
해외 주식 직접 보유 배당: 합산 대상

반면:
미국 주식 매매차익: 양도소득세 별도 신고 (22%)
→ 합산되지 않음

→ 배당소득 줄이고 매매차익 위주 투자 전략
```

## 건강보험 피부양자 주의

```
금융소득 1,000만원 초과 → 피부양자 탈락 위험
금융소득 2,000만원 초과 → 종합과세 + 피부양자 확실 탈락

→ 피부양자 등재 중인 가족은 ISA 활용으로 금융소득 합산 최소화
```

## 종합과세 신고 절차

```
신고 시기: 매년 5월 1~31일
신고 방법: 홈택스 → 종합소득세 신고
→ 금융소득 내역 자동 불러오기 기능 사용
→ 기납부 원천징수세액 차감 후 납부

선납세액 초과 시: 환급
```

## 자주 묻는 질문

**Q. 주식 매매로 2,000만원 수익이 났는데 종합과세인가요?**
A. 국내 상장 주식 **매매차익**은 종합과세 대상이 아닙니다. 배당소득만 합산됩니다.

**Q. 해외 ETF 분배금도 합산되나요?**
A. 국내 증권사에서 보유하는 해외 ETF 분배금(배당)은 배당소득으로 원천징수되고 합산 대상입니다. ISA 내에 담으면 합산 회피 가능.

**Q. 부부 공동으로 2,000만원이 기준인가요?**
A. 아닙니다. 각각 2,000만원이 기준입니다. 자산이 많으면 배우자 명의 분산이 절세 전략이 됩니다.
