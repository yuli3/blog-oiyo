## 회계란 무엇인가

**회계(Accounting)**는 기업의 경제적 활동을 측정·기록·분류·요약하여 정보 이용자가 의사결정을 내릴 수 있도록 전달하는 정보 시스템입니다.

**회계의 목적**: 이해관계자(주주·채권자·정부·경영진)에게 **유용한 재무 정보** 제공

---

## 회계의 분류

| 구분 | 재무회계 | 관리회계 |
|------|--------|---------|
| **목적** | 외부 보고 | 내부 의사결정 |
| **이용자** | 투자자, 채권자, 정부 | 경영진, 관리자 |
| **기준** | GAAP/IFRS 준수 | 자유 형식 |
| **보고 주기** | 정기(분기·반기·연간) | 수시 필요 시 |
| **예시** | 재무제표 | 예산·원가보고서 |

**세무회계**: 세금 계산을 위한 회계. 세법 규정에 따름.

---

## 복식부기 (Double-Entry Bookkeeping)

모든 거래를 **차변(Debit)**과 **대변(Credit)** 양측에 동시 기록하여 회계 등식이 항상 유지되도록 합니다.

```
기본 회계 등식:
자산(Assets) = 부채(Liabilities) + 자본(Equity)
```

**차변 증가 계정**: 자산, 비용
**대변 증가 계정**: 부채, 자본, 수익

```
예시: 현금 1,000만 원을 받고 서비스 제공

(차변) 현금 1,000만 원
(대변) 매출 1,000만 원
→ 자산 증가 = 수익 증가 (회계 등식 균형 유지)
```

---

## 회계의 기본 가정

1. **기업 실체의 가정(Entity Assumption)**: 기업은 소유자와 독립된 별개의 실체
2. **계속기업의 가정(Going Concern)**: 기업이 예측 가능한 미래에 계속 존재한다고 가정
3. **화폐 단위의 가정(Monetary Unit)**: 화폐 단위로만 측정·기록
4. **기간별 보고의 가정(Periodicity)**: 기업의 수명을 일정 기간으로 나누어 보고

---

## 재무제표의 종류

| 재무제표 | 내용 |
|---------|------|
| **재무상태표** | 특정 시점의 자산·부채·자본 현황 |
| **손익계산서** | 일정 기간의 수익·비용·이익 |
| **현금흐름표** | 일정 기간의 현금 유입·유출 |
| **자본변동표** | 일정 기간의 자본 변동 내역 |
| **주석** | 재무제표 항목 상세 설명 |

---

## 회계 정보의 질적 특성 (IFRS 개념체계)

**근본적 질적 특성**:
- **목적적합성**: 이용자의 의사결정에 차이를 만들 수 있는 정보
- **충실한 표현**: 완전성·중립성·오류 없음

**보강적 질적 특성**:
- 비교가능성, 검증가능성, 적시성, 이해가능성

---

## 핵심 개념 카드

**복식부기 원리** ★★★★★
: 모든 거래는 차변과 대변 양쪽에 같은 금액으로 기록. 차변 합계 = 대변 합계가 항상 성립.
*암기 포인트: 자산·비용 = 차변 증가 / 부채·자본·수익 = 대변 증가*

**기본 회계 등식** ★★★★★
: 자산 = 부채 + 자본. 모든 재무제표 작성의 기초.
*암기 포인트: 자 = 부 + 자(본)*

**계속기업 가정** ★★★★☆
: 기업이 파산하지 않고 계속 운영된다고 가정. 감가상각, 장기 자산 평가의 근거.
*암기 포인트: 계속기업 가정이 없으면 청산가치로 평가해야 함*

## 실전 퀴즈

**Q. 재무회계와 관리회계의 가장 큰 차이점은?**
> 재무회계는 외부 이해관계자를 위한 GAAP/IFRS 기준의 공식 보고. 관리회계는 내부 경영진의 의사결정을 위한 자유 형식 보고. 재무회계는 과거 정보 중심, 관리회계는 미래 예측 포함.

**Q. 회사가 사무용 컴퓨터를 100만 원에 현금 구입했다. 분개하라.**
> (차변) 비품(자산) 100만 원 / (대변) 현금(자산) 100만 원. 자산의 구성 변화(현금 감소, 비품 증가)로 회계 등식 유지.
