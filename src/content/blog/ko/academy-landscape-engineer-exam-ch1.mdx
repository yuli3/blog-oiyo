## 조경기사 자격증이란?

조경기사는 한국산업인력공단이 시행하는 **국가기술자격**으로, 공원·녹지·정원 등 외부 공간을 계획·설계·시공·관리하는 전문가를 검증합니다. 건설·환경 분야에서 조경 설계사무소, 건설사, 공공기관(LH·지자체) 취업과 입찰 참여에 핵심 자격입니다.

```
주관/시행: 한국산업인력공단 (Q-Net)
등급: 기사 (산업기사·기능사 상위)
시험: 필기 → 실기 (연 3회 내외)
합격 기준:
- 필기: 과목당 40점 이상 + 평균 60점 이상
- 실기: 60점 이상
```

---

## 응시 자격 (기사 공통)

```
다음 중 하나 충족:
- 관련학과 4년제 졸업(예정)
- 산업기사 취득 + 실무 1년
- 기능사 취득 + 실무 3년
- 동일·유사 분야 실무 4년
- 학점은행제 등 동등 학력

→ 비전공자는 실무경력·관련 자격으로 자격 충족 가능
```

---

## 필기 시험 과목

```
필기 5과목 (객관식, 과목당 20문제):

1. 조경계획
2. 조경설계
3. 조경식재
4. 조경시공구조학
5. 조경관리론

→ 5과목 평균 60점·과락(40점) 없이 합격
→ CBT(컴퓨터 기반 시험)로 시행
```

---

## 실기 시험

```
실기: 조경설계 (필답형 + 작업형)

- 작업형: 도면 작성
  (설계 대상지 평면도·단면도·상세도 등)
- 필답형: 조경시공·적산·관리 단답·계산

→ 제도(製圖) 능력이 핵심
→ 손도면 작성 숙달이 합격을 좌우
```

---

## 조경(造景)이란?

```
조경의 정의:
→ 토지·공간을 인간과 자연이 조화롭도록
  계획·설계·시공·관리하는 종합 예술이자 기술

조경의 대상:
- 공원·녹지 (도시공원, 자연공원)
- 정원 (주택·공공정원)
- 광장·가로·생태복원
- 단지·리조트·골프장 조경

조경의 영역:
계획 → 설계 → 시공 → 관리 (생애 전 과정)
```

---

## 조경 분야의 진로와 전망

```
진로:
- 조경설계사무소 (설계·감리)
- 건설사 조경부서 (시공)
- 공공기관: LH, 지자체 공원녹지과, 산림청
- 조경시공·자재 업체

전망:
- 도시재생·생태복원·탄소중립 정책으로 수요 증가
- 공원녹지 의무·아파트 조경 강화
- 건설업 면허·입찰에 조경기사 필수
```

## 핵심 암기 포인트

```
- 시행: 한국산업인력공단(Q-Net), 국가기술자격
- 필기 5과목: 계획·설계·식재·시공구조학·관리론
- 합격: 필기 과목40·평균60 / 실기 60점
- 실기: 조경설계(도면 작업형 + 필답형)
- 조경 4단계: 계획→설계→시공→관리
- 응시: 관련학과 졸업 또는 실무경력으로 충족
```

## 자주 묻는 질문

**Q. 비전공자도 조경기사를 딸 수 있나요?**
A. 가능합니다. 실무경력 4년, 또는 산업기사·학점은행제 등으로 응시 자격을 갖추면 됩니다. 다만 실기(도면 작성)는 제도 훈련이 필요해 별도 준비가 중요합니다.

**Q. 필기와 실기 중 무엇이 더 어렵나요?**
A. 일반적으로 실기(조경설계 도면 작성)가 더 까다롭습니다. 제한 시간 안에 정확한 도면을 손으로 그려야 해, 반복 연습이 합격의 관건입니다.

**Q. 조경기사와 조경산업기사의 차이는?**
A. 기사가 상위 등급으로 응시 자격(학력·경력)이 더 높고, 설계·감리 등 폭넓은 업무에 활용됩니다. 산업기사는 진입 문턱이 낮은 대신 활용 범위가 상대적으로 제한적입니다.
