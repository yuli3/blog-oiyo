## 특허 요건

```
특허 성립 요건:
발명: 자연법칙을 이용한 기술적 사상의 창작

특허 요건 (실체 요건):
신규성: 출원 전 공지·공용·반포된 발명 아닐 것
진보성: 통상의 기술자가 쉽게 발명할 수 없을 것
산업상 이용가능성

공지 예외:
출원 전 12개월 이내 공개 → 신규성 의제
학술 발표·전시회 등

선원주의:
동일 발명 동시 출원 시 먼저 출원한 자
선발명주의(미국)와 구별
```

---

## 특허 출원 절차

```
출원:
특허청에 명세서·청구범위·도면 제출
출원일 기준으로 권리 발생

출원 공개:
출원일로부터 1년 6개월 후 자동 공개
조기 공개 신청 가능

심사:
출원 후 심사 청구 필수 (3년 이내)
출원 심사청구 안하면 취하 간주

거절이유 통지:
심사관이 거절 이유 통지
의견서·보정서 제출

등록:
등록결정 + 등록료 납부 → 특허권 발생
```

## 특허권 효력과 침해

```
특허권 존속기간:
출원일로부터 20년

특허권 효력:
실시 독점권 (제조·사용·양도·수입)
소극적 효력: 타인 실시 금지

실시권:
전용실시권: 독점 (물권적)
통상실시권: 비독점 (채권적)

침해:
직접침해·간접침해
손해배상·금지청구·폐기청구

특허 무효:
특허 등록 후에도 무효 심판 가능
소급 효력으로 처음부터 없었던 것
```

## 실전 퀴즈

**Q. 진보성 판단에서 '통상의 기술자'가 기준이 되는 이유는?**
> 특허는 기술 발전 장려가 목적. 이미 쉽게 생각할 수 있는 것을 특허로 보호하면 독점 남용. 통상의 기술자: 해당 기술 분야 평균 지식·기술 보유자. 이 기준으로 쉽게 도출 가능 → 진보성 없음 → 특허 거절. 실무에서 진보성이 가장 다툼 많음.

**Q. 특허 무효 심판에서 소급 효력의 실무적 의미는?**
> 특허 무효 확정 → 처음부터 특허 없었던 것. 무효 전 받은 로열티: 반환 의무 없음 (불법행위 성립 가능). 무효 전 침해 소송: 기존 판결 영향. 경쟁사 전략: 강력한 특허라도 무효화로 대응 가능. 특허 분쟁의 핵심 무기.
