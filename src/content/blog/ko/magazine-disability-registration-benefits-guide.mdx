## 장애인 등록이란?

「장애인복지법」에 따라 신체적·정신적 손상으로 일상생활에 상당한 제약을 받는 사람이 국가에 등록해 각종 복지 혜택을 받을 수 있는 제도입니다.

---

## 장애 유형 (15가지)

```
신체적 장애:
1. 지체 장애 (사지·척추 등 기능 이상)
2. 뇌병변 장애 (뇌 손상으로 이동·인지 제한)
3. 시각 장애
4. 청각 장애
5. 언어 장애
6. 안면 장애

정신적 장애:
7. 지적 장애
8. 자폐성 장애
9. 정신 장애 (조현병 등)

내부 기관 장애:
10. 신장 장애
11. 심장 장애
12. 호흡기 장애
13. 간 장애
14. 장루·요루 장애
15. 뇌전증
```

## 등록 신청 방법

### 절차

```
1단계: 주민센터(행정복지센터) 방문
       → '장애인 등록 신청서' 접수

2단계: 지정 의료기관에서 장애 진단
       → 주민센터에서 안내하는 지정 병원 방문
       → 장애 유형에 따른 전문의 진단서 발급

3단계: 국민연금공단 장애 심사
       → 심사 기간: 약 2~4개월
       → 서류 보완 요청될 수 있음

4단계: 결과 통보 및 복지카드 발급
       → 등록 완료 후 '장애인복지카드' 발급
```

### 필요 서류

```
- 장애 진단서 (지정 의료기관 발급)
- 진료 기록지 또는 검사 결과지
- 신분증
- 사진 1매
- 장애인 등록 신청서 (현장 작성)
```

## 장애 정도 구분

```
2019년 장애 등급 폐지 → 장애 정도로 변경:

장애 정도가 심한 장애인 (기존 1~3급):
→ 더 많은 혜택 적용

장애 정도가 심하지 않은 장애인 (기존 4~6급):
→ 기본 혜택 적용

→ 활동지원 등 일부 서비스는 종합 조사 점수로 결정
```

## 주요 혜택

### 장애인 연금 (중증 장애인)

```
대상: 만 18세 이상 등록 중증 장애인
소득 기준: 기준 중위소득 100% 이하 (단독) / 150% 이하 (부부)

급여 (2024년):
- 기초급여: 월 최대 334,810원
- 부가급여: 소득에 따라 추가 (최대 수십만원)

→ 기초생활수급자·차상위는 부가급여 추가 지급
```

### 장애인 활동 지원 서비스

```
대상: 만 6~65세 등록 장애인 중 일상생활 도움 필요한 자
내용: 신체 활동, 가사 활동, 사회 활동 지원
지원 시간: 종합 조사 결과 기준 월 60~480시간

자부담: 소득에 따라 0~15만원
→ 기초수급자: 자부담 없음
```

### 의료비 지원

```
의료급여 1종 적용 (기초수급 장애인):
→ 입원비 본인 부담 0%
→ 외래 진료 1,000~2,000원

건강보험 장애인 산정특례:
→ 장애 진단 관련 치료비 경감
→ 보조기 급여 (휠체어, 의족, 보청기 등)
```

### 세금 감면

```
소득세:
- 장애인 추가 인적공제: 연 200만원 (장애인 본인 or 부양 장애인)

자동차:
- 장애인 특수 제작 차량: 취득세·자동차세 면제
- 승용차 구입 시 취득세 200만원 한도 면제 (장애 정도 심한 경우)

기타:
- 전화 요금 할인 (이동통신, 유선전화)
- 도시철도·버스 무임 (1~3급 해당)
```

### 교통비 지원

```
- 도시철도 (지하철): 전액 무임 (장애 정도 심한 경우)
- KTX·고속버스 할인 (최대 50%)
- 국내 항공 할인 (15~30%)
- 장애인 차량 주차 특혜 (장애인 주차 구역)
- 택시 특별 교통 수단 (복지 콜)
```

### 통신비 지원

```
이동통신:
- 음성 통화 65% 감면 (월 최대 1만4,000원)
- 데이터 요금 감면

시각·청각 장애인:
- 시각: 전화 요금 면제 (일부)
- 청각: 문자 요금 감면
```

### 문화·교육 혜택

```
- 국·공립 시설 입장료 면제 (박물관, 공원, 수목원 등)
- 대학 등록금 지원 (장애 장학금)
- 국립도서관 이용 혜택
```

□ 장애인 주차 증명서 발급
□ KTX·항공 할인 등록

## 자주 묻는 질문

**Q. 임시 장애(골절 등)로도 등록할 수 있나요?**
A. 장애인 등록은 1년 이상 지속되는 영구적 기능 이상을 기준으로 합니다. 일시적 부상은 등록이 어렵습니다.

**Q. 장애인 등록은 언제 해야 가장 좋은가요?**
A. 가능한 빨리 등록할수록 유리합니다. 등록 후부터 혜택이 적용되며 소급되지 않습니다.

**Q. 장애 판정을 받지 못하면 이의 신청이 가능한가요?**
A. 네, 심사 결과에 이의가 있으면 90일 이내 이의 신청이 가능합니다. 추가 의료 소견서를 보완해 재심사를 받을 수 있습니다.

**Q. 외국에 거주 중에도 장애인 등록이 가능한가요?**
A. 국내 거주 사실이 필요하므로 장기 해외 거주 중에는 등록이 어렵습니다. 귀국 후 신청하시기 바랍니다.
