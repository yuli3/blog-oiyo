## 환경 오염의 유형

```
환경 오염의 정의:
→ 인간 활동으로 환경의 자정 능력을 초과하는 오염 물질 배출

오염 유형:
→ 대기 오염
→ 수질 오염
→ 토양 오염
→ 해양 오염
→ 소음·진동 오염
→ 빛 공해

오염원 분류:
→ 점 오염원 (Point Source): 특정 장소에서 배출 (공장 굴뚝)
→ 비점 오염원 (Nonpoint Source): 광범위한 곳에서 배출 (농경지 유출수)
→ 1차 오염물: 직접 배출 (CO, PM10)
→ 2차 오염물: 반응 생성 (오존, 산성비)
```

---

## 대기 오염

```
주요 대기 오염 물질:

미세먼지 (PM2.5, PM10):
→ PM2.5: 직경 2.5μm 이하 (폐 깊이 침투)
→ PM10: 직경 10μm 이하
→ 주요 발생: 화력발전, 자동차, 공장, 황사
→ 건강 영향: 호흡기·심혈관 질환, 사망률 증가

이산화황 (SO₂):
→ 석탄·석유 연소 시 발생
→ 산성비의 원인 (H₂SO₄)
→ 호흡기 자극

질소산화물 (NOₓ):
→ 고온 연소 시 발생 (자동차, 화력발전)
→ 광화학 스모그, 산성비 원인
→ 오존 생성에 관여

오존 (O₃):
→ 성층권 오존: 자외선 차단 (오존층)
→ 대류권 오존: 2차 오염물, 호흡기 자극
→ NOₓ + VOC + 햇빛 → 광화학 스모그

일산화탄소 (CO):
→ 불완전 연소 시 발생
→ 혈중 헤모글로빈과 결합 → 산소 운반 방해

실내 공기 오염:
→ 포름알데히드: 새 가구·건축 자재
→ 라돈: 지반 방사성 가스
→ CO₂: 환기 부족 시 집중력 저하
```

## 수질·토양 오염

```
수질 오염:

부영양화 (Eutrophication):
→ 과잉 영양염류(N, P) → 조류 번식 → 산소 고갈
→ 원인: 농업 비료 유출, 생활 하수
→ 영향: 물고기 폐사, 음용수 오염

중금속 오염:
→ 수은(Hg): 미나마타병 (유기수은)
→ 카드뮴(Cd): 이타이이타이병 (뼈 연화)
→ 납(Pb): 신경·인지 발달 장애
→ 생물 농축: 먹이사슬 따라 농도 증가

수질 지표:
→ DO (용존산소): 높을수록 수질 양호
→ BOD (생물화학적 산소 요구량): 낮을수록 좋음
→ COD (화학적 산소 요구량): 유기물 오염도

토양 오염:

농약·화학 비료:
→ 잔류 농약: 토양·지하수 오염
→ 과잉 질소: 토양 산성화, 수질 오염

중금속:
→ 광산·제련소 주변 토양 오염
→ 식물·식품으로 인체 유입

폐기물 매립:
→ 침출수: 유해 물질이 지하수로 유출
→ 메탄 가스: 온실가스 배출

토양 복원:
→ 생물 정화(Bioremediation): 미생물 활용
→ 식물 정화(Phytoremediation): 식물 활용
```

## 기후 변화

```
온실 효과와 지구 온난화:
→ 온실 가스: CO₂, CH₄, N₂O, 수증기
→ 태양 에너지 흡수, 지구 복사 에너지 차단
→ 자연적 온실 효과: 평균 기온 15°C 유지
→ 인위적 온실 효과 강화: 산업화 후 CO₂ 급증

온실 가스 배출원:
→ CO₂: 화석 연료 연소 (가장 많음)
→ CH₄: 가축 방귀·소화, 쌀 논, 매립지
→ N₂O: 농업 비료, 연소
→ HFC, PFC: 냉매, 반도체 제조

기후 변화의 영향:
→ 평균 기온 상승 (산업화 이전 대비 +1.1°C, 2023년)
→ 극지 빙하 녹음 → 해수면 상승
→ 이상 기후 빈도 증가 (폭염, 홍수, 가뭄)
→ 생물 다양성 감소, 생태계 교란
→ 식량 생산 위협, 기후 난민 발생

티핑 포인트 (Tipping Point):
→ 돌이킬 수 없는 변화가 시작되는 임계점
→ 그린란드 빙상 붕괴, 아마존 사막화
```

## 기후 변화 국제 협약

```
유엔기후변화협약 (UNFCCC, 1992):
→ 기후 변화 대응 국제 협력의 틀
→ 선진국 온실가스 감축 목표 설정

교토의정서 (Kyoto Protocol, 1997):
→ 최초의 구체적 감축 의무
→ 선진국(Annex I)만 의무 감축
→ 2008~2012년 1차 공약기간
→ 미국 불참, 중국·인도 의무 없음 → 한계

파리협정 (Paris Agreement, 2015):
→ 196개국 참여 (보편적 체계)
→ 목표: 산업화 이전 대비 2°C 이하 억제, 1.5°C 노력
→ 자국 결정 기여(NDC): 각국이 자발적 감축 목표 제출
→ 5년마다 강화된 목표 제출
→ 선진국: 개도국 기후 재정 지원 (1,000억 달러/년)

한국의 탄소 중립 목표:
→ 2030년 NDC: 2018년 대비 40% 감축
→ 2050년 탄소 중립 선언
→ 탄소중립·녹색성장 기본법 (2021년)
```

## 기후 변화 정책 수단

```
경제적 수단:

탄소세 (Carbon Tax):
→ 탄소 배출량에 직접 세금 부과
→ 가격 신호로 배출 감소 유도
→ 장점: 단순·명확한 가격 신호
→ 단점: 감축량 불확실, 역진적 (저소득층 부담)
→ 한국: 교통·에너지·환경세로 간접 적용

배출권 거래제 (Emissions Trading Scheme, ETS):
→ 배출 허용량(Cap) 설정 후 시장에서 거래
→ Cap-and-Trade: 총량 고정, 할당량 거래
→ 비용 효율적: 감축 저렴한 업체가 더 감축
→ 한국: K-ETS (2015년 도입, 세계 최초 국가 단위)

규제적 수단:
→ 배출 기준 설정 (자동차 연비 기준 등)
→ 에너지 효율 의무화 (가전 에너지 등급)
→ 재생에너지 의무비율 (RPS)

재생 에너지:
→ 태양광: 급격한 비용 하락, 분산형 발전
→ 풍력: 해상풍력 성장
→ 수소 경제: 그린수소 생산·활용
→ 배터리 에너지 저장 시스템 (BESS)
```

## 자주 묻는 질문

**Q. 탄소세와 배출권거래제 중 어느 것이 더 효과적인가요?**
A. 각각 장단점이 있습니다. 탄소세는 가격이 확실하지만 실제 감축량이 불확실합니다. 배출권거래제는 감축 총량이 확실하지만 탄소 가격이 변동합니다. 경제학자들은 탄소세를 선호하는 경향이 있고, 환경론자들은 배출권거래제의 확실한 목표를 선호합니다. 많은 국가에서 두 가지를 조합해 사용합니다.

**Q. 개인 차원의 탄소 발자국 감소가 실제로 의미 있나요?**
A. 개인 행동과 기업·국가 정책 모두 필요합니다. 개인의 탄소 발자국 감소(채식, 대중교통, 에너지 절약)는 실질적 영향이 있지만 구조적 변화(에너지 시스템, 산업)가 더 큰 영향을 미칩니다. 또한 소비자 행동이 기업의 친환경 제품 공급을 촉진하고 정책에 대한 사회적 요구를 높인다는 점에서 간접 영향도 중요합니다.
