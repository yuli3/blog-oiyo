## 판결의 종류

```
실체 판결:
유죄 판결: 형 선고
무죄 판결: 범죄 불성립 또는 증거 부족

형식 판결:
공소 기각: 공소 요건 흠결
면소: 공소시효 완성·사면 등
관할 위반

기타:
선고유예: 유죄이나 형 선고 유예
집행유예: 유죄이나 형 집행 유예
```

---

## 상소 제도

```
항소 (2심):
1심 판결에 불복
항소 제기 기간: 판결 선고 후 7일 이내
항소 이유: 사실 오인·법리 오해·양형 부당

상고 (3심):
2심 판결에 불복
상고 이유: 법리 오해 (사실 심리 제한)
대법원 심리

항고:
결정·명령에 불복
재항고: 항고 결정에 불복

불이익변경금지:
피고인만 상소 시 원심보다 중한 형 선고 불가
예: 피고인만 항소 → 항소심에서 더 중한 형 불가
```

---

## 확정 판결의 효력

```
기판력:
확정 판결 = 동일 사건 재소 불가 (일사부재리)

집행력:
형 확정 → 형 집행

형의 실효:
집행 완료 후 일정 기간 경과 시 형 실효

재심:
확정 판결 후 새로운 증거로 재심 청구
무죄 증거 발견 시 재심 허용
재심은 피고인 이익 방향만 (불이익 재심 불가)
```

## 핵심 개념 카드

**항소기간=7일** ★★★★★
: 판결 선고일로부터 7일 이내 항소 제기.
*암기 포인트: 항소=7일*

**불이익변경금지=피고인항소** ★★★★★
: 피고인만 항소 시 원심보다 중한 형 불가.
*암기 포인트: 피고인항소=불이익금지*

**재심=이익방향만** ★★★★☆
: 재심은 피고인에게 유리한 방향으로만 허용.
*암기 포인트: 재심=이익재심*

## 실전 퀴즈

**Q. 불이익변경금지 원칙의 예외는 무엇인가?**
> 예외: 검사도 항소한 경우. 피고인과 검사 모두 항소 시 → 원심보다 중한 형 가능. 취지: 피고인이 상소를 두려워하지 않도록 보장. 예: 피고인만 항소 → 항소심에서 1심 징역 2년을 3년으로 올리면 불이익변경금지 위반. 검사도 항소 → 원심보다 중형 가능. 형식: "불이익변경금지 = 피고인만 상소 시" 조건 주의.

**Q. 재심 청구 요건과 절차는?**
> 재심 사유: 새로운 증거 발견 (무죄 증명 명백). 원판결 기초 증거가 허위 또는 위조. 담당 판사의 직무범죄. 원심 확정 후 청구. 청구 기간: 재심 사유 알게 된 날로부터 (기간 제한 있음). 절차: 재심 개시 결정 → 공판 진행. 재심은 이익재심만 허용: 무죄·감경 목적만.
