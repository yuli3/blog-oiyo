## 운(運)의 구조

사주명리학에서 **운(運)**은 시간에 따라 변화하는 에너지의 흐름입니다. 사주 원국이 바탕이라면, 운은 그 위에 오버레이되는 시간적 에너지입니다.

```
인생 = 사주 원국(바탕) + 대운(10년) + 세운(1년) + 월운(1개월)
```

이 세 가지 운이 동시에 긍정적이면 **인생의 최고 전성기**, 모두 부정적이면 **최저점**이 됩니다.

## 대운(大運) 분석

### 대운 계산법

대운은 **월주(月柱)에서 순행 또는 역행**으로 계산합니다.

**순행 (양남·음녀)**:
- 양년 출생 남성
- 음년 출생 여성
- 월주 다음 간지로 순서대로 진행

**역행 (음남·양녀)**:
- 음년 출생 남성
- 양년 출생 여성
- 월주 이전 간지로 역순 진행

**대운 시작 나이 계산**:
```
순행: 생일 이후 다음 절입(節入)까지의 날수 ÷ 3
역행: 생일 이전 직전 절입까지의 날수 ÷ 3
(나머지 날수는 반올림)
```

<Callout type="note">
**예시**: 갑자년 갑인월 생, 다음 절입까지 24일
→ 24 ÷ 3 = 8세에 대운 시작
→ 8세, 18세, 28세, 38세... 마다 대운 바뀜
</Callout>

### 대운 60갑자 순서 예시

월주가 **갑인(甲寅)**인 순행 대운의 경우:
```
첫 대운: 을묘(乙卯)
두 번째: 병진(丙辰)
세 번째: 정사(丁巳)
네 번째: 무오(戊午)
...
```

### 대운 해석의 핵심 원칙

**대운 천간**: 앞 5년의 심리적·대인적 변화
**대운 지지**: 뒤 5년의 환경적·물질적 변화

| 대운 십신 | 주요 테마 | 실제 영향 |
|---|---|---|
| 비겁 대운 | 경쟁·독립 | 독립 창업, 이직, 인간 관계 정리 |
| 식상 대운 | 표현·창조 | 새로운 창작 활동, 자녀, 직업 변화 |
| 재성 대운 | 재물·현실 | 수입 증가 or 지출 급증 |
| 관성 대운 | 시험·성장 | 사회적 지위 변화, 건강 주의 |
| 인성 대운 | 배움·지원 | 학업, 부모의 도움, 안정적 성장 |

## 세운(歲運) 분석

### 세운이란?

세운은 **그해의 간지**로 결정됩니다. 예를 들어 2026년은 **병오년(丙午年)**입니다.

세운의 병화(丙火)와 오화(午火)가 모든 사람의 사주와 상호작용합니다.

### 세운 × 사주 원국 상호작용

**세운 천간과 일간의 합(合)**:
```
갑기합(甲己合): 갑목 일간에 기토 세운이 오면 → 합화 토(土) 발동
을경합(乙庚合): 을목 일간에 경금 세운 → 합화 금(金) 발동
```

합이 되면 해당 오행 에너지가 강하게 활성화됩니다.

**세운 지지와 원국 지지의 충(沖)**:
```
자(子)년 세운 + 원국에 오(午) 있으면 → 자오충 발동
→ 이사, 이직, 중요한 변화의 해
```

### 세운 길흉 판단 기준

**좋은 세운의 특징**:
1. 세운 오행이 내 용신·희신
2. 세운이 대운과 합(合)을 이룸
3. 세운이 원국의 공망(空亡)을 채워줌
4. 충·형·파가 없거나 약함

**주의가 필요한 세운**:
1. 세운 오행이 기신·구신
2. 세운이 대운과 충(沖)
3. 형(刑)이 발동하는 해
4. 원국의 중요한 글자와 세운이 충

## 월운(月運) 분석

### 월운이란?

월운은 **해당 월의 간지**입니다. 세운 안에서 더 세밀한 시기를 파악합니다.

**중요한 결정의 타이밍 잡기**:
- 취업·이직 계약: 용신 월운
- 투자·사업 결정: 재성 월운이 좋을 때
- 결혼·동거 시작: 관성·재성 월운
- 새 프로젝트 시작: 식상 또는 비겁 월운

### 월별 운세 강도표

```
최고: 대운 용신 + 세운 용신 + 월운 용신 (3중 호운)
좋음: 2개 이상 용신 겹침
보통: 용신과 기신 혼재
주의: 대운·세운 기신 + 월운 기신
```

## 실전 사례: 대운·세운 종합 분석

### 가상 사례 분석

**사주**: 을목(乙木) 일간, 현재 **병화(丙火) 대운** 중
**용신**: 수(水) (신강 을목, 제어 필요)

**대운 분석 (병화)**:
- 병화는 목(木)을 설기하는 식신
- 을목의 에너지를 밖으로 발산하는 시기
- 창의적 활동, 사회 진출에 유리
- 단, 용신이 수(水)인데 화(火) 대운 → 약간 불리한 방향

**2026년 세운 분석 (병오년)**:
- 세운 병화 → 일간 을목에게 식신
- 세운 오화(午) 지지 → 火 에너지 추가
- 화(火)가 이중으로 강화 → 용신 수(水)에 불리

**조언**:
- 2026년은 과도한 활동·지출 주의
- 수(水) 오행의 친구·파트너와 협력 강화
- 하반기 수(水)가 강해지는 달에 중요 결정 집중

## 운세를 알면 무엇이 달라지나?

| 운세를 모를 때 | 운세를 알 때 |
|---|---|
| 왜 이 시기에 안 되는지 모름 | 어려운 이유를 이해하고 준비 |
| 좋은 기회인지 판단 어려움 | 언제 적극적으로 움직일지 파악 |
| 막연한 불안감 | 시간에 맞는 전략 수립 |
| 좋은 때를 그냥 흘려보냄 | 황금기에 최대한 활용 |

<Callout type="tip">
**운세 활용의 핵심**: 나쁜 운이 오면 피할 수 없지만, 준비하고 수비적으로 행동할 수 있습니다. 좋은 운이 오면 더 적극적으로 움직여 극대화할 수 있습니다. 운을 아는 것은 삶의 타이밍을 아는 것입니다.
</Callout>
