## 사회 계층(Social Stratification)이란?

```
사회 계층화(Stratification)의 정의:
→ 사회 내에서 부, 권력, 위신 등이
  불균등하게 분포된 위계적 구조

계층화의 특징:
1. 모든 사회에 존재 (보편성)
2. 세대 간 지속 (지속성)
3. 사람들의 삶 기회에 영향 (영향력)
4. 사회적으로 믿어진 정당성 (이데올로기)
```

## 계급(Class) vs 계층(Stratum)

```
계급 (Class, 마르크스 관점):
→ 생산수단에 대한 소유 관계에 따른 집단
→ 부르주아지 (자본가): 생산수단 소유
→ 프롤레타리아트 (노동자): 노동력만 소유
→ 이해가 반대되는 계급 간 필연적 갈등

계층 (Stratum, 베버 관점):
→ 경제·사회적 위치에 따른 연속적 순위 체계
→ 3차원: 계급(경제), 지위(사회), 권력(정치)

현대적 계층 분류:
- 상류층: 대규모 자산가, 최고 경영자
- 중간층: 전문직, 관리직, 자영업자
- 하류층: 저임금 노동자, 불안정 취업자
- 빈곤층: 기초생활수급자 포함
```

## 사회 이동 (Social Mobility)

```
사회 이동의 유형:

1. 수직 이동 vs 수평 이동:
- 수직 이동: 계층 위치 변화 (상향/하향)
- 수평 이동: 같은 계층 내 직업·지역 변화

2. 세대 내 이동 vs 세대 간 이동:
- 세대 내: 한 개인의 생애 동안 계층 변화
- 세대 간: 부모 세대 vs 자녀 세대 비교

3. 개인 이동 vs 집단 이동:
- 개인 이동: 특정 개인의 계층 상승·하강
- 집단 이동: 사회구조 변화로 특정 집단 전체 이동

사회 이동의 경로:
→ 교육: 가장 중요한 수직 이동 수단
→ 결혼: 배우자의 계층으로 이동 가능
→ 사업 성공: 창업, 투자
→ 사회 구조 변화: 직업 구조 변화
```

## 빈곤(Poverty)의 정의와 측정

```
절대적 빈곤 (Absolute Poverty):
→ 기본 생존에 필요한 최소 자원 부족
→ 식량, 의복, 주거의 최소 기준 미충족
→ 세계은행 기준: 하루 2.15달러 이하 (2022년)

상대적 빈곤 (Relative Poverty):
→ 사회 평균 소득과 비교한 상대적 박탈
→ OECD 기준: 중위 소득 50% 이하
→ 풍요로운 사회에서도 상대적 빈곤 존재

주관적 빈곤:
→ 개인이 스스로 가난하다고 느끼는 상태

한국의 빈곤 지표:
→ 기준 중위 소득: 정부가 매년 고시
→ 기초생활수급자: 기준 중위 소득 32% 이하
→ 차상위계층: 기준 중위 소득 50% 이하
```

## 빈곤의 원인 이론

```
1. 개인주의적 설명 (Individualist):
→ 빈곤은 개인의 능력 부족, 게으름, 잘못된 선택 결과
→ 정책: 개인의 자립 의지 강화, 근로 의욕 고취

2. 구조주의적 설명 (Structuralist):
→ 빈곤은 사회 구조(차별, 불평등한 기회, 경제 구조)의 산물
→ 정책: 사회 보장 강화, 평등한 교육 기회 확대

3. 문화적 설명 (Cultural Theory):
→ 오스카 루이스의 '빈곤의 문화' (Culture of Poverty)
→ 빈곤층은 독특한 가치·행동 양식을 내면화
→ 비판: 빈곤층 낙인화 우려

4. 기능주의적 설명:
→ 빈곤층은 사회에서 부도덕하고 위험한 일을 담당
→ 불평등은 동기 부여 기능
→ 비판: 빈곤 정당화로 이어질 우려
```

## 교육과 사회 불평등

```
교육의 두 가지 기능:

순기능 (기능주의):
→ 능력에 따른 선발과 배치 (능력주의)
→ 사회 이동 수단 (사다리 기능)
→ 사회화: 공통 가치 내면화

역기능 (갈등론):
→ 불평등 재생산: 부유층이 더 좋은 교육 받음
→ 부르디외의 문화자본: 중상류층 문화가 학교에서 가치 있게 평가
→ 숨겨진 교육과정 (Hidden Curriculum): 순종·규율 학습

부르디외 (Bourdieu)의 자본 이론:
- 경제자본: 돈, 재산
- 문화자본: 교육 수준, 취향, 지식
- 사회자본: 인맥, 네트워크

→ 문화자본이 학교 성취와 연결 → 계층 재생산
```

## 젠더 불평등 (Gender Inequality)

```
젠더 (Gender) vs 섹스 (Sex):
→ 섹스: 생물학적 성별 (남/여)
→ 젠더: 사회·문화적으로 구성된 성별 정체성과 역할

젠더 불평등의 형태:
1. 임금 격차 (Gender Pay Gap):
→ 동일 직종에서 여성이 남성보다 낮은 임금
→ 한국 성별 임금 격차: OECD 최고 수준

2. 유리 천장 (Glass Ceiling):
→ 여성의 고위직 진출을 가로막는 보이지 않는 장벽

3. 돌봄 노동의 불균등 분담:
→ 무급 가사·육아 노동의 여성 편중

젠더 불평등 이론:
- 기능주의: 성별 역할 분업은 사회 안정에 기능적
- 갈등론: 가부장제는 남성 지배를 정당화하는 구조
- 페미니즘: 젠더 불평등 타파, 동등한 권리·기회 주장
```

## 인종과 민족 불평등

```
인종 (Race):
→ 생물학적 특성(피부색 등)에 기반한 집단 분류
→ 현대 유전학: 인종은 생물학적 실체라기보다 사회적 구성물

민족 (Ethnicity):
→ 공유된 문화, 역사, 언어, 전통에 기반

차별과 편견:
- 편견 (Prejudice): 집단에 대한 부정적 태도·믿음
- 차별 (Discrimination): 편견에 기반한 불평등한 대우
- 제도적 차별: 개인적 의도 없이 사회 구조 속에 내재된 차별

한국의 다문화 현황:
→ 2023년 기준 국내 체류 외국인 약 250만 명 이상
→ 결혼 이주 여성, 외국인 노동자, 유학생 등
→ 다문화 사회로의 전환과 사회 통합 과제
```

## 자주 묻는 질문

**Q. 능력주의(meritocracy)가 완전히 실현된다면 불평등은 정당화될 수 있나요?**
A. 이것이 현대 불평등 논쟁의 핵심입니다. 능력주의를 지지하는 입장은 노력과 능력에 따른 보상이 공정하다고 봅니다. 반면 비판론은 능력 자체가 출발선이 다른 사회 환경(가정환경, 교육 기회)에 의해 형성된다는 점을 지적합니다. 마이클 샌델의 "공정하다는 착각"이 이 주제를 심층적으로 다룹니다.

**Q. 한국 사회는 계층 이동이 어려워지고 있나요?**
A. 연구에 따르면 한국의 세대 간 계층 이동성은 1990년대 이후 낮아지는 경향을 보입니다. 특히 교육비 부담, 부동산 자산 격차 확대가 계층 고착화에 영향을 미치고 있다는 분석이 많습니다.
