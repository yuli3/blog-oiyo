## 직업심리검사 개요

```
직업심리검사의 목적:
→ 내담자의 흥미·적성·성격·가치관 파악
→ 직업 선택·진로 탐색의 근거 제공
→ 상담자의 주관적 판단 보완

검사의 분류:

표준화 검사 vs 비표준화 검사:
→ 표준화: 규준 집단 비교 가능 (Holland, MBTI)
→ 비표준화: 면접·관찰·직업카드 분류

최대 수행 vs 전형적 수행:
→ 최대 수행: 최대 능력 측정 (적성·지능검사)
→ 전형적 수행: 평소 행동 측정 (성격·흥미검사)

검사의 질 기준:
→ 신뢰도: 일관성 — 같은 조건에서 반복 동일 결과
  반분법, 검사-재검사법, 동형 검사법
→ 타당도: 정확성 — 측정하려는 것을 제대로 측정
  내용·구인·준거 타당도
→ 표준화: 실시·채점·해석의 일관성
→ 규준: 집단 비교 기준 (백분위, 표준점수)

표준점수 변환:
→ Z점수: (X - X̄) / s (평균 0, SD 1)
→ T점수: 10Z + 50 (평균 50, SD 10)
→ 스테나인: 1~9 범주 (평균 5, SD 2)
```

## 주요 직업심리검사

```
Holland 직업 흥미 검사:
→ RIASEC 6가지 흥미 유형 측정
→ SDS(Self-Directed Search), VPI, STRONG
→ 3자리 코드: 상위 3개 흥미 조합
→ 코드 일치도: 내담자 흥미와 직업 환경의 적합도

MBTI (Myers-Briggs Type Indicator):
→ 4가지 이분 척도: E/I, S/N, T/F, J/P
→ 16가지 성격 유형
→ 융(Jung)의 심리 유형론 기반
→ 직업 흥미보다 의사소통·학습·협력 스타일 파악

Strong 직업 흥미 검사:
→ GOT (General Occupational Theme): Holland 유형
→ BIS (Basic Interest Scale): 세부 흥미
→ OSS (Occupational Scale): 직업 비교
→ PSS (Personal Style Scale): 개인 스타일

MMPI (Minnesota Multiphasic Personality Inventory):
→ 정신병리적 성격 진단
→ 임상 척도 10개 + 타당도 척도
→ 직업 상담보다 정신건강 선별에 주로 활용

직업 가치관 검사 (Work Values Inventory):
→ 내재적 가치: 성취감·자율성
→ 외재적 가치: 급여·안정성
→ 슈퍼(Super)의 가치 목록

적성 검사 (Aptitude Test):
→ DAT: 8개 적성 측정 (언어추리, 수리능력 등)
→ GATB: 직업 적성 배터리 (한국: 직업적성검사)
→ 지능과 다름: 특정 훈련 가능한 능력
```

## 상담 기본 기술

```
상담 관계 형성 (Rapport):
→ 상담 성공의 전제 조건
→ 수용·공감·진솔성 (Rogers 핵심 조건)

기본 상담 기술:

경청:
→ 적극적 경청: 언어·비언어 모두 주의
→ 최소 촉진자 (Minimal Encouragers): "네", "그렇군요"
→ 비언어 단서: 눈 맞춤, 고개 끄덕임

반영 (Reflection):
→ 감정 반영: 내담자 감정을 언어로 되돌려줌
  "많이 힘드신 것 같아요"
→ 내용 반영(바꿔 말하기): 내용을 다른 말로 요약

명료화:
→ 애매한 내용을 분명히 하도록 질문
→ "그때 '억울하다'는 게 어떤 의미인지 말씀해 주시겠어요?"

질문 기술:
→ 개방형 질문: 폭넓은 응답 ("어떻게 생각하세요?")
→ 폐쇄형 질문: 예/아니오 ("취업 경험이 있으신가요?")
→ 초보 상담자 실수: 폐쇄형 질문 과다

직면 (Confrontation):
→ 내담자의 불일치·모순 지적
→ "~라고 하시면서 행동은 ~하신다고요"
→ 충분한 신뢰 관계 형성 후 사용

해석 (Interpretation):
→ 상담자가 의미·패턴 설명
→ 내담자 수용 가능 수준에서 제시
```

## 상담 과정 단계

```
초기 단계 (상담 관계 형성):
→ 래포(Rapport) 형성
→ 상담 구조화: 규칙·비밀보장·기간 안내
→ 문제 명료화: 주 호소 문제 파악
→ 상담 목표 설정: 구체적·측정 가능하게

중간 단계 (탐색·개입):
→ 문제 원인 탐색
→ 심리검사 실시·해석
→ 정보 제공: 직업 정보, 노동 시장 정보
→ 의사결정 훈련
→ 저항 다루기

저항 (Resistance):
→ 변화에 대한 심리적 방어
→ 원인: 불안, 동기 부족, 낮은 신뢰
→ 다루기: 강요 금지, 저항 수용, 탐색 유도
  "그 부분이 어렵게 느껴지시나요?"

종결 단계:
→ 목표 달성 여부 평가
→ 내담자 변화 인정·강화
→ 재발 대비 계획
→ 추수 상담 안내 (Follow-up)

상담 윤리:
→ 비밀보장: 타해 위험·아동학대 등 예외
→ 이중 관계 금지: 상담자-내담자 이외 관계
→ 내담자 자율성 존중
→ 상담 한계 인식: 의뢰·자문 활용
```

## 집단 직업 상담

```
집단 상담의 장점:
→ 경제성: 다수 동시 서비스
→ 집단 역학: 동료 피드백·모델링
→ 현실감: 다양한 경험 공유
→ 소속감·지지감 형성

집단 직업 상담의 유형:
→ 취업 준비 집단: 이력서·면접 실습
→ 진로 탐색 집단: 직업 정보 탐색
→ 직업 전환 집단: 이직·재취업 지원
→ 특수 집단: 장애인·고령자·결혼이민자

집단 발달 단계 (Tuckman):
→ Forming: 탐색·의존 (규칙 형성)
→ Storming: 갈등·저항 (리더십 도전)
→ Norming: 규범 형성 (응집력 증가)
→ Performing: 생산적 협력 (목표 달성)
→ Adjourning: 종결·평가

집단 지도자의 역할:
→ 촉진자: 집단 상호작용 활성화
→ 전문가: 직업 정보 제공
→ 과정 관리: 목표 초점 유지
→ 갈등 중재: 건설적 해결 유도

집단 크기·빈도:
→ 적정 인원: 8~12명
→ 폐쇄형 집단: 구성원 고정 (더 깊은 신뢰)
→ 개방형 집단: 수시 참여 가능 (유연성)
```

## 자주 묻는 질문

**Q. 심리검사 결과를 내담자에게 어떻게 해석해 드려야 하나요?**
A. 검사 결과를 라벨로 부여하지 않는 것이 중요합니다. 예를 들어 "당신은 R유형이니 이 직업을 해야 한다"는 식의 단정은 내담자 자율성을 침해합니다. 검사 결과를 탐색의 시작점으로 활용해 "이 결과에 대해 어떻게 생각하세요?", "이 부분이 공감되나요?"처럼 내담자의 반응을 확인하며 대화를 이어나가야 합니다. 검사 하나만으로 결정하지 않고 면접, 직업 경험, 생애사 정보를 통합해 해석하는 것이 전문적입니다.

**Q. 초기 상담에서 구조화가 왜 중요한가요?**
A. 구조화(상담의 본질, 규칙, 기간, 비밀보장 설명)는 내담자의 불안을 줄이고 상담에서 무엇을 기대할 수 있는지 명확히 해 줍니다. 비밀보장 설명은 내담자가 솔직하게 이야기할 수 있는 심리적 안전감을 제공합니다. 구조화 없이 진행하면 상담 목적에 대한 오해, 기대 불일치로 인한 조기 종결, 의존 관계 형성 등의 문제가 생길 수 있습니다.
