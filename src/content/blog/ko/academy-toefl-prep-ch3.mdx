## TOEFL Speaking 개요

- **4과제**, **총 16분**
- 채점: ETS AI + 인간 채점관 (0~30점)
- 마이크에 녹음하는 방식 (시험관과 대면 아님)

### 채점 기준 4가지

| 기준 | 설명 |
|------|------|
| Delivery | 속도, 발음, 유창성 |
| Language Use | 문법 정확성, 어휘 범위 |
| Topic Development | 내용의 완성도, 논리 구조 |
| Coherence | 연결어 사용, 일관성 |

## Task 1: Independent Speaking

**형식**: 개인 의견·선호도 표현 (준비 15초 / 응답 45초)

**주제 유형**:
- "A 방법과 B 방법 중 어느 것이 더 낫다고 생각하나요?"
- "어떤 능력/특성이 가장 중요하다고 생각하나요?"

### Task 1 템플릿

```
도입부 (5초):
"In my opinion, [선택/의견]."

이유 1 (15초):
"First, [이유]. For example/instance, [구체적 예시]."

이유 2 (15초):
"Additionally, [이유 2]. [예시 또는 상세 설명]."

마무리 (5초):
"That's why I believe [결론 한 문장]."
```

## Task 2: Reading + Listening + Speaking (통합형 I)

**형식**: 지문 읽기(45초) → 강의 듣기 → 응답 (준비 30초 / 응답 60초)

**전형적 구조**:
- 지문: 학교 정책·서비스·시설 변경 안내
- 강의: 학생 두 명의 대화 (한 명이 찬성 또는 반대)
- 질문: "The man/woman expresses his/her opinion about the announcement. State the opinion and the reasons given."

### Task 2 템플릿

```
"The [man/woman] [agrees/disagrees] with the [policy/change] mentioned in the reading.

[His/Her] first reason is that [이유 1]. [He/She] explains that [구체적 내용].

[His/Her] second reason is that [이유 2]. According to the conversation, [상세 내용]."
```

## Task 3: Reading + Listening + Speaking (통합형 II)

**형식**: 학술 개념 설명 지문 → 교수 강의(예시 포함) → 응답

**질문**: "The professor describes [예시]. Explain how it illustrates the concept in the reading."

### Task 3 템플릿

```
"The reading passage introduces the concept of [개념명].

The professor illustrates this concept through the example of [예시]. 

[In the example], [예시의 첫 번째 특징/단계] [구체 내용]. This demonstrates [개념의 어느 측면].

[Furthermore/Additionally], [예시의 두 번째 측면] [구체 내용], which shows [개념의 또 다른 측면]."
```

---

## Task 4: Listening Only + Speaking (통합형 III)

**형식**: 학술 강의만 듣기 → 응답 (준비 20초 / 응답 60초)

**질문**: "Using points and examples from the lecture, explain [주제]."

### Task 4 템플릿

```
"In the lecture, the professor explains [주제].

The professor makes two main points. First, [포인트 1]. For example, [예시].

Second, [포인트 2]. To illustrate, [예시].

Together, these examples show that [전체 요점 한 문장]."
```

## 유창성 향상 훈련법

### 1. 쉐도잉 (Shadowing)
TED 강연이나 TOEFL 오디오를 들으면서 동시에 따라 말하기.
목표: 원어민 속도와 억양 내면화

### 2. 1분 스피치 타이머 연습
일상 주제로 매일 1분짜리 스피치 녹음 → 자신의 발화 패턴 분석

### 3. 연결어 (Transition Words) 자동화

| 기능 | 연결어 예시 |
|------|-----------|
| 이유 제시 | "One reason is...", "This is because..." |
| 예시 | "For instance...", "To illustrate..." |
| 추가 | "Furthermore...", "Additionally..." |
| 대조 | "However...", "On the other hand..." |
