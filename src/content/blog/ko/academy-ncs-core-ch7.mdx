## 정보능력이란

**NCS 정보능력**은 업무와 관련된 정보를 수집·분석·관리하고, 컴퓨터와 소프트웨어를 효율적으로 활용하는 능력입니다.

**2가지 하위 능력**:
1. **컴퓨터활용능력**: 업무에 필요한 소프트웨어를 효과적으로 사용
2. **정보처리능력**: 데이터를 수집·정리·분석하여 의미 있는 정보로 변환

---

## 컴퓨터 활용 기초

### 업무에서 가장 많이 쓰이는 도구

**스프레드시트 (엑셀, 구글 시트)**:
- 데이터 정리와 계산 자동화
- 피벗 테이블로 대용량 데이터 요약
- 차트와 그래프로 시각화
- VLOOKUP, INDEX-MATCH로 데이터 조회

**프레젠테이션 (파워포인트, 구글 슬라이드)**:
- 정보의 시각적 전달
- 스토리텔링 구조: 문제 → 원인 → 해결책

**문서 처리 (워드, 한글)**:
- 공식 문서, 보고서, 계약서 작성
- 양식 만들기와 스타일 적용

---

## 정보 처리 4단계

### 1. 정보 수집

**내부 정보**: 회사 데이터베이스, ERP 시스템, 과거 보고서
**외부 정보**: 공공 통계, 뉴스, 업계 리포트, 경쟁사 정보

**정보의 품질 평가 기준 (ACUFF)**:
- Accuracy (정확성): 오류가 없는가?
- Currency (최신성): 최근 데이터인가?
- Utility (유용성): 의사결정에 도움이 되는가?
- Fullness (완전성): 필요한 정보가 모두 있는가?
- Format (형식): 이해하고 사용하기 쉬운가?

### 2. 정보 분류와 정리

수집한 데이터를 목적에 맞게 구조화합니다.

**스프레드시트 정리 원칙**:
- 하나의 행 = 하나의 레코드
- 하나의 열 = 하나의 속성
- 빈 행·열 없이 연속 데이터
- 헤더(열 제목)는 첫 행에

### 3. 정보 분석

**기술통계 (Descriptive Statistics)**:
- 평균, 중앙값, 최빈값
- 분산, 표준편차
- 최솟값, 최댓값, 범위

**피벗 테이블**: 대량 데이터를 다차원으로 요약. 월별, 지역별, 제품별 분석을 몇 번의 클릭으로 완성.

**데이터 시각화 원칙**:
- 비교: 막대 그래프
- 추이: 꺾은선 그래프
- 비율: 원 그래프 (항목이 5개 이하)
- 분포: 히스토그램, 상자그림

### 4. 정보 활용

분석 결과를 의사결정에 연결합니다.

**데이터 기반 의사결정 vs 직관 기반 의사결정**:
둘 다 필요합니다. 데이터가 방향을 제시하고, 직관과 경험이 맥락을 더합니다.

---

## 정보 보안

직장에서 정보 보안은 의무입니다.

**기본 보안 수칙**:
- 강력한 비밀번호 사용 (8자 이상, 특수문자 포함)
- 개인 USB 회사 컴퓨터에 사용 금지
- 회사 기밀 문서 외부 유출 금지
- 의심스러운 이메일 링크·첨부 파일 클릭 금지 (피싱 주의)
- 공용 와이파이에서 회사 시스템 접속 주의

**개인정보 보호**:
- 수집·처리·저장의 최소화 원칙
- 목적 이외 사용 금지
- 보존 기간 이후 파기

## 기술능력이란

**NCS 기술능력**은 업무에 필요한 기술을 이해하고 선택하여 적용하는 능력입니다.

**3가지 하위 능력**:
1. **기술이해능력**: 업무에 쓰이는 기기·도구·매뉴얼을 이해
2. **기술선택능력**: 목적에 맞는 최적 기술 선택
3. **기술적용능력**: 선택한 기술을 효율적으로 활용

---

## 기술 변화와 적응

### 기술 수용 주기 (Technology Adoption Curve)

에버렛 로저스(Everett Rogers)의 혁신 확산 이론:

| 그룹 | 비율 | 특징 |
|------|------|------|
| 혁신자 (Innovators) | 2.5% | 새 기술 먼저 시도, 위험 감수 |
| 조기 수용자 (Early Adopters) | 13.5% | 영향력 높음, 오피니언 리더 |
| 조기 다수 (Early Majority) | 34% | 실용적, 검증 후 수용 |
| 후기 다수 (Late Majority) | 34% | 보수적, 주류가 된 후 수용 |
| 지각 수용자 (Laggards) | 16% | 최후 수용자, 변화 저항 |

직장인에게 중요한 것: 새 기술을 너무 빨리 수용하면 안정성 위험, 너무 늦으면 경쟁력 하락. 조기 다수~조기 수용자 위치가 일반적으로 유리합니다.

### 기술 변화 적응 전략

1. **학습 민첩성(Learning Agility)**: 빠르게 배우고 적용하는 능력
2. **전이 학습(Transfer Learning)**: 기존 기술 지식을 새 기술에 적용
3. **사용자 중심 접근**: "왜 쓰는가"를 먼저 이해하고 "어떻게 쓰는가"를 습득

## 매뉴얼 읽기와 적용

NCS 기술능력에서 자주 나오는 유형: **업무 매뉴얼을 보고 절차를 이해·적용**

**매뉴얼 읽기 원칙**:
1. 목차에서 전체 구조 파악
2. 핵심 용어 정의 확인
3. 주의 사항·경고 먼저 확인
4. 단계별 절차를 순서대로 따르기
5. 결과 확인 기준 숙지

**시험 유형**: 매뉴얼에 나온 순서를 올바르게 나열하거나, 특정 상황에서 적용해야 할 절차를 선택하는 문제

---

## NCS 시험 정보·기술 문제 유형

**컴퓨터 활용형**: 엑셀 함수, 파워포인트 기능에 대한 지식 확인

**정보 처리형**: 주어진 데이터·표를 분석하여 결론 도출

**기술 적용형**: 매뉴얼이나 절차서를 읽고 올바른 순서·방법 선택

**보안·저작권형**: 개인정보 보호, 소프트웨어 저작권, 보안 수칙 이해
