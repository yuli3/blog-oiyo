## 공동소송

```
공동소송:
원고 또는 피고가 여러 명인 소송

통상 공동소송:
각 당사자가 독립적
→ 1인의 행위·결과가 다른 공동소송인에게 영향 없음

필수 공동소송:
합일 확정이 필요한 경우
→ 1인의 행위가 전원에게 효력
예: 회사 설립 무효 소송

공동소송 이유:
소송 경제 (한 번에 해결)
모순 판결 방지
```

---

## 제3자 소송참가

```
소송참가:
소송 진행 중 제3자가 소송에 참여

보조참가:
소송 당사자 일방을 보조하기 위해 참가
참가 이익 필요
→ 보조자 독자적 행위 가능 (당사자 의사 반하지 않는 범위)

독립당사자참가:
제3자가 독립적으로 청구를 가지고 참가
→ 3당사자 소송
예: 부동산 소유권 다툼에 제3자 참가

공동소송참가:
기존 소송의 공동소송인이 됨
```

## 선정당사자

```
선정당사자:
공동 이해관계 있는 다수가 그 중 1인을 선정
선정된 1인이 전체를 대리

요건:
공동 이해관계 있는 다수
선정서로 선정

효력:
선정당사자의 판결 = 전원에게 효력

현대 집단 소송:
증권 집단소송: 증권 피해자 집단 구제
소비자 소송: 소비자단체소송

예: 아파트 입주민 전원을 위한 선정당사자 1인 소송
```

## 소송대리

```
소송대리인:
당사자를 대리해 소송 행위 하는 자

변호사 강제주의:
고등법원·대법원: 변호사만 대리 가능

임의대리:
당사자가 선임한 대리인 (변호사 등)

법정대리:
미성년자·제한능력자의 법정대리인

복대리:
대리인이 다시 대리인 선임
→ 소송대리에서 원칙적 불가

무권대리:
대리권 없는 자의 소송 행위
→ 추인 없으면 무효
```

## 핵심 개념 카드

**통상 vs 필수 공동소송** ★★★★★
: 통상=독립, 필수=합일확정 필요(전원에게 효력).
*암기 포인트: 필수=반드시 같은 결론*

**보조참가 vs 독립당사자참가** ★★★★★
: 보조=일방 도움. 독립=자기 청구 가지고 참가.
*암기 포인트: 독립참가=자기청구 있음*

**선정당사자** ★★★★☆
: 공동이해 다수 → 1인 선정 → 전체 대표.
*암기 포인트: 선정=대표1인*

## 실전 퀴즈

**Q. 필수 공동소송에서 1인의 행위가 전원에게 효력인 이유는?**
> 합일 확정이 필요한 소송은 공동소송인 전원에 대해 동일한 결론이 나야 함. 1인이 불리한 행위를 해도 다른 공동소송인에게 불이익 주는 것 방지. 예: 이혼 소송 당사자가 포기해도 다른 관련 당사자 보호.

**Q. 보조참가인이 독립적으로 상소할 수 있는 이유는?**
> 보조참가인은 독립적 이익 있어 참가. 당사자가 상소 포기해도 보조참가인은 독자적으로 상소 가능. 단, 당사자의 의사에 명백히 반하는 행위는 불가.
