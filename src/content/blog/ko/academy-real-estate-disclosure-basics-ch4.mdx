## 지적 제도의 의의

```
지적 (地籍):
토지의 물리적·법률적 현황을 공적으로 등록·관리하는 제도

공간정보관리법 (구 지적법):
지적 제도를 규정한 법률

지적 공부:
국가가 토지 현황을 등록한 공적 장부

종류:
토지대장, 임야대장
지적도, 임야도
경계점좌표등록부
대지권등록부

지적 소관청:
시장·군수·구청장
(국토교통부장관 위임)
```

---

## 토지의 등록

```
지번:
각 토지에 붙이는 번호
특정 토지 식별

지목:
토지의 주된 사용 목적
28개 지목 (전·답·과수원·목장용지·임야·광천지·염전·대·공장용지 등)

주요 지목:
전 (田): 밭
답 (畓): 논
대 (垈): 건물 부지

면적:
토지의 수평 면적
㎡ 단위

경계:
토지와 토지를 구분하는 선
경계 분쟁 → 경계 복원 측량
```

---

## 지적 공부

```
토지대장:
도시 지역 토지 등록
소재·지번·지목·면적·소유자 정보

임야대장:
임야 지역 토지 등록
산림 토지

지적도:
토지대장 토지를 도면으로 표시

임야도:
임야대장 토지를 도면으로 표시

수치지형도:
디지털 방식의 지형 정보

지적 공부 열람·발급:
시·군·구청 또는 인터넷 열람
누구든지 열람 가능 (수수료)
```

---

## 지적 측량

```
지적 측량:
토지의 경계·면적을 측정하는 기술

한국국토정보공사 (LX):
지적 측량 업무 담당 기관

지적 측량 종류:
경계 복원 측량: 경계 분쟁 시 원래 경계 복원
분할 측량: 토지 분할 전 경계 측정
현황 측량: 현재 경계 확인

토지 분할·합병:
분할: 1필지를 2필지 이상으로
합병: 여러 필지를 1필지로 합침

지목 변경:
용도 변경 신청 → 소관청 확인 → 지목 변경
```

## 핵심 개념 카드

**지목 28개 중 대표** ★★★★★
: 전(밭)·답(논)·대(건물부지)·임야·공장용지·도로.
*암기 포인트: 전답대임공도*

**지적 소관청** ★★★★★
: 시장·군수·구청장. (국토교통부 위임)
*암기 포인트: 지적=시군구청장*

**토지대장 vs 임야대장** ★★★★☆
: 토지대장=도시토지. 임야대장=산림.
*암기 포인트: 토지=도시, 임야=산림*

## 실전 퀴즈

**Q. 지목과 현실 이용 상황이 다를 때 법적 효과는?**
> 지목은 주된 사용 목적을 공시하는 것. 실제 이용과 달라도 지목 자체가 위법은 아님. 단, 용도 변경 후 지목 변경 신청 의무. 세금(재산세 등)은 실제 이용 현황 기준으로 부과 가능.

**Q. 경계 분쟁이 발생했을 때 해결 방법은?**
> 1. 경계 복원 측량(LX 의뢰)으로 원래 경계 확인. 2. 합의 불성립 시 민사소송으로 경계 확정. 경계 확정 소는 확인의 소로, 양쪽 모두 소유권 주장 시 경계 확정 소송 활용.
