## 한부모가족이란?

모 또는 부 한 명이 18세 미만 자녀를 혼자 양육하는 가족을 말합니다. 이혼·사별·미혼 출산 등 모든 경우 해당됩니다.

---

## 지원 자격

```
기본 요건:
- 한부모 (모 or 부) + 18세 미만 자녀
- 취학 중인 경우 22세 미만까지 연장
- 기준 중위소득 63% 이하 (2024년 기준)

소득 기준 (2024년):
- 2인 가구: 월 2,342,179원 이하
- 3인 가구: 월 2,991,384원 이하
- 4인 가구: 월 3,638,826원 이하
```

---

## 아동양육비

### 일반 아동양육비

```
기준 중위소득 63% 이하:
자녀 1명당 월 21만원

→ 자녀 2명이면 월 42만원
→ 만 18세 미만 (취학 시 22세) 까지 지급
```

### 추가 아동양육비

```
조손 가정 (조부모가 손자녀 양육):
- 5세 이하: 자녀 1명당 월 5만원 추가

미혼 한부모 (만 25세 이상):
- 5세 이하 영아: 자녀 1명당 월 10만원 추가
```

## 청소년 한부모 특례 (만 24세 이하)

```
만 24세 이하 한부모:

아동양육비: 월 35만원 (일반 21만원보다 많음)
검정고시 학습비 지원: 연 154만원
자립촉진수당: 월 10만원 (학업·취업 조건)

→ 10대·20대 초반 미혼부모에게 집중 지원
```

## 의료비·건강 혜택

```
의료급여 특례:
- 기준 충족 시 의료급여 2종 적용 가능
- 병원비 본인 부담 대폭 감소

건강보험료 경감:
- 한부모 가족으로 인정 시 건강보험료 일부 경감
```

---

## 주거 지원

### 공공임대주택 우선 공급

```
LH 국민임대, 행복주택 등에서 한부모 가족 우선 공급 물량:
→ 일반 공급보다 낮은 소득 기준으로 신청 가능
→ 순위제에서 한부모 가족 가산점 부여

임대주택 입주 후:
→ 자녀가 성장해도 일정 기간 거주 안정 보장
```

### 주거급여

```
소득 기준 충족 시 주거급여도 중복 수급 가능
→ 임차급여(월세 지원) + 아동양육비 동시 수령
```

## 교육 지원

```
교육비 지원:
- 유치원·초·중·고 교육비 및 급식비 지원
- 방과후 학교 교재비 지원

자녀 교육 지원:
→ 대학교 한부모 자녀 장학금 (대학별 상이)
→ 드림스타트 사업 연계 (아동 발달 지원)
```

## 자립 지원

```
취업 지원:
- 한부모 특화 취업 상담 (새일센터, 고용센터)
- 직업 훈련비 지원 (국민내일배움카드 연계)

창업 지원:
- 한부모 소규모 창업 지원 프로그램 (지자체별)

양육비 이행 지원:
- 이행관리원에서 비양육 부모로부터 양육비 청구 대행
- 양육비 불이행 시 법적 조치 지원
→ 양육비이행관리원: 1644-6621
```

## 미혼부 지원

```
미혼부도 동일한 한부모 지원 대상:
→ 출생 신고 + 인지 신고 후 신청 가능
→ 생부 인지 없이는 출생신고 어려울 수 있으므로
   법원에서 '인지 심판' 청구 가능 (무료 법률 지원)
```

---

## 신청 방법

```
신청 장소:
- 거주지 읍·면·동 주민센터
- 복지로 홈페이지 (www.bokjiro.go.kr) 온라인 신청

필요 서류:
- 신분증
- 가족관계증명서 (자녀와의 관계 확인)
- 주민등록등본
- 소득 증빙 서류
- 통장 사본
- (이혼) 이혼증명서 또는 이혼 판결문
```

## 지원 전담 기관

```
한부모가족복지시설:
→ 거주 + 생활 지원 (임시 거처 필요 시)

건강가정지원센터:
→ 심리 상담, 자녀 돌봄 지원

양육비이행관리원:
→ 비양육 부모로부터 양육비 청구 지원
```

## 자주 묻는 질문

**Q. 이혼하지 않고 사실상 별거 중인데 해당되나요?**
A. 한부모 지원은 법적 이혼·사별뿐 아니라 실질적으로 혼자 자녀를 양육하는 경우에도 인정될 수 있습니다. 주민센터에서 상황을 설명하고 상담받으시기 바랍니다.

**Q. 양육비를 받고 있어도 한부모 지원이 되나요?**
A. 양육비를 받더라도 다른 소득과 합산한 소득인정액이 기준 이하면 지원받을 수 있습니다.

**Q. 부모님과 함께 살면 한부모 혜택을 못 받나요?**
A. 조부모와 동거하더라도 경우에 따라 한부모로 인정될 수 있습니다. 세대 구성과 실제 양육 주체에 따라 판단이 달라질 수 있으니 주민센터에 문의하세요.

**Q. 자녀가 18세가 넘으면 갑자기 지원이 끊기나요?**
A. 고등학교 재학 중이면 22세 미만까지 연장됩니다. 대학 진학 후 지원 연장은 별도로 확인이 필요합니다.
