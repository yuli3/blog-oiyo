## 탁구, 11점제와 서브만 알면 된다

탁구는 빠르지만 규칙은 간단하다. 11점 체계와 서브 규정만 익히면 충분하다.

---

## 점수 — 11점 게임

```
게임: 11점 먼저(2점 차)로 획득.
매치: 보통 5판 3선승 또는 7판 4선승.
듀스: 10-10이면 2점 차가 날 때까지(12-10 등).
서브: 2점마다 서브권 교대(듀스부터는 1점마다 교대).
```

---

## 서브 규칙

```
- 손바닥을 펴고 공을 거의 수직으로 16cm 이상 토스
- 손은 테이블 면 위, 엔드라인 뒤에서 서브
- 공을 가리지 않는 '오픈 서브'(상대가 볼 수 있게)
- 자기 코트에 한 번 → 네트 넘어 상대 코트에 바운드
- 서브가 네트에 닿고 정상적으로 넘어가면 '렛'(다시 서브)
```

---

## 랠리 규칙

```
- 공은 자기 코트에 바운드 후 받지 않음(노바운드 직접 리턴)
  → 반드시 네트 넘겨 상대 코트에 한 번 바운드시키기
- 공이 테이블 모서리(엣지)에 맞으면 '인'
- 공이 네트에 걸려 안 넘어가면 실점
- 프리핸드(공 안 든 손)로 테이블을 건드리면 실점
```

---

## 복식 규칙

```
- 서브는 자기 코트 '오른쪽 절반 → 상대 오른쪽 절반'(대각선)
- 같은 팀이 번갈아 쳐야(A→B→상대A→상대B 순서)
- 순서 어기면 실점
```

---

## 핵심 요약

1. 11점(2점 차) 게임, 보통 5판 3선승.
2. 서브권은 2점마다 교대(듀스부턴 1점마다).
3. 서브는 16cm 토스 + 오픈 서브가 필수.
4. 받을 땐 바운드 후 직접 리턴(노바운드), 엣지는 '인'.
5. 복식은 대각선 서브 + 번갈아 타구 순서.

> 세부 규칙은 국제탁구연맹(ITTF) 규정을 기준으로 한다.
