## T계정이란

T계정(T-Account)은 계정과목별로 차변(왼쪽)과 대변(오른쪽)을 분리하여 기록하는 장부 양식입니다. 알파벳 T 모양을 닮아 T계정이라 부릅니다.

```
         [계정과목]
   차변(Dr) | 대변(Cr)
  __________|__________
            |
```

## 복식부기와 T계정의 역할

모든 거래는 최소 두 개의 T계정에 기록됩니다. 예를 들어 현금 100만원으로 재고를 구매하면:

- **현금 계정**: 대변에 100만원 (자산 감소)
- **재고자산 계정**: 차변에 100만원 (자산 증가)

이처럼 한 거래가 두 계정에 동시에 기록되면서 **차변 합계 = 대변 합계**가 항상 유지됩니다.

## 회계등식: 자산 = 부채 + 자본

T계정으로 다음 회계등식이 항상 성립함을 확인할 수 있습니다:

<Callout type="info">
**자산 = 부채 + 자본**
이 등식이 무너지면 분개나 전기 과정에 오류가 있다는 신호입니다.
</Callout>

### 계정 유형별 잔액 방향

| 계정 유형 | 정상 잔액 방향 |
|-----------|--------------|
| 자산 | 차변 (Dr) |
| 비용 | 차변 (Dr) |
| 부채 | 대변 (Cr) |
| 자본 | 대변 (Cr) |
| 수익 | 대변 (Cr) |

## 잔액시산표(Trial Balance)의 의미

잔액시산표는 특정 시점에 모든 T계정의 잔액을 차변과 대변으로 나열한 표입니다.

- **목적**: 분개 전기 과정의 산술적 오류를 검증
- **한계**: 계정 선택 오류, 누락된 분개 등은 검출하지 못함

잔액시산표에서 **차변 합계 = 대변 합계**이면 산술적 오류가 없다는 의미이지만, 회계 처리가 완전히 정확하다는 보장은 아닙니다.

<Callout type="warning">
잔액시산표가 균형을 이루더라도 계정 분류 오류(예: 매입채무를 매출채권으로 기록)는 감지할 수 없습니다.
</Callout>
