## 실용신안법

```
실용신안:
물품의 형상·구조·조합에 관한 고안
특허보다 낮은 수준의 기술적 창작

실용신안 vs 특허 차이:
실용신안: 물품 한정, 10년 존속
특허: 방법·물질·장치 포함, 20년 존속

무심사 등록 주의:
형식 심사 후 등록 (실체심사 없음)
등록 후 이의·무효 심판으로 쟁점

선원주의:
특허와 같은 선원주의 적용
이중 출원 금지 (특허+실용신안)
```

## PCT 국제출원

```
PCT (Patent Cooperation Treaty):
하나의 출원으로 다수 국가 동시 출원 효과

절차:
PCT 출원 → 국제 조사 보고서 → 국내 단계 진입

국내 단계 진입:
각 지정국에 번역문·수수료 제출
통상 출원 후 30개월 이내

장점:
비용·시간 절약
국내 단계 전까지 해외 특허 여부 결정 유예

파리조약 우선권:
최초 출원일로부터 12개월 이내 후속 출원 시
최초 출원일을 우선일로 인정
```

## 저작권과의 비교

```
저작권:
등록 불요, 창작과 동시에 발생
저작자 생존+70년 보호
창작의 표현 보호 (아이디어 불보호)

특허:
등록 필수
기술적 아이디어 보호

상표:
등록 필수, 갱신으로 영구 보호

관계:
소프트웨어: 저작권+특허(알고리즘) 중첩 가능
디자인: 미술저작권+디자인특허 중첩 가능
```

## 핵심 개념 카드

**실용신안=10년, 특허=20년** ★★★★★
: 대상·기간 구별 중요.
*암기 포인트: 실용=10년, 특허=20년*

**PCT=하나로 다수국 출원** ★★★★★
: 국제 단계 후 각국 국내 단계 진입.
*암기 포인트: PCT=하나→다수국*

**파리조약 우선권=12개월** ★★★★☆
: 최초 출원 후 12개월 내 후속 출원.
*암기 포인트: 파리=12개월*

## 실전 퀴즈

**Q. PCT 출원에서 국내 단계 진입 기한을 놓치면?**
> 통상 우선일로부터 30개월(국가마다 상이). 기한 내 각국 특허청에 번역문·수수료 미제출 → 해당국 특허권 포기. 기한 연장 제도 있는 국가도 있음. 변리사의 역할: 각국 현지 대리인 네트워크 관리, 기한 관리가 핵심.

**Q. 실용신안 무심사 등록의 위험은?**
> 등록은 쉽지만 실체 심사 없으므로 권리 불안정. 등록 후 이의신청·무효심판으로 취소 가능. 침해 소송 시 무효 항변 빈번. 전략적으로 특허 심사 대기 중 임시 보호 목적으로 활용. 권리 확보 후 특허 출원으로 승화 고려.
