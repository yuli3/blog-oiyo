## 민사소송 절차

```
소장 제출:
당사자·청구취지·청구원인
첨부서류·인지 납부

변론:
변론주의: 당사자가 주장·증거 제출
처분권주의: 소의 개시·범위·종결 당사자 결정

증거:
서증·인증·감정·검증
증명책임: 권리 발생 주장자

판결:
인용·기각·각하
기판력: 주문에만 발생

상소:
항소: 2주 내 (사실+법률심)
상고: 2주 내 (법률심만)
```

## 강제집행

```
집행권원:
확정판결·화해조서·인낙조서
공정증서 (집행인락)
집행문 부여 후 집행

부동산 경매:
임의경매: 담보권 실행
강제경매: 집행권원 기반
낙찰 → 배당 → 소유권 이전

동산 집행:
집행관이 현장 압류
금전채권 추심·전부 명령

가압류·가처분:
보전처분
가압류=금전채권, 가처분=비금전
```

## 비송사건

```
비송사건 특징:
소송 아닌 법원의 후견적 관여
당사자 대립 없음
법원의 후견적 처분

주요 비송사건:
법인 등기 관련 사건
상속 포기·한정승인 신고
실종 선고
후견 관련 사건

가사사건:
가정법원 관할
이혼·친권·상속 분쟁
```

## 공탁

```
공탁 목적:
변제공탁: 채권자 수령 거부 시
담보공탁: 소송·가처분 담보
집행공탁: 배당 보류

변제공탁 효과:
채무 소멸
공탁물 보관 = 법무부 산하 공탁소

법무사의 공탁 업무:
공탁 신청서 작성·제출 대리
출급·회수 대리
```

## 실전 퀴즈

**Q. 변제공탁이 인정되려면 어떤 요건이 필요한가?**
> 채권자가 수령을 거부하거나 수령 불능 또는 채권자가 누구인지 불명확. 공탁소(법원)에 채무 이행. 공탁 후 채무 소멸. 채권자는 공탁물 출급 청구. 채무자는 회수 가능한 경우 회수권 있음 (채권자 공탁물 수령 전).

**Q. 법무사가 변호사 없이 처리할 수 있는 법원 업무 범위는?**
> 법무사 가능: 소장 작성 및 제출 보조, 공탁, 강제집행 신청 대리, 비송사건 신청, 등기 신청. 불가: 소송 대리 (변론 등 법정 출석). 단독 소장 작성 후 의뢰인이 직접 제출하는 형태. 실무에서 비송·등기·공탁이 법무사 주요 수입원.
