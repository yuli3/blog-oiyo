## 1. 인사관리 전체 프레임

```
인력 계획:
수요·공급 예측 → 과부족 대응

확보:
모집(내부·외부) → 선발(타당성·신뢰성)

개발:
OJT·Off-JT → Kirkpatrick 4단계 평가

활용:
직무분석·설계·배치·경력 개발

유지:
보상·복리후생·동기부여·리더십

방출:
퇴직관리·아웃플레이스먼트
```

## 3. 핵심 수치·원칙 총정리

```
Kirkpatrick = 반학행결 4단계
직무평가 가장 정확 = 점수법
360도 평가 = 개발 목적 적합
타당성 = 신뢰성의 충분조건
변동비율 강화 = 가장 강력
Lewin 변화 = 해빙·변화·재동결
단체협약 최장 = 2년
```

## 4. 빈출 오답 10선

```
① HRM = 확개활유방 (5기능)
② 직무충실화=수직, 직무확대=수평
③ Herzberg 급여=위생요인 (동기요인 아님)
④ Maslow=생안사존자 (안전→사회 순서)
⑤ 타당성은 신뢰성이 있어야 의미 있음
⑥ 후광효과=하나 특성이 전체에 영향
⑦ Vroom=기×수×유 (하나라도 0=동기0)
⑧ 강화이론 변동비율=가장 강력
⑨ 360도 평가=개발 목적 (보상 연계 시 왜곡)
⑩ 구조화 면접=신뢰성·타당성 높음
```

## 6. 실전 퀴즈 (종합)

**Q. 인사관리에서 내부 공정성과 외부 공정성이 충돌할 때 어떻게 해야 하는가?**
> 내부 공정성: 같은 회사 내 직무 간 임금 형평. 외부 공정성: 시장 임금 수준 대비. 충돌: 시장에서 특정 직군(예: IT) 임금 급등 → 내부 형평성 깨짐. 대응: 시장 프리미엄 지급(외부 우선), 단 내부 불만 관리. 또는 직군별 별도 임금 구조 운영. 완전 해결 어려움 → 투명한 소통 필요.

**Q. HR 부서가 전략적 파트너로 인정받으려면 어떤 역할을 해야 하는가?**
> 사업 전략 이해: 사업부 회의 참여·전략 파악. 데이터 기반: 이직률·채용 효율·교육 ROI 수치화. 문제 해결: HR 문제 아닌 사업 문제 해결. 선행 지표: 성과 예측 지표 제시. 변화 관리: 조직 변화 실행 지원. Ulrich 모델: 전략 파트너+변화 촉진자 역할 강조.
