## 약식 절차

```
약식 명령:
경미 범죄 → 서면 심리로 벌금형 선고
공판 절차 없이 처리

대상:
지방법원 관할 사건
벌금·과료 선고 가능한 사건

절차:
검사 약식명령 청구
판사 서면 심리 → 약식명령 발령

이의 신청:
피고인 or 검사 정식재판 청구 가능
청구 기간: 약식명령 고지 후 7일 이내
```

---

## 즉결심판

```
즉결심판:
20만원 이하 벌금·구류·과료
경찰관이 청구, 판사가 판결

대상:
경범죄 (무질서 행위 등)
주취 소란·경범죄처벌법

불복:
정식재판 청구 가능 (7일 이내)

특징:
경찰이 직접 청구 (검사 기소 불요)
매우 빠른 처리
```

## 국민참여재판

```
국민참여재판:
배심원이 유·무죄 평결에 참여
피고인 신청 시 진행

배심원:
9명 (사형·무기 사건), 7명 (기타)
무작위 선정, 일반 국민

평결:
만장일치 권고, 다수결 가능
법원은 평결에 기속 안됨 (권고적)

대상 제외:
성폭력·아동학대 등 피해자 보호 필요 사건
피고인이 신청하지 않은 사건
```

## 소년 사건

```
소년법 적용:
19세 미만 소년
보호처분 우선 (형벌보다 교화)

촉법소년:
10세~14세 미만: 형사 처벌 불가 → 보호처분
범죄소년: 14세 이상 → 형사처벌 가능

심판 기관:
소년부 판사 (가정법원·지방법원)
검사 = 소년부 송치

비밀 보장:
소년 사건 기록 비공개
재범 방지·사회 복귀 목적
```

## 핵심 개념 카드

**약식명령=7일이내정식재판청구** ★★★★★
: 약식명령 불복 시 7일 내 정식재판 청구.
*암기 포인트: 약식명령=7일정식청구*

**국민참여재판=권고적평결** ★★★★★
: 배심원 평결은 법원을 구속하지 않음.
*암기 포인트: 배심원=권고적*

**촉법소년=14세미만형사불가** ★★★★☆
: 14세 미만은 형사 처벌 대신 보호처분.
*암기 포인트: 촉법소년=14세미만*

## 실전 퀴즈

**Q. 국민참여재판에서 배심원 평결이 법원과 다를 경우 어떻게 처리되는가?**
> 배심원 평결은 권고적 효력만. 법원은 평결과 다른 판결 가능. 단 다른 판결 시 이유 명시 의무. 실무: 법원이 평결 존중하는 경향. 미국 배심제와 차이: 미국은 구속력, 한국은 권고. 도입 취지: 사법 민주화, 시민 참여. 피고인 신청 = 피고인이 배심원을 선호하는 경우.

**Q. 약식 절차와 정식재판의 주요 차이는?**
> 약식: 서면 심리, 공판 없음, 벌금만 선고 가능. 정식재판: 공판 심리, 징역형도 가능. 약식 불복 = 7일 내 정식재판 청구 → 정식 절차로 전환. 불이익변경금지: 피고인만 정식재판 청구 시 더 중한 형 불가. 약식명령 확정 = 기판력 발생 (일사부재리 적용).
