## 보험 모집 규제

```
보험모집 자격:
보험설계사: 등록 후 모집 가능
보험대리점: 회사 형태
법인보험대리점 (GA): 대형 대리점

불법 모집 금지:
무자격자 모집
허위·과장 광고
특별 이익 제공 금지 (리베이트)

설명의무:
주요 계약 내용 설명 의무
서명·녹취 증거 보관
```

## 보험설계사 의무

```
적합성 원칙:
고객 니즈·재정 상황 파악
적합한 상품 추천

설명의무:
보험료·보장 내용·면책 사항
해지환급금·예상 수익률

부당행위 금지:
허위 설명
타 보험 부당 비교
불필요한 계약 전환 (승환)

청약 철회:
계약자: 청약일로부터 15일 (통신판매 30일)
보험증권 받은 날로부터 15일
```

## 보험 감독 체계

```
금융감독원:
보험사 경영·감독
약관 심사
소비자 보호

보험료 신고제:
보험료 사전 신고 (금융감독원)
과도한 보험료 방지

지급여력비율 (RBC):
보험사 건전성 지표
최소 100% 이상 유지 권고
부실 보험사 조기 경고

예금자보호법:
1인당 최대 5000만원 보호
(생명·손해보험 적용)
```

## 핵심 개념 카드

**청약철회=15일(통신30일)** ★★★★★
: 청약 후 15일 이내 철회 가능 (통신판매 30일).
*암기 포인트: 청약철회=15일*

**리베이트금지=특별이익제공금지** ★★★★★
: 보험 계약 유치 목적 금품 제공 금지.
*암기 포인트: 리베이트=금지*

**RBC=100%이상** ★★★★☆
: 지급여력비율 100% 이상 유지 권고.
*암기 포인트: RBC=100%*

## 실전 퀴즈

**Q. 보험 청약 철회 제도의 취지와 한계는?**
> 취지: 소비자 충동 계약 보호. 복잡한 보험 내용 숙고 시간 부여. 한계: 15일로 짧음 (장기 계약 내용 이해에 부족). 장기 계약: 해지환급금 손실이 더 큰 문제. 통신판매 30일: 대면 없는 가입의 불확실성 추가 보호. 실무: 계약 후 설계사 부당 권유 발견 시 즉시 철회 행사.

**Q. 불완전판매와 설계사의 법적 책임은?**
> 불완전판매: 설명 의무 위반, 허위 설명, 부당 권유. 책임: 설계사 개인 손해배상 책임. 보험회사 연대 책임 (사용자 책임). 제재: 자격 정지·취소. 소비자 구제: 금감원 분쟁 조정, 손해배상 청구. 핵심 사례: 원금 보장 허위 설명, 수익률 과장, 면책 조항 미설명.
