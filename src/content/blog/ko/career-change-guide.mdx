직업은 인생에서 가장 많은 시간을 보내는 곳입니다. 맞지 않는 직업에서 보내는 시간은 단순한 불행을 넘어 건강, 관계, 정체성에 영향을 미칩니다. 그러나 이직은 쉽지 않습니다. 두려움, 불확실성, 정보 부족이 많은 사람들을 제자리에 머물게 합니다. 이 가이드는 이직을 성공적으로 이끄는 완전한 로드맵입니다.

## 이직을 결심해야 할 때

### 이직의 긍정적 신호

- 현재 역할에서 더 이상 성장이 없다
- 급여가 시장가치보다 현저히 낮다
- 회사의 방향성과 가치관이 맞지 않는다
- 관리자와의 갈등이 해결되지 않는다
- 더 나은 기회가 명확히 있다

### 이직을 재고해야 할 신호

- 단순히 현재 직장이 힘들어서 (모든 직장에는 어려움이 있음)
- 외부 요인(동료, 프로젝트)이 곧 변할 예정
- 충분한 준비 없이 감정적으로 결정

<Callout type="info">
**이직 vs 직장 내 해결**: 문제가 명확히 그 회사의 구조적 문제라면 이직이 맞습니다. 하지만 소통 문제, 일시적 스트레스라면 먼저 내부에서 해결을 시도해보세요.
</Callout>

## 이직 전 자기 분석

### 강점 목록 작성

1. 지난 3~5년간 가장 자랑스러운 성취 5가지
2. 다른 사람들이 나에게 조언을 구하는 영역
3. 시간 가는 줄 모르고 하는 일
4. 힘들어도 하고 싶은 일

### 가치관 명확화

| 가치관 | 중요도 (1~5) | 현재 직장 충족 여부 |
|--------|------------|----------------|
| 일과 삶의 균형 | | |
| 성장 기회 | | |
| 급여 수준 | | |
| 사회적 영향 | | |
| 창의성 발휘 | | |
| 안정성 | | |

### 이상적인 직업 프로필

- 원하는 업무 유형
- 원하는 팀 문화
- 원하는 근무 방식 (원격, 하이브리드, 오피스)
- 목표 업종/직무
- 목표 연봉 범위

## 이직 준비 체크리스트

### 6개월 전

- [ ] 이직 목표 및 이유 명확화
- [ ] 목표 직군/회사 리스트 작성 (20~30개)
- [ ] 부족한 스킬 파악 및 학습 시작
- [ ] [링크드인](https://www.linkedin.com/) 프로필 최적화
- [ ] 네트워크 활성화 시작

### 3개월 전

- [ ] 이력서 최신화 (성과 중심으로)
- [ ] 포트폴리오 준비 (해당되는 경우)
- [ ] 참조인(레퍼런스) 확보
- [ ] 목표 회사 정보 수집

### 1개월 전

- [ ] 지원서 작성 및 제출 시작
- [ ] 면접 준비 (STAR 기법, 모의 면접)
- [ ] 연봉 협상 전략 수립

## 이력서 작성법

### ATS (지원자 추적 시스템) 통과하기

대부분의 대기업은 ATS를 사용하여 키워드로 이력서를 필터링합니다.

**ATS 통과 전략**:
- 채용공고의 핵심 키워드를 이력서에 포함
- 심플한 포맷 (표, 그래픽 최소화)
- PDF보다 Word 형식 선호 (ATS마다 다름)

### 성과 중심 작성

**나쁜 예시**: "고객 서비스 담당"
**좋은 예시**: "월 1,000건 문의 처리, 고객 만족도 92% 달성, 대응 시간 48시간에서 24시간으로 단축"

**수치화 공식**: [행동] + [방법] + [결과] + [수치]

### 이력서 1페이지 vs 2페이지

- 5년 미만 경력: 1페이지
- 5~10년 경력: 1~2페이지
- 10년 이상: 2페이지

## 면접 전략

### STAR 기법

경험 기반 질문에 답하는 구조:
- **S**ituation: 상황 설명
- **T**ask: 맡은 역할/과제
- **A**ction: 구체적 행동
- **R**esult: 결과 (수치 포함)

### 자주 나오는 면접 질문 준비

| 질문 | 핵심 포인트 |
|------|-----------|
| "자기소개를 해주세요" | 지원직무와 연결된 커리어 스토리 |
| "이직 이유는?" | 긍정적으로 (새로운 도전), 전 직장 비판 금지 |
| "가장 큰 단점은?" | 실제 단점 + 개선 중인 노력 |
| "5년 후 목표는?" | 직무와 연결된 구체적 성장 목표 |
| "연봉은 얼마를 원하세요?" | 시장 조사 기반 합리적 범위 제시 |

### 역면접 (당신도 회사를 면접하세요)

- "이 포지션에서 성공의 기준은 무엇인가요?"
- "팀 문화를 한 단어로 설명한다면?"
- "지금 이 역할에서 가장 큰 도전은 무엇인가요?"
- "이 포지션이 왜 지금 공석이 됐나요?"

## 연봉 협상

### 시장 조사 방법

- [잡플래닛](https://www.jobplanet.co.kr/), 크레딧잡, [인크루트](https://www.incruit.com/): 기업별 연봉 정보
- [사람인](https://www.saramin.co.kr/), [잡코리아](https://www.jobkorea.co.kr/), [캐치](https://www.catch.co.kr/)
- [링크드인](https://www.linkedin.com/) 급여 가이드
- 전체 목록: [한국 취업 사이트 가이드](/ko/job-search-korea-guide/)
- 동종 업계 네트워크에 물어보기

### 협상 전략

**1. 먼저 말하지 마세요**
"제 기대 연봉을 먼저 말씀해주세요"는 앵커를 잘못 설정할 수 있습니다.

**2. 범위 제시**
단일 숫자보다 범위가 더 유연합니다. "XXXX~XXXXX만원을 생각하고 있습니다."

**3. 총 보상 패키지 고려**
기본급 + 성과급 + 스톡옵션 + 복리후생 + 유연근무 + 성장 기회 모두 고려.

**4. 제안을 감사하게 받고 시간 요청**
"감사합니다. 검토 후 답변드려도 될까요?" — 협상의 여지를 줍니다.

## 퇴직 후 공백 관리

**공백 기간을 스트레스 없이 보내는 방법**:
1. 비상금 3~6개월치 사전 준비
2. 공백을 역량 개발 기간으로 활용
3. 이력서에 공백 기간의 활동 기재 (학습, 프로젝트)
4. 심리적 건강 관리: 일정 유지, 운동, 사회적 연결 유지
