## 크립토 시장의 변동성

비트코인은 단 하루에 20% 이상 등락하는 일이 드물지 않습니다. 왜 이렇게 극단적으로 변동할까요?

```
변동성이 극심한 이유:

1. 시장 규모가 작음 (주식 시장의 1~2% 수준)
   → 고래(대형 투자자) 한 명이 시장을 움직일 수 있음

2. 24시간 365일 거래
   → 뉴스·트윗 한 개에도 즉각 반응

3. 레버리지 거래 과다
   → 가격 급락 시 청산 연쇄 반응 (폭포 청산)

4. 규제 불확실성
   → SEC 소송, 국가별 금지 발표에 민감

5. 심리 주도 시장
   → FOMO (놓칠 것 같은 두려움), FUD (공포) 사이클
```

## 거래소 해킹 리스크

### 주요 거래소 해킹 사례

```
마운트곡스 (2014): 85만 BTC 도난, 거래소 파산
비트파이넥스 (2016): 12만 BTC 도난 (약 6,500만 달러)
코인체크 (2018): NEM 5,300억 원 도난
FTX (2022): 해킹+내부 횡령, 350억 달러 손실
```

### 왜 거래소가 위험한가

```
거래소 지갑 = Custodial (수탁형)
→ 내 코인이지만 거래소가 관리
→ 거래소 파산/해킹 → 코인 잃을 수 있음

"Not your keys, not your coins"
개인 키를 갖지 않으면 진짜 소유자가 아님
```

### 안전한 보관: 개인 지갑

```
Hot Wallet (온라인): 메타마스크, 트러스트 월렛
→ 편리하지만 해킹 위험

Cold Wallet (오프라인): 렛저, 트레저 하드웨어 지갑
→ 인터넷 미연결, 가장 안전
→ 단, 분실·파손 시 복구 어려움 (시드 구문 보관 필수)
```

## 사기 유형 백과

### 러그풀 (Rug Pull)

```
방식:
1. 그럴싸한 프로젝트 출시
2. 투자자 돈 모음
3. 개발팀이 유동성 전부 빼고 사라짐

징후:
- 익명 팀
- 감사(Audit) 없음
- 빠른 상장 후 마케팅 과열
- 잠금(Lock) 없는 토큰

유명 사례: 스퀴드게임 토큰 (2021, 하루 만에 99.99% 폭락)
```

### 폰지/피라미드

```
폰지 사기:
새 투자자 돈으로 기존 투자자에게 수익 지급
→ 새 투자자가 줄면 붕괴

크립토 폰지 징후:
- 일일 1~5% 고정 수익 보장
- "스테이킹으로 월 30% 수익"
- 추천인 수수료 과다
```

### 피싱 공격

```
방법:
- 가짜 거래소 사이트 (URL 1글자 다름)
- 메타마스크 팝업 위조
- 디스코드/텔레그램 가짜 운영자
- 에어드롭 명목 시드 구문 요구

규칙: 시드 구문은 절대 아무에게도 공유 금지
```

### 펌프앤덤프

```
방법:
1. 거래량 적은 코인 대량 매수 (가격 상승)
2. SNS·텔레그램으로 "내부 정보" 소문 퍼뜨림
3. 개인 투자자 몰리면 조용히 매도
4. 개인 투자자가 고점에 물림
```

## 리스크 관리 원칙

### 포지션 사이징

```
잃어도 괜찮은 돈만 투자:
- 크립토 비중: 전체 포트폴리오의 5~10% 이내 권장
- 단일 코인에 몰빵 금지
- 레버리지 거래: 초보자 강력 지양
```

### 보안 체크리스트

```
거래소 보안:
☐ 2FA(2단계 인증) 활성화 (앱 인증 권장, SMS 지양)
☐ 출금 주소 화이트리스트 설정
☐ 이메일 비밀번호를 거래소와 다르게

개인 지갑:
☐ 시드 구문(12~24 단어) 오프라인 종이에 보관
☐ 하드웨어 지갑에 거액 보관
☐ 의심스러운 사이트에서 지갑 연결 금지
```

## DeFi 특수 리스크

```
스마트 컨트랙트 버그:
→ 코드 취약점 해킹: 2022년 DeFi 해킹 피해 30억 달러 이상
→ 감사받은 프로토콜도 100% 안전 보장 없음

비영구적 손실 (Impermanent Loss):
→ 유동성 공급 시 코인 가격 변동으로 단순 보유보다 손해 가능

오라클 조작:
→ 가격 데이터를 외부에서 가져올 때 조작 공격
```
