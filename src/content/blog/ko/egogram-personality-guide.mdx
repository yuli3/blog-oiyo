## 에고그램이란?

**에고그램(Egogram)**은 심리학자 에릭 번(Eric Berne)의 **교류분석(TA: Transactional Analysis)** 이론을 기반으로, 존 듀세이(John Dusay)가 개발한 성격 진단 도구입니다. 인간의 성격을 5가지 **자아 상태(ego state)**의 에너지 비율로 표현합니다.

5가지 자아 상태:
- **CP (Critical Parent)**: 비판적 부모 자아 — 원칙, 비판, 책임감
- **NP (Nurturing Parent)**: 양육적 부모 자아 — 배려, 공감, 보살핌
- **A (Adult)**: 성인 자아 — 논리, 분석, 현실 판단
- **FC (Free Child)**: 자유로운 아이 자아 — 창의, 자발성, 감정 표현
- **AC (Adapted Child)**: 순응하는 아이 자아 — 복종, 눈치, 자기억제

## 2. 대표적인 에고그램 패턴

### 패턴 1: N형 (양 끝이 높음)

```
CP ▓▓▓▓▓▓▓▓  높음
NP ▓▓▓▓▓     보통
A  ▓▓▓▓      보통
FC ▓▓▓▓▓     보통
AC ▓▓▓▓▓▓▓▓  높음
```

**특징**: CP와 AC 모두 높음 — 겉으로는 엄격하지만 내면은 불안하고 눈치를 봄. 완벽주의적이면서도 타인의 시선을 지나치게 의식합니다.

---

### 패턴 2: U형 (가운데가 낮음)

```
CP ▓▓▓▓▓▓▓▓  높음
NP ▓▓▓▓      낮음
A  ▓▓▓       낮음
FC ▓▓▓▓      낮음
AC ▓▓▓▓▓▓▓▓  높음
```

**특징**: 비판적이고 복종적이지만 공감·논리·자발성 부족. 억압적인 환경에서 자란 경우 많음.

---

### 패턴 3: M형 (높음-낮음-높음)

```
CP ▓▓▓▓      낮음
NP ▓▓▓▓▓▓▓▓  높음
A  ▓▓▓▓      낮음
FC ▓▓▓▓▓▓▓▓  높음
AC ▓▓▓▓      낮음
```

**특징**: 따뜻하고 활기차며 자유롭지만, 논리·원칙이 약해 감정에 치우칠 수 있음.

---

### 패턴 4: 역N형 (균형 이상형)

```
CP ▓▓▓▓▓     중간
NP ▓▓▓▓▓▓    높음
A  ▓▓▓▓▓▓▓   높음
FC ▓▓▓▓▓▓    높음
AC ▓▓▓        낮음
```

**특징**: NP·A·FC 모두 높고 AC 낮음. 따뜻하고 이성적이며 자발적인 이상적 균형형.

## 4. 자아 상태 균형 조절 전략

<Callout type="tip" title="CP를 낮추고 싶다면">
- 비판 전에 "왜 그랬을까?"라고 먼저 생각하기
- 완벽하지 않아도 괜찮다는 자기 수용 연습
- "~해야 한다" 표현을 "~하면 좋겠다"로 바꾸기
</Callout>

<Callout type="tip" title="AC를 낮추고 싶다면">
- 자신의 감정과 의견을 소리 내어 표현하는 연습
- 작은 것부터 자기 결정 내리기 (메뉴, 시간 선택 등)
- 거절하는 연습: "지금은 어렵다"고 말해보기
</Callout>

<Callout type="tip" title="A를 높이고 싶다면">
- 감정적으로 반응하기 전에 3초 멈추기
- 상황을 데이터와 사실 기반으로 정리하는 습관
- 감정 일기: 느낌 + 사실 + 해석을 분리해서 쓰기
</Callout>
