## Reading: 학술 지문 공략법

### TOEFL Reading의 특성

- **2개 지문** × 약 700단어, 각 10문항
- 주제: 자연과학, 사회과학, 인문학, 역사 등 학술적 내용
- **시간**: 35분 (지문당 약 17분)
- **점수**: 0~30점

---

## Reading 문제 유형 분류

| 유형 | 문항 수 | 전략 |
|------|--------|------|
| Factual Information | 3~4개 | 해당 단락 직접 탐색 |
| Negative Factual (NOT/EXCEPT) | 1개 | 오답 3개 찾기 방식 |
| Vocabulary | 2~3개 | 문맥에서 의미 추론 |
| Reference | 1개 | 대명사·지시어 선행사 찾기 |
| Sentence Simplification | 1개 | 핵심 의미 유지 + 세부사항 제거 |
| Inference | 1~2개 | 명시되지 않은 함의 |
| Rhetorical Purpose | 1개 | 단락 기능/목적 파악 |
| Insert a Sentence | 1개 | 문장 삽입 위치 판단 |
| Summary (산문요약) | 1개 (3점) | 주요 아이디어 3개 선택 |

### 빠른 독해 5단계

1. 제목·소주제 훑기 → 주제 예측
2. 첫 문단 정독 → 핵심 논지 파악
3. 각 단락 첫 문장 속독 → 전체 구조 파악
4. 질문 읽기 → 관련 단락으로 바로 이동
5. 요약 문제는 마지막에 (전체 이해 필요)

---

## Vocabulary 문제 전략

**절대 규칙**: 어휘 의미를 모른다고 포기하지 마세요.

**문맥 추론 4단계**:
1. 해당 문장 전체 읽기
2. 앞뒤 문장 확인 (대조어·동의어 단서)
3. 단어의 어근·접두사·접미사 분석
4. 정의/설명이 같은 문장에 있는지 확인

**빈출 학술 어휘**:
- *subsequent* (이후의), *whereas* (반면에), *attributed to* (~의 결과로), *comprise* (구성하다)

## Listening: 강의 노트테이킹 기법

### TOEFL Listening의 특성

- **강의 3개** (4~5분) + **대화 2개** (2~3분)
- 강의: 대학 수업 스타일의 학술 강의
- 대화: 학사 조언, 도서관, 행정 관련
- **점수**: 0~30점

---

## 노트테이킹 시스템

효율적인 노트는 모든 것을 적는 것이 아닙니다. **핵심 정보만 빠르게 포착**하는 것입니다.

### 약어 목록 (자신만의 시스템 개발)

| 약어 | 의미 |
|------|------|
| → | 결과/원인이 됨 |
| ≠ | 다름/반대 |
| w/ | ~와 함께 |
| b/c | 왜냐하면 |
| ex | 예시 |
| imp | 중요한 |
| ↑↓ | 증가/감소 |

### 강의 노트 구조

```
주제: ________________
핵심 포인트 1: 
  - 세부 사항:
  - 예시:
핵심 포인트 2:
  - 세부 사항:
전환 신호: "however", "on the other hand", "for example"
```

---

## Listening 빈출 문제 유형

| 유형 | 특징 | 전략 |
|------|------|------|
| Main Idea | 강의의 핵심 주제 | 첫 30초에 주제 포착 |
| Detail | 구체적 사실 확인 | 노트에서 관련 내용 찾기 |
| Function | 발화의 목적 ("Why does the professor say...") | 문맥·톤 파악 |
| Attitude | 화자의 태도 | 억양·감정 단서 |
| Organization | 강의 구조 | 전체 흐름 파악 |
| Inference | 명시되지 않은 함의 | 논리적 추론 |
