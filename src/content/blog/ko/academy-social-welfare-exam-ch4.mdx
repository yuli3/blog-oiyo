## 사회복지 정책의 개념

```
사회복지 정책의 정의:
→ 국민의 복지 증진을 위해 국가가 취하는 일련의 행동 방침
→ 사회 문제 해결, 사회적 위험 관리

사회복지 정책의 목적:
1. 소득 재분배: 부의 불평등 완화
2. 사회적 위험 보호: 실업, 질병, 노령, 장애
3. 사회 통합: 계층 간 연대 강화
4. 최저 생활 보장: 빈곤층 기본 생활 지원
```

## 사회복지의 필요 (Need) 개념

```
브래드쇼(Bradshaw)의 욕구 유형:

1. 규범적 욕구 (Normative Need):
→ 전문가나 사회 기준에 의해 정의된 욕구
→ 예: 의사가 환자에게 필요하다고 판단

2. 감지된 욕구 (Felt Need):
→ 개인이 주관적으로 느끼는 욕구
→ 예: "나는 의료 서비스가 필요하다"

3. 표현된 욕구 (Expressed Need):
→ 감지된 욕구가 서비스 신청 등 행동으로 표현
→ 예: 의료급여 신청

4. 비교적 욕구 (Comparative Need):
→ 비슷한 상황의 사람들 비교에서 도출
→ 예: 같은 지역 주민과 비교 시 서비스 부족 발견
```

## 사회복지 급여 유형

```
현금 급여 (Cash Benefit):
→ 일정 금액을 현금으로 지급
→ 수급자 선택의 자유 높음
→ 예: 기초연금, 실업급여, 아동수당

현물 급여 (In-kind Benefit):
→ 특정 재화·서비스 직접 제공
→ 오·남용 방지, 목적 달성 용이
→ 예: 식품바우처, 무상급식, 공공주택

바우처 (Voucher):
→ 특정 서비스 구매에 사용 가능한 증서
→ 현금과 현물의 중간 형태
→ 예: 문화 누리 카드, 사회서비스 이용권

서비스 급여:
→ 상담, 요양, 돌봄 서비스 직접 제공
→ 예: 장기요양 방문요양, 드림스타트
```

## 사회복지 프로그램 유형

```
3대 사회복지 프로그램:

1. 사회보험 (Social Insurance):
→ 사전 보험료 납부 → 위험 발생 시 급여
→ 강제 가입, 기여금 비례 급여
→ 한국: 국민연금, 건강보험, 고용보험, 산재보험, 노인장기요양보험

2. 공공부조 (Public Assistance):
→ 국가가 조세로 재원 마련 → 저소득층 지원
→ 자산·소득 조사 기반 (선별적)
→ 한국: 국민기초생활보장제도, 의료급여, 긴급복지지원

3. 사회서비스 (Social Services):
→ 돌봄, 상담, 재활, 교육 등 비물질적 서비스 제공
→ 예: 보육 서비스, 노인 돌봄, 장애인 서비스

비교:
항목     | 사회보험   | 공공부조   | 사회서비스
--------|----------|----------|----------
재원     | 보험료    | 조세     | 조세+이용료
대상     | 피보험자   | 저소득층   | 욕구 있는 자
급여 기반 | 기여 원칙  | 필요 원칙  | 서비스 제공
```

## 복지국가 모델 (티트머스)

```
리처드 티트머스 (Titmuss)의 3가지 복지 모델:

1. 잔여적 모델 (Residual Model):
→ 가족·시장이 실패했을 때만 국가 개입
→ 최소한의 안전망
→ 예: 미국 전통적 복지 체계

2. 산업성취-수행 모델 (Industrial Achievement-Performance):
→ 노동·생산성에 따른 급여
→ 사회보험 중심
→ 예: 독일 비스마르크 모델

3. 제도적-재분배 모델 (Institutional Redistributive):
→ 보편적 서비스 제공
→ 시장 개입, 평등 지향
→ 예: 스웨덴 등 북유럽 복지국가
```

## 에스핑앤더슨의 복지 레짐

```
예스타 에스핑앤더슨 (Esping-Andersen)의 3가지 복지 레짐:

1. 자유주의 레짐 (Liberal Welfare Regime):
→ 시장 역할 강조, 잔여적 복지
→ 탈상품화 낮음
→ 대표 국가: 미국, 영국, 캐나다, 호주

2. 보수주의·조합주의 레짐 (Conservative/Corporatist):
→ 직업 지위·가족 연대 중심
→ 직업별 차별화된 사회보험
→ 대표 국가: 독일, 프랑스, 이탈리아

3. 사회민주주의 레짐 (Social Democratic):
→ 보편적 복지, 높은 탈상품화
→ 완전 고용 + 높은 복지 수준 병행
→ 대표 국가: 스웨덴, 덴마크, 노르웨이

탈상품화 (Decommodification):
→ 시장에 의존하지 않고 생활 유지 가능한 정도
→ 복지 제도가 강할수록 탈상품화 높음

한국의 복지 레짐:
→ 발전주의 복지국가: 경제 성장 지향 + 보수주의 요소
→ 동아시아 복지 모델 (유교적 가족주의 + 국가 복지)
```

## 한국의 사회보험 체계

```
5대 사회보험:

1. 국민연금 (1988년 도입):
→ 노후 소득 보장
→ 가입: 18~60세 취업자
→ 보험료: 기준소득 9% (근로자 4.5% + 사업주 4.5%)

2. 건강보험 (1989년 전국민):
→ 의료비 지원
→ 전 국민 강제 가입
→ 보험료: 직장가입자 7.09% (각 절반)

3. 고용보험 (1995년):
→ 실업급여, 직업능력 개발
→ 근로자·일부 자영업자

4. 산재보험 (1964년, 최초):
→ 업무상 재해·질병 보상
→ 사업주 100% 부담

5. 노인장기요양보험 (2008년):
→ 65세 이상 치료 제외 요양 서비스
→ 건강보험료의 12.95% (2024년)
```

## 자주 묻는 질문

**Q. 사회보험과 민간보험의 차이는 무엇인가요?**
A. 사회보험은 국가가 운영하는 강제 가입 제도로 소득 재분배 기능이 있습니다. 고소득자의 보험료가 저소득자 급여를 지원합니다. 반면 민간보험은 자발적 가입으로 납부한 보험료에 비례한 급여를 지급합니다.

**Q. 한국 복지국가는 선진국에 비해 얼마나 발전했나요?**
A. 한국의 GDP 대비 사회 지출 비율은 OECD 평균보다 낮지만 빠르게 증가 추세입니다. 5대 사회보험 체계는 갖춰져 있으나 급여 수준과 사각지대 문제가 과제로 남아 있습니다. 저출생·고령화 대응이 향후 복지 정책의 핵심 과제입니다.
