## 부가가치세 체계

```
과세 대상:
재화·용역의 공급 (사업자)
재화의 수입

세율:
일반: 10%
영세율: 0% (수출·국제운송 등)
면세: 과세 안됨 (기초생활·의료·교육)

납부 구조:
매출세액 - 매입세액 = 납부세액
매입세액 음수 → 환급

신고·납부:
예정신고: 4월·10월 25일
확정신고: 1월·7월 25일
```

---

## 부가가치세 매입세액 공제

```
공제 가능:
사업 관련 매입세액
세금계산서 수취분

공제 불가:
비영업용 소형승용차
접대비 관련 매입세액
면세 사업 관련
토지 관련

의제매입세액:
농축수산물 등 면세 원재료 매입 시
일정 비율로 매입세액 공제 의제
```

## 상속세

```
과세 대상:
사망으로 무상 이전되는 재산

상속재산 가액:
시가 원칙 (공시가격·감정가 보충)

공제:
기초공제: 2억
인적공제: 자녀·연로자·장애인
일괄공제: 5억 (인적공제와 선택 적용)
배우자공제: 최대 30억

세율:
10%~50% (5억/10억/30억/100억 구간)

신고·납부:
사망일 말일로부터 6개월
```

---

## 증여세

```
과세 대상:
생전 무상 이전 재산

직계비속 증여 공제:
성년 5천만원 (10년 누적)
미성년 2천만원 (10년 누적)

배우자 증여 공제:
6억원 (10년)

증여세 과세가액:
수증자 기준 10년 합산

세율: 상속세와 동일 (10~50%)

사전증여재산:
상속 전 10년 내 증여→상속세에 합산
```

## 핵심 개념 카드

**부가세=매출세액-매입세액** ★★★★★
: 전단계 세액 공제 방식.
*암기 포인트: 부가세=매출-매입*

**상속세 일괄공제=5억** ★★★★★
: 일괄 공제 5억 or 인적공제 선택.
*암기 포인트: 일괄=5억*

**증여 성년공제=5천만원(10년)** ★★★★☆
: 10년 내 누적 5천만원까지.
*암기 포인트: 성년증여=5천(10년)*

## 실전 퀴즈

**Q. 영세율과 면세의 부가세 처리 차이를 정확히 구별하면?**
> 영세율: 부가세율 0%, 매입세액 환급 가능. 수출 기업 → 환급 받음. 면세: 부가세 아예 없음, 매입세액 환급 불가. 면세사업자는 부가세 신고 의무도 없음. 수출=영세율이 면세보다 유리. 혼합사업자는 안분 계산.

**Q. 증여세 절세를 위한 10년 주기 증여 전략은?**
> 공제는 10년마다 초기화. 예: 자녀 태어나면 미성년 2천, 20세 성인 되면 5천, 30세 다시 5천. 조기 증여일수록 재산 증가분도 자녀 것. 단, 상속 전 10년 내 증여는 상속세에 합산. 상속 10년 전 증여가 절세 효과 극대화.
