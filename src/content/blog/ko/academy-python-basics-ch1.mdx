## 파이썬이란 무엇인가

**파이썬(Python)**은 1991년 귀도 반 로섬(Guido van Rossum)이 발표한 **고급 프로그래밍 언어**입니다. 이름은 영국 코미디 그룹 '몬티 파이썬(Monty Python)'에서 따왔습니다.

오늘날 파이썬은 **세계에서 가장 인기 있는 프로그래밍 언어** 중 하나로, 다음과 같은 분야에서 폭넓게 활용됩니다.

- 웹 개발 (Django, Flask, FastAPI)
- 데이터 분석 및 과학 (pandas, numpy, scipy)
- 인공지능 / 머신러닝 (TensorFlow, PyTorch, scikit-learn)
- 자동화 스크립트 (파일 처리, 크롤링)
- 교육 및 학술 연구

---

## 파이썬의 주요 특징

### 1. 읽기 쉬운 문법

파이썬은 **들여쓰기(indentation)**로 코드 블록을 구분합니다. 중괄호 `{}` 없이도 깔끔하게 코드를 작성할 수 있어 처음 배우는 사람도 이해하기 쉽습니다.

```python
# 파이썬 코드 예시
if 10 > 5:
    print("10이 5보다 큽니다")
```

### 2. 인터프리터 언어

사용자가 별도 컴파일 명령을 실행하지 않고 코드를 실행할 수 있다는 것과 컴파일 과정이 없다는 것은 다르다. 대표 구현인 CPython은 소스를 바이트코드로 컴파일한 뒤 실행한다. REPL도 입력한 문장을 평가하며, 함수 정의나 여러 줄 블록까지 단순히 '한 줄씩 즉시 실행한다'고 설명하면 실행 모델을 오해하기 쉽다. [Python 공식 용어집의 바이트코드 설명](https://docs.python.org/3/glossary.html#term-bytecode)을 기준으로 구현과 언어를 구분한다.

### 3. 동적 타이핑

객체에는 타입이 있고, 이름은 객체에 바인딩된다. 이름에 타입을 미리 고정해 선언하지 않으므로 같은 이름을 나중에 다른 타입의 객체에 다시 바인딩할 수 있다. 그러나 호환되지 않는 연산을 자동으로 허용한다는 뜻은 아니다. 예를 들어 정수와 문자열을 `+`로 더하면 `TypeError`가 발생한다. [공식 실행 모델](https://docs.python.org/3/reference/executionmodel.html#binding-of-names)이 이름 바인딩의 기준이다.

```python
x = 10        # 정수형으로 자동 인식
y = 3.14      # 실수형으로 자동 인식
z = "안녕"    # 문자열로 자동 인식
```

### 4. 풍부한 표준 라이브러리

수학, 날짜/시간, 파일 처리, 네트워크 등 방대한 표준 라이브러리가 기본 내장되어 있으며, PyPI로 수십만 개의 서드파티 패키지를 추가로 설치할 수 있습니다.

### 5. 크로스 플랫폼

Windows, macOS, Linux 등에서 사용할 수 있다. 다만 파일 경로·권한·인코딩·셸 명령·네이티브 라이브러리는 환경에 따라 달라질 수 있으므로, 한 운영체제에서 실행됐다는 사실만으로 다른 환경의 동작을 보장하지 않는다.

## 파이썬 버전 이해하기

| 버전 | 상태 | 비고 |
|------|------|------|
| Python 2.x | 지원 종료(2020년) | 레거시 코드에만 존재 |
| Python 3.10 이하 | 지원 종료 | 유지보수 정책을 확인하고 지원 버전으로 이전 검토 |
| Python 3.11 | 보안 유지보수 | 새 기능·일반 버그 수정 단계와 구분 |
| 그 이후 Python 3 버전 | 버전별 상태 확인 필요 | 의존성의 지원 범위와 함께 선택 |

위 지원 상태는 2026-10-03 확인 기준이다. Python 3.10은 [공식 릴리스 일정](https://peps.python.org/pep-0619/#310-lifespan)에 따라 2026-10-01 지원이 종료됐다. 버전 번호가 높다는 이유만으로 프로젝트의 라이브러리와 호환된다고 판단하지 않는다. [Python 공식 버전 상태표](https://devguide.python.org/versions/)에서 지원 단계와 종료 시점을 확인한다.

> **주의**: Python 2와 Python 3는 문법이 달라 호환되지 않는 부분이 많습니다. 반드시 **Python 3**를 사용하세요.

## 파이썬 설치하기

### Windows 설치

1. [Python 공식 다운로드](https://www.python.org/downloads/) 접속
2. 공식 안내에서 Python Install Manager 또는 해당 버전의 설치 프로그램을 확인한다.
3. 설치 방식에 따라 안내를 따른 뒤 터미널에서 `python --version` 또는 `py --version`으로 실행 여부를 확인한다.
4. 기존 설치 프로그램의 PATH 추가는 `python` 명령으로 실행할 때 편리한 옵션이지 Python 사용 자체의 필수 조건은 아니다. `py` 런처나 실행 파일의 전체 경로로도 실행할 수 있다. 여러 설치가 공존하면 어떤 인터프리터를 선택했는지 확인한다.

[현재 Windows 설치 안내](https://docs.python.org/3/using/windows.html)와 [기존 3.13 설치 프로그램 안내](https://docs.python.org/3.13/using/windows.html)는 방식이 다르다. 특정 화면의 체크박스를 모든 설치 방식에 적용하지 않는다.

설치 후 확인:
```bash
python --version
```

출력 형식 예시(설치한 버전에 따라 값은 다름):
```text
Python 3.12.3
```

### macOS 설치

Apple 개발 도구용 Python이 있을 수 있지만, 이를 프로젝트용 최신 Python으로 간주하면 안 된다. 지원되는 Python을 별도로 설치하고 사용할 실행 파일을 확인한다. Apple이 관리하는 인터프리터를 삭제하거나 덮어쓰지 않는다. [공식 macOS 설치 문서](https://docs.python.org/3/using/mac.html)가 두 용도를 구분한다.

**방법 1: 공식 홈페이지**
1. [Python 공식 다운로드](https://www.python.org/downloads/) 접속
2. macOS용 설치 파일 다운로드 및 실행

**방법 2: 이미 Homebrew를 사용하는 경우**
```bash
brew install python3
python3 --version
```

### Linux (Ubuntu/Debian) 설치

대부분의 Linux에는 Python이 기본 설치되어 있습니다.

배포판 저장소에서 패키지 설치:
```bash
sudo apt update
sudo apt install python3 python3-pip
```

## pip — 파이썬 패키지 관리자

**pip**는 Python 패키지를 설치·관리하는 도구다. 공식 바이너리 설치 프로그램에는 기본 포함되지만, 배포판이나 설치 옵션에 따라 없을 수 있다. [공식 패키지 설치 안내](https://docs.python.org/3/installing/index.html)를 확인하며, 버전 번호만으로 pip 존재를 가정하지 않는다.

아래 명령은 프로젝트 가상환경의 인터프리터를 기준으로 실행한다. 설치·업그레이드·제거 명령은 해당 환경을 변경하므로 대상과 패키지를 확인한다.

```bash
python -m pip --version
python -m pip install requests
python -m pip list
python -m pip install --upgrade requests
python -m pip uninstall requests
```

## 개발환경 설정 — IDLE

**IDLE(Integrated Development and Learning Environment)**은 공식 기본 설치에 포함되는 학습용 통합 개발 환경이다. 배포판·설치 옵션에 따라 없을 수 있으며, Tcl/Tk 지원이 필요하다. 모든 Python 설치에 자동 포함된다고 가정하지 않는다.

### IDLE 실행

- **Windows**: 시작 메뉴 → Python → IDLE
- **macOS**: 응용 프로그램 → Python → IDLE

### IDLE 주요 기능

| 기능 | 설명 |
|------|------|
| Shell 창 | 대화형 모드로 코드 한 줄씩 실행 |
| 편집기 창 | 스크립트 파일 작성 및 저장 |
| 구문 강조 | 키워드·문자열·주석 색상 구분 |
| 자동 완성 | Tab 키로 변수명·함수명 자동 완성 |
| 디버거 | 코드 단계별 실행 및 오류 탐색 |

### IDLE에서 첫 코드 실행

1. IDLE 실행 → Shell 창이 열림
2. `>>>` 프롬프트에 입력:

다음은 프롬프트와 출력을 포함한 대화 기록이다. 스크립트 파일에는 `>>>`를 복사하지 않는다.

```text
>>> print("Hello, World!")
Hello, World!
>>> 2 + 3
5
>>> "파이썬" * 3
'파이썬파이썬파이썬'
```

## 개발환경 설정 — VS Code

**Visual Studio Code(VS Code)**는 Microsoft가 만든 코드 편집기다. 편집기 자체와 코드를 실행하는 Python 인터프리터는 별개이며, 이 장에서는 프로젝트 환경을 선택해 실행하는 방법에 초점을 둔다.

### VS Code 설치

1. [VS Code 공식 사이트](https://code.visualstudio.com/) 접속
2. 운영체제에 맞는 버전 다운로드 및 설치

### Python 확장 설치

1. VS Code 실행
2. 왼쪽 사이드바 확장(Extensions) 아이콘 클릭 (단축키: `Ctrl+Shift+X`)
3. 검색창에 "Python" 입력
4. 게시자가 **Microsoft**인 Python 확장을 확인해 설치

### 첫 번째 파이썬 파일 만들기

1. `Ctrl+Shift+P` → "Python: Select Interpreter" → 설치된 Python 버전 선택
2. `Ctrl+N` → 새 파일 생성
3. `Ctrl+S` → `hello.py`로 저장 (확장자 `.py` 필수)
4. 코드 입력 후 실행

### VS Code 유용한 단축키

| 단축키 | 기능 |
|--------|------|
| `F5` | 디버그 실행 |
| `Ctrl+F5` | 디버그 없이 실행 |
| `Ctrl+/` | 주석 토글 |
| `Alt+↑/↓` | 줄 이동 |
| `Ctrl+D` | 같은 단어 다중 선택 |
| Ctrl + 백틱 키 | 터미널 열기(운영체제·키 설정에 따라 다를 수 있음) |

## 첫 번째 프로그램 — Hello, World!

파이썬에서 화면에 출력하는 함수는 `print()`입니다.

```python
print("Hello, World!")
```

출력:
```text
Hello, World!
```

### 다양한 print() 활용

```python
# 문자열 출력
print("안녕하세요, 파이썬!")

# 숫자 출력
print(42)
print(3.14)

# 여러 값을 한 번에 출력 (sep로 구분자 지정)
print("사과", "바나나", "딸기", sep=", ")
# 출력: 사과, 바나나, 딸기

# end 파라미터로 줄바꿈 제어
print("첫 번째 줄", end=" ")
print("같은 줄에 이어서")
# 출력: 첫 번째 줄 같은 줄에 이어서

# 빈 줄 출력
print()

# 이스케이프 문자
print("탭\t사이")       # 탭 문자
print("줄\n바꿈")       # 줄바꿈
print("따옴표: \"큰따옴표\"")
```

## 주석 작성법

`#` 뒤의 내용은 주석이다. 판단 근거와 제약을 남기면 코드를 읽는 사람이 의도를 이해하기 쉽다.

```python
# 고정 문자열을 써서 주석 문법과 출력 결과를 함께 확인한다.
print("Hello")
```

세 따옴표로 감싼 내용은 문자열 리터럴이며 주석 문법이 아니다. 함수·클래스·모듈의 첫 문장인 문자열은 독스트링으로 쓰일 수 있다.

## 가상환경(Virtual Environment) 입문

**가상환경**은 기존 Python 설치를 바탕으로 프로젝트별 패키지 환경을 만든다. 표준 `venv`는 기본적으로 기반 환경의 site-packages와 분리되지만, `--system-site-packages` 옵션을 쓰면 기반 환경의 패키지에도 접근한다. 운영체제·파일·네트워크까지 격리하는 보안 샌드박스가 아니다. [공식 venv 문서](https://docs.python.org/3/library/venv.html)를 기준으로 패키지 격리와 보안 격리를 구분한다.

가상환경 생성:
```bash
python -m venv myenv
```

Windows CMD에서 활성화:
```bat
myenv\Scripts\activate.bat
```

macOS/Linux의 bash·zsh에서 활성화:
```bash
source myenv/bin/activate
```

활성화한 환경에서 패키지를 설치하고, 작업 후 비활성화한다:
```bash
python -m pip install requests
deactivate
```

> 프로젝트별 환경을 만들어 재사용한다. 터미널 세션마다 새 환경을 만들 필요는 없으며, 작업할 때 기존 환경을 활성화한다.

### 설치됐는데 import가 실패할 때 확인할 것

`pip install`이 성공했다고 현재 편집기의 인터프리터에 설치됐다고 단정하면 안 된다. 터미널·편집기·노트북이 서로 다른 Python을 사용할 수 있기 때문이다. 먼저 문제가 발생한 실행 위치에서 다음 진단 코드를 실행한다. 이 코드는 패키지를 설치하거나 파일을 변경하지 않는다.

```python
import sys

print("실행 파일:", sys.executable)
print("Python 버전:", sys.version.split()[0])
print("환경 경로:", sys.prefix)
print("기반 환경:", sys.base_prefix)
print("venv 사용:", sys.prefix != sys.base_prefix)
```

출력 경로와 버전은 컴퓨터마다 다르므로 고정된 정답 문자열로 비교하지 않는다. `sys.prefix != sys.base_prefix`는 표준 `venv`로 만든 환경의 판별에 사용하며, 모든 환경 관리 도구의 상태를 같은 방식으로 설명하는 규칙은 아니다.

| 관측 | 다음 확인 |
|---|---|
| 터미널과 편집기의 실행 파일 경로가 다름 | 편집기에서 프로젝트 인터프리터를 다시 선택하고 같은 위치에서 진단 코드를 실행한다. |
| 실행 파일은 맞지만 패키지가 없음 | 그 환경에서 `python -m pip --version`으로 pip 위치를 확인한 뒤 필요한 패키지를 설치한다. |
| 설치했는데 같은 이름의 모듈이 예상과 다름 | 프로젝트에 `requests.py`처럼 패키지 이름을 가리는 파일이 있는지, 오류가 난 모듈의 실제 경로를 확인한다. |

가상환경의 존재와 실행환경 재현성은 다르다. Python 버전, 의존성 버전, 운영체제와 외부 데이터도 결과에 영향을 준다. 설치 문제를 해결할 때 시스템 Python을 무작정 덮어쓰거나 관리자 권한으로 재설치하는 대신, 먼저 실제 실행 파일과 오류 메시지를 확인한다.

## 실전 퀴즈 5문항

**Q1.** 파이썬에서 화면에 텍스트를 출력하는 기본 함수는 무엇인가요?

**A1.** `print()` 함수입니다. 예: `print("Hello, World!")`

---

**Q2.** 터미널에서는 패키지를 설치했는데 편집기에서는 `ModuleNotFoundError`가 발생한다. 무엇부터 비교해야 하는가?

**A2.** 두 실행 위치의 `sys.executable`과 환경 경로를 비교한다. 서로 다른 인터프리터라면 편집기의 프로젝트 환경을 맞춘다. 같은 인터프리터라면 그 환경의 `python -m pip --version`과 패키지 설치 여부를 확인한다. 설치 성공 메시지 하나만으로 원인을 확정하지 않는다.

---

**Q3.** `print("파이썬", "최고", sep="!")` 를 실행하면 어떤 결과가 출력되나요?

**A3.** `파이썬!최고` 가 출력됩니다. `sep` 파라미터는 여러 인수 사이에 들어갈 구분자를 지정합니다. 기본값은 공백(" ")입니다.

---

**Q4.** 가상환경(Virtual Environment)을 사용하는 이유를 설명하세요.

**A4.** 프로젝트별로 필요한 패키지 버전을 분리하기 위해서다. 기본 venv는 기반 환경의 site-packages와 분리된다. 다만 파일·네트워크 접근을 막거나 운영체제 차이를 없애지는 않으며, 기반 Python과 의존성 버전도 기록해야 재현성을 검토할 수 있다.

---

**Q5.** 파이썬 2와 파이썬 3의 차이점을 간단히 설명하고, 현재 어떤 버전을 사용해야 하는지 답하세요.

**A5.** Python 2는 2020년에 공식 지원이 종료됐으며, `print` 문·문자열 처리·정수 나눗셈 등이 Python 3와 다르다. 신규 프로젝트는 지원 중인 Python 3를 선택하되, 라이브러리 호환성과 운영환경을 함께 확인한다. Python 3이라는 이유만으로 지원 중인 버전이라고 판단하지 않는다.
