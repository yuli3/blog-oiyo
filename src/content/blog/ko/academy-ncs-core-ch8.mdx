## 실전 시험의 특성 이해

NCS 직업기초능력평가는 **지식 암기 시험이 아닙니다.** 주어진 지문·표·그래프를 읽고, 제한 시간 내에 논리적으로 판단하는 능력을 봅니다.

**실전에서 자주 나타나는 현상**:
- "문제는 이해했는데 시간이 부족했다"
- "두 선택지 사이에서 계속 고민했다"
- "쉬운 문제를 틀렸다"

이 3가지 현상의 원인과 해결책을 이번 강의에서 다룹니다.

---

## 능력별 실전 접근법

### 의사소통능력 — 독해 속도가 관건

**문제 특성**: 긴 지문 + 선택지 5개 + '옳은 것/옳지 않은 것 고르기'

**전략 1: 선택지 먼저 읽기**
문제를 읽기 전에 선택지를 빠르게 훑습니다. 어떤 정보를 찾아야 하는지 파악한 뒤 지문을 읽으면 목적 지향적 독해가 가능합니다.

**전략 2: 지문 → 선택지 비교 시 '극단어' 확인**
| 함정 표현 | 실제 지문 표현 |
|---------|------------|
| 반드시, 항상, 절대로 | 일반적으로, 대부분의 경우 |
| 모든, 전체 | 일부, 특정 |
| 불가능하다 | 어렵다, 제한된다 |

'반드시'가 포함된 선택지는 80% 확률로 오답입니다. 지문이 절대적 표현을 쓰지 않는 한.

**전략 3: '옳지 않은 것' 문제 — 소거법**
옳지 않은 것을 고를 때는 각 선택지를 지문에서 직접 확인합니다. 기억으로 판단하면 틀립니다.

---

### 수리능력 — 계산 실수 방지

**문제 특성**: 표/그래프 분석, 백분율, 증감률, 비율 비교

**전략 1: 단위 먼저 확인**
문제를 읽기 전에 표의 단위를 확인합니다. '(단위: 만 명)', '(단위: 억 원)' 등을 놓치면 계산이 10배·100배 틀립니다.

**전략 2: 어림 계산으로 선택지 좁히기**
정확한 값 대신 어림수로 계산해 범위를 좁힙니다.
- 예: 1,237 × 3.82 ≈ 1,200 × 4 = 4,800 → 4,700~4,900 범위 선택지 선택

**전략 3: 증감률 계산 공식 암기**
```
증감률 = (변화 후 - 변화 전) ÷ 변화 전 × 100
```
전년 대비 증가율을 물으면: (이번 해 - 지난 해) ÷ 지난 해 × 100

**자주 나오는 함정**:
- 증가량 vs 증가율 혼동 (절댓값 차이 vs 비율 차이)
- 분모를 '전체'로 해야 하는데 '부분'으로 계산
- 가중 평균이 필요한데 단순 평균으로 계산

---

### 문제해결능력 — 논리 구조 파악

**문제 특성**: 조건 제시 → 논리적 결론 도출, 또는 문제 상황 → 해결책 선택

**전략 1: 조건문 문제 — 기호화**
```
A이면 B이다 → A → B
B가 아니면 A가 아니다 (대우) → ¬B → ¬A
```

5개 조건이 연쇄된 문제에서는 조건들을 기호로 쓰면 빠릅니다.

**전략 2: 추론 문제 — '반드시 참인 것'과 '참일 수 있는 것' 구분**
- '반드시 참': 주어진 조건만으로 100% 도출
- '참일 수 있음': 가능하지만 필연적이지 않음

**전략 3: 실무 상황 문제 — 맥락 독해**
회사 업무 상황을 주고 "다음 중 가장 적절한 행동은?"을 묻는 문제:
- 상위자 보고와 팀 협업 중시하는 선택지가 일반적으로 답
- 독단적 행동, 비공식 채널 사용은 오답 패턴

---

### 자원관리능력 — 계산 + 우선순위

**문제 특성**: 예산 배분, 시간 스케줄링, 인력 배치

**전략: 제약 조건 먼저 파악**
"예산 100만 원 내에서 최대 효과" 유형:
1. 불가능한 조합 먼저 제거
2. 제약을 충족하는 조합에서 목표값(효과, 수익) 비교

**시간 배분 유형**:
A가 3시간, B가 4시간 걸리는 업무를 8시간 내에 처리 → 불가능 조합 파악 → 가능 조합 중 우선순위 판단

---

### 조직이해능력 — 개념 + 상황 판단

**문제 특성**: 조직 구조, 결재 절차, 직장 에티켓

**자주 출제되는 개념**:
- 전결(위임전결)과 대결 구분
- 수평적/수직적 의사소통
- 공식 조직과 비공식 조직의 특징

**전략**: 개념 정의를 정확히 암기하고, 문제 상황에서 어느 개념이 적용되는지 매핑합니다.

---

## 시간 배분 전략

NCS 시험은 보통 **50~60문제 / 60~70분**입니다. 문제당 평균 1.2분.

**시간 배분 원칙**:

| 유형 | 목표 시간 | 이유 |
|------|---------|------|
| 단순 개념 확인 | 30초~1분 | 빠르게 처리 |
| 수리 계산 | 1~2분 | 어림 계산 활용 |
| 긴 지문 독해 | 2~3분 | 선택지 먼저 읽기 |
| 복잡한 조건문 | 2~3분 | 기호화 후 풀기 |

**절대 규칙**: 한 문제에 3분 이상 쓰지 않습니다. 모르면 표시해두고 다음으로 넘어갑니다.

## 오답 패턴 분석

### 오답 패턴 1: 지문 외 지식으로 판단
NCS는 지문에 있는 정보만으로 답합니다. "원래 이렇게 하는 것 아닌가?"는 함정입니다.

### 오답 패턴 2: 선택지의 '모든/항상/반드시'
절대적 표현이 포함된 선택지는 대부분 오답입니다. 하나의 반례만 있어도 틀린 선택지가 되기 때문입니다.

### 오답 패턴 3: 계산 실수 (부호, 단위)
- 증가율을 구하는데 감소율로 계산
- 단위가 '억'인데 '만'으로 읽음
- 분자와 분모 반전

### 오답 패턴 4: 문제 조건 미반영
"A의 경우를 제외하고"라는 조건을 놓치고 A를 포함해 계산

## 고득점 루틴

### 시험 전날
1. 새 내용 학습 ✗ — 이미 아는 것 정리 ✓
2. 오답 노트 복습 (패턴 재확인)
3. 수면 7시간 이상

### 시험 당일
1. 문제지 받으면 전체 구성 30초 확인 (총 문제 수, 유형 분포)
2. 쉬운 유형부터 처리 (빠른 성취감 + 시간 확보)
3. 모르는 문제는 넘기고 마지막에 돌아옴
4. 마지막 5분: 빠진 문제 확인 + 마킹 오류 점검

### 마킹 주의
- OMR은 문제 번호와 선택지 번호가 엇갈리지 않도록
- 10문제마다 한 번씩 번호 확인 습관

## 시리즈 복습 가이드

| 강의 | 핵심 내용 | 출제 비중 |
|-----|---------|---------|
| Ch1 의사소통 | 문서 독해, 논지 파악, 문장 구조 | 높음 |
| Ch2 수리 | 비율·증감률 계산, 표 분석 | 높음 |
| Ch3 문제해결 | 조건 추론, 창의적 사고 유형 | 중간 |
| Ch4 자기개발·자원관리 | 시간·예산 배분, 우선순위 | 중간 |
| Ch5 조직이해·직업윤리 | 조직 구조, 윤리 상황 판단 | 중간 |
| Ch6 대인관계 | 갈등 해결, 협상, 팀워크 | 중간 |
| Ch7 정보·기술 | 컴퓨터 활용, 매뉴얼 읽기 | 낮음~중간 |

**주력 학습**: 의사소통 + 수리 (전체 40~50% 비중)
**안전 확보**: 조직이해 + 직업윤리 (개념 암기로 해결)
