## 중국어 독학이 가능한가?

가능합니다. 단, 한국어와 구조적으로 다른 부분이 있어 전략이 필요합니다.

**한국인에게 유리한 점**:
- 한자 문화권 → 한자 학습 시 의미 파악이 상대적으로 쉬움
- 중국어 어순이 비교적 단순 (주어 + 동사 + 목적어)
- 동사 활용 없음 (시제는 시간 부사로 표현)

**한국인에게 어려운 점**:
- **성조 (4성)**: 한국어에 없는 개념 → 초반 집중 훈련 필수
- **발음 체계**: 권설음, 순치음 등 한국어에 없는 발음
- **간체자 vs 번체자**: 중국 본토(간체), 대만·홍콩(번체)

## 성조 완벽 마스터

중국어 핵심: 성조를 틀리면 전혀 다른 뜻이 됩니다.

### 4성 + 경성

| 성조 | 표현 | 예 | 뜻 |
|-----|-----|-----|-----|
| 1성 (음평) | 높고 평평 (—) | mā 妈 | 엄마 |
| 2성 (양평) | 올라가는 (/) | má 麻 | 삼, 마비 |
| 3성 (상성) | 내려갔다 올라가는 (∨) | mǎ 马 | 말 |
| 4성 (거성) | 내려가는 (\) | mà 骂 | 욕하다 |
| 경성 | 짧고 가볍게 | ma 吗 | 의문 어미 |

### 성조 연습 방법

1. **손 동작**: 성조마다 손을 같이 움직이며 몸으로 기억
2. **과장 발음**: 처음에는 극단적으로 과장해서 발음
3. **성조 노래**: 성조별 짧은 문장을 멜로디처럼 반복
4. **섀도잉**: 원어민 음성 그대로 따라 말하기

**추천 앱**: 드래곤 중국어, HelloChinese, 동그라미 중국어

## 발음 체계 (병음, Pinyin)

병음 = 중국어 로마자 표기 = 발음 기호

### 초성 (声母, 21개)

**한국인 주의 발음**:
- **zh, ch, sh, r**: 권설음 (혀를 말아서 발음)
- **z, c, s**: 평설음 (혀를 앞에 대고)
- **j, q, x**: 구개음 (혀를 앞쪽에)

| 구분 | 발음 | 한국어 근사 |
|-----|-----|---------|
| b, p | 무기음/유기음 | ㅂ/ㅍ |
| d, t | 무기음/유기음 | ㄷ/ㅌ |
| g, k | 무기음/유기음 | ㄱ/ㅋ |
| zh, ch | 권설음 | 혀 말아서 "쮜", "츄" |
| r | 권설음 유성 | 혀 말아서 "르" |

### 모음 (韵母)

단모음: a, o, e, i, u, ü (6개)

복모음: ai, ei, ao, ou, ia, ie, ua, uo, üe, iao, iou, uai, uei

비음: an, en, in, un, ün, ang, eng, ing, ong, iang, iong, uang, ueng

## 한자 암기 전략

### 부수 (偏旁部首) 활용

한자 = 부수 + 구성 요소의 조합.

부수를 알면 의미 추론 가능:
- 氵(삼수변): 물 관련 → 海(바다), 河(강), 汉(한)
- 木(목): 나무 관련 → 树(나무), 桌(책상), 椅(의자)
- 口(구): 입 관련 → 吃(먹다), 说(말하다), 喝(마시다)

### 연상 암기법 (기억술)

의미 없는 한자를 스토리로 연결.

예) 好(좋다) = 女(여자) + 子(아이) → "여자와 아이가 함께 있으면 좋다"

### 단어 묶음 암기

개별 한자보다 **단어 단위** 암기가 효율적.

- 看(보다) → 看电视(TV 보다), 看书(책 보다), 看病(병 보다=진찰)
- 打(치다) → 打电话(전화하다), 打车(택시 타다), 打算(계획하다)

**추천 도구**:
- Anki (플래시카드, 스페이스드 리피티션)
- Pleco (중국어 사전 앱, 학습 기능 포함)

## HSK 단계별 학습 전략

HSK (汉语水平考试) = 중국어 국제 공인 자격증 (중국 정부 운영)

### HSK 레벨 체계

| 레벨 | 어휘 수 | 수준 | 학습 기간 (0부터) |
|-----|-------|-----|-------------|
| HSK 1 | 150개 | 기초 인사·생활 | 1~2개월 |
| HSK 2 | 300개 | 간단한 의사소통 | 3~4개월 |
| HSK 3 | 600개 | 일상 대화 가능 | 6~8개월 |
| HSK 4 | 1,200개 | 비교적 자유로운 의사소통 | 1~1.5년 |
| HSK 5 | 2,500개 | 중국어 신문·드라마 이해 | 2~3년 |
| HSK 6 | 5,000개+ | 고급 수준 | 4~5년+ |

### 단계별 전략

**HSK 1~2 (기초)**:
- 목표: 병음 완전 마스터 + 기초 150~300 단어
- 방법: HelloChinese 앱 + 성조 집중 연습
- 기간: 하루 30분 × 2개월

**HSK 3 (초중급 — 취업에 유리한 최소 수준)**:
- 목표: 일상 회화 가능, 간단한 읽기·쓰기
- 방법: HSK 3 전용 교재 + 드라마 섀도잉
- 기간: 하루 1시간 × 6개월

**HSK 4 (중급 — 실용적 활용 가능)**:
- 목표: 중국인과 자유로운 의사소통
- 방법: 독해 교재 + 작문 연습 + 원어민 튜터
- 기간: HSK 3 이후 추가 6~12개월

**HSK 5 (고급 — 취업·통역 수준)**:
- 방법: 중국어 뉴스·드라마·책 정독 + 작문
- 기간: 수년 꾸준한 노출 필요

## 추천 학습 로드맵 (0→HSK 3)

### 1~2개월: 발음 완성 단계

- 병음 전체 마스터 (4성 포함)
- 기초 150 단어 (HSK 1 범위)
- 인사, 숫자, 날짜, 시간 표현
- **도구**: HelloChinese 앱 (무료) + 드래곤 중국어

### 3~4개월: 초급 회화 단계

- HSK 2 단어 완성 (300개)
- 쇼핑, 교통, 식당 회화
- 매일 10문장 암기
- **도구**: Anki 단어 카드 + 중국어 회화 유튜브

### 5~8개월: HSK 3 준비 단계

- HSK 3 단어 (600개) + 문법
- 섀도잉: 드라마 "爸爸去哪儿", "向往的生活" 활용
- 독해 연습 + HSK 3 기출 문제
- **도구**: HSK 3 기출 문제집 + Pleco 사전

## 실용 중국어 표현

### 기초 회화

```
你好 (nǐ hǎo) — 안녕하세요
谢谢 (xiè xiè) — 감사합니다
不客气 (bú kè qi) — 천만에요
对不起 (duì bu qǐ) — 죄송합니다
没关系 (méi guān xi) — 괜찮아요
```

### 여행/생활 필수

```
多少钱？(duō shǎo qián?) — 얼마예요?
太贵了 (tài guì le) — 너무 비싸요
便宜一点 (pián yí yī diǎn) — 좀 깎아주세요
在哪里？(zài nǎ lǐ?) — 어디에 있어요?
我听不懂 (wǒ tīng bù dǒng) — 못 알아듣겠어요
请说慢一点 (qǐng shuō màn yī diǎn) — 천천히 말해주세요
```

## 중국어 취업 활용

중국어 실력이 유리한 직종:
- 무역·수출입 (중국 거래처)
- 관광·호텔 (중국인 관광객)
- 한중 합작 기업
- 번역·통역
- 해외 취업 (중국, 대만, 싱가포르)

**취업 활용 최소 레벨**: HSK 3 이상 (이력서 기재 가능)
**실무 수준**: HSK 4~5

중국어는 성조가 관문입니다. 첫 2개월 발음 투자가 이후 모든 학습의 기반이 됩니다. 성조를 잡으면 나머지는 반복과 노출의 문제입니다.
