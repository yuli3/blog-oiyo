## 한국 전통 음식 문화

```
한국 음식의 특징:
→ 곡류 중심 (쌀·잡곡)·채소·발효 음식 풍부
→ 건강·약식동원 (藥食同源) 철학
→ 계절과 지역에 따른 음식 다양성
→ 밥·국·반찬의 공간 배치 (상 차림)

발효 음식 (Fermented Foods):
→ 김치: 세계 5대 건강 식품·유네스코 무형 유산
  종류: 배추·깍두기·파김치·총각김치·열무·오이소박이
  김장 문화: 2013년 유네스코 인류무형문화유산
→ 된장·간장·고추장: 장류 (발효 콩)
→ 청국장: 짧은 발효기간의 콩 된장
→ 젓갈: 해산물 발효 (새우젓·멸치액젓·오징어젓)
→ 막걸리: 쌀 발효 탁주

궁중 음식:
→ 조선 왕실 식문화·12첩 반상
→ 신선로 (열구자탕): 중간에 숯불 넣는 전통 냄비 요리
→ 구절판: 9칸 그릇에 담긴 밀전병+8가지 재료
→ 갈비찜·육회·전복찜·각종 떡·한과

절기 음식:
→ 설날: 떡국 (흰 가래떡, 새해 나이)
→ 정월대보름: 오곡밥·부럼 (견과류)·나물
→ 삼복 (복날): 삼계탕·보신탕·육개장
→ 추석: 송편·햅쌀·각종 전·탕

지역 음식:
→ 전주: 비빔밥·콩나물국밥
→ 평양: 냉면·어복쟁반
→ 안동: 찜닭·헛제삿밥
→ 제주: 돔베고기·전복죽·고사리음식
```

## 전통 공예

```
한국 도자기:
→ 고려청자: 비색(翡色) 상감 청자·세계 최고 수준
  12세기 전성기·운학(구름·학)·국화·포도 문양
  현재 강진·부안이 주요 생산지
→ 조선백자: 순백의 아름다움·유교적 검소 미학
  분청사기 (조선 초): 청자에서 백자로 가는 전환기
  달항아리 (Moonjar): 조선 18세기 순백 대형 항아리

나전칠기 (Lacquerware with Mother-of-Pearl):
→ 흑칠 바탕에 자개(조개 껍데기) 문양 삽입
→ 통일신라·고려 시대 발달
→ 현대: 가구·생활용품·선물용으로 제작

한지 (Korean Traditional Paper):
→ 닥나무 껍질로 만든 전통 종이
→ 특성: 질기고 오래 보존 (1000년 이상 수명)
→ 활용: 서예·한옥 창호지·공예·문화재 보존
→ 전주 한지: 가장 유명

매듭 (Korean Knot):
→ 노리개·허리띠·부채 끝에 장식하는 전통 공예
→ 나비매듭·생쪽매듭·잠자리매듭 등 다양한 유형
→ 오방색 (적·청·황·백·흑) 활용

자수 (Embroidery):
→ 규방 공예: 조선 여성의 전통 수예
→ 보자기·베개·병풍·복식 등에 활용
→ 현대: 전통 자수의 현대적 재해석

목공예:
→ 소반 (小盤): 개인 밥상·다양한 지역 형태
→ 함 (函): 혼수 상자·혼례 문화
→ 장롱·문갑·사방탁자: 전통 가구

민화 (Folk Painting):
→ 민간에서 그린 그림·실용적·장식적 목적
→ 화조도·어해도·책거리·산신도·호작도
→ 대담한 색감·평면적 구성·해학적 표현
```

## 자주 묻는 질문

**Q. 외국인 관광객에게 김치를 소개할 때 꼭 알려줘야 할 내용은 무엇인가요?**
A. 김치 소개 시 몇 가지 핵심 정보를 전달하면 효과적입니다. 첫째, 역사와 문화적 의미입니다. 약 1,000년 이상의 역사를 가지며 2013년 유네스코 인류무형문화유산으로 등재된 '김장 문화'와 함께 설명하면 좋습니다. 둘째, 종류의 다양성입니다. 배추김치가 가장 대표적이지만 깍두기·파김치·총각김치·오이소박이 등 200여 종이 넘는다고 알려주면 흥미를 끕니다. 셋째, 건강 효능입니다. 유산균·비타민·항산화 성분이 풍부하여 세계 5대 건강 식품(미국 헬스지 선정)이라는 점을 소개합니다. 넷째, 채식 여부 확인입니다. 전통 김치에는 새우젓·멸치액젓 등 해산물이 들어가므로 채식주의자·알레르기 관광객에게는 미리 알려줘야 합니다. 비건 김치나 해산물을 넣지 않은 김치도 있다고 안내하면 도움이 됩니다.

**Q. 관광통역안내사가 외국인 관광객에게 역사적으로 민감한 주제(일제강점기·남북분단)를 다룰 때 어떤 자세가 필요한가요?**
A. 민감한 역사 주제를 다룰 때는 균형 잡힌 사실 전달이 원칙입니다. 일제강점기(1910~1945)는 한국 근현대사의 중요한 부분으로, 사실에 기반하여 설명하되 지나친 감정적 표현은 피하는 것이 전문적입니다. 외국인 관광객 중 일본인이 있을 경우 특히 주의가 필요합니다. 남북 분단의 경우, DMZ 방문이 인기 관광지인 만큼 역사적 배경과 현재 상황을 객관적으로 설명합니다. 개인적 정치 의견 표명은 삼가고, 관광객이 질문할 경우 한국의 공식 입장과 역사적 사실을 중심으로 답변합니다. 안내사의 역할은 관광객이 한국 역사·문화를 깊이 이해하고 존중할 수 있도록 돕는 것이므로, 교육적이고 성숙한 태도가 중요합니다.
