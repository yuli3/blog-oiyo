# 여행 예산 계산기

여행 계획에서 예산 설정은 가장 중요한 첫 단계입니다. 막연하게 "100만원 정도?"가 아니라, 항목별로 정확히 계산하면 여행 후 지출 충격을 줄이고 더 알차게 즐길 수 있습니다.

## 여행 유형별 하루 평균 예산 (1인 기준)

| 여행지 | 저예산 | 중간 | 프리미엄 |
|---|---|---|---|
| 일본 | 7–10만원 | 12–18만원 | 25만원+ |
| 태국·베트남 | 4–6만원 | 8–12만원 | 20만원+ |
| 유럽 | 10–15만원 | 20–30만원 | 50만원+ |
| 미국 | 12–18만원 | 25–40만원 | 70만원+ |
| 국내 | 5–8만원 | 10–15만원 | 25만원+ |

*숙박·식비·교통 포함, 항공권 제외*

## 여행 예산 절감 팁

<Callout type="tip">
**항공권**: 출발 2–3개월 전 예매, 화·수요일 출발이 저렴. 스카이스캐너로 전체 달력 조회.
</Callout>

| 항목 | 절감 방법 |
|---|---|
| 항공권 | 조기 예매, 얼리버드, 마일리지 활용 |
| 숙박 | 에어비앤비·호스텔, 도심 외곽 숙소 |
| 식비 | 현지 마켓·편의점, 점심 코스 메뉴 |
| 교통 | 1일 교통패스, 도보·자전거 적극 활용 |
| 환전 | 토스·카카오페이 환전, 시내 은행 환율 우대 |

## 여행 예산 배분 가이드 (총 예산 기준)

| 항목 | 권장 비율 |
|---|---|
| 항공권 | 30–40% |
| 숙박 | 20–30% |
| 식비 | 15–20% |
| 교통 | 10–15% |
| 관광·입장료 | 5–10% |
| 쇼핑·기념품 | 5–10% |
| 비상금 | 10% (필수!) |

<Callout type="warning">
해외여행 시 **여행자 보험**은 필수입니다. 의료비, 수하물 분실, 항공 지연 등을 커버하며 비용은 보통 1–3만원 수준입니다.
</Callout>
