## 1. 생산 시스템 유형

### 생산 방식 분류

| 유형 | 내용 | 예시 |
|------|------|------|
| 프로젝트 생산 | 1회성, 대형 | 선박·교량 건설 |
| 잡샵(Job Shop) | 소량 다품종, 주문 | 맞춤 제작 |
| 배치(Batch) | 로트 단위 | 인쇄, 의류 |
| 라인(Line) 생산 | 대량 표준화 | 자동차, 음료 |
| 연속(Continuous) 생산 | 24시간 흐름 | 정유, 화학 |

### 설비 배치 (Layout)
- **제품별 배치 (Product Layout)**: 동일 제품 반복 생산, 효율 높음
- **공정별 배치 (Process Layout)**: 유사 기능 장비 집중, 유연성 높음
- **고정 위치 배치 (Fixed Position)**: 대형 제품, 자재·인력이 제품으로 이동

## 2. 수요 예측

### 정성적 방법
- **델파이 기법**: 전문가 반복 의견 수렴
- **시장 조사**: 소비자 설문
- **경영자 판단**: 내부 전문가 직관

### 정량적 방법

| 방법 | 내용 |
|------|------|
| 이동평균법 | 최근 n기간 평균으로 예측 |
| 지수평활법 | 가중치로 최근 데이터 강조 (α 조정) |
| 회귀분석 | 독립변수(x)로 수요(y) 예측 |
| 시계열 분해 | 추세·계절·순환·불규칙 분해 |

**MAD (평균절대편차)**: 예측 오차 크기 측정 지표 = Σ|실제값 − 예측값| / n

## 3. 일정 계획: PERT/CPM

**PERT (Program Evaluation and Review Technique)**: 불확실성이 높은 프로젝트 — 낙관치·최빈치·비관치로 기대시간 계산.

**CPM (Critical Path Method)**: 확정적 시간 추정 — 최장 경로(임계경로) 파악.

**임계경로 (Critical Path)**: 프로젝트 완료에 걸리는 최소 시간을 결정하는 경로.
→ 임계경로 상의 활동 지연 = 전체 프로젝트 지연.

**여유시간 (Slack)** = 늦은 시작 − 이른 시작. 임계경로의 여유시간 = 0.

## 4. 재고 관리

### 재고 유형
- 원자재 재고 / 재공품(WIP) 재고 / 완제품 재고
- 안전 재고 (Safety Stock): 수요 불확실성 대비 완충 재고

### EOQ (경제적 주문량)

**EOQ 공식**: EOQ = √(2DS/H)
- D: 연간 수요량
- S: 1회 주문 비용
- H: 단위당 연간 보관 비용

**가정**: 수요 일정, 주문 즉시 입고, 부족 불허.

**재주문점 (ROP)** = 1일 수요 × 조달 기간

### JIT (Just-In-Time) / 린 생산

필요한 시간에 필요한 양만 생산·조달 — 재고 최소화.

**칸반 (Kanban)**: 부품 흐름을 시각적으로 통제하는 카드 시스템.

**린 생산의 7대 낭비**
과잉생산 / 대기 / 운반 / 과잉가공 / 재고 / 동작 / 불량

## 5. 품질경영

### TQM (전사적 품질관리)
조직 전체가 지속적 개선에 참여하는 경영철학.

**TQM 핵심 원칙**: 고객 중심 / 지속적 개선 / 전원 참여 / 프로세스 중심

### PDCA 사이클 (데밍 사이클)
Plan(계획) → Do(실행) → Check(검토) → Act(개선) → 반복

### 6시그마
불량률을 100만 개 중 3.4개 이하로 줄이는 품질 혁신 방법론.

**DMAIC**: Define(정의) → Measure(측정) → Analyze(분석) → Improve(개선) → Control(통제)

### ISO 9000 시리즈
국제 품질 경영 시스템 표준. ISO 9001: 품질 경영 시스템 인증 기준.

### 품질 비용 (PAF 모형)

| 비용 유형 | 내용 |
|-----------|------|
| 예방 비용 | 불량 방지 활동 (교육, 설계 검토) |
| 평가 비용 | 검사, 시험, 감사 |
| 내부 실패 비용 | 출하 전 발견 불량 (재작업, 폐기) |
| 외부 실패 비용 | 출하 후 발견 불량 (반품, A/S, 배상) |

## 6. 공급망관리 (SCM)

원자재 조달에서 최종 고객까지의 물류·정보·자금 흐름을 통합 관리.

**채찍 효과 (Bullwhip Effect)**: 소비자 수요 변동이 공급망 상류로 갈수록 증폭되는 현상.
→ 해결책: 정보 공유, 주문 주기 단축, VMI(공급자 재고 관리).
