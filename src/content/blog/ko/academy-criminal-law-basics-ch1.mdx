## 형법의 의의

```
형법:
어떤 행위가 범죄이고 그에 대한 형벌이 무엇인지 규정한 법

형법의 기능:
보호적 기능: 법익(생명·재산·자유 등) 보호
보장적 기능: 개인을 국가 형벌권 남용으로부터 보호

형사법 체계:
형법(실체법): 범죄·형벌 내용 규정
형사소송법(절차법): 수사·재판 절차 규정

형벌의 종류:
생명형: 사형
자유형: 징역·금고·구류
재산형: 벌금·과료·몰수
명예형: 자격상실·자격정지
```

## 죄형법정주의

```
죄형법정주의:
"법률 없으면 범죄 없고, 법률 없으면 형벌 없다"
국가 형벌권의 자의적 행사 방지

파생 원칙:
① 관습형법 금지: 범죄·형벌은 성문 법률로만 규정
② 소급효 금지: 행위 당시 법률로만 처벌
   (단, 피고인에게 유리한 소급은 허용)
③ 유추해석 금지: 법문을 유추하여 처벌 확대 금지
④ 명확성 원칙: 구성요건 명확히 규정

위반 효과:
죄형법정주의 위반 법률 → 위헌 (헌법재판소)
```

## 형법의 적용 범위

```
장소적 적용:
속지주의 (원칙): 대한민국 영토 내 범죄
속인주의 (보충): 한국인이 외국에서 범한 특정 범죄
보호주의: 외국인의 한국 국익 침해 범죄
세계주의: 국제적 중대 범죄 (인류 공공의 적)

시간적 적용:
행위 시 법률 적용 원칙
피고인에게 유리한 경우: 신법 소급 적용
```

## 형벌 이론

```
응보형론:
범죄에 상응하는 형벌 (눈에는 눈)
형벌 = 정의 실현

특별예방론:
범죄자 교화·재사회화
형벌 = 재범 방지

일반예방론:
사회 일반인에 대한 위하
형벌 = 잠재적 범죄자 억제

현대: 예방론 강조
교화, 치료, 사회 복귀 중심
```

## 핵심 개념 카드

**죄형법정주의 4원칙** ★★★★★
: 관습금지·소급효금지·유추해석금지·명확성.
*암기 포인트: 관소유명*

**속지주의 원칙** ★★★★★
: 형법은 대한민국 영토 내 범죄에 원칙 적용. 속인·보호·세계주의는 예외.
*암기 포인트: 원칙=영토내, 예외=속인·보호·세계*

**응보형론 vs 예방형론** ★★★★☆
: 응보=과거 응징. 예방=미래 재범 방지.
*암기 포인트: 응보=과거, 예방=미래*

## 실전 퀴즈

**Q. 죄형법정주의에서 유추해석 금지란 무엇인가?**
> 법에 명시되지 않은 행위를 유사한 규정을 끌어와 처벌하는 것 금지. 예: 자동차를 처벌하는 규정을 오토바이에 유추 적용하면 안 됨. 형벌법규는 엄격하게 문언 그대로 해석해야 함.

**Q. 형사소송법이 형법과 다른 점은?**
> 형법=실체법(무엇이 범죄이고 어떤 형벌인지). 형사소송법=절차법(수사→기소→재판→집행 절차). 형법 없이 처벌 불가, 형사소송법 없이는 형법 집행 불가.
