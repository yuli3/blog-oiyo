## 금리는 왜 움직이는가

금리는 "돈의 가격"입니다. 수요-공급이 가격을 결정하듯, 자금의 수요와 공급이 금리를 결정합니다.

```
금리를 올리는 요인:
- 경기 과열 → 자금 수요 증가
- 인플레이션 상승 → 실질 수익률 보전 필요
- 정부 재정 적자 확대 → 국채 공급 증가
- 외국 자본 유출 방어

금리를 내리는 요인:
- 경기 침체 → 소비·투자 진작 필요
- 인플레이션 하락 → 실질 금리 하락 수용
- 금융 위기 대응 → 유동성 공급
- 디플레이션 우려
```

## 중앙은행의 정책 도구

### 미국 연준 (Federal Reserve)

```
기준금리 (Federal Funds Rate):
- 은행 간 익일물 대출 금리 목표
- FOMC 연 8회 회의에서 결정
- 모든 시장 금리에 영향

QE/QT (양적완화/긴축):
- QE: 국채·MBS 매입 → 시중 유동성 증가
- QT: 보유 자산 감소 → 시중 유동성 축소

포워드 가이던스:
- 미래 금리 방향 시사 → 시장 기대 형성
- 점도표(Dot Plot): FOMC 위원 금리 전망 공개
```

### 한국은행

```
기준금리:
- 금융통화위원회 연 8회 결정
- 미 연준 금리와의 역전 폭이 자본 유출에 영향

환율 방어:
- 달러-원 환율이 급등하면 기준금리 인상 압박
- 수출 경제 특성상 적정 환율 관리 중요

물가목표제:
- 소비자물가 목표: 연 2% 중기 목표
- 목표 초과 지속 시 인상 압박
```

## 수익률 곡선 분석 (심화)

### 수익률 곡선의 형태

```
정상 곡선 (우상향):
단기 금리 &lt; 장기 금리
→ 경기 확장 기대, 정상적 상태

평탄화:
단기 ≈ 장기 금리
→ 경기 불확실성, 금리 전환점 신호

역전 곡선 (우하향):
단기 금리 &gt; 장기 금리
→ 강력한 경기 침체 신호 ★★★

스티프닝:
단기-장기 간격 확대
→ 경기 회복 기대 또는 인플레이션 우려
```

### 2년-10년 스프레드

```
핵심 지표: 미국 10년물 - 2년물 금리
0 이하 = 역전 (경기침체 예고)

역사적 패턴:
1990년 역전 → 1991년 침체
2000년 역전 → 2001년 닷컴 버블 붕괴
2006~07년 역전 → 2008년 금융위기
2022~23년 역전 → 2023~24년 연착륙?

단, 역전 후 침체까지 평균 18~24개월 시차
```

## 금리 사이클 4단계와 채권 전략

```
1단계: 금리 인상 초기
시장 상황: 인플레이션 상승, 경기 양호
채권 전략: 단기채 비중 확대, 듀레이션 단축
유망: T-Bills, SOFR 연동 채권, 단기 회사채

2단계: 금리 인상 후기
시장 상황: 수익률 곡선 역전, 경기 둔화 조짐
채권 전략: 장기채 천천히 매집 시작
유망: 중기 국채, 물가연동채(TIPS)

3단계: 금리 인하 초기
시장 상황: 경기 침체 또는 연착륙 확인
채권 전략: 장기채 비중 크게 확대
유망: 장기 국채 ETF (TLT), 우량 장기 회사채

4단계: 금리 인하 후기
시장 상황: 경기 회복, 다음 인상 사이클 준비
채권 전략: 장기채 차익 실현, 단기채로 이동
유망: 하이일드 채권 (경기 회복 수혜)
```

## 인플레이션과 채권

```
실질 수익률 = 명목 수익률 - 기대 인플레이션

예: 국채 금리 4%, 인플레이션 3% → 실질 수익률 1%
인플레이션 6% 시 → 실질 수익률 -2% (마이너스!)

물가연동채(TIPS) 활용:
원금이 인플레이션에 연동되어 조정
실질 수익률 확정 투자 가능

TIP지표: BEI(Break-even Inflation Rate)
= 명목 국채 수익률 - TIPS 수익률
= 시장이 예상하는 기대 인플레이션
```

## 핵심 암기 포인트

*수익률 곡선 역전(단기&gt;장기) = 경기침체 선행 신호*
*금리 인상 초기 → 단기채 / 인하 전환 시 → 장기채로 이동*
*실질 수익률 = 명목 금리 - 인플레이션 (마이너스 = 채권 보유 손해)*
*BEI(Break-even) = 시장 기대 인플레이션*
