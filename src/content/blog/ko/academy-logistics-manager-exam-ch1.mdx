## 물류관리사 자격증이란?

물류관리사는 국토교통부 주관, 한국산업인력공단이 시행하는 국가전문자격으로, 물류 전반을 관리·기획하는 전문가를 검증합니다. 물류 기업, 제조업체 물류팀, 유통업체 등에서 활용도가 높습니다.

```
주관: 국토교통부 (시행: 한국산업인력공단)
시험 회차: 연 1회 (보통 7~8월)
응시 자격: 제한 없음 (누구나 응시 가능)
합격 기준: 각 과목 40점 이상 + 평균 60점 이상
```

## 시험 과목 구성

```
총 5과목 (각 40문제, 1시간):

1과목: 물류관리론
→ 물류의 개념, 기능, 비용, 아웃소싱, 물류 전략

2과목: 화물운송론
→ 육상·해상·항공 운송, 운임 체계, 운송 계약

3과목: 보관하역론
→ 창고 관리, 재고 관리, 하역 장비, 바코드·RFID

4과목: 물류관련법규
→ 물류정책기본법, 화물자동차운수사업법, 항만법

5과목: 국제물류론
→ 인코텀즈, 해상 운송, 항공 운송, 무역 서류

시험 형식: 객관식 5지선다
총 200문제 / 5시간
```

## 물류(Logistics)란?

```
물류의 정의:
→ 원자재부터 완제품이 최종 소비자에게 전달되기까지의
  운송·보관·하역·포장·정보 활동의 총체

물류의 범위:
원자재 조달 → 생산 → 완제품 → 도매 → 소매 → 소비자

물류 vs 로지스틱스 vs SCM:
- 물류: 물리적 상품 이동 활동
- 로지스틱스: 물류 + 정보 + 계획 통합
- SCM: 공급망 전체(구매~고객) 관리
```

## 물류의 기능 (7R 원칙)

```
물류 서비스의 목표: 7 Right

Right Product   → 적합한 상품을
Right Quantity  → 적합한 수량을
Right Condition → 적합한 상태로
Right Place     → 적합한 장소에
Right Time      → 적합한 시간에
Right Customer  → 적합한 고객에게
Right Price     → 적합한 가격으로

→ 7R을 달성하는 것이 물류 서비스의 핵심 목표
```

## 물류 활동의 5대 요소

```
1. 운송 (Transportation):
→ 물품의 장소적 이동
→ 도로, 철도, 해운, 항공, 파이프라인

2. 보관 (Storage/Warehousing):
→ 물품의 시간적 조정 (생산↔소비 시간 차 해소)
→ 창고, 물류 센터, 배송 센터

3. 하역 (Cargo Handling):
→ 운송·보관 연결 작업 (싣기, 내리기, 이동)
→ 지게차, 컨베이어, 자동 창고

4. 포장 (Packaging):
→ 상품 보호, 취급 편의, 정보 전달
→ 낱포장, 속포장, 겉포장

5. 정보 (Information):
→ 재고 현황, 주문 처리, 배송 추적
→ WMS (창고관리시스템), TMS (운송관리시스템)
```

## 물류 비용 구조

```
물류 비용 분류:

기능별 분류:
- 운송비 (가장 큰 비중: 40~50%)
- 보관비 (20~30%)
- 하역비 (10~15%)
- 포장비 (5~10%)
- 물류 정보비 (5% 미만)

물류 비용 절감 전략:
1. 운송 통합 (공동 배송, 혼재 운송)
2. 창고 최적화 (자동화, ABC 분석)
3. 재고 최소화 (JIT, 린 물류)
4. 아웃소싱 (3PL 활용)
```

## 물류 아웃소싱 (3PL / 4PL)

```
1PL (First Party Logistics):
→ 화주가 자사 물류를 직접 수행

2PL (Second Party Logistics):
→ 화주가 운송 등 일부만 외부 위탁

3PL (Third Party Logistics):
→ 전문 물류 업체가 화주의 물류 전부 대행
→ CJ 대한통운, 롯데 글로벌로지스 등
→ 비용 절감 + 전문성 확보

4PL (Fourth Party Logistics):
→ 물류 컨설팅 + 3PL 통합 관리
→ 전체 공급망 설계·운영 위탁
```

---

## 물류 합리화 (효율화) 방법

```
1. 유닛 로드 시스템 (Unit Load System):
→ 화물을 팔레트·컨테이너로 단위화
→ 하역·운송 효율 향상

2. 표준화:
→ 팔레트, 컨테이너 규격 통일
→ 장비 호환성 향상

3. 공동화:
→ 공동 배송, 공동 창고로 비용 분담
→ 소규모 기업도 물류 효율화 가능

4. 정보화:
→ 바코드, RFID, WMS/TMS/ERP 연계
→ 실시간 재고·배송 현황 파악
```

## 핵심 암기 포인트

```
시험 빈출 키워드:

- 물류의 5대 요소: 운송, 보관, 하역, 포장, 정보
- 7R: 7가지 Right (Right Product ~ Right Price)
- 3PL: 전문 물류 업체에 아웃소싱

- WMS: 창고관리시스템
- TMS: 운송관리시스템
```

## 자주 묻는 질문

**Q. 물류관리사 합격률은 어느 정도인가요?**
A. 과목별로 차이가 있지만 평균 합격률은 20~35% 수준입니다. 5과목이라 범위가 넓어 3~4개월 이상의 준비가 필요합니다.

**Q. 물류관리사를 취득하면 어떤 직무에 지원할 수 있나요?**
A. 물류 기획, 창고 관리, 배송 관리, SCM 담당, 무역 물류 등 다양한 직무에 활용됩니다. 대형 물류사·유통사 공채에서 가산점을 주는 경우가 많습니다.
