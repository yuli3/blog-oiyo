## 지역사회복지의 이해

```
지역사회(Community)의 정의:
→ 특정 지역을 기반으로 공통 이해를 나누는 인간 집단
→ 지역 공동체: 지리적 + 기능적 결합

지역사회복지(Community Social Welfare):
→ 지역사회를 기반으로 한 사회복지 실천
→ 지역 주민의 역량 강화, 자원 개발·활용
→ 탈시설화, 재가 서비스 강조

지역사회복지의 구성 요소:
→ 지역사회 조직
→ 지역사회 개발
→ 사회 계획·정책

등장 배경:
→ 탈시설화: 기관 수용보다 지역사회 생활 지향
→ 정상화 원리: 장애인도 일반 지역사회에서 살 권리
→ 지방화: 중앙→지방 복지 이양
→ 복지 다원주의: 국가·민간·자원·비공식 협력
```

## 로스만의 지역사회 조직 3모델

```
로스만(Rothman)의 3모델:

1. 지역사회 개발 모델 (Locality Development):
→ 지역 주민의 자발적 참여·역량 강화 강조
→ 과정 중심 (변화 과정 자체가 목표)
→ 합의적 접근 (갈등 최소화)
→ 실천가 역할: 안내자, 촉진자
→ 예: 마을 만들기, 주민 자치

2. 사회 계획 모델 (Social Planning):
→ 전문가 주도의 합리적 문제 해결
→ 과제 중심 (구체적 목표 달성)
→ 기술·자료 기반 계획
→ 실천가 역할: 전문가, 계획가
→ 예: 지역사회 욕구 조사, 복지 계획 수립

3. 사회 행동 모델 (Social Action):
→ 권력 관계 변화, 사회 정의 실현
→ 불이익 집단의 이익 대변
→ 갈등적 접근 (압력·협상)
→ 실천가 역할: 옹호자, 조직가
→ 예: 노동 운동, 장애인 권리 운동

웨일·갬블(Weil & Gamble) 8모델:
→ 로스만 3모델을 확장
→ 근린·지역사회 조직, 기능적 지역사회, 지역사회개발 등
```

## 지역사회복지 실천 방법

```
지역사회 욕구 조사:
→ 인구통계, 사회 지표 분석
→ 서비스 조사: 현 서비스 파악
→ 주민 욕구 조사: 설문·인터뷰·FGI
→ 자원 조사: 인적·물적·제도적 자원 파악

지역사회 자원 개발:
→ 자원봉사 관리
→ 후원 개발 (기부·결연)
→ 사회적 기업·협동조합 연계

네트워킹 (Networking):
→ 기관 간 협력 체계 구축
→ 사례 연계, 의뢰 네트워크
→ 민·관 협력: 지역사회보장협의체

지역사회 조직화 과정:
→ 1단계: 지역사회 진입·관계 형성
→ 2단계: 욕구·문제 파악
→ 3단계: 목표 설정·전략 수립
→ 4단계: 실천·조직화
→ 5단계: 평가·유지

지역사회보장협의체 (한국):
→ 시·군·구 단위 민관 협력 기구
→ 지역사회보장계획 심의·자문
→ 복지 자원 연계·조정
```

## 사회복지행정의 이해

```
사회복지행정의 정의:
→ 사회복지 조직이 목표를 효과적으로 달성하도록
  조직·관리·운영하는 활동

사회복지행정의 원리:
→ 효율성: 최소 자원으로 최대 서비스
→ 효과성: 목표 달성 정도
→ 합법성: 법률·규정 준수
→ 책임성: 이해관계자에 대한 책임
→ 형평성: 공정한 서비스 분배

조직 이론 적용:

고전적 관리론:
→ 과학적 관리(테일러), 공식적 구조 강조
→ 효율성 중심

인간관계론:
→ 구성원 만족·동기 중시
→ 비공식 조직 중요성

체계이론:
→ 조직과 환경의 상호작용
→ 투입-전환-산출 모형
```

## 사회복지시설 유형

```
사회복지시설 분류 (사회복지사업법):

이용 시설:
→ 주간 이용, 일시 보호
→ 종합사회복지관, 장애인 주간보호센터
→ 자원봉사센터, 재가복지봉사센터

생활 시설 (입소 시설):
→ 24시간 생활 제공
→ 노인요양원, 아동복지시설, 장애인거주시설

복지관 유형:
→ 종합사회복지관: 지역 주민 종합 서비스
→ 노인복지관: 60세 이상 대상
→ 장애인복지관: 장애인 재활·사회 참여

사회복지관의 3대 기능:
1. 사례 관리: 복합 욕구 통합 서비스
2. 서비스 제공: 직접 서비스
3. 지역 조직화: 주민 역량 강화

민간 사회복지 전달 체계:
→ 사회복지법인, 사단/재단법인
→ 종교 단체 복지 기관
→ 사회적 기업, 협동조합
→ 자원봉사 단체

공공 복지 전달 체계:
→ 보건복지부 → 시·도 → 시·군·구 → 읍·면·동
→ 사회복지담당 공무원 (사회복지직)
→ 복지로 (온라인 복지 서비스 통합 포털)
```

## 사회복지사 2급 시험 핵심 체크

```
필수 암기 항목:

로스만 3모델 구별:
→ 지역사회개발: 주민 참여·역량강화
→ 사회계획: 전문가·합리적 접근
→ 사회행동: 권력 변화·사회정의

지역사회보장협의체:
→ 시·군·구 → 읍·면·동 단위
→ 민관 협력 기구

사회복지 전달 체계 원칙:
→ 접근성, 통합성, 지속성, 포괄성, 전문성, 책임성

사회복지관 기능:
→ 사례관리 + 서비스제공 + 지역조직화

자주 출제 이슈:
→ 탈시설화, 정상화 원리
→ 사회복지 아웃소싱 vs 직접 운영
→ 사회적 기업 인증 요건
→ 지역사회보장계획 (4년 주기)
```

## 자주 묻는 질문

**Q. 사회복지사 2급 시험에서 지역사회복지론은 어떤 비중인가요?**
A. 사회복지사 2급 1교시 시험의 주요 과목으로 상당한 비중을 차지합니다. 로스만의 3모델, 지역사회보장협의체, 사회복지관 기능, 탈시설화·정상화 개념이 자주 출제됩니다. 개념을 정확히 구분하고, 특히 로스만 모델에서 각 모델의 특성·역할·접근 방식 차이를 명확히 외워두는 것이 중요합니다.

**Q. 지역사회복지사는 종합사회복지관에서만 일하나요?**
A. 아닙니다. 지역사회복지 관련 업무는 다양한 곳에서 이루어집니다. 종합사회복지관 외에도 지역자활센터, 정신건강복지센터, 장애인복지관, 노인복지관, 읍·면·동 주민센터(사회복지담당), 지역사회보장협의체 등에서 활동합니다. 최근에는 마을 공동체 사업, 사회적 기업에서도 지역사회 조직화 역량을 갖춘 사회복지사 수요가 늘고 있습니다.
