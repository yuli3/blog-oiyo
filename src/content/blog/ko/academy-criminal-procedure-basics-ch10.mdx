## 형사 절차 전체 흐름

```
수사 단계:
고소·고발·인지 → 수사 개시
임의수사 우선, 강제수사 영장 필요
체포·구속 → 피의자 신문

공소 제기:
검사만 기소 (기소독점주의)
불기소 불복: 재정신청
공소시효: 사형=25년, 무기=15년

공판:
공소장 일본주의 → 증거 조사 → 판결
불이익변경금지: 피고인만 상소 시
```

---

## 핵심 기간 정리

```
체포 관련:
현행범 체포 후 구속 영장: 48시간
긴급체포 후 영장 청구: 즉시
구속 기간 수사: 최대 30일

상소 관련:
항소·상고 제기: 7일 이내
약식명령 정식재판 청구: 7일 이내
즉결심판 정식재판 청구: 7일 이내

공소시효:
사형=25년, 무기=15년
살인=폐지 (시효 없음)
친고죄 고소 취소: 1심 판결 선고 전
```

## 증거 법칙 핵심

```
자백 법칙:
임의성 없는 자백 = 증거 능력 없음
자백 보강 법칙: 자백만으로 유죄 불가

전문 법칙:
전문증거 = 원칙적 증거 능력 없음
예외: 피의자 신문조서 (내용 인정)

위법수집증거:
위법 수집 = 증거 능력 없음
독수독과: 파생 증거도 배제
예외: 선의·필연적 발견·희석
```

## 소송 원칙 핵심

```
무죄추정: 확정 전까지 무죄
in dubio pro reo: 의심=피고인 유리
불이익변경금지: 피고인만 상소 시
일사부재리: 확정 판결 동일 사건 재소 불가
공판중심주의: 법정 심리 중심
공소장일본주의: 예단 방지

국민참여재판:
배심원 평결 = 권고적 (법원 구속 안됨)
피고인 신청 시 진행

소년: 촉법소년=14세미만 형사불가
```

## 핵심 개념 카드

**형사절차=수사→기소→공판→판결→상소** ★★★★★
: 전체 흐름 완전 암기.
*암기 포인트: 수기공판상*

**7일=항소·약식정식재판청구** ★★★★★
: 불복 기간 7일 통일.
*암기 포인트: 불복=7일*

**무죄추정+자백보강+전문배제** ★★★★★
: 형사소송 3대 증거 원칙.
*암기 포인트: 무추+자보+전배*

## 실전 퀴즈

**Q. 형사소송의 가장 핵심적인 3가지 원칙을 설명하라.**
> ① 무죄추정원칙: 유죄 확정 전까지 무죄. 검사가 유죄를 입증할 의무 (거증책임). ② 적법절차원칙: 위법수집증거 배제, 영장주의. 절차 위반 = 증거 능력 없음. ③ 공판중심주의: 수사기록 아닌 법정 직접 심리. 이 3원칙이 충돌하면 원칙적으로 피고인 보호 우선.

**Q. 형사 피의자·피고인의 방어권을 총정리하라.**
> 수사 단계: 진술 거부권(묵비권), 변호인 접견권, 체포 시 고지 의무. 구금 단계: 구속적부심사 청구권, 보석 신청권. 공판 단계: 반대신문권, 증거 신청권, 최후 진술권. 판결 후: 상소권, 재심 청구권. 공통: 자백 강요 금지, 자백 보강 법칙, 무죄 추정.
