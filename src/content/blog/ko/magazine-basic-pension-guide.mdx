## 기초연금이란?

만 65세 이상 노인 중 소득·재산이 일정 기준 이하인 분께 매달 지급하는 정부 복지 급여입니다. 노후 소득 보장을 위한 대표적 노인 복지 제도입니다.

---

## 2024년 기초연금 금액

```
단독 가구 최대: 월 334,810원
부부 가구 최대: 월 535,680원 (각 267,840원)

→ 2023년 대비 인상 (물가 상승분 반영)
→ 소득인정액에 따라 감액 가능
```

## 수급 자격

### 기본 요건

```
1. 연령: 만 65세 이상
2. 국적: 대한민국 국적 보유 + 국내 거주
3. 소득인정액 기준: 수급자 선정 기준액 이하

2024년 선정 기준액:
- 단독 가구: 213만원 이하
- 부부 가구: 340.8만원 이하
```

### 대상에서 제외되는 경우

```
- 공무원연금, 사학연금, 군인연금, 별정우체국연금 수급자
  (또는 수급권자의 배우자)
→ 단, 수령액이 적은 경우 일부 예외 적용
```

## 소득인정액 계산

소득인정액은 실제 받는 돈만이 아니라 **재산도 소득으로 환산**해 합산합니다.

### 계산 공식

```
소득인정액 = 월 소득평가액 + 재산의 월 소득환산액

월 소득평가액:
- 근로소득: (근로소득 - 108만원) × 70%
- 사업소득, 재산소득, 이전소득 포함

재산의 월 소득환산액:
- (재산 - 기본재산액) × 4% ÷ 12개월
- 기본재산액: 대도시 1억3,500만원 / 중소도시 8,500만원 / 농어촌 7,250만원
```

### 예시

```
[단독 노인, 시골 거주]
월 근로소득: 없음
국민연금: 월 30만원 수령
재산: 농지 5,000만원

소득평가액: 30만원 (연금 이전소득)
재산환산: (5,000만 - 7,250만) = 음수 → 0원
소득인정액: 30만원 < 213만원 → 기초연금 수급 가능
```

## 국민연금과의 관계 (감액 기준)

국민연금을 많이 받으면 기초연금이 감액될 수 있습니다.

### 국민연금 연계 감액

```
국민연금 수령액이 기초연금 기준액의 150% 초과 시 감액:
→ 2024년 기준: 502,220원 초과 시 감액 적용
→ 감액 최대: 기초연금의 50%까지 감액 (최소 167,405원 이상 보장)
```

### 왜 감액하나?

```
국민연금 가입 기간이 길고 납입액이 많을수록 국민연금 수령액이 높음
→ 기초연금과의 형평성을 위해 국민연금 고액 수급자 감액
→ 국민연금 납입을 많이 했어도 기초연금 포기가 아님 (최소 절반은 보장)
```

## 부부 가구 감액

```
부부 모두 기초연금 수급자일 경우:
→ 각자 수령액의 20% 감액

이유: 부부가 생활비를 공유하기 때문에 단독 가구보다 적게 지급

예시:
단독 최대: 334,810원
부부 각자: 334,810원 × 80% = 267,848원
→ 부부 합계: 535,696원
```

## 신청 방법

### 신청 장소

```
- 주소지 관할 읍·면·동 주민센터 (행정복지센터) 방문
- 국민연금공단 지사 방문
- 복지로 홈페이지 온라인 신청 (www.bokjiro.go.kr)
- 정부24 앱 온라인 신청
```

### 필요 서류

```
- 신분증 (주민등록증, 운전면허증 등)
- 통장 사본 (수급 계좌)
- 재산세 과세 확인서 (필요 시)
- 금융 정보 제공 동의서 (현장 작성)
→ 서류는 기관에서 대부분 전산으로 조회 가능
```

### 신청 시기

```
만 65세 생일이 속한 달의 1개월 전부터 신청 가능
→ 생일 전달 신청 시 생일달부터 지급
→ 늦게 신청하면 신청월부터 지급 (소급 없음)
→ 생일이 다가오면 미리 신청할 것
```

## 수급 중 신고 의무

```
다음 사항이 변경되면 신고 필요:
- 소득 증가 (취업, 사업 개시)
- 재산 증가 (부동산 취득, 증여 받음)
- 국민연금 등 다른 공적 연금 수급 개시
- 가구 변동 (사망, 세대원 변경)
→ 신고 안 하면 환수될 수 있음
```

## 자주 묻는 질문

**Q. 재산이 아파트 한 채인데 기초연금을 받을 수 있나요?**
A. 아파트 가격에 따라 달라집니다. 소득인정액 계산 시 기본재산액을 공제한 후 환산하므로, 시세가 기본재산액보다 크게 높지 않은 경우 수급 가능합니다. 주민센터에서 무료로 사전 상담을 받으시기 바랍니다.

**Q. 국민연금을 월 100만원 받는데 기초연금은?**
A. 국민연금 100만원은 2024년 감액 기준(502,220원)을 초과하므로 감액이 적용됩니다. 다만 기초연금의 50% 이상(약 167,405원)은 보장됩니다. 정확한 금액은 소득인정액과 함께 계산해야 합니다.

**Q. 자녀 명의로 재산을 이전하면 기초연금을 받을 수 있나요?**
A. 최근 5년 이내 증여·이전한 재산은 소득인정액에 포함될 수 있습니다. 재산 명의 이전이 수급 자격에 영향을 미칠 수 있으므로 주의가 필요합니다.

**Q. 외국에 잠시 나가도 계속 지급되나요?**
A. 국외 체류 중에는 지급이 정지될 수 있습니다. 60일 이상 장기 해외 체류 시 신고가 필요합니다.
