## 사회복지 실천의 개념

```
사회복지 실천이란:
→ 개인, 가족, 집단, 지역사회의 사회적 기능을 향상시키고
  문제를 해결하기 위한 전문적 원조 활동

실천 수준:
- 미시(Micro): 개인 및 가족 대상
- 중범위(Mezzo): 집단, 소규모 조직 대상
- 거시(Macro): 지역사회, 제도, 정책 대상
```

---

## 사회복지 실천의 가치와 윤리

```
핵심 가치:
1. 인간 존엄성 (Human Dignity)
2. 사회 정의 (Social Justice)
3. 자기 결정권 (Self-Determination)
4. 비밀보장 (Confidentiality)
5. 개별화 (Individualization)

윤리적 딜레마 유형:
- 자기 결정 vs 보호 의무 (클라이언트가 위험한 선택)
- 비밀보장 vs 제3자 보호 (타인 위험 위협 시)
- 클라이언트 이익 vs 기관 이익

한국 사회복지사 윤리강령:
→ 한국사회복지사협회 발표
→ 클라이언트·동료·기관·사회에 대한 책임 명시
```

## 바이스텍의 관계 7원칙

```
Felix Biestek의 케이스워크 관계 원칙:

1. 개별화 (Individualization):
   → 클라이언트를 유일한 존재로 대우

2. 의도적 감정 표현 (Purposeful Expression of Feelings):
   → 감정을 자유롭게 표현하도록 허용

3. 통제된 정서적 관여 (Controlled Emotional Involvement):
   → 사회복지사의 공감적·민감한 반응

4. 수용 (Acceptance):
   → 클라이언트를 있는 그대로 수용

5. 비심판적 태도 (Non-Judgmental Attitude):
   → 도덕적 판단 유보

6. 자기 결정 (Self-Determination):
   → 클라이언트 스스로 선택·결정 존중

7. 비밀보장 (Confidentiality):
   → 개인 정보 보호
```

## 사회복지 실천 과정

```
6단계 실천 과정:

1단계 초기 접촉 (Intake/Engagement):
→ 첫 만남, 래포 형성, 서비스 신청 접수

2단계 자료 수집 (Data Collection):
→ 클라이언트 정보, 환경 조사
→ 면접, 관찰, 기록 검토

3단계 사정 (Assessment):
→ 수집된 자료 분석·해석
→ 문제, 욕구, 강점 파악
→ PIE (Person-in-Environment) 사정 도구 활용

4단계 계획 (Planning):
→ 목표 설정 (장·단기)
→ 개입 방법 결정

5단계 개입 (Intervention):
→ 실제 서비스 제공
→ 직접 개입 (상담, 교육) + 간접 개입 (자원 연결)

6단계 평가 및 종결 (Evaluation & Termination):
→ 목표 달성 정도 평가
→ 종결 시 사후 관리 계획
```

## 주요 사회복지 실천 모델

```
1. 심리사회 모델 (Psychosocial Model):
→ 내적·심리적 요인 + 사회 환경 동시 고려
→ '상황 속의 인간' (Person-in-Situation)
→ 대표 학자: 홀리스(Hollis)

2. 기능주의 모델 (Functional Model):
→ 기관 기능 범위 내 원조 (현재 중심)
→ 의지와 자기 결정 강조
→ 대표 학자: 스몰리(Smalley)

3. 문제해결 모델 (Problem-Solving Model):
→ 문제 해결 능력 향상 목표
→ 4P: Person, Problem, Place, Process
→ 대표 학자: 펄만(Perlman)

4. 행동주의 모델 (Behavioral Model):
→ 강화·학습 원리 적용
→ 행동 변화 목표
→ 조작적 조건화 기법 활용

5. 역량 강화 모델 (Empowerment Model):
→ 클라이언트 강점·자원 활용
→ 권력 불평등 해소
→ 클라이언트를 전문가로 인정
```

## 사례 관리 (Case Management)

```
사례 관리의 정의:
→ 복합적 욕구를 가진 클라이언트에게
  다양한 서비스를 통합·조정·연계하는 실천 방법

사례 관리가 필요한 경우:
→ 만성질환·장애·노인 등 복합 서비스 필요
→ 단일 서비스로 해결 어려운 경우

사례 관리 과정:
1. 사례 발견 및 스크리닝
2. 사정 (욕구·강점·자원 파악)
3. 서비스 계획 수립
4. 서비스 연결 및 조정
5. 모니터링
6. 평가 및 종결

사례 관리자의 역할:
- 중개자 (Broker): 자원 연결
- 옹호자 (Advocate): 권리 대변
- 교육자 (Educator): 정보·기술 제공
- 조정자 (Coordinator): 서비스 통합
```

## 면접 기술

```
기본 면접 기술:

1. 경청 (Listening): 주의를 집중하여 듣기
2. 공감 (Empathy): 클라이언트 감정 이해·반영
3. 개방형 질문: "어떻게 느끼셨나요?" (폭넓은 응답 유도)
4. 폐쇄형 질문: "그때 몇 살이었나요?" (사실 확인)
5. 명료화: 모호한 내용 구체화 요청
6. 요약: 핵심 내용 정리·확인
7. 직면: 불일치 또는 모순 지적 (신중 사용)

면접 방해 요인:
- 조급한 조언
- 가치 판단적 언어
- 왜(Why) 질문 남용 (방어심 유발)
- 전문 용어 남용
```

## 핵심 암기 정리

```
시험 빈출:

바이스텍 7원칙:
개별화, 의도적 감정표현, 통제된 정서적 관여, 수용, 비심판적 태도, 자기결정, 비밀보장

실천 과정 6단계:
초기접촉 → 자료수집 → 사정 → 계획 → 개입 → 평가·종결

모델별 핵심:
- 심리사회: 상황 속의 인간
- 문제해결: 4P (Perlman)
- 역량강화: 강점 관점
```
