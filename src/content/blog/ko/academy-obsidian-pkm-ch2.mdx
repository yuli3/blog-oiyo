## Vault부터 이해하기

Obsidian에서 Vault는 노트가 들어 있는 로컬 폴더입니다. 하나의 Vault 안에 마크다운 파일, 첨부 파일, 설정이 함께 들어갑니다. 쉽게 말해 "내 지식 창고 폴더"입니다.

처음에는 Vault를 여러 개 만들기보다 하나로 시작하는 편이 좋습니다. 주제가 조금 달라도 한곳에 모아야 연결을 경험하기 쉽습니다.

## 설치 후 첫 설정

Obsidian은 데스크톱과 모바일에서 사용할 수 있습니다. 기본 앱은 로컬 파일을 중심으로 작동하며, 기기 간 동기화는 Obsidian Sync, iCloud, Dropbox, Git 등 여러 방식으로 구성할 수 있습니다. 동기화 방식마다 장단점이 있으므로 데이터 안정성을 먼저 확인해야 합니다.

처음 설정은 간단하게 시작합니다.

1. 새 Vault를 만든다.
2. `Inbox`, `Notes`, `Projects`, `Archive` 정도의 폴더만 만든다.
3. 매일 기록할 노트 하나를 만든다.
4. 필요할 때만 폴더를 추가한다.

## 마크다운 기본 문법

Obsidian 노트는 기본적으로 `.md` 파일입니다. 자주 쓰는 문법은 많지 않습니다.

| 기능 | 문법 |
|------|------|
| 제목 | `# 제목`, `## 소제목` |
| 굵게 | `**중요한 말**` |
| 목록 | `- 항목` |
| 체크박스 | `- [ ] 할 일` |
| 코드 | `` `짧은 코드` `` |
| 링크 | `[[노트 이름]]` |

마크다운의 장점은 단순함입니다. 꾸미기보다 생각의 구조를 남기는 데 집중할 수 있습니다.

## 첫 노트 예시

처음 노트는 거창할 필요가 없습니다.

```markdown
# AIEO를 공부하며 든 생각

AIEO는 SEO를 버리는 개념이 아니라, AI 검색이 이해하기 쉬운 구조를 더하는 관점이다.

관련 노트: [[E-E-A-T]], [[JSON-LD]], [[콘텐츠 구조]]
```

이렇게 짧은 노트도 나중에 링크를 통해 지식망의 일부가 됩니다.

## 핵심 요약

- Vault는 Obsidian 노트가 저장되는 로컬 폴더입니다.
- 처음에는 하나의 Vault와 단순한 폴더 구조로 시작하는 것이 좋습니다.
- Obsidian은 마크다운 파일을 기본으로 하므로 장기 보관과 이동성이 좋습니다.
- 첫 노트는 짧아도 괜찮으며 링크를 통해 나중에 확장할 수 있습니다.

다음 장에서는 링크, 백링크, 그래프뷰로 노트 사이의 관계를 만드는 방법을 배웁니다.
