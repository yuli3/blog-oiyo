## IELTS Speaking 특성

**시간**: 11~14분, 시험관과 1:1 대면 인터뷰

**TOEFL과의 차이**: 실제 사람과 대화하므로 **자연스러운 대화 능력**이 핵심

---

## Speaking 채점 기준

| 기준 | 평가 내용 |
|------|---------|
| Fluency & Coherence | 유창성, 논리적 연결 |
| Lexical Resource | 어휘 범위와 정확성 |
| Grammatical Range | 문법 다양성과 정확성 |
| Pronunciation | 발음 명확성 (완벽한 원어민 발음 불필요) |

---

## Part 1: 인터뷰 (4~5분)

**내용**: 가족, 직업, 취미, 고향 등 친숙한 주제

**전략**:
- 짧은 답변 금지 — YES/NO 대신 이유와 예시 추가
- "Could you tell me more about...?" 형식의 추가 질문에 대비

**예시 답변 구조 (IERI)**:
- **I**nitial answer: 바로 답변
- **E**xplain: 이유 설명
- **R**elevant example: 구체적 예시
- **I**nterest: 관심 표현 또는 마무리

---

## Part 2: Long Turn (3~4분)

**내용**: 카드에 제시된 주제로 1~2분 발화 (준비 시간 1분)

**카드 예시**: "Describe a time when you had to learn something new quickly."

### Part 2 준비 전략 (1분 활용)

```
주제/대상 (Who/What): 
시간/장소 (When/Where):
핵심 경험 (What happened):
느낀 점/이유 (Why important):
```

**발화 구조**:
```
"I'm going to talk about [주제]."
→ 배경 설명 (30초)
→ 핵심 내용 (45초)
→ 영향/결과/느낀 점 (30초)
```

---

## Part 3: 토론 (4~5분)

**내용**: Part 2 주제와 관련된 심층 토론, 사회적·추상적 주제

**Part 3 특징**:
- "더 깊이 생각해야" — 단순 경험이 아닌 분석·의견 필요
- 복잡한 문법 구조 활용 기회
- 이견도 표현 가능 ("Some might argue, but I believe...")

**예시 질문**: "Do you think technology has made it easier or harder to learn new skills?"

**답변 구조**:
```
의견 제시 → 이유 1 → 이유 2/대조 → 결론
"In my view, ... because ... Moreover, ... Therefore..."
```

---

## 발음 향상 팁

IELTS는 완벽한 영국식 발음을 요구하지 않습니다. **명확성(Clarity)**이 핵심.

- 강세(Stress): 중요한 단어를 강조
- 연음(Linking): "come over" → "comeOver"
- 억양(Intonation): 질문 시 올리기, 진술 시 내리기
