## 특별법의 위치와 중요성

**민사특별법 출제 비중**: 1차 민법 40문항 중 약 5~7문항

```
주요 특별법:
① 주택임대차보호법 — 주거용 임차인 보호
② 상가건물임대차보호법 — 상가 임차인 보호
③ 집합건물의 소유 및 관리에 관한 법률
④ 가등기담보 등에 관한 법률
```

## 주택임대차보호법 (주임법)

### 적용 범위

- **주거용 건물**: 실제 주거 목적 임대차
- **미등기·무허가 건물** 포함
- **일부 주거 사용**도 주거 부분에 한해 적용

### 핵심 3대 보호

#### 1. 대항력

```
요건: 주택 점유(입주) + 전입신고 완료
효력 발생: 전입신고 다음날 0시
```

**의미**: 임차주택이 양도·경매되어도 새 소유자에게 임차권 주장 가능.

```
타임라인 예시:
6월 1일: 전입신고
6월 2일 0시: 대항력 발생
6월 1일 설정된 근저당 → 임차인보다 선순위
6월 3일 설정된 근저당 → 임차인이 선순위
```

#### 2. 우선변제권

```
요건: 대항요건(점유+전입) + 확정일자 취득
효력: 경매 시 확정일자 기준으로 배당
```

**확정일자 취득처**: 주민센터, 공증사무소, 법원, 등기소  
**현재**: 임대차신고 시 자동 부여 가능

#### 3. 최우선변제권 (소액보증금 보호)

```
소액보증금 기준 (지역별 상이, 서울 기준):
- 보증금 1억 6,500만 원 이하 → 최우선변제
- 최우선변제 금액: 5,500만 원

→ 모든 담보권자보다 먼저 배당 (단, 경매개시결정 등기 이전에 대항요건 갖출 것)
```

### 임대 기간

```
최단 임대 기간: 2년 (임차인이 원하면 2년 보장)
묵시적 갱신: 만기 후 통보 없으면 동일 조건 자동 갱신
계약갱신청구권: 1회 행사 가능 (2년 추가)
인상 제한: 갱신 시 5% 이하
```

## 상가건물임대차보호법 (상가임대차법)

### 적용 범위

```
적용 조건:
① 사업자 등록 신청 + 영업 개시
② 환산보증금이 지역별 기준 이하

환산보증금 = 보증금 + 월세 × 100

서울 환산보증금 기준: 9억 원 이하
(초과 시 일부 조항만 적용)
```

### 핵심 보호

**대항력**: 사업자 등록 신청 다음날 0시부터 발생  
**우선변제권**: 사업자 등록 + 확정일자

**갱신 거절 최소 기간**: **10년** (임차인이 갱신 청구하면 최대 10년 보장)

**임대료 인상 상한**: **5%**

## 집합건물법

### 개요

**집합건물**: 아파트·오피스텔·상가 등 1동의 건물에 다수의 구분소유권이 성립하는 건물.

### 구분소유권

```
구성:
- 전유부분: 각 호수 (구분소유권 대상)
- 공용부분: 복도·계단·엘리베이터 (공유)
- 대지사용권: 대지에 대한 지분 (전유부분에 종속)
```

**대지사용권의 분리처분 금지**: 전유부분과 대지사용권은 분리 처분 불가 (원칙).

### 관리단과 관리인

```
관리단: 구분소유자 전원으로 당연 구성
관리단집회: 통상 의결 = 구분소유자 및 의결권 각 과반수
           규약 설정·변경 = 구분소유자 및 의결권 각 3/4 이상
```

## 가등기담보법

### 가등기담보

채무 불이행 시 부동산 소유권을 채권자에게 이전하기로 약정하는 담보 방식.

```
가등기담보의 실행:
채무 불이행 → 청산 절차 (청산금 지급)
→ 청산기간(2개월) 경과 → 본등기
```

**청산금**: 부동산 가치 - 채권액  
**후순위 권리자 보호**: 청산기간 중 후순위 담보권자에게 통지 의무

|------|---------|---------|
| 대항력 | 전입신고 다음날 0시 | 사업자등록 신청 다음날 0시 |
| 우선변제 | 대항요건 + 확정일자 | 대항요건 + 확정일자 |
| 최단 임대 기간 | 2년 | 1년 |
| 갱신 보장 기간 | 2년 (1회) | 10년 |

## 기출 핵심 문제

**Q1. 임차인이 6월 1일 전입신고 시 대항력 발생 시점은?**
> 6월 2일 0시. 전입신고 다음날 0시부터 발생.

**Q2. 최우선변제권과 우선변제권의 차이는?**
> 최우선변제권: 소액 보증금 → 담보권보다 우선. 우선변제권: 확정일자 기준 → 같은 날짜 담보권과 동순위 또는 후순위.

**Q3. 상가임대차법에서 임차인이 10년 갱신 청구가 가능한 의미는?**
> 임차인이 원하면 최초 계약 포함 총 10년까지 계약 갱신 청구권 행사 가능. 임대인의 정당 사유 없는 거절 금지.

**Q4. 집합건물의 대지사용권 분리처분 금지 원칙의 예외는?**
> 규약으로 달리 정한 경우, 또는 공정증서에 의해 분리처분 약정을 한 경우.
