## 과적합 (Overfitting)

머신러닝에서 가장 흔한 함정입니다.

<LectureTable
  title="과적합 vs 과소적합"
  headers={["문제", "정의", "비유", "해결책"]}
  rows={[
    ["과적합 (Overfitting)", "훈련 데이터는 완벽하나 새 데이터에 실패", "시험 문제만 외워 시험 봄", "더 많은 데이터, 규제(Regularization)"],
    ["과소적합 (Underfitting)", "훈련 데이터도 제대로 학습 못함", "공부를 전혀 안 함", "더 복잡한 모델, 더 많은 학습"],
    ["적절한 적합", "훈련·테스트 모두 좋은 성능", "개념 이해 후 새 문제 풀기", "편향-분산 균형"],
  ]}
  highlightColumns={[1]}
/>

```
훈련/검증/테스트 데이터 분리가 필요한 이유:
→ 훈련 데이터(70%): 모델이 패턴 학습
→ 검증 데이터(15%): 하이퍼파라미터 튜닝
→ 테스트 데이터(15%): 최종 성능 평가 (한 번만 사용)

핵심: 테스트 데이터는 철저히 봉인
→ 개봉 전까지 절대 보지 않는다
→ 실제 세계의 미지 데이터를 시뮬레이션
```

<Callout type="important" title="데이터 누수 (Data Leakage)">
  테스트 데이터 정보가 훈련 과정에 스며들면 **데이터 누수**가 발생합니다. 모델은 테스트 성능이 좋지만 현실에서는 실패합니다. 실제 의료 AI 시스템 오류의 주요 원인 중 하나입니다.
</Callout>

## 핵심 암기 포인트

*지도학습: 라벨 데이터 → 패턴 학습 → 새 데이터 예측*
*강화학습: 시행착오 + 보상 → 알파고·자율주행의 엔진*
*과적합: 훈련 데이터 외워도 실제 세계에서 실패 → 테스트 분리 필수*
*머신러닝 ⊂ AI, 딥러닝 ⊂ 머신러닝, LLM ⊂ 딥러닝*
