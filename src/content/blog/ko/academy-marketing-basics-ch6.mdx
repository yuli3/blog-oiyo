## 촉진 믹스 구성 요소

```
광고 (Advertising):
유료·비인적·대중 매체
인지도·이미지 구축
TV·신문·온라인 광고

인적판매 (Personal Selling):
직접 대면·상호작용
B2B·고관여 제품에 효과적
즉각적 피드백

판매촉진 (Sales Promotion):
단기 구매 유인
쿠폰·할인·샘플·경품
유통업자·소비자 대상

PR (Public Relations):
기업·브랜드 이미지 관리
뉴스·이벤트·CSR
비용 대비 높은 신뢰도

다이렉트 마케팅:
직접 반응 유도
이메일·DM·카탈로그
```

## 광고 전략

```
광고 목표:
정보 제공형: 신제품 인지도
설득형: 구매 태도 변화
상기형: 기존 고객 유지

크리에이티브 전략:
USP(독특한 판매 제안): 차별적 특장점 강조
감정 소구: 두려움·유머·사랑
증거 소구: 테스트 결과·사용자 후기

미디어 믹스:
도달률: 노출 인원수
빈도: 평균 노출 횟수
GRP = 도달률 × 빈도
```

## 디지털 마케팅

```
검색 마케팅 (SEM):
SEO: 검색엔진 자연 노출
PPC: 검색어 광고

소셜 미디어:
인스타그램·유튜브·틱톡
인플루언서 마케팅
UGC(사용자 생성 콘텐츠)

콘텐츠 마케팅:
블로그·영상·인포그래픽
가치 있는 콘텐츠로 고객 유인
SEO와 연계

이메일 마케팅:
CRM 기반 개인화
자동화 시퀀스
높은 ROI
```

## PUSH vs PULL 전략

```
PUSH 전략:
제조사 → 중간상에게 판매 촉진
인센티브·리베이트·영업 지원
B2B·기업용 제품에 효과적

PULL 전략:
제조사 → 소비자에게 직접 촉진
소비자가 유통에 제품 요청
광고·소셜미디어·브랜딩 중심
소비재·FMCG에 효과적

혼합 전략:
현대적 접근: 양방향 동시 활용
```

## 핵심 개념 카드

**촉진믹스=광인판PR직** ★★★★★
: 광고·인적판매·판촉·PR·다이렉트.
*암기 포인트: 광인판PR직*

**PR=비용효율높은신뢰도** ★★★★★
: 광고보다 신뢰도 높지만 통제력 낮음.
*암기 포인트: PR=신뢰높음*

**PUSH=유통대상, PULL=소비자대상** ★★★★☆
: 촉진 방향에 따라 구분.
*암기 포인트: PUSH=밀기, PULL=당기기*

## 실전 퀴즈

**Q. 인플루언서 마케팅이 기존 광고보다 효과적일 수 있는 이유는?**
> 준거집단 효과: 팔로워들이 인플루언서를 신뢰. 타겟팅 정확: 팔로워=이미 관심 있는 집단. 콘텐츠 자연스러움: 광고임에도 거부감 낮음. 인게이지먼트: 좋아요·댓글 상호작용. 단, 허위 광고 규제·팔로워 신뢰성 문제 주의.

**Q. 판매촉진(쿠폰·할인)이 장기적으로 브랜드에 미치는 위험은?**
> 브랜드 가격 이미지 훼손. 소비자가 정가에 구매 거부 → 할인 기다림. 브랜드 충성도 감소 (가격 충성). 경쟁사 촉진 대응 → 가격 전쟁. 단기 매출엔 효과적이나 장기 브랜드 자산 손상. 프리미엄 브랜드에는 특히 위험.
