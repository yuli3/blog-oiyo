## 에너지 바우처란?

저소득 취약 계층이 겨울철 난방비 부담을 줄일 수 있도록 정부가 제공하는 바우처(이용권)입니다. 전기, 도시가스, 지역난방, 등유, 연탄 등 에너지 요금에 사용할 수 있습니다.

---

## 2024년 지원 금액

```
가구원 수에 따라 차등 지원:

1인 가구: 154,000원
2인 가구: 219,000원
3인 가구: 254,000원
4인 이상 가구: 296,000원

여름 바우처 (냉방 지원, 7~9월):
1인 가구: 55,700원
2인 이상 가구: 74,400원

→ 겨울(동절기)이 지원 금액 더 큼
```

---

## 신청 자격

```
기본 요건 (두 가지 모두 충족):

1. 소득 기준:
   - 기초생활수급자 (생계·의료·주거·교육급여 모두 해당)
   - 차상위계층

2. 가구 특성 기준:
   다음 중 하나 해당:
   - 노인 (만 65세 이상 가구원 있음)
   - 영·유아 (만 6세 미만 가구원 있음)
   - 장애인 (등록 장애인 가구원 있음)
   - 임산부
   - 중증 질환자·희귀 질환자·중증 난치 질환자
   - 한부모 가족
   - 소년소녀 가정
```

## 신청 방법

### 온라인 신청

```
복지로 홈페이지 (www.bokjiro.go.kr)
→ 회원 로그인 → 에너지 바우처 신청

에너지 바우처 홈페이지 (www.energyv.or.kr)
→ 신청 현황 조회 가능
```

### 오프라인 신청

```
거주지 관할 읍·면·동 주민센터 방문
→ 신청서 작성 + 신분증 지참
→ 현장에서 바우처 발급 or 우편 수령
```

### 신청 기간

```
동절기 (11월~다음해 4월 사용):
→ 9~10월 신청 (지역별 상이)

하절기 (7~9월 사용):
→ 5~6월 신청

→ 매년 신청 필요 (자동 갱신 안 됨)
```

## 사용 방법

### 전기 요금 사용

```
한국전력 고객 번호 등록 방식:
→ 에너지 바우처 카드를 전기 요금 청구 계좌로 연결
→ 자동으로 전기 요금에서 차감

혹은:
→ 한전 사이버지점에서 적용 신청
→ 전화 고객센터 123에서도 신청 가능
```

### 도시가스 사용

```
도시가스 고객 번호 등록:
→ 해당 도시가스 회사 고객 센터에 바우처 적용 신청
→ 가스 요금에서 자동 차감

지역별 도시가스 회사:
→ 서울도시가스, 코원에너지서비스, 예스코 등 지역별 상이
```

### 지역난방

```
한국지역난방공사 또는 지역 난방 회사에 신청:
→ 요금 청구서 고객 번호로 등록
```

### 등유·연탄·LPG

```
실물 카드형 바우처 사용:
→ 지정 판매점에서 현금처럼 사용
→ 에너지 바우처 홈페이지에서 지정점 검색
```

## 잔액 소멸 주의사항

```
동절기 바우처: 다음 해 4월 30일 소멸
하절기 바우처: 9월 30일 소멸

→ 소멸 전 반드시 사용
→ 미사용 잔액 이월 불가

잔액 확인:
→ 에너지 바우처 홈페이지 (energyv.or.kr) 로그인 후 조회
→ 고객 센터: 1600-3190
```

## 자주 묻는 질문

**Q. 기초수급자인데 노인이 없어도 신청할 수 있나요?**
A. 아닙니다. 에너지 바우처는 소득 기준(수급자·차상위)과 가구 특성(노인·영유아·장애인 등) 두 가지를 모두 충족해야 합니다. 가구 특성이 없으면 수급자도 신청 불가합니다.

**Q. 에너지 바우처로 편의점이나 마트에서 살 수 있나요?**
A. 아닙니다. 지정된 에너지(전기·가스·등유·연탄 등) 구매에만 사용할 수 있습니다.

**Q. 매년 새로 신청해야 하나요?**
A. 네, 매년 신청해야 합니다. 자동 갱신되지 않으므로 신청 기간을 놓치지 마세요.

**Q. 문화누리카드와 함께 받을 수 있나요?**
A. 두 제도 모두 수급 자격을 충족하면 동시에 신청 가능합니다. 각각 별개 제도입니다.
