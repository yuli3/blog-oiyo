## 손해보험 개요

```
손해보험 특성:
실손보상원칙 적용
실제 손해액만 보상 (이중이득 금지)
단기 계약 (1년 주기 갱신)

손해보험 종류:
화재보험
자동차보험
해상보험
책임보험
상해보험·건강보험

보험가액 vs 보험금액:
보험가액: 보험 목적의 최대 손해 한도
보험금액: 계약 시 약정한 보험금 한도
```

---

## 화재보험

```
보장 내용:
화재로 인한 건물·재산 손해
소화 활동 손해 포함
폭발·벼락 특약 가능

약정가액 vs 시가:
약정가액: 계약 시 약정한 금액으로 보상
시가: 사고 시 현재 가치로 보상

기업 화재보험:
영업 중단 손실 (이익보험) 포함 가능
대기업 특수 위험
```

---

## 자동차보험 구조

```
의무 가입 (책임보험):
대인배상 I: 피해자 신체 손해 (법정 한도)
대물배상 (기본): 2천만원 이상

임의 가입:
대인배상 II: 책임보험 초과분
대물배상: 한도 증액
자기신체사고: 운전자 신체 손해
자기차량손해: 내 차 손해
무보험차상해: 상대방 무보험 시

보험료 산정:
연령·성별·사고이력·차종·담보 내용
```

## 해상보험

```
해상보험:
선박·화물의 해상 위험 담보
해상 사고·풍재·침몰

선박보험:
선박 선체 손해
피보험이익: 선박 소유자

적하보험:
화물 손해
수출입 무역에 필수

해상보험 특칙:
단독해손: 일부 손해 (각자 부담)
공동해손: 공동 이익을 위한 희생 손해
(모든 이해관계자 분담)
```

## 핵심 개념 카드

**손해보험=실손보상** ★★★★★
: 실제 손해 이상 보상 불가.
*암기 포인트: 손해보험=실손*

**자동차보험=대인I대물의무** ★★★★★
: 대인배상I과 대물배상은 의무 가입.
*암기 포인트: 대인I+대물=의무*

**공동해손=이해관계자분담** ★★★★☆
: 공동 이익을 위한 희생 손해는 모두 분담.
*암기 포인트: 공동해손=분담*

## 실전 퀴즈

**Q. 자동차보험에서 대인배상I과 대인배상II의 차이는?**
> 대인배상I: 의무 가입, 피해자 신체 손해, 법정 한도 내 보상. 대인배상II: 임의 가입, I 초과분 무한 보상 (무한 특약 가능). 예: 사망 손해액 5억, 대인I 한도 2억 → 대인II로 3억 추가 보상. 대인II 미가입 시: 초과분 운전자 개인 부담. 핵심: 대인II 무한 가입 = 사고 시 경제적 파국 방지.

**Q. 일부보험(underinsurance)에서 보상 계산 방법은?**
> 일부보험: 보험금액 < 보험가액. 보상액 = 손해액 × (보험금액 / 보험가액). 예: 보험가액 1억, 보험금액 5000만원, 손해 3000만원. 보상액 = 3000만 × (5000만/1억) = 1500만원. 취지: 보험료를 낮추기 위해 저가 가입한 것에 대한 불이익. 완전 보험 = 손해액 전액 보상.
