# 전세 보증금 반환 계산기

전세 계약 시 가장 중요한 것은 **만기 시 보증금을 온전히 돌려받을 수 있는지** 확인하는 것입니다. 집주인의 신용이나 의도보다 **집의 실제 가치와 선순위 채권**이 핵심입니다.

## 전세 안전도 계산 원리

**안전 공식**: (전세 보증금 + 선순위 근저당) ÷ 집 시세 × 100

| 비율 | 판정 | 의미 |
|---|---|---|
| 70% 이하 | ✅ 안전 | 경매 낙찰 후 보증금 회수 가능 |
| 70–80% | ⚠️ 주의 | 경매 낙찰가 하락 시 손실 위험 |
| 80–90% | 🔶 위험 | 깡통전세 가능성 높음 |
| 90% 초과 | 🚨 고위험 | 계약 재고 강력 권고 |

<Callout type="warning">
**전세가율 80% 기준**: KB국민은행·한국감정원의 '안심전세 앱'은 전세가율 80% 이하를 안전 기준으로 봅니다. 80% 초과 시 전세보증보험(HUG·SGI서울보증) 가입을 반드시 검토하세요.
</Callout>

## 전세사기 예방 체크리스트

| 확인 항목 | 방법 |
|---|---|
| 등기부등본 확인 | 계약 직전·잔금일 당일 발급 |
| 선순위 근저당 확인 | 등기부 을구 항목 |
| 건축물대장 확인 | 위반건축물 여부 |
| 집주인 신분증 대조 | 등기부 소유자와 일치 여부 |
| 전입신고·확정일자 | 잔금일 당일 즉시 처리 |
| 전세보증보험 가입 | 보증금 보호 안전망 |

## 전세보증보험 종류
