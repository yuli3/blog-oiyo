## 사회복지의 의의

```
사회복지 (Social Welfare):
모든 국민이 인간다운 생활을 할 수 있도록
국가와 사회가 제공하는 서비스·지원 체계

사회보장:
출산·양육·실업·노령·장애·질병·빈곤
→ 사회적 위험에서 보호하는 제도

사회복지 이념:
보편성: 모든 국민 대상
평등성: 균등한 서비스
적절성: 최저 생활 보장 이상

헌법 근거:
헌법 제34조: 인간다운 생활권
헌법 제36조: 건강권, 가족 보호
```

## 사회보장기본법

```
사회보장기본법:
사회보장 제도의 기본 원칙 규정

사회보장의 정의:
사회보험·공공부조·사회서비스의 총합

사회보험:
사회적 위험 대비 보험 (국민연금·건강보험 등)
기여(보험료) 기반

공공부조:
국가 재원으로 저소득층 지원
기여 없이 자산 조사 후 지원

사회서비스:
복지·의료·교육·고용·주거 등
직접 서비스 제공

사회보장위원회:
국무총리 산하 심의·조정 기구
```

## 사회복지 급여의 원칙

```
보충성 원칙:
개인·가족·민간이 먼저, 국가는 보충
공공부조의 핵심 원칙

신청주의:
수급자가 직접 신청
예외: 직권조사 가능

현물 급여:
물품·서비스 직접 제공

현금 급여:
금전 직접 지급

자산 조사:
공공부조 지급 전 재산·소득 확인
소득 기준 이하에게만 지급
```

## 핵심 개념 카드

**사회보장 3분류** ★★★★★
: 사회보험+공공부조+사회서비스.
*암기 포인트: 보보서 3분류*

**사회보험 vs 공공부조** ★★★★★
: 사회보험=기여(보험료)+보편. 공공부조=무기여+자산조사+선별.
*암기 포인트: 보험=기여, 부조=무기여*

**보충성 원칙** ★★★★☆
: 개인→가족→민간→국가 순서. 국가는 마지막.
*암기 포인트: 보충성=국가는 마지막*

## 실전 퀴즈

**Q. 사회보험과 공공부조의 재원과 수혜 방식의 차이는?**
> 사회보험: 가입자(근로자+사용자)가 보험료 납부. 납부 이력 기반 수혜. 소득 비례. 공공부조: 세금(국가 재원). 자산 조사 후 기준 이하에게만 지급. 기여 없어도 수혜.

**Q. 사회서비스가 사회보험·공공부조와 다른 점은?**
> 사회보험·공공부조: 주로 금전 급여. 사회서비스: 복지·의료·보육·고용 등 직접 서비스 제공. 돈이 아닌 서비스 자체 제공. 최근 바우처 방식으로 일부 현금화.
