## 유통관리사 자격증이란?

유통관리사는 대한상공회의소가 주관하는 국가공인 자격증으로, 유통 산업 전반에 대한 전문 지식을 검증합니다. 유통업체, 제조업체, 물류기업 취업에 유리하며 대형 유통사 공채 우대 자격증으로도 알려져 있습니다.

```
주관: 대한상공회의소
등급: 1급 / 2급 / 3급 (3급은 유통 관련 실무 지식)
시험 회차: 연 3회 (3월, 6월, 9월 또는 11월 경)
합격 기준 (2급): 각 과목 40점 이상 + 평균 60점 이상
```

## 시험 과목 (2급 기준)

```
총 4과목 (각 25문제):

1과목: 유통물류일반
→ 유통의 개념, 유통 경로, 도·소매업, 유통 정책

2과목: 상권분석
→ 입지 분석, 상권 조사, 경쟁 분석

3과목: 유통마케팅
→ 마케팅 믹스, 소비자 행동, 가격 전략, 판촉 전략

4과목: 유통정보
→ POS 시스템, SCM, CRM, 전자상거래

시험 형식: 객관식 5지선다
시험 시간: 과목당 30분 (총 120분)
```

## 유통의 정의와 기능

```
유통(Distribution)이란:
→ 생산자에서 소비자까지 재화와 서비스가 이동하는 과정
→ 장소적 불일치, 시간적 불일치, 수량적 불일치를 해소

유통의 3대 불일치 해소:
1. 장소적 불일치 → 운송 기능으로 해소
2. 시간적 불일치 → 보관·창고 기능으로 해소
3. 수량적 불일치 → 집하·분산 기능으로 해소
```

---

## 유통의 4대 기능

```
1. 교환 기능 (거래 기능):
   → 구매, 판매, 가격 결정 활동
   → 수요와 공급을 연결

2. 물적 유통 기능 (물류 기능):
   → 운송, 보관, 하역, 포장, 정보

3. 조성 기능:
   → 금융 (대금 결제), 위험 부담, 시장 정보 수집

4. 표준화 기능:
   → 품질 기준 설정, 등급화, 검사
```

## 유통 경로 (Distribution Channel)

```
유통 경로란:
→ 생산자 → (중간상) → 소비자까지의 경로 단계

소비재 유통 경로 유형:
0단계: 생산자 → 소비자 (직거래, 직판)
1단계: 생산자 → 소매상 → 소비자
2단계: 생산자 → 도매상 → 소매상 → 소비자
3단계: 생산자 → 대리인(중개인) → 도매상 → 소매상 → 소비자

산업재 유통 경로:
→ 주로 0~1단계 (직거래 비중 높음)
→ 대형 B2B 거래가 대부분
```

## 도매업과 소매업

```
도매업 (Wholesale):
→ 생산자 또는 제조업체로부터 대량 구매
→ 소매업자·기업에 재판매
→ 최종 소비자에게 직접 판매하지 않음
→ 거래 단위 大, 점포 노출 불필요

소매업 (Retail):
→ 최종 소비자에게 직접 판매
→ 소규모·개별 단위 거래
→ 소비자와 직접 접촉
→ 입지·점포 중요

소매업 유형:
- 백화점: 다양한 상품, 고가격, 고서비스
- 할인점: 저가격, 셀프서비스 (이마트, 홈플러스)
- 편의점: 근거리, 24시간, 소량 다품종
- 전문점: 특정 상품 전문화 (스포츠, 의류 등)
- 무점포 소매: 통신판매, TV홈쇼핑, 인터넷 쇼핑
```

## 중간상의 역할과 존재 이유

```
중간상이 필요한 이유:

1. 거래 수 감소의 원리:
   → 생산자 5명 × 소비자 5명 = 25회 거래 필요
   → 중간상 1명 개입 시 = 5 + 5 = 10회 거래로 감소

2. 위험 부담:
   → 재고 위험, 대금 미수 위험을 부담

3. 시장 정보 제공:
   → 소비자 동향, 경쟁사 정보 수집 전달

4. 신용 공여:
   → 소매상에 외상 거래 제공으로 자금 지원
```

## 수직적 유통 시스템 (VMS)

```
VMS (Vertical Marketing System):
→ 생산자·도매상·소매상이 하나의 시스템으로 통합

유형:
1. 기업형 VMS: 한 기업이 유통 단계 소유·통합 (자사 직영점)
2. 계약형 VMS: 계약으로 통합 (프랜차이즈 시스템)
3. 관리형 VMS: 힘(파워)을 가진 기업이 비공식 통합 (대형 유통사 협력업체 관리)

프랜차이즈 (Franchise):
→ 계약형 VMS의 대표 사례
→ 본사(프랜차이저)가 가맹점(프랜차이지)에 상호, 노하우, 지원 제공
```

## 핵심 요약 정리

```
시험 출제 포인트:

1. 유통의 정의: 생산자→소비자 재화 이동 과정
2. 3대 불일치: 장소적, 시간적, 수량적
3. 4대 기능: 교환, 물적유통, 조성, 표준화
4. 유통 경로 단계: 0단계(직거래)~3단계
5. 도매 vs 소매: 소비자 직접 판매 여부
6. 중간상 역할: 거래 수 감소, 위험 부담, 정보 제공
7. VMS 유형 3가지: 기업형, 계약형, 관리형
```

## 자주 묻는 질문

**Q. 유통관리사 2급은 취득하기 어렵나요?**
A. 합격률은 40~60% 수준으로 비교적 취득이 용이한 편입니다. 기본 이론 위주로 3~4주 집중 학습 시 취득 가능합니다.

**Q. 유통관리사가 취업에 도움이 되나요?**
A. 이마트, 롯데마트, GS리테일 등 대형 유통사 취업 시 우대 자격증으로 인정됩니다. 물류·유통·마케팅 직무 지원 시 경쟁력이 됩니다.
