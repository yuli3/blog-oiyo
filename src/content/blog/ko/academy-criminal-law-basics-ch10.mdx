## 미수·공범 핵심 정리

```
미수 종류:
장애미수: 외부 장애 → 임의적 감경
중지미수: 자의 중지 → 필요적 감경 또는 면제
불능미수: 결과 불가능 → 감경 또는 면제

공범:
공동정범: 공동 의사 + 공동 실행 → 각자 정범
교사범: 결의 유발 → 정범과 동일형
방조범: 실행 도움 → 필요적 감경

핵심: 중지미수=반드시 감경, 교사=동일, 방조=감경
```

## 위법성 조각·책임 조각 비교

```
위법성 조각:
정당방위: 현재 부당한 침해 → 방어 행위
긴급피난: 현재의 위난 → 제3자 희생
피해자 동의: 처분 가능 법익+동의
정당행위: 사회상규 위배 안 됨

책임 조각:
형사미성년자 (14세 미만): 불처벌
심신상실: 완전 불처벌
심신미약: 필요적 감경

원인에서 자유로운 행위:
자의로 심신상실 유도 → 감경 안 됨
```

## 자주 틀리는 오답 포인트

```
① 폭행죄=반의사불벌, 상해죄=아님
   → 폭행: 피해자 처벌 불원 시 불처벌
   → 상해: 피해자 의사와 무관하게 처벌

② 중지미수=반드시 감경, 장애미수=임의 감경
   → 중지: 자의로 멈춤=필요적 감경·면제
   → 장애: 외부 장애=감경 재량

③ 교사범=정범과 동일형
   → 단순히 시킨 사람이라고 가볍지 않음
   → 방조범만 필요적 감경

④ 형사미성년자=14세 미만
   → 10세·12세 아님. 14세 미만 형사책임 없음.
   → 소년법 적용은 별도 기준

⑤ 명예훼손=사실이어도 처벌
   → 진실 적시도 공연성+훼손=범죄
   → 공공이익+진실이면 위법성 조각

⑥ 자백만으로 유죄 불가
   → 자백+보강증거 필요
   → 보강증거 없으면 무죄

⑦ 뇌물죄=직무관련성 필수
   → 직무 무관한 금품=뇌물죄 아님
   → 청탁금지법(김영란법)은 별도 적용

⑧ 사기죄=기망+재물 취득
   → 기망 없는 차용=사기 아님
   → 처음부터 갚을 의사 없으면 기망 성립

⑨ 준강도=강도와 동일형
   → 절도 기회에 폭행·협박
   → 절도죄가 아닌 강도죄로 처벌

⑩ 현행범=영장 없이 체포
   → 영장주의 예외 (긴급체포·현행범)
   → 48시간 내 영장 청구 또는 석방
```

## 실전 퀴즈 (종합)

**Q. 형법 제310조 위법성 조각 요건과 명예훼손죄의 관계는?**
> 형법 307조 명예훼손은 사실 적시도 처벌. 단, 310조: 진실한 사실+공공의 이익 목적이면 위법성 조각. 언론 보도·공익제보 등이 대표 적용 예. 두 요건 모두 충족해야 조각.

**Q. 방조범이 정범보다 형이 가벼운 이유는?**
> 방조범은 이미 범행을 결심한 정범을 도울 뿐, 범죄 결의 자체에 기여하지 않음. 범행에 대한 인과기여도가 정범이나 교사범보다 낮음. 형법은 기여도에 따른 차별적 처우 원칙.
