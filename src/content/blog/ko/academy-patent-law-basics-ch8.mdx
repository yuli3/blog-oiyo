## 속지주의와 국제 출원 필요성

```
속지주의 원칙:
특허권은 등록 국가 내에서만 유효
해외 보호 위해 각국 개별 출원 필요

국제 출원 경로:
파리조약 경로: 각국 직접 출원
PCT 경로: 하나의 출원으로 다수 국가

비용 고려:
각국 번역·관납료·변리사 비용
우선 국가 선정이 핵심 전략
```

---

## 파리조약 우선권

```
우선권 제도:
최초 출원일로부터 12개월 내 타국 출원 시
최초 출원일(우선일)을 출원일로 인정

효과:
최초 출원 후 타국에서 동일 발명 공개돼도
신규성·진보성 판단 시 최초 출원일 기준

절차:
우선권 주장 신청 + 우선권 서류 제출
출원 시 우선권 주장 명시

기간:
특허·실용신안: 12개월
상표·디자인: 6개월
```

## PCT 출원 제도

```
PCT (특허협력조약):
하나의 국제 출원으로 모든 PCT 회원국 보호 가능
세계지식재산기구(WIPO) 관할

PCT 출원 단계:
국제 단계: 하나의 출원서 제출
국내 단계 진입: 각국 심사 (30개월 이내)

주요 이점:
출원일 확보: 하나의 출원으로 다국 우선일 확보
심사 결과 참고: 국제조사보고 활용
비용 분산: 30개월 유예로 상업성 확인 후 결정

국제조사:
신규성·진보성 예비 판단
국제조사보고서 (ISR) 발행
```

## 해외 출원 전략

```
출원 국가 선정 기준:
주요 시장 국가
경쟁사 위치 국가
제조 기지 국가

미국 특허 특이점:
provisional 출원 (가출원) 12개월 유예
AIA (미국발명법): 선원주의로 전환
디자인 특허: 별도 출원 필요

유럽 특허청 (EPO):
단일 출원으로 유럽 특허 취득
각국 번역·등록은 별도
유니터리 특허: 일부 EU국 단일 효력

중국 특허:
발명·실용신형·외관설계 3종
국내 보유 기술 중국 출원 전 국내 출원 먼저
```

## 핵심 개념 카드

**파리조약우선권=12개월** ★★★★★
: 최초 출원 후 12개월 내 타국 출원 시 우선일 소급.
*암기 포인트: 파리조약=12개월*

**PCT=30개월국내단계** ★★★★★
: PCT 국제 출원 후 30개월 이내 각국 국내 단계 진입.
*암기 포인트: PCT=30개월*

**상표·디자인우선권=6개월** ★★★★☆
: 특허·실용신안(12개월)과 달리 상표·디자인은 6개월.
*암기 포인트: 상표디자인=6개월*

## 실전 퀴즈

**Q. 스타트업이 PCT 출원을 선택하는 전략적 이유는?**
> 비용 분산: 30개월 유예로 각국 진입 비용을 사업 성장 후 결정. 시장 확인: 제품 반응 보고 출원 국가 선정. 우선일 확보: 하나의 출원으로 전 세계 우선일 확보. 투자 유치: PCT 출원 = 잠재적 해외 특허 포트폴리오로 기업 가치 제고. 국제조사보고로 등록 가능성 사전 판단. 단점: PCT 출원 비용 자체도 수백만 원.

**Q. 파리조약 우선권과 PCT의 차이점을 설명하라.**
> 파리조약: 각국 직접 출원 + 우선권 주장. PCT: 단일 출원으로 모든 PCT 회원국 커버. 파리조약: 12개월 내 각국 개별 출원 필요. PCT: 30개월까지 국내 단계 진입 유예. 파리조약 비용: 출원 즉시 각국 비용 발생. PCT 비용: 분산 가능하나 초기 PCT 출원비 필요. 대규모 다국 출원 → PCT 유리.
