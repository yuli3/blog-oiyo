## 건물 감정평가의 원칙

**건물**: 토지 위에 영구적으로 부착된 구조물. 토지와 분리하여 독립 평가 가능.

```
건물 평가 원칙:
① 토지와 별도 평가 (원칙)
② 일괄 평가 (복합 부동산, 필요 시)
③ 최유효이용 전제

주요 평가 방법:
- 원가방식 (적산가액): 재조달원가 - 감가
- 비교방식: 유사 건물 거래사례 비교 (보조)
- 수익방식: 임대 건물은 NOI 환원 (보조)
```

## 건물 유형별 재조달원가

### 주거용 건물

```
단독 주택:
- 구조: 목구조·콘크리트·조적조
- 내용연수: 목구조 45년, RC조 60년
- 표준 건축비 = m² 단가 × 연면적

아파트·공동 주택:
- RC 구조 (철근콘크리트) 60–70년
- 설비 (EL·배관) 별도 감가 고려
- 공용 면적 배분 포함
```

### 상업용 건물

```
업무용 (오피스):
- SRC·철골조 60–70년
- 기계·설비 비중 높음 (EL·HVAC·소방)
- 감가: 내용연수법 + 기능적 감가 주의

판매 시설 (상가):
- RC·SRC 구조
- 설계 유연성·변경 가능성 고려

물류 창고:
- 철골조·조립식 (경량 30–40년)
- 단열·높이·하중 요건
```

### 특수 목적 건물

```
공장:
- 기계·설비와 건물 분리 평가
- 구조: 철골조 (40–50년)
- 고정 생산설비 = 기계기구로 별도

호텔·병원:
- 설비 비중 매우 높음
- 실질 내용연수 < 법정 내용연수
- 기능적 감가 별도 추정 필요
```

## 건물 감가수정 심화

### 내용연수 구분

```
법정 내용연수: 세법·감가상각 기준
경제적 내용연수: 실제 경제적 효용 종료 시점
물리적 내용연수: 구조 붕괴 전까지 기간

감정평가 적용: 경제적 내용연수 우선

표준 내용연수 (건물 구조별):
- 목구조: 45년
- 조적조·블록조: 40년
- 철근콘크리트(RC): 60년
- 철골철근콘크리트(SRC): 60~70년
- 철골조: 40~50년
```

### 감가의 3요인 심화

```
물리적 감가:
- 경과연수에 비례
- 유지보수 양호 시 감가율 하향 조정 가능
- 사례: 외벽 균열·지붕 방수 불량·배관 노후

기능적 감가 (현실에서 중요):
- 층고 과소 (물류 창고·현대 오피스 부적합)
- 에너지 비효율 구조 (단열·창호 불량)
- 엘리베이터 노후·용량 부족
- 기준 변경으로 화장실 수 부족
- 치유 가능 감가: 수리비 < 가치 상승분 → 수리비 상당액
- 치유 불가능 감가: 시장 반응 반영

경제적 감가:
- 외부 환경 악화로 건물 가치 감소
- 사례: 주변 혐오 시설·교통 악화·경기 침체
- 건물·토지 모두 영향 → 토지에 귀속 여부 구분
```

## 건물 적산가액 계산 예시

```
대상 건물:
- RC 구조 오피스
- 내용연수: 60년
- 경과연수: 12년
- 재조달원가: 12억 원
- 기능적 감가 (EL 노후 치유 불가능): 5,000만 원

정액법 감가:
감가수정률 = 12/60 = 20%
물리적 감가 = 12억 × 20% = 2억 4,000만 원

기능적 감가 = 5,000만 원

적산가액 = 12억 - 2억 4,000만 - 5,000만
         = 9억 1,000만 원
```

## 건물 감정평가 실무 포인트

```
현장 조사 확인 사항:
① 건물 구조·층수·용도
② 사용승인일 (경과연수 기산점)
③ 증·개축 이력 (부분 감가 처리)
④ 유지보수 상태 (관찰감가 조정)
⑤ 용도 전환 가능성 (기능적 적합성)

증개축 처리:
- 원 건물과 증축 부분 분리하여 각각 내용연수 적용
- 또는 전체 내용연수 재산정 (실질 상태 반영)
```

## 핵심 개념 카드

**건물 내용연수 구분** ★★★★★
: 물리적(구조 유지)·경제적(효용 지속)·법정(세법). 감정평가는 경제적 내용연수 우선.
*암기 포인트: 감정평가 = 경제적 내용연수*

**기능적 감가 치유 가능성** ★★★★★
: 치유 가능 → 수리비 상당액 감가. 치유 불가능 → 시장이 반응하는 가치 손실.
*암기 포인트: 치유 가능=수리비, 불가능=시장반응*

**RC구조 내용연수 60년** ★★★★☆
: 철근콘크리트 60년. 목구조 45년, 철골조 40–50년. 실무 핵심 수치.
*암기 포인트: RC=60, 목=45, 철골=40~50*

## 실전 퀴즈

**Q. 오피스 건물에서 엘리베이터 노후로 교체 비용 3,000만 원이 들지만 교체 후 가치 상승이 4,000만 원 예상되면 어떤 감가인가?**
> 기능적 감가 (치유 가능). 치유 가능 = 수리비 < 가치 상승분이므로 감가액 = 교체 비용 3,000만 원.

**Q. 재조달원가 6억, 내용연수 40년, 경과 8년, 기능적 감가(치유불가) 2,000만 원일 때 적산가액은?**
> 물리적 감가율 = 8/40 = 20%. 물리적 감가 = 6억 × 20% = 1억 2,000만. 적산가액 = 6억 - 1억 2,000만 - 2,000만 = 4억 6,000만 원.
