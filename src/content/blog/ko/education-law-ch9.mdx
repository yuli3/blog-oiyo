## 소비자기본법

**소비자**는 사업자로부터 물품이나 서비스를 구매하는 사람. 사업자와 정보·협상력 불균형 때문에 법이 특별히 보호합니다.

```
소비자의 8대 기본권리:
1. 안전의 권리
2. 알 권리
3. 선택의 권리
4. 의견 반영의 권리
5. 피해보상 받을 권리
6. 소비자 교육 받을 권리
7. 단체 조직·활동 권리
8. 안전하고 쾌적한 환경에서 소비할 권리
```

## 전자상거래 소비자보호법

### 청약 철회권

인터넷·홈쇼핑 등 통신판매에서 소비자가 이유 없이 계약을 취소할 수 있는 권리.

```
청약 철회 기간:
상품 받은 날로부터 7일
(계약서 받은 날이 늦으면 그 날로부터 7일)

청약 철회 불가 사유:
1. 소비자 책임으로 상품 훼손
2. 사용으로 가치 현저히 감소 (화장품 개봉 사용 등)
3. 시간 지나 재판매 곤란 (식품 등)
4. 복제 가능 상품의 포장 훼손 (SW, 음반 개봉)
5. 용역·디지털콘텐츠 이미 제공 완료
```

### 사업자 의무

```
청약 철회 시 사업자 의무:
3일 이내 환급 (신용카드는 취소 처리)
배송비는 원칙상 소비자 부담
(단, 사업자 귀책 시 사업자 부담)
```

## 방문판매법·할부거래법

### 방문판매 (방문판매법)

집이나 직장으로 찾아와 판매하는 경우.

```
청약 철회: 계약 후 14일 이내
다단계 판매(MLM): 별도 규제
후원방문판매: 방문판매법 적용
```

### 할부거래 (할부거래법)

```
할부계약 청약 철회: 계약서 받은 날로부터 7일
할부 항변권: 신용카드사에도 주장 가능
선불식 할부거래: 상조업체 등 (소비자 보호 강화)
```

## 약관의 규제

**약관**은 사업자가 다수 거래를 위해 미리 작성한 계약 내용.

```
불공정 약관 무효 사유 (약관규제법):
- 고객에게 부당하게 불리한 조항
- 고객의 이익을 부당히 제한
- 사업자의 책임을 부당히 면제

명시·설명의무:
- 약관은 고객에게 교부해야
- 중요 사항은 설명해야
- 위반 시 해당 약관 조항 계약 내용 안 됨
```

## 개인정보보호법

### 개인정보란

**살아 있는 개인에 관한 정보**로서, 성명·주민등록번호 등에 의해 특정인을 알아볼 수 있는 정보.

```
개인정보 유형:
일반 정보: 이름, 주소, 연락처, 이메일
민감 정보 (특별 보호):
- 사상·신념, 노동조합·정당 가입
- 정치적 견해
- 건강·성생활 정보
- 유전자 검사 정보
- 범죄 경력
고유식별 정보: 주민등록번호, 여권번호, 운전면허번호
```

### 개인정보 처리 원칙

```
6가지 처리 원칙:
1. 목적 최소화: 목적에 필요한 최소한만
2. 목적 외 사용 금지
3. 안전한 관리
4. 정확성 유지
5. 투명한 처리
6. 책임성 확보
```

### 정보 주체의 권리

```
정보 주체(당신)의 6대 권리:
1. 처리 여부 확인 및 열람 청구
2. 정정·삭제 요구 (잊힐 권리)
3. 처리 정지 요구
4. 동의 철회
5. 손해배상 청구
6. 자동화된 결정 거부 (AI 프로파일링 등)
```

### 개인정보 수집·이용 동의

```
동의가 필요한 경우: 원칙
동의 없이 처리 가능한 경우:
1. 법률 규정
2. 계약 이행에 필수
3. 공공기관 법정 업무
4. 정보 주체·제3자 급박한 생명 위험
5. 개인정보처리자 정당한 이익 (이해관계 충돌 없는 경우)
```

### CCTV와 바이오 정보

```
CCTV 설치 요건:
- 안내판 설치 의무
- 목적 외 사용 금지
- 영상 보관 기간 제한

바이오 정보 (지문, 안면, 홍채):
- 민감 정보에 준하는 보호
- 별도 동의 필요
```

## 개인정보 침해 시 구제

```
행정적 구제:
- 개인정보보호위원회에 신고·조정 신청
- 한국인터넷진흥원(KISA) 신고센터

민사적 구제:
- 손해배상 청구
- 법정 손해배상: 300만 원 이하 (입증 없이도 청구 가능)

형사적 구제:
- 개인정보 불법 제공·유출: 5년 이하 징역 또는 5천만 원 이하 벌금
```

## 실전 응용 케이스

**케이스 1**: 온라인 쇼핑몰에서 옷을 샀는데 색깔이 달라서 반품하고 싶습니다. 입어봤습니다.

> 착용 후 외관상 변화가 없다면 청약 철회 가능(7일 내). 단, 착용으로 상품 가치가 현저히 감소했다면 불가. 사진과 달리 색이 다른 경우는 사업자 귀책 → 배송비도 사업자 부담.

**케이스 2**: 앱이 내 연락처 전체를 수집하려 합니다. 거부할 수 있나요?

> 연락처 전체가 서비스 제공에 필수가 아니라면 최소 수집 원칙 위반. 동의 거부 가능하며, 동의 거부를 이유로 서비스 제공 거부는 위법.
