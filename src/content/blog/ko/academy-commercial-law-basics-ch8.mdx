## 수표의 의의

```
수표 (Cheque):
발행인이 은행(지급인)에게 일정 금액 지급을 위탁하는 유가증권

수표의 특성:
① 지급 수단: 어음과 달리 신용 수단 아님
② 지급인=반드시 은행 (은행이 아닌 곳에는 발행 불가)
③ 일람불: 제시하면 즉시 지급 (만기 개념 없음)
④ 단기 제시: 10일 이내 제시 원칙

수표 법원:
수표법 (어음법과 별도 법률)
어음법 준용: 많은 규정 공통 (배서·항변 등)
```

## 수표 vs 어음 비교

```
┌──────────────┬────────────────┬────────────────┐
│ 구분         │ 수표           │ 어음           │
├──────────────┼────────────────┼────────────────┤
│ 지급인       │ 반드시 은행    │ 누구든 가능    │
├──────────────┼────────────────┼────────────────┤
│ 만기         │ 없음 (일람불)  │ 있음 (기한부)  │
├──────────────┼────────────────┼────────────────┤
│ 인수         │ 없음           │ 있음 (환어음)  │
├──────────────┼────────────────┼────────────────┤
│ 기능         │ 지급 수단      │ 신용·지급 수단 │
├──────────────┼────────────────┼────────────────┤
│ 제시 기간    │ 10일           │ 만기일 ± 2영업일│
└──────────────┴────────────────┴────────────────┘
```

## 수표 기재 사항

```
필수 기재 사항:
① 수표 문구
② 무조건 일정 금액 지급 위탁
③ 지급인 (은행)
④ 지급지
⑤ 발행일·발행지
⑥ 발행인 기명날인

임의 기재 사항:
수취인 이름 (기재 없으면 소지인 지급)
횡선 (선긋기)

백지수표:
기재 사항 일부 공백 + 보충권 부여
보충권 범위 내에서 보충한 경우 유효
```

## 횡선수표·선 긋기

```
횡선수표:
수표 앞면에 평행선 2개 그은 수표
은행에만 지급 가능 → 현금화 제한

일반횡선: 평행선 사이 아무 기재 없음
→ 아무 은행에나 지급 가능

특정횡선: 평행선 사이 특정 은행명 기재
→ 그 은행에만 지급 가능

횡선의 목적:
수표 도난·분실 시 현금화 방지
지급 경로 추적 가능

자기앞수표:
은행이 스스로 발행한 수표
발행인=지급인이 같은 은행
신용도 최고 (은행 자체 지급 보증)
```

## 수표 지급과 소구

```
제시 기간:
발행일로부터 10일 이내 지급 제시
(국내 발행·국내 지급 기준)

기간 경과 효과:
지급 거절 가능 (단, 자금 있으면 임의 지급 가능)
배서인 등 소구의무자에 대한 소구권 소멸

지급 거절:
지급 거절 증서 작성 또는 거절 문언 기재
→ 소구 가능

부도수표:
자금 부족 또는 거래 정지로 지급 불능
부도수표 남발: 부정수표단속법 적용 (형사 처벌)
```

## 핵심 개념 카드

**수표=일람불** ★★★★★
: 수표는 만기가 없고 제시하면 즉시 지급. 어음은 만기일에 지급.
*암기 포인트: 수표=즉시지급, 어음=만기지급*

**수표 지급인=은행** ★★★★★
: 수표 지급인은 반드시 은행. 어음은 누구든 지급인 가능.
*암기 포인트: 수표=은행만*

**횡선수표=은행 통해서만** ★★★★☆
: 횡선수표는 은행에만 지급. 현금 직접 수령 불가.
*암기 포인트: 횡선=은행경유*

## 실전 퀴즈

**Q. 횡선수표를 현금으로 즉시 받지 못하는 이유는?**
> 횡선수표는 은행(금융기관)으로만 지급받을 수 있음. 현금으로 직접 교환 불가. 수표 도난·분실 시 부정 현금화 방지 목적. 계좌로만 입금 가능.

**Q. 자기앞수표가 일반 수표보다 신용도가 높은 이유는?**
> 자기앞수표는 은행이 발행인이자 지급인. 은행 자체 신용으로 지급 보증. 개인·기업이 발행한 수표는 자금 부족 시 부도 가능하지만, 자기앞수표는 은행 지급 능력이 보증.
