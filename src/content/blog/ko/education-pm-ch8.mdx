## 조달 관리란

프로젝트에서 필요한 제품·서비스·결과물을 외부에서 구매하거나 계약하는 전 과정을 관리합니다.

```
Make vs Buy 결정:
내부 제작: 핵심 역량, 기밀 유지, 비용 절감 (장기)
외부 조달: 전문성 부족, 단기 필요, 비용 절감 (단기)

→ 비용·시간·품질·리스크를 종합 비교
```

---

## 계약 유형 — 가장 중요한 개념

### 1. 고정가 계약 (Fixed Price, FP)

```
총 고정가 계약 (FFP - Firm Fixed Price):
→ 가장 일반적
→ 공급업체가 가격 고정 → 비용 초과 리스크는 공급업체 부담
→ 범위가 명확할 때 유리

가격 인센티브 고정가 (FPIF):
→ 목표 달성 시 인센티브, 초과 시 페널티
→ 공급업체 동기 부여

경제적 가격 조정 고정가 (FPEPA):
→ 장기 계약, 인플레이션 반영 가능
```

### 2. 원가 정산 계약 (Cost-Reimbursable, CR)

```
원가 + 고정 수수료 (CPFF):
→ 실제 비용 + 사전 합의 고정 이익
→ 범위 불명확할 때 사용
→ 비용 초과 리스크는 발주자 부담

원가 + 인센티브 수수료 (CPIF):
→ 비용 절감 시 절감분 공유

원가 + 성과 수수료 (CPAF):
→ 성과 기준에 따라 수수료 결정
```

### 3. 시간·자재 계약 (T&M - Time and Materials)

```
→ 단가(시간당·단위당) 사전 합의
→ 총량은 미정
→ 중간 규모 리스크 (발주자·공급업체 공유)
→ 소규모 작업, 기간 불명확할 때 적합
```

## 리스크 관점의 계약 유형 비교

```
발주자 리스크 낮음 ←————————→ 발주자 리스크 높음
      FP          T&M            CR
공급업체 리스크 높음 ←————————→ 공급업체 리스크 낮음
```

## 조달 프로세스

```
1. 조달 계획 수립
   → Make/Buy 결정
   → 계약 유형 선정
   → 조달 문서 준비 (RFP, RFI, IFB)

2. 조달 수행 (입찰·제안서 평가)
   → 공급업체 목록 작성
   → 제안서 평가 (기술 + 비용 + 회사 역량)
   → 협상 → 계약 체결

3. 조달 통제
   → 공급업체 성과 모니터링
   → 인도물 검수
   → 지불 처리
   → 계약 변경 관리

4. 조달 종료
   → 최종 검수·수락
   → 계약 공식 종료 문서 발행
```

## 입찰 문서 유형

```
RFI (Request for Information):
→ 시장 조사 목적
→ 어떤 업체가 있는지 파악

RFP (Request for Proposal):
→ 기술·방법론·비용 모두 제안 요청
→ 복잡한 프로젝트

RFQ (Request for Quotation):
→ 가격만 문의 (표준화된 제품·서비스)

IFB (Invitation for Bid):
→ 공공 조달 입찰 공고
```

---

## 공급업체 성과 관리

```
SLA (Service Level Agreement):
→ 서비스 품질 기준 명시
→ 예: 시스템 가용성 99.9%, 응답시간 &lt;4시간

성과 지표 (KPI):
→ 납기 준수율
→ 품질 결함률
→ 비용 편차율

공급업체 평가:
→ 정기 성과 검토 (월/분기)
→ 개선 계획 수립
→ 재계약 여부 결정
```

## 핵심 암기 포인트

*FP: 발주자 리스크 낮음, 범위 명확할 때 / CR: 발주자 리스크 높음, 범위 불명확*
*T&M: 중간 리스크, 단가 고정·물량 미정*
*RFP vs RFQ: RFP는 방법론+비용 전체 제안, RFQ는 가격만*
*조달 4단계: 계획 → 수행(입찰) → 통제(모니터링) → 종료*
