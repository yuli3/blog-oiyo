## N3 레벨의 이해

```
N3 레벨 기준:
→ 일상생활에서 사용되는 일본어를 어느 정도 이해 가능
→ 어휘: 약 3,000~5,000단어
→ 한자: 약 650자 (N5+N4+N3 누계)

N3 시험 구성:
→ 언어지식(문자·어휘): 30분 (50점)
→ 언어지식(문법)·독해: 70분 (60점)
→ 청해: 40분 (60점)
→ 합격 기준: 각 과목 19점 이상, 총 95점 이상 (180점 만점)

N3 난이도:
→ N4~N3: 중급 진입 (중요 분기점)
→ 일상 대화, 뉴스 일부 이해 수준
→ 한국인 평균 학습 시간: 300~500시간
```

## N3 핵심 문법 패턴 1

```
목적·의도 표현:

~ために (목적):
→ 의미: ~하기 위해서 (목적)
→ 접속: 동사 사전형 + ために
→ 일본어에 합격するために、毎日勉強している
  (일본어에 합격하기 위해 매일 공부하고 있다)
→ 주의: 의지 동사에만 사용

~ように (목적·바람):
→ 의미: ~하도록, ~하게 되도록
→ 접속: 동사 사전형/ない형 + ように
→ 忘れないように、メモした
  (잊지 않도록 메모했다)
→ 자연 현상, 능력 동사에도 사용 가능

~てしまう (완료·유감):
→ 의미: ~해 버리다 (완료+유감/실수)
→ 財布を忘れてしまった
  (지갑을 잊어버렸다)
→ 구어체: てしまう → ちゃう, てしまった → ちゃった

~ておく (준비·유지):
→ 의미: ~해 두다, 미리 ~하다
→ 旅行の前に、ホテルを予約しておく
  (여행 전에 호텔을 예약해 두다)
```

## N3 핵심 문법 패턴 2

```
비교·정도 표현:

~より~のほうが (비교):
→ A より B のほうが 형용사
→ 電車よりバスのほうが安い
  (전철보다 버스 쪽이 싸다)

~ほど~ない (비교):
→ A は B ほど~ない (B만큼 ~하지 않다)
→ 今日は昨日ほど寒くない
  (오늘은 어제만큼 춥지 않다)

~だけ / ~しか~ない:
→ だけ: ~만 (긍정·제한)
→ しか~ない: ~밖에 없다 (부정 형태)
→ 10分しかない = 10分だけしかない
  (10분밖에 없다)

변화·결과 표현:

~ようになる (변화):
→ ~하게 되다 (상태 변화)
→ 日本語が話せるようになった
  (일본어를 말할 수 있게 되었다)

~ことになる (결정·결과):
→ ~하게 되다 (외부 결정)
→ 来月、東京に転勤することになった
  (다음 달 도쿄로 전근하게 되었다)

~ことにする (결심):
→ ~하기로 하다 (자신의 결정)
→ タバコをやめることにした
  (담배를 끊기로 했다)
```

## N3 필수 어휘 분야별 정리

```
감정·상태 어휘:
→ 嬉しい (うれしい): 기쁘다
→ 悲しい (かなしい): 슬프다
→ 恥ずかしい (はずかしい): 부끄럽다
→ 羨ましい (うらやましい): 부럽다
→ 悔しい (くやしい): 분하다, 억울하다
→ 懐かしい (なつかしい): 그립다

시간 관련:
→ 以前 (いぜん): 이전
→ 以後 (いご): 이후
→ 最近 (さいきん): 최근
→ 当時 (とうじ): 당시
→ 突然 (とつぜん): 갑자기
→ やっと: 겨우, 드디어

행동 동사:
→ 諦める (あきらめる): 포기하다
→ 驚く (おどろく): 놀라다
→ 謝る (あやまる): 사과하다
→ 褒める (ほめる): 칭찬하다
→ 叱る (しかる): 꾸짖다
→ 迷う (まよう): 망설이다, 길을 잃다

N3 한자 빈출:
→ 経験 (けいけん): 경험
→ 計画 (けいかく): 계획
→ 機会 (きかい): 기회
→ 理由 (りゆう): 이유
→ 場合 (ばあい): 경우
→ 実は (じつは): 사실은
```

## N3 독해 전략

```
독해 문제 유형:
→ 내용 일치: 본문과 일치하는 것 고르기
→ 주제 파악: 이 글의 주제는?
→ 지시어 이해: 「それ」「この」가 가리키는 것
→ 문맥 추론: 빈칸에 들어갈 말

독해 핵심 전략:

1. 접속사 활용:
→ だから / そのため: 따라서 (결과)
→ しかし / でも: 그러나 (역접)
→ また / そして: 또한 (추가)
→ つまり / すなわち: 즉 (요약)

2. 키워드 찾기:
→ 줄임표(～)나 강조 표현 주목
→ 筆者は~と言っている (필자는 ~라고 말하고 있다)

3. 패턴 익히기:
→ 일본어 글의 구조: 주장 → 이유 → 예시 → 재강조
→ 결론은 마지막 문단에 자주 등장

독해 빈출 표현:
→ とても/非常に: 매우
→ むしろ: 오히려
→ ただし: 단, 다만
→ 一方 (いっぽう): 한편
→ そのため: 그 때문에
```

## N2 준비를 위한 N3 심화

```
N3→N2 격차 극복:

문법:
→ N3: 기본 복문 (~てしまう, ~ように, ~ために)
→ N2: 복합 표현 (~にとって, ~に対して, ~を通じて)
→ 준비: N2 문법 300선 병행

어휘:
→ N2 어휘: 6,000~10,000단어 수준
→ 카테고리별 학습: 뉴스 어휘, 비즈니스 어휘

한자:
→ N2 한자: 약 1,000자 (N3까지의 누계)
→ 읽기 + 쓰기 병행
→ 熟語 (じゅくご, 숙어) 파생어 학습

청해 강화:
→ N3 청해: 일상 대화, 라디오 수준
→ NHK Web Easy, YouTube 일본어 드라마 활용
→ 그림·도표 있는 문제: 먼저 그림 파악

N3 합격 후 로드맵:
→ N3 합격 → 6~12개월 집중 학습 → N2 도전
→ N2 합격 → 일본 취업·유학 지원 가능 수준
→ N1: 전문 분야 일본어 (학술·언론·고급 비즈니스)
```

## 자주 묻는 질문

**Q. N3와 N2의 실질적인 차이는 무엇인가요?**
A. N3는 일상생활 주제의 대화와 글을 이해하는 수준입니다. N2는 신문 기사, 비즈니스 문서, 공식적인 글을 어느 정도 이해할 수 있는 수준으로, 어휘와 문법의 복잡도가 크게 높아집니다. N3가 기초 완성이라면 N2는 실용적 일본어 활용의 시작점입니다.

**Q. JLPT는 말하기 시험이 없는데 의미가 있나요?**
A. JLPT는 읽기·듣기·문법 이해를 중심으로 평가하므로 회화 능력과는 다를 수 있습니다. 그러나 취업, 유학, 자격 요건으로는 공신력이 높습니다. 말하기 능력 향상은 언어 교환 파트너, 회화 학원, 일본 드라마 쉐도잉 등으로 별도로 보완하는 것이 좋습니다.
