## 한국 5대 궁궐

```
조선 궁궐의 특징:
→ 정궁: 법궁으로 정치·의례의 중심
→ 이궁: 비상시 대비 별궁 (창덕궁·창경궁)
→ 배치 원칙: 좌묘우사(左廟右社) — 왼쪽 종묘, 오른쪽 사직

경복궁:
→ 조선 법궁 (1395년 창건)
→ 광화문 → 흥례문 → 근정전(정전) → 사정전(편전)
→ 경회루: 국보, 왕실 연회장 (48개 돌기둥)
→ 향원정: 육각형 정자, 건청궁 내
→ 일제 강점기 훼손 → 복원 중

창덕궁 (세계문화유산):
→ 1405년 창건, 조선 이궁의 정궁
→ 인정전: 정전 (국보)
→ 비원(후원): 자연 지형 살린 정원 — 관광 가치 높음
→ 부용지·주합루·옥류천 계곡

창경궁:
→ 1484년 창건 (성종)
→ 일제 강점기 동물원·식물원 설치 → 1983년 복원
→ 통명전·명정전 (국보)

덕수궁:
→ 대한제국 정궁 (고종 시기)
→ 중화전·석조전 (르네상스 양식) 혼재
→ 개방감 있는 위치 → 시민 접근 용이

경희궁:
→ 서궐 (西闕) — 창덕궁 동궐의 상대 개념
→ 일제 강점기 대부분 훼손 → 일부 복원
```

## 불교 문화유산

```
삼국시대 불교 유입:
→ 고구려: 372년 (전진에서)
→ 백제: 384년 (동진에서)
→ 신라: 528년 (이차돈 순교 이후 공인)

사찰 건축 구조:
→ 일주문 → 천왕문 → 불이문 → 대웅전
→ 금당: 본존불 봉안 공간
→ 가람 배치: 1탑 1금당 → 쌍탑 1금당 (삼국~통일신라)

주요 사찰:
→ 불국사 (경주): 유네스코 세계문화유산
  석가탑(무영탑)·다보탑·청운교·백운교
  대웅전·비로전·극락전
→ 석굴암 (경주): 세계문화유산
  화강암 인공 석굴 → 본존불 비례·조각 예술의 극치
→ 해인사 (합천): 세계문화유산 (팔만대장경)
  장경판전 — 보존과학의 걸작 (통풍·습도 조절)
→ 송광사·선암사 (순천): 한국의 산지 승원
→ 통도사 (양산): 불보 사찰 — 금강계단에 부처 사리

석탑의 변천:
→ 목탑 → 석탑으로 발전
→ 백제: 익산 미륵사지 석탑 (최고 최대 석탑)
→ 신라: 감은사지 3층 석탑, 석가탑
→ 고려: 개성 경천사지 10층 석탑 (원의 영향)
→ 조선: 원각사지 10층 석탑 (국보, 탑골공원)
```

## 조선 왕릉과 민속 마을

```
조선 왕릉 (세계문화유산, 2009):
→ 조선 27대 왕 519년 (1392~1910) 왕과 왕비의 무덤
→ 42기 (수도권 40기 + 북한 2기)
→ 세계유산 등재 가치: 풍수지리 + 유교 의례 + 조경

능의 구조:
→ 홍살문 → 참도 → 정자각(제사 공간) → 능침(무덤)
→ 방향: 산을 등지고 물을 앞에 (배산임수)
→ 봉분 주위: 석인(문관·무관)·석수(호랑이·양 등)

주요 왕릉:
→ 동구릉 (구리): 9기 — 태조 건원릉(띠풀 봉분 독특)
→ 헌릉·인릉 (서초): 태종·순조
→ 선릉·정릉 (강남): 성종·중종
→ 서삼릉 (고양): 효릉 등

민속 마을:

하회 마을 (안동):
→ 물이 S자로 마을 감싸는 지형
→ 풍산 류씨 집성촌 (류성룡의 고향)
→ 하회탈·하회별신굿탈놀이 (유네스코 인류무형문화유산)

양동 마을 (경주):
→ 손씨·이씨 두 가문의 500년 전통 마을
→ 너와지붕·팔작지붕 조화
→ 유네스코 세계문화유산

안동 도산 서원:
→ 퇴계 이황 선생 학덕 기리는 서원
→ 한국의 서원 (9개 서원, 유네스코 등재)
```

## 자연 관광 자원

```
국립공원 (22개소):
→ 환경부 산하 국립공원공단 관리
→ 자연 공원법 기준 최고 등급 보호 지역

주요 국립공원:
→ 지리산: 한국 최초 국립공원 (1967), 최고봉 천왕봉 1915m
→ 설악산: 유네스코 생물권 보전 지역
  대청봉·울산바위·천불동계곡
→ 한라산: 세계자연유산 (제주)
  백록담·구상나무·천연보호구역
→ 북한산: 도심 근교 국립공원 (서울·경기)
  인수봉·백운봉·만경봉

제주 세계자연유산:
→ 한라산 천연보호구역
→ 성산 일출봉 (수성화산 응회구)
→ 거문오름 용암 동굴계 (만장굴·벵뒤굴)

지질 공원:
→ 유네스코 세계 지질 공원:
  제주 지질 공원 (화산 지형의 교과서)
  무등산권 지질 공원 (광주·전남·전북)
  청송 유네스코 세계 지질 공원

비무장지대 (DMZ):
→ 한반도 생태 보고 (60년 이상 자연 회복)
→ 철새 이동 경로·희귀종 서식
→ 평화 관광·역사 관광 자원
→ 판문점·도라산역·임진각

갯벌 (유네스코 세계자연유산, 2021):
→ 서천·고창·신안·보성-순천 갯벌
→ 생물다양성 핫스팟 (조류·저서생물)
```

## 관광 해설 기법

```
해설의 의미와 목적:
→ 프리먼 틸든 해설 원칙 (6가지):
  ① 방문객 관심사·개성과 연결
  ② 정보 전달이 아닌 계시(啓示)
  ③ 해석은 예술이다
  ④ 전체를 보이는 것이 목표
  ⑤ 어린이 해설 별도 접근 필요
  ⑥ 목적(자원 보존)이 먼저

해설 기법:

스토리텔링:
→ 단순 사실 나열 → 이야기 구조로 전달
→ 역사 인물 일화·전설·에피소드 활용
→ 청중 감정 이입 유도

시범 및 체험:
→ 직접 체험 > 설명 청취
→ 전통 음식 맛보기·공예 체험·의복 착용

질문 기법:
→ 개방형 질문 (Open-ended): 참여 유도
→ 수사적 질문: 생각 자극
→ 비교·대조 질문: 관광객 기존 지식 연결

외국인 관광객 대응:
→ 문화 차이 이해: 미국·유럽·중국·일본·동남아별 관심 차이
→ 비언어 소통: 제스처·표정·공간 감각
→ 어려운 역사 해설: 중립적·균형적 서술

안전 관리:
→ 단체 인원 파악·이동 시 선두·후미 관리
→ 응급처치 기본 지식 (AED 위치 파악)
→ 기상 악화·천재지변 대응 절차 숙지
```

## 자주 묻는 질문

**Q. 한국 궁궐 중 왜 창덕궁만 세계문화유산으로 등재되었나요?**
A. 창덕궁은 자연 지형을 최대한 살린 건축 배치와 뛰어난 후원(비원) 조경으로 유네스코의 탁월한 보편적 가치(Outstanding Universal Value) 기준을 충족했습니다. 특히 인공적으로 지형을 변형하지 않고 산세와 물길에 어울리게 건물을 배치한 방식이 높이 평가되었습니다. 경복궁이 화려한 규모와 의례적 정형성을 갖추었다면, 창덕궁은 자연과의 조화·인간적 척도·계절마다 변화하는 경관 등이 독특한 문화적 가치로 인정받았습니다.

**Q. 관광 해설을 할 때 가이드가 주의해야 할 점은 무엇인가요?**
A. 관광 해설의 핵심은 일방적인 정보 전달이 아닌 관광객이 스스로 의미를 발견하도록 돕는 일입니다. 과도한 세부 정보보다 감동과 인상을 남기는 핵심 이야기를 선택해야 합니다. 외국인 관광객에게는 자국 문화와 비교하는 맥락을 제공하면 이해가 깊어집니다. 또한 한국의 역사 중 민감한 사안(일제 강점기·남북 분단 등)은 편향 없이 균형 잡힌 시각으로 해설해야 합니다. 관광객 개개인의 반응을 살피며 설명 깊이와 속도를 조절하는 유연성도 중요합니다.
