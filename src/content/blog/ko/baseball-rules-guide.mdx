## 야구, 흐름만 잡으면 쉽다

야구는 규칙이 많아 보이지만 **공격(타격)과 수비(투구)를 번갈아 한다**는 큰 흐름만 잡으면 술술 읽힌다.

---

## 기본 구조 — 이닝과 공수 교대

```
경기: 9이닝(회). 각 이닝은 초(원정 공격)·말(홈 공격)로 나뉨.
공수 교대: 공격 팀이 3아웃 당하면 수비로 전환.
승부: 9이닝 후 점수가 많은 팀 승. 동점이면 연장.
인원: 수비 9명(투수·포수·내야 4·외야 3).
```

---

## 스트라이크·볼·아웃

<a id="strike-ball"></a>

```
스트라이크 존: 홈플레이트 위, 타자 무릎~가슴 사이.
- 스트라이크 3개 → 삼진 아웃
- 볼 4개 → 볼넷(1루 진루)
- 헛스윙·파울도 스트라이크(단, 2스트라이크 후 파울은 유지)

아웃 방법(주요):
- 삼진 / 뜬공 포구 / 땅볼 송구 후 베이스 터치
- 태그아웃(주자에게 공 태그) / 포스아웃
```

---

## 타격과 진루

| 결과 | 의미 |
|------|------|
| **안타(1·2·3루타)** | 친 공으로 안전하게 진루 |
| **홈런** | 담장을 넘김 → 주자 모두 + 타자 득점 |
| **볼넷/사구** | 4볼 또는 몸에 맞음 → 1루 |
| **번트** | 살짝 대 굴리는 작전 타격 |
| **희생플라이** | 아웃되며 주자를 진루·득점시킴 |

주자가 1→2→3루를 거쳐 **홈플레이트를 밟으면 1점**이다.

---

## 알아두면 좋은 규칙

```
- 포스/태그아웃: 주자가 반드시 가야 하면 포스아웃(베이스 터치),
  아니면 태그아웃(몸에 태그).
- 도루: 투구 중 주자가 다음 베이스로 훔치기.
- 더블플레이(병살): 한 번에 2아웃.
- 인필드플라이: 주자 있고 내야 뜬공 시 타자 자동 아웃(속임수 방지).
- 낫아웃: 2스트라이크서 포수가 3구를 놓치면 타자는 1루로 뛸 수 있음.
```

---

## 포지션과 번호

```
1 투수(P) · 2 포수(C) · 3 1루수 · 4 2루수
5 3루수 · 6 유격수 · 7 좌익수 · 8 중견수 · 9 우익수
(기록지에서 수비 번호로 쓰임 — 예: 6-4-3 병살)
```

---

## 핵심 요약

1. 9이닝, 3아웃이면 공수 교대, 점수 많은 팀 승.
2. 스트라이크 3개 삼진, 볼 4개 볼넷.
3. 1→2→3루 거쳐 홈을 밟으면 1점, 홈런은 즉시 득점.
4. 포스아웃(베이스 터치)과 태그아웃(몸 태그)을 구분한다.
5. 인필드플라이·낫아웃·도루 등은 흐름을 알면 쉽게 이해된다.

> 세부 규칙은 KBO·MLB 공식 규칙(Official Baseball Rules)에 따라 일부 차이가 있을 수 있다.
