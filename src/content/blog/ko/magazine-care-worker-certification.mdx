## 요양보호사란?

노인의 신체 활동 및 일상생활 지원을 전문으로 하는 직업입니다. **노인장기요양보험 서비스 제공자**로서 국가 자격증이 필요합니다.

---

## 요양보호사가 각광받는 이유

```
한국 고령화 속도:
2024년: 65세 이상 인구 19.2%
2026년: 20% 돌파 (초고령사회)
→ 노인 돌봄 수요 폭발적 증가

일자리 안정성:
- 경기 불황과 무관 (필수 복지 서비스)
- 60~70대도 취업 가능
- 경력 단절 여성 재취업 주요 루트
```

---

## 자격증 취득 방법

### 교육 과정 (자격증 취득 전제)

```
총 교육 시간:
- 이론: 80시간
- 실기: 80시간
- 실습: 80시간
합계: 240시간

교육 기관: 요양보호사 교육원 (전국 수백 개)
비용: 55만~100만원 (기관별 상이, 일부 무료 교육 지원)
```

### 무료 교육 지원 대상

```
다음에 해당하면 무료 or 큰 폭 할인:
1. 국민내일배움카드 보유자 (직업 훈련 지원)
   → 고용센터에서 발급 가능
2. 기초생활수급자
3. 50세 이상 재취업 희망자 (일부 지자체)

→ 교육 전 고용센터 상담 필수
```

### 시험 (자격 취득)

```
주관: 한국보건의료인국가시험원 (국시원)
시험 형식:
- 필기: 35문항 (120분)
- 실기: 45문항 (78분)

합격 기준:
- 각 영역 만점의 40% 이상
- 전체 평균 60% 이상

합격률: 보통 90% 이상 (비교적 쉬운 편)
시험 횟수: 연 4회 (3월·6월·9월·12월)
```

## 교육 내용 (무엇을 배우나)

### 이론 과목

```
1. 요양보호론 (노인 심리, 의사소통)
2. 기본 요양보호 각론 (신체 활동 지원)
3. 특수 요양보호 각론 (치매, 임종 케어)
4. 요양보호 기초기술 (건강 상태 체크)
```

### 실기 과목

```
- 구강 청결 돕기
- 세면·목욕 보조
- 식사 돕기
- 이동·보행 보조
- 와상 환자 체위 변경
- 낙상 예방
```

### 실습 (80시간)

```
장소: 요양원, 노인복지관, 노인 전문 병원 등
→ 실제 현장에서 어르신 케어 실습
→ 교육원에서 실습 기관 연결해 줌
```

## 취업처 종류

| 취업처 | 근무 형태 | 특징 |
|--------|---------|------|
| **노인 요양원** | 주간 8~12시간 | 안정적, 급여 높음 |
| **노인 재가 센터** | 하루 3~4시간 단위 | 유연 근무 가능 |
| **방문 요양** | 케어 횟수별 | 이동 필요 |
| **노인 병원** | 간호 보조 형태 | 의료 환경 |
| **주야간 보호 센터** | 낮 시간 근무 | 가정 양립 유리 |
| **가족 요양보호사** | 가족 돌봄 | 하루 1~2시간 제한 |

## 급여 수준 (2024년 기준)

### 월급

```
노인 요양원 (8시간 근무):
→ 최저임금 기준: 약 220~260만원/월
→ 경력 따라 상이

방문 요양 (3~4시간/일, 월 20일):
→ 시급 11,000~13,000원
→ 월 약 100~130만원 (단시간 근로)

요양원 야간 근무:
→ 야간 수당 포함 월 280~350만원
```

### 4대보험·복리후생

```
정규직 취업 시:
- 4대보험 가입 의무
- 주휴수당 포함
- 연차 유급휴가 (1년 이상)
단시간 근로 (주 15시간 이상):
- 주휴수당 발생
- 4대보험 가입
```

## 가족 요양보호사 특례

가족을 직접 돌보면서 급여를 받는 제도입니다.

```
조건:
- 수급자(부모님)가 장기요양등급 보유
- 가족이 요양보호사 자격증 취득
- 공단에 '가족 요양보호사'로 신청

급여:
- 1일 1~2시간 방문 인정
- 월 약 50~60만원 (시간·등급별)

제한:
- 동거 가족 원칙 (별거 가족은 조건부)
- 하루 2시간 이상 급여 인정 안 됨
```

## 취득 후 경력 개발

```
기본 요양보호사
→ 경력 3년 이상: 사회복지사 2급 과정 연계 가능
→ 재가 요양 센터 관리자 (팀장급)
→ 노인복지시설 생활 지도원
→ 치매 전문 요양보호사 자격 (추가 교육)
```

## 자주 묻는 질문

**Q. 나이가 많아도 취득할 수 있나요?**
A. 자격증 취득에 나이 제한이 없습니다. 실제로 50~70대 취득자가 많으며, 이 연령대가 요양 현장에서 오히려 선호되기도 합니다.

**Q. 남성도 요양보호사를 할 수 있나요?**
A. 물론입니다. 남성 요양보호사도 많으며 특히 남성 어르신 목욕 등에서 수요가 있습니다.

**Q. 경력 단절 주부가 국민내일배움카드로 무료로 취득할 수 있나요?**
A. 가능합니다. 고용센터에서 내일배움카드를 발급받고, 요양보호사 교육과정을 수강하면 대부분의 비용이 지원됩니다.
