## 소방공무원 시험 개요

```
소방공무원 시험 구분:
→ 소방사(공채): 필기·체력·면접
→ 소방교(경력경쟁): 특정 경력 보유자
→ 소방간부후보생: 상위 간부 양성 과정

필기 시험 과목 (소방사 공채):
→ 소방학개론 (공통)
→ 행정법총론 (공통)
→ 소방관계법규 (공통)
→ 선택: 화학·물리·생물 중 1과목

소방학개론 출제 비율:
→ 연소·화재론: 25%
→ 소화이론·소화약제: 20%
→ 소방시설: 20%
→ 위험물: 15%
→ 소방조직·법령: 10%
→ 재난관리·소방전술: 10%

합격 전략:
→ 연소·화재론: 기본 이론 완전 이해 필수
→ 소화약제: 종류·적응 화재 암기
→ 소방시설: 설치 기준과 작동 원리 연계
→ 위험물: 유별 성질·지정 수량 반복 암기
```

## 연소 이론

```
연소의 정의:
→ 가연성 물질이 산소와 결합해 빛과 열을 발생하는 산화 반응

연소의 3요소 (소화 원리의 기초):
→ 가연물 (Fuel): 탈 수 있는 물질
→ 산소 (Oxygen): 공기 중 약 21%
→ 점화 에너지 (Heat): 활성화 에너지

연소의 4요소 (연쇄 반응 포함):
→ 가연물 + 산소 + 점화 에너지 + 연쇄 반응
→ 연쇄 반응: 라디칼에 의한 자기 지속 반응

연소 형태:

기체 연소:
→ 확산 연소: 연료·산소 혼합 없이 경계면에서 연소
  예: 촛불, 가스레인지
→ 예혼합 연소: 미리 혼합 후 연소 (분젠버너)

액체 연소:
→ 증발 연소: 액체 표면 증발 → 증기가 연소
  예: 알코올, 가솔린
→ 분해 연소: 열에 의해 분해된 가스가 연소

고체 연소:
→ 표면 연소: 고체 표면에서 직접 연소 (숯, 코크스)
→ 분해 연소: 가열 시 가연성 가스 방출 → 연소
→ 증발 연소: 나프탈렌, 황 등
→ 자기 연소: 자체 산소 포함 (TNT, 셀룰로이드)

연소 생성물:
→ 완전 연소: CO₂, H₂O (이산화탄소, 물)
→ 불완전 연소: CO (일산화탄소) — 맹독성
→ 연기: 미연소 탄소 입자 + 증기
```

## 화재 분류

```
화재 분류 (한국 기준):

A급 화재 (일반화재):
→ 목재·종이·섬유·플라스틱 등
→ 연소 후 재(灰) 남음
→ 소화 방법: 냉각 소화 (물)
→ 표시색: 백색

B급 화재 (유류화재):
→ 가솔린·석유·알코올·유지류
→ 연소 후 재 없음
→ 소화 방법: 질식 소화 (포·CO₂·분말)
→ 물 주수 금지 (비산 위험)
→ 표시색: 황색

C급 화재 (전기화재):
→ 전기 설비·기계 등 통전 상태
→ 비전도성 소화약제 필수 (물 사용 감전 위험)
→ 소화 방법: CO₂·할론·분말
→ 표시색: 청색

D급 화재 (금속화재):
→ 마그네슘·나트륨·칼륨 등 가연성 금속
→ 물·CO₂ 사용 금지 (반응 위험)
→ 소화 방법: 건조사·팽창 질석·특수 분말
→ 표시색: 없음 (독립 분류)

K급 화재 (주방화재):
→ 식용유·동·식물유 화재
→ 주방 화재 특성: 재발화(재점화) 위험
→ 소화 방법: K급 소화기 (습식 화학)
→ 표시색: 없음 (별도 분류)
```

## 인화점·발화점·연소범위

```
인화점 (Flash Point):
→ 가연성 증기가 점화원에 의해 순간 연소하는 최저 온도
→ 외부 점화원 필요
→ 위험물 분류 기준
→ 예: 가솔린 -43°C, 에탄올 13°C, 경유 50°C 이상

발화점 (Ignition Point):
→ 외부 점화원 없이 스스로 연소하는 최저 온도
→ 자연 발화 기준
→ 예: 황 232°C, 목재 250~270°C, 석탄 250°C

자연 발화 (Spontaneous Ignition):
→ 외부 점화원 없이 물질 자체 발열로 화재 발생
→ 원인: 산화, 분해, 발효, 흡착열
→ 예: 기름 묻은 걸레, 생석회+물

연소 범위 (Flammable Range):
→ 공기 중 연소 가능한 가연성 가스 농도 범위
→ 하한계 (LEL): 농도 낮아 연소 불가 경계
→ 상한계 (UEL): 농도 높아 산소 부족 경계
→ 연소 범위 넓을수록 위험

주요 물질 연소 범위:
→ 수소 H₂: 4~75% (매우 넓음 — 위험)
→ 아세틸렌 C₂H₂: 2.5~81% (가장 넓음)
→ 메탄 CH₄: 5~15%
→ 프로판 C₃H₈: 2.1~9.5%
→ 가솔린: 1.4~7.6%
```

## 소화 원리와 소화약제

```
소화의 4가지 원리:

냉각 소화:
→ 연소 온도를 발화점 이하로 낮춤
→ 물: 비열·기화열이 크므로 냉각 효과 최대
→ A급 화재에 주로 사용

질식 소화:
→ 산소 농도를 15% 이하로 낮춤
→ CO₂·포·모래·불활성 기체
→ B급·C급 화재에 효과적

제거 소화:
→ 가연물 제거
→ 가스 밸브 차단, 화세 경계 목재 제거

억제 소화 (부촉매 소화):
→ 연쇄 반응을 화학적으로 차단
→ 할론·분말 소화약제
→ 소량으로 큰 효과

소화약제 종류:

물(Water):
→ 냉각 소화 주
→ A급 화재, C급·B급 일부 금지

이산화탄소(CO₂):
→ 질식+냉각 소화
→ B급·C급 화재 적합 (A급도 가능)
→ 전기 절연, 잔류물 없음
→ 밀폐 공간 질식 위험

분말 소화약제:
→ 제1종: NaHCO₃ (탄산수소나트륨) — B·C급
→ 제2종: KHCO₃ (탄산수소칼륨) — B·C급
→ 제3종: NH₄H₂PO₄ (인산암모늄) — A·B·C급 만능
→ 제4종: KHCO₃+요소 — B·C급

포(Foam) 소화약제:
→ 공기포·수성막포·합성포
→ B급 화재에 주 (유류)
→ 물보다 가벼워 유면 덮어 질식

할론(Halon) 소화약제:
→ 부촉매 소화
→ 오존층 파괴 → 몬트리올 의정서로 제한
→ 할로겐화합물(HFC, HFC, FK 등)으로 대체
```

## 자주 묻는 질문

**Q. C급 화재에 물을 사용하면 안 되는 이유는 무엇인가요?**
A. 물은 전기를 전도하므로 통전 중인 전기 설비에 물을 뿌리면 감전 사고가 발생할 수 있습니다. 또한 전기 기기에 물이 닿으면 기기 손상과 합선을 유발합니다. C급 화재에는 전기 절연성이 있는 CO₂, 할로겐화합물, 분말 소화약제를 사용해야 합니다. 만약 전원 차단이 완전히 이루어졌다면 A급 화재처럼 물로 소화할 수 있지만, 차단 확인 전에는 반드시 비전도성 소화약제를 사용해야 합니다.

**Q. 인화점이 낮을수록 위험한가요?**
A. 네, 인화점이 낮을수록 낮은 온도에서도 연소 가능한 증기가 발생해 화재 위험이 큽니다. 위험물안전관리법에서 제4류 위험물(인화성 액체)을 인화점에 따라 특수 인화물(-20°C 이하), 제1석유류(21°C 미만), 알코올류, 제2석유류(21~70°C)로 분류하는 이유도 이 때문입니다. 가솔린(-43°C)이 경유(50°C 이상)보다 훨씬 위험한 이유가 인화점 차이입니다.
