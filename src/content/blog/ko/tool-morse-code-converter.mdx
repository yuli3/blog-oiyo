# 모스부호 변환기

모스부호(Morse Code)는 1840년대 새뮤얼 모스가 발명한 전기 통신 시스템으로, 점(·)과 선(–)의 조합으로 문자를 표현합니다. SOS(···−−−···) 같은 조난 신호로도 유명하죠.

## 숫자 모스부호

| 숫자 | 모스부호 |
|---|---|
| 1 | ·–––– |
| 2 | ··––– |
| 3 | ···–– |

| 5 | ····· |
| 6 | –···· |

| 8 | –––·· |
| 9 | ––––· |
| 0 | ––––– |

<Callout type="tip">
**SOS**: ···−−−··· (점 3개·선 3개·점 3개). 국제 조난 신호로 1906년 채택. 실제 위기 상황에서는 물체로 땅에 쓰거나 손전등으로도 전송할 수 있습니다.
</Callout>

## 모스부호 규칙

- **점(·)**: 1단위 시간
- **선(–)**: 3단위 시간  
- **문자 내 간격**: 1단위 시간
- **문자 간 간격**: 3단위 시간
- **단어 간 간격**: 7단위 시간
