```
┌──────────────┬─────────────────┬──────────────┬──────────────┐
│ 보험         │ 관리 기관       │ 주요 급여    │ 보험료 부담  │
├──────────────┼─────────────────┼──────────────┼──────────────┤
│ 국민연금     │ 국민연금공단    │ 노령·장애·   │ 근로자+사업주│
│              │                 │ 유족연금     │ 각 4.5%      │

│ 건강보험     │ 국민건강보험공단│ 의료비 지원  │ 근로자+사업주│
│              │                 │              │ 각 약 3.55%  │
├──────────────┼─────────────────┼──────────────┼──────────────┤
│ 고용보험     │ 근로복지공단    │ 실업급여     │ 근로자+사업주│

├──────────────┼─────────────────┼──────────────┼──────────────┤
```

## 고용보험

### 실업급여 (구직급여)

```
수급 요건:
① 비자발적 이직 (해고·계약 만료 등)
② 이직 전 18개월 중 피보험 단위 기간 180일 이상
③ 적극적 재취업 활동

자발적 퇴사:
원칙적 수급 불가
예외: 임금 체불·회사 이전 등 불가피한 사유

지급액:
이직 전 평균임금의 60%
하한: 최저임금의 80%
상한: 1일 66,000원

지급 기간:
피보험 기간·나이에 따라 120~270일
```

### 육아휴직 급여

```
육아휴직 기간: 최대 1년
급여:
- 첫 3개월: 통상임금의 80% (상한 150만)
- 이후: 통상임금의 50% (상한 120만)

6+6 육아휴직 (2024년~):
부모 모두 첫 6개월 동시 또는 순차 사용 시
각 최대 월 200만 → 450만 지원

배우자 출산휴가:
10일 (무급·유급 조합)
```

## 산재보험

### 업무상 재해 인정

```
업무상 재해 요건:
① 업무상 사고: 업무 수행 중 사고
② 업무상 질병: 업무 기인성 질병
③ 출퇴근 재해: 통상 경로 이동 중

인정 기준:
업무 기인성 + 업무 수행성

산재 급여 종류:
- 요양급여: 치료비 전액
- 휴업급여: 평균임금의 70% × 쉬는 일수
- 장해급여: 장해 등급에 따른 지급
- 유족급여: 사망 시 유족에게 지급
- 간병급여: 간병 필요 시
```

### 산재보험 특징

```
사용자 전액 부담:
근로자 보험료 없음 (사용자만)

고의·과실 불문:
사용자 과실 없어도 보상
근로자 과실 있어도 보상 (중대 과실 예외)

제3자 과실:
산재보험 지급 후 → 근로복지공단이 제3자에게 구상권

산재보험 vs 민사 손해배상:
산재보험 수령 → 동일 사유 민사소송 일부 제한
(이중 배상 방지)
```

## 핵심 개념 카드

**산재보험 = 사업주 전부담** ★★★★★
: 4대보험 중 유일하게 사용자만 부담. 근로자 기여금 없음.
*암기 포인트: 산재=사업주 전부담*

**실업급여 수급 180일** ★★★★★
: 이직 전 18개월 중 피보험 단위 기간 180일 이상. 비자발적 이직.
*암기 포인트: 실업급여=180일+비자발적*

**실업급여 평균임금 60%** ★★★★☆
: 이직 전 평균임금 60%. 하한=최저임금 80%, 상한=1일 66,000원.
*암기 포인트: 실업급여=평균임금 60%*

## 실전 퀴즈

**Q. 자발적으로 퇴사한 근로자가 실업급여를 받을 수 없는 일반 원칙의 예외는?**
> 임금 체불 지속·회사 이전(통근 불가)·직장 내 괴롭힘·부당 처우 등 불가피한 사유. 이런 경우 실업 인정 가능.

**Q. 출퇴근 중 사고가 산재보험 급여 대상인 이유는?**
> 2017년 개정으로 통상적 출퇴근 경로·방법의 사고도 산재 인정(출퇴근 재해). 근로자 출퇴근 자체가 업무의 일부로 간주.
