## 마케팅 오답 포인트

```
① STP는 세분→표적→포지셔닝 순서
   → 포지셔닝 먼저 하는 것 아님

② 4P 중 Promotion = 광고만 아님
   → 광고·인적판매·판촉·PR 포함

③ 제품 수명주기 성숙기
   → 매출 최대, 이익 감소 시작
   → 경쟁 심화로 판촉비 증가

④ 스키밍 vs 침투 구별
   → 스키밍=도입기 고가, 침투=저가 시장확보

⑤ 포지셔닝 = 소비자 인식 속 위치
   → 실제 제품 특성과 다를 수 있음
```

## 재무·회계 오답 포인트

```
⑥ ROE vs ROA
   → ROE = 순이익/자기자본 (주주 관점)
   → ROA = 순이익/총자산 (전체 자산 효율)

⑦ NPV > IRR 우선 (상호배타적 투자)
   → IRR은 투자 규모 무시

⑧ 유동비율 vs 당좌비율
   → 유동=유동자산/유동부채
   → 당좌=재고 제외 (더 엄격)

⑨ 영업이익 = 매출총이익 - 판관비
   → 금융비용 제외

⑩ 배당성향 = 배당금/당기순이익
    → 배당수익률 = 배당금/주가 (다름)
```

## 인사·조직 오답 포인트

```
⑪ Maslow = 생안사존자 (5단계)
   → 안전→사회 순서 자주 틀림

⑫ Herzberg = 급여는 위생요인
   → 급여 올려도 동기 부여 안됨

⑬ OJT = 현장 직무 중 교육
   → Off-JT = 집합·집중 교육

⑭ 360도 평가 = 다면 평가
   → 상사만의 평가 아님

⑮ 변혁적 리더십 ≠ 카리스마만
   → 비전·영감·개인 배려 포함
```

---

## 생산관리 오답 포인트

```
⑯ EOQ = 주문비=재고유지비 균형점
   → 총비용 최소화

⑰ JIT = 재고 최소화
   → 수요 변동에 취약 (공급 차질 위험)

⑱ Six Sigma = 6σ = 3.4PPM
   → 5σ나 4σ와 혼동 주의

⑲ 제품별 배치 = 연속 생산 (자동차)
   → 공정별 배치 = 단속·주문 생산

⑳ TQM = 전원 참여 품질 관리
   → 특정 부서만의 역할 아님
```

## 핵심 개념 카드

**생안사존자=Maslow 5단계** ★★★★★
: 생리→안전→사회적→존경→자아실현.
*암기 포인트: 생안사존자*

**NPV>IRR 우선** ★★★★★
: 상호배타적 투자에서 NPV가 더 신뢰.
*암기 포인트: 상호배타=NPV우선*

**위생요인≠동기요인** ★★★★☆
: Herzberg: 급여·조건은 위생, 성취·인정은 동기.
*암기 포인트: 급여=위생(불만제거)*

## 실전 퀴즈

**Q. 유동비율과 당좌비율 중 어느 것이 더 보수적인 지표인가?**
> 당좌비율이 더 보수적. 유동비율: 유동자산 전체 포함(재고자산 포함). 당좌비율: 재고자산 제외(현금화 어렵다). 재고가 많은 기업은 유동비율은 높지만 당좌비율 낮을 수 있음. 단기 채무 상환 능력은 당좌비율이 더 정확.

**Q. 제품 수명주기 성숙기에서 권장 전략은?**
> 매출 최대지만 성장 정체. 경쟁 심화로 가격 인하 압력. 원가 절감·차별화·틈새 시장 집중. 브랜드 강화·로열티 프로그램. 쇠퇴 전에 신제품 도입 준비. 시장 점유율 방어가 핵심 목표.
