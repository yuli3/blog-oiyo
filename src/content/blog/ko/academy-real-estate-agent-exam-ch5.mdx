## 2차 시험 구성 전략

**공법과 세법은 같은 교시에 출제** (40문항 + 40문항 합산):

```
부동산공법 (40문항):
- 국토계획법: 약 40%
- 건축법: 약 30%
- 주택법: 약 15%
- 농지법·도시개발법 등: 약 15%

부동산공시법·세법 (40문항):
- 공시법(지적·등기): 약 40%
- 취득세·등록면허세: 약 20%
- 재산세·종부세: 약 20%
- 양도소득세: 약 20%
```

---

## 국토계획법 핵심

### 용도지역 체계 (최빈출)

```
4대 용도지역:
도시지역 → 주거·상업·공업·녹지
관리지역 → 보전관리·생산관리·계획관리
농림지역
자연환경보전지역

암기법: 도-관-농-자
```

### 건폐율·용적률 시험 빈출표

| 지역 | 건폐율 | 용적률 |
|------|--------|--------|
| 제1종 전용주거 | 50% | 100% |
| 제2종 일반주거 | 60% | 250% |
| 제3종 일반주거 | 50% | 300% |
| 준주거 | 70% | 500% |
| 중심상업 | 90% | 1,500% |
| 일반상업 | 80% | 1,300% |
| 전용공업 | 70% | 300% |
| 보전녹지 | 20% | 80% |

**핵심 공식**:
```
건폐율 = 건축면적 / 대지면적 × 100%
용적률 = 지상층 연면적 / 대지면적 × 100%
(지하층·주차장·옥탑 제외)
```

### 개발행위허가

```
개발행위허가 필요 행위:
① 건축물 건축 / 공작물 설치
② 토지 형질 변경
③ 토석 채취
④ 토지 분할 (일부)
⑤ 물건 적치 (1개월 이상)

허가 불요:
- 경작지 조성 등 농업용
- 재해 복구용 응급 행위
```

## 건축법 핵심

### 건축 허가·신고

```
허가 대상 (원칙): 모든 건축물
신고 대상 (예외):
- 연면적 합계 100㎡ 이하 건축물
- 단독주택 내 건축 행위
- 높이 3m 이하 증축·개축·재축 등
```

### 용도 변경

```
용도 변경 허가 필요: 상위 시설군 → 하위 시설군 변경
용도 변경 신고: 하위 → 상위 변경

시설군 순서 (상위→하위):
자동차관련→산업등→전기통신→문화집회→영업→교육복지→근린생활→주거→기타
```

---

## 주택법 핵심

### 주택 분류

```
단독주택: 단독·다중·다가구·공관
공동주택: 아파트(5층↑)·연립(연면적 660㎡↑, 4층↓)·다세대(660㎡↓, 4층↓)

아파트: 5층 이상
연립: 4층 이하, 1개동 연면적 660㎡ 초과
다세대: 4층 이하, 1개동 연면적 660㎡ 이하
```

### 사업 계획 승인

```
사업계획 승인 대상:
단독주택: 30세대 이상
공동주택: 30세대 이상 (투기과열지구 20세대)

주택 공급 절차:
사업승인 → 착공 → 분양(공급) → 입주 → 소유권 등기
```

## 취득세 핵심

### 세율 체계

```
일반 취득세 (주택):
6억 이하: 1%
6억~9억: 1~3% (누진)
9억 초과: 3%

다주택 중과 (조정대상지역):
2주택: 8%
3주택+: 12%
법인: 12%
```

**과세표준**: 실거래가 (사실상 취득가격)  
**납부 기한**: 취득일로부터 **60일** 이내

---

## 재산세·종부세 핵심

### 재산세

```
과세기준일: 6월 1일
과세표준 = 공시가격 × 공정시장가액비율(60%)

세율:
0.1%(6,000만 이하) → 0.15%(6,000만~1.5억) → 0.25%(1.5억~3억) → 0.4%(3억 초과)

납부:
건물(주택 1/2): 7월
토지·건물(주택 1/2): 9월
```

### 종합부동산세

```
과세기준일: 6월 1일
기본공제: 주택 9억 (1주택 12억)

종부세 = (공시가격 합산 - 공제) × 공정시장가액비율 × 세율
```

## 양도소득세 핵심

### 세율 체계

```
보유 2년 이상, 기본세율: 6~45% (누진)
보유 1~2년: 60% (주택·조합원입주권)
보유 1년 미만: 70%

1세대 1주택 비과세:
- 2년 이상 보유 (+ 조정지역 2년 거주)
- 양도가액 12억 이하 전액 비과세
- 12억 초과분만 과세
```

### 장기보유특별공제

```
1세대 1주택 (보유+거주):
3년~: 최소 24%
10년~: 최대 80%

일반 (보유만):
3년~: 6%
15년~: 30%
```

### 비과세 요건 체크

```
1세대 1주택 비과세 요건:
① 1세대 = 본인 + 배우자 + 생계 함께하는 가족
② 1주택 = 양도 시점 기준
③ 보유 2년 이상 (취득 당시 조정지역: 거주 2년 포함)
④ 양도가액 12억 이하 (초과분 과세)
```

---

## 빈출 공식 암기카드

```
건폐율 = 건축면적 ÷ 대지면적 × 100%
용적률 = 연면적(지상) ÷ 대지면적 × 100%

취득세: 6억 이하 1%, 9억 초과 3%
재산세 기준일: 6월 1일
종부세 기본공제: 1주택 12억

1주택 비과세: 2년 보유 + 2년 거주(조정) + 12억 이하
장특공 최대: 80% (10년 이상 보유+거주)
```

## 기출 핵심 문제

**Q1. 중심상업지역의 건폐율·용적률 법적 상한은?**
> 건폐율 90%, 용적률 1,500%.

**Q2. 취득세 신고·납부 기한은?**
> 취득일로부터 60일 이내.

**Q3. 1세대 1주택 비과세 요건 중 조정대상지역 추가 요건은?**
> 취득 당시 조정대상지역이면 2년 이상 실거주(거주) 요건 추가.

**Q4. 개발행위허가가 필요 없는 경우는?**
> 재해복구·재난수습 응급 행위, 경작을 위한 토지 형질 변경 (일부), 건축 신고 대상 경미한 행위 등.

## 공인중개사 시험 합격 마무리 전략

```
시험 직전 3주 체크리스트:

□ 기출 10개년 오답 노트 정리
□ 건폐율·용적률 수치 완전 암기
□ 취득세·재산세·양도세 세율 암기
□ 대항력·우선변제권·최우선변제 구분 암기
□ 금지행위·결격사유 목록 암기
□ 중개보수 요율 계산 연습

합격 공식: 과락(40점 미만) 없음 + 전 과목 평균 60점
```
