## 국제관계학(International Relations)이란?

```
국제관계학의 정의:
→ 국가, 국제기구, 다국적 기업 등 다양한 행위자들 사이의
  상호작용을 연구하는 학문

주요 연구 주제:
→ 전쟁과 평화
→ 국제 협력과 갈등
→ 외교 정책
→ 세계화와 국제 경제
→ 핵 비확산, 기후변화, 인권

국제 체계 (International System)의 특성:
→ 무정부 상태 (Anarchy): 위에 군림하는 최고 권위체 없음
→ 국가 주권: 각국이 대내적 최고 권위 보유
→ 자조(Self-Help): 안보는 스스로 지켜야
```

## 웨스트팔리아 체제 (1648)

```
웨스트팔리아 조약 (Peace of Westphalia, 1648):
→ 30년 전쟁 종결
→ 현대 국제 체계의 출발점

확립된 원칙:
1. 국가 주권 (State Sovereignty): 영토 내 최고 권위
2. 내정 불간섭 원칙: 타국 내정에 개입 불가
3. 국가 간 평등: 모든 주권 국가는 법적으로 평등

국제 체계의 발전:
→ 유럽 열강 체제 (17~19세기)
→ 두 차례 세계대전 (20세기 전반)
→ 냉전 체제 (1947~1991)
→ 탈냉전 세계화 (1991~현재)
```

## 현실주의 (Realism)

```
기본 전제:
→ 국가는 이기적, 합리적 행위자
→ 국제 체계는 무정부 상태
→ 국제 관계의 본질은 권력 투쟁

주요 개념:

1. 권력 (Power):
→ 국제 관계의 핵심 통화
→ 군사력, 경제력, 외교력

2. 국가이익 (National Interest):
→ 국가의 생존과 안보 최우선
→ 도덕보다 국가이익 우선

3. 세력 균형 (Balance of Power):
→ 패권 방지를 위한 동맹 형성
→ 강대국이 힘의 균형 유지

주요 학자:
→ 투키디데스: 고대 현실주의 (강자의 법칙)
→ 홉스: 자연 상태 = 만인의 전쟁
→ 모겐소 (Morgenthau): 고전 현실주의
→ 왈츠 (Waltz): 신현실주의 (구조적 현실주의)

비판:
→ 협력·제도·규범의 역할 과소평가
→ 국제 변화·진보 설명 어려움
```

## 자유주의 (Liberalism)

```
기본 전제:
→ 국가들은 협력할 수 있다
→ 제도와 국제 규범이 행동을 제약
→ 상호 의존이 평화에 기여

주요 개념:

1. 민주 평화론 (Democratic Peace Theory):
→ 민주주의 국가끼리는 전쟁을 하지 않는다 (칸트)
→ 민주주의 확산 = 평화 확산

2. 경제적 상호 의존:
→ 교역·투자로 연결된 국가는 전쟁 비용 증가
→ 세계화는 평화에 기여

3. 국제 제도 (Institutions):
→ UN, WTO, IMF 등 국제 기구가 협력 촉진
→ 규칙 기반 질서 (Rules-based Order)

자유주의 유형:
→ 제도적 자유주의: 국제 제도를 통한 협력
→ 상업 자유주의: 자유 무역으로 평화
→ 민주 자유주의: 민주화로 전쟁 방지
```

## 구성주의 (Constructivism)

```
기본 전제:
→ 국제 체계는 물질적 구조가 아닌
  아이디어, 규범, 정체성에 의해 형성

주요 개념:

1. 사회적 구성:
→ 국가 이익과 정체성은 사회적 상호작용으로 구성
→ '무정부 상태'도 국가들이 부여하는 의미에 따라 다름

2. 규범 (Norms):
→ 집단이 공유하는 행동 표준
→ 예: 화학무기 사용 금지 규범

3. 정체성 (Identity):
→ 국가의 행동은 국가 정체성에서 비롯
→ "중국은 왜 이렇게 행동하는가?" → 정체성으로 설명

주요 학자:
→ 웬트 (Wendt): "무정부상태는 국가들이 만드는 것"
→ 피네모어 (Finnemore): 국제 규범의 역할

비판:
→ 경험적 검증 어려움
→ 행위 예측력 약함
```

## 국가 행위자와 비국가 행위자

```
국가 행위자 (State Actors):
→ 주권을 가진 국가들
→ 국가 안보, 외교 정책의 주체
→ UN 회원국 193개국

비국가 행위자 (Non-State Actors):

1. 국제 기구 (IGO):
→ 국가들이 설립한 조직
→ 예: UN, WTO, IMF, NATO, ASEAN

2. 비정부 기구 (NGO):
→ 시민 사회 조직
→ 예: 국제 적십자사, 그린피스, 국경없는의사회

3. 다국적 기업 (MNC):
→ 여러 국가에서 활동하는 기업
→ 일부 MNC의 GDP > 소규모 국가

4. 테러 단체·초국가적 범죄 조직:
→ 국제 안보 위협 요소

5. 개인:
→ 지도자의 개인적 결정이 국제 관계에 영향
```

## UN (국제연합)

```
UN 창설: 1945년, 샌프란시스코 (51개국)
현재 회원국: 193개국
본부: 뉴욕

UN 주요 기관:

1. 안전보장이사회 (Security Council):
→ 국제 평화·안보 담당
→ 상임이사국 5개 (미국, 러시아, 중국, 영국, 프랑스)
→ 거부권 (Veto) 보유
→ 비상임이사국 10개 (2년 임기)

2. 총회 (General Assembly):
→ 모든 회원국 참여, 1국 1표
→ 권고 결의 (법적 구속력 없음)

3. 사무국 (Secretariat):
→ UN 행정 담당
→ 사무총장: 현재 안토니우 구테흐스 (포르투갈)

4. 국제사법재판소 (ICJ):
→ 국가 간 법적 분쟁 해결

5. 경제사회이사회 (ECOSOC)

UN 한계:
→ 강대국 거부권으로 안보리 기능 마비 가능
→ 집행력 제한적 (각국 의지에 의존)
```

## 냉전 체제와 탈냉전

```
냉전 (Cold War, 1947~1991):
→ 미국(자본주의) vs 소련(공산주의) 대립
→ 직접 무력 충돌 없는 이념·외교·경제 대결
→ 핵 억지력 (MAD: 상호확증파괴)

양극 체제 (Bipolar System):
→ 두 강대국 중심의 세계 질서
→ NATO (미국 주도) vs 바르샤바 조약 기구 (소련 주도)

탈냉전 (1991~):
→ 소련 해체 → 미국 단극 체제
→ 세계화, 민주화 물결
→ 9·11 테러 이후 테러리즘 부상
→ 중국 부상: G2 체제로 이행

현재 국제 질서:
→ 미·중 전략 경쟁
→ 러시아 우크라이나 침공 (2022)
→ 다극화 경향
→ 기후변화, 팬데믹 등 글로벌 과제
```

## 자주 묻는 질문

**Q. 현실주의와 자유주의 중 어느 이론이 더 맞나요?**
A. 두 이론은 상호 보완적입니다. 현실주의는 국가 간 안보 경쟁과 세력 균형을 잘 설명하고, 자유주의는 경제 협력과 국제 제도의 역할을 잘 설명합니다. 현대 국제 관계는 두 이론의 요소가 모두 작동하는 복합적 현상입니다.

**Q. 국제관계학을 공부하면 어떤 직업을 가질 수 있나요?**
A. 외교관(외무고시), 국제기구 직원, 국제 NGO 활동가, 싱크탱크 연구원, 언론인(국제부), 다국적 기업의 국제 업무 등 다양합니다. 국제 문제에 대한 분석 능력이 핵심 역량입니다.
