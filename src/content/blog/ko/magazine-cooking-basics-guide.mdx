## 요리가 어려운 이유

많은 사람이 요리를 어렵게 느끼는 이유는 **모든 것을 한 번에 잘하려고 하기 때문**입니다.

요리는 기술입니다. 칼질, 불 조절, 간 맞추기 — 각각 독립적으로 배우면 생각보다 빨리 늘어납니다.

---

## 칼 기술 기초

### 칼 잡는 법

**핀치 그립 (권장)**: 엄지와 검지로 칼날 옆면을 잡고, 나머지 손가락은 손잡이.

- 안정적이고 피로 적음
- 프로 셰프가 쓰는 방법

### 재료 잡는 법 (고양이 발)

손가락 끝을 구부려 손가락 마디가 칼 측면에 닿게 함 → 손가락 보호.

### 기본 칼질 종류

| 기법 | 용도 |
|-----|-----|
| 다이스 (정육면체) | 양파, 당근, 감자 |
| 슬라이스 (얇게 썰기) | 마늘, 생강, 버섯 |
| 줄리엔 (채 썰기) | 오이, 당근 (무침용) |
| 다지기 (잘게) | 마늘, 파, 생강 |

**연습 순서**: 양파 → 당근 → 마늘 순으로 반복.

## 불 조절

요리 실패의 70%는 잘못된 불 조절에서 옵니다.

### 불 세기별 용도

| 불 세기 | 용도 |
|--------|-----|
| 강불 | 물 끓이기, 빠른 볶음, 고기 초기 시어링 |
| 중강불 | 일반 볶음, 부침개 |
| 중불 | 찌개·국, 일반 조리 |
| 약불 | 오래 끓이기, 리조또, 달걀 스크램블 |

**팁**: 팬이 충분히 달궈진 후 재료를 넣어야 눌어붙지 않음.

달궈짐 확인: 물 한 방울 떨어뜨렸을 때 바로 증발 → 준비됨.

## 간 맞추기

### 기본 원칙

1. **간은 마지막에**: 조리 중 간이 농축되므로 처음에 적게, 마지막에 조절
2. **간을 보는 습관**: 조리 중 1~2번 맛보기
3. **설탕은 소금보다 먼저**: 단맛은 나중에 넣으면 스며들지 않음

### 주요 양념 역할

| 양념 | 역할 |
|-----|-----|
| 소금 | 기본 간, 재료의 수분 제거 |
| 간장 | 짠맛 + 감칠맛 + 색 |
| 설탕·올리고당 | 단맛, 윤기 |
| 식초 | 신맛, 잡내 제거 |
| 고춧가루 | 매운맛, 색 |
| 참기름 | 마무리 향 |
| 다진 마늘 | 풍미 기반 |

**간이 싱거울 때**: 소금 조금씩 추가
**간이 짤 때**: 감자 넣어 끓이거나 물·두부 추가

## 기본 조리법

### 볶기

**순서**: 팬 달구기 → 기름 두르기 → 향 재료(마늘·파) 먼저 → 주재료 → 간

- **수분이 많은 재료** (버섯, 애호박): 강불, 넓게 펼쳐 볶기
- **고기**: 넣은 후 건드리지 않고 시어링

### 끓이기

- 국·찌개는 **뚜껑 반쯤 열고** 끓임 (넘침 방지 + 잡내 날리기)
- **육수 기본**: 다시마 5분 + 멸치 10분 우려내기 → 제거 후 사용

### 굽기

- 고기는 **양면 강불 시어링** 후 중약불로 속 익히기
- **생선**: 껍질부터 구워야 부서지지 않음
- **달걀 프라이**: 약불, 뚜껑 덮어 흰자 익히기

### 찌기

- 찜기에 물 넉넉히 (끓인 후 재료 올리기)
- **생선찜**: 10~15분, 과하게 찌면 퍽퍽해짐
- **만두**: 김 오른 후 8~10분

## 필수 도구

### 기본 (우선 구비)

| 도구 | 용도 |
|-----|-----|
| 셰프 나이프 8인치 | 다목적 칼 |
| 도마 (나무 or 플라스틱) | 안정적인 것 |
| 프라이팬 28cm | 볶음·부침 |
| 냄비 3~5L | 국·찌개 |
| 체 (거름망) | 채소 세척, 국물 거르기 |

### 양념통 기본 셋

소금, 후추, 참기름, 간장, 된장, 고춧가루 — 이 6가지면 한식 80% 가능.

## 냉장고 식재료 관리

### 냉장 보관 기간

| 식재료 | 보관 기간 |
|------|---------|
| 고기 (생) | 2~3일 |
| 생선 (생) | 1~2일 |
| 달걀 | 3~4주 |
| 두부 (개봉 후) | 2~3일 물에 담아 |
| 채소 (잎채소) | 3~5일 |
| 당근·감자 | 2~3주 |

**냉동 활용**: 고기는 1회 분량씩 소분 → 냉동. 해동은 냉장 이동 (실온 해동은 균 번식).

### 냉장고 정리 법칙

- 먼저 들어온 것 앞에 배치
- 조리 완료 음식 상단, 생고기 하단 (교차 오염 방지)

## 한식 기본 레시피 3가지

### 된장찌개

재료: 된장 2T, 두부 반 모, 애호박 반 개, 양파 반 개, 다시마·멸치 육수 500ml

1. 멸치·다시마 육수 끓이기
2. 된장 풀기
3. 채소 넣고 10분 끓이기
4. 두부 넣고 5분 더

**팁**: 된장은 미리 물에 개어두면 덩어리 없음.

### 계란볶음밥

재료: 밥 1공기, 달걀 2개, 대파 조금, 간장 1T, 참기름

1. 팬 강불 달구기 → 기름
2. 달걀 먼저 스크램블 (반쯤 익을 때)
3. 밥 넣고 잘게 부수며 볶기
4. 간장·참기름·파 넣고 마무리

### 잡채 (간단 버전)

재료: 당면 100g, 시금치·당근·버섯, 간장 3T, 설탕 1T, 참기름

1. 당면 삶기 (8분), 물기 제거
2. 각 채소 따로 볶기 (소금 간)
3. 모두 섞고 양념 버무리기

## 요리 실력 향상 로드맵

### 1개월차
- 달걀 요리 5가지 마스터 (프라이, 스크램블, 삶기, 오믈렛, 달걀찜)
- 된장찌개·계란볶음밥 자유자재

### 2개월차
- 국 1가지 마스터 (미역국 or 북어국)
- 볶음 2가지 (제육볶음, 낙지볶음)

### 3개월차
- 손님상 메뉴 1가지 완성 (불고기 or 갈비찜)

요리는 반복이 전부입니다. 같은 요리를 10번 만들면 레시피 없이도 만들 수 있게 됩니다.
