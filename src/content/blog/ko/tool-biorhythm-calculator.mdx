# 생체리듬(바이오리듬) 계산기

생체리듬(Biorhythm) 이론은 20세기 초 독일·오스트리아 의학자들이 제안한 것으로, 인간의 신체·감성·지성 능력이 일정한 주기로 파동을 그린다는 가설입니다. 과학적으로 완전히 검증된 이론은 아니지만, 자신의 상태를 돌아보는 **자기인식 도구**로 폭넓게 활용됩니다.

## 세 가지 생체리듬 주기

| 리듬 | 주기 | 의미 |
|---|---|---|
| 신체(Physical) | **23일** | 체력, 지구력, 협응력, 면역력 |
| 감성(Emotional) | **28일** | 기분, 창의성, 감수성, 직관 |
| 지성(Intellectual) | **33일** | 논리력, 집중력, 분석력, 기억력 |

<Callout type="tip">
**임계일(Critical Day)**: 각 주기가 0을 지나는 전환점. 이 날은 해당 능력이 불안정해 사고나 실수가 늘 수 있습니다. 중요한 시험, 수술, 장거리 운전은 임계일을 피하는 것이 권장됩니다.
</Callout>

## 리듬별 활용법

| 상태 | 활용 전략 |
|---|---|
| 신체 ↑ (고점) | 운동, 야외 활동, 체력 소모 작업 |
| 신체 ↓ (저점) | 휴식, 회복, 무리한 운동 자제 |
| 감성 ↑ (고점) | 창작 활동, 관계 강화, 발표·협상 |
| 감성 ↓ (저점) | 감정적 결정 자제, 명상·휴식 |
| 지성 ↑ (고점) | 공부, 시험, 복잡한 업무 처리 |
| 지성 ↓ (저점) | 단순 반복 작업, 아이디어 정리 휴식 |

## 계산 원리

각 리듬은 **사인(sin) 함수**로 표현됩니다.

- 신체: sin(2π × 경과일수 / 23)
- 감성: sin(2π × 경과일수 / 28)  
- 지성: sin(2π × 경과일수 / 33)

태어난 날부터 오늘까지의 경과 일수를 각 주기로 나눈 위치를 사인값으로 표현하면 −1(최저)~+1(최고) 사이 값이 나옵니다.

<Callout type="note">
생체리듬은 과학적으로 검증된 의학적 도구가 아닙니다. 일상의 패턴을 돌아보고 자기 관리에 참고하는 용도로 활용하세요.
</Callout>
