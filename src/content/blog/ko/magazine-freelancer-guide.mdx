## 프리랜서와 개인사업자 차이

| 구분 | 프리랜서 | 개인사업자 |
|-----|--------|---------|
| 사업자 등록 | 불필요 | 필요 |
| 세금 처리 | 원천징수 3.3% | 부가세 신고 + 종합소득세 |
| 주요 직종 | 디자인·개발·강의·번역 | 쇼핑몰·식당·공방 등 |
| 세금 절세 | 필요경비 공제 (종합소득세) | 부가세 매입세액 공제 + 필요경비 |

**프리랜서 기준**: 사업자 등록 없이 인적용역(노동력)을 제공하고 대가를 받는 사람.

## 계약서

프리랜서가 가장 소홀히 하는 부분 = 계약서.

### 계약서 없이 일하면 생기는 문제

- 대금 미지급 시 법적 근거 없음
- 작업 범위 분쟁 시 증거 없음
- 납품 후 수정 요청 무한 반복

### 계약서 필수 항목

```
1. 업무 범위 (무엇을, 어디까지)
2. 납품물 형식과 수량
3. 납품 기한
4. 수정 횟수 및 추가 수정 비용
5. 대금 금액 (총액 명시)
6. 지급 조건 (계약금 30%·중도금·잔금)
7. 지급 기한
8. 저작권 귀속
9. 기밀유지 (NDA)
10. 계약 해제 시 환불·보상 기준
```

### 계약서 서식 참고

- **한국예술인복지재단**: 예술 분야 표준계약서 제공
- **콘텐츠분쟁조정위원회**: 분쟁 예방 계약서 가이드

## 세금

### 원천징수 3.3%

프리랜서가 클라이언트로부터 받은 금액에서 3.3%를 원천징수.

클라이언트가 세금을 먼저 떼고 지급 → 프리랜서는 5월에 종합소득세 신고로 정산.

예시:
- 계약금 100만 원 → 클라이언트 지급액 96.7만 원 (3.3% 공제)
- 원천징수영수증 발급 요청

### 종합소득세 신고

**신고 시기**: 매년 5월 1~31일 (전년도 소득 신고)

**핵심**: 3.3% 미리 낸 세금 + 실제 내야 할 세금 차액 정산.

실제 세금이 3.3%보다 적으면 → 환급
실제 세금이 더 많으면 → 추가 납부

### 필요경비 공제

프리랜서 최대 절세 방법 = 필요경비 증빙.

업무와 관련된 모든 지출이 필요경비:
- 컴퓨터·장비 구입비
- 소프트웨어 구독료 (어도비, 노션 등)
- 작업 공간 임대료 (홈오피스 일부 포함 가능)
- 교육·강의비 (업무 관련)
- 인터넷·통신비 (일부)
- 책·자료 구입비

**증빙**: 사업용 카드 사용 권장 (지출 관리 + 세금 신고 편리)

### 단순경비율 vs 기준경비율

소득이 적을 때 장부를 쓰지 않아도 정해진 비율로 경비 인정.

| 구분 | 단순경비율 | 기준경비율 |
|-----|---------|---------|
| 대상 | 직전연도 수입 기준 이하 | 그 이상 |
| 경비 인정 | 수입의 60~80% (업종별) | 주요 경비만 실증, 나머지 정률 |
| 세금 | 낮음 | 장부 작성 시 더 절세 가능 |

**수입이 많아지면**: 복식부기 장부 작성 → 세무사 의뢰 권장.

## 4대보험

프리랜서는 4대보험이 자동 가입되지 않습니다.

### 국민건강보험 (지역가입자)

- 직장 퇴직 후 14일 이내 지역가입자 전환 신청
- 보험료: 소득·재산·자동차 기준 부과
- 피부양자 등록 가능 (배우자의 직장보험에 올리기)

**꿀팁**: 연소득 2,000만 원 이하 + 재산 기준 충족 시 직장인 배우자의 피부양자 등록 가능 → 보험료 0원.

### 국민연금 (지역가입자)

- 18~60세 소득 있는 경우 의무 가입
- 보험료: 신고 소득의 9% (본인 전액 부담)
- 소득 없는 달은 납부 예외 신청 가능

### 고용·산재보험

- 프리랜서 원칙적 미적용
- **예술인 고용보험**: 문화예술용역 계약 체결 프리랜서 → 고용보험 가입 가능 → 실업급여 수령 가능
- **특수고용직 산재보험**: 택배·퀵·대리기사 등 특정 직종 의무 가입

## 수입 안정화 전략

프리랜서 최대 불안 = 불규칙한 수입.

### 1. 고정 클라이언트 확보

**월 정기 계약** 형태 목표:
- "월 00만 원으로 업무 범위 지정" 계약
- 지속 거래로 수입 예측 가능

### 2. 클라이언트 분산

한 클라이언트 의존 → 계약 종료 시 수입 0.

**목표**: 상위 클라이언트 수입 비중 40% 이하.

3~5개 클라이언트 → 한 곳 계약 종료 시 타격 최소화.

### 3. 비수기 대비 자금

수입이 좋은 달 → 3~6개월 생활비 비상금 확보.

비수기(연말·연초 등)를 현금으로 버티는 능력.

### 4. 단가 올리기

경력이 쌓이면 단가 인상 협상.

**단가 협상 근거**:
- 포트폴리오 (결과물 품질)
- 고객 리뷰·추천
- 전문성 (자격증, 특화 분야)

### 5. 플랫폼 활용

| 플랫폼 | 분야 |
|------|-----|
| 크몽 | 디자인·개발·번역·마케팅 |
| 숨고 | 강의·과외·전문서비스 |
| 라우드소싱 | 디자인 공모전·외주 |
| 탈잉 | 강의·멘토링 |
| Upwork (글로벌) | 개발·번역·디자인 |
| Fiverr (글로벌) | 다양한 크리에이티브 |

## 세금 달력

| 시기 | 내용 |
|-----|-----|
| 1월 | 전년도 사업 정리, 원천징수영수증 수집 |
| 5월 | 종합소득세 신고·납부 |
| 7월 | 부가세 예정신고 (개인사업자) |
| 11월 | 종합소득세 중간예납 |
| 1월 | 부가세 확정신고 |

## 프리랜서 필수 도구

| 도구 | 용도 |
|-----|-----|
| 노션·에버노트 | 업무 관리·클라이언트 기록 |
| 슬랙·카카오워크 | 클라이언트 커뮤니케이션 |
| 구글 드라이브 | 파일 공유·협업 |
| 다수의 사업용 카드 | 경비 관리 |
| 삼쩜삼·세금 앱 | 원천징수 관리·종합소득세 도움 |
| 계약서 앱 (docusign 등) | 전자 계약서 |

프리랜서 성공의 80%는 기술이 아니라 **운영**입니다. 계약서, 세금, 수입 분산이 제대로 갖춰지면 직장인보다 더 안정적인 삶이 가능합니다.
