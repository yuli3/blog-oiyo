## 출생차트 해석 표준 프로세스

점성술 기초(Ch1-5)를 종합해 실제 차트를 해석하는 방법을 배웁니다.

**차트 해석 표준 순서:**

```
Step 1: 빅 3 파악 — 태양·달·어센던트
Step 2: 강조된 원소·모달리티 확인
Step 3: 행성의 하우스 위치 파악
Step 4: 주요 어스펙트 해석
Step 5: 지배 행성 상태 확인
Step 6: 종합 스토리 연결
```

---

## 케이스 1: 리더십 기질의 차트

### 차트 요약

```
태양: ♌ 사자자리 (10번 하우스)
달:   ♈ 양자리 (6번 하우스)
어센던트: ♏ 전갈자리
화성: ♈ 양자리 (5번 하우스) — 달과 합
목성: ♐ 사수자리 (2번 하우스)
토성: ♑ 염소자리 (3번 하우스)
```

### Step 1: 빅 3 분석

**태양 = 사자자리 (10번 하우스)**
- 사자자리: 자기 표현, 창의성, 리더십, 빛나고 싶은 욕구
- 10번 하우스: 커리어, 명예, 사회적 성취
- **해석**: 커리어에서 주목받고 이끄는 역할이 핵심 목적. 무대 위에서 빛날 때 삶이 완성됨.

**달 = 양자리 (6번 하우스)**
- 양자리: 직접적, 충동적, 빠른 행동
- 6번 하우스: 일상 업무, 건강
- **해석**: 감정적 반응이 즉각적이고 활발. 일에서 에너지와 안정감을 얻음.

**어센던트 = 전갈자리**
- **해석**: 처음에는 신비롭고 강렬한 인상을 줌. 깊이 있어 보이며 쉽게 마음을 열지 않음.

### Step 4: 주요 어스펙트

**화성-달 합 (양자리)**:
- 행동력과 감정이 합쳐짐
- 감정이 즉각적인 행동으로 나타남
- 열정적이지만 충동적 결정 주의

**태양-목성 호각 (트라인)**:
- 사자자리 태양과 사수자리 목성 — 둘 다 불 원소
- **해석**: 타고난 행운과 낙관성. 커리어에서 확장의 기회가 자연스럽게 옴.

### Step 6: 종합 해석

이 차트는 **공개적인 무대에서 이끄는 리더**의 차트입니다.

- 내면에는 강렬한 에너지(달-화성 합)와 강한 의지(전갈자리 어센던트)
- 사회적으로는 창의적 리더십(태양 10번 하우스)으로 인정받음
- 타고난 행운(태양-목성 트라인)으로 커리어에서 기회를 잘 포착
- **과제**: 충동적 결정(양자리 달-화성)과 오만함(사자자리 태양) 주의

## 케이스 2: 예술가·치유자 기질의 차트

### 차트 요약

```
태양: ♓ 물고기자리 (12번 하우스)
달:   ♋ 게자리 (4번 하우스)
어센던트: ♎ 천칭자리
금성: ♓ 물고기자리 (5번 하우스)
해왕성: ♑ 염소자리 (4번 하우스)
수성: ♒ 물병자리 (5번 하우스)
```

### Step 1: 빅 3 분석

**태양 = 물고기자리 (12번 하우스)**
- 물고기자리: 감성, 영성, 연민, 경계 용해
- 12번 하우스: 은둔, 무의식, 영적 탐구
- **해석**: 눈에 보이지 않는 세계, 예술, 영성이 삶의 핵심. 혼자만의 시간이 재충전의 원천.

**달 = 게자리 (4번 하우스)**
- 게자리: 돌봄, 가정, 안전 욕구
- 4번 하우스: 가정, 심리적 기반
- **해석**: 감정적 안정의 근원이 가정과 가족. 집이 진정한 안식처.

**어센던트 = 천칭자리**
- **해석**: 외적으로는 균형 잡힌 아름다운 첫인상. 부드럽고 외교적으로 보임.

### Step 4: 주요 어스펙트

**태양-금성 합 (물고기자리)**:
- 자아(태양)와 사랑·아름다움(금성)이 결합
- **해석**: 예술적 감수성이 매우 강함. 미적 표현을 통해 자아를 실현.

**달-해왕성 합 (4번 하우스)**:
- 감정(달)과 영성·이상(해왕성)이 결합
- **해석**: 깊은 공감 능력, 영적 감수성. 다른 사람의 감정을 스펀지처럼 흡수할 수 있음.

### Step 6: 종합 해석

이 차트는 **창의적 예술가이자 감성적 치유자**의 차트입니다.

- 예술과 영성이 자아의 핵심(태양-금성 물고기자리 12번 하우스)
- 깊은 공감과 직관(달-해왕성 게자리)
- 외적으로는 조화롭고 우아한 인상(천칭자리 어센던트)
- **과제**: 경계 설정(물고기자리의 과제). 타인의 에너지에 너무 영향받지 않도록 주의.

## 케이스 3: 학자·탐구자 기질의 차트

### 차트 요약

```
태양: ♑ 염소자리 (9번 하우스)
달:   ♍ 처녀자리 (5번 하우스)
어센던트: ♈ 양자리
수성: ♑ 염소자리 (10번 하우스)
토성: ♑ 염소자리 (9번 하우스) — 태양과 합
목성: ♊ 쌍둥이자리 (3번 하우스)
```

### Step 1: 빅 3 분석

**태양 = 염소자리 (9번 하우스)**
- 염소자리: 야심, 책임, 구조, 장기 목표
- 9번 하우스: 철학, 고등 교육, 해외
- **해석**: 지식을 통해 높이 올라가는 것이 삶의 방향.

**달 = 처녀자리 (5번 하우스)**
- 처녀자리: 분석, 세밀함, 완벽주의
- 5번 하우스: 창의성, 즐거움
- **해석**: 분석적이고 세밀한 창의성. 즐거움도 체계적으로 접근.

### Step 4: 주요 어스펙트

**태양-토성 합 (염소자리)**:
- 자아(태양)와 규율(토성)의 결합
- **해석**: 강한 책임감과 자기 규율. 늦은 성공 패턴이지만 오래 지속.

**목성-수성 트라인**:
- 확장(목성)과 소통(수성)의 조화
- **해석**: 학문적 소통 능력이 뛰어남. 지식을 명확하게 전달하는 능력.

### Step 6: 종합 해석

이 차트는 **철학적 학자이자 탐구자**의 차트입니다.

- 지식 추구와 사회적 성취가 핵심(태양 9번 하우스)
- 강한 자기 규율과 책임감(태양-토성 합)
- 지식을 명확하게 전달하는 능력(목성-수성 트라인)
- **과제**: 지나친 완벽주의(처녀자리 달). 규칙과 틀에 갇히지 않도록 주의.
