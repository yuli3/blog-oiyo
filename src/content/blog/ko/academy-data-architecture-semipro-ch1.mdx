## DAsP는 무엇을 확인하나

DAsP는 데이터아키텍처 준전문가로, 조직의 데이터를 구조적으로 이해하고 요구사항, 표준, 모델, 품질 관점에서 설계할 수 있는 기초 역량을 확인하는 자격입니다. 시험일정, 응시자격, 합격기준, 세부 과목은 변경될 수 있으므로 데이터자격검정 공식 홈페이지(https://www.dataq.or.kr)와 시행처 공식 홈페이지 공지를 확인하세요. 확인일: 2026-06.

### DAP와의 관계

| 구분 | 이해 포인트 |
|---|---|
| DAsP | 준전문가 수준의 기본 개념과 실무 이해 |
| DAP | 더 깊은 데이터아키텍처 전문 역량 |
| 공통 축 | 데이터 이해, 표준, 모델링, 품질 |
| 준비 순서 | DAsP로 구조를 잡고 DAP 심화로 확장 |

DAsP는 단순 SQL 시험이 아닙니다. 데이터가 업무 요구를 어떻게 반영하고, 표준 명명과 모델링으로 어떻게 관리 가능한 구조가 되는지를 묻습니다. 그래서 테이블을 많이 아는 것보다 데이터가 조직 안에서 어떤 규칙으로 설계되는지 보는 시야가 필요합니다.

## 학습 로드맵

이 시리즈는 데이터 이해, 요구사항 분석, 표준화, 모델링, 데이터베이스 설계와 품질, 거버넌스, 시험전략 순서로 진행합니다. 처음에는 용어 정의를 정확히 잡고, 이후 개념·논리·물리 모델이 어떻게 이어지는지 그림으로 반복하세요.

## 핵심 요약

- DAsP는 데이터아키텍처 기본 역량을 확인하는 준전문가 자격입니다.
- 일정·응시자격·합격기준은 데이터자격검정 공식 홈페이지에서 확인해야 합니다.
- DAP는 더 심화된 전문 자격으로 이해하면 됩니다.
