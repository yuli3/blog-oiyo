# 디데이 카운터

중요한 날짜들을 한 곳에서 추적합니다. 시험까지 얼마나 남았는지, 커플 기념일이 며칠 지났는지, 여행 출발은 언제인지 한눈에 확인하세요.

이 D-Day 카운터는 여러 이벤트를 동시에 등록해서 브라우저에 저장합니다. 새로고침해도 목록이 유지되며, 각 이벤트마다 남은 일수(D−N)와 경과 일수(D+N)를 자동으로 전환해서 보여줍니다.

**이런 상황에 유용합니다:**
- 수능·공무원·자격증 시험을 준비 중인 수험생
- 커플 기념일(100일·200일·1주년)을 놓치지 않으려는 분
- 해외여행 출발까지 설렘을 카운트하고 싶은 분
- 프로젝트 마감일을 팀원과 공유하고 싶을 때

## D-day vs D+day

| 표기 | 의미 | 예시 |
|---|---|---|
| **D-30** | 목표일까지 30일 남음 | 시험 30일 전 |
| **D-0** | 오늘이 바로 그날 | 당일 |
| **D+100** | 기준일로부터 100일 경과 | 100일 기념일 |

<Callout type="tip">
**D-Day의 유래**: 2차 세계대전 노르망디 상륙작전(1944년 6월 6일)이 D-Day로 불렸습니다. 군사 용어에서 시작해 지금은 중요한 날을 지칭하는 일반 용어로 쓰입니다.
</Callout>

## 활용 예시

| 용도 | 설정 예시 |
|---|---|
| 수험 준비 | 수능·공무원 시험·자격증 시험일 |
| 커플 기념일 | 처음 만난 날 → D+100, D+200 자동 계산 |
| 여행 | 출발일까지 카운트다운 |
| 프로젝트 마감 | 제출일 D-day |
| 임신·육아 | 출산 예정일, 아이 백일·돌 |
