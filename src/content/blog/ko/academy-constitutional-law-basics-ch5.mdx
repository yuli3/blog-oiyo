## 참정권

### 참정권의 개념

```
참정권: 국가 의사 형성에 능동적으로 참여하는 권리
- 선거권: 대표자 선출에 투표
- 피선거권: 선거에 후보로 출마
- 공무담임권: 공직에 취임
- 국민 투표권: 헌법 개정·중요 정책 투표
```

### 선거권

```
선거권 요건:
- 18세 이상 국민 (2020년 개정)
- 금치산자, 수형자 일부 제한 (선거법)

선거의 4원칙 (보통·평등·직접·비밀):
① 보통 선거: 재산·성별 불문 선거권
② 평등 선거: 1인 1표 등가성
③ 직접 선거: 본인이 직접 투표
④ 비밀 선거: 투표 내용 비공개
```

### 피선거권과 공무담임권

```
피선거권 연령:
- 대통령: 40세 이상
- 국회의원·지방의원: 25세 이상
- 지방자치단체장: 25세 이상

공무담임권:
- 공직 취임 기회의 균등
- 국적·연령 요건은 합리적 제한
- 시험 성적·능력 기준 제한은 합헌
```

## 청구권적 기본권

```
청구권: 다른 기본권이 침해되었을 때 구제를 요청하는 절차적 권리

종류:
① 청원권: 국가 기관에 의견·불만 제출
② 재판청구권: 법원에 재판을 받을 권리
③ 국가배상청구권: 공무원 행위로 손해 시 국가에 배상 요구
④ 형사보상청구권: 무죄 판결 시 억울한 구금에 보상
⑤ 범죄피해자구조청구권: 범죄 피해자 국가 구조
```

### 재판청구권

```
재판청구권 (헌법 제27조):
- 헌법과 법률이 정한 법관에 의한 재판
- 신속한 재판
- 형사 피해자의 진술권 (피해자도 재판 참여)

공정한 재판:
- 독립된 법관에 의한 재판
- 적법 절차 준수
- 심급 제도 보장 (항소·상고)
```

### 국가배상청구권

```
국가배상법 제2조:
공무원의 직무 행위로 국민에게 손해 발생 시 국가 배상

요건:
① 공무원 (또는 공무 수탁 사인)
② 직무 행위 (직무와 관련성)
③ 고의 또는 과실 (위법 행위)
④ 타인 손해 발생
⑤ 인과관계

군인·경찰관 이중배상 금지:
- 전투·훈련 중 손해: 국가배상 외 별도 청구 불가
  (국가배상법·보훈보상법으로 대체)

배상 책임의 성질:
- 국가·지방자치단체 : 공무원에게 구상권 행사 가능 (고의·중과실)
```

### 형사보상청구권

```
형사보상 (헌법 제28조):
- 형사 피의자·피고인으로 구금 후 불기소·무죄 확정 시
- 법률이 정하는 보상 청구

형사보상의 법적 성격:
- 국가 행위가 적법하더라도 결과적 손실 보상
- 형사보상법으로 구체화

손실 보상 기준:
- 구금 1일당 보상금 = 최저 임금법상 일급 × 5배 이내
```

## 핵심 개념 카드

**선거 4원칙** ★★★★★
: 보통·평등·직접·비밀 선거. 헌법상 민주적 선거 요건.
*암기 포인트: 보평직비 (보통·평등·직접·비밀)*

**국가배상 5요건** ★★★★★
: 공무원·직무행위·고의과실·타인손해·인과관계. 모두 충족 시 국가 배상.
*암기 포인트: 공직고타인 (공무원·직무·고의과실·타인·인과)*

**형사보상과 국가배상 구분** ★★★★☆
: 형사보상=적법한 구금 후 무죄 → 결과적 보상. 국가배상=위법한 공무원 행위 → 손해배상.
*암기 포인트: 형사보상=적법+무죄, 국가배상=위법+손해*

## 실전 퀴즈

**Q. 대통령 피선거권 연령은?**
> 40세 이상. 국회의원·지방의원·지방자치단체장은 25세 이상.

**Q. 군인이 훈련 중 상관의 과실로 부상을 입었다. 국가배상청구가 가능한가?**
> 원칙 불가. 이중배상 금지 규정(헌법 제29조 제2항)에 따라 군인·경찰관은 전투·훈련 등 직무에서 발생한 손해에 대해 국가배상 외 별도 배상 청구 불가. 보훈 보상법에 따른 보상으로 갈음.
