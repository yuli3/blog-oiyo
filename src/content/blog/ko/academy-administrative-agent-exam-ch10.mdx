## 시험 과목 구성

```
1차 시험 (객관식):
민법 (계약·물권·가족법)
행정법 (총론+각론)
행정학개론

2차 시험 (주관식):
민법 (사례형)
행정법 (사례형)
공문서 작성 실무

합격 기준:
1차: 각 과목 40점 이상·평균 60점
2차: 각 과목 60점 이상
```

```
┌──────────────┬──────────────┬──────────────────┐
│ 구분         │ 행정심판     │ 행정소송         │
├──────────────┼──────────────┼──────────────────┤
│ 기관         │ 행정심판위원회│ 법원             │
```

## 주요 기간 총정리

```
행정심판: 안날 90일·처분일 180일
취소소송: 안날 90일·처분일 1년
불법행위 손해배상: 안날 3년·행위일 10년
채권 소멸시효: 10년 (상사5년)
행정사 결격: 3년
집행정지 효력: 심판 계속 중

기속행위 거부처분 시:
의무이행심판 or 거부처분취소소송
```

## 빈출 오답 10선

```
① 공정력=취소 전까지 유효 (무효는 없음)
② 행정심판=위법+부당, 소송=위법만
③ 심판기간=180일, 소송=1년 (다름)
④ 재량 일탈·남용=위법 (취소 가능)
⑤ 무효확인소송=기간 제한 없음
⑥ 행정사=소송대리 불가, 심판보조 가능
⑦ 해제=소급효, 해지=장래효
⑧ 사용자책임=업무집행 중 불법행위
⑨ 계약취소=소급무효 (해제와 같음)
⑩ 공문서 날짜=마침표 포함
```

## 핵심 개념 카드

**행정사 업무=심판보조·서류작성** ★★★★★
: 소송 대리는 불가. 행정심판 청구 대리 가능.
*암기 포인트: 행정사=심판O·소송X*

**행정법 3대 원칙** ★★★★★
: 법률유보·법률우위·비례원칙.
*암기 포인트: 유우비*

**처분의 효력=공정력+불가쟁력** ★★★★☆
: 취소 전 유효, 기간 지나면 다툼 불가.
*암기 포인트: 공정=취소전, 쟁력=기간후*

## 실전 퀴즈 (종합)

**Q. 행정사 시험에서 행정법과 민법의 연계 포인트는?**
> 행정행위 하자론 → 민법 법률행위 무효·취소 유추. 행정청 손해배상 → 국가배상법 (민법 불법행위 특칙). 행정계약 → 민법 계약법 준용. 두 과목 상호 보완 학습 효과적.

**Q. 행정사 2차 공문서 작성에서 가장 중요한 요소는?**
> 법적 근거 명시: 처분 요청의 법령 조항. 사실 관계 명확: 날짜·장소·행위 특정. 요구 사항 명확: 원하는 결론. 형식 준수: 날짜 형식, 기관명, 날인. 내용보다 형식 실수가 감점 주요 원인.
