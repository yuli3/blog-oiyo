## 한국 누리과정

```
누리과정:
→ 만 3~5세 유아를 위한 국가 수준 교육과정
→ 어린이집 표준보육과정 + 유치원 교육과정 통합 (2012)
→ 2019 개정 누리과정: 놀이 중심·유아 주도성 강화

누리과정 5개 영역:
→ 신체운동·건강: 신체 인식·발달·건강·안전 생활 습관
→ 의사소통: 듣기·말하기·읽기·쓰기 준비·언어 감수성
→ 사회관계: 나를 알고 존중·더불어 생활·사회에 관심 가지기
→ 예술경험: 아름다움 찾아보기·창의적으로 표현·예술 감상
→ 자연탐구: 탐구 과정 즐기기·생활 속 수학·자연과 더불어 살기

2019 개정 누리과정 핵심 방향:
→ 유아 중심·놀이 중심 교육 강화
→ 교사의 자율성·전문성 증대
→ 교육과정 운영의 유연성 (국가 기준 최소화)
→ 협력과 소통: 유아·교사·부모·지역사회 협력

놀이의 의미:
→ 유아의 자발적·내적 동기·즐거움
→ 학습과 발달의 통합적 수단
→ 규칙 있는 놀이·역할 놀이·구성 놀이·신체 놀이
→ 놀이 중 학습: 수개념·언어·사회성·창의성

교육과정 운영:
→ 하루 일과: 등원·자유선택활동·대그룹·소그룹·바깥놀이·식사·귀가
→ 환경 구성: 흥미 영역별 배치 (언어·수조작·과학·미술·역할·쌓기)
→ 일과 계획: 교사-유아 공동 계획 권장
```

## 주요 유아교육 프로그램

```
레지오 에밀리아 접근법 (Reggio Emilia):
→ 이탈리아 레지오 에밀리아 시 발전 (말라구치 주도)
→ 핵심 철학: 100가지 언어 (아동의 다양한 표현 방식 존중)
→ 프로젝트 학습: 유아의 관심에서 출발 장기 탐구
→ 문서화 (Documentation): 관찰·기록·전시로 학습 가시화
→ 교육 공간 제3의 교사: 환경이 교육적 메시지 전달
→ 교사 역할: 협력자·관찰자·촉진자
→ 부모·지역사회 적극 참여

몬테소리 교육 (Montessori):
→ 마리아 몬테소리 (Maria Montessori) 개발
→ 민감기 (Sensitive Periods): 특정 기술 습득에 민감한 발달 시기
→ 준비된 환경: 아동이 독립적으로 학습하는 구조화된 환경
→ 교구: 자기 수정 가능·감각 교구·수 교구·언어 교구
→ 혼합 연령 구성: 3년 묶음 (3~6, 6~9, 9~12세)
→ 교사 역할: 안내자·관찰자 (직접 가르치기 최소화)
→ 자유·자율·자기 규율 강조

발도르프 교육 (Waldorf/Steiner):
→ 루돌프 슈타이너 (Rudolf Steiner) 설립 (1919년)
→ 3단계 발달: 0~7세(의지)·7~14세(감성)·14~21세(사고)
→ 유아기: 예술·공예·자연 리듬·환상 중심
→ 조기 학습(문자·숫자) 지양: 7세 이전 추상 학습 배제
→ 계절·리듬·반복: 안정적 예측 가능한 일과
→ 미디어 사용 최소화

뱅크 스트리트 (Bank Street) 접근법:
→ 존 듀이 영향 (경험 중심 교육)
→ 사회적 상호작용·지역사회 학습
→ 아동 발달 지식에 기반한 적합한 실제 (DAP)

발달에 적합한 실제 (DAP):
→ NAEYC (미국 유아교육협회) 지침
→ 연령 적합성·개인 적합성·사회문화적 적합성
```

## 유아 교수-학습 방법

```
프로젝트 접근법 (Katz & Chard):
→ 유아의 심층적 탐구를 지원하는 교수법
→ 주제: 유아의 실생활 관심사에서 시작

3단계:
→ 1단계 (시작): 공유 경험·질문 생성·개념도 작성
→ 2단계 (전개): 현장 방문·조사·관찰·그리기·건축
→ 3단계 (마무리): 성취 공유·전시·축하

vs 주제 중심 교육:
→ 주제: 교사가 사전 계획 / 프로젝트: 유아-교사 공동 계획
→ 깊이 있는 탐구 vs 폭 넓은 학습

통합교육과정 (Integrated Curriculum):
→ 교과·영역·활동의 연계 통합
→ 웹 (주제망): 중심 주제에서 다양한 활동 연결
→ 블록 타임: 영역 경계 없는 긴 활동 시간

대·소집단 활동:
→ 대집단 (전체): 이야기 나누기·동화·동시·음악
→ 소집단 (5~6명): 실험·요리·토론·구체적 개념 학습
→ 개별 활동: 자유선택활동·포트폴리오 자료 수집

이야기 나누기 (Circle Time):
→ 하루 시작/마무리·공동체 의식 형성
→ 교사 질문 유형: 회상·추론·평가·개방형 질문
→ 유아 사고 촉진: "왜 그럴까?" "어떻게 알았니?"

바깥놀이 중요성:
→ 신체·인지·사회·정서 발달 촉진
→ 자연 탐구·위험 감수 기회
→ 미디어 과다 노출 시대의 신체 활동 보장
```

## 관찰과 평가

```
유아 관찰의 목적:
→ 발달 수준 파악·개별 지원 계획
→ 교육 활동 계획의 기초 자료
→ 부모 상담 자료

관찰 방법:

일화 기록 (Anecdotal Record):
→ 의미 있는 사건을 서술적으로 기록
→ 사실적 기술·해석 분리
→ 장점: 맥락 보존 / 단점: 선택적 기록

표본 기록 (Specimen Record):
→ 특정 시간 동안 유아의 모든 행동을 연속 기록
→ 풍부한 정보·시간 소요 많음

체크리스트 (Checklist):
→ 관찰 항목을 예/아니요·빈도로 체크
→ 발달 기준표·이정표 활용

평정 척도 (Rating Scale):
→ 행동·특성의 강도를 단계로 평가
→ 3점·5점 척도 사용

포트폴리오 평가:
→ 시간 경과에 따른 유아 작품 수집
→ 자기 선택 작품·교사 선택 작품
→ 유아의 성장 이야기 기록

발달 선별 검사:
→ 발달 지연 조기 발견 목적
→ 덴버 발달 선별 검사 (DDST-II)
→ 한국 영유아 발달 검사 (K-DST)

유아 평가 원칙:
→ 표준화 검사보다 실제 활동 관찰
→ 다양한 맥락·다양한 방법 활용
→ 평가의 윤리: 유아 존중·가족 신뢰
→ 결과를 지원·계획에 활용 (평가 = 낙인 금지)
```

## 교사의 역할

```
유아 교사의 역할:

촉진자 (Facilitator):
→ 유아의 탐구·발견을 지원
→ 적시에 적절한 자료 제공
→ 스캐폴딩 (Vygotsky): 근접 발달 영역(ZPD) 내 지원

관찰자 (Observer):
→ 유아 관찰로 학습과 발달 파악
→ 평가와 계획의 근거

환경 제공자 (Environment Provider):
→ 풍부하고 안전한 학습 환경 구성
→ 레지오: 환경이 제3의 교사

의사소통자 (Communicator):
→ 부모·가족과의 파트너십
→ 동료 교사·전문가와 협력

반성적 실천가 (Reflective Practitioner):
→ 자신의 교육 실천 성찰·개선
→ 저널 쓰기·동료 관찰·슈퍼비전

교사-유아 상호작용:
→ 반응적 상호작용: 유아의 신호에 즉각 반응
→ 확장적 발문: 유아의 생각 심화
→ 스캐폴딩: 현재 수준 이상 도전 지원
→ 수용적 태도: 틀린 답도 사고 과정 존중

교사 전문성:
→ 발달 지식: 영역별 발달 특성 이해
→ 교육 내용 지식: 수학·언어·과학·예술 개념
→ 교수법 지식: 다양한 교수 전략
→ 윤리적 실천: 유아 권리·다양성 존중

교사 소진 (Burnout) 예방:
→ 동료 지원·슈퍼비전·자기 돌봄
→ 전문성 개발·자율성 보장
→ 적절한 처우·근무 여건 개선
```

## 자주 묻는 질문

**Q. 누리과정의 놀이 중심 접근은 학습 준비성(school readiness)에 도움이 될까요?**
A. 연구 결과들은 놀이 기반 학습이 초등학교 준비에 오히려 더 효과적임을 보여줍니다. 자유 놀이에서 유아는 자기 조절 능력, 문제 해결력, 창의성, 언어 능력을 발달시키는데, 이것들이 학교 적응과 학업에 핵심적입니다. 반면 과도한 학업 중심(앉아서 쓰기, 수 계산 반복 훈련)은 단기적으로 학업 기술을 높일 수 있지만 장기적으로는 내적 동기와 창의성을 저해한다는 종단 연구들이 있습니다. 독일의 연구에서 학습 준비 중심의 유치원보다 놀이 중심 유치원 졸업생이 10살 이후 학업·사회성에서 더 우수했습니다. 2019 개정 누리과정이 놀이 중심을 강화한 것도 이런 연구 근거를 반영한 것입니다.

**Q. 레지오 에밀리아와 몬테소리의 가장 큰 차이는 무엇인가요?**
A. 두 접근법 모두 아동 존중과 능동적 학습을 강조하지만 철학과 방법에서 차이가 있습니다. 몬테소리는 개발된 구체적 교구와 정해진 사용법이 있는 구조화된 환경을 제공합니다. 교사는 직접 가르치기보다 관찰하고 안내하며, 아동의 독립적 활동을 최대한 보장합니다. 반면 레지오 에밀리아는 교사-유아의 협력적 탐구와 관계를 중심으로 합니다. 정해진 교구 대신 열린 재료를 통한 창의적 표현을 강조하고, 프로젝트는 유아의 관심에서 즉흥적으로 발전합니다. 커뮤니티와 문서화(학습 과정 기록·전시)가 핵심 실천입니다. 몬테소리가 더 구조화된 개인 학습을 강조한다면, 레지오는 공동체 안에서 함께 의미를 구성하는 사회적 학습을 중시합니다.
