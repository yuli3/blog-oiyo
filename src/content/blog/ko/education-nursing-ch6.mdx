# 6장: 심혈관 간호 — 심부전, 심근경색, 심장 모니터링

심혈관 질환(cardiovascular disease)은 전 세계적으로 사망 원인 1위입니다. 중환자실부터 재가 간호까지 모든 현장의 간호사는 심부전, 관상동맥 질환, 부정맥 환자를 돌봅니다. 신속하고 정확한 사정과 목표 지향적 중재는 생명을 살릴 수 있습니다.

## 심부전: 좌심실 부전 vs. 우심실 부전

심부전(heart failure, HF)은 심장이 신체의 대사 요구를 충족할 만큼 충분한 혈액을 펌프질하지 못할 때 발생합니다. 어느 심실이 기능 부전인지 파악하면 사정과 중재의 방향이 명확해집니다.

| 특징 | 좌심실 부전(Left-Sided HF) | 우심실 부전(Right-Sided HF) |
|------|--------------------------|--------------------------|
| 기전 | 좌심실 부전 → 혈액이 폐순환으로 역류 | 우심실 부전 → 혈액이 체순환 정맥으로 역류 |
| 특징적 증상 | 호흡곤란(dyspnea), 기좌호흡(orthopnea), 발작성 야간 호흡곤란(PND) | 말초 부종, 경정맥 확장(JVD), 복수(ascites) |
| 호흡음 | 수포음(crackles) — 폐부종 | 청명 (양심실 부전이 아닌 경우) |
| 체중 | 매일 체중 증가 (>1일 1 kg 이상 → 의사 보고) | 동일 |
| 주요 사정 | SpO₂, 호흡수 | 매일 체중, 말초 부종, 경정맥 확장 |

**NYHA 분류**: I등급(활동 시 증상 없음) → IV등급(안정 시에도 증상 있음).

## 심근경색(Myocardial Infarction, MI) 간호

심근경색은 관상동맥 폐색으로 심근 허혈이 발생하여 세포 괴사에 이르는 상태입니다. 간호 우선순위는 **MONA** 원칙을 따릅니다(현재 근거 기반으로 업데이트됨):
- **M**orphine(모르핀) — NSTEMI에서 예후 악화 가능성이 있으므로 신중하게 사용
- **O**xygen(산소) — SpO₂ < 90%일 때만 투여
- **N**itroglycerin(니트로글리세린) — 흉통 완화 목적(수축기혈압 < 90 mmHg이거나 PDE-5 억제제를 최근 복용한 경우 보류)
- **A**spirin(아스피린) — 금기가 없으면 325 mg 씹어서 즉시 복용

주요 간호 활동: 증상 발생 10분 이내 12유도 심전도 시행, 정맥 확보, 지속적 심장 모니터링, 검사(트로포닌, CK-MB, BNP), 경피적 관상동맥 중재술(PCI) 또는 혈전용해제 투여 준비.

**STEMI vs. NSTEMI**: STEMI는 ST 상승이 나타나며 긴급 PCI가 필요합니다(문(door)-풍선(balloon) 시간 ≤90분). NSTEMI는 ST 상승 없이 트로포닌이 상승합니다.

## 심전도(ECG) 기초

| 구성 요소 | 정상 수치 | 임상적 의의 |
|----------|---------|-----------|
| P파 | < 0.12초 | 심방 탈분극(atrial depolarization) |
| PR 간격 | 0.12–0.20초 | 방실 전도 시간(AV conduction time) |
| QRS 복합체 | < 0.12초 | 심실 탈분극(ventricular depolarization) |
| QT 간격 | < 0.44초(교정치) | 심실 재분극; QTc 연장 = 다형성 심실빈맥(TdP) 위험 |
| ST 분절 | 등전위선 | ST 상승 = STEMI; ST 하강 = 허혈 |

## 심장 약물

**디곡신(Digoxin)** (강심 배당체): 심근 수축력 증가, 방실 전도 억제. 투여 전 1분간 심첨부 맥박 확인 — 성인에서 분당 60회 미만이면 보류. 독성 징후: 서맥, 오심/구토, 시각 이상(노란색·녹색 후광), 부정맥. 치료적 농도: 0.5–2.0 ng/mL. 저칼륨혈증(hypokalemia)은 독성 위험을 높입니다.

**베타차단제(Beta-blockers)** (메토프롤롤, 카르베딜롤): 심박수와 심근 산소 요구량 감소. 심박수 < 50회/분 또는 수축기혈압 < 90 mmHg이면 보류. 갑자기 중단하지 마세요.

**ACE 억제제/ARB**: 후부하(afterload) 감소 및 심부전에서 심장 리모델링 예방. 저혈압, 고칼륨혈증, 신기능 모니터링 필요. ACE 억제제는 건조한 기침을 유발할 수 있어 ARB로 전환할 수 있습니다.

## 핵심 체크리스트

- [ ] 좌심실 부전과 우심실 부전의 기전, 특징적 증상, 우선 간호 사정을 비교하세요.
- [ ] 심근경색 의심 시 첫 10분 이내에 수행해야 할 간호 활동(MONA + 진단 검사)을 설명하세요.
- [ ] 디곡신 투여를 보류해야 하는 심첨부 맥박 기준을 말하고, 디곡신 독성의 세 가지 징후를 나열하세요.
