## 피부 타입 파악이 먼저

맞지 않는 제품이 문제를 만드는 경우가 많습니다. 내 피부 타입을 먼저 파악해야 합니다.

### 피부 타입 구분

| 타입 | 특징 |
|-----|-----|
| 건성 | 세안 후 당김, 각질, 광택 없음 |
| 지성 | 세안 후에도 번들거림, 모공 넓음, 여드름 |
| 복합성 | T존(이마·코·턱) 기름, U존(볼) 건조 |
| 민감성 | 제품에 쉽게 자극, 홍조, 가려움 |
| 중성 | 균형 잡힌 피부, 관리 쉬움 |

**피부 타입 테스트**: 세안 후 아무것도 바르지 않고 30분 대기 → 피부 상태 관찰.

## 기본 스킨케어 루틴

### 아침 루틴 (5분)

1. **세안** — 물 세안 or 약산성 폼클렌저 (아침은 가볍게)
2. **토너** — 피부결 정돈, 수분 공급
3. **에센스/세럼** — 집중 케어 성분
4. **아이크림** — 눈가 수분 (선택)
5. **보습크림** — 수분 잠금
6. **선크림 (SPF30 이상)** — 필수

### 저녁 루틴 (7~10분)

1. **클렌징 오일/밤** — 선크림·메이크업 제거 (더블 클렌징 1단계)
2. **폼 클렌저** — 더블 클렌징 2단계
3. **토너**
4. **에센스/세럼** — 아침보다 고농도 가능
5. **수면팩/크림** — 야간 보습

## 핵심 성분 가이드

### 수분 공급

| 성분 | 효과 | 특징 |
|-----|-----|-----|
| 히알루론산 | 강력한 수분 흡인 | 분자 크기 작은 것이 깊이 침투 |
| 글리세린 | 수분 잡아두기 | 저렴, 효과 우수 |
| 세라마이드 | 피부장벽 강화 | 건성·민감성 피부 필수 |
| 판테놀 (B5) | 진정+보습 | 민감성에 안전 |

### 미백·톤업

| 성분 | 효과 | 주의 |
|-----|-----|-----|
| 나이아신아마이드 | 멜라닌 이동 억제, 모공 축소 | 고농도(20% 이상) 자극 가능 |
| 비타민C (아스코르빈산) | 항산화, 미백 | 빛에 약해 저녁 사용 권장 |
| 알파 아부틴 | 기미·잡티 완화 | 비교적 자극 적음 |
| 트라넥삼산 | 기미 치료 성분 | 피부과 처방 가능 |

### 노화 방지

| 성분 | 효과 | 사용법 |
|-----|-----|------|
| 레티놀 (비타민A) | 세포 재생, 주름 완화 | 저농도부터 시작, 저녁만, SPF 필수 |
| 레티노산 | 레티놀보다 강력 | 피부과 처방 |
| 펩타이드 | 콜라겐 생성 자극 | 민감성도 사용 가능 |
| EGF (표피성장인자) | 세포 재생 | 의료용 성분 |

### 여드름·모공

| 성분 | 효과 |
|-----|-----|
| 살리실산 (BHA) | 모공 속 각질 녹임, 블랙헤드 |
| 벤조일퍼옥사이드 | 여드름균 제거 |
| 아젤라인산 | 여드름+미백 (민감성도 OK) |
| 녹차 추출물 | 항산화, 진정 |

## 피부 타입별 제품 선택

### 건성 피부

- **클렌저**: 크리미 폼 or 밀크 타입 (거품 적은 것)
- **보습**: 세라마이드·히알루론산 고보습 크림
- **피해야 할 것**: 알코올·살리실산 고함유 제품

### 지성·여드름성 피부

- **클렌저**: 살리실산 함유 폼 (주 2~3회)
- **보습**: 오일프리, 논코메도제닉 제품
- **세럼**: 나이아신아마이드, 아젤라인산
- **피해야 할 것**: 과한 유분감 크림, 광물유

### 민감성 피부

- **성분 확인**: 향료·알코올·인공색소 배제
- **신제품 테스트**: 목 뒤나 귀 뒤에 48시간 패치 테스트
- **세안**: 미지근한 물 (뜨거운 물은 피부장벽 손상)
- **권장**: 더마코스메틱 브랜드 (세타필, 라로슈포제, 아벤느)

## 선크림 완전 이해

피부 노화의 80%는 자외선. 선크림은 모든 스킨케어 중 가장 중요합니다.

### SPF·PA 의미

- **SPF**: UVB 차단 (자외선 B — 일광화상 원인), 숫자 높을수록 강함
  - SPF30 = UVB 97% 차단, SPF50 = 98% 차단
- **PA+**: UVA 차단 (자외선 A — 노화 원인), + 기호 많을수록 강함
  - PA++++ 권장

**실내 근무**: SPF30, PA++
**야외 활동**: SPF50+, PA++++

### 도포량

손가락 두 마디 분량 (약 2g)을 얼굴 전체에 고르게.

**재도포**: 2~3시간마다 (특히 야외에서)

## 여드름 관리

### 여드름 종류별 대처

| 종류 | 특징 | 대처 |
|-----|-----|-----|
| 화이트헤드 | 피지 막힌 상태 | 살리실산 국소 도포 |
| 블랙헤드 | 모공 개방된 피지 | BHA 세럼, 코 패치 |
| 구진 (빨간 여드름) | 염증 시작 | 짜지 말 것, 진정 처치 |
| 농포 (고름) | 염증 심화 | 피부과 방문 권장 |
| 낭종 (혹) | 깊은 염증 | 피부과 필수 |

**절대 하면 안 되는 것**: 손으로 짜기 → 흉터·색소침착.

### 식단과 여드름

고혈당 음식(흰 쌀·설탕·우유) → 인슐린 급등 → 피지 분비 증가 연구 있음.

완벽한 금식보다 **저혈당 식사** + 물 충분히 마시기.

## 피부과 시술 가이드

### 비용 대비 효과 높은 시술

| 시술 | 효과 | 비용 (참고) |
|-----|-----|-----------|
| 레이저 토닝 | 기미·잡티, 톤업 | 3~5만 원/회 |
| 피부 스케일링 | 각질 제거, 모공 | 3~5만 원/회 |
| 쥬베룩 (스킨부스터) | 수분 공급, 탄력 | 30~50만 원/회 |
| 프락셀 | 흉터·모공, 피부결 | 30~80만 원/회 |

**의료보험 적용**: 여드름 치료 (약 처방), 아토피 치료

## 피부 건강 생활 습관

- **수면 7~8시간**: 피부 세포 재생은 밤에 활발
- **수분 섭취**: 하루 1.5~2L
- **금연**: 흡연은 혈류 감소 → 칙칙한 피부
- **손 대지 않기**: 세균 전파 차단

좋은 피부는 제품보다 **수면·수분·선크림**이 먼저입니다. 비싼 제품보다 기본을 챙기세요.
