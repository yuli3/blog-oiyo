## 보관(Storage)과 창고의 역할

```
보관의 정의:
→ 물품을 일정 기간 안전하게 저장하는 활동
→ 생산과 소비의 시간적 불일치 해소

보관의 효용:
- 시간 효용: 생산·소비 시기 조정
- 가격 안정: 수요·공급 완충
- 위험 분산: 재고 분산 보관

창고의 기능:
1. 보관 기능: 물품 저장
2. 유통 가공: 조립, 분류, 포장 등
3. 정보 기능: 재고 정보 제공
4. 환적 기능: 화물 이동 거점
```

## 창고 유형

```
소유별 분류:
1. 자가 창고 (Owned Warehouse):
→ 기업이 직접 소유·운영
→ 장점: 통제 용이, 보안
→ 단점: 초기 투자비 高, 유연성 低

2. 영업 창고 (Public Warehouse):
→ 외부 창고 업체 임대·이용
→ 장점: 유연성, 초기 투자 없음
→ 단점: 통제 제한, 장기 비용 높음

3. 계약 창고 (Contract Warehouse):
→ 특정 기업과 장기 계약
→ 자가·영업 창고의 중간 형태

기능별 분류:
- 배송 센터 (DC): 배송 거점, 출하 중심
- 물류 센터 (LC): 보관 + 유통가공 + 배송
- 크로스도킹 센터: 보관 없이 즉시 분류·배송
```

## 재고 관리 기법

```
EOQ (경제적 주문량):
→ 주문 비용과 보유 비용의 합계를 최소화하는 주문량

공식: EOQ = √(2DS / H)
- D: 연간 수요량
- S: 1회 주문 비용
- H: 단위당 연간 보유 비용

재주문점 (ROP: Reorder Point):
→ 재고가 이 수준에 도달하면 발주
ROP = 평균 일일 수요 × 조달 기간 + 안전 재고

안전 재고 (Safety Stock):
→ 수요 변동·공급 지연에 대비한 여분 재고
→ 재고 부족 방지용 완충
```

## ABC 분석 (재고 분류)

```
ABC 분석:
→ 재고 품목을 중요도(금액·수량)에 따라 A, B, C로 분류
→ 파레토의 법칙 (80/20 원칙) 기반

A등급 (상위 20% 품목 → 매출의 약 80%):
→ 고가치, 엄격한 관리 필요
→ 재고 기록 정확, 잦은 주기 실사

B등급 (중간 30% 품목 → 매출의 약 15%):
→ 중간 가치, 정기적 관리

C등급 (하위 50% 품목 → 매출의 약 5%):
→ 저가치, 간소화된 관리
→ 대량 주문, 단순 관리

활용:
→ A급 품목에 물류 자원 집중 투입
→ 창고 내 A급 품목을 출구 근처 배치 (피킹 효율)
```

## 재고 회전율과 적정 재고

```
재고 회전율 (Inventory Turnover):
→ 일정 기간 재고가 몇 번 팔렸는가

공식: 재고 회전율 = 매출 원가 / 평균 재고액

재고 일수 (Days of Inventory):
→ 현재 재고로 며칠 버틸 수 있는가

공식: 재고 일수 = 365 / 재고 회전율

해석:
→ 회전율 높을수록: 재고 효율 좋음 (빠른 판매)
→ 회전율 낮을수록: 재고 과잉 (자금 묶힘)

JIT (Just-In-Time):
→ 필요한 물품을 필요한 시간에 필요한 만큼만 공급
→ 재고 최소화, 낭비 제거 (도요타 생산 방식)
```

## 하역(Cargo Handling) 장비

```
지게차 (Forklift):
→ 팔레트 화물 적재·이동
→ 카운터밸런스, 리치, 오더피커 등 종류

컨베이어 (Conveyor):
→ 연속 자동 이송
→ 벨트 컨베이어, 롤러 컨베이어

스태커 크레인 (Stacker Crane):
→ 자동화 창고에서 높은 랙에 화물 입출고
→ AS/RS (Automatic Storage Retrieval System)

AGV (Autonomous Guided Vehicle):
→ 자동화된 무인 운반차
→ 창고 내 자율 주행

팔레트 (Pallet):
→ 하역 표준화 도구
→ ISO 표준 팔레트: 1,200mm × 1,000mm
→ 팔레트 풀 시스템: 공동 사용으로 비용 절감
```

## WMS (창고관리시스템)

```
WMS (Warehouse Management System):
→ 창고 내 재고, 입출고, 위치를 실시간 관리하는 IT 시스템

주요 기능:
- 입고 처리: 수취, 검수, 위치 배정
- 재고 위치 관리: 로케이션 관리
- 피킹 지시: 최적 피킹 경로 제시
- 출고 처리: 출하 지시, 적재 관리
- 재고 실사: 주기적 재고 확인

연계 시스템:
- ERP: 전사적 자원 관리
- TMS: 운송관리시스템
- OMS: 주문관리시스템

바코드와 RFID:
- 바코드: 빛(레이저) 반사로 정보 읽기, 저비용
- RFID: 전파로 비접촉 정보 읽기, 고비용·고기능
→ RFID는 동시 다수 인식 가능 (바코드 대비 장점)
```

## 크로스도킹 (Cross Docking)

```
크로스도킹:
→ 입고된 화물을 보관하지 않고 즉시 분류·출고

특징:
→ 보관 비용 거의 없음
→ 신선 식품, 빠른 배송 필요 상품에 적합
→ 정밀한 공급망 조율 필요

적합한 상품:
- 유통기한 짧은 식품
- 긴급 부품
- 대형 유통사 특판 상품

크로스도킹 vs 일반 창고:
→ 크로스도킹: 재고 0 지향 (flow-through)
→ 일반 창고: 재고 보유 후 출고
```

## 자주 묻는 질문

**Q. ABC 분석에서 각 등급 비율을 정확히 외워야 하나요?**
A. A등급이 약 20% 품목으로 80% 매출을 차지한다는 원칙을 이해하는 것이 중요합니다. 정확한 비율은 조금씩 다를 수 있으나 파레토 법칙(80/20)을 기반으로 한다는 점을 기억하세요.

**Q. WMS와 ERP의 차이는 무엇인가요?**
A. WMS는 창고 내 물리적 재고·위치 관리에 특화된 시스템이고, ERP는 기업 전체(회계, 생산, 판매, 구매 등)를 통합 관리하는 시스템입니다. WMS는 ERP의 물류 모듈과 연계되어 운영됩니다.
