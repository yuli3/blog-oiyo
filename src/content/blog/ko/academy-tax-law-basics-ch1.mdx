## 조세의 의의

```
조세 (Tax):
국가 또는 지방자치단체가 공공서비스 재원 마련을 위해
법률에 의거 강제적으로 징수하는 금전 급부

조세의 특성:
① 강제성: 납세 의무 법률 강제
② 무상성: 반대 급부 없음 (공공서비스와 직결 안 됨)
③ 금전 급부: 원칙적으로 화폐
④ 법정성: 법률에 근거
```

## 조세의 분류

### 국세 vs 지방세

```
국세 (국가 징수):
- 내국세: 소득세·법인세·부가가치세·상속세·증여세 등
- 관세: 수입 물품

지방세 (지방자치단체 징수):
- 취득세·재산세·주민세·자동차세 등
- 도세·시군세 구분

세수 비중:
국세 > 지방세 (약 75:25)
```

### 직접세 vs 간접세

```
직접세:
- 담세자 = 납세자 (전가 없음)
- 예: 소득세·법인세·상속세·증여세·종합부동산세
- 특성: 응능과세 원칙, 누진세율 적용 가능

간접세:
- 담세자 ≠ 납세자 (소비자에게 전가)
- 예: 부가가치세·개별소비세·주세·관세
- 특성: 역진성 (저소득층 부담 비율 높음)
```

### 보통세 vs 목적세

```
보통세: 특정 용도 없이 일반 경비 충당
→ 소득세·법인세·부가가치세 등 대부분

목적세: 특정 목적 경비에만 사용
→ 교육세 (교육 재원)
→ 농어촌특별세 (농어촌 지원)
→ 교통에너지환경세 (도로·교통 재원)
```

## 조세법률주의

```
헌법 제59조:
"조세의 종목과 세율은 법률로 정한다."

조세법률주의의 내용:
① 과세요건 법정주의: 납세의무 발생 요건 법률 규정
② 과세요건 명확주의: 과세 요건 명확하게 규정
③ 소급과세 금지: 행위 후 소급 과세 불가
④ 엄격 해석 원칙: 유추 해석·확장 해석 금지

조세 평등주의:
같은 담세 능력이면 같은 세금
→ 응능과세 원칙
```

## 세법 체계

```
세법 구성:
국세기본법 (절차)
    ├── 소득세법
    ├── 법인세법
    ├── 부가가치세법
    ├── 상속세 및 증여세법
    ├── 종합부동산세법
    └── 개별소비세법 등

세법 적용 순서:
국세기본법 → 개별 세법 (특별법 우선)

납세의무의 성립·확정·소멸:
성립: 과세 요건 충족 시 자동 성립
확정: 신고·부과로 확정
소멸: 납부·충당·부과 제척 기간 경과
```

## 핵심 개념 카드

**직접세 vs 간접세** ★★★★★
: 직접세=담세자=납세자(소득세·법인세). 간접세=담세자≠납세자(부가세·소비세).
*암기 포인트: 직접=직접 부담, 간접=전가*

**조세법률주의 4원칙** ★★★★★
: 과세요건 법정·명확·소급금지·엄격해석. 헌법 제59조 근거.
*암기 포인트: 법정+명확+소급금지+엄격해석*

**국세 vs 지방세 주요 세목** ★★★★☆
: 국세=소득세·법인세·부가가치세·상속증여세. 지방세=취득세·재산세·주민세.
*암기 포인트: 취득·재산=지방세, 소득·법인·부가=국세*

## 실전 퀴즈

**Q. 부가가치세가 간접세인 이유는?**
> 납세자(판매사업자)가 실제 세금을 납부하지만, 상품 가격에 포함시켜 최종 소비자(담세자)에게 부담을 전가하기 때문.

**Q. 소급과세 금지 원칙의 의미는?**
> 납세자가 행위 당시 예상할 수 없었던 새로운 세금을 소급하여 부과 금지. 기존 법률에 따라 행동한 사람에게 불이익 소급 적용 불가.
