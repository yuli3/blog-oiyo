## 증거의 종류와 구별

```
증거 종류:
직접증거: 요증사실 직접 증명
간접증거(정황증거): 요증사실 간접 추인
인증: 사람 진술 (증인·감정인)
물증: 물건·문서

증거 능력:
증거로 사용할 수 있는 자격
능력 없으면 증거 자체로 쓸 수 없음

증명력 (신빙성):
증거 능력 있는 증거의 신빙성 정도
법관 자유심증으로 판단
```

---

## 자백 법칙

```
자백의 증거 능력:
임의성 있는 자백만 증거 능력 인정
임의성 없는 자백 = 증거 능력 없음

임의성 없는 자백:
고문·폭행·협박에 의한 자백
부당한 장기 구금 후 자백
이익 약속에 의한 자백

자백의 증명력 제한:
자백만으로 유죄 불가
보강증거 필요 (자백보강법칙)
자백 외 보강증거가 있어야 유죄 가능

이유:
자백 강요 방지
허위 자백 방지
```

## 전문 법칙

```
전문증거:
원진술자가 법정에서 직접 진술 않고
타인이 전달한 진술·문서

전문 법칙:
전문증거는 원칙적으로 증거 능력 없음
직접심리주의·반대신문권 보장

예외 (형소법 제312조 이하):
검사 작성 피의자 신문조서: 내용 인정 시 가능
경찰 작성 피의자 신문조서: 내용 인정 필요
참고인 진술서: 특신상태 + 필요성

특신상태:
신용성 정황적 보장이 있는 상태
진술 당시 특별히 신빙성 있는 상황
```

## 위법수집증거 배제 법칙

```
원칙:
위법하게 수집된 증거 = 증거 능력 없음
영장주의 위반 압수물 등

독수독과 이론:
위법 증거에서 파생된 2차 증거도 배제

예외:
선의의 예외 (good faith): 영장 유효 믿고 집행
필연적 발견: 어차피 합법적으로 발견될 것
희석 이론: 위법성과 관련성 희박
```

## 핵심 개념 카드

**자백보강법칙=자백만유죄불가** ★★★★★
: 자백 외 보강증거 없으면 유죄 불가.
*암기 포인트: 자백=보강증거필요*

**전문법칙=원칙배제** ★★★★★
: 전문증거는 원칙적 증거 능력 없음.
*암기 포인트: 전문증거=원칙배제*

**위법수집=독수독과** ★★★★☆
: 위법 증거에서 파생된 2차 증거도 배제.
*암기 포인트: 위법=독수독과*

## 실전 퀴즈

**Q. 경찰서에서 작성된 피의자 신문조서의 증거 능력 요건은?**
> 피의자가 법정에서 그 내용을 인정해야 함. 단순히 조서 자체 존재만으로는 증거 능력 없음. 내용 부인 시 증거 능력 없어짐. 검사 작성 조서: 피의자 서명 + 내용 인정. 경찰 작성 조서: 내용 인정 요건 더 엄격. 이유: 수사기관 조서 신뢰성 남용 방지.

**Q. 자백 보강 법칙의 취지와 보강증거 예시는?**
> 취지: 자백만으로 유죄 판결 시 자백 강요 남용 우려. 허위 자백 (무고한 자 자백) 방지. 보강증거 예시: 피해자 진술, 목격자 증언, CCTV 영상, 피해 흔적, 물증. 보강증거 정도: 자백 내용과 합리적 관련성 있으면 충분. 자백 내용 전부를 보강할 필요는 없음.
