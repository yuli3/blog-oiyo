## 시리즈 핵심 개념 압축 정리

### 시장 실패와 정부의 역할

**시장 실패 4원인**:
1. 공공재 → 무임승차 → 정부 공급
2. 외부효과 → 피구세(음) / 보조금(양)
3. 자연독점 → 공기업·규제
4. 정보 비대칭 → 역선택·도덕적 해이

**파레토 효율**: 다른 사람의 희생 없이는 더 나아질 수 없는 상태

**코즈 정리**: 재산권 명확 + 거래 비용 = 0이면 외부효과도 협상으로 해결

### 조세 원칙과 귀착

**탄력성과 세금 부담**: 비탄력적인 쪽이 더 많이 부담

| 공급 비탄력 | 공급자 부담 증가 | 토지세 → 지주 100% 부담 |
|-----------|--------------|-------------------|
| 수요 비탄력 | 소비자 부담 증가 | 담배세 → 흡연자 대부분 부담 |

**역탄력성 규칙**: 효율성 극대화 → 탄력성 낮은 재화에 높은 세율

**초과 부담**: ∝ t² (세율의 제곱에 비례)

### 공공지출·복지

**사무엘슨 조건**: ΣMBi = MC (모든 개인 한계편익 합 = 한계비용)

**중위투표자 정리**: 다수결 → 중위 투표자 선호 채택

**티부 가설**: 발로 하는 투표 → 지역 선호 반영

**지니계수**: 0(완전 평등) ~ 1(완전 불평등)

### 소득세·법인세 이론

**래퍼 곡선**: 세율 0% · 100% → 세수 = 0. 최적 세율 존재.

**대체효과**: 세율 ↑ → 여가 증가·노동 감소
**소득효과**: 세율 ↑ → 소득 유지 위해 노동 증가

**이중과세**: 법인세(법인) + 배당세(주주) → 배당세액공제로 완화

### 부가가치세·간접세

**VAT 납부 세액**: 매출세액 - 매입세액

**영세율 vs 면세**:
- 영세율: 세율 0% + 매입세액 환급 (수출)
- 면세: 과세 없음 + 매입세액 환급 불가 (의료·교육)

**VAT 역진성**: 소득 대비 소비 비율이 저소득자에서 높음

### 재정 정책

| 승수 | 공식 |
|------|------|
| 정부 지출 승수 | `1 / (1-MPC)` |
| 조세 승수 | `-MPC / (1-MPC)` |
| 균형예산 승수 | `1` |

**자동안정화장치**: 누진소득세 + 실업급여 (재량 정책 없이 자동)

**리카도 대등성**: 세금 감면 → 저축 증가 → 소비 불변 → 재정 정책 무효

**크라우딩아웃**: 재정 지출 → 이자율 ↑ → 민간 투자 ↓

### 지방재정

**오우츠 정리**: 선호 다양 지역 공공재 → 지방 공급이 효율적

**이상적 지방세**: 토지세·재산세 (이동성 낮음, 편익 원칙)

**지방교부세**: 기준재정수요 - 기준재정수입 (재정 형평화)

### 연금·건강보험

**부과식 수익률**: ≈ 인구 성장률 + 임금 성장률

**사무엘슨 조건과 건강보험**: 역선택 + 도덕적 해이 → 강제 사회보험

**수요 유인 공급**: 행위별 수가제 → 포괄수가제(DRG)로 억제

### 예산 이론

**예산 제도 발전**: 품목별 → 성과주의 → PPBS → ZBB → 성과 기반

**ZBB**: 전년도 기준 없이 0부터 재검토

**준예산**: 헌법 기관 경비, 법령 의무 지출만 집행 가능

## 세무사 시험 출제 유형 분석

### 유형 1: 개념 정의·분류 (약 40%)

- 시장 실패의 원인과 해결책
- 조세 원칙 (효율성·공평성·단순성)
- 예산 제도 특징 비교
- 공공재 vs 사유재 vs 클럽재 vs 공유자원

**전략**: 개념을 예시와 함께 암기. 표로 정리해 비교.

### 유형 2: 귀착 분석 계산 (약 25%)

- 탄력성으로 세금 부담 배분 계산
- 승수 계산 (MPC 주어질 때)
- 초과 부담 계산

**전략**: 공식 암기 + 계산 연습. 단위 주의.

### 유형 3: 정책 효과 분석 (약 25%)

- 재정 정책 효과 (IS-LM 맥락)
- 사회보험 정책 효과
- 보조금 형태에 따른 후생 효과

**전략**: 메커니즘을 단계적으로 서술 연습.

### 유형 4: 사례 응용 (약 10%)

- 실제 사례에 이론 적용 (특정 정책의 귀착, 효율성 분석)

## 자주 틀리는 포인트

**함정 1: 영세율 vs 면세 혼동**
- 영세율 = 0% + 매입세액 환급 가능 (실질 VAT 부담 0)
- 면세 = 과세 없음이지만 매입세액 환급 불가 (일부 VAT 부담 내포)

**함정 2: 균형예산 승수**
- 세금 인상 + 지출 증가가 동시에 이루어지면 승수 = 1
- 지출만 늘리거나 세금만 낮추는 것과 다름

**함정 3: 리카도 대등성의 적용 조건**
- 조세 감면 시 효과가 없다는 것은 이상적 조건에서만 성립
- 현실에서는 부분적 소비 증가 존재

**함정 4: 크라우딩아웃과 IS-LM**
- IS 수직이면 크라우딩아웃 없음 (투자가 이자율 비탄력)
- LM 수직이면 완전 크라우딩아웃

**함정 5: 코즈 정리 적용 범위**
- 거래 비용 = 0이어야 협상으로 해결
- 당사자가 많을수록 거래 비용 증가 → 코즈 정리 적용 어려움

## 재정학 면접 활용 가이드

공기업·금융기관 면접에서 재정학 지식을 활용하는 방법:

**"국가채무 증가가 왜 문제인가?"**
→ 크라우딩아웃(이자율 상승·민간 투자 감소) + 세대 간 형평성(미래 세대 부담) + 재정 위기 위험

**"부가가치세 인상의 경제적 효과는?"**
→ 소비 억제(물가 상승·소비 감소) + 역진성 문제(저소득층 부담 비율 증가) + 세수 증가·세율 인상의 중립성

**"고령화가 재정에 미치는 영향은?"**
→ 연금·건강보험 지출 증가 + 노동 인구 감소로 세수 기반 축소 + 부과식 연금의 세대 간 부담 증가

**"정부가 경기 부양책을 펼 때 효과와 한계는?"**
→ 승수 효과로 GDP 증가 + 크라우딩아웃으로 민간 투자 감소 + 리카도 대등성으로 소비 불변 가능성 + 자동안정화장치로 부분 대응 이미 작동 중
