## 핵심 기간 암기표

| 사항 | 기간 |
|------|------|
| 행정 심판 청구 | 안 날 90일 / 있은 날 180일 |
| 취소 소송 제소 | 안 날 90일 / 있은 날 1년 |
| 수용 재결 이의신청 | 재결일로부터 30일 |
| 수용 보상금 소송 | 재결일로부터 90일 |
| 소청 심사 청구 | 처분 안 날로부터 30일 |

| 청문 통지 | 청문일 10일 전 이상 |
| 사전 통지 의견 제출 | 10일 이상 부여 |

## 행정 행위 효력 비교

| 효력 | 내용 | 포인트 |
|------|------|--------|
| 공정력 | 위법해도 취소 전까지 유효 | 적법 추정 아님 |
| 구속력 | 상대방·행정청 구속 | 내용의 효력 |
| 불가쟁력 | 제소 기간 경과 후 쟁송 불가 | 무효는 예외 |
| 불가변력 | 행정청 스스로 취소·변경 불가 | 준사법적 행위에만 |

## 빈출 암기 공식

```
비례 원칙: 적합성 → 필요성 → 상당성
신뢰보호: 공적표명 + 신뢰 + 처분 = 보호

행정심판 기간: 안날 90일 / 있은날 180일
취소소송 기간: 안날 90일 / 있은날 1년

대집행 요건: 작위+대체+불가+공익
청문: 불이익 처분 + 법령 규정 + 행정청 인정

자치사무 감독: 적법성만
기관위임사무 감독: 합목적성도 가능

징계: 파면>해임>강등>정직>감봉>견책
파면 5년 재임용 금지, 해임 3년 금지

국가배상 공무원 과실 필요
영조물 하자 무과실 책임
손실보상 정당한 보상 (완전 보상)
```

## 실전 퀴즈 (종합)

**Q. 행정 처분에 불복할 때 행정 심판과 행정 소송 중 어느 것이 좋은가?**
> 행정 심판: 위법+부당 모두 다툼, 비용 저렴, 빠름. 행정 소송: 위법만 다툼, 법원 판단. 원칙 임의 선택. 단, 특별법에 심판 전치 규정 있으면 심판 먼저.

**Q. 공무원이 파면되면 5년 후 공무원 재임용이 가능한가?**
> 가능. 파면은 5년간 공무원 임용 결격사유. 5년 경과 후 결격사유 해소.

**Q. 도로가 폭우로 갑자기 함몰되어 사고가 발생했다. 지방자치단체의 면책 주장이 가능한가?**
> 불가. 영조물 하자는 무과실 책임. 단, 자연재해 등 불가항력으로 예측·방지 불가했음을 증명하면 면책 가능.
