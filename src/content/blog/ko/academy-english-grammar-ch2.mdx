## 2강 개요

조동사(Modal Verbs)는 영어에서 화자의 태도, 확신의 정도, 의무감, 가능성을 나타내는 핵심 문법입니다. 같은 상황에서도 `must`를 쓰느냐 `should`를 쓰느냐에 따라 강도가 완전히 달라집니다. 각 조동사의 핵심 뉘앙스를 이해하면 영어 소통의 정확성이 크게 높아집니다.

---

## 조동사 의미 지도

### 확신의 정도 (추측)

현재/미래 추측:
```
must > should > may/might > could
(100% 확신) → (가능성 높음) → (가능) → (희박한 가능성)

He must be tired. (분명히 피곤할 것이다 — 근거 있는 강한 추측)
He should be there by now. (지금쯤 거기 있을 것이다)
He may/might be late. (늦을 수도 있다)
He could be anywhere. (어디 있을지도 모른다)
```

과거 추측 (`have p.p.` 사용):
```
She must have forgotten. (분명히 잊었을 것이다)
He might have left early. (일찍 떠났을 수도 있다)
They can't have seen us. (우리를 봤을 리 없다)
```

## can vs be able to

| | can | be able to |
|---|---|---|
| 현재 능력 | Can you swim? | Are you able to swim? (더 격식) |
| 미래 가능성 | — | I will be able to attend. (will can ❌) |
| 과거 능력 | I could swim at 5. | I was able to escape (specific achievement) |
| 허가 | Can I use your phone? | — |

<Callout type="note">
`could`는 과거의 일반적 능력(어릴 때 수영할 수 있었다)에, `was/were able to`는 특정 상황의 성취(결국 탈출에 성공했다)에 씁니다.
</Callout>

## must vs have to vs should

```
You must submit the report by Friday. (내부 강한 의무 — 본인이 느낌)
You have to submit the report by Friday. (외부 규칙·의무 — 규정이 그러함)
You should submit early. (권고·조언 — 하는 게 좋지만 강제는 아님)
You'd better submit on time. (경고 — 안 하면 결과 있음)
```

부정형에서 의미가 크게 달라집니다:
```
You must not smoke here. (절대 금지 — 강한 금지)
You don't have to come. (올 필요 없다 — 선택)
You shouldn't be late. (늦으면 안 된다 — 조언)
```

## would: 다양한 용법

`would`는 과거 습관, 정중한 요청, 가정법, 완곡한 표현에 쓰입니다.

```python
# 과거 습관 (used to와 유사, 상태 동사에는 would ❌)
When I was young, I would play outside every day.
(어릴 때 매일 밖에서 놀곤 했다)

# 정중한 요청
Would you mind opening the window?
Would you like some coffee?

# 가정법
If I had more time, I would travel the world.
I would have called you if I had known.

# 완곡한 표현
I would like to report an issue. (= I want to, but more polite)
```

## may vs might

| | may | might |
|---|---|---|
| 가능성 | 50% 정도 | 30% 이하 |
| 허가 | 격식적 허가 | — |
| 과거 | may have done | might have done |
| 양보 | Though he may be right... | Though he might be right... |

```
May I come in? (격식적 허가 요청)
You may leave early today. (허가 부여)
It might rain this afternoon. (비올 가능성 낮음)
It may rain this afternoon. (비올 가능성 있음)
```

---

## shall vs will

현대 영어에서 `shall`은 주로 형식적 제안이나 법률 문서에서 사용됩니다.

```
Shall we dance? (제안 — 우리 춤출까요?)
Shall I call a taxi? (제안 — 택시 불러드릴까요?)
The contractor shall complete work by June 30. (계약서 — 의무)
```

## 자주 묻는 질문

**Q: "I'd like to"와 "I want to"의 차이는?**
A: `I'd like to`는 `I would like to`의 단축형으로, `I want to`보다 정중하고 부드럽습니다. 공식적 상황이나 처음 만나는 사람과의 대화에서는 `I'd like to`를 사용하세요.

**Q: TOEIC에서 조동사 문제 공략법은?**
A: 문맥에서 의무/가능성/추측 중 어느 것인지 파악하고, 빈칸 뒤 동사 형태(원형/have p.p.)를 확인하세요. `must` + have p.p. = 과거에 대한 추측, `should` + have p.p. = 과거에 했어야 했는데 안 한 것.
