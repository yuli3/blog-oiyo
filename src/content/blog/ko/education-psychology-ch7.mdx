## 발달 심리학이란

발달 심리학은 인간이 태어나서 죽을 때까지 어떻게 변화하는지를 연구합니다. 신체·인지·감정·사회성 모든 측면에서의 변화를 다룹니다.

```
핵심 질문:
- 성장은 연속적인가, 단계적인가?
- 유전(nature)과 환경(nurture) 중 무엇이 더 중요한가?
- 변화의 동력은 무엇인가?
```

## 피아제의 인지 발달 단계

장 피아제(Jean Piaget)는 아동이 능동적으로 지식을 구성한다고 주장했습니다.

```
1단계: 감각운동기 (0~2세)
→ 오감과 움직임으로 세계 탐색
→ 핵심: 대상 영속성 (사라진 것도 존재함)

2단계: 전조작기 (2~7세)
→ 언어 발달, 상징적 사고
→ 자기중심성 (타인 시각 이해 어려움)

3단계: 구체적 조작기 (7~11세)
→ 논리적 사고 (보존 개념 획득)
→ 분류·계열화 가능

4단계: 형식적 조작기 (12세~)
→ 추상적·가설적 사고 가능
→ 과학적 추론 발달
```

## 에릭슨의 심리사회적 발달

에릭 에릭슨은 전 생애에 걸친 8단계 발달 이론을 제시했습니다.

| 단계 | 나이 | 핵심 갈등 | 성공 결과 |
|------|------|----------|----------|
| 1 | 0~1세 | 신뢰 vs 불신 | 희망 |
| 2 | 1~3세 | 자율성 vs 수치심 | 의지 |
| 3 | 3~6세 | 주도성 vs 죄책감 | 목적 |
| 4 | 6~12세 | 근면성 vs 열등감 | 능력 |
| 5 | 청소년 | 정체성 vs 역할 혼란 | 성실 |
| 6 | 성인 초기 | 친밀감 vs 고립 | 사랑 |
| 7 | 중년 | 생산성 vs 침체 | 배려 |
| 8 | 노년 | 자아 통합 vs 절망 | 지혜 |

## 애착 이론

존 볼비(John Bowlby)의 애착 이론: 영아와 양육자의 정서적 유대가 이후 발달의 기초가 됩니다.

```
메리 에인스워스의 애착 유형 (낯선 상황 실험):

안정 애착 (약 60%):
- 양육자 떠날 때 불안, 돌아오면 쉽게 안정
- 양육자가 일관되게 반응적일 때 형성

불안 애착 (약 20%):
- 양육자와 분리 시 극도로 불안
- 재결합 후에도 분노·매달림

회피 애착 (약 15%):
- 양육자와 분리·재결합 시 별 반응 없음
- 양육자가 거부적·냉담할 때 형성

비조직화 애착 (약 5%):
- 일관성 없는 반응
- 학대·방치 환경에서 형성
```

## 언어 발달

```
0~6개월: 옹알이 시작
12개월: 첫 단어 (mama, papa)
18~24개월: 단어 폭발 — 어휘 급증
2세: 두 단어 문장 ("더 줘", "맘마 주세요")
3~4세: 문법 규칙 습득 시작
5세: 성인과 유사한 문장 구성

촘스키의 언어 습득 장치(LAD):
→ 인간은 언어 학습을 위한 선천적 능력을 가짐
→ 보편 문법의 존재 주장
```

## 청소년기 — 정체성 형성

```
마샤의 정체성 지위 이론:

정체성 성취: 탐색 후 헌신
→ 가장 건강한 상태

정체성 유예: 탐색 중, 아직 결정 안 함
→ 불안하지만 성장 중

정체성 조기 폐쇄: 탐색 없이 헌신 (부모 가치 수용)
→ 경직되기 쉬움

정체성 혼미: 탐색도 헌신도 없음
→ 발달적 문제 가능성
```

## 성인기와 노년기

```
성인 초기 (20~40대):
- 친밀한 관계 형성 (에릭슨 6단계)
- 직업 정체성 확립
- 뇌 가소성 여전히 높음

중년기 (40~60대):
- 생산성 vs 침체 갈등
- 중년의 위기: 삶의 의미 재평가
- 결정성 지능 증가 (경험 기반 문제 해결)

노년기 (60대~):
- 자아 통합: 삶 전체 수용
- 결정성 지능 유지, 유동성 지능 감소
- 사회정서 선택 이론: 의미 있는 관계에 집중
```

## 핵심 암기 포인트

*피아제: 감각운동 → 전조작 → 구체적조작 → 형식적조작*
*에릭슨: 8단계 갈등 — 신뢰·자율·주도·근면·정체성·친밀·생산·통합*
*애착 유형: 안정(60%) / 불안(20%) / 회피(15%) / 비조직화(5%)*
*유동성 지능 (나이와 함께 감소) vs 결정성 지능 (경험으로 증가)*
