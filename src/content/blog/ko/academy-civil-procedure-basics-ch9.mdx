## 독촉 절차 (지급명령)

```
지급명령:
채권자의 신청으로 법원이 채무자에게
금전 등 지급을 명하는 약식 절차

장점:
소장 작성·변론 없이 신속 처리
인지 비용 1/10 (일반 소송 대비)

절차:
지급명령 신청 → 법원 심사 → 지급명령 발령
채무자에게 송달 → 2주 내 이의신청 없으면 확정

이의신청:
채무자가 2주 이내 이의신청
→ 통상 소송으로 이행

확정된 지급명령:
집행권원 효력 (강제집행 가능)
기판력은 없음 (통상 소송과 차이)
```

## 소액사건심판

```
소액사건심판:
소송 물가액 3천만 원 이하 사건의 간이 절차

특징:
1회 기일로 심리 종결 (집중 심리)
판결 이유 간략 기재 생략 가능
항소 제한: 법령 위반·판례 위반만

소송 촉진 원칙:
기일 날짜에 양당사자 출석 권장
불출석 시 진술 간주 가능

이행권고결정:
소액사건에서 지급명령과 유사한 약식 결정
이의신청 없으면 확정
```

## 가사소송

```
가사소송:
가족 관계에 관한 소송
가정법원 전속 관할

가사 소송 종류:
가류: 이혼, 친생자 부인 등
나류: 이혼에 따른 재산 분할 등
다류: 친권자 지정 등

직권주의:
가사소송에서 법원이 직권으로 사실 탐지 가능
→ 변론주의 예외

조정 전치주의:
소 제기 전 조정 신청 먼저 (일부 사건)

이혼의 종류:
협의이혼: 당사자 합의 (법원 이혼 의사 확인)
재판상 이혼: 이혼 사유 있을 때 법원 판결
```

## 행정소송

```
행정소송:
행정청의 위법한 처분에 대한 불복 소송

취소소송:
위법한 행정처분 취소 요구
처분청을 피고로

항고소송:
취소소송·무효등확인소송·부작위위법확인소송

당사자소송:
공법상 법률관계 직접 다투는 소송

기간 제한:
처분 안 날로부터 90일, 처분일로부터 1년
→ 어느 하나라도 경과 시 소 불가

행정심판 전치주의:
일부 사건: 행정심판 먼저 거쳐야 소 제기 가능
원칙: 행정소송과 행정심판 선택 가능
```

## 핵심 개념 카드

**지급명령=이의2주** ★★★★★
: 지급명령 송달 후 2주 내 이의. 이의 없으면 확정→집행권원.
*암기 포인트: 지급명령=이의 2주*

**소액사건=3천만원이하** ★★★★★
: 소송 물가액 3천만 원 이하. 1회 기일+항소 제한.
*암기 포인트: 소액=3천만원+간이절차*

**행정소송 기간=90일/1년** ★★★★★
: 처분 안날부터 90일, 처분일부터 1년. 모두 충족해야.
*암기 포인트: 행정소송=90일+1년 둘 다*

## 실전 퀴즈

**Q. 지급명령과 소송의 핵심 차이는?**
> 지급명령: 채무자 이의신청 없으면 변론 없이 확정. 인지 1/10. 기판력 없음(확정판결과 차이). 소송: 변론 필요. 인지 전액. 기판력 있음. 지급명령은 채무자가 다투지 않을 것이 예상될 때 효율적.

**Q. 행정소송에서 90일과 1년의 제소 기간 중 어느 것이 먼저 경과하면?**
> 둘 중 먼저 경과하는 기간이 도과하면 소 제기 불가. 처분 후 1년이 지났으면 90일 내라도 불가. 처분을 안 날이 처분일로부터 1년 전이어도 안 날로부터 90일이 지나면 불가.
