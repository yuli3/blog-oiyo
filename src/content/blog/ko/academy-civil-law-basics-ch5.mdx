## 친족법의 기본 구조

**친족(親族)**: 혈연·혼인·입양으로 연결된 가족 관계에 있는 사람.

### 친족의 범위 (민법 제777조)

```
친족 범위:
① 8촌 이내 혈족
② 4촌 이내 인척
③ 배우자
```

**혈족**: 혈연으로 연결된 사람 (직계·방계)  
**인척**: 혼인으로 연결된 사람 (배우자의 혈족, 혈족의 배우자)

## 혼인법

### 혼인의 성립 요건

```
실질적 요건:
① 혼인 의사 합치 (당사자 의사)
② 혼인 적령 (만 18세 이상)
③ 근친혼 금지 (8촌 이내 혈족, 6촌 이내 혈족 등)
④ 중혼 금지

형식적 요건:
- 가족관계등록법에 따른 신고 (창설적 신고)
```

**사실혼**: 법적 신고 없이 부부로 생활. 일부 법적 보호 있으나 상속권·친족권 없음.

### 이혼

```
협의이혼: 당사자 합의 + 가정법원 확인 + 신고
재판이혼: 법정 이혼 사유 해당 시 법원에 청구
          (배우자 부정행위, 악의 유기, 심히 부당한 대우 등)
```

## 상속법

### 상속의 개시

피상속인(사망자) 사망 시 즉시 개시. 상속인은 별도 의사 표시 없이 자동 취득.

### 법정 상속 순위 (민법 제1000조)

```
1순위: 직계비속 (자녀, 손자녀) + 배우자
2순위: 직계존속 (부모, 조부모) + 배우자
3순위: 형제자매
4순위: 4촌 이내 방계혈족

→ 배우자: 직계비속이나 직계존속과 공동 상속
   배우자 단독 상속: 다른 순위 없을 때
```

**대습상속**: 상속인이 피상속인보다 먼저 사망한 경우 그 직계비속이 대신 상속.

### 법정 상속 분율 (민법 제1009조)

```
같은 순위의 상속인: 균분 상속
배우자와 공동 상속 시: 배우자 = 1.5배 가산

예시: 배우자 + 자녀 2명
자녀 1인 지분 = 1
배우자 지분 = 1.5
총 = 3.5
배우자: 1.5/3.5 ≈ 43%
자녀 각: 1/3.5 ≈ 28.5%
```

## 상속의 승인과 포기

### 단순 승인

상속 재산(적극·소극 모두) 전부 승계. 상속개시 안 날로부터 **3개월** 내에 포기·한정 승인 안 하면 단순 승인 간주.

### 한정 승인

상속 재산 한도 내에서만 채무 변제. 상속인 전원 동의 또는 단독 가능.

```
한정 승인 시:
상속 재산 > 채무 → 잉여 상속인 취득
상속 재산 < 채무 → 나머지 채무는 소멸 (상속인 개인 재산 보호)
```

### 상속 포기

상속 자체를 거절. 상속 개시 안 날로부터 3개월 내.  
포기하면 처음부터 상속인 아닌 것으로 간주 → 다음 순위 상속인에게.

## 유언

### 유언의 방식 (엄격한 요식행위)

```
유언 방식:
① 자필증서 유언: 전문·날짜·주소·성명 자필 + 날인
② 녹음 유언: 유언·성명·날짜 + 참여인 1명
③ 공정증서 유언: 공증인 + 증인 2명 앞에서
④ 비밀증서 유언: 봉인된 봉투 + 공증인·증인 2명
⑤ 구수증서 유언: 임박한 사망 위급 시, 증인 2명
```

**유언 능력**: 만 17세 이상.

## 유류분 (遺留分)

상속인의 최소한의 상속 권리 보장 제도.

```
유류분 비율:
직계비속·배우자: 법정 상속분의 1/2
직계존속·형제자매: 법정 상속분의 1/3

유류분 청구:
상속 개시 안 날 + 반환 청구해야 할 증여·유증 사실 안 날로부터 1년
상속 개시일로부터 10년
```

## 핵심 개념 카드

**법정 상속 순위** ★★★★★
: 1순위 직계비속, 2순위 직계존속, 3순위 형제자매, 4순위 4촌 이내 방계. 배우자는 1·2순위와 공동 상속.
*암기 포인트: 비속→존속→형제자매→방계 + 배우자 공동*

**한정 승인** ★★★★★
: 상속 재산 한도 내에서만 채무 변제. 상속인 개인 재산은 보호됨. 3개월 내 신청.
*암기 포인트: 한정 승인 = 상속 재산 범위 내 책임*

**유류분** ★★★★☆
: 직계비속·배우자 법정상속분의 1/2, 직계존속·형제자매 1/3. 1년(안 날)/10년(개시일) 제척기간.
*암기 포인트: 직계비속 1/2, 존속·형제자매 1/3*

## 실전 퀴즈

**Q. 甲이 사망 시 배우자 乙, 자녀 丙·丁이 있다. 각각의 법정 상속분은?**
> 乙(배우자): 1.5/(1.5+1+1) = 3/7. 丙(자녀): 1/3.5 = 2/7. 丁(자녀): 2/7.

**Q. 상속인이 상속 재산보다 채무가 훨씬 많은 것을 알았을 때 취해야 할 조치는?**
> 상속 개시 안 날로부터 3개월 내 가정법원에 한정 승인 또는 포기 신고. 기간 내 조치 없으면 단순 승인 간주.
