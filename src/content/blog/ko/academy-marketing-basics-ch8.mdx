## 글로벌 마케팅 진입 전략

```
수출:
간접 수출: 수출 중간상 활용
직접 수출: 자체 수출 부서

계약 방식:
라이선싱: 지적재산권 허여
프랜차이징: 비즈니스 모델 허여
계약 생산: 현지 생산 위탁

투자 방식:
합작투자 (JV): 현지 기업과 공동 소유
단독 투자: 자회사 설립·인수

진입장벽 낮음 → 높음:
수출→라이선싱→프랜차이징→JV→단독투자
```

## 표준화 vs 현지화

```
표준화:
전 세계 동일 마케팅 믹스
규모의 경제·브랜드 일관성
예: 코카콜라 로고·맥도날드 M

현지화:
현지 문화·소비자에 맞게 조정
높은 비용, 현지 반응 우수
예: 맥도날드 메뉴 (인도=채식·한국=불고기버거)

글로컬(Glocal):
글로벌 브랜드 + 로컬 적응
두 가지 장점 결합
```

## 관계 마케팅과 CRM

```
관계 마케팅:
신규 고객 획득보다 기존 고객 유지 중시
충성 고객 1인 > 신규 고객 5인 이상 가치

CRM (고객관계관리):
고객 데이터 수집·분석
개인화된 커뮤니케이션
생애 전반 가치 극대화

고객 생애 가치 (CLV):
고객 관계 기간 전체 수익 현재가치
CLV 높은 고객 집중 투자

고객 유지율:
5% 증가 → 이익 25~95% 증가 가능
이탈 원인 분석·대응
```

## 디지털 전환과 마케팅

```
마케팅 4.0 (Kotler):
전통 마케팅 → 디지털 마케팅 통합
온·오프라인 경계 소멸

5A 고객 여정:
Aware → Appeal → Ask → Act → Advocate
구매 후 옹호자(Advocate)가 핵심

데이터 기반 마케팅:
빅데이터·AI 활용
개인화 추천
실시간 타겟팅
```

## 실전 퀴즈

**Q. 라이선싱과 프랜차이징의 차이는?**
> 라이선싱: 특허·상표·기술 등 지적재산권만 허여. 로열티 수취. 제품 제조 허여 (예: 디즈니 캐릭터 사용권). 프랜차이징: 비즈니스 전체 모델·운영 방식 허여. 더 포괄적인 통제. 가맹점이 브랜드·메뉴·교육까지 동일하게 운영. 맥도날드·스타벅스가 대표적 프랜차이징.

**Q. 고객 유지율이 수익에 미치는 영향이 큰 이유는?**
> 신규 고객 획득 비용 = 기존 유지 비용의 5~7배. 기존 고객: 재구매 확률 높음·추가 구매·구전 효과. CLV 높은 고객 확보가 장기 성장 핵심. 이탈률 5% 감소 → 이익 25~95% 증가 연구 결과. CRM·멤버십·로열티 프로그램의 이론적 근거.
