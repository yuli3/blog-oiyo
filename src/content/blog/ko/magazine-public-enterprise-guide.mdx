## 공기업 취업이 왜 어려운가

공기업은 안정성과 보상 수준으로 인해 경쟁률이 높습니다.

그러나 난이도와 경쟁률이 천차만별입니다. 한국전력·한국철도공사와 같은 대형 공기업은 수백 대 일의 경쟁률을 보이는 반면, 중소형 지방 공기업은 상대적으로 경쟁이 낮습니다.

**공기업 취업의 핵심 인식**:
- 필기 → 서류 → 면접이 아니라, **공기업마다 전형 순서가 다름**
- NCS 필기가 만능이 아님 — 직무 적합성 심사가 함께 진행
- '공기업 취업'이 아닌 '특정 기관 취업'으로 타겟을 좁혀야 함

## 공기업 유형과 특성

### 공공기관 유형

| 유형 | 대표 기관 | 특징 |
|------|---------|------|
| **공기업** (시장형) | 한국전력, 가스공사, 인천공항 | 매출 2조+, 높은 자립도 |
| **공기업** (준시장형) | 한국철도공사, 수자원공사 | 시장·정책 혼합 |
| **준정부기관** (기금관리) | 국민연금공단, 근로복지공단 | 기금 운용 중심 |
| **준정부기관** (위탁집행) | 한국산업인력공단, 심평원 | 정부 업무 위탁 |
| **기타 공공기관** | 지방 공기업, 소규모 공공기관 | 다양 |

타겟 기관 선정 시 고려 사항:
- 관심 업무 분야 (에너지·교통·금융·사회복지 등)
- 희망 근무지 (본사 위치·지방 이전 여부)
- 연봉·복지 수준
- 필기 비중 vs 면접 비중

## 채용 공고 분석법

**공공기관 통합 채용 공고**: [알리오](https://www.alio.go.kr/), [잡알리오](https://job.alio.go.kr/), [나라일터](https://www.gojobs.go.kr/), [잡플래닛](https://www.jobplanet.co.kr/), 각 기관 홈페이지. 민간·후기 목록은 [취업 가이드](/ko/job-search-korea-guide/).

공고 분석 시 확인 사항:
1. **채용 유형**: 체험형 인턴 vs 채용형 인턴 vs 정규직 공채
2. **전형 순서**: 서류→필기→면접 vs 필기→서류→면접
3. **직무**: 사무·행정 / 기술·ICT / 전문직 / 연구
4. **우대 사항**: 지역인재 (30% 가산), 취업 취약 계층, 특정 자격증

## NCS 직업기초능력 필기 전략

### NCS 10개 영역

| 영역 | 주요 내용 |
|------|---------|
| 의사소통능력 | 문서 이해·작성, 경청, 말하기 |
| 수리능력 | 기초 계산, 통계, 도표 해석 |
| 문제해결능력 | 사고력, 문제 인식, 대안 선택 |
| 자기개발능력 | 목표 설정, 자기 관리 |
| 자원관리능력 | 시간·돈·인력·물적 자원 관리 |
| 대인관계능력 | 팀워크, 갈등 관리, 협상 |
| 정보능력 | 정보 수집·분석·활용 |
| 기술능력 | 도구·장비 사용 |
| 조직이해능력 | 조직 구조·문화 이해 |
| 직업윤리 | 직장 예절, 윤리 의식 |

### 시험 유형별 전략

**PSAT형 (피셋형)**: 언어논리+자료해석+상황판단 통합
- 많은 문항, 제한된 시간 → 시간 배분 전략이 핵심
- 자료해석: 계산 전략(나누기보다 비교·어림)
- 언어논리: 논리 퀴즈 유형 집중

**모듈형 (영역별 구분)**: 10개 영역별 문제
- 각 영역 기출 유형 파악이 핵심
- 약한 영역 집중 보완

**혼합형**: PSAT + 직무 지식
- 기관별 직무 지식 범위 파악 필요

## 직무능력평가 (전공 필기)

많은 공기업이 NCS 외에 **직무 전공 지식**을 별도 평가합니다.

주요 직무별 출제 영역:

| 직무 | 주요 과목 |
|------|---------|
| 경영·행정 | 경영학, 경제학, 행정학, 회계학 |
| 전기·전력 | 전기기사 수준 전공 |
| 토목·건설 | 토목기사 수준 전공 |
| ICT | 데이터베이스, 알고리즘, 네트워크 |
| 환경 | 환경기사 수준 전공 |

경영직은 경영학 핵심 시리즈와 경제학 핵심 시리즈가 직무 시험 준비에 도움이 됩니다.

## 서류 전형 전략

공기업 서류는 자소서 중심입니다. NCS 기반 역량 중심 자소서가 일반적입니다.

### NCS 자소서 작성 공식

**STAR 기법** + **NCS 역량 매핑**:
- **S (상황)**: 어떤 상황이었나
- **T (과제)**: 어떤 과제/목표가 있었나
- **A (행동)**: 내가 구체적으로 무엇을 했나
- **R (결과)**: 어떤 성과를 냈나

NCS 역량과 경험 매핑:
- 팀 프로젝트 → 대인관계능력 (팀워크·갈등 관리)
- 아르바이트·인턴 → 직업윤리 (책임감·성실성)
- 자격증·공부 → 자기개발능력 (목표 달성)

## 면접 전형 준비

공기업 면접은 크게 4가지로 구성됩니다.

### PT 면접

주제를 받아 5~10분 발표 후 질의응답.

준비 전략:
- 두berlingo 구조: 현황 → 문제점 → 원인 → 해결책 → 기대 효과
- 기관별 주요 사업 이슈 미리 숙지
- 1~2분 내 핵심 전달 훈련

### 토론 면접

주제에 대해 지원자들이 토론. 개인보다 그룹 다이나믹스 평가.

핵심 전략:
- 발언 점유율 균등하게 (너무 많거나 적으면 감점)
- 상대 의견을 경청하고 반영하는 모습
- 결론 내리기 역할 맡으면 인상적

### 경험 면접 (구조화 면접)

"~한 경험을 말해주세요" 형태.

준비 전략:
- 역량별 에피소드 3~5개 미리 준비
- STAR 기법으로 구체적으로 서술
- 과장 없이 실제 본인의 역할 강조

### 상황 면접

"~한 상황이라면 어떻게 하겠습니까" 형태.

핵심: 공기업 직원으로서 취해야 할 행동 선택 — 규정 준수 + 고객 서비스 + 조직 이익 균형

## 공기업 취업 타임라인

### 일반적 준비 기간

**6개월 이내 취업 목표**: 현실적으로 어렵습니다. 필기 준비만으로 4~6개월 소요.

**1년 준비**:
- 상반기: NCS 필기 집중 + 자소서 기본 준비
- 하반기: 지원 기관 선정 + 직무 전공 + 면접 준비

**1.5~2년 준비** (비전공자 또는 경쟁력 강화):
- 자격증 취득 (기사 자격, 컴퓨터 활용능력 등)
- 인턴 경험 확보
- 관련 학습 이력 쌓기

## 합격률 높이는 포인트

**기관 집중 전략**:
여러 기관에 광범위하게 지원하는 것보다 2~3개 기관에 집중하면 합격 가능성이 높아집니다.

**지역 인재 활용**:
지역 인재는 일부 기관에서 30% 가산 또는 별도 선발. 해당 지역 출신이면 반드시 확인.

**채용형 인턴 활용**:
채용형 인턴 → 정규직 전환 비율이 높음. 정규직 직접 응시보다 진입 장벽이 낮음.

**NCS 기출 반복**:
가장 효과적인 필기 준비법. 한국산업인력공단 공식 예제 + 기관별 기출 활용.
