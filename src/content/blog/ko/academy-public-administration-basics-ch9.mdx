## 행정 환경 변화

```
인구 변화:
저출생: 합계출산율 급감 (한국 0.7대)
고령화: 65세 이상 비율 증가
→ 인구 감소 → 경제·복지 재정 압박

4차 산업혁명:
AI·빅데이터·IoT·블록체인
행정 서비스 자동화, 예측 행정
공공 데이터 활용 증가

글로벌화:
국제 환경 변화가 국내 행정에 즉각 영향
이민·난민 문제, 국제 규범 준수

기후변화:
환경 행정 수요 증가
탄소중립 정책, 에너지 전환
재난·안전 행정 강화
```

## 복지행정

```
복지국가:
사회적 위험(질병·실업·노령·빈곤)을 국가가 보장
복지 패러다임 변화

잔여적 복지 (미국식):
시장·가족이 우선, 국가는 최후 수단
선별적 급여 (빈곤층만)

보편적 복지 (북유럽식):
모든 시민에게 기본 서비스 보장
세금으로 재원 충당

한국 복지 발전:
4대 사회보험 (국민연금·건강·고용·산재)
기초연금, 국민기초생활보장
돌봄 서비스 확대

복지 재정 압박:
고령화→복지 지출 급증
저성장→세수 감소
복지 지속가능성 논란
```

## 규제 행정

```
규제:
정부가 민간 활동을 제한·유도하는 공식 규칙

경제 규제:
시장 실패 교정 (독과점, 외부효과, 정보 비대칭)
가격·진입 규제

사회 규제:
안전·환경·보건·소비자 보호
기술 기준, 환경 기준

규제 개혁:
불필요한 규제 완화 (기업 활동 자유)
규제 일몰제: 유효기간 설정, 자동 폐지
규제 영향 분석: 규제 도입 전 비용편익 분석

포지티브 vs 네거티브 규제:
포지티브: 허용 목록만 허용 (한국 전통)
네거티브: 금지 목록 외 모두 허용 (혁신 친화)
```

## 재난·안전 행정

```
재난 유형:
자연재난: 홍수·지진·태풍
사회재난: 화재·교통사고·전염병

재난 관리 단계:
완화 (Mitigation): 재난 발생 예방·저감
대비 (Preparedness): 대응 계획 수립
대응 (Response): 재난 발생 후 즉각 대응
복구 (Recovery): 피해 회복·지원

한국 재난 관리:
행정안전부, 소방청, 해양경찰청
국가위기관리 기본지침

위기 소통:
신속·정확한 정보 공개
가짜뉴스 대응, 언론 협력
```

## 핵심 개념 카드

**저출생·고령화 행정 과제** ★★★★★
: 복지 재정 압박, 인력 감소, 지방소멸 위기.
*암기 포인트: 저출생=재정+인력+소멸*

**잔여적 vs 보편적 복지** ★★★★★
: 잔여=선별(빈곤층). 보편=모든 시민. 한국=혼합.
*암기 포인트: 잔여=선별, 보편=모두*

**재난관리 4단계** ★★★★☆
: 완화→대비→대응→복구.
*암기 포인트: 완대대복*

## 실전 퀴즈

**Q. 포지티브 규제와 네거티브 규제의 차이가 혁신에 미치는 영향은?**
> 포지티브: 허용 목록에 없으면 불가 → 새로운 기술·서비스 규제 공백 시 불허. 혁신 저해. 네거티브: 금지 목록 외 모두 허용 → 신기술을 우선 허용 후 문제 시 규제. 혁신 친화적. 핀테크·자율주행 등 신산업에 네거티브 방식 적용 추세.

**Q. 저출생이 행정에 미치는 영향은?**
> 생산 가능 인구 감소→세수 감소. 노인 인구 증가→복지 지출 증가. 지방 인구 감소→지방자치단체 재정 악화·소멸 위기. 교육·주거·일자리 행정 수요 변화. 외국인 인력 정책 확대 필요성.
