별자리 운세를 읽을 때 우리는 보통 "태양 별자리"—즉 생년월일에 해당하는 별자리—만 봅니다. 그러나 완전한 점성술 분석은 출생 시간과 장소를 기반으로 한 **출생 차트(Natal Chart)**를 통해 이루어집니다. 이 가이드에서는 출생 차트를 읽고 해석하는 방법을 안내합니다.

## 출생 차트란

출생 차트는 당신이 태어난 정확한 순간, 당신이 태어난 장소에서 바라본 하늘의 스냅샷입니다. 이 차트는 원형으로 구성되며 세 가지 핵심 요소로 이루어집니다:

1. **행성(Planets)**: 태양, 달, 수성, 금성, 화성, 목성, 토성, 천왕성, 해왕성, 명왕성
2. **별자리(Signs)**: 12가지 황도대 별자리
3. **하우스(Houses)**: 12개 삶의 영역

**출생 차트 만들기**: 무료 사이트 추천 — Astro.com, AstroSage, Café Astrology

<Callout type="info">
**정확한 출생 시간이 중요**: 출생 차트 계산에는 정확한 출생 시간이 필요합니다. 출생 시간이 1시간만 달라져도 상승 별자리(어센던트)와 하우스 배치가 크게 바뀝니다.
</Callout>

## 3대 핵심 별자리

### 태양 별자리 (Sun Sign) — 의식적 자아

생년월일로 결정되는 가장 익숙한 별자리. **당신이 누구인가**, **의식적 자아 정체성**을 나타냅니다.

"나는 어떤 사람인가?"에 답합니다.

### 달 별자리 (Moon Sign) — 무의식적 자아

달이 위치한 별자리. 약 2.5일에 한 번 이동합니다. **감정, 본능, 무의식적 반응, 내면의 욕구**를 나타냅니다.

"나는 무엇을 느끼는가? 나는 무엇이 필요한가?"에 답합니다.

| 달 별자리 | 감정 스타일 | 필요한 것 |
|---------|----------|---------|
| 양자리 | 즉각적, 직접적 | 독립성, 자율성 |
| 황소자리 | 안정적, 감각적 | 안전, 편안함 |
| 쌍둥이자리 | 지적, 변동적 | 소통, 다양성 |
| 게자리 | 깊은 감성, 모성적 | 연결, 보살핌 |
| 사자자리 | 드라마틱, 창의적 | 인정, 자기 표현 |
| 처녀자리 | 분석적, 실용적 | 질서, 유용함 |
| 천칭자리 | 조화적, 우아한 | 균형, 파트너십 |
| 전갈자리 | 깊은 감정, 강렬한 | 깊이, 변환 |
| 사수자리 | 낙관적, 철학적 | 자유, 의미 |
| 염소자리 | 절제된, 책임감 | 성취, 안정 |
| 물병자리 | 독립적, 혁신적 | 자유, 독창성 |
| 물고기자리 | 민감한, 영적 | 연결, 평화 |

### 어센던트/상승 별자리 (Ascendant/Rising) — 외적 자아

태어날 때 동쪽 지평선에 떠오르던 별자리. **다른 사람들이 처음에 보는 당신**, **외적 행동 스타일**을 나타냅니다.

"나는 어떻게 보이는가? 어떻게 접근하는가?"에 답합니다.

## 12하우스 시스템

하우스는 12개의 삶의 영역을 나타냅니다. 어떤 별자리나 행성이 어떤 하우스에 있는지가 삶의 구체적 영역에 영향을 미칩니다.

| 하우스 | 영역 | 키워드 |
|--------|------|--------|
| 1하우스 | 자아, 외모 | 정체성, 첫인상 |
| 2하우스 | 재물, 가치 | 자원, 소유 |
| 3하우스 | 소통, 근거리 이동 | 형제자매, 학습 |
| 4하우스 | 가정, 뿌리 | 가족, 기원 |
| 5하우스 | 창의, 연애 | 즐거움, 자녀 |
| 6하우스 | 건강, 일상 | 서비스, 루틴 |
| 7하우스 | 파트너십 | 결혼, 사업 파트너 |
| 8하우스 | 변환, 죽음 | 공동 자원, 심층 심리 |
| 9하우스 | 철학, 장거리 | 교육, 여행, 신념 |
| 10하우스 | 커리어, 사회적 지위 | 목표, 명성 |
| 11하우스 | 친구, 꿈 | 공동체, 희망 |
| 12하우스 | 무의식, 영성 | 숨겨진 것, 카르마 |

## 차트 읽기 예시

**예**: 태양 = 전갈자리 (8하우스), 달 = 황소자리 (2하우스), 어센던트 = 사자자리

**해석**:
- 태양/전갈자리/8하우스: 깊은 변환과 심층 심리에 관심. 강렬하고 비밀스러운 자아 표현. 공유 자원과 삶/죽음의 테마가 정체성과 연결.
- 달/황소자리/2하우스: 안정과 물질적 안전이 감정적 필요. 땅에 발을 딛은 감각이 정서적 안정 제공.
- 어센던트/사자자리: 당당하고 창의적인 첫인상. 자기 표현에 자신감 있어 보임.
