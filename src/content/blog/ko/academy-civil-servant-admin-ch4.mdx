## 행정 가치와 목표

```
행정의 기본 가치 체계:

본질적 가치:
→ 공익 (Public Interest): 행정의 최종 목표
→ 사회적 형평성: 공정한 자원 배분
→ 정의 (Justice): 절차·실질 정의

수단적 가치:
→ 합법성: 법률에 근거한 행정
→ 능률성 (Efficiency): 최소 비용으로 최대 산출
→ 효과성 (Effectiveness): 목표 달성 정도
→ 민주성: 국민 참여와 통제
→ 책임성: 결과에 대한 책임

행정 이념의 변천:
→ 1930년대 이전: 능률성·합법성 강조
→ 1950~60년대: 민주성·사회적 형평성 부각
→ 1970년대: 효과성·형평성 강조 (신행정론)
→ 1980년대~: 경제성·고객 만족 (신공공관리)
→ 2000년대~: 협치(Governance)·공공가치

가치 충돌:
→ 능률 vs 민주: 효율을 위해 참여 축소 vs 참여로 속도 느림
→ 형평 vs 능률: 약자 배려 비용 vs 최적 배분
→ 합법성 vs 효과성: 규칙 준수 vs 목표 달성
```

## 행정 환경 이론

```
공공선택론 (Public Choice Theory):
→ 뷰캐넌(Buchanan) 등 창시
→ 경제학적 방법으로 정치·행정 분석
→ 관료도 자기 이익 극대화 행동
→ 정부 실패 원인: 예산 극대화 편향
→ 처방: 시장 메커니즘 도입, 민영화, 경쟁

신공공관리론 (New Public Management, NPM):
→ 1980년대 영국·뉴질랜드 등 행정 개혁
→ 특징:
  ① 성과 중심 관리
  ② 시장 원리 도입 (민영화·민간 위탁)
  ③ 고객주의 (국민을 고객으로)
  ④ 분권화·권한 이양
→ 비판: 행정의 공공성·형평성 약화

뉴거버넌스 (New Governance):
→ 정부·민간·시민사회의 협력적 네트워크 통치
→ 시장·네트워크 활용
→ 참여와 협력 강조

신공공서비스론 (New Public Service):
→ 덴하트(Denhardt) 등 제창
→ 시민을 고객이 아닌 '주인'으로
→ 공공 가치 우선, 민주주의·시민권 강조
→ NPM 비판에 대한 대안

포스트모더니즘 행정:
→ 보편적 진리·거대 서사 거부
→ 다양성·분권·참여 강조
→ 담론적 설계·다원주의
```

## 동기이론

```
내용 이론 (What motivates):

매슬로우 욕구계층론 (Maslow):
→ 5단계: 생리→안전→소속→존경→자아실현
→ 하위 욕구 충족 후 상위 욕구 동기화
→ 비판: 단계 고정성·문화적 보편성 의문

앨더퍼 ERG 이론:
→ 존재(Existence)·관계(Relatedness)·성장(Growth)
→ 좌절-퇴행: 상위 욕구 좌절 → 하위 욕구 강화
→ 동시적 욕구 인정 (매슬로우 보완)

허즈버그 2요인 이론 (Herzberg):
→ 위생요인: 불만족 제거 (급여·감독·작업 조건)
→ 동기요인: 만족 유발 (성취·인정·책임·성장)
→ 위생요인 충족 → 불만족 해소 (동기 부여 아님)
→ 동기요인 강화 → 직무 만족·동기 부여

맥클리랜드 (McClelland):
→ 성취 욕구·권력 욕구·친화 욕구
→ 성취 욕구 높은 사람: 도전적 과제 선호

과정 이론 (How motivation works):

브룸 기대 이론 (Vroom's Expectancy Theory):
→ 동기 = 기대 × 수단성 × 유인가
→ 기대: 노력 → 성과 가능성
→ 수단성: 성과 → 보상 가능성
→ 유인가: 보상에 대한 개인적 가치

아담스 공정성 이론 (Adams' Equity Theory):
→ 자신의 투입/산출 비율을 타인과 비교
→ 불공정 지각 → 긴장 → 균형 회복 행동
```

## 리더십 이론

```
특성 이론 (Trait Theory):
→ 리더는 태어나는 것 (성격·지능·체력 등)
→ 비판: 보편적 특성 목록 없음

행동 이론 (Behavioral Theory):
→ 아이오와 연구: 민주적·권위적·자유방임
→ 오하이오 연구: 구조 주도 + 배려 (2차원)
→ 관리격자 (Blake & Mouton): 인간·생산 관심 2축
  (9,9): 팀형 리더십 최적

상황 이론 (Contingency Theory):

피들러 (Fiedler):
→ LPC 척도: 과업 지향·관계 지향 측정
→ 상황 유리성: 리더-부하 관계·과업 구조·지위 권력
→ 매우 유리/불리 → 과업 지향 우수
→ 중간 유리 → 관계 지향 우수

허시·블랜차드 상황 이론:
→ 부하의 성숙도(능력+의지)에 따라 리더 스타일 변화
→ 지시형(S1) → 설득형(S2) → 참여형(S3) → 위임형(S4)

변혁적 리더십 (Transformational Leadership):
→ 부하의 가치관·동기·태도 변환
→ 4I: 이상적 영향·영감적 동기·지적 자극·개별적 고려
→ 거래적 리더십(보상·교환)과 대비

서번트 리더십 (Servant Leadership):
→ 구성원 섬김이 우선
→ 리더의 자아보다 구성원 성장·자율 중시
```

## 조직 구조 유형

```
공식 조직 구조:

계층제 (Hierarchy):
→ 명령 계통의 위계 구조
→ 장점: 명확한 권한·책임, 통일성
→ 단점: 경직성, 하향식 소통 왜곡

라인-스태프 (Line and Staff):
→ 라인: 직접 업무 수행
→ 스태프: 지원·자문·분석 기능
→ 대규모 조직의 표준 형태

위원회 조직:
→ 합의제 의사결정
→ 장점: 다양한 시각, 민주적
→ 단점: 책임 분산, 느린 결정

프로젝트팀 (Task Force):
→ 특정 과제 해결을 위해 임시 구성
→ 전문가 집합 → 해산

매트릭스 조직:
→ 기능 조직 + 프로젝트 조직 동시 존재
→ 구성원이 두 명의 상관 (기능·프로젝트)
→ 장점: 유연성·전문성 활용
→ 단점: 이중 명령 혼란, 갈등

애드호크라시 (Adhocracy):
→ 탈관료제, 유기적 구조
→ 급변 환경 적응, 혁신 조직
→ 사업부제·네트워크 조직 포함

조직 규모와 구조:
→ 민츠버그 5가지 조직 유형:
  단순 구조 / 기계 관료제 / 전문 관료제 / 사업부제 / 애드호크라시
```

## 자주 묻는 질문

**Q. 신공공관리론과 뉴거버넌스의 차이점은 무엇인가요?**
A. 신공공관리론(NPM)은 정부 내부의 효율성을 시장 원리로 개혁하는 것에 초점을 둡니다. 성과 측정, 경쟁, 민영화, 고객주의가 핵심입니다. 반면 뉴거버넌스는 정부 혼자가 아니라 민간·시민사회·NGO와 네트워크를 이루어 협력적으로 공공 문제를 해결하는 것에 초점을 둡니다. NPM이 정부 내 효율화라면 뉴거버넌스는 정부 외부와의 협치라는 점이 핵심 차이입니다.

**Q. 매슬로우 욕구계층론이 비판받는 이유는 무엇인가요?**
A. 주요 비판은 세 가지입니다. 첫째, 하위 욕구를 완전히 충족해야 상위 욕구가 생긴다는 단계 고정성이 현실과 맞지 않습니다(굶주리면서도 자아실현을 추구하는 예술가). 둘째, 5단계 분류와 위계 순서의 경험적 검증이 어렵습니다. 셋째, 개인주의 문화를 전제로 해서 집단주의 문화에서는 소속감 욕구가 더 기본적일 수 있습니다. 이를 보완한 이론이 앨더퍼의 ERG 이론입니다.
