# 원가회계 — 주문이 다르면 평균 단가로는 입찰할 수 없다

[2장](/ko/academy-cost-accounting-ch2/)의 3요소가 작업마다 다르면 개별원가계산이다. 같은 제품을 공정에서 흘리면 [4장](/ko/academy-cost-accounting-ch4/)이다. 어느 시스템을 고를지는 [10장](/ko/education-accounting-ch12/), 보조부문 상호배부는 [9장](/ko/education-accounting-ch11/)이다.

## 1. 작업원가표는 추적이 되는 것만 직접 붙인다

건설·인쇄·특수 장비처럼 주문마다 사양이 다르면 작업지시서별로 직접재료와 직접노무를 모은다. 출고 전표와 작업시간표가 추적의 증거다. 공장 전기·감가상각·감독자 급여는 여러 작업이 같이 쓰므로 배부한다.

## 2. 정상원가계산은 간접비만 예정으로 붙인다

직접재료·직접노무는 실제, 제조간접은 예정배부율이다. 예정 제조간접 6,000만 원, 예정 기계시간 10,000시간이면 배부율은 시간당 6,000원. 작업 A가 기계 80시간을 쓰면 배부액은 48만 원이다.

<Callout type="warning">
기계시간이 원가 발생과 무관한데 기계시간으로 나누면, 단순한 대량 작업이 복잡한 소량 작업을 보조한다. 과소배부·과대배부는 기말에 매출원가 또는 재공품·제품·매출원가에 조정한다. 배부 오차를 작업 원가의 ‘실제’로 읽지 않는다.
</Callout>

## 확인문제

예정 제조간접 6,000만 원, 예정 시간 10,000시간, 실제 시간 9,500시간, 실제 제조간접 5,890만 원이다. 배부액은 5,700만 원, 과소배부는 190만 원이다. 실제 총액 5,890만 원을 작업 원가의 합으로 바꾸지 않는다.
