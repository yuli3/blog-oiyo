## 과목별 중요도와 특성

### 1차

**부동산학개론**
- 난이도: ★★★☆☆
- 암기량: 중간
- 특징: 이론 위주. 부동산 기초 시리즈 Ch1~Ch3 직결.
- 핵심: 감정평가 3방식, 토지 특성, 수익률 계산

**민법 및 민사특별법**
- 난이도: ★★★★☆
- 암기량: 매우 많음
- 특징: 법률 과목. 판례 암기 필수. 가장 어려운 과목.
- 핵심: 물권·채권 구분, 주택임대차보호법, 집합건물법

### 2차

**공인중개사법·중개실무**
- 난이도: ★★★☆☆
- 암기량: 중간
- 특징: 법령 위주. 실무 문제 병행.
- 핵심: 중개보수 요율, 결격 사유, 확인·설명 의무

**부동산공법**
- 난이도: ★★★★☆
- 암기량: 많음
- 특징: 국토계획법·건축법·주택법·농지법 범위 넓음.
- 핵심: 용도지역 건폐율·용적률, 개발행위허가

**부동산공시법 및 부동산세법**
- 난이도: ★★★☆☆
- 암기량: 중간~많음
- 특징: 공시법(등기·지적)과 세법 혼합.
- 핵심: 등기 제도, 취득세·재산세·종부세·양도세 세율

## 학습 전략 및 권장 순서

```
권장 학습 순서 (6개월 기준):

월 1~2: 부동산학개론 → 이론 기초 확립
         부동산기초 시리즈 Ch1~Ch5 활용

월 2~4: 민법 → 가장 시간 많이 투자
         물권법→채권법→특별법 순서

월 4~5: 공인중개사법 + 부동산공법 병행
         법령 암기표 활용

월 5~6: 공시법·세법 + 전 과목 모의고사
         기출 10개년 최소 3회 반복
```

## 빈출 핵심 공식 모음

```
건폐율 = 건축면적 / 대지면적 × 100%
용적률 = 연면적 / 대지면적 × 100%

임대수익률 = 연임대료 / 매입가격 × 100%
수익가액 = NOI / 환원율

LTV = 대출금 / 담보가치 × 100%
DSR = 모든 부채 원리금 / 연소득 × 100%

대항력: 전입신고 + 점유 → 다음날 0시
확정일자: 우선변제권 취득
```

## 합격률과 현실적 목표

```
최근 5개년 합격률:
1차: 약 30~40%
2차: 약 20~30%
1·2차 동시: 약 15~25%
```

**현실적 조언**:
- 1차·2차 동시 합격보다 1차 먼저 합격 전략도 유효
- 민법에 최소 전체 학습 시간의 40% 투자
- 공법은 범위가 넓어 포기 과목 만들지 않는 것이 핵심
