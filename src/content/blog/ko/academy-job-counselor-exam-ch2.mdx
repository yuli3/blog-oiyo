## 직업심리학의 이해

```
직업심리학(Vocational Psychology)의 정의:
→ 직업 선택, 직업 발달, 직업 적응을 심리학적으로 연구
→ 진로 상담의 이론적 기반

주요 이론 분류:

특성-요인 이론 (개인-환경 매칭):
→ 파슨스(Parsons): 개인 특성 + 직업 요건 매칭
→ 홀랜드(Holland): 성격 유형-직업 환경 일치

발달 이론:
→ 수퍼(Super): 생애 발달 단계
→ 고틀프레드슨(Gottfredson): 타협과 제한

사회인지 이론:
→ 크롬볼츠(Krumboltz): 사회학습
→ 렌트(Lent): 사회인지 진로이론 (SCCT)

구성주의/내러티브:
→ 사비카스(Savickas): 진로 구성 이론
```

## 홀랜드의 직업 유형론

```
홀랜드(Holland) 이론의 핵심:
→ 사람의 성격 유형과 직업 환경 유형을 6가지로 분류
→ 성격-환경 일치도 높을수록 만족도·성취 높음

RIASEC 6가지 유형:

R (Realistic, 실재형):
→ 특성: 솔직, 성실, 물질 중시, 사교성 부족
→ 직업: 기계공, 전기기사, 농업, 군인

I (Investigative, 탐구형):
→ 특성: 분석적, 지적 호기심, 과제 지향
→ 직업: 연구원, 의사, 수학자, 과학자

A (Artistic, 예술형):
→ 특성: 창의적, 감성적, 독창성, 비순응적
→ 직업: 예술가, 음악가, 작가, 배우

S (Social, 사회형):
→ 특성: 봉사 지향, 대인 관계 능력, 친절
→ 직업: 교사, 사회복지사, 상담사, 간호사

E (Enterprising, 기업형):
→ 특성: 리더십, 설득력, 경쟁적, 모험적
→ 직업: CEO, 영업, 정치인, 변호사

C (Conventional, 관습형):
→ 특성: 꼼꼼, 체계적, 규칙 준수, 안정 선호
→ 직업: 회계사, 사무원, 은행원, 비서

홀랜드 6각형 모델:
→ 인접 유형: 유사성 높음 (R-I-A-S-E-C 순서)
→ 대각선 유형: 유사성 낮음 (R vs S, I vs E, A vs C)

핵심 개념:
→ 일관성: 3자리 코드의 인접성
→ 분화성: 특정 유형 뚜렷 vs 여러 유형 혼재
→ 일치성: 성격 유형과 직업 환경의 일치 정도
→ 정체성: 자아 및 직업 정체성의 명확성
```

## 수퍼의 진로발달 이론

```
수퍼(Super)의 핵심 개념:
→ 진로는 평생에 걸친 발달 과정
→ 자아개념 (Self-Concept): 직업 발달의 핵심
→ 역할 현저성: 삶에서 다양한 역할 중요도

생애 무지개 (Life-Career Rainbow):
→ 삶의 공간: 아동, 학생, 여가인, 시민, 근로자, 가정인
→ 삶의 시간: 5단계 발달 단계

5단계 진로 발달:

1. 성장기 (Growth, 0~14세):
→ 가정·학교에서 주요 인물 동일시
→ 능력, 태도, 흥미, 자아개념 발달
→ 하위 단계: 환상기→흥미기→능력기

2. 탐색기 (Exploration, 14~24세):
→ 직업 탐색, 잠정적 선택
→ 하위 단계: 잠정기→전환기→시행기

3. 확립기 (Establishment, 24~44세):
→ 직업 세계 정착, 경력 발전
→ 하위 단계: 시행기→안정기

4. 유지기 (Maintenance, 44~64세):
→ 기존 직업적 지위 유지
→ 혁신 vs 현상 유지

5. 쇠퇴기 (Decline, 64세~):
→ 은퇴 준비, 활동 감소
→ 하위 단계: 감속기→은퇴기

아치형 모델:
→ 진로 발달의 생물-심리-사회적 요인 도식화
```

## 크롬볼츠의 사회학습 이론

```
크롬볼츠(Krumboltz) 이론:
→ 직업 선택은 학습의 결과
→ 우연적 사건도 진로에 중요한 역할

직업 선택에 영향하는 4요인:
1. 유전적 자질 (타고난 능력, 외모 등)
2. 환경적 조건 (노동 시장, 사회 변화)
3. 학습 경험:
   → 도구적 학습: 강화·처벌을 통한 학습
   → 연합적 학습: 관찰·경험을 통한 학습
4. 과제 접근 기술 (문제 해결 방식, 감정 반응)

계획된 우연 (Planned Happenstance):
→ 예기치 못한 사건을 기회로 활용
→ 개방성, 호기심, 낙관성, 인내, 유연성 중요
→ 진로 불확실성을 부정이 아닌 기회로 인식

적용:
→ 다양한 경험 탐색 권장
→ 불안 감소: 정해진 진로보다 과정 중시
→ 우연 활용 능력 계발
```

## 인지적 정보처리 이론 (CIP)

```
Peterson, Sampson, Reardon의 CIP 이론:

핵심 개념:
→ 진로 선택은 정보 처리 과정
→ 인지적 능력 + 메타인지가 진로 발달 핵심

피라미드 모델:

하위: 지식 영역
→ 자기 지식 (Self-Knowledge): 흥미, 능력, 가치
→ 직업 지식 (Occupational Knowledge): 직업 세계

중위: 의사결정 기술 영역
→ CASVE 주기:
  C (Communication): 문제 인식
  A (Analysis): 원인 분석
  S (Synthesis): 대안 탐색·선택
  V (Valuing): 가치 평가·선택
  E (Execution): 실행

상위: 메타인지 영역
→ 자기 대화 (Self-Talk): 부정적 인지 인식
→ 자기 인식 (Self-Awareness)
→ 모니터링과 통제

역기능적 사고:
→ 자신, 타인, 미래에 대한 부정적 자동 사고
→ 예: "나는 좋은 직업을 가질 수 없어"
→ 상담에서 인지 재구성 (cognitive restructuring) 활용
```

## 자주 묻는 질문

**Q. 직업상담사 2급 시험에서 이론 문제는 어느 정도 비중인가요?**
A. 직업상담학(직업심리학) 과목에서 이론은 매우 높은 비중을 차지합니다. 홀랜드, 수퍼, 크롬볼츠, CIP 등 각 이론의 핵심 개념, 발달 단계, 주요 학자 이름은 반드시 암기해야 합니다. 단순 암기보다 이론 간 비교(발달이론 vs 특성-요인이론 등)를 이해하면 응용 문제에도 대응할 수 있습니다.

**Q. 홀랜드 이론과 특성-요인 이론의 차이는 무엇인가요?**
A. 특성-요인 이론(파슨스)은 자신을 알고, 직업을 알고, 둘을 매칭하라는 3단계 모델로 진로 결정의 합리적 과정을 강조합니다. 홀랜드 이론은 여기서 발전해 성격 유형을 6가지(RIASEC)로 체계화하고, 성격과 직업 환경의 일치성을 강조합니다. 홀랜드는 MBTI, 직업 흥미 검사 등 실용적 도구와 연결되어 더 구체적으로 적용됩니다.
