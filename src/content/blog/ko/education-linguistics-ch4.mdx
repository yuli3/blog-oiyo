## 사회언어학의 기초

```
사회언어학 (Sociolinguistics):
→ 언어와 사회의 관계 연구
→ 누가·언제·어디서·왜 특정 언어 형태를 사용하는가

언어 변이 (Linguistic Variation):
→ 방언 (Dialect): 지역·사회 집단에 따른 언어 변이형
→ 레지스터 (Register): 상황·맥락에 따른 문체 변이
  격식체·비격식체·전문어·은어
→ 이디올렉트 (Idiolect): 개인의 고유한 언어 습관

라보브의 사회방언학:
→ 변항 (Variable): 여러 형태로 실현되는 언어 단위
→ 사회적 변항: 사회 계층·연령·성별·민족에 따른 분포
→ 뉴욕 백화점 연구 (1966): 사회 계층에 따른 /r/ 발음 차이
  고급 백화점 직원이 저급 직화점보다 r 발음 더 많이 함

언어와 계층:
→ 번스타인 (Bernstein): 정교 코드 vs 제한 코드
  중간계층: 정교 코드 (명시적·탈맥락적)
  노동계층: 제한 코드 (암묵적·맥락 의존적)
→ 비판: 언어적 결핍론 (Deficit Theory)이 아닌 차이론 (Difference Theory) 강조

언어와 성별 (Language and Gender):
→ 레이코프 (Lakoff): 여성 언어의 특징 (불확실성·공손성)
→ 탠넨 (Tannen): 문화적 차이 (친밀성 대화 vs 지위 대화)
→ 젠더 수행성 (Butler): 언어 사용이 젠더를 수행·구성
→ 성 중립 언어 운동: 직함·대명사 변화
```

## 방언과 표준어

```
방언 (Dialect):
→ 동일 언어의 지역적·사회적 변이형
→ 지역 방언 (Regional Dialect): 지리적 거리에 따른 변이
→ 사회 방언 (Social Dialect, Sociolect): 사회 집단에 따른 변이

방언의 연속체:
→ 방언 연속체 (Dialect Continuum): 인접 방언들 사이 점진적 변화
→ 네덜란드어-독일어 연속체: 언어 경계 자의적
→ 언어 vs 방언 구분의 정치성:
  "언어는 군대를 가진 방언이다" (막스 바인라이히)

한국어 방언:
→ 중부(서울)·서남(전라)·동남(경상)·서북(평안)·동북(함경)·제주 방언
→ 경상 방언: 성조 (높낮이 차이) 유지
→ 제주 방언: 독자적 특징·유네스코 소멸 위기 언어 분류

표준어:
→ 한 언어의 규범적 형태: 공식 상황·교육·방송에 사용
→ 사회적 위신을 가지나 언어학적으로 우월하지 않음
→ 한국 표준어 규정: "교양 있는 사람들이 두루 쓰는 현대 서울말"
→ 표준어와 방언의 관계: 권력·정치의 산물

이상적인 언어 태도:
→ 모든 방언은 체계적이고 규칙적인 언어 형태
→ 방언 차별 (Linguistic Profiling) 극복
→ 방언 보존 가치: 지역 문화 정체성·다양성
```

## 이중언어와 코드 스위칭

```
이중언어 (Bilingualism):
→ 두 가지 이상 언어를 사용하는 개인 또는 사회
→ 유형:
  동시 이중언어 (Simultaneous): 두 언어 동시 습득 (0~3세)
  순차 이중언어 (Sequential): 모국어 습득 후 제2언어

사회적 이중언어:
→ 이중언어 사회: 두 언어가 공식적으로 사용 (캐나다·벨기에·싱가포르)
→ 다언어 사회: 세 가지 이상 (인도·스위스·파푸아뉴기니)

다이글로시아 (Diglossia):
→ 퍼거슨 (Ferguson): 한 사회에서 두 언어 변이형이 다른 기능 수행
→ 고급 변이형 (H, High): 공식·교육·종교 (아랍어 고전)
→ 저급 변이형 (L, Low): 가정·비격식 (아랍어 방언)
→ 확장된 다이글로시아 (Fishman): 방언 + 표준어 구분

코드 스위칭 (Code Switching):
→ 이중언어 화자가 대화 중 두 언어를 교대로 사용
→ 유형:
  문장 간 전환 (Inter-sentential): 문장 경계에서
  문장 내 전환 (Intra-sentential): 문장 내부에서
  단어 삽입 (Tag Switching): 감탄사·태그만 교체

코드 스위칭의 기능:
→ 특정 주제가 한 언어에 더 적합할 때
→ 집단 정체성 표현·연대감
→ 화제 전환·강조·인용
→ 언어 능력 부족 보완 (아닌 경우도 많음)

영어와 한국어 혼용:
→ "나 오늘 meeting이 있어서..."
→ 코드 스위칭 vs 외래어 차용
→ 한국어 정체성 보존 vs 영어 영향력
```

## 언어 태도와 편견

```
언어 태도 (Language Attitudes):
→ 특정 언어·방언·언어 변이형에 대한 평가·감정
→ 직접적 방법: 설문·인터뷰
→ 간접적 방법: 위장 기법 (Matched Guise Technique)

위장 기법 실험:
→ 동일인이 두 언어/방언으로 말한 녹음을 평가자에게 들려줌
→ 다른 사람이라고 생각하고 평가
→ 사회적 편견이 언어 평가에 미치는 영향 측정

표준어 이념 (Standard Language Ideology):
→ 표준어가 가장 정확하고 아름다운 언어라는 믿음
→ 방언 화자를 교육 없거나 지능이 낮다고 판단하는 편견 야기
→ 언어학적으로 근거 없음: 모든 언어 변이형은 규칙 있음

언어 차별 (Linguistic Discrimination):
→ 언어·방언·억양에 따른 고용·교육 차별
→ 영어 억양 차별: 비원어민 영어 화자 차별
→ 한국 사회: 경상도 억양에 대한 편견 연구

언어와 정체성:
→ 언어는 개인·집단 정체성의 핵심 요소
→ 이민자 언어 유지와 동화 문제
→ 재외 동포의 한국어: 계승어 (Heritage Language)
→ 언어 충성도 (Language Loyalty): 모국어 보존 의지
```

## 언어정책과 언어 계획

```
언어정책 (Language Policy):
→ 정부·기관이 언어 사용을 관리하는 결정·법률·규정
→ 공식 언어 지정·교육 언어·소수어 권리

언어 계획 (Language Planning):
→ 코러스·하우겐: 체계적 언어 변화 노력
→ 지위 계획: 사회에서 언어의 기능·역할 결정
  공식 언어 지정·교육 정책
→ 코퍼스 계획: 언어 자체 표준화·현대화
  맞춤법·어휘·문자 체계 개발
→ 습득 계획: 언어 학습 촉진

언어 부흥 (Language Revitalization):
→ 소멸 위기 언어를 살리려는 노력
→ 히브리어: 현대 국가 언어로 부활 (성공 사례)
→ 웨일스어·아일랜드어: 교육 언어 지정
→ 제주어: 유네스코 소멸 위기·보존 노력

공식 언어 정책 유형:
→ 단일 언어 정책: 한 가지 공식 언어 (한국·프랑스)
→ 이중·다중 언어 정책: 캐나다(영·불)·스위스(독·불·이·로)
→ 영토 원칙: 지역에 따른 언어 (벨기에)
→ 인물 원칙: 개인에 따른 언어권 (핀란드)

한국어 정책:
→ 국어기본법: 한국어 발전·보전의 법적 기반
→ 국립국어원: 표준어 규정·외래어 표기·새어 다듬기
→ 한국어 세계화: 한국어능력시험 (TOPIK)·세종학당
→ 외래어 대체: "아이디어→생각" "미팅→회의" 권장
→ 북한과의 언어 이질화: 70년 분단으로 어휘·표현 차이 증가
```

## 자주 묻는 질문

**Q. 이중언어로 자란 아이는 언어 발달이 늦어지나요?**
A. 이것은 매우 일반적인 오해입니다. 연구에 따르면 이중언어 아동은 단일 언어 아동과 같은 발달 시기표를 따릅니다. 이중언어 아동이 각 언어에서 쓸 수 있는 어휘 수는 단일 언어 아동보다 적어 보일 수 있지만, 두 언어의 어휘를 합산하면 동등하거나 더 많습니다. 이 현상을 '분산된 어휘'라고 합니다. 또한 이중언어 아동이 두 언어를 섞어 쓰는 코드 스위칭은 발달 문제의 신호가 아니라 이중언어 능력의 자연스러운 표현입니다. 오히려 이중언어 환경에서 자란 아이들은 언어 인식 능력이 높고, 전통적으로 실행 기능(억제 조절·과제 전환)에서 장점을 보인다는 연구들도 있습니다.

**Q. 표준어를 쓰는 것이 더 '올바른' 언어 사용인가요?**
A. 언어학적으로 표준어가 방언보다 더 올바르다는 근거는 없습니다. 모든 방언은 체계적인 규칙을 가진 완전한 언어 형태입니다. 경상도 방언이나 전라도 방언이 서울 표준어보다 문법적으로 열등하거나 불규칙하지 않습니다. 표준어는 역사적·정치적·사회적 이유로 특정 변이형이 공식적 지위를 얻은 것입니다. 표준어가 필요한 이유는 의사소통의 공통 기반을 제공하기 위함이지, 다른 변이형이 잘못됐기 때문이 아닙니다. 사회적으로는 표준어 화자가 더 유능하거나 교육 수준이 높다는 편견이 존재하지만, 이는 언어 차별로 극복해야 할 사회 문제입니다.
