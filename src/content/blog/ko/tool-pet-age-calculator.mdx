# 반려동물 나이 계산기

"우리 강아지 나이 10살이면 사람으로 치면 몇 살이지?" 단순히 7배를 곱하던 시대는 지났습니다. 최근 연구에 따르면 개의 노화 속도는 크기와 나이에 따라 크게 달라집니다.

## 강아지 나이 환산 (크기별)

**소형견 (10kg 미만)**

| 강아지 나이 | 사람 나이 환산 |
|---|---|
| 1년 | 약 15세 |
| 2년 | 약 24세 |
| 5년 | 약 36세 |
| 10년 | 약 56세 |
| 15년 | 약 76세 |

**대형견 (25kg 이상)** — 소형견보다 빠르게 노화

| 강아지 나이 | 사람 나이 환산 |
|---|---|
| 1년 | 약 15세 |
| 5년 | 약 40세 |
| 10년 | 약 66세 |
| 13년 | 약 96세 |

<Callout type="tip">
**UCSD 2020년 연구**: 개의 DNA 메틸화 패턴을 분석해보니, 초기 1–2년은 사람의 청소년기에 해당할 만큼 급격히 노화하고, 이후 속도가 느려집니다. "나이 × 7 = 사람 나이" 공식은 부정확합니다.
</Callout>

## 고양이 나이 환산

고양이는 품종 크기 차이가 작아 단일 기준을 사용합니다.

| 고양이 나이 | 사람 나이 환산 | 생애 단계 |
|---|---|---|
| 1년 | 약 15세 | 청소년 |
| 2년 | 약 24세 | 청년 |
| 6년 | 약 40세 | 중년 초기 |
| 10년 | 약 56세 | 중년 후기 |
| 15년 | 약 76세 | 노년 |
| 20년 | 약 96세 | 초고령 |

## 반려동물 생애 단계별 건강 관리

| 단계 | 나이 (소형견 기준) | 핵심 관리 |
|---|---|---|
| 어린이기 | 0–1년 | 백신 완성, 중성화 수술, 사회화 |
| 청년기 | 1–3년 | 정기 검진 연 1회, 치석 관리 |
| 중년기 | 4–7년 | 체중 관리, 심장·관절 체크 |
| 시니어기 | 8–11년 | 검진 연 2회, 처방식 전환 검토 |
| 노년기 | 12년+ | 통증 관리, 인지기능 저하 모니터링 |
