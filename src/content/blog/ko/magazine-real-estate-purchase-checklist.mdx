## 부동산 매매, 절차를 알면 실수가 없다

```
매매 계약 순서:
1. 물건 검토 및 시세 파악
2. 계약서 작성 + 계약금 지급
3. 중도금 지급 (있는 경우)
4. 잔금 지급 + 등기 이전
5. 취득세 신고 납부
```

---

## 계약 전 등기부 등본 확인

### 확인 방법

```
인터넷 등기소 (iros.go.kr):
→ 등기부 등본 발급 (수수료 700~1,000원)
→ 계약 당일 최신본 확인 필수 (계약 직전 재발급)
```

### 반드시 확인할 항목

```
갑구 (소유권 관련):
□ 소유자 본인 확인 (신분증과 대조)
□ 가압류, 압류 여부 → 있으면 매매 부적합
□ 가처분 신청 여부

을구 (근저당 관련):
□ 근저당 설정 금액 확인
   → 근저당 채권 최고액이 매매 금액의 일정 % 이상이면 주의
□ 전세권 설정 여부
□ 임차권 등기 여부 (세입자 있는지 확인)

→ 잔금 후 근저당이 말소되는 조건이면 계약서에 명시
```

## 매매 계약서 필수 체크 항목

```
□ 물건 주소, 면적, 구조 정확히 기재되었는가
□ 계약금·중도금·잔금 및 지급일 명확히 기재
□ 현 세입자 현황 (전세·월세 있는 경우 명시)
□ 잔금 기일까지 근저당 말소 조건
□ 특약 사항:
  - "잔금 기일까지 근저당 말소 불이행 시 계약 해지 가능"
  - 옵션 포함 여부 (에어컨, 냉장고 등)
  - 현 상태 인도 조건
□ 중개 수수료 금액 및 지급 방법
```

## 계약금 후 주의사항

```
계약 해제 시 불이익:
- 매수인(구매자) 귀책: 계약금 포기 (돌려받지 못함)
- 매도인(판매자) 귀책: 계약금 2배 반환

계약금 이체 후:
→ 매도인 명의 통장으로 이체 여부 확인
→ 부동산 명의인과 동일인 확인

계약금 이체 영수증 보관:
→ 분쟁 시 증거 자료
```

## 잔금일 전 확인 사항

```
잔금일 당일 아침:
□ 등기부 등본 재발급 (새벽 이후 변동 확인)
□ 근저당 설정이 그대로인지 확인
□ 가압류·가처분 신규 설정 여부 확인

잔금 이전에:
□ 주민등록 말소 여부 확인 (세입자 퇴거 여부)
□ 공과금 정산 (전기·가스·관리비 미납 없는지)
□ 열쇠, 주차 스티커 수령 예정 확인
```

---

## 잔금 지급 및 등기 이전

```
잔금 처리 순서:
1. 잔금 이체 (매도인 통장)
2. 열쇠 수령
3. 법무사 동석 하에 소유권 이전 서류 서명·날인
4. 법무사가 동일 날 등기 신청

등기 완료:
→ 보통 3~5 영업일 후 등기 완료 확인 가능
→ 인터넷 등기소에서 새 소유자로 변경 확인
```

## 취득세 신고 납부

```
잔금 지급일로부터 60일 이내 취득세 신고·납부:
→ 신고 지연 시 가산세 부과

취득세율:
- 1주택자, 6억원 이하: 1%
- 6억~9억원: 1~3% (구간별 계산)
- 9억원 초과: 3%
- 2주택: 8% (조정대상지역)
- 3주택 이상: 12% (중과)

신고:
→ 위택스 (wetax.go.kr) 온라인 신고
→ 또는 관할 시군구청 세무과 방문
```

## 흔히 하는 실수

```
실수 1: 잔금 직전 등기부 재확인 안 함
→ 잔금 당일 오전에 반드시 재발급 확인

실수 2: 세입자 현황 미확인
→ 매도인이 말한 것과 실제 다를 수 있음
→ 계약 전 직접 확인 필요

실수 3: 근저당 말소 조건 미기재
→ 잔금 후 근저당이 안 없어지면 법적 분쟁
→ 계약서에 명시 필수

실수 4: 공인중개사 확인 소홀
→ 공인중개사 자격증 및 사무소 등록 확인
→ 사기 피해 예방
```

## 부동산 사기 예방

```
전세사기 수법이 매매에도 적용:
→ 등기부 상 소유자가 아닌 다른 사람이 계약 시도
→ 대리인 계약 시 위임장·인감 증명서 반드시 확인

이중 계약:
→ 동일 물건 여러 명에게 계약
→ 잔금 전 등기부 재확인으로 방어

→ 의심스러우면 법무사·변호사 동석 계약 추천
```

## 자주 묻는 질문

**Q. 부동산 중개 수수료는 언제 주나요?**
A. 일반적으로 잔금일에 지급합니다. 계약서에 수수료 금액과 지급 시기를 미리 명시해두는 것이 좋습니다.

**Q. 세입자가 있는 집을 살 수 있나요?**
A. 가능합니다. 단, 임대차 계약 승계가 되므로 세입자 계약 만료일, 보증금 규모를 반드시 확인하고 협의해야 합니다.

**Q. 법무사는 누가 선택하나요?**
A. 보통 매수인(구매자)이 선택합니다. 등기 이전 비용은 매수인 부담입니다. 법무사 비용은 통상 30~80만원 수준입니다.

**Q. 잔금 당일 문제가 생기면 어떻게 하나요?**
A. 근저당 미말소, 세입자 미퇴거 등 문제 발생 시 잔금 지급을 보류하고 계약 해제 또는 조건부 연기 협의를 즉시 진행하세요.
