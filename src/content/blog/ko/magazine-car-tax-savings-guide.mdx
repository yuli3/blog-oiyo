## 자동차세란?

매년 자동차 소유자에게 부과되는 지방세입니다. 1년에 2번(6월, 12월)으로 나뉘어 부과되며, 연납을 선택하면 할인 혜택이 있습니다.

---

## 자동차세 계산 기준

### 배기량 기준 (비영업용 승용차)

```
1,000cc 이하: cc당 80원
1,600cc 이하: cc당 140원
1,600cc 초과: cc당 200원

예시:
- 2,000cc 차량: 2,000 × 200원 = 400,000원
- 1,600cc 차량: 1,600 × 140원 = 224,000원
- 1,000cc 차량: 1,000 × 80원 = 80,000원
```

### 차령에 따른 감액 (오래된 차일수록 저렴)

```
차령 3년: 세액 × 95% (5% 감액)
차령 4년: 세액 × 90% (10% 감액)
차령 5년: 세액 × 85%
차령 6년: 세액 × 80%
차령 7~9년: 세액 × 75%~60%
차령 12년 이상: 세액 × 50% (최대 감액)
```

---

## 연납 선택 시 할인

```
1월 연납 신청: 세액의 9.15% 할인 (연 10% 기준 월별 조정)
→ 2024년부터 할인율 조정됨

연납 신청 방법:
→ 1월 16일~31일 사이 신청 (가장 높은 할인)
→ 3월, 6월, 9월에도 연납 가능 (할인율 감소)

1월 연납 예시:
- 2,000cc 차량 세액 40만원
- 연납 할인 9.15% → 약 36,640원 절약
→ 연납 후 납부: 약 363,360원
```

## 자동차세 부과 시기

```
정기 부과 (2회):
- 6월 (1기): 1월~6월분, 6월 16~30일 납부
- 12월 (2기): 7월~12월분, 12월 16~31일 납부

연납 선택 시:
- 1월: 전액 선납 (최고 할인)
- 3월: 3~12월분 납부
- 6월: 6~12월분 납부
- 9월: 9~12월분 납부
```

## 감면·면제 대상

### 전기차·수소차

```
친환경차 자동차세:
- 전기차: 연 100,000원 정액 과세 (배기량 기준 없음)
- 수소차: 연 100,000원 정액 과세

→ 2,000cc 내연기관차 대비 약 75% 세금 절약
```

### 경차

```
1,000cc 이하 경차:
- 연 세액이 80,000원 수준
→ 2,000cc 차량 대비 약 80% 절약
```

### 장애인 자동차

```
장애인 명의 or 장애인 세대 보호자 명의 차량:
→ 자동차세 전액 면제 가능 (1대 한정)

조건:
- 등록 장애인이 직접 소유 or 동거 가족 명의
- 고급차 제외 (기준 가격 이상 차량은 제한)
→ 주소지 관할 시군구에 감면 신청
```

### 국가유공자

```
국가유공자 또는 그 유족:
→ 배기량 2,000cc 이하 1대 자동차세 면제
→ 관할 구청 자동차 담당 부서에 신청
```

## 자동차세 환급 — 중도 매도·폐차

```
연중에 차를 팔거나 폐차한 경우:
→ 이미 납부한 자동차세 중 남은 기간분 환급

환급 신청:
→ 별도 신청 불필요 (자동 환급)
→ 환급 통장으로 입금 or 등록된 계좌로 이체
→ 기간: 매도·이전 후 60일 이내 처리
```

---

## 절약 요약

```
절약 포인트 정리:

1. 1월 연납 신청 (9~10% 할인)
   → 매년 1월 16일~31일 위택스에서 신청

2. 차령에 따른 감액 확인
   → 오래된 차는 자동으로 감액 적용

3. 전기차로 교체 시 세금 절감
   → 2,000cc 차량 40만원 → 전기차 10만원

4. 장애인·국가유공자 감면 신청
   → 대상이면 반드시 신청

5. 자동차 매도 시 환급 확인
   → 자동 환급이지만 계좌 등록 확인
```

## 자주 묻는 질문

**Q. 연납을 1월에 신청 못 했는데 아직 할인받을 수 있나요?**
A. 3월, 6월, 9월에도 연납 가능합니다. 다만 1월보다 할인율이 낮습니다. 6월 납부 시점에도 2기분 연납이 가능합니다.

**Q. 차를 중고로 팔면 자동차세는 언제 환급되나요?**
A. 명의 이전 후 자동으로 처리됩니다. 보통 60일 이내 환급 계좌로 입금됩니다.

**Q. 할부 구입한 차도 연납 신청이 가능한가요?**
A. 내 명의로 등록된 차량이면 할부 여부와 무관하게 연납 신청 가능합니다.

**Q. 위택스 앱에서 연납 신청이 가능한가요?**
A. 스마트 위택스 앱에서 자동차세 연납 신청이 가능합니다. 공동인증서로 로그인 후 신청하세요.
