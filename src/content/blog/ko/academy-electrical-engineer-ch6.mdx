## 제어공학의 관점

제어공학은 원하는 출력이 나오도록 시스템을 조절하는 학문입니다. 전기기사에서는 전달함수, 블록선도, 피드백, 시간응답, 안정도 판별을 중심으로 출제됩니다. 수식이 낯설어도 “입력에 대해 출력이 어떻게 변하는가”라는 질문으로 접근하면 됩니다.

### 주요 개념

| 개념 | 의미 |
|------|------|
| 전달함수 | 입력과 출력의 비를 라플라스 영역에서 표현 |
| 피드백 | 출력 일부를 다시 입력 쪽으로 되돌림 |
| 시간응답 | 과도응답, 정상상태응답, 오버슈트 |
| 안정도 | 시간이 지나도 출력이 발산하지 않는 성질 |

폐루프 제어는 외란에 강하지만 구조가 복잡합니다. 개루프 제어는 단순하지만 출력 오차를 스스로 보정하기 어렵습니다. 블록선도 문제는 합류점과 분기점을 조심하면서 등가 변환을 단계적으로 진행하세요.

### 안정도 학습

안정도는 특성방정식의 근과 연결됩니다. 시험에서는 루스 판별법처럼 계산 절차가 정해진 방법이 자주 쓰입니다. 절차형 문제는 한 줄을 건너뛰면 전체가 틀어지므로 표를 천천히 채우는 연습이 필요합니다.

## 핵심 요약

- 제어공학은 입력과 출력의 관계를 다룹니다.
- 피드백은 오차 보정과 안정성 이해의 핵심입니다.
- 안정도 판별은 절차를 정확히 적용하는 훈련이 필요합니다.
