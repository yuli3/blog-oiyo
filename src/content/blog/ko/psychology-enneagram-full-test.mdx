## 에니어그램이란?

에니어그램(Enneagram)은 인간의 성격을 **9가지 근본적인 유형**으로 분류하는 성격 이론입니다. 고대 수피 전통에서 기원하여 20세기 초 서방으로 전해졌으며, 1970년대 이후 심리학자들이 체계화했습니다.

에니어그램은 단순한 성격 분류가 아닙니다. 각 유형의 **핵심 동기(욕구와 두려움)**, **자동적 행동 패턴**, **성장을 위한 방향**을 제시하는 심층 심리 시스템입니다.

<Callout type="note">
**MBTI와의 차이**: MBTI가 행동 패턴을 설명한다면, 에니어그램은 그 행동 아래의 **동기와 두려움**을 설명합니다. "왜 나는 이렇게 행동하는가?"에 대한 심층적인 답을 줍니다.
</Callout>

## 에니어그램 9가지 유형 한눈에 보기

| 유형 | 이름 | 핵심 동기 | 핵심 두려움 |
|---|---|---|---|
| **1번** ⚖️ | 완벽주의자 | 올바르고 선한 사람이 되기 | 나쁘고 부도덕한 사람 |
| **2번** 🤗 | 조력자 | 사랑받고 소중한 존재 되기 | 사랑받지 못함 |
| **3번** 🏆 | 성취자 | 가치 있고 성공한 사람 되기 | 가치 없고 실패한 사람 |
| **4번** 🎨 | 개인주의자 | 고유한 정체성 찾기 | 정체성 없는 평범함 |
| **5번** 🔬 | 탐구자 | 유능하고 지식이 풍부해지기 | 무능하고 쓸모없음 |
| **6번** 🛡️ | 충성가 | 안전하고 지지받는 환경 | 지지 없이 혼자 남겨짐 |
| **7번** ✨ | 낙천주의자 | 행복하고 만족스러운 삶 | 고통·결핍·제한에 갇힘 |
| **8번** 🦁 | 도전자 | 자신의 삶을 스스로 통제 | 타인에게 통제당함 |
| **9번** ☮️ | 평화주의자 | 내외면의 평화와 조화 | 갈등과 단절로 평화를 잃음 |

## 날개(Wing)와 통합·분열 방향

### 날개(Wing)

모든 유형은 **양옆의 이웃 유형 중 하나의 영향을 더 많이 받습니다**. 이것이 날개입니다.

예시: 4번 유형이라면
- **4w3** (4번 주, 3번 날개): 성취 지향적인 예술가
- **4w5** (4번 주, 5번 날개): 내성적이고 탐구적인 예술가

같은 유형도 날개에 따라 매우 다른 특성을 보입니다.

### 통합과 분열 방향

에니어그램의 특별한 통찰 중 하나는 **스트레스 상황과 성장 상황**에서 다른 유형의 특성을 보인다는 것입니다.

| 유형 | 분열(스트레스) | 통합(성장) |
|---|---|---|
| 1번 | → 4번 (비판·우울) | → 7번 (자유로움) |
| 2번 | → 8번 (지배·폭발) | → 4번 (자기 인식) |
| 3번 | → 9번 (무기력) | → 6번 (헌신) |
| 4번 | → 2번 (의존·집착) | → 1번 (원칙·규율) |
| 5번 | → 7번 (산만·충동) | → 8번 (자신감) |
| 6번 | → 3번 (경쟁·허영) | → 9번 (평화로움) |
| 7번 | → 1번 (완벽주의·비판) | → 5번 (집중·깊이) |
| 8번 | → 5번 (고립) | → 2번 (돌봄·나눔) |
| 9번 | → 6번 (불안·의심) | → 3번 (목표 지향) |

## 각 유형의 건강한 모습과 불건강한 모습

에니어그램은 유형마다 **건강 수준(1~9단계)**이 있습니다.

**건강할 때**: 유형의 강점이 가장 빛납니다
**보통일 때**: 전형적인 유형 패턴을 보입니다
**불건강할 때**: 유형의 그림자가 드러납니다

| 유형 | 건강한 모습 | 불건강한 모습 |
|---|---|---|
| 1번 | 현명한 개혁가, 도덕적 모범 | 완벽주의적 비판가, 분노 억압 |
| 2번 | 무조건적 사랑, 진정한 봉사 | 조종적 배려, 에너지 소진 |
| 3번 | 진정성 있는 롤모델 | 기만적 이미지 관리, 감정 억압 |
| 4번 | 창의적인 예술가, 깊은 공감 | 과도한 우울, 자기 연민 |
| 5번 | 통찰력 있는 혁신가 | 고립된 은둔자, 탐욕스러운 지식 축적 |
| 6번 | 용감하고 헌신적인 동반자 | 편집증적 불안, 권위 의존 |
| 7번 | 자유롭고 기쁨을 나누는 존재 | 나르시시즘, 중독적 쾌락 추구 |
| 8번 | 정의로운 보호자 | 지배적 폭군 |
| 9번 | 현명한 중재자, 영적 깊이 | 무기력한 수동성, 자기 망각 |

## 에니어그램을 실생활에 활용하는 법

### 직업과 커리어

에니어그램 유형은 **직업 적합성**과 깊이 연관됩니다.

| 유형 | 잘 맞는 직업 |
|---|---|
| 1번 | 법조인, 감사, 교사, 사회 개혁가 |
| 2번 | 상담사, 의료인, 사회복지사, HR |
| 3번 | 기업인, 마케터, 세일즈, 정치인 |
| 4번 | 예술가, 치료사, 작가, 디자이너 |
| 5번 | 연구자, 프로그래머, 철학자, 의사 |
| 6번 | 경찰, 소방관, 프로젝트 매니저 |
| 7번 | 크리에이터, 여행 관련, 기획자 |
| 8번 | 기업가, 군인, 변호사, 경영자 |
| 9번 | 중재자, 외교관, 상담사, 교육자 |

### 연애와 인간 관계

에니어그램은 **관계의 역학**을 이해하는 데도 유용합니다.

<Callout type="tip">
**궁합 팁**: 에니어그램 궁합에서 가장 중요한 것은 유형의 번호가 아니라 **각자의 건강 수준**입니다. 건강한 1번은 어떤 유형과도 좋은 관계를 맺을 수 있습니다.
</Callout>

## 에니어그램 자주 묻는 질문

**Q: 나는 여러 유형의 특성을 모두 가지고 있는데, 어떻게 내 유형을 알 수 있나요?**
A: 모든 사람은 9가지 특성을 모두 가집니다. 핵심은 **어떤 두려움과 욕구가 가장 강하게 나를 움직이는가**입니다. 반복적인 갈등 패턴과 핵심 두려움에 주목하세요.

**Q: 에니어그램 유형이 바뀔 수 있나요?**
A: 기본 유형은 변하지 않지만, **건강 수준은 달라질 수 있습니다**. 성장을 통해 더 건강한 수준으로 이동하는 것이 에니어그램의 목표입니다.

**Q: 에니어그램과 MBTI를 함께 사용해도 되나요?**
A: 네. 두 도구는 다른 차원을 탐구합니다. MBTI가 인지 스타일을 설명한다면, 에니어그램은 심층 동기를 설명합니다. 함께 사용하면 더 입체적인 자기 이해가 가능합니다.
