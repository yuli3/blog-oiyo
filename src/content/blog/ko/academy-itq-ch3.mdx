## ITQ 파워포인트·한쇼 시험 구성

```
시험 구성:
→ 실기 시험 60분, 500점 만점
→ A등급 400점 이상 / B등급 300점 이상

출제 영역:
→ 전체 구성 (60점): 슬라이드 크기·테마·슬라이드 마스터
→ 슬라이드 1 (30점): 제목·부제목 텍스트, 도형
→ 슬라이드 2 (30점): 목차·텍스트 상자·클립아트
→ 슬라이드 3 (30점): 텍스트, 도형, 스마트아트
→ 슬라이드 4 (40점): 표 삽입·편집
→ 슬라이드 5 (60점): 차트 삽입·편집
→ 슬라이드 6 (50점): 도형·그림·워드아트 복합
→ 애니메이션·화면전환 (100점)
→ 저장·완성 (100점)

채점 포인트:
→ 글꼴·크기·속성 정확히
→ 개체 위치·크기 지시 사항 준수
→ 색 채우기·선 색 정확히 설정
→ 애니메이션 순서·효과 정확히
→ 저장 시 파일명·형식 확인

합격 전략:
→ 슬라이드 마스터 먼저 설정 → 전체 통일성
→ 도형·텍스트·그림 작업 순서 일관되게
→ 애니메이션은 나중에 일괄 설정
→ 시간 남으면 전체 검토
```

## 슬라이드 마스터

```
슬라이드 마스터의 역할:
→ 모든 슬라이드에 공통 적용할 서식 지정
→ 보기 탭 → 슬라이드 마스터

마스터에서 설정할 내용:
→ 배경 색·그림·그라데이션
→ 머리글 영역: 제목 글꼴·크기·색·위치
→ 내용 영역: 본문 글꼴·크기·색
→ 페이지 번호·날짜·바닥글 자리 표시자

테마 적용:
→ 디자인 탭 → 테마 선택
→ 배경 스타일: 밝음·중간·어두움
→ 배경 서식: 단색·그라데이션·그림·질감

슬라이드 레이아웃:
→ 제목 슬라이드·제목 및 내용·비어 있음·그림 있는 내용 등
→ 마스터에서 레이아웃별 서식 각각 설정 가능

슬라이드 크기:
→ 표준 (4:3) vs 와이드스크린 (16:9)
→ 디자인 탭 → 슬라이드 크기 → 사용자 지정
→ 시험 지시 사항의 크기 정확히 설정 (cm 단위)

머리글과 바닥글:
→ 삽입 → 머리글 및 바닥글
→ 날짜·슬라이드 번호·바닥글 텍스트 설정
→ 제목 슬라이드 제외 옵션 활용
```

## 텍스트·도형·스마트아트

```
텍스트 상자:
→ 삽입 → 텍스트 상자 → 가로 또는 세로
→ 글꼴·크기·색·정렬 설정
→ 텍스트 상자 서식: 채우기·테두리·효과

WordArt (워드아트):
→ 삽입 → WordArt → 스타일 선택
→ 텍스트 효과: 변환·네온·그림자·반사

도형 삽입·편집:
→ 삽입 → 도형 → 종류 선택
→ 도형 서식: 채우기 색·선 색·굵기·효과
→ 텍스트 추가: 도형 더블클릭 → 입력
→ 도형 정렬: 맞춤 → 왼쪽·가운데·오른쪽·위·아래·분산

도형 변환:
→ 도형 변경: 도형 형식 탭 → 도형 편집 → 도형 변경
→ 점 편집: 도형 세부 모양 조정

스마트아트 (SmartArt):
→ 목록·프로세스·주기·계층구조·관계·행렬·피라미드
→ 삽입 → SmartArt → 유형 선택
→ 텍스트 입력: 텍스트 창 또는 도형 직접 입력
→ 색 변경: SmartArt 디자인 탭 → 색 변경
→ 레이아웃 변경: SmartArt 유형 변경 가능

그림 삽입:
→ 삽입 → 그림 → 파일에서
→ 서식: 꾸밈 효과·자르기·색 조정
→ 배치: 앞에·뒤에·문자 뒤·투명도
```

## 표와 차트

```
표 삽입·편집:
→ 삽입 → 표 → 행/열 수 지정
→ 셀 병합·분할·크기 조정
→ 표 스타일: 디자인 탭 → 표 스타일 갤러리
→ 셀 채우기 색·테두리 개별 설정

표 텍스트 서식:
→ 셀 안 세로 정렬: 위·가운데·아래
→ 글꼴·크기·색 셀별 설정
→ 텍스트 방향: 가로·세로·45도

차트 삽입:
→ 삽입 → 차트 → 유형 선택
→ Excel 창 열림 → 데이터 입력
→ 차트 유형: 세로막대·꺾은선·원형·가로막대·분산형

차트 요소:
→ 차트 제목: 글꼴·크기·위치
→ 축 제목: 가로(항목)·세로(값) 축 제목
→ 범례: 아래·오른쪽·위·왼쪽·없음
→ 데이터 레이블: 값·백분율 표시 위치
→ 데이터 테이블: 차트 아래 데이터 표시

차트 서식:
→ 차트 영역: 채우기·테두리
→ 그림 영역: 채우기 색 별도 설정
→ 계열 채우기 색 개별 설정
→ 보조 축: 2개 계열 단위 다를 때

원형 차트 특별 설정:
→ 조각 분리: 전체 또는 특정 조각
→ 시작 각도: 첫 조각의 시작 방향 (도)
→ 데이터 레이블에 백분율+이름 표시
```

## 애니메이션과 화면 전환

```
애니메이션:
→ 애니메이션 탭 → 효과 추가
→ 효과 유형:
  시작: 나타나기 (나타나기·날아오기·확대/축소)
  강조: 확대·회전·색 변경
  끝내기: 사라지기 (사라지기·날아가기)

애니메이션 순서:
→ 애니메이션 창에서 순서 드래그 변경
→ 순서 번호 표시: 슬라이드 위 번호 확인
→ 개체 번호 순서가 시험 지시 사항과 일치해야

타이밍 설정:
→ 시작: 클릭할 때·이전 효과와 함께·이전 효과 후
→ 지연: 이전 효과 후 몇 초 대기
→ 재생 시간: 효과 지속 시간

화면 전환 (Transitions):
→ 전환 탭 → 이 슬라이드에 적용
→ 효과: 밀기·닦아내기·분할·사각형·원형 등
→ 소리: 전환 시 소리 추가
→ 지속 시간: 전환 속도
→ 자동 전환: 클릭할 때 또는 지정 초 후 자동

모든 슬라이드 적용:
→ 전환 탭 → 모두 적용 (균일한 설정 시)

하이퍼링크:
→ 텍스트·도형 선택 → 삽입 → 링크
→ 대상: URL·다른 파일·현재 문서 내 다른 슬라이드
→ 실행 단추: 홈·뒤로·앞으로·처음으로·마지막으로

슬라이드 쇼 설정:
→ 슬라이드 쇼 탭 → 쇼 설정
→ 발표자 보기·부스 보기·개인 쇼 설정
→ 예행 연습 시간 기록
```

## 자주 묻는 질문

**Q. ITQ 파워포인트 시험에서 애니메이션 순서를 틀리면 얼마나 감점되나요?**
A. 애니메이션과 화면 전환은 총 100점 배점으로 ITQ 파워포인트 시험에서 큰 비중을 차지합니다. 개별 애니메이션 효과의 종류·순서·타이밍이 지시 사항과 다르면 각 항목별 감점이 이루어집니다. 순서가 어긋나면 효과가 올바르게 설정되었더라도 점수를 잃습니다. 애니메이션 창을 열고 번호 순서를 지시 사항과 대조하며 작업하는 것이 중요합니다. 또한 각 슬라이드에 화면 전환 효과와 모든 슬라이드에 동일 적용 여부도 확인해야 합니다.

**Q. 슬라이드 마스터를 먼저 설정해야 하는 이유는 무엇인가요?**
A. 슬라이드 마스터는 모든 슬라이드에 공통 적용되는 배경·글꼴·레이아웃을 한 번에 설정하는 도구입니다. 마스터를 먼저 설정하면 이후 생성하는 모든 슬라이드가 자동으로 마스터 서식을 따르므로 개별 슬라이드마다 반복 설정하는 시간을 절약합니다. 또한 배경색이나 글꼴을 일괄 변경할 때 마스터만 수정하면 전체에 반영됩니다. 시험에서는 마스터 설정 항목(로고 삽입·배경 그림 등)이 별도 채점 요소이므로 반드시 마스터에서 작업해야 개별 슬라이드 채점에도 영향을 주지 않습니다.
