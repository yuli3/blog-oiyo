## IFRS란

**IFRS(International Financial Reporting Standards)**: 국제회계기준위원회(IASB)가 제정한 글로벌 회계 기준.

**도입 배경**:
- 세계 자본시장 통합으로 국가별 회계 기준의 차이가 투자 장벽으로 작용
- EU가 2005년 상장사에 IFRS 의무화
- 한국: 2011년 상장법인 K-IFRS 전면 도입

---

## K-GAAP vs K-IFRS 주요 차이

| 항목 | K-GAAP (구 기준) | K-IFRS (현행) |
|------|----------------|-------------|
| **기본 재무제표** | 개별 재무제표 | **연결 재무제표** 중심 |
| **자산 평가** | 역사적 원가 중심 | 공정가치 허용 확대 |
| **재고자산** | LIFO 허용 | LIFO 금지 |
| **연구비·개발비** | 자산화 가능 | 연구단계: 비용, 개발단계: 조건부 자산 |
| **리스** | 운용리스 부외처리 | 사용권자산·리스부채 인식 |

## 공정가치 회계 (Fair Value Accounting)

**공정가치(Fair Value)**: 독립된 당사자들이 정상적인 거래에서 합의할 가격.

IFRS는 취득원가(역사적 원가)뿐 아니라 **공정가치 측정**을 적극 허용.

**공정가치 측정 계층**:
1. **Level 1**: 활성 시장의 공시 가격 (가장 신뢰)
2. **Level 2**: 유사 자산의 관측 가능한 시장 데이터
3. **Level 3**: 관측 불가능한 투입 변수 (모형 추정, 가장 불확실)

---

## 연결재무제표

**연결재무제표(Consolidated Financial Statements)**: 지배기업과 종속기업 집단 전체를 하나의 경제 단위로 보고 작성한 재무제표.

```
지배기업: 종속기업의 재무·영업 정책 결정력 보유
(보통 50% 초과 의결권 보유)

연결 제거 항목:
- 내부거래 (지배사↔종속사 매출·매입)
- 내부 미실현이익 (재고 또는 자산 포함)
- 지배기업의 종속기업 투자 계정
```

**비지배지분(Non-Controlling Interest)**: 연결재무제표에서 지배기업이 소유하지 않은 종속기업의 순자산 지분.

## 주요 IFRS 기준서

| 기준서 | 내용 |
|--------|------|
| **IFRS 15** | 고객과의 계약에서 생기는 수익 |
| **IFRS 16** | 리스 (사용권자산·리스부채) |
| **IFRS 9** | 금융상품 (분류·측정·손상) |
| **IAS 36** | 자산 손상 |
| **IAS 37** | 충당부채, 우발부채 |
| **IFRS 3** | 사업결합 (영업권 처리) |

## 리스 회계 (IFRS 16)

구 기준에서 운용리스는 부채로 인식하지 않았으나, IFRS 16에서는 모든 리스를 재무제표에 인식.

```
리스 자산(사용권자산) 인식 → 재무상태표 자산 증가
리스 부채 인식 → 재무상태표 부채 증가

효과: 부채비율 증가, EBITDA 증가 (리스료 → 감가상각+이자)
```

---

## 핵심 개념 카드

**연결재무제표** ★★★★★
: 지배기업과 종속기업을 하나의 실체로 보는 재무제표. K-IFRS에서 주재무제표.
*암기 포인트: IFRS = 연결 중심 (개별은 참고용)*

**공정가치 계층** ★★★★☆
: Level 1(시장가) > Level 2(유사자산) > Level 3(모형). 높을수록 신뢰도 높음.
*암기 포인트: 1=시장, 2=유사, 3=추정*

**IFRS 16 리스** ★★★★☆
: 운용리스도 재무제표에 자산·부채로 인식. 부외처리 금지.
*암기 포인트: IFRS 16 = 모든 리스 → 부채 인식*

## 실전 퀴즈

**Q. IFRS 도입 후 리스 항공사의 재무제표가 어떻게 변하는가?**
> 항공기 운용리스를 사용권자산·리스부채로 인식 → 자산과 부채 모두 크게 증가. 부채비율 상승, EBITDA 증가. 영업이익은 높아지고 이자비용이 별도 인식됨.

**Q. 연결재무제표에서 내부거래를 제거하는 이유는?**
> 그룹 내 거래는 외부와의 거래가 아니므로 실질적 수익·비용이 아님. 제거하지 않으면 매출과 이익이 과대 계상되어 집단 전체 성과를 왜곡함.
