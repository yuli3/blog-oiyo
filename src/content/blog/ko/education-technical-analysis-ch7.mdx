## 오실레이터란

오실레이터(Oscillator)는 특정 범위 내에서 진동하는 지표로, 가격 추세의 강도와 방향 전환 시점을 포착합니다.

```
핵심 용도:
→ 과매수/과매도 구간 판별
→ 다이버전스(Divergence) 포착 → 추세 전환 신호
→ 추세 강도 측정
```

---

## RSI (상대강도지수) 심화

```
RSI = 100 - [100 ÷ (1 + RS)]
RS = 평균 상승폭 ÷ 평균 하락폭 (기본 14일)

해석:
70 이상: 과매수 → 매도 신호 가능
30 이하: 과매도 → 매수 신호 가능
50 기준: 추세 방향 확인

실전 팁:
→ 강한 상승 추세에서 RSI 70 이탈 = 매도 아님
→ 추세 시장: 30~70 레벨 자체가 높게 유지
→ 횡보 시장에서만 30/70 레벨 효과적
```

### RSI 다이버전스

```
강세 다이버전스 (매수 신호):
가격: 저점↓ 하락 / RSI: 저점↑ 상승
→ 가격 하락에도 RSI 반등 = 하락 동력 약화

약세 다이버전스 (매도 신호):
가격: 고점↑ 상승 / RSI: 고점↓ 하락
→ 가격 상승에도 RSI 하락 = 상승 동력 약화
```

## 스토캐스틱 (Stochastic) 심화

```
%K = (현재가 - 기간 최저가) ÷ (기간 최고가 - 기간 최저가) × 100
%D = %K의 3일 이동평균

패스트 스토캐스틱: %K (민감)
슬로우 스토캐스틱: %K 3일 이평을 새 %K로 사용 (권장)

매수 신호: %K가 %D를 20 이하에서 상향 교차
매도 신호: %K가 %D를 80 이상에서 하향 교차
```

---

## MACD (이동평균수렴발산) 심화

```
MACD 라인 = 12일 EMA - 26일 EMA
시그널 라인 = MACD의 9일 EMA
히스토그램 = MACD - 시그널

신호:
골든 크로스: MACD가 시그널 상향 돌파 → 매수
데드 크로스: MACD가 시그널 하향 돌파 → 매도
히스토그램 0선 교차: 추세 전환 신호

MACD 다이버전스:
→ RSI와 동일 원리 — 특히 장기 차트에서 강력
```

## CCI (상품 채널 지수)

```
CCI = (일반가격 - 이동평균) ÷ (0.015 × 평균편차)

일반가격 = (고가 + 저가 + 종가) ÷ 3

해석:
+100 이상: 과매수 / -100 이하: 과매도
0선 교차: 추세 전환 신호

특징:
→ 주식보다 원자재·코인에 더 효과적
→ 빠른 반응 (단기 신호 포착)
```

---

## 복수 오실레이터 활용 전략

```
확인 전략 (Confirmation):
RSI + 스토캐스틱 동시 과매도 → 강한 매수 신호
→ 단독 신호보다 신뢰도 ↑

다이버전스 확인:
RSI + MACD 동시 다이버전스 → 추세 전환 가능성 대폭 증가

주의:
→ 오실레이터만으로 매매하지 말 것
→ 추세 지표(이동평균, 볼린저밴드)와 결합 필수
```

## 핵심 암기 포인트

*RSI 다이버전스: 가격↓ RSI↑ = 강세 반전 신호 (가장 신뢰도 높음)*
*스토캐스틱: %K가 %D를 20이하/80이상에서 교차 = 매수/매도*
*MACD 히스토그램 확장 = 추세 강화, 수축 = 추세 약화*
*오실레이터 단독 사용 금지 → 추세 지표와 반드시 결합*
