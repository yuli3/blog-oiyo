## 행정 구제 제도 체계

**행정 구제**: 위법·부당한 행정 작용으로 침해된 국민의 권익을 구제하는 제도.

```
사전 구제: 행정 절차법 (청문, 의견 제출)
사후 구제:
  ├── 행정 쟁송 (행정 심판, 행정 소송)
  └── 손해 전보 (손해 배상, 손실 보상)
```

---

## 행정 심판

**행정 심판**: 행정 기관이 행정 처분의 적법성·타당성을 스스로 심판하는 제도.

### 종류

```
행정 심판 3종류:
① 취소 심판: 위법·부당한 처분의 취소·변경 청구
② 무효 등 확인 심판: 처분 무효·유효·존재·부존재 확인
③ 의무이행 심판: 행정청의 부당한 거부·부작위에 대해 처분 이행 요구
```

### 청구 기간

```
취소 심판: 처분 있음을 안 날로부터 90일 내
           처분이 있은 날로부터 180일 내 (둘 중 먼저)

무효 확인 심판: 기간 제한 없음
의무이행 심판: 부작위의 경우 기간 제한 없음
```

### 재결

**재결**: 행정 심판의 결론.

```
재결 유형:
① 인용 재결: 청구 인정 (취소·변경·이행명령)
② 기각 재결: 청구 이유 없음
③ 각하 재결: 심판 요건 불충족

재결의 기속력: 처분청이 재결에 따라야 함 (같은 이유 거부 불가)
```

## 행정 소송

**행정 소송**: 법원이 행정 처분의 적법성을 심판하는 소송.

### 종류

```
행정 소송 4종류:
① 항고 소송 (가장 핵심)
   - 취소 소송
   - 무효 등 확인 소송
   - 부작위 위법 확인 소송
② 당사자 소송 (공법상 법률관계 다툼)
③ 민중 소송 (선거 무효 등)
④ 기관 소송 (기관 간 다툼)
```

### 취소 소송

```
취소 소송 요건:
① 처분성 있는 행위 대상
② 원고 적격 (법률상 이익 있는 자)
③ 피고 적격 (처분청)
④ 제소 기간: 처분 안 날 90일, 있은 날 1년
⑤ 행정 심판 전치주의 여부 (임의적)

주요 특수성:
- 취소 판결의 기속력 (행정청 구속)
- 간접 강제 (불이행 시 배상금)
```

## 집행 정지

**집행 정지**: 취소 소송 진행 중 처분의 집행을 멈추는 제도.

```
집행 정지 요건:
① 적법한 소 계속 중
② 처분·집행 등의 집행이 있을 것
③ 회복하기 어려운 손해 예방 필요
④ 공공복리에 중대한 영향 없을 것

효력: 집행 정지 결정 → 판결 확정까지 집행 정지
     판결 확정 후 자동 소멸
```

## 행정 심판 vs 행정 소송 비교

| 구분 | 행정 심판 | 행정 소송 |
|------|---------|---------|
| 심판 기관 | 행정 기관 | 법원 |
| 심판 기준 | 위법+부당 | 위법만 |
| 취소 기간 | 90일/180일 | 90일/1년 |
| 비용 | 저렴 | 상대적 고가 |
| 효력 | 기속력 | 기속력 |

## 핵심 개념 카드

**행정 심판 3종류** ★★★★★
: 취소·무효확인·의무이행. 의무이행 = 부작위에 대해 처분 이행 청구.
*암기 포인트: 취-무-의 (취소·무효·의무이행)*

**취소 소송 제소 기간** ★★★★★
: 처분 안 날 90일, 있은 날 1년. 둘 중 먼저 도래한 기간.
*암기 포인트: 안 날 90일 / 있은 날 1년*

**집행 정지 요건** ★★★★☆
: 소 계속 + 회복 어려운 손해 + 공공복리 방해 없음. 3요건 모두 충족해야.
*암기 포인트: 소+손해+공익 없음 = 집행정지*

## 실전 퀴즈

**Q. 영업 허가 취소 처분을 받은 날로부터 100일 후 행정 심판을 청구할 수 있는가?**
> 취소 심판 청구 기간: 안 날로부터 90일 또는 처분일로부터 180일. 처분일로부터 100일이면 아직 180일 이내이므로 가능.

**Q. 행정 소송 진행 중 처분이 먼저 집행되면 소송의 의미가 없어진다. 이를 막을 수 있는 제도는?**
> 집행 정지 신청. 회복 어려운 손해 예방과 공공복리 저해 없음을 소명해 법원에 신청.
