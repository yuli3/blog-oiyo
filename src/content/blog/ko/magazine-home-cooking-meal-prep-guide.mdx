## 밀프렙이란?

Meal Prep = 미리 식사를 준비해두는 것.

**효과**:
- 매일 "오늘 뭐 먹지?" 결정 피로 제거
- 외식·배달 비용 절감 (주 3~5만 원 절약)
- 영양 균형 잡힌 식사 유지
- 요리 시간 주 2~3시간 → 일일 15~20분으로 단축

**누구에게 적합?**:
- 바쁜 직장인
- 건강한 식단을 유지하고 싶은 사람
- 1인 가구 (소량 조리가 비효율적)

---

## 주 1회 밀프렙 루틴

### 기본 타임라인 (일요일 2~3시간)

| 시간 | 작업 |
|-----|-----|
| 0~30분 | 장보기 or 온라인 주문 도착 확인 |
| 30~60분 | 재료 손질 (세척·썰기) |
| 60~120분 | 조리 (병렬로 여러 메뉴) |
| 120~150분 | 분류·보관, 청소 |

**병렬 조리 핵심**: 밥솥 돌리는 동안 채소 볶기, 오븐 사용하는 동안 스토브 사용.

---

## 밀프렙 3대 구성요소

### 1. 단백질

| 재료 | 보관 | 조리법 |
|-----|-----|------|
| 닭가슴살 | 냉장 3~4일 | 삶기 or 오븐 굽기 (소금·후추) |
| 달걀 (삶은 것) | 냉장 5~7일 | 완숙 12분 |
| 연어·생선 | 냉장 2~3일 | 팬 굽기 or 에어프라이어 |
| 두부 | 냉장 3~4일 | 두부조림, 구운 두부 |
| 소고기 (불고기 양념) | 냉동 1개월 | 간편 볶음 |

**냉동 전략**: 닭가슴살·소고기는 1회 분량씩 소분 냉동 → 전날 냉장 이동해 해동.

### 2. 탄수화물

| 재료 | 보관 |
|-----|-----|
| 현미밥·잡곡밥 | 냉장 3일 / 냉동 1개월 |
| 고구마 (찐 것) | 냉장 5일 |
| 통밀 파스타 (삶은 것) | 냉장 3일 |
| 퀴노아 | 냉장 4~5일 |

**밥 냉동 팁**: 뜨거울 때 한 공기씩 지퍼백에 → 냉각 후 냉동. 전자레인지 5분 복원.

### 3. 채소

| 재료 | 보관 | 조리 팁 |
|-----|-----|-------|
| 브로콜리 (데친 것) | 냉장 3~4일 | 소금 넣고 2분 데치기 |
| 당근 (볶은 것) | 냉장 3~4일 | 참기름+소금 볶음 |
| 시금치 (데친 것) | 냉장 3일 | 데쳐서 물기 짜고 참기름 무침 |
| 콩나물 (무침) | 냉장 3일 | 5분 삶아 무침 |
| 방울토마토 | 냉장 5~7일 | 그대로 |

## 컨테이너 선택

| 종류 | 장점 | 단점 |
|-----|-----|-----|
| 유리 (파이렉스) | 전자레인지 안전, 냄새 안 밴 | 무거움 |
| 플라스틱 (BPA Free) | 가볍고 저렴 | 전자레인지 주의 |
| 스테인리스 | 위생적 | 전자레인지 불가 |
| 실리콘 | 냉동·전자레인지 가능 | 냄새 밸 수 있음 |

**추천**: 유리 or BPA Free 플라스틱 여러 크기 세트 (가장 활용도 높음).

**크기 기준**: 1인 1끼 기준 600~700ml 컨테이너 7개 (아침 제외 주 7끼).

## 1주일 밀프렙 플랜 (1인 기준)

### 일요일 장바구니

**단백질**: 닭가슴살 500g, 달걀 10개, 두부 1모
**탄수화물**: 현미 2컵, 고구마 3개
**채소**: 브로콜리 1개, 당근 2개, 시금치 1봉, 방울토마토 1팩
**기타**: 양파 2개, 대파

**예상 비용**: 3~4만 원 (주 5일 점심 + 저녁 기준)

### 일주일 메뉴 설계

| 요일 | 점심 | 저녁 |
|-----|-----|-----|
| 월 | 닭가슴살 + 현미밥 + 브로콜리 | 두부조림 + 시금치 + 현미밥 |
| 화 | 달걀 볶음밥 | 닭가슴살 + 당근 볶음 |
| 수 | 닭가슴살 샐러드 | 계란찜 + 고구마 |
| 목 | 두부 + 현미밥 | 닭가슴살 + 콩나물 무침 |
| 금 | 남은 재료 비빔밥 | 외식 or 냉동 메뉴 |

---

## 냉동 가능한 한식 메뉴

장기 보관으로 급할 때 활용:

| 메뉴 | 냉동 보관 |
|-----|---------|
| 불고기 | 1개월 (양념 전 소분) |
| 제육볶음 | 1개월 |
| 미역국 | 2~3개월 |
| 된장찌개 | 1개월 |
| 갈비찜 | 2개월 |
| 만두 | 3개월 (생만두 or 완성품) |

**냉동 주의**: 두부, 감자, 콩나물, 달걀 (삶지 않은 것) — 식감 손상.

## 밀프렙 효율화 팁

### 같은 재료 다르게 활용

닭가슴살 500g → 
- 200g: 슬라이스해서 샐러드용
- 200g: 잘게 찢어 비빔밥·볶음밥용
- 100g: 큐브로 잘라 볶음용

### 소스 미리 만들기

**간장 베이스 소스**: 간장 3T + 다진 마늘 1T + 설탕 1T + 참기름 1T → 병에 담아 냉장 2주.

어떤 재료에도 활용 가능.

### 아침 밀프렙 (간단)

- **오버나이트 오트**: 귀리 30g + 우유 200ml + 꿀 → 전날 밤 냉장
- **스무디팩**: 과일·채소 한 번에 갈아서 밀봉 냉동 → 아침에 우유만 추가

밀프렙은 완벽한 식단보다 **지속 가능한 식단**이 목표입니다. 처음에는 3~4가지 기본 재료만 준비하는 것으로 시작하세요.
