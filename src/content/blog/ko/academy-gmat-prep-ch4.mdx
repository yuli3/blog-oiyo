## Data Sufficiency: GMAT 고유 문제 유형

DS는 GMAT에서만 볼 수 있는 독특한 문제 형식입니다. 답을 직접 구하는 게 아니라 **주어진 조건이 답을 구하기에 충분한지 판단**합니다.

### 5가지 고정 선택지

모든 DS 문제의 선택지는 항상 동일합니다:

**(A)** 조건(1)만으로 충분하고, 조건(2)만으로는 불충분  
**(B)** 조건(2)만으로 충분하고, 조건(1)만으로는 불충분  
**(C)** 두 조건을 합치면 충분하지만, 각각은 불충분  
**(D)** 각 조건 단독으로도 충분  
**(E)** 두 조건을 합쳐도 불충분

### DS 황금 규칙
1. **각 조건을 독립적으로 테스트**: (1)을 볼 때 (2)를 잊어라
2. **충분 ≠ 특정 값**: YES/NO 질문도 YES만 나오면 충분
3. **함정**: "충분해 보이는" 복잡한 조건이 실제로는 불충분한 경우

## Table Analysis

스프레드시트 형태의 테이블을 보고 각 문장이 TRUE인지 FALSE인지 판단합니다.

**전략**:
- 테이블 정렬 기능 활용 (열 클릭으로 정렬)
- 각 문장을 독립적으로 검증
- 극단값(최소·최대)이나 비율 계산 문제가 빈출

---

## Graphics Interpretation

그래프(막대·선·산포도·원형 등)를 보고 빈칸에 맞는 값이나 관계를 선택합니다.

**주요 그래프 유형별 접근**:

| 그래프 | 주목할 점 |
|--------|---------|
| 막대 그래프 | 절댓값 비교, 증감 추세 |
| 선 그래프 | 기울기(변화율), 교차점 |
| 산포도 | 상관관계(양/음/무), 이상치 |
| 원형 차트 | 비율 합계 = 100% |

---

## Multi-Source Reasoning

여러 개의 탭(텍스트·테이블·그래프 혼합)에 걸쳐 정보를 종합하여 질문에 답합니다.

**전략**:
- 각 탭을 먼저 훑어 어떤 정보가 어디 있는지 파악
- 질문을 읽고 필요한 탭으로 바로 이동
- 정보들 사이의 모순이나 비교가 핵심
