# Chapter 3. 추론의 엔진: 삼단논법과 후건 부정

조건문을 기호화하는 법을 배웠다면, 이제 그 기호들을 연결하여 **'사슬(Chain)'**을 만들 차례입니다. 논리 퀴즈의 80%는 흩어져 있는 전제들을 하나의 긴 화살표 사슬로 연결하는 순간 끝이 납니다.

---

## 1. 삼단논법 (Hypothetical Syllogism)

"A→B이고 B→C이면 A→C이다." 너무나 당연해 보이지만, 실제 시험지에서는 B가 다양한 형태로 숨겨져 있습니다.

- **핵심**: 매개체인 **B**를 찾는 것.
- **팁**: B가 직접 보이지 않으면 대우(~B→~A)를 취해서 꼬리를 맞춰봅니다.

## 2. 후건 부정 (Modus Tollens) ★★★

수험생들이 가장 많이 놓치는 '치트키'입니다. 결론이 거짓임을 알 때 원인을 부정하는 강력한 도구입니다.

<FormulaBox
  formula="(A → B) ∧ ~B  ⇒  ~A"
  label="후건 부정 (Modus Tollens)"
  description="결과(B)가 벌어지지 않았다면, 원인(A)도 없었음이 확실합니다."
  color="#ef4444"
/>

<Callout type="warning">
  **역의 오류 주의**: "비가 오면 땅이 젖는다"에서 "땅이 젖었다(B)"고 해서 "비가 왔다(A)"고 결론 내리면 안 됩니다! (누가 물 뿌렸을 수도 있음) 
  오직 **"땅이 안 젖었다(~B)"**일 때만 **"비가 안 왔다(~A)"**고 말할 수 있습니다.
</Callout>

## 3. 진화하는 문제 풀이 (Step 7: 사슬 잇기)

**문제 6**: 다음 전제가 모두 참일 때, 반드시 참인 결론은?

> - 전제 1: 성실하면 성공한다.
> - 전제 2: 행복하지 않으면 성공하지 못한 것이다.
> - 전제 3: 철수는 성실하다.

1. 철수는 성공했지만 행복하지는 않다.
2. 철수는 행복하다.
3. 철수는 성공하지 못했다.
4. 성공하면 반드시 행복하다.

<Callout type="tip">
**[사고 프로세스: 사슬 구성]**
1. 1단계 (기호화): 
   - (1) 성실 → 성공
   - (2) ~행복 → ~성공
2. 2단계 (대우 취하기): 
   - (2)의 대우: **성공 → 행복**
3. 3단계 (사슬 연결): 
   - 성실 → 성공 → 행복
   - 즉, **성실 → 행복**
4. 4단계 (사실 대입): 
   - 철수는 성실함(T).
   - 따라서 철수는 행복함(T).

**정답: 2번**
</Callout>

## 4. 진화하는 문제 풀이 (Step 8: 거꾸로 추론)

**문제 7**: 다음 결론이 도출되기 위해 필요한 전제는?

> - **전제 1**: 날씨가 좋으면 소풍을 간다.
> - **전제 2**: 소풍을 가면 기분이 좋다.
> - **결론**: 기분이 좋지 않다면 날씨가 좋지 않은 것이다.

1. 날씨가 좋지 않으면 소풍을 가지 않는다.
2. 기분이 좋으면 소풍을 간 것이다.
3. 추가 전제 없이 이미 결론이 도출된다.
4. 소풍을 가지 않으면 기분이 좋지 않다.

<Callout type="tip">
**[사고 프로세스]**
1. 사슬: 날씨 좋음 → 소풍 감 → 기분 좋음
2. 최종 사슬: **날씨 좋음 → 기분 좋음**
3. 결론 확인: 결론인 "~기분 좋음 → ~날씨 좋음"은 최종 사슬의 **대우**임.
4. 따라서 이미 논리적으로 완벽하게 도출되는 상황임.

**정답: 3번**
</Callout>

## 🚀 20만원 강의의 Insight
진정한 고수들은 전제를 보자마자 머릿속으로 '대우'를 수시로 바꿔보며 "A→B→C" 혹은 "A→B, ~C→~B" 같은 구조를 순식간에 캐치합니다. 연습할 때 문장 옆에 화살표를 그리는 습관을 들이세요. 기호화가 속도와 정확도를 모두 잡는 유일한 길입니다.
