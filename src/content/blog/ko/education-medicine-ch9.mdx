## 뼈대계(골격계)

성인 인체에는 206개의 뼈가 있습니다.

```
뼈의 기능:
→ 지지: 몸의 형태 유지
→ 보호: 뇌(두개골), 심폐(흉곽), 척수(척추)
→ 운동: 근육의 지렛대 역할
→ 조혈: 적골수에서 혈액세포 생산
→ 저장: 칼슘·인 저장소

뼈의 구조:
피질골(치밀골): 단단한 외층 — 강도 제공
해면골(스폰지골): 내부 다공성 — 경량화
골막(Periosteum): 뼈 표면 덮개 — 감각·재생
골수강: 내부 공간 — 적골수/황골수
```

## 골절과 뼈의 치유

```
골절 유형:
완전 골절: 완전히 두 조각
불완전 골절: 금만 간 상태 (어린이 그린스틱)
개방 골절: 피부 밖으로 노출 (감염 위험↑)
압박 골절: 척추 등 눌려서 찌그러짐

치유 4단계:
1. 혈종 형성 (1~3일): 출혈 → 혈전 형성
2. 연골 가골 (2~3주): 연골로 임시 연결
3. 경골 가골 (3~4주): 칼슘 침착 → 단단해짐
4. 리모델링 (수개월~수년): 원래 형태로 복원
```

## 관절과 관절염

```
관절 유형:
부동관절: 두개골 봉합 — 움직임 없음
반관절: 척추간 — 제한적 움직임
가동관절: 어깨·무릎·손가락 — 자유 운동

관절 구조:
활막: 윤활액 분비 → 마찰 감소
연골: 충격 흡수
인대: 뼈-뼈 연결 → 관절 안정성
힘줄: 근육-뼈 연결
```

### 주요 관절 질환

```
골관절염 (퇴행성 관절염):
→ 연골 마모 → 뼈끼리 마찰
→ 노화·비만·과사용이 원인
→ 무릎, 엉덩이, 손가락 관절 주로 침범

류마티스 관절염:
→ 자가면역 질환 — 면역계가 활막 공격
→ 좌우 대칭 발생, 아침 강직이 특징
→ 항류마티스제(DMARDs) 치료

통풍:
→ 요산 결정이 관절에 침착
→ 엄지발가락 관절에서 시작
→ 급성 극심한 통증
→ 퓨린 많은 음식(내장·맥주) 제한
```

## 골다공증

```
정의: 뼈 밀도 감소 → 골절 위험 증가

위험 요인:
- 여성 (에스트로겐 감소 → 폐경 후)
- 노령, 가족력
- 칼슘·비타민D 부족
- 흡연, 과음
- 스테로이드 장기 복용

진단: DEXA 검사 (골밀도 측정)
T-스코어: -1 이상 정상, -1~-2.5 골감소증, -2.5 이하 골다공증

예방:
칼슘 1,000~1,200mg/일 + 비타민D 800~1,000IU/일
규칙적 체중 부하 운동 (걷기·달리기)
낙상 예방 (욕실 손잡이, 미끄럼 방지)
```

## 근육계

```
근육 유형:
골격근: 수의적 수축, 줄무늬 패턴
심근: 불수의적, 지칠 줄 모름
평활근: 내장·혈관, 불수의적

근수축 메커니즘 (슬라이딩 필라멘트 이론):
액틴(가는 필라멘트) + 미오신(굵은 필라멘트)
→ 미오신 머리가 액틴에 결합 → 당김 → 수축
→ ATP 에너지 + 칼슘이온 필요

근육 손상:
근좌상: 근섬유 미세 파열 → DOMS (지연성 근육통)
건염: 힘줄 염증 (테니스 엘보, 아킬레스건염)
근파열: 심한 갑작스러운 힘 → 수술 필요 가능
```

## 피부계 — 인체 최대 기관

```
피부 3층 구조:
표피 (Epidermis): 외부 장벽
  → 각질형성세포 → 각질층 (방수층)
  → 멜라닌세포: 자외선 차단 (피부색 결정)
  → 두께: 0.1mm (눈꺼풀) ~ 1.5mm (발바닥)

진피 (Dermis): 지지·영양
  → 콜라겐·엘라스틴: 탄력·강도
  → 모낭, 땀샘, 피지선, 신경, 혈관

피하조직 (Hypodermis): 지방 저장
  → 충격 흡수, 체온 유지, 에너지 저장
```

### 주요 피부 질환

```
아토피 피부염:
→ 피부 장벽 기능 이상 + 면역 과민 반응
→ 극심한 가려움, 만성 재발
→ 보습제 적극 사용, 자극 회피

건선:
→ 피부세포 과증식 (정상 28일 → 3~4일 주기)
→ 은백색 인설 동반 홍반 판
→ 자가면역 요소, 완치 어려움

피부암:
기저세포암: 가장 흔함, 전이 드뭄
편평세포암: 자외선·흡연·인유두종바이러스 관련
흑색종: 가장 위험, 멜라닌세포 악성화
→ ABCDE 규칙: 비대칭·경계·색·크기·진화
```

## 핵심 암기 포인트
