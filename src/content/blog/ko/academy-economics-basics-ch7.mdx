## 국민소득 개념

### GDP (국내총생산)

```
GDP (Gross Domestic Product):
일정 기간(분기 또는 연간) 한 나라 경제영역 내에서
생산된 최종 재화·서비스의 시장가치 합계

핵심 키워드:
- 일정 기간: 스톡(잔액)이 아닌 플로우(유량)
- 영토 내: 외국인 포함, 해외 국민 제외
- 최종재: 중간재 제외 (이중 계산 방지)
- 시장가치: 가격 × 수량

GNI (국민총소득):
거주자 기준으로 국내외에서 벌어들인 소득
명목 GNI = 명목 GDP + 국외순수취 본원소득
```

과거 교재의 GNP는 생산 개념이고 오늘날 국민계정에서는 소득 흐름을 보여주는 GNI를 주로 사용합니다. 여기서 ‘국민’은 법적 국적이 아니라 경제적 이해의 중심이 있는 **거주자** 기준입니다. 실질 GNI는 교역조건 변화에 따른 실질무역손익까지 반영하므로 `실질 GDP + 국외순수취 본원소득`만으로 단순 계산하지 않습니다.

### 국민소득 3면 등가

```
생산국민소득 = 지출국민소득 = 분배국민소득

지출 접근 (GDP 지출):
GDP = C + I + G + (X - M)
C: 민간소비
I: 투자 (기업 설비+건설+재고)
G: 정부 지출
(X-M): 순수출

소득 접근:
GDP = 피용자보수 + 영업잉여·혼합소득 + 고정자본소모 + 생산·수입세 − 보조금
```

## 명목 GDP vs 실질 GDP

```
명목 GDP: 당해 연도 가격으로 측정
실질 GDP: 가격 변동의 영향을 제거해 물량 변화를 측정

GDP 디플레이터:
= 명목 GDP / 실질 GDP × 100
= 전반적 물가 수준 측정

물가 지수:
① GDP 디플레이터: 국내 생산 전체 반영
② CPI (소비자물가지수): 가계 소비 바스켓
③ PPI (생산자물가지수): 생산자 단계 물가

실질 경제성장률:
= (실질 GDP₁ - 실질 GDP₀) / 실질 GDP₀ × 100
```

## 국민소득 파생 지표

```
NNI (국민순소득) = GNI - 고정자본소모
국민소득 파생식은 국민계정 체계와 평가가격에 따라 조정 항목이 달라짐
PI (개인소득) = NI - 법인유보이익 - 사회보험료 + 이전소득
DI (가처분소득) = PI - 개인소득세
```

## 경기순환 (Business Cycle)

```
경기순환 4국면:
① 확장 (Expansion): GDP 증가, 고용 증가, 물가 상승
② 정점 (Peak): 경기 최고점
③ 수축 (Contraction): 생산·소득·고용 등이 광범위하게 둔화
   - ‘실질 GDP 2분기 연속 감소’는 기술적 경기침체라는 간편 기준일 뿐, 공식 경기국면 판정과 같지 않음
④ 저점 (Trough): 경기 최저점

선행·동행·후행 지표:
선행 지표: 경기 변동 앞서 움직임 (주가·건설 수주)
동행 지표: 경기와 동시 움직임 (공업생산·취업자수)
후행 지표: 경기 후에 움직임 (실업률·소비자물가)
```

## 핵심 개념 카드

**GDP = C+I+G+(X-M)** ★★★★★
: 지출 접근법. 민간소비+투자+정부지출+순수출. 수입은 빼는 것 주의.
*암기 포인트: GDP=소비+투자+정부+순수출*

**명목·실질·디플레이터** ★★★★★
: 디플레이터=명목/실질×100. 실질GDP=물가 제거 → 실질 성장 파악.
*암기 포인트: 디플레이터=명목÷실질×100*

**선행지표 예시** ★★★★☆
: 주가, 건설 수주, 장단기 금리차, 소비자심리지수. 경기 앞서 움직임.
*암기 포인트: 선행=주가·건설수주*

## 실전 퀴즈

**Q. 명목 GDP 1,000조, GDP 디플레이터 125일 때 실질 GDP는?**
> 실질 GDP = 명목 GDP / 디플레이터 × 100 = 1,000 / 125 × 100 = 800조 원.

**Q. GDP에 포함되는 것과 포함되지 않는 것을 각각 예로 드시오.**
> 포함: 기업의 최종 상품 판매, 정부 공무원 급여 지불. 불포함: 중고차 거래(이전, 이미 계상됨), 주식 매매(자산 이전), 지하경제·무급 가사노동.
