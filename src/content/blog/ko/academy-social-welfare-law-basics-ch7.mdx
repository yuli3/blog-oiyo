## 국민건강보험

```
국민건강보험법:
모든 국민의 질병·부상 시 의료비 지원

보험자:
국민건강보험공단

피보험자:
직장가입자: 근로자 + 피부양자
지역가입자: 자영업자 등

보험료:
직장: 보수월액 × 보험료율 (근로자+사용자 절반)
지역: 소득·재산 기반 부과

급여 종류:
요양급여: 의료 서비스 (진찰·입원·수술)
요양비: 요양기관 외 치료비
건강검진
```

## 건강보험 급여와 비급여

```
급여:
건강보험 적용 항목
본인 부담금 있음 (일부 부담)

비급여:
건강보험 미적용 항목
전액 본인 부담

본인 부담률:
외래: 30~60% (의원급)
입원: 20%
상급병원 외래: 60%

본인 부담 상한제:
연간 본인 부담 총액 상한 설정
초과분: 건보공단이 사후 환급

실손보험:
건강보험 적용 후 나머지 부담 보전
민간 보험
```

## 의료급여

```
의료급여:
생활 어려운 저소득층의 의료비 지원
국민기초생활보장법의 급여 중 하나

의료급여 수급권자:
1종: 근로 능력 없는 수급자
2종: 근로 능력 있는 수급자

본인 부담:
1종: 없음 또는 극소액
2종: 소액 (건강보험보다 낮음)

의료급여 기관:
1차: 의원
2차: 병원
3차: 상급 종합병원 (1·2차 경유 필요)
```

## 산업재해보상보험

```
산재보험:
업무상 재해 시 근로자 보상

사업주 전액 부담:
근로자 보험료 없음

업무상 재해:
업무상 사고, 업무상 질병, 출퇴근 재해

급여 종류:
요양급여: 의료비 전액
휴업급여: 평균임금 70% × 쉬는 날
장해급여: 장해 등급별
간병급여: 간병 필요 시
유족급여: 사망 시

특이 사항:
민사 손해배상과 부분 중복 제한
산재 확인 이의: 근로복지공단 → 행정소송
```

## 핵심 개념 카드

**건강보험 본인부담 상한제** ★★★★★
: 연간 본인부담 초과분 환급. 저소득일수록 낮은 상한.
*암기 포인트: 상한제=초과분 환급*

**의료급여 1종 vs 2종** ★★★★★
: 1종=근로능력없음·본인부담없음. 2종=근로능력있음·소액부담.
*암기 포인트: 1종=무부담, 2종=소액*

**산재=사업주전액** ★★★★★
: 산재보험 보험료는 사업주만. 근로자 기여 없음.
*암기 포인트: 산재=사업주100%*

## 실전 퀴즈

**Q. 건강보험 급여와 의료급여의 대상자 차이는?**
> 건강보험: 모든 국민(국민건강보험공단 관리). 보험료 납부 기반. 의료급여: 기초생활수급자 등 저소득층(국가 재원). 보험료 없이 자산 조사 기반. 의료급여 대상자는 건강보험 아닌 의료급여로 의료 지원.

**Q. 산재보험 수령 후 민사 손해배상을 청구할 수 있는가?**
> 가능하지만 제한적. 산재보험 수령액과 민사 배상액이 중복되면 동일 손해 항목은 공제. 사용자 과실이 있으면 민사 청구 가능하지만 산재 수령액만큼 감액. 이중 배상 완전 불가는 아님.
