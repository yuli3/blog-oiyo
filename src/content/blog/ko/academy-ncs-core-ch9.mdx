## NCS 수리능력의 구성

NCS 수리능력은 2가지 핵심 유형으로 나뉩니다:

1. **기초 연산**: 사칙연산, 분수·소수, 비율·백분율, 방정식
2. **자료 해석**: 표·그래프를 읽고 분석하여 결론 도출

공기업 시험에서 **자료 해석이 더 많은 비중**을 차지합니다. 이번 강의는 자료 해석 심화와 자주 쓰이는 응용 계산에 집중합니다.

---

## 자료 해석의 5단계 프로세스

### Step 1: 자료 구조 파악 (30초)
- 표 vs 그래프 유형 (막대, 꺾은선, 원, 복합)
- 단위 확인 (만 명, 억 원, %, 지수)
- 기간/항목 범위 파악

### Step 2: 문제 선택지 읽기 (30초)
선택지를 먼저 읽고, 어떤 값을 계산해야 하는지 파악합니다.

### Step 3: 필요한 데이터만 추출
모든 숫자를 읽지 않습니다. 선택지에서 요구하는 항목만 찾습니다.

### Step 4: 어림 계산으로 범위 좁히기
정확한 계산 전에 어림수로 선택지 2~3개를 제거합니다.

### Step 5: 검산 (필요 시)
계산이 의심스러울 때만 재계산.

## 핵심 계산 유형 1: 증감률

### 공식
```
증감률(%) = (비교 기간 - 기준 기간) ÷ 기준 기간 × 100
```

### 함정: 증가량 vs 증가율

| 항목 | 2020년 | 2021년 |
|------|--------|--------|
| A 제품 | 1,000 | 1,100 |
| B 제품 | 500 | 700 |

- A 제품 증가량: 100, 증가율: 10%
- B 제품 증가량: 200, 증가율: **40%**

"증가율이 더 높은 제품" = B (40%)
"증가량이 더 많은 제품" = B (200)

둘 다 B이지만, 경우에 따라 결과가 달라집니다.

### 연평균 성장률 (CAGR)

```
CAGR = (최종값 / 초기값)^(1/연수) - 1
```

시험에서는 정확한 CAGR보다 **단순 비교** 형태로 출제됩니다.

---

## 핵심 계산 유형 2: 비율·구성비

### 점유율 계산

```
A의 점유율(%) = A ÷ 전체 합계 × 100
```

**함정**: 전체 합계가 바뀌면 각 항목의 점유율도 바뀝니다.

### 복합 비율 문제

"A국의 GDP 대비 수출 비중이 30%이고, 수출 중 B 품목이 25%를 차지한다면, GDP 대비 B 품목 수출 비중은?"

30% × 25% = **7.5%**

백분율끼리 곱할 때는 소수로 변환합니다: 0.30 × 0.25 = 0.075

---

## 핵심 계산 유형 3: 지수와 기준점

### 지수 읽기

지수는 **기준 시점을 100으로 설정**한 상대적 값입니다.

"2020년을 100으로 했을 때 2023년 소비자물가지수가 115라면, 물가 상승률은?"
→ 15% 상승 (115 - 100 = 15)

### 기준 연도 변경 함정

지수 기준 연도가 다른 두 지수를 직접 비교하면 오답입니다.

---

## 핵심 계산 유형 4: 가중 평균

단순 평균이 아닌 가중치가 있을 때 사용합니다.

### 혼합 문제 (농도·가격)

10% 소금물 200g과 20% 소금물 300g을 혼합한 소금물의 농도:

```
소금 양 = 200 × 0.1 + 300 × 0.2 = 20 + 60 = 80g
혼합 물 = 200 + 300 = 500g
농도 = 80 / 500 = 16%
```

### 평균 속도 (주의!)

A가 시속 60km로 1시간, 시속 30km로 1시간 이동했다면 평균 속도는?

단순 평균: (60 + 30) / 2 = 45km/h ← **오답!**
실제 평균: 총 거리 / 총 시간 = (60 + 30) / 2 = 45km/h ← 우연히 같음

그러나 "60km를 시속 60km로, 30km를 시속 30km로" 이동한 경우:
- 시간: 1시간 + 1시간 = 2시간
- 거리: 90km
- 평균 속도: 45km/h

"60km를 시속 60km로, 60km를 시속 30km로" 이동:
- 시간: 1 + 2 = 3시간, 거리: 120km
- 평균: 40km/h ← 단순 평균(45)와 다름!

**핵심**: 같은 시간이 아닌 같은 거리를 이동한 경우, 평균 속도 = 조화평균

## 핵심 계산 유형 5: 일·작업률

### 기본 공식

```
일률 = 1 / 걸리는 시간 (전체 일을 1로 보았을 때)
```

A가 혼자 하면 6일, B가 혼자 하면 4일. 같이 하면?

```
A 일률: 1/6, B 일률: 1/4
합산: 1/6 + 1/4 = 2/12 + 3/12 = 5/12
완성 시간: 12/5 = 2.4일
```

### 일부 완성 후 나머지

A가 3일 일한 뒤 B와 함께 나머지를 완성:
- A가 3일 완성분: 3 × (1/6) = 1/2
- 남은 작업: 1 - 1/2 = 1/2
- A+B 일률: 5/12
- 나머지 시간: (1/2) ÷ (5/12) = 6/5 = 1.2일

## 확률 기초

### 덧셈 법칙

두 사건 A, B가 있을 때:
```
P(A 또는 B) = P(A) + P(B) - P(A and B)
```

A, B가 서로 배반(둘 다 불가)이면: P(A 또는 B) = P(A) + P(B)

### 곱셈 법칙

독립 사건일 때:
```
P(A and B) = P(A) × P(B)
```

### 조건부 확률

```
P(A | B) = P(A and B) / P(B)
```

"B가 일어났다는 조건 하에서 A가 일어날 확률"

### 빈출 유형: 조합 계산

5명 중 2명을 뽑는 경우의 수:
```
₅C₂ = 5! / (2! × 3!) = 10
```

10명 중 팀장 1명, 부원 2명:
```
₁₀C₁ × ₉C₂ = 10 × 36 = 360
```

## 그래프 유형별 주의 사항

### 이중 축 그래프

왼쪽 y축과 오른쪽 y축의 단위가 다릅니다. 두 데이터를 직접 비교하면 안 됩니다.

### 누적 막대 그래프

각 구간의 실제 값 = 상단 값 - 하단 값. 전체 막대의 높이가 합계입니다.

### 꺾은선 그래프의 기울기

기울기 = 변화 속도. 기울기가 가파를수록 변화 속도가 빠릅니다. x축 간격이 일정할 때만 기울기를 직접 비교할 수 있습니다.

## 빠른 계산 팁

| 상황 | 팁 |
|------|-----|
| ×0.9 | ×(1-0.1) = 10% 감소 |
| ×1.1 × 1.1 | ≈ ×1.21 (20% 이상 증가 아님) |
| 분수 비교 | 분자/분모 비율로 어림 |
| 나눗셈 | 역수 곱셈으로 변환 |
| 백분율 → 분수 | 25%=1/4, 33%≈1/3, 20%=1/5 |
