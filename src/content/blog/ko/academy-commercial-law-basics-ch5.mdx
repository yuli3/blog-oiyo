## 주주 권리 체계

```
주주 권리:
┌──────────┬────────────────────────────────────┐
│ 자익권   │ 경제적 이익 목적                    │
│          │ 배당청구권·잔여재산분배청구권        │
│          │ 신주인수권·전환사채 전환권           │
├──────────┼────────────────────────────────────┤
│ 공익권   │ 회사 운영 참가 목적                  │
│          │ 의결권·주주총회 소집청구권           │
│          │ 위법행위 유지청구권·대표소송권       │
└──────────┴────────────────────────────────────┘

단독주주권: 주식 1주만 있어도 행사 가능
→ 의결권, 배당청구권 등

소수주주권: 일정 지분 이상 보유 주주만 행사 가능
→ 경영에 영향 주는 강력한 권리 제한
```

## 의결권

```
1주 1의결권 원칙:
각 주식 1개당 1개의 의결권

의결권 제한:
자기주식: 의결권 없음
상호주식: 일정 한도 내 제한 (10% 초과분)
무의결권 우선주

의결권 행사 방법:
직접 출석: 주주가 주주총회 참석
대리인 행사: 위임장으로 대리인이 행사
서면투표: 사전 서면 제출 (정관에 근거)
전자투표: 온라인 의결권 행사 (정관에 근거)

집중투표제:
이사 선임 시 1주에 이사 수만큼 의결권 부여
소수주주가 이사 1인 이상 선임 가능하도록
비공개회사: 정관으로 배제 가능
```

## 소수주주권

```
주주총회 소집청구권:
요건: 발행주식 3% 이상 보유
6주 전에 이사회에 서면 청구
이사회 불응 시 법원 허가 받아 직접 소집

이사·감사 해임청구권:
요건: 발행주식 3% 이상
직무 집행에 현저한 손해 발생 우려

이사의 위법행위 유지청구권:
요건: 발행주식 1% 이상
이사가 법령·정관 위반 행위 예정 시
법원에 유지명령 신청

대표소송:
요건: 6개월 이상 보유 + 발행주식 0.01% 이상 (상장회사)
비공개회사: 지분율 요건 없음 (6개월 보유만)
회사를 위해 이사 책임 추궁

장부열람권:
요건: 발행주식 3% 이상
회계장부·서류 열람·등사 청구
```

## 주주총회

```
정기 주주총회:
매년 1회 정기 소집
결산 후 3개월 이내

임시 주주총회:
필요 시 수시 소집
이사회 결의 또는 소수주주 청구

주주총회 결의 효력:
결의 취소: 결의일로부터 2개월 이내 소
결의 무효: 무효 사유→언제든지 확인 소
결의 부존재: 실질적 의결이 없는 경우

결의 취소 사유:
소집 절차·결의 방법 위반
정관 위반 결의
현저한 불공정 결의
```

## 핵심 개념 카드

**소수주주권 지분 요건** ★★★★★
: 총회소집=3%, 장부열람=3%, 위법행위유지=1%, 대표소송=0.01%(상장).
*암기 포인트: 청구·열람=3%, 유지=1%, 대표소송=0.01%*

**의결권 1주 1의결권** ★★★★★
: 자기주식·무의결권 우선주는 예외. 상호주 10% 초과분도 제한.
*암기 포인트: 1주=1의결권, 예외=자기주·무의결권우선주*

**주주총회 결의 취소 기간** ★★★★☆
: 취소 사유=결의일로부터 2개월 이내만 소 제기 가능.
*암기 포인트: 결의 취소=2개월 이내*

## 실전 퀴즈

**Q. 소수주주가 임시 주주총회 소집을 원할 때 절차는?**
> 발행주식 총수의 3% 이상 보유 주주가 이사회에 서면 청구. 이사회가 6주 내 소집하지 않으면 법원 허가를 받아 주주가 직접 소집 가능.

**Q. 대표소송과 직접 손해배상 청구의 차이는?**
> 대표소송: 주주가 회사를 대신해 이사에게 손해배상 청구(회사를 위한 소). 직접청구: 이사의 악의·중과실로 제3자 손해 시 제3자가 직접 청구. 대표소송 승소 이익은 회사에 귀속.
