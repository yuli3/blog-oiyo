## 주거급여란?

기초생활보장 수급자 중 주거 지원이 필요한 분께 **임차비(월세)를 보조**하거나 **자가 주택 수선비를 지원**하는 제도입니다.

---

## 주거급여의 두 가지 형태

```
1. 임차급여: 전세·월세 거주자에게 임차비 지급
2. 수선유지급여: 자가 주택 소유자에게 주택 수리비 지원
```

---

## 신청 자격

```
기준 중위소득 48% 이하 (2024년 기준):
- 1인 가구: 월 1,069,654원 이하
- 2인 가구: 월 1,767,652원 이하
- 3인 가구: 월 2,263,035원 이하
- 4인 가구: 월 2,750,358원 이하

→ 생계급여(32%)보다 소득 기준이 넓음
→ 생계급여 탈락자도 주거급여는 받을 수 있음
```

## 임차급여 — 월세 거주자 지원

### 지급 기준 임대료 (2024년)

| 가구원수 | 서울 | 경기·인천 | 광역시 | 그 외 |
|--------|-----|---------|------|------|
| 1인 | 341,000원 | 268,000원 | 228,000원 | 191,000원 |
| 2인 | 382,000원 | 300,000원 | 255,000원 | 212,000원 |
| 3인 | 455,000원 | 358,000원 | 302,000원 | 254,000원 |
| 4인 | 527,000원 | 414,000원 | 350,000원 | 294,000원 |

```
지급 금액 산정:
→ 실제 임차료와 기준 임대료 중 낮은 금액
→ 자기부담금이 있으면 그 금액은 차감

예시:
서울 1인 가구, 월세 30만원 → 기준 임대료 34.1만원
→ 실 임차료 30만원 전액 지급
```

## 수선유지급여 — 자가 주택 수리 지원

```
자가 주택 소유 수급자 대상:

수선 주기별 지원 금액:
- 경보수 (3년 주기): 457만원
- 중보수 (5년 주기): 849만원
- 대보수 (7년 주기): 1,241만원

수선 내용:
- 경보수: 도배, 장판 교체, 창호 수리
- 중보수: 단열, 난방 설비, 지붕 수리
- 대보수: 기초 구조물 보강, 전기·수도 전면 교체
```

## 청년 주거급여 분리 지급

### 제도 목적

```
부모와 별도로 거주하는 미혼 청년이 부모 수급 가구에 포함되어
주거급여를 따로 못 받는 문제 해결
→ 청년이 독립 거주 시 별도 임차급여 지급 가능
```

### 자격 요건

```
- 수급 가구 내 만 19세~30세 미만 미혼 자녀
- 부모와 다른 주소에 거주 (독립 주거 확인)
- 주거급여 수급 가구에 포함된 자녀

지급 금액: 해당 거주 지역 1인 가구 기준 임대료 적용
신청: 주민센터 → 주거급여 분리 지급 신청
```

---

## 신청 방법

```
신청 장소:
- 거주지 관할 읍·면·동 주민센터
- 복지로 홈페이지 (www.bokjiro.go.kr) 온라인 신청
- LH 마이홈 포털 (myhome.go.kr)

필요 서류:
- 신분증
- 임대차 계약서 사본 (임차급여 신청 시)
- 통장 사본
- 소득·재산 관련 서류 (주민센터에서 상당 부분 전산 조회)
```

---

## 주거급여와 다른 급여 중복 여부

```
주거급여는 다른 기초생활보장 급여와 독립적:
- 생계급여 + 주거급여: 중복 수급 가능
- 의료급여 + 주거급여: 중복 수급 가능
- 교육급여 + 주거급여: 중복 수급 가능

단, 각 급여마다 소득 기준 충족 여부 별도 판단
```

## 주거급여 조정 사유

```
다음 변동 시 신고 필요:
- 임차료 변경 (인상 or 인하)
- 이사 (새 임대차 계약서 제출)
- 소득·재산 변동
- 가구원 변동 (사망, 전출 등)
→ 미신고 시 환수 또는 급여 감액
```

## 자주 묻는 질문

**Q. 생계급여를 못 받아도 주거급여는 받을 수 있나요?**
A. 네, 주거급여 소득 기준(기준 중위 소득 48%)이 생계급여(32%)보다 넓습니다. 생계급여 탈락자도 주거급여 대상일 수 있으므로 주민센터에 확인하세요.

**Q. 보증금이 있는 전세에도 지급되나요?**
A. 전세 거주자도 임차급여 대상입니다. 보증금이 있는 경우 임차료 환산 방식으로 계산해 지급합니다.

**Q. 월세가 기준 임대료보다 높으면 어떻게 되나요?**
A. 기준 임대료 한도까지만 지급됩니다. 초과분은 본인 부담입니다.

**Q. 고시원에 사는 경우도 해당되나요?**
A. 고시원, 원룸, 오피스텔 등도 임차 계약이 있다면 임차급여 신청이 가능합니다. 단, 불법 건물이나 계약서가 없는 경우는 어렵습니다.
