## 청약통장이 왜 중요한가

아파트 분양가는 시세 대비 **10~40% 저렴**한 경우가 많습니다. 수억 원의 차익이 청약 하나로 결정됩니다. 청약통장은 단순한 적금이 아니라 **내 집 마련의 핵심 열쇠**입니다.

---

## 주택청약종합저축 기본 개요

| 항목 | 내용 |
|------|------|
| **가입 대상** | 국민 누구나 (연령 제한 없음) |
| **월 납입** | 2만원~50만원 자유 납입 |
| **금리** | 연 2.0~2.8% (납입 기간별) |
| **세금 혜택** | 연간 납입액 240만원 한도, 40% 소득공제 |
| **청약 가능** | 공공·민간·전용면적 무관 모두 적용 |

### 월 10만원 vs 25만원 납입 전략

- **공공분양** 목표: 월 10만원으로 납입 횟수(회차) 쌓기
- **민간분양** 목표: 월 25만원×24개월 = 600만원 이상이면 1순위 충족
- **서울 85㎡ 이하 민간**: 24회 이상 + 600만원 이상

> **핵심**: 민간 1순위는 납입 횟수보다 납입 금액이 중요합니다.

### 공공분양 1순위

| 구분 | 투기과열지구 | 기타 지역 |
|------|------------|---------|
| 가입 기간 | 24개월 이상 | 12개월 이상 |
| 납입 횟수 | 24회 이상 | 12회 이상 |
| 세대주 여부 | 필요 | 필요 |
| 무주택 기간 | 필요 | 필요 |

### 민간분양 1순위

| 구분 | 투기과열지구 | 청약과열지구 | 기타 |
|------|------------|-----------|------|
| 가입 기간 | 24개월 | 12개월 | 6개월 |
| 납입 금액 | 600만원+ | 600만원+ | 지역별 상이 |

## 청약 가점제 완전 분석

민간분양 85㎡ 이하는 **가점제 40~100%** 적용됩니다. 가점이 높을수록 당첨 확률↑

### 가점 항목 (총 84점)

| 항목 | 최고 점수 | 계산 방법 |
|------|----------|---------|
| **무주택 기간** | 32점 | 1년마다 2점 (최대 15년 이상 = 32점) |
| **부양가족 수** | 35점 | 0명=5점, 1명=10점, ..., 6명이상=35점 |
| **청약통장 가입 기간** | 17점 | 6개월=1점, 1년=2점, ..., 15년이상=17점 |

### 가점 예시 계산

```
무주택 기간 5년  → 12점
부양가족 3명    → 20점 (본인 제외: 배우자+자녀2)
통장 가입 3년   →  6점
─────────────────────
합계: 38점 (평균 수준)
```

> **통장 장기 보유 필수**: 15년 통장이면 17점, 1년 통장은 2점 — 무려 15점 차이입니다.

## 특별공급 vs 일반공급 선택 전략

### 특별공급 유형 7가지

| 유형 | 대상 | 비율 |
|------|------|------|
| **신혼부부** | 혼인 7년 이내, 자녀 있으면 우선 | 민간 20% |
| **생애최초** | 생애 처음 주택 구입, 5년 이상 직장인 | 민간 15% |
| **노부모부양** | 만 65세 이상 직계존속 3년 이상 부양 | 민간 3% |
| **다자녀** | 미성년 자녀 3명 이상 | 민간 10% |
| **기관추천** | 국가유공자, 장애인 등 | 10% |
| **이전기관** | 혁신도시 이전기관 종사자 | 별도 |
| **청년** | 만 19~39세, 미혼, 무주택 | 공공분양 |

### 특별공급 신청 가능 횟수

- **평생 1회** (유형별 1회, 총합 1회)
- 단, 공공분양과 민간분양은 별도 카운트되기도 함

> **중요**: 특별공급 당첨 이력이 있으면 일반공급 1순위는 가능하지만, 다른 특별공급 신청 불가.

## 신혼부부 특별공급 전략 (가장 유리)

### 소득 기준 (2024년 기준)

| 구분 | 공공분양 | 민간분양 |
|------|---------|---------|
| 소득 기준 | 도시근로자 월평균 130% 이하 | 140% 이하 |
| 2인 기준 | 약 650만원 이하 | 약 700만원 이하 |
| 우선공급 | 자녀 있는 경우 | 자녀 있는 경우 |

### 신혼부부 특공 당첨 순서

1. **우선공급** (자녀 있음, 소득 100% 이하) — 물량의 70%
2. **잔여공급** (자녀 없음, 소득 130% 이하) — 물량의 30%

> **전략**: 소득이 기준을 넘는다면 민간분양 일반공급(가점)으로 전환 고려.

## 생애최초 특별공급 활용법

### 요건

- 세대원 모두 **생애 처음 주택 구입**
- 혼인 중이거나 미혼 자녀 있는 경우 우선
- 소득세 납부 이력 1년 이상
- 도시근로자 월평균 소득 130% 이하

### 2023년 변경 사항

- **추첨 50%** 도입 — 소득·자산 기준 완화
- 미혼 1인 가구도 청약 가능 (도입)

## 무주택 기간 계산 주의사항

무주택 기간은 가점의 핵심. 다음에 주의하세요:

| 상황 | 무주택 기간 |
|------|-----------|
| 만 30세 이후 무주택이면 | 30세부터 기산 |
| 결혼 후 무주택이면 | 결혼일부터 기산 (더 이른 날부터) |
| 배우자가 주택 소유 시 | 무주택 인정 안 됨 |
| 소형·저가 주택 소유 시 | 일부 인정 특례 있음 |

## 청약 당첨 확률 높이는 실전 전략

### 전략 1: 경쟁률 낮은 타입 선택

- 선호 타입(84㎡ A타입)은 수백:1 경쟁
- **비인기 타입·층**: 저층, 북향, 도로변 → 경쟁률 10:1 이하
- 당첨 후 추첨 물량(추첨제)에서 기회 잡기

### 전략 2: 지역 선택 다각화

- 거주지역 우선 공급(50~100%) 이후 기타 지역 공급
- **조정대상지역 해제** 지역: 1순위 요건 완화, 경쟁률 낮을 수 있음

### 전략 3: 예비 당첨자 활용

- 당첨자 계약 포기 시 예비번호 순서대로 기회
- 청약홈에서 예비번호 확인 → 계약일정 관리 필수

### 전략 4: 추첨제 물량 노리기

- 가점 낮으면 가점제보다 **추첨제 물량** 노리기
- 85㎡ 초과 민간분양은 100% 추첨제

## 청약 시 체크리스트

**청약 전:**
- [ ] 청약통장 납입 횟수·금액 확인
- [ ] 무주택 기간 확인 (배우자 포함)
- [ ] 세대원 주택 소유 이력 확인
- [ ] 특별공급 자격 여부 확인
- [ ] 소득 기준 충족 여부 확인

**청약 당일:**
- [ ] 청약 타입·층 최종 결정
- [ ] 청약홈 접속 속도 확인 (모바일 또는 PC)
- [ ] 오전 이른 시간 신청 (서버 혼잡 피하기)

**당첨 후:**
- [ ] 당첨자 발표 날짜 확인
- [ ] 서류 준비 (무주택 확인서, 소득 증빙 등)
- [ ] 계약금 준비 (분양가의 10~20%)
- [ ] 중도금 대출 조건 사전 확인

## 청약 FAQ

**Q. 청약통장 명의 변경이 가능한가요?**
A. 배우자·직계존비속 간 증여 가능합니다. 단, 가입 기간은 그대로 승계됩니다.

**Q. 청약통장 해지 후 재가입하면?**
A. 기간이 초기화됩니다. 절대 해지하지 마세요. 금리 불만이면 납입 일시 중단으로 대응하세요.

**Q. 분양권 전매는 가능한가요?**
A. 투기과열지구는 소유권 이전등기 시까지 전매 제한. 지역·시기마다 다르므로 분양 공고문 확인 필수.

**Q. 부모님 집에 살면 무주택인가요?**
A. 본인 명의 주택이 없으면 무주택. 단, 세대원으로 합산되면 세대원 주택 소유 여부 확인 필요.

## 마무리 — 청약의 핵심 원칙

청약 성공 공식은 단순합니다: **오래된 통장 + 무주택 유지 + 부양가족**. 지금 당장 청약통장 가입이 안 됐다면 오늘 바로 개설하세요. 15년 후 가점 17점이 기다립니다.
