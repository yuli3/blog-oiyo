## TOEFL Writing 개요

| 과제 | 시간 | 특성 |
|------|------|------|
| Task 1: Integrated | 20분 | 읽기(3분) + 듣기 → 비교 요약 |
| Task 2: Academic Discussion | 10분 | 온라인 토론에 의견 추가 |
| **총계** | **29분** | 0~30점 채점 |

---

## Task 1: Integrated Writing

**형식**: 3분간 250~300단어 지문 읽기 → 강의 듣기 (강의는 항상 지문과 반대 또는 보완) → 요약 (20분, 150~225단어 권장)

**핵심 규칙**: 
- 강의 내용을 지문과 **비교하며** 정리
- 본인 의견 넣지 말 것
- 지문을 너무 많이 인용하지 말 것 (강의 중심)

### Task 1 고득점 템플릿

```
단락 1 (도입, 2~3문장):
"The reading passage discusses [주제], suggesting that [지문 핵심 주장].
However, the professor in the lecture challenges/supports these points, arguing that [강의 핵심 주장]."

단락 2 (첫 번째 포인트, 4~5문장):
"First, the reading claims that [지문 포인트 1]. 
The professor, however, contends that [강의 반박/보완 1].
According to the lecture, [구체적 설명/예시]."

단락 3 (두 번째 포인트):
"Second, the reading states that [지문 포인트 2].
The professor challenges this by pointing out that [강의 반박 2]."

단락 4 (세 번째 포인트):
"Finally, the reading argues that [지문 포인트 3].
The lecture, on the other hand, suggests that [강의 반박 3]."
```

## Task 2: Academic Discussion

**형식**: 두 학생의 의견이 이미 제시된 온라인 강의 토론에 자신의 의견 추가 (10분, 100단어 이상)

**채점 핵심**: 
- 자신만의 새로운 아이디어 제시 (기존 의견 단순 반복 금지)
- 구체적 이유와 예시
- 최소 100단어 이상

### Task 2 고득점 템플릿

```
도입 (1~2문장, 자신의 입장):
"In my view, [주장]. While both [학생1 이름] and [학생2 이름] raise valid points, I believe [자신의 핵심 주장]."

이유 + 예시 (4~5문장):
"One key reason is that [이유]. For instance, [구체적 예시]. This suggests that [함의]."

결론 또는 추가 관점 (2~3문장):
"Furthermore, [추가 아이디어]. Therefore, [최종 결론]."
```

## Writing 고득점 어휘 목록

### 지문-강의 비교 표현

| 표현 | 사용 맥락 |
|------|---------|
| contradicts | 강의가 지문 주장에 반박 |
| challenges | 강의가 지문에 의문 제기 |
| casts doubt on | 지문의 신뢰성 약화 |
| supports/confirms | 강의가 지문 보완 |
| elaborates on | 강의가 지문 내용 확장 |

### Academic Discussion 고급 표현

- "It stands to reason that..."
- "One could argue that..."
- "Empirical evidence suggests..."
- "Drawing on [경험/연구]..."

## 흔한 실수와 교정

| 실수 | 교정 |
|------|------|
| 지문 문장 그대로 복사 (copy-paste) | 반드시 paraphrase |
| 강의 요약 빠뜨림 | 강의가 핵심, 지문은 보조 |
| 너무 짧은 답변 | Task 1: 최소 150단어, Task 2: 최소 100단어 |
| 본인 의견 삽입 (Task 1) | Integrated에서는 절대 금지 |
