# 2장: 해부학적 구성 — 세포에서 기관계까지

해부학 (Anatomy)은 신체의 구조를 기술하고, 생리학 (Physiology)은 그 구조가 어떻게 기능하는지를 설명합니다. 이 두 학문은 임상 의학의 토대를 이룹니다. 어떤 기관계를 본격적으로 살펴보기 전에, 먼저 신체의 구성 위계와 해부학자들이 사용하는 공간적 언어를 이해해야 합니다.

## 해부학 용어

임상의와 해부학자는 신체를 모호함 없이 기술하기 위해 표준화된 단면, 방향, 위치 용어를 사용합니다. 모든 기술은 **해부학적 자세 (anatomical position)** — 똑바로 서서 앞을 바라보고 손바닥이 앞쪽을 향한 상태 — 를 기준으로 합니다.

**방향 용어:**
- **위쪽 / 아래쪽 (Superior / Inferior)** — 머리 쪽 / 발 쪽
- **앞쪽(복측) / 뒤쪽(배측) (Anterior, Ventral / Posterior, Dorsal)** — 앞면 / 뒷면
- **안쪽 / 가쪽 (Medial / Lateral)** — 정중선 쪽 / 정중선에서 먼 쪽
- **몸쪽 / 먼쪽 (Proximal / Distal)** — 몸통에 가까운 쪽 / 몸통에서 먼 쪽
- **얕은 / 깊은 (Superficial / Deep)** — 표면 쪽 / 내부 쪽

**해부학적 단면:**
- **시상면 (Sagittal)** — 신체를 좌우로 나누는 면
- **관상면(전두면) (Coronal, Frontal)** — 신체를 앞뒤로 나누는 면
- **횡단면(수평면) (Transverse, Axial)** — 신체를 위아래로 나누는 면

## 구조적 위계

신체는 가장 단순한 것에서 가장 복잡한 것까지 다음과 같이 구성됩니다:

1. **화학적 수준 (Chemical level)** — 원자와 분자 (물, 단백질, DNA)
2. **세포 수준 (Cellular level)** — 생명의 기본 구조 단위
3. **조직 수준 (Tissue level)** — 공통 기능을 수행하는 유사한 세포들의 집합
4. **기관 수준 (Organ level)** — 특정 기능을 수행하는 두 가지 이상의 조직
5. **기관계 수준 (Organ system level)** — 공동 목표를 위해 함께 작동하는 기관들
6. **개체 수준 (Organism level)** — 모든 계통이 통합된 살아 있는 전체

### 4대 기본 조직 유형

| 조직 | 기능 | 예시 |
|---|---|---|
| 상피 조직 (Epithelial) | 피복, 내벽 형성, 분비 | 피부 표피, 장 점막 |
| 결합 조직 (Connective) | 지지, 결합, 운반 | 뼈, 혈액, 지방 조직 |
| 근육 조직 (Muscle) | 수축과 운동 | 심근, 골격근, 평활근 |
| 신경 조직 (Nervous) | 신호 전달 | 뉴런, 신경교세포 |

## 11대 기관계

| 기관계 | 주요 기능 |
|---|---|
| 외피계 (Integumentary) | 보호, 체온 조절, 감각 |
| 골격계 (Skeletal) | 지지, 운동, 혈액 세포 생산, 무기질 저장 |
| 근육계 (Muscular) | 운동, 자세 유지, 열 생산 |
| 신경계 (Nervous) | 조절, 소통, 통합 |
| 내분비계 (Endocrine) | 대사, 성장, 생식의 호르몬 조절 |
| 심혈관계 (Cardiovascular) | 산소·영양소·호르몬 운반, 노폐물 제거 |
| 림프/면역계 (Lymphatic/Immune) | 체액 균형, 면역, 지방 흡수 |
| 호흡계 (Respiratory) | 가스 교환 (O₂/CO₂) |
| 소화계 (Digestive) | 영양소 소화 및 흡수 |
| 비뇨계 (Urinary) | 여과, 노폐물 배설, 체액/전해질 균형 |
| 생식계 (Reproductive) | 종족 유지 |

## 항상성

**항상성 (Homeostasis)** 은 외부 환경이 변화하더라도 신체 내부 환경을 안정적으로 유지하는 능력입니다. 이는 **음성 피드백 루프 (negative feedback loops)** 를 통해 이루어지며, 기준점에서 벗어난 변화가 감지되면 그것을 정상 범위로 되돌리는 교정 반응이 작동합니다 (예: 체온 조절, 혈당 조절). 양성 피드백 (positive feedback)은 변화를 증폭시키며, 분만이나 혈액 응고와 같은 특정 상황에서 사용됩니다.

### 핵심 체크리스트

- [ ] 위쪽, 안쪽, 몸쪽 등 해부학적 방향 용어를 올바르게 사용할 수 있다
- [ ] 세포 → 조직 → 기관 → 기관계로 이어지는 구조적 위계를 설명할 수 있다
- [ ] 항상성과 음성 피드백·양성 피드백 루프의 차이를 설명할 수 있다
