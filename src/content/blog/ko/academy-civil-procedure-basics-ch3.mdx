## 변론주의와 직권탐지주의

```
변론주의:
사실관계와 증거 수집을 당사자에게 맡기는 원칙
→ 민사소송의 기본 원칙

변론주의의 3원칙:
① 주요 사실은 당사자가 주장해야 재판 기초로 삼음
② 당사자가 자인(인정)한 사실은 그대로 인정
③ 증거 신청은 당사자가 해야 함

직권탐지주의:
법원이 직권으로 사실·증거 탐지
민사소송에서 예외적 적용
(가사소송·행정소송 등)

처분권주의:
소송의 개시·종결·대상을 당사자가 결정
원고가 청구한 것 이상을 법원이 줄 수 없음
```

## 준비서면

```
준비서면:
변론 준비를 위해 미리 제출하는 서면
상대방에게 주장·증거 사전 통지

기재 사항:
주장 사실, 증거 방법, 답변 내용

준비서면 미제출:
제출 안 하면 변론에서 주장 못할 수 있음
(변론 준비 절차에서 주장 시)

답변서:
피고가 소장에 대한 답변
30일 이내 제출 권고

무변론 판결:
피고가 답변서 미제출 → 자백 간주
→ 원고 청구 그대로 인용 가능
```

## 변론의 원칙

```
구술심리주의:
변론은 구술(말)로 진행
서면만으로 판결 불가 (원칙)

공개주의:
재판은 공개 (헌법상 원칙)
예외: 국가 안전·선량한 풍속 등

직접주의:
판결하는 법관이 직접 변론 참여
다른 사람이 대신 변론 들으면 안 됨

쌍방심리주의:
원고·피고 모두에게 변론 기회 부여
일방적 판결 금지
```

---

## 변론 절차

```
변론 기일:
법원이 지정한 변론 날짜

변론의 집중:
원칙: 1회 변론으로 마무리
현실: 여러 기일에 걸쳐 진행

변론 분리·병합:
분리: 여러 청구를 별개로 심리
병합: 관련 사건 하나로 심리

소송 행위:
변론 기일에 한 행위만 유효
기일 외 합의·통지는 효력 없을 수 있음

자백:
상대방의 주장 사실을 인정하는 진술
재판상 자백: 법원 앞에서 한 자백
→ 철회 제한 (착오·사기 증명 시 예외)
```

## 핵심 개념 카드

**변론주의 3원칙** ★★★★★
: 주장책임·자백구속·증거신청.
*암기 포인트: 당사자가 주장·인정·증거 제출*

**처분권주의** ★★★★★
: 소송 개시·종결·대상 당사자 결정. 청구 이상 줄 수 없음.
*암기 포인트: 처분권=당사자 주도*

**재판상 자백의 구속** ★★★★☆
: 법원 앞 자백은 철회 어려움. 착오·사기 입증해야 번복 가능.
*암기 포인트: 재판상 자백=구속력*

## 실전 퀴즈

**Q. 변론주의에서 당사자가 주장하지 않은 사실을 법원이 판결 근거로 삼을 수 있는가?**
> 변론주의 원칙상 불가. 당사자가 주장하지 않은 주요 사실은 법원이 판결 기초로 삼을 수 없음. 단, 공지의 사실, 법률 규정은 당사자 주장 없어도 법원이 적용 가능.

**Q. 무변론 판결이 내려지는 상황은?**
> 피고가 답변서를 제출하지 않아 원고 주장을 다투지 않는 경우. 법원은 변론 없이 원고 승소 판결 가능. 다만, 소장 내용이 합리적이고 공서양속에 반하지 않아야 함.
