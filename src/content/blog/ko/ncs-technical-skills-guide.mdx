NCS 기술능력은 직장에서 사용하는 기술을 이해하고, 적절히 활용하며, 더 나은 방향으로 개발·개선하는 능력을 다룹니다. 출제 비중은 약 **10%** (50점 기준 5문항). 기술 개념부터 특허·산업재산권, 기술혁신, 산업재해까지 폭넓게 출제됩니다.

## 1. 기술의 개념과 분류

### 기술(Technology)이란?

기술은 **인간이 자연을 변형하여 인간의 필요를 충족시키기 위해 사용하는 지식·도구·방법의 총체**입니다.

**기술의 특성**:
- **체계성**: 단편적 지식이 아닌 체계적·조직적 지식
- **목적성**: 인간의 필요 충족을 목적으로 함
- **사회성**: 사회적 맥락 속에서 발전
- **누적성**: 이전 기술 위에 새 기술이 축적됨

### 기술의 유형

| 유형 | 내용 | 예시 |
|------|------|------|
| **암묵적 기술(Tacit)** | 언어화·문서화 어려운 노하우 | 장인의 기술, 요리 감각 |
| **명시적 기술(Explicit)** | 문서·매뉴얼로 표현 가능 | 설계도면, 레시피 |
| **제품 기술** | 제품에 내재된 기술 | 반도체 설계, 신약 성분 |
| **공정 기술** | 생산·제조 방법에 관한 기술 | 제조 공정, 품질관리 기법 |

### 기술 선택 기준 (적정기술)

**적정기술(Appropriate Technology)**: 해당 지역·사회의 자원·환경·문화적 특성에 맞는 기술. 최첨단보다 지속가능성·접근성을 우선.

기술 선택 시 고려 요소:
- **경제성**: 비용 대비 효과
- **실현 가능성**: 현재 기술 수준에서 구현 가능한가
- **안전성**: 사용자 안전 보장
- **환경성**: 환경 영향 최소화

## 2. 산업재산권 (지식재산권)

### 지식재산권 체계

```
지식재산권
├── 산업재산권 (특허청 등록)
│   ├── 특허권
│   ├── 실용신안권
│   ├── 디자인권
│   └── 상표권
└── 저작권 (문화체육관광부, 창작 시 자동발생)
```

### 산업재산권 비교 ⭐ 빈출

| 종류 | 보호 대상 | 존속 기간 | 특징 |
|------|---------|---------|------|
| **특허권** | 고도의 기술적 창작 | 출원일로부터 **20년** | 심사주의, 물·방법 발명 |
| **실용신안권** | 물품의 형상·구조·조합 | 출원일로부터 **10년** | 소발명, 특허보다 낮은 창작성 |
| **디자인권** | 물품의 외관 (심미성) | 등록일로부터 **20년** | 형상·모양·색채 |
| **상표권** | 상품·서비스 식별 표지 | 등록일로부터 **10년** (갱신 가능) | 반복 갱신으로 영구 존속 가능 |

**저작권**: 소설·음악·그림 등 문화적 창작물 보호. 저작자 사망 후 **70년** 존속.

> **시험 포인트**: 특허·실용신안 = 출원일 기준 / 디자인·상표 = 등록일 기준

### 특허 요건

| 요건 | 내용 |
|------|------|
| **신규성** | 출원 전에 공개된 적 없을 것 |
| **진보성** | 당업자가 용이하게 발명할 수 없을 것 |
| **산업상 이용가능성** | 산업에 활용 가능할 것 |

**특허받을 수 없는 것**: 자연법칙·자연현상 자체, 단순한 발견, 공공질서에 반하는 발명

## 3. 기술혁신

### 기술혁신의 유형

**점진적 혁신(Incremental Innovation)**:
- 기존 기술을 개선·개량
- 낮은 위험, 안정적 수익
- 예: 스마트폰 카메라 성능 개선

**급진적 혁신(Radical Innovation)**:
- 완전히 새로운 기술 개발
- 높은 위험, 시장 파괴 가능
- 예: 스마트폰 자체의 등장 (피처폰 대체)

### 기술혁신의 S-곡선 (Foster, 1986)

```
성능
│         ___________
│       /
│      /
│    /
│   /
│__/
└─────────────────── 기술투자
```

- **도입기**: 투자 대비 성능 향상 느림
- **성장기**: 투자 대비 성능 급격 향상
- **성숙기**: 한계에 도달, 성능 향상 둔화
- **다음 S-곡선**: 새로운 기술로 전환 필요

### 기술수명주기 (기술 도입 단계)

| 단계 | 특징 |
|------|------|
| **기초연구** | 원천기술 개발, 장기 투자 |
| **응용연구** | 상업화 가능성 검토 |
| **개발연구** | 시제품 개발 |
| **기술이전** | 기업에 기술 이전 |
| **상업화** | 제품·서비스 출시 |

### 파괴적 혁신 (Disruptive Innovation, 크리스텐슨)

기존 주류 시장을 파괴하는 혁신:
- 초기에는 저성능·저가로 틈새시장 진입
- 점차 성능 향상으로 주류 시장 대체
- 예: 디지털카메라(→필름카메라 대체), 스트리밍(→DVD 대체)

## 4. 기술 적용 능력 — 산업재해 예방

### 산업재해의 정의

**산업재해**: 근로자가 업무에 관계되는 건설물·설비·원재료·가스·증기·분진 등에 의하거나 작업 또는 그 밖의 업무로 인해 사망·부상 또는 질병에 걸리는 것 (산업안전보건법 제2조)

### 하인리히 법칙 (1:29:300)

버드(Bird)·하인리히의 재해 연쇄 이론:

**1 : 29 : 300**
- 중대재해 1건 발생 → 경상해 29건 → 아차사고(Near-miss) 300건

**의미**: 하나의 큰 사고 이면에는 수많은 경미한 사고와 아차사고가 있다 → 아차사고 단계에서 예방해야 함

### 재해의 직접·간접 원인

| 구분 | 내용 | 예시 |
|------|------|------|
| **직접원인 — 불안전한 행동** | 사람의 부적절한 행동 | 안전장비 미착용, 규정 위반 |
| **직접원인 — 불안전한 상태** | 환경·설비의 위험 상태 | 결함 있는 기계, 불량 조명 |
| **간접원인 — 기술적** | 설계·제조·설치 문제 | 기계 설계 결함 |
| **간접원인 — 교육적** | 안전 교육 부족 | 작동법 미숙지 |
| **간접원인 — 관리적** | 조직·제도 문제 | 안전 수칙 미비 |

### 안전 관리 원칙 — STOP

| 단계 | 내용 |
|------|------|
| **S**top | 위험 상황 인지 시 즉시 중지 |
| **T**hink | 위험 요소 분석·판단 |
| **O**bserve | 주변 환경 재확인 |
| **P**roceed | 안전 확인 후 작업 재개 |

### 산업재해 지수

**재해율**: (재해자 수 ÷ 근로자 수) × 100

**도수율(빈도율, FR)**: (재해 건수 ÷ 연 근로시간 수) × 1,000,000
→ 100만 근로시간당 재해 건수

**강도율(SR)**: (근로 손실 일수 ÷ 연 근로시간 수) × 1,000
→ 1,000 근로시간당 손실 일수

## 5. 기술 문서 이해

### 기술 문서의 종류

| 종류 | 내용 |
|------|------|
| **매뉴얼(Manual)** | 제품·장비 사용 설명 |
| **규격서(Specification)** | 제품·서비스 요구 사항 기술 |
| **작업표준서** | 작업 방법·순서·기준 기술 |
| **보고서(Report)** | 기술적 발견·결과 기술 |

### 도면 읽기 기초

- **정면도**: 물체를 앞에서 본 모양
- **측면도**: 옆에서 본 모양
- **평면도**: 위에서 본 모양

**투상도**: 3D 물체를 2D 도면으로 표현하는 방법. 공기업 NCS에서 도면 해석 문제 출제.

## 실전 문제

### 문제 1

> 다음 중 특허권에 관한 설명으로 옳은 것은?
>
> ① 물품의 외관 디자인을 보호한다
> ② 출원일로부터 10년간 존속한다
> ③ 고도의 기술적 창작물로, 출원일로부터 20년간 존속한다
> ④ 등록일로부터 10년간 존속하며, 갱신이 가능하다

**풀이**: ①은 디자인권, ②·④는 실용신안권·상표권. 특허권은 **출원일로부터 20년** 존속.

**정답**: ③

### 문제 2

> 하인리히 법칙에서 중대재해 1건과 관련된 아차사고의 수는?
>
> ① 29건
> ② 100건
> ③ 300건
> ④ 1,000건

**정답**: ③

## 핵심 요약

```
기술 유형:   암묵적↔명시적, 제품↔공정
산업재산권:  특허(20년/출원), 실용신안(10년/출원)
             디자인(20년/등록), 상표(10년 갱신/등록)
하인리히:    1:29:300 — 아차사고 300건이 대재해 1건의 배경
기술혁신:    점진적↔급진적, S-곡선, 파괴적 혁신
```

---

기술능력은 단순히 기계를 다루는 능력이 아닙니다. 기술이 어떻게 탄생하고(혁신), 어떻게 보호되며(지식재산권), 어떻게 안전하게 활용되는가(산업재해 예방)를 이해하는 것이 현대 직장인의 기본 소양입니다. 공기업 시험에서도, 실제 업무에서도 기술을 이해하고 올바르게 활용하는 능력은 점점 중요해지고 있습니다.
