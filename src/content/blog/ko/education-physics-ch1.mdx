## 물리학이란?

```
물리학의 정의:
→ 자연 현상의 근본 법칙을 수학적으로 기술하는 학문
→ 관측 → 가설 → 실험 → 이론의 과학적 방법

물리학의 주요 분야:
→ 역학 (Mechanics): 힘과 운동
→ 열역학 (Thermodynamics): 열과 에너지
→ 전자기학 (Electromagnetism): 전기와 자기
→ 광학 (Optics): 빛의 성질
→ 현대 물리: 양자역학, 상대성 이론

SI 기본 단위:
→ 길이: m (미터)
→ 질량: kg (킬로그램)
→ 시간: s (초)
→ 전류: A (암페어)
→ 온도: K (켈빈)
```

## 벡터와 스칼라

```
스칼라 (Scalar): 크기만 있는 물리량
→ 온도, 질량, 시간, 에너지, 속력

벡터 (Vector): 크기와 방향 모두 있는 물리량
→ 변위, 속도, 가속도, 힘, 운동량

벡터의 표현:
→ 기호: 굵은 v, 화살표 v̄, 성분 (vx, vy, vz)

벡터 덧셈:
→ 성분별 덧셈: (ax+bx, ay+by)
→ 합력 크기: |R| = √(Rx² + Ry²)
→ 방향: θ = arctan(Ry/Rx)

단위 벡터:
→ i (x방향), j (y방향), k (z방향)
→ v = vx·i + vy·j + vz·k
```

## 운동학 (Kinematics)

```
기본 개념:
→ 위치 (x): 기준점으로부터의 거리
→ 변위 (Δx): 위치 변화량 (방향 있음)
→ 거리: 이동한 경로 총 길이 (방향 없음)

속도와 속력:
→ 평균 속도: v_avg = Δx/Δt
→ 순간 속도: v = dx/dt (미분)
→ 속력: 속도의 크기 (스칼라)

가속도:
→ 평균 가속도: a_avg = Δv/Δt
→ 순간 가속도: a = dv/dt

등속 운동:
→ a = 0, v = 일정
→ x = x₀ + v·t

등가속 운동 (균일 가속도):
→ v = v₀ + a·t
→ x = x₀ + v₀t + (1/2)a·t²
→ v² = v₀² + 2a·Δx
→ x = x₀ + (v₀+v)/2 · t
```

## 2차원 운동

```
포물체 운동 (발사체):
→ x방향: 등속 (ax = 0)
  vx = v₀cosθ
  x = v₀cosθ · t
→ y방향: 등가속 (ay = -g = -9.8 m/s²)
  vy = v₀sinθ - g·t
  y = v₀sinθ·t - (1/2)g·t²

최대 높이:
→ vy = 0일 때: H = (v₀sinθ)² / 2g

수평 사거리:
→ R = v₀²sin(2θ) / g
→ 최대 사거리: θ = 45°

등속 원운동:
→ 속력은 일정, 방향 변화 → 가속도 존재
→ 구심 가속도: a = v²/r (원 중심 방향)
→ 구심 힘: F = mv²/r
→ 주기: T = 2πr/v
```

## 뉴턴의 운동 법칙

```
제1법칙 — 관성의 법칙:
→ 외력이 없으면 정지 물체는 정지, 운동 물체는 등속 직선 운동
→ 관성 (Inertia): 운동 상태를 유지하려는 성질
→ 질량 ∝ 관성의 크기

제2법칙 — 가속도의 법칙:
→ F = ma
→ 합력(net force) = 질량 × 가속도
→ a = F_net / m
→ 단위: N = kg·m/s²

제3법칙 — 작용·반작용 법칙:
→ 물체 A가 B에 힘 가하면, B도 A에 같은 크기 반대 방향 힘
→ F_AB = -F_BA
→ 작용·반작용 쌍은 항상 다른 물체에 작용 (상쇄 불가)
```

## 힘의 종류

```
중력 (Gravity):
→ 지구 표면: W = mg (g ≈ 9.8 m/s²)
→ 만유인력: F = G·m₁m₂/r²
  G = 6.67×10⁻¹¹ N·m²/kg²

수직항력 (Normal Force):
→ 표면이 물체에 수직으로 미치는 힘
→ 수평면 위 정지 물체: N = mg
→ 경사면 위: N = mgcosθ

마찰력 (Friction):
→ 정지 마찰력: f_s ≤ μ_s · N
→ 운동 마찰력: f_k = μ_k · N
→ 일반적으로 μ_s > μ_k
→ 마찰 계수는 표면 재질에 따라 결정

장력 (Tension):
→ 줄, 로프에서 당기는 힘
→ 이상적 줄: 질량 무시, 모든 점에서 동일 장력
```

## 자주 묻는 질문

**Q. 무게와 질량의 차이는 무엇인가요?**
A. 질량(mass)은 물질의 양으로 어디서나 같습니다(단위: kg). 무게(weight)는 중력이 물체에 작용하는 힘으로 W=mg입니다(단위: N). 달에서는 중력가속도 g가 지구의 약 1/6이므로 무게가 1/6이 되지만 질량은 변하지 않습니다.

**Q. 뉴턴 제3법칙에서 작용·반작용은 왜 상쇄되지 않나요?**
A. 작용·반작용은 서로 다른 물체에 작용하기 때문입니다. 예를 들어 사람이 바닥을 밀면(사람→바닥), 바닥도 사람을 밀지만(바닥→사람) 이 두 힘은 다른 물체에 작용합니다. 상쇄되려면 같은 물체에 작용해야 합니다.
