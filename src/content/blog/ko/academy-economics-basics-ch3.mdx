## 효용 개념

```
효용 (Utility): 재화·서비스 소비로 얻는 만족감

총효용 (Total Utility, TU):
- 일정량 소비 시 얻는 총 만족감
- 소비량 증가 → 총효용 증가 (감소 속도 체감)

한계효용 (Marginal Utility, MU):
- 재화 1단위 추가 소비 시 증가하는 효용
- MU = ΔTU / ΔQ

한계효용 체감의 법칙:
소비량 증가 → 한계효용 감소
(처음 먹는 피자 조각 > 5번째 피자 조각)
```

## 한계효용 균등의 법칙

```
소비자 최적 선택 조건:
MUx / Px = MUy / Py

= 1원당 한계효용을 균등화

해석:
모든 재화의 마지막 1원당 한계효용이 동일하면
효용 극대화 달성

예시:
MUx/Px = 3, MUy/Py = 2
→ X재 구매 늘리고, Y재 줄이면 효용 증가
→ 균형은 MUx/Px = MUy/Py 도달 시
```

---

## 무차별곡선 (Indifference Curve)

```
무차별곡선: 동일한 효용을 주는 X·Y 재화 조합의 궤적

특성:
① 우하향: X 늘리면 Y 줄여야 동일 효용
② 볼록 (원점): 한계대체율 체감 반영
③ 교차 불가: 이행성 위반
④ 원점에서 멀수록 높은 효용

한계대체율 (MRS):
MRS = MUx / MUy = ΔY/ΔX (무차별곡선 기울기 절댓값)
→ X 1단위 추가 시 포기하는 Y의 양

한계대체율 체감:
X 소비 늘릴수록 MRS 감소 (무차별곡선 볼록 이유)
```

## 예산제약선 (Budget Line)

```
예산제약선: 주어진 소득(M)과 가격(Px, Py)으로
구입 가능한 X·Y 조합의 경계

M = Px·X + Py·Y
→ Y = M/Py - (Px/Py)·X

기울기 = -Px/Py (상대가격)

예산제약선 이동:
- 소득 증가: 평행 이동 (오른쪽 위)
- Px 하락: X축 절편 증가 (오른쪽 회전)
```

## 소비자 균형

```
소비자 균형 조건:
무차별곡선과 예산제약선의 접선점

접선 조건:
MRS = Px/Py
MUx/MUy = Px/Py
→ MUx/Px = MUy/Py (한계효용 균등 원칙과 동일)

가격 변화 효과:
- 대체 효과: 상대가격 변화 → X·Y 대체
- 소득 효과: 실질소득 변화 → 소비 전반 변화

정상재: 소득 효과(+) → 가격 하락 → 소비 증가
열등재: 소득 효과(-) → 가격 하락 → 소비 증가 (대체 효과 우위)
기펜재(Giffen): 소득 효과(-) > 대체 효과 → 가격 하락 → 소비 감소
```

---

## 핵심 개념 카드

**한계효용 균등 원칙** ★★★★★
: MUx/Px = MUy/Py. 1원당 한계효용이 같을 때 효용 극대화.
*암기 포인트: 1원당 MU 균등화 = 최적 소비*

**무차별곡선 특성** ★★★★★
: 우하향·볼록·교차불가·원점 멀수록 고효용. 기울기 = MRS = MUx/MUy.
*암기 포인트: 무차별=우하향+볼록+교차불가*

**기펜재 조건** ★★★★☆
: 열등재이면서 소득 효과가 대체 효과보다 큼. 가격 하락 → 수요 감소 (수요 법칙 예외).
*암기 포인트: 기펜재=열등재+소득효과>대체효과*

## 실전 퀴즈

**Q. MUx = 12, Px = 4, MUy = 6, Py = 2일 때 소비자는 어떻게 조정해야 하는가?**
> MUx/Px = 12/4 = 3, MUy/Py = 6/2 = 3. 균형 상태. 조정 불필요.

**Q. 무차별곡선이 원점에 볼록한 이유는?**
> 한계대체율 체감의 법칙 때문. X재를 더 많이 가질수록 X재의 한계효용이 하락, Y재의 한계효용이 상승 → MRS = MUx/MUy 감소 → 기울기 감소 → 볼록.
