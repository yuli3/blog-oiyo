## 행정개혁의 의의

```
행정개혁:
정부 기능·구조·과정을 의도적으로 변화시키는 것

행정개혁의 접근:
구조적 접근: 조직 구조 변경 (부처 통폐합, 지방분권)
기능적 접근: 업무 방식 변경 (규제 완화, 민간 위탁)
행태적 접근: 공무원 의식·행동 변화 (문화 혁신)
기술적 접근: ICT 도입 (전자정부)

개혁 저항:
기득권 상실 우려, 불확실성, 변화 거부감
극복: 참여, 교육, 점진적 실행
```

## 신공공관리론 (NPM)

```
등장 배경:
1980년대 영미 복지국가 위기
작은 정부·효율적 정부 추구

핵심 내용:
① 시장 원리 도입: 경쟁, 성과 연봉
② 민간 위탁: 공공 서비스 민영화
③ 고객 지향: 시민=서비스 수요자
④ 성과 관리: 목표·결과 기준 평가
⑤ 규제 완화: 정부 규제 축소

대표 국가:
영국 (대처 정부), 미국 (레이건 정부)
뉴질랜드, 오스트레일리아 (대규모 개혁)

NPM 한계:
공공성·형평성 약화
시장 실패 → 재정부화 필요
책임 소재 불명확
복잡한 사회 문제 해결 한계
```

## 뉴거버넌스

```
거버넌스:
정부·시민사회·시장이 함께 문제 해결
네트워크, 파트너십, 협력

특징:
① 네트워크 조정: 수직적 명령 → 수평적 협력
② 참여: 시민·NGO·기업 의사결정 참여
③ 협력: 공동 서비스 생산
④ 유연성: 환경 변화에 적응

뉴거버넌스 vs NPM:
NPM: 정부→민간 (경쟁·시장)
거버넌스: 정부+민간+시민사회 (협력·네트워크)

협력적 거버넌스 한계:
책임 불명확, 의사결정 지연
참여 불균형 (강한 집단 우위)
```

## 전자정부

```
전자정부:
ICT를 활용해 행정 서비스를 효율적으로 제공하는 정부

발전 단계:
1단계: 정보 제공 (단방향: 정부→국민)
2단계: 상호작용 (쌍방향: 민원 문의)
3단계: 트랜잭션 (온라인 민원 처리)
4단계: 통합 (부처 간 연계, 원스톱 서비스)

한국 전자정부:
정부24 (민원 통합 포털)
전자조달 (나라장터)
공공데이터 개방 (data.go.kr)

행정 정보화 효과:
행정 효율성↑, 비용 절감
부패 감소 (대면 접촉 줄임)
국민 접근성 향상

디지털 격차:
고령층·저소득층·장애인 디지털 접근 불평등
→ 디지털 포용 정책 필요
```

## 핵심 개념 카드

**NPM 핵심 특징** ★★★★★
: 시장원리·민간위탁·성과관리·고객지향. 효율성 강조, 공공성 약화.
*암기 포인트: NPM=시장+성과+고객*

**뉴거버넌스** ★★★★★
: 정부+시민사회+시장 네트워크 협력. NPM의 한계 극복 시도.
*암기 포인트: 거버넌스=협력 네트워크*

**전자정부 발전 4단계** ★★★★☆
: 정보제공→상호작용→트랜잭션→통합.
*암기 포인트: 정상트통*

## 실전 퀴즈

**Q. 민간 위탁 확대의 장단점은?**
> 장점: 비용 절감, 전문성 활용, 경쟁을 통한 효율 향상. 단점: 공공성 약화, 책임 소재 불명확, 저임금·불안정 고용 문제, 수익성 낮은 서비스는 민간이 기피.

**Q. 디지털 격차가 전자정부의 한계가 되는 이유는?**
> 전자정부는 인터넷·스마트폰 기반이라 이를 활용 못하는 고령층·장애인·저소득층은 행정 서비스 접근에 불이익. 전자정부 전환이 오히려 취약계층 배제 심화시킬 수 있음.
