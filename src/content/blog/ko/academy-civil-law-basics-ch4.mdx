## 계약의 성립

**계약**: 청약과 승낙이라는 두 의사표시의 합치로 성립하는 법률행위.

```
계약 성립 과정:
청약 ──────────────────→ 상대방
     ←─── 승낙 ─────────
     = 계약 성립 (양 의사표시 합치)
```

**청약의 구속력**: 청약자는 청약 후 일방적으로 철회 불가 (승낙 기간 내).  
**승낙 적격 기간**: 청약에 기간이 있으면 그 기간 내, 없으면 상당 기간 내 승낙.

## 계약의 효력

### 동시이행 항변권 (민법 제536조)

쌍무계약에서 상대방이 이행 전 내 이행을 거절할 수 있는 권리.

```
요건:
① 쌍무계약에서 발생한 대가관계 채무
② 상대방이 자기 채무를 이행하지 않음
③ 자기 채무의 이행기가 도래

효과: 이행을 거절해도 이행지체 책임 없음
```

**매매 계약 예시**: 매도인은 잔금 지급 전까지 소유권 이전 등기 의무 거절 가능.

### 위험부담 (민법 제537조)

쌍무계약에서 한쪽 채무가 채무자 귀책 없이 불능된 경우 상대방 채무도 소멸.

```
위험부담 원칙: 채무자 위험부담
예외: 채권자 귀책 + 특정물 + 이행제공 후 수령지체 → 채권자 위험부담
```

## 계약의 해제와 해지

### 계약 해제 (소급 효력)

```
법정해제: 이행지체(최고 후) 또는 이행불능(즉시)
약정해제: 계약에서 정한 사유 발생 시

효과:
- 소급적 소멸 → 이미 이행한 급부 원상회복
- 원상회복: 수령한 것은 반환 + 이자 또는 사용이익 반환
```

**해제와 손해배상**: 해제 + 손해배상 청구 가능 (민법 제551조).

### 계약 해지 (장래 효력)

계속적 계약(임대차, 고용, 위임)에서 장래를 향해 계약 소멸.  
이미 이행된 부분은 원상회복 불요.

## 주요 전형계약

### 매매 계약

```
매매 계약:
매도인 의무: ① 소유권 이전, ② 인도
매수인 의무: 대금 지급

하자담보책임:
- 매도인이 하자 없음을 보증
- 매수인이 계약 목적 달성 불가: 해제 가능
- 목적 달성 가능하면: 손해배상만
- 안 날로부터 6개월 내 행사
```

### 임대차 계약

```
임대인 의무:
- 임차물 사용·수익 가능 상태로 인도
- 수선 의무 (통상적 수선)
- 임차인 평온 사용 보장

임차인 의무:
- 차임 지급
- 선량한 관리자의 주의로 보관
- 계약 또는 관행에 좇아 사용
- 계약 종료 시 반환 (원상회복)
```

**임차권 양도·전대**: 임대인 동의 필요. 무단 전대 시 해지 사유.

### 도급 계약

```
도급: 일의 완성을 목적으로 하는 계약
수급인: 일을 완성하고 보수 청구
도급인: 일의 완성 후 보수 지급

수급인의 하자담보책임:
- 건물·공작물: 5년 (토석·금속 10년)
- 일반 하자: 1년
```

### 위임 계약

```
위임: 사무 처리를 맡기는 계약
수임인: 위임인을 위해 사무 처리 (선관의무)
보수: 특약 없으면 무보수 원칙

임의 해지 가능 (각 당사자 언제든지)
불리한 시기 해지 → 손해배상 책임
```

## 부당이득과 불법행위

### 부당이득 (민법 제741조)

법률상 원인 없이 타인의 재산·노무로 이익을 얻고 손해를 입힌 경우.

```
요건:
① 이득
② 손실
③ 이득과 손실 간 인과관계
④ 법률상 원인 없음

효과: 이익의 반환 의무
      선의 수익자: 현존 이익만 반환
      악의 수익자: 전부 반환 + 이자
```

### 불법행위 (민법 제750조)

```
일반 불법행위 요건:
① 고의 또는 과실
② 위법한 행위
③ 손해 발생
④ 행위와 손해 간 인과관계

특수 불법행위:
- 사용자 책임 (피용자 행위)
- 공작물 책임 (점유자·소유자)
- 동물 점유자 책임
```

## 핵심 개념 카드

**동시이행 항변권** ★★★★★
: 쌍무계약에서 상대방이 이행하지 않으면 내 이행을 거절할 수 있는 권리. 이행지체 책임 없음.
*암기 포인트: 너 먼저 이행해야 나도 이행 — 동시이행*

**하자담보책임 기간** ★★★★★
: 매매 — 안 날로부터 6개월. 도급 — 건물 5년(토석·금속 10년), 일반 1년.
*암기 포인트: 매매 6개월, 건물 도급 5년*

**해제 vs 해지** ★★★★☆
: 해제 = 소급 소멸(원상회복). 해지 = 장래 소멸(이행분 유지). 임대차 중도 종료는 해지.
*암기 포인트: 해제=소급, 해지=장래*

## 실전 퀴즈

**Q. 매매 대금 지급 의무와 소유권 이전 의무는 동시이행 관계인가?**
> 네. 쌍무계약의 대가 관계 → 동시이행 항변권 성립. 매도인은 잔금 수령 전까지 등기 이전 거절 가능.

**Q. 수급인이 완성한 건물에 하자가 있을 때 도급인의 권리는?**
> 하자 보수 청구 → 불이행 시 손해배상. 하자로 계약 목적 달성 불능이면 해제도 가능. 단 5년(목조 2년) 제척기간.
