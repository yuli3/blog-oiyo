## PEST 거시환경 분석

```
Political (정치·법률):
규제·법률 변화
정부 정책·세금
무역 장벽

Economic (경제):
경기 순환·성장률
금리·환율·인플레이션
소비자 구매력

Social (사회·문화):
인구통계 변화
라이프스타일 트렌드
문화적 가치관

Technological (기술):
기술 혁신 속도
디지털 전환
R&D 투자 동향
```

## SWOT 분석

```
내부 요인:
S (Strengths): 강점 — 경쟁우위 원천
W (Weaknesses): 약점 — 개선 필요 영역

외부 요인:
O (Opportunities): 기회 — 활용 가능한 환경 변화
T (Threats): 위협 — 대응 필요한 위험

전략 매트릭스:
SO: 강점으로 기회 활용
ST: 강점으로 위협 극복
WO: 기회로 약점 보완
WT: 약점+위협 최소화
```

## Porter 5 Forces

```
산업 수익성 결정 요인:

기존 경쟁자:
경쟁 강도·집중도
차별화 수준

신규 진입 위협:
진입장벽 (규모의 경제·브랜드·자본)

대체재 위협:
대체 가능한 타 업종 제품

구매자 교섭력:
집중도·전환비용·정보력

공급자 교섭력:
공급자 집중도·대체 공급원
```

## 경쟁자 분석

```
경쟁자 유형:
브랜드 경쟁자: 유사 제품 동일 고객
산업 경쟁자: 동일 산업 내
일반 경쟁자: 동일 예산 경쟁
소망 경쟁자: 고객의 모든 지출 경쟁

벤치마킹:
최우수 경쟁자 프랙티스 학습
성능 격차 분석 → 개선

경쟁 전략 (Porter):
원가우위: 낮은 비용으로 표준 제품
차별화: 독특한 가치로 프리미엄
집중: 특정 세분 시장 집중
```

## 실전 퀴즈

**Q. SWOT 분석에서 WO 전략이란?**
> 약점(W)+기회(O) 전략: 외부 기회를 통해 내부 약점 보완. 예: 기술력 부족한 기업 → 기술 발전 트렌드 시 파트너십·인수합병으로 약점 극복. 자원 없는 스타트업이 시장 확장기에 전략적 제휴로 성장하는 것도 WO 전략.

**Q. 구매자 교섭력이 높아지는 조건은?**
> 구매자 집중: 소수의 대형 고객. 낮은 전환비용: 공급자 교체 쉬움. 구매자 정보력: 가격·품질 정보 풍부. 대체재 많음: 다른 공급자로 이동 가능. 역방향 통합 위협: 구매자가 직접 생산 가능. 반대 조건이면 공급자 교섭력 높아짐.
