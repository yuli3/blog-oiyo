## 대통령의 지위

```
대통령의 이중 지위:
① 국가 원수: 대외적으로 국가 대표
② 행정부 수반: 행정권 총괄 집행

임기·선출:
- 임기: 5년 단임
- 선거: 직선 (국민 직접 선출)
- 결선 투표 없음: 1위 후보 당선

피선거권 요건:
- 국내 거주 40세 이상 국민
```

## 대통령의 권한

### 행정에 관한 권한

```
법령 집행권:
- 법률 공포 및 집행

행정 입법권:
- 대통령령 (시행령): 법률 위임 또는 집행 필요 시
- 총리령·부령: 대통령 위임

임면권:
- 국무총리 임명 (국회 동의)
- 행정각부 장관 임명
- 대법관·헌법재판관 일부 임명
```

### 비상적 권한

```
긴급명령 (헌법 제76조 제2항):
- 전시·사변·이에 준하는 비상 사태
- 국가 안위를 위하여 긴급 조치 필요 시
- 법률의 효력 갖는 명령 발할 수 있음
- 지체 없이 국회 승인 (부결 시 효력 상실)

긴급재정경제명령 (헌법 제76조 제1항):
- 내우·외환·천재지변 또는 중대 재정·경제 위기
- 대통령령으로 재정·경제 조치
- 국회 승인 필요

계엄 (헌법 제77조):
- 비상계엄: 군사 법원 관할 확대, 영장·집회·언론 제한 가능
- 경비계엄: 군사 관련 사항 관할
- 국회 재적 과반수 찬성 → 계엄 해제 요구 가능
```

### 사면권

```
사면:
- 일반사면: 범죄 종류 지정, 국무회의 심의+국회 동의
- 특별사면: 특정인 지정, 국무회의 심의 (국회 동의 불필요)

감형: 형량 경감
복권: 자격 회복

사면권 행사 한계:
- 헌법 제79조: 일반사면 → 국회 동의
- 내란·외환죄 수괴 사면 금지 (헌법 비명문 논의)
```

## 행정부 구성

### 국무총리

```
지위:
- 대통령 보좌 + 행정 각부 통할 (감독)
- 대통령 유고 시 권한 대행 (1순위)

임명:
- 대통령이 임명하되 국회 동의 필요

권한:
- 국무위원 임면 제청 (제안)
- 부령 발령
- 국무회의 부의장

해임:
- 국회 해임 건의 → 법적 구속력 없음
- 대통령이 해임 결정
```

### 국무회의

```
지위: 최고 심의 기관 (의결기관 아님)
구성: 대통령 (의장) + 국무총리 (부의장) + 국무위원 15–30인

심의 사항 (필수적 심의):
- 헌법 개정안·법률안·대통령령
- 예산안·결산·국채
- 선전포고·강화·조약 체결
- 계엄 선포·해제
- 사면·감형·복권

특징:
- 심의 기관이므로 의결 결과가 대통령을 구속하지 않음
```

## 행정 입법

```
법규명령 (국민 구속력 있음):
① 대통령령: 헌법 제75조 (구체적 위임 필요)
② 총리령·부령: 헌법 제95조

포괄 위임 금지 원칙:
- 법률이 구체적으로 범위 정해야 위임 가능
- 백지 위임 = 위헌

행정규칙 (행정 내부):
- 훈령·예규·지침·고시
- 국민에게 직접 법적 구속력 없음
- 반복 적용 시 행정관행 형성 → 법원성 인정 논의
```

## 핵심 개념 카드

**대통령 임기·단임** ★★★★★
: 5년 단임. 재임 불가. 임기 연장 또는 중임 허용 개정은 개정 당시 대통령에게 적용 불가.
*암기 포인트: 5년 단임 = 재임 불가*

**긴급명령 vs 계엄** ★★★★★
: 긴급명령=법률 효력 명령, 국회 승인. 비상계엄=군사법원 확대+기본권 제한, 국회 해제 요구 가능.
*암기 포인트: 긴급명령=법률효력, 계엄=군사통치*

**국무회의 심의 의무** ★★★★☆
: 헌법 제89조 열거 사항은 반드시 국무회의 심의 거쳐야 함. 심의만, 대통령 구속 안 함.
*암기 포인트: 국무회의=심의기관(의결아님)*

## 실전 퀴즈

**Q. 대통령이 국무총리를 임명할 때 필요한 절차는?**
> 국회의 동의 필요. 국회 인사청문회 후 동의 의결.

**Q. 비상계엄을 해제할 수 있는 국회의 권한은?**
> 국회 재적의원 과반수 찬성으로 계엄 해제 요구 가능. 대통령은 즉시 해제해야 함(헌법 제77조 제5항).
