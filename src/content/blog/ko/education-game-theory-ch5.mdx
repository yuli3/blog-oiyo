## 진화적 안정 전략 (ESS)

생물학적 진화와 게임이론의 결합 — 존 메이너드 스미스의 개념:

<LectureTable
  title="매-비둘기 게임 — 진화적 안정 전략"
  headers={["전략", "상대 매", "상대 비둘기", "특성"]}
  rows={[
    ["매 (공격)", "둘 다 부상 (-25, -25)", "자원 독점 (+50, 0)", "공격적, 고위험"],
    ["비둘기 (회피)", "양보 (0, +50)", "자원 반분 (+15, +15)", "소극적, 저위험"],
  ]}
  highlightColumns={[1, 2]}
/>

```
진화적 안정 전략 (ESS):
→ 개체군에 침입자 전략이 퍼질 수 없는 상태
→ 매만 있는 집단: 비둘기 침입 가능 (평화적 비둘기 = 고수익)
→ 비둘기만 있는 집단: 매 침입 가능 (공격적 매 = 독점)
→ 혼합 ESS: 매 비율 p*, 비둘기 비율 (1-p*) 공존

현실 응용:
→ 종간 경쟁의 공존 설명
→ 조직 내 강경파 vs 온건파 비율
→ 시장의 공격적 vs 방어적 기업 균형
```

## 투표 역설과 정치 게임이론

<LectureTable
  title="투표 역설 — 콩도르세의 역설"
  headers={["유권자", "1순위", "2순위", "3순위"]}
  rows={[
    ["유권자 A (1/3)", "정책 X", "정책 Y", "정책 Z"],
    ["유권자 B (1/3)", "정책 Y", "정책 Z", "정책 X"],
    ["유권자 C (1/3)", "정책 Z", "정책 X", "정책 Y"],
  ]}
  highlightColumns={[1]}
/>

```
다수결 비교:
X vs Y → X 승 (A+C 선호)
Y vs Z → Y 승 (A+B 선호)
Z vs X → Z 승 (B+C 선호)

→ X > Y > Z > X (집단 선호의 비이행성)
→ 의제 설정자가 투표 순서를 조작하면 원하는 결과 도출 가능

중위 투표자 정리 (Median Voter Theorem):
→ 1차원 정책 경쟁에서 중도 유권자를 잡는 정당이 승리
→ 미국 양당 정치가 중간으로 수렴하는 경향 설명
```

## 핵심 암기 포인트 종합

*신호 게임: 비용 있는 신호만 신뢰 — 모방 불가 = 진실 공개*
*도덕적 해이: 인센티브 설계로 대리인 이익을 주인 이익과 일치*
*메커니즘 설계: 원하는 결과가 내쉬 균형이 되도록 규칙을 설계*
*투표 역설: 의제 순서가 결과를 결정 — 규칙 설계자가 진짜 권력자*
