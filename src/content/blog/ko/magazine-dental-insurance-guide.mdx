## 치아보험이 필요한 이유

치과 치료는 건강보험 급여 항목이 제한적입니다. 임플란트, 크라운, 브릿지 등 주요 치료는 비급여로 진행되어 1회 치료에 수십~수백만 원이 발생할 수 있습니다.

```
주요 치과 치료 비용 (비급여 기준):
- 임플란트: 100~200만원/개
- 세라믹 크라운: 40~80만원/개
- 레진 충치 치료: 5~15만원
- 신경 치료: 15~40만원
- 브릿지(3개): 120~240만원
→ 치아보험으로 일부 보전 가능
```

## 치아보험 보장 구조

### 기본 보장 항목

```
1. 충치 치료 (보존 치료)
   - 레진, 아말감, 인레이, 온레이
   - 신경 치료

2. 보철 치료 (비싼 치료)
   - 임플란트
   - 크라운 (금·세라믹)
   - 브릿지
   - 틀니 (부분·완전)

3. 보조 치료
   - 잇몸 치료 (치주 치료)
   - 발치
```

### 일반적으로 보장 안 되는 항목

```
- 미용 목적 (치아 미백, 라미네이트)
- 교정 치료 (치아 배열)
- 임플란트 보철 분리 시 일부
- 스케일링 (일부 보험 소액 보장)
- 가입 전 이미 치료 중이거나 발병한 치아
```

## 면책 기간 — 가장 중요한 조항

```
면책 기간이란:
보험 가입 후 일정 기간 동안 특정 치료를 보장하지 않는 기간

보존 치료 (충치·신경치료): 면책 기간 없음 or 3개월
보철 치료 (임플란트·크라운·틀니): 면책 기간 1~2년

예시:
→ 1월에 가입 → 임플란트 면책 2년 → 2년 후부터 보장
→ 면책 기간 내 임플란트 → 보험금 지급 안 됨

주의:
→ 가입 시 치아 상태 고지 의무 (고의 누락 시 보험금 거절)
```

## 보장 방식: 정액형 vs 실손형

### 정액형

```
치료 항목별 정해진 금액 지급
예: 임플란트 1개당 50만원, 크라운 1개당 20만원

장점: 실제 치료비와 무관하게 정해진 금액 지급
단점: 치료비가 높은 병원에서는 본인 부담 증가
```

### 실손형 (드물지만 일부 상품)

```
실제 치료비의 일정 비율 보장
예: 비급여 치료비의 80% 보장 (본인 부담 20%)

장점: 고액 치료 시 더 많이 받을 수 있음
단점: 보험료 높음, 병원·시술 선택 제한 가능
```

## 보험사별 주요 비교 포인트

### 체크 항목

```
1. 임플란트 보장:
   - 1개당 지급 금액 (30만~80만원)
   - 연간 지급 한도 (1~3개)
   - 생애 총 지급 한도 (5~10개)

2. 면책 기간:
   - 보철 치료: 1년 vs 2년
   - 보존 치료: 없음 vs 3개월

3. 갱신 구조:
   - 비갱신형: 보험료 고정, 보장 기간 내 동일 조건
   - 갱신형: 매 1~3년 보험료 갱신 (나이 들수록 오름)
   
4. 보험료:
   - 40대: 월 3~7만원 (비갱신형 기준)
   - 50대: 월 5~12만원 (비갱신형 기준)
   - 60대: 월 8~20만원 (비갱신형 기준)
```

## 가입 전 체크리스트

```
□ 현재 치아 상태 확인 (기존 치료 부위 고지 의무)
□ 임플란트 면책 기간 1년 vs 2년 비교
□ 연간·생애 임플란트 지급 한도 확인
□ 비갱신형 선택 시 총 납입 기간 대비 보험료 계산
□ 갱신형 선택 시 65~70세 예상 보험료 확인
□ 보존 치료 (충치) 연간 보장 횟수 제한 확인
□ 잇몸 치료 포함 여부 확인
```

## 치아보험과 건강보험 급여 관계

```
건강보험 급여 치아 치료:
- 만 65세 이상 임플란트: 2개 급여 (본인부담 30~50%)
- 스케일링: 연 1회 급여
- 일부 크라운·발치: 급여 적용

→ 65세 이상은 건강보험 급여 혜택 증가
→ 치아보험과 중복 청구 가능 여부 확인 필요
→ 비급여 부분만 치아보험 청구 가능
```

## 나이별 가입 전략

### 30~40대

```
→ 보철 치료 필요성 아직 낮음
→ 비갱신형 상품 장기 가입 시 보험료 유리
→ 충치 보장 중심 저렴한 상품도 고려
```

### 50~60대

```
→ 임플란트·틀니 필요성 높아짐
→ 기존 치아 문제 있으면 고지 의무 중요
→ 임플란트 면책 기간 1년짜리 우선 고려
→ 갱신형은 70대 보험료 급상승 주의
```

### 65세 이상

```
→ 건강보험 급여 임플란트 2개 우선 활용
→ 치아보험 신규 가입 어렵거나 보험료 부담
→ 기존 가입 유지가 중요
```

## 자주 묻는 질문

**Q. 치아보험과 실손의료보험이 중복 보장되나요?**
A. 실손의료보험은 비급여 치과 치료를 보장하지 않습니다. 치과 치료는 치아보험으로 별도 가입해야 합니다.

**Q. 이미 충치가 있는데 가입할 수 있나요?**
A. 가입은 가능하지만, 현재 치료 중이거나 진단받은 치아는 보험금 청구가 거절될 수 있습니다. 정확히 고지해야 합니다.

**Q. 임플란트 2개를 동시에 심으면 2배 보장받나요?**
A. 연간 지급 한도가 있습니다. 예를 들어 '연간 2개 한도'라면 동시에 2개를 심어도 2개분만 보장됩니다.

**Q. 갱신형과 비갱신형 중 무엇이 유리한가요?**
A. 장기 가입이 확실하다면 비갱신형이 총 보험료 측면에서 유리한 경우가 많습니다. 갱신형은 초기 보험료가 낮지만 고령이 될수록 보험료가 크게 오릅니다.
