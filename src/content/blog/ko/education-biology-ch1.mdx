## 생물학이란?

```
생물학(Biology)의 정의:
→ 생명체의 구조, 기능, 성장, 진화, 분포를 연구하는 학문

생명의 특성 (7가지):
1. 세포성: 세포가 기본 구조·기능 단위
2. 물질대사: 화학 반응으로 에너지 획득·사용
3. 생장: 성장하고 발달
4. 반응성: 환경 자극에 반응
5. 항상성: 내부 환경 일정하게 유지
6. 생식: 자손 번식
7. 진화: 세대 거치며 변화

생물학의 계층적 조직:
원자 → 분자 → 세포 소기관 → 세포 → 조직 → 기관
→ 기관계 → 개체 → 개체군 → 군집 → 생태계 → 생물권
```

## 원핵세포 vs 진핵세포

```
원핵세포 (Prokaryote):
→ 핵막 없음 (DNA가 세포질에 직접 존재)
→ 막으로 싸인 소기관 없음
→ 매우 작음 (1~10 μm)
→ 세균(Bacteria), 고세균(Archaea)
→ 구조: 세포벽, 세포막, 리보솜, 핵양체(nucleoid)
→ 일부: 편모, 피막(capsule)

진핵세포 (Eukaryote):
→ 이중 핵막으로 싸인 핵(nucleus) 존재
→ 다양한 막성 세기관 존재
→ 크기: 10~100 μm
→ 식물, 동물, 균류, 원생생물
→ 동물세포: 중심소체, 리소솜 있음
→ 식물세포: 세포벽, 엽록체, 액포 있음

내공생 이론 (Endosymbiotic Theory):
→ 미토콘드리아와 엽록체는
  과거 원핵세포가 큰 세포에 흡수·공생한 흔적
→ 증거: 자체 DNA, 이중막, 독립 분열
```

## 세포 소기관

```
핵 (Nucleus):
→ 이중 핵막 (핵공 존재)
→ DNA(염색체) 보관, 유전 정보 저장
→ 핵소체(Nucleolus): rRNA 합성

미토콘드리아 (Mitochondria):
→ ATP(세포 에너지) 생산
→ 이중막: 외막 + 내막(크리스타)
→ 호기성 호흡의 주요 장소
→ 자체 DNA 보유 (반자율성 소기관)

엽록체 (Chloroplast) — 식물 전용:
→ 광합성 (빛 에너지 → 화학 에너지)
→ 틸라코이드(thylakoid) + 스트로마
→ 자체 DNA 보유

리보솜 (Ribosome):
→ 단백질 합성 (mRNA 번역)
→ 막 없음, 모든 세포에 존재
→ 소포체 부착형 vs 유리형

소포체 (Endoplasmic Reticulum):
→ 거친 ER(조면 ER): 리보솜 부착, 단백질 합성·가공
→ 매끈한 ER(활면 ER): 지질 합성, 해독

골지체 (Golgi Apparatus):
→ 단백질·지질 수식·포장·분류
→ 분비 소포로 세포막 또는 밖으로 수송

리소솜 (Lysosome) — 동물세포:
→ 소화 효소 보관
→ 세포 내 소화, 낡은 소기관 분해

액포 (Vacuole) — 식물세포:
→ 중앙 액포: 물, 이온, 색소 저장
→ 세포 팽압(Turgor pressure) 유지
```

## 세포막 구조

```
유동 모자이크 모델 (Fluid Mosaic Model, Singer & Nicolson):
→ 인지질 이중층 (Phospholipid bilayer)
  - 친수성 머리: 물 쪽
  - 소수성 꼬리: 안쪽
→ 단백질: 내재성(막관통) + 표재성
→ 유동성: 인지질과 단백질이 측면 이동 가능

콜레스테롤(동물):
→ 막의 유동성 조절
→ 온도 높음: 유동성 억제
→ 온도 낮음: 유동성 유지

세포막의 기능:
→ 선택적 투과성 (반투과막)
→ 세포 내외 물질 이동 조절
→ 신호 수용 (수용체 단백질)
→ 세포 인식 (당단백질, 당지질)
```

## 세포막 수송

```
수동 수송 (에너지 불필요):
→ 단순 확산: 농도 높은 곳→낮은 곳
  (O₂, CO₂, 지용성 물질)
→ 촉진 확산: 막단백질(채널/운반체) 이용
  (포도당, 이온)
→ 삼투 (Osmosis): 물의 반투과막 통과
  - 저장액(hypotonic)→세포로 물 유입 → 팽윤
  - 고장액(hypertonic)→세포에서 물 유출 → 수축

능동 수송 (에너지 필요):
→ 농도 기울기 거슬러 이동
→ ATP 소모
→ 예: Na⁺-K⁺ 펌프 (Na⁺ 3개 밖, K⁺ 2개 안)

대량 수송:
→ 세포내 섭취 (Endocytosis): 외부 물질 흡수
  - 식작용: 큰 입자 포식
  - 음작용: 액체·소분자
→ 세포 외 분비 (Exocytosis): 소포체→골지체→세포막
```

## 세포 분열

```
세포 주기:
→ G1기 (성장): 세포 성장, 단백질 합성
→ S기 (합성): DNA 복제
→ G2기 (성장): 분열 준비
→ M기 (유사분열): 실제 분열

유사분열 (Mitosis) 단계:
1. 전기 (Prophase): 염색체 응축, 방추사 형성
2. 전중기 (Prometaphase): 핵막 소실, 방추사 부착
3. 중기 (Metaphase): 염색체 적도판 배열
4. 후기 (Anaphase): 염색분체 양극으로 이동
5. 말기 (Telophase): 핵막 재형성
6. 세포질 분열: 2개 딸세포

감수분열 (Meiosis):
→ 생식세포 형성 (난자, 정자)
→ DNA 복제 1회, 분열 2회
→ 결과: 염색체 수 반감 (2n → n)
→ 유전적 다양성: 교차(crossing over), 독립적 분리
```

## 자주 묻는 질문

**Q. 식물세포와 동물세포의 차이는 무엇인가요?**
A. 식물세포에는 세포벽(셀룰로오스), 엽록체, 중앙 액포가 있지만 동물세포에는 없습니다. 반대로 동물세포에는 중심소체(centriole)와 리소솜이 있고 식물세포에는 없습니다. 이 차이가 두 세포의 다양한 기능적 차이를 만들어냅니다.

**Q. 삼투압과 세포의 관계는 무엇인가요?**
A. 세포가 저장액(소금 농도 낮음)에 있으면 물이 세포 안으로 들어와 팽윤하고, 고장액(소금 농도 높음)에 있으면 물이 빠져나가 수축합니다. 식물 세포는 세포벽 덕분에 저장액에서도 파열되지 않고 팽압을 유지합니다. 이것이 식물이 서 있을 수 있는 이유입니다.
