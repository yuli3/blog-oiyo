## 면접은 준비한 만큼 보인다

합격자와 탈락자의 차이: 대부분 **능력**이 아닌 **준비도**입니다.

면접관은 짧은 시간에 판단합니다. 준비된 사람은 명확하게 말하고, 준비 안 된 사람은 두루뭉술하게 말합니다.

---

## 면접 종류

| 종류 | 특징 | 준비 포인트 |
|-----|-----|----------|
| 인성 면접 | 가치관·성격·협업 방식 | 자기소개, 지원 동기, 강약점 |
| 직무 면접 | 직무 관련 지식·경험 | STAR 기법 사례, 업무 시뮬레이션 |
| 임원 면접 | 회사 적합성, 장기 비전 | 회사·산업 이해, 큰 그림 |
| PT 면접 | 주제 발표 후 질의응답 | 논리 구조, 시각 자료 |
| 토론 면접 | 그룹 토론 | 경청+발언, 설득력, 팀워크 |
| 실무 테스트 | 코딩, 분석, 영어 | 직무별 상이 |

## 1분 자기소개 구성

가장 중요한 첫 인상. 구조를 미리 만들어 완성도 높이기.

### 공식 구조

```
1. 핵심 키워드 (나를 한 마디로)
2. 과거 경험 (핵심 경험 1~2가지)
3. 역량 연결 (이 경험이 직무에 어떻게 연결되는가)
4. 미래 기여 (이 회사에서 무엇을 이루겠는가)
```

**예시**:
"저는 데이터로 문제를 정의하는 마케터입니다. 3년간 스타트업에서 퍼포먼스 마케팅을 담당하며 구글 애즈 ROAS를 2배 향상시킨 경험이 있습니다. 이 경험을 바탕으로 귀사의 디지털 마케팅 전략을 고도화하는 데 기여하고 싶습니다."

**팁**: 
- 1분 = 약 200~250자
- 두루뭉술한 칭찬보다 구체적 숫자·성과
- 외우지 말고 흐름을 내면화

## STAR 기법

경험 기반 답변의 황금 공식.

| 요소 | 내용 |
|-----|-----|
| S (Situation) | 상황·맥락 설정 (간략히) |
| T (Task) | 내가 맡은 과제·역할 |
| A (Action) | 내가 취한 구체적 행동 (핵심) |
| R (Result) | 결과 (수치로 명확히) |

**예시 (팀 갈등 상황)**:
- S: "프로젝트 마감 2주 전, 팀원 간 역할 분담으로 갈등이 생겼습니다."
- T: "PM으로서 갈등을 중재하고 일정 내 완수해야 했습니다."
- A: "각자의 우선순위를 개별 면담으로 파악 후, 역할을 재조정하고 일일 체크인 미팅을 도입했습니다."
- R: "마감 5일 전 완료, 품질 평가 상위 10% 달성. 팀원 관계도 개선."

## 자주 나오는 질문과 답변 원칙

### 인성 질문

**"본인의 강점과 약점은?"**

강점: 직무 연관된 강점 + 구체적 근거.
약점: 실제 약점이지만 **개선 노력** 중인 것으로 (발전 의지 보여주기).

피해야 할 것: "완벽주의가 약점"처럼 위장된 강점 표현 → 면접관이 싫어하는 유형.

**"왜 이 회사에 지원했나요?"**

공식 답변 3단계:
1. 업계·분야에 관심 갖게 된 계기
2. 이 회사의 특정 지점 (제품, 문화, 비전)이 당신과 맞는 이유
3. 여기서 어떻게 기여하고 싶은지

**"5년 후 목표는?"**

대부분의 정답: 이 직무에서 전문가가 되어 팀에 기여하는 모습 + 큰 그림.
극단적인 목표 (CEO, 창업) → 해당 회사가 발판처럼 보임 → 주의.

**"실패 경험을 말해주세요."**

진짜 실패 + 배운 점 + 이후 적용. 
포인트: 실패를 숨기지 않는 솔직함 + 성장 서사.

### 직무 질문

직무마다 다르지만 공통 원칙:

- 추상적 설명 대신 **구체적 사례**로 증명
- "경험해봤다" + "배웠다" + "적용했다"
- 모르는 것을 물으면: "정확히는 모르지만, 이렇게 접근하겠습니다."

## 역질문 (질문 있으십니까?)

면접관에게 역질문하지 않는 것 = 기회 낭비.

**좋은 역질문 예시**:
- "이 팀에서 성공한 사람들의 공통점은 무엇인가요?"
- "현재 팀이 직면한 가장 큰 도전은 무엇인가요?"
- "입사 후 첫 3개월 동안 어떤 성과를 기대하시나요?"
- "팀의 협업 문화와 코드 리뷰 프로세스는 어떻게 되나요?" (개발직)

**피해야 할 역질문**:
- "연봉은 협상 가능한가요?" (인사팀 아닌 경우)
- "어떤 복지가 있나요?" (정보 수집용처럼 보임)

## 비언어 소통

- **악수**: 적당한 힘, 눈을 보며
- **앉는 자세**: 등 편하게 기대지 않고, 약간 앞으로 (관심 표현)
- **시선**: 면접관에게 70%, 나머지 테이블·자료
- **웃음**: 경직되지 않게, 진정성 있게
- **메모**: 면접 중 허락 받고 노트 메모 → 진지함 표현

---

## 면접 전날 준비

- [ ] 회사 최근 뉴스·사업 현황 확인
- [ ] 면접 장소 미리 확인 (교통 + 10~15분 여유)
- [ ] 복장 준비 (회사 문화에 맞게, 깔끔하게)
- [ ] 질문 목록 최종 확인
- [ ] 충분한 수면

## 면접 후 감사 메일

면접 24시간 내 감사 이메일 → 인상 남기기.

**구성**:
1. 시간 내주신 것에 대한 감사
2. 면접에서 논의된 내용 중 인상적인 점 언급 (개인화)
3. 자신의 관심 재확인
4. 추가 정보 필요 시 연락 요청

면접은 준비한 것을 보여주는 자리입니다. 경험이 없더라도 준비가 있으면 합격하고, 경험이 있어도 준비 없이는 탈락합니다.
