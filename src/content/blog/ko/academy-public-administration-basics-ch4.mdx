## 예산의 의의와 원칙

```
예산:
일정 기간 정부 수입·지출 계획
국회 의결로 확정

예산의 원칙 (전통):
공개성: 국민에게 공개
명확성: 내용 명확히 표시
사전 의결: 지출 전 국회 승인
한정성: 목적·금액·기간 제한
완전성: 모든 수입·지출 포함
단일성: 하나의 예산
정확성: 실제에 부합

예외:
준예산: 예산 불성립 시 전년도 예산 준용
수정 예산: 국회 제출 후 수정
추가경정예산: 집행 중 변경
```

---

## 예산 제도의 발전

```
품목별 예산 (LIBS):
지출 대상(인건비·물건비 등)으로 분류
통제 기능 강조
단점: 성과 파악 어려움

성과 예산 (PBS):
사업 목표·성과로 예산 편성
관리 기능 강조

계획 예산 (PPBS):
장기 계획 + 성과 + 예산 통합
시스템 분석, 비용편익 분석

영기준 예산 (ZBB):
전년도 기준 없이 매년 제로에서 편성
모든 사업을 새로 정당화
장점: 낭비 제거
단점: 시간·비용 과다

목표 관리 예산 (MBO):
부서 목표 설정 + 목표 달성 기준 예산
```

## 예산 과정

```
① 예산 편성 (행정부):
각 부처 예산 요구 → 기재부 조정·편성
국무회의 의결 → 국회 제출 (회계연도 90일 전)

② 예산 심의 (입법부):
국회 상임위 예비 심사
예산결산특별위원회 종합 심사
본회의 의결

③ 예산 집행:
각 부처 배정 예산 집행
예산 전용·이용·이월·불용

④ 결산:
지출 실적 정산
감사원 결산 검사 → 국회 제출

한국 회계연도: 1월 1일 ~ 12월 31일
예산 국회 제출: 9월 3일 (90일 전)
국회 의결 기한: 12월 2일
```

## 예산 종류

```
일반회계:
국가 기본 수입·지출
조세 수입→일반 행정 지출

특별회계:
특정 목적 사업 수행
수익자 부담, 기업성 사업

기금:
탄력적 운용
출연금·기금운용수익
예산 원칙 적용 제외 (일부)

통합재정:
일반회계+특별회계+기금 전체
국가 재정 전체 규모 파악
```

## 핵심 개념 카드

**예산 과정 순서** ★★★★★
: 편성(행정부)→심의(국회)→집행→결산.
*암기 포인트: 편심집결*

**ZBB의 특징** ★★★★★
: 전년도 기준 없이 제로부터 모든 사업 재정당화. 낭비 제거하지만 시간 과다.
*암기 포인트: ZBB=제로베이스*

**일반회계 vs 특별회계** ★★★★☆
: 일반=전반적 국가기능. 특별=특정사업·수익자부담.
*암기 포인트: 특별=특정목적*

## 실전 퀴즈

**Q. 한국에서 추가경정예산이 자주 편성되는 이유는?**
> 예산 편성 후 경기 침체·자연재해·코로나 등 예상치 못한 재정 수요 발생 시 대응. 원래 예산 목적 외 지출 필요 시 국회 승인 받아 수정. 경기 부양 목적으로도 활용.

**Q. 성과 예산과 품목별 예산의 핵심 차이는?**
> 품목별: 무엇에 쓰는지(인건비·물건비) 통제 중심. 성과: 어떤 결과를 위해 쓰는지 관리 중심. 성과 예산은 투입보다 산출·결과를 예산 편성 기준으로 삼음.
