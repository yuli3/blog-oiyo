## 공식 확인 기준

시험 시간, 입실 시각, 준비물, 응시자 유의사항은 시행연도별 공고로 확인해야 합니다. LEET는 법학전문대학원협의회 주관 시험이므로 [법학전문대학원협의회](https://akls.kr)와 공식 LEET 접수·공지 사이트를 기준으로 최신 안내를 확인하세요. 확인일: 2026-06.

## 시간관리의 원칙

LEET는 한 문제를 오래 붙잡는 순간 전체 점수가 흔들릴 수 있습니다. 영역별로 처음 훑는 속도, 어려운 문제를 표시하는 기준, 마지막 검토 시간을 미리 정해 두어야 합니다. 단, 구체적인 시간표는 해당 연도 공식 시험시간을 확인한 뒤 조정해야 합니다.

| 상황 | 운영 기준 |
|------|-----------|
| 지문이 길다 | 첫 문단과 문단 기능을 빠르게 표시 |
| 선지가 헷갈린다 | 지문 근거가 있는 선지부터 남기기 |
| 조건이 복잡하다 | 표나 기호로 옮긴 뒤 경우를 줄이기 |
| 시간이 부족하다 | 고난도 문제를 표시하고 다음 문제로 이동 |

## 모의고사 복기

실전 연습은 점수 확인보다 복기가 중요합니다. 틀린 문제, 맞혔지만 오래 걸린 문제, 마지막에 찍은 문제를 따로 표시하고 원인을 분류하세요. 합격 가능성이나 향후 난도를 단정하기보다 자신의 시간 손실 패턴을 줄이는 것이 현실적입니다.

## 핵심 요약

- 시험 운영 정보는 공식 LEET 공고 기준으로 확인합니다.
- 시간관리는 문제를 버리는 기준까지 포함해야 합니다.
- 모의고사는 점수보다 오답 원인과 시간 손실 분석이 중요합니다.
- 영역별 루틴은 실제 시험시간 확인 뒤 조정합니다.
