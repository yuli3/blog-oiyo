## 핵심 수치 총정리

```
IFRS 재무제표: 5종류 (재포자현주)
유형자산 감가상각: 정액·정률·생산량비례
손상: MAX(순공정가치, 사용가치)
소득세 세율: 6~45% (8단계)
부가세율: 10% (영세율=0%)
법인세율: 9~24% (중소=9%)
감사의견: 4종류 (적한부의)
BEP = 고정원가/단위공헌이익
```

## 빈출 오답 10선

```
① 충당부채=재무상태표, 우발부채=주석
② 손상=MAX(순공정가치, 사용가치)
③ FVOCI 평가손익=기타포괄손익
④ 영세율=환급가능, 면세=환급불가
⑤ 전부원가=생산량>판매량 시 이익높음
⑥ 공헌이익=매출-변동원가
⑦ BEP=고정원가/단위공헌이익
⑧ 감사의견거절=범위제한, 부적정=왜곡
⑨ 연결재무제표=내부거래 제거
⑩ 퇴직·양도소득=분류과세 (합산 안됨)
```

## 실전 퀴즈 (종합)

**Q. 공인회계사의 독립성이 왜 감사의 핵심인가?**
> 감사는 제3자 입장에서 재무제표 공정성 확인. 감사인이 피감사인과 이해관계 있으면 객관성 상실. 정신적 독립성: 실제로 독립. 외관적 독립성: 제3자 눈에 독립처럼 보여야. 독립성 위반 시 감사 품질 불신 → 자본시장 신뢰 훼손.

**Q. CPA 시험 2차 재무회계와 세법을 동시 준비하는 전략은?**
> 재무회계: IFRS 기본 원칙 체계화 후 기준서별 심화. 세법: 세목별(법인세·소득세·부가세) 구조 파악 후 계산 반복. 연계: 세무회계는 재무회계 기반 위에 세무조정 추가. 주관식 답안: 분개·계산 과정 명시. 부분점수 전략 중요.
