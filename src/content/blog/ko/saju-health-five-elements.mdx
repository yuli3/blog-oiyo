## 오행과 인체의 연결

사주명리학에서 오행(五行)은 자연뿐 아니라 **인체의 각 기관과도 연결**됩니다. 오행 의학은 한의학의 기초이기도 합니다.

| 오행 | 관련 장기 | 감각 기관 | 감정 |
|---|---|---|---|
| 목(木) | 간·담낭 | 눈·시력 | 분노 |
| 화(火) | 심장·소장 | 혀·언어 | 기쁨 (과잉 시 불안) |
| 토(土) | 비장·위장 | 입·소화 | 걱정·생각 |
| 금(金) | 폐·대장 | 코·호흡 | 슬픔 |
| 수(水) | 신장·방광 | 귀·청력 | 두려움 |

<Callout type="note">
**의학적 주의**: 이 내용은 전통 동양 의학의 관점을 소개하는 일입니다. 실제 건강 문제는 반드시 의료 전문가와 상담하세요.
</Callout>

## 오행별 건강 특성

### 목(木) — 간·담낭·눈

**목이 강한 경우 (과다)**:
- 간 기능에 부담이 갈 수 있음
- 눈 피로, 시력 저하 주의
- 분노를 자주 느끼고 스트레스가 간에 영향
- 근육 긴장, 편두통 경향

**목이 약한 경우 (부족)**:
- 근육이 유연하지 않고 쉽게 피로
- 집중력이 약하고 의지력 부족
- 봄에 특히 몸이 힘들 수 있음

**목 에너지 건강 관리:**
```
✅ 적합: 규칙적인 운동, 녹황색 채소, 충분한 수면
✅ 힐링: 자연 속 걷기, 요가·스트레칭
⚠️ 주의: 과음 (간 직결), 눈의 과로, 분노 억압
```

---

### 화(火) — 심장·소장·혀

**화가 강한 경우 (과다)**:
- 심장이 두근거리고 불안·흥분 상태
- 수면 장애, 불면증
- 여름에 더위를 많이 탐
- 혈압·혈액 순환 주의

**화가 약한 경우 (부족)**:
- 순환이 나빠 손발이 차가움
- 무기력하고 열정이 없어짐
- 우울감이 나타날 수 있음

**화 에너지 건강 관리:**
```
✅ 적합: 적정 유산소 운동, 붉은색 식품 (토마토, 비트)
✅ 힐링: 명상, 음악 감상
⚠️ 주의: 과도한 흥분·스트레스, 자극적인 식품
```

---

### 토(土) — 비장·위장·입

**토가 강한 경우 (과다)**:
- 소화 기능이 강하지만 과식 경향
- 생각이 많아 위장에 스트레스
- 복부 비만 경향
- 습기에 취약

**토가 약한 경우 (부족)**:
- 소화력 약함, 위장 장애
- 식욕 부진이나 과식의 양극단
- 면역 기능 약화 경향

**토 에너지 건강 관리:**
```
✅ 적합: 규칙적인 식사, 노란색·주황색 식품 (호박, 고구마)
✅ 힐링: 규칙적인 생활 리듬, 마사지
⚠️ 주의: 과식·과음, 불규칙한 식사, 지나친 걱정
```

---

### 금(金) — 폐·대장·코

**금이 강한 경우 (과다)**:
- 피부가 예민하고 알레르기 경향
- 호흡기 질환(비염, 천식)에 취약
- 슬픔·우울을 억압하면 폐에 영향
- 대장 기능 주의

**금이 약한 경우 (부족)**:
- 호흡기 면역력 약함
- 피부 문제
- 감기에 자주 걸림

**금 에너지 건강 관리:**
```
✅ 적합: 맑은 공기, 깊은 호흡, 흰색 식품 (배, 무, 연근)
✅ 힐링: 자연 속 深호흡, 감정 표현하기
⚠️ 주의: 미세먼지·흡연, 슬픔 억압
```

---

### 수(水) — 신장·방광·귀

**수가 강한 경우 (과다)**:
- 신장에 부담
- 부종, 냉증 경향
- 두려움이 과할 때 신장에 영향
- 생식·비뇨기계 주의

**수가 약한 경우 (부족)**:
- 에너지·정력 부족
- 뼈·치아 약화 경향
- 청력 감퇴 가능성
- 겨울에 몸이 특히 힘듦

**수 에너지 건강 관리:**
```
✅ 적합: 충분한 수분 섭취, 검은색 식품 (검은콩, 흑임자)
✅ 힐링: 충분한 수면, 물 근처 휴식
⚠️ 주의: 과도한 불안·두려움, 피로 누적, 과한 성생활
```

## 일간별 건강 취약 부위

| 일간 | 오행 | 건강 취약 부위 | 주의 사항 |
|---|---|---|---|
| 갑·을목 | 목(木) | 간·담낭·눈·근육 | 과음 절대 금물, 눈 피로 주의 |
| 병·정화 | 화(火) | 심장·혈관·수면 | 스트레스 관리, 과도한 흥분 |
| 무·기토 | 토(土) | 위장·소화·비장 | 규칙적 식사, 과식 주의 |
| 경·신금 | 금(金) | 폐·호흡기·피부·대장 | 미세먼지 차단, 호흡 운동 |
| 임·계수 | 수(水) | 신장·방광·뼈·청력 | 충분한 수면, 냉증 예방 |
