한국에서 이사는 단순히 짐을 옮기는 일이 아닙니다. 계약 검토, 이사업체 비교, 전입신고, 공과금 이전 등 놓치면 손해를 볼 수 있는 절차들이 연속적으로 이어집니다. 아래 체크리스트를 순서대로 따라가면 빠짐없이 처리할 수 있습니다.

---

## 1. 이사 2~4주 전 — 계약과 업체 선정

### 임대차 계약 검토
- 등기부등본 확인: [인터넷등기소](https://www.iros.go.kr) → 근저당·압류 여부 확인
- 계약서에 **잔금일, 입주일, 특약사항** 명확히 기재
- 전세·월세라면 확정일자 받기 (주민센터 또는 [온라인 확정일자](https://www.iros.go.kr))
- 전세보증보험 가입 여부 검토: [주택도시보증공사(HUG)](https://www.khug.or.kr)

### 이사업체 선정
- 최소 3곳 이상 견적 비교 (방문 견적 권장)
- **국가공인 이사화물 운송업체** 여부 확인: [화물운송허가 조회](https://www.ftc.go.kr)
- 계약서에 이사 날짜·시간·비용·파손 보상 조항 명기
- 소형 이사(원룸~1.5룸): 용달·화물 이사도 고려

### 이사 날짜 선택
- 말일(25~31일), 월초(1~5일)는 이사 성수기 → 비용 20~30% 높음
- 주말·공휴일도 할증 적용
- 이사 최소 2주 전 예약 권장

---

## 2. 이사 1주 전 — 짐 정리와 신청

### 짐 분류 및 포장
- 버릴 것 / 팔 것(당근마켓) / 옮길 것 3분류
- 깨지기 쉬운 물건: 신문지·에어캡으로 직접 포장
- 이사업체 포장 서비스 여부 확인 (추가 비용)
- 냉장고: 이사 전날 밤 전원 차단, 음식 소진

### 기관 변경 신청 (미리 처리)
- 우체국 우편물 주소 변경: [우편물 주소 변경 신청](https://www.epost.go.kr)
- 은행·증권사 주소 변경 (인터넷뱅킹 또는 방문)
- 정기 구독 서비스 주소 변경

---

## 3. 이사 당일

### 출발지 점검 체크리스트
- [ ] 모든 가구·가전 목록과 실제 짐 대조
- [ ] 벽·바닥 기존 파손 상태 사진 촬영 (분쟁 예방)
- [ ] 가스·수도·전기 마지막 미터기 사진 촬영
- [ ] 관리비 정산 (관리사무소)
- [ ] 열쇠·카드키 반납
- [ ] 에어컨 실외기, 세탁기 배수 호스 확인

### 도착지 점검 체크리스트
- [ ] 입주 전 벽·바닥·천장 상태 사진 촬영
- [ ] 수도·가스·전기 정상 작동 확인
- [ ] 인터넷 개통 여부 확인 (사전 신청 권장)
- [ ] 이삿짐 파손 여부 즉시 확인 → 업체에 현장에서 고지

## 4. 이사 후 2주 이내 — 필수 행정 처리

### ① 전입신고 (14일 이내 의무)
- 방법: 주민센터 방문 또는 [정부24 온라인](https://www.gov.kr) 신청
- 필요 서류: 신분증, 임대차계약서
- **전입신고 = 대항력 발생** (임차인 보호의 핵심)
- 확정일자를 받지 않았다면 전입신고 시 함께 신청

### ② 건강보험·국민연금 주소 변경
- 전입신고 시 자동 연동되는 경우가 많으나 직접 확인 권장
- [국민건강보험공단](https://www.nhis.or.kr) / [국민연금공단](https://www.nps.or.kr)

### ③ 자동차 등록 주소 변경
- 이사 후 15일 이내 변경 의무
- 방법: 가까운 차량등록사업소 방문 또는 [자동차민원 대국민포털](https://www.ecar.go.kr)

### ④ 공과금 이전
- 전기: [한국전력 고객센터](https://cyber.kepco.co.kr) (123) 또는 앱
- 가스: 해당 도시가스 공급사에 전화 (지역마다 다름)
- 수도: 관할 수도사업소에 전화
- 인터넷·TV: 해지 또는 이전 설치 신청 (이전 설치비 발생 여부 확인)

### ⑤ 운전면허·여권 주소 변경
- 운전면허: [도로교통공단](https://www.safedriving.or.kr) 온라인 또는 경찰서
- 여권: 주소 변경은 재발급 시 자동 반영 (긴급하지 않으면 생략 가능)

## 분쟁 예방 팁

이사 후 집주인과 보증금 반환 분쟁이 발생할 경우:
- **주택임차권 등기명령 신청**: 법원에 신청해 임차권을 등기로 보호 가능
- **내용증명 발송**: 우체국에서 보증금 반환 청구 내용증명 발송
- **대한법률구조공단**: [법률 무료 상담](https://www.klac.or.kr) (국번 없이 132)
