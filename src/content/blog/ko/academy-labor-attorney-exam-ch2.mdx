## 노동법 사례형 답안 구조: IRAC 방식

IRAC(Issue·Rule·Application·Conclusion)는 법학에서 사용하는 사례형 답안 작성의 표준 방식입니다.

### IRAC 4단계

```
① ISSUE (쟁점 제시)
   "이 사건에서 문제되는 쟁점은 ○○의 해고가 정당한지 여부이다."

② RULE (관련 법조문 제시)
   "근로기준법 제23조에 따르면, 사용자는 정당한 이유 없이 근로자를
    해고할 수 없으며, 동법 제27조에 따르면 해고는 서면으로 통지하여야
    효력이 있다."

③ APPLICATION (사실관계에 법조문 적용)
   "사안에서 A회사는 ○○○를 이유로 甲을 해고하였는데,
    이는 정당한 이유에 해당하는지 검토한다. (구체적 사실 분석)"

④ CONCLUSION (결론 도출)
   "따라서 甲에 대한 해고는 정당한 이유가 결여된 부당해고에 해당하며,
    甲은 노동위원회에 구제신청을 제기할 수 있다."
```

## 자주 출제되는 노동법 사례 유형

### 유형 1: 해고 유효성 판단

**판단 구조**

```
① 해고 사유의 정당성 (근기법 제23조)
   - 근로자의 귀책 사유 존재 여부
   - 사회통념상 고용관계를 지속하기 어려운 정도인가

② 절차적 정당성
   - 서면 통지 여부 (근기법 제27조)
   - 해고 예고 30일 또는 30일분 통상임금 지급 (근기법 제26조)
   - 취업규칙·단체협약상 절차 준수 여부

③ 결론: 실체적 정당성 + 절차적 정당성 모두 충족해야 유효한 해고
```

**빈출 시나리오**

- 서면 통지 없는 구두 해고 → 절차 위반으로 부당해고
- 징계 없이 즉시 해고 → 절차 위반 가능성
- 경영상 이유 해고(정리해고): 근기법 제24조 4요건 충족 여부 (긴박한 경영상 필요 + 해고 회피 노력 + 합리적 기준 + 노사 협의)

### 유형 2: 근로자성 인정 여부

근로자성 판단은 사실관계의 세부 요소를 검토하여 판정합니다.

**판단 요소 (대법원 기준)**

| 요소 | 근로자 인정 요소 | 비근로자 요소 |
|------|----------------|--------------|
| 업무 지시·감독 | 구체적 업무 지시 있음 | 독립적 업무 수행 |
| 출퇴근 시간 | 사용자가 결정 | 본인이 결정 |
| 대체성 | 본인만 업무 수행 | 대체인력 활용 가능 |
| 보수 성격 | 정기적 고정 급여 | 성과에 따른 보수 |
| 경제적 종속성 | 주된 수입원 | 독립적 사업자 |
| 4대보험 | 직장가입자 | 지역가입자 또는 미가입 |

### 유형 3: 쟁의행위 합법성

**판단 구조**

```
① 주체 요건: 노동조합 또는 그 조합원의 쟁의행위인가?
② 목적 요건: 근로조건 향상 등 적법 목적인가? (정치파업·경영권 개입 목적 불가)
③ 절차 요건:
   - 노동쟁의 조정 신청 완료 여부
   - 조정 기간(일반 10일, 공익사업 15일) 경과 여부
   - 찬반 투표 실시 여부 (조합원 직접·비밀·무기명 투표 과반)
④ 방법 요건: 폭력·파괴 행위 없음, 생산시설 점거 없음
```

### 유형 4: 부당노동행위 성립

```
① 행위 주체: 사용자 (사용자 측 행위만 부당노동행위)
② 행위 유형: 7종 중 해당 유형 특정
③ 불이익 취급의 경우: 노동3권 행사와의 인과관계 입증
④ 구제 방법: 노동위원회에 부당노동행위 구제신청 (처분 안 날부터 3개월)
```

### 동기이론 핵심

**내용이론 (무엇이 동기를 유발하는가)**

| 이론 | 핵심 내용 |
|------|-----------|
| 매슬로의 욕구 5단계 | 생리→안전→소속→존중→자아실현 (하위→상위 단계로 이동) |
| 허즈버그의 2요인이론 | 위생요인(불만 제거)과 동기요인(만족 증가) 구분 |
| 맥그리거 X·Y 이론 | X이론(통제·지시) vs Y이론(자율·참여) |
| 앨더퍼 ERG 이론 | 존재·관계·성장 욕구 (상위 좌절 시 하위 욕구 강화 — 좌절-퇴행) |

**과정이론 (어떤 과정으로 동기가 작동하는가)**

- **브룸의 기대이론**: 동기 = 기대감 × 수단성 × 유의성
- **공정성이론**: 자신의 투입/산출 비율을 타인과 비교 → 불공정 지각 시 행동 변화
- **목표설정이론**: 구체적이고 도전적인 목표가 높은 성과로 이어짐

### BSC·KPI 성과관리

- BSC(균형성과표): 재무·고객·내부 프로세스·학습과 성장 4관점의 균형
- KPI(핵심성과지표): 전략 목표 달성을 측정하는 정량적 지표
- BSC와 KPI의 연계: BSC 전략지도의 각 목표를 KPI로 측정

### 직무분석과 직무평가

**직무분석** — 직무의 내용과 요건을 체계적으로 파악하는 절차

- 직무기술서(Job Description): 직무 내용, 책임, 조건
- 직무명세서(Job Specification): 직무 수행에 필요한 자격 요건

**직무평가 4방법**

| 방법 | 특징 |
|------|------|
| 서열법 | 직무를 상대적으로 순위화 — 간단하지만 주관적 |
| 분류법 | 사전에 등급 기준 설정 후 직무를 해당 등급에 배치 |
| 요소비교법 | 기준 직무와 비교하여 요소별 임금 결정 |
| 점수법 | 평가 요소별 점수 부여 후 합산 — 가장 객관적 |

### 행정쟁송법 핵심 3테마

**① 구제신청 기간**

| 유형 | 기간 | 기산점 |
|------|------|--------|
| 부당해고 | 3개월 | 해고가 있었던 날 |
| 부당노동행위 | 3개월 | 부당노동행위가 있었던 날 |
| 정리해고(경영상 해고) | 3개월 | 해고가 있었던 날 |

**② 화해 권고**

노동위원회는 관계 당사자의 신청이나 직권으로 화해를 권고할 수 있습니다.

- 화해 성립 시: 구제신청 취하 간주
- 화해 효력: 재판상 화해와 동일한 효력 (강제집행 가능)

**③ 이행강제금**

사용자가 노동위원회의 구제명령(원직복직)을 이행하지 않으면 이행강제금이 부과됩니다.

- 부과 주체: 노동위원회 (지방노동위원회)
- 부과 기준: 위반 행위에 따라 구제명령 불이행 시 연 2회, 최대 2년 간 부과
- 금액: 구제명령 내용에 따라 차등 (원직복직 명령 불이행 시 최대 3,000만원/회)
