## 물류 비용의 이해

```
물류 비용의 중요성:
→ 기업 총비용의 10~20% 차지
→ 물류 비용 절감 = 직접 이익 증가

물류 비용의 분류:

기능별 분류:
→ 수송비: 화물 이동 비용 (가장 큰 비중)
→ 보관비: 창고 임대·관리·인건비
→ 포장비: 포장재·포장 작업비
→ 하역비: 상·하차, 분류 작업비
→ 유통가공비: 재포장, 라벨링 비용
→ 정보비: 물류 정보 시스템 운영비

원가 형태별 분류:
→ 고정비: 창고 임대료, 차량 감가상각 (물량 무관)
→ 변동비: 연료비, 아르바이트 인건비 (물량 비례)
→ 준변동비: 기본료 + 사용량 비례 (전기요금)

ABC 물류 비용 분석:
→ A: 비용 큰 물류 활동 집중 관리 (80% 비용)
→ B: 중간 관리 (15%)
→ C: 단순 모니터링 (5%)
```

## 총비용 분석 (Total Cost Analysis)

```
총비용 접근법:
→ 물류 개별 비용이 아닌 전체 비용 최적화
→ 한 요소 절감이 다른 요소 비용 증가 야기 가능

총비용의 구성:
Total Logistics Cost = 수송비 + 재고 유지 비용
                     + 창고 비용 + 주문 처리 비용
                     + 서비스 수준 비용

재고 유지 비용 (Inventory Carrying Cost):
→ 자본 비용 (재고 투자액의 기회비용)
→ 보관 비용 (공간·보험)
→ 위험 비용 (진부화, 손상, 도난)
→ 세금 (재고 보유세)
→ 일반적으로 재고 금액의 20~30%/년

수송비 vs 재고 비용 트레이드오프:
→ 빈번한 소량 배송: 수송비 증가 but 재고 감소
→ 대량 일괄 배송: 수송비 감소 but 재고 증가
→ 최적 발주량(EOQ)으로 균형

서비스 수준 비용:
→ 재고 부족 (Stockout): 판매 기회 손실, 고객 불만
→ 서비스 수준 높일수록 안전 재고 증가
```

## 3PL과 물류 아웃소싱

```
3PL (Third-Party Logistics):
→ 물류 기능 전체 또는 일부를 외부 전문 업체에 위탁
→ 화주(Shipper) → 3PL 업체 → 최종 고객

3PL vs 자체 물류:
→ 자체 물류:
  + 통제권, 고객 서비스 차별화
  - 고정비 부담, 전문성 한계
→ 3PL 활용:
  + 변동비화, 전문성 활용, 핵심 역량 집중
  - 통제권 약화, 전환 비용

4PL (Fourth-Party Logistics):
→ 공급망 전체를 관리하는 통합 서비스 제공자
→ 물류 자산 보유 없이 공급망 설계·관리·최적화
→ IT 기반 물류 컨설팅+코디네이션

아웃소싱 의사결정 (Make or Buy):
→ 핵심 역량인가? → 자체
→ 비용 효율 유리한가? → 외주
→ 전문성 필요한가? → 외주
→ 통제 필요한가? → 자체

3PL 선택 기준:
→ 서비스 범위·능력
→ 기술·시스템 역량
→ 재무 안정성
→ 가격 경쟁력
→ 레퍼런스·신뢰도
```

## 물류 네트워크 설계

```
물류 네트워크의 구성:
→ 공급업체 → 물류센터/DC → 소매점/고객
→ 시설 수, 위치, 용량 결정이 핵심

물류 거점 전략:

단일 거점 (Centralized):
→ 재고 집중 → 안전재고 감소
→ 고객 서비스 거리 증가, 배송 시간 길어짐

다수 거점 (Decentralized):
→ 고객 근처 소규모 창고 다수
→ 배송 빠름, 재고 분산 비용 증가

중간 거점 (Hub-and-Spoke):
→ 허브(중심) + 스포크(지선) 구조
→ 항공 화물, 택배 네트워크
→ 허브 집결 후 각 지역 배분

크로스 도킹 (Cross Docking):
→ 창고 보관 없이 입하 즉시 출하
→ 재고 제로 목표
→ 풀트럭-단위 배송에 적합

입지 선정 모형:
→ 무게중심법 (Center of Gravity):
  x* = Σ(수요량_i × x좌표_i) / Σ수요량_i
  y* = Σ(수요량_i × y좌표_i) / Σ수요량_i
→ P-중위점 모형: 최대 거리 최소화
```

## 역물류 (Reverse Logistics)

```
역물류의 정의:
→ 소비자로부터 제조업체 방향으로 제품 회수·처리

역물류의 이유:
→ 반품 (품질 불량, 변심)
→ 리콜 (안전 문제)
→ 수리/재생산
→ 재활용/폐기

역물류의 경제적 의미:
→ 연간 역물류 비용: 미국만 수천억 달러
→ 전자상거래 확산으로 반품율 30%+ 보편화
→ 효율적 역물류 → 비용 절감 + 고객 충성도

역물류 전략:
→ 반품 게이트키핑: 수취 전 검사·분류
→ 재활용: 부품 해체·재사용
→ 재생산 (Remanufacturing): 기능 복원
→ 처분: 중고 시장, 기부, 폐기

지속 가능 물류 (Green Logistics):
→ 친환경 포장재
→ 친환경 연료 차량 (전기차, CNG)
→ 적재율 최적화 → 탄소 감소
→ 공동 배송: 업체간 물류 협력
→ ESG 경영의 핵심 요소
```

## 자주 묻는 질문

**Q. 물류 아웃소싱의 가장 큰 위험은 무엇인가요?**
A. 핵심 물류 역량 상실입니다. 너무 많이 아웃소싱하면 내부 전문성이 사라져 나중에 자체화하기 어렵습니다. 또한 3PL 업체에 대한 의존도 증가로 협상력이 약화됩니다. 이외에도 고객 서비스 품질 통제 어려움, 기밀 정보 노출 위험도 있습니다. 아웃소싱 전에 계약서에 SLA(서비스 수준 협약), KPI, 비밀유지 조항을 명확히 명시해야 합니다.

**Q. 크로스도킹은 모든 물류에 적합한가요?**
A. 아닙니다. 크로스도킹은 예측 가능하고 안정적인 대량 상품에 적합합니다. 슈퍼마켓 체인처럼 매일 동일 상품이 대량으로 입고되는 환경이 이상적입니다. 다품종 소량, 수요 예측이 어려운 상품, 또는 빠른 주문-납품 사이클이 필요한 B2B 맞춤 생산에는 적합하지 않을 수 있습니다.
