## AWS Solutions Architect Associate란?

**AWS Certified Solutions Architect – Associate(SAA-C03)**는 Amazon Web Services가 공인하는 클라우드 아키텍처 자격증입니다. AWS 서비스를 활용해 안전하고 확장 가능하며 비용 효율적인 솔루션을 설계하는 역량을 검증합니다.

<Callout type="info">
SAA-C03은 2022년 8월에 개정된 최신 버전입니다. 이전 버전(SAA-C02)과 달리 **마이크로서비스, 컨테이너, 서버리스** 비중이 크게 높아졌습니다.
</Callout>

## 시험 기본 정보

| 항목 | 내용 |
|------|------|
| **시험 코드** | SAA-C03 |
| **문항 수** | 65문항 (채점 문항 50 + 미채점 15) |
| **시험 시간** | 130분 |
| **합격 점수** | 720점 / 1000점 |
| **시험 비용** | $150 USD (한국 약 20만원) |
| **유효 기간** | 3년 |
| **언어** | 영어, 일본어, 한국어, 중국어 |

## 도메인별 출제 비율 ★★★★★

| 도메인 | 내용 | 비율 |
|--------|------|------|
| **Domain 1** | 안전한 아키텍처 설계 | 30% |
| **Domain 2** | 복원력 있는 아키텍처 설계 | 26% |
| **Domain 3** | 고성능 아키텍처 설계 | 24% |
| **Domain 4** | 비용 최적화 아키텍처 설계 | 20% |

<Callout type="warning">
Domain 1(보안)이 30%로 가장 높습니다. IAM, KMS, VPC 보안그룹, NACLs를 반드시 숙지하세요.
</Callout>

## 문항 유형

**선택형(Multiple Choice)**: 단일 정답 선택  
**복수 선택형(Multiple Response)**: 5개 중 2개 정답 선택

실제 시험에서는 **시나리오 기반 문제**가 대부분입니다. "고객 요구사항이 X일 때 가장 적합한 AWS 서비스는?" 형태로 출제됩니다.

## 권장 사전 경험

- AWS 서비스 사용 경험 **1년 이상** (필수는 아니지만 권장)
- 네트워크 기초 (IP, DNS, 라우팅) 이해
- 리눅스/윈도우 기본 운영 경험

## 준비 전략

### 1단계: 이론 학습 (4~6주)

```
추천 학습 순서:
1. AWS 공식 문서 및 Whitepaper
2. Stephane Maarek의 Udemy 강좌
3. AWS Skill Builder 공식 강좌
4. Adrian Cantrill 강좌 (심화)
```

### 2단계: 실습 (2~3주)

AWS Free Tier를 활용해 직접 서비스를 구성해보는 것이 핵심입니다.

| 실습 항목 | 중요도 |
|-----------|--------|
| S3 버킷 생성 및 정책 설정 | ★★★★★ |
| VPC + 서브넷 구성 | ★★★★★ |
| EC2 Auto Scaling 그룹 | ★★★★☆ |
| RDS Multi-AZ 배포 | ★★★★☆ |
| Lambda 함수 생성 | ★★★☆☆ |

### 3단계: 모의고사 (2주)

- **Tutorials Dojo** 모의고사: 가장 실제 시험과 유사
- **Whizlabs**: 문제 해설이 상세
- 목표 점수: 모의고사에서 **85% 이상** 달성 후 응시

---

## 합격률과 난이도

AWS 공식 합격률은 공개되지 않지만, 업계 추정치는 **50~60%** 수준입니다. 충분한 준비 없이 응시하면 실패 확률이 높습니다.

<Callout type="success">
평균 준비 기간: **8~12주**. IT 배경이 있다면 6~8주도 가능합니다.
</Callout>
