## 생산 함수와 한계생산

```
생산함수: Q = f(K, L)
K: 자본, L: 노동

한계생산 (Marginal Product):
MPL = ΔQ / ΔL (노동 1단위 추가 시 산출량 증가)

한계생산 체감의 법칙:
단기에서 가변 요소(L) 증가 → MPL 감소
→ 자본(K) 고정 상태에서 노동만 계속 추가

총생산(TP)·평균생산(AP)·한계생산(MP) 관계:
MP > AP → AP 상승
MP = AP → AP 최대
MP < AP → AP 하락
```

## 비용 개념

```
단기 비용 구분:
총고정비용 (TFC): 산출량 불변 (임차료·기계 감가)
총변동비용 (TVC): 산출량 비례 변화 (노무비·원자재)
총비용 (TC) = TFC + TVC

평균 비용:
AFC = TFC / Q (체감)
AVC = TVC / Q (U자형)
ATC = TC / Q = AFC + AVC (U자형)

한계비용 (MC):
MC = ΔTC / ΔQ = ΔTVC / ΔQ

MC와 ATC 관계:
MC < ATC → ATC 하락
MC = ATC → ATC 최소
MC > ATC → ATC 상승
→ MC는 ATC의 최저점을 통과
```

## 단기 비용곡선의 형태

```
AVC, ATC: U자형
- 처음: 한계생산 체증으로 하락
- 이후: 한계생산 체감으로 상승

AFC: 우하향 (산출량 증가할수록 단위당 고정비 감소)

MC: U자형 (AVC·ATC의 최저점 통과)

AVC 최저 < ATC 최저:
AVC = ATC 아님 → AFC 양수이므로 ATC > AVC 항상
```

## 한계비용: 평균비용과 이윤극대화를 연결한다

한계비용(MC)은 산출량을 한 단위 더 늘릴 때 증가하는 총비용입니다. 고정비용은 산출량 변화와 무관하므로 `MC = ΔTC/ΔQ = ΔTVC/ΔQ`입니다. 총비용이 Q=10에서 100, Q=11에서 112라면 11번째 단위의 한계비용은 12입니다. 평균총비용 `112/11`과 혼동하지 않습니다.

한계값이 평균보다 낮으면 평균을 끌어내리고, 높으면 끌어올립니다. 따라서 MC는 AVC와 ATC 각각의 최저점을 통과하지만, **MC 자신의 최저점이 두 평균비용의 최저점이라는 뜻은 아닙니다.** 또한 MC는 AFC의 최저점을 통과하지 않습니다. AFC는 산출량이 늘수록 계속 하락하기 때문입니다.

기업의 내부해 이윤극대화는 보통 MC가 MR을 아래에서 위로 지나는 구간에서 `MR=MC` 후보를 찾고, 조업중단·생산능력·경계 조건까지 확인합니다. 완전경쟁에서는 `MR=P`이므로 `P=MC`가 되지만, 독점에서는 먼저 `MR=MC`로 수량을 정한 뒤 수요곡선에서 가격을 찾습니다. **모든 시장에서 P=MC가 이윤극대화 조건**이라는 선지는 틀립니다.

## 장기 비용과 규모의 경제

```
장기: 모든 생산요소 가변
→ 장기평균비용곡선(LAC) = 단기 ATC들의 포락선

규모의 경제 (Economies of Scale):
생산 규모 확대 → LAC 하락
→ 대규모 생산이 유리 (자연독점 원인)

규모의 불경제:
생산 규모 확대 → LAC 상승
→ 관료화·비효율 발생

최적 규모 (MES):
LAC 최저점 생산 규모
```

## 이윤 극대화 조건

```
이윤 (π) = TR - TC

이윤 극대화:
MR = MC

직관:
MR > MC → 1단위 더 생산 시 이윤 증가
MR < MC → 1단위 더 생산 시 이윤 감소
MR = MC → 이윤 극대

완전경쟁 시장:
P = MR (가격 수용자)
→ P = MC에서 이윤 극대

손익분기점:
P = ATC (경제적 이윤 = 0)
조업중단점 (단기):
P = AVC (P < AVC → 변동비도 못 건짐 → 생산 중단)
```

## 핵심 개념 카드

**MC = ATC 최저점 통과** ★★★★★
: 한계비용이 평균비용보다 낮으면 평균 하락, 높으면 평균 상승. MC는 ATC 최저를 아래에서 위로 통과.
*암기 포인트: MC=ATC 교차=ATC 최저점*

**이윤 극대화 MR=MC** ★★★★★
: 한계수입=한계비용인 산출량에서 이윤 극대화. 완전경쟁에서 P=MC.
*암기 포인트: MR=MC = 이윤 극대*

**조업중단 조건** ★★★★☆
: P < AVC → 단기 조업 중단. P < ATC → 손실 발생하나 변동비 커버 → 단기 계속 생산.
*암기 포인트: P&lt;AVC=중단, P&lt;ATC=손실 생산 가능*

## 실전 퀴즈

**Q. 완전경쟁 기업이 P=20, MC=18, ATC=22일 때 어떻게 해야 하는가?**
> MR(=P=20) > MC(=18) → 생산량 증가. P(=20) < ATC(=22) → 손실 발생. 그러나 P(=20) > AVC 여부 확인 필요. AVC를 모르지만 단기에 AFC를 차감하면 AVC < ATC. 만약 AVC < 20이면 단기 생산 지속하면서 MR=MC 도달 추구.

**Q. 장기 LAC가 우하향 구간에 있는 기업이 규모를 확대해야 하는 이유는?**
> 규모의 경제 구간. 생산 규모 확대 → LAC 하락 → 단위 원가 감소 → 경쟁 우위 확보.
