## 6강 개요: 비즈니스 커뮤니케이션의 AI 혁신

직장인은 하루 평균 2~4시간을 이메일·메시지 작성에 쓴다. AI로 이 시간을 절반으로 줄이면서 오히려 더 명확하고 전문적인 커뮤니케이션을 할 수 있다.

---

## 1. 비즈니스 이메일 작성

### 목적별 이메일 프롬프트

```
프롬프트 (거절 이메일):
"거래처 제안을 정중하게 거절하는 이메일을 작성해주세요.
- 거절 이유: [이유]
- 관계 유지: 필요
- 향후 가능성: 열어두기
- 톤: 전문적이고 따뜻하게"

프롬프트 (협업 요청):
"타 부서에 협업을 요청하는 이메일을 작성해주세요.
- 요청 내용: [내용]
- 기대 기여: [상대방 역할]
- 마감: [날짜]
- 인센티브: [상호 이익]"
```

**이메일 유형별 핵심 원칙:**

| 유형 | 첫 문장 | 핵심 |
|---|---|---|
| 요청 이메일 | 목적부터 | 상대 이익 명시 |
| 거절 이메일 | 감사 표현 | 이유 + 대안 |
| 사과 이메일 | 즉시 사과 | 재발 방지 대책 |
| 보고 이메일 | 결론 먼저 | PREP 구조 |

---

## 2. 회의록 자동화

회의 음성/텍스트를 AI에 붙여넣어 회의록을 자동 생성한다.

```
프롬프트:
"아래 회의 내용을 공식 회의록으로 정리해주세요.

포함 항목:
- 회의 일시·참석자·안건
- 논의 내용 요약 (핵심만)
- 결정 사항 (명확히)
- 액션 아이템 (담당자·마감일)
- 다음 회의 예정

[회의 내용 붙여넣기]"
```

---

## 3. 슬랙·팀즈 메시지 최적화

```
프롬프트:
"아래 내용을 슬랙 메시지로 작성해주세요.
- 긴급도: [긴급/보통/낮음]
- 대상: [팀장/팀원/전체]
- 목적: [공지/요청/보고]
- 길이: 3줄 이내

내용: [전달할 내용]"
```

**채널별 메시지 톤 가이드:**

| 채널 | 톤 | 길이 |
|---|---|---|
| #긴급 | 명확·간결 | 1~2줄 |
| #일반 | 친근·정보적 | 3~5줄 |
| #경영진 보고 | 격식·구조적 | PREP 형식 |
| #팀 채널 | 캐주얼·협력적 | 자유 |

---

## 4. 어려운 대화 시뮬레이션

갈등 상황이나 민감한 피드백을 전달하기 전, AI와 먼저 연습한다.

```
프롬프트:
"[상황]에서 [상대방]에게 [메시지]를 전달해야 합니다.
감정적으로 반응하지 않고 문제를 해결하는 방향으로
대화를 시뮬레이션해주세요.
상대방 역할도 맡아서 내가 어떻게 대응해야 할지 가르쳐주세요."
```
