# 창업·법인설립 완전 가이드

사업을 시작할 때 가장 먼저 결정해야 하는 것은 **어떤 형태로 사업을 운영할 것인가**입니다. 개인사업자와 법인은 세금, 책임, 신뢰도에서 큰 차이가 있습니다.

---

## 1. 개인사업자 vs 법인 비교

| 항목 | 개인사업자 | 법인(주식회사) |
|---|---|---|
| **설립 비용** | 무료 (등록면허세 없음) | 등록면허세 등 약 30–50만원 |
| **설립 절차** | 세무서 사업자등록 (1–2일) | 공증 + 법원 등기 (1–2주) |
| **법적 책임** | 무한책임 (개인 재산 위험) | **유한책임** (출자금 한도) |
| **세금 구조** | 종합소득세 (6%–45%) | 법인세 (9%–24%) + 배당소득세 |
| **대외 신뢰도** | 낮음 | 높음 (기업 조달, 투자 유리) |
| **회계 의무** | 간편 장부 가능 | 복식 부기 + 외부 감사 (일정 규모 이상) |

<Callout type="tip">
**세금 분기점**: 연매출 약 1억 5,000만원(순이익 기준)부터 법인 세율이 개인보다 유리해지는 경우가 많습니다. 하지만 법인 운영 비용(세무사, 회계)을 포함하면 실질 손익분기점은 더 높을 수 있습니다.
</Callout>

---

## 2. 개인사업자 등록 절차

**필요 서류:**
- 신분증
- 임대차계약서 (사업장 주소 증명)
- 인허가증 (해당 업종)

**절차:**
1. 국세청 홈택스 (hometax.go.kr) 또는 세무서 방문
2. 업종코드 선택 (중요: 잘못 선택하면 세금 불이익 발생)
3. 사업자등록증 발급 (당일~3영업일)
4. 필요시 부가가치세 과세/면세 여부 선택
5. 건강보험 지역가입자 전환 (자동 처리)

---

## 3. 법인(주식회사) 설립 절차

**일반 절차:**

| 단계 | 내용 | 비용 | 기간 |
|---|---|---|---|
| 1. 정관 작성 | 회사 기본 규약 | — | 1일 |
| 2. 공증 | 정관 공증 (자본금 10억 이하 생략 가능) | 30–50만원 | 1일 |
| 3. 발기설립 | 주주 출자금 납입 | 자본금 | 1일 |
| 4. 법원 등기 | 법인 설립 등기 신청 | 등록면허세 (자본금의 0.4%) | 3–5일 |
| 5. 사업자등록 | 세무서 등록 | 무료 | 1–3일 |

<Callout type="note">
**자본금 얼마로 할까?** 법적 최소 자본금은 100원입니다. 하지만 조달·투자·거래처 신뢰 등을 고려하면 최소 1,000만원~1억원을 권장합니다. 초기 운영자금을 자본금으로 투입해 법인 통장 개설 후 비용 처리를 투명하게 하세요.
</Callout>

## 4. 업종별 추가 인허가

사업 업종에 따라 사업자등록 외에 별도 인허가가 필요합니다.

| 업종 | 필요 인허가 | 담당 기관 |
|---|---|---|
| 음식점·카페 | 식품위생법 영업신고 | 시·군·구청 |
| 유통·판매 | 통신판매업 신고 (온라인 쇼핑) | 시·도청 |
| 부동산 중개 | 공인중개사 자격증 + 개설등록 | 시·군·구청 |
| 의료기기 판매 | 의료기기 판매업 신고 | 식품의약품안전처 |
| IT 솔루션 | 소프트웨어 사업 신고 (해당 시) | 과학기술정보통신부 |
| 금융 서비스 | 금융업 인가 | 금융위원회 |

## 5. 세금 처리: 법인 vs 개인사업자

### 법인세율 (2024년 기준)

| 과세표준 | 세율 |
|---|---|
| 2억원 이하 | 9% |
| 2억~200억원 | 19% |
| 200억~3,000억원 | 21% |
| 3,000억원 초과 | 24% |

### 개인사업자 세금: 종합소득세

| 과세표준 | 세율 |
|---|---|
| 1,400만원 이하 | 6% |
| 1,400만~5,000만원 | 15% |
| 5,000만~8,800만원 | 24% |
| 8,800만~1.5억원 | 35% |
| 1.5억~3억원 | 38% |
| 3억~5억원 | 40% |
| 5억원 초과 | 42–45% |

## 6. 초기 창업 체크리스트

- [ ] 사업 아이템 검증 (시장 조사, MVP 테스트)
