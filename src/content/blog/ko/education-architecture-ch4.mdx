## 스마트 시티

```
스마트 시티 (Smart City):
→ ICT로 도시 기반시설 연결·최적화 → 효율·삶의 질 향상
→ IBM 스마터 시티·시스코·지멘스 등 기업 주도 초기
→ 현재: 시민 참여·데이터 거버넌스 중심으로 전환

스마트 시티 핵심 요소:

스마트 교통:
→ 지능형 교통 시스템 (ITS): 실시간 교통 신호 최적화
→ 자율주행차 인프라: V2X 통신·LIDAR 지원 도로
→ 공유 이동성: 카셰어링·킥보드·MaaS (이동 서비스)
→ 교통 빅데이터: 최적 경로·혼잡 예측·수요 반응 대중교통

스마트 에너지:
→ 스마트 그리드: 양방향 전력 통신·수급 실시간 조정
→ 분산 발전: 태양광 지붕·ESS·마이크로그리드
→ 건물 에너지 관리 시스템 (BEMS): 냉난방·조명 자동 최적화
→ 디지털 트윈: 도시 에너지 흐름 시뮬레이션

스마트 워터:
→ 스마트 미터: 실시간 사용량 모니터링
→ 누수 감지: 센서 네트워크로 조기 탐지
→ 수질 모니터링: IoT 센서 연속 측정

데이터 도시 (Data City):
→ 도시 디지털 트윈: 물리 도시의 가상 복제
  싱가포르 버추얼 싱가포르
  서울: 서울 디지털 트윈 (SDT)
→ 도시 OS: 다양한 도시 데이터 통합 플랫폼
→ 시민 참여형: 오픈 데이터·시민 서비스 혁신

스마트 시티 도전:
→ 개인정보·감시 우려: 중국 사회 신용 체계 비판
→ 디지털 격차: 스마트 기기 접근 불평등
→ 사이버 보안: 핵심 인프라 취약성
→ 구글 사이드워크 토론토: 민간 기업 도시 관리 논쟁 후 철수
```

## 지속가능 건축

```
지속가능 건축 개념:
→ 환경 부담 최소화·에너지 효율 극대화·거주자 건강
→ 전체 수명 주기 (Life Cycle): 재료 채취→시공→사용→해체
→ 3중 바닥 이론: 환경·사회·경제 동시 고려

패시브 하우스 (Passive House):
→ 독일 파시브 하우스 인증 기준
→ 단열·기밀·열교 차단·열 회수 환기로 에너지 수요 90% 절감
→ 연간 난방 에너지: 15kWh/m² 이하
→ 핵심 기술:
  외단열 (EIFS)·삼중 유리·기밀 시공·창호 설계
  열 교환 환기 (HRV): 배기 열로 급기 예열
→ 국내 적용: 서울 에너지드림센터

제로에너지 건물 (ZEB):
→ 연간 에너지 소비 = 재생에너지 생산 (순 에너지 = 0)
→ 건물 에너지 소비 60~70% 절감 + 태양광 자체 생산
→ 한국 의무화: 2025년 공공 500m² 이상·2030년 민간

녹색 건축 인증 (Green Building Certification):
→ LEED (미국): Leadership in Energy and Environmental Design
  소재·에너지·물·실내환경·혁신 항목 점수 합산
  Certified·Silver·Gold·Platinum 등급
→ BREEAM (영국): 가장 역사 깊은 인증
→ G-SEED (한국 녹색건축 인증):
  에너지·환경부하·생태환경·실내환경·자원 절약 영역

바이오필릭 디자인 (Biophilic Design):
→ 건축 공간에 자연 요소 통합 → 웰빙·생산성 향상
→ 직접 자연 접촉: 실내 정원·녹벽·채광
→ 간접 자연 요소: 자연 패턴·자연 재료·유기적 형태
→ 싱가포르 쥬얼 창이 공항의 실내 폭포·숲

순환 건축 (Circular Architecture):
→ 건물 해체 시 재료 재사용 설계 (Design for Disassembly)
→ 재생 재료 우선 사용 (재생 콘크리트·FSC 인증 목재)
→ 모듈러 건축: 분리·재조립 가능
```

```
서양 건축 역사:

고전 건축:
→ 그리스: 도리아·이오니아·코린트 오더
  파르테논 신전: 황금비·착시 보정·엔타시스
→ 로마: 아치·볼트·콘크리트 혁신
  콜로세움·판테온 (비보강 콘크리트 돔)·아치교·수로

중세:
→ 로마네스크 (9~12세기): 두꺼운 벽·반원 아치
→ 고딕 (12~16세기): 첨두 아치·플라잉 버트레스
  빛의 건축: 스테인드 글라스·수직 상승

르네상스·바로크:
→ 르네상스: 고전 부활·비례·원근법 (브루넬레스키·미켈란젤로)
→ 바로크: 역동성·감정·화려함 (베르사이유 궁전)

  "형태는 기능을 따른다" (설리번)

  미스 반 데어 로에·르 코르뷔지에·그로피우스
→ 브루탈리즘: 노출 콘크리트·솔직한 구조

한국 전통 건축:
→ 삼국 시대: 중국 영향·불교 건축 도입
→ 통일 신라: 석굴암·불국사 (균형·비례)
→ 고려: 목조 건축 발전·무량수전 (배흘림 기둥)
→ 조선: 유교 건축 원리·검소함
  경복궁·창덕궁·종묘: 자연 지형 활용·위계
  한옥: 마루·온돌·마당·자연 재료
→ 근대: 일제 서양식 도입·전통과 단절

현대 한국 건축:
→ 1970~80년대: 개발 우선·획일적 아파트

→ 동대문 디자인 플라자 (DDP): 자하 하디드 설계·한국 해체주의 랜드마크
→ 한옥 르네상스: 북촌·은평 한옥마을
```

## BIM과 디지털 설계

```
BIM (Building Information Modeling):
→ 건물의 물리적·기능적 특성을 디지털 표현
→ 설계→시공→유지관리 전 수명 주기 데이터 통합
→ 2D 도면 → 3D 모델 → 4D(일정)→ 5D(비용)→ 6D(지속가능)→ 7D(FM)

BIM의 혜택:
→ 충돌 탐지 (Clash Detection): 구조·기계·전기 간 간섭 사전 발견
→ 물량 자동 산출·견적
→ 시뮬레이션: 일조·에너지·소방 대피
→ 시공 후 건물 유지관리 DB
→ 협업: 건축사·구조·설비 실시간 공유

주요 BIM 소프트웨어:
→ Autodesk Revit: 가장 광범위 사용
→ ArchiCAD: 건축 특화
→ Bentley MicroStation: 인프라·토목
→ Dynamo·Grasshopper: 파라메트릭 설계 플러그인

파라메트릭 설계 (Parametric Design):
→ 변수(파라미터)로 형태 생성·변형
→ Grasshopper (Rhino 플러그인): 알고리즘 설계
→ 복잡한 기하학적 형태 신속 생성·변형
→ 사례: 베이징 수영장 물방울 구조·자하 하디드 곡선 건물

3D 프린팅 건축:
→ 콘크리트 3D 프린팅: 복잡한 형태·인력 절감
→ Apis Cor: 24시간 소형 주택 출력
→ 달·화성 건축 실험

AR·VR과 건축:
→ VR 공간 경험: 시공 전 가상 체험
→ AR 현장 시공: 설계 위에 실시간 시각화
→ 디지털 트윈: 완공 후 건물 운영 관리

탄소 중립 건축:
→ 내재 탄소 (Embodied Carbon): 재료 생산·시공 배출
  건설 업계 전체 배출 11% 차지
→ 운영 탄소: 사용 중 에너지 소비
→ Mass Timber (CLT): 탄소 격리·철근 콘크리트 대체
  일본 도쿄 스카이트리·Vancouver Brock Commons
```

## 자주 묻는 질문

**Q. 스마트 시티가 실제로 도시 문제를 해결할 수 있나요?**
A. 스마트 시티 기술이 일부 도시 문제를 개선하는 데 효과를 보이지만, 만능 해결책은 아닙니다. 교통 신호 최적화로 정체 감소, 스마트 가로등으로 에너지 절감, 누수 탐지 센서로 물 손실 감소 등은 실제 성과가 확인되었습니다. 그러나 비판도 있습니다. 첫째, 기술 솔루션이 도시의 근본적 불평등(주거·소득 격차)을 해결하지 못합니다. 둘째, 구글 사이드워크 토론토 사례처럼 민간 기업이 도시 데이터를 통제할 때 민주적 통제와 프라이버시 문제가 발생합니다. 셋째, 디지털 접근성이 낮은 시민들이 소외될 수 있습니다. 성공적인 스마트 시티는 기술 자체보다 '왜, 누구를 위해'에서 시작하며, 시민 참여·개인정보 보호·데이터 거버넌스를 함께 고려합니다.

**Q. 한옥은 현대 건축에서 어떻게 재해석되고 있나요?**
A. 현대 한옥 재해석은 크게 세 방향으로 나타납니다. 첫째, 전통 한옥의 현대적 개량입니다. 전통 형태와 재료를 유지하면서 단열·방수·설비를 현대화한 '신한옥'으로, 국토부 한옥 지원 사업을 통해 보급됩니다. 둘째, 한옥 원리의 현대 건축 적용입니다. 마당(중정), 처마, 자연 환기, 지형 순응 등 한옥의 공간 원리를 현대 건축 언어로 번역합니다. 한국의 많은 공공 건축이 이 방식으로 한국성을 표현합니다. 셋째, 글로벌 무대의 한국성입니다. 런던, 파리 등 해외 한국 문화원 건물들이 현대적 재료와 기술로 한옥의 기억을 재현합니다. 가장 중요한 것은 한옥의 형태를 그대로 복제하는 것이 아니라, 자연과의 관계·인간 척도·공간의 여백이라는 한옥의 본질적 가치를 현대에 맞게 구현하는 것입니다.
