## 재고자산이란

**재고자산(Inventory)**: 정상적인 영업 과정에서 판매 목적으로 보유하거나 생산 중인 자산.

```
재고자산 종류:
- 상품: 판매 목적으로 구입한 완성품 (유통업)
- 제품: 직접 제조한 완성품 (제조업)
- 재공품: 생산 중인 제품 (Work-in-Progress)
- 원재료: 생산에 사용할 원자재
```

---

## 재고 평가 방법

재고자산의 원가 배분 방법에 따라 매출원가와 기말 재고 금액이 달라집니다.

### 선입선출법 (FIFO)
먼저 구입한 것이 먼저 판매된다고 가정.

```
예시: 1월에 100만 원, 2월에 120만 원에 100개씩 매입
     3월에 150개 판매

매출원가 = 100개 × 100만 원 + 50개 × 120만 원 = 16,000만 원
기말재고 = 50개 × 120만 원 = 6,000만 원
```

**물가 상승 시**: 기말재고 가치 ↑, 매출원가 ↓, 이익 ↑

### 평균법 (Weighted Average Cost)
총 원가를 총 수량으로 나눈 평균 단가로 원가 배분.

```
평균 단가 = 총 구입 원가 / 총 구입 수량
```

### IFRS에서 허용하지 않는 방법
**후입선출법(LIFO)**: 최근 구입한 것이 먼저 팔린다고 가정. IFRS에서 금지.

## 제조원가의 구성

**제조원가(Manufacturing Cost)**:
```
직접재료비   → 직접 제품에 투입된 원재료
+ 직접노무비  → 생산 노동자 인건비
+ 제조간접비  → 공장 임차료, 감가상각비, 간접재료
─────────────────────────────
= 총 제조원가
```

**기간원가**: 판매비·관리비 등 생산과 직접 관련 없는 비용 (당기 비용 처리)

## CVP 분석 (Cost-Volume-Profit Analysis)

원가-조업도-이익 분석: 원가와 판매량(조업도) 변화에 따른 이익 변동 분석.

**기본 개념**:
```
공헌이익 = 매출액 - 변동비
공헌이익률 = 공헌이익 / 매출액

영업이익 = 공헌이익 - 고정비
```

### 손익분기점 (Break-Even Point, BEP)

영업이익이 0이 되는 판매량 또는 매출액.

```
BEP 수량 = 고정비 / 단위당 공헌이익
BEP 매출액 = 고정비 / 공헌이익률

예시: 고정비 1,000만 원, 판매가 10만 원, 변동비 6만 원
단위당 공헌이익 = 10 - 6 = 4만 원
BEP 수량 = 1,000 / 4 = 250개
BEP 매출액 = 250 × 10 = 2,500만 원
```

### 목표이익 달성 판매량

```
목표 판매량 = (고정비 + 목표이익) / 단위당 공헌이익
```

---

## 안전한계 (Margin of Safety)

```
안전한계 = 실제 매출액 - BEP 매출액
안전한계율 = 안전한계 / 실제 매출액 × 100%
```

안전한계율이 높을수록 손익분기점을 넘은 여유가 많음.

## 핵심 개념 카드

**선입선출법(FIFO)** ★★★★★
: 먼저 구입한 것이 먼저 판매된다고 가정. 물가 상승 시 재고 자산 가치 높고 이익 크게 인식.
*암기 포인트: FIFO = 오래된 것부터 팔기*

**공헌이익** ★★★★★
: 매출액 - 변동비. 고정비 회수와 이익 창출에 기여하는 금액.
*암기 포인트: 공헌이익 = 고정비 메우는 기여분*

**손익분기점(BEP)** ★★★★★
: 이익이 0인 판매량/매출액. BEP = 고정비 ÷ 공헌이익률. 이를 초과하면 이익 발생.
*암기 포인트: BEP = 고정비 ÷ (판매가 - 변동비)*

## 실전 퀴즈

**Q. FIFO와 평균법 중 물가 상승기에 이익을 더 크게 인식하는 방법은?**
> FIFO. 오래된(더 싼) 재고가 먼저 매출원가로 인식되어 매출원가가 낮게 기록되고, 이익이 크게 나타남.

**Q. 고정비 2,000만 원, 판매가 단위당 5만 원, 변동비 단위당 3만 원일 때 손익분기점 수량은?**
> 공헌이익 = 5 - 3 = 2만 원. BEP = 2,000 ÷ 2 = 1,000개.
