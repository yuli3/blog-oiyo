## 법인세 오답 포인트

```
① 손금불산입 vs 익금불산입
   → 손금불산입: 비용으로 인정 안됨 (과세↑)
   → 익금불산입: 수익으로 안봄 (비과세)

② 법인세율 4구간
   → 9%(2억이하)·19%·21%·24%(3000억초과)
   → 구간 경계 금액 혼동 주의

③ 접대비 한도 = 기본3600만+수입금액×비율
   → 한도 초과=손금불산입+상여처분

④ 소득처분 유보 vs 유출
   → 유보=자산·부채 조정(나중 추인)
   → 유출=사외 귀속 (배당·상여·기타)

⑤ 이월결손금 공제 후 과세표준
   → 공제 한도: 중소=100%, 일반=60%
```

## 소득세 오답 포인트

```
⑥ 금융소득 종합과세 기준 = 2천만원
   → 초과 시 전액 종합과세

⑦ 퇴직소득·양도소득 = 분류과세
   → 종합소득과 합산 안함

⑧ 기본공제 = 1인당 150만원
   → 배우자·부양가족 포함

⑨ 세액공제 vs 소득공제
   → 소득공제=과세표준 낮춤
   → 세액공제=산출세액에서 직접 공제 (더 유리)

⑩ 소득세 신고기한 = 5월 31일
    → 법인세 = 사업연도 말로부터 3개월
```

## 부가가치세 오답 포인트

```
⑪ 영세율 = 환급 가능 (수출)
   → 면세 = 환급 불가

⑫ 매입세액 불공제 = 비영업용소형승용차·접대비
⑬ 확정신고 = 1월·7월 25일
   → 예정신고 = 4월·10월 25일

⑭ 의제매입세액 = 면세 원재료도 일부 공제
⑮ 간이과세자 = 연 매출 1억400만원 미만
```

## 상속·증여세 오답 포인트

```
⑯ 상속세 일괄공제 = 5억
   → 인적공제와 선택 적용

⑰ 증여 성년 공제 = 5천만원 (10년 누적)
   → 미성년 = 2천만원

⑱ 사전증여재산 = 10년 내 합산
   → 상속 10년 전 증여는 합산 없음

⑲ 조세불복 전치주의 = 심판 후 소송
   → 행정심판 임의주의와 다름

⑳ 세무조사 사전통지 = 15일 전
    → 예외: 긴급 탈세 혐의
```

## 핵심 개념 카드

**금융소득 종합과세=2천만원** ★★★★★
: 초과 시 전액 종합과세.
*암기 포인트: 금융=2천만원*

**세액공제>소득공제 유리** ★★★★★
: 세액공제는 세금에서 직접 공제.
*암기 포인트: 세액>소득공제*

**조세불복=전치주의** ★★★★☆
: 심판 먼저, 소송은 그 다음.
*암기 포인트: 조세=전치주의*

## 실전 퀴즈

**Q. 이월결손금 공제가 중소기업에 더 유리한 이유는?**
> 일반법인: 소득의 60%까지만 공제 (40%는 납부). 중소기업: 100% 공제 가능. 적자가 많은 기업이 흑자 전환 시 중소기업은 결손금 전액 공제로 법인세 0. 중소기업 지원 목적. 10년 이내 발생 결손금만 공제 가능.

**Q. 세무사가 세무조사 단계에서 납세자에게 도움이 되는 방법은?**
> 조사 범위 확인·한정. 조사관 요청 서류 검토 후 제출. 해석 다툼이 있는 항목 사전 협의. 과세전 적부심사 전략적 활용. 조사 결과 부당 시 불복 청구 준비. 납세자 단독 대응 시 불리한 자료 자발 제출 위험 → 세무사 대리 효과 큼.
