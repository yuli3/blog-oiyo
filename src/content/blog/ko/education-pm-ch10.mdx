## PMBOK 10개 지식 영역

```
1. 통합 관리 (Integration)
2. 범위 관리 (Scope)
3. 일정 관리 (Schedule)
4. 비용 관리 (Cost)
5. 품질 관리 (Quality)
6. 자원 관리 (Resource)
7. 커뮤니케이션 관리 (Communications)
8. 리스크 관리 (Risk)
9. 조달 관리 (Procurement)
10. 이해관계자 관리 (Stakeholders)
```

## 5개 프로세스 그룹

```
착수 (Initiating):
→ 프로젝트 헌장 작성 / 이해관계자 식별

계획 (Planning):
→ 전체 관리 계획 수립 / 기준선 설정

실행 (Executing):
→ 작업 지시·관리 / 팀 운영 / 품질 보증

감시·통제 (Monitoring & Controlling):
→ 프로젝트 성과 측정 / 변경 통제

종료 (Closing):
→ 인도물 수락 / 교훈 문서화 / 계약 종료
```

## PMP 핵심 공식 정리

### EVM (획득 가치 관리)

```
PV (계획 가치): 이 시점까지 완성해야 할 작업의 예산
EV (획득 가치): 실제 완성된 작업의 예산 가치
AC (실제 비용): 실제로 지출한 비용

편차:
SV (일정 편차) = EV - PV  (양수 = 앞서감)
CV (비용 편차) = EV - AC  (양수 = 예산 절약)

성과 지수:
SPI (일정 성과 지수) = EV ÷ PV  (1.0 = 정상)
CPI (비용 성과 지수) = EV ÷ AC  (1.0 = 정상)

예측:
BAC (완성 예산)
EAC (완성 시 총 비용 예측) = BAC ÷ CPI
ETC (잔여 비용 예측) = EAC - AC
```

### 커뮤니케이션 채널 수

```
채널 수 = n(n-1) ÷ 2
(n = 프로젝트 팀원 수)

예: 10명 팀 = 10×9÷2 = 45개 채널
→ 팀 규모 증가 시 커뮤니케이션 복잡도 기하급수적 증가
```

## 실무 PM 체크리스트

### 프로젝트 착수

```
☐ 프로젝트 헌장 작성 및 스폰서 서명 획득
☐ 주요 이해관계자 식별 및 영향력/관심도 분석
☐ 킥오프 회의 개최
☐ 초기 리스크 목록 작성
```

### 계획 단계

```
☐ WBS 작성 (팀 참여)
☐ 네트워크 다이어그램 → 크리티컬 패스 식별
☐ 자원 히스토그램 → 피크 확인 → 평준화
☐ 예산 기준선 및 예비비 설정
☐ 리스크 등록대장 완성 (확률×영향 매트릭스)
☐ 커뮤니케이션 계획 (누구에게, 언제, 어떤 형식으로)
```

### 실행·통제 단계

```
☐ 주간 상태 보고 (계획 vs 실제)
☐ EVM 지표 추적 (SPI, CPI ≥0.8 유지)
☐ 리스크 정기 검토 (월별)
☐ 변경 요청 → CCB 검토 → 기준선 업데이트
☐ 품질 검토 및 결함 추적
```

### 종료 단계

```
☐ 최종 인도물 수락서 서명
☐ 교훈 회의 개최 및 문서화
☐ 조달 계약 공식 종료
☐ 팀원 성과 인정 및 복귀 통보
☐ 프로젝트 기록 보관
```

## PM의 핵심 역량

```
기술적 역량 (Technical):
→ PMBOK 방법론, EVM, 리스크 분석

리더십 역량 (Leadership):
→ 동기 부여, 갈등 해결, 의사소통

전략적 역량 (Strategic):
→ 비즈니스 맥락 이해
→ 프로젝트 ↔ 조직 전략 연계

→ PMI가 강조: 세 역량의 균형이 성공 PM의 조건
```

---

*좋은 PM은 계획을 세우지만, 훌륭한 PM은 계획이 틀렸을 때를 대비한다.*
