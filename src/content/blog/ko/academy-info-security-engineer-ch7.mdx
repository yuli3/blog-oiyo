## 실기는 어떻게 다른가?

정보보안기사 실기는 개념을 아는지보다 상황에 맞게 설명하고 적용할 수 있는지를 봅니다. 단답형은 용어 정확도가 중요하고, 서술형은 원인·영향·대응을 논리적으로 써야 합니다. 실무형은 로그, 설정, 취약 코드, 네트워크 흐름을 읽는 문제가 나올 수 있습니다. 세부 형식과 기준은 회차별 공고를 [Q-net](https://www.q-net.or.kr)에서 확인하세요. 확인일: 2026-06.

### 답안 구성

| 유형 | 답안 전략 |
|------|-----------|
| 단답 | 키워드와 약어를 정확히 암기 |
| 서술 | 정의, 원인, 대응 순서로 작성 |
| 실무형 | 증거를 먼저 찾고 판단 근거를 제시 |

예를 들어 SQL Injection 문제라면 “입력값이 쿼리 구조를 바꾸는 취약점”이라고 정의하고, prepared statement와 입력 검증을 대응으로 적습니다. 로그 문제는 시간, 계정, IP, 이벤트 결과를 순서대로 확인하세요.

### 연습 루틴

필기 개념을 실기 문장으로 바꾸는 훈련이 필요합니다. 하루 한 주제씩 “정의 1문장, 위험 1문장, 대응 2개” 형식으로 쓰면 서술형 감각이 빠르게 잡힙니다.

## 핵심 요약

- 실기는 암기보다 설명과 적용 능력이 중요합니다.
- 서술형 답안은 정의, 원인, 대응의 구조가 안정적입니다.
- 로그와 설정 문제는 증거 기반으로 판단해야 합니다.

다음 장에서는 과목별 학습 순서와 합격 체크리스트로 전체 전략을 마무리합니다.
