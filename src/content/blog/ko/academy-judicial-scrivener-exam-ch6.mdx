## 계약법 핵심

```
계약 성립:
청약 + 승낙 → 계약
계약 자유 원칙 (내용·상대방·체결)

동시이행 항변권:
쌍무계약에서 상대방 이행 전 자기 이행 거절권
매매: 소유권 이전 ↔ 대금 지급

위험부담:
쌍무계약 일방 급부 불능 시 반대급부
원칙: 채무자 위험부담 (채무자 불이익)
예외: 채권자 귀책 시 채권자 부담

계약 해제:
법정해제: 이행거절·이행불능·이행지체(상당기간)
소급 효력 + 원상회복
```

---

## 각종 계약 유형

```
매매:
매도인: 소유권 이전 + 담보책임
매수인: 대금 지급

교환:
금전 이외 재산권 상호 이전

임대차:
사용·수익 + 차임 지급
임차인: 선량한 관리자 주의

도급:
일의 완성 + 보수 지급
하자담보책임: 1년~5년·10년

위임:
법률·사무 처리 위탁
수임인: 선관주의 의무
```

## 불법행위

```
일반 불법행위 요건:
고의·과실
위법성
손해 발생
인과관계

손해배상:
재산적 손해 + 위자료
과실상계 가능
소멸시효: 안날 3년·발생일 10년

특수 불법행위:
사용자 책임 (피용자 불법행위)
공작물 책임 (점유자·소유자)
동물 점유자 책임

공동불법행위:
수인의 공동 → 연대 책임
```

## 상속법

```
상속 순위:
1순위: 직계비속 + 배우자
2순위: 직계존속 + 배우자
3순위: 형제자매
4순위: 4촌 이내 방계혈족

법정 상속분:
배우자 가산: 직계비속·존속과 공동 시 50% 가산

상속 포기:
상속 개시 안 날 3개월 이내 가정법원
한정승인도 동일

유류분:
직계비속·배우자: 법정상속분×1/2
직계존속·형제자매: ×1/3
```

## 핵심 개념 카드

**계약해제=소급효+원상회복** ★★★★★
: 처음부터 없었던 것처럼.
*암기 포인트: 해제=소급*

**불법행위 소멸시효=3+10** ★★★★★
: 안날 3년, 발생일 10년.
*암기 포인트: 불행=3·10*

**상속포기=3개월** ★★★★☆
: 개시 안 날 3개월 내 가정법원 신고.
*암기 포인트: 포기=3개월*

## 실전 퀴즈

**Q. 도급계약의 하자담보책임 기간은 어떻게 다른가?**
> 건물 등 토지 공작물: 인도 후 10년 (목재=5년). 일반 목적물: 1년. 특칙: 하자 알고 고지 안하면 기간 무관 책임. 수급인의 하자보수 또는 손해배상. 도급인은 하자 알면 1년 내 청구해야 함.

**Q. 유류분 반환 청구는 누구에게 할 수 있는가?**
> 유류분 침해한 증여나 유증 받은 자에게 청구. 증여가 먼저(최근→과거 순서), 유증이 나중 반환 대상. 침해 안 날 1년, 상속 개시 10년 소멸시효. 법정상속인 중 직계비속·배우자·직계존속·형제자매.
