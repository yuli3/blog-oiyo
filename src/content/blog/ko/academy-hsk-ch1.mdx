## HSK(汉语水平考试)란?

```
HSK (Chinese Proficiency Test):
→ 중국 교육부 주관 국제 표준 중국어 능력 시험
→ 모국어가 중국어가 아닌 외국인 대상
→ 한국: 연 4~6회 시행

등급 체계:
HSK 1급 → HSK 2급 → HSK 3급 → HSK 4급 → HSK 5급 → HSK 6급

추가 시험:
HSKK: 구술 중국어 능력 시험 (초급/중급/고급)
YCT: 어린이·청소년 중국어 시험
BCT: 비즈니스 중국어 시험
```

## 등급별 능력 기준

```
HSK 1급:
→ 기초 중국어 문장 이해
→ 어휘 150단어
→ 이수 시간: 약 30~40시간

HSK 2급:
→ 일상 주제 간단한 소통
→ 어휘 300단어
→ 이수 시간: 약 60~80시간

HSK 3급:
→ 생활, 학습, 업무 기본 소통
→ 어휘 600단어
→ 이수 시간: 약 120~160시간

HSK 4급:
→ 광범위한 주제 유창한 대화
→ 어휘 1,200단어
→ 이수 시간: 약 400~500시간

HSK 5급:
→ 중국어 신문·잡지 이해, 공식 발표 가능
→ 어휘 2,500단어
→ 이수 시간: 약 600시간 이상

HSK 6급:
→ 모국어 수준에 근접한 이해·표현
→ 어휘 5,000단어 이상
→ 이수 시간: 약 1,200시간 이상
```

## 시험 과목 구성

```
HSK 1~2급:
→ 듣기 + 독해 (2과목)

HSK 3~6급:
→ 듣기 + 독해 + 쓰기 (3과목)

HSK 3급 시험 구성:
→ 듣기: 40문제 (35분)
→ 독해: 30문제 (30분)
→ 쓰기: 10문제 (15분)
→ 합격 기준: 총 300점 만점 중 180점 이상

HSK 4급 시험 구성:
→ 듣기: 45문제 (30분)
→ 독해: 40문제 (40분)
→ 쓰기: 15문제 (25분)
→ 합격 기준: 총 300점 만점 중 180점 이상

합격 기준: 모든 등급 300점 만점 중 180점 이상
```

## HSK 활용처

```
취업·취학:
→ HSK 4급 이상: 중국계 기업 취업 서류 우대
→ HSK 5급: 중국 대학 학부 입학 (일부 대학)
→ HSK 6급: 중국 대학원 입학, 통역·번역 전문직

자격·인증:
→ 공공기관 중국어 관련 직군 가산점
→ 무역·관광·항공사 채용 우대

생활·여행:
→ HSK 3급: 중국 여행 독립 의사소통 가능
→ HSK 4급: 중국어 콘텐츠 대부분 이해 가능
```

## 병음(拼音) 기초

```
중국어 발음 표기 체계: 한어병음(汉语拼音)

성모 (声母, 자음) 21개:
b p m f | d t n l | g k h
j q x | zh ch sh r | z c s

운모 (韵母, 모음) 36개:
단운모: a o e i u ü
복합운모: ai ei ao ou ia ue 등

성조 (声调, 4가지 + 경성):
1성 (阴平): ā 높고 평탄하게 (─ 모양)
2성 (阳平): á 낮다가 올라가며 (/ 모양)
3성 (上声): ǎ 낮게 구부렸다가 (∨ 모양)
4성 (去声): à 높다가 떨어지며 (\ 모양)
경성: 짧고 약하게

예시:
mā (妈): 어머니 (1성)
má (麻): 삼, 마 (2성)
mǎ (马): 말 (3성)
mà (骂): 꾸짖다 (4성)
```

```
인사·기본 표현:

没关系 (méi guān xi): 괜찮습니다

수 (숫자):
一二三四五六七八九十百千万

시간:
今天 (jīn tiān): 오늘
昨天 (zuó tiān): 어제
明天 (míng tiān): 내일
现在 (xiàn zài): 지금
几点 (jǐ diǎn): 몇 시

방향·장소:

```

## HSK 3급 핵심 문법

```
연동문 (두 동사 연속):
→ 我去超市买东西。(wo qu chaohi mai dongxi)
  나는 마트에 가서 물건을 산다.

把자문 (목적어 전치):
→ 我把书放在桌子上。(나는 책을 책상 위에 놓았다)
→ 把 + 목적어 + 동사 + 결과

被자문 (피동):
→ 我的钱包被偷了。(내 지갑이 도둑맞았다)
→ 주어 + 被 + 행위자 + 동사

比자문 (비교):
→ 他比我高。(그는 나보다 키가 크다)
→ A + 比 + B + 형용사

결과보어:
→ 动词 + 好/完/到/见/着/会
→ 做好了: 다 잘 했다
→ 吃完了: 다 먹었다
```

## 자주 묻는 질문

**Q. 한자를 모르면 HSK를 시작하기 어렵나요?**
A. 한국인은 한자 어휘 기반이 있어 다른 외국인에 비해 유리합니다. 한자를 완전히 알 필요는 없지만, HSK 학습과 병행하여 자주 나오는 한자부터 익히면 효율적입니다.

**Q. HSK와 HSKK를 동시에 준비해야 하나요?**
A. HSKK(구술)은 선택 사항입니다. 취업이나 진학에 구술 능력이 필요한 경우 HSKK를 같이 취득하면 좋습니다. 일반적으로 HSK 필기 시험을 먼저 취득한 후 HSKK에 도전하는 것을 권장합니다.
