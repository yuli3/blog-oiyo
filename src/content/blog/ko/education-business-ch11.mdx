# 경영학 Ch11. 생산관리(OM) 및 정보시스템(MIS) 핵심 정리

---

## 1. 경영과학과 예측 기법

### (1) 선형계획법 (Linear Programming)

목표(이익 최대화, 비용 최소화)와 자원의 제약조건이 주어졌을 때, 최적해를 찾는 수리모형 (단찌히 고안).

- **의사결정 기법**: MAXIMAX(최대값 극대화 / 낙관적), MAXIMIN(최소값 극대화 / 비관적), MINIMAX(최대후회 극소화), 라플라스(Laplace, 동일확률), 후르비츠(Hurwicz, 절충).

### (2) 수송모형과 목표계획법

선형계획법의 두 갈래 확장이다. **무엇을 최적화하는가**가 다르다.

- **수송모형 (Transportation Model)**: 공급지 m 곳에서 수요지 n 곳으로
  보낼 때 **총 수송비를 최소화**하는 배분을 찾는다. 선형계획법의 특수형이라
  일반 심플렉스법 대신 북서코너법·최소비용법·보겔법으로 초기해를 잡고
  디딤돌법(stepping stone)·MODI 법으로 개선한다.
  - 공급 합 = 수요 합이면 **균형 수송문제**, 다르면 가상의 공급지·수요지를
    더해 균형으로 만든 뒤 푼다.
  - 할당문제(assignment)는 공급·수요가 모두 1인 수송문제의 특수형이며
    헝가리법으로 푼다.

- **목표계획법 (Goal Programming)**: 목적함수가 **여러 개**이고 서로
  충돌할 때 쓴다. 선형계획법은 목적함수가 하나여야 하지만, 현실에서는
  "이익도 늘리고 고용도 유지하라"처럼 목표가 여럿이다.
  - 각 목표에 **우선순위**를 주고, 목표와의 편차변수(deviation)를 최소화한다.
  - 만족화(satisficing) 접근이다 — 최적해가 아니라 "받아들일 만한 해"를 찾는다.

```
선형계획법   목적함수 1개 · 최적해
수송모형     선형계획의 특수형 · 배분 비용 최소화
목표계획법   목적함수 여러 개 · 우선순위 · 편차 최소화(만족화)
```

### (3) 프로젝트 관리 기법 (PERT / CPM)

대규모 프로젝트의 일정을 관리하는 네트워크 기법. **주경로(Critical Path)**가 핵심 (가장 오래 걸리는 경로 = 프로젝트의 최소 완료시간).

- **PERT**: 소요시간이 불확실할 때 3점 추정법(낙관·비관·최가능) 사용.
- **CPM**: 소요시간이 확실할 때 사용. (비용과 시간의 상충관계 초점)

### (4) 수요 예측 기법

| 기법 종류       | 설명                         | 예시                                                                        |
| --------------- | ---------------------------- | --------------------------------------------------------------------------- |
| **정성적 기법** | 주관적 판단에 의존           | 델파이법(전문가 합의), 경영자 판단법, 패널조사                              |

### (2) 제품-프로세스 행렬 (Hayes & Wheelwright)

1. **개별작업 (Job Shop)**: 다품종 소량생산, 유연성 최고 (인쇄소) — _공정별 배치_
2. **뱃치 (Batch)**: 중간 수준 다양성 (중장비, 제과점)
3. **라인 (Line Layout)**: 소품종 대량생산 (자동차 조립) — _제품별 배치_
4. **연속 (Continuous)**: 표준화 극대화 (정유, 화학, 설탕 정제)

## 3. 품질경영 (TQM & Six Sigma)

### (1) 전사적 품질경영 (TQM)

기존 조직이 '수익 극대화'를 목표로 했다면, TQM은 '고객 만족'과 지속적 개선, 전원 참여를 강조.

- **데밍의 PDCA 사이클**: 계획(Plan) → 실행(Do) → 검토(Check) → 조치(Act)
- **품질비용**:
  - _통제비용_: 예방비용 (사전 방지) / 평가비용 (검사)
  - _실패비용_: 내부실패 (고객 전달 전) / 외부실패 (고객 인도 후 반품, 배상. 가장 치명적)

### (2) 6시그마 (Six Sigma)

100만 개 중 3.4개의 불량(3.4 PPM)만을 허용하는 완벽 추구 통계적 품질관리 기법.

- **DMAIC 프로세스**: **D**efine(정의) → **M**easure(측정) → **A**nalyze(분석) → **I**mprove(개선) → **C**ontrol(통제)
- **조직 구조**: 챔피언 → 마스터 블랙벨트 → 블랙벨트(전임) → 그린벨트(현업)

### (3) 통계적 품질관리 (관리도)

- **계량형 관리도**: X-관리도 (중심화 경향), R-관리도 (산포도) — 연속형 데이터(길이, 무게)
- **계수형 관리도**: p-관리도 (불량률), c-관리도 (결점수) — 이산형 데이터(합격/불합격, 건수)

## 4. 재고관리와 공급사슬관리 (SCM)

### (1) 경제적 주문량 (EOQ)

재고관련 비용 중 **재고유지비용**과 **주문비용(가동준비비용)**의 합이 최소가 되는 1회 주문 크기.

### (2) 정량주문모형 vs 정기주문모형

EOQ 는 "얼마나 주문하는가"를 답한다. **"언제 주문하는가"** 는 두 방식으로 갈린다.

```
정량주문모형 (Q 시스템, 연속실사):
언제      재고가 재주문점(ROP)에 닿을 때
얼마나    항상 같은 양 (EOQ)
실사      계속 지켜본다 — 재고 기록이 늘 최신이어야 한다
안전재고  조달기간 동안의 변동만 대비 → 상대적으로 적다
적합      단가가 높고 중요한 품목 (ABC 의 A 등급)

정기주문모형 (P 시스템, 정기실사):
언제      정해진 주기마다 (매주 월요일 등)
얼마나    최대재고수준까지 채울 만큼 — 주문량이 매번 다르다
실사      주기마다만 센다 — 관리가 쉽다
안전재고  주기 + 조달기간 전체를 대비 → 더 많이 쌓아야 한다
적합      단가가 낮고 여러 품목을 한 거래처에서 받을 때 (B·C 등급)
```

핵심 대비 한 줄

```
정량 = 양이 고정, 시점이 변동 · 정기 = 시점이 고정, 양이 변동
```

### (3) JIT (Just in Time) / 도요타 시스템 / 린(Lean) 시스템

**"필요한 것을, 필요한 때에, 필요한 만큼만 생산한다."** 낭비 제거가 핵심 철학.

- **특징**: 무재고(Zero Inventory) 지향, 풀(Pull) 시스템(칸반 방식), 소규모 로트 사이즈, 작업장 부하 균일화(평준화), 셀룰러 배치, 포카요케(실수방지).

### (4) 공급사슬관리 (SCM)

자재 공급자부터 최종 고객까지 이어지는 사슬 전체의 물류, 정보, 자금을 통합 관리.

<Callout type="warning">
  **채찍효과 (Bullwhip Effect)** 하류(고객)에서 상류(공급자)로 갈수록 수요의
  변동 폭이 증폭되는 현상. *원인*: 정보 공유 부재, 긴 리드타임, 일괄 주문 등.
  *해결책*: 리드타임 단축 격파, 파트너 간 정보 공유(EDI, POS), 직배송.
</Callout>

**채찍효과 지연 전략 (지연차별화 전략)**: 제품을 끝까지 미완성 상태로 두었다가, 고객의 요구가 확정되는 시점에 최종 맞춤 조립 (예: 베네통 염색).

## 5. 제약이론과 가치분석

### (1) 제약이론 (TOC, Theory of Constraints)

골드랫(Goldratt)의 『The Goal』에서 나온 관점이다. **전체 산출은 가장 느린
공정(병목, bottleneck)이 정한다**는 한 문장이 핵심이다.

- 병목이 아닌 곳을 아무리 개선해도 전체 산출은 늘지 않는다. 오히려 재공품만
  쌓인다.
- 개선 5단계 (Five Focusing Steps)

```
① 제약 발견 (Identify)      어디가 병목인가
② 제약 활용 (Exploit)       그 자원을 놀리지 않는다
③ 나머지 종속 (Subordinate) 다른 공정을 병목 속도에 맞춘다
④ 제약 향상 (Elevate)       그래도 부족하면 능력을 늘린다
⑤ 반복 (Repeat)             병목이 옮겨가면 ①로 돌아간다
```

- **DBR(Drum-Buffer-Rope)**: 병목이 북(drum)처럼 박자를 정하고, 그 앞에
  완충재고(buffer)를 두며, 자재 투입을 밧줄(rope)로 병목 속도에 묶는다.
- TOC 의 성과 지표는 원가가 아니라 **스루풋(throughput)·재고·운영비용** 셋이다.

### (2) 가치분석 / 가치공학 (VA / VE)

마일즈(Miles)가 GE 에서 시작했다. **기능을 유지하면서 원가를 낮추는** 접근이다.

```
가치 = 기능 / 원가
```

이 식을 올리는 길은 넷이다 — 기능 유지·원가 절감 / 기능 향상·원가 유지 /
기능 향상·원가 절감 / 기능 크게 향상·원가 약간 상승.

- **VA(Value Analysis)**: 이미 생산 중인 제품을 대상으로 한다.
- **VE(Value Engineering)**: 설계 단계에서 미리 한다 — 효과가 더 크다.
- 묻는 질문은 "이 부품이 무슨 **기능**을 하는가, 그 기능을 더 싸게 낼 방법은
  없는가"다. 부품을 깎는 게 아니라 **기능 단위로** 본다.

### 기업연계 정보시스템

- **ERP (전사적 자원관리)**: 전사적 비즈니스 프로세스 통합(재무, 인사, 생산 통합 데이터베이스).
- **CRM (고객관계관리)**: 평생고객가치 극대화를 위한 고객 데이터 수집 및 선별적 마케팅.
- **SCM (공급사슬관리)**: 자재, 정보 조달 최적화.
- **KMS (지식관리시스템)**: 기업 내 암묵지/형식지를 디지털화하여 공유.
