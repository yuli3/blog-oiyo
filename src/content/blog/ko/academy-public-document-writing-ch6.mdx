## 공문서 양식의 종류

행정 업무 목적에 따라 다른 양식 사용.

```
주요 공문서 양식:
① 기안문: 내부 의사 결정 요청
② 보고서: 상위 기관·직책에 현황·결과 보고
③ 통보문: 결정 사항·정보를 하급 기관에 전달
④ 협조문: 타 부서·기관에 협조 요청
⑤ 회의록: 회의 안건·결과·참석자 기록
⑥ 지시문: 상급 기관이 하급 기관에 명령·지시
```

## 기안문 작성법

### 기안문 구조

```
기안문 기본 구조:
[두문]
  수신: 내부 결재권자 (또는 경유 기관)
  제목: ~에 관한 기안

[본문]
  1. 배경·목적
  2. 현황·내용
  3. 추진 방향 (또는 조치 사항)
  4. 기대 효과 (필요 시)
  붙임: 첨부 자료 목록

[결문]
  담당자: 이름·연락처·기안일
```

### 기안문 작성 요령

```
목적 명확화:
- 결재받고자 하는 내용이 무엇인지 첫 문단에 명시
- "~에 관하여 결재를 요청드립니다" 형식

근거 제시:
- 법령·규정·상위 지시 명시
- "○○법 제○조에 따라"

예산·일정 포함:
- 소요 예산, 시행 일정 반드시 포함
- 숫자는 구체적으로 (단위 명시)

나쁜 예:
"예산을 적절히 확보하겠습니다."
좋은 예:
"소요 예산: 3,500만 원 (2026년 1/4분기 본예산)"
```

## 보고서 작성법

### 보고서 유형

```
업무 보고서 종류:
① 주간 보고: 추진 현황·다음 주 계획
② 사업 결과 보고: 사업 완료 후 성과 정리
③ 현황 분석 보고: 수치·통계 기반 현황 제시
④ 문제 상황 보고: 이슈 발생 즉시 보고

보고서 3요소:
현황 (What happened) → 원인 분석 (Why) → 대책 (What to do)
```

### 보고서 작성 요령

```
두괄식 구성:
- 핵심 결론·요청 사항을 앞에 제시
- 상위 직책은 전체를 읽지 않을 수 있음

수치 활용:
- "증가했습니다" → "전월 대비 15% 증가(2,300건→2,645건)"
- 표·그래프 첨부 시 본문에 요약 수치 포함

사실과 의견 분리:
- 현황: 객관적 사실
- 분석·의견: 명확히 구분 ("~으로 분석됩니다")
```

## 통보문과 협조문

### 통보문

```
통보문 = 결정 사항·정보를 수신 기관에 전달

기본 구조:
수신: 하급 기관 또는 관계 기관
제목: ○○ 통보
본문:
  ○○에 관하여 다음과 같이 통보합니다.
  1. 통보 내용 (구체적 사항)
  2. 시행 일자
  3. 문의처

표현 예시:
"○○에 관하여 다음 사항을 통보하오니 업무에 참고하시기 바랍니다."
```

### 협조문

```
협조문 = 타 부서·기관에 협조 요청

기본 구조:
수신: 협조 요청 기관
제목: ○○에 관한 협조 요청
본문:
  협조 사항 구체 기술
  마감 기한 명시
  담당자 연락처

표현 예시:
"○○ 업무 추진을 위해 아래와 같이 협조를 요청드리오니 적극적인 협조 부탁드립니다."

주의: "부탁드립니다" 남발 지양
→ 공식적이고 명확한 기한·사항 제시가 핵심
```

## 회의록 작성법

```
회의록 필수 항목:
① 회의명 (회의 종류)
② 일시·장소
③ 참석자 (직위·이름)
④ 회의 목적·안건
⑤ 논의 내용 (요약)
⑥ 결정 사항
⑦ 후속 조치·담당자·기한

작성 원칙:
- 발언자 이름·직위 병기
- 결정 사항은 굵게 강조 또는 별도 항목
- 이의·반대 의견도 기록 (생략 금지)
- 수정 발의 시 원안·수정안 모두 기록
```

## 핵심 개념 카드

**기안문 핵심 요소** ★★★★★
: 배경→현황→추진방향→기대효과 순. 예산·일정 숫자 구체화 필수.
*암기 포인트: 기안=배경+현황+방향+예산+일정*

**두괄식 보고서** ★★★★★
: 결론을 앞에 쓰고 근거를 뒤에. 상위 직책이 첫 단락만 읽어도 핵심 파악 가능하게.
*암기 포인트: 결론→근거→대책 순*

**통보문 vs 협조문** ★★★★☆
: 통보=결정사항 전달(일방). 협조=타 기관에 도움 요청(쌍방).
*암기 포인트: 통보=전달, 협조=요청*

## 실전 퀴즈

**Q. 보고서에서 "증가하고 있는 상황입니다"를 어떻게 고쳐야 하는가?**
> "전월 대비 12% 증가(1,200건→1,344건)하였습니다." — 수치 명시 + 피동·명사화 표현 제거.

**Q. 협조문을 작성할 때 가장 중요하게 포함해야 할 내용은?**
> 구체적인 협조 사항, 마감 기한, 담당자 연락처. 모호한 요청이 아닌 명확한 업무·기한 제시.
