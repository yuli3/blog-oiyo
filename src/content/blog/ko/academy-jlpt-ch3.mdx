## N2 레벨 이해

```
N2 레벨 기준:
→ 일상적 상황과 다양한 범위 주제의 글을 이해 가능
→ 신문·잡지 일부, 비즈니스 문서 이해 수준
→ 어휘: 약 6,000~10,000단어

N2 시험 구성:
→ 언어지식(문자·어휘): 35분 (60점)
→ 언어지식(문법)·독해: 105분 (60점)
→ 청해: 50분 (60점)
→ 합격 기준: 각 과목 19점 이상, 총 90점 이상 (180점 만점)

N2의 실용적 가치:
→ 일본 대학 입학 요건 (일부 학교)
→ 일본 기업 취업 기본 요건
→ 통·번역 업무 진입점
→ 한국인 학습자 도달 목표 1순위

N2 합격 전략:
→ N3 합격 후 6~12개월 집중
→ 문법 400개 완전 마스터
→ 매일 독해 500자 이상 읽기
→ 청해: 드라마·뉴스로 실력 강화
```

## N2 핵심 문법 패턴 1 — 관계·비교

```
~にとって (입장·관점):
→ 의미: ~에게 있어서, ~의 입장에서는
→ 学生にとって、時間は貴重だ
  (학생에게 있어서 시간은 귀중하다)
→ 사람·집단에 대한 의미·가치 표현

~に対して (대상·대립):
→ 의미: ~에 대해서, ~에게 (대상)
→ 彼に対して厳しく言いすぎた
  (그에게 너무 엄하게 말했다)
→ 대조·역접 의미도: 親は賛成なのに対して、子は反対だ
  (부모는 찬성인 데 반해 아이는 반대다)

~を通じて / ~を通して (수단·경로):
→ 의미: ~을 통해서
→ メディアを通じて情報が広まった
  (미디어를 통해 정보가 퍼졌다)
→ 期間全体: 一年を通じて温かい
  (일 년 내내 따뜻하다)

~に関して / ~に関する (관련):
→ 의미: ~에 관해서, ~에 관한
→ この件に関しては後で話し合おう
  (이 건에 관해서는 나중에 이야기하자)
→ ~について와 유사하지만 더 공식적
```

## N2 핵심 문법 패턴 2 — 양보·조건·한정

```
~にもかかわらず (역접):
→ 의미: ~임에도 불구하고
→ 雨にもかかわらず、試合は行われた
  (비가 오는데도 불구하고 경기가 진행되었다)
→ 격식체, 접속사로도 사용

~はもとより (당연·추가):
→ 의미: ~은 물론이고, ~은 말할 것도 없고
→ 彼は英語はもとより、中国語も話せる
  (그는 영어는 물론이고 중국어도 말할 수 있다)

~に限り / ~に限らず:
→ ~に限り: ~에 한해서, ~만 (한정)
→ 本日に限り、割引します (오늘에 한해 할인합니다)
→ ~に限らず: ~뿐만 아니라 (확장)
→ 若者に限らず、老人も使う
  (젊은이뿐만 아니라 노인도 쓴다)

~ものの (역접):
→ 의미: ~이지만, ~이기는 하지만
→ 日本語は勉強したものの、まだ話せない
  (일본어를 공부하기는 했지만 아직 말 못한다)
→ 기대와 현실이 다를 때

~上は (이상은):
→ 의미: ~한 이상은, ~한 바에는
→ 引き受けた上は、最後までやり遂げる
  (맡은 이상은 끝까지 해낸다)
```

## N2 필수 어휘

```
N2 비즈니스·사회 어휘:
→ 批判 (ひはん): 비판
→ 主張 (しゅちょう): 주장
→ 提案 (ていあん): 제안
→ 評価 (ひょうか): 평가
→ 影響 (えいきょう): 영향
→ 効果 (こうか): 효과
→ 方針 (ほうしん): 방침
→ 基準 (きじゅん): 기준

고빈도 복합어·관용 표현:
→ 必ずしも~ない: 반드시 ~한 것은 아니다
→ 少なくとも: 적어도
→ いかに: 어떻게 (의문), 얼마나 (강조)
→ せめて: 적어도, 최소한 (소망)
→ いずれ: 언젠가, 어차피
→ まさか~ないだろう: 설마 ~하지 않겠지

N2 부사 정리:
→ かえって: 오히려
→ いきなり: 갑자기 (N3 수준이지만 N2서 심화)
→ あいにく: 공교롭게도, 안타깝게도
→ そもそも: 애초에, 원래
→ 相変わらず (あいかわらず): 여전히, 변함없이
→ むやみに: 함부로, 무분별하게
→ おのずと: 자연히, 저절로
```

## N2 독해 전략

```
N2 독해 유형:

중문 독해 (500~700자):
→ 3~4단락 글 (설명문, 논설문, 에세이)
→ 문제 유형: 필자 의도·주장, 내용 일치
→ 전략:
  ① 설문 먼저 읽어 키워드 파악
  ② 단락별 주제 파악 (첫·마지막 문장)
  ③ 역접 표현 뒤에 주장

장문 독해 (1000자 이상):
→ 두 단락 비교·대조 형식 자주 출제
→ 의문·문제 제기 → 논거 → 결론 구조 파악

정보 검색:
→ 표·공지·안내문에서 필요 정보 찾기
→ 조건·예외 사항 주의

독해 핵심 표현:
→ ~ではなく: ~가 아니라 (주장 강조)
→ ~というのは: ~라는 것은 (정의)
→ 言い換えれば: 바꿔 말하면
→ したがって/そのため: 따라서
→ ところが: 그런데 (예상 외)
→ むしろ: 오히려 (역전)

N2 독해 시간 배분 (105분):
→ 문법: 30~35분
→ 독해: 70~75분 (1문제당 3~4분)
→ 시간 부족 방지: 쉬운 문제 먼저
```

## 자주 묻는 질문

**Q. N2 문법 400개를 어떻게 효율적으로 암기하나요?**
A. 무작정 암기보다 패턴 분류로 접근하는 것이 효율적입니다. 비슷한 의미 그룹(역접·조건·시간·한정 등)으로 묶어 비교하며 학습하면 혼동을 줄일 수 있습니다. 예문을 통해 문맥에서 자연스럽게 이해하는 것이 중요하며, 직접 예문을 만들어 보는 것도 기억 강화에 효과적입니다. JLPT 기출 문제집으로 자주 나오는 문법을 우선적으로 공략하세요.

**Q. N2 청해는 어떻게 준비하나요?**
A. N2 청해는 실생활 속도의 빠른 일본어를 이해해야 합니다. 드라마와 영화로 자연스러운 발화 패턴에 익숙해지고, NHK Web Easy(쉬운 뉴스)와 NHK Podcast로 실제 뉴스 청취에 도전하세요. 받아쓰기(dictation)도 청해와 문법 실력을 동시에 기르는 좋은 방법입니다. 특히 N2 청해는 첫 문장에서 상황·화제를 빠르게 파악하는 연습이 중요합니다.
