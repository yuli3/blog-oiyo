## IFRS 기본 프레임워크

```
재무보고 목적:
일반 목적 재무보고
의사결정 유용성

재무제표 구성:
재무상태표
포괄손익계산서
자본변동표
현금흐름표
주석

질적 특성:
근본: 목적 적합성·충실한 표현
보강: 비교가능성·검증가능성·적시성·이해가능성
```

## 유형자산 회계처리

```
취득 원가:
구입가 + 취득 부대비용
차입원가 자본화 (적격자산)

감가상각:
정액법: (취득원가-잔존가치)/내용연수
정률법: 미상각잔액 × 상각률
생산량비례법

손상차손:
회수가능액 < 장부금액 → 손상
회수가능액 = MAX(순공정가치, 사용가치)

재평가모형:
공정가치로 재평가
재평가잉여금 → 기타포괄손익
```

## 금융자산 분류 (IFRS 9)

```
상각후원가(AC):
원리금만 지급, 보유 목적
이자수익 유효이자율법

기타포괄손익 공정가치(FVOCI):
원리금 지급 + 매도 목적
평가손익 → 기타포괄손익

당기손익 공정가치(FVPL):
그 외
평가손익 → 당기손익

기대신용손실:
손상 인식: 12개월·전체기간 ECL
Stage 1→2→3 으로 이동
```

## 충당부채와 우발부채

```
충당부채:
현재 의무 + 자원 유출 가능 + 신뢰성 추정
재무상태표에 계상

우발부채:
의무 가능성 or 금액 추정 불가
주석 공시 (재무상태표 계상 불가)

우발자산:
거의 확실: 자산 인식
가능성 높음: 주석 공시
가능성 낮음: 무시
```

## 핵심 개념 카드

**IFRS 재무제표=5종류** ★★★★★
: 재무상태표·포괄손익·자본변동·현금흐름·주석.
*암기 포인트: 재포자현주*

**손상=회수가능액&lt;장부금액** ★★★★★
: 회수가능액=MAX(순공정가치, 사용가치).
*암기 포인트: 손상=장부>회수*

**충당부채 3요건** ★★★★☆
: 현재의무+자원유출가능+신뢰성추정.
*암기 포인트: 현유신*

## 실전 퀴즈

**Q. 유형자산 재평가 시 재평가잉여금이 기타포괄손익인 이유는?**
> 영업활동과 무관한 자산 가치 변동은 당기손익 아닌 기타포괄손익. 실현되지 않은 이익을 손익계산서에 반영 시 이익 과대 표시 우려. 재평가잉여금은 자본에 직접 반영. 후속 감가상각 시 이익잉여금으로 대체 가능.

**Q. 충당부채와 우발부채를 구별하는 핵심 기준은?**
> 충당부채: 현재 의무 확실 + 자원 유출 가능성 높음 + 금액 신뢰성 있게 추정 → 계상. 우발부채: 의무 불확실 또는 가능성 낮음 또는 추정 불가 → 주석 공시. 소송 중인 경우: 패소 가능성 높고 추정 가능 → 충당부채.
