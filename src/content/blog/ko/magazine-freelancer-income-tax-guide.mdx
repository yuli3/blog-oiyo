## 프리랜서라면 반드시 알아야 할 종합소득세

직장인은 연말정산으로 세금이 정리되지만, 프리랜서와 N잡러는 **매년 5월 종합소득세 신고**를 직접 해야 합니다. 신고를 놓치거나 잘못하면 가산세까지 붙습니다.

---

## 종합소득세 신고 대상

### 반드시 신고해야 하는 경우

| 소득 유형 | 신고 의무 |
|---------|---------|
| **사업소득** (프리랜서·자영업) | 금액 무관, 반드시 신고 |
| **근로+사업소득** (직장+부업) | 반드시 신고 (연말정산과 별도) |
| **기타소득** 연 300만원 초과 | 신고 의무 |
| **임대소득** 연 2,000만원 초과 | 신고 의무 |

### 신고 기간

```
신고 기간: 매년 5월 1일 ~ 5월 31일
납부 기한: 5월 31일 (분납 가능: 6월·9월)
장부 미작성 시 추정 신고: 기한 내 신고
```

---

## 소득 구분: 사업소득 vs 기타소득

많은 프리랜서가 헷갈려하는 부분입니다.

| 구분 | 사업소득 | 기타소득 |
|------|---------|---------|
| 정의 | 계속·반복적 소득 | 일시적·우발적 소득 |
| 예시 | 유튜브 광고비, 디자인 외주, 강의 | 원고료(일시), 강연료(1회) |
| 원천징수율 | 3.3% | 8.8% (20% × 44%) |
| 필요경비 | 실제 경비 or 경비율 | 수입의 60% 자동 공제 |

> **포인트**: 기타소득으로 받으면 60% 경비 자동 공제 → 소득이 낮을 때 유리. 사업소득으로 받으면 실제 경비를 더 많이 공제 가능 → 소득이 높을 때 유리.

---

## 3.3% 원천징수와 종합소득세의 관계

```
클라이언트가 계약서 없이 100만원 지급 →
실수령: 96.7만원 (3.3% 원천징수)

→ 3.3만원은 '선납 세금'
→ 5월 신고 후:
   - 내 세금이 3.3만원보다 낮으면 → 환급
   - 내 세금이 3.3만원보다 높으면 → 추가 납부
```

**환급 받는 케이스**: 연 수입이 낮거나 경비가 많아 실제 세금이 원천징수액보다 적을 때.

## 비용 처리 (경비 인정 항목)

경비를 많이 인정받을수록 세금이 줄어듭니다.

### 인정되는 주요 경비

| 항목 | 내용 | 증빙 |
|------|------|------|
| **사무용품·소프트웨어** | 업무용 노트북, 구독료 | 카드 영수증 |
| **통신비** | 업무용 핸드폰 요금 (50~100%) | 통신사 청구서 |
| **교통비** | 업무 관련 이동 (대중교통·택시·KTX) | 카드 내역 |
| **교육비** | 업무 관련 강의, 책 구입 | 영수증 |
| **식비·접대비** | 업무 관련 식사 (한도 있음) | 세금계산서 |
| **임차료** | 작업실, 스튜디오 임대 | 계약서+이체 내역 |
| **인건비** | 보조 인력 급여 | 원천세 신고 |

### 자택 업무 시 경비 처리

```
자택 면적 중 업무 공간 비율만큼 임차료 경비 처리 가능
예: 원룸 30㎡, 책상 공간 5㎡ → 임차료의 약 17% 경비 인정
```

## 신고 방법: 단순경비율 vs 기장

### 단순경비율 신고 (소규모 프리랜서)

장부를 작성하지 않고 국세청이 정한 **경비율을 자동 적용**하는 방법.

| 업종 | 단순경비율 (2024년 기준 예시) |
|------|--------------------------|
| 디자인·IT 서비스 | 64.1% |
| 학원·교육 | 61.4% |
| 작가·강사 | 72.7% |
| 유튜버·인플루언서 | 56.0% |

```
수입 1,000만원 × (1 - 64.1%) = 과세 소득 358.5만원
→ 세율 6% 적용 → 세금 약 21.5만원
```

**대상**: 직전 연도 수입 기준 업종별 기준금액 이하 (서비스업: 3,600만원 이하)

### 기장 신고 (수입이 많은 프리랜서)

실제 수입과 지출을 **장부에 기록**하고 신고.

- **간편장부**: 소규모 사업자 대상, 수입·지출 기록
- **복식부기**: 수입 일정 이상이면 의무

> **절세 포인트**: 실제 경비가 단순경비율보다 많으면 기장 신고가 유리.

## 홈택스 신고 절차 (단계별)

### 1단계: 홈택스 로그인 및 신고서 불러오기

```
홈택스(hometax.go.kr) → 로그인 → 세금 신고 → 종합소득세
→ '신고서 작성하기' 클릭
→ 소득 자료 자동 조회 (3.3% 원천징수 내역 자동 반영)
```

### 2단계: 소득 확인

```
- 사업소득: 원천징수 내역 자동 불러옴
- 기타소득: 별도 확인 필요
- 근로소득: 연말정산 완료분 자동 포함
→ 누락 소득 수동 입력
```

### 3단계: 경비 입력 (단순경비율 또는 기장)

```
단순경비율 선택 시: 자동 계산
기장 선택 시: 경비 항목별 직접 입력
→ 증빙 서류는 보관 (5년), 신고 시 첨부 불필요
```

### 4단계: 공제 항목 입력

```
인적공제: 본인 150만원, 부양가족 1인당 150만원
연금보험료 공제: 납입 국민연금 전액
노란우산공제: 사업소득자 전용, 연 500만원까지 소득 공제
개인연금·IRP: 연 900만원 한도 세액공제
```

### 5단계: 세액 계산 및 신고

```
과세표준 × 세율 = 산출세액
- 세액공제 적용
= 결정세액
- 기납부세액 (3.3% 원천징수 합계)
= 납부(또는 환급) 세액
```

## 세율표 (2024년 기준)

| 과세표준 | 세율 | 누진공제 |
|---------|------|---------|
| 1,400만원 이하 | 6% | - |
| 1,400~5,000만원 | 15% | 126만원 |
| 5,000~8,800만원 | 24% | 576만원 |
| 8,800~1.5억원 | 35% | 1,544만원 |
| 1.5억~3억원 | 38% | 1,994만원 |
| 3억~5억원 | 40% | 2,594만원 |
| 5억원 초과 | 42% | 2,994만원 |

> **지방소득세**: 산출세액의 10% 추가 납부

## 절세 전략 5가지

### 전략 1: 노란우산공제 가입

소기업·소상공인 공제 제도로 사업소득자라면 필수.

```
연 납입 한도: 500만원
소득 공제: 납입액 전액 (사업소득 4,000만원 이하)
실질 절세: 500만원 × 24% = 연 120만원 절세 (5,000만원 소득 기준)
```

### 전략 2: 개인형 IRP + 연금저축 최대 활용

```
연금저축펀드: 연 600만원 한도
IRP: 연 300만원 추가 (합산 900만원)
세액공제율: 총급여 5,500만원 이하 → 16.5%
최대 환급: 900만원 × 16.5% = 148.5만원
```

### 전략 3: 경비 증빙 철저히 모으기

```
업무 관련 지출은 반드시 사업자 카드 or 현금영수증 사업자등록번호 입력
→ 경비 인정률 높임 → 과세 소득 감소
```

### 전략 4: 사업자등록 여부 검토

프리랜서도 사업자등록을 하면:
- 부가세 환급 가능 (일반과세자)
- 경비 처리 폭 넓어짐
- 단, 부가가치세 신고 의무 추가

### 전략 5: 분납 활용

납부 세액이 1,000만원 초과 시 **2회 분납** 가능.

```
1회: 5월 31일 납부 (50%)
2회: 6월 30일 납부 (나머지 50%)
→ 자금 유동성 관리에 유리
```

## 자주 묻는 질문

**Q. 직장 다니면서 유튜브 부업 중인데 신고해야 하나요?**
A. 네. 유튜브 수익은 사업소득. 회사에서 연말정산을 하더라도 부업 소득이 있으면 5월에 합산 신고 해야 합니다. 단, 부업 소득이 연 150만원 이하이고 분리과세 선택 시 제외 가능한 경우도 있습니다.

**Q. 3.3% 뗐는데 신고 안 해도 되나요?**
A. 3.3%는 선납 세금이지 최종 세금이 아닙니다. 반드시 5월에 신고해야 합니다. 신고 안 하면 무신고 가산세(20%) + 납부불성실 가산세가 붙습니다.

**Q. 작년에 수입이 거의 없었는데도 신고해야 하나요?**
A. 사업소득이 있으면 금액에 관계없이 신고 의무가 있습니다. 다만, 실제 세금이 원천징수액보다 적으면 환급받을 수 있으니 신고를 해야 환급도 됩니다.

**Q. 세무사에게 맡기면 얼마나 드나요?**
A. 단순경비율 신고: 10~20만원 / 기장 신고: 월 5~15만원 수준. 수입이 연 3,000만원 이상이거나 경비가 복잡하면 세무사 활용을 추천합니다.
