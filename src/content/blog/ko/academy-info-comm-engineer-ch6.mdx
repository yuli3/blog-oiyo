## 전송과 교환의 차이

전송 기술은 신호나 데이터를 얼마나 안정적으로 보내는가에 초점을 둡니다. 반면 교환 기술은 여러 사용자와 목적지 사이에서 어느 경로로 연결할 것인가를 다룹니다. 두 영역은 분리되어 보이지만 실제 통신망에서는 전송 품질과 경로 선택이 함께 서비스 품질을 만듭니다.

### 비교 정리

| 구분 | 핵심 질문 |
|---|---|
| 전송 | 어떤 매체와 방식으로 신호를 보낼 것인가 |
| 다중화 | 여러 신호를 어떻게 한 회선에 실을 것인가 |
| 동기화 | 송수신 타이밍을 어떻게 맞출 것인가 |
| 회선교환 | 통신 동안 전용 경로를 유지할 것인가 |
| 패킷교환 | 데이터를 나누어 독립적으로 보낼 것인가 |

다중화는 자원을 효율적으로 쓰기 위한 기술입니다. 시간, 주파수, 코드, 파장 같은 기준으로 여러 신호를 한 전송로에 실을 수 있습니다. 동기화는 송신자와 수신자가 같은 기준으로 데이터를 해석하도록 맞추는 과정입니다.

## 회선교환과 패킷교환

회선교환은 연결을 설정한 뒤 일정한 경로를 유지하므로 예측 가능한 품질을 제공하기 쉽습니다. 패킷교환은 데이터를 작은 단위로 나누어 보내므로 자원 활용이 좋고 인터넷 구조와 잘 맞습니다. 시험에서는 어느 방식이 절대적으로 우월한지보다 지연, 효율, 신뢰성, 장애 대응의 차이를 비교하는 문제가 중요합니다.

## 핵심 요약

- 전송은 보내는 방식, 교환은 연결과 경로 선택의 문제입니다.
- 다중화와 동기화는 전송 효율과 품질을 좌우합니다.
- 회선교환과 패킷교환은 지연, 효율, 연결 방식으로 비교하세요.
