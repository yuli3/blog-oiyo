## HSK 3-4급 레벨 이해

```
HSK 3급:
→ 생활·학습·업무 기본 교류 가능 수준
→ 어휘: 600단어 (누계)
→ 시험: 듣기(40문항) + 독해(30문항) + 쓰기(10문항)
→ 총점 300점, 180점 이상 합격
→ 유학, 취업 기초 요건

HSK 4급:
→ 다양한 주제로 원어민과 유창한 소통 가능
→ 어휘: 1,200단어 (누계)
→ 시험: 듣기(45문항) + 독해(40문항) + 쓰기(15문항)
→ 총점 300점, 180점 이상 합격
→ 중국 대학 입학·교환 학생 기본 요건

한국인 학습 시간:
→ HSK 3급: 약 150~200시간 (전혀 모름 기준)
→ HSK 4급: 추가 200~300시간
→ 대학 중어중문학과 2~3학년 수준
```

## HSK 3급 핵심 문법

```
把 구문 (ba 구문):
→ 목적어를 동사 앞으로 이동, 처치 강조
→ 구조: 주어 + 把 + 목적어 + 동사 + 결과·방향보어
→ 我把作业做完了。(나는 숙제를 다 했다)
→ 我把书放在桌子上。(나는 책을 책상 위에 놓았다)
→ 주의: 把 뒤에는 반드시 특정 명사, 동사 홀로 불가

被 구문 (bei 구문):
→ 수동 표현: ~에 의해 ~당하다
→ 구조: 주어 + 被 + 행위자 + 동사 + 기타
→ 我的手机被弟弟摔坏了。
  (나의 핸드폰이 동생에 의해 떨어져 망가졌다)
→ 행위자 생략 가능

比 비교 구문:
→ A 比 B 형용사: A가 B보다 ~하다
→ 今天比昨天冷。(오늘은 어제보다 춥다)
→ 정도 추가: A 比 B + 형용사 + 得多/一点/多了
→ 今天比昨天冷多了。(오늘은 어제보다 훨씬 춥다)
→ 부정: A 没有 B + 형용사 (A가 B만큼 ~하지 않다)
```

## HSK 3급 보어 정리

```
결과보어:
→ 동사 + 完/好/到/懂/错/见/住/开...
→ 吃完 (다 먹다), 做好 (잘 하다), 听懂 (듣고 이해하다)
→ 부정: 没 + 동사 + 결과보어
→ 我没吃完。(나는 다 못 먹었다)

방향보어:
→ 동사 + 来/去/上/下/进/出/回/过/起
→ 走进来 (걸어 들어오다), 拿出去 (꺼내 가다)

가능보어:
→ 동사 + 得/不 + 결과·방향보어
→ 看得懂 (이해할 수 있다) vs 看不懂 (이해 못 한다)
→ 我听不懂他说的话。
  (나는 그가 하는 말을 이해 못 한다)

정도보어:
→ 동사/형용사 + 得 + 정도 표현
→ 他跑得很快。(그는 달리기가 매우 빠르다)
→ 今天热得不能出去。
  (오늘 더워서 나갈 수가 없다)
```

## HSK 4급 핵심 문법

```
连~都/也 (심지어 ~도):
→ 连 + 목적어 + 都/也 + 동사
→ 他连饭都没吃。(그는 밥조차도 먹지 않았다)
→ 我连他的名字都不知道。
  (나는 그의 이름조차 모른다)

只要~就 (~하기만 하면):
→ 只要 + 조건절 + 就 + 결과절
→ 只要努力，就会成功。
  (노력하기만 하면 성공할 것이다)

既然~就 (이미 ~한 이상):
→ 既然 + 사실절 + 就 + 판단
→ 既然你不喜欢，就别去了。
  (이미 좋아하지 않는 이상 가지 마라)

虽然~但是/可是 (비록 ~이지만):
→ 虽然 + 양보절 + 但是 + 주요 주장
→ 虽然很累，但是很开心。
  (비록 힘들지만 매우 즐겁다)

不管~都 (어떠해도):
→ 不管 + 조건 + 都 + 결과
→ 不管多忙，都要锻炼。
  (얼마나 바빠도 운동해야 한다)
```

## HSK 4급 필수 어휘 카테고리

```
감정·태도:
→ 激动 (jīdòng): 흥분하다, 감격하다
→ 感激 (gǎnjī): 감격하다, 고마워하다
→ 后悔 (hòuhuǐ): 후회하다
→ 犹豫 (yóuyù): 망설이다
→ 担心 (dānxīn): 걱정하다
→ 紧张 (jǐnzhāng): 긴장하다

사회·생활:
→ 环境 (huánjìng): 환경
→ 经济 (jīngjì): 경제
→ 文化 (wénhuà): 문화
→ 社会 (shèhuì): 사회
→ 发展 (fāzhǎn): 발전하다
→ 影响 (yǐngxiǎng): 영향(을 주다)

고빈도 동사:
→ 提高 (tígāo): 높이다, 향상시키다
→ 解决 (jiějué): 해결하다

→ 表示 (biǎoshì): 나타내다, 표현하다
→ 增加 (zēngjiā): 증가하다
→ 改变 (gǎibiàn): 바꾸다, 변화하다

고빈출 부사:
→ 尤其 (yóuqí): 특히
→ 终于 (zhōngyú): 드디어, 결국
```

## 독해·쓰기 전략

```
HSK 독해 전략:

3급 독해:
→ 일치하는 문장 고르기: 핵심어 대조
→ 빈칸 채우기: 문맥, 연결어 파악
→ 단문 독해: 주요 정보 추출

4급 독해:
→ 문장 순서 배열: 첫 문장·마지막 문장 찾기
→ 빈칸 채우기: 접속사·부사 패턴
→ 중문 독해: 주제문 파악, 세부 사항 확인

핵심 접속사 패턴:
→ 虽然~但是 / 尽管~还是 (역접)
→ 因为~所以 / 由于~因此 (인과)
→ 不仅~还 / 不但~而且 (추가)
→ 如果~就 / 要是~就 (가정)

쓰기 전략:

3급: 어순 배열
→ 주어 + 시간/장소 + (把/被) + 동사 + 보어 + 목적어

4급: 어순 배열 + 조건절 구문
→ 접속 관계(因果·转折·条件) 파악
→ 연결어(因为·虽然·只要) 먼저 확인
```

## 자주 묻는 질문

**Q. HSK 4급이면 중국 취업이 가능한가요?**
A. HSK 4급은 중국 대학 교환 학생이나 관련 업무 지원의 기초 요건으로 활용됩니다. 실제 중국 기업 취업이나 중국어 통역·번역 업무를 위해서는 HSK 5~6급이 필요합니다. 한국 기업의 중국어 관련 업무는 HSK 4~5급 + 회화 능력을 함께 요구하는 경우가 많습니다.

**Q. 把 구문은 언제 반드시 사용해야 하나요?**
A. 把 구문은 필수가 아니라 선택적이지만, 목적어를 처치(처리·변화·이동)했을 때 결과를 강조하고 싶을 때 자연스럽습니다. 특히 동사 뒤에 결과보어나 방향보어가 올 때, 또는 목적어가 특정·한정된 것일 때 把를 쓰는 것이 자연스럽습니다.
