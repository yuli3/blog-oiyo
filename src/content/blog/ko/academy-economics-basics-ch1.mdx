## 경제학의 의의

**경제학(Economics)**: 희소한 자원을 어떻게 배분할 것인가를 연구하는 학문.

```
경제학의 핵심 문제:
① 무엇을 얼마나 생산할 것인가? (What)
② 어떻게 생산할 것인가? (How)
③ 누구를 위해 생산할 것인가? (For Whom)

미시경제학: 개인·기업·시장의 의사결정
거시경제학: 국민소득·물가·실업·환율 등 국가 경제 전체
```

---

## 희소성과 선택

```
희소성 (Scarcity):
- 인간의 욕구는 무한, 자원은 유한
- 모든 경제 문제의 근원

선택의 필요성:
- 희소성 → 선택 불가피
- 선택 = 무언가를 포기

비용 개념:
- 명시적 비용: 실제로 지출한 금액
- 암묵적 비용: 포기한 대안의 가치
- 경제적 비용 = 명시적 + 암묵적 비용
```

## 기회비용과 매몰비용

### 기회비용 (Opportunity Cost)

```
기회비용: 어떤 선택을 함으로써 포기한 최선의 대안의 가치

예시:
대학 진학 vs 취업
→ 대학 진학의 기회비용 = 취업 시 얻을 수 있는 임금 + 학비

핵심:
- 기회비용 = 포기한 것 중 가장 좋은 것
- 여러 대안 포기해도 기회비용은 하나 (최선의 대안)
```

### 매몰비용 (Sunk Cost)

```
매몰비용: 이미 지출되어 회수 불가능한 비용
→ 의사결정 시 고려하지 않아야 함

매몰비용의 오류:
"이미 3,000만 원 투자했으니 포기할 수 없다"
→ 3,000만 원은 매몰비용 → 미래 수익만 고려해야 함

합리적 결정 기준:
한계편익 > 한계비용 → 계속 추진
한계편익 < 한계비용 → 중단
```

## 생산가능곡선 (PPF)

```
생산가능곡선 (Production Possibility Frontier):
- 주어진 자원·기술로 최대 생산 가능한 조합
- 곡선 위: 효율적 생산
- 곡선 안쪽: 비효율 (자원 낭비)
- 곡선 바깥: 현재 불가능 (기술 발전 시 가능)

PPF의 기울기 = 기회비용
기울기 체증 (오목): 기회비용 체증의 법칙
→ X재 생산 늘릴수록 Y재 포기량 증가
```

## 경제 체계

```
시장 경제 (자본주의):
- 가격 메커니즘으로 자원 배분
- 사유재산·이윤 동기
- 장점: 효율성, 혁신
- 단점: 불평등, 시장 실패

계획 경제 (사회주의):
- 정부 계획으로 자원 배분
- 장점: 평등, 공공재 공급
- 단점: 비효율, 유인 부족

혼합 경제 (현실):
- 시장 경제 기반 + 정부 개입
- 대부분의 현대 국가
```

## 핵심 개념 카드

**기회비용 = 포기한 최선** ★★★★★
: 여러 대안 중 포기한 것 중 가장 좋은 것. 명시적 비용이 아닌 암묵적 비용 포함.
*암기 포인트: 기회비용=포기한 최선의 대안*

**매몰비용 무시 원칙** ★★★★★
: 이미 지출된 회수 불가 비용은 미래 의사결정에서 제외. 한계편익 vs 한계비용만 비교.
*암기 포인트: 매몰비용=의사결정 무관*

**PPF 기울기 = 기회비용** ★★★★☆
: 오목한 PPF = 기회비용 체증. X재 생산 늘릴수록 Y재 포기량 증가.
*암기 포인트: PPF 오목=기회비용 체증*

## 실전 퀴즈

**Q. 1,000만 원을 투자한 사업이 현재까지 손실 500만 원. 앞으로 200만 원 추가 투입 시 400만 원 수익 예상. 계속 추진해야 하는가?**
> 계속. 매몰비용 1,500만 원(1,000+500) 무시. 추가 투입 200만 원 → 수익 400만 원 → 순편익 +200만 원. 한계편익(400) > 한계비용(200).

**Q. 다음 중 기회비용에 포함되는 것은? ① 교재 구매비 ② 포기한 아르바이트 수입 ③ 작년에 낸 등록금**
> ①②. ③은 매몰비용. ①은 명시적 비용, ②는 암묵적 비용 — 둘 다 기회비용에 포함.
