## HRD (인적자원개발)

```
HRD 정의:
Human Resource Development
개인·집단·조직의 학습 능력 향상

HRD 영역:
교육훈련 (Training & Development)
조직 개발 (Organization Development)
경력 개발 (Career Development)

교육훈련 필요성 분석 (TNA):
조직 분석: 전략 방향
직무 분석: 필요 역량
개인 분석: 역량 갭
```

---

## 교육훈련 방법

```
OJT (On-the-Job Training):
직무 수행 중 교육
멘토링·코칭·잡 로테이션
즉각 적용·현실적

Off-JT (Off-the-Job Training):
직무 외 집합 교육
강의·워크숍·세미나·e-러닝
체계적 이론·광범위 대상

혼합 (Blended Learning):
OJT + Off-JT 결합
이론 + 실습 병행

코칭 vs 멘토링:
코칭: 특정 스킬 향상 (현재 직무)
멘토링: 경력 전반 조언 (장기 관계)
```

---

## 교육훈련 평가 — Kirkpatrick 4단계

```
Level 1 반응:
참가자 만족도 (설문)
교육 품질 인식

Level 2 학습:
지식·스킬·태도 변화
사전·사후 테스트

Level 3 행동:
현업 적용도
업무 행동 변화 관찰

Level 4 결과:
비용절감·생산성·이직률 변화
ROI 측정
```

## 경력 개발 관리

```
경력 개발 (Career Development):
개인의 장기적 성장 계획·지원

경력 앵커 (Schein):
개인이 중시하는 경력 핵심 가치
기술/역량, 관리, 안정, 기업가 정신 등

CDP (경력 개발 프로그램):
경력 경로 설계
직무 이동·교육 연계

후계자 계획 (Succession Planning):
핵심 직위 후보자 식별·육성
조직 연속성 확보
```

## 핵심 개념 카드

**OJT=현장, Off-JT=집합** ★★★★★
: OJT=On=현장 직무 중, Off=별도 교육장.
*암기 포인트: OJT=현장*

**Kirkpatrick=반학행결** ★★★★★
: 반응→학습→행동→결과 4단계.
*암기 포인트: 반학행결*

**코칭=현재, 멘토링=장기** ★★★★☆
: 코칭은 특정 스킬, 멘토링은 경력 전반.
*암기 포인트: 코칭=지금, 멘토링=장기*

## 실전 퀴즈

**Q. Kirkpatrick 모델에서 Level 4(결과) 측정이 가장 어려운 이유는?**
> 교육 외 다른 변수 통제 어려움. 성과는 교육뿐 아니라 경기·팀·제품에도 영향. 측정까지 오랜 시간 소요. ROI 계산 복잡. 그러나 경영진이 가장 관심 갖는 단계. 현실적으로는 Level 1~2를 주로 측정, Level 3~4는 추정.

**Q. 후계자 계획(Succession Planning)이 필요한 이유는?**
> 핵심 인재 갑작스러운 이탈 대비. 조직 연속성 확보. 핵심 직위 공백 최소화. 고위직일수록 외부 충원 시간·비용 막대. 내부 육성 = 조직 문화 유지. 직원 동기부여: 성장 경로 보여줌. 특히 CEO·임원 승계 계획이 중요.
