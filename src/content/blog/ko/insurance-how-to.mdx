보험은 종류가 많고 약관이 복잡해서 가입 후 막상 필요할 때 보장받지 못하는 경우가 생깁니다. 이 가이드에서는 한국의 주요 보험 3종(생명보험·실손의료보험·자동차보험)의 가입 절차와 반드시 확인해야 할 핵심 조항을 정리했습니다.

---

## 1. 보험 가입 전 공통 원칙

### 보험료 비교는 공식 채널에서
- **보험다모아**: [e-insmarket.or.kr](https://www.e-insmarket.or.kr) — 금융감독원 운영, 생명·손해보험사 보험료 한 번에 비교 (무료)
- **생명보험협회**: [klia.or.kr](https://www.klia.or.kr)
- **손해보험협회**: [knia.or.kr](https://www.knia.or.kr)

### 가입 전 필수 질문 3가지
1. **보장 범위**: 어떤 상황에서 얼마를 받을 수 있나?
2. **면책 조항**: 보장 안 되는 예외 상황은 무엇인가?
3. **갱신형 vs 비갱신형**: 보험료가 나이에 따라 오르는가?

---

## 2. 실손의료보험 — 가장 먼저 가입할 보험

### 실손보험이란?
병원 치료 시 실제로 지출한 의료비를 돌려받는 보험. 건강보험이 적용되지 않는 비급여 항목을 커버.

### 세대별 상품 구분 (2024년 기준)
| 구분 | 특징 | 자기부담금 |
|---|---|---|
| 1세대 (2009년 이전) | 보장 넓음, 보험료 낮음 (이미 가입 유지 중이면 유지 권장) | 없음~10% |
| 2세대 (2009~2017) | 중간 수준 | 10~20% |
| 3세대 (2017~2021) | 자기부담금 높아짐 | 20~30% |
| 4세대 (2021~) | 급여·비급여 분리, 비급여 자기부담 높음 | 급여 20%, 비급여 30% |

> 현재 신규 가입은 4세대만 가능. 기존 보험 있으면 함부로 해지하지 말 것.

### 가입 시 확인 사항
- **비갱신형 vs 갱신형**: 4세대 실손은 모두 갱신형 (보험료 주기적 인상)
- **대기 기간**: 가입 후 90일간 특정 질병 보장 제외 (일반적)
- **기왕증 고지 의무**: 기존 질병 반드시 고지 → 고지 안 하면 보험금 지급 거절 가능

### 가입 절차
1. 보험다모아에서 보험료 비교
2. 선택한 보험사 홈페이지 또는 앱에서 온라인 가입 (설계사 가입보다 저렴한 경우 있음)
3. 건강 고지 사항 작성 (기존 질환·약 복용 여부 등 정확히 기재)
4. 보험료 납입 방법 설정 (월납/연납)

## 3. 생명보험 — 정기·종신·CI보험

### 주요 상품 유형

| 종류 | 내용 | 적합 대상 |
|---|---|---|
| 정기보험 | 일정 기간 사망 보장 (보험료 낮음) | 경제활동기 가족이 있는 사람 |
| 종신보험 | 평생 사망 보장 (보험료 높음) | 상속·유산 고려하는 경우 |
| CI(중대질병)보험 | 암·뇌졸중·심근경색 등 중대질병 발생 시 고액 지급 | 가족력 있는 경우 |
| 암보험 | 암 진단·치료비 특화 | 별도 암 보장 원하는 경우 |

### 생명보험 가입 시 핵심 체크
- **보험금 수령인 지정**: 사망보험금은 수익자 지정 필수 (미지정 시 법정 상속)
- **납입 기간 vs 보장 기간**: 20년 납입·평생 보장 등 구조 확인
- **해지환급금**: 중도 해지 시 납입액의 일부만 돌려받음 (초기 해지 시 손실 큼)
- **갱신형 CI/암보험**: 나이 들수록 보험료 급등 → 비갱신형 비교 필수

### 가입 절차
1. 보험다모아 또는 보험사 비교 사이트에서 상품 비교
2. 보험 설계사 상담 (복잡한 상품은 전문가 도움 권장)
3. 청약서 작성 및 건강 고지 사항 기재
4. 청약 철회 기간 활용: **가입 후 15일 이내** 청약 철회 시 납입 보험료 전액 환급

## 4. 자동차보험 — 의무 가입 + 종합보험

### 자동차보험 구성

| 담보 | 내용 | 의무 여부 |
|---|---|---|
| 대인배상 Ⅰ | 의무보험. 사망·부상 시 최소 보장 | **의무** |
| 대인배상 Ⅱ | 대인 Ⅰ 초과 손해 보상 | 권장 |
| 대물배상 | 상대방 재물 피해 보상 | 의무 (2,000만 원 이상) |
| 자기신체사고 | 내 부상 보상 | 선택 |
| 자기차량손해 | 내 차 수리비 보상 | 선택 |
| 무보험차상해 | 무보험 차량에 의한 피해 | 권장 |

### 보험료 절감 방법
- **온라인 직접 가입**: 설계사 가입 대비 10~15% 저렴
- **마일리지 특약**: 연간 주행거리가 적으면 추가 할인
- **블랙박스 특약**: 블랙박스 장착 시 할인
- **안전운전 특약**: 앱 연동 안전운전 평가 우수 시 할인

### 가입 절차
1. 보험다모아 → 자동차보험 비교 (5분 내 여러 회사 비교 가능)
2. 선택한 보험사 앱 또는 홈페이지에서 직접 가입
3. 차량번호·운전자 정보 입력 → 보험료 확인
4. 보험 증권 발급 (이메일·앱 수령)
5. **출고 전 신차라면**: 출고일 전날 가입해두기

## 보험 가입 후 반드시 해야 할 것

- **보험증권 보관**: 가족이 알 수 있는 곳에 보관 (또는 앱에 저장)
- **보험금 청구 절차 파악**: 사고 발생 시 바로 청구할 수 있도록 보험사 연락처 저장
- **정기 점검**: 매년 보험 갱신 시 보장 내용·보험료 재검토
