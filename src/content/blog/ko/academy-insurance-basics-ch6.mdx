## 사회보험 개요

```
사회보험 특성:
강제 가입 (민영보험과 차이)
국가가 운영
소득 재분배 기능
최저 생활 보장

4대 사회보험:
국민건강보험
국민연금
산재보험
고용보험

민영보험 vs 사회보험:
민영: 임의 가입, 영리, 실손·정액 보상
사회: 강제 가입, 비영리, 소득비례
```

---

## 국민건강보험

```
운영: 국민건강보험공단
가입: 전 국민 강제

보험료:
직장: 보수월액 × 요율 (근로자+사용자 반반)
지역: 소득·재산 기준

급여:
요양급여: 의료비 지원
현금급여: 장제비·출산비 등

본인부담금:
입원: 20%, 외래: 30~60%
```

## 국민연금

```
운영: 국민연금공단
목적: 노후 소득 보장

급여 종류:
노령연금: 10년 이상 납부 후 수령
장애연금: 납부 중 장애 발생
유족연금: 사망 시 유족에게

보험료: 기준소득월액 × 9% (근로자·사용자 반반)
수령 개시: 65세 (조기 수령 감액)

장점: 물가 연동, 종신 지급
단점: 수익률 낮음
```

## 산재·고용보험

```
산재보험:
업무상 재해·질병 보상
보험료: 사용자 100% 부담
급여: 요양급여·휴업급여·장해급여·유족급여

고용보험:
실업급여: 이직 후 소득 지원
취업촉진수당: 재취업 장려
보험료: 근로자+사용자 분담

실업급여 수급:
비자발적 이직
피보험 단위기간 180일 이상
구직활동 의무
```

## 실전 퀴즈

**Q. 사회보험과 민영보험의 근본적 차이점은?**
> 강제성: 사회보험은 강제 가입, 민영은 임의. 목적: 사회보험=최저 생활 보장+소득 재분배. 민영=개인 위험 대비. 보험료 산정: 사회보험=소득 비례 (능력에 따른 부담). 민영=위험도 비례. 수익성: 사회보험=비영리 국가 운영. 민영=영리. 역선택 방지: 강제 가입으로 저위험자 이탈 방지.

**Q. 국민연금이 개인 연금보다 유리한 점은?**
> 종신 지급: 수명에 관계없이 사망 시까지. 물가 연동: 실질 구매력 유지. 장애·유족 연금: 납부 중 사고 시에도 보장. 강제 저축 효과: 노후 대비 자동화. 세제 혜택: 납입액 소득 공제. 단점: 수익률 상대적으로 낮음, 개인 수명 짧으면 불리. 결론: 기본 노후 보장으로 국민연금 + 개인연금 병행 전략.
