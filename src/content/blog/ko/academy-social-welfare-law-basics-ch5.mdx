## 아동복지법의 의의

```
목적:
아동이 건강하게 출생하고 행복하게 자랄 수 있는 환경 보장

아동 정의:
18세 미만 (아동복지법)
→ 유엔 아동권리협약과 동일

아동 권리 4원칙:
① 생존권: 생명 보호, 기본 의식주
② 발달권: 교육, 놀이, 문화
③ 보호권: 학대·착취·방임에서 보호
④ 참여권: 의사 표현, 사회 참여

국가·지방자치단체 의무:
아동 복지 계획 수립
아동 보호 서비스 제공
```

---

## 아동학대

```
아동학대:
보호자 또는 성인이 아동의 건강·복지 해치는 행위
신체적·정서적·성적 학대, 방임

신고 의무자:
교직원, 의료인, 사회복지사, 어린이집 교사 등 25개 직군
신고 불이행 시 과태료 (500만 원 이하)

신고 기관:
112 (경찰) 또는 1391 (아동보호전문기관)

아동학대 대응:
아동보호전문기관 현장 조사
긴급 격리(피해 아동 즉시 분리)
가해자 접근 금지 명령

처벌:
아동학대범죄의 처벌 등에 관한 특례법
상습 아동학대: 가중 처벌
```

## 아동 보호 서비스

```
아동 보호 서비스:
학대 피해 아동, 위기 아동 지원

보호 대상 아동:
부모에게 양육받을 수 없는 아동
→ 아동복지시설 입소 또는 가정위탁

가정위탁:
위탁 가정에서 아동 양육
시설 보호보다 가정 환경 제공

아동 보호 전문 기관:
학대 신고 접수·조사·상담
전국 배치

드림스타트:
취약계층 아동 건강·복지·교육 통합 지원
0~12세 아동
```

## 영유아보육법

```
영유아보육법:
영유아(6세 미만) 보육 지원

어린이집 종류:
국공립, 직장, 가정, 협동, 민간 어린이집

보육 교사:
보육 교사 1~3급 자격
아동 수에 따른 배치 기준

보육료 지원:
연령·소득에 따라 정부 지원
0~5세 보육료 지원

누리과정:
3~5세 표준 교육과정
어린이집·유치원 공동 적용

아이돌봄서비스:
12세 이하 아동 가정 방문 돌봄
맞벌이 가정 지원
```

## 실전 퀴즈

**Q. 아동학대 신고 의무자가 신고하지 않으면 어떻게 되는가?**
> 아동복지법에서 규정한 25개 신고 의무 직군(교사·의사·사회복지사 등)이 학대를 인지하고도 신고하지 않으면 과태료(500만 원 이하). 고의적 미신고는 더 무거운 제재 검토.

**Q. 가정위탁과 아동복지시설 입소의 차이는?**
> 가정위탁: 위탁 가정에서 일반 가정환경 제공. 애착 형성에 유리. 시설 입소: 아동복지시설(공동생활가정, 아동양육시설)에서 집단 생활. 국제적으로 가정위탁 우선 권장(탈시설화).
