## 상권(商圈)이란?

```
상권의 정의:
→ 특정 점포 또는 상업 지역이 고객을 끌어들일 수 있는
  지리적 범위

상권 유형:
- 1차 상권: 전체 고객의 약 60~70%가 거주하는 지역 (핵심)
- 2차 상권: 추가 15~25% 고객 지역 (부차)
- 3차 상권: 나머지 고객 지역 (한계)

→ 상권 분석은 출점 전략, 마케팅 전략의 기본
```

---

## 상권에 영향을 미치는 요인

```
내부 요인 (점포 자체):
- 점포 규모 (매장 면적)
- 취급 품목 수, 상품 구색
- 가격 수준, 서비스 품질
- 주차 시설 여부

외부 요인 (환경):
- 인구 밀도, 배후 인구 수
- 교통 접근성 (대중교통, 자가용)
- 경쟁 점포 위치
- 도로 구조, 가시성
- 핵점포 (앵커 스토어) 존재 여부
```

## 입지 선정 (Location Analysis)

```
입지의 중요성:
→ '상업의 3원칙: 입지, 입지, 입지'
→ 소매업에서 입지는 성공의 핵심 요소

입지 유형:
1. 독립 입지: 경쟁점 없는 단독 위치 (집객력은 낮음)
2. 집적 입지: 동종·이종 업체가 밀집한 상권 (시너지 발생)
3. 복합 상업 시설 내 입지: 쇼핑몰, 백화점 내 테넌트

입지 평가 기준:
□ 유동 인구 (시간대별 통행량)
□ 표적 고객 비율
□ 가시성 (도로에서 점포가 잘 보이는가)
□ 접근성 (교통, 주차)
□ 임대료 대비 매출 잠재력
```

## 레일리의 소매 인력 법칙 (Reilly's Law of Retail Gravitation)

```
이론 내용:
→ 두 도시(상권)의 거래 흡인력은
  인구에 비례하고, 거리의 제곱에 반비례

공식:
Ba/Bb = (Pa/Pb) × (Db/Da)²

용어:
- Ba, Bb: 도시 A, B의 중간 지역 흡인력
- Pa, Pb: 도시 A, B의 인구
- Da, Db: 도시 A, B까지의 거리

적용: 두 상권 사이 경계선 위치 파악에 활용
→ 경쟁 상권과의 영향력 경계 지점 계산
```

## 허프 확률 모형 (Huff Model)

```
이론 내용:
→ 소비자가 특정 점포를 선택할 확률은
  점포 면적에 비례하고, 거리에 반비례

공식:
Pij = (Sj / Tij^λ) / Σ(Sk / Tik^λ)

용어:
- Pij: 소비자 i가 점포 j를 선택할 확률
- Sj: 점포 j의 면적
- Tij: 소비자 i에서 점포 j까지 거리
- λ: 거리 마찰 계수 (업종별 상이)

활용:
→ 신규 출점 시 해당 점포의 예상 고객 흡인율 계산
→ 경쟁 점포 출점 후 자사 고객 감소 예측
```

## 상권 조사 방법

```
1차 자료 수집 (직접 조사):
- 통행량 조사 (시간대별 유동인구 직접 카운팅)
- 고객 설문 조사
- 경쟁 점포 방문 관찰

2차 자료 수집 (기존 자료 활용):
- 통계청 인구 통계
- 국토부 상가건물 임대차 정보
- 소상공인시장진흥공단 상권 분석 시스템 (상권정보)
- KB부동산 상권 분석
- 네이버 플레이스 리뷰 데이터

현대적 상권 분석 도구:
→ GIS (지리정보시스템) 활용 반경 분석
→ 통신사 빅데이터 유동인구 분석
→ KT 잘나가게, SKT 지오비전 등
```

## 점포 입지 평가 항목

```
체크리스트:

□ 배후 인구: 반경 500m, 1km, 2km 내 거주 인구
□ 유동 인구: 평일/주말 피크타임 통행량
□ 표적 고객 비율: 전체 통행인 중 내 고객 될 가능성
□ 경쟁 현황: 동종 업종 점포 수, 거리
□ 가시성: 도로 정면 노출 여부, 간판 설치 가능성
□ 접근성: 대중교통, 주차
□ 임대료: 매출 대비 임대료 비율 (10~15% 이내 권장)
□ 계약 조건: 임대 기간, 인테리어 가능 여부
```

## 소매 포화 지수 (IRS)

```
Index of Retail Saturation:
→ 특정 상권의 소매 시장 포화 정도 측정

공식:
IRS = (C × RE) / RF

- C: 상권 내 소비자 수
- RE: 1인당 소매 지출액
- RF: 경쟁 점포 총 매장 면적

해석:
→ IRS 높을수록 → 소매 공급 부족 → 출점 기회
→ IRS 낮을수록 → 포화 상태 → 출점 위험
```

## 핵심 암기 정리

```
시험 빈출:

- 1차 상권: 60~70% 고객 거주
- 레일리 법칙: 인구 비례, 거리² 반비례
- 허프 모형: 면적 비례, 거리 반비례 → 선택 확률
- IRS: 높을수록 출점 기회
- 입지 3원칙: 입지, 입지, 입지
- 통행량 조사: 1차 자료 수집 방법
```

## 자주 묻는 질문

**Q. 레일리 법칙과 허프 모형의 차이는 무엇인가요?**
A. 레일리 법칙은 두 도시(상권) 간 경계선을 구하는 데 사용하고, 허프 모형은 소비자 한 명이 특정 점포를 선택할 확률을 계산합니다. 둘 다 거리의 영향을 강조하지만 적용 목적이 다릅니다.

**Q. 상권 분석 실습은 어떻게 하나요?**
A. 소상공인시장진흥공단의 무료 상권 분석 서비스(sg.sbiz.or.kr)를 활용하면 실전 데이터 기반 분석 연습이 가능합니다. 시험에도 이 개념이 자주 출제됩니다.
