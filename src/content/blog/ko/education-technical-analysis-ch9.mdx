## 왜 다중 시간대 분석인가

단일 시간대만 보면 큰 그림을 놓칩니다.

```
문제 예시:
15분봉: 골든 크로스 → 매수
일봉: 강한 저항선 바로 아래 → 즉시 막힘

→ 단기 신호가 장기 맥락과 충돌 → 손실
→ 상위 시간대 추세와 일치하는 신호만 매매
```

---

## 시간대별 역할 구분

```
분석 3단계 구조:

1. 상위 시간대 (Big Picture) — 주봉·월봉
   역할: 추세 방향 결정
   질문: "지금 큰 추세가 상승인가 하락인가?"

2. 중간 시간대 (Trend) — 일봉·4시간봉
   역할: 진입 타이밍 파악
   질문: "지금 하락 눌림목인가, 추세 전환인가?"

3. 하위 시간대 (Entry) — 1시간봉·15분봉
   역할: 정밀 진입·손절 설정
   질문: "어디서 정확히 사고, 어디서 손절할까?"
```

---

## 실전 3단계 분석 예시 (삼성전자)

```
1단계 (주봉 분석):
→ 주봉 상승 추세 확인 (고점·저점 모두 상승)
→ 이동평균선 배열: 단기 &gt; 중기 &gt; 장기
→ 방향: 매수 방향으로 접근

2단계 (일봉 분석):
→ 일봉에서 20일 이동평균까지 눌림목 확인
→ RSI 50 근처 → 추세 초기 매수 구간
→ 볼린저 중심선 지지 여부 확인

3단계 (4시간봉 진입):
→ 하단 밴드 터치 후 반등 캔들 확인
→ 거래량 증가 동반
→ 진입: 반등 캔들 고점 돌파 시
→ 손절: 4시간봉 저점 - 1 ATR
```

## 완전한 매매 시스템 구성요소

```
1. 진입 조건 (Entry Rules)
   → 모든 조건이 동시 충족 시만 진입
   예: 일봉 상승추세 + RSI 40~50 + 볼린저 중심선 지지

2. 손절 기준 (Stop Loss)
   → 반드시 사전 정의
   → ATR 기반 or 기술적 구조적 레벨 기반

3. 목표가 (Take Profit)
   → 피보나치 확장 or 이전 고점/저점
   → 리스크-리워드 비율 최소 1:2 이상

4. 청산 조건 (Exit Rules)
   → 목표가 도달 / 손절 도달
   → 추세 반전 신호 발생 시 부분 청산
```

## 리스크 리워드 (R:R) 관리

```
황금 규칙:
손실 1 대비 이익 2 이상 (1:2)

예시:
진입: 70,000원
손절: 68,500원 (리스크 = 1,500원)
목표: 73,000원 (이익 = 3,000원)
R:R = 1:2

→ 승률 40%에 R:R 1:2 = 수익
(0.4 × 2) - (0.6 × 1) = 0.8 - 0.6 = +0.2

→ 승률보다 R:R이 더 중요!
```

## 매매 일지와 시스템 개선

```
매매 일지 기록 필수 항목:
날짜 | 종목 | 진입 조건 | 진입가
손절가 | 목표가 | 청산가
결과(수익/손실) | 오늘의 교훈

월별 검토:
→ 승률, 평균 R:R, 기대값 계산
→ 자주 실수하는 패턴 파악
→ 한 가지씩 개선
```

## 핵심 암기 포인트

*다중 시간대: 상위(방향) → 중간(타이밍) → 하위(정밀 진입)*
*상위 시간대 추세와 반대 방향 신호는 무시*
*R:R 최소 1:2 — 승률보다 리스크-리워드 비율이 더 중요*
*매매 일지 작성 = 가장 빠른 실력 향상 방법*
