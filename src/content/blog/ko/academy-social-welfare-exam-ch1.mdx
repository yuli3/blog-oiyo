## 사회복지사 2급 자격증이란?

사회복지사 2급은 사회복지 현장에서 일하기 위한 국가 자격증입니다. 복지관, 요양원, 학교, 병원, 지역사회 기관 등 다양한 분야에서 활동할 수 있으며, 취업 경쟁력이 높은 자격증 중 하나입니다.

```
자격증 발급 기관: 한국사회복지사협회
관련 법령: 사회복지사업법 제11조
자격 등급: 1급 / 2급 / 3급 (현재 3급은 신규 발급 중단)
```

## 사회복지사 2급 취득 방법

```
방법 1: 대학(교) 사회복지학과 졸업
→ 4년제 또는 2~3년제 대학 사회복지 관련 학과 졸업
→ 규정된 교과목 이수 시 졸업과 동시에 자격 취득 가능

방법 2: 학점은행제 이수
→ 사회복지학 학위 취득 (전문학사 이상)
→ 사회복지 관련 14과목(42학점) 이수 + 실습 120시간

방법 3: 기존 자격 취득자 (3급 → 2급 승급)
→ 현재는 신규 적용 없음
```

## 응시 자격 조건 (학점은행제 기준)

```
필수 조건:
1. 전문학사 이상 학위 취득 (또는 예정)
2. 사회복지 관련 과목 14과목 이수
3. 사회복지 현장실습 120시간 이수

과목 구분:
필수 10과목 + 선택 4과목 이상

필수 과목 (10개):
- 사회복지개론
- 인간행동과 사회환경
- 사회복지조사론
- 사회복지실천론
- 사회복지실천기술론
- 사회복지정책론
- 사회복지행정론
- 사회복지법제론
- 사회복지현장실습
- 지역사회복지론

선택 과목 예시:
- 아동복지론, 노인복지론, 장애인복지론
- 청소년복지론, 가족복지론
- 의료사회사업론, 정신건강사회복지론
- 사회복지재정론, 자원봉사론 등
```

## 사회복지사 1급 시험 (2급 취득 후 응시 가능)

```
2급을 취득한 후 경력 요건 충족 시 1급 시험 응시 가능

1급 시험 과목 (3교시):
1교시: 사회복지기초 (인간행동과 사회환경, 사회복지조사론)
2교시: 사회복지실천 (사회복지실천론, 사회복지실천기술론, 지역사회복지론)
3교시: 사회복지정책과 제도 (사회복지정책론, 사회복지행정론, 사회복지법제와 실천)

합격 기준:
→ 각 과목 40점 이상
→ 전 과목 평균 60점 이상
```

## 현장실습 안내

```
실습 시간: 120시간 이상 (1일 8시간 기준 약 15일)

실습 기관 조건:
→ 사회복지법인 또는 사회복지시설
→ 사회복지사업법에 의한 인가 기관

실습 내용:
- 사회복지사 역할 관찰 및 보조
- 개인·집단·지역사회 실천 활동 참여
- 슈퍼비전 수혜 및 기록 작성

실습 신청 방법:
→ 학점은행제 수강 시 실습 기관 직접 섭외 or 교육기관 연계
```

## 사회복지사 취업 분야

```
주요 취업처:
- 종합사회복지관
- 노인 요양 시설 (장기요양기관)
- 장애인 복지 시설
- 아동·청소년 복지 시설
- 병원·의료 사회복지팀
- 학교 사회복지사
- 정신건강복지센터
- 지자체 사회복지 공무원 (별도 채용)

처우 수준 (2024년 기준):
→ 공공기관: 지자체 복지직 공무원 급여 수준
→ 민간시설: 사회복지시설 종사자 인건비 가이드라인 적용
→ 경력 누적에 따라 처우 개선
```

## 학습 로드맵 (학점은행제 기준)

```
일반적 취득 기간: 약 1~2년

1단계 (1~6개월): 필수 과목 이론 수강 (온라인 가능)
2단계 (6~12개월): 선택 과목 이수
3단계: 현장실습 120시간 이수
4단계: 학위 신청 및 자격증 발급 신청

등록 방법:
→ 국가평생교육진흥원 학습자 등록
→ 학점은행제 교육훈련기관 수강 (원격 가능)
→ 학습구분 확인 후 과목 등록
```

## 자주 묻는 질문

**Q. 사회복지사 2급은 시험이 있나요?**
A. 2급 자체에는 별도 필기시험이 없습니다. 규정 과목 이수와 실습 이수로 자격이 부여됩니다. 1급으로 승급하려면 국가시험에 합격해야 합니다.

**Q. 인터넷 강의만으로 취득 가능한가요?**
A. 이론 과목은 온라인 수강이 가능합니다. 다만 현장실습은 반드시 실제 기관에서 진행해야 합니다.

**Q. 학점은행제 수강료는 얼마인가요?**
A. 기관마다 다르지만 과목당 5~15만원 수준입니다. 내일배움카드 활용 시 일부 비용 지원이 가능합니다.
