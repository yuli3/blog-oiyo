## 인사행정의 기반 원칙

```
엽관주의 (Spoils System):
집권 정당이 공직을 지지자에게 배분
장점: 정치적 책임성, 정책 실현 용이
단점: 행정 불안정, 전문성 저하

실적주의 (Merit System):
능력·시험으로 임용, 정치 중립
장점: 전문성, 안정성, 공정성
단점: 관료제 경직성, 신진대사 어려움

직업공무원제:
종신 고용 보장, 계급 기반 승진
신분 보장 → 안정적 전문 공무원
단점: 개방성 부족, 역동성 부재
```

## 직위분류제와 계급제

```
직위분류제:
직무 내용·난이도 기준으로 직위 분류
동일 직무=동일 보수 원칙
직무 전문성 강조 (미국·캐나다)

계급제:
사람의 자격·능력 기준으로 계급 부여
신분 보장·순환 보직 (영국·한국)
일반 행정가 양성

비교:
직위분류제: 전문가, 직무 중심, 경력 폐쇄적
계급제: 일반가, 사람 중심, 경력 개방적

한국:
계급제 기반 + 직위분류제 요소 혼합
1~9급 계급 + 직렬·직류 분류
```

## 공무원 임용

```
시험 임용:
공개 경쟁 시험 (공채)
특별 채용 (특채): 전문 분야

승진:
근무 성적 + 경력 평정 기반
심사 승진, 시험 승진

전보·파견:
전보: 같은 직급 내 직위 변경
파견: 타 기관 업무 지원

강임:
하위 직급으로 강제 이동
징계 또는 직제 개편 시

개방형 직위:
민간인도 공모 가능한 고위직
전문성 확보 목적
```

## 공무원 교육훈련과 근무 성적 평정

```
교육훈련:
직전 훈련: 임용 전 훈련
직장 내 훈련: OJT (On-the-Job Training)
직장 외 훈련: 교육원, 연수

근무 성적 평정:
공무원 업무 실적·능력 평가
승진·성과급 기준

다면 평가:
상관·동료·부하·자기 평가 종합
→ 360도 평가

성과 관리:
목표 설정 → 중간 평가 → 최종 평가
성과급 연계
```

## 공무원 징계

```
징계 종류:
파면: 신분 박탈, 퇴직금 감액
해임: 신분 박탈 (파면보다 가벼움)
강등: 1계급 강등, 3개월 정직
정직: 1~3개월 직무 정지, 보수 없음
감봉: 1~3개월 보수 감액
견책: 경고

공무원 권리 구제:
소청심사: 징계 등 불복 → 소청심사위원회
행정소송: 소청 후 불복 시 법원 제소
```

## 핵심 개념 카드

**실적주의 vs 엽관주의** ★★★★★
: 실적=능력·시험 기준. 엽관=정치적 충성 기준.
*암기 포인트: 실적=시험공정, 엽관=정치보은*

**직위분류제 vs 계급제** ★★★★★
: 직위분류=직무중심·전문가. 계급=사람중심·일반가.
*암기 포인트: 직위=직무, 계급=사람*

**공무원 징계 순서** ★★★★☆
: 파면>해임>강등>정직>감봉>견책.
*암기 포인트: 파해강정감견 (무거운→가벼운)*

## 실전 퀴즈

**Q. 한국 공무원 제도에서 계급제와 직위분류제가 혼합된 이유는?**
> 계급제는 신분 안정·순환 보직의 장점이 있지만 전문성 약함. 직위분류제는 전문성 강하지만 순환 어려움. 한국은 1~9급 계급 구조 유지하면서 직렬·직류 분류로 직무 전문화 보완.

**Q. 개방형 직위 제도의 목적은?**
> 민간 전문가를 고위직에 임용해 정부에 민간 전문성 도입. 공직 경쟁 활성화, 혁신 촉진. 내부 승진만으로 채울 수 없는 전문 분야(IT, 금융, 의료 등) 대응.
