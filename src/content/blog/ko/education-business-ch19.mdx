## 1. 글로벌화의 동인

**글로벌화 (Globalization)**: 국가 간 무역·투자·문화·기술의 통합이 심화되는 현상.

### 글로벌화 4가지 동인 (Yip)

| 동인 | 내용 |
|------|------|
| 시장 동인 | 소비자 동질화, 글로벌 고객 증가 |
| 비용 동인 | 규모의 경제, 저임금 생산지 |
| 정부 동인 | 관세 철폐, 지적재산권 조약 |
| 경쟁 동인 | 글로벌 경쟁자 등장, 선점 압력 |

## 2. 해외 진입 전략

### 진입 방식과 통제력·위험·수익 관계

| 방식 | 통제력 | 위험 | 자원 투입 |
|------|--------|------|----------|
| 수출 | 낮음 | 낮음 | 낮음 |
| 라이선싱 | 낮음 | 낮음 | 낮음 |
| 프랜차이징 | 중간 | 낮음 | 중간 |
| 합작투자 (JV) | 중간 | 중간 | 중간 |
| 전략적 제휴 | 중간 | 중간 | 중간 |
| 단독 직접투자 (WOS) | 높음 | 높음 | 높음 |
| 인수합병 (M&A) | 높음 | 높음 | 매우 높음 |

**그린필드 투자**: 현지에 새로 공장·사무소 설립 (시간 長, 통제력 高).
**브라운필드 투자**: 기존 시설 인수 후 개조 (시간 短, 숨겨진 부채 위험).

## 3. 다국적기업 이론

### 절충 이론 (OLI 패러다임, Dunning)

기업이 해외 직접투자(FDI)를 선택하는 이유를 3가지 우위로 설명.

| 우위 | 내용 |
|------|------|
| O (Ownership) 우위 | 브랜드·기술·경영노하우 등 기업 고유 자산 |
| L (Location) 우위 | 현지의 저렴한 노동·자원·시장 접근성 |
| I (Internalization) 우위 | 직접 운영이 계약보다 유리 (기술 유출 방지) |

### 글로벌 전략 유형 (Bartlett & Ghoshal)

| 전략 | 글로벌 통합 | 현지 반응성 |
|------|------------|------------|
| 글로벌 전략 | 高 | 低 (표준화) |
| 멀티도메스틱 전략 | 低 | 高 (현지화) |
| 국제 전략 | 低 | 低 (모국 중심) |
| 초국가적(Transnational) 전략 | 高 | 高 (균형) |

## 4. 문화 차이 관리

### Hofstede 문화 차원 (6가지)

| 차원 | 내용 |
|------|------|
| 권력 거리 | 권력 불평등 수용 정도 |
| 불확실성 회피 | 불확실성에 대한 불안 정도 |
| 개인주의 vs 집단주의 | 개인 vs 집단 정체성 |
| 남성성 vs 여성성 | 성과·경쟁 vs 삶의 질·협력 |
| 장기 지향 vs 단기 지향 | 미래 투자 vs 현재 전통 |
| 자기 방종 vs 절제 | 욕구 충족 허용 정도 |

### 문화 충격 (Culture Shock) U곡선
신혼기 → 불만기 → 적응기 → 통합기의 4단계로 현지 적응.

### 문화 관리 전략
- **에스노센트리즘** (자국 중심): 본국 문화·관행 그대로 이식
- **폴리센트리즘** (현지 중심): 각국 자율 운영
- **지오센트리즘** (글로벌 통합): 최선의 방법을 전 세계적으로 공유

## 5. 환율과 글로벌 재무

### 환율 위험 유형

| 유형 | 내용 |
|------|------|
| 거래 위험 | 외화 계약의 결제 시 환율 변동 |
| 환산 위험 | 재무제표 통합 시 환율 차이 |
| 경제적 위험 | 장기 경쟁력에 미치는 환율 영향 |

### 헷징 수단
- **선물환 계약**: 미래 환율 고정
- **통화 스왑**: 두 통화 간 이자·원금 교환
- **통화 옵션**: 불리한 환율 변동 시 방어

## 6. 글로벌 공급망과 무역

**비교 우위 (Ricardo)**: 각국이 상대적으로 더 잘하는 것을 특화하면 모두 이익.

**국가 다이아몬드 모형 (Porter)**: 국가 경쟁우위의 4가지 결정 요인.
- 요소 조건 (생산 요소의 질·량)
- 수요 조건 (내수 시장의 질)
- 연관 산업 (공급업·연관업의 경쟁력)
- 기업 전략·구조·경쟁
