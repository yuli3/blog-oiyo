## 강제집행의 의의

```
강제집행:
이행 의무 있는 채무자가 이행하지 않을 때
국가 강제력으로 권리를 실현하는 절차

집행권원:
강제집행의 근거가 되는 문서

종류:
① 확정 판결
② 가집행 선고 있는 판결
③ 화해 조서·인낙 조서·조정 조서
④ 공정증서 (집행인낙 문언 있는 것)
⑤ 지급명령 (확정된 것)

집행문:
집행권원에 집행력 있음을 증명하는 기관
법원 서기관 또는 공증인이 부여
```

## 부동산 강제집행

```
부동산 경매 (강제경매):
채권자 신청 → 법원 경매 개시
최고가 매수인에게 부동산 매각

절차:
강제경매 신청 → 경매 개시 결정 + 압류
→ 현황 조사·감정 → 매각 기일 공고
→ 입찰 → 매각 허가 결정 → 대금 납부
→ 소유권 이전 → 배당

압류의 효력:
처분 금지 효력 (압류 후 양도해도 경매에 영향 없음)
배당 기준일: 배당 순위에 따라 분배

부동산 담보 경매:
저당권·근저당권 실행
강제경매와 절차 유사
```

## 유체동산·채권 집행

```
유체동산 집행:
집행관이 채무자 소유 동산 압류
→ 경매로 환가 → 채권자에게 배당

면제 재산:
생활 필수품, 생업 도구, 급여 일부
→ 압류 금지 (인간다운 생활 보장)

채권 집행:
채무자의 제3자(제3채무자)에 대한 채권 압류
→ 제3채무자에게 직접 지급 금지 명령
→ 전부명령 또는 추심명령

전부명령:
압류 채권 채권자에게 이전 (채권 취득)

추심명령:
채권자가 제3채무자에게 직접 청구권 취득
```

## 가압류·가처분

```
가압류:
강제집행 전 채무자 재산 보전
금전 채권 보전 목적

가처분:
다툼 대상 현상 유지·임시 지위 확보
비금전 채권 보전 목적

피보전권리:
가압류·가처분 신청자의 권리

보전의 필요성:
가압류·가처분을 안 하면 집행 불가 위험

담보:
채권자가 담보 제공 (가압류·가처분 잘못 시 배상)

이의 신청:
채무자가 가압류·가처분에 불복
취소·변경 신청
```

## 핵심 개념 카드

**집행권원 종류** ★★★★★
: 확정판결·화해조서·인낙조서·공정증서·지급명령.
*암기 포인트: 판화인공지*

**가압류 vs 가처분** ★★★★★
: 가압류=금전채권 보전. 가처분=비금전채권·현상유지.
*암기 포인트: 가압=금전, 가처=비금전*

**압류 면제 재산** ★★★★☆
: 생활필수품·생업도구·급여일부는 압류 금지.
*암기 포인트: 생필품=압류불가*

## 실전 퀴즈

**Q. 가압류와 강제집행의 차이는?**
> 가압류: 집행권원 없어도 가능. 재산 보전 목적. 임시 처분. 강제집행: 집행권원 필요. 실제 권리 실현. 가압류로 보전 후 소송으로 집행권원 취득 → 강제집행 순서.

**Q. 전부명령과 추심명령의 차이는?**
> 전부명령: 채무자의 채권이 채권자에게 이전. 제3채무자에게 직접 청구 가능. 채권이 채권자 것이 됨. 추심명령: 채권은 채무자 것이지만 채권자가 직접 청구권 행사. 소멸시효 주의.
