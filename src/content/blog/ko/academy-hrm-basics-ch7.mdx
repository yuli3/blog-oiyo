## 1. 내용 이론

```
Maslow 욕구단계설:
생리 → 안전 → 사회적(소속) → 존경 → 자아실현
하위 욕구 충족 후 상위 욕구 동기
생안사존자

Herzberg 2요인 이론:
위생요인: 불만족 방지 (급여·작업환경·안전)
동기요인: 만족 증가 (성취·인정·책임·성장)
→ 위생 충족해도 동기 안됨. 동기요인 강화 필요

Alderfer ERG 이론:
Existence·Relatedness·Growth
퇴행 가능: 상위 욕구 좌절 시 하위로

McGregor X·Y 이론:
X: 인간=게으름, 통제·지시 필요
Y: 인간=자율·책임, 자아실현 추구
→ Y 관점이 현대적
```

## 2. 과정 이론

```
Vroom 기대이론:
동기 = 기대 × 수단 × 유의성
기대: 노력 → 성과 가능성
수단: 성과 → 보상 연결
유의성: 보상의 개인적 가치

Adams 공정성 이론:
투입/산출 비율 비교 (나 vs 준거인)
불공정 인식 → 불쾌감 → 조정 행동

목표설정 이론 (Locke):
구체적·도전적 목표 = 높은 성과
목표 수용·피드백 필요
SMART 목표
```

## 3. 강화 이론

```
강화 이론 (Skinner):
행동 결과에 따라 행동 반복·억제

긍정적 강화:
원하는 행동 후 보상 → 반복

부정적 강화:
불쾌 자극 제거 → 행동 반복
(예: 잔소리 안 들으려 과제 완료)

벌 (Punishment):
원하지 않는 행동 후 부정 자극 → 억제

소거:
보상 제거 → 행동 소멸

강화 계획:
고정간격·고정비율·변동간격·변동비율
변동비율 = 가장 강력 (도박·SNS 원리)
```

## 4. 핵심 개념 카드

**Maslow=생안사존자** ★★★★★
: 생리→안전→사회→존경→자아실현.
*암기 포인트: 생안사존자*

**Herzberg 급여=위생요인** ★★★★★
: 급여 올려도 동기부여 아님. 성취·인정이 동기요인.
*암기 포인트: 급여=위생*

**기대이론=기수유** ★★★★☆
: 기대×수단×유의성.
*암기 포인트: 기수유*

## 5. 실전 퀴즈

**Q. Vroom 기대이론에서 동기가 0이 되는 경우는?**
> 기대·수단·유의성 중 하나라도 0이면 전체 동기=0. 기대=0: 아무리 노력해도 성과 안 날 것 같음. 수단=0: 성과 내도 보상 안 줄 것 같음. 유의성=0: 보상이 나에게 의미 없음. 실무: 성과-보상 연결고리 명확히, 직원별 원하는 보상 파악이 중요.

**Q. 변동비율 강화 계획이 가장 강력한 이유는?**
> 언제 보상이 나올지 모름 → 기대감 지속. 소거에 가장 강함: 보상 없어도 오래 시도. 도박·소셜미디어 좋아요가 변동비율 원리. 고정비율: 판매 건당 커미션 (예측 가능). 변동비율: 매일 다른 건수의 보상 → 중단 어려움. HR에서는 서프라이즈 보상 활용.
