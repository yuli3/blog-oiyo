## 사회복지(Social Welfare)의 이해

```
사회복지의 정의:
→ 사람들의 기본적 욕구를 충족시키고 사회적 기능을 향상시키며
  모든 시민이 최소한의 인간다운 삶을 영위할 수 있도록
  사회가 집합적으로 취하는 행동

광의의 사회복지:
→ 국민의 삶의 질을 향상시키는 모든 사회적 프로그램·서비스
→ 교육, 보건, 주거, 사회보험 포함

협의의 사회복지:
→ 도움이 필요한 취약 계층을 위한 서비스
→ 공공부조, 사회서비스
```

## 사회복지의 이념과 가치

```
사회복지의 핵심 가치:

1. 인간의 존엄성 (Human Dignity):
→ 모든 인간은 그 자체로 존귀한 존재
→ 사회복지 실천의 근본 원칙

2. 사회 정의 (Social Justice):
→ 자원의 공정한 분배
→ 기회의 평등

3. 평등 (Equality):
→ 수직적 평등: 능력에 따른 차등 대우
→ 수평적 평등: 같은 욕구에 같은 서비스

4. 자유 (Freedom):
→ 소극적 자유: 개입으로부터의 자유
→ 적극적 자유: 삶을 스스로 형성할 자유

5. 연대 (Solidarity):
→ 사회 구성원 간 상호 책임과 돌봄
→ "한 명을 위한 모두, 모두를 위한 한 명"

6. 자기 결정 (Self-Determination):
→ 개인의 자율적 선택 존중
```

## 잔여주의 vs 제도주의

```
잔여적 관점 (Residual View):
→ 가족과 시장이 1차 복지 제공
→ 실패했을 때만 국가 개입 (임시적·응급적)
→ 복지 의존성 경계, 근로 의욕 강조
→ 자유주의·보수주의 이념 기반
→ 예: 미국 전통적 복지 철학

제도적 관점 (Institutional View):
→ 국가는 모든 시민의 기본 욕구 충족 책임
→ 보편적 서비스, 예방적 접근
→ 복지 수혜를 낙인 없이 권리로 인식
→ 사회민주주의 이념 기반
→ 예: 북유럽 복지국가

발전주의 관점 (Developmental View):
→ 복지와 경제 발전 동시 추구
→ 인적 자원 개발 통한 경제 성장 지원
→ 한국, 싱가포르, 대만 등 동아시아 복지 모델
```

## 사회복지의 역사

```
영국 사회복지 역사 (세계 최초 복지국가):

엘리자베스 구빈법 (1601):
→ 최초의 공공 빈민 구제 법률
→ 교구 단위 빈민 책임
→ 노동 능력 있는 빈민: 작업장 강제 노동
→ 노동 불능 빈민: 구빈원 또는 구제금

신구빈법 (1834):
→ 원내 구제 원칙 (작업장 강제)
→ 열등 처우 원칙: 공공 구제 < 최저 임금

빈곤 조사 (1880s~1900s):
→ 부스, 라운트리의 과학적 빈곤 조사
→ 빈곤이 개인 잘못이 아닌 사회 문제임을 증명

베버리지 보고서 (1942):
→ 현대 복지국가 청사진
→ 5대 악: 결핍, 질병, 무지, 불결, 게으름
→ 요람에서 무덤까지 (Cradle to Grave) 사회보장

한국 사회복지 역사:
→ 1944: 조선구호령 (일제)
→ 1961: 생활보호법 (군사정권)
→ 1977: 의료보험 도입
→ 1988: 국민연금 실시
→ 1999: 국민기초생활보장법 (생산적 복지)
→ 2000년대~: 복지 확대기 (노무현~)
```

## 사회적 위험 (Social Risk)

```
사회적 위험의 정의:
→ 개인의 통제를 넘어 다수에게 발생하는 생활 장애 요인

고전적 사회적 위험 (구 사회적 위험):
→ 노령·장애·질병·산재·실업·사망
→ 산업사회의 주요 위험
→ 사회보험으로 대응

신사회적 위험 (New Social Risks):
→ 후기 산업사회·탈근대의 새로운 위험
→ 아동 돌봄 필요 (여성 취업 증가)
→ 기술 변화에 따른 숙련 불일치
→ 이혼·가족 해체
→ 불안정 노동 (비정규직, 플랫폼 노동)
→ 사회적 배제

코로나19와 새로운 위험:
→ 팬데믹이 새로운 사회적 위험 유형으로 부각
→ 자영업자, 플랫폼 노동자의 사각지대 드러남
```

## 욕구 이론과 복지

```
매슬로우의 욕구 위계 (복지 관점):

1단계 생리적 욕구: 기초생활보장, 의료급여
2단계 안전 욕구: 주거 지원, 고용 안정
3단계 소속·애정 욕구: 사회서비스, 돌봄
4단계 존경 욕구: 직업 재활, 역량 강화
5단계 자아실현 욕구: 교육 기회, 문화 복지

→ 하위 욕구 충족이 상위 욕구 달성의 전제
→ 사회복지는 모든 단계 욕구 지원

노먼 존슨의 복지 혼합 경제:
→ 국가만 복지 공급자가 아님
→ 공식 부문: 국가, 지방자치단체
→ 비공식 부문: 가족, 이웃, 친구
→ 자원 부문: NGO, 종교단체, 자원봉사
→ 영리 부문: 민간 복지 기업
```

## 자주 묻는 질문

**Q. 사회복지는 빈곤층만을 위한 것인가요?**
A. 아닙니다. 현대 사회복지는 모든 시민을 대상으로 합니다. 국민연금, 건강보험은 모든 국민이 이용하는 보편적 제도입니다. 또한 아동수당, 무상급식 등 보편적 서비스가 확대되고 있습니다. 사회복지는 빈곤 구제에서 전 국민의 삶의 질 향상으로 패러다임이 전환되었습니다.

**Q. 복지 확대는 경제에 부담이 되지 않나요?**
A. 이것은 복지 경제학의 핵심 논쟁입니다. 단기적으로 재정 부담이 될 수 있지만, 장기적으로 인적 자원 개발, 사회 안전망 강화로 경제 생산성을 높인다는 주장도 있습니다. 북유럽 국가들이 높은 복지 수준과 높은 경제 경쟁력을 동시에 갖춘 사례가 이를 지지합니다.
