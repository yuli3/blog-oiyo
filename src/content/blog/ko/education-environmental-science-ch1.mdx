## 환경학(Environmental Science)이란?

환경학은 인간과 자연 환경의 상호작용을 다학제적으로 연구하는 학문입니다. 자연과학, 사회과학, 인문학을 융합하여 환경 문제의 원인과 해결책을 탐구합니다.

```
환경학의 주요 관심사:
→ 자원 고갈 (화석연료, 식수, 광물)
→ 기후변화 (온실가스, 지구 온난화)
→ 생물다양성 감소 (종 멸종 위기)
→ 오염 (대기, 수질, 토양)
→ 폐기물 관리 (플라스틱, 전자폐기물)

환경 문제의 역사적 전환점:
→ 1962: 레이첼 카슨 '침묵의 봄' (DDT 살충제 경고)
→ 1972: 로마 클럽 '성장의 한계' 보고서
→ 1987: 브룬트란트 보고서 (지속 가능한 발전 개념)
→ 1992: 리우 환경 정상회의 (기후변화협약 채택)
→ 2015: 파리 협정 (지구 온도 1.5°C 상승 억제)
→ 2023: COP28 (화석연료 전환 합의)
```

## 생태계(Ecosystem)의 구조

```
생태계의 정의:
→ 생물(Biotic) 요소와 비생물(Abiotic) 요소가
  상호작용하는 기능적 단위

생물 요소:
→ 생산자 (Producers): 광합성으로 유기물 합성 (식물, 조류)
→ 소비자 (Consumers):
  - 1차 소비자: 초식동물 (소, 사슴)
  - 2차 소비자: 육식동물 (여우, 개구리)
  - 3차 소비자: 상위 포식자 (독수리, 인간)
→ 분해자 (Decomposers): 유기물을 무기물로 분해 (박테리아, 균류)

비생물 요소:
→ 빛, 온도, 강수량, 토양, 수질, 대기

생물권 (Biosphere):
→ 지구에서 생물이 살 수 있는 영역
→ 육지권, 수권, 대기권의 일부
```

## 먹이 사슬과 에너지 흐름

```
먹이 사슬 (Food Chain):
식물(풀) → 메뚜기 → 개구리 → 뱀 → 독수리

먹이 그물 (Food Web):
→ 여러 먹이 사슬이 얽힌 복잡한 망
→ 현실 생태계는 단순한 사슬이 아닌 복잡한 그물

영양 단계 (Trophic Level):
1단계: 생산자 (식물)
2단계: 1차 소비자
3단계: 2차 소비자
4단계: 3차 소비자 (최상위 포식자)

10% 법칙 (생태 에너지 효율):
→ 한 영양 단계에서 다음 단계로 에너지 약 10%만 전달
→ 90%는 호흡, 열로 소실
→ 식물(1,000 kcal) → 메뚜기(100 kcal) → 개구리(10 kcal) → 뱀(1 kcal)

생태 피라미드:
→ 에너지, 생물량, 개체수 모두 위로 갈수록 감소
→ 최상위 포식자는 적은 개체 수로 먹이 사슬 유지
```

## 물질 순환

```
탄소 순환 (Carbon Cycle):
대기 중 CO₂ 
→ 광합성으로 유기물 고정 (식물)
→ 호흡으로 CO₂ 방출 (생물)
→ 분해로 CO₂ 방출 (분해자)
→ 화석연료 연소로 CO₂ 방출 (인간 활동)

질소 순환 (Nitrogen Cycle):
대기 N₂ → 질소 고정 세균 → 암모니아 → 질산염
→ 식물 흡수 → 소비자 → 분해 → 탈질소 → 대기 N₂

인 순환 (Phosphorus Cycle):
→ 암석 풍화로 방출
→ 식물 흡수, 먹이 사슬로 전달
→ 분해로 토양 귀환
→ 해저 퇴적

인간의 순환 교란:
→ 화석연료 연소: 탄소 순환 교란 → 기후변화
→ 인공 비료 사용: 질소·인 과잉 → 수질 오염 (부영양화)
```

## 기후변화 메커니즘

```
온실 효과 (Greenhouse Effect):
→ 지구 복사 에너지가 대기 중 온실가스에 의해
  우주로 빠져나가지 못하고 지구에 갇히는 현상

온실가스 (Greenhouse Gases):
→ 이산화탄소 (CO₂): 화석연료 연소, 산림 파괴
→ 메탄 (CH₄): 가축, 벼 농사, 습지
→ 아산화질소 (N₂O): 비료, 산업
→ 불소 가스: 냉매, 산업

지구 온난화 (Global Warming):
→ 산업화 이후 대기 CO₂ 농도 증가
→ 약 1.1°C 이상 상승 (2023년 기준)
→ 파리 협정 목표: 1.5°C 억제

기후변화의 영향:
→ 해수면 상승: 남태평양 섬나라 수몰 위기
→ 극단적 기상: 폭염, 홍수, 가뭄 빈도 증가
→ 생태계 교란: 생물 이동·멸종
→ 농업 생산 변화: 곡물 생산지 이동
```

## 생물다양성 (Biodiversity)

```
생물다양성의 정의:
→ 유전자, 종, 생태계 수준의 생물학적 다양성

생물다양성의 수준:
1. 유전적 다양성: 같은 종 내 유전자 변이
2. 종 다양성: 특정 지역의 종 수
3. 생태계 다양성: 생태계 유형의 다양성

생물다양성의 중요성:
→ 생태계 서비스: 식량, 의약품, 깨끗한 물·공기
→ 회복 탄력성: 다양할수록 환경 변화에 강함
→ 내재적 가치: 생명 자체의 가치

현재 멸종 위기:
→ 제6차 대멸종 (현재 진행 중으로 추정)
→ 자연 멸종 속도의 100~1,000배 빠른 현재 멸종 속도
→ 원인: 서식지 파괴, 오염, 남획, 기후변화, 외래종

생물다양성 협약:
→ 1992년 리우에서 채택
→ 생물다양성 보전, 지속 가능한 이용, 이익 공유
```

## 지속 가능한 발전 (Sustainable Development)

```
브룬트란트 정의 (1987):
→ "미래 세대가 자신의 욕구를 충족시킬 능력을 해치지 않으면서
  현재 세대의 욕구를 충족시키는 발전"

지속 가능한 발전의 3대 축:
1. 경제적 지속 가능성: 경제 성장
2. 사회적 지속 가능성: 사회 정의·형평성
3. 환경적 지속 가능성: 생태계 보전

SDGs (Sustainable Development Goals, 2015):
→ UN이 채택한 17개 지속 가능 발전 목표
→ 빈곤 종식, 기후행동, 질 좋은 교육, 성평등 등
→ 2030년까지 달성 목표

녹색 경제 (Green Economy):
→ 환경 파괴 없이 인간의 삶을 개선하는 경제 모델
→ 재생에너지, 친환경 농업, 순환 경제
```

## 자주 묻는 질문

**Q. 개인이 기후변화를 막을 수 있나요?**
A. 개인의 행동(채식 식단, 대중교통, 에너지 절약)이 탄소 발자국을 줄이는 데 기여하지만, 기후변화의 근본적 해결은 시스템적 변화(에너지 정책, 산업 규제, 국제 협약)가 필수입니다. 개인의 선택과 집단적 시스템 변화가 동시에 필요합니다.

**Q. 한국의 환경 현황은 어떻나요?**
A. 한국은 GDP 대비 탄소 배출량이 OECD 상위권에 속합니다. 2050 탄소 중립을 선언했으며 재생에너지 확대와 산업 구조 전환이 진행 중입니다. 미세먼지, 플라스틱 폐기물, 수도권 녹지 부족도 주요 환경 과제입니다.
