## KcLep은 회계 지식을 입력으로 검증하는 도구다

전산회계 2급의 실무형 문제는 KcLep을 통해 회계 지식을 확인합니다. 프로그램을 잘 다룬다는 것은 단축키를 많이 안다는 뜻이 아니라, 거래를 읽고 올바른 메뉴와 계정과목에 입력할 수 있다는 뜻입니다. 기초정보가 틀리면 이후 전표와 장부도 틀어지므로, 처음 화면에서 확인할 항목을 정해 두어야 합니다.

KcLep 수험 환경은 시험 시행기관의 안내와 프로그램 버전에 따라 달라질 수 있습니다. 따라서 메뉴명이나 화면 순서를 암기하기보다 **회사등록 → 거래처 확인 → 계정과목 확인 → 일반전표 입력 → 장부 조회**라는 업무 흐름을 익히는 것이 안전합니다.

## 기초정보 등록의 의미

기초정보는 회사의 장부를 만들기 위한 기본 설정입니다. 회사명, 사업자등록번호, 회계기간, 업종, 거래처, 계정과목 같은 정보가 여기에 해당합니다. 전산회계 2급에서는 이미 주어진 자료를 확인하거나, 문제 지시에 따라 일부를 등록·수정하는 형태로 접근할 수 있습니다.

| 기초정보 | 확인할 내용 | 틀렸을 때 영향 |
|----------|-------------|----------------|
| **회사등록** | 회사명, 회계기간, 사업자 정보 | 전체 장부의 기준 오류 |
| **거래처등록** | 거래처명, 코드, 사업자 정보 | 채권·채무 관리 오류 |
| **계정과목** | 계정 코드와 성격 | 전표 분류 오류 |
| **전기분 잔액** | 이전 기간에서 넘어온 금액 | 재무제표 잔액 오류 |
| **환경 설정** | 입력 방식과 조회 조건 | 화면 표시·집계 혼동 |

기초정보는 시험에서 시간을 많이 쓰지 않아야 하지만, 무시하면 안 됩니다. 특히 회계기간이 다르면 같은 거래도 다른 기간의 장부에 들어가게 됩니다. 거래처 코드를 잘못 선택하면 외상매출금이나 외상매입금의 상대방 관리가 어긋납니다.

## 일반전표 입력의 기본 흐름

일반전표는 전산회계 2급에서 가장 기본이 되는 입력 화면입니다. 부가가치세 신고서와 직접 연결되는 매입매출전표보다 단순해 보이지만, 계정과목과 차변·대변 판단이 그대로 드러납니다.

일반전표 입력은 다음 순서로 연습하면 좋습니다.

1. 거래일자를 입력합니다.
2. 차변 계정과 대변 계정을 선택합니다.
3. 거래처가 필요한 계정이면 거래처를 선택합니다.
4. 금액을 입력합니다.
5. 적요를 간단히 기록합니다.
6. 저장 후 분개장이나 계정별 원장에서 반영 여부를 확인합니다.

예를 들어 5월 3일 사무실 임차료 300,000원을 보통예금에서 이체했다면 다음 분개가 됩니다.

`(차) 임차료 300,000 / (대) 보통예금 300,000`

KcLep에서는 거래일자 5월 3일, 차변 임차료, 대변 보통예금, 금액 300,000원, 적요 “5월 사무실 임차료”처럼 입력 흐름을 정리할 수 있습니다.

## 거래처 입력이 필요한 경우

거래처는 모든 전표에 반드시 필요한 것은 아닙니다. 하지만 외상매출금, 외상매입금, 미수금, 미지급금처럼 상대방별 관리가 필요한 계정에서는 거래처 입력이 중요합니다. 거래처를 빠뜨리면 총액은 맞아도 거래처별 잔액이 맞지 않을 수 있습니다.

| 계정과목 | 거래처 필요성 | 이유 |
|----------|---------------|------|
| **외상매출금** | 높음 | 거래처별 받을 돈 관리 |
| **외상매입금** | 높음 | 거래처별 지급할 돈 관리 |
| **미수금** | 높음 | 영업 외 채권 상대방 관리 |
| **미지급금** | 높음 | 영업 외 채무 상대방 관리 |
| **급여** | 상황별 | 직원별 관리 자료가 별도일 수 있음 |
| **소모품비** | 낮음 | 단순 비용 처리 가능 |

예를 들어 거래처 오이상사에 상품 700,000원을 외상 판매했다면 외상매출금에 거래처를 연결해야 합니다.

`(차) 외상매출금 700,000 / (대) 매출 700,000`

이때 거래처를 다른 업체로 선택하면 분개 금액은 맞아도 거래처별 채권 잔액이 틀립니다.

## 입력 후 조회가 실력이다

전표를 입력하고 끝내면 실무형 시험에서 실수를 발견하기 어렵습니다. 입력 후에는 분개장, 총계정원장, 거래처원장, 시산표, 재무제표 조회를 통해 결과가 의도대로 반영되었는지 확인해야 합니다. 전산회계 공부의 장점은 입력 결과를 바로 확인할 수 있다는 점입니다.

| 조회 화면 | 확인할 내용 | 활용 포인트 |
|-----------|-------------|-------------|
| **분개장** | 입력한 전표의 차변·대변 | 개별 거래 오류 확인 |
| **총계정원장** | 계정별 증가·감소 내역 | 특정 계정 흐름 확인 |
| **거래처원장** | 거래처별 채권·채무 | 외상 잔액 확인 |
| **시산표** | 계정 잔액과 합계 | 전체 균형 확인 |
| **재무제표** | 자산·부채·자본·손익 | 최종 결과 확인 |

예를 들어 외상매출금을 회수한 거래를 입력했다면 외상매출금 거래처원장에서 잔액이 줄어야 합니다.

`(차) 보통예금 200,000 / (대) 외상매출금 200,000`

분개장만 보면 맞아 보일 수 있지만, 거래처를 잘못 넣었다면 거래처원장에서 오류가 드러납니다.

## 학습 체크포인트

- KcLep은 회계 판단을 입력과 조회로 확인하는 프로그램이다.
- 회사등록과 회계기간은 전체 장부의 기준이 된다.
- 거래처가 필요한 계정은 상대방별 잔액까지 확인해야 한다.
- 일반전표 입력 후 분개장과 원장 조회로 결과를 검토해야 한다.
- 메뉴명 암기보다 업무 흐름을 익히는 것이 시험장에서 안정적이다.

## 자주 틀리는 오답 패턴

KcLep 실무에서 첫 번째 오답은 프로그램 화면을 외우는 데만 집중하고 회계 판단을 건너뛰는 것입니다. 메뉴 위치를 알아도 거래를 잘못 읽으면 잘못된 계정과목을 선택합니다. 프로그램은 분개 실력을 대신해 주지 않습니다. 입력 전에는 반드시 종이에 차변·대변을 짧게 정리하고, 입력 후에는 조회 화면에서 결과를 확인해야 합니다.

두 번째 오답은 기초정보를 시험 초반에 대충 넘기는 것입니다. 회사등록의 회계기간, 거래처 코드, 계정과목 설정이 잘못되면 뒤의 전표가 맞아도 최종 장부가 어긋날 수 있습니다. 특히 거래처가 여러 개 제시되는 문제에서는 이름이 비슷한 업체를 잘못 선택하지 않도록 코드와 상호를 함께 확인해야 합니다.
