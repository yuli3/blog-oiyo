## 3강 개요: 시세는 '어디까지' 가나

파동(형)·시간(언제)을 익혔으니, 마지막 기둥은 가격이다. **값폭관측론(値幅観測論)** 은 파동의 폭을 바탕으로 다음 목표 가격대를 계산한다.

<Callout type="info">
**이 강의의 목표**: V·N·E·NT 네 가지 계산값의 원리를 이해하고, 상승 N파동에서 목표가를 산출하는 법을 익힌다.
</Callout>

---

## 1. 기준이 되는 세 지점

가격론은 직전 파동의 세 변곡점을 기준으로 한다.

```
상승 국면 예:
  A = 출발 저점
  B = 1차 상승 고점
  C = 조정 저점(B에서 되돌린 자리)
→ A→B 상승폭과 B→C 조정폭으로 다음 목표를 계산
```

---

## 2. 네 가지 계산값

| 계산값 | 공식(상승) | 의미 |
|--------|-----------|------|
| **V** | C + (B − C) | 조정폭만큼 되돌림(이중천장 대칭) |
| **N** | C + (B − A) | 1차 상승폭을 C에 더함(가장 기본) |
| **E** | B + (B − A) | 1차 상승폭을 B에 더함(배수 확장) |
| **NT** | C + (C − A) | A→C 폭을 C에 더함 |

```
폭 관계: 보통 V < N < E (E가 가장 높은 목표)
NT는 조정이 얕을 때 의미가 커진다.
```

<Callout type="tip">
**N계산값이 가장 기본이다.** "1차로 오른 만큼 조정 저점에서 다시 오른다"는 N파동의 대칭성을 그대로 목표가로 옮긴 것이다. 처음엔 N을 기준 목표로 삼고, 돌파하면 E를 다음 목표로 본다.
</Callout>

---

## 3. 계산 예시

```
A = 10,000 / B = 13,000 / C = 12,000 이라면
- 1차 상승폭(B−A) = 3,000 / 조정폭(B−C) = 1,000

V = C + (B−C) = 12,000 + 1,000 = 13,000
N = C + (B−A) = 12,000 + 3,000 = 15,000
E = B + (B−A) = 13,000 + 3,000 = 16,000
NT = C + (C−A) = 12,000 + 2,000 = 14,000

→ 목표대: 13,000(V)·14,000(NT)·15,000(N)·16,000(E)
```

---

## 4. 목표가를 쓰는 법

```
- 여러 계산값이 한 가격대에 겹치면 그 자리가 강한 목표·저항
- 구름대·전고점 등 다른 저항과 겹치면 신뢰도 ↑
- 목표 도달 + 변화일(시간론) 일치 = 청산·반전 주의 구간
```

<Callout type="note">
가격론은 '정확한 한 점'이 아니라 **'유력한 목표대'** 를 준다. V~E의 띠를 그리고, 그 안에서 시간론·파동·다른 저항과 겹치는 지점을 핵심 후보로 좁히는 것이 실전이다.
</Callout>

---

## 5. 하락 국면 적용

상승의 공식을 좌우·상하 대칭으로 뒤집으면 하락 목표가가 된다.

```
하락 N = C − (A − B)  (A=출발 고점, B=1차 하락 저점, C=반등 고점)
→ 부호만 반대, 원리는 동일
```

---

## 이번 강의 핵심 요약

1. 값폭관측론은 직전 파동의 폭으로 다음 목표 가격대를 계산한다.
2. 기준점은 출발(A)·1차 고점(B)·조정 저점(C)이다.
3. V·N·E·NT 네 계산값 중 **N이 가장 기본**, E가 가장 높은 목표.
4. 여러 계산값이 겹치거나 구름·전고점과 겹치면 강한 목표·저항이다.
5. 목표 도달 + 변화일 일치 구간은 반전·청산을 주의한다.

**다음 강의**: 이제 이론에서 선으로 돌아온다. 전환선·기준선·후행스팬·선행스팬의 상호작용과, 호전·역전을 더 정밀하게 해석하는 법을 다룬다.
