## ITQ 시험 개요

```
ITQ (Information Technology Qualification):
→ 한국생산성본부(KPC) 시행 국가공인 자격
→ 컴퓨터 활용 능력 자격 — 실무 중심

시험 종목:
→ 한글 (아래아한글)
→ MS 워드 (Word)
→ 한셀 / 엑셀 (스프레드시트)
→ 한쇼 / 파워포인트 (프레젠테이션)
→ 인터넷 (인터넷 Explorer·Edge)
→ MS 액세스 (Database)

급수 체계:
→ A등급 (400점 이상): 최고
→ B등급 (300~399점)
→ C등급 (200~299점)
→ OA 마스터: 4과목 이상 A등급

시험 방식:
→ 실기 시험 (컴퓨터 직접 작업)
→ 시험 시간: 60분
→ 총 500점 만점
→ 제시된 문서 출력물과 동일하게 작성

채점 기준:
→ 문제별 부분 점수
→ 글꼴·크기·속성 오류 감점
→ 위치·크기·내용 불일치 감점
→ 파일 저장 방식 오류 시 0점 처리 주의
```

## 글자 모양과 문단 모양

```
글자 모양 (Alt + L):
→ 글꼴 설정: 굴림·맑은고딕·HY헤드라인M 등
→ 크기: 9pt·10pt·12pt·14pt·16pt·18pt·24pt
→ 속성: 진하게(Ctrl+B)·기울임(Ctrl+I)·밑줄(Ctrl+U)
→ 자간: 자간 좁히기/넓히기 (장평과 구별)
→ 장평: 글자의 가로 크기 조절 (%)
→ 글자 색: 색상 팔레트 선택
→ 음영·강조점·취소선·위첨자·아래첨자

문단 모양 (Alt + T):
→ 정렬: 왼쪽·오른쪽·가운데·양쪽·배분
→ 여백: 왼쪽·오른쪽 들여쓰기
→ 첫째 줄: 들여쓰기·내어쓰기 mm 단위
→ 간격: 줄 간격 (160%·180%·200% 등)
→ 문단 앞·뒤 간격: pt 단위

스타일 (F6):
→ 미리 정의된 글자·문단 속성 집합
→ 제목 1·제목 2·본문·글머리표 등
→ 일괄 변경: 스타일 수정 → 전체 적용

단축키 정리:
→ Ctrl+A: 전체 선택
→ Ctrl+Z: 되돌리기 (Undo)
→ Ctrl+Y: 다시 실행 (Redo)
→ Ctrl+C/V/X: 복사·붙여넣기·잘라내기
→ F7: 맞춤법 검사
→ Ctrl+S: 저장
```

## 표 작성과 편집

```
표 삽입:
→ 삽입 메뉴 → 표 → 행/열 수 지정
→ 단축키: Ctrl+N, T (표 삽입)

표 편집:
→ 셀 합치기: 선택 후 [셀 합치기] (M)
→ 셀 나누기: 행/열 수 지정
→ 행/열 삽입·삭제
→ 셀 너비·높이 조정: 드래그 또는 표 속성

셀 속성:
→ 안 여백 (셀 안 텍스트 여백)
→ 세로 정렬: 위·가운데·아래
→ 대각선·배경색 설정

표 속성 (자주 출제):
→ 테두리 종류·굵기·색상
→ 배경: 그라데이션·그림·색상
→ 글자처럼 취급: 본문과 어울림

계산식 (표 내부):
→ 블록 합계: 블록 지정 → Ctrl+Shift+S
→ 함수: SUM·AVG·MAX·MIN·COUNT
→ 블록 평균: Ctrl+Shift+A

표 디자인 팁 (ITQ 출력물 기준):
→ 첫 행 배경색·글자 색 변경 (제목 행 강조)
→ 테두리 굵기: 외곽선 굵게, 내선 보통
→ 표 전체 글꼴·크기 통일 후 선택 부분만 변경
```

## 그림·개체 삽입

```
그림 삽입:
→ 삽입 → 그림 → 파일에서 (Ctrl+N, I)
→ 그림 속성: 본문과의 배치 (어울림·문자열·자리차지)

그림 편집:
→ 자르기: 테두리 드래그
→ 밝기·명암 조절
→ 테두리 선: 종류·색·굵기
→ 그림 크기: 가로·세로 mm 단위 입력 (정확도 중요)

도형 삽입:
→ 삽입 → 도형 (직선·화살표·사각형·타원·말풍선 등)
→ 채우기 색·선 색 설정
→ 그림자·3D 효과

글상자:
→ 삽입 → 글상자
→ 내용 입력 후 글자 모양·정렬 설정
→ 테두리·배경색 설정

개체 선택·정렬:
→ Shift 클릭: 여러 개체 선택
→ 맞춤: 왼쪽·오른쪽·가운데·상단·하단 맞춤
→ 간격 맞추기: 동일 간격 배분
→ 그룹: 여러 개체를 하나로 묶기 (Ctrl+G)

캡션:
→ 그림·표 선택 → [개체 속성] → [설명문]
→ 자동 번호 부여 기능
```

## 머리말·꼬리말·쪽 번호

```
머리말 (Header):
→ 삽입 → 머리말 → 짝수·홀수·모든 쪽 선택
→ 내용 입력: 문서 제목·회사명·날짜
→ 글자 속성 동일 방법으로 변경
→ 닫기: 머리말 영역 밖 클릭

꼬리말 (Footer):
→ 삽입 → 꼬리말
→ 쪽 번호 삽입 (꼬리말 내에서 코드 삽입)

쪽 번호:
→ 삽입 → 쪽 번호 → 위치·모양 선택
→ 모양: 1, 2, 3 / i, ii, iii / 가, 나, 다
→ 위치: 쪽 상단·하단, 좌·중·우
→ 새 번호로 시작: 특정 쪽에서 번호 재시작

구역 설정:
→ 쪽 설정 → 구역 나누기
→ 구역별 다른 머리말·꼬리말·쪽 방향 적용
→ 홀수 쪽 시작·짝수 쪽 시작 설정

메일 머지 (주소록 연결):
→ 도구 → 메일 머지 → 메일 머지 표시 달기 → 편지 연결
→ 데이터 파일: 표 또는 CSV 형태 주소록
→ 메일 머지 필드: {{이름}}, {{주소}} 등 삽입
→ 출력: 화면·프린터·파일로 출력
→ 레이블 메일 머지: 명함·스티커 형식 출력
```

## 자주 묻는 질문

**Q. ITQ 한글 시험에서 가장 많이 틀리는 부분은 무엇인가요?**
A. 가장 빈번한 실수는 첫째 문단 모양에서 줄 간격이나 들여쓰기 값을 정확히 입력하지 않는 일입니다. 둘째, 표의 셀 크기와 배경색·테두리 굵기를 지시사항과 다르게 설정하는 경우입니다. 셋째, 그림의 크기를 mm 단위로 정확히 입력하지 않고 드래그로 대략 맞추는 실수입니다. 넷째, 스타일 적용을 빠뜨리거나 잘못 적용하는 일입니다. 시험 전 출력물과 자신의 작업을 꼼꼼히 비교하는 습관이 중요합니다.

**Q. 메일 머지 기능은 어떤 상황에서 사용하나요?**
A. 메일 머지는 동일한 형식의 문서를 여러 수신자에게 맞춤 발송할 때 사용합니다. 예를 들어 초청장, 청구서, 합격 통보서처럼 내용은 같되 이름·주소·금액만 다른 문서를 수백 개 만들 때 효율적입니다. 데이터 파일(주소록)과 서식 파일(편지)을 연결해 한 번에 출력할 수 있습니다. ITQ 시험에서는 메일 머지 표시 달기, 데이터 연결, 출력 과정 전체를 순서대로 실행해야 감점을 피할 수 있습니다.
