# 동물 성격 유형 테스트

행동 심리학의 대표 모델인 DISC 이론은 William Moulton Marston이 1928년 《Emotions of Normal People》에서 처음 제시한 후 수십 년간 기업 교육, 리더십 개발, 팀 빌딩에 광범위하게 활용되고 있습니다.

그러나 D, I, S, C라는 알파벳은 직관적으로 이해하기 어렵습니다. 이 테스트는 각 유형을 동물 아키타입으로 비유해 훨씬 더 직관적이고 재미있게 자신의 행동 패턴을 이해할 수 있도록 설계했습니다.

## 4가지 동물 유형

**🦁 사자형 (D — Dominance / 주도형)**
목표를 향해 직진하는 강한 추진력. "결과를 보여주겠다"는 마인드의 소유자입니다.

**🐬 돌고래형 (I — Influence / 사교형)**
사람들에게 에너지를 주는 천부적 소통가. "함께하면 더 재밌어진다"는 사람입니다.

**🐻 곰형 (S — Steadiness / 안정형)**
팀의 든든한 버팀목. "믿고 의지할 수 있는 사람"으로 인정받는 유형입니다.

**🦉 올빼미형 (C — Conscientiousness / 신중형)**
데이터와 분석으로 최고의 결과를 추구하는 전문가형입니다.

이 테스트는 12문항으로 구성되며, 각 질문에서 가장 자신과 가까운 행동을 선택하세요.

## 결과 해석 가이드

### 팀에서의 역할

| 유형 | 이상적 역할 | 주의할 점 |
|---|---|---|
| 🦁 사자 | 프로젝트 리더, 영업, 기획 | 팀원 감정 배려 필요 |
| 🐬 돌고래 | 마케팅, 고객응대, 팀 분위기 메이커 | 세부 실행력 보완 필요 |
| 🐻 곰 | 운영, 지원, 팀 조화 유지 | 자기 의사 표현 연습 필요 |
| 🦉 올빼미 | 데이터 분석, 품질 관리, 전문직 | 빠른 실행과 결정 연습 필요 |

### 유형 간 궁합

- 🦁 + 🦉: 사자의 추진력 + 올빼미의 분석력 = 강력한 시너지
- 🐬 + 🐻: 돌고래의 소통력 + 곰의 안정감 = 따뜻한 팀 문화
- 🦁 + 🐬: 두 외향 유형 → 에너지는 넘치지만 실행 디테일 주의
- 🐻 + 🦉: 두 신중 유형 → 안정적이지만 변화 대응 속도 주의

<Callout type="tip">
**이 테스트의 핵심 활용법**: 내 유형을 알았다면 이제 팀원의 유형을 생각해보세요. "저 사람은 왜 저렇게 행동할까?"의 답이 보이기 시작합니다. 서로 다른 동물이 모여야 강한 팀이 됩니다.
</Callout>
