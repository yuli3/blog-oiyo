## 공문서 작성 핵심 규칙 총정리

```
구성 요소:
① 두문: 수신·발신·제목
② 본문: 내용 (두괄식)
③ 결문: 붙임·담당자·발신일·직인

날짜: 2026. 5. 13. (마지막 마침표 필수)

금액: 1,500,000원 → 서술 시 "150만 원"

숫자: 아라비아 숫자 원칙

면적: ㎡ (평 사용 금지)

경어:
- 기관 수신: ~귀중
- 개인 수신: ~귀하
- 과도한 이중 경어 금지
```

## 문장 유형별 교정표

```
┌────────────────────────────┬──────────────────────────────┐
│ 나쁜 표현                  │ 좋은 표현                    │
├────────────────────────────┼──────────────────────────────┤
│ 검토가 이루어졌습니다      │ 검토하였습니다               │
│ 추진이 될 예정입니다       │ 추진할 예정입니다            │
│ 되어지다, 보여지다         │ 되다, 보이다                 │
│ 조속한 시일 내에           │ 2026. 6. 30.까지             │
│ 적극적으로 추진하겠습니다  │ ○월 ○일까지 완료하겠습니다  │
│ 관계 기관과 협의           │ ○○기관과 ○일 이내 협의      │
│ ~하는 방향으로 검토        │ 검토하겠습니다               │
│ 이와 같은 이유로 인하여    │ 이러한 이유로                │
│ 알려드리겠습니다           │ 알립니다                     │
│ 현재 진행 중에 있습니다    │ 진행 중입니다                │
└────────────────────────────┴──────────────────────────────┘
```

## 양식별 핵심 체크리스트

### 기안문

```
☐ 수신·발신 기관 정확히 기재
☐ 제목: 간결하고 내용 요약
☐ 배경 → 현황 → 추진 방향 순
☐ 예산: 정확한 금액·재원
☐ 일정: 구체적 날짜
☐ 붙임 자료 목록
☐ 담당자 연락처
```

### 보고서

```
☐ 두괄식: 결론·핵심 먼저
☐ 현황 수치: 구체적 숫자 사용
☐ 사실 vs 의견 분리
☐ 조치 사항: 담당자·기한 명시
☐ 과도한 경어 표현 제거
```

### 통보문·협조문

```
☐ 통보 사항 명확히 열거
☐ 협조 요청 기한 명시
☐ 담당자 연락처 포함
☐ 수신처 올바른 경어 (귀중/귀하)
```

## 자주 틀리는 오답 포인트

```
① 날짜 마지막 마침표 누락
   → "2026. 5. 13." (O) / "2026. 5. 13" (X)

② 금액 단위 생략
   → "3,500만" (X) → "3,500만 원" (O)

③ 이중 피동 표현
   → "되어지다·보여지다" (X)

④ 모호한 기간·방법
   → "조속히·적극적으로" (X) → 구체적 날짜·방법 (O)

⑤ 기관 경어 혼동
   → 기관에 "귀하" (X) → "귀중" (O)
   → 개인에 "귀중" (X) → "귀하" (O)

⑥ 평(坪) 단위 사용
   → 공문서 면적: ㎡ 사용

⑦ 과도한 경어·겸양어
   → "알려드리겠습니다" (이중 경어) → "알립니다"

⑧ 두 개 이상 정보를 한 문장에
   → 항목 번호로 분리 (1., 2., 3.)

⑨ 주어-서술어 호응 불일치
   → "목적은 ~하기 위해" (X) → "목적은 ~임" (O)

⑩ 접속사 과다 사용
   → "그리고·또한·그런데" 반복 → 항목화 또는 삭제
```

## 핵심 개념 카드

**날짜 표기 완성형** ★★★★★
: 2026. 5. 13. — 연도 4자리, 월·일 아라비아, 마지막 마침표.
*암기 포인트: 마지막 마침표 절대 빠뜨리지 말 것*

**이중 피동 절대 금지** ★★★★★
: "되어지다·보여지다" = 이중 피동. "검토가 이루어지다" → "검토하다".
*암기 포인트: 피동은 한 번만*

**두괄식 구성** ★★★★★
: 결론·핵심을 첫 문장에. 상위 결재권자가 첫 단락만 읽어도 파악 가능하게.
*암기 포인트: 핵심→근거→세부 순*

## 실전 퀴즈 (종합)

**Q. 다음 문장을 올바른 공문서 표현으로 고치시오: "이번 행사는 적극적으로 추진되어질 예정입니다."**
> "이번 행사는 2026. 6. 30.까지 추진할 예정입니다." — 이중 피동 제거, 모호한 기간 → 구체적 날짜.

**Q. 공문서에서 금액 "12,345,678원"을 서술할 때 읽기 쉬운 표기법은?**
> "1,234만 5,678원" 또는 "약 1,235만 원(12,345,678원)". 만 단위 구분 + 원 단위 명시.

**Q. 기관명 "○○시청"을 수신자로 표기할 때와 특정 직위자 "○○과장"을 수신자로 표기할 때 각각 올바른 경어는?**
> 기관 수신: "○○시청 귀중". 특정 직위자 수신: "○○시청 기획과장 귀하".
