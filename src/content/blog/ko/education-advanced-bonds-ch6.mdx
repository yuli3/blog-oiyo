## 왜 채권 포트폴리오가 필요한가

단일 채권 투자의 문제점:

```
만기 집중 리스크: 한 시점에 대규모 만기
금리 위험: 단기에 모두 몰면 재투자 위험
유동성 문제: 장기만 보유 시 현금화 어려움
```

포트폴리오 접근으로 이 위험들을 체계적으로 분산합니다.

## 3대 채권 포트폴리오 전략

### 1. 래더 전략 (Ladder Strategy)

```
구성:
동일 금액을 여러 만기에 분산
예: 1년, 2년, 3년, 4년, 5년에 각 20%

작동 방식:
1년 만기 → 원금 회수 → 5년 채권 재투자
→ 항상 1~5년 포트폴리오 유지

장점:
- 금리 변동에 자동 적응 (평균 매수)
- 정기적 현금 흐름 확보
- 복잡한 판단 불필요

단점:
- 금리 급등 시 단기 수익률 기회 놓침
- 금리 급락 시 장기 채권 수익 제한
```

### 2. 바벨 전략 (Barbell Strategy)

```
구성:
단기(1~2년) + 장기(10~30년)에만 집중
중간 만기는 보유하지 않음

예: 단기 50% + 장기 50%

작점:
- 단기: 유동성 확보 + 금리 상승 시 빠른 재투자
- 장기: 금리 하락 시 자본 이익 극대화

단점:
- 중간 금리 상승 시 장기 채권 손실
- 변동성이 래더보다 큼
```

### 3. 불릿 전략 (Bullet Strategy)

```
구성:
특정 목표 시점에 만기 집중
예: 5년 후 집 살 계획 → 5년 만기 채권에 집중

장점:
- 목표 자금 조달에 최적화
- 금리 예측 정확하면 수익 극대화

단점:
- 목표 시점에 금리가 낮으면 재투자 수익률 하락
- 단일 시점 집중으로 분산 효과 없음
```

## 채권-주식 배분 원칙

### 전통적 60/40 포트폴리오

```
주식 60% + 채권 40%

역사적 성과 (1990~2020):
- 연평균 수익률: 약 8~9%
- 2022년 급격한 금리 인상으로 둘 다 하락 (위기)

조정된 현대 배분:
- 위험 감내도에 따라 유연하게 조정
- 100 - 나이 = 주식 비중 (전통 규칙, 참고용)
```

### 연령별 채권 비중 가이드

| 연령대 | 채권 비중 | 이유 |
|--------|-----------|------|
| 20~30대 | 10~20% | 장기 투자 지평, 위험 감내 가능 |
| 40대 | 20~40% | 균형 포트폴리오로 전환 |
| 50대 | 40~60% | 자산 보전 강화 |
| 60대 이상 | 50~70% | 안정적 현금 흐름 우선 |

## 채권 포트폴리오 리밸런싱

### 리밸런싱이 필요한 시점

```
시간 기반: 6개월 또는 1년마다 정기적으로
임계치 기반: 목표 비율에서 5%p 이상 벗어날 때
이벤트 기반: 금리 사이클 전환 판단 시
```

### 리밸런싱 실행

```
예시:
목표: 주식 60% / 채권 40%
현재: 주식 68% / 채권 32% (주가 상승)

→ 주식 8% 매도, 채권 8% 매수로 원상 복귀
→ 이때 발생하는 양도차익에 세금 주의
```

## 채권 포트폴리오의 듀레이션 관리

```
목표 듀레이션 설정:
금리 상승 예상 → 듀레이션 단축 (단기 채권 비중 늘림)
금리 하락 예상 → 듀레이션 연장 (장기 채권 비중 늘림)
불확실 시 → 중립 포지션

듀레이션 계산:
포트폴리오 듀레이션 = 각 채권 듀레이션의 가중 평균
예: 2년 채권 50% + 10년 채권 50% = 6년 듀레이션
```

## 실전 포트폴리오 예시

**40대 직장인, 1억 원 채권 포트폴리오**

```
래더 전략 적용:
단기(1~2년): 국채 2,000만 원
중기(3~5년): 국채 3,000만 원
중장기(7년): 우량회사채 A+ 2,000만 원
장기(10년): 국채 2,000만 원
물가연동채(TIPS): 1,000만 원

예상 수익률: 연 3.5~4.5% (금리 환경에 따라 변동)
듀레이션: 약 5.5년
```
