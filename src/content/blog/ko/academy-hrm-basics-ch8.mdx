## 리더십 이론 발전

```
특성 이론:
리더 고유 특성 (지능·외향성·자신감)
태어난 리더 vs 만들어진 리더

행동 이론:
Ohio State: 구조 주도·배려 (2차원)
Blake·Mouton: 관리 그리드 (5가지 스타일)

상황 이론:
Fiedler: 과업 지향·관계 지향 매칭
Hersey·Blanchard: 부하 성숙도에 따른 적응
Path-Goal 이론: 경로 명확·장애 제거
```

---

## 변혁적 vs 거래적 리더십

```
거래적 리더십:
조건부 보상 (성과 → 보상)
예외 관리 (문제 발생 시 개입)
현상 유지

변혁적 리더십:
비전 제시 (Inspirational Motivation)
지적 자극 (Intellectual Stimulation)
개별 배려 (Individual Consideration)
이상적 영향 (Idealized Influence)

서번트 리더십:
구성원 성장·욕구 지원
리더=하인 관점
신뢰·봉사
```

## 조직문화

```
조직문화 정의:
조직 구성원이 공유하는 가치·규범·믿음

Schein 3수준:
인공물: 가시적 요소 (공간·복장·의식)
가치관: 선언된 믿음
기본 가정: 무의식적 믿음 (핵심)

문화 유형 (Quinn):
위계 문화: 규칙·통제 중심
시장 문화: 경쟁·성과 중심
씨족 문화: 협력·팀워크 중심
혁신 문화: 창의성·변화 중심
```

---

## 조직 개발 (OD)

```
OD 정의:
계획적·체계적 조직 변화 관리

OD 접근:
감수성 훈련 (T그룹)
팀 빌딩
과정 자문
서베이 피드백

변화 관리 (Lewin):
해빙 → 변화 → 재동결
저항 원인: 불확실·손실 우려·습관

Kotter 8단계 변화 모델:
위기감 조성→연합 구축→비전 설정→
소통→권한 부여→단기 성과→지속→정착
```

## 실전 퀴즈

**Q. 조직문화가 조직 성과에 미치는 영향은?**
> 강한 문화: 구성원 행동 일관·예측 가능. 전략 실행 용이. 단, 변화 저항 강함. 문화-전략 정합성 중요: 혁신 전략인데 위계 문화이면 실행 실패. 삼성·애플·구글 모두 독특한 문화가 경쟁우위. 채용·온보딩·의식·이야기로 문화 전파.

**Q. 변화에 대한 저항을 관리하는 방법은?**
> Lewin 해빙 단계: 현재 상태의 불편함 인식시키기. 소통: 변화 이유·방향 명확히. 참여: 변화 설계에 구성원 참여. 지원: 교육·코칭·심리적 안전. 인센티브: 변화 실행 보상. Kotter: 단기 성과(Quick Wins)로 신뢰 구축. 저항을 적이 아닌 피드백으로.
