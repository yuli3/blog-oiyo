## Qu'est-ce que la psychopathologie — la frontière du « normal » et de l'« anormal »

```
Les 4D du comportement anormal :
Deviance (déviance) : s'écarter des normes socioculturelles
Distress (détresse) : la personne éprouve de la souffrance
Dysfunction (dysfonctionnement) : entrave la vie quotidienne et les relations
Danger (dangerosité) : menace pour soi ou pour autrui

→ Les quatre critères n'ont pas à être tous réunis
→ Le contexte culturel est déterminant
```

## Les principaux troubles psychiques

### La dépression (Major Depressive Disorder)

```
Symptômes (au moins deux semaines, cinq critères ou plus) :
- Humeur dépressive presque chaque jour
- Baisse de l'intérêt et du plaisir (anhédonie)
- Modification du sommeil (hypersomnie ou insomnie)
- Modification de l'appétit
- Fatigue, perte d'énergie
- Culpabilité, sentiment d'inutilité
- Difficultés de concentration
- Pensées de mort

Prévalence sur la vie entière : environ 15 %
Environ deux fois plus fréquente chez les femmes
```

### Les troubles anxieux

```
Trouble d'anxiété généralisée (TAG) :
→ Inquiétude excessive et diffuse pendant plus de six mois

Trouble panique :
→ Terreur intense et soudaine (tachycardie, sensation d'étouffement, impression de mourir)
→ Récidives imprévisibles

Anxiété sociale :
→ Peur extrême d'être humilié en situation sociale
→ Évitement des prises de parole, des conversations, du regard d'autrui

Phobies :
→ Peur irrationnelle d'un objet ou d'une situation précise
→ Acrophobie, arachnophobie…
```

### TSPT (trouble de stress post-traumatique)

```
Survient après un événement traumatique :
- Symptômes intrusifs : flash-back, cauchemars
- Évitement : fuir personnes, lieux et pensées liés au trauma
- Cognitions et affects négatifs : culpabilité, sentiment d'étrangeté
- Hyperactivation : sursauts exagérés, troubles du sommeil

Traitement : EMDR et exposition prolongée sont efficaces
```

## Les grandes approches thérapeutiques

### La thérapie cognitivo-comportementale (TCC)

Aujourd'hui la plus répandue et la mieux étayée par les données :

```
Principe central :
Modifier le lien pensée (cognition) → émotion → comportement

Restructuration cognitive :
→ Repérer les pensées automatiques négatives
→ Examiner les preuves → les remplacer par des pensées plus équilibrées

Activation comportementale :
→ Augmenter les activités agréables en période dépressive
→ Affronter progressivement les conduites d'évitement

Thérapie d'exposition :
→ Exposition graduée au stimulus redouté
→ Apprentissage de l'extinction de l'anxiété
```

### Psychanalyse et thérapies psychodynamiques

```
Sur les bases freudiennes :
→ Les conflits inconscients sont à l'origine des symptômes
→ Exploration de l'inconscient par l'association libre et l'analyse des rêves
→ Analyse du transfert

Psychodynamique contemporaine :
→ Relier les expériences d'attachement précoces aux schémas relationnels actuels
→ Traitement au long cours (de plusieurs mois à plusieurs années)
```

### Thérapie humaniste — l'approche centrée sur la personne de Rogers

```
Conditions essentielles :
Regard positif inconditionnel : accueillir sans juger
Compréhension empathique : comprendre depuis la position du client
Congruence : l'authenticité du thérapeute

L'être humain porte en lui une force de croissance vers la réalisation de soi
→ Le thérapeute en est le facilitateur

→ Efficace même en thérapie brève ; socle de toutes les approches
```

## Les traitements biologiques

```
Antidépresseurs :
ISRS (inhibiteurs sélectifs de la recapture de la sérotonine) : fluoxétine (Prozac)
→ Bloquent la recapture, augmentant la concentration synaptique de sérotonine
→ Effet perceptible après 2 à 4 semaines

Anxiolytiques :
Benzodiazépines : effet rapide, risque de dépendance
→ Usage court terme uniquement recommandé

Électroconvulsivothérapie (ECT) :
→ Pour les dépressions sévères, en cas d'échec des autres traitements
→ Efficace, mais effets indésirables sur la mémoire
```

---

## Guide du choix thérapeutique

```
Dépression : TCC + antidépresseur (l'association surpasse chaque option seule)
Troubles anxieux : TCC + exposition (premier choix)
TSPT : EMDR, exposition prolongée
Troubles de la personnalité : thérapie comportementale dialectique (TCD), psychodynamique au long cours
Schizophrénie : antipsychotiques + soutien psychosocial
```

## Points à retenir

*Les 4D du comportement anormal : Deviance, Distress, Dysfunction, Danger*
*TCC : modifier le lien pensée→émotion→comportement — la thérapie la mieux étayée*
*ISRS : inhibition de la recapture de la sérotonine → première ligne pour dépression et anxiété*
*Les trois conditions de Rogers : regard positif inconditionnel, empathie, congruence*
