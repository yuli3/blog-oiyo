# Minuteur Pomodoro

La méthode Pomodoro a été développée par Francesco Cirillo à la fin des années 1980. Son principe est simple : travailler en sprints de **25 minutes** entrecoupés de pauses courtes de **5 minutes**. La recherche en neurosciences confirme que ce rythme s'aligne sur les cycles naturels d'attention du cerveau.

## Comment pratiquer la méthode Pomodoro

| Étape | Durée | Action |
|---|---|---|
| 🍅 Pomodoro | 25 min | Travail concentré, sans distraction |
| Pause courte | 5 min | Levez-vous, étirez-vous, regardez au loin |
| Après 4 pomodori | 15–30 min | Pause longue, déconnexion totale |

<Callout type="tip">
**Règle d'or** : Si une distraction survient pendant un Pomodoro, notez-la sur un papier et revenez-y après. Ne brisez pas le cycle pour "juste un truc rapide" — c'est là que commence la procrastination.
</Callout>

## Pourquoi les pauses sont essentielles

| Mécanisme | Explication |
|---|---|
| **Default Mode Network** | Le cerveau consolide les informations pendant les pauses, pas pendant le travail |
| **Fatigue décisionnelle** | Les décisions de qualité diminuent après 90–120 minutes de concentration continue |
| **Mémoire de travail** | Se vide pendant les pauses, libère de la capacité pour la suite |

## Productivité selon les types de tâches

| Type de tâche | Durée recommandée | Technique |
|---|---|---|
| Rédaction / création | 25 min | Pomodoro standard |
| Code / débogage | 50 min | Pomodoro double |
| Révision / lecture | 25–50 min | Selon complexité |
| Réunion | Limiter à 45 min | No-Pomodoro, agenda strict |

<Callout type="note">
Selon une étude de l'Université de l'Illinois, une brève interruption mentale améliore significativement la concentration sur de longues tâches. Les pauses Pomodoro ne sont pas du temps perdu — elles sont investies dans la durabilité de votre performance.
</Callout>
