# Compatibilité MBTI

Le MBTI (Myers-Briggs Type Indicator) divise les personnalités en 16 types selon quatre axes : Extraversion/Introversion, Sensation/Intuition, Pensée/Sentiment, Jugement/Perception. Bien que sa validité scientifique soit débattue, c'est l'un des outils de connaissance de soi les plus utilisés au monde.

## Les 16 Types MBTI

| Catégorie | Types | Trait principal |
|---|---|---|
| **Analystes** | INTJ, INTP, ENTJ, ENTP | Logique, stratégique |
| **Diplomates** | INFJ, INFP, ENFJ, ENFP | Empathique, idéaliste |
| **Sentinelles** | ISTJ, ISFJ, ESTJ, ESFJ | Fiable, responsable |
| **Explorateurs** | ISTP, ISFP, ESTP, ESFP | Spontané, adaptable |

## Axes de compatibilité

| Axe partagé | Effet sur la relation |
|---|---|
| **N/S identique** | Communication plus naturelle, vision commune |
| **T/F opposés** | Tensions possibles, mais complémentaires |
| **J/P opposés** | L'un planifie, l'autre s'adapte — friction ou équilibre |
| **E/I mix** | Souvent enrichissant si les deux comprennent les besoins de l'autre |

<Callout type="tip">
**Les couples "opposés" (ex : INTJ & ENFP)** sont souvent parmi les plus durables. Chacun apporte ce que l'autre ne possède pas naturellement. La clé est la compréhension mutuelle, pas la similitude.
</Callout>

<Callout type="note">
**Rappel scientifique** : Le MBTI est critiqué pour sa fiabilité test-retest (30–50 % des personnes obtiennent un type différent à 5 semaines d'intervalle). Utilisez-le comme un cadre de réflexion, non comme une étiquette définitive.
</Callout>
