# Carte Tarot du Jour

Le tarot de Marseille et le tarot de Rider-Waite sont les deux systèmes les plus connus. Les 22 Arcanes Majeurs représentent les grandes étapes du parcours humain — de 0 (Le Mat / Le Fou) à 21 (Le Monde).

## Les 22 Arcanes Majeurs

| N° | Carte | Thème principal |
|---|---|---|
| 0 | Le Mat (Le Fou) | Nouveau départ, liberté |
| I | Le Bateleur | Créativité, pouvoir personnel |
| II | La Papesse | Intuition, mystère |
| VI | L'Amoureux | Choix, relation |
| X | La Roue de Fortune | Cycles, changement |
| XII | Le Pendu | Perspective inversée |
| XIII | La Mort | Transformation |
| XVII | L'Étoile | Espoir, renouveau |
| XVIII | La Lune | Inconscient, illusion |
| XIX | Le Soleil | Joie, succès |
| XX | Le Jugement | Éveil, bilan |
| XXI | Le Monde | Accomplissement |

<Callout type="note">
Le tarot est un outil de réflexion symbolique, non de prédiction certaine. La valeur d'un tirage réside dans ce qu'il révèle de votre état intérieur, pas dans sa capacité à prévoir l'avenir.
</Callout>
