# Vos mots favoris sont un autoportrait concret

Les tests de personnalite aident, mais les petits favoris du quotidien parlent parfois plus clairement. Parler, convaincre, ecouter, assembler, observer. Une boisson aimee, l'air apres la douche, l'odeur du linge chaud, un parfum familier a la maison. Ces details montrent quelle attention vous redonne de l'energie.

## 1. Commencer par les verbes

Les noms disent ce que vous aimez. Les verbes montrent votre mouvement.

| Mot | Ce que cela peut indiquer |
| --- | --- |
| Parler | Vous organisez vos pensees en les exprimant |
| Convaincre | Vous aimez lire la logique et les besoins de l'autre |
| Ecouter | Vous valorisez le contexte et la chaleur relationnelle |
| Assembler | Vous aimez transformer une idee en forme concrete |
| Observer | Vous preferez voir les motifs avant de juger |

Notez trois scenes ou chaque verbe est apparu naturellement. Ne cherchez pas tout de suite une reponse de carriere. Partez du reel.

## 2. Collectionner les petites joies

Plus une joie est petite, plus elle peut revenir aujourd'hui.

- Une boisson que vous aimez
- L'air sur la peau apres la douche
- Le linge chaud
- Une odeur familiere chez vous
- Un coin arrange a votre maniere

Demandez-vous ce qui etait agreable : temperature, texture, odeur, silence, souvenir, rythme ou presence de quelqu'un.

## 3. Les personnes que vous voulez revoir

Les personnes qui vous manquent revelent souvent des valeurs : securite, apprentissage, gratitude, reparation ou parole inachevee. Ecrivez leur nom, ce qu'elles vous ont donne, puis une phrase que vous aimeriez dire maintenant.

## 4. Remplir une partie de la journee avec vos favoris

Inutile de changer toute votre vie d'un coup. Choisissez un mot favori et donnez-lui une petite place aujourd'hui.

- Verbe : observer
- Action : marcher dix minutes et noter trois couleurs
- Espace : ranger un coin du bureau
- Recompense : boire quelque chose que vous aimez

Ce profil reste vivant. Les tendances changent avec le temps. Ecrivez plutot "en ce moment je suis attire par..." que "je suis toujours comme ca".
