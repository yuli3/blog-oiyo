## Rappel des principes fondamentaux

```
Principe 1 : tout comportement a des causes
→ Même ce qui paraît impulsif résulte de facteurs biologiques, psychologiques et sociaux

Principe 2 : hérédité et environnement comptent tous les deux
→ Nature vs Nurture → désormais Nature AND Nurture
→ Les gènes offrent des possibilités, l'environnement les réalise

Principe 3 : seule la méthode scientifique sépare le savoir de la superstition
→ Essai contrôlé randomisé > cas individuel > intuition

Principe 4 : l'humain est vulnérable aux biais cognitifs
→ Il faut prendre l'habitude de douter des jugements rapides du système 1
```

## La psychologie dans les relations

### Attirance et sympathie

```
Effet de proximité : plus on est proche, plus la sympathie augmente
Effet de simple exposition : plus on voit quelqu'un, plus on l'apprécie
Similarité : on est attiré par ceux qui nous ressemblent
Réciprocité : être apprécié conduit à apprécier en retour

Le triangle de l'amour de Sternberg :
→ Passion + intimité + engagement = amour accompli
→ L'équilibre des trois détermine la qualité de la relation
```

### Résolution des conflits

```
Les travaux de Gottman — les quatre cavaliers qui prédisent le divorce :
1. Critique : attaquer le caractère et la personne
2. Mépris : sarcasme, ironie blessante
3. Défensive : se justifier, contre-attaquer
4. Dérobade : retrait affectif

→ Le mépris est le plus toxique
→ Remplacer la critique par des messages en « je »
```

## La psychologie au travail

### Motiver

```
Motivation intrinsèque vs extrinsèque :
→ Une récompense externe excessive réduit la motivation intrinsèque (effet de sur-justification)

Sécurité psychologique (Amy Edmondson) :
→ Le sentiment qu'une erreur au sein de l'équipe ne sera pas dangereuse
→ Condition préalable de l'innovation et de l'apprentissage
→ Projet Aristote de Google : premier facteur de performance des équipes

Flow (Csikszentmihalyi) :
→ Productivité maximale quand le défi égale le niveau de compétence
→ Nécessite des objectifs clairs et un retour immédiat
```

### Décider

```
Prévenir la pensée de groupe :
→ Désigner un avocat du diable
→ Recueillir délibérément des points de vue divers
→ Recourir au vote anonyme

Surmonter le biais de confirmation :
→ Poser l'hypothèse inverse (« et si mon idée était fausse ? »)
→ Pré-mortem : imaginer l'échec à l'avance
```

## Santé et psychologie

```
Stress et santé :
Le SGA de Selye (syndrome général d'adaptation) :
alarme → résistance → épuisement

Cortisol chroniquement élevé → immunité affaiblie, mémoire altérée

Psychoneuroimmunologie :
→ L'état psychique agit directement sur la fonction immunitaire
→ Émotions positives → activation des cellules NK

Renforcer la résilience :
→ Construire un réseau de soutien social
→ Chercher du sens (logothérapie)
→ Pratiquer la pleine conscience
```

## Au terme de ce parcours

La psychologie est un outil pour comprendre l'être humain.

```
Ce que la psychologie peut vous apporter :

Se comprendre soi-même :
→ Comprendre l'origine de ses émotions et de ses schémas de conduite
→ Reconnaître qu'un changement est possible

Comprendre autrui :
→ Juger moins
→ Voir le contexte caché derrière les comportements

Mieux décider :
→ Repérer ses biais cognitifs → juger plus rationnellement
→ Comprendre la dynamique de groupe → devenir un meilleur coéquipier

Résilience :
→ Faire du stress et de l'adversité des occasions de croissance
→ Mettre en pratique des stratégies de bonheur scientifiquement validées
```

*Comprendre l'être humain, c'est déjà entreprendre le voyage qui mène à soi.*
