# Biorhythm Calculator

Biorhythm theory, proposed by German and Austrian researchers in the early 20th century, holds that physical, emotional, and intellectual abilities follow regular wave-like cycles. While not scientifically proven, it is widely used as a **self-awareness tool** for reflecting on personal patterns.

## The Three Biorhythm Cycles

| Cycle | Period | What It Governs |
|---|---|---|
| Physical | **23 days** | Stamina, endurance, coordination, immunity |
| Emotional | **28 days** | Mood, creativity, sensitivity, intuition |
| Intellectual | **33 days** | Logic, focus, analytical thinking, memory |

<Callout type="tip">
**Critical Days**: The transition points where each cycle crosses zero. On these days the relevant ability is unstable, increasing the chance of errors or accidents. It is generally advised to avoid important exams, surgeries, or long drives on critical days.
</Callout>

## How to Use Each Cycle

| State | Strategy |
|---|---|
| Physical ↑ (peak) | Exercise, outdoor activities, physically demanding work |
| Physical ↓ (low) | Rest, recovery, avoid overtraining |
| Emotional ↑ (peak) | Creative work, strengthening relationships, presentations |
| Emotional ↓ (low) | Avoid emotional decisions, meditate and rest |
| Intellectual ↑ (peak) | Study, exams, complex tasks |
| Intellectual ↓ (low) | Routine tasks, light idea-gathering |

## The Math Behind It

Each cycle is expressed as a **sine function**:

- Physical: sin(2π × days elapsed / 23)
- Emotional: sin(2π × days elapsed / 28)
- Intellectual: sin(2π × days elapsed / 33)

The number of days since birth is divided by each cycle length, and the sine value gives a result between −1 (lowest) and +1 (highest).

<Callout type="note">
Biorhythm theory is not a medically validated tool. Use it as a reference for self-reflection and daily planning — not as a substitute for professional health or medical advice.
</Callout>
