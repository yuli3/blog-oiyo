# Lost Ark Raid Splitter

When running a Legion Commander Raid across multiple games, this tool automatically distributes DPS and support characters to keep each party balanced in every game.

## Run Formats

**Main-1-Alt-1 (2 games)**: Each player runs their main once and one alt once.  
**Main-1-Alt-3 (4 games)**: Each player runs their main once and three alts.

For each game, the algorithm minimizes support/DPS imbalance.

## How to Input

```
D(M) D S ㄷ
```

| Symbol | Meaning |
|---|---|
| `D`, `ㄷ`, `d` | DPS (dealer) |
| `S`, `ㅍ`, `s` | Support |
| `(M)` suffix | Main character |

Enter one character per line, separated by spaces.

## Balancing Algorithm

The tool uses a swap-based optimization algorithm to minimize the variance in main supports, sub-supports, and main DPS across all games. It runs until the max–min difference for each role across games is no greater than 1.
