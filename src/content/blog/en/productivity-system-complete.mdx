Your brain isn't built for storing ideas — it's built for **generating** them. Try to hold every piece of information and every to-do in your head, and it overloads. The best productivity systems all chase the same goal: **freeing up the brain**.

## GTD (Getting Things Done) — David Allen

### The 5-Step GTD System

**Step 1: Capture**
Get everything in your head into an external system. "Open loops" — unresolved commitments — are what create cognitive load.

- Set up an inbox: a notebook, email, a physical tray
- Capture everything the moment it crosses your mind

**Step 2: Clarify**
Process what you've captured. For each item, ask: "Is this actionable?"

- Actionable → what's the next action?
- Not actionable → trash it, file it as reference, or put it on a someday/maybe list

**The 2-minute rule**: if it takes less than 2 minutes, just do it now.

**Step 3: Organize**
Put each clarified item where it belongs.

| Category | Description |
|------|------|
| Next actions | Concrete things you can do right now |
| Projects | Anything that needs two or more actions |
| Waiting for | Things you're waiting on from someone else |
| Someday/maybe | Not now, but maybe later |
| Reference material | No action needed, just information |
| Calendar | Things tied to a specific date or time |

**Step 4: Reflect**
Trusting the system means updating it regularly.

- **Daily review**: check today's tasks and calendar
- **Weekly review** (the most important one): one hour a week, review and update the whole system

**Step 5: Engage**
Choose your next action based on four factors: context, available time, available energy, and priority.

## Zettelkasten — Niklas Luhmann

The knowledge-management system behind how German sociologist Luhmann wrote 30 books. "Zettelkasten" literally means "slip box."

### Core Principles

**Atomic notes**: one idea per note. Keep it short and focused.

**In your own words**: don't just copy a quote — rewrite it in your own understanding.

**Link everything**: connect related notes to each other. Over time, this builds a web of knowledge.

**Record the context**: write down why the idea matters and how it connects to everything else.

### 3 Types of Notes

| Type | Description |
|------|------|
| **Fleeting notes** | Quick capture of a spontaneous idea, to process later |
| **Literature notes** | What you learned from something you read, in your own words |
| **Permanent notes** | Refined, final ideas, kept permanently |

### Recommended Tools

- **Obsidian**: free, local markdown files, excellent linking features
- **Roam Research**: pioneer of bidirectional linking
- **Notion**: integrates with databases, good for team collaboration
- **Bear**: simple notes for Mac and iPhone

## Building a Second Brain — Tiago Forte

A methodology for using digital notes to build a "second brain."

### The CODE Method

**C — Capture**: save information that's genuinely valuable

**O — Organize**: organize by actionability

**D — Distill**: keep only the essence. "Progressive summarization" — highlight first, bold the second pass, write a summary note on the third

**E — Express**: use your notes to create, not just to store

### The PARA Folder System

| Folder | Contents | Example |
|------|------|------|
| **P**rojects | What you're actively working on right now | "Prepare June presentation" |
| **A**reas | Ongoing areas you maintain | "Health," "Finances," "Learning" |
| **R**esources | Reference material on topics you care about | "Psychology," "Investing" |
| **A**rchive | Completed or inactive items | Past projects |

## Bringing the 3 Systems Together

| System | Best Used For |
|--------|---------|
| GTD | Task management, execution tracking |
| Zettelkasten | Building knowledge, creative thinking |
| Second Brain | Content capture, project management |

**A suggested combination**:
- Tasks: GTD (Todoist, Things, OmniFocus)
- Knowledge/notes: Obsidian, run Zettelkasten-style
- Project documents: Notion (using the PARA structure)

<Callout type="tip">
**Where to start**: don't get obsessed with building the perfect system. Start with a single, simple inbox. Jotting down whatever comes to mind in a notes app — that's the starting point of every productivity system.
</Callout>
