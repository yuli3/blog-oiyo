## What Capital Budgeting Is

**Capital budgeting** is decision-making about fixed-asset investments whose effects last more than a year. Installing new equipment, replacing existing equipment, expanding production capacity, and long-term projects are all capital budgeting decisions.

Capital budgeting connects directly to firm value. A bad long-term investment ties up cash flow for years, while a good one generates cash flows that exceed the capital the firm put in.

The capital budgeting process typically follows these steps.

1. Set investment objectives and identify alternative projects
2. Estimate the cash flows for each project
3. Evaluate the economics of each project and select among them
4. Implement the chosen project and re-evaluate afterward

---

## What Makes a Good Evaluation Criterion

An investment criterion shouldn't be judged by how easy it is to calculate, but by whether it increases firm value. An ideal criterion should satisfy three conditions.

1. It accounts for the **time value of money**.
2. It properly reflects the project's **risk**.
3. Its decision aligns with **increasing firm value**.

By this standard, the payback period and accounting rate of return are more like supplementary indicators, while net present value and internal rate of return serve as the core evaluation tools.

---

## A Summary of Investment Evaluation Methods

| Method | Meaning | Rule for an independent project | Rule for mutually exclusive projects |
| --- | --- | --- | --- |
| Payback period | Time required to recover the investment | Accept if shorter than the target payback period | Choose the project with the shortest payback period |
| Accounting rate of return | Accounting profit relative to the investment amount | Accept if higher than the target rate | Choose the project with the highest accounting rate of return |
| Net present value (NPV) | Present value of future cash flows minus the initial investment | Accept if NPV is positive | Choose the project with the highest NPV |
| Internal rate of return (IRR) | The discount rate that makes NPV equal to zero | Accept if IRR exceeds the required return | Choose the project with the highest IRR |
| Profitability index (PI) | Present value created per dollar invested | Accept if PI is greater than 1 | Choose the project with the highest PI |

### Payback period

The payback period is easy to understand and quickly reveals liquidity risk. But it ignores cash flows that occur after the payback point, and generally doesn't adequately capture the time value of money.

### Accounting rate of return

The accounting rate of return is easy to apply because it uses readily available accounting data. But it uses accounting profit rather than cash flow, and reflects time value and risk only weakly.

## Net Present Value (NPV)

The **net present value method** subtracts the initial investment from the present value of the cash flows a project is expected to generate.

```
NPV = Σ [CFt / (1 + r)^t] - C0

CFt: the cash flow at time t
r: the required return, or risk-adjusted discount rate
C0: the initial investment
```

A positive NPV means the project not only meets the required return but adds to firm value beyond that. So an independent project should be accepted if NPV is positive, and among mutually exclusive projects, the one with the highest NPV should be chosen.

NPV's biggest advantage is the **value-additivity principle**.

```
Total NPV = NPV of project A + NPV of project B + ...
```

Because firm value can be described as the sum of the value each project adds, NPV connects most directly to the goal of maximizing firm value.

---

## Internal Rate of Return (IRR)

The **internal rate of return** is the discount rate that makes a project's NPV equal to zero.

```
0 = Σ [CFt / (1 + IRR)^t] - C0
```

If IRR exceeds the required return, the project is judged to be more profitable than the required return demands. Because it's expressed as a rate of return, it's intuitive and easy to communicate.

That said, IRR has several limitations.

1. It implicitly assumes interim cash flows are reinvested at the IRR itself.
2. If cash flow signs change more than once, multiple IRRs can result.
3. In some cases, no IRR exists at all.
4. It struggles to handle situations where the discount rate varies by period.
5. For mutually exclusive projects, differences in scale can lead IRR to a different conclusion than NPV.

When the two conflict, **NPV generally takes priority**.

---

## Profitability Index and Capital Rationing

The **profitability index (PI)** shows the present value of future cash flows generated per dollar invested.

```
PI = present value of future cash flows / initial investment
```

A PI above 1 means the present value exceeds the investment, so the project is economically worthwhile. PI is especially useful when the investment budget is limited and several smaller projects must be combined. But because NPV directly shows the increase in firm value, it should still be considered alongside PI in the final decision.

## The Incremental Cash Flow Principle

A project's cash flows should be estimated based on the **incremental cash flows the project itself causes**, not accounting totals. Projects should also be evaluated independently, separate from the firm's other activities.

The following items should be excluded from or included in cash flow estimates.

| Category | Item | Reason |
| --- | --- | --- |
| Excluded | Non-cash expenses like depreciation | Not a cash outflow, so not deducted directly |
| Excluded | Interest expense and dividends | Already reflected in the discount rate as the cost of capital, so including them would double-count |
| Excluded | Sunk costs | Already incurred and unrecoverable |
| Included | Working capital investment | Cash actually tied up in inventory, receivables, and similar items |
| Included | Capital expenditures | Cash outflows for acquiring or replacing equipment |
| Included | Opportunity costs | The value of existing resources that could have been used elsewhere |
| Included | Tax effects on disposal | Gains or losses on asset sales affect after-tax cash flow |

Total cash flow is typically organized as follows.

```
Total project cash flow
= operating cash flow - net capital expenditures - change in net working capital

Incremental operating cash flow
= incremental EBIT × (1 - tax rate) + incremental depreciation
```

## Risk and Capital Budgeting

If a project's risk differs from the firm's average risk, the discount rate should differ too. This is called the **risk-adjusted discount rate**.

Using CAPM, the cost of equity can be estimated as:

```
re = rf + [E(rM) - rf] × β
```

If a new project's operating risk matches the firm's existing operating risk, the firm's overall beta can be used. But if the new project's risk differs, the discount rate should reflect a beta specific to **the project's own risk**, not the firm-wide beta.

If a firm uses debt as well as equity, the cost of equity alone isn't enough. The required return needs to reflect the cost of debt too — which connects directly to WACC in the next chapter.

---

## Key Takeaways

1. Capital budgeting is long-term decision-making for fixed-asset investments whose effects last more than a year.
2. A good evaluation criterion accounts for time value, risk, and the increase in firm value together.
3. NPV shows the increase in firm value directly, making it generally more sound than IRR as a decision rule.
4. Project cash flows should be estimated as incremental cash flows, not accounting totals.
5. If a project's risk differs from the existing business, a risk-adjusted discount rate suited to that project should be used.
