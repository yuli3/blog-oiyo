## Task 1: Graph/Diagram Description (20 min, 150+ words)

### By Chart Type

| Type | Core Description Focus |
|------|----------------------|
| Line graph | Change over time, trends |
| Bar chart | Comparisons between categories |
| Pie chart | Proportions and composition |
| Table | Numerical comparisons, highest/lowest |
| Process diagram | Sequential steps |

### Task 1 Template

```
Paragraph 1 (Overview):
"The [chart type] illustrates/shows [what] [in/over period/conditions]."

Paragraph 2 (Overall trend):
"Overall, [most notable trend 1 or 2 features] can be observed."

Paragraph 3 (Specific data group 1):
"In terms of [first category], [specific figures + comparison]."

Paragraph 4 (Specific data group 2):
"Regarding [second category], [figures + trend]."
```

### Key Vocabulary for Data Description

**Increase**: rise, grow, climb, surge, jump, increase sharply/gradually
**Decrease**: fall, drop, decline, decrease, dip, plummet
**Stable**: remain stable, plateau, level off, stay constant
**Peak/Bottom**: peak at, reach a high of, bottom out at

## Task 2: Opinion/Argument Essay (40 min, 250+ words)

### Essay Types

| Type | Question Format |
|------|----------------|
| Opinion/Agree-Disagree | "To what extent do you agree or disagree?" |
| Discussion | "Discuss both views and give your own opinion" |
| Problem-Solution | "What causes this? What solutions exist?" |
| Advantage-Disadvantage | "Discuss advantages and disadvantages" |

### Opinion Essay Structure

```
Introduction (2–3 sentences):
Background context + your clear position

Body 1 (Reason 1 + Example):
Topic sentence → reason → specific example

Body 2 (Reason 2 + Example):
Topic sentence → reason → specific example

Optional: Counterargument + Rebuttal

Conclusion:
Restate position + summary
```

---

### Band 7+ Vocabulary Strategies

- **Synonyms for common words**: good → beneficial, advantageous, substantial; bad → detrimental, adverse, harmful
- **Academic phrases**: "Research indicates that...", "It is widely acknowledged that..."
- **Varied transitions**: Furthermore, Nonetheless, Notwithstanding, Consequently
