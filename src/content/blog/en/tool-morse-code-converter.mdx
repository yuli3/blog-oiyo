# Morse Code Converter

Morse code, invented by Samuel Morse in the 1840s, encodes characters as sequences of dots (·) and dashes (–) transmitted over telegraph lines. It's most famous for the distress signal SOS (···−−−···).

<Callout type="tip">
**SOS**: ···−−−··· (3 dots · 3 dashes · 3 dots). Adopted as the international distress signal in 1906. In an emergency it can also be tapped, written in the ground, or flashed with a torch.
</Callout>

## Morse Code Timing Rules

- **Dot (·)**: 1 unit
- **Dash (–)**: 3 units
- **Gap within a character**: 1 unit
- **Gap between characters**: 3 units
- **Gap between words**: 7 units
