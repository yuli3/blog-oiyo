## 1. 직무분석과 직무설계

### 직무분석 (Job Analysis)
직무를 구성하는 과업과 직무 수행에 필요한 자격 요건을 체계적으로 파악하는 과정.

**산출물**
- **직무기술서 (Job Description)**: 직무의 내용, 책임, 환경 기술
- **직무명세서 (Job Specification)**: 직무 수행자의 자격 요건 (학력, 경험, 기술)

**직무분석 방법**

| 방법 | 내용 |
|------|------|
| 관찰법 | 직접 관찰로 과업 파악 |
| 면접법 | 직무 수행자 인터뷰 |
| 설문법 | 직위분석설문지(PAQ) 활용 |
| 중요사건기록법 | 효과적/비효과적 행동 사례 수집 |
| 작업일지법 | 직무 수행자 자기 기록 |

### 직무설계 (Job Design)
직무 내용과 수행 방법을 설계하는 것.

**직무특성 이론 (Hackman & Oldham)**

5가지 핵심 직무 특성:
1. **기술 다양성** — 다양한 기술 사용 여부
2. **과업 정체성** — 처음부터 끝까지 완결성
3. **과업 중요성** — 타인에게 미치는 영향
4. **자율성** — 일정과 방법 결정 권한
5. **피드백** — 수행 결과 정보

→ 5가지 특성 → **심리 상태 3가지** → **성과 향상**

**직무설계 유형**

| 유형 | 내용 |
|------|------|
| 직무 단순화 | 과업 분할로 효율 극대화 (테일러식) |
| 직무 순환 | 여러 직무를 교대로 수행 |
| 직무 확대 | 수평적 확장 (과업 수 증가) |
| 직무 충실화 | 수직적 확장 (자율성·책임 증가) — Herzberg |

## 2. 모집과 선발

### 모집 (Recruitment)
**내부 모집**: 내부 이동·승진 → 동기 부여, 비용 절감 / 단, 침체 위험
**외부 모집**: 신규 채용 → 신선한 아이디어 / 단, 비용·위험 증가

### 선발 도구 신뢰도·타당도

| 개념 | 의미 |
|------|------|
| 신뢰도 | 동일 측정을 반복해도 같은 결과 나오는 일관성 |
| 내용 타당도 | 측정 내용이 직무를 대표하는가 |
| 기준 타당도 | 선발 도구가 직무 성과를 예측하는가 |
| 구인 타당도 | 심리적 특성을 올바르게 측정하는가 |

## 3. 인사평가

### 절대평가 vs 상대평가

| 구분 | 절대평가 | 상대평가 |
|------|---------|---------|
| 기준 | 사전 설정 기준 | 구성원 간 비교 |
| 장점 | 협력 촉진, 공정 | 변별력 확보 |
| 단점 | 관대화 오류 가능 | 협력 저해 |

### 주요 평가 방법

**MBO (목표관리법)**
상사·부하가 함께 목표 설정 → 목표 달성도로 평가. Drucker 제창.

**BARS (행위기준고과법)**
구체적인 직무 행동 사례를 등급별로 정의한 척도로 평가. 객관성 높음.

**360도 평가**
상사·동료·부하·고객이 모두 평가. 다면 피드백.

**행동관찰척도 (BOS)**
특정 행동의 관찰 빈도를 평가.

### 평가 오류

| 오류 | 내용 |
|------|------|
| 현혹(후광) 효과 | 한 특성이 다른 특성 평가에 영향 |
| 혼효(연쇄) 효과 | 먼저 평가한 대상이 다음 평가에 영향 |
| 관대화 오류 | 모두 높게 평가 |
| 중심화 경향 | 중간 점수 위주 평가 |
| 근접 오류 | 최근 행동에만 의존 |
| 대비 오류 | 평가자 자신과 비교 |

## 4. 교육훈련

### ADDIE 모형 (5단계)

| 단계 | 내용 |
|------|------|
| Analysis (분석) | 교육 요구 분석, 대상자 분석 |
| Design (설계) | 학습 목표 설정, 교수전략 수립 |
| Development (개발) | 교재·콘텐츠 제작 |
| Implementation (실행) | 교육 실시 |
| Evaluation (평가) | Kirkpatrick 4수준 평가 |

### Kirkpatrick 4수준 교육평가

| 수준 | 평가 내용 |
|------|----------|
| 반응 | 교육 만족도 |
| 학습 | 지식·기술 습득도 |
| 행동 | 현업 적용 정도 |
| 결과 | 조직 성과 향상 |

### 교육훈련 방법

**On-the-Job Training (OJT)**: 직장 내 훈련 — 상사·선배가 실무 중 지도
**Off-JT**: 집합 교육, 강의, 세미나
**CDP (경력개발 프로그램)**: 체계적 경력 계획·지원

## 5. 임금관리

### 임금 유형

| 유형 | 내용 |
|------|------|
| 연공급 | 근속연수 기준 — 안정성, 동기부여 약 |
| 직능급 | 직무 수행 능력 기준 |
| 직무급 | 직무 가치 기준 — 공정성, 도입 복잡 |
| 성과급 | 성과·목표 달성 기준 |

### 복리후생 유형
- **법정 복리후생**: 4대 보험 (국민연금·건강·고용·산재)
- **자발적 복리후생**: 선택적 복리후생(카페테리아 플랜) 포함
