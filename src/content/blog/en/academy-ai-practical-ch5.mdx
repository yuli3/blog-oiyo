## Chapter 5 Overview: Reports and Proposals — Speed and Quality Together, with AI

One of the tasks that eats up the most of an office worker's time is **writing documents**. With AI, you can cut drafting time by 70% while producing more tightly structured, polished documents.

<Callout type="info">
**Goal of this lecture**: quickly nail down the structure of a report or proposal with AI, then finish it as a genuinely persuasive document.
</Callout>

---

## 1. Writing a Report — A 5-Minute First Draft

### Status report prompt

```
Prompt:
"Based on the information below, write an executive-level status
report.

Purpose of the report: [purpose]
Key metrics: [figures]
Problems: [current issues]
Proposed direction: [ideas]

Format: 3-line summary → current status → root cause → proposal
→ expected impact"
```

**The PREP structure for a good report:**

| Component | Content | Length |
|---|---|---|
| **P** (Point) | State the conclusion first | 1–2 sentences |
| **R** (Reason) | Evidence and data | 3–5 points |
| **E** (Example) | A concrete example | 1–2 examples |
| **P** (Point) | Restate the conclusion + your ask | 1–2 sentences |

## 2. Writing a Proposal — A Structure That Persuades Leadership

### New project proposal

```
Prompt:
"Turn the idea below into a proposal that will persuade
leadership.

Idea: [core idea]
Background: [problem context]
Budget: [estimated cost]
Timeline: [execution period]

Include:
1. Background and problem statement
2. Solution overview
3. Expected impact (quantitative/qualitative)
4. Execution plan (timeline)
5. Resources needed and risks"
```

## 3. A 5-Step AI Document-Writing Workflow

```
Step 1: Ask for structure
"Give me a 5-section outline for a report on [topic]."

Step 2: Generate content for each section
"Write section 1, 'Current Status,' in about 150 words,
including [data]."

Step 3: Connect everything and check the flow
"Read the whole report and check whether the logical flow
feels natural."

Step 4: Edit for an executive audience
"Summarize this so a CEO can grasp it in 30 seconds."

Step 5: Final proofread
"Find vague phrasing, redundancy, and unnecessary content
in this report and fix it."
```
