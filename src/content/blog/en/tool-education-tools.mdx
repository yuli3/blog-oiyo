## CEFR English Level Guide

| Level | Description | TOEIC Score |
|---|---|---|
| A1 | Beginner: simple expressions | Below 120 |
| A2 | Elementary: everyday phrases | Below 225 |
| B1 | Intermediate: familiar topics | Below 550 |
| B2 | Upper-intermediate: complex topics | Below 785 |
| C1 | Advanced: fluent, natural expression | 905+ |

## Typing Speed Benchmarks (WPM)

| Level | English WPM | Description |
|---|---|---|
| Beginner | 20–30 | Hunt-and-peck style |
| Intermediate | 40–60 | Average office worker |
| Fast | 60–80 | Professional administrative |
| Very fast | 80–100+ | Typist / developer level |

<Callout type="tip">
**Spaced Repetition for Flashcards**: Review new words at 1 day → 3 days → 7 days → 14 days → 30 days intervals to convert them to long-term memory. This is the core principle behind apps like Anki.
</Callout>
