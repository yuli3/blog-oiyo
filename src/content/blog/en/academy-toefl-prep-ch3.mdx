## TOEFL Speaking Overview

- **4 tasks**, **16 minutes total**
- Scoring: ETS AI + human raters (0–30 points)
- Format: Microphone recording (not live conversation)

### Scoring Criteria

| Criterion | Description |
|-----------|-------------|
| Delivery | Pace, pronunciation, fluency |
| Language Use | Grammatical accuracy, vocabulary range |
| Topic Development | Content completeness, logical structure |
| Coherence | Transition use, consistency |

---

## Task 1: Independent Speaking

**Format**: Express personal opinion/preference (15 sec prep / 45 sec response)

**Common topics**:
- "Which approach do you prefer: A or B?"
- "What quality/ability is most important and why?"

### Task 1 Template

```
Opening (5 sec):
"In my opinion, [position/choice]."

Reason 1 (15 sec):
"First, [reason]. For example/instance, [specific example]."

Reason 2 (15 sec):
"Additionally, [reason 2]. [Example or elaboration]."

Closing (5 sec):
"That's why I believe [one-sentence conclusion]."
```

---

## Task 2: Reading + Listening + Speaking

**Format**: Read passage (45 sec) → Listen to conversation → Respond (30 sec prep / 60 sec)

**Typical structure**:
- Reading: School announcement (policy, facility, service change)
- Listening: Student conversation, one expressing opinion (for/against)
- Question: State the person's opinion and reasons

### Task 2 Template

```
"The [man/woman] [agrees/disagrees] with the [policy/change] mentioned in the reading.

[His/Her] first reason is that [reason 1]. [He/She] explains that [specific detail].

[His/Her] second reason is that [reason 2]. According to the conversation, [detail]."
```

---

## Task 3: Reading + Listening + Speaking (Academic Concept)

**Format**: Academic concept in reading → Professor illustrates with example

### Task 3 Template

```
"The reading passage introduces the concept of [concept name].

The professor illustrates this concept through the example of [example].

[In the example], [first characteristic/step], which demonstrates [aspect of concept].

Furthermore, [second aspect of example], showing how [another aspect of concept]."
```

---

## Task 4: Listening Only + Speaking

**Format**: Academic lecture only → Respond (20 sec prep / 60 sec)

### Task 4 Template

```
"In the lecture, the professor explains [topic].

The professor makes two main points. First, [point 1]. For example, [example].

Second, [point 2]. To illustrate, [example].

Together, these points show that [summary statement]."
```

## Fluency Training Techniques

### 1. Shadowing
Listen to TED Talks or TOEFL audio and speak simultaneously. Goal: internalize native speaker rhythm and intonation.

### 2. Daily 1-Minute Speech Practice
Record a 60-second response on any topic → listen back → identify hesitation patterns

### 3. Transition Word Automation

| Function | Phrases |
|----------|---------|
| Reasons | "One reason is...", "This is because..." |
| Examples | "For instance...", "To illustrate..." |
| Adding | "Furthermore...", "Additionally..." |
| Contrasting | "However...", "On the other hand..." |
