## Ⅰ. 인사관리(HRM)의 숲 보기

인사관리는 **"사람을 뽑고(확보), 키우고(개발), 평가하고(평가), 대우하는(보상)"** 흐름입니다.
공기업 시험은 이 4가지 기둥에서 **'공정성'과 '직무 중심'** 이슈를 집중적으로 묻습니다.

| 흐름                       | 핵심 키워드 (공기업)                  |
| :------------------------- | :------------------------------------ |
| **1. 확보 (Acquisition)**  | NCS, 블라인드 채용, 직무기술서        |
| **2. 개발 (Development)**  | OJT vs Off-JT, 경력개발(CDP)          |
| **3. 평가 (Evaluation)**   | MBO, 다면평가, 평가 오류(Halo)        |
| **4. 보상 (Compensation)** | 직무급, 임금피크제, 카페테리아식 복지 |

---

## Ⅱ. 확보관리 (채용의 룰이 바뀌었다) ⭐⭐⭐⭐⭐

### 1️⃣ 직무분석 (Job Analysis) : 인사의 기초

- **직무기술서 (Description)**: "일" 중심 (과업, 책임, 의무) → **TDR** (Task, Duty, Responsibility)
- **직무명세서 (Specification)**: "사람" 중심 (지식, 기술, 능력) → **KSA** (Knowledge, Skill, Ability)

👉 **시험 함정**: 기술서와 명세서의 정의를 바꿔서 냅니다.

- "자격요건을 기술한 문서" = **명세서**

### 2️⃣ 모집과 선발

#### 내부모집 vs 외부모집

| 구분                          | 장점                                     | 단점                                 |
| :---------------------------- | :--------------------------------------- | :----------------------------------- |
| **내부모집** (승진, 배치전환) | 모티베이션(안정감), 비용 절감, 적응 빠름 | 조직 경직(고인물), 파벌 형성         |
| **외부모집** (공채, 경력직)   | 새로운 피(혁신), 전문가 영입 가능        | 비용 증가, 적응 시간 필요, 내부 반발 |

#### 선발 도구의 요건 ⭐

- **신뢰성 (Reliability)**: 일관성 (오늘 1등이 내일도 1등인가?)
- **타당성 (Validity)**: 정확성 (시험 점수가 실제 업무 능력과 일치하는가?)

👉 **공기업 트렌드**: **NCS(국가직무능력표준)** 기반 채용은 **내용 타당성(직무 연관성)**을 높이기 위함입니다.

---

## Ⅲ. 개발관리 (키우는 방식)

### 1️⃣ 교육훈련

- **OJT (On-the-Job Training, 직장 내 훈련)**
  - 장점: 실무 직결, 비용 저렴, 상사 피드백 즉시 가능
  - 단점: 체계 부족, 지도자의 능력에 의존, 업무 중단 가능성
- **Off-JT (Off-the-Job Training, 집합 교육)**
  - 장점: 체계적 학습, 업무 집중에서 해방
  - 단점: 현장감 부족, 비용 발생

### 2️⃣ 경력개발 (CDP)

- 과거: 조직 주도, 수직적 승진 중심
- **현대**: **개인 주도 + 조직 지원**, 나선형/수평적 이동 포함

---

## Ⅳ. 평가관리 (가장 헷갈리는 파트) ⭐⭐⭐

### 1️⃣ 주요 평가 기법

- **MBO (목표관리법)**: 상사와 부하가 **합의**하여 목표 설정 → 결과로 평가 (결과 지향)
- **BSC (균형성과표)**: 재무뿐만 아니라 **비재무(고객, 프로세스, 학습)** 지표도 중시
- **다면평가 (360도)**: 상사 + 부하 + 동료 + 고객 (객관성 확보, but 인기투표 변질 우려)

### 2️⃣ 평가의 오류 (단골 문제)

| 오류 명칭                      | 내용                                                      | 해결책           |
| :----------------------------- | :-------------------------------------------------------- | :--------------- |
| **현혹효과 (Halo Effect)**     | 하나의 장점이 전체 평가를 좋게 만듦 (S대니까 일 잘하겠지) | 평가 항목 세분화 |
| **중심화 경향**                | 모두에게 '보통(중간)' 점수 부여 (극단 회피)               | 강제배분법       |
| **관대화 경향**                | 모두에게 '후한' 점수 부여                                 | 강제배분법       |
| **상동적 태도 (Stereotyping)** | 집단에 대한 편견으로 평가 (남자는 힘쓰는 일 잘해)         | 평가자 교육      |

👉 시험 팁: "**최신 정보**에 영향을 받는 것" = **시간적 오류 (Recent Effect)**

---

## Ⅴ. 보상관리 (공기업 핫이슈) ⭐⭐⭐⭐⭐

### 1️⃣ 임금 체계

- **연공급 (호봉제)**: 근속년수 기준. (장점: 안정, 충성심 / 단점: 무사안일)
- **직무급**: **직무의 가치(난이도, 중요도)** 기준. (동일노동 동일임금) 👉 **공기업 개혁 방향**
- **직능급**: 사람의 **능력(자격증 등)** 기준.
- **성과급**: 결과 기준.

### 2️⃣ 복리후생

- **카페테리아식 (선택적) 복리후생**: 직원이 원하는 항목을 메뉴판에서 고르듯 선택.
  - 장점: 만족도 제고, 효율성
  - 단점: 관리 비용 증가, 잘못된 선택 가능성

---

## Ⅵ. 시험장에서 바로 쓰는 판별 공식

### 🔹 1초 컷 공식

- "직무의 상대적 가치" → **직무급**
- "사람의 자격, 능력" → **직능급**
- "평가자가 피평가자의 특정 특성에 현혹" → **Halo Effect**
- "NCS 채용의 목적" → **직무 적합성 (타당성) 강화**

---

## Ⅶ. 3강 요약 (시험 직전 암기용)

- 직무기술(Description) = 일 / 직무명세(Specification) = 사람
- 신뢰성 = 일관성 / 타당성 = 정확성
- OJT = 실무형 / Off-JT = 이론형
- MBO = 합의, 결과 중심
- 중심화/관대화 해결책 = 강제배분법
- 공기업 지향점 = 직무급 (Job-based)
