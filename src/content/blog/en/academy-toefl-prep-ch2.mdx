## Reading: Academic Passage Strategy

### TOEFL Reading Overview
- **2 passages** × ~700 words, 10 questions each
- Topics: Natural science, social science, humanities, history
- **Time**: 35 minutes total (~17 min per passage)
- **Score**: 0–30 points

---

## Reading Question Types

| Type | Count | Strategy |
|------|-------|---------|
| Factual Information | 3–4 | Locate directly in the relevant paragraph |
| Negative Factual (NOT/EXCEPT) | 1 | Find 3 true answers; remainder is correct |
| Vocabulary | 2–3 | Use context to infer meaning |
| Reference | 1 | Find the antecedent of a pronoun or reference |
| Sentence Simplification | 1 | Keep core meaning; eliminate secondary details |
| Inference | 1–2 | What's implied but not stated? |
| Rhetorical Purpose | 1 | Why does the author include this? |
| Insert a Sentence | 1 | Test each insertion point; check coherence |
| Prose Summary | 1 (3 pts) | Identify 3 major points, exclude minor details |

### 5-Step Speed Reading

1. Skim title and subheadings → predict topic
2. Read first paragraph carefully → identify thesis
3. Scan first sentence of each subsequent paragraph → map structure
4. Read questions → go directly to relevant paragraph
5. Save Prose Summary for last (requires whole-passage understanding)

---

## Vocabulary Question Strategy

**Never give up on unknown words** — context makes inference possible.

**4-Step Inference**:
1. Read the full sentence containing the word
2. Check the sentences before and after for contrast words or synonyms
3. Analyze roots, prefixes, or suffixes
4. Look for a definition or explanation in the same sentence

**High-frequency academic vocabulary**:
- *subsequent* (following), *whereas* (in contrast), *attributed to* (caused by), *comprise* (to consist of)

## Listening: Lecture Note-Taking System

### TOEFL Listening Overview
- **3 lectures** (4–5 min) + **2 conversations** (2–3 min)
- Lectures: University-style academic content
- Conversations: Academic advising, library, administrative office
- **Score**: 0–30 points

---

## Efficient Note-Taking

Effective notes capture **key information**, not everything.

### Personal Abbreviation System

| Symbol | Meaning |
|--------|---------|
| → | leads to / causes |
| ≠ | different from / opposite |
| w/ | with |
| b/c | because |
| ex | example |
| imp | important |
| ↑↓ | increase / decrease |

### Lecture Note Structure

```
TOPIC: ________________
Main point 1: 
  - Detail:
  - Example:
Main point 2:
  - Detail:
Signal words: "however," "in contrast," "for instance," "as a result"
```

---

## Listening Question Types

| Type | Characteristic | Strategy |
|------|---------------|---------|
| Main Idea | Core topic of the lecture | Capture in first 30 seconds |
| Detail | Specific factual content | Find in notes |
| Function | Why does the professor say X? | Focus on context and tone |
| Attitude | Speaker's stance or feeling | Listen for hedges, emphasis, tone |
| Organization | How is the lecture structured? | Follow the overall flow |
| Inference | What can be inferred? | Reason from what's stated |
