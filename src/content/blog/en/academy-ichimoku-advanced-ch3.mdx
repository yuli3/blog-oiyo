## Lesson 3 Overview: How Far Does the Market Go?

With wave (shape) and time (when) covered, the final pillar is price. **Price-Target Theory (値幅観測論)** uses the size of a prior wave to calculate the next target price range.

<Callout type="info">
**Goal of this lesson**: Understand the logic behind the four calculated values — V, N, E, and NT — and learn to derive target prices from an upward N-wave.
</Callout>

---

## 1. The Three Reference Points

Price-Target Theory works off the three turning points of the most recent wave.

```
Example, in an uptrend:
  A = starting low
  B = first rally high
  C = correction low (the pullback off B)
→ The A→B rally and the B→C correction are used to calculate the next target
```

---

## 2. The Four Calculated Values

| Value | Formula (uptrend) | Meaning |
|--------|-----------|------|
| **V** | C + (B − C) | Retraces the correction's size (double-top symmetry) |
| **N** | C + (B − A) | Adds the first rally's size to C (the most fundamental) |
| **E** | B + (B − A) | Adds the first rally's size to B (a multiple extension) |
| **NT** | C + (C − A) | Adds the A→C span to C |

```
Typical ordering: V < N < E (E is usually the highest target)
NT matters most when the correction is shallow.
```

<Callout type="tip">
**The N value is the most fundamental.** It directly translates the N-wave's symmetry — "the market rallies again from the correction low by the same amount as the first rally" — into a price target. Treat N as your baseline target first; if it's broken, treat E as the next target.
</Callout>

---

## 3. Worked Example

```
A = 100 / B = 130 / C = 120
- First rally (B−A) = 30 / correction (B−C) = 10

V = C + (B−C) = 120 + 10 = 130
N = C + (B−A) = 120 + 30 = 150
E = B + (B−A) = 130 + 30 = 160
NT = C + (C−A) = 120 + 20 = 140

→ Target range: 130 (V) · 140 (NT) · 150 (N) · 160 (E)
```

---

## 4. Using Target Prices in Practice

```
- When several calculated values cluster in one price zone, that zone becomes a strong target/resistance area
- Confidence rises further when it overlaps with the Cloud, a prior high, or other resistance
- Reaching a target while also hitting a change day (Time Theory) is a zone to watch for an exit or reversal
```

<Callout type="note">
Price-Target Theory doesn't give you an "exact single point" — it gives a **likely target zone.** In practice, sketch the band from V to E, then narrow it down to the points where it overlaps with Time Theory, wave structure, and other resistance.
</Callout>

---

## 5. Applying It to a Downtrend

Flip the uptrend formulas left-right and top-bottom, and you get downside targets.

```
Downside N = C − (A − B)  (A = starting high, B = first decline low, C = bounce high)
→ Only the sign flips; the logic is identical
```

---

## This Lesson's Key Takeaways

1. Price-Target Theory calculates the next target price range from the size of the prior wave.
2. The reference points are the starting point (A), the first high (B), and the correction low (C).
3. Among the four values — V, N, E, NT — **N is the most fundamental**, and E is typically the highest target.
4. Where multiple calculated values cluster, or overlap with the Cloud or a prior high, that's a strong target/resistance zone.
5. Reaching a target while a change day converges is a zone that calls for caution around reversals or exits.
