## The Time Value of Money

The first calculation language in financial management is the **time value of money**. A dollar received today is worth more than a dollar received in the future, even if the amounts are identical.

There are three reasons for this.

1. People generally prefer **current consumption** to future consumption.
2. Capital available today can be put to productive use and earn additional returns.
3. Future cash flows carry uncertainty.

So a future cash flow has to be a larger amount than a present one to compensate for giving up today's consumption. That rate of compensation is the **interest rate**.

```
Interest rate = risk-free rate + risk premium
```

The risk-free rate compensates for time itself; the risk premium compensates for the extra uncertainty of a future cash flow.

---

## Future Value and Compounding

**Future value (FV)** tells you what a present cash flow will grow to after a given period. The key mechanism is **compounding**, not simple interest — compounding means interest is earned not just on the principal, but also on interest already accumulated in prior periods.

```
FVn = PV × (1 + r)^n

PV: present value
r: interest rate per period
n: number of periods
(1 + r)^n: the compound value interest factor (CVIF)
```

For example, investing $1,000 at 10% annual compound interest for 3 years grows to:

```
FV3 = 1,000 × (1.10)^3
    = 1,331
```

With compounding, growth accelerates the longer the horizon. This same structure recurs throughout financial management — in long-term investments, annuities, bonds, and stock valuation.

---

## Present Value and Discounting

**Present value (PV)** converts a future cash flow into today's terms. Where future value applies compounding, present value applies **discounting**.

```
PV = FVn / (1 + r)^n
   = FVn × (1 + r)^(-n)

(1 + r)^(-n): the present value interest factor (PVIF)
```

The higher the discount rate, the lower the present value of a future cash flow. That's because the discount rate isn't just a mechanical input — it's the **required rate of return, reflecting opportunity cost and risk**.

### Why present value matters

Firm value is the sum of the present values of future cash flows. So whether an investment looks attractive shouldn't be judged by accounting profit, but by how much it increases firm value once future cash flows are converted to today's terms.

```
Firm value = Σ present value of future cash flows
```

This is where Chapter 1's choice of firm-value maximization as the corporate goal becomes something you can actually calculate.

## The Future Value of an Annuity

An **annuity** is a cash flow that pays the same amount every period. It's the tool for evaluating regular savings contributions, or bonds and annuity products that pay a fixed amount each period.

If you deposit C dollars at the end of every period, at interest rate r for n periods, the future value of the annuity is:

```
FVA = C × [((1 + r)^n - 1) / r]

C: the constant cash flow each period
[((1 + r)^n - 1) / r]: the compound value interest factor for an annuity (CVIFA)
```

Each payment compounds for the number of periods remaining. The first payment has the longest time to grow and contributes the most; the last payment has almost no time to earn interest.

---

## The Present Value of an Annuity

The **present value of an annuity (PVA)** converts a series of identical future cash flows into a value at today's date.

```
PVA = C × [1 - (1 + r)^(-n)] / r

[1 - (1 + r)^(-n)] / r: the present value interest factor for an annuity (PVIFA)
```

The present value of an annuity is used to value loan repayments, lease payments, regular dividends, or coupon interest — anything that recurs.

### Perpetuities

A **perpetuity** is an identical cash flow that continues forever. Because the number of periods is infinite, the present value formula simplifies dramatically.

```
PV of perpetuity = C / r
```

This is the building block for valuing perpetual bonds, and for stock valuation models that assume a constant dividend paid indefinitely.

---

## The Present Value of a Stock

A stock can be valued by discounting its future dividends and eventual sale price back to the present. The simplest case is a stock that pays the same dividend every year, forever.

```
P0 = D / r

P0: current stock price
D: constant annual dividend
r: the return shareholders require
```

Real-world stocks may have dividends that grow or fluctuate, but the underlying logic is the same: **a stock's value is the present value of the future cash flows shareholders will receive.**

---

## The Present Value of a Bond

A bond typically pays periodic interest and repays principal at maturity. So a bond's value is the present value of its interest payments plus the present value of its principal at maturity.

```
Bond value = Σ [interest / (1 + r)^t] + [face value / (1 + r)^n]
```

A perpetual bond pays interest indefinitely with no principal repayment. In that case, its value equals that of a perpetuity.

```
Perpetual bond value = annual interest / required return
```

In bond valuation, the discount rate is the return the market requires. When the discount rate rises, the present value of an existing bond falls; when it falls, the bond's present value rises.

---

## Key Takeaways

1. A cash flow today is worth more than the same cash flow in the future, because of the preference for current consumption, the productivity of capital, and future uncertainty.
2. Future value is present value multiplied by a compound interest factor; present value is a future cash flow discounted back to today.
3. An annuity is a cash flow that repeats the same amount every period; both its future and present value use their own annuity interest factors.
4. The present value of a perpetuity simplifies to `C / r`.
5. The value of a stock or bond ultimately comes down to the present value of the future cash flows an investor will receive.
