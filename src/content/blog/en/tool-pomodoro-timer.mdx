# Pomodoro Timer

The Pomodoro Technique was developed by Francesco Cirillo in the late 1980s. It takes its name from the tomato-shaped kitchen timer he used as a student ("pomodoro" is Italian for tomato).

## The Pomodoro Cycle

| Stage | Duration | Purpose |
|---|---|---|
| 🍅 Focus session (1 Pomodoro) | 25 min | Single-task deep work |
| ☕ Short break | 5 min | Brain reset, stretching |
| Long break (after 4 cycles) | 15–30 min | Deep recovery |

<Callout type="tip">
**The core rule**: When a distraction appears (social media urge, unrelated thought) during a focus session, write it down immediately and ignore it. If you stop before the timer rings, that Pomodoro doesn't count.
</Callout>

## The Science Behind It

**Attention span limit**: The human brain peaks at concentration for roughly 20–25 minutes. Beyond that, focus degrades sharply without deliberate recovery.

**Intentional rest**: Short breaks reset working memory and activate the Default Mode Network (DMN), the brain's creative problem-solving circuit.

## By Work Type

| Work Type | Recommended Approach |
|---|---|
| Writing / coding | Standard 25/5 cycle |
| Repetitive tasks | Extended 50/10 cycle |
| Creative work | Adjust intervals flexibly |
| Meetings | Pause Pomodoro; restart afterward |

## Daily Pomodoro Targets

| Type | Pomodoro Sessions | Effective Focus Time |
|---|---|---|
| Typical office worker | 4–6 | ~2–2.5 hours |
| Student (intensive study) | 8–12 | ~4–5 hours |
| High-intensity focus | max 16 | ~7–8 hours |
