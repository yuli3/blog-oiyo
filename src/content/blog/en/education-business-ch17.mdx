## 1. MIS Overview

**MIS (Management Information System)**: A system that collects, processes, stores, and distributes data to support management decision-making.

### Stages of Information System Evolution

| Generation | System | Focus |
|------------|--------|-------|
| 1st Generation | TPS (Transaction Processing System) | Routine transaction automation |
| 2nd Generation | MIS (Management Information System) | Management reports |
| 3rd Generation | DSS (Decision Support System) | Semi-structured decision-making |
| 4th Generation | EIS (Executive Information System) | Executive strategic support |
| 5th Generation | AI/Knowledge-Based System | Expert systems, AI |

### Systems by Decision-Making Type

| Type | Characteristics | System |
|------|-----------------|--------|
| Structured | Repetitive, clear rules | TPS, MIS |
| Semi-structured | Some rules exist | DSS |
| Unstructured | Creative, uncertain | EIS, AI |

## 2. Integrated Enterprise Systems

### ERP (Enterprise Resource Planning)

A system that integrally manages all corporate resources (production, purchasing, accounting, human resources, logistics) in real-time.

**Characteristics**: Single database / Real-time information sharing / Modular structure

**ERP Module Examples**: Financial accounting / Management accounting / Human resources / Production planning / Purchasing / Sales / Logistics

**ERP Adoption Effects**: Elimination of work duplication, data consistency, improved decision-making speed.
**ERP Adoption Risks**: Adoption costs, user resistance, customization limitations.

### SCM (Supply Chain Management)

Integrally optimizes the entire supply chain from raw material suppliers → manufacturers → distributors → final customers.

**SCM Goals**: Minimize total supply chain costs + Maximize customer service levels.

**VMI (Vendor-Managed Inventory)**: Suppliers directly manage customer inventory → Mitigates the bullwhip effect.

### CRM (Customer Relationship Management)

Integrates and analyzes customer information to provide customized services and improve customer loyalty.

**CRM Types**
- Operational CRM: Sales, marketing, and service automation
- Analytical CRM: Customer data analysis and segmentation
- Collaborative CRM: Cross-channel integrated communication

### KMS (Knowledge Management System)

A system that collects, stores, shares, and utilizes tacit and explicit knowledge within an organization.

**Nonaka's SECI Model**: Tacit knowledge ↔ Explicit knowledge conversion
- Socialization (S) → Externalization (E) → Combination (C) → Internalization (I)

## 3. Big Data and Analytics

### Big Data 3V (Gartner)

| V | Description |
|---|-------------|
| Volume | Large-scale data in TB/PB units |
| Velocity | Real-time or high-speed processing |
| Variety | Structured, semi-structured, and unstructured data |

**Additional Vs**: Veracity, Value

### Types of Data Analytics

| Type | Description | Value |
|------|-------------|-------|
| Descriptive Analytics | Summary of past data | Low |
| Diagnostic Analytics | Identifying causes | Medium |
| Predictive Analytics | Forecasting the future | High |
| Prescriptive Analytics | Suggesting optimal actions | Highest |

## 4. Cloud Computing

Provides computing resources (servers, storage, software) as a service over the internet.

| Service Model | Description | Examples |
|---------------|-------------|----------|
| IaaS | Infrastructure provision | AWS EC2, Azure |
| PaaS | Platform provision | Google App Engine |
| SaaS | Software provision | Office 365, Salesforce |

**Deployment Models**: Public / Private / Hybrid

## 5. Digital Transformation Technologies

### AI (Artificial Intelligence)
- **Machine Learning**: Learning patterns from data
- **Deep Learning**: Unstructured data processing based on neural networks
- **NLP**: Natural Language Processing (chatbots, translation)

### RPA (Robotic Process Automation)
Software robots automatically process repetitive, rule-based tasks.
**Advantages**: Rapid adoption, labor cost reduction, error reduction.

### IoT (Internet of Things)
Connecting sensors and networks to physical objects → Data collection and control.
**Smart Factory**: Production optimization using IoT + AI + Big Data.

### Blockchain
Distributed ledger technology — Transaction records are distributed and stored across multiple nodes, preventing tampering.
**Applications**: Smart contracts, supply chain tracking, digital assets.
