# Anniversary Calculator

Remembering exact anniversary dates can be surprisingly tricky — months have different lengths, leap years throw off the count, and it's easy to lose track of whether it's been one year or two.

This calculator takes a **single start date** and automatically computes every major milestone that follows.

**Dates calculated:**
- 22nd, 50th, 100th, 200th, 300th day — short-term milestones
- 500th, 1000th day — long-term day milestones
- 1st, 2nd, 3rd, 5th, 10th anniversary — year-based milestones

## Tips for Using This Calculator

### What start dates can I use?

| Start Date | Use Case |
|---|---|
| First date / day you met | Couple anniversary tracking |
| First day of work | Work tenure milestones |
| Birthday | Age and birthday planning |
| Business launch date | Company founding anniversaries |
| Pet adoption date | Pet milestones |
| Quit date (smoking, diet) | Habit-tracking motivation |

<Callout type="tip">
**100-day vs. 1-year**: These are often confused. The 100-day mark is 99 days after the start (the 100th day total), while a 1-year anniversary falls exactly 365 days later. This calculator handles both correctly.
</Callout>

### D-Day Countdown

As an anniversary approaches, the remaining days are shown in **D-N** format. Past anniversaries are stored as history. If you need a standalone countdown for future events, check out the [D-Day Calculator](/en/tool-dday-calculator) as well.
