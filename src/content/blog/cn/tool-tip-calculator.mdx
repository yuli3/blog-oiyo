# 小费计算器

小费文化因国而异。在美国被视为礼貌的金额，在日本可能被视为冒犯。本工具帮您避免文化失礼，轻松搞定小费计算和分账。

## 各国小费习惯

| 国家/地区 | 通常比例 | 说明 |
|---|---|---|
| **美国 / 加拿大** | 15–20%（最低） | 服务员工资依赖小费，文化上必须给 |
| **中国大陆** | 通常不给 | 高档酒店/餐厅可给5–10% |
| **香港** | 10%（如未含） | 账单通常已含服务费 |
| **日本 / 韩国** | 不给（可能冒犯） | 服务价格已含在账单中 |
| **欧洲** | 取整+5–10%（自愿） | 法国、西班牙已含服务费 |
| **泰国 / 东南亚** | 10–15%（旅游区） | 当地习惯不同，视情况而定 |
| **中东（迪拜等）** | 10–15% | 账单常已含服务费 |

<Callout type="note">
在中国大陆，餐厅通常不期望小费，但高档国际酒店、西餐厅或有外籍服务的场所可适当给予。建议看账单是否已含服务费（通常10%）。
</Callout>

## 如何公平AA分账

| 方式 | 优点 | 缺点 |
|---|---|---|
| 平均分 | 简单快捷 | 各人消费差异大时不公平 |
| 按消费比例 | 公平精确 | 计算麻烦 |
| 轮流请客 | 长期来看划算，增进感情 | 需要互信 |
| 分账App（AA、Splitwise） | 自动记录欠款 | 需要安装 |
