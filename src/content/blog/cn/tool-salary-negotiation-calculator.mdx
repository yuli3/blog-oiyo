## 薪资增长参考基准（2024年全球）

| 情境 | 典型涨幅 |
|---|---|
| 大型企业（年度调薪） | 3–6% |
| 中小企业 | 2–5% |
| 高速成长型互联网公司 | 10–20%+ |
| 跳槽换工作 | **+15–30%**（行业公认） |
| 全球通胀率（2024年） | ~2.5–3.5% |

<Callout type="tip">
**跳槽是最有效的涨薪方式**：数据表明，跳槽平均能带来20%的薪资增幅，远高于内部年度调薪的3–5%。手握竞争性offer，是最强的谈判筹码。
</Callout>

## 谈判准备清单

| 步骤 | 具体行动 |
|---|---|
| 市场调研 | 领英薪资、猎聘、Boss直聘薪资数据 |
| 量化成就 | 整理有数字支撑的工作成果 |
| 准备备选方案（BATNA） | 争取到竞争性offer或明确离职意愿 |
| 设定区间 | 底线 / 目标 / 理想值 |
| 选好时机 | 完成重要项目后或年度绩效评估期 |
