# 12星座性格深度解析

西方占星学根据出生时太阳所在星座，将人的性格归纳为12种原型。每个星座属于四大元素之一，并各有独特的性格特质与人生主题。

## 四大元素分类

| 元素 | 星座 | 共同特质 |
|---|---|---|
| **火象** 🔥 | 白羊、狮子、射手 | 热情、行动力强、有感召力 |
| **土象** 🌍 | 金牛、处女、摩羯 | 务实、可靠、有耐心 |
| **风象** 💨 | 双子、天秤、水瓶 | 智识型、善沟通、适应力强 |
| **水象** 💧 | 巨蟹、天蝎、双鱼 | 直觉敏锐、情感丰富、有同理心 |

## 三种模式

| 模式 | 星座 | 特征 |
|---|---|---|
| **开创座** | 白羊、巨蟹、天秤、摩羯 | 主动发起、领导力强 |
| **固定座** | 金牛、狮子、天蝎、水瓶 | 坚持不懈、意志力强 |
| **变动座** | 双子、处女、射手、双鱼 | 灵活变通、适应性强 |
