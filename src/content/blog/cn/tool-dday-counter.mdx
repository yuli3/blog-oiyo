# D-Day多事件计数器

当你同时需要追踪多个重要日期时，单一倒数计时远远不够。本工具支持同时管理多个D-Day事件，数据自动保存在浏览器本地。

| 人群 | 需要追踪的事件 |
|---|---|
| 学生 | 期末考试、论文提交、毕业答辩 |
| 职场人 | 项目截止日、年终总结、休假计划 |
| 情侣 | 恋爱周年、情人节、求婚日 |
| 旅行者 | 出发日、签证到期、回程日 |
| 健身人群 | 比赛日、打卡目标、体检日 |
