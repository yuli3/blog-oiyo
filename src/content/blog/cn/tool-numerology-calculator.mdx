# 数字命理计算器

数字命理学是探索数字在人类生命中意义的学问。由毕达哥拉斯推广，将1-9每个数字与特定性格特征和人生主题关联。它是一种象征性思考框架，而非预测科学。

## 四大核心数字

| 数字 | 计算依据 | 含义 |
|---|---|---|
| **生命数（命运数）** | 出生日期 | 您此生的核心使命 |
| **表达数（天赋数）** | 全名（字母数值） | 您的天赋与潜力 |
| **灵魂渴望数** | 名字中的元音字母 | 您内心深处的渴望 |
| **个性数** | 名字中的辅音字母 | 他人眼中的您 |

## 1-9数字含义

| 数字 | 主题 | 特质 |
|---|---|---|
| **1** | 领导力 | 独立、开拓、进取 |
| **2** | 和谐 | 外交、敏感、合作 |
| **3** | 创造力 | 表达、活泼、沟通 |
| **4** | 稳定 | 有序、务实、可靠 |
| **5** | 自由 | 冒险、适应、好奇 |
| **6** | 责任 | 保护、利他、家庭 |
| **7** | 智慧 | 内省、分析、灵性 |
| **8** | 权力 | 雄心、物质、坚定 |
| **9** | 慈悲 | 人道、理想、博爱 |
