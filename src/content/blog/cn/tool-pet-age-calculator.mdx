# 宠物年龄计算器

"1岁狗龄=7岁人龄"是常见误解。动物在幼年时衰老速度远快于人类，此后逐渐减慢。对于狗狗，体型大小也会影响换算结果。

## 小型犬年龄换算参考

| 狗狗年龄 | 等效人类年龄 |
|---|---|
| 1岁 | 约15岁 |
| 3岁 | 约28岁 |
| 7岁 | 约44岁 |
| 10岁 | 约56岁 |
| 15岁 | 约76岁 |

## 猫咪年龄换算参考

| 猫咪年龄 | 等效人类年龄 |
|---|---|
| 1岁 | 约15岁 |
| 5岁 | 约36岁 |
| 10岁 | 约56岁 |
| 15岁 | 约76岁 |
| 20岁 | 约96岁 |

<Callout type="tip">
**为什么大型犬老得更快？** 大型犬（金毛、拉布拉多）代谢更旺盛，生长更快。7岁的大型犬身体状况相当于55岁左右的人，而同龄小型犬（博美、吉娃娃）只相当于44岁左右。
