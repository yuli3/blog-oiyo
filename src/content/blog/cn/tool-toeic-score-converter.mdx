# TOEIC分数换算器

托业（TOEIC）是全球最广泛认可的职场英语能力测试，每年参考人数超700万。了解你的分数意味着什么，有助于制定更高效的学习计划。

## TOEIC分数 → CEFR等级对照表

| TOEIC分数 | CEFR等级 | 描述 |
|---|---|---|
| 10–254 | A1 | 入门级 |
| 255–399 | A2 | 基础级 |
| 400–549 | B1 | 中级 |
| 550–784 | B2 | 中高级 |
| 785–899 | C1 | 高级 |
| 900–990 | C1+ | 职业精通 |

## 各场景参考分数要求

| 场景 | 建议分数 |
|---|---|
| 外资企业求职 | 700+ |
| 跨国公司工作 | 800+ |
| 海外外派 | 850+ |
| 出国留学申请 | 785+（相当于雅思6.5） |
