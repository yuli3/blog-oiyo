## 欧洲语言共同参考框架（CEFR）

| 级别 | 称谓 | 能力描述 |
|---|---|---|
| **A1** | 入门 | 简单句子，基本自我介绍 |
| **A2** | 基础 | 日常情境交流 |
| **B1** | 中级 | 熟悉话题，旅行交流 |
| **B2** | 中高级 | 复杂文本，自发互动 |
| **C1** | 高级 | 流利、专业使用 |
| **C2** | 精通 | 接近母语水平 |

## 打字速度参考标准

| 级别 | 速度（字符/分钟） | 描述 |
|---|---|---|
| 初学者 | < 100 | 偶尔使用电脑 |
| 一般 | 150–200 | 日常办公 |
| 良好 | 200–300 | 频繁键盘工作 |
| 优秀 | 300–400 | 专业打字员 |
| 专家 | > 400 | 速记员、高效开发者 |
