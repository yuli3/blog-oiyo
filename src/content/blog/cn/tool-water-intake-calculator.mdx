# 饮水量计算器

人体约**60–70%由水构成**。仅仅2%的脱水就会影响认知功能。然而大多数人饮水不足——不是因为缺乏意志力，而是缺乏规律。

## 不同人群每日饮水需求

| 人群 | 每日参考饮水量 |
|---|---|
| 静坐成人（70kg） | 约2.0–2.5升 |
| 活跃成人（70kg，运动1小时） | 约2.5–3.0升 |
| 孕妇 | 额外+0.3升 |
| 哺乳期女性 | 额外+0.7升 |
| 高温/高湿环境 | 额外+0.5–1.0升 |

<Callout type="tip">
**实用法则**：每公斤体重约35ml。70kg成人：70×35=2450ml。每小时中等强度运动额外补充400–600ml。
</Callout>

## 全天喝水时间表

| 时间 | 建议水量 | 原因 |
|---|---|---|
| 起床后 | 250–500ml | 补充睡眠期间流失的水分 |
| 餐前 | 250ml | 助消化，适当控制食欲 |
| 下午（14–16点） | 300–500ml | 自然能量低谷期 |
| 运动前 | 500ml | 预防抽筋 |
| 运动后 | 400–700ml | 补充出汗流失 |
| 睡前1小时 | 最多150ml | 避免夜间起床 |

## 脱水信号

| 症状 | 脱水程度 |
|---|---|
| 轻微口渴、尿液深黄 | -1至2% |
| 头痛、疲劳 | -2至3% |
| 头晕、肌肉痉挛 | -4至5% |
| 意识模糊、心跳加速 | >-5% |

<Callout type="note">
一次性喝超过500ml反而适得其反。**每1–2小时喝200ml**的吸收效率更高。在手机设置每2小时提醒，养成喝水习惯并不难。
</Callout>
