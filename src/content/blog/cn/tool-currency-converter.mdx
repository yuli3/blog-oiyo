# 货币换算器

出行换汇前了解真实汇率，每笔交易都能省下几个百分点。机场换汇、银行、境外刷卡——每种方式都有隐藏成本。

## 各换汇方式实际成本

| 方式 | 典型手续费 | 说明 |
|---|---|---|
| 机场换汇 | 5–15% | 除非紧急，尽量避免 |
| 传统银行 | 2–4% | 通常还有固定手续费 |
| 普通银行卡刷卡 | 1.5–3% | 每笔交易收取 |
| Wise / 招行全币种卡 | 0–0.5% | 接近银行间汇率 |
| 当地ATM取款 | 1–2% | 通常优于现场换汇 |

<Callout type="tip">
**出行建议**：使用Wise、招行全币种卡等低手续费卡片境外消费。在当地ATM取款通常比换汇更划算。避免商家提供的"人民币结算"选项（DCC），汇率通常很差。
</Callout>

## 主要货币对

| 货币对 | 波动性 | 主要用途 |
|---|---|---|
| USD/CNY | 低（管制） | 中美贸易、出行 |
| USD/JPY | 中等 | 赴日旅行、投资 |
| EUR/CNY | 中等 | 赴欧旅行、贸易 |
| USD/HKD | 很低（联系汇率） | 港澳出行 |
| CNY/TWD | 中等 | 两岸往来 |

<Callout type="note">
此处显示的汇率为市场参考汇率。实际换汇时银行或换汇机构会加收手续费或买卖价差。具体汇率请以各机构为准。
</Callout>
