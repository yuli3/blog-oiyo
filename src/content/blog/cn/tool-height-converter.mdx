# 身高换算器

美国、英国等英语国家用英尺英寸表示身高，而非厘米。本工具让换算变得简单直接。

## 换算公式

```
1英尺 = 30.48厘米
1英寸 = 2.54厘米
1英尺 = 12英寸

厘米 → 英尺：[身高cm] ÷ 30.48
英尺 → 厘米：[英尺] × 30.48 + [英寸] × 2.54
```
