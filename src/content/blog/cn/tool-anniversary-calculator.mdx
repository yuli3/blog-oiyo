# 纪念日计算器

手动计算纪念日容易出错——每月天数不同，还要考虑闰年。只需**输入一个起始日期**，计算器会自动帮您算好所有重要纪念日。

**计算的纪念日：**
- 22天、50天、100天、200天、300天——短期里程碑
- 500天、1000天——中期里程碑
- 1周年、2周年、3周年、5周年、10周年——年度纪念

## 适用场景

| 起始日期 | 使用示例 |
|---|---|
| 恋爱开始日 | 情侣纪念日（100天、周年） |
| 入职日期 | 工作周年纪念 |
| 生日 | 个人里程碑计算 |
| 创业日期 | 公司周年纪念 |
| 宠物到家日 | 宠物纪念日 |
| 戒烟/健身开始日 | 励志里程碑追踪 |

<Callout type="tip">
**倒数计时**：临近纪念日时，计算器显示**距今D−N天**。已过的纪念日作为历史记录保留，方便回顾。如需设置目标日期倒数，可搭配使用[D-Day计算器](/cn/tool-dday-calculator)。
</Callout>
