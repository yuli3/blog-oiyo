## 各目的地人均每日预算参考（人民币）

| 目的地 | 经济型 | 舒适型 | 豪华型 |
|---|---|---|---|
| 东南亚（泰国、越南等） | ¥200–350 | ¥500–900 | ¥1,500+ |
| 日本 | ¥400–650 | ¥900–1,400 | ¥2,500+ |
| 欧洲 | ¥600–950 | ¥1,300–2,000 | ¥4,000+ |
| 中国（国内） | ¥150–300 | ¥400–700 | ¥1,200+ |
| 美国 | ¥700–1,100 | ¥1,600–2,600 | ¥4,500+ |
| 中东（迪拜等） | ¥500–800 | ¥1,200–2,000 | ¥4,000+ |

*含住宿、餐饮及当地交通，不含国际机票*

## 省钱攻略

<Callout type="tip">
**机票**：提前6–10周预订。周二、周三出发通常更便宜。使用携程、去哪儿或Google Flights的"整月视图"找到最优价格日期。
</Callout>

| 类别 | 省钱方法 |
|---|---|
| 机票 | 提前预订、使用里程、避开节假日 |
| 住宿 | 民宿/青旅、稍远离市中心 |
| 餐饮 | 当地市场、便利店、午市套餐 |
| 交通 | 日票/周票、共享单车、步行 |
| 货币 | 使用Wise或当地ATM换汇，避免机场换汇 |

## 预算分配建议（占总预算比例）

| 类别 | 建议比例 |
|---|---|
| 机票 | 30–40% |
| 住宿 | 20–30% |
| 餐饮 | 15–20% |
| 当地交通 | 10–15% |
| 景点门票/活动 | 5–10% |
| 购物/纪念品 | 5–10% |
| 应急备用金 | 10%（必备！） |

<Callout type="warning">
**旅行保险不可或缺。**它能覆盖医疗紧急情况、行李丢失和航班延误——标准国际旅行保险通常每次只需¥100–300。
</Callout>
