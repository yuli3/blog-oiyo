# D-Day多事件計數器

當你同時需要追蹤多個重要日期時，單一倒數計時遠遠不夠。本工具支援同時管理多個D-Day事件，資料自動儲存在瀏覽器本地。

## 常見使用組合

| 族群 | 需要追蹤的事件 |
|---|---|
| 學生 | 期末考試、論文繳交、畢業口試 |
| 職場人 | 專案截止日、年終考核、休假計畫 |
| 情侶 | 交往周年、情人節、求婚日 |
| 旅行者 | 出發日、簽證到期、回程日 |
| 健身族 | 比賽日、打卡目標、健康檢查日 |
