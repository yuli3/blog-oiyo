## FRM核心公式速查

| 科目 | 公式 |
|------|------|
| VaR N日扩展 | VaR_N = VaR_1 × √N |
| `GARCH(1,1)` | σ²ₜ = ω + α·ε²ₜ₋₁ + β·σ²ₜ₋₁ |
| 长期方差 | ω/(1−α−β) |
| 预期损失EL | PD × LGD × EAD |
| CDS利差 ≈ | PD × LGD |
| LCR | HQLA/30日净流出 ≥ 100% |
| 久期价格变化 | ΔP/P ≈ −D* × Δy |
| RAROC | (收益−成本−EL)/经济资本 |

## 20道FRM模拟题

**Q1.** 1日VaR(99%)为\$100万，10日VaR约为？
A) \$100万  B) \$316万  C) \$1000万  D) \$200万

**Q2.** `GARCH(1,1)`中α+β&lt;1说明？
A) 波动率无限增长  B) 波动率均值回归  C) 波动率为随机游走  D) 波动率为零

**Q3.** FRTB中，替代VaR的风险度量指标是？
A) 压力VaR  B) 预期损失ES  C) 条件VaR  D) 历史VaR

**Q4.** PD=2%，LGD=40%，EAD=\$500万，预期损失为？
A) \$4万  B) \$40万  C) \$400万  D) \$8万

**Q5.** CDS保护买方支付了年利差，信用事件发生时应？
A) 支付名义本金  B) 收取名义本金（赔付）  C) 继续支付利差  D) 合同自动终止

**Q6.** 巴塞尔III下，监管资本覆盖何种置信水平？
A) 95%  B) 99%  C) 99.9%  D) 99.97%

**Q7.** 历史模拟法的主要优势是？
A) 假设收益率正态分布  
B) 无需分布假设，自然捕捉厚尾  
C) 计算速度最快  
D) 只使用最近30天数据

**Q8.** 高斯Copula的主要缺陷是？
A) 计算复杂  B) 尾部相关性为零，低估危机联动  C) 只能处理两个变量  D) 需要大量历史数据

**Q9.** EWMA中λ从0.94降低到0.90意味着？
A) 历史数据权重增加  B) 近期数据权重增加  C) 所有数据等权重  D) 波动率更稳定

**Q10.** LCR中，Level 2A资产的折扣率（Haircut）是？
A) 0%  B) 15%  C) 25%  D) 50%

**Q11.** 巴塞尔IV SMA中，内部损失乘数（ILM）>1的条件是？
A) 内部损失低于BIC基准  B) 内部损失高于BIC基准  C) 总资产超过一定规模  D) 始终等于1

**Q12.** 操作风险中，"员工歧视诉讼"属于哪类事件？
A) 内部欺诈  B) 外部欺诈  C) 就业惯例与工作场所安全  D) 执行与流程管理

**Q13.** NSFR的计算公式是？
A) HQLA/30日净流出  B) 可用稳定资金（ASF）/所需稳定资金（RSF）  C) Tier1/总敞口  D) CET1/RWA

**Q14.** 久期缺口（Duration Gap）公式是？
A) D_A + D_L  B) D_A − (L/A)×D_L  C) D_L − D_A  D) D_A × D_L

**Q15.** RAROC高于股权成本（WACC）意味着？
A) 风险过高  B) 创造股东价值  C) 监管资本不足  D) 经济资本需减少

**Q16.** EVT中POT方法拟合的分布是？
A) 正态分布  B) 学生t分布  C) 广义帕累托分布（GPD）  D) 对数正态分布

**Q17.** 债券修正久期为7，利率上升50bps，价格变化约为？
A) +3.5%  B) −3.5%  C) +7%  D) −7%

**Q18.** CET1最低要求（不含资本缓冲）是？
A) 4.5%  B) 6%  C) 8%  D) 10.5%

**Q19.** 以下哪项指标衡量单位主动风险的超额收益？
A) 夏普比率  B) 特雷诺比率  C) 信息比率  D) 索提诺比率

**Q20.** 完全免疫化（Full Immunization）需要满足以下哪些条件？
A) 仅资产久期=负债久期  
B) 资产久期=负债久期+资产现值=负债现值+资产凸性>负债凸性  
C) 只需资产现值≥负债现值  
D) 无需凸性条件

## 答案速查

| Q | 答案 | 简要解析 |
|---|------|---------|
| 1 | B | \$100万×√10 ≈ **\$316万** |
| 2 | B | α+β&lt;1 → 方差均值回归至ω/(1−α−β) |
| 3 | B | FRTB用ES(97.5%)替代VaR(99%) |
| 4 | B | EL = 0.02×0.40×500万 = **\$40万** |
| 5 | B | CDS保护买方：信用事件 → **收取名义本金赔付** |
| 6 | C | 巴塞尔IRB资本覆盖99.9%置信水平 |
| 7 | B | 历史模拟法无需分布假设 |
| 8 | B | 高斯Copula尾部相关=0 → 危机联动被低估 |
| 9 | B | λ降低 → (1−λ)增大 → **近期数据权重更高** |
| 10 | B | Level 2A折扣率：**15%** |
| 11 | B | 内部损失>BIC基准 → ILM>1（惩罚机制） |
| 12 | C | 员工歧视 → **就业惯例与工作场所安全** |
| 13 | B | NSFR = ASF/RSF ≥ 100% |
| 14 | B | 久期缺口 = D_A − (L/A)×D_L |
| 15 | B | RAROC>WACC → **创造股东价值** |
| 16 | C | POT法 → **广义帕累托分布（GPD）** |
| 17 | B | ΔP/P ≈ −7×0.005 = **−3.5%** |
| 18 | A | CET1最低要求：**4.5%**（+2.5%缓冲=7%） |
| 19 | C | 信息比率 = α/追踪误差 = 单位主动风险超额收益 |
| 20 | B | 完全免疫三条件：久期+现值+凸性（资产凸性>负债凸性） |
