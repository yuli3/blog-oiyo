## 工作狂并非勤奋的代名词

“因为热爱工作而投入大量时间”与“因为无法停止工作而被迫继续”在表面上看起来很相似。两者都表现为频繁加班、在休息日查看工作消息，以及高度重视绩效。然而，从心理学角度来看，这两种状态有着本质的区别。

充满热情的人即使工作量很大，也能在生活其他领域保持一定的平衡。相反，工作成瘾（workaholism）是指当不工作时会感到焦虑或内疚，即使健康、人际关系和休息受到损害，也难以减少工作量。本文旨在提供自我反思的指南，不能替代医学诊断。

## 卑尔根工作成瘾量表（BWAS）的7个维度

在工作成瘾的研究中，挪威研究员塞西莉·舒·安德烈亚森（Cecilie Schou Andreassen）等人提出的**卑尔根工作成瘾量表（Bergen Work Addiction Scale, BWAS）**是常用的工具之一。该量表将成瘾行为的研究框架应用于工作行为，认为工作成瘾具有以下7个核心特征：

| 维度 | 工作中的表现 |
|------|------|
| 显著性 | 工作占据了大脑的大部分空间，即使在休息时也无法停止思考工作 |
| 心境改变 | 工作时感到安心、兴奋或掌控感，停止工作时则感到不适 |
| 耐受性 | 为了获得与以往相同的满足感，工作时间越来越长，强度越来越大 |
| 戒断反应 | 无法工作时会感到烦躁、易怒或产生强烈的内疚感 |
| 冲突 | 即使与家人、朋友、健康或睡眠发生冲突，仍将工作置于首位 |
| 复发 | 即使下定决心减少工作，很快又会回到过度劳累的模式 |
| 问题 | 即使身心已经出现问题，仍无法降低工作强度 |

这7个维度提出了一个比“我工作很努力”更重要的问题：**工作是在拓宽我的生活，还是在挤压生活的其他部分？**

## 热情与成瘾的区别

热爱工作的人会进入“心流”状态。心流是指时间飞逝、任务与能力恰好匹配，结束后虽然疲惫但内心充实的状态。相反，工作成瘾者在工作结束后并不会感到轻松。即使取得了成就，内心仍残留着“还不够好”的感觉，如果不寻找下一项任务，就会感到焦虑。

区分这两种状态的核心在于**选择感**。热情更接近于“因为想做而做”，而工作成瘾则更接近于“因为不做就无法忍受而做”。充满热情的人在面对重要的人际关系或健康问题时能够调整工作，而工作成瘾的模式则会让人将这种调整视为失败或威胁。

另一个区别是**自我认同的广度**。工作可以是生活的重要组成部分，但如果工作成了你价值的全部，那就很危险了。当绩效等同于自尊，错误就成了存在的失败。在这种情况下，连休息时间都被视为一种退步，而非恢复。

## 为什么难以停下来？

工作成瘾不仅是个人的性格问题，还受到焦虑、完美主义、认可需求、经济压力和竞争性组织文化的影响。特别是那些深信“我必须有用才能被爱”的人，更容易通过工作来获得安全感。

问题在于，工作在短期内确实能降低焦虑。当担忧袭来时，处理一项工作任务能带来暂时的掌控感。但如果这种方式反复出现，休息就会变得更加陌生，身体也会持续处于紧张状态。最终，工作不再是解决问题的工具，而成了逃避情绪的手段。

组织环境也有影响。随时随地必须回复的即时通讯文化、将加班视为奉献的氛围、模糊的绩效标准，都会强化工作成瘾的模式。如果个人只是一味地反思“是不是我有问题？”，就很容易忽略结构性的压力。

## 恢复并不是学习懒惰

从工作成瘾中恢复，并不意味着要减少对工作的热爱。相反，是为了能更长久地工作，在工作与自我之间建立健康的边界。

首先，**设定小范围的工作时间边界**。从一开始就实现完美的“工作与生活平衡（Work-Life Balance）”很难。需要设定一些微小且可观察的边界，例如下班后关闭通知30分钟，或者将周末上午的一段时间设为“无工作时间”。

其次，**记录恢复指标而非绩效指标**。关注睡眠时间、饮食、散步、与家人的对话，以及不需要高度集中的爱好等身体恢复的信号。在工作成瘾模式下，绩效指标容易无限膨胀，而恢复指标则容易消失。

第三，**学习直接应对焦虑的方法**。当停止工作时，将涌现的内疚感、落后感或不被认可的恐惧写下来，仅仅通过书写就能延缓自动化的负面反应。如果需要，通过心理咨询处理完美主义或自我苛责的模式也会有所帮助。

## 给自己的提问

以下问题并非诊断，而是为了自我检查：

| 问题 | 观察点 |
|------|------|
| 休息时是否感到焦虑或内疚？ | 戒断反应与心境调节 |
| 是否多次尝试减少工作但都失败了？ | 复发模式 |
| 即使关系、健康、睡眠受损，仍优先考虑工作吗？ | 冲突与问题 |
| 如果没有绩效，是否觉得自己的价值降低了？ | 自我认同的狭隘化 |

## 核心摘要

- 工作成瘾不是勤奋，而是一种难以停止工作的重复模式。
- 安德烈亚森的BWAS通过显著性、心境改变、耐受性、戒断反应、冲突、复发、问题这7个维度来解释工作成瘾。
- 热情会带来选择感和恢复力，而成瘾则是为了缓解焦虑和内疚而被迫持续工作。
- 恢复不是放弃工作，而是重新建立工作边界、恢复指标和焦虑调节机制的过程。
