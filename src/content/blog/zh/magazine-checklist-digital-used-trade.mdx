# 闲鱼二手交易如何保住你的数据和钱包

原价动辄小一万的最新款旗舰手机和电脑，让闲鱼、转转成为数码爱好者淘宝的圣地。但“二手水太深”也是共识：不慎买到华强北翻新机、隐藏的ID锁，或是卖掉旧手机后被恶意恢复暴露了隐私照片？跟着这份**终极交易防骗清单**来操作。

---

## 🔒 第一部分：“出二手”时的数据彻防

别以为点了“恢复出厂设置”就算完事！在云端同步时代，这点操作无法真正保护你的隐私资产。

- [ ] **步骤 1：手动退出所有云端账号（ID锁）**
  - **苹果 (iOS)：** 设置 ➔ 点最顶部的名字 ➔ 滑到最下方点击【退出登录】。这是必须做的一步，否则会带着“查找我的iPhone”的激活锁，买家拿到后根本无法使用。
  - **安卓 (华为/小米/OV)：** 手动在设置中退掉华为云空间、小米账号及所有关联的同步功能。
- [ ] **步骤 2：解绑所有底层蓝牙设备**
  - 在蓝牙设置里，将之前连接过的无线耳机（AirPods等）、智能手表全部“忽略此设备”。
- [ ] **步骤 3：数据覆写与最终格式化**
  - 登出账号后，才在设置里执行“抹掉所有内容和设置”。
  - *防恢复黑客级贴士：* 在抹掉数据前，先用毫无意义的高清视频（比如对着白墙录几十分钟）把剩余的几十G存储空间全部塞满！这样闪存芯片会被垃圾数据覆盖，任何数据恢复软件都无法找回你原本的私密照片。

---

## 🔎 第二部分：“买二手”时的面交试机大全

即使你是在闲鱼下单，同城面交或是快递签收时，务必在点击“确认收货”前完成这几步极速体检。打款了就再也找不到人了！

### 📱 验手机实战
- [ ] **核验序列号与有锁/无锁：** 找到手机的序列号（或IMEI），在苹果官网或微信相关查询小程序验明正身。如果是买iPhone，必须确认【关于本机】里显示“无SIM卡限制”，以防水货“有锁机（卡贴机）”。
- [ ] **电池健康度与爱思助手：**
  - 苹果手机如果电池健康度低于80%，需要尽快花几百块换电池，这也是你跟卖家“砍价”的最好理由。带个电脑插上数据线跑一次爱思助手全绿测试，看零部件有没有被大修过。
- [ ] **屏幕烧屏与坏点检测（OLED通病）：** 打开备忘录调至全屏纯白并且亮度拉满，仔细看屏幕有没有残影（比如键盘的影子印在了屏幕上）。
- [ ] **全功能限时速测：** 
  1. 插入你自己的SIM卡，马上打个电话看网络信道和听筒好不好。
  2. 测试前摄、后摄、闪光灯和变焦。
  3. 拨动全部物理静音键、音量键。

### 💻 笔记本电脑当面验机
- [ ] **电池循环次数：** 
  - 购买MacBook：按住Option ➔ 苹果Logo ➔ 系统信息 ➔ 电源 ➔ 查看“循环计数”。通常300次内都是正常，超过800次基本电池快废了。
- [ ] **键盘盲点测试：** 满屏幕随便乱敲！特别是最边角的键位和空格键，全部都要能回弹且反应灵敏。
- [ ] **转轴疲劳度：** 把屏幕开合到45度看看会不会自己因为重力垮掉，这关系到后期的维修大坑。
