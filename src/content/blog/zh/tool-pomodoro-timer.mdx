# 番茄钟计时器

番茄工作法由弗朗西斯科·西里洛于1980年代末创立。核心思路很简单：以**25分钟**为一个专注冲刺，搭配**5分钟**短暂休息。神经科学研究证实，这一节奏契合大脑的自然注意力周期。

## 番茄工作法操作步骤

| 步骤 | 时长 | 行动 |
|---|---|---|
| 🍅 一个番茄 | 25分钟 | 专注工作，屏蔽一切干扰 |
| 短暂休息 | 5分钟 | 起身、伸展、远眺 |
| 完成4个番茄后 | 15–30分钟 | 长休息，彻底放松 |

<Callout type="tip">
**黄金法则**：番茄钟进行中若有干扰想法，立即记到纸上，番茄结束后再处理。不要为了「就一分钟」而打断——拖延症往往就从这一秒开始。
</Callout>

## 为什么休息至关重要

| 机制 | 说明 |
|---|---|
| **预设模式网路** | 大脑在休息时巩固资讯，而非工作时 |
| **决策疲劳** | 持续专注90–120分钟后，决策品质明显下降 |
| **工作记忆** | 休息时清空缓存，为后续任务释放容量 |

## 不同任务的推荐时长

| 任务类型 | 推荐时长 | 技巧 |
|---|---|---|
| 写作 / 创作 | 25分钟 | 标准番茄 |
| 程式设计 / 除错 | 50分钟 | 双番茄 |
| 复习 / 阅读 | 25–50分钟 | 根据难度调整 |
| 会议 | 控制在45分钟内 | 严格议程，不使用番茄法 |
