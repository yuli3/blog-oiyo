# 番茄鐘計時器

番茄工作法由弗朗西斯科·西里洛於1980年代末創立。核心思路很簡單：以**25分鐘**為一個專注衝刺，搭配**5分鐘**短暫休息。神經科學研究證實，這一節奏契合大腦的自然注意力週期。

## 番茄工作法操作步驟

| 步驟 | 時長 | 行動 |
|---|---|---|
| 🍅 一個番茄 | 25分鐘 | 專注工作，屏蔽一切干擾 |
| 短暫休息 | 5分鐘 | 起身、伸展、遠眺 |
| 完成4個番茄後 | 15–30分鐘 | 長休息，徹底放鬆 |

<Callout type="tip">
**黃金法則**：番茄鐘進行中若有干擾想法，立即記到紙上，番茄結束後再處理。不要為了「就一分鐘」而打斷——拖延症往往就從這一秒開始。
</Callout>

## 為什麼休息至關重要

| 機制 | 說明 |
|---|---|
| **預設模式網路** | 大腦在休息時鞏固資訊，而非工作時 |
| **決策疲勞** | 持續專注90–120分鐘後，決策品質明顯下降 |
| **工作記憶** | 休息時清空緩存，為後續任務釋放容量 |

## 不同任務的推薦時長

| 任務類型 | 推薦時長 | 技巧 |
|---|---|---|
| 寫作 / 創作 | 25分鐘 | 標準番茄 |
| 程式設計 / 除錯 | 50分鐘 | 雙番茄 |
| 複習 / 閱讀 | 25–50分鐘 | 根據難度調整 |
| 會議 | 控制在45分鐘內 | 嚴格議程，不使用番茄法 |
