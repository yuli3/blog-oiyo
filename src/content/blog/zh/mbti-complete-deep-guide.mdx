## 什么是MBTI？

**MBTI（Myers-Briggs Type Indicator）**是以卡尔·荣格（Carl Jung）的心理类型理论为基础，由伊莎贝尔·布里格斯·迈尔斯（Isabel Briggs Myers）和凯瑟琳·库克·布里格斯（Katharine Cook Briggs）开发的人格类型测评。自1943年首次出版以来，它已成为全球200多个国家每年数百万人使用的主流人格模型之一。

MBTI用四组二分维度来描述人格偏好。

| 维度 | 极端 A | 极端 B | 核心问题 |
|-----|-------|-------|---------|
| **能量方向** | E（外向） | I（内向） | 你从哪里获得能量？ |
| **信息感知** | S（感觉） | N（直觉） | 你如何接收信息？ |
| **判断标准** | T（思考） | F（情感） | 你如何做决定？ |
| **生活方式** | J（判断） | P（知觉） | 你如何安排和面对世界？ |

## 2. 8项认知功能：MBTI的核心

如果只把MBTI理解成四个字母的标签，就很难看到它的深度。真正的MBTI需要通过**8项认知功能**的组合来理解。

| 功能 | 名称 | 说明 |
|-----|-----|-----|
| **Se** | 外向感觉 | 专注当下的感官经验。即兴性、现实适应力 |
| **Si** | 内向感觉 | 将过去经验与当前情境比较。传统、稳定、细节记忆 |
| **Ne** | 外向直觉 | 探索可能性和模式。连接想法、创造性发散 |
| **Ni** | 内向直觉 | 深层洞察与未来愿景。收束式洞察、预见力 |
| **Te** | 外向思考 | 将逻辑和效率应用于外部世界。建立系统、达成目标 |
| **Ti** | 内向思考 | 在内在体系中组织逻辑。分析原理、追求准确性 |
| **Fe** | 外向情感 | 与他人保持和谐与共情。管理群体情绪、建立社会连接 |
| **Fi** | 内向情感 | 个人价值观与真实感。探索内心情绪、自我认同 |

### 16种类型的功能堆栈

每种类型都会按照**主导功能（Dominant）→ 辅助功能（Auxiliary）→ 第三功能（Tertiary）→ 劣势功能（Inferior）**的顺序使用四项功能。

**例：INTJ的功能堆栈**
1. **Ni**（主导功能）：长期愿景与深层洞察
2. **Te**（辅助功能）：把愿景落实为现实系统
3. **Fi**（第三功能）：个人价值观，随成长逐渐发展
4. **Se**（劣势功能）：当下感官经验，也是压力下的脆弱点

## 6. MBTI与关系模式

### 相性较好的类型（互补关系）

一般来说，**同属NT/NF/SJ/SP群体**的类型更容易产生亲近感，而在**主导功能与辅助功能互补的组合**中，也更容易形成深层连接。

| 类型组合 | 互补关系的原因 |
|--------|-------------|
| INTJ ↔ ENFP | Ni-Te vs Ne-Fi：愿景与创造力的结合 |
| INFJ ↔ ENTP | Ni-Fe vs Ne-Ti：洞察与逻辑的协同 |
| ISTJ ↔ ESFP | Si-Te vs Se-Fi：稳定与活力的平衡 |
| INFP ↔ ENFJ | Fi-Ne vs Fe-Ni：价值与愿景的协调 |

<Callout type="info" title="MBTI相性只是参考指标">
MBTI相性是相互理解的起点，不是绝对规则。个人成长水平、价值观是否一致、沟通方式，往往比类型本身更关键。
</Callout>

## 8. MBTI的研究背景与学术视角

MBTI在大众层面非常流行，但在学术心理学中一直存在争议。

**支持依据**:
- 全球数十年广泛使用的数据积累
- 对自我认识和团队沟通改善有实际帮助
- 将荣格理论具体化为可使用的工具

**批评依据**:
- 重测信度问题：4~5周后重测时，约50%的人类型会改变
- 二分法的局限：真实人格更像连续谱
- 与大五人格（OCEAN）等模型相比，预测效度较低

<Callout type="info" title="大五人格 vs MBTI">
在学术心理学中，**大五人格模型（OCEAN：开放性、尽责性、外向性、宜人性、神经质）**通常表现出更高的信度和效度。MBTI更适合作为自我反思与对话工具，大五人格更适合作为研究与预测工具，两者可以互补使用。
</Callout>
