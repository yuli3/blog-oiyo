# 不想被黑心中介与奇葩房东榨干？租房避开大坑指南

一线城市房租动辄吞掉大半工资，交钱容易退押金难。不管是通过自如租公寓，还是安居客、链家找私人房东，这篇**看房与搬家终极清单**将教你护紧钱袋子。

---

## 🏚️ 第一部分：线下实地看房（找痛点）

不要一进门就被虚假的“温馨ins风壁纸”所迷惑，你的关注点应在基建上。

### 🚿 水电与基础设施暴力检验
- [ ] **高层水压检验：** 把厨房和洗手间的水龙头同时开到最大，如果细弱如发丝，你每天早上洗澡都会非常痛苦。
- [ ] **手机信号黑洞：** 别光顾着看采光，走到卧室最里侧和卫生间，用手机打开视频看看能不能秒播！有些老破小由于楼距原因，移动信号会全无。
- [ ] **隔音的真相（敲敲看）：** 用手背敲一敲分割两间卧房的墙。如果发出“空空”脆响且十分单薄，代表这是后期加建打的隔断墙（甚至是违建），隔壁室友的打鼾声和打电话声你绝对受不了。

<Callout type="note">
**看房的时间差：白天看光，晚上看鬼** <br/>
白天一定要多看两次看采光和西晒程度。而晚上必须复看一次：看看周围有无彻夜施工的工地大挂车、广场舞噪音、以及小区昏暗地带的安全监控是否全覆盖。
</Callout>

### 📜 合同雷区勘误（最核心部分）
- [ ] **押一付三背后的隐藏大坑：** 明确“中介费”是由谁承担，是否有“物业费”、“入户网费强制包年”或“每月保洁费”等未被告知的杂项支出！
- [ ] **房产证与二房东确认：** 付定金前，必须有底气说：“麻烦出示一下房产证原件和房东身份证”。如果是二房东，一定要对方出示一手房东准许转租的白纸黑字合同。

### 🕒 安置落户的尾巴
- [ ] **居住证与流动人口登记：** 在大城市生活，及时去居委会或者通过小程序办理居住证变更，这关系到你后续买车摇号或者其他社会服务。
- [ ] **修改一切快递默认地址：** 打开淘宝、拼多多和京东，不仅要添加新地址，还要立刻删掉或者解绑老地址，防止接下来的买菜和包裹全去了几十公里外。
