# 寵物年齡計算器

「1歲狗齡=7歲人齡」是常見誤解。動物在幼年時老化速度遠快於人類，此後逐漸減慢。對於狗狗，體型大小也會影響換算結果。

## 小型犬年齡換算參考

| 狗狗年齡 | 等效人類年齡 |
|---|---|
| 1歲 | 約15歲 |
| 3歲 | 約28歲 |
| 7歲 | 約44歲 |
| 10歲 | 約56歲 |
| 15歲 | 約76歲 |

## 貓咪年齡換算參考

| 貓咪年齡 | 等效人類年齡 |
|---|---|
| 1歲 | 約15歲 |
| 5歲 | 約36歲 |
| 10歲 | 約56歲 |
| 15歲 | 約76歲 |
| 20歲 | 約96歲 |

<Callout type="tip">
**資深毛孩照護**：狗狗7歲（大型犬）或10歲（小型犬）、貓咪10歲後，建議每半年健康檢查一次，每年血液檢查，並換用老年配方飼料。
</Callout>
