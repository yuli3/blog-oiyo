# 數字命理計算器

數字命理學是探索數字在人類生命中意義的學問。由畢達哥拉斯推廣，將1-9每個數字與特定性格特徵和人生主題關聯。它是一種象徵性思考框架，而非預測科學。

## 四大核心數字

| 數字 | 計算依據 | 含義 |
|---|---|---|
| **生命數（命運數）** | 出生日期 | 您此生的核心使命 |
| **表達數（天賦數）** | 全名（字母數值） | 您的天賦與潛力 |
| **靈魂渴望數** | 姓名中的母音字母 | 您內心深處的渴望 |
| **個性數** | 姓名中的子音字母 | 他人眼中的您 |

## 1-9數字含義

| 數字 | 主題 | 特質 |
|---|---|---|
| **1** | 領導力 | 獨立、開拓、進取 |
| **2** | 和諧 | 外交、敏感、合作 |
| **3** | 創造力 | 表達、活潑、溝通 |
| **4** | 穩定 | 有序、務實、可靠 |
| **5** | 自由 | 冒險、適應、好奇 |
| **6** | 責任 | 保護、利他、家庭 |
| **7** | 智慧 | 內省、分析、靈性 |
| **8** | 權力 | 雄心、物質、堅定 |
| **9** | 慈悲 | 人道、理想、博愛 |
