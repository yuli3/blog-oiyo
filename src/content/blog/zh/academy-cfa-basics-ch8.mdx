## CFA Level I核心公式速查表

| 科目 | 公式 |
|------|------|
| 戈登成长DDM | P = D₁/(r−g) |
| CAPM | E(R) = Rf + β[E(Rm)−Rf] |
| 修正久期价格变化 | ΔP/P ≈ −D* × Δy |
| 组合方差（双资产） | σ²p = w₁²σ₁² + w₂²σ₂² + 2w₁w₂σ₁σ₂ρ |
| 夏普比率 | (Rp−Rf)/σp |
| EL（预期损失） | PD × LGD × EAD |
| LCR | HQLA / 30天净流出 ≥ 100% |
| 看涨-看跌平价 | C + PV(X) = P + S₀ |

## 20道模拟考题

**Q1.** CFA特许金融分析师获得一份礼物以换取优先分发研究报告。违反了哪项标准？
A) 独立性与客观性（I-B）  B) 公平对待（III-B）  C) 忠诚（IV）  D) 合理依据（V-A）

**Q2.** 股票预计明年股息为\$2，永续增长率4%，要求收益率10%。内在价值为？
A) \$20  B) \$25  C) \$33.33  D) \$50

**Q3.** 修正久期为5的债券，利率上升100bps，价格变化约为？
A) +5%  B) −5%  C) −10%  D) +10%

**Q4.** 两资产组合，A：期望收益8%，权重40%；B：期望收益12%，权重60%。组合期望收益为？
A) 9.2%  B) 10.0%  C) 10.4%  D) 11.2%

**Q5.** β=1.5，无风险利率3%，市场收益率8%，CAPM预期收益率为？
A) 10.5%  B) 12.5%  C) 13.5%  D) 9.5%

**Q6.** 认购期权内在价值计算：当前股价\$50，行权价\$45。内在价值为？
A) \$0  B) \$5  C) \$10  D) \$45

**Q7.** 价格上涨期间，LIFO相比FIFO的效果是？
A) 更高的净利润，更低的存货  
B) 更低的净利润，更高的销售成本  
C) 更低的净利润，更高的存货  
D) 更高的销售成本，更高的存货

**Q8.** 有效市场假说半强式成立时，哪种分析方法无效？
A) 技术分析  B) 基本面分析  C) 量化分析  D) 内幕信息利用

**Q9.** CFA Level I考试中，伦理与职业标准的权重约为？
A) 5%  B) 10%  C) 15~20%  D) 25%

**Q10.** ROE的杜邦三因素分解是？
A) 净利率 × 资产周转率 × 权益乘数  
B) 毛利率 × EBITDA利润率 × 总资产回报率  
C) 净利润 × 总资产 / 股东权益  
D) EPS × P/E × 股息支付率

**Q11.** 收益率曲线倒挂通常预示？
A) 经济扩张  B) 通货膨胀加速  C) 经济衰退  D) 货币政策宽松

**Q12.** 看涨-看跌平价：C=3，PV(X)=97，S=100，则P=？
A) 0  B) 3  C) 6  D) −3

**Q13.** 卡玛比率（Calmar Ratio）的计算公式是？
A) (Rp−Rf)/σp  B) 年化收益率/最大回撤  C) α/追踪误差  D) (Rp−Rf)/β

**Q14.** 自由现金流（FCF）的最常见计算方式是？
A) EBITDA − 所得税  
B) 净利润 + 折旧  
C) 经营活动现金流 − 资本支出  
D) 营业收入 × 净利率

**Q15.** 根据CAPM，β=0.8的防御性股票在牛市中表现如何？
A) 超越市场  B) 与市场相同  
C) 低于市场表现  D) 与市场负相关

**Q16.** 房地产估值中，Cap Rate从5%上升至6%，NOI不变。物业价值变化？
A) 增加20%  B) 减少约17%  C) 不变  D) 增加约17%

**Q17.** 期权中，Vega为正表示？
A) 波动率上升时，期权价值下降  
B) 波动率上升时，期权价值上升  
C) 波动率对期权价值无影响  
D) 只有认购期权受波动率影响

**Q18.** LBO的三大回报来源不包括？
A) 债务杠杆效应  B) 运营改善  
C) 估值倍数扩张  D) 股息再投资

**Q19.** 信息比率（IR）衡量的是？
A) 每单位总风险的超额收益  
B) 每单位主动风险的超额收益（主动管理效率）  
C) 最大回撤与年化收益之比  
D) 投资组合与市场指数的相关性

**Q20.** 一只债券面值$1000，到期收益率高于票面利率，则该债券？
A) 溢价发行  B) 平价发行  C) 折价发行  D) 无法判断

## 答案与解析

| Q | 答案 | 简要解析 |
|---|------|---------|
| 1 | A | 换取优先研究分发的礼物 → 损害独立性与客观性（I-B） |
| 2 | C | P = 2/(0.10−0.04) = 2/0.06 = **$33.33** |
| 3 | B | ΔP/P ≈ −5 × 0.01 = **−5%** |
| 4 | C | 0.4×8% + 0.6×12% = 3.2 + 7.2 = **10.4%** |
| 5 | A | E(R) = 3% + 1.5×(8%−3%) = 3% + 7.5% = **10.5%** |
| 6 | B | 内在价值 = max(50−45, 0) = **$5** |
| 7 | B | 价格上涨+LIFO：最新高价存货先进成本 → COGS更高，净利润更低 |
| 8 | B | 半强式EMH：公开信息已充分反映 → 基本面分析无法持续获取超额收益 |
| 9 | C | CFA Level I伦理科目权重：**15~20%** |
| 10 | A | 杜邦：ROE = 净利率 × 资产周转率 × 权益乘数 |
| 11 | C | 收益率倒挂是经济衰退的历史领先指标 |
| 12 | A | C + PV(X) = P + S → 3 + 97 = P + 100 → **P = 0** |
| 13 | B | 卡玛比率 = 年化收益率 / 最大回撤 |
| 14 | C | FCF = 经营活动现金流 − 资本支出 |
| 15 | C | β < 1：牛市中涨幅小于市场（防御性） |
| 16 | B | 价值 = NOI/Cap Rate；Cap Rate 5%→6%：变化率 = −(6−5)/6 ≈ **−16.7%** |
| 17 | B | Vega > 0：波动率↑ → 期权价值↑（无论认购还是认沽） |
| 18 | D | LBO三大来源：杠杆+运营+倍数扩张；股息再投资不在其中 |
| 19 | B | IR = α/追踪误差，衡量主动管理效率 |
| 20 | C | YTM > 票面利率 → 债券按**折价**交易 |
