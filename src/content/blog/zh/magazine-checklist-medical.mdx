# 拔个牙要几千元？保卫你的健康与钱包

去了躺富丽堂皇的口腔诊所，本想只是补一个轻度的龋齿，结果被“销售主任”拉进小黑屋一通恐吓，给你开具了包含几颗烤瓷牙和进口种植材料的上万元长长账单？

面对莆田系、资本化运营的连锁诊所以及防不胜防的医美隐形消费，这套**就诊防坑检验单**是你拿在手里的反杀武器。

---

## 🦷 第一部分：初诊时“资本化医疗”的报警信号

你进的到底是医院，还是销售中心？

- [ ] **谁在主导诊断（医生还是销售？）：** 如果白大褂的医生只是粗略看了两眼，随即就让一位妆容精致的“咨询师”、“客服主管”带着你算分期付款，并极力向你推销套路贷或者京东白条，赶紧走！真正的医生是从不用推销去治病的。
- [ ] **强扣你的就诊资料与片子：** 你的CT片子、X光照片，你有100%的所有权。当你说：“您可以把拍过的片子发到我微信上吗，我需要和家里人商量一下”时，如果他们百般阻挠、脸瞬间拉长，这就是最大的做贼心虚。
- [ ] **“不立刻下决定骨头就烂了”的恐吓：** 除了危及生命的心脑血管急症，极少有慢性牙科或医疗问题是“你今天在这个店不掏钱立刻做就无可救药”的。所有以限时恐吓驱动消费的，通通是割韭菜。

## 🩺 第二部分：看大病或整容前的“多方比价法”

去三甲看和去高端连锁看，花的是两种截然不同的钱。拿到第一份上万报价表后，请拿着你的片子严格执行同城交叉问诊。

- [ ] **开启伪装模式：** 去找三甲医院老专家看病时，绝口不提前面私立医院给你下的病危通知单，直接平心静气地说你的基础病症（比如“我喝冷水的时候这半边牙会疼”）。看老专家的保守治疗给的是什么方案。
- [ ] **死磕费用明细清单（要到每一颗螺丝钉）：** 千万别接受“骨粉填充+植体套餐 = 4999元”这种模糊报价！一定要索要盖公章的明细：用的是什么品牌的植体（奥齿泰、诺贝尔？）、质保几年？
- [ ] **网络背景筛查工具：** 打开企查查或天眼查工具，搜索这家医院的主体公司。如果发现它有大量的“医疗损害责任纠纷”官司，或者频繁更名甚至吊销营业执照的黑历史，绝对不要踏入半步！
