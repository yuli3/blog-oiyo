# 生物節律計算器

生物節律理論認為人類存在影響體能、情緒和智力的規律性生物週期。雖然其科學性仍有爭議，但作為自我認知的輔助工具頗受歡迎。

## 三大主要週期

| 週期 | 時長 | 影響範圍 |
|---|---|---|
| **體力** | 23天 | 力量、耐力、協調性、代謝 |
| **情感** | 28天 | 情緒、創造力、直覺、敏感性 |
| **智力** | 33天 | 邏輯、專注力、記憶、問題解決 |

## 各階段解讀

| 階段 | 位置 | 狀態 |
|---|---|---|
| **高峰期** | +50%~+100% | 能力處於最佳狀態 |
| **過渡期** | ~0% | 穩定過渡 |
| **低谷期** | -50%~-100% | 能力有所下降 |
| **關鍵日** | 穿越零點 | 不穩定，建議謹慎行事 |
