## 什么是会计学？

**会计学**是一套资讯系统，用于衡量、记录、分类及汇总企业的经济活动，以便资讯使用者做出有依据的决策。

**会计的目的**：向利益关系人（股东、债权人、政府、管理层）提供**有用的财务资讯**

---

## 会计的分类

| 类别 | 财务会计 | 管理会计 |
|------|---------|---------|
| **目的** | 对外报告 | 内部决策 |
| **使用者** | 投资者、债权人、政府 | 管理层、内部人员 |
| **准则** | 须遵循GAAP/IFRS | 格式自由 |
| **报告周期** | 定期（季/半年/年） | 按需即时 |
| **范例** | 财务报表 | 预算、成本报告 |

**税务会计**：以计算应纳税额为目的的会计，依照税法规定编制。

## 复式记帐法

每一笔交易同时记录在**借方**与**贷方**，确保会计恒等式始终平衡。

```
基本会计恒等式：
资产 = 负债 + 股东权益
```

**借方增加的科目**：资产、费用
**贷方增加的科目**：负债、股东权益、收益

```
范例：提供服务，收取现金 $10,000

（借）现金       $10,000
（贷）营业收入   $10,000
→ 资产增加 = 收益增加（会计恒等式维持平衡）
```

<Callout type="tip">
**复式记帐的核心逻辑**：每笔交易必然同时影响两个或以上的会计科目，且借方合计永远等于贷方合计。这不只是记帐技术，更是一种对企业经济实质的如实反映。
</Callout>

## 会计基本假设

1. **个体假设**：企业是独立的经济个体，有别于其所有者
2. **持续经营假设**：企业在可预见的未来将持续运作
3. **货币计量假设**：只记录可以用货币衡量的经济活动
4. **会计期间假设**：企业的生命可划分为特定时间段（月、季、年）进行报告

## 财务报表的种类

| 财务报表 | 内容 |
|---------|------|
| **资产负债表** | 特定时点的资产、负债与股东权益 |
| **损益表** | 特定期间的收益、费用与利润 |
| **现金流量表** | 特定期间的现金流入与流出 |
| **股东权益变动表** | 特定期间股东权益的变动 |
| **财务报表附注** | 财务报表项目的详细说明 |

## IFRS概念框架的质量特征

**基本质量特征**：
- **攸关性**：能影响使用者决策的资讯
- **如实呈现**：完整性、中立性、无重大错误

**增强质量特征**：
- 可比性、可验证性、及时性、可理解性

## 重点整理

**复式记帐原理** ★★★★★
: 每笔交易以相等金额同时记录于借方与贷方。借方合计永远等于贷方合计。
*记忆口诀：资产、费用借方增 / 负债、权益、收益贷方增*

**基本会计恒等式** ★★★★★
: 资产 = 负债 + 股东权益。所有财务报表编制的基础。
*记忆口诀：A = L + E*

**持续经营假设** ★★★★☆
: 假设企业将持续运作而不清算。是折旧计提与长期资产估值的基础。

## 练习题

**Q. 财务会计与管理会计最重要的差异是什么？**
> 财务会计是依GAAP/IFRS准则向利益关系人进行的正式对外报告；管理会计是以管理层决策为目的的非正式内部报告，无固定格式要求。财务会计侧重历史资讯；管理会计兼含前瞻性预测。

**Q. 企业以现金 $1,000 购入办公设备。请记录分录。**
> （借）办公设备（资产）\$1,000 /（贷）现金（资产）\$1,000。资产组成改变（现金减少、设备增加），会计恒等式维持平衡。
