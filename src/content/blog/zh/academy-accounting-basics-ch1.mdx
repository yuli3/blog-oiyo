## 什麼是會計學？

**會計學**是一套資訊系統，用於衡量、記錄、分類及彙總企業的經濟活動，以便資訊使用者做出有依據的決策。

**會計的目的**：向利益關係人（股東、債權人、政府、管理層）提供**有用的財務資訊**

---

## 會計的分類

| 類別 | 財務會計 | 管理會計 |
|------|---------|---------|
| **目的** | 對外報告 | 內部決策 |
| **使用者** | 投資者、債權人、政府 | 管理層、內部人員 |
| **準則** | 須遵循GAAP/IFRS | 格式自由 |
| **報告週期** | 定期（季/半年/年） | 按需即時 |
| **範例** | 財務報表 | 預算、成本報告 |

**稅務會計**：以計算應納稅額為目的的會計，依照稅法規定編製。

---

## 複式記帳法

每一筆交易同時記錄在**借方**與**貸方**，確保會計恆等式始終平衡。

```
基本會計恆等式：
資產 = 負債 + 股東權益
```

**借方增加的科目**：資產、費用
**貸方增加的科目**：負債、股東權益、收益

```
範例：提供服務，收取現金 $10,000

（借）現金       $10,000
（貸）營業收入   $10,000
→ 資產增加 = 收益增加（會計恆等式維持平衡）
```

<Callout type="tip">
**複式記帳的核心邏輯**：每筆交易必然同時影響兩個或以上的會計科目，且借方合計永遠等於貸方合計。這不只是記帳技術，更是一種對企業經濟實質的如實反映。
</Callout>

## 會計基本假設

1. **個體假設**：企業是獨立的經濟個體，有別於其所有者
2. **持續經營假設**：企業在可預見的未來將持續運作
3. **貨幣計量假設**：只記錄可以用貨幣衡量的經濟活動
4. **會計期間假設**：企業的生命可劃分為特定時間段（月、季、年）進行報告

## 財務報表的種類

| 財務報表 | 內容 |
|---------|------|
| **資產負債表** | 特定時點的資產、負債與股東權益 |
| **損益表** | 特定期間的收益、費用與利潤 |
| **現金流量表** | 特定期間的現金流入與流出 |
| **股東權益變動表** | 特定期間股東權益的變動 |
| **財務報表附註** | 財務報表項目的詳細說明 |

## IFRS概念框架的質量特徵

**基本質量特徵**：
- **攸關性**：能影響使用者決策的資訊
- **如實呈現**：完整性、中立性、無重大錯誤

**增強質量特徵**：
- 可比性、可驗證性、及時性、可理解性

---

## 重點整理

**複式記帳原理** ★★★★★
: 每筆交易以相等金額同時記錄於借方與貸方。借方合計永遠等於貸方合計。
*記憶口訣：資產、費用借方增 / 負債、權益、收益貸方增*

**基本會計恆等式** ★★★★★
: 資產 = 負債 + 股東權益。所有財務報表編製的基礎。
*記憶口訣：A = L + E*

**持續經營假設** ★★★★☆
: 假設企業將持續運作而不清算。是折舊計提與長期資產估值的基礎。

## 練習題

**Q. 財務會計與管理會計最重要的差異是什麼？**
> 財務會計是依GAAP/IFRS準則向利益關係人進行的正式對外報告；管理會計是以管理層決策為目的的非正式內部報告，無固定格式要求。財務會計側重歷史資訊；管理會計兼含前瞻性預測。

**Q. 企業以現金 $1,000 購入辦公設備。請記錄分錄。**
> （借）辦公設備（資產）\$1,000 /（貸）現金（資產）\$1,000。資產組成改變（現金減少、設備增加），會計恆等式維持平衡。
