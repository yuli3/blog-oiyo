# 旅行預算計算器

制定旅行預算是行程規劃的第一步。按類別細分支出——而非粗略估算——可以避免回國後的財務驚喜。

## 各目的地人均每日預算參考（新台幣）

| 目的地 | 經濟型 | 舒適型 | 豪華型 |
|---|---|---|---|
| 東南亞（泰國、越南等） | NT$600–1,200 | NT$1,500–2,800 | NT$5,000+ |
| 日本 | NT$1,500–2,500 | NT$3,000–5,000 | NT$9,000+ |
| 歐洲 | NT$2,200–3,500 | NT$4,500–7,000 | NT$14,000+ |
| 台灣（國內） | NT$800–1,500 | NT$2,000–3,500 | NT$6,000+ |
| 美國 | NT$2,500–4,000 | NT$6,000–9,000 | NT$16,000+ |
| 韓國 | NT$1,200–2,000 | NT$3,000–5,000 | NT$9,000+ |

*含住宿、餐飲及當地交通，不含國際機票*

## 省錢攻略

<Callout type="tip">
**機票**：提前6–10週預訂。週二、週三出發通常較便宜。使用KAYAK、Google Flights或Skyscanner的「整月視圖」找到最優價格日期。
</Callout>

| 類別 | 省錢方法 |
|---|---|
| 機票 | 提前預訂、使用里程、避開連假 |
| 住宿 | 民宿/青旅、稍遠離市中心 |
| 餐飲 | 當地市場、便利商店、午間套餐 |
| 交通 | 日票/週票、YouBike、步行 |
| 貨幣 | 使用Wise或當地ATM換匯，避免機場換匯 |

## 預算分配建議（佔總預算比例）

| 類別 | 建議比例 |
|---|---|
| 機票 | 30–40% |
| 住宿 | 20–30% |
| 餐飲 | 15–20% |
| 當地交通 | 10–15% |
| 景點門票/活動 | 5–10% |
| 購物/紀念品 | 5–10% |
| 應急備用金 | 10%（必備！） |

<Callout type="warning">
**旅遊保險不可或缺。**它能覆蓋醫療緊急情況、行李遺失和航班延誤——標準國際旅遊保險通常每次只需NT$300–600。
</Callout>
