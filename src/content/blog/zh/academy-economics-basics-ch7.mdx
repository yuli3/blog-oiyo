# 经济学导论 — GDP是在市场中度量的最终产出，而不是福利

宏观经济学的起点不是"国家成绩单"，而是**一定时期内、一国领土之内、按市场价格计算的最终产品和服务**。计入什么、剔除什么，正是面试题的陷阱所在。

## 1. 支出、生产和收入从三个侧面看同一个循环

<FormulaBox
  label="支出法"
  formula="Y = C + I + G + (X-M)"
  description="C为家庭消费，I为设备、建筑和存货变动，G为政府消费和投资(不含转移支付)，X−M为净出口。"
/>

买小麦做面包时，小麦是中间产品，不直接计入GDP，它已经包含在面包价格中。作为存货剩下的小麦计为投资(存货增加)。二手商品不是当期生产的，只有差价可能作为服务计入。转移支付(失业救济)不属于G。

第1年名义GDP:苹果10个×1000韩元+梨5个×2000韩元=20000韩元。第2年:苹果12×1200+梨5×2200=25400韩元。按基年价格计算的第2年实际GDP为$12×1000+5×2000$=22000韩元。增长率是10%，而不是27%。

<FormulaBox
  label="GDP平减指数"
  formula="\text{平减指数} = \text{名义GDP} / \text{实际GDP} \times 100"
  description="本例中为25400/22000×100≈115.5。物价上涨约15.5%，数量增加10%。"
/>

CPI是固定篮子的消费者价格，平减指数则反映全部国内生产的当前构成。进口消费品在CPI中有，在平减指数中的比重却很小。"通胀率是多少"其实是选择哪个指数的问题。

## 2. GDP不计算的东西

家庭内生产、环境破坏、闲暇、分配和黑市，要么被遗漏，要么被错误计入。污染若带来治理支出，GDP反而可能上升。不要把增长率公告当作福利改善来解读。

潜在GDP是不引起通胀加速的产出水平。实际GDP低于它，就是(负的)产出缺口;高于它，就是过热。周期是围绕趋势的波动;若把每次原因各不相同的冲击(需求冲击、供给冲击)都叫作"衰退"，政策就会出错。在供给冲击导致的衰退中只刺激需求，只会推高物价。

## 3. 失业不是增长的反面，而是另一种流量

失业率是求职者占劳动力的比例。若人们放弃求职，分子和分母同时缩小，失业率看起来可能更低。就业率可以弥补这一错觉。奥肯定律是经验上的相关关系，而不是恒等式。

<Callout type="warning">
不要在名义增长高的年份写"经济很好"。油价推高进口价格时，名义数字膨胀，实际产出却可能停滞。反之，在通缩阶段，名义工资冻结就是实际工资上涨。一定要同时看价格指数。
</Callout>

国民总收入(GNI)加上了来自国外的净要素收入。对于从海外工厂获得大量股息的国家，GNI可能比GDP更有意义。选择指标本身就是分析的一部分。

## 练习题

公务员工资10万亿韩元和失业救济10万亿韩元都计入GDP吗?工资属于政府消费(生产)，计入;失业救济是转移支付，不计入。领取者用这笔钱消费时，会通过C间接计入。把两个10万亿都加到G里，就是重复计算和错误分类。
