# 踩油门前必须完成的“10分钟护钱”攻略

节假日开开心心在神州租车或一嗨租车下单，还车时却因为几道划痕被扣除上千元押金？又或是在瓜子、人人车看二手车时被二手车贩子忽悠得云里雾里？其实只要在拿到钥匙后花仅仅10分钟做好这套**现场查验清单**，你就能省下这笔冤枉钱。

---

## 🚗 第一部分：租车交接前的10分钟清单

就算工作人员把钥匙递给你说“车况很好，直接开吧”，也**绝对不要立刻点火出发**。

### 📸 强制性录像（视频）取证流程
- [ ] **前保险杠底部：** 站着是看不见的！必须蹲下来，用手机录像扫过车头下方。这里是被路肩刮蹭最多的重灾区。
- [ ] **全车轮毂与轮胎：** 轮毂边缘的刮伤（俗称“马路牙子吻痕”）是扯皮最多的地方，四个轮子必须全部给特写。
- [ ] **后视镜外壳：** 经过限宽门或狭窄小巷极易受损的位置。
- [ ] **车顶后方区域：** 特别是租SUV时绝不能漏看！有没有被树枝或冰雹砸出的凹陷。
- [ ] **仪表盘留底：** 拍下出发前的精确油量（或剩余电量）及公里数。

<Callout type="warning">
**为什么拍视频 > 拍照片？** <br/>
用4K清晰度围绕车身缓慢绕行一圈录制视频，绝无死角。如果验车员为了赶时间说“那个小划痕不影响的”，一定要把这句话的声音也录进这个核验视频里作为免责金牌。
</Callout>

### 📄 合同条款与保险避坑
- [ ] **尊享服务（不计免赔）：** 如果你只买了基础保险，发生事故需承担前1500元修理费。对新手来说，花几十块钱买“尊享免赔”是必须的。
- [ ] **停运损失费与贬值费：** 这是最大的坑！即使买了不计免赔，有些小租车行仍会收取“修车期间车辆无法出租的损失费”。务必确认合同里是否100%免除了停运损失。

## 🚙 第二部分：二手车线下看车（防坑）清单

车商的话术再好听，也不如你亲眼所见的这5个细节。

- [ ] **水泡车验证（安全带与点烟器）：** 将安全带用力拉到最尽头！如果尽头有发霉、泥沙或难以忍受的霉味，哪怕价格再低也绝对不要碰。用手机手电筒照一下点烟器内部是否有严重生锈。
- [ ] **事故车验证（螺丝掉漆）：** 打开引擎盖，看翼子板和水箱框架连接处的固定螺丝。如果螺丝表面的原厂车漆被拧掉或有明显扳手扭伤的痕迹，说明这块区域必然因为撞击更换过配件。
- [ ] **空调异味及霉菌测试：** 将空调温度调到最低，风量开到最大。如果有呛鼻的酸腐味或土腥味，蒸发箱已被霉菌占领。
- [ ] **机油渗漏观察：** 试驾一圈后，看看车原来停靠的地砖上有没有黑色的油滴。如果有，说明发动机或变速箱存在漏油隐患。
- [ ] **查维保与出险记录：** 永远不要相信车商的口头“零事故”承诺。通过微信小程序（如“查博士”或“蚂蚁看车”），输入VIN码（车架号），花二三十块钱拉取全部的4S店维修保养记录和保险出险记录！这是撕开套路的终极武器。
