# 宏观经济学 — 物价一变动，IS-LM中的一个点就成了总需求曲线

[第4章](/zh/education-economics-ch14/)的IS-LM把物价固定。物价上升时，同样名义货币量的实际购买力$M/P$下降，LM左移，产出减少。把物价与产出的这种关系连起来，就是**总需求(AD)曲线**。再加上表示企业在各物价水平上生产多少的**总供给(AS)曲线**，物价和产出就同时被决定。

## 1. 总需求曲线的推导

在第4章的经济中(IS:$Y=410-10r$，货币需求$0.5Y-20r$)，设名义货币量$M=180$，把物价$P$留作变量，则LM为$180/P=0.5Y-20r$。与IS联立消去$r$:

<FormulaBox
  label="总需求曲线"
  formula="Y = 328 + \frac{72}{P}"
  description="P = 1时Y = 400(第4章的均衡)，P = 1.2时为388，P = 0.8时为418。物价上升使实际余额减少、利率上升、投资减少(凯恩斯效应)。"
/>

沿AD曲线的**移动**是由物价变化引起的，AD曲线本身的**移动**则由政府支出、税收、名义货币量、预期等因素引起。名义货币量增加10%时，AD变为$Y=328+79.2/P$，这条曲线在物价1.1时实现同样的产出400。


### 一、总需求曲线的一般式与斜率

把上式改写成参数形式，就能看出什么决定AD的斜率。从IS $Y=\frac{1}{1-c}(\bar A-br)$ 和LM $M/P=kY-hr$ 中消去 $r$，得

<FormulaBox
  label="参数形式的总需求曲线"
  formula="Y=\frac{\bar A+\frac{b}{h}\cdot\frac{M}{P}}{(1-c)+\frac{bk}{h}}"
  description="这一经济中Ā=82、c=0.8、b=2、k=0.5、h=20，分母为0.25，于是Y = 328 + 0.4·(M/P)。M=180时即为上面的Y = 328 + 72/P。"
/>

物价上升使 $M/P$ 减少，其效应经系数 $\frac{b/h}{(1-c)+bk/h}$ 传到产出。投资对利率不敏感（$b$ 小）或货币需求对利率很敏感（$h$ 大）时，该系数变小，AD**更陡**。在流动性陷阱（$h\to\infty$）的极端情形下，物价下降、实际余额增加也不能使利率下降，AD变为垂直——这时仅靠物价下跌无法摆脱衰退（[第15章](/zh/education-economics-ch26/)）。
## 2. 短期总供给与长期总供给

**长期**内工资和价格都会调整，产出停留在由劳动、资本、技术决定的潜在产出$Y^*$。长期总供给(LRAS)在$Y^*$处垂直。

**短期**内，由于名义工资合同、菜单成本和不完全信息，价格不会立即调整。物价高于预期时，企业增加生产。

<FormulaBox
  label="短期总供给"
  formula="P = P^e + \frac{1}{\alpha}\,(Y - Y^*)"
  description="P^e为预期物价。只有实际物价高于预期时，产出才会超过潜在水平。预期赶上实际物价后，SRAS上移，产出回到Y*。"
/>

设$Y^*=400$，$P^e=1$，斜率$1/\alpha=0.002$。

## 3. 货币扩张的短期与长期

名义货币量增加10%时:

- **短期**:新的AD与原有SRAS的交点为$Y\approx 406.2$，$P\approx 1.012$。产出大幅增加，物价略有上升。
- **长期**:人们看到物价上涨而提高预期物价，SRAS上移。预期物价达到1.1时，新均衡为$Y=400$，$P=1.1$。产出回到潜在水平，只有物价恰好上涨10%。

名义货币量在长期内无法改变实际变量(产出、就业)、只改变物价的性质，称为**货币的长期中性**。短期效果有多大、持续多久，取决于SRAS的斜率和预期调整的速度。这一调整路径在[第15章](/zh/education-economics-ch26/)中进一步讨论。

## 4. 四种冲击

<LectureTable
  title="各种冲击的短期与长期结果"
  headers={["冲击", "短期(Y, P)", "长期"]}
  rows={[

    ["总需求减少", "Y↓ P↓", "Y = Y*，P↓(调整缓慢则衰退漫长)"],
    ["不利供给冲击(油价↑)", "Y↓ P↑(滞胀)", "若是暂时的则恢复原状，若是永久的则Y*下降"],
    ["有利供给冲击(生产率↑)", "Y↑ P↓", "Y*上升"],
  ]}
/>

不利的供给冲击使政策当局陷入两难。扩大总需求以保产出，物价会进一步上涨；压缩总需求以抑制物价，衰退会加深。20世纪70年代的石油危机就是这种情况，应对的选择见[第10章](/zh/education-economics-ch21/)和[第13章](/zh/education-economics-ch24/)。

<Callout type="warning">
垂直的长期总供给并不意味着"政策无效"，而是指产出**水平**在长期内与总需求无关。提高潜在产出本身的增长是[第11、12章](/zh/education-economics-ch22/)的主题。此外，若忽视短期价格粘性、用垂直的AS解读所有衰退，就会把总需求不足造成的失业误判为"自然的"。反过来，若忽视长期调整，就会误以为扩大总需求能永远增加产出。
</Callout>


### 一、用数字看供给冲击的两难

## 练习题

**问题1.** 在上述经济中名义货币量增加20%，长期均衡在哪里？

**解答.** 长期 $Y=400$，AD为 $Y=328+86.4/P$，由 $86.4/P=72$ 得 $P=1.2$。物价恰好上涨20%。实际余额 $M/P=216/1.2=180$ 回到原水平，利率和投资也恢复原状。

**问题2.** 其他条件不变，若货币需求的利率敏感度加倍为 $h=40$，在名义货币量180下物价从1升到1.1时，AD上的产出减少多少？与原经济（$h=20$）比较。

**解答.** 分母为 $0.2+2\times0.5/40=0.225$，系数为 $(2/40)/0.225\approx0.222$，所以AD为 $Y\approx364.4+40/P$。物价为1时产出404.4，为1.1时400.8，约减少3.6。原经济中减少 $72-72/1.1\approx6.5$，可见货币需求对利率越敏感，AD越陡。
