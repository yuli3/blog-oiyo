# 十二生肖性格與運勢

中國傳統的十二生肖以12年為一個輪回，與十天干組合形成60年一循環的干支曆法。每個生肖都有獨特的性格特質和人生主題。

## 十二生肖速查表

| 生肖 | 近期年份 | 五行 | 核心特質 |
|---|---|---|---|
| 🐭 **鼠** | 2020、2008、1996 | 水 | 機智、靈活、善於理財 |
| 🐂 **牛** | 2021、2009、1997 | 土 | 勤勞、可靠、意志堅定 |
| 🐯 **虎** | 2022、2010、1998 | 木 | 勇敢、魄力強、天生領袖 |
| 🐰 **兔** | 2023、2011、1999 | 木 | 溫和、機敏、優雅 |
| 🐲 **龍** | 2024、2012、2000 | 土 | 有魅力、有雄心、精力充沛 |
| 🐍 **蛇** | 2025、2013、2001 | 火 | 直覺強、神秘、有智慧 |
| 🐴 **馬** | 2026、2014、2002 | 火 | 活力四射、自由奔放 |
| 🐑 **羊** | 2027、2015、2003 | 土 | 溫柔、有創造力、喜愛和平 |

| 🐓 **雞** | 2029、2017、2005 | 金 | 觀察力強、勤奮、誠實 |

| 🐷 **豬** | 2031、2019、2007 | 水 | 寬厚、真誠、享受生活 |

<Callout type="note">
生肖基於農曆年份，而非西曆。每年的「換生肖」在農曆正月初一（即農曆新年），而非元旦。因此，1月底至2月初出生的人需特別確認自己屬於哪一年的生肖。
</Callout>
