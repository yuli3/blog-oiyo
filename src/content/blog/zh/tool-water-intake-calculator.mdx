# 飲水量計算器

人體約**60–70%由水構成**。僅僅2%的脫水就會影響認知功能。然而大多數人飲水不足——不是因為缺乏意志力，而是缺乏規律。

## 不同人群每日飲水需求

| 人群 | 每日參考飲水量 |
|---|---|
| 久坐成人（70kg） | 約2.0–2.5公升 |
| 活躍成人（70kg，運動1小時） | 約2.5–3.0公升 |
| 孕婦 | 額外+0.3公升 |
| 哺乳期女性 | 額外+0.7公升 |
| 高溫/高濕環境 | 額外+0.5–1.0公升 |

<Callout type="tip">
**實用法則**：每公斤體重約35ml。70kg成人：70×35=2450ml。每小時中等強度運動額外補充400–600ml。
</Callout>

## 全天喝水時間表

| 時間 | 建議水量 | 原因 |
|---|---|---|
| 起床後 | 250–500ml | 補充睡眠期間流失的水分 |
| 餐前 | 250ml | 助消化，適當控制食慾 |
| 下午（14–16點） | 300–500ml | 自然能量低谷期 |
| 運動前 | 500ml | 預防抽筋 |
| 運動後 | 400–700ml | 補充出汗流失 |
| 睡前1小時 | 最多150ml | 避免夜間起床 |

<Callout type="note">
一次性喝超過500ml反而適得其反。**每1–2小時喝200ml**的吸收效率更高。在手機設定每2小時提醒，養成喝水習慣並不難。
</Callout>
