# 貨幣換算器

出行換匯前了解真實匯率，每筆交易都能省下幾個百分點。機場換匯、銀行、境外刷卡——每種方式都有隱藏成本。

## 各換匯方式實際成本

| 方式 | 典型手續費 | 說明 |
|---|---|---|
| 機場換匯 | 5–15% | 除非緊急，盡量避免 |
| 傳統銀行 | 2–4% | 通常還有固定手續費 |
| 普通銀行卡刷卡 | 1.5–3% | 每筆交易收取 |
| Wise / 玉山外幣帳戶 | 0–0.5% | 接近銀行間匯率 |
| 當地ATM提款 | 1–2% | 通常優於現場換匯 |

<Callout type="tip">
**出行建議**：使用Wise、玉山全球通等低手續費卡片境外消費。在當地ATM提款通常比換匯更划算。避免商家提供的「台幣結算」選項（DCC），匯率通常很差。
</Callout>

## 主要貨幣對

| 貨幣對 | 波動性 | 主要用途 |
|---|---|---|
| TWD/USD | 中低等 | 赴美旅行、貿易 |
| TWD/JPY | 中等 | 赴日旅行（台灣最熱門） |
| TWD/EUR | 中等 | 赴歐旅行、貿易 |
| TWD/KRW | 中等 | 赴韓旅行 |
| TWD/HKD | 低 | 港澳出行 |

<Callout type="note">
此處顯示的匯率為市場參考匯率。實際換匯時銀行或換匯機構會加收手續費或買賣價差。具體匯率請以各機構為準。
</Callout>
