# 小費計算器

小費文化因國而異。在美國被視為禮貌的金額，在日本可能被視為冒犯。本工具幫您避免文化失禮，輕鬆搞定小費計算和分帳。

## 各國小費習慣

| 國家/地區 | 通常比例 | 說明 |
|---|---|---|
| **美國 / 加拿大** | 15–20%（最低） | 服務員薪資依賴小費，文化上必須給 |
| **台灣** | 通常不給 | 高檔餐廳/飯店服務費已含在帳單 |
| **香港** | 10%（如未含） | 帳單通常已含服務費 |
| **日本 / 韓國** | 不給（可能冒犯） | 服務價格已含在帳單中 |
| **歐洲** | 取整+5–10%（自願） | 法國、西班牙已含服務費 |
| **泰國 / 東南亞** | 10–15%（觀光區） | 依當地習慣而定 |

<Callout type="note">
在台灣，大部分餐廳帳單已含10%服務費，無需額外給小費。但若是較高級的西餐廳或飯店，對服務人員表示感謝可適當給予。
</Callout>

## 如何公平AA分帳

| 方式 | 優點 | 缺點 |
|---|---|---|
| 平均分 | 簡單快捷 | 各人消費差異大時不公平 |
| 按消費比例 | 公平精確 | 計算麻煩 |
| 輪流請客 | 長期來看划算，增進感情 | 需要互信 |
| 分帳App（Splitwise、Tricount） | 自動記錄欠款 | 需要安裝 |
