## 什么是发展心理学

发展心理学研究人从出生到死亡之间如何变化，涵盖身体、认知、情绪与社会性等各个层面。

```
核心问题：
- 成长是连续的，还是分阶段的？
- 遗传（nature）与环境（nurture），哪一个更重要？
- 推动变化的动力是什么？
```

## 皮亚杰的认知发展阶段

让·皮亚杰（Jean Piaget）主张，儿童不是被动接受知识，而是主动地建构知识。

```
第一阶段：感知运动期（0～2 岁）
→ 用五感与身体动作探索世界
→ 关键是客体永久性（看不见了也依然存在）

第二阶段：前运算期（2～7 岁）
→ 语言发展，象征性思维萌芽
→ 自我中心（难以站在他人视角）

第三阶段：具体运算期（7～11 岁）
→ 具备逻辑思维（获得守恒概念）
→ 能够分类与排序

第四阶段：形式运算期（12 岁～）
→ 能进行抽象与假设性思考
→ 科学推理逐渐发展
```

## 埃里克森的心理社会发展

埃里克·埃里克森没有把发展看作止于童年的事，而是提出了贯穿一生的八阶段理论。

| 阶段 | 年龄 | 核心冲突 | 达成的品质 |
|------|------|------|------|
| 1 | 0～1 岁 | 信任 vs 不信任 | 希望 |
| 2 | 1～3 岁 | 自主 vs 羞怯怀疑 | 意志 |
| 3 | 3～6 岁 | 主动 vs 内疚 | 目的 |
| 4 | 6～12 岁 | 勤奋 vs 自卑 | 能力 |
| 5 | 青春期 | 同一性 vs 角色混乱 | 忠诚 |
| 6 | 成年早期 | 亲密 vs 孤独 | 爱 |
| 7 | 中年期 | 繁衍 vs 停滞 | 关怀 |
| 8 | 老年期 | 自我整合 vs 绝望 | 智慧 |

## 依恋理论

约翰·鲍尔比（John Bowlby）的依恋理论认为，婴儿与照料者之间建立的情感纽带，是日后一切发展的基础。

```
玛丽·安斯沃思的依恋类型（陌生情境实验）：

安全型（约 60%）：
- 照料者离开时会不安，回来后很快平静下来
- 在照料者持续给予回应时形成

焦虑型（约 20%）：
- 分离时表现出极度不安
- 重聚之后仍有愤怒与黏人的表现

回避型（约 15%）：
- 无论分离还是重聚都几乎没有反应
- 在照料者拒绝或冷淡时形成

混乱型（约 5%）：
- 反应缺乏一致性
- 在虐待或忽视的环境中形成
```

## 语言的发展

```
0～6 个月：开始咿呀学语
12 个月：第一个词（妈妈、爸爸）
18～24 个月：词汇爆发 — 掌握的词量骤增
2 岁：双词句（"还要"、"要饭饭"）
3～4 岁：开始掌握语法规则
5 岁：能组织出接近成人的句子

乔姆斯基的语言习得装置（LAD）：
→ 人天生具备学习语言的能力
→ 主张普遍语法的存在
```

## 青春期 — 同一性的形成

```
马西亚的同一性状态理论：

同一性获得：经过探索之后作出承诺
→ 最健康的状态

延缓：正在探索之中，尚未决定
→ 虽有不安，却处在成长途中

早闭：未经探索就作出承诺（直接接受父母的价值）
→ 容易变得僵化

同一性弥散：既无探索也无承诺
→ 可能引发发展上的问题
```

## 成年期与老年期

```
成年早期（20～40 岁）：
- 建立亲密关系（埃里克森第六阶段）
- 确立职业上的身份
- 大脑可塑性依然很高

中年期（40～60 岁）：
- 繁衍 vs 停滞的冲突
- 中年危机：重新审视人生的意义
- 晶体智力增长（基于经验的问题解决）

老年期（60 岁～）：
- 自我整合：接纳人生的整体
- 晶体智力得以保持，流体智力下降
- 社会情绪选择理论：把重心收拢到有意义的关系上
```

## 需要记住的要点

*皮亚杰：感知运动 → 前运算 → 具体运算 → 形式运算*
*埃里克森：八阶段冲突 — 信任·自主·主动·勤奋·同一性·亲密·繁衍·整合*
*依恋类型：安全（60%）／焦虑（20%）／回避（15%）／混乱（5%）*
*流体智力（随年龄下降） vs 晶体智力（随经验增长）*
