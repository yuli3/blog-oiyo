## 认知心理学的诞生

1960 年代的"认知革命"——心理学从只处理刺激与反应的行为主义中走出，开始用科学方法研究记忆、思维、语言、问题解决这些内在的心理过程。

```
核心比喻：人的心灵 = 信息加工系统
输入 → 加工 → 输出
```

---

## 记忆的结构 — 阿特金森-希夫林模型

通常所说的"多重存储模型"，准确地讲是**阿特金森-希夫林模型（Atkinson–Shiffrin model）**。
它由理查德·阿特金森（Richard C. Atkinson）与理查德·希夫林（Richard Shiffrin）于 1968 年提出，
把记忆划分为感觉记忆 → 短时记忆 → 长时记忆这三级存储来加以说明。
信息不会自动进入下一阶段：必须被**注意**才能进入短时记忆，必须经过**复述与编码**才能转入长时记忆。

```
感觉记忆（Sensory Memory）：
→ 保持时间：0.5～3 秒
→ 容量：非常大，但迅速消失
→ 视觉：图像记忆 ／ 听觉：回声记忆

短时记忆（Short-Term Memory）：
→ 保持时间：15～30 秒（若无复述）
→ 容量：7±2 个组块（米勒定律）
→ 只有被注意到的信息才能进入

长时记忆（Long-Term Memory）：
→ 保持时间：几乎没有上限
→ 容量：事实上没有上限
→ 分为陈述性记忆与程序性记忆
```

## 工作记忆 — 巴德利模型

这是对短时记忆更为精细的刻画。

前面提到的阿特金森-希夫林模型，是信息单向流动的简单串行模型，
因而无法说明在短时记忆内部保持并操作信息的过程。巴德利模型正是弥补了这一局限。

```
中央执行系统（Central Executive）：
→ 注意的控制、策略的选择、计划

语音回路（Phonological Loop）：
→ 加工言语信息
→ "脑海中的声音"

视空间模板（Visuospatial Sketchpad）：
→ 加工视觉与空间信息
→ 心理地图、意象旋转

情景缓冲区（Episodic Buffer）：
→ 与长时记忆相连接

→ 工作记忆容量与智力、学习能力密切相关
```

## 长时记忆的分类

```
陈述性记忆（外显记忆）：
  语义记忆：关于世界的知识（"巴黎是法国的首都"）
  情景记忆：个人的经历（"去年的生日聚会"）

程序性记忆（内隐记忆）：
  技能与习惯：骑自行车、打字
  启动效应：先前经验在无意识中影响之后的反应
```

## 遗忘的成因

```
衰退说：不使用，记忆痕迹就会变弱

干扰说：
- 前摄干扰：先前的学习妨碍新的学习
  （学过英语之后，学中文时英语会来捣乱）
- 倒摄干扰：新的学习妨碍此前的记忆

提取失败：记忆还在，却因缺少线索而想不起来
→ 舌尖现象（话到嘴边说不出来）

艾宾浩斯遗忘曲线：
学习后 20 分钟 → 保持 42%
1 小时后 → 遗忘 56%
1 天后 → 遗忘 67%
→ 分散学习（间隔重复）更为有效
```

## 注意 — 选择与集中

```
选择性注意：
鸡尾酒会效应 — 在嘈杂的场合也能听见自己的名字

双加工理论：
系统 1：快速、自动、直觉（无意识）
系统 2：缓慢、有意识、逻辑（需要有意的努力）
→ 日常判断绝大多数由系统 1 承担

非注意盲视（Inattentional Blindness）：
大猩猩实验 — 不加注意，眼前的东西也看不见
```

## 认知偏差与决策

来自卡尼曼与特沃斯基的研究。

```
可得性启发式：
→ 越容易想起来的事，越被判断为常见
→ 空难 vs 车祸 — 人更怕坐飞机，实际上开车危险得多

代表性启发式：
→ 只要符合典型形象，就判断其概率高
→ 忽略基础比率

确认偏误：
→ 只搜集能印证自己信念的信息
→ 无视反面证据

损失厌恶：
→ 得到 100 万元的喜悦 &lt; 失去 100 万元的痛苦（约 2.5 倍）
```

## 问题解决与创造力

```
问题解决的策略：
算法：系统而可靠（耗时较长）
启发式：快速但可能出错

顿悟（Insight）：
→ 忽然到来的"啊哈！"体验
→ 信息的重新组织

创造力的 4P：
Person（有创造力的个人）
Process（创造的过程）
Press（有创造性的环境）
Product（创造的成果）
```

## 需要记住的要点

*记忆结构：感觉记忆（秒）→ 短时记忆（30 秒，7±2）→ 长时记忆（无上限）*
*工作记忆：中央执行系统 + 语音回路 + 视空间模板*
*遗忘：衰退·干扰·提取失败 — 用分散学习来克服*
*系统 1（直觉·快） vs 系统 2（逻辑·慢） — 偏差产生于系统 1*
