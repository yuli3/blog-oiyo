# 宏观经济学 — 乘数是上限，不是承诺

在[第5章](/zh/education-economics-ch16/)中，我们用凯恩斯交叉图计算了均衡产出和乘数。本章要看的是:这一均衡**如何**达到，乘数实际上按什么顺序累积，以及在什么条件下乘数会变小甚至消失。在价格不会马上变动的短期内，决定产出的是**有效需求**，即实际会被支出的需求。

## 1. 存货调整产出

计划支出$AE$与实际产出$Y$不一致时，差额表现为**非计划的存货变动**。

    ["310", "310", "0", "保持"],

产出高于均衡时，存货堆积，企业减产;低于均衡时，存货减少，企业增产。调整的是**数量**而不是价格，这是凯恩斯短期模型的核心。国民账户把非计划存货变动也计入投资，因此事后总有$Y=C+I+G+NX$成立。均衡条件是**计划**支出等于产出。

## 2. 乘数逐轮累积

政府支出增加10万亿韩元，这10万亿韩元成为某人的收入;若MPC为0.8，其中8万亿韩元被消费，又成为另一人的收入。

## 3. 漏出使乘数缩小

每一轮收入增量中没有回到消费的部分就是**漏出**。不仅储蓄，税收和进口也是漏出。

<FormulaBox
  label="包含漏出的乘数"
  formula="k = \frac{1}{1 - c(1-t) + m}"
  description="c = 0.8、边际税率t = 0.25、边际进口倾向m = 0.2时，k = 1/(1 − 0.6 + 0.2) ≈ 1.67，是无漏出时5的三分之一。"
/>

经济越小、越开放，进口倾向越高，乘数越小——刺激效果有一部分漏到了贸易伙伴国。这也是多个国家同时刺激时，彼此出口增加、各国效果变大的原因。

## 4. 节俭悖论

如果所有家庭同时想多储蓄，会怎样?设上述经济中的自发消费$c_0$从20降到10(家庭想多储蓄10万亿韩元)。新均衡为$Y=52/0.2=260$万亿韩元，减少了50万亿。可支配收入为250万亿时，消费为$10+0.8\times 250=210$万亿，私人储蓄为$250-210=40$万亿。原均衡的私人储蓄也是$300-260=40$万亿。**想多储蓄，结果只是收入减少，储蓄不变。**

由恒等式$S_p=I+(G-T)+NX$可知，若投资和财政固定，私人储蓄无法增加。对个人合理的增加储蓄，对整个经济只会减少收入——这就是**合成谬误**。

反之，当利率被困在下限、没有挤出，闲置产能和失业多，受流动性约束的家庭多时，乘数会变大。这就是金融危机后的研究报告衰退期和利率下限期财政乘数更大的原因。

<Callout type="warning">
"政府支出1韩元使GDP增加乘数倍"不是一般命题，而是以存在闲置资源、利率固定和封闭经济为前提的比较静态结论。节俭悖论也是需求不足的短期情形。在接近充分就业的长期，储蓄是投资和资本积累的资金来源([第11章](/zh/education-economics-ch22/))。
</Callout>

## 练习题

在MPC为0.8、边际税率为0.25、进口倾向为0的经济中，10万亿韩元政府支出对产出和税收的影响是多少?乘数为$1/(1-0.6)=2.5$，因此产出增加25万亿韩元，税收增加$0.25\times 25=6.25$万亿。财政赤字增加的不是10万亿，而是3.75万亿。若边际税率为0，产出效应为50万亿韩元。
