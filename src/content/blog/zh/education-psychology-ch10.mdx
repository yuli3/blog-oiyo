## 重申心理学的核心原则

```
原则 1：行为都有原因
→ 看似冲动的行为，同样是生物、心理与社会因素共同的产物

原则 2：遗传与环境都很重要
→ Nature vs Nurture → 如今是 Nature AND Nurture
→ 基因给出可能性，环境把这份可能性变成现实

原则 3：只有科学方法能把迷信区分出来
→ 随机对照实验 > 个案 > 直觉

原则 4：人容易受认知偏差影响
→ 需要养成怀疑系统 1 快速判断的习惯
```

## 关系中的心理学

### 好感与吸引

```
邻近效应：距离越近，好感越强
单纯曝光效应：见得越多，越容易喜欢
相似性：人被与自己相似的人吸引
互惠性：对方喜欢自己，自己也会喜欢对方

斯滕伯格的爱情三角：
→ 激情 + 亲密 + 承诺 = 完满的爱
→ 三者的均衡决定关系的质量
```

### 冲突化解

```
戈特曼的研究 — 预测离婚的四骑士：
1. 批评：攻击性格与人格
2. 蔑视：讥讽、冷嘲热讽
3. 防御：为自己辩解、反击
4. 筑墙：情感上的抽离

→ 蔑视的毒性最强
→ 用"我"讯息取代批评
```

## 职场中的心理学

### 激励

```
内在动机 vs 外在动机：
→ 过度的外部奖赏反而削弱内在动机（过度理由效应）

心理安全感（艾米·埃德蒙森）：
→ 在团队中即使犯错也不会有危险的感觉
→ 创新与学习的前提条件
→ 谷歌"亚里士多德计划"：影响团队绩效的第一要素

心流（Csikszentmihalyi）：
→ 挑战 = 能力水平时，生产力最高
→ 需要明确的目标与即时的反馈
```

### 决策

```
防止群体思维：
→ 指定一位"魔鬼代言人"
→ 有意识地收集多元观点
→ 善用匿名投票

克服确认偏误：
→ 设立反证假设（"如果我的想法是错的呢？"）
→ 事前验尸（Premortem）：预先想象失败的情形
```

## 健康与心理学

```
压力与健康：
塞利耶的 GAS（一般适应综合征）：
警觉 → 抵抗 → 衰竭

皮质醇长期偏高 → 免疫力下降、记忆受损

心理神经免疫学：
→ 心理状态直接影响免疫功能
→ 积极情绪 → 激活 NK 细胞

强化心理韧性：
→ 建立社会支持网络
→ 寻找意义（意义治疗）
→ 实践正念
```

## 心理学学习到此告一段落

心理学是理解人的工具。

```
心理学能给你的：

自我理解：
→ 理解自己情绪与行为模式的成因
→ 意识到改变是可能的

理解他人：
→ 减少评判
→ 看见行为背后隐藏的脉络

更好的决策：
→ 意识到认知偏差 → 判断更为理性
→ 理解群体动力 → 成为更好的团队成员

心理韧性：
→ 把压力与逆境转化为成长的机会
→ 实践经科学验证的幸福策略
```

*理解人，正是一趟理解自己的旅程。*
