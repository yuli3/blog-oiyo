# 紀念日計算器

手動計算紀念日容易出錯——每月天數不同，還要考慮閏年。只需**輸入一個起始日期**，計算器會自動幫您算好所有重要紀念日。

**計算的紀念日：**
- 22天、50天、100天、200天、300天——短期里程碑
- 500天、1000天——中期里程碑
- 1周年、2周年、3周年、5周年、10周年——年度紀念

## 適用場景

| 起始日期 | 使用示例 |
|---|---|
| 交往開始日 | 情侶紀念日（100天、周年） |
| 到職日期 | 工作周年紀念 |
| 生日 | 個人里程碑計算 |
| 創業日期 | 公司周年紀念 |
| 寵物到家日 | 毛孩紀念日 |
| 戒菸/健身開始日 | 勵志里程碑追蹤 |

<Callout type="tip">
**倒數計時**：臨近紀念日時，計算器顯示**距今D−N天**。已過的紀念日作為歷史記錄保留，方便回顧。如需設置目標日期倒數，可搭配使用[D-Day計算器](/zh/tool-dday-calculator)。
</Callout>
