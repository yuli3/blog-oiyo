# 学习宇宙的第一张地图

宇宙科学之所以显得困难，是因为名词太多：太阳、行星、卫星、小行星、彗星、恒星、星云、星系、黑洞。入门时不必先死记硬背，可以先用**尺度、引力和能量**来整理。

## 1. 什么是太阳系

太阳系的中心不是地球，而是**太阳**。太阳的引力把行星、卫星、矮行星、小行星和彗星连接成一个系统。

| 天体 | 含义 | 例子 |
| --- | --- | --- |
| 恒星 | 通过核聚变发光的天体 | 太阳 |
| 行星 | 围绕恒星运行的大型天体 | 地球、火星、木星 |
| 卫星 | 围绕行星运行的天体 | 月球、欧罗巴 |
| 矮行星 | 类似行星但没有清理轨道的天体 | 冥王星 |
| 彗星 | 含冰和尘埃、靠近太阳时可能出现尾巴的天体 | 哈雷彗星 |

## 2. 行星可以分成两类

水星、金星、地球和火星是内侧的岩石行星。木星、土星是气态巨行星，天王星和海王星常被称为冰巨行星。

这个分类能解释为什么有些星球适合着陆探测，而有些星球更适合研究大气、环、磁场和卫星。

## 3. 太阳为什么发光

太阳不是普通的火球。它是一颗由**核聚变**供能的恒星。太阳核心把氢聚变成氦，并释放能量。光和热到达地球后，驱动天气、海洋循环、光合作用和生命节律。

## 4. 恒星也有生命周期

恒星诞生于气体和尘埃云。引力让物质聚集，温度和压力升高，核聚变开始。最关键的变量是质量：质量越大的恒星越明亮，也越短命。

恒星最后可能成为白矮星、中子星或黑洞。

## 5. 什么是黑洞

黑洞不是宇宙吸尘器。重点是**逃逸速度**。在事件视界以内，连光也很难逃离。

| 术语 | 含义 |
| --- | --- |
| 事件视界 | 逃离变得不可能的边界 |
| 奇点 | 理论上密度极端的中心 |
| 吸积盘 | 围绕黑洞高速旋转并发热的物质 |

学习顺序可以是：地球和月球、太阳系、恒星、星系、黑洞，最后进入宇宙学。科学不会消除神秘感，它会让神秘变得更清晰。
