## 财务报表分析的重要性

财务报表分析在CFA Level I中占**11~14%**的权重，是最重要的科目之一。理解三大财务报表的构成与联系，是进行企业估值和投资决策的基础。

---

## 三大财务报表

### 资产负债表（Balance Sheet）

**会计恒等式**：资产 = 负债 + 所有者权益

| 项目 | 内容 |
|------|------|
| 流动资产 | 现金、应收账款、存货（1年内变现） |
| 非流动资产 | 固定资产、无形资产、长期投资 |
| 流动负债 | 应付账款、短期借款、预收款项 |
| 非流动负债 | 长期借款、递延税款 |
| 所有者权益 | 股本 + 留存收益 |

### 利润表（Income Statement）

**营业收入 → 毛利润 → 营业利润 → 税前利润 → 净利润**

关键公式：
- **毛利率** = 毛利润 / 营业收入
- **净利率** = 净利润 / 营业收入
- **EBITDA** = 净利润 + 所得税 + 利息费用 + 折旧摊销

### 现金流量表（Cash Flow Statement）

| 活动类别 | 内容 |
|---------|------|
| 经营活动 | 核心业务现金流入流出 |
| 投资活动 | 资本支出、资产购置/处置 |
| 筹资活动 | 借款、还款、股息、股权融资 |

**自由现金流（FCF）** = 经营活动现金流 − 资本支出

## 关键财务比率

### 盈利能力
| 比率 | 公式 |
|------|------|
| ROE | 净利润 / 平均股东权益 |
| ROA | 净利润 / 平均总资产 |
| 毛利率 | 毛利润 / 营业收入 |

### 流动性
| 比率 | 公式 |
|------|------|
| 流动比率 | 流动资产 / 流动负债 |
| 速动比率 | (流动资产 − 存货) / 流动负债 |

### 杠杆
| 比率 | 公式 |
|------|------|
| 资产负债率 | 总负债 / 总资产 |
| 利息保障倍数 | EBIT / 利息费用 |

### 杜邦分析（DuPont Analysis）
**ROE = 净利率 × 资产周转率 × 权益乘数**

## IFRS vs. US GAAP 关键差异

| 项目 | IFRS | US GAAP |
|------|------|--------|
| 存货计价 | 禁止LIFO | 允许LIFO |
| 研发支出 | 开发阶段可资本化 | 全部费用化 |
| 固定资产 | 允许重估价值 | 历史成本 |
| 收入确认 | 五步模型（与US GAAP趋同） | 与IFRS趋同 |

## 考点提示

- DuPont分析三因素分解：利润率×效率×杠杆
- LIFO在价格上涨时：COGS更高，净利润更低，存货更低
- FCF = CFO − CapEx（最常见考法）
- ROE > ROA说明公司有财务杠杆
