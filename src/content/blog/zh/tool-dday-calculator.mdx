# D-Day计算器

无论是备考、出行还是纪念日，精确知道距目标还有多少天，能把模糊的目标变成清晰的倒数计时——这是最简单的自我激励方式之一。

## 常见使用场景

| 场景 | 示例 |
|---|---|
| 考试备考 | 学测、指考、国考 |
| 出行计划 | 出发日期、签证到期、订票截止日 |
| 健康目标 | 戒烟100天、健身打卡目标 |
| 情侣纪念 | 周年纪念、求婚计划 |
| 工作专案 | 专案截止日、合约到期 |
| 个人生活 | 生日、婚礼、搬家日 |

<Callout type="tip">
**效率小技巧**：将D-Day用于反向规划。如果目标在90天后，从终点往前推：D−60（中间检查点）、D−30（最终确认）、D−7（最后准备）。
</Callout>
