# D-Day計算器

無論是備考、出行還是紀念日，精確知道距目標還有多少天，能把模糊的目標變成清晰的倒數計時——這是最簡單的自我激勵方式之一。

## 常見使用場景

| 場景 | 示例 |
|---|---|
| 考試備考 | 學測、指考、國考 |
| 出行計畫 | 出發日期、簽證到期、訂票截止日 |
| 健康目標 | 戒菸100天、健身打卡目標 |
| 情侶紀念 | 周年紀念、求婚計畫 |
| 工作專案 | 專案截止日、合約到期 |
| 個人生活 | 生日、婚禮、搬家日 |

<Callout type="tip">
**效率小技巧**：將D-Day用於反向規劃。如果目標在90天後，從終點往前推：D−60（中間檢查點）、D−30（最終確認）、D−7（最後準備）。
</Callout>
