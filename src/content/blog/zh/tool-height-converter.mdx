# 身高換算器

美國、英國等英語國家用英尺英寸表示身高，而非公分。本工具讓換算變得簡單直接。

## 換算公式

```
1英尺 = 30.48公分
1英寸 = 2.54公分
1英尺 = 12英寸

公分 → 英尺：[身高cm] ÷ 30.48
英尺 → 公分：[英尺] × 30.48 + [英寸] × 2.54
```
