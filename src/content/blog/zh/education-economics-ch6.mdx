# 微观经济学 — 竞争的长期均衡是经济利润为零，而不是会计利润为零

第5章的单个企业在$P=MC$处生产，价格低于AVC最低点时停产。本章考察由许多这样的企业组成的市场。短期内企业数量固定，长期内利润吸引进入，亏损导致退出。

单个企业面对的需求曲线在市场价格处是水平的，因为哪怕稍微提价也会失去全部顾客。所以$MR=P$。

## 2. 短期行业供给是各企业供给的水平加总

设有100家企业，每家$MC=2q$(万韩元)，$AVC=q$。一家企业的供给为$P=2q$，即$q=P/2$(在AVC以上)。在同一价格下把数量相加，行业供给为$Q=100\times P/2=50P$。

若需求为$Q=200-10P$，由$50P=200-10P$得$P=10/3\approx 3.33$万韩元，$Q\approx 166.7$。每家企业产量约1.67，此时AVC ≈ 1.67万韩元 < 3.33万韩元，所以所有企业都生产。

## 3. 长期:进入把价格推到最低平均成本

利润为正时，新企业进入，供给增加，价格下降；亏损时，企业退出，供给减少，价格上升。当价格等于所有企业的最低平均成本时，调整停止。

  description="企业在P = MC处最优生产，经济利润为零，每家企业都在平均成本最低的规模上生产。"

**经济利润为零**不是会计利润为零。ATC中包含所有者投入的资本和时间的机会成本(正常利润)。即使账面上有利润，只要这一利润等于把资源投向别处的收益，经济利润就为零。

来看所有企业成本相同、投入品价格与行业规模无关的**成本不变行业**。若最低ATC为40韩元(每家企业产量4)，市场需求为$P=120-Q$，长期均衡为$P=40$韩元，$Q=80$，企业数20家。

假设需求增至$P=140-Q$。若现有20家企业的短期供给为$P=40+(Q-80)/2$，则

- **短期**:由$140-Q=40+(Q-80)/2$得$Q\approx 93.3$，$P\approx 46.7$韩元。现有企业获得利润。
- **长期**:利润吸引进入，价格回到40韩元。数量为$140-40=100$，企业数变为25家。

## 4. 竞争为何有效率

在长期竞争均衡中，两种效率同时成立。

- **配置效率**:$P=MC$。消费者对最后一单位的支付意愿等于其生产成本，没有无谓损失。
- **生产效率**:$P=\min ATC$。每家企业都以最便宜的规模生产。

第7章的垄断违背前者，第8章的垄断竞争违背后者。不过，这是假定没有外部性和信息问题的局部均衡结论。第10章将放松这些条件。

<Callout type="warning">
自由进入并不只是法律不禁止进入。如果执照、区位、品牌、网络效应构成事实上的壁垒，即使存在利润也不会有进入。此外，若各企业成本不同，长期内成本低的企业也能获得正利润(租金)。常被当作完全竞争例子的农产品市场，也因质量差异和信息不对称而不能完全满足条件。
</Callout>

## 练习题

$P=30$韩元、$MC=2Q$、$AVC=Q$的竞争企业，最优产量是多少?由$30=2Q$得$Q=15$。AVC为15韩元 < 30韩元，因此生产。若固定成本为100韩元，ATC为$15+100/15\approx 21.7$韩元，每单位利润约8.3韩元，总利润为$30\times 15-(100+225)=125$韩元。这一利润吸引进入，价格就会下降。
