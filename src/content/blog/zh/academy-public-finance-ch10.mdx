# 财政学综合 — 把一项政策从头到尾走一遍

前面九章逐一介绍了各种工具。现实的政策问题会按顺序用到所有这些工具。本章以碳税为例，依次追问:"为什么要干预 → 谁来负担 → 扭曲有多大 → 税收用在哪里 → 值不值得做"。其中的数字是为说明结构而作的假设。

## 1. 为什么要干预(第1章)

温室气体排放是典型的负外部性。损害分散在全世界和未来世代，受害者太多，科斯式谈判无法进行。按第1章的结论，基准是等于边际外部成本的**庇古税**。

设每吨碳的边际损害(碳的社会成本)为5万韩元。燃烧1升汽油约排放2.3千克二氧化碳，因此每升的税额为$0.0023\times 50{,}000\approx 115$韩元。

## 2. 谁来负担(第2章)

在韩国这样的小型开放经济中，原油供给在国际价格上几乎完全有弹性。按第2章的公式，供给弹性非常大时，消费者负担比例$\varepsilon_s/(\varepsilon_s+|\varepsilon_d|)$接近1。每升115韩元的大部分会体现在消费者价格上。

按收入阶层看，能源支出占年收入的比重低收入家庭更高，所以单看税收是**累退的**。若低收入家庭每年负担20万韩元、高收入家庭每年负担60万韩元，绝对额是高收入阶层大，但占收入的比例是低收入阶层高。

## 3. 扭曲有多大(第2章、第5章)

设汽油需求的短期价格弹性为$-0.2$。在1700韩元的价格上加115韩元(约6.8%)，消费约减少1.4%。矫正税的目的正是这种减少。按第1章的逻辑，因矫正税而减少的交易是社会成本大于收益的交易，所以若税率等于边际损害，这种减少不是超额负担，而是**福利收益**。

超额负担产生于别处。按第5章的税收交互效应，能源价格上涨会降低实际工资，对劳动供给造成少许扭曲。此外，若运输、工业和家庭适用不同税率，减少同样1吨排放的成本在各部门之间就会不同，产生无法从最便宜的减排做起的低效率。碳税在**所有排放源适用同一税率**时最有效率。

## 4. 税收用在哪里(第3章、第4章、第6章)

若年排放6亿吨中有5亿吨纳入征税范围，每吨5万韩元，税收为25万亿韩元。使用方式不同，政策的性质也不同。

来算一算均等返还。把25万亿韩元分给5000万人，每人每年50万韩元。上一节中的低收入家庭(负担20万韩元)若为2人家庭，可领取100万韩元，净收益80万韩元;高收入家庭(负担60万韩元)若也是2人，净收益40万韩元。负担高于人均返还额的高排放家庭则承担净负担。由于这种结构把企业缴纳的税也分给了家庭，本例中大多数家庭都是净受益者，实际分布取决于各家庭的直接和间接排放。即使税收本身是累退的，**把税收和返还合在一起的政策也可能是累进的**。正如第3章的教训，分配从支出一侧来纠正成本最低。

## 5. 值不值得做(第9章)

放进成本收益分析的框架，收益是减排量乘以碳的社会成本，成本是减排所耗费的资源(更贵的能源和设备)加上税收交互效应带来的超额负担。由于收益在数十年间逐步显现，第9章贴现率的选择对结论影响很大。碳的社会成本估计值本身就会因贴现率不同而相差数倍。

按第7章的原则，地方政府的作用有限。这是收益外溢到整个地球的公共物品，地方层面的碳税容易定得过低;只有一个地区征税，排放就会转移到其他地区(碳泄漏)。边境碳调节就是把同样的逻辑应用到国家层面。

<Callout type="warning">
在碳税争论中，"它是累退的"和"它会搞垮经济"往往撇开税收用途不谈。反过来，"有双重红利，所以是免费的"又撇开了税收交互效应。只有按本章的顺序把干预依据、归宿、扭曲、税收用途和净收益全部写出来，政策评价才算完整。
</Callout>
