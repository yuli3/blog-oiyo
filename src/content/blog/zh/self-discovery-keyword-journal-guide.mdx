# 喜欢的关键词，是贴近日常的自我介绍

性格测试有帮助，但日常的喜欢常常更诚实。说话、说服、倾听、组装、观察。喜欢的饮料、洗澡后吹到的风、温暖衣物的味道、家里的安心气味。这些细节不是小事，它们说明什么样的注意力会让你恢复能量。

## 1. 从动词开始

名词说明你喜欢什么，动词说明你如何行动。

| 关键词 | 可能的含义 |
| --- | --- |
| 说话 | 你通过表达来整理思路 |
| 说服 | 你喜欢理解他人的逻辑和需求 |
| 倾听 | 你重视关系的温度和语境 |
| 组装 | 你喜欢把抽象的东西变成可触摸的成果 |
| 观察 | 你习惯先看模式和差异，再下判断 |

为每个动词写三个真实场景。不要急着得出职业结论，先记录具体生活。

## 2. 收集小幸福

幸福越小，越容易被安排进今天。

- 喜欢的饮料
- 洗澡后的风
- 温暖衣物的味道
- 熟悉的居家气味
- 一个按自己喜好整理的小角落

问自己：到底是什么让它舒服？温度、触感、气味、安静、记忆、节奏，还是身边的人？

## 3. 写下想见的人

想见的人往往指向价值：安全感、学习、感谢、修复，或还没说出口的话。写下名字、对方给过你的东西，以及现在想说的一句话。

## 4. 用喜欢的东西填满一天的一小块

不用一次改变整个人生。今天只选择一个喜欢的关键词，让它进入一个小行动。

- 动词：观察
- 行动：散步十分钟，找出三种颜色
- 空间：整理书桌一角
- 奖励：喝一杯喜欢的饮料

这不是固定的性格标签。人的倾向会随时间变化。比起“我永远是这样”，写“最近的我被这个吸引”会更准确。
