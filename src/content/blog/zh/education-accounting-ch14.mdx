[成本会计第13章](/zh/academy-cost-accounting-ch8/)的基本本量利分析假定只有一种产品、税前利润、需求确定。现实中的公司销售多种产品，要缴税，也无法确定销量。本章逐一放宽这三个假设，使本量利分析贴近实际决策。

## 1. 多种产品与销售组合

BN公司按数量3 : 1销售产品A（售价10万韩元，变动成本6万韩元）和产品B（售价8万韩元，变动成本6万韩元），共同固定成本1,400万韩元。

### 一、销售组合改变时

组合变为1 : 1时，加权平均边际贡献为$(4 + 2)/2 = 3$万韩元，保本点升至约467件。即使总销量相同，边际贡献低的B比重增大，利润也会减少。若只按销售额发放销售激励，组合可能偏向好卖的低毛利产品。

## 2. 税后目标利润

有所得税时，要把目标**税后**利润换算为税前利润来计算。

<FormulaBox
  label="实现税后目标利润的销量"

## 3. 敏感性分析

观察假设变化时结果波动多大。BN公司若把A的价格降低10%（10万 → 9万韩元），A的边际贡献变为3万韩元，加权平均边际贡献为$(3 \times 3 + 2)/4 = 2.75$万韩元，保本点约为509件。降价10%使保本点提高27%。如果没有把握降价后销量增长超过27%，降价就会减少利润。

## 4. 不确定性与期望值

销量不确定时，按各情景的概率求期望利润。BN公司在考虑是否投入300万韩元做新广告。不做广告，销量有50%概率为500件、50%概率为700件；做广告，50%概率为600件、50%概率为900件。

- 不做广告：期望销量600件，期望利润$600 \times 3.5 - 1{,}400 = 700$万韩元
- 做广告：期望销量750件，期望利润$750 \times 3.5 - 1{,}700 = 925$万韩元

广告的期望增量利润为225万韩元。但在最坏情景（600件）下利润为400万韩元，只比不做广告的最坏情景（500件，350万韩元）多50万韩元。厌恶风险的管理者不仅看期望值，还要看利润的方差和最坏结果。

<Callout type="warning">
多产品的保本点只有在**销售组合保持不变的假设**下才是一个确定的数字。实际组合会随季节、竞争和销售策略不断变化。而且，不把固定成本分为共同成本和专属成本，就无法计算各产品的保本点。本量利分析是线性近似，不要远远外推到计划范围之外。
</Callout>

## 练习题

BO公司按销售额60 : 40销售产品P（边际贡献率50%）和Q（边际贡献率30%）。固定成本2,100万韩元，税率25%。保本销售额和实现税后利润900万韩元所需的销售额各是多少？

加权平均边际贡献率为$0.6 \times 50\% + 0.4 \times 30\% = 42\%$。保本销售额为$2{,}100 / 0.42 = 5{,}000$万韩元。税后900万韩元所需的税前利润为$900 / 0.75 = 1{,}200$万韩元，所需销售额为$(2{,}100 + 1{,}200) / 0.42 ≈ 7{,}857$万韩元。
