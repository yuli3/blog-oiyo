## 資產負債表（Balance Sheet）

資產負債表是**時點報表**，呈現某一特定日期（如12月31日）企業的財務狀況。

```
資產 = 負債 + 股東權益
```

### 資產的分類

**流動資產**（預計一年內變現或使用）：
- 現金及約當現金
- 應收帳款（已銷售但尚未收款）
- 存貨（用於銷售的商品）
- 預付費用（已付但尚未耗用的費用）

**非流動資產**（使用期限超過一年）：
- 不動產、廠房及設備（PP&E）
- 無形資產（專利、商標、商譽）
- 長期投資

### 負債的分類

**流動負債**（一年內到期）：
- 應付帳款
- 短期借款
- 預收收益

**非流動負債**（超過一年到期）：
- 長期借款
- 應付公司債

### 股東權益的組成

- 股本（投入資本）
- 保留盈餘（累積未分配盈餘）
- 其他綜合損益

<Callout type="tip">
**流動性排列原則**：資產負債表中，資產通常依流動性由高至低排列（現金最先，固定資產最後）；負債依到期日由近至遠排列。這有助於讀者快速評估企業的短期償債能力。
</Callout>

## 損益表（Income Statement）

損益表是**期間報表**，呈現某一會計期間（如2024年全年）的經營成果。

```
收益 - 費用 = 淨利潤（或淨虧損）
```

### 損益表的結構

| 項目 | 說明 |
|------|------|
| **營業收益** | 銷售商品或提供服務的收入 |
| **銷售成本** | 直接與銷售相關的成本 |
| **毛利潤** | 營業收益 − 銷售成本 |
| **營業費用** | 銷售費用、管理費用等 |
| **營業利潤** | 毛利潤 − 營業費用 |
| **業外損益** | 利息收入/費用、投資損益等 |
| **稅前利潤** | 營業利潤 ± 業外損益 |
| **所得稅費用** | 依稅法計算的應納稅額 |
| **淨利潤** | 稅前利潤 − 所得稅費用 |

### 收益的認列原則

依IFRS 15，收益在**控制權轉移**給客戶時認列，而非收到現金時。

**5步驟收益認列模型**：
1. 識別與客戶的合約
2. 識別履約義務
3. 決定交易價格
4. 將交易價格分配給各履約義務
5. 於每項履約義務滿足時認列收益

## 兩份報表的關聯

資產負債表與損益表並非獨立，而是通過**保留盈餘**緊密相連：

```
期末保留盈餘 = 期初保留盈餘 + 本期淨利潤 − 股利
```

期間的損益，最終影響資產負債表中的股東權益餘額。這就是為什麼「財務報表必須整體閱讀」。

## 重點整理

**資產負債表** ★★★★★
: 時點報表，反映特定日期的財務狀況。公式：資產 = 負債 + 股東權益。

**流動性分類** ★★★★☆
: 流動資產/負債 = 一年內可轉換或到期；非流動 = 超過一年。是評估短期財務健康的關鍵。

**收益認列** ★★★★★
: 依IFRS，收益在控制權轉移時認列，而非收到現金時。現金基礎 vs 應計基礎的核心差異。

## 練習題

**Q. 為什麼說「資產負債表是時點報表，損益表是期間報表」？**
> 資產負債表像一張「快照」，呈現某特定日期（如12/31）的財務狀況；損益表像一部「影片」，記錄一段期間（如全年）的經營成果。兩者時間框架不同，各有其資訊價值。

**Q. 應收帳款歸類於資產負債表的哪個類別？為什麼？**
> 流動資產。應收帳款預計在一年內收回，具有短期變現能力，因此歸類為流動資產而非非流動資產。
