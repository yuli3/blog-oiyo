## 资产负债表（Balance Sheet）

资产负债表是**时点报表**，呈现某一特定日期（如12月31日）企业的财务状况。

```
资产 = 负债 + 股东权益
```

### 资产的分类

**流动资产**（预计一年内变现或使用）：
- 现金及约当现金
- 应收帐款（已销售但尚未收款）
- 存货（用于销售的商品）
- 预付费用（已付但尚未耗用的费用）

**非流动资产**（使用期限超过一年）：
- 不动产、厂房及设备（PP&E）
- 无形资产（专利、商标、商誉）
- 长期投资

### 负债的分类

**流动负债**（一年内到期）：
- 应付帐款
- 短期借款
- 预收收益

**非流动负债**（超过一年到期）：
- 长期借款
- 应付公司债

### 股东权益的组成

- 股本（投入资本）
- 保留盈余（累积未分配盈余）
- 其他综合损益

<Callout type="tip">
**流动性排列原则**：资产负债表中，资产通常依流动性由高至低排列（现金最先，固定资产最后）；负债依到期日由近至远排列。这有助于读者快速评估企业的短期偿债能力。
</Callout>

## 损益表（Income Statement）

损益表是**期间报表**，呈现某一会计期间（如2024年全年）的经营成果。

```
收益 - 费用 = 净利润（或净亏损）
```

### 损益表的结构

| 项目 | 说明 |
|------|------|
| **营业收益** | 销售商品或提供服务的收入 |
| **销售成本** | 直接与销售相关的成本 |
| **毛利润** | 营业收益 − 销售成本 |
| **营业费用** | 销售费用、管理费用等 |
| **营业利润** | 毛利润 − 营业费用 |
| **业外损益** | 利息收入/费用、投资损益等 |
| **税前利润** | 营业利润 ± 业外损益 |
| **所得税费用** | 依税法计算的应纳税额 |
| **净利润** | 税前利润 − 所得税费用 |

### 收益的认列原则

依IFRS 15，收益在**控制权转移**给客户时认列，而非收到现金时。

**5步骤收益认列模型**：
1. 识别与客户的合约
2. 识别履约义务
3. 决定交易价格
4. 将交易价格分配给各履约义务
5. 于每项履约义务满足时认列收益

## 两份报表的关联

资产负债表与损益表并非独立，而是通过**保留盈余**紧密相连：

```
期末保留盈余 = 期初保留盈余 + 本期净利润 − 股利
```

期间的损益，最终影响资产负债表中的股东权益余额。这就是为什么「财务报表必须整体阅读」。

## 重点整理

**资产负债表** ★★★★★
: 时点报表，反映特定日期的财务状况。公式：资产 = 负债 + 股东权益。

**流动性分类** ★★★★☆
: 流动资产/负债 = 一年内可转换或到期；非流动 = 超过一年。是评估短期财务健康的关键。

**收益认列** ★★★★★
: 依IFRS，收益在控制权转移时认列，而非收到现金时。现金基础 vs 应计基础的核心差异。

## 练习题

**Q. 为什么说「资产负债表是时点报表，损益表是期间报表」？**
> 资产负债表像一张「快照」，呈现某特定日期（如12/31）的财务状况；损益表像一部「影片」，记录一段期间（如全年）的经营成果。两者时间框架不同，各有其资讯价值。

**Q. 应收帐款归类于资产负债表的哪个类别？为什么？**
> 流动资产。应收帐款预计在一年内收回，具有短期变现能力，因此归类为流动资产而非非流动资产。
