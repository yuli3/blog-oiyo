NCS 필기에서 문제해결능력은 **14%** 비중으로 3위에 해당합니다. 50문항 기준 약 7문항. 암기 위주의 수리능력과 달리, 문제해결능력은 **개념 이해 + 적용**이 핵심입니다. 상황 설명 후 "가장 적절한 접근은?" 형태의 사례 문제가 많습니다.

## NCS 문제해결능력 구성

| 하위 능력 | 내용 | 출제 비중 |
|----------|------|---------|
| 사고력 | 창의적·논리적·비판적 사고 개념 | 40% |
| 문제처리능력 | 문제 정의→원인 분석→해결→평가 프로세스 | 60% |

## 1. 사고력: 세 가지 핵심 사고 유형

### 창의적 사고(Creative Thinking)

기존의 틀을 벗어나 새로운 방법을 찾는 사고.

**특성**: 유창성(많은 아이디어), 유연성(다양한 관점), 독창성(새로운 아이디어), 정교성(아이디어 발전)

**기법**
- **브레인스토밍(Brainstorming)**: 판단 없이 최대한 많은 아이디어 도출. 핵심 규칙: 비판 금지, 자유연상, 양이 질보다 우선, 결합·개선 환영
- **SCAMPER**: 대체(Substitute)·결합(Combine)·응용(Adapt)·수정/확대/축소(Modify/Magnify/Minify)·다른 용도(Put to other uses)·제거(Eliminate)·뒤집기(Rearrange)
- **마인드맵(Mind Map)**: 핵심 개념에서 방사형으로 아이디어 전개
- **6가지 모자 기법(Six Thinking Hats)**: 흰모자(사실), 빨간모자(감정), 검은모자(비판), 노란모자(긍정), 초록모자(창의), 파란모자(진행)

### 논리적 사고(Logical Thinking)

근거에 기반해 타당한 결론을 도출하는 사고.

**연역 추론**: 일반 원칙 → 특수한 사례
예: "모든 포유류는 폐호흡을 한다. 고래는 포유류다. → 고래는 폐호흡을 한다."

**귀납 추론**: 개별 사례들 → 일반 법칙
예: "A회사 직원들의 만족도가 높다. B회사도, C회사도... → 복지 좋은 회사는 만족도가 높다."

**유추 추론**: A와 B의 유사성으로 A의 특성을 B에 적용

### 비판적 사고(Critical Thinking)

정보를 객관적으로 평가하여 결론의 타당성을 검증하는 사고.

핵심 질문: "이 주장의 근거는 충분한가?", "대안적 설명은 없는가?", "어떤 가정이 숨어 있는가?"

## 2. 문제 정의: 문제의 유형 이해

### 발생형 문제 vs 탐색형 문제 vs 설정형 문제

| 유형 | 정의 | 예시 |
|------|------|------|
| **발생형 문제** | 이미 발생한 문제 (원상 복구 필요) | 생산 라인 고장, 고객 불만 발생 |
| **탐색형 문제** | 현재는 잘 돌아가지만 더 잘할 수 있는 문제 | 업무 프로세스 개선, 비용 절감 기회 |
| **설정형 문제** | 아직 발생하지 않았지만 미래 목표 설정 | 신규 사업 진출, 혁신 전략 수립 |

시험에서: "다음 상황은 어떤 유형의 문제인가?" 형태로 출제됩니다.

## 3. 원인 분석 기법

### 특성요인도 (Fishbone Diagram, 이시카와 다이어그램)

문제(물고기 머리)의 원인을 4M 또는 6M 범주로 분석.

**4M**: Man(사람), Machine(기기), Material(재료), Method(방법)

**6M**: 4M + Measurement(측정), Mother Nature/Environment(환경)

사용법: 문제를 오른쪽에 적고, 주요 원인 카테고리를 가지로 그린 뒤, 각 가지에 세부 원인을 추가합니다.

### 5Why 기법

"왜?"를 5번 반복하여 근본 원인(Root Cause)을 찾는 방법.

**예시**:
1. 왜 기계가 멈췄는가? → 과부하가 걸렸다
2. 왜 과부하가 걸렸는가? → 베어링이 제대로 윤활되지 않았다
3. 왜 윤활되지 않았는가? → 오일 펌프가 충분히 작동하지 않았다
4. 왜 오일 펌프가 충분하지 않았는가? → 펌프 축이 마모되었다
5. 왜 펌프 축이 마모되었는가? → **정기 점검 일정이 없었다** (근본 원인)

해결책: 정기 유지보수 일정표 수립

### SWOT 분석

| | 내부 요인 | 외부 요인 |
|--|---------|---------|
| 긍정 | **S**trengths (강점) | **O**pportunities (기회) |
| 부정 | **W**eaknesses (약점) | **T**hreats (위협) |

**SO 전략**: 강점으로 기회 활용 (공격적 전략)
**ST 전략**: 강점으로 위협 극복 (다양화 전략)
**WO 전략**: 약점 보완으로 기회 포착 (방향 전환 전략)
**WT 전략**: 약점 최소화, 위협 회피 (방어적 전략)

시험 출제 패턴: SWOT 분석표 제시 후 "가장 적절한 전략은?" 또는 "ST 전략에 해당하는 것은?"

## 4. 의사결정 기법

### 합리적 의사결정 모형 (6단계)

1. **문제 인식**: 현재 상태와 목표 상태의 차이 파악
2. **기준 설정**: 평가 기준과 각 기준의 중요도 결정
3. **대안 도출**: 가능한 해결 방안 목록 작성
4. **대안 평가**: 각 기준에 따라 대안별 점수 부여
5. **최선안 선택**: 총점이 높은 대안 선택
6. **실행 및 평가**: 실행 후 결과 모니터링

### 가중 평가 행렬 (Weighted Decision Matrix)

| 기준 | 가중치 | 대안 A | 대안 B | 대안 C |
|------|-------|-------|-------|-------|
| 비용 | 0.4 | 8점 | 6점 | 7점 |
| 품질 | 0.3 | 7점 | 9점 | 6점 |
| 속도 | 0.3 | 6점 | 7점 | 8점 |
| **총점** | | **7.1** | **7.2** | **7.0** |

각 대안의 총점 = Σ(가중치 × 점수)

대안 A 총점: 0.4×8 + 0.3×7 + 0.3×6 = 3.2 + 2.1 + 1.8 = **7.1**

## 5. 문제해결 프로세스 전체 흐름

```
문제 인식 → 문제 정의 → 원인 분석 → 해결안 도출 → 최선안 선택 → 실행 계획 → 실행 → 평가/피드백
```

### 단계별 핵심 도구

| 단계 | 주요 도구 |
|------|---------|
| 문제 정의 | SWOT 분석, 문제 유형 분류 |
| 원인 분석 | 특성요인도, 5Why, 파레토 분석 |
| 해결안 도출 | 브레인스토밍, SCAMPER, 마인드맵 |
| 최선안 선택 | 가중 평가 행렬, 비용-편익 분석 |
| 실행 계획 | 간트 차트, PERT |
| 평가 | KPI, 피드백 루프 |

## 6. 파레토 분석 (80/20 법칙)

전체 결과의 80%는 전체 원인의 20%에서 발생한다는 법칙.

**적용 예**: 고객 불만의 80%가 5개 항목에서 발생 → 이 5개 항목 우선 해결

시험에서: "다음 데이터에서 우선적으로 해결해야 할 항목을 파레토 원칙에 따라 선택하시오"

## 7. 자주 출제되는 문제 유형과 함정

### 함정 1: 창의적 사고 vs 논리적 사고 혼동
브레인스토밍은 **창의적 사고** 기법. 연역/귀납 추론은 **논리적 사고**.

### 함정 2: SWOT 전략 매칭 오류
SO전략: 강점(S) × 기회(O) → 공격적 확장
WT전략: 약점(W) × 위협(T) → 방어 및 회피

"강점으로 위협에 대응"은 **ST** 전략.
"약점을 보완해 기회를 잡는다"는 **WO** 전략.

### 함정 3: 5Why는 5번 정확히가 아님
5Why는 근본 원인에 도달할 때까지 반복하는 것. 반드시 5번이어야 하는 것은 아닙니다.
