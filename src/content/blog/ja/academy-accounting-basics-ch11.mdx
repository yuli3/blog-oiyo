[第1章](/ja/academy-financial-accounting-advanced-ch1/)の趨勢分析で、FA社の売掛金と在庫は売上高より速く増えた。この章ではそのシグナルを回転率と回転日数で確かめ、営業に縛られた現金の大きさを計算する（単位：億ウォン、1年365日）。

## 1. 運転資本

**正味運転資本**とは、営業に必要な流動資産から営業上の流動負債を差し引いた金額である。よく売掛金＋棚卸資産−買掛金で計算する。FA社は20X1年末$120 + 160 - 100 = 180$億ウォン、20X2年末$150 + 200 - 120 = 230$億ウォンで、50億ウォン増えた。この50億ウォンは利益を上げたのに現金として入ってこず、営業に縛られたお金である。正味運転資本の増加率は約28%で、売上高の増加率20%を上回る。

仕入債務回転率は本来、仕入高で計算すべきである。仕入高の資料がなければ売上原価で代用する。仕入高は売上原価＋期末在庫−期首在庫で推定できる（FA社は880億ウォン、回転日数45.6日）。

## 3. キャッシュ・コンバージョン・サイクル

<FormulaBox
  label="キャッシュ・コンバージョン・サイクル"
  formula="\text{CCC} = \text{DSO} + \text{DIO} - \text{DPO} = 41.1 + 78.2 - 47.8 = 71.5\text{日}"
  description="原材料の代金を払ってから顧客から現金を受け取るまでにかかる期間である。この間、会社は自分のお金か借りたお金で営業を支える。"
/>

20X1年は期首残高の資料がないので期末残高で比べてみると、DSO $120 / 1{,}000 \times 365 ≈ 43.8$日、DIO $160 / 720 \times 365 ≈ 81.1$日、DPO $100 / 720 \times 365 ≈ 50.7$日である。20X2年の期末残高基準では、DSO 45.6日、DIO 86.9日、DPO 52.1日である。同じ基準で比べると、売上債権と在庫の回転日数がともに長くなった。

## 4. 回転日数を金額に換える

回転日数が1日延びれば、その分だけ現金が余計に縛られる。

<FormulaBox
  label="回転日数の変化の現金効果"
  formula="\text{現金効果} = \Delta\text{回転日数} \times \frac{\text{年間売上高（または売上原価）}}{365}"
  description="FA社20X2年の売上高1日分は約3.29億ウォンである。売上債権の回転日数を45.6日から40日に縮めれば、約18.4億ウォンの現金が解放される。"
/>

在庫の回転日数を86.9日から75日に縮めれば、売上原価1日分約2.30億ウォン×11.9日≈27.4億ウォンが解放される。二つを合わせれば、正味運転資本の増加分50億ウォンの大部分を取り戻せる。運転資本管理は、新たな資金調達なしに現金を生み出す方法である。

<Callout type="warning">
回転率が高ければいつもよいわけではない。在庫を減らしすぎれば品切れで売上を失い、買掛金の支払いを無理に遅らせれば供給業者との関係が悪化したり割引の恩恵を失ったりする。また、期末だけ売掛金をファクタリングしたり在庫を減らしたりすると、期末残高基準の回転率が水増しされる。サプライヤー・ファイナンス（リバース・ファクタリング）は買掛金を増やしてDPOを長く見せるので、注記のサプライヤー・ファイナンス契約の開示を確認する（[会計原理第11章](/ja/academy-accounting-basics-ch4/)）。
</Callout>

## 確認問題

FD社の年間売上高は730億ウォン、売上原価は547.5億ウォンである。平均売掛金は100億ウォン、平均在庫は90億ウォン、平均買掛金は60億ウォンである。DSO、DIO、DPOとキャッシュ・コンバージョン・サイクルはいくらか。供給業者と交渉してDPOを10日延ばせば、現金はどれだけ増えるか。

売上高1日分は2億ウォン、売上原価1日分は1.5億ウォンである。DSOは$100 / 2 = 50$日、DIOは$90 / 1.5 = 60$日、DPOは$60 / 1.5 = 40$日である。キャッシュ・コンバージョン・サイクルは$50 + 60 - 40 = 70$日である。DPOを10日延ばせば買掛金が$10 \times 1.5 = 15$億ウォン増え、その分だけ現金が残る。
