## 会計とは何か

**会計（Accounting）** は、企業の経済活動を測定・記録・分類・要約し、情報利用者が判断できるように渡す情報システムです。

**会計の目的**: 利害関係者（株主・債権者・政府・経営）に **有用な財務情報** を提供する。

---

## 会計の分類

| 区分 | 財務会計 | 管理会計 |
|----------|--------------------|--------------------|
| **目的** | 外部報告 | 内部の意思決定 |
| **利用者** | 投資家、債権者、政府 | 経営、内部管理者 |
| **基準** | GAAP/IFRS 準拠 | 自由形式 |
| **報告周期** | 定期（四半期・半期・年） | 必要に応じて |
| **例** | 財務諸表 | 予算、原価報告 |

**税務会計**: 税額計算を目的とする会計。税法の規定に従う。

---

## 複式簿記

すべての取引を **借方** と **貸方** の両方に同時に記録し、会計等式が常に釣り合うようにする。

```
基本の会計等式:
資産 = 負債 + 純資産
```

**借方で増える勘定**: 資産、費用  
**貸方で増える勘定**: 負債、純資産、収益

```
例: 役務を提供し、現金10,000ドルを受け取る

（借）現金        10,000
（貸）収益        10,000
→ 資産増 = 収益増（等式は釣り合う）
```

---

## 基本の会計仮定

1. **企業実体**: 事業は所有者と別の実体
2. **継続企業**: 予見可能な将来、清算せず継続すると仮定する
3. **貨幣単位**: 経済活動は貨幣単位でのみ測定・記録する
4. **期間**: 事業の寿命を、報告のために区切られた期間に分けられる

---

## 財務諸表の種類

| 財務諸表 | 内容 |
|--------------------|---------|
| **貸借対照表** | 一時点の資産、負債、純資産 |
| **損益計算書** | 一期間の収益、費用、利益 |
| **キャッシュ・フロー計算書** | 一期間の現金の流入と流出 |
| **純資産変動計算書** | 一期間の純資産の変動 |
| **注記** | 項目の詳細説明 |

## 会計情報の質的特性（IFRS概念フレームワーク）

**基本的質的特性**:
- **関連性**: 利用者の意思決定に差を出し得る情報
- **忠実な表現**: 完全性、中立性、誤りのなさ

**補強する質的特性**:
- 比較可能性、検証可能性、適時性、理解可能性

## 概念カード

**複式の原則** ★★★★★  
: すべての取引を、借方と貸方に同額で記録する。借方合計は常に貸方合計に等しい。  
*記憶: 資産・費用は借方増 / 負債・純資産・収益は貸方増*

**基本の会計等式** ★★★★★  
: 資産 = 負債 + 純資産。すべての財務諸表作成の土台。  
*記憶: A = L + E*

**継続企業の仮定** ★★★★☆  
: 清算せず継続すると仮定する。減価償却と長期資産評価の根拠。  
*記憶: この仮定が無いと、資産は清算価値で評価する必要がある*

## 練習

**Q. 財務会計と管理会計のいちばん大きい差は何か。**  
> 財務会計は利害関係者への正式な外部報告で、GAAP/IFRSに従う。管理会計は経営判断のための非公式な内部報告で、必須形式はない。財務会計は過去情報に寄り、管理会計は先の見通しも含む。

**Q. 会社が事務機器を現金1,000ドルで買う。仕訳を記録せよ。**  
> （借）器具（資産）1,000 / （貸）現金（資産）1,000。資産の構成が変わる（現金減、器具増）。等式は保たれる。
