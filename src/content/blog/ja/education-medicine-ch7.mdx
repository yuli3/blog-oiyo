# 第7章：免疫学 — 自然免疫、獲得免疫、ワクチン

免疫系は体の防衛ネットワークです。物理的バリア、循環する細胞、分子シグナルが巧みに連携し、自己と非自己を区別して、宿主組織を傷つけることなく病原体を排除します。

## 自然免疫と獲得免疫

| 特徴 | 自然免疫 | 獲得免疫 |
|---|---|---|
| 速度 | 即時（数分〜数時間） | 遅い（数日〜数週間） |
| 特異性 | 非特異的（PAMPs・パターン認識） | 高い特異性（抗原特異的受容体） |
| 記憶 | なし | あり — ワクチンの基盤 |
| 主要細胞 | 好中球、マクロファージ、NK細胞、樹状細胞 | T リンパ球、B リンパ球 |
| 可溶性因子 | 補体、インターフェロン、サイトカイン | 抗体（免疫グロブリン） |

**パターン認識受容体（PRR）**：自然免疫細胞は、トル様受容体（TLR）を介してPAMPs（病原体関連分子パターン）と呼ばれる保存された微生物パターンを認識し、炎症を引き起こします。

## 獲得免疫：T 細胞と B 細胞

**T リンパ球**（胸腺で成熟）：
- **CD4⁺ ヘルパー T 細胞（Th）**：免疫応答を調整し、B 細胞や細胞傷害性 T 細胞を活性化し、サイトカイン（IL-2、IL-4、IFN-γ）を放出する。HIV は CD4⁺ 細胞を標的にする。
- **CD8⁺ 細胞傷害性 T 細胞（CTL）**：パーフォリン／グランザイムを介してウイルス感染細胞や腫瘍細胞を殺傷する
- **制御性 T 細胞（Treg）**：免疫応答を抑制し、自己免疫を防ぐ

**B リンパ球**（骨髄で成熟）：
- 活性化すると**形質細胞**（抗体産生工場）と**記憶 B 細胞**に分化する
- クラススイッチには T 細胞の助け（CD40L–CD40 相互作用）が必要

## 抗体の構造

抗体（免疫グロブリン、Ig）は Y 字型の糖タンパク質で以下を持つ：
- **可変領域**：抗原結合部位（Fab 領域）
- **定常領域**：抗体クラスとエフェクター機能を決定（Fc 領域）

| アイソタイプ | 主な役割 |
|---|---|
| IgG | 最も豊富；胎盤通過；二次応答 |
| IgM | 最初に産生される抗体（一次応答）；五量体 |
| IgA | 粘膜免疫（消化管、気道、母乳） |
| IgE | アレルギー反応；寄生虫への防御 |
| IgD | B 細胞受容体；B 細胞活性化に関与 |

## MHC（主要組織適合遺伝子複合体）

- **MHC クラス I**（すべての有核細胞上）：内因性抗原を CD8⁺ T 細胞に提示 — 「自己監視」
- **MHC クラス II**（APC 上：マクロファージ、樹状細胞、B 細胞）：外来抗原を CD4⁺ T 細胞に提示

## ワクチン：能動免疫と受動免疫

**能動免疫**：免疫系が自ら応答を生成する（自然感染またはワクチン接種）。長期持続する。

**受動免疫**：既製の抗体が個人に移転される（母体 IgG、IVIG、抗毒素）。即効性があるが一時的（半減期約 3〜4 週間）。

**ワクチンの種類：**
- **生ワクチン（弱毒化）**：MMR、水痘、黄熱病 — 強力で持続的な免疫；免疫抑制患者には禁忌
- **不活化ワクチン**：インフルエンザ（注射）、A 型肝炎、ポリオ（IPV） — 安全性が高いがブースターが必要
- **サブユニット／組換えワクチン**：B 型肝炎、無細胞性百日咳、HPV — 高度精製、副作用少
- **mRNA ワクチン**：COVID-19（ファイザー-ビオンテック、モデルナ）— 抗原タンパク質を産生するよう細胞に指示

## 自己免疫疾患

自己寛容が崩れると、免疫系が宿主組織を攻撃する：

| 疾患 | 自己抗体／メカニズム | 侵犯組織 |
|---|---|---|
| 関節リウマチ | 抗 CCP、RF | 滑膜 → 関節 |
| SLE | 抗 dsDNA、抗 Smith | 多臓器（腎臓、皮膚、中枢神経） |
| 1 型糖尿病 | 抗 GAD、抗 IA2 | 膵臓β細胞 |
| 橋本甲状腺炎 | 抗 TPO、抗サイログロブリン | 甲状腺 |
| 重症筋無力症 | 抗 AChR | 神経筋接合部 |
