# 生理周期計算機

生理周期を把握することはコンディション管理・旅行や行事の計画・妊活に大きく役立ちます。最終生理開始日と平均周期を入力するだけです。

## 生理周期の基本知識

**平均周期**：21〜35日（平均28日）  
**生理期間**：3〜7日  
**排卵日**：次回生理予定日の約14日前

| 段階 | 期間（28日周期） | 特徴 |
|---|---|---|
| 月経期 | 1〜5日 | 子宮内膜剥離・ホルモン最低 |
| 卵胞期 | 6〜13日 | エストロゲン上昇・活力増加 |
| 排卵期 | 14日前後 | 妊娠可能期のピーク・LH急上昇 |
| 黄体期 | 15〜28日 | プロゲステロン上昇・PMS開始 |

<Callout type="tip">
**妊娠可能期間**：排卵日の5日前＋排卵当日＋排卵後1日、合計約7日。精子は体内で3〜5日生存するため、排卵日前から妊娠可能期が始まります。
</Callout>

## 月経不順の基準

| 状態 | 基準 |
|---|---|
| 正常範囲 | 周期21〜35日・変動±7日以内 |
| 頻発月経 | 周期21日未満 |
| 稀発月経 | 周期35日以上 |
| 無月経 | 3ヶ月以上なし |
| 過多月経 | 経血量が過多（1時間でナプキン交換） |

<Callout type="warning">
この計算機は**平均周期に基づく予測**です。ストレス・体重変化・ホルモンバランスの乱れで実際の排卵日は変わる場合があります。妊活や避妊が必要な場合は、排卵検査薬の併用と婦人科への相談をお勧めします。
</Callout>

## PMS（月経前症候群）の管理

排卵後の黄体期（15〜28日）に多くの方がPMSを経験します。

- **身体症状**：乳房の圧痛・腹部膨満感・頭痛・倦怠感
- **精神症状**：イライラ・気分の落ち込み・集中力低下
- **緩和法**：定期的な有酸素運動・カフェイン・塩分の制限・十分な睡眠・マグネシウム補給
