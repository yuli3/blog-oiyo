# 経済学概論 — 消費者は限界で相対価格に合わせる

効用最大化とは「一番好きな組み合わせを買う」ことではない。**予算の上で**、ある財を少し多く買うために他の財を諦める比率が、市場の求める諦めの比率と等しくなる点である。

## 1. 内点解の1階の条件

無差別曲線の傾きの絶対値が限界代替率$\mathrm{MRS} = MU_{x}/MU_{y}$である。予算線の傾きの絶対値は$P_{x}/P_{y}$である。両者が接すれば、組み合わせを組み替えても効用はもう上がらない。

<FormulaBox
  label="消費者均衡(内点解)"
  formula="MRS = MUx / MUy = Px / Py"
  description="同じことを1ウォン当たりの限界効用で書けばMUx/Px = MUy/Py。ある財の1ウォン当たりの効用が大きければ、そちらに予算を移す。"
/>

$MU_{x}=10$、$MU_{y}=4$、$P_{x}$=2,000ウォン、$P_{y}$=1,000ウォンなら、1ウォン当たりの限界効用はそれぞれ1/200、1/250である。Xを増やしYを減らすべきである。限界効用逓減を仮定すれば、移すほど$MU_{x}$は下がり$MU_{y}$は上がって、等式が回復する。

完全代替財は無差別曲線が直線なので接点がなく、安い財だけを買う(端点解)。完全補完財は直角なので、固定比率でしか買わない。「常にMRS=価格比」は、内点解・凸の選好・正の消費量のもとでの文である。

## 2. 価格の変化は代替と所得に分かれる

Xの価格が上がると、二つのことが同時に起きる。相対価格がXに不利になってXを減らす**代替効果**と、実質所得が減って正常財なら両方を減らす**所得効果**である。劣等財なら、所得効果はXを増やす方向に働く。その所得効果が代替効果を上回ればギッフェン財になる。

観察された需要が右下がりだからといって、所得効果がないという意味ではない。ヒックス分解は元の無差別曲線に戻れるように補償し、スルツキー分解は元の組み合わせを買えるように補償する。試験問題がどちらの補償を使っているかを先に見る。

## 3. 効用の数字は順序がすべてかもしれない

序数的効用では、単調変換は同じ選好を残す。$u$と$\ln u$のMRSは同じである。「効用が10から20になったから2倍幸せ」は、基数的効用(リスク、期待効用)に進む前には誤りである。金融経済学のリスク・プレミアムはその次の段階である。

<Callout type="warning">
1ウォン当たりの限界効用の均等は、離散的な単位・分割できない財・数量の制約のもとでは等式で終わらない。整数個しか買えなければ不等式になり、配給ならシャドー・プライスがつく。現物支援が現金より効用が低くなりうる理由でもある。
</Callout>

労働供給は余暇と消費の選択である。賃金上昇の代替効果は労働を増やし、所得効果は余暇を増やす。後方屈曲的な労働供給は、この章の所得効果と代替効果と同じ文法である。

## 確認問題

二つの財の価格が同じで$MU_{x}=6$、$MU_{y}=6$なのに、Xだけを買っている。内点解か。MRS=1、価格比=1なので、1階の条件は満たされている。しかし、すでに端点にいるなら、その点が唯一かどうかは選好の形による。完全代替財なら、予算線上のすべての点が無差別かもしれない。条件が同じだからといって、内部の接点だと断定しない。
