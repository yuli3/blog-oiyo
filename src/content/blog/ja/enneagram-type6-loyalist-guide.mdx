エニアグラム6番タイプは**忠実者（The Loyalist）**または**守護者（The Guardian）**と呼ばれます。不確実性と潜在的な危険を警戒し、信頼できる人やシステムの中に安全を求めます。「世界は危険だ。信頼できるものに頼らなければならない」という信念が人生を導きます。

## 6番タイプ 核心プロフィール

| 項目 | 内容 |
|------|------|
| タイプ名 | 忠実者 / 守護者 |
| 基本的な欲求 | 安全・サポート・確信 |
| 基本的な恐れ | サポートされずひとりにされること |
| 核心的動機 | 安全を確保し信頼できるシステムを構築 |
| センター | 思考（頭）センター |
| 世界観 | 「危険がどこから来るかわからない。常に警戒しなければならない」 |

<Callout type="info">
**6番タイプの二つのパターン**:
- **恐怖指向型（Phobic 6）**: 危険を認識すると逃げたり回避します。より静かで従順に見えます。
- **反恐怖指向型（Counter-phobic 6）**: 恐れを正面から向き合います。極限スポーツや挑発的な行動として現れます。外から見ると8番のように見えることもあります。
</Callout>

## 性格特性

### 強み

**忠誠心と信頼性**: 一度信頼した人や組織には絶対的な忠誠を示します。「義理」の代名詞です。

**責任感**: 任された仕事を必ず完遂します。チームで最も頼れるメンバーです。

**リスク予測能力**: 問題が起きる前に潜在的な危険を把握します。優れたリスク管理者になります。

**ユーモア**: ストレスを和らげるためにユーモアを使う傾向があります。特有の自虐的なユーモアが魅力です。

**コミュニティ構築**: 共同体の中で人々をつなぎ結束させる能力が卓越しています。

### 弱み

**過度な心配**: まだ起きていないことを先回りして心配してエネルギーを消耗します。

**権威への両価感情**: 権威を必要としながらも権威を疑います。

**疑心**: 他者の動機をよく疑い、信頼を築くのに長い時間がかかります。

**決断障害**: 間違った決断への恐れで決断を先延ばしにする傾向があります。

## ウィングタイプ

### 5w6（五のウィングの六）

- より内向的で分析的
- 知識で不安を管理
- 学術・専門性の追求
- 静かで観察的

### 7w6（七のウィングの六）

- より外向的で社交的
- ユーモアと前向きさで不安を管理
- 楽しさと責任のバランス
- 活発で社交的

## ストレスと安全

| 状態 | 方向 | 特徴 |
|------|------|------|
| ストレス時 | → 3番（達成者） | 競争的になりイメージに執着 |
| 安全なとき | → 9番（平和主義者） | 穏やかで信頼し、くつろぐ |

## 恋愛パターン

### 恋愛の強み

- 一度信頼を与えると最高のパートナーになります
- パートナーを守り保護しようとする本能が強いです
- どんな困難も一緒に乗り越えようとします

### 恋愛の課題

- パートナーの忠誠心を頻繁にテストします
- 不安なとき過度に確認したり疑います
- 最初に信頼を築くのが非常に遅いです

### 理想のパートナー

6番に一貫した信頼を与えるパートナー。不安なときに安心させてくれるが、不確かなパートナーは6番を極度に不安にさせます。

## 6番タイプ 成長ガイド

1. **自分の内なる知恵を信頼しましょう**: 外部の権威より自分の判断を信じる練習をしましょう。
2. **心配と本当の危険を区別しましょう**: 心配の90%は起きません。
3. **不確実性を友にしましょう**: すべてをコントロールできないことを受け入れることが成長です。
4. **今この瞬間は安全です**: 未来の危険より現在の平和に集中しましょう。
