# 第12章: 予算制度と過程

予算制度は、環境の変化に応じて政府が志向する価値（統制、管理、計画、削減など）を反映しながら変化してきました。

---

## 1. 予算制度改革の流れ

| 制度                 | 重点価値          | 特徴                         | 短所                     |
| :------------------- | :---------------- | :--------------------------- | :----------------------- |
| **品目別 (LIBS)**    | 統制 (Control)    | 支出項目ごとの限度設定       | 結果の把握が困難、硬直的 |
| **成果主義 (PBS)**   | 管理 (Management) | 単位コスト × 業務量          | 業務量測定の難しさ       |
| **計画予算 (PPBS)**  | 計画 (Planning)   | 長期計画と予算を結合         | 意思決定の集権化         |
| **零ベース (ZBB)**   | 削減 (Reduction)  | 前年度予算を無視 (0ベース)   | 多大な時間と労力が必要   |
| **新成果主義 (OBB)** | 成果 (Outcomes)   | 投入より成果 (Outcomes) 重視 | 国家財政運用計画との連携 |

---

## 2. 予算の過程 (予算サイクル)

1. **予算編成 (政府)**: 各部署が要求書を提出し、財務当局が調整・確定する。
2. **予算審議 (議会)**: 施政方針演説 $\rightarrow$ 常任委員会予備審査 $\rightarrow$ 決算特別委員会総合審査 $\rightarrow$ 本会議議決。
3. **予算執行 (政府)**: 配分と再配分の過程を経て資金を使用。伸縮性維持の仕組み（流用、移用など）を活用。
4. **決算・会計検査**: 事後に予算執行の適法性を問う。監査機関が実施。

---

## 3. 予算執行の伸縮性維持制度

- **移用**: 立法科目（款・項）間の融通。 **議会の承認が必要**。
- **流用**: 行政科目（目・節）間の融通。 **政府内部の承認で可能**。
- **予備費**: 予測できない支出に充てるために、あらかじめ確保しておく資金。
