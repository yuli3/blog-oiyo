# 第10編. 経済安定政策の理論

## 第30章. 経済安定政策をめぐる論争

### 1. 経済学派の発展系統（試験必須暗記）

| 学派 | 形成のきっかけ／核心理論 | 政府と市場の観点 |
| --- | --- | --- |
| 古典派（マーシャル、ピグー） | セイの法則／価格の伸縮性 | 市場は完全、非自発的失業は存在しない |
| **ケインズ派（Keynes）** | 1930年代の大恐慌／有効需要の不足 | 市場は不完全、財政政策が必須 |
| マネタリズム（フリードマン） | 新貨幣数量説／K%ルール | 政策のタイムラグの誤りを批判、ルールを重視 |
| **新古典派（ルーカス）** | 合理的期待形成理論／実物景気循環 | 予想された政策 ＝ 実物効果ゼロ |
| **新ケインズ派（マンキュー）** | メニューコスト／効率賃金理論 | 合理的期待の受容 ＋ 価格硬直性のミクロ的正当化 |

### 2. フィリップス曲線（Phillips Curve）とスタグフレーション

フィリップス曲線は、**インフレ率と失業率の間の短期的なトレードオフ（Trade-off）**を示します。

- **需要ショック（拡張政策）**: 右下がりの短期フィリップス曲線上の移動 → 物価↑、失業率↓
- **供給ショック（オイルショックなど）**: 短期フィリップス曲線自体が右上方に移動 → 物価↑、失業率↑ ＝ **スタグフレーション（Stagflation）**

### 3. 自然失業率仮説と長期フィリップス曲線（フリードマン）

長期的に失業率は「自然失業率」の水準へと回帰 → 長期フィリップス曲線は**垂直線。**

# 第11編. 失業とインフレ

## 第31章. 失業理論

### 1. 失業の4つのタイプ

| タイプ | 原因 | 性格 |
| --- | --- | --- |
| **景気的失業** | 景気後退・不況（デフレギャップ） | 非自発的、ケインズが打破の対象に指定 |
| **構造的失業** | 産業構造の急激な転換、技術革新 | 非自発的、長期的な訓練が必要 |
| **季節的失業** | 農業・建設業などの季節的要因 | 非自発的、予測可能 |
| **摩擦的失業** | 離職・転職の過程における探索期間 | **自発的**、自然失業の一部 |

### 2. 新ケインズ派の「賃金の下方硬直性」の根拠

- **効率賃金理論（Efficiency Wage Theory）**: 賃金が労働の限界生産性を決定するという発想。企業は利潤最大化のために均衡賃金より高い「効率賃金」を自発的に支払う。
  - 目的：モラルハザードの防止、優秀な人材の流出防止（逆選択）、離職コストの削減。
  - 結果：超過労働供給（＝非自発的失業）があっても市場賃金は下落しない。

## 第32章. インフレの波及効果

### 1. 需要牽引型 vs コストインフレ型インフレ

| 区分 | 需要牽引型（Demand-Pull） | コストインフレ型（Cost-Push） |
| --- | --- | --- |
| 主な原因 | 通貨量の過多、財政支出の急増 | 賃金闘争、原材料価格の暴騰（原油価格） |
| AD-ASの変化 | AD曲線が**右側**に移動 | SRAS曲線が**左側**に移動 |
| 国民所得の様相 | 物価↑、国民所得↑（景気好転を伴う） | 物価↑、国民所得↓（スタグフレーション） |
| 政府の処方箋 | 総需要抑制政策が効果的 | 解決が困難。構造改善・為替安定が急務 |

### 2. 予想された vs 予想できなかったインフレのコスト

**予想されたインフレ**が発生するコスト：

- **靴底コスト（Shoe-leather cost）**: 保有現金を減らすために銀行を頻繁に訪れる手間のコスト。
- **メニューコスト（Menu cost）**: 継続的な価格変動の通知を更新しなければならない物理的コスト。

**予想できなかったインフレ → 富の強制移転：**

| 有利なグループ | 不利なグループ |
| --- | --- |
| 債務者（借金の負担が軽減） | 債権者（貨幣価値が暴落） |
| 不動産・実物資産の保有者 | 固定金利・年金の受給者 |
| 政府（税収が実質的に増加） | 給与生活者（実質賃金の下落） |

<Callout type="note" title="発展：インフレ税（Inflation Tax）">
  過度な財政拡張の手段として中央銀行が通貨を発行しすぎるとき、インフレを強制的に引き起こして民間の実質的な貨幣購買力を目減りさせる。これを**インフレ税（Inflation Tax）**と呼び、政府は実質的にインフレを通じて税金を徴収する効果を享受する。
</Callout>
