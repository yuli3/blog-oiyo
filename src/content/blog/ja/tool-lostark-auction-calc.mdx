# ロストアーク競売計算機

ロストアークの軍団長レイドや深淵ダンジョンで競売アイテムが出た際に、いくらで入札するとパーティーメンバー全員に公平かを素早く計算するツールです。

## 計算方式

**均等分配入札価格の計算式：**
```
入札価格 = 手数料除外市場価格 × (人数 - 1) ÷ 人数
```

**最大利得入札価格の計算式：**
```
入札価格 = 均等分配入札価格 ÷ 1.1
```

取引所の手数料（5%）は市場価格から自動的に差し引かれます。

## 用語説明

<Callout type="note">
**均等分配入札価格**：落札者と落札できなかったパーティーメンバーが同じ利益を得る入札価格です。パーティー内の公平さを最優先にする場合に使います。
</Callout>

<Callout type="tip">
**最大利得入札価格**：落札者が最大の利益を得られる入札価格です。パーティーメンバーと合意が取れている場合に使います。均等分配入札価格より低い金額になります。
</Callout>

### 実例

市場価格100,000ゴールド、4人パーティーの場合：
- 手数料（5%）：5,000ゴールド
- 分配される金額：95,000ゴールド
- **均等分配入札価格：71,250ゴールド**（落札者含む4人全員が約23,750ゴールドの利益）
- **最大利得入札価格：64,772ゴールド**（落札者が最大利益）
