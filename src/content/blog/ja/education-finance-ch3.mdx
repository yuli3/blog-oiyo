# Chapter 3. 卵を一つのカゴに盛るな：リスク、収益率、そしてポートフォリオ理論

皆さん、お帰りなさい。前回、私たちは「バリュエーション」を通じて資産の真の重さを測る方法を学びました。今日は、それらの資産をどのように混ぜれば最も美味しい「収益のカクテル」を作れるのか、つまり **ポートフォリオ理論 (Portfolio Theory)** の世界へと旅立ちます。

「ハイリスク・ハイリターン」。私たちが日常的に使うこの言葉は、財務管理の最も核心的な真理です。しかし、単にリスクを冒すことが目的ではありません。現代財務管理の巨匠ハリー・マーコウィッツは、 <mark><strong>「リスクを無料で減らす方法」</strong></mark> を数学的に証明しました。経済学において唯一の例外と呼ばれる「分散投資の魔法」を今日、共に解き明かしましょう。

---

## 1. リスクの正体：数字で見る変動性

財務管理においてリスク（Risk）は、単なる「お金を失う可能性」ではありません。それは <mark><strong>「期待していた結果と実際の結果が異なる可能性」</strong></mark> 、すなわち **変動性 (Volatility)** を意味します。

### (1) 期待収益率 (Expected Return)

未来に発生し得る様々な状況（好況、不況など）の確率と、それに応じた収益率を平均した値です。

### (2) 標準偏差：リスクの尺度

私たちは、収益率が平均からどれだけ離れて揺れ動くかを **標準偏差 ($\sigma$)** で測定します。標準偏差が大きいということは、それだけ一寸先が分からないリスクの高い資産であることを意味します。

## 2. 分散投資の魔法：ポートフォリオ効果

なぜ賢明な投資家は、特定の銘柄だけに「オールイン」しないのでしょうか？

<mark><strong>相関係数の決定的な役割</strong></mark>：二つの株式が全く同じように動くなら（相関 = +1）、混ぜても意味がありません。しかし、一方が笑う時にもう一方が泣く組み合わせ（相関 < 1）を見つければ、収益率は維持しながら全体の物理的なリスクを劇的に減らすことができます。

---

## 3. 効率的フロンティア

数万通りの組み合わせの中で、私たちはどれを選ぶべきでしょうか？

リスクに対して最高の収益率を与えるポートフォリオを繋いだ線を **効率的フロンティア (Efficient Frontier)** と呼びます。合理的な投資家であれば、必ずこの線上にあるポートフォリオを選択すべきです。

---

## 4. 体系的リスク vs 非体系的リスク

分散投資をすればすべてのリスクが消えるのでしょうか？残念ながら、そうではありません。

<LecturePieChart
  title="全体リスクの構成"
  description="分散投資で除去できるリスクは限られています。"
  data={[
    { name: "非体系的リスク (分散可能)", value: 60, color: "var(--color-primary)" },
    { name: "体系的リスク (市場全体)", value: 40, color: "#f43f5e" },
  ]}

- **非体系的リスク**: 「会社の社長が不祥事を起こした」。特定の企業にのみ限定されたリスクです。銘柄を増やせば **除去可能です。**
- **体系的リスク**: 「世界的な金利高騰や戦争」。市場全体を襲う波です。いくら分散しても **除去できません。**

---

## 5. 結論：賢くリスクを選択せよ

ポートフォリオ理論の核心は、単にリスクを避けることではなく、 <mark><strong>「回避できるリスクは除去し、補償（収益）が得られるリスクだけを選別して受け入れる戦略的な大胆さ」</strong></mark> です。
