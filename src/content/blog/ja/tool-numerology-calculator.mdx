# 数秘術（ヌメロロジー）計算機

数秘術は数字に特別な意味とエネルギーがあるという古代の哲学で、ピタゴラス（紀元前570〜495年）が体系化しました。生年月日を足して出た数字で人生の方向性と性格を探求します。

## 運命数（ライフパスナンバー）の計算法

生年月日のすべての数字を1桁になるまで足し続けます。

**例：1990年5月23日**  
1+9+9+0 + 0+5 + 2+3 = 29 → 2+9 = **11**（マスターナンバー）  
または 1+1 = **2**

<Callout type="tip">
**マスターナンバー（11・22・33）**：2桁のまま保持する特別な数字。より大きな可能性と挑戦を象徴します。通常は単一の数字（2・4・6）とマスターナンバーの両方を考慮して解釈します。
</Callout>

## 運命数別の意味

| 数字 | キーワード | 性格の特徴 |
|---|---|---|
| **1** | 開拓者 | 独立心・リーダーシップ・創造力 |
| **2** | 調和する者 | 協調性・外交術・感受性 |
| **3** | 表現する者 | 創造性・コミュニケーション・楽観性 |
| **4** | 建設者 | 誠実さ・体系性・安定志向 |
| **5** | 自由人 | 冒険・変化・多才さ |
| **6** | 養育者 | 責任感・愛情・家庭重視 |
| **7** | 探求者 | 分析力・精神的探求・内向性 |
| **8** | 達成者 | 野心・権力・物質的成功 |
| **9** | 人道主義者 | 寛大さ・理想主義・奉仕 |
| **11** | 霊的直感者 | 直感力・インスピレーション・高い感受性 |
| **22** | マスタービルダー | 大きなビジョン・実行力 |
| **33** | マスターティーチャー | 利他主義・癒し・霊的指導 |
