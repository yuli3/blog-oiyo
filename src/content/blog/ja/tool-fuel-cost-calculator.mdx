## 燃費を上げるエコドライブの習慣

<Callout type="tip">
**エコドライブ**で燃費を最大20%改善できます。
</Callout>

| 習慣 | 燃費改善効果 |
|---|---|
| 急加速・急ブレーキを避ける | +10〜15% |
| タイヤの空気圧を適正に維持 | +3〜5% |
| エアコンの使用を最小限に | +5〜10% |
| トランクの不要な荷物を降ろす | +1〜3% |
| 高速道路での定速走行（100km/h） | 最適な燃費区間 |

## ガソリン代を節約するコツ

| 方法 | 節約法 |
|---|---|
| セルフスタンドを利用 | 1Lあたり数円〜10円程度安い |
| 提携クレジットカードを使う | 特定の石油会社の提携カード |
| ガソリン価格比較アプリ | 近くの最安値スタンドを検索 |
| 給油時間帯 | 早朝（燃料密度が高い） |

<Callout type="note">
**正確な燃費測定のコツ**：満タンにしてから出発し、同じスタンドで再度満タンにした際の給油量と走行距離を記録してください。
</Callout>
