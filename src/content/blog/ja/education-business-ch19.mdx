## 1. グローバル化の推進要因

**グローバル化 (Globalization)**：国家間の貿易・投資・文化・技術の統合が深まる現象。

### グローバル化の4つの推進要因（Yip）

| 要因 | 内容 |
|------|------|
| 市場要因 | 消費者の同質化、グローバル顧客の増加 |
| コスト要因 | 規模の経済、低賃金の生産拠点 |
| 政府要因 | 関税撤廃、知的財産権条約 |
| 競争要因 | グローバル競争者の登場、先行者圧力 |

## 2. 海外参入戦略

### 参入方式と統制力・リスク・収益の関係

| 方式 | 統制力 | リスク | 資源投入 |
|------|--------|------|----------|
| 輸出 | 低い | 低い | 低い |
| ライセンシング | 低い | 低い | 低い |
| フランチャイジング | 中程度 | 低い | 中程度 |
| 合弁投資 (JV) | 中程度 | 中程度 | 中程度 |
| 戦略的提携 | 中程度 | 中程度 | 中程度 |
| 単独直接投資 (WOS) | 高い | 高い | 高い |
| 合併・買収 (M&A) | 高い | 高い | 非常に高い |

**グリーンフィールド投資**：現地に新規で工場・事務所を設立（時間 長、統制力 高）。
**ブラウンフィールド投資**：既存施設を買収して改修（時間 短、隠れた負債リスク）。

## 3. 多国籍企業理論

### 折衷理論（OLIパラダイム、Dunning）

企業が海外直接投資（FDI）を選択する理由を3つの優位性で説明。

| 優位性 | 内容 |
|------|------|
| O (Ownership) 優位性 | ブランド・技術・経営ノウハウなど企業固有の資産 |
| L (Location) 優位性 | 現地の安価な労働力・資源・市場アクセス |
| I (Internalization) 優位性 | 直接運営が契約より有利（技術流出の防止） |

### グローバル戦略の類型（Bartlett & Ghoshal）

| 戦略 | グローバル統合 | 現地適応性 |
|------|------------|------------|
| グローバル戦略 | 高 | 低（標準化） |
| マルチドメスティック戦略 | 低 | 高（現地化） |
| インターナショナル戦略 | 低 | 低（本国中心） |
| トランスナショナル戦略 | 高 | 高（バランス） |

## 4. 文化の違いの管理

### Hofstedeの文化次元（6つ）

| 次元 | 内容 |
|------|------|
| 権力格差 | 権力の不平等をどこまで受け入れるか |
| 不確実性の回避 | 不確実性に対する不安の程度 |
| 個人主義 vs 集団主義 | 個人 vs 集団のアイデンティティ |
| 男性性 vs 女性性 | 成果・競争 vs 生活の質・協調 |
| 長期志向 vs 短期志向 | 将来への投資 vs 現在・伝統の重視 |
| 放縦 vs 抑制 | 欲求充足をどこまで許容するか |

### カルチャーショック（Culture Shock）のUカーブ
新婚期 → 不満期 → 適応期 → 統合期の4段階で現地に適応。

### 文化マネジメント戦略
- **エスノセントリズム**（自国中心）：本国の文化・慣行をそのまま移植
- **ポリセントリズム**（現地中心）：各国が自律的に運営
- **ジオセントリズム**（グローバル統合）：最善の方法を世界的に共有

## 5. 為替とグローバル財務

### 為替リスクの類型

| 類型 | 内容 |
|------|------|
| 取引リスク | 外貨契約の決済時における為替変動 |
| 換算リスク | 財務諸表統合時の為替差異 |
| 経済的リスク | 長期的競争力に及ぼす為替の影響 |

### ヘッジ手段
- **先物為替契約**：将来の為替レートを固定
- **通貨スワップ**：二つの通貨間の利子・元本の交換
- **通貨オプション**：不利な為替変動時の防御

## 6. グローバルサプライチェーンと貿易

**比較優位（Ricardo）**：各国が相対的に得意なものに特化すれば、双方が利益を得る。

**国家ダイヤモンドモデル（Porter）**：国家の競争優位を決定する4つの要因。
- 要素条件（生産要素の質・量）
- 需要条件（国内市場の質）
- 関連産業（供給業・関連業の競争力）
- 企業戦略・構造・競争
