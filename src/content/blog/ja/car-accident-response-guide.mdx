## 事故は「順番」が半分

事故直後は誰でも慌てる。順番を知っておけば、損害もトラブルも大きく減らせる。以下を順番どおりに。

> 一般的な案内です。具体的な処理は保険会社・警察・各国法律に従ってください。下記の番号は韓国用です。他国では現地の緊急番号を使ってください。

---

## ステップ1 — まず安全確保

```
□ ハザードランプを点灯
□ 安全な場所へ車を移動（二次事故防止）—
  ただし負傷・重大事故では現場を保存
□ 高速道路：ガードレールの外など安全地帯へ退避し、後方に三角表示板
□ 負傷者を確認 → けが人がいれば直ちに救急へ
```

<aside>
**二次事故が最も危険だ。** 高速道路やトンネルでは車内・路上に留まらず、**ガードレールの外へ退避**してから通報する。
</aside>

---

## ステップ2 — 通報（公式番号）

```
□ 負傷・死亡・ひき逃げ・大事故 → 警察・救急へ
□ 韓国：112（警察）、119（消防・救急）、1339（救急医療情報）
□ 保険会社に事故受付（コールセンター）— 現場から受付を
□ 韓国の高速道路：1588-2504
□ 他国：現地の緊急番号（例：日本110・119、欧州112）
```

---

## ステップ3 — 証拠確保（写真）

写真は紛争の決定的証拠だ。距離・角度を変えて残す。

```
□ 現場全体（車両の位置関係が分かるように）— 遠くから
□ 両車の損傷部位 — 近くで
□ タイヤの向き・ブレーキ痕・信号・車線
□ ドライブレコーダー映像を保存（上書き前に）
□ 相手の情報：ナンバー・連絡先・保険会社・免許
□ 目撃者の連絡先（いれば）
```

---

## ステップ4 — 保険・病院

```
□ 受付番号・担当者を確認
□ 痛みは後から出ることも → 必要なら受診・記録
□ 示談を急がない — 負傷・修理費が確定してから
```

---

## ⚠️ 絶対にやってはいけないこと

```
✗ 現場での現金示談・念書（後のトラブル・隠れた負傷）
✗ 軽率な過失の認定（過失割合は調査で決まる）
✗ 写真なしで車を完全移動（軽微でも証拠が先）
✗ 負傷者の放置・ひき逃げ（刑事処罰の対象）
✗ 飲酒・無免許の隠蔽
```

---

## 主要番号（韓国）

| 状況 | 番号 |
|------|------|
| 警察 | **112** |
| 消防・救急 | **119** |
| 救急医療情報 | **1339** |
| 高速道路 | 1588-2504 |
| 保険会社 | 加入先のコールセンター |

> 番号・制度は変わりうるため、警察・消防・保険会社の**公式チャネル**で確認を。韓国外では現地の番号を。

---

## まとめ

1. 順番：**安全確保 → 通報 → 証拠写真 → 保険・病院。**
2. 二次事故防止が最優先 — 高速道路はガードレールの外へ。
3. 写真は遠近＋ドライブレコーダー。
4. 現場の現金示談・軽率な過失認定・写真前の車移動はNG。
5. 主要番号（韓国）：112・119・1339、保険会社へ即受付。
