## 1. 企業倫理 (Business Ethics)

**企業倫理**: 企業の経営活動において、善し悪しを判断する道徳的原則と価値体系。

### 倫理的意思決定の基準

| 基準 | 内容 |
|------|------|
| 功利主義 | 最大多数の最大幸福 |
| 義務論 (Kant) | 普遍的な道徳法則に従う行為 |
| 徳倫理 | 徳高い品性から生じる行為 |
| 正義論 (Rawls) | 公正な分配の原則 |

### 倫理経営の阻害要因
- **倫理的フェーディング**: 意思決定時に倫理的側面が徐々に薄れていく現象
- **同調圧力**: 集団の非倫理的な慣行に従ってしまう現象
- **倫理的盲点**: 自身の非倫理性を認識できないバイアス

## 2. CSR (企業の社会的責任)

### CarrollのCSRピラミッド (4段階)

| 段階 | 責任の種類 | 内容 |
|------|----------|------|
| 4 (最上) | 慈善的責任 | 寄付、地域社会への貢献 (選択) |
| 3 | 倫理的責任 | 期待される道徳的行動 |
| 2 | 法的責任 | 法律・規制の遵守 (義務) |
| 1 (基盤) | 経済的責任 | 利益の創出 (基本) |

**核心**: 経済的責任が基盤であり、慈善的責任は期待される最上位の活動。

### ステークホルダー理論 (Freeman)

企業は株主(stockholder)だけでなく、**すべてのステークホルダー(stakeholder)**に対して責任を負う。

**ステークホルダーの種類**: 株主 / 従業員 / 顧客 / サプライヤー / 地域社会 / 政府 / 環境

**株主理論 vs ステークホルダー理論**

| 区分 | 株主理論 (Friedman) | ステークホルダー理論 |
|------|---------------------|---------------|
| 目標 | 株主利益の最大化 | すべてのステークホルダーの利益のバランス |
| CSRの観点 | コスト、株主資金の無駄遣い | 長期的な企業価値の創出 |

## 3. ESG経営

**ESG**: **E**nvironmental(環境)・**S**ocial(社会)・**G**overnance(ガバナンス) — 持続可能な経営成果の測定フレームワーク。

### E (Environment)

| 項目 | 内容 |
|------|------|
| 炭素排出 | 温室効果ガスの削減、カーボンニュートラル2050 |
| エネルギー | 再生可能エネルギーへの転換 (RE100) |
| 資源管理 | 水の使用、廃棄物の削減 |
| 生物多様性 | 生態系への影響の最小化 |

**RE100**: 企業が使用する電力を100%再生可能エネルギーで調達するというグローバルイニシアチブ。

### S (Social)

| 項目 | 内容 |
|------|------|
| 労働慣行 | 安全、多様性、公正な賃金 |
| サプライチェーン管理 | 協力会社の人権・環境基準 |
| 地域社会 | 社会貢献、地域経済への貢献 |
| 製品責任 | 消費者の安全、個人情報の保護 |

### G (Governance)

| 項目 | 内容 |
|------|------|
| 取締役会 | 独立性、多様性、専門性 |
| 反腐敗 | 透明性の高い会計、コンプライアンス |
| 経営陣の報酬 | 成果連動型報酬の公正性 |
| 株主権利 | 議決権、情報開示 |

### ESG投資
**ESGスクリーニング**: ESG基準による投資対象のフィルタリング。
**TCFD (気候関連財務情報開示タスクフォース)**: 気候変動リスクを財務報告書に含める。

## 4. ガバナンス (Corporate Governance)

**コーポレートガバナンス**: 企業を統制・指示する原則と構造 — 取締役会、監査、株主関係。

### エージェンシー問題 (Agency Problem)
株主(principal) ↔ 経営陣(agent) 間の利害の不一致 — 経営陣が自身の利益のために行動してしまうリスク。

**解決手段**: 成果連動型報酬 / 取締役会による監督 / 外部監査 / 情報開示の強化

### 取締役会の構造
- **社外取締役**: 経営陣から独立した外部の取締役 → 監査機能
- **監査委員会**: 財務報告・内部統制の監督
- **報酬委員会**: 経営陣の報酬決定

## 5. UN SDGsと企業

**持続可能な開発目標 (SDGs)**: 2030年までに達成する17のグローバル目標。

企業関連の主要SDGs:
- SDG 8: 働きがいも経済成長も
- SDG 12: つくる責任 つかう責任
- SDG 13: 気候変動に具体的な対策を
- SDG 17: パートナーシップで目標を達成しよう

**CSV (共通価値の創造、Porter & Kramer)**: 企業が社会課題の解決を通じて同時に経済的価値を創造するアプローチ。CSR(コストの観点)とは区別される。
