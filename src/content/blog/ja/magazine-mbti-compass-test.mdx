# 4問MBTIコンパス：あなたの認知スタイルはどこへ向かう？

集中力、判断、日々の進め方は意外とパターンがあります。

## 1. 4問でサクッと診断

## 2. 結果の読み方

MBTIは正解ではなく**方向性**です。  
次の4軸を覚えておくと、より実用的に解釈できます。

1. **E / I**: エネルギーの回復方法
2. **S / N**: 情報の捉え方
3. **T / F**: 判断の基準
4. **J / P**: 予定と締切の運用スタイル
