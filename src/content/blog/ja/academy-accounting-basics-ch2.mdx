## 貸借対照表とは何か

**財政状態計算書（貸借対照表）**  
一時点の会社の **資産、負債、純資産** を示す財務諸表。

```
資産 = 負債 + 純資産
（持っているもの）=（負っているもの）+（持分）
```

---

## 資産

将来の経済的便益をもたらすと期待される、会社が持つ経済資源。

### 流動資産
一年以内に現金化できる資産。

| 項目 | 説明 |
|------|-------------|
| 現金及び現金同等物 | すぐ現金化できる |
| 短期投資 | 1年以内に満期の預金・債券 |
| 売掛金 | 掛売りの未収 |
| 棚卸資産 | 販売用の商品、製品、原材料 |
| 前払費用 | 先に払った費用 |

### 非流動資産
便益が一年を超えて実現する長期資産。

| 項目 | 説明 |
|------|-------------|
| 有形固定資産（PP&E） | 土地、建物、機械（減価償却の対象） |
| 無形資産 | 特許、のれん、ソフトウェア |
| 長期投資 | 長期預金、持分法投資 |
| 繰延税金資産 | 一時差異から生じる |

---

## 負債

他者に負う義務。将来の経済資源の流出が期待される項目。

### 流動負債
一年以内に期限が来る債務。

| 項目 | 説明 |
|------|-------------|
| 買掛金 | 掛買いの未払 |
| 短期借入 | 1年以内の借入 |
| 未払負債 | 発生したが未払いの費用 |
| 前受収益 | 役務提供前に受け取った収益 |

### 非流動負債
一年を超えて期限が来る長期債務。

- 社債
- 長期借入
- 退職給付義務
- 繰延税金負債

---

## 純資産（株主資本）

資産から負債を引いた残り。株主の請求権を表す。

```
純資産 = 資産 - 負債 = 正味資産
```

| 構成 | 説明 |
|-----------|-------------|
| **資本金（額面）** | 発行済株式の額面合計 |
| **資本剰余金** | 発行時に額面を超えて受け取った額 |
| **利益剰余金** | 配当としてまだ分配していない累積純利益 |
| **その他の包括利益累計額（AOCI）** | 資産・負債の再評価など |
| **自己株式** | 会社が買い戻した株式（純資産の控除） |

## 貸借対照表の分析比率

**流動性分析**:
```
流動比率 = 流動資産 / 流動負債 × 100%
（200%以上: 健康、という目安）

当座比率 = （流動資産 - 棚卸） / 流動負債 × 100%
（100%以上: 健康、という目安）
```

**安全性分析**:
```
負債資本倍率 = 総負債 / 純資産 × 100%
（100%以下: 安定、という目安）

自己資本比率 = 純資産 / 総資産 × 100%
（50%以上: 健全、という目安）
```

目安であり、業種と時点で変わる。

## 概念カード

**流動 vs 非流動資産** ★★★★★  
: 一年が境界。1年以内に現金化 = 流動。1年超 = 非流動。  
*記憶: 流動 = 1年以内*

**負債資本倍率** ★★★★★  
: 外部金融への依存。総負債 ÷ 純資産 × 100%。高いほど財務リスク。  
*記憶: D/E 100% = 負債が純資産と等しい*

**利益剰余金** ★★★★☆  
: 過去全期間の純利益累計から配当を引いたもの。内部留保。  
*記憶: 利益剰余金 = 通期純利益 − 通期配当*

## 練習

**Q. 売掛金と買掛金はそれぞれどこに分類されるか。**  
> 売掛金（掛売りの未収）→ 流動資産。買掛金（掛買いの未払）→ 流動負債。

**Q. 負債資本倍率300%の会社と50%の会社を比べよ。**  
> 300%は負債が純資産の三倍 → 財務レバレッジが高く、下降局面の破綻リスクが大きい。50%は負債が純資産の半分 → 安定だが、投資能力を使い切っていない可能性がある。
