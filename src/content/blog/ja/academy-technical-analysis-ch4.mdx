## 第4章 概要：価格が記憶する場所

市場には人々が記憶する価格帯がある。そこで何度も止まり反転する。その場所を線で示したのが**支持・抵抗線**、トレンドの方向に沿って引いたのが**トレンドライン**だ。これらの線が作る図形がチャートパターンである。

<Callout type="info">
**この講義の目標**：支持・抵抗とトレンドラインを引く原則を身につけ、代表的な反転・継続パターンでエントリー・損切り・目標のシナリオを立てる。
</Callout>

---

## 1. 支持線と抵抗線

| 区分 | 定義 | 心理 |
|------|------|------|
| **支持線** | 価格がそれ以上下がらず支えられる価格帯 | 「この価格なら買う」買い待ち |
| **抵抗線** | 価格がそれ以上上がれず阻まれる価格帯 | 「この価格なら売る」売り待ち |

### 支持・抵抗の役割転換
抵抗線を強く突破すると、その線は以後**支持線に変わる。** 逆に支持線が崩れると抵抗線になる。一度抜けた価格帯へ戻って試す（リテスト）流れがよく出る。

<Callout type="tip">
**何度も触れるほど強い。** 同じ価格帯で3〜4回止まった線は、1回だけの線よりはるかに信頼度が高い。ただし強い線ほど、いったん抜けると反対方向へ大きく動く。
</Callout>

---

## 2. トレンドラインの引き方

- **上昇トレンドライン**：安値（HL）を結んで右肩上がりに引く → 支持の役割
- **下降トレンドライン**：高値（LH）を結んで右肩下がりに引く → 抵抗の役割
- **チャネル**：トレンドラインと平行線を引いて値動きの通路を作る

```
上昇チャネル：
        /   /   /  ← 抵抗（平行線）
      /   /   /
    /   /   /      ← 支持（トレンドライン）
```

トレンドラインが崩れること（上昇トレンドラインの下抜け）は、トレンド転換の一次警告だ。

---

## 3. 反転パターン — トレンドが変わる

| パターン | 形 | 意味 |
|---------|----|------|
| **ヘッドアンドショルダー** | 左肩・頭・右肩＋ネックライン | 上昇→下落転換 |
| **逆ヘッドアンドショルダー** | 上下反転した形 | 下落→上昇転換 |
| **ダブルトップ** | M字形、高値2回 | 上昇→下落転換 |
| **ダブルボトム** | W字形、安値2回 | 下落→上昇転換 |

### ヘッドアンドショルダーの売買シナリオ
1. 頭の形成後、**ネックライン**を引く。
2. 右肩がネックラインを下抜けたら売りシグナル。
3. **目標値** ≈ 頭〜ネックラインの高さをネックライン下に投影。

<Callout type="note">
パターンは**完成（ブレイク）するまで仮説**にすぎない。ネックラインを割る前のヘッドアンドショルダーは単なるレンジかもしれない。完成を確認してから入るのが定石だ。
</Callout>

---

## 4. 継続パターン — トレンドが続く

トレンド途中の小休止で、ブレイク方向へトレンドが続く可能性が高い。

- **三角保ち合い（トライアングル）**：値幅が狭まり一点に収束 → ブレイク方向へ進行
  - 上昇三角形（水平抵抗＋上昇支持） → 通常は上抜け
  - 下降三角形（水平支持＋下降抵抗） → 通常は下抜け
- **フラッグ／ペナント**：急騰（急落）後の短い調整 → 既存方向へ再開
- **ボックス（長方形）**：一定範囲の横ばい → ブレイクで方向決定

---

## 5. ブレイクとダマシ（ヒゲ）

<Callout type="warning">
すべてのブレイクが本物ではない。少し線を抜けて戻る**ダマシ（ヒゲ・Whipsaw）**が頻発する。これを濾す2つの手がかり：
1. **出来高** — 本物のブレイクは出来高が伴う（第5章）。
2. **終値基準** — 場中に一瞬抜けるより、終値が線の外で引けるかが重要。
</Callout>

---

## 今回のまとめ

1. 支持・抵抗は市場が記憶する価格帯で、抜けると役割が入れ替わる。
2. トレンドラインは安値・高値を結び、割れは転換の一次警告。
3. ヘッドアンドショルダー・ダブルトップ／ボトムは反転、三角保ち合い・フラッグは継続パターン。
4. パターンは**ブレイクで完成するまで仮説**で、目標値はパターンの高さで推定。
5. 出来高と終値基準でダマシ（ヒゲ）を濾す。

**次回**：これまで後回しにした「出来高」を本格的に扱う。出来高がトレンドとブレイクの真偽をどう確認するか、出来高プロファイルまで見る。
