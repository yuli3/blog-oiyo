# 結婚年齢計算機

結婚に関連する年齢をさまざまな観点から分析します。法的基準から統計的な平均、財務的な準備まで見ていきましょう。

## 韓国の法定婚姻年齢

| 区分 | 基準 |
|---|---|
| 法定婚姻可能年齢 | **満18歳以上**（2023年改正、男女同一） |
| 以前の基準 | 男性満18歳、女性満16歳（旧法） |
| 未成年者の婚姻 | 2023年7月から完全廃止 |

## 韓国の初婚年齢の推移（韓国統計庁）

| 年 | 男性平均初婚 | 女性平均初婚 |
|---|---|---|
| 2000年 | 29.3歳 | 26.5歳 |
| 2010年 | 31.8歳 | 28.9歳 |
| 2020年 | 33.2歳 | 30.8歳 |
| 2023年 | **34.0歳** | **31.5歳** |

初婚年齢は毎年着実に上昇しています。

<Callout type="tip">
**結婚準備期間**：式場の予約は通常12〜18ヶ月前、新居の契約は6〜12ヶ月前が一般的です。シーズン（春・秋）の式場は2年前から満席になることもあります。
</Callout>

## 結婚前の財務チェックリスト（ソウル基準）

| 項目 | 目安費用 |
|---|---|
| 式場＋スタジオ・ドレス・メイク | 1,000〜2,500万ウォン |
| 新居の保証金 | 전세3〜5億ウォン、月払い保証金2,000万ウォン以上 |
| 家具・家電・婚礼品 | 500〜2,000万ウォン |
| 新婚旅行 | 200〜600万ウォン |
| **総予想費用** | **5,000万〜1億ウォン以上** |

<Callout type="note">
結婚費用は地域・規模・選択によって大きく異なります。スモールウェディングや一部省略すれば1,000万ウォン以下も可能です。
</Callout>
