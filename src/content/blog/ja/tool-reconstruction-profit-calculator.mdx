# 韓国재건築収益計算機

韓国の재건築・재개발投資の核心は**権利価額と新しいアパート分譲価格の差**です。追加負担金を払っても新しいアパートの価値の方が高ければ収益が生まれます。

## 再建築収益の計算構造

**権利価額** = 現在の物件価格（鑑定額）× 비례율  
**追加負担金** = 新しいアパート分譲価格 − 権利価額  
**予想収益** = 新しいアパートの市場価格 − 既存投資額 − 追加負担金

<Callout type="tip">
**비례율（비례율）**：재건축事業の収益性指標。100%以上なら組合員に利益、100%未満なら損失。ソウルの主要재건築団地は通常100〜120%。
</Callout>

## 재건築の進行段階

| 段階 | 内容 | 所要期間 |
|---|---|---|
| 安全診断 | D・Eクラス通過が必要 | 6ヶ月〜1年 |
| 整備区域指定 | 自治体の告示 | 1〜2年 |
| 組合設立 | 土地等所有者の75%同意 | 1〜2年 |
| 事業施行認可 | 設計・工事計画確定 | 2〜3年 |
| 管理処分認可 | 負担金確定 | 1〜2年 |
| 移転・撤去・着工 | 工事開始 | 3〜4年 |
| 完工・入居 | 新しいアパート完成 | — |

## 再建築投資の注意事項

- 各段階での規制変更リスク（安全診断の強化・재건築超過利益還収制）
- 事業遅延時の利息費用発生
- 管理処分認可後の移転費用の確保が必要
- 実居住義務2年（投機過熱地区の分譲権）

<Callout type="warning">
再建築投資は事業期間が10〜20年に及ぶ可能性があり、規制変更によって収益性が大きく変わります。専門家に相談してから投資を決定してください。
</Callout>
