# 共感力とは？

「共感力が高い」と言うと、まるで一つの才能のように聞こえます。けれど実際には、相手の立場を頭で理解する力と、相手の感情を自分の中でも感じ取る力は同じではありません。さらに、共感しすぎることで心が疲れてしまうこともあります。共感を三つの側面に分けて見ると、自分の強みや疲れやすいポイントが見えやすくなります。

## 1. 認知的共感 — 頭で理解する

相手が何を考え、どのような視点に立っているのかを**理解する**力です。日本語で言えば「相手の立場に立って考える」に近い感覚です。認知的共感が高い人は、交渉・相談・リーダーシップの場面で、相手が何を必要としているのかを読み取りやすくなります。ただし、感情を伴わずに理解だけが先に立つと、冷たく計算高い印象を与えることもあります。

## 2. 情動的共感 — 一緒に感じる

相手の感情を**実際に一緒に感じ取る**力です。友人がつらそうにしていると、自分の胸まで重くなるような感覚がこれにあたります。情動的共感が高いと深いつながりを築きやすい一方で、他人の感情に巻き込まれやすくなることもあります。

## 3. 共感疲労 — 感じすぎて疲れるとき

共感力は無限に使えるものではありません。看護師、カウンセラー、介護やケアに関わる人のように、他者の苦しみに継続的に触れる環境では、**共感疲労(compassion fatigue)**が蓄積することがあります。これは共感力が「壊れた」という意味ではなく、心を回復させる時間が必要だというサインです。

## なぜ三つに分けて見る必要があるのか

- **認知が高く情動が低い**: 状況はよく把握できるが、冷たく見られることがある → 感情を言葉や態度で意識的に伝える。
- **情動が高く認知が低い**: 感情移入しやすいが、状況判断がぶれやすい → 一歩引いて、事実と視点を整理する。
- **どちらも高い**: 深く共感できるが、共感疲労のリスクがある → 境界線を引くことと回復時間を確保することが大切。

## 共感力は育てられます

共感力は、生まれつき固定された数値ではありません。相手の話を途中で遮らずに最後まで聞くこと、「そう感じるのも無理はないかもしれない」と判断をいったん保留すること、そして自分の感情と相手の感情を分けて見つめる練習が役立ちます。同時に、自分を守るための境界線を持つことも、健やかな共感の一部です。

## よくある質問

**Q. 共感力が高いことは、いつも良いことですか？**
情動的共感が強すぎると、他人の感情に引き込まれて自分が消耗してしまうことがあります。健やかな共感とは、「一緒に感じながらも、自分を見失わない」バランスです。境界線を引くことや回復の時間を持つことも、共感力の一部です。

**Q. 認知的共感と情動的共感では、どちらが重要ですか？**
場面によって変わります。対立の調整や交渉では認知的共感が、慰めや信頼関係づくりでは情動的共感がより必要になります。大切なのは、どちらか一方だけではなく、状況に合わせて使い分ける柔軟さです。

**Q. 共感力はトレーニングで伸ばせますか？**
はい。積極的に聞くこと、すぐに判断しないこと、相手の視点に立って考える練習によって、特に認知的共感は伸ばしやすくなります。このテストは自己理解のための参考ツールであり、専門的な診断に代わるものではありません。
