# パスワード生成器

「123456」「password」「qwerty」——世界で最も多く使われているパスワードです。このようなパスワードはハッカーに1秒もかからずに破られてしまいます。今すぐ本当に強力なパスワードを作りましょう。

## パスワード強度の基準

| 強度 | 文字数 | 構成 | 解読時間（ブルートフォース） |
|---|---|---|---|
| 非常に弱い | 6文字以下 | 数字のみ | 即座 |
| 弱い | 8文字 | 小文字のみ | 数分 |
| 普通 | 10文字 | 大文字＋小文字＋数字 | 数ヶ月 |
| 強い | 12文字 | 大文字＋小文字＋数字＋特殊文字 | 数年 |
| 非常に強い | 16文字以上 | 全文字種＋ランダム | 数百年以上 |

## パスワードセキュリティの原則

| 原則 | 説明 |
|---|---|
| **サイトごとに異なるパスワードを使う** | 1箇所が漏れると全部危険 |
| **12文字以上** | 最低12文字・重要なアカウントは16文字以上 |
| **定期的に変更** | 重要なアカウントは6ヶ月ごとに変更 |
| **パスワードマネージャーを使う** | 1Password・Bitwarden・KeePassなど |
| **2段階認証を併用** | SMS認証よりも認証アプリが推奨 |

## 絶対に使ってはいけないもの

- 名前・生年月日・電話番号
- 連続した数字・文字：1234、abcd
- キーボードパターン：qwerty、asdf
- 単純な単語＋数字：password123
- 以前のパスワードの再使用

<Callout type="warning">
この生成器は**ブラウザ内でのみ動作**し、生成されたパスワードをサーバーに保存したり送信したりしません。生成後すぐにコピーして安全な場所に保管してください。
</Callout>
