# バイオリズム計算機

バイオリズム理論は20世紀初頭にドイツ・オーストリアの研究者が提唱したもので、人間の身体・感情・知性能力が一定の周期で波打つという仮説です。科学的に完全に検証されたわけではありませんが、自分の状態を振り返る**自己認識ツール**として広く活用されています。

## 3つのバイオリズム周期

| リズム | 周期 | 意味 |
|---|---|---|
| 身体（Physical） | **23日** | 体力・持久力・協調性・免疫力 |
| 感情（Emotional） | **28日** | 気分・創造性・感受性・直感 |
| 知性（Intellectual） | **33日** | 論理力・集中力・分析力・記憶力 |

<Callout type="tip">
**臨界日（Critical Day）**：各周期がゼロを通過する転換点。この日は該当能力が不安定になり、ミスや事故が増えやすいとされます。重要な試験・手術・長距離ドライブは臨界日を避けることが推奨されています。
</Callout>

## リズム別の活用法

| 状態 | 活用戦略 |
|---|---|
| 身体↑（高値） | 運動・アウトドア活動・体力を使う作業 |
| 身体↓（低値） | 休息・回復・無理な運動は控える |
| 感情↑（高値） | 創作活動・人間関係強化・プレゼン・交渉 |
| 感情↓（低値） | 感情的な決断を避ける・瞑想・休息 |
| 知性↑（高値） | 勉強・試験・複雑な業務 |
| 知性↓（低値） | 単純作業・アイデア整理・休息 |

## 計算の原理

各リズムは**サイン（sin）関数**で表されます。

- 身体：sin(2π × 経過日数 / 23)
- 感情：sin(2π × 経過日数 / 28)
- 知性：sin(2π × 経過日数 / 33)

誕生日から今日までの経過日数を各周期で割った位置をサイン値で表すと、−1（最低）〜+1（最高）の値が得られます。

<Callout type="note">
バイオリズムは医学的に検証されたツールではありません。日常のパターンを振り返り、自己管理の参考として活用してください。
</Callout>
