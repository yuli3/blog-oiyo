# ペット年齢計算機

「うちの犬が10歳なら、人間でいうと何歳？」犬の年齢に7を掛ける時代は終わりました。最近の研究によると、犬の老化速度はサイズと年齢によって大きく異なります。

## 犬の年齢換算（サイズ別）

**小型犬（10kg未満）**

| 犬の年齢 | 人間年齢換算 |
|---|---|
| 1年 | 約15歳 |
| 2年 | 約24歳 |
| 5年 | 約36歳 |
| 10年 | 約56歳 |
| 15年 | 約76歳 |

**大型犬（25kg以上）** — 小型犬より速く老化

| 犬の年齢 | 人間年齢換算 |
|---|---|
| 1年 | 約15歳 |
| 5年 | 約40歳 |
| 10年 | 約66歳 |
| 13年 | 約96歳 |

<Callout type="tip">
**UCSD 2020年の研究**：犬のDNAメチル化パターンを分析したところ、最初の1〜2年は急激に老化し（人間の青年期に相当）、その後は速度が落ちることが判明しました。「年齢×7＝人間年齢」の計算式は不正確です。
</Callout>

## 猫の年齢換算

猫は品種によるサイズの差が小さいため、単一の基準を使用します。

| 猫の年齢 | 人間年齢換算 | ライフステージ |
|---|---|---|
| 1年 | 約15歳 | 青少年期 |
| 2年 | 約24歳 | 青年期 |
| 6年 | 約40歳 | 中年初期 |
| 10年 | 約56歳 | 中年後期 |
| 15年 | 約76歳 | 老年期 |
| 20年 | 約96歳 | 超高齢 |

## ライフステージ別の健康管理（小型犬基準）

| ステージ | 年齢 | 主な管理 |
|---|---|---|
| 幼犬期 | 0〜1年 | ワクチン完了・去勢手術・社会化 |
| 青年期 | 1〜3年 | 年1回の定期検診・歯石管理 |
| 中年期 | 4〜7年 | 体重管理・心臓・関節チェック |
| シニア期 | 8〜11年 | 年2回の検診・処方食への移行検討 |
| 老年期 | 12年以上 | 痛みの管理・認知機能低下のモニタリング |
