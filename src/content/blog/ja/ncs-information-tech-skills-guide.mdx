## 1. 컴퓨터 기초 개념

### 하드웨어 vs 소프트웨어

**하드웨어(Hardware)**: 물리적 장치
- 입력장치: 키보드, 마우스, 스캐너
- 출력장치: 모니터, 프린터, 스피커
- 저장장치: HDD, SSD, USB
- 처리장치: CPU (중앙처리장치)

**소프트웨어(Software)**: 프로그램
- 시스템 소프트웨어: 운영체제(Windows, macOS, Linux)
- 응용 소프트웨어: 워드, 엑셀, 브라우저

### 컴퓨터 처리 단위

| 단위 | 크기 |
|------|------|
| 1 Bit | 0 또는 1 (최소 단위) |
| 1 Byte | 8 bits |
| 1 KB (킬로바이트) | 1,024 Bytes ≈ 1,000 Bytes |
| 1 MB (메가바이트) | 1,024 KB |
| 1 GB (기가바이트) | 1,024 MB |
| 1 TB (테라바이트) | 1,024 GB |

**시험 출제 포인트**: "1MB는 몇 KB인가?" → 1,024 KB

### 인터넷 관련 용어

**IP 주소**: 네트워크상 각 컴퓨터의 고유 주소 (예: 192.168.0.1)

**URL**: 웹 자원의 위치 표시 (Uniform Resource Locator)

**HTTP/HTTPS**: 웹 통신 프로토콜. HTTPS는 암호화된 보안 버전.

**DNS**: 도메인명을 IP 주소로 변환 (Domain Name System)

**쿠키(Cookie)**: 웹사이트가 사용자 컴퓨터에 저장하는 소용량 데이터

## 2. 엑셀(Excel) 주요 함수 (시험 최빈출)

### 기본 수식 연산

```
=SUM(범위)          합계
=AVERAGE(범위)      평균
=MAX(범위)          최댓값
=MIN(범위)          최솟값
=COUNT(범위)        숫자 개수
=COUNTA(범위)       비어있지 않은 셀 개수
```

### 조건 함수

```
=IF(조건, 참일때값, 거짓일때값)
예: =IF(A1>=60, "합격", "불합격")

=COUNTIF(범위, 조건)
예: =COUNTIF(B1:B10, ">=80")  → 80 이상인 셀 개수

=SUMIF(조건범위, 조건, 합계범위)
예: =SUMIF(A1:A10, "영업부", C1:C10)  → 영업부 매출 합계
```

### 텍스트 함수

```
=LEN(텍스트)          문자 수 반환
=LEFT(텍스트, N)      왼쪽에서 N개 문자
=RIGHT(텍스트, N)     오른쪽에서 N개 문자
=MID(텍스트, 시작, N) 중간에서 N개 문자
=UPPER(텍스트)        모두 대문자
=LOWER(텍스트)        모두 소문자
```

### 찾기/참조 함수

```
=VLOOKUP(찾을값, 범위, 열번호, [일치방식])
세로 방향 검색, 가장 많이 출제되는 함수

예: =VLOOKUP(A2, $D$1:$F$100, 2, 0)
  → A2 값을 D1:F100 범위 첫 번째 열에서 찾아 두 번째 열 반환
  → 0 = 정확히 일치
```

### 날짜/시간 함수

```
=TODAY()          오늘 날짜
=NOW()            현재 날짜와 시간
=YEAR(날짜)        연도 추출
=MONTH(날짜)       월 추출
=DAY(날짜)         일 추출
=DATEDIF(시작, 끝, "Y")  연 차이 계산
```

## 3. 정보 처리 프로세스

### 정보 처리 5단계

1. **정보 수집(Collection)**: 목적에 맞는 데이터/정보 탐색·수집
2. **정보 분류(Classification)**: 수집된 정보를 유형별로 정리
3. **정보 분석(Analysis)**: 패턴 발견, 의미 추출
4. **정보 저장(Storage)**: 적절한 매체·형식으로 보관
5. **정보 활용(Utilization)**: 의사결정, 문제해결에 적용

### 데이터 vs 정보 vs 지식

| 개념 | 정의 | 예시 |
|------|------|------|
| **데이터(Data)** | 가공되지 않은 원시 사실 | 25, 서울, 2026 |
| **정보(Information)** | 의미 있게 처리된 데이터 | 25세 서울 거주자 |
| **지식(Knowledge)** | 정보를 이해하고 경험으로 체화 | "청년 지원 정책이 필요하다" |

### 데이터베이스(Database)

**데이터베이스**: 구조화된 데이터의 집합

**DBMS(Database Management System)**: 데이터베이스를 관리하는 소프트웨어 (Oracle, MySQL, MS SQL Server)

**기본 SQL 개념**:
```sql
SELECT   데이터 조회
INSERT   데이터 삽입
UPDATE   데이터 수정
DELETE   데이터 삭제
```

시험에서는 SQL 작성 능력보다 "다음 중 데이터베이스 관련 용어의 설명으로 옳은 것은?" 형태의 개념 이해 문제가 주로 출제됩니다.

## 4. 정보 보안

### 정보 보안의 3요소 (CIA)

| 요소 | 내용 |
|------|------|
| **기밀성(Confidentiality)** | 인가된 사람만 정보에 접근 가능 |
| **무결성(Integrity)** | 정보가 승인 없이 변조되지 않음 |
| **가용성(Availability)** | 인가된 사용자가 필요시 정보 이용 가능 |

### 주요 보안 위협

**악성 소프트웨어(Malware)**:
- 바이러스(Virus): 실행 파일에 자신을 복제·감염
- 웜(Worm): 네트워크를 통해 스스로 전파
- 트로이 목마(Trojan): 정상 소프트웨어로 위장한 악성 코드
- 랜섬웨어(Ransomware): 파일 암호화 후 복호화 비용 요구

**사회공학(Social Engineering)**:
- 피싱(Phishing): 가짜 이메일·웹사이트로 개인정보 탈취
- 스미싱(Smishing): SMS를 통한 피싱
- 보이스피싱: 전화를 통한 사기

**DDoS (Distributed Denial of Service)**: 대량 트래픽으로 서버 마비

### 암호화

**대칭키 암호화**: 암호화와 복호화에 같은 키 사용 (속도 빠름, 키 분배 문제)

**비대칭키 암호화(공개키)**: 공개키로 암호화, 개인키로 복호화 (안전, 느림)

**해시(Hash)**: 일방향 암호화. 비밀번호 저장에 활용. 복호화 불가.

### 개인정보보호

**개인정보**: 특정 개인을 식별할 수 있는 정보 (이름, 주민번호, 연락처, 이메일 등)

**개인정보보호법 핵심 원칙**:
1. 최소 수집: 목적에 필요한 최소한만 수집
2. 목적 제한: 수집 목적 외 사용 금지
3. 동의: 수집·이용 시 정보 주체 동의 필요
4. 안전한 관리: 분실·도난·유출 방지

## 5. 저작권과 정보 윤리

### 저작권 유형

- **저작권(Copyright)**: 창작물에 대한 독점적 권리 (소설, 음악, 소프트웨어)
- **특허권**: 발명에 대한 독점 권리
- **상표권**: 브랜드명·로고 등에 대한 권리

### 소프트웨어 라이선스

| 종류 | 특징 |
|------|------|
| 상용 소프트웨어 | 구매 또는 구독료 필요 |
| 셰어웨어 | 일정 기간 무료 사용 후 구매 |
| 프리웨어 | 무료 배포, 저작권 유지 |
| 오픈소스 | 소스코드 공개, 자유로운 수정·배포 |
| 퍼블릭 도메인 | 저작권 만료 또는 포기, 자유 이용 |
