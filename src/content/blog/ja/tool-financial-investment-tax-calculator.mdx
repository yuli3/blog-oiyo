# 金融投資所得税計算機（韓国）

株式・펀드・ETF投資で利益が出た場合、韓国の金融投資所得税の納付義務を確認してください。

## 金融投資所得税の構造

| 項目 | 内容 |
|---|---|
| 課税対象 | 国内株式・펀드・ETF・債券など |
| 基本控除 | **年5,000万ウォン** |
| 税率（控除後3億ウォン以下） | **20%** |
| 税率（控除後3億ウォン超） | **25%** |
| 地方所得税込み | ×1.1（22% / 27.5%） |
| 申告方法 | 翌年5月の総合所得税申告 |

<Callout type="tip">
**基本控除5,000万ウォン**：1年間のすべての金融投資損益を合算して、純利益5,000万ウォンまで非課税です。5,100万ウォンの利益なら100万ウォンのみ課税されます。
</Callout>

## 損益通算の例

| 項目 | 金額 |
|---|---|
| A株式の利益 | +8,000万ウォン |
| B펀드の損失 | −1,000万ウォン |
| 純利益合計 | 7,000万ウォン |
| 基本控除 | −5,000万ウォン |
| **課税対象** | **2,000万ウォン** |
| **税金（20%）** | **400万ウォン** |

## 旧制度との比較

| 区分 | 旧制度（大株主のみ） | 金融投資所得税（全員） |
|---|---|---|
| 課税基準 | 銘柄ごとに10億ウォン以上保有 | 全投資家 |
| 基本控除 | なし | 5,000万ウォン |
| 税率 | 20〜30% | 20〜25% |
| 損益通算 | 不可 | 可能 |

<Callout type="note">
金融投資所得税の施行時期と細部規定は政治的議論により変更される可能性があります。最新の税法を確認するか、税理士に相談してください。
</Callout>
