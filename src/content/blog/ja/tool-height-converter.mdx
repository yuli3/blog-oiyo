# 身長変換器

アメリカのドラマやSNSで「I'm 5'11"」という表現を見て戸惑ったことはありませんか？cmとフィート・インチを即時変換し、アメリカ基準の衣類サイズも確認できます。

## 主な身長変換早見表

| cm | フィート・インチ | 表記 |
|---|---|---|
| 150cm | 4フィート11インチ | 4'11" |
| 160cm | 5フィート3インチ | 5'3" |
| 165cm | 5フィート5インチ | 5'5" |
| 170cm | 5フィート7インチ | 5'7" |
| 175cm | 5フィート9インチ | 5'9" |
| 180cm | 5フィート11インチ | 5'11" |
| 185cm | 6フィート1インチ | 6'1" |
| 190cm | 6フィート3インチ | 6'3" |

## 単位変換の計算式

| 変換 | 計算式 |
|---|---|
| cm → インチ | cm ÷ 2.54 |
| インチ → cm | インチ × 2.54 |
| フィート → cm | フィート × 30.48 |
| cm → フィート | cm ÷ 30.48 |
| 1フィート | = 12インチ = 30.48cm |

<Callout type="tip">
**素早い暗算**：170cm ≈ 5フィート7インチ。170 ÷ 30.48 ≈ 5.577 → 5フィート + 0.577 × 12 ≈ 6.9インチ ≈ 5'7"。
</Callout>
