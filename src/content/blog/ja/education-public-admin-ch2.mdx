# 第2章: 現代行政の潮流: NPMからガバナンスまで

肥大化した伝統的官僚制による非効率を解決するために、「市場」と「ネットワーク」の原理が導入されました。この変化は行政学の試験において最も重要視されるトピックの一つです。

---

## 1. 新公共管理論 (NPM: New Public Management)

「政府は『漕ぐこと（執行）』よりも『舵取り（企画）』に集中すべきである。」 - オズボーン＆ゲーブラー

### (1) 主な特徴

- **市場原理**: 政府内への競争導入、アウトソーシングの拡大。
- **結果重視**: 投入(Input)よりも成果(Outcome)や結果に対する責任を強調。
- **顧客志向**: 市民を行政サービスの「顧客」とみなす。

---

## 2. ニューガバナンス (New Governance)

NPMが市場競争を強調したのに対し、ニューガバナンスは政府、市場、市民社会の間の **ネットワークと協働** を強調します。

### (1) NPM vs ニューガバナンスの比較

| 区分           | 新公共管理論 (NPM) | ニューガバナンス     |
| :------------- | :----------------- | :------------------- |
| **作動原理**   | 市場、競争         | ネットワーク、信頼   |
| **管理機構**   | 市場               | 連携網 (Network)     |
| **市民の役割** | 顧客 (Customer)    | パートナー (Partner) |
| **主な関心**   | 効率性             | 民主性、透明性       |

---

## 3. 新公共サービス論 (NPS: New Public Service)

「政府は市民にサービスを提供(Serve)すべきであり、操縦(Steer)することではない。」 - デンハート＆デンハート

- **価値**: 民主的な市民権と公益を最優先します。
- **市民の地位**: 消費者やパートナーを超え、行政の主権を持つ「市民」そのものです。

---

## 4. ポストNPM (Post-NPM)

NPMによる過度な分節化（省庁間の壁）を解決するために登場しました。

- **核心**: 「ホール・オブ・ガバメント (Whole-of-Government)」の観点から、省庁間の統合と調整を強調します。
