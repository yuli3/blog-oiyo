# 第1章：動物界 — 分類学と分類体系

動物学（zoology）は、動物の構造、生理、行動、そして分類を網羅する動物についての科学的研究です。広大な動物生命の多様性を意味深く扱うためには共通の言語、すなわち生物を論理的かつ階層的な集団に整理する分類体系が必要です。**分類学（taxonomy）**と呼ばれるこの体系は、すべての生物科学の基礎です。

## 分類階層構造

生物学者は入れ子状の階層的分類段階を使用してすべての生物を分類します。最も広いカテゴリから最も狭いカテゴリの順に並べると以下のようになります。

| 段階 | 例（人間） | 記憶法 |
|------|-----------|--------|
| ドメイン (Domain) | Eukarya | **D**ear |
| 界 (Kingdom) | Animalia | **K**ing |
| 文 (Phylum) | Chordata | **P**hilip |
| 綱 (Class) | Mammalia | **C**ame |
| 目 (Order) | Primates | **O**ver |
| 科 (Family) | Hominidae | **F**rom |
| 属 (Genus) | *Homo* | **G**ermany |
| 種 (Species) | *sapiens* | **S**oon |

**DKPCOFGS**（"Dear King Philip Came Over From Germany Soon"）という英語の記憶法はこの順番を覚えるのに役立ちます。各段階は直上の段階よりも排他的です。すべての種は正確に1つの属に、すべての属は1つの科に属するという形で続いていきます。

## 二名法

18世紀にカール・リンネ（Carl Linnaeus）が開発した**二名法（binomial nomenclature）**は、すべての種に固有の2部分からなるラテン語の名前を付与します。最初の部分は属名（大文字で開始）、2番目の部分は種小名（小文字）です。どちらの部分もイタリック体で表記します。例えば *Panthera leo*（ライオン）、*Canis lupus*（オオカミ）などです。

この体系は地域ごとに異なる一般名の問題を解決してくれます。北米で「マウンテンライオン（mountain lion）」と呼ばれる動物は「ピューマ（puma）」または「クーガー（cougar）」とも呼ばれますが、*Puma concolor* という学名は世界中のどこでも同じ動物を指します。

## 分類体系

### 5界説（Whittaker, 1969）
伝統的な分類体系で、生命をモネラ界（Monera）、原生生物界（Protista）、菌界（Fungi）、植物界（Plantae）、動物界（Animalia）の5界に分けます。

### 3ドメイン系（Woese, 1990）
現代の分子系統学（molecular phylogenetics）はリボソームRNAに基づく3つのドメイン（domain）を支持します。
- **細菌ドメイン（Bacteria）** — 核膜のない原核生物
- **古細菌ドメイン（Archaea）** — 独自の生化学的特性を持つ原核生物
- **真核生物ドメイン（Eukarya）** — すべての真核生物（動物を含む）

## 主要な動物門

| 門 (Phylum) | 代表例 | 主な特徴 |
|-----------|---------|---------|
| 海綿動物門 (Porifera) | カイメン | 濾過摂食者、真の組織なし |
| 刺胞動物門 (Cnidaria) | クラゲ、サンゴ | 刺胞（nematocyst）、放射相称 |
| 扁形動物門 (Platyhelminthes) | 扁形動物 | 体腔なし（acoelomate）、左右相称 |
| 線形動物門 (Nematoda) | 線虫類 | 偽体腔（pseudocoelomate）、完全な消化管 |
| 環形動物門 (Annelida) | ミミズ、ヒル | 体節（segmentation）、真の体腔（coelom） |
| 軟体動物門 (Mollusca) | カタツムリ、タコ | 外套膜（mantle）、歯舌（radula） |
| 節足動物門 (Arthropoda) | 昆虫、クモ | 外骨格（exoskeleton）、関節足 |
| 棘皮動物門 (Echinodermata) | ヒトデ、ウニ | 水管系（water vascular system）、五放射相称 |
| 脊索動物門 (Chordata) | 魚類、哺乳類、鳥類 | 脊索（notochord）、腹側神経索 |
