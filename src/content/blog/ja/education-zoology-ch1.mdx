# 제1장: 동물의 왕국 — 분류학과 분류 체계

동물학(zoology)은 동물의 구조, 생리, 행동, 그리고 분류를 아우르는 동물에 대한 과학적 연구입니다. 광대한 동물 생명의 다양성을 의미 있게 다루기 위해서는 공통된 언어, 즉 생물을 논리적이고 계층적인 집단으로 정리하는 분류 체계가 필요합니다. **분류학(taxonomy)**이라고 불리는 이 체계는 모든 생물 과학의 기초입니다.

## 분류 계층 구조

생물학자들은 중첩된 계층적 분류 단계를 사용하여 모든 생물을 분류합니다. 가장 넓은 범주부터 가장 좁은 범주 순으로 나열하면 다음과 같습니다.

| 단계 | 예시 (인간) | 기억법 |
|------|-----------|--------|
| 도메인 (Domain) | Eukarya | **D**ear |
| 계 (Kingdom) | Animalia | **K**ing |
| 문 (Phylum) | Chordata | **P**hilip |
| 강 (Class) | Mammalia | **C**ame |
| 목 (Order) | Primates | **O**ver |
| 과 (Family) | Hominidae | **F**rom |
| 속 (Genus) | *Homo* | **G**ermany |
| 종 (Species) | *sapiens* | **S**oon |

**DKPCOFGS** ("Dear King Philip Came Over From Germany Soon")라는 영어 기억법은 이 순서를 외우는 데 도움이 됩니다. 각 단계는 바로 위 단계보다 더 배타적입니다. 모든 종은 정확히 하나의 속에, 모든 속은 하나의 과에 속하는 방식으로 이어집니다.

## 이명법

18세기 칼 린네(Carl Linnaeus)가 개발한 **이명법(binomial nomenclature)**은 모든 종에 고유한 두 부분으로 이루어진 라틴어 이름을 부여합니다. 첫 번째 부분은 속명(대문자로 시작), 두 번째 부분은 종소명(소문자)입니다. 두 부분 모두 이탤릭체로 표기합니다. 예를 들어 *Panthera leo*(사자), *Canis lupus*(늑대)와 같습니다.

이 체계는 지역마다 다른 일반 이름 문제를 해결해 줍니다. 북미에서 "마운틴 라이언(mountain lion)"이라고 불리는 동물은 "퓨마(puma)" 또는 "쿠거(cougar)"라고도 불리지만, *Puma concolor*라는 학명은 전 세계 어디서나 동일한 동물을 가리킵니다.

## 분류 체계

### 5계 체계 (Whittaker, 1969)
전통적인 분류 체계로, 생명을 원핵생물계(Monera), 원생생물계(Protista), 균계(Fungi), 식물계(Plantae), 동물계(Animalia)의 5계로 나눕니다.

### 3역 체계 (Woese, 1990)
현대 분자 계통학(molecular phylogenetics)은 리보솜 RNA를 기반으로 한 3개의 역(domain)을 지지합니다.
- **세균역(Bacteria)** — 핵막이 없는 원핵생물
- **고균역(Archaea)** — 독특한 생화학적 특성을 가진 원핵생물
- **진핵생물역(Eukarya)** — 모든 진핵생물(동물 포함)

## 주요 동물 문(門)

| 문(Phylum) | 대표 예시 | 핵심 특징 |
|-----------|---------|---------|
| 해면동물문 (Porifera) | 해면 | 여과 섭식자, 진정한 조직 없음 |
| 자포동물문 (Cnidaria) | 해파리, 산호 | 자포(nematocyst), 방사 대칭 |
| 편형동물문 (Platyhelminthes) | 편형동물 | 체강 없음(acoelomate), 좌우 대칭 |
| 선형동물문 (Nematoda) | 선충류 | 가성체강(pseudocoelomate), 완전한 소화관 |
| 환형동물문 (Annelida) | 지렁이, 거머리 | 체절(segmentation), 진정한 체강(coelom) |
| 연체동물문 (Mollusca) | 달팽이, 문어 | 외투막(mantle), 치설(radula) |
| 절지동물문 (Arthropoda) | 곤충, 거미 | 외골격(exoskeleton), 관절 다리 |
| 극피동물문 (Echinodermata) | 불가사리, 성게 | 수관계(water vascular system), 오방 방사 대칭 |
| 척삭동물문 (Chordata) | 어류, 포유류, 조류 | 척삭(notochord), 배쪽 신경삭 |
