[第3章](/ja/academy-cost-accounting-ch3/)と[第4章](/ja/academy-cost-accounting-ch4/)で、個別原価計算と総合原価計算をそれぞれ学んだ。実際の工場は、どちらか一方にぴったり当てはまらないことが多い。この章では、**どの制度をいつ使うか**、そして制度を誤って選ぶと原価がどうゆがむかを扱う。

核心となる問いは二つである。製品単位ごとに**資源の消費が大きく違うか**、そして製品別に原価を**追跡する費用がその情報の価値より小さいか**。どちらも「はい」なら個別原価計算、どちらも「いいえ」なら総合原価計算である。

## 2. 工程別原価計算

衣料工場が綿のシャツとシルクのシャツをつくるとしよう。生地代は製品ごとに大きく違うが、裁断・縫製・包装の工程は同じである。このときは**直接材料費を作業（バッチ）別に追跡**し、**加工費は工程別に集めて換算量単価で配賦**する。

加工費1,200万ウォンを1,500枚で割った1枚当たり0.8万ウォンを工程単価として使い、生地代だけをバッチ別に追跡した。

## 3. 誤って選んだ制度によるゆがみ

同じ工場が総合原価計算を使い、すべての原価を総数量で割ると、1枚当たり原価は$5{,}700 / 1{,}500 = 3.8$万ウォンになる。

<FormulaBox
  label="平均化によるゆがみ"
  formula="\text{原価のゆがみ} = \text{平均単位原価} - \text{実際の単位原価}"
  description="綿シャツは3.8 − 2.3 = +1.5万ウォン（過大）、シルクシャツは3.8 − 6.8 = −3.0万ウォン（過小）である。綿シャツがシルクシャツの原価を肩代わりする「原価の内部補助」が生じる。"
/>

この原価で価格を決めると、綿シャツは競合より高く出してシェアを失い、シルクシャツは原価割れで売って損失を出す。原価計算制度の選択は会計の技術ではなく、価格・製品ミックス決定の土台である。

## 4. サービス業と部門別原価計算

病院、法律事務所、会計事務所は代表的な個別原価計算の業種である。患者や案件ごとに投入時間と資源が違うからである。一方、コールセンターや銀行窓口の取引のような反復的なサービスには、取引当たり平均原価、すなわち総合原価計算の論理が合う。

部門が複数あれば、製造間接費を部門別に集めて**部門別配賦率**を使う。機械中心の部門は機械時間、手作業中心の部門は作業時間で配賦すると、工場全体の単一配賦率より正確である。補助部門費を製造部門に振り替える方法は[第8章](/ja/education-accounting-ch11/)で扱う。

<Callout type="warning">
精緻な制度がいつもよいわけではない。原価の追跡には時間とお金がかかる。製品間の資源消費の違いが小さければ、単純な総合原価計算で十分である。逆に、製品の種類が増えて多品種少量に変わったのに昔の単純な制度をそのまま使うと、原価のゆがみが累積して収益性の判断がひっくり返る。[第9章](/ja/academy-cost-accounting-ch5/)の活動基準原価計算がこの問題への対応である。
</Callout>

## 確認問題

TT社は小型部品A（10,000個）とカスタム部品B（500個）をつくる。直接材料はAが1個当たり1万ウォン、Bが1個当たり6万ウォンである。加工費は総額1億3,000万ウォンで、機械時間を基準にAが8,000時間、Bが2,000時間を使った。すべての原価を総数量で割る方式と、材料は追跡し加工費は機械時間で配賦する方式で、AとBの単位原価はそれぞれいくらか。

総原価は材料$10{,}000 + 3{,}000 = 13{,}000$万ウォンと加工費13,000万ウォンを合わせた2億6,000万ウォンである。総数量10,500個で割ると1個当たり約2.48万ウォンである。材料を追跡し加工費を機械時間で配賦すると、加工費の配賦率は1時間当たり1.3万ウォンである。Aは$1 + 8{,}000 \times 1.3 / 10{,}000 = 2.04$万ウォン、Bは$6 + 2{,}000 \times 1.3 / 500 = 11.2$万ウォンである。単純平均はAを約0.44万ウォン過大に、Bを約8.72万ウォン過小に計算する。
