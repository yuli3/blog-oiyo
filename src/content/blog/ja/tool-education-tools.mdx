# 英語学習ツール集

英語力向上の第一歩は現在のレベルを正確に把握することです。レベルテストで出発点を確認し、フラッシュカードで語彙を積み上げ、タイピング速度を高めて業務の生産性を上げましょう。3つのツールは独立して使うこともできますし、まとめて学習ルーティンとして活用することもできます。

## 英語レベルテスト

語彙・文法問題で現在の英語レベル（CEFR A1〜C1）を素早く診断します。結果に応じて自分に合った学習の方向性を設定できます。

## 英語レベル（CEFR）基準

| レベル | 説明 | TOEIC目安 |
|---|---|---|
| A1 | 入門：簡単な表現が可能 | 120以下 |
| A2 | 初級：日常表現が可能 | 225以下 |
| B1 | 中級：身近なテーマで会話可能 | 550以下 |
| B2 | 中上級：複雑なテーマを理解 | 785以下 |
| C1 | 上級：流暢で自然な表現 | 905以上 |

## タイピング速度の目安（WPM）

| レベル | 英文WPM | 説明 |
|---|---|---|
| 初級 | 20〜30 | 2本指打ち |
| 中級 | 40〜60 | 一般的な事務職レベル |
| 速い | 60〜80 | 専門的な事務職 |
| 非常に速い | 80〜100+ | タイピスト・開発者レベル |

<Callout type="tip">
**フラッシュカード学習法（間隔反復）**：初めて覚えた単語は1日→3日→7日→14日→30日の間隔で復習すると長期記憶に定着します。これがAnkiなどのアプリの核心原理です。
</Callout>
