# 第10講：動名詞と不定詞 — -ing vs. to の完璧ガイド

「enjoy to do? それとも enjoy doing?」英語を学ぶ多くの人が悩むのが**動名詞（Gerund）**と**不定詞（Infinitive）**の使い分けです。この講義でスッキリ解決しましょう！

## 動名詞と不定詞の基本

| 項目 | 動名詞 | 不定詞 |
|------|--------|--------|
| 形 | 動詞 + -ing | to + 動詞原形 |
| 例 | swimming, reading | to swim, to read |
| 感覚 | 行為そのもの（実際に行っていること） | これから行うこと・可能性 |

## 動名詞のみ取る動詞

以下の動詞の後は必ず **-ing形（動名詞）**が来ます：

| 動詞 | 例文 |
|------|------|
| enjoy | *I enjoy **swimming**.* |
| finish | *She finished **reading** the book.* |
| avoid | *He avoids **making** eye contact.* |
| keep | *Keep **trying**!* |
| suggest | *She suggested **going** to the movies.* |
| consider | *I'm considering **changing** jobs.* |
| mind | *Do you mind **opening** the window?* |
| practice | *I practice **speaking** English daily.* |
| give up | *He gave up **smoking**.* |
| can't help | *I can't help **laughing**.* |

**覚え方のヒント**：過去・中断・回避に関係する動詞は動名詞をとりやすい。

## 不定詞のみ取る動詞

以下の動詞の後は必ず **to + 原形（不定詞）**が来ます：

| 動詞 | 例文 |
|------|------|
| want | *I want **to learn** French.* |
| hope | *She hopes **to visit** Paris.* |
| decide | *He decided **to quit** his job.* |
| plan | *We plan **to travel** next summer.* |
| agree | *They agreed **to help** us.* |
| offer | *She offered **to drive** us.* |
| refuse | *He refused **to answer**.* |
| seem | *It seems **to be** working.* |
| manage | *She managed **to finish** on time.* |
| fail | *He failed **to mention** it.* |

**覚え方のヒント**：未来・意図・決断に関係する動詞は不定詞をとりやすい。

## 両方とれるが意味が変わる動詞

<Callout type="important">
以下の動詞は動名詞と不定詞の両方をとれますが、**意味が大きく変わります**！しっかり覚えましょう。
</Callout>

| 動詞 | + 動名詞 | + 不定詞 |
|------|---------|---------|
| **remember** | *I remember **locking** the door.*（過去の動作の記憶） | *Remember **to lock** the door.*（これからすべきことを覚えている） |
| **forget** | *I forgot **meeting** her.*（過去に会ったことを忘れた） | *I forgot **to meet** her.*（会う約束を忘れた） |
| **stop** | *He stopped **smoking**.*（タバコをやめた） | *He stopped **to smoke**.*（タバコを吸うために立ち止まった） |
| **try** | *Try **adding** more salt.*（試しに塩を足してみて） | *Try **to add** less sugar.*（砂糖を減らそうと努力する） |
| **regret** | *I regret **saying** that.*（あれを言ったことを後悔している） | *I regret **to say** this.*（これをお伝えするのは残念ですが） |

## 両方とれて意味が変わらない動詞

| 動詞 | 動名詞 | 不定詞 |
|------|--------|--------|
| love | *I love **swimming**.* | *I love **to swim**.* |
| like | *She likes **reading**.* | *She likes **to read**.* |
| hate | *He hates **waiting**.* | *He hates **to wait**.* |
| begin | *It began **raining**.* | *It began **to rain**.* |
| continue | *She continued **working**.* | *She continued **to work**.* |
| start | *I started **feeling** sick.* | *I started **to feel** sick.* |

## よくあるミスと修正

- ❌ *I enjoy **to swim**.* → ✅ *I enjoy **swimming**.*
- ❌ *She decided **going** abroad.* → ✅ *She decided **to go** abroad.*
- ❌ *Stop **to talk** and listen!* → ✅ *Stop **talking** and listen!*（動作をやめる）
- ❌ *I remember **to see** you last year.* → ✅ *I remember **seeing** you last year.*

## 今日の講義のまとめ

- [ ] 動名詞のみとる動詞（enjoy, finish, avoid等）を覚える。
- [ ] 不定詞のみとる動詞（want, hope, decide等）を覚える。
- [ ] remember/forget/stop/tryは意味が変わることを覚える。
- [ ] love/like/hate/beginは両方使えることを把握する。
