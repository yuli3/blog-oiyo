# 第1章 条件文と宣言の基準

公共企業のロジック作成における最も致命的な間違いは、**条件文の否定**です。 상 언어의 직관과 논리학의 공식이 충돌하기 때문이죠。 今日のクラスでは、その矛盾を完全に解決し、あらゆる文を機械的に変換する能力を獲得します。 

---

## 1. 조건문의 부정: ~(A → B) ≡ A ∧ ~B

これが最も重要な公式です。 「雨が降ると地面が濡れる」という約束を破る（否定する）唯一の状況は何ですか？ 

- **重要なポイント**: 「雨が降らなければ地面は濡れない」ではありません。 
- **공식**: 전건(A)은 그대로 두고、후건(B)만 부정하여 '그리고(∧)'로 연결합니다。 

<式ボックス
式="~(A → B) ≡ A ∧ ~B"
label="条件の否定"
description="「A ではなく B」のみが条件を false にします。 "
color="#ef4444"
/>

<コールアウトタイプ="警告">
**いいえ。受験生の間違い1つ**：「合格したら車を買ってあげる」の否定は「不合格なら車を買ってもらえない」のではなく、**「合格しても車を買ってもらえない状況」**です。 
</吹き出し>

## 2. 条件文と宣言文の交換式

条件文（→）と宣言文（∨）を自由に切り替えて論理問題を解くことができます。 

<式ボックス
式="A → B ≡ ~A ∨ B"
label="条件文-宣言遷移(Orへの矢印)"
description="「A ではない場合、または少なくとも B」は、論理的には「A であれば B」と同等です。 "
color="#3b82f6"
/>

- **使用法**: 「リンゴか梨を食べる (A ∨ B)」 → 「A なら B (リンゴを食べないなら梨を食べる)」
- **실전 팁**: 모든 '또는(∨)' 문장은 화살표 하나가 그려지는 조건문으로 즉시 변환하세요。 

---

## 3. 進化する問題の解決 (ステップ 3: 論理変換)

**問題 2**: 「チョルスが犯人ならヨンヒは無実である」という命題が **偽**である場合、必ず正しいのは次のうちどれですか?

1. チョルスが犯人ではないか、ヨンヒが無罪であるかのどちらかです。 
2. 철수가 범인이 아니면 영희는 결백하지 않다。 
3. 철수는 범인이고 영희는 결백하지 않다。 
4. チョルスは犯人ではないし、ヨンヒは無実ではない。 

<コールアウトタイプ="ヒント">
**[段階的なアルゴリズム]**
1. 문장 기호화: 철수(A) → 영희 결백(B)
2. 문제 요구사항: ~(A → B) 가 '참'인 상황을 찾으라는 것。 (元の命題が「偽」だから)
3. 式の置換: ~(A → B) ≡ A ∧ ~B
4. 解釈：「チョルスは犯罪者（A）、ヨンヒは無実ではない（~B）」

**正解: 3**
</吹き出し>

---

## 4. 進化する問題の解決 (ステップ 4: 複合条件文)

**問題 3**: 以下の 3 つの条件がすべて真である場合、必ず真となるのはどれですか?

> - 条件 1: A が昇格するか、B が昇格する。 
> - 条件 2: B が昇格しても、C は昇格しません。 
> - 条件 3: C が昇格します。 

1. A と B の両方が昇格します。 
2. B は昇進しますが、A は昇進しません。 
3. A は昇進しますが、B は昇進しません。 
4. 何も促進されません。 

<コールアウトタイプ="ヒント">
**[思考プロセス: 矢印の連鎖を作成する]**
1. 条件 1 (宣言) 変換: ~A → B (または **~B → A**)
2. 条件 2: B → ~C
3. 条件 3: **C (確認済みの情報)**
4. 逆推論を開始します。
- C가 참이므로, 조건 2의 대우(~(~C) → ~B 즉, **C → ~B**)에 의해 **~B(B 미추진) 확정.**
- ~B가 확정되었으므로, 조건 1의 변환형(**~B → A**)에 의해 **A(A 추진) 확정.**
5. 結論: **A は昇進しますが、B は昇進しません。**

**正解: 3**
</吹き出し>

## 🚀 20万ウォンの講義から得た洞察
複雑な問題の経験則は、「確立された事実」(この場合は C) から始めて、矢印の方向に逆方向に作業することです。 「または（∨）」が表示された場合は、心配せずに矢印に変更してください。 道が見えてきます。
