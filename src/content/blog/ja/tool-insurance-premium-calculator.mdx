# 保険料計算機

保険料は年齢が若いほど、健康であるほど、保障期間が短いほど低くなります。事前に目安の金額を把握しておくと、予算計画が立てやすくなります。

## 保険の種類と特徴

| 保険の種類 | 保障内容 | 向いている方 |
|---|---|---|
| **終身保険** | 死亡時に保険金支払い（生涯保障） | 扶養家族がいる家族の主たる生計者 |
| **定期保険** | 一定期間の死亡保障、保険料が安い | 30〜40代・コスト重視の方 |
| **がん保険** | がん診断金・治療費支払い | 全年代・がんの家族歴がある方 |
| **医療保険** | 実際の医療費80〜90%保障 | 全年代（必須保険） |
| **年金保険** | 老後の月額年金支払い | 老後準備中の40〜50代 |

<Callout type="tip">
**保険料の適切な割合**：月収の**7〜10%**以内が推奨されます。医療保険 → がん保険 → 死亡保険 → 老後保険の順で優先順位をつけましょう。
</Callout>

## 年齢別保険料の変化（参考例、男性）

| 加入年齢 | 医療保険 月額 | がん保険 月額 |
|---|---|---|
| 20代 | 1,000〜2,000円 | 2,000〜4,000円 |
| 30代 | 2,000〜4,000円 | 4,000〜8,000円 |
| 40代 | 5,000〜9,000円 | 8,000〜15,000円 |
| 50代 | 10,000〜20,000円 | 15,000〜30,000円 |

## 保険加入前のチェックリスト

- 重複保障の確認（職場の団体保険を含む）
- 更新型 vs 非更新型の比較
- 免責期間・削減期間の確認
- 自動引落割引・健康体割引の適用確認

<Callout type="note">
この計算機は**参考用の目安**です。実際の保険料は保険会社・商品・健康告知内容によって大きく異なります。正確な見積もりは保険代理店か保険比較サイトでご確認ください。
</Callout>
