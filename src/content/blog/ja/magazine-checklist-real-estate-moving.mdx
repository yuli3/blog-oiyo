# お部屋探しで絶対に妥協してはいけないチェックポイント

敷金・礼金、仲介手数料など、引っ越しには莫大な初期費用がかかります。「住んでみたら壁が薄くて隣のいびきが聞こえる」「カビがひどい」といったトラブルを防ぐため、**SUUMOやアパマンショップでの内見時**と**引っ越し当日**の必須チェックリストを公開します。

---

## 🏚️ パート1：内見（物件見学）必勝チェックリスト

不動産屋さんのペースに巻き込まれず、自分の目で以下をしっかり確認してください。

### 🚿 設備と環境の確認
- [ ] **水圧と排水のテスト：** キッチンの水を強く出しながら、トイレの水を流してみてください。水の勢いが極端に弱くなるなら、忙しい朝にシャワーと水洗いでストレスを抱えることになります。
- [ ] **壁の防音性テスト：** 壁面を軽くノックしてみます。軽い「コンコン」という音が響く場合（石膏ボード）、隣の部屋の生活音がかなり漏れてきます。重い「ドスッ」というコンクリートの音が理想です。
- [ ] **カビと日当たりの痕跡：** 窓枠周辺やクローゼットの奥を覗いて結露やカビの跡がないかチェック。新しい壁紙でも、湿気のある部屋は独特の匂いがします。
- [ ] **スマートフォンの電波状況：** 意外と盲点です。部屋の奥やトイレで、スマホの電波（4G/5G）がきちんと入るか確認してください。

<Callout type="note">
**なぜ「昼と夜」の2回見に行くべきなのか？** <br/>
昼間は「日当たり」や「部屋の傷」を確認するために行き、夜は「周辺の治安（街灯の暗さ）」や「隣人の騒音トラブル」を確認するために行くべきです。本命の物件は、夜にもう一度建物の周りを歩いてみましょう。
</Callout>

### 📜 契約前の確認事項（特約事項）
- [ ] **退去時のクリーニング代と原状回復：** 契約書の【特約事項】を必ず読み、「退去時のハウスクリーニング代を借主が負担する」等の金額が異常に高くないか確認します。
- [ ] **更新料の有無：** 関東では2年ごとに「家賃1ヶ月分の更新料」が発生するのが一般的ですが、交渉や物件次第で0円になる場合もあります。

### 🕒 引越し完了後の手続き
- [ ] **ライフラインの開始手続き：** 電気と水道はすぐ使えますが、**都市ガス/プロパンガスは業者の開栓立ち会い**が絶対必要です。必ず2週間前までに予約しておきましょう。
- [ ] **転出・転入届とマイナンバーカード：** 引越し後14日以内に、新しい役所で転入の手続きとマイナンバーカードの住所変更を行う必要があります。
- [ ] **郵便物の転送（e転居）：** 漏れを防ぐため、郵便局のサイトから「e転居」を申請し、古い住所宛の郵便物を1年間無料で新住所へ転送してもらいます。
