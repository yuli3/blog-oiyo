# 旅行予算計算機

旅行計画で予算設定は最も重要な第一歩です。漠然と「10万円くらい？」と見積もるのではなく、項目別に正確に計算すると旅行後の出費ショックを防ぎ、より充実した旅を楽しめます。

## 旅行スタイル別の1日あたりの平均予算（1人）

| 旅行先 | バックパッカー | スタンダード | プレミアム |
|---|---|---|---|
| 韓国 | 7,000〜10,000円 | 12,000〜18,000円 | 25,000円以上 |
| タイ・ベトナム | 4,000〜6,000円 | 8,000〜12,000円 | 20,000円以上 |
| ヨーロッパ | 10,000〜15,000円 | 20,000〜30,000円 | 50,000円以上 |
| アメリカ | 12,000〜18,000円 | 25,000〜40,000円 | 70,000円以上 |
| 国内（日本） | 5,000〜8,000円 | 10,000〜15,000円 | 25,000円以上 |

*宿泊・食費・現地交通費を含む、航空券除く*

## 旅費節約のコツ

<Callout type="tip">
**航空券**：2〜3ヶ月前の購入がお得。火曜・水曜出発が安い傾向あり。スカイスキャナーの「1ヶ月全体」表示で最安値を確認。
</Callout>

| 項目 | 節約方法 |
|---|---|
| 航空券 | 早期予約・マイル活用 |
| 宿泊 | Airbnb・ホステル・市街地から少し外れた場所 |
| 食費 | 現地の市場・コンビニ・ランチのセットメニュー |
| 交通 | 1日乗り放題チケット・徒歩・自転車 |
| 両替 | 銀行ATM・旅行前の事前両替 |

## 旅行予算の配分ガイド（総予算比）

| 項目 | 推奨比率 |
|---|---|
| 航空券 | 30〜40% |
| 宿泊 | 20〜30% |
| 食費 | 15〜20% |
| 交通 | 10〜15% |
| 観光・入場料 | 5〜10% |
| ショッピング・お土産 | 5〜10% |
| 緊急資金 | 10%（必須！） |

<Callout type="warning">
海外旅行の際は**旅行保険**は必須です。医療費・手荷物の紛失・フライトの遅延などをカバーし、費用は通常1,000〜3,000円程度です。
</Callout>
