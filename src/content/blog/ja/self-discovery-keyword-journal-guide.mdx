# 好きなキーワードは生活に近い自己紹介

性格診断も役に立ちますが、日常の「好き」はもっと正直なことがあります。話す、説得する、聴く、組み立てる、観察する。好きな飲み物、シャワーの後の風、あたたかい洗濯物の匂い、家の中の小さな安心感。こうした断片は、自分がどんな注意の向け方で元気になるかを教えてくれます。

## 1. 名詞より動詞から始める

名詞は好みを示し、動詞は自分の動き方を示します。

| キーワード | 読み取れること |
| --- | --- |
| 話す | 考えを外に出しながら整理する |
| 説得する | 相手の論理や願いを読むことに関心がある |
| 聴く | 関係の温度や文脈を大切にする |
| 組み立てる | 形になる過程に満足を感じる |
| 観察する | すぐ判断せず、差やパターンを見る |

それぞれの動詞が自然に出た場面を三つ書いてみます。仕事や才能の結論を急がず、具体的な場面から始めます。

## 2. 小さな幸せを集める

幸せは小さく書くほど、今日の中に戻しやすくなります。

- 好きな飲み物
- シャワー後の風
- あたたかい洗濯物の匂い
- 家の中の落ち着く匂い
- 自分らしく整えた小さな場所

何が心地よかったのかを見ます。温度、手触り、匂い、静けさ、記憶、リズム、そばにいた人。

## 3. 会いたい人を書く

会いたい人は、自分が大切にしている価値を映します。安心、学び、感謝、修復、まだ言えていない言葉。名前、もらったもの、今伝えたい一文を書きます。

## 4. 好きなもので一日を少し満たす

人生全体を一度に変えなくて大丈夫です。今日の小さな枠に、好きなキーワードを一つ置きます。

- 動詞: 観察する
- 行動: 10分歩いて色を三つ見つける
- 空間: 机の一角を整える
- ごほうび: 好きな飲み物を飲む

これは固定された性格表ではありません。人の傾向は変わります。「私はいつもこう」より、「最近の私はこれに惹かれる」と書く方が正確です。
