# 宇宙を学ぶための最初の地図

宇宙の勉強でつまずきやすい理由は、言葉が一気に出てくるからです。太陽、惑星、衛星、小惑星、彗星、星、星雲、銀河、ブラックホール。最初は暗記よりも、**大きさ・重力・エネルギーの流れ**で整理すると理解しやすくなります。

## 1. 太陽系とは何か

太陽系の中心は地球ではなく**太陽**です。太陽の重力が、惑星、衛星、準惑星、小惑星、彗星をひとつの仕組みとして結びつけています。

| 天体 | 意味 | 例 |
| --- | --- | --- |
| 恒星 | 核融合で光る天体 | 太陽 |
| 惑星 | 恒星の周りを回る大きな天体 | 地球、火星、木星 |
| 衛星 | 惑星の周りを回る天体 | 月、エウロパ |
| 準惑星 | 惑星に近いが軌道を掃き清めていない天体 | 冥王星 |
| 彗星 | 氷や塵を多く含む天体 | ハレー彗星 |

## 2. 惑星は二つに分けると見える

水星、金星、地球、火星は内側の岩石惑星です。木星と土星はガス巨大惑星、天王星と海王星は氷巨大惑星です。

この区分を知ると、着陸探査が向いている世界と、大気・環・衛星を観測する世界の違いが見えてきます。

## 3. 太陽はなぜ光るのか

太陽は酸素で燃える火ではありません。中心部で**核融合**が起こる星です。水素がヘリウムに変わるときにエネルギーが生まれ、それが光と熱として外へ届きます。

地球の天気、風、海の循環、植物の光合成も、根本では太陽エネルギーに支えられています。

## 4. 星にも一生がある

星はガスと塵の雲から生まれます。重力で物質が集まり、温度と圧力が上がり、核融合が始まります。大切なのは質量です。重い星ほど明るく、短く生きます。

最後は白色矮星、中性子星、ブラックホールなどになります。

## 5. ブラックホールとは何か

ブラックホールは何でも吸い込む掃除機ではありません。中心にあるのは**脱出速度**という考え方です。事象の地平面の内側では、光でさえ逃げることが難しくなります。

| 用語 | 意味 |
| --- | --- |
| 事象の地平面 | そこを越えると脱出が難しい境界 |
| 特異点 | 密度が極端になると考えられる中心 |
| 降着円盤 | ブラックホールの周囲を回る高温の物質 |

宇宙の学習は、地球と月、太陽系、星、銀河、ブラックホール、宇宙論の順に進むと迷いにくくなります。
