## 心理学の核原則を再確認する

```
原則1: 行動には原因がある
→ 衝動に見える行動も、生物・心理・社会の産物

原則2: 生得も環境も効く
→ Nature vs. Nurture → いまは Nature AND Nurture
→ 遺伝子は可能性。環境がどの可能性が実現するかを決める

原則3: 科学的方法が知識と神話を分ける
→ 無作為化比較試験 > 個別事例 > 直感

原則4: 人間は認知バイアスに弱い
→ システム1の速い判断を疑う心の習慣が要る
```

## 関係のなかの心理学

### 魅力と好意

```
近接効果:    近いほど好きになりやすい
単純接触:    反復接触が好意を上げる
類似:        価値と特性を共有する人に引かれる
互恵:        自分を好きな人を好きになりやすい

スタンバーグの愛の三角形:
→ 情熱 ＋ 親密 ＋ コミット = 完成愛
→ 三成分の釣り合いが関係の質を決める
```

### 対立の処理

```
ゴットマン — 関係破綻を予測する四騎士:
1. 批判:    性格や人格への攻撃
2. 軽蔑:    皮肉、冷笑、目を転がす
3. 防御:    自己正当化、反撃
4. 石垣:    情緒の撤退とシャットダウン

→ 軽蔑がいちばん毒
→ 批判を、自分の感情を出す「私」文に置き換える
```

## 職場の心理学

### 動機

```
内発 vs 外発:
→ 過剰な外報酬が内発を減らすことがある
  （過剰正当化効果）

心理的安全性（エイミー・エドモンドソン）:
→ 対人リスクを取っても安全だ、という共有信念
→ 革新と学習の前提
→ Google Project Aristotle: 高成果チームの第1因子

フロー（チクセントミハイ）:
→ 課題が技能と合うときのピーク生産性
→ はっきりした目標 ＋ すぐのフィードバックが要る
```

### 意思決定

```
集団浅慮を防ぐ:
→ 悪魔の代弁者を置く
→ 多様な視点を意図して探す
→ 匿名投票

確証バイアスを超える:
→ 反対仮説を試す（「自分のアイデアが間違っていたら」）
→ プレモータム: 企画が失敗したと鮮やかに想像する — 何が悪かったか
```

## 心理学と健康

```
ストレスと体:
セリエの一般適応症候群（GAS）:
警告 → 抵抗 → 消耗

慢性の高いコルチゾール → 免疫抑制、記憶障害

精神神経免疫学:
→ 心の状態が免疫機能に直接影響する、という読み
→ 正の感情 → NK細胞活性の上昇、という報告

レジリエンスを建てる:
→ 強い社会的支えの網
→ 逆境に意味を見つける（ロゴセラピー）
→ マインドフルネス
```

続く苦しさは専門の助けを先に。この章は治療ではありません。

## 結び

心理学は、人間であることの理解の道具です。

```
心理学が渡し得るもの:

自己理解:
→ 自分の情緒と行動の型の原因を掴む
→ 変わる容量を認める

他者理解:
→ 判断を減らす
→ 行動の背後の文脈を見る

より良い判断:
→ 認知バイアスを認める → より明晰に推論する
→ 集団力学を理解する → より効くチームメンバーになる

レジリエンス:
→ ストレスと逆境を成長の機会に変える
→ 科学で検証された幸福戦略を実務に入れる
```

*他者を理解することは、結局、自分を理解する旅です。*
