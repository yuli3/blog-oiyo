NCS 필기에서 수리능력은 **16%** 비중으로 의사소통능력(18%) 다음으로 높습니다. 50문항 기준 약 8문항. 계산 문제는 정확한 공식을 알면 반드시 맞출 수 있는 영역입니다. 공식 암기 + 실전 계산 연습으로 완전히 정복할 수 있습니다.

## NCS 수리능력 4가지 하위 능력

| 하위 능력 | 내용 | 출제 빈도 |
|----------|------|---------|
| 기초연산능력 | 사칙연산, 비율, 백분율, 단위 변환 | ★★★★★ |
| 기초통계능력 | 평균, 중앙값, 최빈값, 분산, 표준편차 | ★★★★ |
| 도표분석능력 | 표·그래프 독해 및 수치 계산 | ★★★★★ |
| 도표작성능력 | 데이터를 적절한 도표로 표현 | ★★ |

## 1. 기초연산: 반드시 외워야 할 공식들

### 백분율 계산

```
백분율 = (부분 / 전체) × 100
```

예: 500명 중 120명이 합격 → 합격률 = 120/500 × 100 = **24%**

### 증가율·감소율 (시험 최빈출!)

```
증가율(%) = (당기값 - 전기값) / 전기값 × 100
```

예: 전년도 매출 320억, 올해 384억 → 증가율 = (384-320)/320 × 100 = 64/320 × 100 = **20%**

**주의**: 증가율과 증가량을 혼동하지 마세요.
- 증가량: 384 - 320 = 64억 (단순 차이)
- 증가율: 20% (비율)

### 비율과 비례

```
A : B = C : D  →  A×D = B×C (내항의 곱 = 외항의 곱)
```

예: 남:녀 = 3:2인 집단에서 총 250명이면 남성 수는?
3+2=5 부분 중 3이 남성 → 250 × (3/5) = **150명**

### 역수와 배수 관계

A가 B의 n배 → B는 A의 1/n배

A가 B보다 40% 많다 → A = B × 1.4 → B = A / 1.4 = A × (5/7)

A가 B보다 25% 적다 → A = B × 0.75

### 단위 변환 (함정 주의!)

| 변환 | 공식 |
|------|------|
| km → m | × 1,000 |
| m → cm | × 100 |
| kg → g | × 1,000 |
| L → mL | × 1,000 |
| 만 → 억 | × 10,000 |
| 천만 → 억 | × 0.1 |

**시험 최빈 함정**: 도표의 단위가 '천 명'인데 계산할 때 '명'으로 읽는 실수

## 2. 기초통계: 평균·분산·표준편차

### 평균 (Mean)

```
평균 = 모든 값의 합 / 개수
```

예: 5, 7, 8, 10, 5 → 평균 = (5+7+8+10+5)/5 = 35/5 = **7**

### 중앙값 (Median)

데이터를 순서대로 정렬했을 때 가운데 값.
- 홀수 개: 가운데 1개
- 짝수 개: 가운데 2개의 평균

예: 3, 5, 7, 9, 11 → 중앙값 = **7**
예: 3, 5, 7, 9 → 중앙값 = (5+7)/2 = **6**

### 최빈값 (Mode)

가장 자주 등장하는 값.
예: 2, 3, 3, 5, 7, 3, 8 → 최빈값 = **3** (3회 등장)

### 분산 (Variance)

```
분산 = Σ(Xi - 평균)² / N
```

각 값과 평균의 차이를 제곱하여 평균 낸 값.

### 표준편차 (Standard Deviation)

```
표준편차 = √분산
```

분산의 양의 제곱근. 단위를 원래 데이터와 맞추기 위해 사용.

**시험 출제 패턴**: 분산이나 표준편차를 직접 계산하기보다, "분산이 클수록 데이터 편차가 크다" 등의 개념 이해 문제가 더 많이 출제됩니다.

## 3. 도표분석: 시험에서 가장 많이 나오는 유형

### 표(Table) 독해 전략

**5단계 접근법**:

1. **제목 확인**: 무슨 데이터인지 먼저 파악
2. **단위 확인**: 숫자 옆 단위(명/억/% 등) 반드시 체크
3. **행과 열 구조 파악**: 무엇이 행, 무엇이 열인지
4. **선지 하나씩 검증**: 선지에서 언급된 셀(cell)만 찾아 계산
5. **정답이 아닌 것 소거**: 확실히 틀린 것부터 제거

### 막대그래프 독해

- 막대 높이(길이) = 해당 항목의 값
- 두 막대의 차이 = 증가량
- 짧은 막대 / 긴 막대 × 100 = 상대 비율

### 꺾은선 그래프 독해

- 기울기 = 변화 속도 (가파를수록 빠른 변화)
- 상승 구간 vs 하락 구간 파악
- 최대값·최소값 지점 확인

### 원그래프(파이차트) 독해

- 전체 = 360° = 100%
- 각 섹터 각도 / 360 × 100 = 해당 비율
- 가장 큰/작은 섹터 파악

## 4. 실전 계산 문제

### 문제 1: 증가율 계산

> A 기관의 2024년 직원 수: 450명, 2025년: 495명
> 2025년의 전년도 대비 증가율은?

**풀이**: (495 - 450) / 450 × 100 = 45/450 × 100 = **10%**

### 문제 2: 비율과 실수 변환

> 2025년 A 부서 전체 예산 3억 원 중 인건비가 45%이다. 인건비는?

**풀이**: 3억 × 0.45 = **1억 3,500만 원**

### 문제 3: 도표 계산

> [표] 연도별 합격자 수 (단위: 명)
> 2022년: 320명  2023년: 368명  2024년: 423명

**Q1**: 2022→2023 증가율?
(368-320)/320 × 100 = 48/320 × 100 = **15%**

**Q2**: 2023→2024 증가율?
(423-368)/368 × 100 = 55/368 × 100 ≈ **14.9%** ≈ 15%

**Q3**: 2022→2024 증가율?
(423-320)/320 × 100 = 103/320 × 100 ≈ **32.2%**

### 문제 4: 가중평균

> A: 국어 85점(비중 40%), 영어 90점(비중 60%)
> 가중평균 점수는?

**풀이**: 85 × 0.4 + 90 × 0.6 = 34 + 54 = **88점**

### 문제 5: 확률 계산

> 제품 100개 중 불량품 5개. 무작위 1개 선택 시 불량품일 확률은?

**풀이**: 5/100 = **5%** = 0.05

## 5. 자주 나오는 함정 유형 완전 정리

### 함정 1: 증가율 vs 증가량 혼동
"2025년이 2024년보다 가장 많이 증가한 항목" → 증가량(절대값 차이) 기준
"2025년 전년 대비 증가율이 가장 높은 항목" → 증가율(%) 기준

두 기준의 답이 다를 수 있음. 문제를 정확히 읽으세요.

### 함정 2: 단위 착각
도표 단위 '천 명' → 수치 5 → 실제 5,000명
"%로 표시된 값을 실수로 잘못 계산" → 반드시 단위 확인

### 함정 3: 분모 오류
증가율 계산 시 분모는 **전기(비교 기준 시점)** 값
현기 / 전기가 아니라 (현기 - 전기) / 전기

### 함정 4: 합계 오류
"비중의 합 = 100%"가 항상 맞는지 확인
도표에 소계/총계 항목이 있으면 포함 관계 파악 후 계산

## 시험 시간 전략

수리능력 8문항 목표 시간: **12분 이내**

- 기초 계산 문제: 1문항당 60초
- 도표 분석 문제: 1문항당 90초
- 통계 개념 문제: 1문항당 45초

계산 오류를 줄이는 팁:
- **큰 수는 만 단위로 절삭**: 3억 2,400만 → 3.24억
- **분수로 먼저 계산 후 소수**: 3/20 = 15%
- **'어림셈' 활용**: 15.3% ≈ 15%, 선지가 14%/15%/16%/17%이면 15% 선택
