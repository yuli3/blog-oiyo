# マクロ経済学 — 消費は今年の所得だけでなく生涯の資源の関数である

消費はGDPで最も大きな項目であり、消費が所得の変化にどれだけ反応するか(限界消費性向)が乗数の大きさを決める。この章ではケインズの単純な消費関数で乗数を計算したあと、その限界消費性向が**どの所得**に対するものかを問う理論に進む。一時的な給付金と恒久的な減税は同じ数字ではない。

## 1. ケインズ型消費関数とクロス

$C=20+0.8(Y-10)$、投資と政府支出の合計$I+G=50$(兆ウォン)なら、計画支出は$AE=62+0.8Y$である。均衡は計画支出が産出に等しくなる$Y=62+0.8Y$、すなわち$Y=310$兆ウォンである。

政府支出が10兆ウォン増えると、均衡は$Y=72+0.8Y$から360兆ウォンである。乗数は$1/(1-0.8)=5$。MPCが0.6なら乗数は2.5に下がる。乗数の大きさはMPCに非常に敏感である。

## 2. クズネッツの謎

ケインズ型消費関数は、家計の横断面データや短い時系列にはよく当てはまった。高所得の家計ほど所得に占める消費の割合が低かった。ところがクズネッツが数十年の長期データを見ると、平均消費性向はほぼ一定だった。短期には平均消費性向が所得とともに下がるのに長期には下がらないというこの食い違いが**クズネッツの謎**である。次の2つの理論がこの謎に答えた。

## 3. 恒常所得仮説とライフサイクル仮説

**フリードマンの恒常所得仮説**:所得は長期的に期待される**恒常所得**と一時的な**変動所得**に分かれ、消費は主に恒常所得に反応する。ある年の所得が一時的に高い家計は、その年の消費率が低く測定される。横断面で高所得層の平均消費性向が低く見える理由である。長期には変動所得が平均的に相殺されるので、平均消費性向は一定になる。

**モディリアーニのライフサイクル仮説**:人々は生涯の資源を生涯にわたって均等に消費しようとする。勤労期に貯蓄し、引退期に貯蓄を取り崩す。

<FormulaBox
  label="ライフサイクル消費(利子率ゼロの単純形)"
  formula="C = \frac{W + R\,Y}{T}"
  description="Wは現在の資産、Rは残りの勤労年数、Yは年間所得、Tは残りの生涯年数。資産2億ウォン、引退まで20年間年5,000万ウォン、残りの生涯40年なら、C = (2億 + 10億)/40 = 3,000万ウォンである。"
/>

上の例でこの人は勤労期に毎年2,000万ウォンを貯蓄する。資産が1億ウォン増えれば(たとえば住宅価格の上昇)、年間消費は$1\text{億}/40=250$万ウォン増える。資産に対する限界消費性向が0.025という意味である。

## 4. ランダムウォーク消費と流動性制約

ホールは、恒常所得仮説に合理的期待を加えると消費の変化は予測できないはずだという結論を出した。予測可能な所得変化はすでに今日の消費に反映されているからである(**ランダムウォーク消費**)。実証では、予測可能な所得増加(たとえば予定された税還付)にも消費が反応する**過剰感応性**がしばしば観察される。

その理由の一つが**流動性制約**である。将来の所得が高くても今借りられなければ消費を平準化できない。2008年の米国の税還付の研究(パーカーら)では、家計は還付金のかなりの部分を1四半期のうちに支出し、流動資産の少ない家計ほど反応が大きかった。クレジットカードの限度額や住宅ローンの条件が、マクロのMPCを変える経路である。こうした現在バイアスや心の会計の役割は[行動経済学 第4・6章](/ja/academy-behavioral-economics-ch4/)で扱う。

<Callout type="warning">
平均MPC 0.8をあらゆる政策に当てはめると、乗数を大きく過大評価する。一時的な支援が貯蓄や債務返済に漏れる割合は、対象家計の所得・資産・信用状況しだいである。また**節約のパラドックス**(全員が同時に貯蓄を増やそうとすると所得が減り、総貯蓄は意図したほど増えない)は、需要が不足する短期の話である。長期には貯蓄が資本蓄積と成長を支えるという[第11章](/ja/education-economics-ch22/)の命題と矛盾しない。
</Callout>

## 確認問題

上の経済で一時的な移転支出10兆ウォンが支給され、受給家計のMPCが0.3なら、1次の消費増加は。3兆ウォンである。その後の乗数過程で所得が増える家計のMPCが0.8なら、総効果は$3\times 5=15$兆ウォンである。最初からケインズの0.8を当てはめて$10\times 0.8\times 5=40$兆ウォンと計算すると、2倍以上の過大評価になる。
