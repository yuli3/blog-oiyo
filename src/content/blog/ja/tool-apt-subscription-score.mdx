# 韓国マンション申込加点計算機

韓国の分譲マンション申込加点制（청약가점제）は、投機過熱地区・申込過熱地域において分譲物量の一部を加点順に配分する制度です。自分の加点が何点かを正確に把握することが重要です。

## 加点配点表

| 項目 | 最大点数 | 基準 |
|---|---|---|
| **無住宅期間** | 32点 | 15年以上32点、1年未満2点 |
| **扶養家族数** | 35点 | 6人以上35点、0人5点 |
| **청약통장加入期間** | 17点 | 15年以上17点、6ヶ月未満1点 |
| **合計** | **84点** | |

<Callout type="tip">
**無住宅期間**：満30歳または結婚した日から計算（世帯主基準）。住民票で無住宅履歴の確認が必要です。
</Callout>

## 加点別当選可能性（ソウル基準、2023〜2024）

| 加点 | 申込可能エリア | 難易度 |
|---|---|---|
| 70点以上 | 江南3区・人気エリア | 上位1% |
| 60〜69点 | ソウル主要立地 | 難 |
| 50〜59点 | ソウル郊外・首都圏 | 普通 |
| 40〜49点 | 首都圏郊外 | 可能 |
| 40点未満 | 抽選制物量に集中 | 運次第 |

## 1順位申込条件

| 地域 | 条件 |
|---|---|
| 投機過熱地区・申込過熱地域 | 청약통장加入2年以上＋納入24回以上 |
| 首都圏 | 1年以上＋12回以上 |
| 非首都圏 | 6ヶ月以上＋6回以上 |

<Callout type="note">
**2024年の制度変更**：新婚夫婦特別供給の比率拡大、生涯初特別供給の所得要件緩和など、制度が頻繁に変わります。申込前に청약홈(apply.lh.or.kr)の公告文を必ず確認してください。
</Callout>
