## 1. 職務分析と職務設計

### 職務分析 (Job Analysis)
職務を構成するタスク（過業）と職務遂行に必要な資格要件を体系的に把握するプロセス。

**成果物**
- **職務記述書 (Job Description)**: 職務の内容、責任、環境の記述
- **職務明細書 (Job Specification)**: 職務遂行者の資格要件（学歴、経験、スキル）

**職務分析の方法**

| 方法 | 内容 |
|------|------|
| 観察法 | 直接観察によるタスクの把握 |
| 面接法 | 職務遂行者へのインタビュー |
| 質問紙法 | 職位分析質問紙（PAQ）の活用 |
| 重要事件記録法 | 効果的・非効果的な行動事例の収集 |
| 作業日誌法 | 職務遂行者による自己記録 |

### 職務設計 (Job Design)
職務の内容と遂行方法を設計すること。

**職務特性モデル (Hackman & Oldham)**

5つの核心的職務特性:
1. **技能多様性** — 多様なスキルの使用有無
2. **タスクアイデンティティ** — 最初から最後まで完結しているか
3. **タスク重要性** — 他者に与える影響
4. **自律性** — スケジュールと方法を決める権限
5. **フィードバック** — 遂行結果に関する情報

→ 5つの特性 → **3つの心理状態** → **成果の向上**

**職務設計のタイプ**

| タイプ | 内容 |
|------|------|
| 職務単純化 | タスクの分割により効率を最大化（テイラー式） |
| 職務ローテーション | 複数の職務を交代で遂行 |
| 職務拡大 | 水平的拡張（タスク数の増加） |
| 職務充実 | 垂直的拡張（自律性・責任の増加） — Herzberg |

## 2. 募集と選考

### 募集 (Recruitment)
**内部募集**: 内部異動・昇進 → 動機付け、コスト削減 / ただし、停滞のリスク
**外部募集**: 新規採用 → 新鮮なアイデア / ただし、コスト・リスク増

### 選考ツールの信頼性と妥当性

| 概念 | 意味 |
|------|------|
| 信頼度 | 同じ測定を繰り返しても同じ結果が出る一貫性 |
| 内容妥当性 | 測定内容が職務を代表しているか |
| 基準妥当性 | 選考ツールが職務成果を予測できるか |
| 構成概念妥当性 | 心理的特性を正しく測定しているか |

## 3. 人事評価

### 絶対評価 vs 相対評価

| 区分 | 絶対評価 | 相対評価 |
|------|---------|---------|
| 基準 | 事前設定の基準 | 構成員間の比較 |
| メリット | 協力の促進、公正 | 差別化（弁別力）の確保 |
| デメリット | 寛大化エラーの可能性 | 協力の阻害 |

### 主な評価手法

**MBO (目標管理)**
上司と部下が共に目標を設定 → 目標達成度で評価。Druckerが提唱。

**BARS (行動期待尺度法)**
具体的な職務行動の事例を等級別に定義した尺度で評価。客観性が高い。

**360度評価**
上司・同僚・部下・顧客の全員が評価。多面評価。

**行動観察尺度 (BOS)**
特定行動の観察頻度を評価。

### 評価エラー

| エラー | 内容 |
|------|------|
| ハロー効果 | ある特性が他の特性評価に影響する |
| 混合（連鎖）効果 | 先に評価した対象が次の評価に影響する |
| 寛大化エラー | 全員を高く評価する |
| 中心化傾向 | 中間の点数を中心に評価する |
| 近接エラー | 最近の行動にのみ依存する |
| 対比エラー | 評価者自身と比較する |

## 4. 教育訓練

### ADDIEモデル (5段階)

| 段階 | 内容 |
|------|------|
| Analysis (分析) | 教育ニーズ分析、対象者分析 |
| Design (設計) | 学習目標の設定、教授戦略の策定 |
| Development (開発) | 教材・コンテンツの制作 |
| Implementation (実行) | 教育の実施 |
| Evaluation (評価) | Kirkpatrickの4段階評価 |

### Kirkpatrickの4段階教育評価

| 段階 | 評価内容 |
|------|----------|
| 反応 | 教育の満足度 |
| 学習 | 知識・スキルの習得度 |
| 行動 | 現業への適用度 |
| 結果 | 組織成果の向上 |

### 教育訓練の方法

**On-the-Job Training (OJT)**: 職場内訓練 — 上司や先輩が実務の中で指導する
**Off-JT**: 集合教育、講義、セミナー
**CDP (キャリア開発プログラム)**: 体系的なキャリア計画・支援

## 5. 賃金管理

### 賃金のタイプ

| タイプ | 内容 |
|------|------|
| 年功給 | 勤続年数基準 — 安定性、動機付けは弱い |
| 職能給 | 職務遂行能力基準 |
| 職務給 | 職務価値基準 — 公正性、導入の複雑さ |
| 成果給 | 成果・目標達成基準 |

### 福利厚生のタイプ
- **法定福利厚生**: 4大保険（国民年金・健康・雇用・労災）
- **法定外福利厚生**: カフェテリアプラン（選択的福利厚生）を含む
