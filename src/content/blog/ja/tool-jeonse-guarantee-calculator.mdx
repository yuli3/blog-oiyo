# 韓国전세安全度計算機

韓国独自の**전세（チョンセ）**制度：借主が多額の一時金（物件時価の50〜80%程度）を預けて無償で居住し、契約終了時に全額返還される賃貸方式です。

契約前に最も重要なことは、**契約満了時に保証金を完全に返してもらえるか**確認することです。これは家主の信用や意図よりも、**物件の実際の価値と先順位債権**が鍵です。

## 安全度の計算原理

**安全度計算式**：（전세保証金 + 선순위根저당） ÷ 物件時価 × 100

| 比率 | 判定 | 意味 |
|---|---|---|
| 70%以下 | ✅ 安全 | 競売落札後も保証金回収可能 |
| 70〜80% | ⚠️ 注意 | 落札価格下落時に損失リスク |
| 80〜90% | 🔶 危険 | 깡통전세の可能性が高い |
| 90%超 | 🚨 高リスク | 契約の再考を強く推奨 |

<Callout type="warning">
**전세가율80%基準**：KB国民銀行・韓国不動産院の「安心전세アプリ」は전세가率80%以下を安全基準としています。80%超の場合は전세보증보험（HUG・SGI서울보증）への加入を必ず検討してください。
</Callout>

## 전세詐欺防止チェックリスト

| 確認項目 | 方法 |
|---|---|
| 登記簿謄本の確認 | 契約直前と残金支払当日に取得 |
| 선순위根저당の確認 | 登記簿의乙区項目 |
| 建築物台帳の確認 | 違反建築物の有無 |
| 家主の身分証確認 | 登記簿の所有者と一致しているか |
| 転入届・確定日付 | 残金支払当日に即座に処理 |
| 전세보증보험への加入 | 保証金保護の安全網 |
