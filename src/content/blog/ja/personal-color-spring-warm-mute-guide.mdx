봄 웜(Spring Warm) 계절 중에서도 **뮤트(Mute)** 톤 — 선명하지 않고 부드럽게 가라앉은 따뜻한 색상이 가장 자연스럽게 어울리는 봄 웜 뮤트 유형. 봄 웜 라이트나 비비드처럼 선명하거나 투명하지 않고, 채도를 조금 낮추어 따뜻하면서도 은은한 컬러가 피부와 가장 조화롭게 어우러집니다. 이른 봄의 연무 같은, 살짝 안개가 낀 듯한 따뜻한 색감이 봄 웜 뮤트의 키워드입니다.

## 봄 웜 뮤트란?

퍼스널컬러 시스템에서 봄(Spring)은 웜(Warm) 언더톤을 기반으로, 봄처럼 밝고 따뜻한 에너지를 가집니다. 봄 계절 안에서 **뮤트(Mute)**는:

- 채도: **낮음~중간** (선명하지 않고 부드럽게 가라앉음)
- 명도: **밝음~중간** (라이트보다 조금 낮음)
- 톤 특성: 스프링 웜에 회기가 살짝 가미된 소프트 웜 컬러
- 전체적 인상: 자연스럽고 부드러운 봄날의 따뜻함

봄 웜 라이트가 맑고 선명한 봄 하늘이라면, 봄 웜 뮤트는 약간 흐린 봄 하늘 — 더 차분하고 자연스러운 따뜻함입니다.

## 봄 웜 뮤트 체크리스트

자연광 아래, 메이크업 없이 확인하세요.

### 피부 체크

- [ ] 피부 언더톤이 황금빛, 복숭아빛, 또는 아이보리-웜
- [ ] 피부 위에 금반지를 올렸을 때 자연스럽게 조화 (은보다 금이 어울림)
- [ ] 볼에 자연스러운 복숭아빛 홍조가 있음
- [ ] 전체 피부 톤이 따뜻하고 자연스러운 편
- [ ] 너무 선명하고 채도 높은 컬러를 입으면 피부가 오히려 거칠어 보임
- [ ] 봄 웜 라이트처럼 피부가 완전히 맑고 투명하지는 않음 — 조금 더 자연스러운 피부

**봄 웜 라이트/비비드와의 차이**:
- 라이트: 맑고 투명한 피부, 파스텔 봄 컬러
- 비비드: 선명하고 생기 있는 피부, 선명한 코럴-오렌지
- 뮤트: 조금 더 자연스럽고 차분, 은은한 따뜻한 컬러

### 눈 체크

- [ ] 눈동자 색상: 따뜻한 갈색, 황갈색, 또는 헤이즐
- [ ] 눈빛이 전반적으로 부드럽고 자연스러운 인상
- [ ] 흰자가 아이보리 또는 따뜻한 흰색

### 머리카락 체크

- [ ] 자연 모발이 따뜻한 갈색 또는 황갈색 계열
- [ ] 모발이 라이트/비비드 타입보다 조금 어둡거나 덜 선명한 느낌
- [ ] 소프트한 따뜻한 브라운 계열로 염색 시 자연스럽고 예뻐 보임

### 색상 반응 테스트

**잘 어울리는 것으로 보이면 봄 웜 뮤트 가능성 ↑**
- 소프트 코럴 (채도를 낮춘 코럴)
- 웜 로즈 (살짝 뮤트된 로즈)
- 더스티 살구
- 소프트 피치
- 뮤트 오렌지

**안 어울리는 것으로 보이면 봄 웜 뮤트 가능성 ↑**
- 얼음빛 쿨 블루
- 선명한 형광 컬러
- 너무 밝고 강한 쿨 핑크
- 짙고 어두운 뮤트 컬러 (가을 웜 딥 영역)

## 봄 웜 뮤트 베스트 컬러 팔레트

### 🍑 복숭아·살구 계열 (핵심 컬러군)
- **더스티 살구**: 뮤트된 따뜻한 살구색 ★★★
- **소프트 피치**: 부드럽고 은은한 복숭아빛
- **웜 로즈 피치**: 장밋빛이 가미된 복숭아색

### 🌸 로즈·핑크 계열
- **뮤트 코럴 핑크**: 채도를 낮춘 코럴-핑크 ★★
- **더스티 코럴**: 안개 낀 듯한 코럴
- **웜 로즈**: 따뜻한 기운이 있는 로즈
- **소프트 살몬**: 부드러운 연어빛 핑크

### 🟡 옐로우·크림 계열
- **소프트 버터 옐로**: 크리미한 버터빛 노랑
- **웜 크림**: 따뜻한 아이보리-크림
- **소프트 골든**: 너무 선명하지 않은 은은한 골든

### 🌿 그린 계열
- **소프트 민트 (웜)**: 황기가 살짝 가미된 연한 민트
- **라이트 올리브**: 밝고 부드러운 올리브

### 🤍 뉴트럴
- 웜 아이보리 ★★
- 크림 화이트
- 소프트 웜 베이지
- 라이트 카멜

## 봄 웜 뮤트 메이크업 가이드

### 베이스
목표: 자연스럽고 건강한 봄날의 피부 표현

- **파운데이션**: 웜 베이지 언더톤 (핑크 베이스 ×)
- **컨실러**: 웜 아이보리~복숭아빛
- **세팅파우더**: 웜 베이지 또는 아이보리 파우더
- **하이라이터**: 소프트 골드, 피치 골드 (너무 강하지 않게)

### 아이 메이크업
- **아이섀도**: 소프트 코럴 브라운, 웜 베이지, 더스티 로즈 브라운, 피치 브라운
- **아이라이너**: 소프트 브라운, 웜 브라운 (블랙보다 브라운 계열)
- **마스카라**: 브라운 또는 브라운-블랙

피해야 할 아이 메이크업: 쿨 그레이, 파우더 블루, 선명한 퍼플

### 블러셔
- **베스트**: 소프트 피치, 더스티 코럴, 소프트 복숭아빛
- 피해야 할 것: 쿨 핑크, 오렌지-레드 (너무 선명), 라벤더

### 립 메이크업
봄 웜 뮤트의 립은 부드럽고 자연스럽게:
- 더스티 코럴 ★★★ (시그니처)
- 소프트 피치
- 웜 로즈 누드
- 뮤트 코럴 핑크
- 살구빛 누드

피해야 할 립: 쿨 레드, 선명한 오렌지, 쿨 핑크, 짙은 버건디

## 봄 웜 뮤트 패션 가이드

### 추천 코디 포뮬러

**더스티 코럴 + 아이보리**: 더스티 코럴 블라우스 + 아이보리 팬츠 → 자연스럽고 따뜻한 봄 룩

**소프트 피치 + 카멜**: 피치 니트 + 카멜 팬츠 → 부드럽고 세련된 봄 룩

**웜 크림 올인원**: 크리미 화이트 원피스 → 은은하고 자연스러운 봄날

**소프트 민트 + 피치**: 소프트 민트 셔츠 + 피치 스커트 → 봄꽃 같은 조화

### 피해야 할 패션 색상
- 쿨 블루, 라벤더, 쿨 퍼플
- 순백 (너무 차갑고 플랫하게 보임)
- 짙고 어두운 컬러 (가을 딥 영역)
- 형광 컬러

## 봄 웜 뮤트 헤어 추천

### 최고의 헤어 컬러
- 소프트 캐러멜 브라운 ★★★
- 허니 브라운 (조금 탁한 계열)
- 웜 애시 브라운 (너무 차갑지 않은 애시)
- 골든 브라운 (부드러운 계열)

### 피해야 할 헤어 컬러
- 새까만 흑발 (너무 강한 대비)
- 쿨 플래티넘 애시
- 선명한 코퍼 오렌지 (너무 강함)

봄 웜 뮤트는 선명하거나 화려하지 않아도 자연스럽고 부드럽게 아름다운 유형입니다. 뮤트하고 은은한 따뜻한 색상이 당신의 피부와 눈을 가장 편안하고 사랑스럽게 만들어줍니다. 더스티 코럴과 소프트 피치가 당신을 위한 색 — 자연스러움이 가장 아름다운 스타일입니다.
