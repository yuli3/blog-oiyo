# Dデーカウンター

大切な日付をまとめて追跡します。試験まで何日あるか、カップルの記念日から何日経ったか、旅行の出発はいつか、一目で確認できます。

このDデーカウンターは複数のイベントを同時登録してブラウザに保存します。ページを更新してもリストが維持され、各イベントごとに残り日数（D−N）と経過日数（D+N）を自動で切り替えて表示します。

**こんなシーンに便利です：**
- 大学入試・公務員試験・資格試験を準備している受験生
- カップルの記念日（100日・200日・1周年）を忘れたくない方
- 海外旅行の出発までの期待感をカウントしたい方
- プロジェクトの締め切りをチームで共有したいとき

## D−N vs D+N

| 表記 | 意味 | 例 |
|---|---|---|
| **D−30** | 目標日まで30日残り | 試験30日前 |
| **D−0** | 今日がその日 | 当日 |
| **D+100** | 基準日から100日経過 | 100日記念日 |

<Callout type="tip">
**Dデーの語源**：第二次世界大戦のノルマンディー上陸作戦（1944年6月6日）がDデーと呼ばれました。軍事用語から始まり、現在は重要な日を指す一般用語として使われています。
</Callout>

## 活用例

| 用途 | 設定例 |
|---|---|
| 試験対策 | 入試・公務員試験・資格試験日 |
| カップル記念日 | 初めて会った日 → D+100・D+200を自動計算 |
| 旅行 | 出発日までのカウントダウン |
| プロジェクト締め切り | 提出日のDデー |
| 妊娠・育児 | 出産予定日・赤ちゃんの100日・1歳誕生日 |
