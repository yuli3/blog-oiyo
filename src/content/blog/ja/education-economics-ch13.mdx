# マクロ経済学 — 中央銀行が変えるのはベースマネーであって預金の自動的な倍数ではない

[経済学入門 第8章](/ja/academy-economics-basics-ch8/)が貨幣乗数の上限を示したとすれば、この章は乗数がなぜその上限に届かないのか、そして今日の中央銀行が通貨量ではなく金利を目標とするようになって教科書の因果の向きがどう逆転したのかを見る。貨幣需要関数は[第16章](/ja/education-economics-ch27/)、銀行のバランスシートは[第18章](/ja/education-economics-ch29/)でさらに扱う。

## 1. 貨幣の機能と指標

貨幣は**交換の媒介**(物々交換の欲望の二重の一致を不要にする)、**価値の尺度**(価格を一つの単位で表す)、**価値の貯蔵**(購買力を将来に移す)の3つの機能を果たす。3つ目の機能は債券や株式も果たすが、貨幣は収益率が低い代わりに、すぐに使える流動性が最も高い。

## 2. 貨幣乗数:ベースマネーがマネーストックになる過程

銀行は預金の一部だけを準備として残し、残りを貸し出す。貸出金は他の銀行の預金になり、その一部が再び貸し出される。この過程がベースマネーを何倍ものマネーストックにする。

現金・預金比率$c$、法定準備率$r$、超過準備率$e$とすると、マネーストック$M=C+D$、ベースマネー$H=C+R$、$C=cD$、$R=(r+e)D$なので、

<FormulaBox
  label="貨幣乗数"
  formula="\frac{M}{H}=\frac{1+c}{c+r+e}"
  description="r = 10%、c = 20%、e = 0なら乗数は1.2/0.3 = 4。ベースマネー1兆ウォンがマネーストック4兆ウォンになる。現金の漏れと超過準備がないときの上限は1/r = 10である。"
/>

乗数は**上限であって固定値ではない**。人々が現金を多く持てば($c$↑)貸出が預金として戻ってこず、銀行が貸出の代わりに超過準備を積めば($e$↑)連鎖が途切れる。銀行が超過準備10%を積めば、乗数は$1.2/0.4=3$に下がる。逆に準備率を5%に下げても、銀行が超過準備5%を積めば乗数は再び$1.2/0.3=4$である。制度の変化と実際の信用創造は別の数字である。

2008年の金融危機後、多くの中央銀行が資産を大量に買い入れてベースマネーを大きく増やしたが、銀行が超過準備を積んだため、マネーストックはそれほど増えなかった。$e$が大きくなって乗数が急落した例である。

## 3. 通貨量目標から金利目標へ

韓国銀行をはじめ多くの中央銀行は政策金利を定め、短期市場金利がその水準にとどまるよう、必要なだけ流動性を供給または吸収する。銀行が貸出を増やして準備需要が増えれば、中央銀行は金利を守るために準備を供給する。この体制では「ベースマネー → 乗数 → マネーストック」ではなく、「貸出需要 → 預金 → 準備需要 → ベースマネー」の順に因果が逆向きに流れる。ベースマネーが外生変数から内生変数に変わったのである。

## 4. 金利と債券価格

1年後に10,000ウォンを支払う割引債の価格は$P=10{,}000/(1+i)$である。金利が2%なら約9,804ウォン、4%なら約9,615ウォンである。金利の上昇と債券価格の下落は同じ出来事の2つの表現である。中央銀行が債券を買えば(公開市場での買い入れ)債券価格が上がり、金利が下がる。

## 5. 貨幣数量説とその条件

<FormulaBox
  label="交換方程式"
  formula="MV = PY"
  description="マネーストックM、貨幣の流通速度V、物価P、実質産出Y。定義上成り立つ恒等式に近い。"
/>

**貨幣数量説**はこの恒等式に2つの仮定を加える。流通速度$V$が安定し、産出$Y$が貨幣と無関係に潜在水準で決まるなら、$M$の増加は$P$の増加につながる。増加率で書くと$\pi\approx g_M+g_V-g_Y$である。通貨が年8%、実質産出が3%増え、流通速度が一定なら、インフレ率は約5%である。

この関係は長期や高インフレ国ではよく当てはまるが、短期にはあまり当てはまらない。短期には価格が硬直的なので$Y$が貨幣に反応し、金利が変われば貨幣保有需要が変わって$V$も動く。

<Callout type="warning">
「通貨を増やせば物価だけが上がる」は長期の命題である。短期には産出と流通速度も動くので、通貨の増加が物価にどう配分されるかは決まらない。逆に流動性の罠のように金利が下限に張りつくと、貨幣と債券がほぼ代替財になり、債券を買ってベースマネーを増やしても金利をそれ以上下げられない。第4章のLM曲線の水平部分である。
</Callout>

## 確認問題

$r=10\%$、$c=20\%$、$e=0$のとき乗数は4である。銀行が超過準備10%を積むと乗数はいくつか。$1.2/(0.2+0.1+0.1)=3$である。ベースマネー1兆ウォンから生まれるマネーストックが4兆ウォンから3兆ウォンに減る。中央銀行が同じマネーストックを維持するには、ベースマネーを約1.33兆ウォンに増やす必要がある。
