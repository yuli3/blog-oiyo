# 栄養成分計算機

食事を計画したり、今日食べた食品の栄養成分を合計したいときに活用する計算機です。20種類の主要食品の100gあたりの栄養成分データを内蔵しており、摂取量（g）を調整するとリアルタイムで合算されます。

**対応する栄養成分：**
- カロリー（kcal）
- タンパク質（g）
- 脂質（g）
- 炭水化物（g）
- 食物繊維（g）
- ナトリウム（mg）

## 栄養成分の読み方

<Callout type="tip">
**日本人の食事摂取基準（成人目安）**：カロリー2,000kcal・タンパク質55〜65g・脂質50〜65g・炭水化物300g・食物繊維25g・ナトリウム2,000mg以下。（厚生労働省基準）
</Callout>

### ダイエット中に注意すべき食品

| 食品 | 落とし穴 | 理由 |
|---|---|---|
| インスタントラーメン | ナトリウム過多 | 100gあたり1,160mg（1日推奨量の58%） |
| アーモンド | カロリー過多 | 100gあたり579kcal（高カロリー脂肪） |
| チーズ | 飽和脂肪 | 100gあたり33g脂質 |

### タンパク質効率の高い食品トップ5

1. 鶏胸肉：109kcal / タンパク質23.1g
2. 豆腐：76kcal / タンパク質8.1g
3. 卵：155kcal / タンパク質12.6g
4. サーモン：208kcal / タンパク質20.0g
5. 牛肉（サーロイン）：247kcal / タンパク質18.0g

栄養成分データは韓国食品栄養素含量データベースおよびUSDA基準を参照しています。
