## 弱さではない

「長く押しすぎて空になった。」「何も意味がない。」「好きだった仕事なのに、出勤がいちばん重い。」

これが近いなら、先に言うことがあります。**怠惰でも、規律の不足でもない。** バーンアウトには心理と身体の症状が文書化されています。WHOは2019年に職業上の現象として位置づけました。疾患名の自己診断ではありません。

---

## マスラックの定義：三つの次元

クリスティーナ・マスラックは40年以上、バーンアウトを研究しています。交差する三つの次元で定義します。

### 1. 情緒的消耗
「もう出すものがない。」

情緒の蓄えが減る。仕事、関係、役割にエネルギーが残らない。休んでも戻った感じがしない。

### 2. 冷笑・離人
「なぜこれが大事なのか、わからない。」

意味があった仕事から離れる。同僚や相手に機械的に応じ、感情を切る。これ以上減らないための防御、という読み方があります。

### 3. 個人的達成の低下
「やっていることに効果がない。自分には無理だ。」

否定的な自己評価が続く。達成感が消え、無力が残る。

三つが揃うと、バーンアウトとして語られます。

## 12の段階

ヘルベルト・フロイデンベルガーは、バーンアウトは突然ではなく段階で進む、と述べました。

| 段階 | 見え方 |
|-------|-------------------|
| 1 | 自分を証明しようとする強迫（「もっとやらねば」） |
| 2 | より働く（自分で負荷を足す） |
| 3 | 個人の必要を後回し（睡眠、食事、関係） |
| 4 | 対立を避ける（問題を見ない） |
| 5 | 価値のずれ（仕事以外が薄くなる） |
| 6 | 否認（何もおかしくない、と自分に言う） |
| 7 | 社会的な撤退 |
| 8 | 行動の変化（冷笑、いらだち） |
| 9 | 離人（自分と他者からの距離） |
| 10 | 内側の空虚 |
| 11 | 抑うつ |
| 12 | 全面の崩壊（心と体） |

4〜6段階では「忙しいだけ」と言いやすい。その否認自体が段階の一つです。

## バーンアウトを作る六つのずれ

マスラックの研究では、原因は残業だけではありません。**個人と職場のずれ** が六つの領域にあります。

| ずれ | 例 |
|--------------|---------|
| **過負荷** | 要求が資源を大きく超える |
| **統制のなさ** | 結果の責任はあるが、方法の権限がない |
| **報酬の不足** | 給与、認め、意味のいずれも足りない |
| **共同体の崩壊** | 同僚との信頼やつながりがない |
| **公正の不在** | 決定が偏る、見えない |
| **価値の衝突** | 個人の価値と組織の要求が逆を向く |

どのずれが主かを見ると、手を入れる場所がはっきりします。

---

## バーンアウトと抑うつ

症状は重なります。混同されやすいです。

| | バーンアウト | 抑うつ |
|--|---------|------------|
| **範囲** | 主に仕事と役割 | 生活全体に広がりやすい |
| **回復** | 環境の変化と休息で動きやすい | 状況が変わっても残りやすい |
| **自己像** | 比較的残る | 無価値感、自己の溶解 |
| **扱い** | 回復中心 | 専門の治療（対話、薬物など） |

長いバーンアウトは臨床的な抑うつへ進むことがあります。両方が疑われるなら、専門の支えが先です。この記事は診断ではありません。

---

## 回復の原則

### 1. 認める

「自分は燃え尽きている。」失敗の告白ではない。折れた骨に手当てが要るように、消耗にも手当てが要る。

### 2. 負荷を今すぐ減らす

「もっと頑張れば良くなる」は、燃え尽きでは誤りです。折れた足で走ると悪化する。**今なにかを減らす** ことが回復の始まりです。

### 3. 回復と麻痺

Netflixの連続再生や無限スクロールは **麻痺** であり、**回復** ではないことが多い。

回復に近いのは、外を歩く、実際の睡眠、体を使う趣味、信頼できる人との会話。

### 4. 根を見る

考える余白が戻ったら、「何がここまで連れてきたか」。六つのずれを見て、変えられるものを見る。
