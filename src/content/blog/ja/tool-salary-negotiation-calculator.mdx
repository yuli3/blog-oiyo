# 年収交渉計算機

年収交渉の時期になると「いくら上げてほしいと言えばいいのか」途方に暮れることがあります。現在の年収と目標を数字で明確にすると、交渉がずっとスムーズになります。

## 年収昇給率のベンチマーク（2024年基準・韓国）

| 区分 | 平均昇給率 |
|---|---|
| 国内大手企業 | 4〜7% |
| 中堅企業 | 3〜5% |
| スタートアップ（好業績の場合） | 10〜20%以上 |
| 転職時の年収交渉 | **現在の年収＋15〜30%**が可能 |
| 物価上昇率（2024） | 約2.3% |

<Callout type="tip">
**転職が最高の年収交渉**：統計的に転職時の昇給幅（平均20%）が在職中の交渉（平均3〜5%）よりもはるかに大きいです。キャリア計画に転職を戦略的なツールとして活用しましょう。
</Callout>

## 交渉準備チェックリスト

| 準備事項 | 内容 |
|---|---|
| 市場相場の調査 | 転職サイト・LinkedInの年収データ |
| 成果の文書化 | 数値で証明できる貢献リスト |
| BATNAの確保 | 別のオファーや転職意志の準備 |
| 目標範囲の設定 | 最低ライン・目標・理想の3段階 |
| タイミング | 成果評価直後・プロジェクト完了後 |

## 年収交渉の会話例

**NG例**  
「給与を上げてほしいです。生活費が苦しくて……」

**良い例**  
「先四半期の担当プロジェクトで売上15%向上、顧客維持率8%改善を達成しました。市場相場を調査した結果、私の職級・経験に対して〇〇万円水準が適切と考えます。現在の年収から〇〇%の昇給をお願いしたいと思います。」

<Callout type="note">
韓国の手取り額は国民年金・健康保険・雇用保険・産災保険・勤労所得税が控除されます。年収5,000万ウォン基準で手取りは約3,750〜3,900万ウォン程度です。
</Callout>
