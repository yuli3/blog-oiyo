## 本当の関係の相性を高める要素

楽しむための名前相性とは異なり、研究が示す実際の関係満足度を高める要素があります。

| 要素 | 説明 |
|---|---|
| **共通の価値観** | お金・子供・家庭への基本的な考え方が一致 |
| **コミュニケーションスタイル** | 対立時に話し合うか避けるかのパターン |
| **愛着スタイル** | 不安型・回避型・安定型の組み合わせ |
| **成長マインドセット** | 関係は努力で発展できるという信念 |
| **共感能力** | 相手の感情を理解しようとする意志 |

## 愛の言語（5 Love Languages）

ゲーリー・チャップマンの研究によると、人によって愛を表現し受け取る方法が異なります。

| 愛の言語 | 特徴 |
|---|---|
| 肯定の言葉 | 褒め言葉・感謝・励まし |
| クオリティタイム | 集中した時間と関心 |
| プレゼント | 小さな贈り物で気持ちを表現 |
| 奉仕行為 | 助けと行動で愛を表現 |
| 身体的接触 | 抱擁・スキンシップで繋がりを形成 |
