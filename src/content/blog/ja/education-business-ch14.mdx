## 1. STP 戦略

マーケティングの核心戦略フレームワーク — **S**egmentation（市場細分化） → **T**argeting（標的市場選定） → **P**ositioning（ポジショニング）。

### 市場細分化 (Segmentation)

市場を意味のある消費者集団に分類する。

**細分化基準**

| 基準 | 例 |
|------|------|
| 人口統計的 | 年齢、性別、所得、職業 |
| 地理的 | 地域、都市/農村、気候 |
| 心理的 | ライフスタイル、性格、価値観 |
| 行動的 | 購入頻度、使用量、ロイヤルティ |

**有効な細分化の条件**: 測定可能性 / アクセス可能性 / 実質性 / 実行可能性

### 標的市場選定 (Targeting)

| 戦略 | 内容 |
|------|------|
| 無差別マーケティング | 全体市場に単一の製品・メッセージ |
| 差別化マーケティング | 複数の細分市場にそれぞれ異なる戦略 |
| 集中マーケティング | 一つの細分市場に集中 |
| パーソナライズマーケティング | 1対1のカスタマイズ |

### ポジショニング (Positioning)
標的顧客の心の中に製品に対する差別的位置を設定すること。

**ポジショニングマップ**: 2つの属性軸で競合製品の位置を視覚化する。

## 2. 4P マーケティングミックス

McCarthyが提案したマーケティングツール4つ: **製品(Product)・価格(Price)・流通(Place)・プロモーション(Promotion)**。

### 製品 (Product)

**製品ライフサイクル (PLC)**

| 段階 | 特徴 | 戦略 |
|------|------|------|
| 導入期 | 売上低い、損失 | 認知度構築、選択的流通 |
| 成長期 | 売上急増、競争増加 | 市場シェア拡大 |
| 成熟期 | 売上ピーク、競争激化 | 市場細分化、リポジショニング |
| 衰退期 | 売上減少 | 収穫戦略または撤退 |

**製品ミックス**: 製品系列の幅(Width) × 深さ(Depth) × 一貫性(Consistency)

### 価格 (Price)

**価格戦略**

| 戦略 | 内容 |
|------|------|
| 原価加算 | 原価 + 利益マージン |
| 競合基準 | 競合他社の価格基準 |
| 価値基準 | 消費者の知覚価値基準 |
| スキミング | 高価格 → 段階的な価格引き下げ（革新製品） |
| 浸透価格 | 低価格参入 → 市場シェア獲得 |
| 心理的価格 | 9,900ウォン、バンドル価格 |

### 流通 (Place)
**流通チャネルの長さ**: 直接（0段階） → 小売商（1段階） → 卸売・小売（2段階） → 卸売・中間・小売（3段階）

**流通戦略**
- 集約的流通: できるだけ多くの流通店舗（最寄り品）
- 選択的流通: 資格を備えた少数の流通店舗（専門品）
- 専属的流通: 特定地域に1つの流通店舗（高級品）

### プロモーション (Promotion)

**AIDA モデル**: Attention → Interest → Desire → Action

**プロモーションミックス**

| 手段 | 特徴 |
|------|------|
| 広告 | 非人的、大量到達、費用低い/単位あたり |
| 人的販売 | 双方向コミュニケーション、高コスト |
| PR・広報 | 信頼度高い、コントロールが難しい |
| 販売促進 | 短期的な購入刺激（クーポン、割引） |
| ダイレクトマーケティング | パーソナライズ、DM・メール・SNS |

## 3. 消費者行動

### 購入意思決定5段階
問題認識 → 情報探索 → 代替案評価 → 購入決定 → 購入後行動

### 購入後不協和（認知不協和）
高関与製品の購入後、別の代替案のほうが良かったのではないかという不安感。解消策: A/S強化、購入確認メッセージ。

### 消費者行動に影響を与える要因
- **個人的**: 年齢、職業、経済状況、ライフスタイル、性格
- **心理的**: 動機(Maslow)、知覚、学習、態度
- **社会的**: 準拠集団、家族、社会階層

## 4. デジタルマーケティングとCRM

### デジタルマーケティングチャネル

| チャネル | 内容 |
|------|------|
| SEO | 検索エンジン最適化による自然流入 |
| SEM | 検索広告購入（キーワード広告） |
| SNSマーケティング | インスタグラム・YouTube・TikTok活用 |
| コンテンツマーケティング | ブログ・動画による価値提供 |
| メールマーケティング | ターゲット顧客への直接アプローチ |
| インフルエンサーマーケティング | クリエイターコラボレーション |

**ROAS (Return on Ad Spend)** = 広告売上 / 広告費 × 100%

### CRM (顧客関係管理)

顧客データを活用して長期的な関係を構築し、ロイヤルティを高める戦略。

**CRM 3段階**: 顧客獲得 → 顧客維持 → 顧客価値向上

**CLV (顧客生涯価値)**: 1人の顧客が生涯にわたって生み出す予想収益。

**RFM分析**
- R (Recency): 最近購入時点
- F (Frequency): 購入頻度
- M (Monetary): 購入金額

## 5. ブランド管理

**ブランド資産 (Brand Equity)** — Keller基準:
- ブランド認知度
- ブランドイメージ（連想）
- 知覚された品質
- ブランドロイヤルティ

**ブランド戦略**

| 戦略 | 内容 |
|------|------|
| 個別ブランド | 各製品に別ブランド |
| 統合ブランド (Family) | 全製品に企業名を使用 |
| 混成ブランド | 企業名 + 個別名の組み合わせ |
| ブランド拡張 | 既存ブランドで新製品発売 |
| ライン拡張 | 同一カテゴリで変形製品を追加 |
