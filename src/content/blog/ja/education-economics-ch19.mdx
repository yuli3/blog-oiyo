# マクロ経済学 — 物価が動けばIS-LMの一点が総需要曲線になる

[第4章](/ja/education-economics-ch14/)のIS-LMは物価を固定していた。物価が上がると、同じ名目通貨量の実質購買力$M/P$が減ってLMが左に移り、産出が減る。物価と産出のこの関係を結んだものが**総需要(AD)曲線**である。ここに、企業が物価に応じてどれだけ生産するかを表す**総供給(AS)曲線**を加えると、物価と産出が同時に決まる。

## 1. 総需要曲線の導出

第4章の経済(IS:$Y=410-10r$、貨幣需要$0.5Y-20r$)で名目通貨量を$M=180$とし、物価$P$を変数として残すと、LMは$180/P=0.5Y-20r$である。ISと連立して$r$を消去すると、

<FormulaBox
  label="総需要曲線"
  formula="Y = 328 + \frac{72}{P}"
  description="P = 1ならY = 400(第4章の均衡)、P = 1.2なら388、P = 0.8なら418である。物価が上がると実質残高が減って金利が上がり、投資が減る(ケインズ効果)。"
/>

AD曲線**上の移動**は物価の変化によるもので、AD曲線自体の**シフト**は政府支出、税、名目通貨量、期待などの要因による。名目通貨量が10%増えると、ADは$Y=328+79.2/P$となる。同じ産出400を物価1.1で実現する曲線である。

## 2. 短期総供給と長期総供給

**長期**には賃金と価格がすべて調整されるので、産出は労働・資本・技術が決める潜在産出$Y^*$にとどまる。長期総供給(LRAS)は$Y^*$で垂直である。

**短期**には名目賃金契約、メニューコスト、不完全情報のために価格がすぐには調整されない。物価が予想より高ければ企業は生産を増やす。

<FormulaBox
  label="短期総供給"
  formula="P = P^e + \frac{1}{\alpha}\,(Y - Y^*)"
  description="P^eは期待物価。実際の物価が期待より高いときにだけ、産出は潜在水準を超える。期待が実際の物価に追いつけばSRASが上に移り、産出はY*に戻る。"
/>

$Y^*=400$、$P^e=1$、傾き$1/\alpha=0.002$としよう。

## 3. 金融緩和の短期と長期

名目通貨量を10%増やすと、

- **短期**:新しいADと既存のSRASが交わる点は$Y\approx 406.2$、$P\approx 1.012$である。産出が大きく増え、物価は少し上がる。
- **長期**:人々が物価上昇を見て期待物価を上げると、SRASが上に移る。期待物価が1.1になると、新しい均衡は$Y=400$、$P=1.1$である。産出は潜在水準に戻り、物価だけがちょうど10%上がった。

このように名目通貨量が長期には実質変数(産出、雇用)を変えられず、物価だけを変える性質を**貨幣の長期中立性**という。短期の効果がどれだけ大きく長く続くかは、SRASの傾きと期待が調整される速さによる。この調整経路は[第15章](/ja/education-economics-ch26/)でさらに詳しく扱う。

## 4. 4つのショック

<LectureTable
  title="ショック別の短期・長期の結果"
  headers={["ショック", "短期(Y, P)", "長期"]}
  rows={[
    ["総需要の増加(G↑、M↑)", "Y↑ P↑", "Y = Y*、P↑"],
    ["総需要の減少", "Y↓ P↓", "Y = Y*、P↓(調整が遅ければ長い不況)"],
    ["不利な供給ショック(原油価格↑)", "Y↓ P↑(スタグフレーション)", "一時的なら元に戻り、恒久的ならY*が低下"],
    ["有利な供給ショック(生産性↑)", "Y↑ P↓", "Y*が上昇"],
  ]}
/>

不利な供給ショックは政策当局をジレンマに陥れる。総需要を増やして産出を守れば物価がさらに上がり、総需要を減らして物価を抑えれば不況が深まる。1970年代の石油危機がこの状況であり、その対応の選択肢は[第10章](/ja/education-economics-ch21/)と[第13章](/ja/education-economics-ch24/)で扱う。

<Callout type="warning">
垂直な長期総供給は「政策が無力だ」という意味ではなく、産出の**水準**が長期には総需要と無関係だという意味である。潜在産出そのものを増やす成長は[第11・12章](/ja/education-economics-ch22/)のテーマである。また短期の価格硬直性を無視してすべての不況を垂直なASで読むと、総需要不足で生じた失業を「自然な」ものと誤判する。逆に長期の調整を無視すると、総需要の拡大が永遠に産出を増やすと誤判する。
</Callout>

## 確認問題

上の経済で名目通貨量を20%増やすと、長期均衡は。長期には$Y=400$で、ADは$Y=328+86.4/P$なので、$86.4/P=72$から$P=1.2$である。物価はちょうど20%上がる。実質残高$M/P=216/1.2=180$が元と同じになるので、金利と投資も元に戻る。
