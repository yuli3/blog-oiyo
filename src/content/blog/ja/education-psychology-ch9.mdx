## 異常心理学 — 「正常」と「異常」の線はどこか

講義の整理です。自己診断や治療の指示ではありません。続く苦しさは専門の助けを先に。

```
異常行動の 4 D:
Deviance:    社会文化規範からの逸脱
Distress:    本人が主観の苦しみを経験する
Dysfunction: 日常機能や関係への干渉
Danger:      自己または他者への危害リスク

→ 四つが同時に揃う必要はない
→ 文化の文脈が臨界
```

## 主な精神障害（DSMの枠の要約）

### 大うつ病性障害（MDD）

```
症状（5つ以上、ほとんど一日中、少なくとも2週）:
- ほぼ毎日の抑うつ気分
- 興味または喜びの喪失（無快楽）
- 睡眠の乱れ（過眠または不眠）
- 食欲の変化
- 疲労、エネルギーの喪失
- 無価値感または過剰な罪悪感
- 集中の困難
- 死または自殺の反復思考

生涯有病率: およそ15–20%、という報告
女性の診断は男性のおよそ二倍、という報告
```

### 不安障害

```
全般性不安障害（GAD）:
→ 複数の話題への過剰で統制できない心配が6か月超

パニック障害:
→ 突然の強い恐れのエピソード（心拍、息苦しさ、破滅の感じ）
→ 予期せず、反復する

社交不安障害:
→ 恥ずかしい・評価される恐れによる対人場面への強い恐れ
→ 人前での発言、会話、観察されることの回避

特定の恐怖症:
→ 特定の対象や状況への非合理で続く恐れ
→ 高所、蜘蛛、飛行など
```

### PTSD（心的外傷後ストレス障害）

```
外傷事象のあとに発達する:
- 侵入: フラッシュバック、悪夢
- 回避: 外傷に関連する人、場所、思考を避ける
- 負の認知と気分: 罪悪感、他者からの切断
- 過覚醒: 過剰な驚愕、睡眠の乱れ

効くとされる治療: EMDR、持続エクスポージャー
```

## 心理療法の主な接近

### 認知行動療法（CBT）

いま広く使われ、根拠が厚い療法の一つ:

```
核の原則:
思考（認知）→ 感情 → 行動 の結びを変える

認知の再構成:
→ 自動の負思考を特定する
→ 証拠を見る → より釣り合った思考に置き換える

行動活性化:
→ 抑うつ中の快活動への関与を増やす
→ 避けた場に段階的に向かう

エクスポージャー:
→ 恐れ刺激への段階的、系統的な暴露
→ 不安反応の消去を許す
```

専門家の下で行うのが安全です。

### 精神分析 / 力動療法

```
フロイトに根:
→ 無意識の衝突が症状の源
→ 自由連想と夢分析が無意識を暴く
→ 転移の分析（過去の人物への感情を治療者に投影する）

現代の力動療法:
→ 早い愛着経験をいまの関係の型につなぐ
→ 長期（月〜年）
```

### 人間主義療法 — ロジャーズの来談者中心

```
三つの核条件:
無条件の肯定的配慮: 判断なしの受容
共感的理解:         クライエントの目で世界を見る
一致（真正）:       治療者が本物である

人間には自己実現への生得の駆動がある
→ 治療者の役割は、その成長を促す — 指示しない

→ 短い形式でも効く。すべての療法の土台の一つ
```

## 生物学的治療（概観）

```
抗うつ薬:
SSRI（選択的セロトニン再取り込み阻害薬）: フルオキセチン（Prozac）
→ セロトニンの再取り込みを阻害し、シナプス濃度を上げる
→ 効果は通常2–4週後

抗不安薬:
ベンゾジアゼピン: 速いが、依存リスク
→ 短期使用が勧められる

電気けいれん療法（ECT）:
→ 他が失敗した重い抑うつ
→ 効くが、記憶の副作用と関連する
```

薬物は医師の判断です。この講義は処方ではありません。

## 治療選択の案内（教科書の要約）

```
抑うつ:           CBT ＋ 抗うつ薬（組み合わせ > 単独、という報告）
不安障害:         CBT ＋ エクスポージャー（第一選択として語られる）
PTSD:             EMDR、持続エクスポージャー
パーソナリティ障害: DBT、長期力動
統合失調症:       抗精神病薬 ＋ 心理社会的支え
```

## 要点

*異常行動の4 D: Deviance, Distress, Dysfunction, Danger*  
*CBT: 思考–感情–行動の輪を変える — 療法のなかで根拠がいちばん厚い、という位置*  
*SSRI: セロトニン再取り込み阻害 → 抑うつと不安の第一選択薬として語られる*  
*ロジャーズの三条件: 無条件の肯定的配慮、共感、一致*
