여름 쿨(Summer Cool) 계절 중에서도 **라이트(Light)** 톤 — 부드럽고 밝은 쿨 톤 색상이 가장 잘 어울리는 여름 쿨 라이트 유형. 한국에서 "쿨톤 화이트 피부"라고 자주 묘사되는 여름 쿨 라이트는 맑고 투명한 피부에 은은한 쿨 기운을 가진 유형으로, 부드럽고 여성스러운 파스텔 컬러가 얼굴을 가장 생기있고 섬세하게 만들어줍니다.

## 여름 쿨 라이트란?

퍼스널컬러 시스템에서 여름(Summer)은 쿨(Cool) 언더톤을 기반으로, 봄 웜에 비해 차갑고 부드러운 에너지를 가집니다. 여름 계절 안에서 **라이트(Light)**는:

- 채도: **낮음~중간** (부드럽고 은은한 컬러)
- 명도: **높음** (밝고 투명한 컬러)
- 톤 특성: 파스텔, 연한, 블루-베이스 쿨 톤
- 전체적 인상: 청순하고 부드러운 느낌, 물안개 같은 은은함

여름 쿨 뮤트가 스모키하고 차분한 쿨 톤이라면, 여름 쿨 라이트는 맑고 투명한 쿨 톤입니다.

## 여름 쿨 라이트 체크리스트

자연광 아래, 메이크업 없이 확인하세요.

### 피부 체크

- [ ] 피부 언더톤이 핑크베이지, 로즈빛, 또는 차가운 아이보리
- [ ] 피부 위에 은반지를 올렸을 때 피부가 더 밝아 보임 (금반지보다 은반지 효과적)
- [ ] 볼에 자연스러운 핑크빛 또는 장밋빛 홍조
- [ ] 피부가 전체적으로 맑고 투명한 느낌
- [ ] 햇빛에 타면 쉽게 빨갛게 타거나, 타도 핑크빛으로 탐
- [ ] 전체적인 피부 인상이 섬세하고 여려 보임

### 눈 체크

- [ ] 눈동자 색상: 연한 갈색, 적갈색, 또는 차가운 블랙
- [ ] 눈동자에 따뜻한 황금빛보다는 차가운 느낌
- [ ] 흰자가 밝고 맑은 흰색 또는 약간의 블루-화이트
- [ ] 눈의 전체적 인상이 맑고 투명함

### 머리카락 체크

- [ ] 자연 모발이 검은빛, 짙은 갈색, 또는 자연스러운 어두운 색
- [ ] 모발에 따뜻한 붉은빛이나 황금빛이 없음 (차갑거나 중성적)
- [ ] 차갑고 밝은 계열로 염색하면 피부가 밝아 보임
- [ ] 따뜻한 붉은빛 계열로 염색하면 피부가 칙칙해 보임

### 색상 반응 테스트

**잘 어울리는 것으로 보이면 여름 쿨 라이트 가능성 ↑**
- 라벤더
- 연한 파우더 블루
- 소프트 핑크 (차가운 핑크)
- 로즈 핑크
- 라이트 라일락

**안 어울리는 것으로 보이면 여름 쿨 라이트 가능성 ↑**
- 오렌지, 코럴 (너무 주황빛이 도는 것)
- 황금빛 노랑
- 뜨거운 레드 (웜 레드)
- 형광 계열

## 여름 쿨 라이트 베스트 컬러 팔레트

### 핑크 계열 (최고의 컬러군)
- **로즈 핑크**: 여름 쿨 라이트의 시그니처 컬러 ★★★
- **베이비 핑크**: 차갑고 부드러운 파스텔 핑크
- **소프트 핑크**: 파우더 같은 연한 분홍
- **블러시**: 연한 살구-핑크 (차가운 계열)

피해야 할 핑크: 오렌지 핑크(코럴), 살구빛 핑크(웜 피치)

### 파랑·보라 계열
- **파우더 블루**: 연하고 차가운 하늘빛 ★★★
- **라벤더**: 부드러운 연보라 ★★★
- **라이트 라일락**: 연한 보라빛
- **스카이 블루**: 밝고 맑은 하늘색
- **페리윙클**: 청보라 계열

### 초록 계열 (제한적)
- **민트 그린**: 차갑고 신선한 민트
- **소프트 세이지**: 파우더처럼 차분한 세이지 그린

피해야 할 초록: 황록색, 올리브 그린, 라임

### 뉴트럴
- 로즈 화이트 (차가운 흰색)
- 라이트 그레이
- 실버 그레이
- 소프트 라벤더 그레이
- 아이스 핑크

피해야 할 뉴트럴: 아이보리 (너무 노랑빛), 카멜, 베이지 (따뜻한 계열)

## 여름 쿨 라이트 메이크업 가이드

### 베이스
목표: 맑고 빛나는 피부, 보정보다는 투명한 피부 표현

- **파운데이션**: 핑크 베이지 언더톤 (옐로 베이스 ×)
- **컨실러**: 라이트 핑크~분홍빛
- **세팅파우더**: 투명 세팅 파우더 또는 라이트 핑크 파우더
- **하이라이터**: 은빛 펄 또는 로즈 골드 (차가운 계열)

### 아이 메이크업
- **아이섀도**: 핑크 베이지, 라벤더, 로즈, 소프트 브라운, 라이트 퍼플
- **아이라이너**: 그레이-브라운, 소프트 블랙, 연한 소프트 퍼플
- **마스카라**: 블랙 또는 소프트 브라운

피해야 할 아이 메이크업: 황금빛 브론즈, 오렌지 브라운, 웜 테라코타

### 블러셔
- **베스트**: 쿨 핑크, 로즈, 베이비 핑크
- 피해야 할 것: 오렌지 블러셔, 코럴, 복숭아빛

### 립 메이크업
여름 쿨 라이트의 립은 부드럽고 로맨틱하게:
- 로즈 핑크 ★ (시그니처)
- 베이비 핑크
- 라이트 라즈베리
- 쿨 뉴드 (핑크 베이스 누드)
- 소프트 모브

피해야 할 립: 오렌지-레드, 코럴, 황금빛 베이지 누드

## 여름 쿨 라이트 패션 가이드

### 추천 코디 포뮬러

**라벤더 + 화이트**: 라벤더 블라우스 + 화이트 팬츠 → 청순하고 여성스러운 봄 룩

**소프트 핑크 + 라이트 그레이**: 핑크 니트 + 그레이 슬랙스 → 세련된 오피스 룩

**파우더 블루 + 실버**: 파우더 블루 드레스 + 실버 액세서리 → 공주 같은 우아한 룩

**화이트 + 로즈 핑크 포인트**: 화이트 원피스 + 로즈 핑크 벨트·가방 → 청순하고 세련된 베이직

### 피해야 할 패션 색상
- 오렌지, 코럴, 황금빛 계열
- 짙고 무거운 어스 톤 (테라코타, 번트 오렌지)
- 황록색, 올리브

- 라이트 로즈 브라운
