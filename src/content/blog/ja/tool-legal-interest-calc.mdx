# 法定利息計算機（韓国）

利率が契約書にない場合や不明な場合、または訴訟で遅延利息を算定する際に使用する計算機です。

## 韓国の法定利率の種類

| 区分 | 利率 | 根拠 |
|---|---|---|
| 民事法定利率 | 年5% | 民法第379条 |
| 商事法定利率 | 年6% | 商法第54条 |
| 訴訟促進特例 | 年12% | 訴訟促進等に関する特例法第3条 |

**どの利率をいつ使うか？**

- **民事**：個人間の金銭貸借・不当利得返還など
- **商事**：商人間の取引・商行為関連の債権・債務
- **訴訟促進特例**：判決言渡し後に未払いとなった金額に対する遅延利息（2019年6月以降12%）

## 活用事例

| 状況 | 適用利率 |
|---|---|
| 貸したお金が返ってこない（個人間） | 民事5% |
| 取引代金が未収（事業者間） | 商事6% |
| 判決後の支払い遅延 | 訴訟促進特例12% |
| 未払い賃金・退職金 | 最低民事5%（判例により異なる） |
| 損害賠償の遅延 | 不法行為時点から民事5% → 判決後12% |
