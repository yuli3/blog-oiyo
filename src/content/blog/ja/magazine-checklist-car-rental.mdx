# ハンドルを握る前に、必ず行うべき10分の確認

沖縄旅行や北海道ドライブで気持ちよく車を借りて、返却時に理不尽な修理費やNOC（休業補償：Non-Operation Charge）を請求された経験はありませんか？トヨタレンタカーやタイムズカーシェアの利用前、あるいは中古車販売店で車を購入する際、たった10分投資するだけで数十万円を守れる**現場用チェックリスト**を公開します。

---

## 🚗 パート1：レンタカー出発前の10分チェックリスト

スタッフから鍵を渡されても、絶対にすぐエンジンをかけないでください！その場で車の状態を確認し、証拠となる動画を残す必要があります。

### 📸 必須撮影（動画）リスト
- [ ] **車両の下部（バンパー下）：** 立ったままでは見えません。膝を曲げ、フロントバンパー下の擦り傷を撮ってください。
- [ ] **ホイールとタイヤ：** ガリ傷など、ホイールの擦れは最もトラブルになりやすい箇所です。4輪すべてをドアップで撮影します。
- [ ] **サイドミラーカバー：** 狭い路地で最も擦りやすいパーツです。
- [ ] **車のルーフ（屋根）：** 特にSUVの場合に見落としがちですが、木の枝による擦り傷がよく発見されます。
- [ ] **燃料ゲージと走行距離：** 出発時のガソリンが本当に満タンだったかメーターを撮影しておきます。

<Callout type="warning">
**動画撮影のコツ** <br/>
写真よりも、**4Kの高画質動画**でゆっくり車を一周撮影するのが最も確実です。スタッフが「これくらいの傷は問題ないですよ」と言っても、その会話の音声ごと証拠として残してください。
</Callout>

### 📄 契約とNOC（休業補償料金）の確認リスト
- [ ] **免責補償額の確認：** 万が一の事故で自分が最低限支払う免責額（5万〜10万円）がいくらか。
- [ ] **NOC（ノンオペレーションチャージ）の落とし穴：** 免責補償に加入していても、「修理期間中の営業補償（NOC：自走可能なら2万円、不可なら5万円）」は顧客に請求されるケースが多いです。これが免除される「安心Wプラン」等の加入を確認してください。

## 🚙 パート 2：中古車購入前のチェックリスト（カーセンサー等）

営業マンの巧みな話術に騙されないでください。自分の目で直接確認すべき5つの隠されたポイントです。

- [ ] **水没車チェック（シートベルト）：** 運転席と助手席のシートベルトを**最後の一滴まで**引き出してください。先端に泥の跡やカビ臭さがあれば、100％冠水車です。
- [ ] **水没車チェック（シガーソケット）：** シガーソケットの奥をスマホのライトで照らし、ひどく錆びていれば危険なサインです。
- [ ] **ボルトの塗装剝がれ：** ボンネットを開け、フェンダー等のネジ（ボルト）の塗装が剝がれていないか確認します。剝がれていれば、事故修理の為に部品をごっそり交換した可能性が高いです。
- [ ] **エアコンのカビ臭テスト：** エンジンを掛け、エアコンを最低温度で最強風量に設定します。酸っぱいカビの臭いが充満すれば、エバポレーターが深刻な状態です。
- [ ] **オイル漏れ確認：** 車を少し動かし、元々停まっていた地面を見てください。黒いシミが落ちていれば、エンジンやミッションオイルが漏れています。

<Callout type="note">
**修復歴（事故歴）の盲点** <br/>
「修復歴なし」と表示されていても、フレーム（骨格）に影響しないドア交換などは修復歴に含まれません。相場より不自然に安い車には必ず裏があります。第三者機関の鑑定書（Goo鑑定など）があるか確認しましょう。
</Callout>
