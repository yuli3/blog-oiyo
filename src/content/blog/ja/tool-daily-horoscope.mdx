# 今日の運勢

西洋占星術の黄道12宮（ゾディアック）に基づいて今日の運勢を確認します。誕生月による星座で全体運・恋愛運・金運・健康運を見てみましょう。

毎朝1日を始める前に今日のエネルギーの流れを確認することは、日々の計画に軽やかな方向性を与えます。全体運は今日1日全般のエネルギー、恋愛運は関係と感情、金運は金銭・決断、健康運は身体・精神的コンディションを象徴します。

**運勢の活用法：**
- スコアが高い日 → 重要な決断、新しいスタート
- スコアが低い日 → 慎重に行動、エネルギーを温存
- 中間スコア → バランスを保ち、穏やかに
