# 水分摂取量計算機

「1日に水を2リットル飲まなければならない」という言葉を一度は聞いたことがあるでしょう。しかしこの推奨量は**体重・活動量・気温**によって人それぞれ異なります。65kgのデスクワーカーと80kgのアスリートの水分必要量が同じはずはありません。

## 計算式

**基本量** = 体重（kg）× 30ml  
**活動加算**：適度な運動 +350ml / 激しい運動・肉体労働 +700ml  
**気温加算**：普通（20〜30°C）+150ml / 暑い（30°C以上）+350ml  
**利尿補充**：コーヒー1杯 +150ml / アルコール1杯 +250ml

<Callout type="tip">
**コーヒーを飲むと水分を補う必要がありますか？** カフェインには利尿作用があり、水分を早く排出します。コーヒー1杯（アメリカーノ基準）あたり約150mlを追加補充することが推奨されています。
</Callout>

## 脱水のサインチェック

| サイン | 意味 |
|---|---|
| 濃い黄色の尿 | 水分不足の初期サイン |
| 口の渇きと頭痛 | 軽度の脱水（体水分−1〜2%） |
| めまいと集中力の低下 | 中等度の脱水（−3〜5%） |
| ひどい倦怠感と筋肉けいれん | 深刻な脱水（即座に水分補給が必要） |

## 水を飲む時間帯のコツ

| 時間 | 推奨 |
|---|---|
| 起床直後 | 200ml — 夜間の水分損失を補う |
| 食事30分前 | 200ml — 満腹感・消化を助ける |
| 午前・午後の途中 | 200ml × 2〜3回 |
| 運動前・中・後 | 各150〜300ml |
| 就寝1時間前 | 150ml以下 — 夜間頻尿を防ぐ |

<Callout type="note">
一度に500ml以上飲むよりも**200mlずつ数回に分けて**飲む方が吸収率が高いです。2時間ごとにアラームをセットしてコップ1杯ずつ飲む習慣が効果的です。
</Callout>
