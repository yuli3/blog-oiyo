基本的なCVP分析は、[原価計算第13章](/ja/academy-cost-accounting-ch8/)で一つの製品、税引前利益、確定した需要を仮定した。実際の会社は複数の製品を売り、税金を払い、販売量に確信がもてない。この章では三つの仮定を一つずつ外して、CVP分析を実際の意思決定に合わせる。

## 1. 複数の製品とセールス・ミックス

BN社は製品A（販売価格10万ウォン、変動費6万ウォン）と製品B（販売価格8万ウォン、変動費6万ウォン）を3：1の数量比率で売る。共通固定費は1,400万ウォンである。

<FormulaBox
  label="加重平均単位当たり貢献利益"
  formula="\overline{CM} = \frac{3 \times 4 + 1 \times 2}{3 + 1} = 3.5\text{万ウォン}, \qquad Q_{BEP} = \frac{1{,}400}{3.5} = 400\text{個}"
  description="400個を3：1に分けると、A 300個、B 100個が損益分岐点である。二つの製品をまとめた「セット」（A 3個＋B 1個、貢献利益14万ウォン）100セットで計算しても同じである。"
/>

### ア. セールス・ミックスが変わると

ミックスが1：1に変われば、加重平均貢献利益は$(4 + 2)/2 = 3$万ウォンとなり、損益分岐点は約467個に上がる。総販売量が同じでも、貢献利益の低いBの比重が大きくなれば利益は減る。営業のインセンティブを売上高だけに連動させると、売りやすい低マージン製品にミックスが傾きうる。

## 2. 税引後目標利益

法人税があれば、目標とする**税引後**利益を税引前利益に直して計算する。

<FormulaBox
  label="税引後目標利益の販売量"
  formula="Q = \frac{F + \dfrac{\text{目標税引後利益}}{1 - t}}{\overline{CM}} = \frac{1{,}400 + \dfrac{560}{1 - 0.2}}{3.5} = \frac{1{,}400 + 700}{3.5} = 600\text{個}"
  description="税率20%なら、税引後560万ウォンを残すには税引前700万ウォンが必要である。損益分岐点は利益が0なので税金の影響を受けない。"
/>

## 3. 感度分析

仮定が変わると結果がどれだけ揺れるかを見る。BN社がAの価格を10%下げれば（10万→9万ウォン）、Aの貢献利益は3万ウォンとなり、加重平均貢献利益は$(3 \times 3 + 2)/4 = 2.75$万ウォン、損益分岐点は約509個になる。10%の値下げが損益分岐点を27%押し上げる。値下げで販売量が27%を超えて増える自信がなければ、値下げは利益を減らす。

## 4. 不確実性と期待値

販売量が確実でなければ、シナリオ別の確率で期待利益を求める。BN社は新しい広告に300万ウォンを使うか迷っている。広告なしでは販売量が確率50%で500個、50%で700個である。広告をすれば確率50%で600個、50%で900個である。

- 広告なし：期待販売量600個、期待利益$600 \times 3.5 - 1{,}400 = 700$万ウォン
- 広告あり：期待販売量750個、期待利益$750 \times 3.5 - 1{,}700 = 925$万ウォン

広告の期待差額利益は225万ウォンである。ただし最悪のシナリオ（600個）では利益が400万ウォンで、広告なしの最悪（500個、350万ウォン）よりわずか50万ウォン多いだけである。リスクを嫌う経営者なら、期待値だけでなく利益の分散と最悪の結果も見る。

<Callout type="warning">
複数製品の損益分岐点は、**セールス・ミックスが維持されるという仮定**のもとでのみ一つの数字になる。実際のミックスは季節、競争、営業戦略によって変わり続ける。また、固定費を共通費と個別費に分けなければ、製品別の損益分岐点は計算できない。CVP分析は線形近似なので、計画の範囲から遠く外挿しない。
</Callout>

## 確認問題

BO社は製品P（貢献利益率50%）とQ（貢献利益率30%）を売上高基準60：40で売る。固定費は2,100万ウォン、税率は25%である。損益分岐点売上高と、税引後利益900万ウォンのための売上高はいくらか。

加重平均貢献利益率は$0.6 \times 50\% + 0.4 \times 30\% = 42\%$である。損益分岐点売上高は$2{,}100 / 0.42 = 5{,}000$万ウォンである。税引後900万ウォンのための税引前利益は$900 / 0.75 = 1{,}200$万ウォンなので、必要売上高は$(2{,}100 + 1{,}200) / 0.42 ≈ 7{,}857$万ウォンである。
