## 1. 生産システムタイプ

### 生産方式分類

| タイプ | 内容 | 例 |
|------|------|------|
| プロジェクト生産 | 1回限り、大型 | 船舶・橋梁建設 |
| ジョブ・ショップ (Job Shop) | 多品種少量、受注 | カスタムメイド |
| バッチ (Batch) | ロット単位 | 印刷、アパレル |
| ライン (Line) 生産 | 大量標準化 | 自動車、飲料 |
| 連続 (Continuous) 生産 | 24時間フロー | 製油、化学 |

### 設備配置 (Layout)
- **製品別配置 (Product Layout)**: 同一製品の繰り返し生産、効率が高い
- **工程別配置 (Process Layout)**: 類似機能の設備を集中、柔軟性が高い
- **固定位置配置 (Fixed Position)**: 大型製品、資材・人員が製品のほうへ移動

## 2. 需要予測

### 定性的方法
- **デルファイ法 (Delphi Method)**: 専門家による繰り返しの意見収斂
- **市場調査**: 消費者アンケート
- **経営者判断**: 内部専門家の直観

### 定量的方法

| 方法 | 内容 |
|------|------|
| 移動平均法 | 直近n期間の平均で予測 |
| 指数平滑法 | 重み付けで直近データを強調 (α調整) |
| 回帰分析 | 独立変数(x)で需要(y)を予測 |
| 時系列分解 | トレンド・季節・循環・不規則分解 |

**MAD (平均絶対偏差)**: 予測誤差の大きさを測定する指標 = Σ|実際値 − 予測値| / n

## 3. スケジューリング: PERT/CPM

**PERT (Program Evaluation and Review Technique)**: 不確実性の高いプロジェクト — 楽観値・最頻値・悲観値で期待時間を計算。

**CPM (Critical Path Method)**: 確定的時間推計 — 最長経路（クリティカルパス）を把握。

**クリティカルパス (Critical Path)**: プロジェクト完了にかかる最小時間を決定する経路。
→ クリティカルパス上の活動の遅延 = プロジェクト全体の遅延。

**余裕時間 (Slack)** = 遅い開始 − 早い開始。クリティカルパスの余裕時間 = 0。

## 4. 在庫管理

### 在庫タイプ
- 原材料在庫 / 仕掛品 (WIP) 在庫 / 完成品在庫
- 安全在庫 (Safety Stock): 需要の不確実性に備える緩衝在庫

### EOQ (経済的発注量)

**EOQ公式**: EOQ = √(2DS/H)
- D: 年間需要量
- S: 1回あたりの発注費用
- H: 単位あたり年間保管費用

**前提条件**: 需要が一定、発注即時入庫、欠品不許可。

**発注点 (ROP)** = 1日の需要 × 調達期間

### JIT (Just-In-Time) / リー生産 (Lean Production)

必要な時に必要な量だけ生産・調達 — 在庫を最小化。

**カンバン (Kanban)**: 部品の流れを視覚的に統制するカードシステム。

**リー生産の7つの無駄**
作りすぎ / 待機 / 運搬 / 作りすぎの加工 / 在庫 / 動作 / 不良

## 5. 品質経営

### TQM (総合的品質管理)
組織全体が継続的改善に参加する経営哲学。

**TQMの核心原則**: 顧客中心 / 継続的改善 / 全員参加 / プロセス中心

### PDCAサイクル (デミングサイクル)
Plan(計画) → Do(実行) → Check(確認) → Act(改善) → 繰り返し

### シックスシグマ (Six Sigma)
不良率を100万個中3.4個以下に減らす品質革新方法論。

**DMAIC**: Define(定義) → Measure(測定) → Analyze(分析) → Improve(改善) → Control(管理)

### ISO 9000 シリーズ
国際品質経営システム標準。ISO 9001: 品質経営システム認証基準。

### 品質コスト (PAFモデル)

| コストタイプ | 内容 |
|-----------|------|
| 予防コスト | 不良防止活動 (教育、設計レビュー) |
| 評価コスト | 検査、試験、監査 |
| 内部失敗コスト | 出荷前に発見された不良 (手直し、廃棄) |
| 外部失敗コスト | 出荷後に発見された不良 (返品、A/S、賠償) |

## 6. サプライチェーン管理 (SCM)

原材料調達から最終顧客までの物流・情報・資金の流れを統合管理。

**ブルームウェップ効果 (Bullwhip Effect)**: 消費者の需要変動がサプライチェーンの上流に向かうほど増幅する現象。
→ 解決策: 情報共有、発注サイクルの短縮、VMI (ベンダー主導型在庫管理)。
