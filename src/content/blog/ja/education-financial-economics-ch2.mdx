# 金融経済学 — リスクのあるキャッシュフローは、期待値が同じでも価格が違う

第1章の状態価格$q_s$を確率で割ると、確率的割引因子(SDF)になる。この章では、その値がなぜ不況で大きくなるのか、そして企業財務で使うCAPMがどの仮定のもとでの特殊ケースなのかを見る。

## 1. 限界効用の高い状態の1ウォンのほうが高い

代表的消費者がいて、効用が時間について分離可能だとする。今日の消費を1ウォン減らして状態$s$で1ウォン多く得る対価は、限界効用の比率である。

<FormulaBox
  label="確率的割引因子"
  formula="m_s = \beta u'(c_s) / u'(c_0)"
  description="不況のように消費が少なく限界効用が大きい状態ではmが大きくなり、その状態のキャッシュフローはより高い現在価値を受ける。"
/>

資産価格は、キャッシュフローと$m$の積の期待値である。

<FormulaBox
  label="資産価格"
  formula="p = E[m x]"
  description="xが不況で大きい資産(保険、国債)はE[m x]が大きくなり、価格が高く期待収益率は低い。"
/>

期待収益率で書き直すと、$E[R] - r_f = -(1+r_f)\,\mathrm{Cov}(m, R)$である。市場と一緒に動く資産は$m$と負の共分散を持つので、リスク・プレミアムは正である。価格に入るリスクは「分散が大きい」ことではなく、「悪い状態で損失が出る」ことである。

## 2. 数字で見ると、保険は株式より高い

無リスク金利を2%、好況・不況の確率をそれぞれ50%とする。好況では$m=0.90$、不況では$m=1.06$である。平均は$E[m]=0.98$なので、$1/E[m]≈1.0204$で無リスク金利と合う。

株式は好況で140ウォン、不況で70ウォンを支払う。価格は$0.5×(0.90×140 + 1.06×70) = 100.1$ウォンである。期待キャッシュフローは105ウォンだが、価格はそれより低い。保険金は好況で0ウォン、不況で100ウォンである。価格は$0.5×1.06×100 = 53$ウォンで、期待キャッシュフロー50ウォンより高い。同じ期待値50ウォンでも、不況に集中していればプレミアムを払って買う。

## 3. CAPMは、SDFが市場収益率の線形であるときに出てくる

平均・分散の選好を持つか、収益率が正規分布に従うなら、選択は平均と分散だけで決まる。そのときSDFは市場ポートフォリオの収益率の線形になり、リスク・プレミアムはベータに比例する。

<FormulaBox
  label="CAPM"
  formula="E[R_i] = r_f + \beta_i (E[R_m]-r_f)"
  description="ベータは資産と市場の共分散を市場の分散で割った値である。固有リスクは分散されれば価格に残らないという主張である。"
/>

企業実務でのCAPMの使い方は[企業財務第4章](/ja/education-finance-ch4/)にある。ここで重要な限界は三つある。市場ポートフォリオは観測できない。消費のリスクと市場収益率は異なりうる。労働所得や住宅のように取引されないリスクは、ベータの外に残る。

<Callout type="warning">
株式の歴史的な超過収益率が消費のリスクで説明するには大きすぎる、というのが株式プレミアム・パズルである。モデルを棄却せずに「人々はもっとリスク回避的だ」だけで埋めると、無リスク金利パズルと衝突する。説明は習慣形成、長期リスク、災害リスクなどに分かれ、合意された一つの式はない。
</Callout>

## 確認問題

市場と逆に動く資産の期待収益率は、無リスク金利より高いか。高くない。消費が少ない状態で利得を生むのでSDFと正の共分散を持ち、リスク・プレミアムが負になって、期待収益率は無リスク金利より低い。第2節の保険は53ウォンで買って平均50ウォンを受け取るので、期待収益率は約−5.7%である。
