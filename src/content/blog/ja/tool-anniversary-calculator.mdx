# 記念日計算機

交際を始めた日や大切な日を覚えていたいとき、正確な記念日の日付を計算するのは意外と面倒です。月ごとに日数が違い、うるう年の計算もあり、「あれ、もう2年？3年？」と混乱することも。

この計算機は**基準日を1つ入力するだけ**で、その後のすべての主要な記念日を自動で計算します。

**計算できる記念日：**
- 22日・50日・100日・200日・300日 — 短期記念日
- 500日・1000日 — 長期日数記念日
- 1周年・2周年・3周年・5周年・10周年 — 年単位記念日

## 記念日の活用ヒント

### どんな基準日でも使えます

| 基準日 | 活用例 |
|---|---|
| 初めて会った日 | カップルの記念日計算 |
| 入社日 | 勤続記念 |
| 誕生日 | 年齢・誕生日関連の日付 |
| 開業日 | 創業記念日 |
| ペットを迎えた日 | ペット記念日 |
| 禁煙・ダイエット開始日 | 習慣トラッキングの動機づけ |

<Callout type="tip">
**100日 vs 1周年**: 混同しやすいですが、100日記念は開始日から99日後（通算100日目）、1周年は正確に1年後です。この計算機は両方を正確に計算します。
</Callout>

### カウントダウン表示

記念日が近づくと残り日数が**D−N**形式で表示されます。過去の記念日は履歴として確認できます。特定の日までのカウントダウンが必要な場合は、[D-Dayカウントダウン](/ja/tool-dday-calculator)も合わせてご活用ください。
