# 経済学概論 — GDPは厚生ではなく、市場で測った最終生産である

マクロの出発点は「国の成績表」ではない。**一定期間に、一つの領土内で、市場価格で評価した最終財・サービス**である。何を入れて何を除くかが、面接の問いの落とし穴である。

## 1. 支出・生産・所得は同じ循環を三つの面から見る

<FormulaBox
  label="支出面からのアプローチ"
  formula="Y = C + I + G + (X-M)"
  description="Cは家計消費、Iは設備・建設・在庫変動、Gは政府の消費・投資(移転支出を除く)、X−Mは純輸出。"
/>

小麦を買ってパンをつくれば、小麦は中間財なのでGDPに直接は入れない。パンの価格にすでに含まれている。在庫として残った小麦は投資(在庫の増加)として計上される。中古品はその期に生産されたのではないので、マージンだけがサービスとして計上されうる。移転支出(失業給付)はGではない。

1年目の名目GDP:りんご10個×1,000ウォン+梨5個×2,000ウォン=20,000ウォン。2年目:りんご12×1,200+梨5×2,200=25,400ウォン。基準年の価格で見た2年目の実質は$12×1000+5×2000$=22,000ウォン。成長率は10%であって27%ではない。

<FormulaBox
  label="GDPデフレーター"
  formula="\text{デフレーター} = \text{名目GDP} / \text{実質GDP} \times 100"
  description="この数値では25400/22000×100≈115.5。物価は約15.5%上がり、数量は10%増えた。"
/>

CPIは固定されたバスケットの消費者価格、デフレーターは国内生産全体の現在の構成である。輸入消費財はCPIにはあるが、デフレーターでの比重は小さい。「インフレ率は何%か」は指数の選択の問題である。

## 2. GDPが数えないもの

家庭内の生産、環境破壊、余暇、分配、闇市場は、抜けているか誤って入っている。公害が復旧の支出を生めば、GDPは上がりうる。成長率の発表を、厚生の改善と同じ文として読まない。

潜在GDPは、インフレを加速させずに生産できる水準である。実際のGDPがそれを下回ればGDPギャップ(マイナス)、上回れば過熱である。循環はトレンドの周りの変動であり、そのたびに異なる原因(需要ショック、供給ショック)を同じ「不況」と呼べば政策を誤る。供給ショックの不況で需要だけを刺激すれば、物価が上がるだけである。

## 3. 失業は成長の裏面ではなく、別のフローである

失業率は、労働力人口に対する求職者の割合である。求職をあきらめると分母と分子がともに減り、失業率は低く見えることがある。就業率がその錯覚を補う。オークンの法則は経験的な相関であって恒等式ではない。

<Callout type="warning">
名目成長率の高い年に「景気がよい」と書かない。原油価格が輸入物価を押し上げれば、名目は膨らみ、実質は止まることがある。逆にデフレの局面では、名目賃金の据え置きは実質賃金の上昇である。常に物価指数を一緒に見る。
</Callout>

国民総所得(GNI)は、海外からの純要素所得を加える。海外工場からの配当が大きい国では、GDPよりGNIのほうが意味をもつこともある。指標を選ぶこと自体がすでに分析である。

## 確認問題

公務員の賃金10兆ウォンと失業給付10兆ウォンは、どちらもGDPに入るか。賃金は政府消費(生産)なので含まれ、失業給付は移転なので含まれない。受給者がそのお金で消費すれば、Cを通じて間接的に計上される。二つの10兆ウォンをともにGに足すのは、二重計算であり誤った分類である。
