# 中古デバイス取引で個人情報とお金を守る方法

最新のiPhoneやMacBookの価格が高騰する中、メルカリやヤフオク、ジモティーを利用した高額な電子機器の中古取引が活発化しています。しかし「赤ロム（ネットワーク利用制限端末）」を掴まされたり、初期化が甘くてプライベートな写真が流出するトラブルも起きています。この**中古デジタル機器チェックリスト**で、あなたのお金とプライバシーを守りましょう。

---

## 🔒 パート1：「売る時」の個人情報完全保護リスト

ただ単に「初期化」ボタンを押すだけでは危険です！クラウド連携を根本から絶つ必要があります。

- [ ] **ステップ 1：アカウントからの完全ログアウト**
  - **iPhone (iOS)：** 設定 ➔ 一番上の名前をタップ ➔ 一番下の「サインアウト」➔ ここで「「探す」のアクティベーションロック解除」を確実に確認します。
  - **Android：** 設定 ➔ アカウント ➔ Googleアカウントなどを完全に削除。
- [ ] **ステップ 2：Bluetoothのペアリング解除**
  - 以前接続していたAirPodsやApple Watchなどのデバイス情報を「このデバイスの登録を解除」ですべて消去します。
- [ ] **ステップ 3：最終的な工場出荷状態へのリセット**
  - アカウント削除後、「すべてのコンテンツと設定を消去」を実行します。
  - *Tip：* スマホの場合、初期化する前にダミーの大きな動画ファイルを容量限界まで詰め込んでから消去すると、データ領域が上書き(Overwrite)され、悪意あるデータ復旧を強力に防ぐことができます。

## 🔎 パート 2：「買う時」の不良品見極めリスト

メルカリなどで受け取り評価をする前に、必ずこれらのテストを行ってください（評価後は返金が難しくなります）。

### 📱 スマホの動作・状態チェック
- [ ] **IMEI（端末暗証番号）による「赤ロム」チェック：** 出品画像や説明欄のIMEI番号を「ネットワーク利用制限確認サイト」に入力し、「〇」判定であることを確認します（「△」や「×」は将来通信できなくなる危険があります）。
- [ ] **バッテリーの最大容量確認：** 
  - iPhone：設定 ➔ バッテリー ➔ バッテリーの状態。「80％」付近の場合はすぐに交換費用（約1万円〜）が発生するため、値引き交渉の材料になります。
- [ ] **画面の焼き付き（バーンイン）テスト：** 真っ白なメモ帳アプリを全画面表示にし、キーボードなどの影が画面に焼き付いていないか確認します。
- [ ] **全機能の動作テスト：** 
  1. 自分のSIMカードを挿して、即座に電波（4G/5G）を掴むか。
  2. カメラ撮影、マイクの録音テスト。
  3. 各物理ボタン（音量、マナーモードスイッチ）の反応。

### 💻 MacBook・ノートPCのチェック
- [ ] **バッテリーの充放電回数：** 
  - Macの場合：Optionキーを押しながら左上のAppleロゴをクリック ➔ システム情報 ➔ 電源 ➔「充放電回数」を確認します（通常300回未満なら良好）。
- [ ] **キーボード反応テスト：** メモ帳を開き全てのキーパッド（特に端のキーとスペースバー）が正常に打てるか確認します。
- [ ] **ヒンジ（画面の接続部）の緩み：** 画面を45度や90度に開いた際、グラグラと落ちてこないか確認します。
