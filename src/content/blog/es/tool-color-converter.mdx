# Convertidor de Colores

Cada formato de color tiene su ámbito de aplicación: HEX para la web, RGB para pantallas y programación, HSL para ajustes intuitivos, HSV para ruedas de color. Convertir manualmente entre estos formatos es propenso a errores — esta herramienta lo hace al instante.

## Formatos de color explicados

| Formato | Sintaxis | Uso principal |
|---|---|---|
| **HEX** | `#FF5733` | CSS, HTML, diseño web |
| **RGB** | `rgb(255, 87, 51)` | Pantallas, Canvas, CSS |
| **RGBA** | `rgba(255, 87, 51, 0.8)` | CSS con transparencia |
| **HSL** | `hsl(14°, 100%, 60%)` | Ajustes tono/saturación |
| **HSV** | `hsv(14°, 80%, 100%)` | Adobe, herramientas gráficas |
| **CMYK** | `C0 M66 Y80 K0` | Impresión offset |

<Callout type="tip">
**Consejo de diseño**: Usa HSL para crear paletas armoniosas. Para crear una variante más clara o más oscura, mantén el tono (H) y la saturación (S) y varía solo la luminosidad (L). Ej: `hsl(220°, 80%, 60%)` → versión clara: `hsl(220°, 80%, 85%)`
</Callout>
