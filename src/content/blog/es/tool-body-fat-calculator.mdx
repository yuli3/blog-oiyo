# Calculadora de Grasa Corporal

El peso solo no refleja tu composición corporal. Dos personas con el mismo peso y talla pueden tener porcentajes de grasa corporal radicalmente diferentes. **La masa grasa** es un indicador mucho más preciso de la salud metabólica.

## Categorías de grasa corporal (ACSM)

### Hombres

| Categoría | 20–29 años | 30–39 años | 40–49 años | 50–59 años |
|---|---|---|---|---|
| Excelente | < 11 % | < 12 % | < 14 % | < 15 % |
| Bien | 11–13 % | 12–14 % | 14–16 % | 15–17 % |
| Media | 14–20 % | 15–21 % | 17–23 % | 18–24 % |
| Por encima | 21–23 % | 22–24 % | 24–26 % | 25–27 % |
| Obesidad | > 23 % | > 24 % | > 26 % | > 27 % |

### Mujeres

| Categoría | 20–29 años | 30–39 años | 40–49 años | 50–59 años |
|---|---|---|---|---|
| Excelente | < 16 % | < 17 % | < 18 % | < 19 % |
| Bien | 16–19 % | 17–20 % | 18–21 % | 19–22 % |
| Media | 20–28 % | 21–29 % | 22–30 % | 23–31 % |
| Por encima | 29–31 % | 30–32 % | 31–33 % | 32–34 % |
| Obesidad | > 31 % | > 32 % | > 33 % | > 34 % |

<Callout type="note">
**Fórmula US Navy**: Usa el perímetro de cintura (y caderas en mujeres) y cuello. Más práctico que la pesada hidrostática pero con un margen de error de ±3–4 %.
</Callout>

## Estrategia de pérdida de grasa

| Estrategia | Detalle |
|---|---|
| Déficit calórico | 500 kcal/día → pérdida de ~2 kg de grasa/mes |
| Proteínas | 1,6–2,2 g/kg de peso corporal para preservar músculo |
| Cardio + fuerza | La combinación es más eficaz que el cardio solo |
| Velocidad óptima | Reducción de 0,5–1 % de grasa/semana |
